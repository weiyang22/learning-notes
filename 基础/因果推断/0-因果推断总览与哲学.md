## 阅读前置：一套统一语言

### 处理、结果与反事实

设 $A\in\{0,1\}$ 为处理，$Y$ 为结果，$X$ 为处理前协变量。每个个体都有潜在结果 $Y(1)$ 与 $Y(0)$，但同一时刻只能观察其中一个。
因果效应不是 $P(Y\mid A=1)-P(Y\mid A=0)$ 这个裸差异，而是同一目标人群在两种处理世界中的结果差。

```math
ATE = E[Y(1)-Y(0)]
ATT = E[Y(1)-Y(0) | A=1]
CATE(x) = E[Y(1)-Y(0) | X=x]
```
### 三类假设

| 假设 | 含义 | 违反时的风险 |
| --- | --- | --- |
| 一致性 | 实际接受的处理等于对应潜在结果 | 处理定义含糊，估计对象不清 |
| 可交换性 | 给定协变量后处理分配与潜在结果独立 | 残余混杂，观察差异不等于因果效应 |
| 正值性 | 每类协变量都存在接受各处理的概率 | 没有重叠，模型只能外推 |

### 因果问题的最小模板

1. 谁是决策单位？2. 处理是什么？3. 结果窗口多长？4. 反事实是什么？5. 识别假设是什么？6. 估计量如何验证？7. 哪个指标决定上线？

### 用 NumPy 构造随机化实验

```python
import numpy as np

rng = np.random.default_rng(7)
n = 20_000
x = rng.normal(size=n)
a = rng.binomial(1, 0.5, size=n)
y = 2.0 * a + 0.8 * x + rng.normal(size=n)
ate = y[a == 1].mean() - y[a == 0].mean()
print(f"estimated_ate={ate:.3f}")
assert abs(ate - 2.0) < 0.08
```

### 用 PyTorch 学习结果模型

```python
import torch
from torch import nn

class OutcomeNet(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(dim + 1, 64), nn.ReLU(),
            nn.Linear(64, 32), nn.ReLU(), nn.Linear(32, 1)
        )

    def forward(self, x, a):
        return self.net(torch.cat([x, a], dim=-1))

x = torch.randn(128, 8)
a = torch.randint(0, 2, (128, 1)).float()
y = 1.5 * a + x[:, :1] + 0.1 * torch.randn(128, 1)
model = OutcomeNet(x.size(1))
loss = nn.MSELoss()(model(x, a), y)
loss.backward()
assert torch.isfinite(loss)
```

## 方法选择与反例

| 场景 | 首选设计 | 最先检查的假设 | 常见失败 |
| --- | --- | --- | --- |
| 可随机分流 | A/B 或集群实验 | 分流、污染、功效 | 只看短期指标 |
| 有可信外生冲击 | IV / DiD | 排除限制或平行趋势 | 把相关政策当工具 |
| 丰富处理前特征 | 调整 / IPW / DR | 可交换性、重叠 | 把处理后变量纳入 |
| 目标是个性化 | Causal Forest / DR Learner | HTE 稳定性 | 过拟合异质性 |
| 推荐日志评估 | IPS / DR / 随机探索 | 支持集覆盖 | 极端权重爆炸 |

### 失败案例：控制了碰撞点

```text
能力 U ──→ 曝光 E ←─ 业务选择 V
             ↓
          点击 Y

若在分析点击时强行条件化 E，可能打开 U 与 V 的伪相关路径。
```
“控制变量越多越好”是错误直觉；正确做法是根据目标效应与 DAG 选择最小合法调整集。

### 1. 深挖单元：因果问题的三层表达

#### 问题定义

把“因果问题的三层表达”写成一个可回答的问题：如果我们改变处理、曝光、策略或模型版本，目标结果会如何变化？
先固定分析单位、处理时间、观察窗口与目标人群，再讨论模型；否则同一个术语会对应多个不同 estimand。
#### 形式化

$au(x)=E[Y(1)-Y(0)\mid X=x]$，整体效应是对目标人群分布积分：$au=E_X[au(X)]$。
若使用 DAG，则必须区分观察条件 $A=a$ 与主动干预 $do(A=a)$；若使用潜在结果，则必须说明未观测反事实如何被识别。
#### 诊断与实践

| 检查项 | 合格信号 | 风险信号 |
| --- | --- | --- |
| 口径 | 处理与结果有时间顺序 | 结果窗口漂移 |
| 重叠 | 各组协变量分布可比较 | propensity 接近 0 或 1 |
| 稳健性 | 多种估计器方向一致 | 换模型即换结论 |

| 稳健性 | 多种估计器方向一致 | 换模型即换结论 |

#### 练习

- 练习：为“因果思维习惯”画一张至少包含处理、结果、一个混杂与一个护栏指标的 DAG。
- 练习：写出一个会被辛普森悖论误导的分组表，并说明应该调整、分层还是随机化。
