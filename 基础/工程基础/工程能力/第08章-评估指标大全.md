## 8.1 分类 (Classification) 指标

> 适用:二分类、多分类、多标签分类。本节是排序和推荐指标的基础。

### 8.1.1 混淆矩阵 (Confusion Matrix)

**定义**:分类结果的四象限表。

**结构**:

```text
              预测正例 (P)    预测负例 (N)
实际正例 (P)    TP              FN
实际负例 (N)    FP              TN
```

**符号含义**:

- **TP** (True Positive): 实际为正,预测为正
- **FN** (False Negative): 实际为正,预测为负 (漏报)
- **FP** (False Positive): 实际为负,预测为正 (误报)
- **TN** (True Negative): 实际为负,预测为负

**示例**:癌症检测 (正例 = 患病):
- 实际患病 100 人,模型预测患病 90 人 → TP=90, FN=10
- 实际健康 1000 人,模型预测患病 50 人 → FP=50, TN=950

**文字**:混淆矩阵是分类问题的"总账",所有分类指标都基于它派生。关键洞察:**癌症筛查宁可 FP 多也不能 FN 多** (漏诊代价远大于误诊),所以医学场景倾向高 Recall 模型;而垃圾邮件过滤宁可 FN 多也不能 FP 多 (误判正常邮件代价大),所以 Gmail 倾向高 Precision 模型。

### 8.1.2 Accuracy / Precision / Recall / F1

**定义**:四个最常用的分类指标,基于混淆矩阵。

**公式**:

$$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}$$

$$\text{Precision} = \frac{TP}{TP + FP} \quad \text{(查准率, 预测为正的里面真有多少正)}$$

$$\text{Recall} = \frac{TP}{TP + FN} \quad \text{(查全率, 实际为正的里面被找出来多少)}$$

$$F_1 = \frac{2 \cdot P \cdot R}{P + R} = \frac{2 \cdot TP}{2 \cdot TP + FP + FN}$$

**解释**:

- **Accuracy**: 总体正确率,**类别均衡时**好用;**类别严重不均衡时失效** (例:99% 负样本的欺诈检测,全预测为负就有 99% Accuracy)
- **Precision**: 宁缺毋滥 (预测为正的一定要准)
- **Recall**: 宁可错杀 (实际为正的一定要找全)
- **F1**: Precision 和 Recall 的调和平均,综合平衡

**代码** (sklearn 风格):

```python
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score

y_true = [1, 0, 1, 1, 0, 1, 0, 0]
y_pred = [1, 0, 1, 0, 0, 1, 1, 0]

acc   = accuracy_score(y_true, y_pred)      # 0.75
prec  = precision_score(y_true, y_pred)     # 0.75 (3 TP / 4 predicted pos)
rec   = recall_score(y_true, y_pred)        # 0.75 (3 TP / 4 actual pos)
f1    = f1_score(y_true, y_pred)            # 0.75
```

**多分类版本**:

```python
# average='macro'  : 每个类独立算,再算术平均
# average='micro'  : 全局 TP/FP/FN,等同 Accuracy
# average='weighted': 按类别样本数加权
prec_macro = precision_score(y_true, y_pred, average='macro')
prec_micro = precision_score(y_true, y_pred, average='micro')
prec_weighted = precision_score(y_true, y_pred, average='weighted')
```

**F-beta (F1 的广义形式)**:

$$F_\beta = (1 + \beta^2) \cdot \frac{P \cdot R}{(\beta^2 \cdot P) + R}$$

- $\beta > 1$: 加重 Recall (例: F2 更看重找全)
- $\beta < 1$: 加重 Precision (例: F0.5 更看重查准)

**适用**:

| 场景 | 推荐指标 | 原因 |
| :--- | :--- | :--- |
| 类别均衡 | Accuracy | 简单直观 |
| 类别不均衡 (欺诈/罕见病) | F1 / AUPRC | Accuracy 失效 |
| 宁可漏报 (癌症筛查) | Recall / F2 | 漏诊代价高 |
| 宁可误报 (垃圾邮件) | Precision / F0.5 | 误判代价高 |

**局限**:

- **不反映概率质量**:模型输出 0.51 vs 0.99 都被判定为正,这两个概率的"质量"被无视了 → 用 LogLoss
- **不反映排序**:100 个样本里 50 个正例,模型把 50 个负例排在正例前面 vs 把 50 个正例排在负例前面,Precision/Recall 一样 → 用 AUC

### 8.1.3 ROC 曲线 & AUC

**定义**:ROC 曲线展示"不同阈值下" TPR vs FPR 的关系;AUC 是 ROC 曲线下面积。

**公式**:

$$\text{TPR} = \text{Recall} = \frac{TP}{TP + FN} \quad (\text{正例命中率})$$

$$\text{FPR} = \frac{FP}{FP + TN} \quad (\text{负例误报率})$$

$$\text{AUC} = P(\text{score}(x^+) > \text{score}(x^-))$$

> AUC 的**概率解释**:随机抽一个正样本和一个负样本,模型把正样本打分高于负样本的概率。

**曲线绘制**:遍历所有阈值 $\theta \in [0, 1]$:

```python
from sklearn.metrics import roc_curve, auc

fpr, tpr, thresholds = roc_curve(y_true, y_pred_score)
auc_value = auc(fpr, tpr)  # 或 roc_auc_score(y_true, y_pred_score)
```

**AUC 取值解读**:

| AUC 值 | 含义 |
| :---: | :--- |
| 0.5 | 完全随机 (抛硬币) |
| 0.6-0.7 | 较弱 |
| 0.7-0.8 | 一般 |
| 0.8-0.9 | 良好 |
| 0.9-0.95 | 优秀 |
| > 0.99 | 几乎完美 (警惕过拟合/数据泄漏) |
| < 0.5 | 反向预测 (把标签取反) |

**AUC vs Accuracy 的核心区别**:

- **AUC 不依赖阈值**:它衡量模型"区分正负"的能力,而非"在某个固定阈值下的正确率"
- **AUC 对类别不均衡更鲁棒**:因为它看的是排序,不是绝对数量
- **AUC 不反映"实际正例被预测为正的概率"**:阈值变了,TPR 和 FPR 都会变,但 AUC 不变

**适用**:

| 场景 | 是否适合 AUC |
| :--- | :--- |
| 排序质量评估 (搜推广核心) | ✅ **强推** |
| 类别严重不均衡 | ✅ 比 Accuracy 鲁棒 |
| 需要选最优阈值 | ❌ AUC 给不出阈值 |
| 多分类 | ⚠️ 用 one-vs-rest |

**局限**:

- **不能跨数据集比较**:A 数据集 AUC=0.85, B 数据集 AUC=0.85,不代表两模型等价 (正负样本分布不同)
- **不能反映"高分区"性能**:AUC 是整体排序,可能头部精度差但尾部精度高 (搜推广常关注头部 → 用 NDCG@10 等 Top-K 指标)
- **类别极度不均衡时 AUC 也会失真**:99% 负样本下,AUC 仍可被 1%  容易分类的正样本主导 → 用 AUPRC

**搜索推广特定**:

- **GAUC** (Group AUC):按用户分组计算 AUC,再加权平均 (消除用户活跃度差异影响)

### 8.1.4 PR 曲线 & AUPRC

**定义**:PR 曲线是 Precision vs Recall 的关系,AUPRC 是曲线下面积。

**公式**:同 8.1.2 的 Precision 和 Recall,遍历阈值得到曲线。

```python
from sklearn.metrics import precision_recall_curve, average_precision_score

precision, recall, thresholds = precision_recall_curve(y_true, y_pred_score)
ap = average_precision_score(y_true, y_pred_score)  # AUPRC 等价于 AP
```

**为什么有 PR 曲线还要 ROC**:

- **类别不均衡时**:ROC 容易"虚高" (负样本太多,FPR 受分母稀释);PR 曲线更敏感
- **关注正例**:PR 直接关心 Precision 和 Recall,而 ROC 还关心 FPR (对负样本正确率)

**适用场景**:

- **正样本稀少**:欺诈检测、罕见病诊断、异常检测
- **关心头部**:Precision@K 等价于 PR 曲线在某点的值

**搜推广**:

- CTR 预估常用 **AUPRC** 而非 AUC,因为点击 (正样本) 占比 < 10%

### 8.1.5 LogLoss / CrossEntropy

**定义**:衡量预测概率分布与真实分布的差异。

**公式**:

$$\text{LogLoss} = -\frac{1}{N} \sum_{i=1}^{N} \left[ y_i \log(\hat{p}_i) + (1-y_i) \log(1-\hat{p}_i) \right]$$

多分类版本:

$$\text{CrossEntropy} = -\frac{1}{N} \sum_{i=1}^{N} \sum_{c=1}^{C} y_{i,c} \log(\hat{p}_{i,c})$$

**代码**:

```python
import torch
import torch.nn.functional as F

# 二分类
logits = torch.tensor([2.0, -1.0, 0.5, -0.3])
y_true = torch.tensor([1.0, 0.0, 1.0, 0.0])
loss = F.binary_cross_entropy_with_logits(logits, y_true)

# 多分类
logits = torch.randn(3, 5)  # 3 样本, 5 类别
y_true = torch.tensor([2, 0, 4])  # 真实类别索引
loss = F.cross_entropy(logits, y_true)
```

**特性**:

- **范围**: $[0, +\infty)$ ,完美预测为 0
- **惩罚置信错误**:预测 0.99 但实际为 0,损失是 $-\log(0.01) = 4.6$,远大于预测 0.5 的 $-\log(0.5) = 0.69$
- **可微**:可以直接作为损失函数反向传播
- **KL 散度关系**:$\text{KL}(p \| q) = H(p, q) - H(p)$,其中 $H(p, q)$ 是交叉熵。当 $p$ 是真实分布 (one-hot) 时,$H(p) = 0$,所以 LogLoss 等于 KL 散度。

**适用**:

| 场景 | 是否适合 LogLoss |
| :--- | :--- |
| 训练损失函数 | ✅ **强推** (默认选择) |
| 评估概率质量 | ✅ 比 Accuracy 更好 |
| 类别极度不均衡 | ⚠️ 负样本主导,需加权 |
| 离线评估报告 | ✅ 可与 AUC 并列 |

**局限**:

- **不可与 Accuracy 直接比较**:LogLoss=0.1 不一定比 Accuracy=0.9"好"
- **可解释性差**:用户很难理解"LogLoss=0.5 意味着什么"
- **不同问题域不可比**:推荐系统 LogLoss=0.5 vs 图像分类 LogLoss=0.5 不代表同等级别

### 8.1.6 Cohen's Kappa

**定义**:考虑随机一致性的"修正 Accuracy"。

**公式**:

$$\kappa = \frac{p_o - p_e}{1 - p_e}$$

- $p_o$ = 观察一致率 (即 Accuracy)
- $p_e$ = 随机一致率 (类别分布加权)

**示例**:三分类任务,实际标签分布 [40%, 35%, 25%],模型纯随机预测,期望一致率 $p_e = 0.4^2 + 0.35^2 + 0.25^2 = 0.345$,Accuracy=0.5 (随机),则 $\kappa = (0.5 - 0.345) / (1 - 0.345) = 0.237$。

**解读**:

| κ 值 | 一致性 |
| :--- | :--- |
| < 0 | 比随机还差 |
| 0.0-0.2 | 轻微 |
| 0.2-0.4 | 一般 |
| 0.4-0.6 | 中等 |
| 0.6-0.8 | 良好 |
| 0.8-1.0 | 几乎完美 |

**适用**:

- **类别不均衡时**比 Accuracy 更公平
- **标注一致性评估**:多标注员打分,用 Kappa 看标注员之间的一致度

---

### 8.1.7 Matthews Correlation Coefficient (MCC)

**定义**:用混淆矩阵四元素定义的相关系数,$\kappa = +1$ 完美,$-1$ 完全反向,$0$ 随机。

**公式**:

$$\text{MCC} = \frac{TP \cdot TN - FP \cdot FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}$$

**优势**:

- **类别极度不均衡时**:仍能给出有意义的值 (而 F1/AUC 可能虚高)
- **取值 [-1, +1]**:直接可解释为相关系数

**代码**:

```python
from sklearn.metrics import matthews_corrcoef
mcc = matthews_corrcoef(y_true, y_pred)
```

**适用**:欺诈检测、医疗诊断等类别极不均衡场景,作为 F1/AUC 的补充。

## 8.2 排序 (Ranking) 指标——搜推广核心

> 适用:召回、粗排、精排、重排。搜推广最核心的评估领域。
> 关键洞察:**搜推广不关心绝对分数,只关心"用户最可能喜欢的东西是否排在前面"**。

### 8.2.1 NDCG@K (Normalized Discounted Cumulative Gain)

**定义**:位置加权的"累积增益",按位置倒数打折,再做归一化。

**公式**:

$$\text{DCG@K} = \sum_{i=1}^{K} \frac{\text{rel}_i}{\log_2(i+1)}$$

$$\text{IDCG@K} = \sum_{i=1}^{K} \frac{\text{rel}_i^*}{\log_2(i+1)} \quad (\text{理想排序的 DCG})$$

$$\text{NDCG@K} = \frac{\text{DCG@K}}{\text{IDCG@K}}$$

**符号**:

- $\text{rel}_i$ = 第 $i$ 个位置的真实相关性分数 (如点击=1, 加购=3, 购买=10)
- $\log_2(i+1)$ = 折扣因子 (位置越靠后,折扣越大)
- IDCG = 理想排序下的 DCG (所有正样本排在最前面)
- 归一化到 [0, 1]

**代码**:

```python
import numpy as np

def dcg_at_k(rel, k):
    """rel: list of relevance scores in rank order"""
    rel = np.asarray(rel, dtype=float)[:k]
    discounts = np.log2(np.arange(2, len(rel) + 2))
    return np.sum(rel / discounts)

def ndcg_at_k(rel_true, rel_pred_scores, k=10):
    """rel_true: 真实相关性, rel_pred_scores: 模型预测分数"""
    # 按预测分数排序,得到对应的真实相关性
    rank_order = np.argsort(rel_pred_scores)[::-1]
    rel_sorted = np.asarray(rel_true)[rank_order]

    dcg = dcg_at_k(rel_sorted, k)
    idcg = dcg_at_k(sorted(rel_true, reverse=True), k)
    return dcg / idcg if idcg > 0 else 0.0

# 示例
rel_true = [3, 2, 3, 0, 1, 2]  # 真实相关性
rel_pred = [2.1, 1.5, 0.9, 0.7, 0.5, 0.3]  # 模型预测分数
print(ndcg_at_k(rel_true, rel_pred, k=5))  # 输出 ~0.78
```

**sklearn 版本** (使用 predicted score 排序):

```python
from sklearn.metrics import ndcg_score
y_true = [[3, 2, 3, 0, 1, 2]]  # 真实相关性 (每行一个查询)
y_score = [[2.1, 1.5, 0.9, 0.7, 0.5, 0.3]]  # 预测分数
print(ndcg_score(y_true, y_score, k=5))  # ~0.78
```

**适用**:

| 场景 | 是否适合 NDCG |
| :--- | :--- |
| 搜推广排序核心指标 | ✅ **强推** |
| 关心位置 (前几名更重要) | ✅ NDCG 强项 |
| 多级相关性 (浏览/点击/购买) | ✅ 增益分级 |
| 单一相关性 (0/1) | ⚠️ 退化为 DCG,可用 Hit Rate |

**公式解读**:

- **位置折扣 $\frac{1}{\log_2(i+1)}$**:位置 1 的权重 = 1,位置 2 = 0.63,位置 10 = 0.29,位置 100 = 0.15
- **相关性分级**:点击 (rel=1) vs 加购 (rel=2) vs 购买 (rel=3) 应有不同权重
- **归一化**:不同查询的候选数不同,直接比较 DCG 无意义,NDCG 解决了这个问题

**局限**:

- **要求真实相关性**:需要标注每个 item 的真实相关度,工业界常用"点击=1, 未点击=0"简化
- **位置折扣公式有争议**:有人用 $\frac{1}{\log_2(i+1)}$,有人用 $\frac{1}{i}$,见 Web 搜索领域讨论
- **不反映排序的多样性**:只关注相关性,不关注"前 10 个里有多少是重复品类"

**搜推广实战**:

- **离线 NDCG 提升 → 在线 CTR 提升**:通常成立,但需关注分布漂移
- **NDCG@10 比 NDCG@100 更敏感**:前者关注头部精度,后者关注召回
- **冷启动新物品**:NDCG 难以评估 (新物品没有历史数据)

### 8.2.2 MAP (Mean Average Precision)

**定义**:每个查询的 Average Precision (AP) 的均值。

**公式**:

单查询 AP:

$$\text{AP} = \frac{1}{R} \sum_{k=1}^{N} \text{Precision@K} \cdot \text{rel}(k)$$

- $R$ = 相关文档总数
- $\text{rel}(k)$ = 位置 $k$ 是否相关 (0/1)
- 求和只在相关位置上进行

多查询 MAP:

$$\text{MAP} = \frac{1}{Q} \sum_{q=1}^{Q} \text{AP}_q$$

**代码**:

```python
from sklearn.metrics import average_precision_score

# 单查询 AP
ap = average_precision_score(y_true, y_score)
# 多查询 MAP
map_score = mean_average_precision_score(y_true_list, y_score_list)
```

**NDCG vs MAP**:

- **MAP 用 0/1 相关性,NDCG 可用多级**:NDCG 更灵活
- **MAP 对位置敏感但用 Precision 折扣**:MAP 只在"正例位置"算 Precision,而 NDCG 在所有位置算
- **计算速度**:MAP 比 NDCG 慢 (因为 AP 需要按位算)

**适用**:

- 信息检索 (TREC 等基准)
- 推荐系统 (少用,NDCG 更主流)

---

### 8.2.3 MRR (Mean Reciprocal Rank)

**定义**:第一个相关结果排名的倒数的均值。

**公式**:

$$\text{MRR} = \frac{1}{Q} \sum_{q=1}^{Q} \frac{1}{\text{rank}_q}$$

- $\text{rank}_q$ = 第 $q$ 个查询中第一个相关结果的排名

**代码**:

```python
def mrr_at_k(rel_true, k=10):
    """
    rel_true: list of relevance (1 if relevant, 0 otherwise)
    Returns reciprocal rank (1/rank of first relevant item)
    """
    rel_true = rel_true[:k]
    for i, r in enumerate(rel_true, 1):
        if r > 0:
            return 1.0 / i
    return 0.0
```

**示例**:

- 第 1 个位置就相关 → MRR = 1.0
- 第 3 个位置才相关 → MRR = 0.333
- 没有任何相关 → MRR = 0.0

**适用**:

- **问答系统**:第一个正确答案出现的位置 (百度搜索 FAQ)
- **导航类推荐**:用户通常只看第一个结果
- **粗排**:粗排给精排 1000 个,第一个相关的位置很重要

**搜推广**:

- **召回阶段常用**:召回率关注"是否召回了真相关"
- **粗排关注头部**:用 MRR 而不是 NDCG

**局限**:只看第一个相关,忽略后续;若任务需关注多个相关,用 NDCG。

---

### 8.2.4 Hit Rate@K

**定义**:在前 K 个结果中是否至少有一个相关。

**公式**:

$$\text{HitRate@K} = \frac{1}{Q} \sum_{q=1}^{Q} \mathbb{1}[\exists k \leq K: \text{rel}_q(k) > 0]$$

**代码**:

```python
def hit_rate_at_k(rel_true, k=10):
    return 1.0 if any(r > 0 for r in rel_true[:k]) else 0.0

# 多查询
hit_rate = sum(hit_rate_at_k(r, k) for r in all_relevances) / len(all_relevances)
```

**适用**:

- **召回系统核心指标**:召回了真相关 → Hit,没召回 → Miss
- **Top-K 推荐**:前 K 个里有没有用户喜欢的
- **简单易懂**:非技术人员也能理解

**搜推广**:Hit Rate@100 常用于评估召回通道,Hit Rate@10/50 用于精排。

---

### 8.2.5 Precision@K & Recall@K

**定义**:前 K 个结果中的 Precision/Recall。

**公式**:

$$\text{Precision@K} = \frac{|\text{Top-K} \cap \text{relevant}|}{K}$$

$$\text{Recall@K} = \frac{|\text{Top-K} \cap \text{relevant}|}{|\text{relevant}|}$$

**代码**:

```python
def precision_recall_at_k(rel_true, k=10):
    rel_k = rel_true[:k]
    relevant_count = sum(1 for r in rel_k if r > 0)
    total_relevant = sum(1 for r in rel_true if r > 0)

    precision = relevant_count / k if k > 0 else 0
    recall = relevant_count / total_relevant if total_relevant > 0 else 0
    return precision, recall
```

**适用**:

- **多分类单标签**:每类一个 P@K,宏观平均
- **召回系统**:P@100 = 召回了多少相关 (前 100 个里)
- **粗排**:P@1000 (粗排给精排 1000 个)

**与 Hit Rate 的关系**:Hit Rate@K = "Recall@K ≥ 1" 的二元化版本。

---

### 8.2.6 GAUC (Group AUC)

**定义**:按用户分组计算 AUC,再加权平均 (权重通常是用户曝光数)。

**公式**:

$$\text{GAUC} = \frac{\sum_{u=1}^{U} \text{impressions}_u \cdot \text{AUC}_u}{\sum_{u=1}^{U} \text{impressions}_u}$$

**为什么需要 GAUC**:

- **整体 AUC 失效场景**:用户 A 看 100 个 item (99 正 1 负) vs 用户 B 看 100 个 (1 正 99 负),两者对整体 AUC 贡献同等,但实际意义悬殊
- **GAUC 按用户独立评估**:每个用户内部计算 AUC,体现"模型对单个用户排序能力"

**代码**:

```python
def gauc(y_true_per_user, y_score_per_user, user_impressions):
    """
    y_true_per_user: list of lists, 每个用户真实标签
    y_score_per_user: list of lists, 每个用户预测分数
    user_impressions: list of 每个用户曝光数
    """
    auc_sum = 0
    imp_sum = 0
    for y_t, y_s, imp in zip(y_true_per_user, y_score_per_user, user_impressions):
        if len(set(y_t)) < 2:  # 全正或全负,跳过
            continue
        user_auc = roc_auc_score(y_t, y_s)
        auc_sum += user_auc * imp
        imp_sum += imp
    return auc_sum / imp_sum if imp_sum > 0 else 0
```

**适用**:搜推广精排核心指标之一 (与 NDCG 并列)。

---

### 8.2.7 多样性指标 (Diversity)

**定义**:推荐列表中物品之间的差异度。

**公式 (ILD - Intra-List Diversity)**:

$$\text{ILD} = \frac{1}{|L|(|L|-1)} \sum_{i \in L} \sum_{j \in L, j \neq i} (1 - \text{sim}(i, j))$$

**适用**:重排阶段,确保"前 10 个不是同质化推荐"。

## 8.3 推荐 (Recommendation) 指标——业务核心

> 适用:CTR/CVR 预估、召回/粗排/精排评估、在线业务监控。

### 8.3.1 CTR (Click-Through Rate)

**定义**:点击率,推荐物品被点击的比例。

**公式**:

$$\text{CTR} = \frac{\text{clicks}}{\text{impressions}}$$

**代码**:

```python
ctr = total_clicks / total_impressions
```

**特点**:

- **简单但粗**:只看"是否点击",不看后续
- **位置偏差**:位置 1 的物品天然 CTR 高 (曝光 ≠ 公平)
- **标题党陷阱**:夸张标题拉高 CTR 但转化低

**适用**:所有推荐场景的基础指标。

---

### 8.3.2 CVR (Conversion Rate)

**定义**:转化率 (点击后购买/注册/加购等的比率)。

**公式**:

$$\text{CVR} = \frac{\text{conversions}}{\text{clicks}}$$

$$\text{pCTCVR} = \text{CTR} \times \text{CVR} = \frac{\text{conversions}}{\text{impressions}}$$

**SSB 问题 (Sample Selection Bias)**:CVR 训练数据只在"被点击"的样本上,线上预测时需要"全样本空间"上预测,导致分布不一致 → ESMM 等多任务模型就是为了解决 SSB。

**代码** (参见第 7 章):

```python
# ESMM: 全样本空间建模 pCTR 和 pCVR,联合预测 pCTCVR
class ESMM(nn.Module):
    def __init__(self, base_model):
        super().__init__()
        self.ctr_model = base_model
        self.cvr_model = base_model

    def forward(self, x):
        pctr = torch.sigmoid(self.ctr_model(x))
        pcvr = torch.sigmoid(self.cvr_model(x))
        pctcvr = pctr * pcvr
        return pctr, pcvr, pctcvr
```

**适用**:电商、广告、视频。

---

### 8.3.3 RPM / eCPM

**定义**:每千次曝光的收入 (Revenue Per Mille / Effective Cost Per Mille)。

**公式**:

$$\text{eCPM} = \frac{\text{total revenue}}{\text{impressions}} \times 1000$$

广告侧:

$$\text{eCPM} = \text{CTR} \times \text{CVR} \times \text{bid}$$

**适用**:广告系统核心指标。

---

### 8.3.4 GMV (Gross Merchandise Volume)

**定义**:商品交易总额。

**公式**:

$$\text{GMV} = \sum_{\text{orders}} \text{price}$$

**适用**:电商核心业务指标,常按天/周/月统计。

**注意**:GMV 可被"刷单"虚高,需结合订单数、退款率等综合判断。

---

### 8.3.5 留存指标 (Retention)

**定义**:用户在第 N 天是否仍活跃。

**公式 (N 日留存)**:

$$\text{Retention}_N = \frac{\text{D}_N \text{活跃用户}}{\text{D}_0 \text{新增用户}}$$

**常见**:

- **D1 Retention**:次日留存 (关键指标)
- **D7 Retention**:7 日留存 (周留存)
- **D30 Retention**:月留存 (决定 LTV)

**可视化**:留存曲线 (Retention Curve),横轴天数,纵轴留存率。

---

### 8.3.6 LTV / LTGM

**定义**:用户生命周期价值 (LifeTime Value) / 生命周期 GMV。

**公式**:

$$\text{LTV} = \sum_{t=0}^{T} \frac{\text{Revenue}_t}{(1+r)^t}$$

- $T$ = 用户生命周期 (月/年)
- $r$ = 折现率
- $t$ = 时间

**简化版**:

$$\text{LTV} \approx \text{ARPU} \times \text{Lifetime (in periods)}$$

**适用**:用户价值评估、获客成本 (CAC) 对比、ROI 计算。

---

### 8.3.7 推荐多样性 / 覆盖率 / 新颖性

**公式**:

- **覆盖率 (Coverage)**:被推荐过的物品数 / 总物品数

$$\text{Coverage} = \frac{|\bigcup_{u \in U} R_u|}{|I|}$$

- **基尼系数 (Gini)**:推荐分布的公平性 (类似经济学基尼系数,越小越公平)

$$\text{Gini} = \frac{\sum_{i=1}^{n} (2i - n - 1) \cdot x_i}{n \cdot \sum_{i=1}^{n} x_i}$$

- **新颖性 (Novelty)**:推荐物品的"冷门程度" (常用 -log(p(item)) 加权平均)

$$\text{Novelty} = -\frac{1}{|R_u|} \sum_{i \in R_u} \log_2 p(i)$$

**适用**:评估"长尾"是否被推荐,头部是否过载。

---

## 8.4 回归 (Regression) 指标

> 适用:点击率预估 (回归形式)、时长预估、销量预测、房价预测等。

### 8.4.1 MSE / RMSE / MAE / MAPE

**公式**:

$$\text{MSE} = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2$$

$$\text{RMSE} = \sqrt{\text{MSE}}$$

$$\text{MAE} = \frac{1}{N} \sum_{i=1}^{N} |y_i - \hat{y}_i|$$

$$\text{MAPE} = \frac{1}{N} \sum_{i=1}^{N} \left| \frac{y_i - \hat{y}_i}{y_i} \right| \times 100\%$$

**代码**:

```python
import numpy as np

y_true = np.array([3.0, -0.5, 2.0, 7.0])
y_pred = np.array([2.5, 0.0, 2.0, 8.0])

mse  = np.mean((y_true - y_pred) ** 2)           # 0.375
rmse = np.sqrt(mse)                              # 0.612
mae  = np.mean(np.abs(y_true - y_pred))          # 0.5
mape = np.mean(np.abs((y_true - y_pred) / y_true)) * 100  # 注意 y=0 时除零
```

**PyTorch**:

```python
import torch
import torch.nn.functional as F

loss_mse = F.mse_loss(y_pred, y_true)
loss_mae = F.l1_loss(y_pred, y_true)
```

**指标对比**:

| 指标 | 单位 | 异常值敏感 | 优点 | 缺点 |
| :--- | :--- | :---: | :--- | :--- |
| MSE | y² | ✅ 高 | 可微,凸函数 | 单位不好解释 |
| RMSE | y | ✅ 高 | 同 MSE 但单位一致 | 同上 |
| MAPE | % | ❌ 低 | 跨数据集可比 | y=0 时除零,小 y 放大误差 |
| MAE | y | ❌ 低 | 鲁棒 | 不可微 (用 sub-gradient) |

**适用**:

| 场景 | 推荐指标 |
| :--- | :--- |
| 训练损失函数 | MSE (可微) |
| 业务报表 | MAE / MAPE (易理解) |
| 异常值存在 | MAE / Huber Loss |
| 跨规模数据 | MAPE |

---

### 8.4.2 R² (Coefficient of Determination)

**定义**:模型解释方差的比例,$R^2 = 1$ 完美,$R^2 = 0$ 等于均值,$R^2 < 0$ 比均值还差。

**公式**:

$$R^2 = 1 - \frac{\sum_{i=1}^{N} (y_i - \hat{y}_i)^2}{\sum_{i=1}^{N} (y_i - \bar{y})^2}$$

**代码**:

```python
from sklearn.metrics import r2_score
r2 = r2_score(y_true, y_pred)
```

**调整 R² (Adjusted R²)**:

$$R^2_{adj} = 1 - \frac{(1 - R^2)(N-1)}{N-p-1}$$

- $p$ = 特征数
- 惩罚过多特征,防止过拟合假象

**适用**:回归模型整体评估,跨数据集可比。

---

### 8.4.3 Spearman / Pearson 相关系数

**公式**:

**Pearson** (线性相关):

$$\rho_P = \frac{\text{Cov}(y, \hat{y})}{\sigma_y \sigma_{\hat{y}}}$$

**Spearman** (秩相关,单调相关):

$$\rho_S = 1 - \frac{6 \sum_{i=1}^{N} d_i^2}{N(N^2 - 1)}$$

- $d_i = \text{rank}(y_i) - \text{rank}(\hat{y}_i)$
- 衡量排序一致性,不要求线性

**代码**:

```python
from scipy.stats import pearsonr, spearmanr

pearson_corr, _ = pearsonr(y_true, y_pred)
spearman_corr, _ = spearmanr(y_true, y_pred)
```

**适用**:

- **Pearson**:线性回归评估
- **Spearman**:搜推广排序评估 (只看排序对不对,不看绝对分数) — **强推**

## 8.5 CV (Computer Vision) 指标

> 适用:目标检测、图像分割、图像生成、图像分类。

### 8.5.1 mAP (mean Average Precision)

**定义**:每个类别的 AP (Average Precision) 的均值。

**单类 AP**:PR 曲线下面积。

**多类 mAP**:

$$\text{mAP} = \frac{1}{C} \sum_{c=1}^{C} \text{AP}_c$$

**IoU 阈值变体**:

- **mAP@0.5**:IoU ≥ 0.5 视为命中 (PASCAL VOC 标准)
- **mAP@0.5:0.95**:IoU 从 0.5 到 0.95 每 0.05 计算一次 AP,再平均 (COCO 标准)

**代码**:

```python
# torchmetrics
from torchmetrics.detection import MeanAveragePrecision

metric = MeanAveragePrecision(box_format='xyxy', iou_type='bbox')
metric.update(preds, targets)
mAP = metric.compute()
```

**适用**:目标检测 (YOLO / Faster R-CNN / DETR) 标准指标。

---

### 8.5.2 IoU / mIoU

**定义**:交并比,衡量预测框/分割区域与真实框/区域的重叠度。

**公式**:

$$\text{IoU} = \frac{|A \cap B|}{|A \cup B|}$$

**mIoU**:多类 IoU 的平均。

**代码**:

```python
import numpy as np

def iou(pred, target):
    intersection = np.logical_and(pred, target).sum()
    union = np.logical_or(pred, target).sum()
    return intersection / union if union > 0 else 0
```

**适用**:语义分割、目标检测的 box 评估。

---

### 8.5.3 Dice 系数 (F1 在像素级别)

**公式**:

$$\text{Dice} = \frac{2 |A \cap B|}{|A| + |B|}$$

**与 IoU 的关系**:Dice 给予重叠区域更高权重,对小目标更敏感。

**适用**:医学图像分割 (肿瘤/器官分割)。

---

### 8.5.4 PSNR / SSIM (图像质量)

**PSNR (Peak Signal-to-Noise Ratio)**:

$$\text{PSNR} = 10 \log_{10} \frac{\text{MAX}^2}{\text{MSE}}$$

- MAX = 像素最大值 (255 for uint8, 1.0 for normalized)
- 单位 dB,越大越好
- 通常 30-50 dB 算高质量

**SSIM (Structural Similarity)**:

$$\text{SSIM}(x, y) = \frac{(2\mu_x \mu_y + c_1)(2\sigma_{xy} + c_2)}{(\mu_x^2 + \mu_y^2 + c_1)(\sigma_x^2 + \sigma_y^2 + c_2)}$$

- $\mu$ = 均值, $\sigma$ = 标准差, $\sigma_{xy}$ = 协方差
- 范围 [-1, 1],1 表示完全一致

**适用**:超分辨率、图像压缩、去噪。

---

### 8.5.5 FID (Fréchet Inception Distance)

**定义**:衡量生成图像与真实图像分布的距离 (越小越好)。

**公式**:

$$\text{FID} = \|\mu_r - \mu_g\|^2 + \text{Tr}(\Sigma_r + \Sigma_g - 2(\Sigma_r \Sigma_g)^{1/2})$$

- $r$ = 真实图像, $g$ = 生成图像
- $\mu, \Sigma$ = Inception 网络提取的特征的均值和协方差

**适用**:GAN / Diffusion / VAE 的图像生成质量。

**局限**:

- 需要 Inception 预训练模型 (无法迁移到非 ImageNet 域)
- 对小样本敏感 (通常需 ≥ 1000 张)
- 不反映语义质量

---

### 8.5.6 CLIP Score

**定义**:用 CLIP 模型计算图文一致性分数 (生成图像与文本 prompt 的匹配度)。

**公式**:

$$\text{CLIPScore} = \max(100 \cdot \cos(E_{\text{text}}, E_{\text{image}}), 0)$$

- $E_{\text{text}}, E_{\text{image}}$ = CLIP 文本和图像 embedding

**适用**:Text-to-Image 生成 (Stable Diffusion / DALL-E)。

## 8.6 NLP / LLM 指标

> 适用:NLP 任务、LLM 训练/评估、大模型基准测试。

### 8.6.1 Perplexity (PPL)

**定义**:模型对样本的"惊讶度",越小越好。

**公式**:

$$\text{PPL}(x) = \exp\left(-\frac{1}{N} \sum_{i=1}^{N} \log p(x_i | x_{<i})\right)$$

- $N$ = token 数
- 等价于"模型预测每个 token 的平均交叉熵的指数"

**代码**:

```python
import torch
import torch.nn.functional as F

def perplexity(logits, targets):
    """logits: (N, V), targets: (N,)"""
    log_probs = F.log_softmax(logits, dim=-1)
    nll = F.nll_loss(log_probs, targets)
    return torch.exp(nll)
```

**适用**:语言模型预训练评估,越小代表模型对语言建模越好。

**局限**:

- **不反映下游任务**:PPL=10 的模型在 QA 上可能不如 PPL=15
- **不同词表不可比**:GPT-2 (50K) vs LLaMA (32K) 的 PPL 不能直接对比
- **长文本衰减**:超长文本 PPL 自然上升

---

### 8.6.2 BLEU (Bilingual Evaluation Understudy)

**定义**:机器翻译/生成的 n-gram 精度指标,衡量与参考答案的重叠度。

**公式**:

$$\text{BLEU} = \text{BP} \cdot \exp\left(\sum_{n=1}^{N} w_n \log p_n\right)$$

- $p_n$ = n-gram 精度 (modified,防止重复词刷分)
- $w_n$ = 权重 (通常均匀 1/N)
- $\text{BP}$ = 短句惩罚 (Brevity Penalty)

$$\text{BP} = \begin{cases} 1 & \text{if } c > r \\ e^{1-r/c} & \text{if } c \leq r \end{cases}$$

- $c$ = 候选长度, $r$ = 参考长度

**代码** (使用 sacrebleu):

```python
import sacrebleu

reference = ["The cat is on the mat."]
hypothesis = "The cat sat on the mat."
bleu = sacrebleu.corpus_bleu([hypothesis], [reference])
print(bleu.score)  # 通常 0-100
```

**适用**:机器翻译、文本摘要、图像描述。

**局限**:

- **不考虑语义**:同义词替换会被罚分
- **不反映流畅度**:n-gram 完美匹配但句法错乱也可能高分

---

### 8.6.3 ROUGE (Recall-Oriented Understudy for Gisting Evaluation)

**定义**:与 BLEU 对偶,衡量**召回** (参考答案的 n-gram 在候选中出现多少)。

**变体**:

- **ROUGE-N**: n-gram 召回 (ROUGE-1, ROUGE-2, ROUGE-3, ROUGE-4)
- **ROUGE-L**: 最长公共子序列 (LCS)
- **ROUGE-W**: 加权 LCS (连续匹配奖励更高)

**公式** (ROUGE-N):

$$\text{ROUGE-N} = \frac{\sum_{\text{ref}} \sum_{\text{ngram} \in \text{ref}} \text{Count}_{\text{match}}(\text{ngram})}{\sum_{\text{ref}} \sum_{\text{ngram} \in \text{ref}} \text{Count}(\text{ngram})}$$

**适用**:摘要任务 (比 BLEU 更常用)。

---

### 8.6.4 METEOR

**公式**:

$$\text{METEOR} = F_{\text{mean}} \cdot (1 - \text{Penalty})$$

- 考虑同义词、词干、词序
- 比 BLEU 更符合人类判断

**代码**:

```python
import nltk
from nltk.translate.meteor_score import meteor_score

reference = "the cat is on the mat"
hypothesis = "the cat sat on the mat"
score = meteor_score([reference.split()], hypothesis.split())
```

---

### 8.6.5 BERTScore

**定义**:用 BERT embedding 计算 token 级别的相似度,克服 BLEU/ROUGE 的同义词问题。

**公式**:

$$\text{BERTScore} = \frac{1}{|x|} \sum_{x_i \in x} \max_{y_j \in y} \cos(\mathbf{e}_{x_i}, \mathbf{e}_{y_j})$$

- 用 BERT (或 RoBERTa) 提取 token embedding
- 用余弦相似度做 token 匹配

**代码**:

```python
from bert_score import score

P, R, F1 = score(
    cands=["The cat sat on the mat."],
    refs=["The cat is on the mat."],
    lang="en",
    model_type="roberta-large"
)
print(f"F1: {F1.mean().item():.4f}")
```

**适用**:文本生成、摘要、翻译,比 BLEU/ROUGE 更鲁棒。

**局限**:依赖 BERT 模型,大文档慢;不同 BERT 模型结果不同。

## 8.7 生成模型指标

> 适用:图像生成、文本生成、音乐生成。

### 8.7.1 Inception Score (IS)

**公式**:

$$\text{IS} = \exp\left(\mathbb{E}_x \left[ D_{KL}(p(y|x) \| p(y)) \right]\right)$$

- $p(y|x)$ = Inception 对生成图像的条件分布 (越尖锐越好)
- $p(y)$ = 边缘分布 (越均匀越好)

**代码**:

```python
from torchmetrics.image.fid import FrechetInceptionDistance

# IS 类似,需用 Inception V3
```

**适用**:GAN 早期主流指标,现已被 FID 取代。

### 8.7.2 FID

见 8.5.5。

### 8.7.3 Distinct-N (文本多样性)

**定义**:生成文本中 unique n-gram 的比例。

**公式**:

$$\text{Distinct-N} = \frac{\text{Count of unique n-grams}}{\text{Count of total n-grams}}$$

**适用**:对话系统、文本生成多样性 (避免"我爱学习学习学习学习"重复)。

**代码**:

```python
from collections import Counter

def distinct_n(texts, n=2):
    all_ngrams = []
    for text in texts:
        tokens = text.split()
        ngrams = [tuple(tokens[i:i+n]) for i in range(len(tokens) - n + 1)]
        all_ngrams.extend(ngrams)
    if not all_ngrams:
        return 0.0
    return len(set(all_ngrams)) / len(all_ngrams)
```

### 8.7.4 Self-BLEU

**定义**:用 BLEU 衡量"生成样本之间的相似度",越小代表多样性越高。

**适用**:配合 Distinct-N 评估生成多样性。

## 8.8 强化学习 (RL) 指标

> 适用:RLHF、RL 训练评估、游戏/机器人策略评估。

### 8.8.1 Cumulative Reward

**公式**:

$$G_t = \sum_{k=0}^{T-t} \gamma^k r_{t+k}$$

- $\gamma$ = 折扣因子 (通常 0.99)
- $r$ = 每步奖励

**适用**:RL 训练核心指标,越高代表策略越好。

---

### 8.8.2 Average Return

$$\bar{R} = \frac{1}{N} \sum_{i=1}^{N} G_0^{(i)}$$

- $N$ = 评估回合数
- 比 Cumulative Reward 更稳定 (对 episode 长度不敏感)

---

### 8.8.3 Success Rate

**适用**:机器人/导航任务,完成目标的回合比例。

$$\text{Success Rate} = \frac{\text{成功回合数}}{\text{总回合数}}$$

---

### 8.8.4 Episode Length

**适用**:稀疏奖励任务 (如 Atari),策略若能坚持更久 = 学到"不做死"。

---

### 8.8.5 RLHF 特定:Reward Model Accuracy

**定义**:Reward Model 对 (chosen, rejected) 对的偏好预测准确率。

**适用**:RLHF 第一阶段 (RM 训练),RM Acc 应 > 70%。

---

## 8.9 公平性与偏差 (Fairness & Bias)

> 适用:推荐系统的"长尾暴露公平"、AI 伦理、AB 实验用户分层。

### 8.9.1 Popularity Bias

**定义**:推荐结果倾向于热门物品的程度。

**公式**:

$$\text{Popularity Bias} = \frac{1}{|R|} \sum_{i \in R} \text{pop}(i)$$

- $\text{pop}(i)$ = 物品 $i$ 的流行度 (曝光/点击数)
- 高 = 偏向热门,低 = 长尾友好

**Gini 系数**:推荐分布公平性,见 8.3.7。

---

### 8.9.2 Position Bias

**定义**:点击率受展示位置影响,位置 1 天然 CTR 高。

**建模 (Position Debiasing)**:

$$P(\text{click} = 1 | u, i) = P(\text{exam} | \text{pos}) \cdot P(\text{like} | u, i)$$

- $P(\text{exam}|\text{pos})$ = 用户看到 (examine) 的概率,仅依赖位置
- $P(\text{like}|u, i)$ = 用户喜欢的概率,与位置无关

**评估**:对比有/无 position embedding 的 AUC 差异。

---

### 8.9.3 Demographic Parity (人口均等)

**公式**:

$$|P(\hat{Y} = 1 | G = a) - P(\hat{Y} = 1 | G = b)| < \epsilon$$

- $G$ = 受保护属性 (性别/种族)
- $\epsilon$ = 容差 (通常 0.05-0.1)

---

### 8.9.4 Equal Opportunity (机会均等)

**公式**:

$$|P(\hat{Y} = 1 | Y = 1, G = a) - P(\hat{Y} = 1 | Y = 1, G = b)| < \epsilon$$

- 在"真实正例"群体内,各组预测正例的比率应相等

**适用**:贷款审批、招聘筛选等高 stakes 场景。

---

## 8.10 因果推断 / AB 实验指标

> 适用:A/B 实验、因果效应识别、政策评估。

### 8.10.1 ATE / ATT / CATE

**公式**:

$$\text{ATE} = E[Y(1) - Y(0)]$$

$$\text{ATT} = E[Y(1) - Y(0) | T = 1]$$

$$\text{CATE}(x) = E[Y(1) - Y(0) | X = x]$$

- ATE = 平均处理效应
- ATT = 处理组的平均处理效应
- CATE = 条件平均处理效应 (异质性)

---

### 8.10.2 P-value / 置信区间

**公式**:

$$\text{CI}_{95\%} = \hat{\theta} \pm 1.96 \cdot \text{SE}(\hat{\theta})$$

- $\hat{\theta}$ = 估计的处理效应
- SE = 标准误

**P-value**:在零假设下观察到此结果的概率,$p < 0.05$ 视为显著。

**代码**:

```python
from scipy import stats

# 两组对比 (CTR 提升实验)
control = [0.052, 0.051, 0.053, ...]  # 对照组 CTR
treatment = [0.054, 0.055, 0.054, ...]  # 实验组 CTR

t_stat, p_value = stats.ttest_ind(treatment, control)
print(f"P-value: {p_value:.4f}")
print(f"Lift: {(np.mean(treatment) - np.mean(control)) / np.mean(control) * 100:.2f}%")
```

---

### 8.10.3 显著性检验

| 指标类型 | 检验方法 |
| :--- | :--- |
| 连续指标 (CTR/RPM) | t 检验 / Welch's t / Mann-Whitney |
| 比例指标 (CTR/CVR) | Z 检验 / 卡方 / Fisher 精确 |
| 序检验 (Sequential) | mSPRT / Group Sequential |
| 多组对比 | ANOVA / Kruskal-Wallis |

**最小样本量计算**:

$$N = \frac{(Z_{\alpha/2} + Z_{\beta})^2 \cdot (p_1(1-p_1) + p_2(1-p_2))}{(p_1 - p_2)^2}$$

- $Z_{\alpha/2}$ = 显著性水平对应 Z 值 (0.05 → 1.96)
- $Z_{\beta}$ = 检验力 (0.8 → 0.84)
- $p_1, p_2$ = 两组预期比例

**代码**:

```python
from statsmodels.stats.power import NormalIndPower

power_analysis = NormalIndPower()
sample_size = power_analysis.solve_power(
    effect_size=0.02,    # 期望的 CTR 提升 (如 5% → 5.02%)
    alpha=0.05,
    power=0.8,
    alternative='two-sided'
)
print(f"每组需要 {sample_size:.0f} 个样本")
```

---

### 8.10.4 CUPED 方差缩减

**问题**:A/B 实验方差大,小效应难以显著。

**公式**:

$$Y_{\text{CUPED}} = Y - \theta \cdot (X - E[X])$$

- $Y$ = 实验期指标
- $X$ = 实验前基线指标
- $\theta$ = 拟合系数 (用预实验数据回归得)

**方差缩减效果**:通常减少 30-50% 方差,等效于 30-50% 流量节省。

**代码**:

```python
def cuped_transform(y_exp, x_pre, theta):
    """CUPED 方差缩减变换"""
    y_cuped = y_exp - theta * (x_pre - x_pre.mean())
    return y_cuped

# 用实验前数据回归得 theta
from sklearn.linear_model import LinearRegression
model = LinearRegression()
model.fit(x_pre.reshape(-1, 1), y_exp)
theta = model.coef_[0]
```

---

### 8.10.5 序检验 (Sequential Testing)

**问题**:多次看数据 (peeking) 会膨胀 I 型错误率。

**方法**:

- **Group Sequential**:预设几次中期分析,用 α-spending function
- **Always Valid Inference (mSPRT)**:任何时候看数据都不需要 α 调整

**公式 (mSPRT)**:

$$p_{\text{mSPRT}} = \min \left\{ \frac{p^{(1-\tau)} (1-p)^\tau}{\int_0^1 p^{(1-\tau)} (1-p)^\tau dp} \right\}$$

- $\tau$ = mixing weight (0.5 为混合先验)

## 8.11 多任务 / 多标签 (Multi-Task / Multi-Label)

> 适用:多目标推荐、多标签分类。

### 8.11.1 Hamming Loss

**公式**:

$$\text{Hamming} = \frac{1}{N \cdot L} \sum_{i=1}^{N} \sum_{l=1}^{L} \mathbb{1}[\hat{y}_{i,l} \neq y_{i,l}]$$

- $N$ = 样本数, $L$ = 标签数
- 衡量标签级别的错分率

**适用**:多标签分类 (一个样本可有多个标签)。

---

### 8.11.2 Subset Accuracy (Exact Match)

**公式**:

$$\text{Subset Acc} = \frac{1}{N} \sum_{i=1}^{N} \mathbb{1}[\hat{Y}_i = Y_i]$$

- $\hat{Y}_i$ = 预测的标签集合
- 所有标签都猜对才算 1 (严苛)

**适用**:多标签分类的"完美预测率"。

---

### 8.11.3 Macro / Micro / Weighted F1

- **Macro F1**:每个类独立算 F1,再平均 (各类等权)
- **Micro F1**:全局 TP/FP/FN,等价于 Accuracy
- **Weighted F1**:按类别样本数加权

**适用**:多分类报告,需根据场景选择:

| 场景 | 推荐 |
| :--- | :--- |
| 类别均衡 | Macro |
| 类别不均衡,关注大类 | Weighted |
| 类别不均衡,关注整体表现 | Micro |
| 关注每个小类 | Macro |

---

## 8.12 校准 (Calibration)

> 适用:概率预测 (CTR/CVR 预估、天气预报、医疗诊断)。

### 8.12.1 ECE (Expected Calibration Error)

**定义**:预测概率与真实频率的偏差,越小越好。

**公式**:

$$\text{ECE} = \sum_{m=1}^{M} \frac{|B_m|}{N} |\text{acc}(B_m) - \text{conf}(B_m)|$$

- $B_m$ = 第 $m$ 个概率区间 (bin)
- $\text{acc}(B_m)$ = 该区间内真实正例比例
- $\text{conf}(B_m)$ = 该区间内预测概率均值

**代码**:

```python
from torchmetrics.classification import CalibrationError

ece = CalibrationError(task='binary', n_bins=10)
ece.update(preds, target)
print(f"ECE: {ece.compute():.4f}")  # 0 表示完美校准
```

**适用**:概率预测必须校准,否则 CTR=0.05 但实际只有 0.03 会严重误导决策。

---

### 8.12.2 MCE (Maximum Calibration Error)

**公式**:取所有 bin 中最大误差 (比 ECE 更悲观)。

---

### 8.12.3 Reliability Diagram

**可视化**:横轴预测概率,纵轴实际频率。理想是 y=x 对角线。

```python
import matplotlib.pyplot as plt
from sklearn.calibration import calibration_curve

prob_true, prob_pred = calibration_curve(y_true, y_pred_prob, n_bins=10)
plt.plot([0, 1], [0, 1], 'k:', label='Perfect calibration')
plt.plot(prob_pred, prob_true, 's-', label='Model')
plt.xlabel('Predicted probability')
plt.ylabel('Actual frequency')
plt.legend()
```

---

### 8.12.4 校准方法

| 方法 | 公式 | 适用 |
| :--- | :--- | :--- |
| Platt Scaling | $\hat{p} = \sigma(a \cdot z + b)$ | 单调校准 |
| Isotonic Regression | 单调阶梯函数 | 任意分布 |
| Temperature Scaling | $\hat{p} = \text{softmax}(z/T)$ | 神经网络 |

## 8.13 鲁棒性与泛化

> 适用:OOD 检测、对抗鲁棒性、分布漂移检测。

### 8.13.1 OOD 检测指标

**AUROC for OOD**:

```python
# OOD 检测 = 二分类 (in-distribution vs OOD)
from sklearn.metrics import roc_auc_score
ood_scores = model.ood_score(test_data)  # 模型对每个样本的 OOD 分数
labels = [0] * len(id_data) + [1] * len(ood_data)  # 0=ID, 1=OOD
auroc = roc_auc_score(labels, ood_scores)
```

---

### 8.13.2 对抗鲁棒性

**公式**:

$$\text{Robust Acc} = \frac{1}{N} \sum_{i=1}^{N} \mathbb{1}[\text{model}(x_i + \epsilon) = y_i]$$

- $\epsilon$ = 对抗扰动 (L2 或 Linf 约束)
- 衡量在攻击下的稳定性

**适用**:安全敏感场景 (自动驾驶、人脸识别)。

---

### 8.13.3 分布漂移检测

**PSI (Population Stability Index)**:

$$\text{PSI} = \sum (P_{\text{new}} - P_{\text{base}}) \cdot \ln\frac{P_{\text{new}}}{P_{\text{base}}}$$

| PSI 值 | 含义 |
| :---: | :--- |
| < 0.1 | 分布稳定 |
| 0.1-0.25 | 轻微漂移 |
| > 0.25 | 显著漂移,需重新训练 |

**适用**:监控线上特征分布变化。

---

## 8.14 时序预测 (Time Series)

> 适用:销量预测、股价预测、流量预测、负载预测。

### 8.14.1 SMAPE (Symmetric MAPE)

**公式**:

$$\text{SMAPE} = \frac{100\%}{N} \sum_{i=1}^{N} \frac{|y_i - \hat{y}_i|}{(|y_i| + |\hat{y}_i|) / 2}$$

**优势**:对正负误差对称,避免 MAPE 的"小数值大误差"问题。

**适用**:M4/M5 竞赛标准指标。

---

### 8.14.2 MASE (Mean Absolute Scaled Error)

**公式**:

$$\text{MASE} = \frac{\text{MAE}_{\text{model}}}{\text{MAE}_{\text{naive}}}$$

- 朴素预测 (naive):上一时刻的值作为下一时刻预测
- MASE < 1 表示模型比朴素好

**适用**:跨序列比较 (不同尺度的时序)。

---

### 8.14.3 Quantile Loss (分位数损失)

**公式**:

$$L_q(y, \hat{y}) = \max(q(y - \hat{y}), (q-1)(y - \hat{y}))$$

- $q$ = 分位数 (如 0.5 = MAE, 0.9 = P90)
- 用于预测区间,而不是点估计

**适用**:库存预测、容量规划 (需要 P95 置信区间)。

---
