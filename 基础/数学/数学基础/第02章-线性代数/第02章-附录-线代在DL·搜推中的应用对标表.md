## 🎴 面试快速回忆卡片 (30 张)

**卡片 1:向量内积 vs 余弦相似度**
- 内积 = 相似度(未归一化),余弦 = 内积 / 范数(归一化)
- 双塔召回用余弦(防止 item 范数主导),排序可用内积

**卡片 2:矩阵乘法的三种视角**
- 线性变换:把向量映到另一个空间
- 线性方程组:$A\mathbf{x} = \mathbf{b}$,$\mathbf{x} = A^{-1}\mathbf{b}$
- 神经网络:nn.Linear = $Y = XW + b$

**卡片 3:SVD 是"任何矩阵的最优低秩近似"**
- $A = U \Sigma V^T$,截断 top-$k$ 奇异值 = 最优 rank-$k$ 近似
- Eckart-Young 定理:误差最小

**卡片 4:特征值/特征向量的意义**
- $A\mathbf{v} = \lambda \mathbf{v}$:方向 $\mathbf{v}$ 在 $A$ 作用下不旋转,只缩放 $\lambda$
- 谱半径 = $\max |\lambda|$ 决定收敛速度

**卡片 5:正定矩阵**
- $\mathbf{x}^T A \mathbf{x} > 0$ 对所有 $\mathbf{x} \neq 0$
- 强凸损失($\text{Hessian} \succ 0$) → 任何局部最优 = 全局最优

**卡片 6:条件数 = 病态程度**
- $\kappa(A) = \sigma_{\max} / \sigma_{\min}$
- $\kappa$ 大 → 优化器选 Adam(自适应),SGD 会震荡

**卡片 7:Jacobian 与 Hessian**
- Jacobian:多输出对多输入的一阶导
- Hessian:标量对多输入的二阶导,决定曲率

**卡片 8:反向传播 = 链式法则**
- $\partial L / \partial W = (\partial L / \partial Y) (\partial Y / \partial W)^T$
- 矩阵转置是 BP 的关键

**卡片 9:张量 stride**
- 元素地址 = offset + sum($i_k \cdot$ stride$_k$)
- stride 控制 view/reshape,影响内存访问模式

**卡片 10:Johnson-Lindenstrauss 引理**
- 高维向量投影到 $O(\log n / \epsilon^2)$ 维,距离近似保持
- LSH / SimHash 的理论基础

**卡片 11:稀疏 vs 低秩**
- 稀疏:大多数元素为 0,Embedding 表
- 低秩:可由少量基向量生成,LoRA
- 组合拳:量化 + 低秩 + 稀疏 = 30x 压缩

**卡片 12:LoRA 的核心**
- $\Delta W = B A^T$,$B \in \mathbb{R}^{d \times r}$,$A \in \mathbb{R}^{d \times r}$,$r \ll d$
- 冻结 $W$,只训练 $B, A$,参数从 $d^2$ 降到 $2dr$

**卡片 13:Toeplitz 与卷积**
- 一维卷积 = Toeplitz 矩阵乘向量
- FFT 加速:$O(NK) \to O(N \log N)$

**卡片 14:正交初始化**
- $W$ 初始化为正交矩阵:$\|W^k\| = 1$ 对所有 $k$
- RNN 训练初期梯度不爆炸不消失
- 训练中 $W$ 偏离正交,需配合 LSTM gate / 梯度裁剪

**卡片 15:置换矩阵的两个作用**
- batch shuffle:打破样本相关性
- RoPE:2 维块置换 + 旋转 = 旋转位置编码

**卡片 16:块对角矩阵与多头注意力**
- $h$ 个头 = 块对角矩阵的 $h$ 个块
- 块间独立,可 GPU 并行
- 单头复杂度 $O(d^2)$,多头仍是 $O(hd^2)$,但 $h$ 个独立计算

**卡片 17:为什么 Embedding 用 L2 归一化**
- 归一化后所有向量范数 = 1,在单位球面上
- 内积 = 余弦相似度,避免"长向量主导"
- ANN 检索更准(HNSW 假设球面分布)

**卡片 18:谱归一化为什么稳定 GAN**
- Spectral Norm = $\sigma_{\max}(W)$
- 除以 $\sigma_{\max}$ 让 $\|W\|_2 = 1$
- Lipschitz 常数 = 1,Wasserstein 距离有界

**卡片 19:Hadamard 矩阵的两个优势**
- 元素 $\pm 1$:无浮点乘,只有加减
- WHT 复杂度 $O(n \log n)$,比 FFT 常数小
- Swin Transformer 用 WHT 做 attention

**卡片 20:三对角矩阵的 Thomas 算法**
- 一般 $O(n^3)$ 求解 → Thomas $O(n)$
- 前向消元 + 后向代入
- 用于时间序列 AR 模型、Poisson 方程

**卡片 21:SVD 的几何含义**
- 把矩阵看成"旋转 + 缩放 + 旋转"
- $U$:输入空间的旋转
- $\Sigma$:沿主轴的缩放
- $V^T$:输出空间的旋转
- 截断 = 丢到小缩放方向 = 降维

**卡片 22:为什么 PCA 用特征值分解**
- 数据协方差矩阵是实对称的
- 实对称矩阵 → 谱定理 → 正交对角化
- 特征向量 = 主成分方向,特征值 = 方差

**卡片 23:为什么用 Frobenius 范数做正则**
- $\|W\|_F^2 = \sum w_{ij}^2$
- 与权重衰减等价:$\mathcal{L} + \lambda \|W\|_F^2$
- 凸,可微,与 L2 一致

**卡片 24:RMSNorm vs LayerNorm**
- LN:减均值 + 除标准差,2 个统计量
- RMSNorm:只除 RMS, 1 个统计量
- RMSNorm 训练更快,精度相当 → LLaMA 采用

**卡片 25:RoPE 为什么用旋转而不是加法**
- 相对位置编码,token 间距离自然编码
- 内积 $\langle q_m, k_n \rangle$ 只依赖 $(m-n)$ 与位置模长
- 可以外推到训练时未见过的长度

**卡片 26:为什么 GNN 用图 Laplacian**
- $L = D - A$ 编码图结构
- 谱定理保证实对称,可对角化
- 特征值反映图连通性,$\lambda_2$ 越大越连通
- 切比雪夫多项式近似谱卷积

**卡片 27:QLoRA 三件套**
- NF4 量化:4-bit NormalFloat,分位数编码
- 双重量化:对量化常数再次量化
- 分页优化器:防止显存峰值 OOM
- 效果:65B 模型单卡 48GB 可微调

**卡片 28:为什么 einsum 是 ML 的"通用语"**
- 任意多维运算统一表达
- 编译器可以自动优化(寻找最优 reshape 顺序)
- 比手写 matmul/mul/transpose 更可读
- 比手写代码快(常数小),比 einsum 优化器更通用

**卡片 29:知识蒸馏为什么"软标签"比"硬标签"好**
- 硬标签是 one-hot,只传递类别信息
- 软标签包含类别间相似度("猫"和"狗"的 prob 接近)
- 温度 $T$ 放大 logits 差异,学生学到更丰富信息
- 数学上:对齐教师和学生的 logits 分布

**卡片 30:谱半径与 GNN 收敛**
- GCN 每层 $H^{(l+1)} = \sigma(\tilde{D}^{-1/2} \tilde{A} \tilde{D}^{-1/2} H^{(l)} W)$
- 邻接归一化矩阵的特征值在 $[-1, 1]$
- 谱半径 < 1 → 不会指数放大/衰减
- 这就是 GCN 加 Renormalization trick 的原因

- **ViT**:全局 attention,Attention 矩阵 $L \times L$ ($L$ = 序列长度,大图 = 数万)
- **Swin**:window attention + shifted window
  - 窗口内 attention(块对角,块独立)
  - 置换矩阵实现 shifted(窗口循环移位,§10 §5)
  - WHT(§10 §6) 进一步降低 attention 复杂度

**核心线代故事**:**Swin 用块对角 + 置换 + Hadamard,比 ViT 减少 $O(L)$ 倍 attention 计算**。

### 案例 5:为什么 GraphSAGE 比 GCN 更通用?

- **GCN**:用整图 Laplacian,只能 transductive(训练时见过所有节点)
- **GraphSAGE**:邻居采样 + 聚合函数(mean/LSTM/pool)
  - 采样降低邻接矩阵大小 → 稀疏矩阵 §9
  - 聚合用 MLP = 矩阵乘链 §2
  - 邻居特征 mean = 加权求和 = 矩阵乘 §2
- 关键洞察:采样避免拉普拉斯整体特征值分析

**核心线代故事**:**GraphSAGE = 稀疏采样 + 矩阵乘聚合 + 归纳式学习**。

## 8. 矩阵基础理论严格化

### 8.1 矩阵的 4 大子空间

对 $A \in \mathbb{R}^{m \times n}$:

- **列空间** $C(A) \subset \mathbb{R}^m$, 维数 $= r$ (秩)
- **零空间** $N(A) \subset \mathbb{R}^n$, 维数 $= n - r$
- **行空间** $C(A^\top) \subset \mathbb{R}^n$, 维数 $= r$
- **左零空间** $N(A^\top) \subset \mathbb{R}^m$, 维数 $= m - r$

**秩-零化度定理**: $\dim C(A) + \dim N(A) = n$。

**应用**: 推荐系统矩阵补全的解空间 = 零空间 + 特解。

### 8.2 矩阵乘法视角

$AB$ 的多种解读:

- **线性变换**: 先 $B$ 后 $A$
- **行-列**: $(AB)_{ij} = \sum_k A_{ik} B_{kj}$
- **外积和**: $AB = \sum_k A_{*k} B_{k*}$
- **秩 1 分解**: $A = \sum_k \sigma_k u_k v_k^\top$ (SVD)

### 8.3 矩阵与张量

- 0 阶张量 = 标量
- 1 阶张量 = 向量
- 2 阶张量 = 矩阵
- 高阶 = 多维数组

DL: 图像是 3 阶, batch 是 4 阶, 视频是 5 阶。

## 9. 特征值与特征向量深度

### 9.1 几何意义

$A v = \lambda v$: $v$ 是 $A$ 的"不变方向", $A$ 沿 $v$ 拉伸 $\lambda$ 倍。

### 9.2 谱定理

**对称矩阵**: $A = Q \Lambda Q^\top$, $Q$ 正交, $\Lambda$ 对角。

**应用**: PCA, Hessian 的特征分解, Graph Laplacian。

### 9.3 Jordan 标准型 (一般矩阵)

任何 $A$ 相似于 Jordan 块: $A = P J P^{-1}$, $J$ 是 Jordan 形式。

**应用**: 微分方程求解。

### 9.4 Schur 分解

$A = U T U^\top$, $T$ 上三角 (Schur 形式)。

**应用**: 矩阵函数定义 (如 $e^A$)。

## 10. SVD 全面解析

### 10.1 定义

$A = U \Sigma V^\top$, $U \in \mathbb{R}^{m \times m}$ 正交, $\Sigma = \text{diag}(\sigma_1, \ldots, \sigma_r)$, $V \in \mathbb{R}^{n \times n}$ 正交, $\sigma_1 \ge \sigma_2 \ge \ldots \ge \sigma_r > 0$。

### 10.2 几何意义

$A$ 把单位球映成椭球, 主轴 = $u_i$, 半轴长度 = $\sigma_i$。

### 10.3 极分解

$A = UP$, $U$ 正交, $P$ 半正定。

### 10.4 低秩近似 (Eckart-Young-Mirsky)

最优秩-$k$ 近似: $A_k = \sum_{i=1}^k \sigma_i u_i v_i^\top$, $\|A - A_k\|_2 = \sigma_{k+1}$。

**应用**: 推荐系统矩阵压缩, LoRA 低秩适应。

### 10.5 增广 SVD

$m > n$ 时用 thin SVD, 节省内存。

```python
U, S, Vt = torch.linalg.svd(A, full_matrices=False)
```

### 10.6 Randomized SVD

$O(mn \log k)$ 近似 SVD, 大矩阵用。

```python
from sklearn.utils.extmath import randomized_svd
U, S, Vt = randomized_svd(A, n_components=10)
```

## 11. 矩阵范数

### 11.1 诱导范数

$\|A\|_p = \max_{\|x\|_p = 1} \|A x\|_p$

- 1-范数: 最大列和
- $\infty$-范数: 最大行和
- 2-范数: $\sigma_{\max}(A)$ (谱范数)
- Frobenius: $\|A\|_F = \sqrt{\sum A_{ij}^2} = \sqrt{\sum \sigma_i^2}$

### 11.2 范数关系

$\|A\|_2 \le \|A\|_F \le \sqrt{n} \|A\|_2$

$\frac{1}{\sqrt{n}}\|A\|_1 \le \|A\|_2 \le \sqrt{m}\|A\|_1$

### 11.3 算子范数与 Lipschitz

$\|A\|_2$ 是 $A$ 作为线性算子的 Lipschitz 常数。

**应用**: 谱归一化让 $\|W\|_2 \le 1$。

## 12. 矩阵分解家族

### 12.1 LU 分解

$A = LU$, $L$ 下三角单位, $U$ 上三角。

**复杂度**: $O(n^3/3)$。

### 12.2 QR 分解

$A = QR$, $Q$ 正交, $R$ 上三角。

**应用**: 最小二乘 (数值稳定)。

### 12.3 Cholesky 分解

$A = LL^\top$, $A$ 对称正定。

**复杂度**: $O(n^3/3)$, LU 的一半。

### 12.4 特征分解

$A = Q \Lambda Q^{-1}$, 对称时 $A = Q \Lambda Q^\top$。

### 12.5 SVD

通用分解 (任意矩阵)。

### 12.6 非负矩阵分解 (NMF)

$A \approx WH$, $W, H \ge 0$。

**应用**: 推荐系统, 主题模型。

### 12.7 Tucker 分解

张量分解, PCA 的张量推广。

**应用**: 多维推荐。

## 13. 矩阵微积分

### 13.1 常用公式

$\frac{\partial}{\partial X} \text{Tr}(X) = I$

$\frac{\partial}{\partial X} \text{Tr}(X A X^\top) = X (A + A^\top)$

$\frac{\partial}{\partial X} \text{Tr}(X^{-1} A) = -(X^{-\top} A X^{-\top})$

$\frac{\partial}{\partial X} \log \det X = X^{-\top}$

### 13.2 矩阵链式法则

$F = g(X)$, $L = f(F)$, $\frac{\partial L}{\partial X} = \sum_{ij} \frac{\partial L}{\partial F_{ij}} \frac{\partial F_{ij}}{\partial X}$。

### 13.3 Jacobian 与梯度

向量函数 $f: \mathbb{R}^n \to \mathbb{R}^m$, Jacobian $J_{ij} = \partial f_i / \partial x_j$。

**反向传播**: $\frac{\partial L}{\partial x} = J^\top \frac{\partial L}{\partial f}$。

## 14. 应用矩阵专题

### 14.1 PCA 主成分分析

**步骤**:

1. 中心化 $X \leftarrow X - \bar X$
2. 协方差 $C = X^\top X / n$
3. 特征分解 $C = V \Lambda V^\top$
4. 取 top-$k$ 特征向量 = 主成分
5. 投影 $X_{\text{proj}} = X V_k$

**信息保留**: $\sum_{i=1}^k \lambda_i / \sum_{i=1}^n \lambda_i$。

### 14.2 线性判别分析 (LDA)

最大化类间方差 / 类内方差。

**与 PCA 区别**: PCA 无监督, LDA 有监督。

### 14.3 推荐矩阵分解

$R \approx U V^\top$, $R$ 是评分矩阵, $U, V$ 是 user/item embedding。

**ALS 优化**: 固定 $U$ 优化 $V$, 固定 $V$ 优化 $U$, 交替。

### 14.4 Attention 矩阵

$A = \text{softmax}(Q K^\top)$, 行的和 = 1 (概率分布)。

### 14.5 邻接矩阵与图

$A_{ij} = 1$ 当 $i, j$ 相连。GNN 核心数据结构。

## 15. 应用代码示例

### 15.1 SVD 图像压缩

```python
import numpy as np
import matplotlib.pyplot as plt

# 加载图像 (假设是灰度矩阵)
img = np.random.randn(100, 100)  # placeholder

U, S, Vt = np.linalg.svd(img, full_matrices=False)

# 取 top-k 奇异值重建
for k in [5, 20, 50]:
    img_k = U[:, :k] @ np.diag(S[:k]) @ Vt[:k, :]
    # 内存: k * (100 + 100) = 200k
    # vs 原图: 100*100 = 10000
    print(f"k={k}: 压缩比 {10000/(200*k):.2f}x, 误差 {np.linalg.norm(img - img_k):.2f}")
```

### 15.2 PCA 实现

```python
def pca(X, n_components):
    X_centered = X - X.mean(dim=0, keepdim=True)
    U, S, Vt = torch.linalg.svd(X_centered, full_matrices=False)
    # 取 top-k
    components = Vt[:n_components].T  # [d, k]
    explained_var = S[:n_components] ** 2 / (X.shape[0] - 1)
    explained_ratio = explained_var / explained_var.sum()
    return components, explained_ratio

# 用法
X = torch.randn(100, 50)
components, var_ratio = pca(X, n_components=10)
print(f"Top-10 主成分解释 {var_ratio.sum():.2%} 方差")
```

### 15.3 矩阵求逆稳定性

```python
def stable_inverse_solve(A, b):
    """数值稳定解线性方程组."""
    cond = torch.linalg.cond(A)
    if cond < 1e6:
        return torch.linalg.solve(A, b)
    elif cond < 1e12:
        # 加 Tikhonov 正则
        return torch.linalg.solve(A + 1e-6 * torch.eye_like(A), b)
    else:
        # SVD + 截断
        U, S, Vt = torch.linalg.svd(A, full_matrices=False)
        S_inv = torch.where(S > 1e-10, 1.0 / S, torch.zeros_like(S))
        return (Vt.T * S_inv) @ U.T @ b
```

## 16. 矩阵与 DL 的深度联系

### 16.1 Transformer

$Q, K, V \in \mathbb{R}^{n \times d}$, 注意力 = $\text{softmax}(Q K^\top / \sqrt{d}) V$, $O(n^2 d)$ 计算。

### 16.2 LoRA

$W \in \mathbb{R}^{m \times n}$, LoRA 增量 = $BA$, $B \in \mathbb{R}^{m \times r}$, $A \in \mathbb{R}^{r \times n}$, $r \ll \min(m, n)$。

### 16.3 Neural ODE

$\frac{dh}{dt} = f(h, t)$, 离散化 $h_{t+1} = h_t + \Delta t \cdot f(h_t, t)$, 类似 Euler 步进。

### 16.4 矩阵指数

$e^A = \sum_k A^k / k!$, 用 Padé 逼近。

**应用**: 残差网络 = $e^{tF} x$ (形式)。

## 17. 数学例题

### 例题 17.1: 特征值计算

**题目**: $A = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$, 特征值?

**解答**: $\det(A - \lambda I) = (2-\lambda)^2 - 1 = \lambda^2 - 4\lambda + 3 = (\lambda-1)(\lambda-3) = 0$。

$\lambda_1 = 3, v_1 = (1, 1)/\sqrt{2}$; $\lambda_2 = 1, v_2 = (1, -1)/\sqrt{2}$。

### 例题 17.2: SVD

**题目**: $A = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}$, SVD?

**解答**: $A^\top A = \begin{pmatrix} 1 & 1 \\ 1 & 2 \end{pmatrix}$, 特征值 $2.618, 0.382$, 奇异值 $\sqrt{2.618}, \sqrt{0.382}$。

### 例题 17.3: 矩阵条件数

**题目**: $A = \begin{pmatrix} 1 & 1 \\ 1 & 1.0001 \end{pmatrix}$, 条件数?

**解答**: 行列式 = 0.0001, 接近奇异, 条件数大 ($\sim 10^4$)。

---

### 例题 17.4: 反向传播 Jacobian

**题目**: $y = W x + b$, $\ell = \|y - y^*\|^2 / 2$, 求 $\partial \ell / \partial W$。

**解答**: $\partial \ell / \partial y = y - y^*$, $\partial y / \partial W = x^\top$ (外积), $\partial \ell / \partial W = (y - y^*) x^\top$。

---

### 例题 17.5: LoRA 参数节省

**题目**: $W \in \mathbb{R}^{4096 \times 4096}$, $r = 8$, LoRA 参数数?

**解答**: 原 $W$ = 16M 参数。LoRA = $4096 \times 8 + 8 \times 4096$ = 65536, 节省 245x。

---

### 例题 17.6: SVD 压缩比

**题目**: $A \in \mathbb{R}^{1000 \times 1000}$, $k = 50$ 截断, 内存比?

**解答**: 原 = $10^6$。截断 = $1000 \cdot 50 + 50 + 50 \cdot 1000 = 10^5$。节省 10x。

---

### 例题 17.7: Power Iteration

**题目**: 用 power 迭代求 $A = \begin{pmatrix} 2 & 1 \\ 1 & 3 \end{pmatrix}$ 主特征值。

**解答**: 迭代 $v \leftarrow A v / \|A v\|$, 收敛到 $(0.526, 0.851)$, 特征值 = 3.618。

---

### 例题 17.8: 矩阵范数

**题目**: $A = \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}$, $\|A\|_2$?

**解答**: $A^\top A = \begin{pmatrix} 10 & 14 \\ 14 & 20 \end{pmatrix}$, 特征值 $(30 \pm \sqrt{196})/2 = (30 \pm 14)/2 = 22, 8$, 谱范数 = $\sqrt{22} \approx 4.69$。

## 18. 面试高频 (15 题)

### Q1: SVD 与特征分解的区别?

**答**: 特征分解仅对**对称 (或方阵)** 适用, SVD 对**任意矩阵**适用。SVD 唯一, 特征分解不唯一。

---

### Q2: 什么是伪逆? 何时用?

**答**: Moore-Penrose 伪逆 $A^+ = V \Sigma^+ U^\top$, $\Sigma^+ = \text{diag}(1/\sigma_i)$。当 $A$ 不方或不可逆时, 给出最小二乘解。

---

### Q3: 为什么 LoRA 用低秩?

**答**: 经验上权重更新是低秩的 (Aghajanyan 2020)。LoRA 把全秩 $\Delta W$ 分解为 $BA$, $r \ll \min(m, n)$, 大幅减参数。

---

### Q4: 矩阵范数有哪些? 关系?

**答**: 1-范数 (列和), 2-范数 (谱范数), $\infty$-范数 (行和), Frobenius (元素平方和)。关系: $\|A\|_2 \le \|A\|_F \le \sqrt{n} \|A\|_2$。

---

### Q5: 谱归一化数学?

**答**: 强制 $\|W\|_2 = \sigma_{\max}(W) = 1$。让 GAN 判别器 1-Lipschitz, 训练稳定。Power iteration 在线估计 $\sigma_{\max}$。

---

### Q6: PCA 的几何意义?

**答**: 找数据方差最大的方向, 这些方向**正交**, 张成"主成分子空间"。数据投影后, 方差最大。

---

### Q7: 推荐系统矩阵分解?

**答**: 评分矩阵 $R \in \mathbb{R}^{m \times n}$ 分解为 $U V^\top$, $U \in \mathbb{R}^{m \times d}$ (user), $V \in \mathbb{R}^{n \times d}$ (item)。ALS 训练。

---

### Q8: 为什么 Transformer 用 scaled dot-product?

**答**: 除以 $\sqrt{d_k}$ 让 softmax 输入方差 = 1, 避免梯度消失。$Q K^\top$ 的方差随 $d_k$ 增长, 缩放归一化。

---

### Q9: 矩阵求逆 vs 解线性方程组?

**答**: **永远不解 $Ax = b$ 通过 $A^{-1} b$**。`np.linalg.solve(A, b)` 用 LU 分解, 比 `np.linalg.inv(A) @ b` 数值更稳定且更快 (尤其多次解同一 $A$)。

---

### Q10: Tensor 的 mode-k unfolding?

**答**: 把张量某一模展开为矩阵。例如 3-阶张量 $\mathcal{X} \in \mathbb{R}^{I \times J \times K}$, mode-1 unfolding 是 $X_{(1)} \in \mathbb{R}^{I \times JK}$。

**应用**: Tucker 分解, 张量 PCA。

---

### Q11: Symmetric Positive Definite (SPD) 矩阵的性质?

**答**: (1) 特征值全正; (2) $x^\top A x > 0$ for all $x \ne 0$; (3) Cholesky 分解存在; (4) 平方根存在。

---

### Q12: 谱半径与谱范数?

**答**: 谱半径 $\rho(A) = \max |\lambda_i(A)|$, 谱范数 $\|A\|_2 = \sigma_{\max}(A) = \sqrt{\rho(A^\top A)}$。**谱半径控制迭代收敛** ($\rho < 1$), **谱范数控制 Lipschitz**。

---

### Q13: Householder 变换为什么数值稳定?

**答**: 通过反射 $H = I - 2vv^\top$, 正交化时不需要显式开方, 避免数值误差。

---

### Q14: Attention 矩阵为什么是低秩?

**答**: 经验上, 训练后 Attention 矩阵的有效秩远小于 token 数 (Voita 2019)。这是稀疏 Attention 的理论依据。

---

### Q15: 矩阵指数 $e^A$ 怎么算?

**答**: 用 Padé 逼近: $e^A \approx (I - A/2 + A^2/12 - ...)^{-1} (I + A/2 + A^2/12 + ...)$。数值稳定 (SciPy `linalg.expm`)。

## 20. 矩阵论扩展

### 20.1 正交矩阵

$Q^\top Q = I$, 列正交, 数值稳定。

**性质**: $\|Q x\| = \|x\|$, 保范数。

### 20.2 投影矩阵

$P^2 = P$, $P = P^\top$ (正交投影)。

$P = A (A^\top A)^{-1} A^\top$ (到 $C(A)$ 的投影)。

### 20.3 酉矩阵 (复数)

$U^* U = I$, $U^* = U^\top$ 的复推广。

**应用**: 量子计算, 复数神经网络。

### 20.4 反射矩阵

$H = I - 2 vv^\top$, $H^2 = I$。

**应用**: Householder QR。

### 20.5 置换矩阵

每行每列恰一个 1。

**应用**: LU 部分主元。

## 21. 矩阵不等式

### 21.1 Cauchy-Schwarz (矩阵版)

$|\langle A, B \rangle| \le \|A\|_F \|B\|_F$, $\langle A, B \rangle = \text{Tr}(A^\top B)$。

### 21.2 AM-GM

$\text{Tr}(AB) \le \frac{1}{2} (\text{Tr}(A^2) + \text{Tr}(B^2))$。

### 21.3 Poincaré 不等式

$\|x - \bar x\|^2 \le C \|x - \nabla x\|^2$, 用于流形上的集中。

---

## 22. 张量基础

### 22.1 定义

$n$ 阶张量 = $n$ 维数组 $\mathcal{X} \in \mathbb{R}^{I_1 \times I_2 \times \ldots \times I_n}$。

### 22.2 运算

- **mode-k 乘积**: $\mathcal{Y} = \mathcal{X} \times_k U$, $U \in \mathbb{R}^{J \times I_k}$
- **Frobenius 范数**: $\|\mathcal{X}\|_F = \sqrt{\sum X_{i_1 \ldots i_n}^2}$
- **张量内积**: $\langle \mathcal{X}, \mathcal{Y} \rangle = \sum X \odot Y$

### 22.3 张量分解

**CP 分解**: $\mathcal{X} \approx \sum_{r=1}^R u_1^{(r)} \circ u_2^{(r)} \circ \ldots \circ u_n^{(r)}$, $\circ$ = 外积。

**Tucker 分解**: $\mathcal{X} \approx \mathcal{G} \times_1 U_1 \times_2 U_2 \ldots \times_n U_n$, $\mathcal{G}$ 核心张量。

**应用**: 多维推荐 (user × item × context)。

## 23. 矩阵分析

### 23.1 矩阵的微分方程

$\frac{dX}{dt} = AX + XA^\top + B$, 解为 $X(t) = e^{tA} X(0) e^{tA^\top} + \int_0^t e^{(t-s)A} B e^{(t-s)A^\top} ds$。

### 23.2 Lyapunov 方程

$AX + XA^\top = Q$, 用于稳定性分析。

### 23.3 Sylvester 方程

$AX + XB = C$, 唯一解条件 $\sigma(A) \cap \sigma(-B) = \emptyset$。

## 24. 矩阵计算进阶

### 24.1 矩阵函数

$f(A) = U f(\Lambda) U^\top$, $f$ 是 $A$ 的谱分解。

例: $\log A = U \log \Lambda U^\top$, $\exp(A) = U \exp(\Lambda) U^\top$。

### 24.2 矩阵对数

$\log A$ = 求 $X$ 使 $e^X = A$。用于流形优化。

### 24.3 矩阵平方根

$A^{1/2} = U \Lambda^{1/2} U^\top$。Covariance 的逆是 $A^{-1/2}$。

## 32. 实战: 矩阵计算代码模板

### 32.1 矩阵分解模板

```python
import torch
import numpy as np

class MatrixDecompositions:
    """常用矩阵分解的工具类."""

    @staticmethod
    def lu_decompose(A):
        """LU 分解 (含部分主元)."""
        P, L, U = torch.linalg.lu(A)
        return P, L, U

    @staticmethod
    def qr_decompose(A):
        """QR 分解."""
        Q, R = torch.linalg.qr(A, mode='reduced')
        return Q, R

    @staticmethod
    def cholesky_decompose(A):
        """Cholesky 分解 (A 必须正定)."""
        L = torch.linalg.cholesky(A)
        return L

    @staticmethod
    def svd_decompose(A, full=True):
        """SVD 分解."""
        if full:
            U, S, Vt = torch.linalg.svd(A, full_matrices=True)
        else:
            U, S, Vt = torch.linalg.svd(A, full_matrices=False)
        return U, S, Vt

    @staticmethod
    def eig_decompose(A):
        """特征分解 (对称)."""
        eigvals, eigvecs = torch.linalg.eigh(A)
        return eigvals, eigvecs

# 测试
A = torch.tensor([[2.0, 1.0], [1.0, 3.0]])
decomp = MatrixDecompositions()
P, L, U = decomp.lu_decompose(A)
print(f"LU: ||A - PLU|| = {torch.norm(A - P @ L @ U):.2e}")
Q, R = decomp.qr_decompose(A)
print(f"QR: ||A - QR|| = {torch.norm(A - Q @ R):.2e}")
L = decomp.cholesky_decompose(A)
print(f"Cholesky: ||A - LL^T|| = {torch.norm(A - L @ L.T):.2e}")
```

```python
def matrix_rank(A, tol=None):
    """数值秩."""
    if tol is None:
        tol = max(A.shape) * torch.finfo(A.dtype).eps
    return torch.linalg.matrix_rank(A, tol=tol)

def is_positive_definite(A):
    """检查矩阵是否正定."""
    try:
        torch.linalg.cholesky(A)
        return True
    except RuntimeError:
        return False

def condition_number(A):
    """条件数."""
    return torch.linalg.cond(A)

def orthogonalize_columns(X):
    """正交化矩阵的列 (Gram-Schmidt)."""
    Q, _ = torch.linalg.qr(X)
    return Q
```

### 32.3 矩阵微积分自动求导

```python
# 反向传播中常用的矩阵导数
def gradient_check_matmul(A, B, loss_fn):
    """验证 matmul 反向传播."""
    A = A.clone().requires_grad_(True)
    B = B.clone().requires_grad_(True)
    loss = loss_fn(A @ B)
    loss.backward()
    # 数值梯度
    eps = 1e-5
    A_num = torch.zeros_like(A)
    B_num = torch.zeros_like(B)
    for i in range(A.numel()):
        a_flat = A.view(-1)
        orig = a_flat[i].item()
        a_flat[i] = orig + eps
        l_plus = loss_fn(A @ B).item()
        a_flat[i] = orig - eps
        l_minus = loss_fn(A @ B).item()
        a_flat[i] = orig
        A_num.view(-1)[i] = (l_plus - l_minus) / (2 * eps)
    print(f"Max diff A: {(A.grad - A_num).abs().max():.2e}")
```

### 45.2 矩阵运算复杂度

| 运算 | 复杂度 |
| :--- | :--- |
| 矩阵乘法 $AB$ ($m \times n$ × $n \times p$) | $O(mnp)$ |
| 矩阵转置 | $O(mn)$ |
| 矩阵求逆 | $O(n^3)$ |
| LU 分解 | $O(n^3/3)$ |
| QR 分解 | $O(2mn^2/3)$ |
| Cholesky | $O(n^3/3)$ |
| 特征分解 (对称) | $O(n^3/3)$ |
| SVD | $O(mn^2)$ 或 $O(n^3)$ |

### 45.3 矩阵论的 5 个常见陷阱

1. **混淆 dim**: PyTorch 用 dim, NumPy 用 axis
2. **混淆 in-place vs out-of-place**: PyTorch 区分
3. **混淆 dtype**: FP16 矩阵运算会丢精度
4. **混淆 batch 维度**: matmul 自动 batch, einsum 显式
5. **混淆 contiguous vs non-contiguous**: view 要求 contiguous

### 45.4 矩阵的"工程实现"经验

- 永远 batch 操作, 不要 for loop
- 优先用 FP32, FP16 配 AMP
- 大矩阵用 sparse 表示
- 矩阵乘优先 cuBLAS
- 监控矩阵 norm, 早期发现问题
