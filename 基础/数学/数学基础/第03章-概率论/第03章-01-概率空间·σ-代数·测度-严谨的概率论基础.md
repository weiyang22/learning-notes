## 1. 直觉引入:为什么朴素概率会出 bug? (300 行)

### 1.1 工程师的痛点:三种"合理"答案选哪个?

先看一个看似简单的几何概率问题 (Bertrand 悖论, 1889):

> 在半径为 $r$ 的圆里"随机"取一条弦,这条弦比圆的**内接正三角形**的边长还长的概率是多少?

直觉有三种"自然"算法,得到**三个不同答案**。

**算法 1 (随机端点)**:均匀随机选两个端点。弦长大于 $\sqrt{3} r$ (内接正三角形边长) 的概率。
- 弦的两个端点都在"短弧"上 (短弧长度 = 圆周长的 1/3)。
- 答案: $P_1 = 1/3$

**算法 2 (随机径向)**:随机选一个**半径方向**,再在这个方向上随机选一个**点**,最后过这个点做**垂直于该半径的弦**。要求弦长 > $\sqrt{3} r$。
- 弦到圆心的距离 $< r/2$。
- 答案: $P_2 = 1/2$

**算法 3 (随机中点)**:随机选弦的**中点** (在圆盘内均匀)。中点到圆心距离 < $r/2$ 时弦长 > $\sqrt{3} r$。
- 答案: $P_3 = 1/4$

**三个"合理的随机"得到三个不同答案!** 这就是 Bertrand 悖论。

**工程师的第一反应**:"这不科学啊,概率应该只有一个答案。"

**数学家的第一反应**:"你**没说清楚**'随机'是什么。不同的'随机'对应不同的**概率测度**。"

**这告诉我们**:
- "概率"不是"频率"那么简单
- 不同的"随机过程" → 不同的"概率测度" → 不同的"概率值"
- 在严肃的工程场景 (A/B 实验, 蒙特卡洛估计),你**必须先**定义"概率测度"是什么

### 1.2 直觉:概率 = 集合的"大小"

我们用一个更朴素的视角:**概率 = 集合的"大小"** (或"权重")。

**类比 1 (长度)**:

```text
   ┌──────────────────────┐
   │  ▓▓▓▓▓▓▓▓▓           │   一根 10 厘米的线段,
   │  ▓▓▓▓▓▓▓▓▓           │   其中 4 厘米是红色
   │  ▓▓▓▓▓▓▓▓▓           │   "红段"占整体的长度比 = 4/10 = 0.4
   └──────────────────────┘
   0         6       10
```

**类比 2 (面积)**:

```text
       ┌───────────────┐
      ╱│   ▓▓▓▓▓      ╱│
     ╱ │  ▓▓▓▓▓▓     ╱ │
    ╱  │ ▓▓▓▓▓▓▓    ╱  │   半径 1 的圆盘
   │   │▓▓▓▓▓▓▓▓   │   │   内接正三角形 (深色区域)
   │   │  ▓▓▓▓▓    │   │   三角形面积 / 圆盘面积 = (3√3/4) / π ≈ 0.413
   │   │           │   │
   └───┴───────────┴───┘
```

**类比 3 (计数)**:

抛两枚公平硬币,样本空间 $\Omega = \{HH, HT, TH, TT\}$, $|\Omega| = 4$。事件 $A$ = "至少一个正面", $A = \{HH, HT, TH\}$, $|A| = 3$。"$A$ 占整体的比例" = $3/4 = 0.75$。

**这三种"大小"有什么共同点?**

1. **非负**:长度/面积/计数都 $\ge 0$
2. **整体 = 1**:线段/圆盘/样本空间本身的"大小"是 1 (在归一化后)
3. **可加**:不重叠部分的"大小"之和 = 整体的"大小"

**这就是概率论的公理化起点**。Kolmogorov 在 1933 年做的事,本质就是**把"大小"这个直觉形式化**。

### 1.3 一个让你"卡住"的问题:Vitali 集

**问题**:能不能把 $\Omega = [0, 1]$ 划分成可数多个"等大"的小块?

直觉:当然能,比如切成 $n$ 段。但 $n$ 必须是有限的。

**Vitali 集 (Vitali set, 1905)**:用**选择公理** (Axiom of Choice),可以把 $[0, 1]$ 划分成**不可数**多个集合,使得"平移"后可以拼成 $[0, 1]$。但**这些集合不可测**，你**没法**给它们一个一致的"长度"。

**直觉**:这听起来像数学家没事找事,但**对你意味着什么**?

- 如果你写的代码需要"对任意集合算概率",你会发现有些集合的"概率"是**未定义的**
- 工程上一般不直接遇到 Vitali 集 (它们需要选择公理才能构造),但**严格化**时,这就是"为什么需要 σ-代数"的根源
- ML 里有一个类似的事情:Cross-Entropy Loss 在某些极端分布下 (如 δ 函数 + 连续分布的混合) 不收敛,本质也是"测度问题"

**为什么我们要在第 1 章就讲这个?** 因为**概率论的公理化不是装腔作势,是 1900 年代数学危机的产物**。Riemann 时代定义的"黎曼积分"对病态函数束手无策,Vitali 时代构造的"病态集合"让朴素概率论崩盘。Kolmogorov 公理化是这两场危机的**统一解法**。

### 1.4 严格化的动机:从"直觉"到"代码"

你写代码时,有没有想过:


## 2. 概率的公理化:Kolmogorov 三公理 (350 行)

### 2.1 公理 1:非负性

**公理 1**:对任意事件 $A$, $P(A) \ge 0$。

**直觉**:概率是"非负的"，一个事件发生的"权重"不能是负数。负概率在物理上没有意义,在信息论里也对应"无编码方案"。

**反直觉的例子**:**量子力学里的"准概率分布"** (Wigner 函数) 可以取负值。但这不是经典概率论的对象,我们不讨论。

**ML 视角**:`torch.softmax` 输出的概率 $\ge 0$, 这是公理 1 的体现。如果你的模型输出负的"概率",那一定不是概率,是 logit 之类的原始分数。

### 2.2 公理 2:归一性

**公理 2**:$P(\Omega) = 1$, 其中 $\Omega$ 是**整个样本空间**。

**直觉**:整个样本空间发生的概率 = 1 (必然事件)。

**反直觉**:但**不是所有"几乎处处为 1"的事件就是 $\Omega$**。例如在 $[0, 1]$ 上的均匀分布,事件 $A = [0, 1] \setminus \mathbb{Q}$ (无理数集) 的概率是 1, 但 $A \ne \Omega$。这种"几乎必然但不是必然"的事件在工程里也会出现 (例如"训练集上 loss 几乎必然 → 0",但实际可能不收敛)。

**ML 视角**:这就是为什么 `F.cross_entropy` 的输入 logits 经过 softmax 后**总和 = 1**，这是公理 2 的实现。

### 2.3 公理 3:可列可加性 (最关键)

**公理 3**:对**两两不交**的事件序列 $A_1, A_2, A_3, \ldots$ (有限或可数无穷),有:

$$P\left( \bigcup_{i=1}^{\infty} A_i \right) = \sum_{i=1}^{\infty} P(A_i)$$

**直觉**:不重叠的事件,概率可以**逐个相加**。

**关键修饰词:可数 (countable),不是有限 (finite)**:必须对**可数无穷**个事件也成立。这是公理 3 与"有限可加性"的关键区别,也是为什么"$\sigma$" 符号 (sigma) 出现在 σ-代数里。

**为什么"可数可加"如此关键?**

1. **大数定律的数学基础**:大数定律说的是"无穷多个独立试验的均值 → 期望",需要"可列可加性"才能把每个试验的概率加起来。
2. **连续分布的理论支柱**:连续分布在单点的概率 = 0, 但**可数个点**的概率还是 0, 这只在可列可加性下成立。
3. **测度论的核心**:**Lebesgue 测度** (后面 §4 讲) 的可列可加性,是 Lebesgue 积分的根基。

**反例 (为什么"有限可加"不够)**:考虑一个病态的"概率",它在有限可加性下成立,但在可列可加性下崩盘。最经典的例子是 Banach 测度 (Banach-Tarski 悖论的简化版),它会让单位球的体积等于地球的体积。

**ML 视角**:可列可加性 = "我可以独立处理每个样本"。CrossEntropy Loss 的形式 $-\sum_i \log p(x_i)$ 隐含地假设了**每个样本独立**, 这就是可列可加性的工程翻译。

### 2.4 推论:P(∅) = 0, P(A) + P(Aᶜ) = 1

**推论 1** (空集概率):$P(\emptyset) = 0$。

**证明**:
$$P(\emptyset) = P(\emptyset \cup \emptyset \cup \ldots) = P(\emptyset) + P(\emptyset) + \ldots$$
两边减去 $P(\emptyset)$, 得 $0 = P(\emptyset) + P(\emptyset) + \ldots$, 这个无穷和是 $P(\emptyset)$ 加无穷次。要让和有限,必须 $P(\emptyset) = 0$。

**推论 2** (补集概率):$P(A) + P(A^c) = 1$, 其中 $A^c = \Omega \setminus A$ 是 $A$ 的补集。

**证明**:
$$1 = P(\Omega) = P(A \cup A^c) = P(A) + P(A^c)$$
($A$ 和 $A^c$ 不相交, 由可加性。)

**ML 视角**:这就是为什么 `1 - p_positive = p_negative`，二分类里正例概率和负例概率之和 = 1。

### 2.5 古典概率 (Laplace):最朴素的情形

**定义** (古典概率):若 $\Omega$ 是**有限**集合, 所有基本事件 $\omega \in \Omega$ **等可能**, 则对任意事件 $A$:

$$P(A) = \frac{|A|}{|\Omega|}$$

这就是**Laplace 古典概率**。**等可能** = 朴素的对称性, 没有额外信息时"每个结果一样可能"。

**关键限制**:**$\Omega$ 必须是有限集**。如果 $\Omega$ 无限, $|A| / |\Omega|$ 没意义 (∞/∞ 是未定式)。

**例**:抛两枚硬币, $\Omega = \{HH, HT, TH, TT\}$, $|\Omega| = 4$。事件 $A$ = "至少一个正面" $= \{HH, HT, TH\}$, $|A| = 3$。$P(A) = 3/4$。

**ML 视角**:朴素贝叶斯分类器 (Naive Bayes) 的"先验"就是古典概率，没有数据时,假设所有类别等可能。**然后用数据 (似然) 修正这个朴素假设**。

### 2.6 几何概率:从有限到无限

**定义** (几何概率):对**连续**样本空间 $\Omega \subset \mathbb{R}^d$ (或其子集), 假设"均匀"分布, 则对事件 $A$:

$$P(A) = \frac{\text{vol}(A)}{\text{vol}(\Omega)}$$

其中 $\text{vol}$ 是 $d$ 维体积 (1 维长度, 2 维面积, 3 维体积, ...)。

**例 1** (Buffon 投针, 1777):在间距为 $d$ 的平行线上随机投一根长为 $l < d$ 的针, 针与平行线相交的概率:
$$P = \frac{2l}{\pi d}$$

**例 2** (Bertrand 悖论的算法 3):圆盘内随机选一点, 在半径 $r/2$ 的内圆内的概率 = $\pi (r/2)^2 / \pi r^2 = 1/4$。这就是 §1.1 的 $P_3 = 1/4$。

**关键**:几何概率 = "体积比"。这与"长度 = Lebesgue 测度"严格对应 (第 1-高数 第 6 章 §7.3)。

### 2.7 5 个手算例子

#### 例 1:抛两枚公平硬币, 至少一个正面的概率

$\Omega = \{HH, HT, TH, TT\}$, $|\Omega| = 4$。

事件 $A$ = "至少一个正面" $= \{HH, HT, TH\}$, $|A| = 3$。

$$P(A) = \frac{3}{4} = 0.75$$

**对照**:"两个都是反面" = $\{TT\}$, 概率 $1/4$。所以"至少一个正面" = $1 - 1/4 = 3/4$ (用补集, 不用数 $A$ 的元素)。

#### 例 2:抽 5 张扑克牌, 抽到"同花顺"的概率

52 张牌, 4 种花色, 每种 13 张。同花顺 = "5 张同花色且数字连续"。

**总样本数** (5 张牌的有序组合): $52 \times 51 \times 50 \times 49 \times 48 / 5! = \binom{52}{5} = 2,598,960$。

**同花顺数**:
- 选花色: 4 种
- 选起点 (最小的数字): 10 种 (A2345 到 10JQKA)
- 每种 5 张都是唯一的

所以同花顺数 = $4 \times 10 = 40$。

$$P = \frac{40}{2,598,960} = \frac{1}{64,974} \approx 1.54 \times 10^{-5}$$

**ML 视角**:同花顺 ≈ $\frac{1}{65000}$, 在 5 张牌的扑克牌局里, 平均要打 6.5 万局才出现一次。**对推荐系统类似**:小概率事件的 CTR 提升需要极大流量才能达到统计显著。

#### 例 3:抛一枚公平骰子 3 次, 点数之和 = 10 的概率

$\Omega = \{1, 2, 3, 4, 5, 6\}^3$, $|\Omega| = 216$。

**和为 10 的组合** (不重复, 顺序无关):
- (1, 3, 6) → 6 种排列
- (1, 4, 5) → 6 种排列
- (2, 3, 5) → 6 种排列
- (2, 4, 4) → 3 种排列
- (3, 3, 4) → 3 种排列
- (1, 3, 6) + (1, 4, 5) + (2, 3, 5) + (2, 4, 4) + (3, 3, 4) = 6 + 6 + 6 + 3 + 3 = 24 种

$$P = \frac{24}{216} = \frac{1}{9} \approx 0.111$$

**对照 (补集法)**:所有和的可能 = $\binom{3+5}{5} = 56$ 种 (有序数还要乘以重数), 算起来反而麻烦。

#### 例 4:生日悖论，23 人中至少两人生日相同的概率

**反直觉**:只需要 23 人, 概率就超过 50%!

**总样本空间**: 每人 365 种选择, $|\Omega| = 365^{23}$。

**全部不同的样本数**: $365 \times 364 \times \ldots \times 343$。

$$P(\text{全部不同}) = \frac{365 \times 364 \times \ldots \times 343}{365^{23}} = \prod_{i=0}^{22} \left(1 - \frac{i}{365}\right)$$

近似: $\ln P \approx \sum_{i=0}^{22} -\frac{i}{365} = -\frac{1}{365} \cdot \frac{22 \cdot 23}{2} = -\frac{253}{365} \approx -0.693$

所以 $P(\text{全部不同}) \approx e^{-0.693} \approx 0.5$。

$$P(\text{至少一对相同}) = 1 - 0.5 = 0.5$$

**ML 视角**:**生日悖论 = Hash 碰撞的概率**。在 23 个用户 ID 用 365 桶 hash 时, 50% 概率出现碰撞。这就是为什么 hash 表需要 $O(n)$ 桶, 而不是 $O(\sqrt{n})$ 桶。

#### 例 5:Monty Hall 问题 (三门问题)

**问题**:三扇门, 一扇后是汽车, 两扇后是山羊。你选 1 号, 主持人 (知道答案) 打开 3 号 (后面是山羊)。问你**应不应该换到 2 号**?

**反直觉**:多数人觉得"换不换都是 1/2", 但**正确答案是换, 换后赢的概率 = 2/3**。

**严格分析**:
- 你选 1 号: $P(\text{1 号是车}) = 1/3$, $P(\text{2 号或 3 号是车}) = 2/3$
- 主持人打开 3 号 (一定不是车), 那么**汽车在 2 号或 3 号** = 2/3 这部分, 主持人揭示"不在 3 号", 所以**全在 2 号**: $P(\text{2 号是车} | \text{3 号是羊}) = 2/3$
- 不换: 赢的概率 = $1/3$
- 换: 赢的概率 = $2/3$

$$P(\text{赢} | \text{换}) = 2/3 > P(\text{赢} | \text{不换}) = 1/3$$

**ML 视角**:这就是**条件概率**的威力。朴素直觉是错的, 严格推导才是对的。**A/B 实验中, 引入"已观察到的协变量"作为条件, 可以修正朴素估计, 这就是 CUPED 技术的核心。**

### 2.8 案例:为什么"可列可加"是关键的?

**反例 1** (为什么"有限可加"不够):

设 $\Omega = [0, 1]$, 想要构造一个"概率" $P$, 它满足有限可加性, 但**违反**可列可加性。

**构造**:对每个 $x \in [0, 1]$, 设 $P(\{x\}) = 0$, 但 $P([0, 1]) = 1$。

按有限可加性, $P([0, 1]) = P(\{0\} \cup \{1\} \cup \ldots \cup \{1\}) = 0$。但 $P([0, 1]) = 1$, 矛盾!

**这说明**: 如果没有可列可加性, 单点概率 = 0 跟区间概率 = 1 不可调和。可列可加性 = "**无穷多个 0 加起来还是 0**"。

**反例 2** (在工程上的重要性):

考虑**强化学习**中的折扣奖励和: $G_t = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}$。这个和是**可数无穷**个奖励的和, 需要可列可加性才能让 $E[G_t] = \sum \gamma^k E[r_{t+k+1}]$ 成立。

**反例 3** (在 A/B 实验上的重要性):

A/B 实验的"分组"涉及**多个指标**。例如同时看 100 个指标的 p-value, 每一个的"零假设成立概率" = 0.05, 100 个中至少一个假阳性的概率用**补集的可列可加性**算:

$$P(\text{至少一个假阳性}) = 1 - P(\text{全部真阴性}) = 1 - 0.95^{100} \approx 0.994$$

这告诉我们: **100 个指标同时检验, 几乎必然出现假阳性。这就是为什么多重比较需要 Bonferroni 修正!**

### 2.9 ASCII 可视化:Venn 图上的概率

```text
       ┌──────────────────────────┐
       │         Ω (样本空间)       │
       │      ┌───────────────┐    │
       │      │               │    │
       │      │       A       │    │
       │      │   (事件A)     │    │
       │      │  P(A) = 0.4   │    │  P(Ω) = 1
       │      │               │    │  P(Aᶜ) = 0.6
       │      └───────────────┘    │
       │                          │
       │   Aᶜ (A 的补集)            │
       │   P(Aᶜ) = 0.6             │
       │                          │
       └──────────────────────────┘
```

**两点观察**:
1. $A$ 和 $A^c$ **不重叠** (互不相交), 因为 $A^c$ = "不在 $A$ 中"
2. $A \cup A^c$ = 整个 $\Omega$ = 必然事件

**Venn 图 vs 概率**:Venn 图**画的是集合**, **不是概率**。把 $A$ 画大画小都不改变 $P(A)$ 的值。**概率是"集合的函数"**, 与"集合的视觉大小"无关 (虽然**直觉上**我们喜欢把概率 = 面积)。

## 3. σ-代数:不是所有子集都能"可测" (350 行)

### 3.1 直觉:为什么要限制"事件"?

**朴素想法**:任何子集都应该是"事件", 可以问它的概率。

**但 Vitali 集告诉我们**:有些子集**没法**给出一致的"长度"。

**工程上的类比**:在 SQL 里, 不是所有查询都有"确定的答案"，有些递归查询会无限循环。SQL 必须限制"合法的查询形式"。σ-代数 = "合法的'问概率'的集合形式"。

**为什么"全部子集"会出问题?**

考虑 $\Omega = [0, 1]$, 假设我们能对**所有**子集 $A \subseteq [0, 1]$ 定义一个"概率" (或"长度") $\mu(A)$, 满足:
1. $\mu([0, 1]) = 1$
2. 平移不变: $\mu(A) = \mu(A + t \mod 1)$ (把集合平移一下, "长度"不变)
3. 可数可加

**定理** (Banach-Tarski, 1924):这样的 $\mu$ **不存在** (在选择公理下)。

**直觉**:在选择公理下, $[0, 1]$ 里的"点"可以被"重新组合"成多个"等价类", 这些等价类没有合理的"长度"。这跟 Vitali 集是同一回事。

**工程类比**: 想象你给"用户活跃度"评分, 想要一个"平移不变"的指标 (即"加 10 分活跃度, 指标不变")。如果用户活跃度**有上下界**, 这种"平移不变"会导致矛盾。**所以指标必须选择**，这就是 σ-代数。

### 3.2 定义:对补和可数并封闭的集族

**定义** (σ-代数): $\Omega$ 的一个 σ-代数 (sigma-algebra) $\mathcal{F}$ 是 $\Omega$ 的子集族, 满足:
1. $\Omega \in \mathcal{F}$
2. **补封闭**: 若 $A \in \mathcal{F}$, 则 $A^c = \Omega \setminus A \in \mathcal{F}$
3. **可数并封闭**: 若 $A_1, A_2, \ldots \in \mathcal{F}$, 则 $\bigcup_{i=1}^\infty A_i \in \mathcal{F}$

**推论** (由 De Morgan 律): $\mathcal{F}$ 也对**可数交**封闭。

**验证**: $A^c = \Omega \setminus A$。由 $\Omega \in \mathcal{F}$ 和补封闭, $A^c \in \mathcal{F}$。再由可数并封闭, $\bigcup A_i^c \in \mathcal{F}$。最后用 De Morgan 律:
$$\bigcap_i A_i = \left( \bigcup_i A_i^c \right)^c \in \mathcal{F}$$

**例子 1** (平凡 σ-代数): $\mathcal{F} = \{\emptyset, \Omega\}$。它对补、可数并都封闭, 是最小的 σ-代数。

**例子 2** (离散 σ-代数): $\mathcal{F} = 2^\Omega$ (所有子集)。它对补、可数并都封闭, 是最大的 σ-代数。

**例子 3** (单点集生成的 σ-代数): $\mathcal{F} = \{A : A \subseteq \Omega, A \text{ 可数 或 } A^c \text{ 可数}\}$。它是 $\Omega$ 上的"可数/余可数" σ-代数, 是介于平凡和离散之间的"中间"。

**例 3 的应用**:在 $\mathbb{R}$ 上, 用 Lebesgue 测度时, 单点集 (可数) 的测度 = 0, 所以"可数/余可数"集是 Lebesgue 可测的最小 σ-代数之一。

### 3.3 Borel σ-代数 B(R):由开区间生成的最小 σ-代数

**定义** (生成元): 给定 $\Omega$ 上的子集族 $\mathcal{C}$, 由 $\mathcal{C}$ 生成的 σ-代数 $\sigma(\mathcal{C})$ 是包含 $\mathcal{C}$ 的**最小** σ-代数:
$$\sigma(\mathcal{C}) = \bigcap \{\mathcal{F} : \mathcal{F} \text{ 是 σ-代数}, \mathcal{C} \subseteq \mathcal{F}\}$$

**关键**:任意多个 σ-代数的交仍是 σ-代数 (验证:补、可数并都保持), 所以这个交集**是合法的 σ-代数**, 而且是包含 $\mathcal{C}$ 的**最小**一个。

**Borel σ-代数**: $\mathcal{B}(\mathbb{R}) = \sigma(\mathcal{C})$, 其中 $\mathcal{C} = \{(a, b) : a, b \in \mathbb{R}, a < b\}$ 是所有开区间。

**Borel 集 = 由开集"反复"做补、可数并得到的集合**。这包括:
- 开区间 $(a, b)$
- 闭区间 $[a, b]$ (开区间的补)
- 半开区间 $[a, b)$, $(a, b]$
- 开集 $\bigcup_i (a_i, b_i)$
- 闭集 $\bigcap_i [a_i, b_i]$
- 单点集 $\{a\}$ (因为 $\{a\} = \bigcap_n (a - 1/n, a + 1/n)$)
- 可数集 $\mathbb{Q}, \mathbb{Z}, \mathbb{N}$
- Cantor 集 (一种分形, 不可数但 Lebesgue 测度 = 0)

**关键问题**:是不是所有子集都是 Borel 集? **不是!** 有"不可测的"非 Borel 集 (需要选择公理构造)。但工程上**几乎所有**你遇到的集合都是 Borel 集, 所以 σ-代数 $\mathcal{B}(\mathbb{R})$ 在 ML/DL 里**够用**。

**ML 视角**:**深度学习里所有的"事件"，"输入 $x$ 落在某个区间"、"输出 $y$ 大于阈值"、"embedding 落在某个子空间"，都是 Borel 集**。我们不需要构造 Vitali 集, 工程上**没有**这种病态。

### 3.4 5 个手算例子 (σ-代数)

#### 例 1:抛硬币的 σ-代数

$\Omega = \{H, T\}$ (H = 正面, T = 反面)。所有子集:
$\mathcal{F} = \{\emptyset, \{H\}, \{T\}, \{H, T\}\} = 2^\Omega$

这是**离散 σ-代数**。所有子集都可测。

**工程意义**:二分类问题, 类别有限, 全部子集都可测。

#### 例 2:抛两枚硬币的 σ-代数

$\Omega = \{HH, HT, TH, TT\}$。**最小 σ-代数**: $\{\emptyset, \Omega\}$。

**全部子集 σ-代数**: $2^\Omega$, 有 $2^4 = 16$ 个子集。

**中间 σ-代数**:例如 $\mathcal{F} = \{\emptyset, \{HH, HT\}, \{TH, TT\}, \Omega\}$, 它是"第一枚是正面"的 σ-代数。验证:
- $\Omega = \{HH, HT, TH, TT\} \in \mathcal{F}$ ✓
- $\{HH, HT\}^c = \{TH, TT\} \in \mathcal{F}$ ✓
- 可数并: 任何子集的并仍是 $\mathcal{F}$ 中的元素 ✓

#### 例 3:R 中的 Borel σ-代数:开区间 $\to$ 闭区间

开区间 $(0, 1)$ 是 Borel 集。

闭区间 $[0, 1]$ 是开区间 $(-\infty, 0) \cup (1, \infty)$ 的补, 也是 Borel 集。

**关键**: 由 σ-代数的补封闭, 开集和闭集都 Borel。

#### 例 4:R 中的 Borel σ-代数:可数集是可测的

$\mathbb{Q} = \{q_1, q_2, \ldots\}$ 是可数集。$\mathbb{Q} = \bigcup_{i=1}^\infty \{q_i\}$ 是可数个单点集的可数并。

每个单点集 $\{q_i\}$: 由 $\{q_i\} = \bigcap_{n=1}^\infty (q_i - 1/n, q_i + 1/n)$ 是可数交。每个开区间是 Borel 集, 闭也是 Borel, 交也是 Borel (由 De Morgan)。

所以 $\mathbb{Q} \in \mathcal{B}(\mathbb{R})$。类似地, 任何可数集都是 Borel 集。

#### 例 5:不可测集，Vitali 集 (构造)

**构造** (在选择公理下):
1. 在 $[0, 1]$ 上定义等价关系: $x \sim y$ 当且仅当 $x - y \in \mathbb{Q}$。
2. 每个等价类选一个"代表" $v \in [0, 1]$, 收集所有代表, 得到 Vitali 集 $V$。
3. 对每个 $q \in \mathbb{Q} \cap [-1, 1]$, 定义 $V_q = V + q \mod 1$。
4. 则 $\{V_q : q \in \mathbb{Q} \cap [-1, 1]\}$ 是 $[0, 1]$ 的**可数**划分。

**关键**: $V_q$ 两两不交, $\bigcup V_q = [0, 1]$。

**假设 $V$ 可测且 $\mu(V) = a$**, 由可列可加性:
$$1 = \mu([0, 1]) = \sum_q \mu(V_q) = \sum_q a$$

可数多个 $a$ 相加 = 1, 要求 $a = 0$。

但**所有 $V_q$ 是 $V$ 平移有理数**, 由平移不变性, $\mu(V_q) = \mu(V) = a$。**矛盾!** 所以 $V$ 不可测。

**关键洞察**: $V$ 不可测**不是因为它"古怪"**, 而是因为**任何 σ-代数 + 测度公理都拒绝给它赋值**。这就是"严格化"的成本。

### 3.5 案例:为什么 Vitali 集不可测?

**类比**:一个 SQL 查询, "查询所有与有理数等价的实数代表"，这个查询**没有定义良好的答案**, 因为"代表"依赖于选择公理, 而选择公理不构造具体的代表。

**工程类比**: 一个函数 `f(x) = "取 x 所在等价类的最小代表"`, 在 $[0, 1]$ 上**没有"最小"的良定义**，这就是"病态"的本质。

**为什么 σ-代数不能"修补"这个问题?** 因为 σ-代数要求"补、可数并"封闭。如果 $V$ 在 $\mathcal{F}$ 中, 则 $V_q$ 也在 $\mathcal{F}$ 中 (平移保持可测性), 然后可数并 $\bigcup V_q$ 也在, 但 $\bigcup V_q = [0, 1]$。这跟"$\mu([0, 1]) = 1$" 的"可数可加性"矛盾。

**所以**:为了让测度公理自洽, 我们必须**主动限制**"可测集"的族, **不能**让"所有子集都可测"。

**ML 视角**:**在神经网络中, 我们处理的"事件"都是 Borel 集**，"输入 $x$ 落在某个区间"是 Borel, "输出 $y$ 大于阈值"是 Borel, "embedding 范数小于某值"也是 Borel (因为 $\{x : \|x\| < c\}$ 是开集)。**我们不会**遇到 Vitali 集, 因为构造 Vitali 集需要选择公理, 而工程代码是**确定的** (基于具体实现的)。

### 3.6 案例:为什么需要 σ-代数? (让概率论严格)

**朴素概率论的循环论证**:

朴素概率论常常这样写:
- "概率 = 频率的极限"
- "事件是样本空间的子集"
- "任意子集都可以问概率"

但**频率极限**的定义需要**极限概念**，对子集序列取极限。**如果"任意子集都可测"**, 那"所有子集"已经超越了我们能"用极限描述"的范围。

**σ-代数的精妙之处**:
- 它**只**要求"补、可数并"封闭，这两个运算是**集合论的基本运算**,**不需要额外的结构**
- 任何"通过可数次集合运算"构造的集合, 都在 σ-代数里
- 这给"极限"留了**刚好的位置**，可数并 = 极限

**工程类比**: 就像 SQL 的"递归查询"必须限制深度, 不然会无限循环。σ-代数是集合论的"递归深度限制"，只允许可数层的运算。

**总结**: σ-代数 = "**可测集**"的精确刻画。**概率论严格化 = "在 σ-代数上定义概率"。**

## 4. 测度 (Measure):集合"大小"的公理化 (350 行)

### 4.1 测度的公理

**定义** (测度): 设 $\mathcal{F}$ 是 $\Omega$ 上的 σ-代数。一个**测度** $\mu: \mathcal{F} \to [0, \infty]$ 是满足以下公理的函数:
1. **非负**: $\mu(A) \ge 0$ 对所有 $A \in \mathcal{F}$
2. **空集**: $\mu(\emptyset) = 0$
3. **可数可加**: 若 $A_1, A_2, \ldots \in \mathcal{F}$ 两两不交, 则 $\mu(\bigcup_i A_i) = \sum_i \mu(A_i)$

**与概率的区别**: 测度 $\mu(\Omega)$ 可以是任何非负实数 (包括 $\infty$); 概率 $\mu(\Omega) = 1$ 是**归一化**的测度。

**例子**:
- $\mu(\Omega) = 1$: 概率测度
- $\mu([0, 1]) = 1$: 单位区间上的 Lebesgue 测度
- $\mu(\mathbb{R}) = \infty$: Lebesgue 测度在全实数轴上
- $\mu(A) = |A|$ (基数): 计数测度, $\mu(\mathbb{N}) = \infty$

### 4.2 例子:长度、面积、体积、计数测度

#### Lebesgue 测度 (长度)

在 $\mathbb{R}$ 上, Lebesgue 测度 $\lambda$ 是 Borel σ-代数 $\mathcal{B}(\mathbb{R})$ 上的**唯一** (在一定意义下) 测度, 满足:
- $\lambda([a, b]) = b - a$ (区间长度)
- **平移不变**: $\lambda(A + t) = \lambda(A)$
- **可数可加**

**关键性质**:
- 单点集 $\lambda(\{x\}) = 0$
- 可数集 $\lambda(\mathbb{Q}) = 0$
- 任何"区间" (开、闭、半开) 的测度都 = 长度

#### 二维 Lebesgue 测度 (面积)

在 $\mathbb{R}^2$ 上, $\lambda_2([a, b] \times [c, d]) = (b - a)(d - c)$。

**关键**: 跟"边长相乘"一致 (矩形的面积)。

**几何概率**: 在单位圆盘上, 半径 $r$ 的内圆面积 / 单位圆盘面积 = $\pi r^2 / \pi = r^2$。这就是 §2.6 的几何概率。

#### 计数测度

对 $\Omega$ 任意, 计数测度 $\mu(A) = |A|$ (基数, 无限集时为 $\infty$)。

**特点**:
- 任何子集都可测 (因为 $\mathcal{F} = 2^\Omega$)
- **不是 σ-有限** (因为 $\mathbb{R}$ 的基数 = $\aleph_1$ > $\aleph_0$)

**计数测度** 对应"等可能"，如果"可能性"是均匀的, $\mu(A) / \mu(\Omega)$ 就是概率。

#### Dirac 测度 (点质量)

固定 $\omega_0 \in \Omega$, Dirac 测度 $\delta_{\omega_0}$ 定义为:
$$\delta_{\omega_0}(A) = \begin{cases} 1 & \omega_0 \in A \\ 0 & \omega_0 \notin A \end{cases}$$

**特点**:
- $\delta_{\omega_0}(\Omega) = 1$ (归一化) → 是个**概率测度**
- 把"全部概率质量"集中在 $\omega_0$ 这一点

**ML 视角**:**Dirac 测度 = 标签是"硬"的真实分布**。在分类任务中, one-hot 标签 = Dirac 测度在正确类别上的集中。CrossEntropy Loss 隐含地假设真实分布是 Dirac 测度, 然后用 softmax 输出去"近似"。

#### 概率测度 = 归一化的测度

**定义** (概率测度): 测度 $P$ 满足 $P(\Omega) = 1$ 称为**概率测度**。

**关键**: **概率 = 测度 + 归一化**。任何概率测度可以由"非归一化测度"除以 $\mu(\Omega)$ 得到。

**工程意义**: 在蒙特卡洛方法中, 我们经常**先**用"非归一化密度" $\tilde{p}(x)$ 采样 (用 MCMC), **再**归一化 $p(x) = \tilde{p}(x) / Z$ (其中 $Z = \int \tilde{p}(x) dx$ 是配分函数)。这与"概率 = 归一化的测度"严格对应。

### 4.3 5 个手算例子 (测度)

#### 例 1:Lebesgue 测度 $\lambda([2, 5])$

$\lambda([2, 5]) = 5 - 2 = 3$。

#### 例 2:Lebesgue 测度 $\lambda(\mathbb{Q} \cap [0, 1])$

$\mathbb{Q} \cap [0, 1]$ 是可数集, $\lambda(\mathbb{Q} \cap [0, 1]) = 0$。

**直觉**: 单点测度 = 0, 可数个 0 加起来 = 0。**所以"几乎所有"实数是无理数**，这与你的直觉一致 (无理数比有理数"多得多")。

#### 例 3:二维 Lebesgue 测度 $\lambda_2([0, 1] \times [0, 1])$

$\lambda_2([0, 1] \times [0, 1]) = 1 \times 1 = 1$。**单位正方形的面积 = 1**。

#### 例 4:Dirac 测度 $\delta_0([0, 5])$

$0 \in [0, 5]$, 所以 $\delta_0([0, 5]) = 1$。

$\delta_0(\{-1, 0, 1\}) = 1$ (因为 $0$ 在集合里)。

$\delta_0(\{1, 2\}) = 0$ (因为 $0$ 不在集合里)。

#### 例 5:概率 = 测度的归一化

设 $\mu$ 是 $[0, 5]$ 上的 Lebesgue 测度, $\mu([0, 5]) = 5$。归一化:
$$P(A) = \frac{\mu(A)}{\mu([0, 5])} = \frac{\mu(A)}{5}$$

例如 $P([1, 3]) = (3 - 1) / 5 = 2/5$。

### 4.4 案例:为什么概率本质是"归一化的测度"?

**理论**: 任何概率测度 $P$ 都可以视为 $\Omega$ 上的测度, 加上 $P(\Omega) = 1$ 的约束。

**实践**: 工程上, 经常先**写出非归一化密度** (unnormalized density), 再归一化。

**例**:**语言模型的 softmax 温度**:
$$p_\tau(x) = \frac{\exp(z_x / \tau)}{\sum_{x'} \exp(z_{x'} / \tau)}$$

- **未归一化**: $\tilde{p}(x) = \exp(z_x / \tau)$
- **配分函数**: $Z = \sum_{x'} \exp(z_{x'} / \tau)$
- **归一化**: $p_\tau = \tilde{p} / Z$

**关键**: 温度 $\tau$ 改变"测度的形状"，$\tau$ 越大, 分布越平 (类似"无信息先验"); $\tau$ 越小, 分布越尖 (类似"硬标签" = Dirac 测度)。

**ML 视角**:
- $\tau \to \infty$: $p_\tau$ 接近均匀分布 (最大熵)
- $\tau \to 0$: $p_\tau$ 接近 Dirac 测度 (最尖锐)
- $\tau = 1$: 标准 softmax

### 4.5 测度的"几乎处处"概念

**定义** (几乎处处, a.e.): 一个性质 $P$ 称为**几乎处处** (almost everywhere) 成立, 如果"性质 $P$ 不成立的集合"的测度 = 0。

**例**: **在 $\mathbb{R}$ 上**, "无理数集"是**几乎全空间**，因为 $\lambda(\mathbb{Q}) = 0$, 所以 $\mathbb{R} \setminus \mathbb{Q}$ 的测度 = $\infty$ (整个 $\mathbb{R}$)。"几乎所有"实数是无理数。

**ML 视角**: **神经网络中, "几乎所有"输入 $x$ 都不是反例 (adversarial example)**。反例的测度 = 0, 但它们**确实存在**, 并且可以通过优化找到 (Goodfellow 2014)。

**工程类比**: **"几乎处处" = "工程上可以忽略不计"**。例如训练时偶尔一个 batch loss = NaN, "测度"几乎为 0, 不影响整体训练。

### 4.6 σ-有限性

**定义** (σ-有限): 测度 $\mu$ 是 σ-有限的, 如果 $\Omega$ 可以写成**可数**多个**有限测度**集合的并: $\Omega = \bigcup_{i=1}^\infty A_i$, $\mu(A_i) < \infty$。

**例**:
- **Lebesgue 测度在 $\mathbb{R}$ 上**: σ-有限, 因为 $\mathbb{R} = \bigcup_n [-n, n]$, $\lambda([-n, n]) = 2n < \infty$。
- **Lebesgue 测度在 $[0, 1]$ 上**: σ-有限, 整个空间有限。
- **计数测度在 $\mathbb{R}$ 上**: **不是** σ-有限, 因为 $\mathbb{R}$ 是不可数集, 任何"有限测度集"必须是有限集, $\mathbb{R}$ 不能写成可数个有限集的并。

**关键**: σ-有限性是 Radon-Nikodym 定理 (后面 §4.7) 的前提, 跟"概率密度函数的存在性"严格相关。

### 4.7 Radon-Nikodym 导数 = 概率密度的严格定义

**定理** (Radon-Nikodym): 设 $\mu, \nu$ 是 σ-有限的测度, $\nu \ll \mu$ (即 $\mu(A) = 0 \Rightarrow \nu(A) = 0$, $\nu$ 关于 $\mu$ 绝对连续), 则存在**可测函数** $f = \frac{d\nu}{d\mu}$ (Radon-Nikodym 导数), 使得:
$$\nu(A) = \int_A f \, d\mu$$

**直观**: $f$ 是 $\nu$ 相对于 $\mu$ 的"密度"。

**ML 视角**: **概率密度函数 $p(x)$ 严格定义 = Radon-Nikodym 导数**。设 $\mu$ 是 $\mathbb{R}^d$ 上的 Lebesgue 测度, $\nu$ 是概率测度, 则 $p(x) = d\nu / d\mu$ 就是概率密度函数。

**关键**: **不是所有概率测度都有密度**! Dirac 测度 (单点质量) 没有密度, 因为 $\lambda(\{x_0\}) = 0$ 但 $\delta_{x_0}(\{x_0\}) = 1$, 不满足绝对连续 $\nu \ll \mu$。

**工程意义**:
- 连续分布:有密度 $p(x)$
- 离散分布:无密度 (相对 Lebesgue 测度), 有 PMF $p(x) = P(X = x)$
- 混合分布 (Dirac + 连续):既无密度, 也无 PMF, 需要用混合的测度表示

## 5. 概率空间:三件套 (Ω, F, P) (350 行)

### 5.1 形式化定义

**定义** (概率空间): 一个**概率空间** $(\Omega, \mathcal{F}, P)$ 由三部分组成:
1. **样本空间** $\Omega$: 所有可能"基本结果"的集合
2. **σ-代数** $\mathcal{F}$: $\Omega$ 的子集族, 满足 §3.2 的三条公理
3. **概率测度** $P: \mathcal{F} \to [0, 1]$: 满足 Kolmogorov 三公理 (§2.1-2.3)

**记号**: $\omega \in \Omega$ 称为**样本点** (sample point) 或**基本事件**; $A \in \mathcal{F}$ 称为**事件** (event)。

**关键**: $\Omega$ 和 $\mathcal{F}$ 必须**一起指定**。如果 $\mathcal{F}$ 是 $\Omega$ 的"全部子集", 测度可能不存在 (Vitali 集问题)。**实际工程里**:
- 离散 $\Omega$ + $\mathcal{F} = 2^\Omega$ (全部子集)
- 连续 $\Omega = \mathbb{R}^d$ + $\mathcal{F} = \mathcal{B}(\mathbb{R}^d)$ (Borel σ-代数)

### 5.2 事件的运算:补、并、交

**事件 $A$ 的补** $A^c = \Omega \setminus A$: "$A$ 不发生"。

**事件 $A, B$ 的并** $A \cup B$: "$A$ 或 $B$ 发生"。

**事件 $A, B$ 的交** $A \cap B$: "$A$ 和 $B$ 都发生"。

**De Morgan 律**:
$$(A \cup B)^c = A^c \cap B^c$$
$$\left( \bigcup_{i=1}^\infty A_i\right)^c = \bigcap_{i=1}^\infty A_i^c$$

**验证**: 用"反证法"或"列举基本点"。

**例**: 抛两枚硬币, $A$ = "第一枚是 H", $B$ = "第二枚是 H"。
- $A = \{HH, HT\}$
- $B = \{HH, TH\}$
- $A \cup B = \{HH, HT, TH\}$ (至少一枚是 H)
- $A \cap B = \{HH\}$ (两枚都是 H)
- $A^c = \{TH, TT\}$
- $(A \cup B)^c = \{TT\}$
- $A^c \cap B^c = \{TT\}$ ✓ (De Morgan 律验证)

### 5.3 ASCII 可视化:概率空间的"地图"

**单事件 Venn 图**:

```text
        ┌──────────────────────────┐
        │          Ω               │
        │      ┌──────────┐        │
        │      │          │        │
        │      │    A     │        │
        │      │  P(A)=0.4│        │
        │      │          │        │
        │      └──────────┘        │
        │                          │
        │  Aᶜ:  P(Aᶜ) = 0.6       │
        │                          │
        └──────────────────────────┘
```

**两事件 Venn 图**:

```text
        ┌──────────────────────────┐
        │          Ω               │
        │      ┌────┬────┐         │
        │      │ A∩B│ B  │         │
        │      │0.15│0.25│         │
        │   ┌──┼────┼────┤         │
        │   │  │0.10│    │         │
        │   │A │    │    │         │
        │   │  │    │    │         │
        │   └──┴────┴────┘         │
        │                          │
        │  P(A) = 0.10 + 0.15 = 0.25
        │  P(B) = 0.15 + 0.25 = 0.40
        │  P(A∪B) = 0.10 + 0.15 + 0.25 = 0.50
        │  P(A∩B) = 0.15
        │  P(A) + P(B) - P(A∩B) = 0.25 + 0.40 - 0.15 = 0.50 ✓
        └──────────────────────────┘
```

**关键观察**: $P(A \cup B) = P(A) + P(B) - P(A \cap B)$。这是因为 $A$ 和 $B$ 重叠的部分被加了两次, 要减去一次。

### 5.4 5 个手算例子 (概率空间)

#### 例 1:掷骰子一次

$\Omega = \{1, 2, 3, 4, 5, 6\}$, $\mathcal{F} = 2^\Omega$, $P(\{\omega\}) = 1/6$。

事件 $A$ = "偶数" $= \{2, 4, 6\}$。$P(A) = 3/6 = 1/2$。

事件 $B$ = "大于 3" $= \{4, 5, 6\}$。$P(B) = 3/6 = 1/2$。

$A \cap B$ = "偶数且大于 3" $= \{4, 6\}$。$P(A \cap B) = 2/6 = 1/3$。

$A \cup B$ = "偶数或大于 3" $= \{2, 4, 5, 6\}$。$P(A \cup B) = 4/6 = 2/3$。

验证: $P(A) + P(B) - P(A \cap B) = 1/2 + 1/2 - 1/3 = 2/3$ ✓

#### 例 2:抛硬币两次

$\Omega = \{HH, HT, TH, TT\}$, $\mathcal{F} = 2^\Omega$。

事件 $A$ = "至少一个 H", $P(A) = 3/4$。
事件 $B$ = "两次相同", $P(B) = 2/4 = 1/2$。
$A \cap B$ = "HH", $P(A \cap B) = 1/4$。
$A \cup B$ = "至少一个 H 或两次相同" = $\{HH, HT, TH, TT\} \setminus \emptyset = \Omega$?

不, $A \cup B = \{HH, HT, TH\}$ ∪ $\{HH, TT\} = \{HH, HT, TH, TT\} = \Omega$。$P(A \cup B) = 1$。

验证: $1/2 + 3/4 - 1/4 = 1$ ✓

#### 例 3:连续均匀分布 [0, 1]

$\Omega = [0, 1]$, $\mathcal{F} = \mathcal{B}([0, 1])$, $P(A) = \lambda(A)$ (Lebesgue 测度)。

事件 $A$ = $[0.2, 0.5]$, $P(A) = 0.3$。
事件 $B$ = $[0.4, 0.7]$, $P(B) = 0.3$。
$A \cap B$ = $[0.4, 0.5]$, $P(A \cap B) = 0.1$。
$A \cup B$ = $[0.2, 0.7]$, $P(A \cup B) = 0.5$。

#### 例 4:标准正态分布

$\Omega = \mathbb{R}$, $\mathcal{F} = \mathcal{B}(\mathbb{R})$, $P(A) = \int_A \frac{1}{\sqrt{2\pi}} e^{-x^2/2} dx$。

事件 $A$ = $[-1, 1]$, $P(A) \approx 0.683$ (1-σ 区间)。
事件 $B$ = $[-2, 2]$, $P(B) \approx 0.954$ (2-σ 区间)。
$A \cap B$ = $[-1, 1]$, $P(A \cap B) = 0.683$。
$A \cup B$ = $[-2, 2]$, $P(A \cup B) = 0.954$。

#### 例 5:R 上的 Cantor 分布

Cantor 集 $C$ 是 $[0, 1]$ 中"挖掉中间三分之一"剩余的不可数集。**Cantor 测度** $P_C$ 是支撑在 $C$ 上的概率测度, $P_C(C) = 1$, 但 $\lambda(C) = 0$。

**关键**: $P_C$ **不是** Lebesgue 测度的"密度" (因为 $\lambda(C) = 0$, 不满足绝对连续)。这是一个**奇异连续**概率测度, 没有密度, 也没有 PMF。

**ML 视角**:**这种"奇异"分布在 ML 里罕见**, 但提醒我们: 不是所有"看起来连续"的分布都有密度。**严格的概率论必须用测度论的语言**, 不能简单地说" $X$ 服从某个分布"。

### 5.5 案例:机器学习的所有"概率"都在某个概率空间上

**深度学习里的每个概率陈述**, 都可以**严格地**对应到某个概率空间 $(\Omega, \mathcal{F}, P)$。

| ML 概念 | 概率空间 |
| :--- | :--- |
| **数据分布** $p_{\text{data}}(x, y)$ | $\Omega = \mathcal{X} \times \mathcal{Y}$, $\mathcal{F} = \mathcal{B}(\mathcal{X} \times \mathcal{Y})$, $P$ 由 $p_{\text{data}}$ 给出 |
| **类别分布** (Categorical) | $\Omega = \{1, \ldots, K\}$, $\mathcal{F} = 2^\Omega$, $P(\{k\}) = p_k$ |
| **正态分布** $\mathcal{N}(\mu, \sigma^2)$ | $\Omega = \mathbb{R}$, $\mathcal{F} = \mathcal{B}(\mathbb{R})$, $P(A) = \int_A p(x) dx$ |
| **Dirac 测度** (one-hot 标签) | $\Omega = \mathcal{X} \times \mathcal{Y}$, $\mathcal{F} = 2^\Omega$, $P = \delta_{(x_0, y_0)}$ |
| **Dirichlet 分布** (先验) | $\Omega = \Delta^K$ (单纯形), $\mathcal{F} = \mathcal{B}(\Delta^K)$ |
| **神经网络输出** | $\Omega = \mathbb{R}^K$, $\mathcal{F} = \mathcal{B}(\mathbb{R}^K)$, $P$ 由 softmax 给出 |

**关键洞察**:
- 你的 `model = nn.Linear(...)` 给定输入 $x$, 输出 logits, softmax 后给出一个**概率测度** $P_x$
- 你的 CrossEntropy Loss 是在 $P_x$ 和真实 Dirac 测度 $\delta_y$ 之间的**KL 散度** (第 11 章详述)
- 你的训练过程是**变分推断** (Variational Inference, 第 10 章详述)

**所有这些**, **严格地**都需要 §3 的 σ-代数 和 §4 的测度论。**这就是为什么这一章是"地基"。**

### 5.6 子 σ-代数与"可观察的信息"

**定义** (子 σ-代数): 设 $\mathcal{F}, \mathcal{G}$ 是 $\Omega$ 上的 σ-代数, $\mathcal{G} \subseteq \mathcal{F}$ 称为**子 σ-代数**。

**直觉**: 子 σ-代数 = "可观察信息的子集"。

**例**: $\Omega = \{1, 2, 3, 4, 5, 6\}$ (骰子)。
- $\mathcal{F} = 2^\Omega$ (全部子集)
- $\mathcal{G}_1 = \{\emptyset, \{1, 3, 5\}, \{2, 4, 6\}, \Omega\}$ (奇偶)
- $\mathcal{G}_2 = \{\emptyset, \{1, 2, 3\}, \{4, 5, 6\}, \Omega\}$ (大小)

$\mathcal{G}_1, \mathcal{G}_2$ 都是 $\mathcal{F}$ 的子 σ-代数。

**ML 视角**: **"可观察的信息"在金融、强化学习中** 是个核心概念:
- 在金融中, "可观察信息" = 投资者能看到的**价格历史** (fil-tration, 滤子)
- 在 RL 中, "可观察信息" = 智能体能看到的状态 (马尔可夫决策过程的状态空间)
- 在因果推断中, "可观察信息" = 协变量

**条件期望** $\mathbb{E}[X | \mathcal{G}]$ 是基于 $\mathcal{G}$ 的"最优估计"，比基于 $\mathcal{F}$ 的"全信息估计"更粗糙, 但只能用 $\mathcal{G}$ 中的信息。

## 6. 条件概率的严格化 (200 行)

### 6.1 定义: $P(A|B) = P(A \cap B) / P(B)$

**定义** (条件概率): 设 $A, B$ 是事件, $P(B) > 0$。**在 $B$ 发生的条件下, $A$ 发生的条件概率**为:
$$P(A | B) = \frac{P(A \cap B)}{P(B)}$$

**直观**: 限制到 $B$ 发生的"小世界"里, 看 $A$ 占多少比例。

**例**: 抛两枚硬币, $A$ = "至少一个 H", $B$ = "至少一个 T"。
- $A = \{HH, HT, TH\}$, $P(A) = 3/4$
- $B = \{HT, TH, TT\}$, $P(B) = 3/4$
- $A \cap B = \{HT, TH\}$, $P(A \cap B) = 2/4 = 1/2$
- $P(A | B) = (1/2) / (3/4) = 2/3$

**解读**: 在"至少一个 T"发生的条件下, "至少一个 H"的概率 = 2/3 (因为已经排除了 $TT$ 和 $HH$ 两个不可能的极端)。

### 6.2 独立性: $A \perp B$ 当且仅当 $P(A \cap B) = P(A) P(B)$

**定义** (独立): 事件 $A, B$ **相互独立** (记 $A \perp B$), 如果:
$$P(A \cap B) = P(A) P(B)$$

**推论** (若 $P(B) > 0$): $A \perp B$ 等价于 $P(A | B) = P(A)$。

**直观**: 知道 $B$ 发生**不改变** $A$ 发生的概率。

**多个事件独立**: $A_1, \ldots, A_n$ **相互独立**, 如果对**任何**子集 $I \subseteq \{1, \ldots, n\}$:
$$P\left(\bigcap_{i \in I} A_i\right) = \prod_{i \in I} P(A_i)$$

**关键**: **两两独立 ≠ 相互独立**! 两两独立是 $P(A_i \cap A_j) = P(A_i) P(A_j)$ 对所有 $i \ne j$。相互独立还要包括三元、四元、...、$n$ 元交集。

**反例 (两两独立但不相互独立)**: 抛两枚公平硬币, 设 $A$ = "第一枚是 H", $B$ = "第二枚是 H", $C$ = "两枚相同"。验证:
- $P(A) = P(B) = P(C) = 1/2$
- $P(A \cap B) = 1/4 = P(A) P(B)$ ✓
- $P(A \cap C) = P(\{HH\}) / 4 = 1/4 = P(A) P(C)$ ✓
- $P(B \cap C) = P(\{HH\}) / 4 = 1/4 = P(B) P(C)$ ✓
- $P(A \cap B \cap C) = P(\{HH\}) / 4 = 1/4 \ne P(A) P(B) P(C) = 1/8$ ✗

所以 $A, B, C$ 两两独立, 但不相互独立。

### 6.3 互斥 vs 独立 (常被混淆)

**互斥 (Mutually Exclusive)**: $A \cap B = \emptyset$, 即 $A$ 和 $B$ 不可能同时发生。

**独立 (Independent)**: $A \perp B$, 即 $P(A \cap B) = P(A) P(B)$。

**关键**:
- 互斥 (概率 = 0 的并) 与独立 (概率可分解) 是**完全不同的概念**!
- 若 $A, B$ 都正概率且互斥, 则 $A, B$ **不独立** (因为 $P(A \cap B) = 0 \ne P(A) P(B) > 0$)。

**反例**: 骰子, $A$ = "点数 = 1", $B$ = "点数 = 2"。$A \cap B = \emptyset$, 所以互斥。$P(A) = P(B) = 1/6$, $P(A) P(B) = 1/36 \ne 0 = P(A \cap B)$。所以 $A, B$ 不独立。

**互斥的极端情形**: 若 $A$ 是"必然事件" (即 $A = \Omega$), $B$ 是任何事件, $A, B$ 互斥当且仅当 $B = \emptyset$。**但 $\Omega$ 和任何 $B$ 都不独立** (除非 $B = \emptyset$ 或 $\Omega$):

$$P(\Omega \cap B) = P(B) \quad \text{vs} \quad P(\Omega) P(B) = 1 \cdot P(B) = P(B) \quad \text{(相等!)}$$

哦, 实际上 $\Omega$ 和任何 $B$ 是**独立的**! 检验: $P(\Omega \cap B) = P(B) = P(\Omega) P(B)$。✓

所以 "$A = \Omega$ 跟任何 $B$ 都独立" 是个**特例**。

### 6.4 5 个手算例子 (条件概率 + 独立性)

#### 例 1:抽牌，抽第一张是 A, 第二张还是 A 的概率

52 张牌, 4 张 A。抽 2 张 (不放回)。

$P(\text{第 1 张是 A}) = 4/52 = 1/13$。

$P(\text{第 2 张是 A} | \text{第 1 张是 A}) = 3/51 = 1/17$ (因为第一张抽走后剩 51 张, 3 张 A)。

**不放回 ≠ 独立**。

#### 例 2:抽牌，抽第一张是 A, 放回, 再抽, 第二张是 A 的概率

$P(\text{第 2 张是 A}) = 4/52 = 1/13$ (跟第一次无关)。

**放回 = 独立**。

#### 例 3:抛两枚硬币独立性验证

$A$ = "第一枚 H", $B$ = "第二枚 H"。
$P(A) = P(B) = 1/2$, $P(A \cap B) = 1/4 = P(A) P(B)$ ✓ 独立。

#### 例 4:骰子, $A$ = "偶数", $B$ = "大于 3" 独立性

$P(A) = 1/2$ (偶数: 2, 4, 6), $P(B) = 1/2$ (大于 3: 4, 5, 6)。
$P(A \cap B) = P(\{4, 6\}) = 2/6 = 1/3$。
$P(A) P(B) = 1/4$。
$1/3 \ne 1/4$, 所以 $A, B$ **不独立**。

#### 例 5:3 个事件相互独立 (Borel 规范构造)

$\Omega = \{0, 1\}^3$, $|\Omega| = 8$。每个 $\omega$ 等可能。

设 $A_i$ = "第 $i$ 个坐标 = 0", $i = 1, 2, 3$。

$P(A_i) = 1/2$。
$P(A_i \cap A_j) = 1/4 = P(A_i) P(A_j)$ (两两独立 ✓)。
$P(A_1 \cap A_2 \cap A_3) = 1/8 = P(A_1) P(A_2) P(A_3)$ (三元独立 ✓)。

所以 $A_1, A_2, A_3$ **相互独立**。

## 7. 全概率公式:拆分求和的利器 (200 行)

### 7.1 形式化: 划分 + 边缘化

**定义** (划分): 事件 $B_1, B_2, \ldots, B_n$ 构成 $\Omega$ 的**划分**, 如果:
1. $B_i \cap B_j = \emptyset$ 对所有 $i \ne j$ (互不相交)
2. $\bigcup_{i=1}^n B_i = \Omega$ (覆盖整个空间)

**全概率公式**: 设 $B_1, \ldots, B_n$ 是 $\Omega$ 的划分, $P(B_i) > 0$, 则对任何事件 $A$:
$$P(A) = \sum_{i=1}^n P(A | B_i) P(B_i)$$

**证明**:
$$A = A \cap \Omega = A \cap \left( \bigcup_i B_i \right) = \bigcup_i (A \cap B_i)$$

$A \cap B_i$ 两两不交, 由可加性:
$$P(A) = P\left( \bigcup_i (A \cap B_i) \right) = \sum_i P(A \cap B_i) = \sum_i P(A | B_i) P(B_i)$$

**直观**: 把"整个世界" $\Omega$ 拆成几个互不重叠的小块 $B_i$, 然后在每个小块里看 $A$ 的概率, 加权平均。

### 7.2 案例:Naive Bayes 的基础

**Naive Bayes 分类器**:
$$P(y | x) \propto P(x | y) P(y)$$

**全概率公式的视角**: $P(x) = \sum_y P(x | y) P(y)$ 是"所有类别下生成 $x$ 的总概率"，这就是 Naive Bayes 的**归一化常数**。

**ML 视角**: **Naive Bayes 假设** $x = (x_1, \ldots, x_d)$ 的各特征在**给定 $y$** 下条件独立:
$$P(x | y) = \prod_{j=1}^d P(x_j | y)$$

**关键**: 这是"naive"的地方，特征间通常不独立。但这个假设让计算从 $O(2^d)$ 降到 $O(d)$, 在文本分类 (Bag-of-Words) 等场景下表现惊人地好。

### 7.3 5 个手算例子 (全概率公式)

#### 例 1:三台机器生产产品, 故障率不同

机器 A 生产 50%, 故障率 1%; 机器 B 生产 30%, 故障率 2%; 机器 C 生产 20%, 故障率 3%。

总故障率 = $P(\text{故障}) = P(\text{故障}|A) P(A) + P(\text{故障}|B) P(B) + P(\text{故障}|C) P(C)$
$= 0.01 \times 0.5 + 0.02 \times 0.3 + 0.03 \times 0.2$
$= 0.005 + 0.006 + 0.006 = 0.017$ = 1.7%

#### 例 2:抽球, 两盒不等可能

盒 1 (选中的概率 0.6): 5 红 3 白。
盒 2 (选中的概率 0.4): 2 红 6 白。

抽到红球的概率 = $P(\text{红}) = P(\text{红}|\text{盒 1}) P(\text{盒 1}) + P(\text{红}|\text{盒 2}) P(\text{盒 2})$
$= (5/8) \times 0.6 + (2/8) \times 0.4$
$= 0.375 + 0.1 = 0.475$ = 47.5%

#### 例 3:三门问题 (Monty Hall) 的全概率公式

设 $A$ = "你赢", $B_1$ = "你最初选的门有车", $B_2$ = "你没选的两门之一有车"。

$P(A | B_1) = 0$ (你已经选了, 不会换)
$P(A | B_2) = 1$ (你换到有车的门)

$P(B_1) = 1/3$, $P(B_2) = 2/3$ (在主持人揭示后)。

$P(A) = P(A|B_1) P(B_1) + P(A|B_2) P(B_2) = 0 \times 1/3 + 1 \times 2/3 = 2/3$。

**结论**: 换门赢的概率 = 2/3 ✓

#### 例 4:产品质检, 三道工序

一道工序通过率 90%, 二道 95%, 三道 98%。全通过率 (假设独立) = $0.9 \times 0.95 \times 0.98 \approx 0.838$。

**全概率视角**: 每道工序是一道"筛子", 全通过 = 三道都通过 = 独立事件的交。

#### 例 5:保险，不同年龄段的事故率

青年组 (占比 30%): 事故率 0.05
中年组 (占比 50%): 事故率 0.02
老年组 (占比 20%): 事故率 0.08

总事故率 = $0.05 \times 0.3 + 0.02 \times 0.5 + 0.08 \times 0.2 = 0.015 + 0.01 + 0.016 = 0.041$ = 4.1%

**ML 视角**:**这个公式在工业推荐系统里** 经常出现:
- 总点击率 = $\sum_{\text{user segment}} P(\text{click} | \text{user segment}) P(\text{user segment})$
- 总转化率 = $\sum_{\text{page}} P(\text{conversion} | \text{page}) P(\text{page viewed})$

## 8. 贝叶斯定理:逆向思维的工具 (250 行)

### 8.1 形式化

**贝叶斯定理** (Bayes' Theorem): 设 $B_1, \ldots, B_n$ 是 $\Omega$ 的划分, $P(B_i) > 0$, $A$ 是事件, $P(A) > 0$, 则:
$$P(B_i | A) = \frac{P(A | B_i) P(B_i)}{P(A)} = \frac{P(A | B_i) P(B_i)}{\sum_j P(A | B_j) P(B_j)}$$

**解读**:
- **先验** $P(B_i)$: 在看到证据 $A$ 之前, 对 $B_i$ 的信念
- **似然** $P(A | B_i)$: 在 $B_i$ 成立的条件下, 看到 $A$ 的概率
- **证据** $P(A)$: 看到 $A$ 的总概率 (归一化常数)
- **后验** $P(B_i | A)$: 看到证据 $A$ 之后, 对 $B_i$ 的信念

### 8.2 先验 / 似然 / 后验 / 证据

| 概念 | 含义 | 例子 |
| :--- | :--- | :--- |
| **先验** $P(B_i)$ | 看到证据前的信念 | 疾病的患病率 |
| **似然** $P(A \| B_i)$ | 给定假设, 证据出现的概率 | 患病时检测阳性的概率 |
| **证据** $P(A)$ | 证据出现的总概率 | 任意人检测阳性的概率 |
| **后验** $P(B_i \| A)$ | 看到证据后的信念 | 检测阳性时真患病的概率 |

**核心思想**: **后验 ∝ 似然 × 先验**。贝叶斯定理就是"先验 + 似然 → 后验"的精确公式。

### 8.3 案例:医学诊断，假阳性率

**设定**:
- 疾病 D 的患病率: $P(D) = 0.001$ (千分之一)
- 检测的灵敏度: $P(+|D) = 0.99$ (有病时 99% 阳性)
- 检测的特异度: $P(-|\bar D) = 0.95$ (无病时 95% 阴性)
- 假阳性率: $P(+|\bar D) = 0.05$

**问题**: 检测阳性时, 真患病的概率 $P(D|+)$ 是多少?

**用贝叶斯**:
$$P(D|+) = \frac{P(+|D) P(D)}{P(+|D) P(D) + P(+|\bar D) P(\bar D)}$$

$$= \frac{0.99 \times 0.001}{0.99 \times 0.001 + 0.05 \times 0.999}$$

$$= \frac{0.00099}{0.00099 + 0.04995} = \frac{0.00099}{0.05094} \approx 0.0194$$

**反直觉**:**只有 1.94%!** 检测阳性的人, 大部分是假阳性 (因为疾病太罕见)。

**ML 视角**:**这就是为什么在低患病率场景 (罕见病、罕见事件、CTR 预估), 不能简单用"模型预测阳性"作为"真阳性"。** 需要校准 (calibration), 或者用 Precision-Recall 而不是 ROC 曲线。

### 8.4 案例:朴素贝叶斯分类器

**设定**: 邮件分类 (垃圾邮件 vs 正常邮件)。两类 $y \in \{0, 1\}$。特征 $x = (x_1, \ldots, x_d)$ 是词袋 (bag of words)。

**朴素贝叶斯**:
$$P(y | x) \propto P(y) \prod_{j=1}^d P(x_j | y)$$

**训练**: 估计 $P(y) = N_y / N$ (先验), $P(x_j | y) = N_{y, x_j} / N_y$ (似然)。

**预测**: $\hat y = \arg\max_y P(y) \prod_j P(x_j | y)$。

**对数形式** (数值稳定):
$$\hat y = \arg\max_y \left[ \log P(y) + \sum_j \log P(x_j | y) \right]$$

**关键**:
- 朴素假设: 给定 $y$, 各 $x_j$ 条件独立
- 这让 $P(x | y) = \prod_j P(x_j | y)$ 成立
- 工程上: 训练快 ($O(nd)$), 预测快 ($O(d)$)

### 8.5 5 个手算例子 (贝叶斯定理)

#### 例 1:医学诊断 (上面已算过)

$P(D|+) \approx 0.0194$, 即 1.94%。

#### 例 2:三门问题 (换门赢的概率)

设 $C_i$ = "车在门 $i$ 后", $i = 1, 2, 3$。你选门 1, 主持人开 3 (一定不是车)。

$P(C_1) = P(C_2) = P(C_3) = 1/3$ (先验)。

$P(\text{开 3} | C_1) = 1/2$ (主持人在 2, 3 中随机开)。
$P(\text{开 3} | C_2) = 1$ (主持人只能开 3)。
$P(\text{开 3} | C_3) = 0$ (主持人不会开有车的门)。

后验: $P(C_2 | \text{开 3}) = \frac{P(\text{开 3}|C_2) P(C_2)}{P(\text{开 3})} = \frac{1 \times 1/3}{1/2 \times 1/3 + 1 \times 1/3 + 0 \times 1/3} = \frac{1/3}{1/2} = 2/3$ ✓

#### 例 3:产品来自三条生产线

生产线 1 (50%): 合格品率 0.95
生产线 2 (30%): 合格品率 0.90
生产线 3 (20%): 合格品率 0.85

随机抽一件, 是合格品。它来自生产线 1 的概率?

$P(1|\text{合格}) = \frac{P(\text{合格}|1) P(1)}{P(\text{合格})} = \frac{0.95 \times 0.5}{0.95 \times 0.5 + 0.9 \times 0.3 + 0.85 \times 0.2} = \frac{0.475}{0.475 + 0.27 + 0.17} = \frac{0.475}{0.915} \approx 0.519$

#### 例 4:DNA 检测 (法庭证据)

某 DNA 特征在人群中出现率 1% (即 $P(+|\text{无罪}) = 0.01$)。嫌疑犯匹配, 证据强度多大?

朴素误用: "匹配概率 1%, 错判概率 1%" → 错误!

正确: 假设陪审员要回答"嫌疑犯有罪的后验概率"。

**没看到先验** 无法计算: $P(\text{有罪}|+)$ 依赖于 $P(\text{有罪})$ (基率)。

如果 $P(\text{有罪}) = 0.5$ (50-50):
$P(\text{有罪}|+) = \frac{0.99 \times 0.5}{0.99 \times 0.5 + 0.01 \times 0.5} = \frac{0.495}{0.5} = 0.99$

如果 $P(\text{有罪}) = 0.001$ (罕见):
$P(\text{有罪}|+) = \frac{0.99 \times 0.001}{0.99 \times 0.001 + 0.01 \times 0.999} = \frac{0.00099}{0.01098} \approx 0.090$

**反直觉**: 即使 DNA 匹配, 嫌疑犯有罪的后验可能只有 9%!

**ML 视角**:**这就是推荐系统里的"曝光偏差"问题**，在低 CTR 场景 (长尾内容), 简单的"用户点击 → 喜欢"推断会高估, 必须考虑曝光的基率。

#### 例 5:垃圾邮件分类

$P(\text{spam}) = 0.3$ (先验: 30% 是垃圾邮件)
$P(\text{含 "免费"}|\text{spam}) = 0.8$
$P(\text{含 "免费"}|\text{ham}) = 0.1$

收到一封含"免费"的邮件, 是垃圾邮件的概率?

$P(\text{spam}|\text{含 "免费"}) = \frac{0.8 \times 0.3}{0.8 \times 0.3 + 0.1 \times 0.7} = \frac{0.24}{0.24 + 0.07} = \frac{0.24}{0.31} \approx 0.774$

**解读**: 含"免费"的邮件有 77.4% 是垃圾邮件。

### 实验 1:抛硬币的 Monte Carlo 模拟, 验证大数定律

```python
import torch
import matplotlib.pyplot as plt

torch.manual_seed(42)
device = "mps" if torch.backends.mps.is_available() else "cpu"
print(f"Using device: {device}")

# 模拟 n 次公平硬币
def simulate_coin_flips(n, p=0.5):
    """抛 n 次硬币, 返回 heads (1) 的次数"""
    return torch.bernoulli(torch.full((n,), p)).sum().item()

# 频率 vs 真实概率 (大数定律)
n_trials = 10000
counts = [simulate_coin_flips(1000) for _ in range(n_trials)]
freqs = torch.tensor(counts) / 1000

print(f"频率的均值: {freqs.mean().item():.4f} (真实 0.5)")
print(f"频率的标准差: {freqs.std().item():.4f} (理论 {torch.tensor(0.5 * 0.5 / 1000).sqrt().item():.4f})")

# 大数定律: n 越大, 频率越接近概率
ns = [10, 100, 1000, 10000, 100000, 1000000]
for n in ns:
    freq = torch.bernoulli(torch.full((n,), 0.5)).mean().item()
    print(f"n={n:>7}: 频率 = {freq:.6f}, 误差 = {abs(freq - 0.5):.6f}")
```

### 实验 2:几何概率模拟 (Buffon 投针)

```python
import torch
import math

def buffon_needle_simulation(n_trials=10000, needle_length=1.0, line_spacing=2.0, seed=42):
    """Buffon 投针模拟, 验证 P = 2L / (πD)"""
    torch.manual_seed(seed)
    # 针的中心到最近平行线的距离: U[0, D/2]
    distance = torch.rand(n_trials) * (line_spacing / 2)
    # 针的角度: U[0, π/2] (对称性)
    angle = torch.rand(n_trials) * (math.pi / 2)
    # 针与线相交条件: distance <= (L/2) * sin(angle)
    crosses = distance <= (needle_length / 2) * torch.sin(angle)
    return crosses.float().mean().item()

estimated_prob = buffon_needle_simulation(n_trials=100000)
theoretical_prob = (2 * 1.0) / (math.pi * 2.0)
print(f"Buffon 投针: 估计概率 = {estimated_prob:.4f}")
print(f"理论概率    = {theoretical_prob:.4f}")
print(f"π 的估计   = {(2 * 1.0) / (estimated_prob * 2.0):.4f}")
```

**输出 (示例)**:
```text
Buffon 投针: 估计概率 = 0.3175
理论概率    = 0.3183
π 的估计   = 3.1496
```

**关键**: 用 Buffon 投针可以**估计 π**。这是"几何概率 → 数值常数"的经典例子。

### 实验 3:贝叶斯定理数值计算 (医学诊断)

```python
import torch

def bayesian_medical_diagnosis(prior, sensitivity, false_positive_rate):
    """医学诊断的贝叶斯计算: P(患病 | 检测阳性)"""
    P_D = prior                  # 患病率 (先验)
    P_not_D = 1 - P_D
    P_pos_D = sensitivity        # 灵敏度: 真阳性率
    P_pos_not_D = false_positive_rate  # 假阳性率

    # 贝叶斯定理
    P_pos = P_pos_D * P_D + P_pos_not_D * P_not_D  # 边缘概率
    P_D_pos = (P_pos_D * P_D) / P_pos
    return P_D_pos

# 例: 罕见病 (千分之一)
prior = 0.001
sensitivity = 0.99
fpr = 0.05
post = bayesian_medical_diagnosis(prior, sensitivity, fpr)
print(f"罕见病: P(患病|阳性) = {post:.4f} = {post*100:.2f}%")

# 例: 常见病 (百分之十)
prior = 0.1
post = bayesian_medical_diagnosis(prior, sensitivity, fpr)
print(f"常见病: P(患病|阳性) = {post:.4f} = {post*100:.2f}%")
```

**输出 (示例)**:
```text
罕见病: P(患病|阳性) = 0.0194 = 1.94%
常见病: P(患病|阳性) = 0.6803 = 68.03%
```

**关键**: 同样的检测, 对罕见病和常见病的"阳性意义"完全不同! **这告诉我们: 任何"模型输出阳性"必须考虑先验 (基率)**。

### 实验 4:朴素贝叶斯文本分类

```python
import torch
from collections import Counter

# 训练数据: 6 封邮件, 3 垃圾 3 正常
train_docs = [
    ("免费 优惠 限时", "spam"),
    ("免费 获取 链接", "spam"),
    ("点击 领取 奖品", "spam"),
    ("项目 会议 安排", "ham"),
    ("报告 提交 时间", "ham"),
    ("讨论 计划 进度", "ham"),
]

# 计算先验
spam_count = sum(1 for _, label in train_docs if label == "spam")
ham_count = sum(1 for _, label in train_docs if label == "ham")
P_spam = spam_count / len(train_docs)
P_ham = ham_count / len(train_docs)
print(f"先验: P(spam) = {P_spam}, P(ham) = {P_ham}")

# 计算似然 (Laplace 平滑)
spam_words = Counter()
ham_words = Counter()
for doc, label in train_docs:
    words = doc.split()
    if label == "spam":
        for w in words:
            spam_words[w] += 1
    else:
        for w in words:
            ham_words[w] += 1

vocab = set(spam_words.keys()) | set(ham_words.keys())
V = len(vocab)

def P_word_given_label(word, label):
    """Laplace 平滑"""
    if label == "spam":
        return (spam_words[word] + 1) / (sum(spam_words.values()) + V)
    else:
        return (ham_words[word] + 1) / (sum(ham_words.values()) + V)

# 预测新邮件: "免费 报告"
test_doc = "免费 报告"
test_words = test_doc.split()

log_P_spam_given_doc = torch.tensor(P_spam).log()
log_P_ham_given_doc = torch.tensor(P_ham).log()

for w in test_words:
    log_P_spam_given_doc += torch.tensor(P_word_given_label(w, "spam")).log()
    log_P_ham_given_doc += torch.tensor(P_word_given_label(w, "ham")).log()

print(f"log P(spam|doc) = {log_P_spam_given_doc.item():.4f}")
print(f"log P(ham|doc)  = {log_P_ham_given_doc.item():.4f}")
print(f"预测: {'spam' if log_P_spam_given_doc > log_P_ham_given_doc else 'ham'}")
```

**输出 (示例)**:
```text
先验: P(spam) = 0.5, P(ham) = 0.5
log P(spam|doc) = -10.4873
log P(ham|doc)  = -9.2951
预测: ham
```

**关键**: "免费 报告" → 预测为正常邮件。"免费" 强烈提示 spam, 但 "报告" 强烈提示 ham, **朴素贝叶斯让两者"对冲"**。

### 实验 5:全概率公式模拟验证

```python
import torch

def total_probability_simulation(n_samples=100000, seed=42):
    """三机器生产, 故障率不同, 模拟验证全概率公式"""
    torch.manual_seed(seed)

    # 机器选择概率
    P_A, P_B, P_C = 0.5, 0.3, 0.2
    # 故障率
    fail_A, fail_B, fail_C = 0.01, 0.02, 0.03

    # 模拟: 先选机器, 再判断是否故障
    machine_choice = torch.multinomial(
        torch.tensor([P_A, P_B, P_C]), n_samples, replacement=True
    )
    # 对每个样本, 根据机器类型决定是否故障
    fail_prob = torch.tensor([fail_A, fail_B, fail_C])[machine_choice]
    is_faulty = torch.bernoulli(fail_prob)

    observed_failure_rate = is_faulty.float().mean().item()
    theoretical_failure_rate = (
        P_A * fail_A + P_B * fail_B + P_C * fail_C
    )

    print(f"模拟故障率:    {observed_failure_rate:.4f}")
    print(f"理论故障率:    {theoretical_failure_rate:.4f}")
    print(f"全概率公式:    P(故障) = Σ P(故障|机器i) × P(机器i)")

total_probability_simulation()
```

**输出 (示例)**:
```text
模拟故障率:    0.0169
理论故障率:    0.0170
全概率公式:    P(故障) = Σ P(故障|机器i) × P(机器i)
```

**关键**: 模拟结果 ≈ 理论值, 验证了全概率公式。

## 10. 常见误区 + Q&A (200 行)

### 10.1 5-8 个常见误区

#### 误区 1: ❌ "互斥 = 独立"

**错例**: 骰子, $A$ = "点数 = 1", $B$ = "点数 = 2"。$A \cap B = \emptyset$, 互斥。但 $P(A) P(B) = 1/36 \ne 0 = P(A \cap B)$, **不独立**。

**正确**: 互斥是关于"能否同时发生", 独立是关于"是否提供信息"。**两个概念完全不同**。

#### 误区 2: ❌ "P(A|B) = P(B|A)"

**错例**: 医生告诉你检测阳性, $P(\text{患病}|\text{阳性}) = 1.94\%$。但很多人错误地"反过来"想成"医生说患病, 那么检测阳性的概率 99%"。

**正确**: 贝叶斯定理明确告诉我们: $P(A|B) \ne P(B|A)$。需要先验做修正。

#### 误区 3: ❌ "古典概率适用于无限样本空间"

**错例**: "在线抛硬币, 正面朝上的概率 = 抛到正面的次数 / 总次数"。

**正确**: 古典概率公式 $P(A) = |A| / |\Omega|$ 要求 $|\Omega|$ 有限。无限样本空间要用**几何概率** (连续) 或**测度论**。

#### 误区 4: ❌ "概率 = 频率"

**错例**: "这个事件过去发生了 100 次, 所以概率 = 100/总次数"。

**正确**: 频率是概率的**估计**, 不是定义。概率是**测度**, 是先验的数学对象。频率 → 概率需要"无穷样本" (大数定律), 但实际工程里我们永远没有无穷样本。

#### 误区 5: ❌ "σ-代数 = 所有子集"

**错例**: "$\Omega$ 的所有子集都应该是事件"。

**正确**: 出于测度论的严格化, 必须**主动限制**"可测集"的族。否则 Vitali 集等病态集合会导致概率论的内部矛盾。**ML/DL 里** 默认 σ-代数 = Borel σ-代数 $\mathcal{B}(\mathbb{R}^d)$, 包含所有工程上能构造的集合。

#### 误区 6: ❌ "Dirac 测度有密度"

**错例**: "$\delta_0$ 对应 $p(x) = \infty$ 在 $x=0$, 否则 $p(x) = 0$"。

**正确**: $\delta_0$ 没有密度, 因为它**不绝对连续**于 Lebesgue 测度 ($\lambda(\{0\}) = 0$ 但 $\delta_0(\{0\}) = 1$)。Dirac 测度是**纯点测度**, 必须用测度论表示, 不能用密度函数。

#### 误区 7: ❌ "概率密度可以大于 1"

**错例**: "$p(x) = 2$ 在 $[0, 0.5]$ 上, $\int_0^{0.5} 2 dx = 1$, 所以这是合法的 PDF"。

**正确**: PDF 可以 > 1, 例如 $U(0, 0.5)$ 的密度在 $[0, 0.5]$ 上 = 2。**PDF 是密度, 不是概率**。PDF 在某点的值没有"概率"的直接解释, 解释"概率"的是 $p(x) dx$。

#### 误区 8: ❌ "事件越多, 概率越大"

**错例**: "$A \subseteq B$, 所以 $P(A) \le P(B)$? 不一定! 也许 $P(A) = 0.5$, $P(B) = 0.3$"。

**正确**: 如果 $A \subseteq B$, **则 $P(A) \le P(B)$** (单调性)。但前提是 $A$ 确实是 $B$ 的子集。如果"事件越多"指的是"事件的形式更多" (例如 $A \cup B$ vs $A$), 概率可能更大也可能更小，取决于具体的事件。

### 10.2 5 个面试 Q&A (L7/L8 难度)

#### Q1: "Kolmogorov 公理的三条是什么? 为什么?"

**标准答案**:
1. **非负性**: $P(A) \ge 0$，概率是"非负的权重", 物理上没有负概率
2. **归一性**: $P(\Omega) = 1$，必然事件的概率 = 1
3. **可列可加性**: 不相交事件的并的概率 = 各事件概率之和 (对**可数**个事件)

**为什么这样选?**
- 这三条是**最少**的公理, 加上它们能推出概率论的所有定理
- 任何其他合理的"概率"概念 (频率极限, 信念度, 赌博赔率) 都能证明满足这三条
- 改弱公理 (如"有限可加性"代替"可列可加性") 会让某些定理失效 (大数定律需要可列可加性)

**追问 1**: "为什么可列可加这么关键?"
- **大数定律的数学基础**: 平均的极限需要把无穷多个独立事件的概率加起来
- **连续分布**: 单点概率 = 0 但区间概率 > 0, 这需要可列可加性
- **测度论根基**: Lebesgue 测度的核心性质

**追问 2**: "如果只允许有限可加, 会出什么问题?"
- 答: Banach-Tarski 悖论: 球可以"重组"成两个相同大小的球, 这违反"可加"但符合"有限可加"。

#### Q2: "互斥和独立的区别? 举例说明"

**标准答案**:
- **互斥** (Mutually Exclusive): $A \cap B = \emptyset$, 即 $A$ 和 $B$ 不可能同时发生
- **独立** (Independent): $A \perp B$ 即 $P(A \cap B) = P(A) P(B)$, 即 $A$ 和 $B$ 的发生互不影响

**关键区别**:
- 互斥是**几何**概念 (集合不相交)
- 独立是**概率**概念 (概率可分解)

**例子**:
- **互斥但不独立**: 骰子, $A$ = "1 点", $B$ = "2 点"。$A \cap B = \emptyset$ 但 $P(A) P(B) = 1/36 \ne 0$。
- **独立但不互斥**: 抛两枚硬币, $A$ = "第一枚 H", $B$ = "第二枚 H"。$A \cap B = \{HH\} \ne \emptyset$ 但 $P(A) P(B) = 1/4 = P(A \cap B)$。
- **既独立又互斥**: 平凡情形, $A = \emptyset$ 或 $A = \Omega$。

**追问**: "为什么两个事件独立时不能互斥?"
- 答: 如果 $A, B$ 互斥且都正概率, 则 $P(A \cap B) = 0 \ne P(A) P(B) > 0$, 矛盾。

#### Q3: "贝叶斯定理的工程意义是什么?"

**标准答案**:
贝叶斯定理 $P(B|A) \propto P(A|B) P(B)$ 是**逆向推断**的工具, 在工程上有多重意义:

1. **更新信念**: 在看到新证据 (似然) 后, 修正对假设的信念 (先验 → 后验)
2. **校准 (Calibration)**: 处理"低基率"问题 (罕见病、长尾内容)
3. **生成模型 (VAE, Diffusion)**: 用 ELBO 近似后验
4. **A/B 实验**: 贝叶斯方法用先验 + 数据得到后验, 避免 p 值的过度解读

**关键应用**:
- **医学诊断**: 阳性率 vs 患病率
- **垃圾邮件分类**: 朴素贝叶斯
- **推荐系统**: 隐式反馈的基率修正
- **强化学习**: Thompson Sampling 用后验指导 exploration

**追问**: "贝叶斯 vs 频率派的根本区别?"
- 频率派: 概率 = 频率的极限 (客观)
- 贝叶斯派: 概率 = 信念度 (主观, 但可以更新)

#### Q4: "为什么需要 σ-代数? 直接用所有子集不行吗?"

**标准答案**:
**直接答**: 测度论里有**病态集合** (如 Vitali 集), 在所有子集上**没法**给出一致的"长度"或"概率"。

**具体解释**:
- Vitali 集 $V \subset [0, 1]$ 由选择公理构造
- $V$ 在平移有理数下能划分 $[0, 1]$
- 假设 $V$ 可测, 由可列可加性得 $\mu(V) = 0$ 又 $\mu(V) > 0$, 矛盾
- 所以 $V$ 必须**不在 σ-代数里**，σ-代数必须主动排除这种"病态"集

**工程意义**:
- **ML/DL 里** 默认用 Borel σ-代数 $\mathcal{B}(\mathbb{R}^d)$, 包含所有工程上能构造的集合 (开区间、闭区间、有限集、可数集、连续函数图像等)
- 我们**不会**遇到 Vitali 集, 因为代码是确定的, 不依赖选择公理
- 但**严格的理论** 必须用 σ-代数, 否则概率论的内部一致性会被破坏

**追问**: "工程上不用 σ-代数, 会有什么问题?"
- 答: 在 ML/DL 的 99.9% 场景下**没有问题**。但**论文发表**、**严格证明** 时, 必须使用 σ-代数, 否则有些定理 (大数定律、中心极限定理) 的证明会"不严谨"。

#### Q5: "概率、似然、先验、后验的区别? 在 MLE/MAP 中的角色?"

**标准答案**:
- **概率** $P(X; \theta)$: 在**给定参数** $\theta$ 下, 数据 $X$ 出现的概率
- **似然** $L(\theta; X) = P(X | \theta)$: 形式上跟概率一样, 但**视角相反**，把 $\theta$ 视为变量, $X$ 视为固定
- **先验** $P(\theta)$: 在看到数据前, 对参数 $\theta$ 的信念
- **后验** $P(\theta | X)$: 看到数据后, 对参数 $\theta$ 的信念

**MLE (Maximum Likelihood Estimation)**:
$$\hat \theta_{\text{MLE}} = \arg\max_\theta P(X | \theta) = \arg\max_\theta L(\theta; X)$$

**MAP (Maximum A Posteriori)**:
$$\hat \theta_{\text{MAP}} = \arg\max_\theta P(\theta | X) = \arg\max_\theta P(X | \theta) P(\theta)$$

**贝叶斯估计**:
$$P(\theta | X) = \frac{P(X | \theta) P(\theta)}{P(X)}$$

**关键区别**:
- MLE 只用似然, 不加先验
- MAP 加了先验 (相当于"正则化")
- 贝叶斯估计输出**整个后验分布**, 不是单点估计

**ML 视角**:
- L2 正则化 = MAP with Gaussian prior
- 神经网络训练 ≈ MLE (CrossEntropy Loss) + 隐式正则化
- Bayesian Neural Network = 贝叶斯估计 (后验分布)

## 12. 进阶专题:不可测集与"为什么必须用 σ-代数" (350 行)

这一节把"为什么 σ-代数是必须的"用反例讲透。学完你会知道:概率论不是数学家的智力游戏,而是有真实的"会出 bug"的反例逼迫出来的设计。

### 12.1 Vitali 集:选择公理下的"反例怪物"

考虑 $\Omega = [0, 1]$, 我们想构造一个"等价的"等价关系: $x \sim y$ 当且仅当 $x - y \in \mathbb{Q}$。

**步骤 1**: 用选择公理 (Axiom of Choice) 在每个等价类中**选一个代表元**, 组成集合 $V \subset [0, 1]$。

**步骤 2**: 把 $V$ 平移有理数: $V_q = (V + q) \mod 1$, $q \in \mathbb{Q} \cap [-1, 1]$。

**关键性质**: 不同 $V_q$ 两两不交, 且 $\bigcup_q V_q = [0, 1]$ (因为每个实数都属于某个等价类)。

**步骤 3**: 假设 $V$ 是 Lebesgue 可测的, 则 $\lambda(V_q) = \lambda(V)$ (平移不变)。可数个不交可测集的并仍然是可测集, 所以:
$$
1 = \lambda([0, 1]) = \lambda\left(\bigcup_q V_q\right) = \sum_q \lambda(V_q)
$$
如果 $\lambda(V) > 0$, 那么右边的求和 = $\infty$ (可数个相同正数的和), 矛盾。
如果 $\lambda(V) = 0$, 那么右边 = 0, 也矛盾。

**结论**: $V$ **不是 Lebesgue 可测的**。即, 没有办法给 $V$ 一个合理的"长度", 让它和"长度"的基本性质 (可数可加 + 平移不变) 相容。

> 这就是 σ-代数存在的根本原因: 不是所有"看起来像"集合的对象都能赋予概率, 我们必须把"可测"这件事**严格地**划出来。

```text
Vitali 集的形象化:
[0, 1] = V_0 ∪ V_{1/3} ∪ V_{2/3} ∪ V_{1/2} ∪ ...   (可数个有理平移)
         ↓                ↓                ↓
       平移 0           平移 1/3          平移 2/3
       (不交)
```
每个 $V_q$ 都是 $V$ 的有理平移, 长度都应该等于 $V$ 的长度。但 [0,1] 长度 = 1。

### 12.2 Banach-Tanski 悖论:把球"复制"成两个

考虑 $\mathbb{R}^3$ 中的单位球 $B$, 我们可以通过旋转 + 选择公理把它**切分成有限块**, 然后重新拼成 **两个** 同样的单位球。

直觉上, "体积" 不可能倍增。但 "体积" 是 Lebesgue 测度, 而切分用到了 Vitali 集之类的不可测集, 重新拼时 Lebesgue 测度不再适用。

> 这告诉我们: 在不可测集上, "体积"概念失效。把概率论建在"所有子集都可测"上会导致矛盾, σ-代数不是数学洁癖, 是工程必需品。

### 12.3 σ-代数的"封闭性"为什么必须是可数?

定义要求 σ-代数在**可数**并/可数交/补运算下封闭。为什么不是"有限"封闭?

**反例动机**: 设 $\Omega = \mathbb{R}$, 令 $\mathcal{A}$ = 所有有限子集 + 它们的补 + 空集。

$\mathcal{A}$ 在有限并/有限交下封闭, 但 $\mathbb{R} = \bigcup_{n=1}^{\infty} \{n\}$ 是 $\mathcal{A}$ 的可数个元素的并, 而 $\mathbb{R} \notin \mathcal{A}$ (因为 $\{1, 2, 3, ...\}$ 不是有限集, 它的补 $\{0\} \cup (负数 + 分数)$ 也不是有限集)。

所以"有限可加" + "有限封闭" 推出 "可数封闭", 这个例子就破了。

**为什么这很重要**: 工程上我们经常做"无穷多个事件的并", 比如:

- "用户在 [0, ∞) 内任意时刻点击" = $\bigcup_{t=0}^{\infty} \{t \text{ 时刻点击}\}$
- "Embedding 向量落在 [0,1]^n 的某个边界上" = 可数多个超平面的并

如果 σ-代数对这些事件不封闭, 我们连"这件事的概率是多少"都问不出来。

### 12.4 工程上的 σ-代数实例

虽然 σ-代数看起来抽象, 工程里我们其实一直在用 "Borel σ-代数" $\mathcal{B}(\mathbb{R})$。

**Borel σ-代数**: $\mathcal{B}(\mathbb{R})$ = 包含所有开区间的最小 σ-代数。

```text
所有开区间 (a, b)
       ↓ (添加端点、单点、可数并)
所有闭区间 [a, b]
       ↓
所有可数个开集的并 (开集)
       ↓
所有可数个闭集的交 (闭集 = 开集的补)
       ↓
G_δ 集 (可数个开集的交) 和 F_σ 集 (可数个闭集的并)
       ↓
... (更复杂的集合) ...
       ↓
最后封顶 = Borel σ-代数 B(R)
```

任何"自然"的事件都在 Borel σ-代数里。例如:

- $\{$ 用户年龄在 18-25 岁之间 $\}$ = $[18, 25] \in \mathcal{B}(\mathbb{R})$
- $\{$ 用户点击了某个特定 item $\}$ = 单点集, Borel 可测
- $\{$ 用户点击次数 ≤ 5 $\}$ = $(-\infty, 5]$, Borel 可测

工程上**永远不需要**担心非 Borel 可测集 (它们依赖于选择公理, 是"病态"的)。

### 12.5 完备化:为什么概率空间要做"完备化"

定义: $(\Omega, \mathcal{F}, P)$ 是**完备的** (complete) 当且仅当: 如果 $A \in \mathcal{F}$ 且 $P(A) = 0$, 那么 $A$ 的任何子集 $B \subseteq A$ 也属于 $\mathcal{F}$ (且 $P(B) = 0$)。

**动机**: Lebesgue 测度是完备的 (任何零测子集都可测), Borel 测度不完备 (单点集是 Borel 可测的, 但单点的子集 $\emptyset$ 也 Borel 可测, 这里碰巧没问题; 但有些构造里, Borel 零测集的子集可能不是 Borel 集)。

工程意义: 如果你用 `torch.distributions` 里的 `Bernoulli(p=0)`, 它会返回概率全 0 的"退化分布", 任何事件都在零测集上, 必须保证它的子集也有概率 0, 否则你的概率计算会"卡住"。

## 13. 工程师的概率直觉训练 (300 行)

下面 5 道题是工程场景下的概率直觉训练题, 每题都附详细解答。**建议自己先做, 再看答案**。

### 练习 1: 推荐系统的位置偏差

**问题**: 在推荐系统中, 用户看到 item 的位置会影响点击率。假设位置 $p$ 处 item 的"位置点击率提升因子"为 $\alpha_p$, 真实 CTR 为 $c$。那么位置 $p$ 处观察到的 CTR 为 $c \cdot \alpha_p$, $\alpha_p$ 是已知的。

我们想让"位置偏差归一化": 给定位置 $p$ 处的观测点击 $k_p$ 和曝光 $n_p$, 估计 item 的真实 CTR $c$。

**解答**:

设 $K_p \sim \text{Binomial}(n_p, c \cdot \alpha_p)$。

观测到 $k_p$ 后, $c$ 的 MLE:
$$
\hat{c} = \arg\max_c \prod_p \binom{n_p}{k_p} (c \alpha_p)^{k_p} (1 - c \alpha_p)^{n_p - k_p}
$$
取 log, 求导, 令为 0:
$$
\sum_p \frac{k_p}{c} - \sum_p \frac{(n_p - k_p) \alpha_p}{1 - c \alpha_p} = 0
$$
这是一个关于 $c$ 的非线性方程, 通常用数值方法 (Newton-Raphson) 求。

**简化版**: 如果数据来自多个位置, 加权 MLE 等价于:
$$
\hat{c} = \frac{\sum_p k_p}{\sum_p n_p \alpha_p}
$$

直觉: 把每个位置的"曝光数"按位置偏差反加权, 然后用总点击数除以总加权曝光数。

```python
import torch
def estimate_ctr(clicks, exposures, alpha):
    """clicks, exposures: tensor of shape [num_positions]
       alpha: tensor of shape [num_positions]"""
    weighted_exposures = (exposures * alpha).sum()
    total_clicks = clicks.sum()
    return total_clicks / weighted_exposures

# 例: 3 个位置, alpha = [1.0, 1.2, 1.5]
clicks = torch.tensor([100.0, 130.0, 150.0])
exposures = torch.tensor([1000.0, 1000.0, 1000.0])
alpha = torch.tensor([1.0, 1.2, 1.5])
print(estimate_ctr(clicks, exposures, alpha))
# 输出 ~0.1056 (位置偏差归一化后的真实 CTR)
```

### 练习 2: A/B 实验的样本量估算

**问题**: 你的产品想做一个 A/B 实验, 把推荐算法的 CTR 从基线的 5% 提升到 5.5% (相对提升 10%)。希望检验的功效 (power) = 0.8, 显著性水平 α = 0.05。每组需要多少样本?

**解答**:

两比例 z 检验的样本量公式:
$$
n = \frac{(z_{\alpha/2} + z_{\beta})^2 \cdot (p_1(1-p_1) + p_2(1-p_2))}{(p_2 - p_1)^2}
$$
其中 $z_{\alpha/2} = 1.96$ (双侧 5%), $z_\beta = 0.84$ (功效 80%)。

代入 $p_1 = 0.05$, $p_2 = 0.055$:
$$
n = \frac{(1.96 + 0.84)^2 \cdot (0.05 \cdot 0.95 + 0.055 \cdot 0.945)}{0.005^2} = \frac{7.84 \cdot 0.0995}{0.000025} \approx 31200
$$

所以每组约需 31200 个样本, 两组共 62400。

```python
from scipy.stats import norm
import math

p1, p2 = 0.05, 0.055
alpha = 0.05
power = 0.8

z_alpha = norm.ppf(1 - alpha/2)  # 1.96
z_beta = norm.ppf(power)          # 0.84

n = ((z_alpha + z_beta)**2 * (p1*(1-p1) + p2*(1-p2))) / (p2 - p1)**2
print(f"每组需要样本量: {math.ceil(n)}")
# 输出: 每组需要样本量: 31205
```

**直觉**: 提升幅度越小, 样本量指数级增加。10% 的相对提升要 6 万样本, 5% 的相对提升要 25 万样本, 1% 的相对提升要 600 万样本。这就是为什么"微小改动"用 A/B 实验几乎不可行。

### 练习 3: Bayesian A/B 测试的先验选择

**问题**: 用 Beta-Bernoulli 模型做 A/B 测试。先验 Beta(α, β) 中的 α 和 β 应该怎么选?

**解答**:

工程上有三个常见选择:

1. **无信息先验** Beta(1, 1) = Uniform(0, 1): 不偏袒任何 CTR, 后验 = (k+1, n-k+1)
2. **弱信息先验** Beta(0.5, 0.5) = Jeffreys prior: 后验 = (k+0.5, n-k+0.5), 鼓励 0% 和 100% CTR (反映"边界厌恶")
3. **强信息先验** Beta(α₀, β₀) 其中 α₀/(α₀+β₀) = 历史均值, α₀+β₀ = 假想样本量 (effective sample size)

```python
import torch
from torch.distributions import Beta

# 无信息先验 + 100 次曝光 5 次点击
k, n = 5, 100
prior = Beta(1.0, 1.0)
posterior = Beta(1.0 + k, 1.0 + n - k)
print(f"后验均值: {posterior.mean.item():.4f}")
# 输出: 后验均值: 0.0594

# 强信息先验: 假设历史是 1000 次曝光 50 次点击 (CTR=5%)
prior_strong = Beta(50.0, 950.0)
posterior_strong = Beta(50.0 + k, 950.0 + n - k)
print(f"强先验后验均值: {posterior_strong.mean.item():.4f}")
# 输出: 强先验后验均值: 0.0505
```

**直觉**: 强先验让后验更"保守", 不容易被 5/100 的小数据带跑。这就是为什么大厂的 A/B 测试平台默认有先验, 不是工程师偷懒, 是有意为之。

### 练习 4: 多重检验校正

**问题**: 你做了 20 个 A/B 实验 (20 个不同算法的对照), 每个独立检验都用 α = 0.05。至少 1 个假阳性的概率是多少?

**解答**:

假设所有实验 H0 都成立 (没真效果), 每个假阳性概率 0.05, 互相独立。
$$
P(\text{至少 1 个假阳性}) = 1 - P(\text{全没假阳性}) = 1 - 0.95^{20} \approx 0.64
$$

即 64% 的概率至少 1 个实验"假阳性", 即使所有算法都没真效果。这就是**多重检验问题**。

**Bonferroni 校正**: 把每个实验的 α 降到 $\alpha/m$, 这里 $0.05/20 = 0.0025$。

**Benjamini-Hochberg (BH) 校正**: 控制 FDR (False Discovery Rate), 比 Bonferroni 不那么保守, 工程上更常用。

```python
from statsmodels.stats.multitest import multipletests

p_values = [0.001, 0.008, 0.039, 0.041, 0.042, 0.06, 0.074, 0.205]  # 8 个实验
rejected, p_corrected, _, _ = multipletests(p_values, alpha=0.05, method='fdr_bh')
print("拒绝 H0:", rejected)   # [True, True, False, False, False, False, False, False]
print("校正后 p-value:", p_corrected)
```

**直觉**: 多重检验是 A/B 实验平台的"暗坑", 没做校正的实验报告 100% 有假阳性。Netflix/Google 的实验平台内部都有 FDR 控制机制。

### 练习 5: Embedding 协方差矩阵的正定性

**问题**: 你的 Embedding 矩阵 $X \in \mathbb{R}^{n \times d}$, $n$ 个样本, $d$ 维。计算 $\hat{\Sigma} = \frac{1}{n} X^T X$。如果 $n < d$, $\hat{\Sigma}$ 一定可逆吗?

**解答**:

不一定。$\text{rank}(X) \le \min(n, d)$, 所以 $\text{rank}(\hat{\Sigma}) = \text{rank}(X) \le n$。

如果 $n < d$, $\hat{\Sigma}$ 至少亏 $d - n$ 秩, 不满秩, **不可逆**。

**工程后果**: BatchNorm 里的 $\hat{\sigma}^2$ 在小 batch 时会接近 0, 后续除法爆炸。Embedding 白化 (whitening) 时如果样本不够, 矩阵不可逆。

**解决方法**:

1. 加阻尼 (damping): $\hat{\Sigma} + \epsilon I$, $\epsilon$ 通常 $10^{-4}$ 到 $10^{-2}$
2. 用 truncated SVD, 只取前 $k$ 个奇异值
3. 累积协方差 (类似 BatchNorm 的 running stats)

```python
import torch
torch.manual_seed(0)

# n=5, d=10: n < d, X^T X 不可逆
X = torch.randn(5, 10)
Sigma = X.T @ X / 5

try:
    torch.linalg.inv(Sigma)
    print("可逆")
except RuntimeError as e:
    print(f"不可逆: {e}")

# 加阻尼: 可逆
Sigma_damped = Sigma + 1e-3 * torch.eye(10)
print("加阻尼后特征值:", torch.linalg.eigvalsh(Sigma_damped))
# 输出: 全部 > 0, 可逆
```

## 15. 概率空间的"分形"图景:可视化概率论 (200 行)

下面用 ASCII 可视化把概率空间的关键概念画出来, 帮助工程师建立直觉。

### 15.1 概率空间三件套

```text
        样本空间 Ω
        ┌─────────────────────────────────────┐
        │ ω₁ ω₂ ω₃ ω₄ ω₅ ω₆ ω₇ ω₈ ... ω_∞   │  所有"基本结果"
        └─────────────────────────────────────┘
                  ↓ 概率 P 映射
        ┌─────────────────────────────────────┐
        │ 0.05  0.1  0.2  0.1  0.05 ...  0.0  │  每个基本结果一个概率
        └─────────────────────────────────────┘
```

σ-代数 $\mathcal{F}$ = "哪些子集是事件", 概率 $P$ = "给每个事件一个数, 且满足三公理"。

### 15.2 高斯分布的"概率等高线"

```text
   概率密度 f(x) 的形状 (高斯):
                ▁▂▃▄▅▆▇████▇▆▅▄▃▂▁
        ┌──────────────────────────────────┐
   0.0  │   ▂▄▆▇████████████████████▇▆▄▂   │ ← 概率最高
        │ ▂▄█████████████████████████████▄▂ │
        │▂████████████████████████████████▂│
        │██████████████████████████████████│
        │▂████████████████████████████████▂│
        │ ▂▄█████████████████████████████▄▂ │
   0.0  │   ▂▄▆▇████████████████████▇▆▄▂   │
        └──────────────────────────────────┘
              -3σ   -2σ  -μ  0  μ  2σ   3σ
                       ↑
                   μ = mean
              σ = std 控制"宽度"
```

不同的 σ 让同一均值的高斯"胖瘦"不同:

```text
σ = 0.5:  ▂▆████████▆▂            (窄而高)
σ = 1.0:  ▂▄▆████████▆▄▂          (标准)
σ = 2.0:  ▁▂▄▆████████▆▄▂▁        (宽而矮)
σ = 5.0:  ▁▁▂▃▅▆██████▆▅▃▂▁▁      (很宽很矮, 但总面积 = 1)
```

直觉: σ 越大, 不确定性越大, 概率分布越"摊平"。这就是为什么 Bayesian NN 用 MC Dropout 增大 σ 来表达不确定性。

### 15.3 σ-代数的"颗粒度"对比

```text
粗 σ-代数 (例如 {∅, Ω}):
        ┌──────────┐
        │    Ω     │ ← 1 个事件
        └──────────┘
能问的问题: "事件会发生吗?" → P(Ω) = 1 或 P(∅) = 0

中 σ-代数 (例如硬币正反面):
        ┌────┬────┐
        │ 正面│反面│ ← 2 个事件
        └────┴────┘
能问的问题: "是正面吗?" "是反面吗?"

细 σ-代数 (例如所有 Borel 子集):
        ┌─────────────────────────────┐
        │ [0,0.1) [0.1,0.2) ... [0.9,1) │
        │   ↑ 能问 "x ∈ 任何 Borel 集吗?"│
        └─────────────────────────────┘
能问的问题: 任何连续型问题
```

工程意义: 我们的"问题颗粒度"决定需要多细的 σ-代数。预测"用户点击 vs 不点击" 用二元 σ-代数足够, 预测"用户的精确停留时长"需要 Borel σ-代数。

### 15.4 概率的"分形"分布

很多自然现象是"分形"的, 概率分布也呈分形:

```text
Zipf 分布 (词频) 在双对数坐标下呈直线:
频率
  │
1 │█
  │ █
  │  █
  │   █
  │    █
  │     █
  │      █
  │       █
  │        █
  └───────────────→ 词频排名
        log-log 坐标
```

这种"重尾分布"在推荐系统里非常常见: 头部 item 占 80% 流量, 尾部 item 几乎没人点。如果用高斯假设会严重低估尾部概率。

### 15.5 联合分布与边缘分布

```text
联合分布 P(X, Y) 的可视化:
              Y=0  Y=1  Y=2  Y=3
        X=0   0.05 0.05 0.05 0.05
        X=1   0.10 0.10 0.10 0.10
        X=2   0.05 0.05 0.10 0.20  ← 峰值在 (2, 3)
              ────────────────────
   边缘 P(X)   0.20 0.40 0.40   (列和)
   边缘 P(Y)   0.20 0.20 0.25 0.35  (行和)
```

X 和 Y 不独立 (联合 ≠ 各边缘的乘积), 边缘是联合的"投影"。在 VAE 中, 我们想学 latent 分布 $p(z)$, 它是 $p(x, z)$ 对 $x$ 的边缘化。

## 16. 概率论历史八卦与工程师的彩蛋 (150 行)

最后这一节是"轻松阅读", 讲讲概率论历史上的关键人物和趣事, 帮助工程师把抽象概念"人格化"。

### 16.1 概率论的诞生:赌博与 Pascal

1654 年, 赌徒 Chevalier de Méré 向 Pascal 提了一个问题: "如果一场比赛提前中断, 赌注怎么分?"

Pascal 和 Fermat 在通信中发展出了**期望值** (expected value) 的概念。这是有史以来第一次用数学严格地处理不确定性。

> 工程师彩蛋: 期望值不是"最可能的值", 是"长期平均"。如果你的模型只关心"最可能的输出", 用 argmax; 如果关心"长期平均收益", 用期望。

### 16.2 Kolmogorov 1933:公理化

20 世纪初, 概率论基础一团糟。Borel 测度刚被定义, Lebesgue 在做积分。Kolmogorov 在 1933 年 (他 30 岁) 出版了一本小册子《概率论基础》, 用**测度论**统一了概率, 给出三公理。这本书只有 60 页, 但奠定了现代概率论的地基。

> 工程师彩蛋: 你用的 `torch.distributions` 里的所有分布都满足这三公理。你不必手动检验它们, 因为 PyTorch 帮你做了。

### 16.3 贝叶斯 vs 频率派:百年之争

- **频率派** (Fisher, Neyman, Pearson): 参数是固定的, 概率是长期频率。MLE、p-value 是这一派的产物。
- **贝叶斯派** (Bayes, Laplace, de Finetti): 参数是分布, 概率是信念强度。先验 + 似然 = 后验。

20 世纪频率派占上风 (因为计算便宜), 21 世纪贝叶斯派借 MCMC / VI 复兴 (因为算力跟上来了)。

> 工程师彩蛋: 工业上**两种都用**。A/B 实验用频率派 (p-value), 推荐系统的 CTR 平滑用贝叶斯派 (Beta-Bernoulli)。混用不矛盾, 是不同抽象层级。

### 16.4 信息论与概率的握手

1948 年 Shannon 发表《通信的数学理论》, 用概率论定义熵。从那以后, 信息论 = 概率论的"编码视角"。

> 工程师彩蛋: CrossEntropy Loss = Shannon 熵 + KL 散度。第 11 章会展开。

### 速查表 1:概率空间三件套

### 速查表 2:常用符号

| 符号 | 含义 |
| :--- | :--- |
| $P(A)$ | 事件 A 的概率 |
| $P(A \cap B)$ | A 和 B 都发生 |
| $P(A \cup B)$ | A 或 B 发生 |
| $P(A \mid B)$ | B 发生时 A 的概率 |
| $P(A^c)$ | A 不发生 (补事件) |

### 速查表 3:条件概率与贝叶斯速记

| 公式 | 用途 |
| :--- | :--- |
| $P(A \mid B) = \frac{P(A \cap B)}{P(B)}$ | 条件概率定义 |
| $P(A \cap B) = P(A \mid B) P(B)$ | 乘法规则 |
| $P(A) = \sum_i P(A \mid B_i) P(B_i)$ | 全概率公式 |
| $P(B_j \mid A) = \frac{P(A \mid B_j) P(B_j)}{P(A)}$ | 贝叶斯定理 |
| $P(A, B) = P(A) P(B)$ (A,B 独立) | 朴素贝叶斯 |

### 速查表 4:常见概率计算模式

| 模式 | 公式 | 例子 |
| :--- | :--- | :--- |
| 至少一个发生 | $1 - P(\text{都不})$ | $1 - (1-p)^n$ |
| 二项分布 | $P(K=k) = \binom{n}{k} p^k (1-p)^{n-k}$ | n 次试验 k 次成功 |
| 条件期望 | $E[X \mid Y] = \sum_x x P(X=x \mid Y)$ | 给定 Y 时 X 的均值 |

### 速查表 5:常见陷阱

| 陷阱 | 正确说法 |
| :--- | :--- |
| "P-value = H0 为真的概率" | "在 H0 成立时, 看到当前或更极端结果的概率" |
| "95% CI = 真值有 95% 在区间内" | "长期重复实验下, 95% 的 CI 会覆盖真值" |
| "概率小 = 不可能" | "概率小 = 在单次实验中罕见, 但长期下会发生" |
| "独立 = 不相关" (对高斯) | "独立 ⇒ 不相关; 反之一般不成立" |
| "$P(A) + P(B) = P(A \cup B)$" | "$P(A) + P(B) - P(A \cap B) = P(A \cup B)$" |

## 18. 工程实战:5 个真实 ML 场景的概率空间构造 (400 行)

这一节把抽象的概率空间概念落到 5 个具体的 ML 场景上。每个场景都给出**完整的概率空间三件套构造 + PyTorch 代码**。这是把本章"测度论"应用到工程的关键一步。

### 18.1 场景 1:二分类问题的概率空间

**问题**: 预测用户是否会点击广告 (CTR 二分类)。

**概率空间三件套构造**:

- 样本空间 $\Omega$: 所有 (用户, 广告, 上下文) 的可能组合
  - 简化: 一次"曝光-点击"事件就是一个 $\omega \in \Omega$
- σ-代数 $\mathcal{F}$: 用户行为的所有 Borel 可测子集
  - 简化: 二分类问题只需要 4 个事件: {∅, 点击, 不点击, 全部}
- 概率测度 $P$: 由模型输出 $p_\theta(\text{click} \mid \text{user, ad})$

**关键观察**: σ-代数只需要 4 个事件, 比 Borel σ-代数细得多。**问题颗粒度决定 σ-代数的粗细**。

```python
import torch
from torch.distributions import Bernoulli

# 单次曝光: 二分类
p_click = torch.tensor(0.05)  # 模型预测的 CTR
click_dist = Bernoulli(probs=p_click)

# 一次试验: 采样
sample = click_dist.sample()  # tensor(0.) 或 tensor(1.)
log_prob = click_dist.log_prob(sample)  # log P(click | p)

# 多次曝光: 独立同分布
n = 1000
clicks = click_dist.sample((n,))  # 1000 次采样
total_clicks = clicks.sum()
empirical_ctr = total_clicks / n  # 经验 CTR, 应该接近 0.05
print(f"理论 CTR: 0.05, 经验 CTR: {empirical_ctr:.4f}")
```

**MLE 联系**: 训练神经网络最小化 BCE loss = 最大化 log P(clicks | θ), 就是 MLE。

### 18.2 场景 2:多分类问题的概率空间

**问题**: 预测图片是猫/狗/鸟/... 中的哪一类 (10 分类)。

**概率空间三件套构造**:

- $\Omega$: 所有可能的 (图片, 类别) 对
- $\mathcal{F}$: 让 {图片属于类别 k} 对 k = 1, ..., 10 都可测
- $P$: 用 Categorical(softmax(logits)) 给出

```python
import torch
from torch.distributions import Categorical

# 模型输出 logits
logits = torch.tensor([2.0, 1.0, 0.1, 0.5, 0.3, 0.8, 0.2, 0.4, 0.6, 0.7])
# softmax 后就是概率分布
probs = torch.softmax(logits, dim=-1)
print(f"类别概率: {probs}")

# 采样一个类别
cat_dist = Categorical(probs=probs)
sample = cat_dist.sample()
print(f"采样类别: {sample.item()}")

# log probability (用作 NLL loss)
log_prob = cat_dist.log_prob(sample)

# MLE 训练: 最小化 -log_prob
target = torch.tensor(3)  # 真实类别是第 3 类 (0-indexed)
loss = -cat_dist.log_prob(target)
print(f"单个样本的 NLL loss: {loss.item():.4f}")
```

**工程意义**: CrossEntropyLoss = Categorical 分布的 NLL, 这是几乎所有分类网络的训练目标。

### 18.3 场景 3:回归问题的概率空间

**问题**: 预测房价 (连续值)。

**概率空间三件套构造**:

- $\Omega$: 所有 (房子, 价格) 对
- $\mathcal{F}$: Borel σ-代数 $\mathcal{B}(\mathbb{R})$ (因为价格是连续值)
- $P$: 高斯分布 $N(\mu_\theta(x), \sigma^2)$, $\mu_\theta$ 由神经网络输出

```python
import torch
from torch.distributions import Normal

# 模型预测均值, 假设方差固定 (简化)
mu = torch.tensor([300.0])  # 预测房价 300 万
sigma = torch.tensor([50.0])  # 标准差 50 万

# 构造高斯分布
price_dist = Normal(mu, sigma)

# 采样一个价格预测
sample = price_dist.sample()
print(f"采样价格: {sample.item():.2f} 万")

# log probability: NLL loss
actual_price = torch.tensor([280.0])
log_prob = price_dist.log_prob(actual_price)

# MSE 联系: -log_prob = 0.5 * log(2π σ²) + (x - μ)² / (2σ²)
# 当 σ 固定时, 最小化 NLL 等价于最小化 MSE
mse = (actual_price - mu) ** 2
print(f"log_prob: {log_prob.item():.4f}, MSE: {mse.item():.2f}")
```

**关键观察**: MSE = 高斯似然 (σ 固定) 的 NLL。这是为什么"回归问题用 MSE" 不是任意选择, 是概率论推导出来的。

**进阶**: 如果让 σ 也由网络预测, NLL = "MSE + σ 正则化", 此时网络学会"对不确定的样本预测更大的 σ"。这就是**异方差回归** (heteroscedastic regression)。

### 18.4 场景 4:Embedding 空间的概率建模

**问题**: 用户/物品的 Embedding 向量怎么用概率建模?

**概率空间三件套构造**:

- $\Omega$: 所有可能的 Embedding 向量 $x \in \mathbb{R}^d$
- $\mathcal{F}$: $\mathbb{R}^d$ 上的 Borel σ-代数 $\mathcal{B}(\mathbb{R}^d)$
- $P$: 多维高斯 $N(\mu, \Sigma)$, $\mu \in \mathbb{R}^d$, $\Sigma \in \mathbb{R}^{d \times d}$ 半正定

```python
import torch
from torch.distributions import MultivariateNormal

# 一个 3 维 Embedding
mu = torch.tensor([1.0, 2.0, 3.0])  # 均值向量
Sigma = torch.tensor([
    [1.0, 0.5, 0.2],
    [0.5, 1.0, 0.3],
    [0.2, 0.3, 1.0]
])  # 协方差矩阵, 必须半正定

# 构造多维高斯分布
embed_dist = MultivariateNormal(mu, Sigma)

# 采样 Embedding
sample = embed_dist.sample()  # shape: (3,)
print(f"采样 Embedding: {sample}")

# 计算某个 Embedding 的 log probability
actual_embed = torch.tensor([1.5, 2.5, 2.8])
log_prob = embed_dist.log_prob(actual_embed)
print(f"log probability: {log_prob.item():.4f}")
```

**应用**:

1. **VAE 的隐空间**: $z \sim N(\mu_\phi(x), \sigma_\phi^2(x) I)$, decoder 从 $z$ 重建 $x$
2. **推荐系统的分布 Embedding**: 把用户点击历史编码成 $N(\mu, \Sigma)$, 用 KL 散度作为相似度
3. **异常检测**: 正常样本的 log_prob 高, 异常样本 log_prob 低

### 18.5 场景 5:Diffusion 模型的前向/反向过程

**问题**: Diffusion 模型把图片 $x_0$ 变成噪声 $x_T$, 再从 $x_T$ 一步步去噪回 $x_0$。

**概率空间三件套构造**:

- $\Omega$: 所有 $d$ 维图片 (像素向量)
- $\mathcal{F}$: $\mathbb{R}^d$ 上的 Borel σ-代数
- $P$: 扩散过程的边缘分布 $q(x_t) = \int q(x_0) q(x_{1:t} \mid x_0) dx_0$

**前向过程 (固定加噪)**:
$$
q(x_t \mid x_{t-1}) = N(x_t; \sqrt{1 - \beta_t} x_{t-1}, \beta_t I)
$$
每步加一点高斯噪声, 总共加 T 步得到 $x_T \approx N(0, I)$。

**反向过程 (学习去噪)**:
$$
p_\theta(x_{t-1} \mid x_t) = N(x_{t-1}; \mu_\theta(x_t, t), \Sigma_\theta(x_t, t))
$$
神经网络预测去噪的方向。

```python
import torch
from torch.distributions import Normal

# 简化版: 1 维"图片"
T = 1000  # 总步数
betas = torch.linspace(0.0001, 0.02, T)  # 加噪强度

# 前向过程: 从 x_0 加噪到 x_t (一步到位)
def q_xt_given_x0(x0, t):
    alpha_bar = (1 - betas).cumprod(dim=0)
    mean = torch.sqrt(alpha_bar[t]) * x0
    var = 1 - alpha_bar[t]
    return Normal(mean, torch.sqrt(var))

# x_0 是真实"图片" (1 维)
x0 = torch.tensor([1.0])
for t in [0, 100, 500, 999]:
    q = q_xt_given_x0(x0, t)
    xt = q.sample()
    print(f"t={t}: x_t = {xt.item():.4f}, log_prob = {q.log_prob(xt).item():.4f}")

# 输出 (大致):
# t=0:    x_t ≈ 1.0    (没加噪)
# t=100:  x_t ≈ 0.85   (加了一点噪)
# t=500:  x_t ≈ 0.1    (几乎全是噪)
# t=999:  x_t ≈ 0.0    (纯噪声, 几乎无信息)
```

**关键观察**: 前向过程是固定的高斯加噪, 反向过程是学习的高斯去噪。整个 Diffusion 模型就是一个**时变多维高斯序列**。

**训练目标**: 简化版 ELBO 推出, 训练网络预测噪声 $\epsilon$, loss = $\|\epsilon - \epsilon_\theta(x_t, t)\|^2$, 这就是 DDPM 论文里的简单 loss。

### 18.6 五个场景的统一视角

```text
场景                 Ω (样本空间)              σ-代数       概率分布
─────────────────────────────────────────────────────────────────
二分类                {点击, 不点击}            4 个事件       Bernoulli(p)
多分类                {类别1, ..., 类别K}       K 个事件       Categorical(softmax)

Embedding              ℝᵈ (向量)              ℬ(ℝᵈ)           MultivariateNormal
```

### 19.4 重参数化技巧 (Reparameterization Trick)

为什么 VAE 能用 SGD 训练? 因为它用了重参数化:

```python
# ❌ 不能反向传播 (采样操作不可微)
z = dist.sample()  # z 是从 N(μ, σ²) 采的, 但采样过程没有梯度

# ✅ 重参数化: 把随机性外置
eps = torch.randn_like(mu)  # 噪声来自简单分布, 可反向传播
z = mu + sigma * eps        # 通过线性变换得到目标分布的样本
```

**原理**: 采样 = "从简单分布采 + 一个可微变换"。eps 没有参数, 不需要梯度; 但 $\mu, \sigma$ 是网络输出, 梯度通过它们流回去。

这是 PyTorch 里所有分布都支持 `rsample()` (reparameterized sample) 的原因: 训练时用 `rsample()`, 推理时用 `sample()`。

```python
import torch
from torch.distributions import Normal

mu = torch.tensor([0.0], requires_grad=True)
sigma = torch.tensor([1.0], requires_grad=True)
dist = Normal(mu, sigma)

# 训练模式: 重参数化采样
z = dist.rsample()  # z = mu + sigma * eps, eps ~ N(0, 1)
print(f"z.requires_grad: {z.requires_grad}")  # True

# 推理模式: 普通采样
with torch.no_grad():
    z = dist.sample()
print(f"z.requires_grad: {z.requires_grad}")  # False
```

### 19.5 实战: 自定义分布

PyTorch 允许你继承 `Distribution` 类自定义分布:

```python
import torch
from torch.distributions import Distribution, Normal
from torch.distributions.constraints import real, positive

class TruncatedNormal(Distribution):
    """截断高斯: 只支持 [a, b] 区间"""

    arg_constraints = {
        'loc': real,
        'scale': positive,
        'a': real,
        'b': real
    }
    has_rsample = False

    def __init__(self, loc, scale, a, b):
        self.loc = loc
        self.scale = scale
        self.a = a
        self.b = b
        self._normal = Normal(loc, scale)
        # 归一化常数: 用未截断高斯在 [a,b] 上的概率
        self._Z = self._normal.cdf(b) - self._normal.cdf(a)

    def sample(self, sample_shape=torch.Size()):
        # 用逆 CDF 采样: U ~ Uniform(0,1), X = F^{-1}(F(a) + U * (F(b) - F(a)))
        u = torch.rand(sample_shape)
        cdf_a = self._normal.cdf(self.a)
        cdf_b = self._normal.cdf(self.b)
        return self._normal.icdf(cdf_a + u * (cdf_b - cdf_a))

    def log_prob(self, value):
        log_p_normal = self._normal.log_prob(value)
        return log_p_normal - torch.log(self._Z)

# 使用
trunc_norm = TruncatedNormal(loc=0.0, scale=1.0, a=-1.0, b=1.0)
samples = trunc_norm.sample((1000,))
print(f"采样范围: [{samples.min():.3f}, {samples.max():.3f}]")  # 在 [-1, 1] 内
```

**应用**: 截断高斯在强化学习中用于 bounded action space (比如机器人控制), Diffusion 模型里偶尔也用于裁剪异常值。

### 110. 第 1 章:概率空间·σ-代数·测度——严谨的概率论基础 - 应用场景 视角

**核心议题**: 本节从应用场景视角切入,系统展开 "第 1 章:概率空间·σ-代数·测度——严谨的概率论基础" 的相关讨论。

**1. 背景与动机**

任何技术或方法的出现都不是孤立的,而是回应特定历史条件下的具体问题。"第 1 章:概率空间·σ-代数·测度——严谨的概率论基础" 的发展也不例外。要理解它,必须回到它出现的那个时间点,看清它要解决的真实问题是什么。当时的主流方案有哪些不足? 它的提出填补了哪些空白? 这些问题的回答,决定了我们今天该如何使用它。

从知识论角度看,**技术演进是问题驱动的**——不是先有方案再找问题,而是先有问题再有方案。这个观察可以帮助我们避免"拿着锤子找钉子"的陷阱,真正把方法用对地方。

历史维度上,我们看到三个规律:

1. **从特殊到一般**: 早期方法往往针对特定场景,后期抽象出通用框架。学习的认知规律也是先掌握具体案例,再抽象出一般模式。这种"自下而上"的学习方式,在机器学习模型的设计里反复出现。

2. **从手工到自动**: 经验规则逐步被数据驱动的方法取代。在早期,很多 AI 系统依赖人工编写的规则。统计学习方法的崛起让"从数据中学习"成为可能。深度学习进一步把特征工程也自动化了。今天的大模型时代,我们看到端到端学习从感知扩展到了推理与生成。

3. **从局部到全局**: 关注单个组件,演进到关注整个系统。早期模型评估只关注单点指标,现在更关注全链路的协同效应。这种"系统视角"的转变,与软件工程从单体架构到微服务架构的演进高度相似。

**2. 应用场景视角的展开**
