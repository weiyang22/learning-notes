## 1. 直觉引入:为什么 CrossEntropy 叫"交叉"熵?

### 1.1 工程师的痛点:这两个 loss 到底什么关系?

打开任何一个 PyTorch 分类项目,你大概率会写:

```python
# 分类
loss = F.cross_entropy(logits, labels)

# 二分类(数值稳定性等价)
loss = F.binary_cross_entropy_with_logits(logits, labels)

# 知识蒸馏
loss = F.kl_div(student_logits, teacher_logits, reduction='batchmean')

# 困惑度
ppl = torch.exp(loss)  # 或者 2 ** (loss / log(2))
```

新人会问:**这些 loss 是什么?它们之间什么关系?为什么 KL 散度不是对称的?为什么我要传 `log_target`?**

更扎心的问题:

- 老板让你做 LLM 评估,你算出 `loss = 2.5`,困惑度是多少?为什么大家用困惑度不用 loss?
- 你做对比学习,InfoNCE loss 写成 `sim(z1, z2) / temperature - log(N)`,它**到底在最大化什么**?
- 你做知识蒸馏,学生模型学老师的分布,loss 是 `KL(student || teacher)` 还是 `KL(teacher || student)`?两个都见过,差在哪?

**这些问题的答案,全部藏在本章**。我们先把"为什么叫'交叉'熵"这个问题彻底搞清楚。

### 1.2 直觉:信息论 = 用概率论度量"信息"

什么是"信息"?直觉上,信息 = **意外程度**。一件事越不可能发生,它发生的时候带的信息就越大。

> "太阳从东边升起" → 信息量 0 (废话)
> "今天北京下雪了" → 信息量中等
> "外星人刚刚降落在天安门" → 信息量爆炸

怎么把"意外程度"翻译成数学?Shannon 的天才观察是:

> **信息量 = 概率的负对数**

$$
h(x) = -\log p(x)
$$

- 概率 $p$ 越大,$\log p$ 越大(负值小),$-\log p$ 越小 → 信息量小
- 概率 $p$ 越小,$\log p$ 越小(负值大),$-\log p$ 越大 → 信息量大

这和直觉完美匹配。**信息是概率的函数**。所以"信息"的概念,本质上就是概率论的延伸。

```text
意外程度    →    概率    →    信息量
"完全可预测"   p = 1      h = -log 1 = 0
"小概率事件"   p = 0.01   h = -log 0.01 ≈ 4.6 (nats)
"几乎不可能"   p = 1e-10  h = -log 1e-10 ≈ 23 (nats)
```

### 1.3 ASCII 可视化:概率 → 信息的桥梁

下面这张图是本章的"核心地图"。从概率出发,可以推导出三个核心概念:**熵、KL 散度、互信息**。这三个概念是同一棵树上的三根枝条,共享一个根系(概率 + 期望)。

```text
                          概率论基础

                          │ p(x)    │  ← 概率分布
                          │ 期望 E  │  ← 积分
                          │ log p   │  ← 负对数
                          └────┬────┘
                               │
            ┌──────────────────┼──────────────────┐
            │                  │                  │
            v                  v                  v
       熵 H(X)           KL 散度 D_KL         互信息 I(X;Y)
     = E[-log p(X)]    = E_p[log(p/q)]    = E_{p(x,y)}[log(p(x,y)/(p(x)p(y)))]
            │                  │                  │
            │                  │                  │
            v                  v                  v

            │                  │                  │

```

**关键洞察**:三个概念都用**期望 + 负对数**来构造。这是 Shannon 信息论的"基因":一旦你接受了"信息 = $-\log p$"和"系统量 = 期望"两个公理,熵/KL/互信息就是**唯一合理的派生**。

### 1.4 案例:为什么"信息"是概率的负对数?

为什么不选别的形式?比如 $h(x) = 1/p(x)$ 或 $h(x) = 1 - p(x)$?这就涉及 Shannon 的公理化推导(完整版见 5-信息论 第 2 章)。这里给一个直觉解释。

**公理 1**:**连续性**。$h(p)$ 是 $p$ 的连续函数。
**公理 2**:**单调性**。概率越小,信息量越大(严格递减)。
**公理 3**:**可加性**。两个独立事件的信息量 = 各自信息量之和。

最关键的公理是**可加性**。如果 $X, Y$ 独立,$p(X, Y) = p(X) p(Y)$,那么:

$$
h(X, Y) = h(X) + h(Y)
$$

要求 $h(p(X) p(Y)) = h(p(X)) + h(p(Y))$。满足这个函数方程的连续单调函数,只有一种(在对数尺度下):

$$
h(p) = -c \log p
$$

其中 $c$ 是一个正常数(只影响单位)。**取 $c = 1$** 就得到 Shannon 的定义。这是为什么"信息"**必须**是负对数。这是唯一满足三条公理的函数形式。

**工程意义**:这个唯一性告诉我们,**没有什么"另一种信息论"**。你看到的所有"信息度量"。熵、KL、互信息、f-散度。都是同一条 DNA 的不同表达。

## 2. 熵的不严格引入:系统有多"乱"?

### 2.1 直觉:熵 = 系统的不确定性

工程师最朴素的熵理解:**熵 = 系统有多"乱"**。一个东西越乱、越不可预测,熵就越大。

**例子 1:硬币 vs 骰子 vs 几乎确定的硬币**

- 公平硬币:正反各 50% → 熵 = 1 bit
- 公平骰子:6 个面各 1/6 → 熵 ≈ 2.58 bits
- 几乎确定的硬币:正面 99.9% → 熵 ≈ 0.0014 bits

骰子比硬币"乱",所以熵更大。**熵衡量的是"平均信息量",也就是平均意外程度**。

**例子 2:天气预报**

- "今天晴" 100% 确定 → 熵 = 0
- "今天晴 70%, 雨 30%" → 熵 ≈ 0.88 bits
- "晴 50%, 雨 50%" → 熵 = 1 bit

越不确定,熵越大。

### 2.2 抛硬币 H=1, 公平骰子 H≈2.58

手算一下,这是最简单的两个熵的例子。

**例 1:抛硬币**

概率分布 $p(\text{正}) = 1/2, p(\text{反}) = 1/2$。

熵的(暂时用非正式)定义为:
$$
H(X) = \sum_x p(x) \cdot (-\log p(x))
$$

手算:
$$
H = (1/2) \cdot (-\log 1/2) + (1/2) \cdot (-\log 1/2) = 2 \cdot (1/2 \cdot \log 2) = \log 2 = 1 \text{ bit}
$$

(底数为 2,单位是 bit;底数为 $e$,单位是 nat。1 bit = $\log_2 e \approx 0.693$ nats。)

**例 2:公平骰子**

概率分布 $p(i) = 1/6, i = 1, ..., 6$。

手算:
$$
H = 6 \cdot (1/6 \cdot (-\log_2 1/6)) = \log_2 6 \approx 2.585 \text{ bits}
$$

这就是**6 面骰子一次投掷的不确定性**,也是"用二进制最少要几个 bit 才能编码一次投掷"的理论下界。

**例 3:不公平硬币**

概率 $p(\text{正}) = p, p(\text{反}) = 1-p$。

熵:
$$
H(p) = -p \log_2 p - (1-p) \log_2 (1-p)
$$

几个特殊值:
- $p = 0.5$: $H = 1$ bit(最乱)
- $p = 0.1$ 或 $0.9$: $H \approx 0.469$ bits
- $p = 0.01$ 或 $0.99$: $H \approx 0.081$ bits
- $p = 0$ 或 $1$: $H = 0$ bits(完全确定)

**结论**:**最公平的硬币熵最大**。这是 §3.4 重要定理(均匀分布熵最大)的雏形。

### 2.4 工程师的第一印象:"熵"在 PyTorch 哪?

你大概率在 PyTorch 里见过这些"熵"相关的函数:

```python
# 1. 分布的熵
import torch.distributions as D
p = D.Bernoulli(probs=torch.tensor([0.5]))
print(p.entropy())  # tensor(0.6931)  ← log 2 (单位 nat)

# 2. Softmax 输出的"预测熵" = 模型对自己预测的不确定性
logits = torch.tensor(`2.0, 1.0, 0.1`)
probs = torch.softmax(logits, dim=-1)
entropy = -(probs * probs.log()).sum(dim=-1)  # = 0.8423
# 这个值大 = 模型对所有类都"差不多确定" = 不确定
# 这个值小 = 模型很确定某个类

# 3. CrossEntropyLoss
loss = F.cross_entropy(logits, torch.tensor([0]))  # = 1.4076
# 这正是 -log(p_0) = -log(softmax(logits)[0])
```

这三种"熵"在数学上**严格不同**,但在直觉上**一脉相承**:
- 分布的熵:这个分布**本身**有多不确定
- 预测熵:模型**对当前样本**的预测有多不确定
- 交叉熵:用**模型分布** $q$ 编码**真实分布** $p$ 的平均代价(§7 展开)

## 3. 熵的严格定义:为什么是 $-\sum p \log p$?

### 3.1 离散熵的定义

**定义 3.1 (Shannon 熵,离散情形)**: 设离散随机变量 $X$ 取值于 $\mathcal{X}$,概率质量函数为 $p(x)$,则 $X$ 的(香农)**熵**定义为:

$$
H(X) = -\sum_{x \in \mathcal{X}} p(x) \log p(x) = \mathbb{E}_{p}\left[-\log p(X)\right]
$$

约定 $0 \log 0 = 0$ (因为 $\lim_{p \to 0^+} p \log p = 0$)。

**两个常用底数**:
- 底数 2:**比特 (bits)**,通信、压缩、信息论论文常用
- 底数 $e$:**奈特 (nats)**,机器学习、统计物理常用(PyTorch 默认)

**换算**: $H_{\text{bits}} = H_{\text{nats}} / \log 2 \approx H_{\text{nats}} / 0.693$

### 3.2 连续熵的定义

**定义 3.2 (微分熵)**: 设连续随机变量 $X$ 有概率密度 $p(x)$,则 $X$ 的**微分熵**定义为:

$$
h(X) = -\int p(x) \log p(x) \, dx = \mathbb{E}_{p}\left[-\log p(X)\right]
$$

**注意**:微分熵的英文是 "differential entropy",**不是** Shannon 熵的直接推广。它可以**取负值**(因为 $p(x)$ 在 $x$ 大时可以大于 1),**也不再有"非负"性质**。这点在第 5 章会详细展开。

**例子**:
- $X \sim \text{Uniform}(0, a)$: $h(X) = \log a$
  - $a < 1$ 时 $h < 0$(反直觉!因为密度 $1/a > 1$)
  - $a = 1$ 时 $h = 0$
- $X \sim \mathcal{N}(\mu, \sigma^2)$: $h(X) = \frac{1}{2}\log(2\pi e \sigma^2) \approx \log \sigma + 1.42$
- $X \sim \text{Exp}(\lambda)$: $h(X) = 1 - \log \lambda$

### 3.3 Shannon 公理推导 (简介, 完整版在 5-信息论 第 2 章)

为什么**必须**是 $-\sum p \log p$?这涉及 Shannon 在 1948 年的原始推导(其实是 Khinchin 1953 严格化)。核心是三个公理 + 唯一性定理。

**公理 1 (连续性)**: $H$ 是概率分布 $p$ 的连续函数。
**公理 2 (单调性)**: 当某事件概率为 1 时, $H = 0$。
**公理 3 (可加性)**: $H(X, Y) = H(X) + H(Y | X)$(链式法则),即"总不确定性 = $X$ 的不确定性 + 知道 $X$ 后 $Y$ 的不确定性"。

**唯一性定理 (Khinchin)**:满足这三条公理的函数,只有一种(在差一个常数倍的意义下):

$$
H(p) = -c \sum p(x) \log p(x)
$$

取 $c = 1$ 就得到 Shannon 熵。**没有"另一种熵"**。**没有"另一种信息论"**。

**工程意义**:这三个公理看似抽象,但每个都对应一个工程直觉:
- 连续性:概率微扰不会让熵跳变(模型 loss 平滑)
- 单调性:完全确定的系统没有信息(预测熵 = 0)
- 可加性:复杂系统 = 子系统之和(可以分解计算)

### 3.4 三个手算例子:均匀、伯努利、正态

**例 1:均匀分布 $\text{Uniform}\{1, ..., K\}$ 的熵**

$p(x) = 1/K$,每个取值的 $-\log p = \log K$。

$$
H = \sum_{x=1}^K \frac{1}{K} \log K = K \cdot \frac{\log K}{K} = \log K
$$

**结果**: $H = \log K$ bits。

- $K = 2$(硬币): $H = 1$ bit ✓
- $K = 6$(骰子): $H = \log 6 \approx 2.585$ bits ✓
- $K = 256$(字节): $H = 8$ bits = 1 byte ✓

**这个公式是 Huffman 编码的理论下界**:对 $K$ 个等概率符号,最少需要 $\log_2 K$ bits。

**例 2:Bernoulli 分布的熵**

$p(0) = 1 - p, p(1) = p$。

$$
H(p) = -p \log p - (1-p) \log(1-p)
$$

手算几个值:
- $p = 0.5$: $H = 0.5 \cdot 1 + 0.5 \cdot 1 = 1$ bit
- $p = 0.1$: $H = -0.1 \log 0.1 - 0.9 \log 0.9 = 0.1 \cdot 3.32 + 0.9 \cdot 0.152 = 0.469$ bits
- $p = 0$: $H = 0$
- $p = 1$: $H = 0$

**关键性质**:
- $H(p) = H(1 - p)$(关于 $p = 0.5$ 对称)
- $H(0) = H(1) = 0$(完全确定)
- $H(0.5) = 1$(最乱)
- $H$ 在 $[0, 1]$ 上是**凹函数**(这点在第 5 章 Jensen 不等式处会用)

**例 3:正态分布 $\mathcal{N}(\mu, \sigma^2)$ 的微分熵**

$$
h(X) = \frac{1}{2}\log(2\pi e \sigma^2) = \frac{1}{2}\log(2\pi e) + \log \sigma \approx 1.42 + \log \sigma \text{ (nats)}
$$

**手算**:
- $\sigma = 1$: $h = \frac{1}{2}\log(2\pi e) \approx 1.42$ nats
- $\sigma = 2$: $h = \frac{1}{2}\log(2\pi e \cdot 4) \approx 1.42 + \log 2 \approx 2.12$ nats
- $\sigma = 0.5$: $h = 1.42 + \log 0.5 \approx 0.73$ nats

**注意**:$\sigma$ 越大,熵越大。**标准差大的分布更"散",更不确定**。

**重要事实**:对于所有**固定方差**的连续分布,正态分布的微分熵**最大**。这是高斯分布在变分推断、扩散模型、最大熵模型中无处不在的根因。

### 3.5 性质:非负、凹、均匀最大

**性质 1:非负** (离散情形)

$$
H(X) \geq 0
$$

证明:$-\log p(x) \geq 0$(因为 $0 \leq p(x) \leq 1$),所以 $H = \sum p(x) \cdot (-\log p(x)) \geq 0$。✓

等号成立当且仅当 $X$ 是**确定性的**(某个 $p(x) = 1$)。**连续情形的微分熵没有这个性质**。

**性质 2:凹性** (离散情形)

$H$ 是 $p$ 的**凹函数**。这意味着:
- 凸组合分布的熵 $\geq$ 各分布熵的凸组合
- 在第 5 章讲 Jensen 不等式时,这是关键工具

**性质 3:均匀分布最大** (离散, $\mathcal{X}$ 有限)

设 $\mathcal{X}$ 有限,$|\mathcal{X}| = K$。则:

$$
H(X) \leq \log K
$$

等号成立当且仅当 $X$ 在 $\mathcal{X}$ 上**均匀分布**。

**证明思路**:用 Jensen 不等式,$H = -\sum p \log p = \sum p \log(1/p) \leq \log(\sum p \cdot (1/p)) = \log K$。

**工程意义**:
- 二分类最大熵 = 1 bit($K = 2$)
- 1000 类分类最大熵 = $\log_2 1000 \approx 9.97$ bits
- 这就是为什么**随机初始化的神经网络 CrossEntropy ≈ log K**:因为输出接近均匀分布

### 3.6 案例:为什么 LLM 评估用 bpb (bits per byte)?

LLM 评估有多个指标:NLL、perplexity、bpb (bits per byte)、bpc (bits per character)、BPW (bits per word)。它们有什么关系?

**bpb 的定义**:
$$
\text{bpb} = \frac{H(\text{model})}{\log 2 \cdot \text{bytes}}
$$

也就是**每个字节平均要多少 bits 编码**。把 NLL 从 nats 转换到 bits,再除以总字节数。

**为什么用 bpb 不用 perplexity?**

1. **跨数据集可比**:perplexity = $2^H$,和"事件空间大小"耦合;bpb 归一化到字节,不同文本(中文 vs 英文 vs 代码)可以比
2. **人类直觉对齐**:英文文本 bpb ≈ 1.0(每个字节 1 bit,接近压缩极限),中文 bpb ≈ 0.5(中文信息密度高)
3. **压缩比直接对应**:bpb = log(压缩后大小 / 原始大小)

**例子**:GPT-2 在 WikiText-103 上 bpb ≈ 0.92。这说明模型能用 0.92 bit 编码每个字节,接近 ZIP 压缩的水平(0.5-1.5 bit/byte 区间)。

### 3.7 本节回顾

**你刚建立的直觉**:
1. 离散熵 $H(X) = -\sum p \log p$, 连续熵(微分熵) $h(X) = -\int p \log p \, dx$
2. Shannon 公理(连续、单调、可加)唯一确定 $-\log$ 形式
3. 均匀分布熵最大 = $\log K$ bits, 正态分布微分熵最大(给定方差)
4. 离散熵非负, 微分熵可负
5. LLM 用 bpb 而非 perplexity 是为了跨数据集可比

**下一步**:单一变量太简单,我们来看**两个变量**。联合熵和条件熵。这是互信息的基石。

## 4. 联合熵·条件熵·链式法则

### 4.1 联合熵的定义

**定义 4.1 (联合熵)**: 联合分布 $(X, Y)$ 的熵:

$$
H(X, Y) = -\sum_{x, y} p(x, y) \log p(x, y) = \mathbb{E}_{p(x, y)}[-\log p(X, Y)]
$$

直观上:把 $(X, Y)$ 看作一个**单一随机变量**,取值是 $\mathcal{X} \times \mathcal{Y}$。联合熵就是这个"超变量"的不确定性。

**离散例子**:$X, Y$ 都取 $\{0, 1\}$ 四个组合,等概率 $1/4$。
$$
H(X, Y) = 4 \cdot (1/4) \cdot \log 4 = \log 4 = 2 \text{ bits}
$$

这正是"两个独立公平硬币"的熵。

### 4.2 条件熵的定义

**定义 4.2 (条件熵)**: 给定 $Y = y$ 时 $X$ 的熵,然后对 $y$ 求期望:

$$
H(X | Y) = \mathbb{E}_{y \sim p(y)}[H(X | Y = y)] = -\sum_y p(y) \sum_x p(x | y) \log p(x | y)
$$

化简:
$$
H(X | Y) = -\sum_{x, y} p(x, y) \log p(x | y)
$$

直观上:**知道 $Y$ 后,$X$ 还剩多少不确定性**。

### 4.3 链式法则:联合熵的可加分解

**定理 4.3 (链式法则)**:
$$
H(X, Y) = H(X) + H(Y | X) = H(Y) + H(X | Y)
$$

直观:**总不确定性 = $X$ 的不确定性 + 知道 $X$ 后 $Y$ 还剩的不确定性**。

**手算例 1**: $X, Y$ 独立, $X \sim \text{Bernoulli}(0.5), Y \sim \text{Bernoulli}(0.5)$。

$$
H(X, Y) = H(X) + H(Y | X) = 1 + 1 = 2 \text{ bits}
$$

独立情形下,条件熵 = 边际熵,链式法则退化为"两者熵之和"。

**手算例 2**: $X = Y$(完全相关,都 $\sim \text{Bernoulli}(0.5)$)。

$$
H(X, Y) = H(X) + H(Y | X) = 1 + 0 = 1 \text{ bit}
$$

完全相关时,知道 $X$ 就知道 $Y$,条件熵 = 0。**联合熵 = 边际熵**(因为 $(X, Y)$ 实际上就一个变量)。

**手算例 3**: $X$ 独立, $Y = X$ XOR(异或)。$X, Z$ 都 $\sim \text{Bernoulli}(0.5), Y = X \oplus Z$。

$p(x, y)$ 表:
```text
       Y=0   Y=1
X=0   1/4    1/4
X=1   1/4    1/4
```
均匀分布,所以 $H(X, Y) = 2$ bits。

$H(X) = 1$ bit,$H(Y) = 1$ bit。

$H(Y | X)$: 知道 $X$ 后,$Y = X \oplus Z$,而 $Z$ 独立, 所以 $Y | X$ 仍是 Bernoulli(0.5),$H(Y | X) = 1$ bit。

链式法则验证: $H(X) + H(Y | X) = 1 + 1 = 2 = H(X, Y)$ ✓

**关键观察**:虽然 $X$ 和 $Y$ 联合起来是均匀的(熵最大),但 $X$ 和 $Y$ 不是独立的。$Y$ 由 $X$ 决定(经由 $Z$)。独立 vs 相关看的是 $p(x, y) = p(x)p(y)$。这里 $p(x=0, y=0) = 1/4 \neq 1/2 \cdot 1/2 = 1/4$ 。等等,这恰好等于!所以 $X, Y$ 其实**是独立**的。让我换一个例子。

**手算例 4(修正)**: $X \sim \text{Bernoulli}(0.5), Z \sim \text{Bernoulli}(0.5)$, $Y = X$ (完全相关)。

```text
       Y=0   Y=1
X=0   1/2    0
X=1   0      1/2
```

$H(X, Y) = -2 \cdot (1/2) \log(1/2) = 1$ bit。$H(Y | X) = 0$(知道 $X$ 就知道 $Y$)。$H(X) + H(Y | X) = 1 + 0 = 1 = H(X, Y)$ ✓

### 4.4 三个手算例子(详细)

**例 1:骰子和硬币独立**

$X \in \{1, ..., 6\}$ 均匀, $Y \in \{0, 1\}$ 均匀,独立。

$H(X) = \log 6 \approx 2.585$ bits
$H(Y) = 1$ bit
$H(X, Y) = \log 6 + 1 \approx 3.585$ bits
$H(X | Y) = H(X) = 2.585$ bits(独立, $Y$ 不给 $X$ 任何信息)
$H(Y | X) = H(Y) = 1$ bit

**例 2:相同变量**

$Y = X$。$H(X) = 1$ bit(假设 $X \sim \text{Bernoulli}(0.5)$)。

$H(X, Y) = H(X) = 1$ bit(因为 $(X, Y)$ 实际上是一个变量)
$H(Y | X) = 0$(知道 $X$ 就知道 $Y$)
$H(X | Y) = 0$

**例 3:有限 Markov 链**

$Y \to X$: $Y$ 取 $\{0, 1\}$ 各 0.5;给定 $Y$,$X$ 是 Bernoulli($p = 0.8$ if $Y = 1$ else $0.2$)。

$H(X) = ?$
$p(X = 1) = 0.5 \cdot 0.8 + 0.5 \cdot 0.2 = 0.5$(对称)
所以 $H(X) = 1$ bit。

$H(Y) = 1$ bit(均匀)。

$H(X | Y) = 0.5 \cdot H(X | Y=0) + 0.5 \cdot H(X | Y=1) = 0.5 \cdot H_2(0.2) + 0.5 \cdot H_2(0.8)$
其中 $H_2(p) = -p \log p - (1-p) \log(1-p)$ 是 Bernoulli 熵。
$H_2(0.2) = H_2(0.8) \approx 0.722$
$H(X | Y) = 0.5 \cdot 0.722 + 0.5 \cdot 0.722 = 0.722$ bits

$H(X, Y) = H(Y) + H(X | Y) = 1 + 0.722 = 1.722$ bits

**直觉**:
- 单独看 $X$ 或 $Y$, 熵都是 1 bit(看起来都不确定)
- 但**联合**起来 1.722 bits,**没有** $1 + 1 = 2$ 那么高
- 因为 $X$ 和 $Y$ 相关,联合不确定性**小于**独立之和
- 节省的 $2 - 1.722 = 0.278$ bits,正是**互信息** $I(X; Y)$ 的值!(§5 展开)

### 4.5 案例:为什么"联合熵"在多模态学习中重要?

多模态学习(CLIP、ImageBind、DALL-E)的核心问题:**图像和文本的"共享信息"是多少?**

设 $I$ = 图像, $T$ = 文本。两者联合熵 $H(I, T)$ 包含了:
- 图像独有的信息(纹理、光照)
- 文本独有的信息(句法、措辞)
- **共享信息**(语义内容)

直觉上, $H(I, T) = H(I) + H(T) - I(I; T)$。**互信息**就是它们"重叠"的部分(§5)。

多模态预训练的目标之一:**最大化 $I(\text{image}; \text{text})$**,即让两个模态的表征**保留尽可能多的共享信息**。这是 CLIP 用对比学习 (InfoNCE) 的理论根据。

**ASCII 可视化**:用韦恩图表示信息。

```text
   ┌──────────────────┐
   │ H(X)             │
   │   ┌──────────────┼──────────────┐
   │   │              │              │
   │   │  X 独有      │ I(X;Y)       │ Y 独有
   │   │              │              │
   │   │  ┌───────────┼───┐          │
   │   │  │           │   │          │
   └───┼──┘           └───┼──────────┘
       │  H(X|Y)         │ H(Y|X)
       │  (知道Y后X还剩)  │  (知道X后Y还剩)

H(X, Y) = H(X) + H(Y | X) = H(Y) + H(X | Y)
        = H(X) ∪ H(Y) ∪ I(X; Y) 的并集
```

**关键不变量**:
- $H(X, Y) \leq H(X) + H(Y)$(相关时取等)
- $H(X, Y) \geq \max(H(X), H(Y))$(因为联合至少包含单个)

### 4.6 链式法则的推广:多于两个变量

**推广到 $n$ 个变量**:
$$
H(X_1, X_2, \ldots, X_n) = \sum_{i=1}^n H(X_i | X_1, \ldots, X_{i-1})
$$

**手算例**:三元 Markov 链 $X_1 \to X_2 \to X_3$。

$H(X_1, X_2, X_3) = H(X_1) + H(X_2 | X_1) + H(X_3 | X_1, X_2)$
              $= H(X_1) + H(X_2 | X_1) + H(X_3 | X_2)$ (Markov 性质: $X_3 \perp X_1 | X_2$)

**工程应用**:
- **自回归语言模型**: $\log p(x_1, ..., x_n) = \sum_i \log p(x_i | x_{<i})$,这是**链式法则的直接应用**
- **PixelCNN**: 图像像素按行列展开为序列,用链式法则 $p(\text{image}) = \prod_i p(\text{pixel}_i | \text{previous})$
- **Speech Transformer**: 音频帧的自回归建模

**没学过链式法则,就不会理解为什么 LLM 可以"逐个 token 生成"**。

### 4.7 本节回顾

**你刚建立的直觉**:
1. 联合熵 = 把 $(X, Y)$ 看作一个超变量
2. 条件熵 = 知道 $Y$ 后 $X$ 还剩多少不确定性
3. 链式法则: $H(X, Y) = H(X) + H(Y | X)$,是"逐步拆解"联合熵的工具
4. 自回归模型 = 链式法则 + 神经网络
5. 多模态学习的核心 = 提取 $X$ 和 $Y$ 的共享信息(互信息)

**下一步**:终于到本章最核心的概念。互信息。它是"知道 $Y$ 后,$X$ 的不确定性减少量"的精确度量。

## 5. 互信息:两个变量"共享"多少信息?

### 5.1 互信息的定义

**定义 5.1 (互信息)**: 两个随机变量 $X, Y$ 的**互信息**:

$$
I(X; Y) = H(X) - H(X | Y) = H(Y) - H(Y | X)
$$

等价形式:
$$
I(X; Y) = H(X) + H(Y) - H(X, Y) = \mathbb{E}_{p(x, y)}\left[\log \frac{p(X, Y)}{p(X) p(Y)}\right]
$$

**直观**:
- 第一种形式:**知道 $Y$ 后, $X$ 的不确定性减少量**
- 第二种形式:**总不确定性减去联合不确定性**(重叠的部分)
- 第三种形式:**联合分布与"独立假设"的 KL 散度**(关键联系,见 §6)

互信息衡量"两个变量**相关**到什么程度"。

### 5.2 性质:$I(X; Y) \geq 0$

**定理 5.2 (非负性)**: $I(X; Y) \geq 0$,等号成立当且仅当 $X$ 和 $Y$ 独立。

**证明**:用 KL 散度非负(§6.2):
$$
I(X; Y) = D_{\text{KL}}(p(x, y) \| p(x) p(y)) \geq 0
$$

**手算例**:刚才 Markov 链 $Y \to X$。
- $I(X; Y) = H(X) - H(X | Y) = 1 - 0.722 = 0.278$ bits
- 验证: $H(X) + H(Y) - H(X, Y) = 1 + 1 - 1.722 = 0.278$ bits ✓

### 5.3 互信息与熵的韦恩图

这是信息论最有名的图。

```text
        H(X)              H(Y)
       ┌────┐           ┌────┐
       │    │           │    │
       │    ├─────┬─────┤    │
       │    │     │     │    │
       │    │ I(X;Y)     │    │
       │    │     │     │    │
       │    ├─────┴─────┤    │
       │    │           │    │
       └────┘           └────┘
              H(X|Y)        H(Y|X)
```

**读法**:
- 左圆 = $H(X)$
- 右圆 = $H(Y)$
- 重叠 = $I(X; Y)$(互信息)
- 左圆独占 = $H(X | Y)$(知道 $Y$ 后 $X$ 还剩)
- 右圆独占 = $H(Y | X)$(知道 $X$ 后 $Y$ 还剩)
- 全图 = $H(X) + H(Y) - I(X; Y) = H(X, Y)$

### 5.4 五个手算例子

**例 1:独立**

$X, Y$ 独立。$I(X; Y) = 0$(韦恩图不重叠)。

**例 2:完全相关 $Y = X$**

$I(X; Y) = H(X) - H(X | X) = H(X) - 0 = H(X)$。

**例 3:完全独立 $\to$ 完全相关(连续过渡)**

设 $Y = X \oplus Z$, $Z \sim \text{Bernoulli}(\epsilon)$, $X \sim \text{Bernoulli}(0.5)$, $\epsilon$ 是"噪声率"。

- $\epsilon = 0$: $Y = X$, $I = 1$ bit
- $\epsilon = 0.5$: $Y$ 独立于 $X$, $I = 0$ bit
- $\epsilon = 0.1$: $I = 1 - H_2(0.1) = 1 - 0.469 = 0.531$ bits

**直觉**:**噪声率越高,互信息越低**。这和"信道容量"的物理意义一致。噪声信道损失信息。

**例 4:高斯相关**

$X, Y \sim \mathcal{N}(0, 1)$, $\text{Corr}(X, Y) = \rho$。

$$
I(X; Y) = -\frac{1}{2}\log(1 - \rho^2) \text{ nats}
$$

- $\rho = 0$: $I = 0$(独立)
- $\rho = 0.5$: $I = -\frac{1}{2}\log(0.75) \approx 0.144$ nats
- $\rho = 0.9$: $I = -\frac{1}{2}\log(0.19) \approx 0.831$ nats
- $\rho = 1$: $I = \infty$(完全相关,知道一个等于知道另一个)

**直觉**:**相关系数越高,互信息越大**。但**不是线性关系**。$\rho = 0.99$ 和 $\rho = 0.999$ 的互信息差距可以很大。

**例 5:多模态**

设图像 $I$ 和文本 $T$ 共享"猫"的语义,但各自有独立噪声(纹理、措辞)。

$I(I; T) \approx 1.5$ bits(假设"猫"语义占了 1.5 bit 信息)

预训练 CLIP 的目标:**让 $\hat I, \hat T$(模型表征)的互信息尽量接近 $I(I; T)$**。

### 5.5 案例:为什么 InfoNCE loss 是互信息下界?

对比学习(CLIP、SimCSE、MoCo)的核心 loss:

$$
\mathcal{L}_{\text{InfoNCE}} = -\mathbb{E}\left[\log \frac{\exp(s(z_i, z_j) / \tau)}{\sum_{k=1}^{N} \exp(s(z_i, z_k) / \tau)}\right]
$$

其中 $z_i, z_j$ 是正样本对, $z_k$ 是负样本, $s$ 是相似度, $\tau$ 是温度。

**核心定理 (Oord et al. 2018, Poole et al. 2019)**:

$$
I(X; Y) \geq \log(N) - \mathcal{L}_{\text{InfoNCE}}
$$

**手算例**:取 $N = 64$ 负样本, $\mathcal{L} = 4.0$。则互信息下界 $I \geq \log 64 - 4 = 4.158 - 4 = 0.158$ nats。

**直觉**:
- $\mathcal{L}$ 越小(模型对正样本对的相似度评分越高),互信息下界越大
- $N$ 越大(更多负样本),下界越紧
- 实际中,InfoNCE loss 是 InfoNCE **互信息估计**的副产品

**工程启示**:
- **温度 $\tau$** 太小 → 相似度差异放大 → loss 容易饱和 → 估计不准
- **温度 $\tau$** 太大 → 相似度差异压缩 → loss 难收敛
- **负样本数 $N$** 越大 → 互信息下界越紧 → 但计算量线性增长

**SimCSE / CLIP 的 $\tau$ 选择**(通常 $\tau = 0.05 \sim 0.1$)是一个工程经验值,信息论告诉我们"它必须存在"。

### 5.6 案例:为什么"特征选择"用互信息?

**场景**:你有一个数据集,有 100 个特征,你想选 top 10 训练模型。

**朴素方法**:用相关系数、决策树重要性、L1 系数。但这些都不能保证"选出的特征**对预测目标有最大信息**"。

**互信息方法**:
- 对每个特征 $X_i$,计算 $I(X_i; Y)$(和目标 $Y$ 的互信息)
- 选 $I$ 最大的 $K$ 个

**为什么更好**:
- 互信息捕捉**任意**统计依赖(不是只线性)
- $I = 0$ ⇔ 独立(完美的"无关"度量)
- $I$ 大 ⇔ 知道 $X_i$ 大幅减少 $Y$ 的不确定性(对预测最有价值)

**mRMR 准则** (Peng et al. 2005): 选特征时同时考虑 $I(X_i; Y)$(相关性)和**与已选特征的平均相似度** $\frac{1}{|S|} \sum_{X_j \in S} I(X_i; X_j)$(冗余性):

$$
\text{mRMR}(X_i) = I(X_i; Y) - \frac{1}{|S|} \sum_{X_j \in S} I(X_i; X_j)
$$

**工程应用**:
- 搜推场景:从 1000 个用户/物品特征选 top 50 训练
- 生物信息学:从 20000 个基因选 top 100 做疾病预测
- 金融风控:从 200 个衍生指标选 top 30 训练

### 5.7 互信息估计:MINE 与 InfoNCE 的联系

**MINE (Mutual Information Neural Estimation, Belghazi et al. 2018)**:

$$
\hat I(X; Y) = \sup_T \mathbb{E}_{p(x, y)}[T(x, y)] - \log \mathbb{E}_{p(x) p(y)}[e^{T(x, y)}]
$$

其中 $T$ 是一个神经网络(鉴别器),$p(x, y)$ 是联合分布,$p(x) p(y)$ 是边缘分布的乘积。

**直觉**:用神经网络 $T$ 学习一个"打分函数",让正样本对的分数高,负样本对(打散后的边缘乘积)的分数低。**互信息 = 最大的分数差**。

**MINE vs InfoNCE**:
- MINE:理论上界紧,但训练不稳定(Donsker-Varadhan 估计)
- InfoNCE:下界(不是上界),但训练稳定
- 工程上 InfoNCE 更常用, MINE 多用于研究

**完整推导见 5-信息论 第 3 章**。

### 5.8 条件互信息与信息瓶颈

**条件互信息**: 在 $Z$ 给定下, $X$ 和 $Y$ 的互信息:

$$
I(X; Y | Z) = H(X | Z) - H(X | Y, Z) = \mathbb{E}_{p(z)}[D_{\text{KL}}(p(x, y | z) \| p(x | z) p(y | z))]
$$

**信息瓶颈 (IB, Tishby et al. 1999)**: 给定 $X$,找一个表征 $Z$,使:

$$
\min_{Z} I(X; Z) - \beta I(Z; Y)
$$

**直觉**:
- $I(X; Z)$: 表征保留了 $X$ 的多少信息(应**最小化**。压缩)
- $I(Z; Y)$: 表征对预测 $Y$ 有多少帮助(应**最大化**。预测)

**应用**:深度学习的信息瓶颈理论、SimCLR 表征压缩、神经网络的"遗忘曲线"分析。

### 5.9 本节回顾

**你刚建立的直觉**:
1. 互信息 = 知道 $Y$ 后 $X$ 的不确定性减少量 = 韦恩图的重叠
2. $I(X; Y) \geq 0$,等号当且仅当独立
3. 高斯相关 $I = -\frac{1}{2}\log(1 - \rho^2)$
4. InfoNCE loss 是 $I$ 的**下界**: $I \geq \log N - \mathcal{L}$
5. MINE 是 $I$ 的**上界**(通过 Donsker-Varadhan 估计)
6. 特征选择 = 选 $I(X_i; Y)$ 大的;信息瓶颈 = 同时优化压缩和预测

**下一步**:互信息的"近亲"。KL 散度。它是**两个分布之间的距离**度量,虽然**不满足三角不等式**。

## 6. KL 散度:两个分布"差多远"?

### 6.1 KL 散度的定义

**定义 6.1 (KL 散度 / 相对熵)**: 两个分布 $p, q$(假设 $p$ 绝对连续于 $q$,或 $q(x) = 0 \Rightarrow p(x) = 0$),**从 $p$ 到 $q$** 的 KL 散度:

$$
D_{\text{KL}}(p \| q) = \mathbb{E}_{p(x)}\left[\log \frac{p(x)}{q(x)}\right] = \int p(x) \log \frac{p(x)}{q(x)} dx
$$

(离散情形用求和。)

**约定**:如果存在 $x$ 使 $p(x) > 0$ 但 $q(x) = 0$, $D_{\text{KL}} = \infty$。

**直观**:**用 $q$ 编码 $p$ 的样本,平均多花的 bits 数**(如果用 $p$ 自己编码,平均就是 $H(p)$;用 $q$ 编码,平均是 $-\sum p \log q = H(p) + D_{\text{KL}}(p \| q)$)。

### 6.2 性质:非负、非对称

**性质 1:非负** $D_{\text{KL}}(p \| q) \geq 0$,等号当且仅当 $p = q$。

**证明 (Jensen 不等式)**:
$$
D_{\text{KL}}(p \| q) = -\sum p(x) \log \frac{q(x)}{p(x)} \geq -\log \sum p(x) \cdot \frac{q(x)}{p(x)} = -\log 1 = 0
$$

(用了 $\log$ 是凹函数, $-\log$ 是凸函数, Jensen 不等式反向。)

**性质 2:非对称** $D_{\text{KL}}(p \| q) \neq D_{\text{KL}}(q \| p)$(通常)。

**手算反例**: 设 $p = (0.5, 0.5)$, $q = (0.9, 0.1)$。

$$
D_{\text{KL}}(p \| q) = 0.5 \log(0.5/0.9) + 0.5 \log(0.5/0.1) = 0.5 \log(0.556) + 0.5 \log 5
$$
$$
= 0.5 \cdot (-0.588) + 0.5 \cdot 1.609 = -0.294 + 0.805 = 0.511 \text{ bits}
$$

$$
D_{\text{KL}}(q \| p) = 0.9 \log(0.9/0.5) + 0.1 \log(0.1/0.5)
$$
$$
= 0.9 \log 1.8 + 0.1 \log 0.2 = 0.9 \cdot 0.588 + 0.1 \cdot (-2.322) = 0.529 - 0.232 = 0.297 \text{ bits}
$$

$D_{\text{KL}}(p \| q) = 0.511 \neq 0.297 = D_{\text{KL}}(q \| p)$。**不对称!** ✓

**性质 3:不满足三角不等式** $D_{\text{KL}}$ **不是距离**(没有对称性和三角不等式)。

**工程意义**:
- 不能说 "$p$ 到 $q$ 的距离等于 $q$ 到 $p$ 的距离"
- 不能用三角不等式做"传递性"估计
- 想用"对称距离" → JS 散度、Wasserstein 距离

### 6.3 五个手算例子

**例 1:两个 Bernoulli**

$p = \text{Bernoulli}(0.5)$, $q = \text{Bernoulli}(0.5)$。
$$
D_{\text{KL}}(p \| q) = 0
$$
(两个分布相同。)

**例 2:$p$ 公平, $q$ 偏**

$p = (0.5, 0.5)$, $q = (0.9, 0.1)$。
$$
D_{\text{KL}}(p \| q) = 0.5 \log(0.5/0.9) + 0.5 \log(0.5/0.1) \approx 0.511 \text{ bits}
$$
"用偏向 $0.9$ 的分布去编码公平的硬币,每个样本多花 0.511 bit"。

**例 3:两个高斯**

$p = \mathcal{N}(\mu_1, \sigma_1^2)$, $q = \mathcal{N}(\mu_2, \sigma_2^2)$。

$$
D_{\text{KL}}(p \| q) = \log \frac{\sigma_2}{\sigma_1} + \frac{\sigma_1^2 + (\mu_1 - \mu_2)^2}{2\sigma_2^2} - \frac{1}{2}
$$

**手算**: $\mu_1 = 0, \sigma_1 = 1$, $\mu_2 = 0, \sigma_2 = 2$。

$$
D_{\text{KL}} = \log 2 + \frac{1}{0} \cdot \ldots = \log 2 + \frac{1 + 0}{8} - 0.5 = 0.693 + 0.125 - 0.5 = 0.318 \text{ nats}
$$

**直觉**:让一个 $\mathcal{N}(0, 1)$ "以为"自己来自 $\mathcal{N}(0, 4)$,多花 0.318 nats。

**例 4:Dirichlet-KL**

两个 Dirichlet 分布 $\text{Dir}(\alpha), \text{Dir}(\beta)$:

$$
D_{\text{KL}}(\text{Dir}(\alpha) \| \text{Dir}(\beta)) = \log \frac{B(\beta)}{B(\alpha)} + \sum_{i=1}^K (\alpha_i - \beta_i)[\psi(\alpha_i) - \psi(\alpha_0)]
$$

(其中 $B$ 是 Beta 函数, $\psi$ 是 digamma 函数。) 公式复杂,但工程上**Theta 算法 + Dirichlet 后验**会用到。

**例 5:同分布的 KL = 0**

任何 $p = q$ 都有 $D_{\text{KL}}(p \| q) = 0$。但**反之不成立**。理论上 $D_{\text{KL}} = 0$ 也可能在 $p \neq q$ 时(如果它们支撑集互补,实际 $D_{\text{KL}}$ 是 $\infty$ 而不是 0)。

**工程检查**:训练 KL 散度,看到 loss 接近 0,**不要立刻认为训练成功**。检查 $p, q$ 的支撑集是否匹配,否则 $D_{\text{KL}}$ 是 $\infty$ 不是 0。

### 6.4 案例:为什么 VAE loss 中有 KL 项?

VAE 训练 loss(详见第 10 章):

$$
\mathcal{L}_{\text{VAE}} = -\mathbb{E}_{q(z|x)}[\log p(x|z)] + D_{\text{KL}}(q(z|x) \| p(z))
$$

**第一项** = 重建项(让 $p(x|z)$ 还原 $x$)。
**第二项** = KL 正则(让 $q(z|x)$ 接近先验 $p(z) = \mathcal{N}(0, I)$)。

**为什么是 $D_{\text{KL}}(q \| p)$ 而不是 $D_{\text{KL}}(p \| q)$?**

回看 ELBO 推导(第 10 章 §3.1):
$$
\log p(x) \geq \mathbb{E}_{q(z|x)}[\log p(x|z)] - D_{\text{KL}}(q(z|x) \| p(z))
$$

最小化 $-ELBO$ = 最大化 ELBO = 最大化 $\log p(x)$ 的下界,**用** $D_{\text{KL}}(q \| p)$ **的方向**(变分分布 → 先验)。

**反向会怎样?** $D_{\text{KL}}(p(z) \| q(z|x))$ 没有变分下界的意义,只是两个分布的距离(但因为 $p(z)$ 不依赖 $x$,这个方向没有优化目标)。

**工程意义**:
- $D_{\text{KL}}(q \| p)$:**Mode-seeking**(变分分布被推向先验的某个 mode,可能漏掉其他 mode)
- $D_{\text{KL}}(p \| q)$:**Mode-covering**(变分分布覆盖先验的所有 mode,包括不重要的)
- VAE 用前者,会导致**后验坍缩**(posterior collapse)
- 解决:**β-VAE**、**退火 KL**、**free bits**

### 6.5 案例:为什么 Mode Collapse 是 KL 散度的反方向?

**Mode Collapse**: GAN 生成器只产出几种样本(模式坍缩),不覆盖真实数据的所有模式。

**为什么和 KL 有关?**

GAN 训练是极小极大:
$$
\min_G \max_D \mathbb{E}_{p_{\text{data}}}[\log D(x)] + \mathbb{E}_{p_z}[\log(1 - D(G(z)))]
$$

如果用 $D_{\text{KL}}$ 替换 → 不稳定(不对称 + 极端值)。
如果用 **JS 散度**(对称版 KL) → 经典 GAN loss 的近似(§8)。

**Mode Collapse 的 KL 解读**:
- 数据分布 $p_{\text{data}}$ 是多峰的
- 生成器分布 $p_G$ 选了 $p_{\text{data}}$ 的一个 mode
- $D_{\text{KL}}(p_{\text{data}} \| p_G) \approx \infty$(因为 $p_G$ 在其他 mode 上 = 0)
- $D_{\text{KL}}(p_G \| p_{\text{data}}) < \infty$(但很小,只覆盖一个 mode)

**这两个不对称值**正是 mode collapse 的数学症状。

**Wasserstein GAN 的动机**: 用 Wasserstein 距离代替 KL/JS,因为 Wasserstein 满足三角不等式,即使 $p_G$ 和 $p_{\text{data}}$ 不重叠也能给出有意义的梯度。

### 6.6 案例:为什么知识蒸馏用 KL 散度?

**场景**:你训练了一个大模型(教师),现在想训练一个小模型(学生)来"模仿"教师的输出。

**学生 loss**(Hinton 2015):
$$
\mathcal{L}_{\text{distill}} = \alpha \mathcal{L}_{\text{CE}}(z_s, y) + (1 - \alpha) T^2 \cdot D_{\text{KL}}(\text{softmax}(z_s / T) \| \text{softmax}(z_t / T))
$$

其中 $T$ 是温度, $z_s, z_t$ 是学生/教师的 logits。

**为什么是 $D_{\text{KL}}(p_s \| p_t)$?**

- 学生输出 $p_s$ 应该**逼近**教师输出 $p_t$
- $D_{\text{KL}}(p_s \| p_t)$ 衡量"用 $p_t$ 的视角看 $p_s$ 的代价"
- 等价于交叉熵: $H(p_s, p_t) = H(p_s) + D_{\text{KL}}(p_s \| p_t)$

**为什么用温度 $T$?**

- $T$ 大 → softmax 平滑 → 暴露教师的"软知识"(类别间关系)
- $T = 1$ → 标准 softmax → 硬标签
- 工程经验: $T = 3 \sim 20$ 蒸馏效果最好

**为什么学生用 $p_s$ 在前?** 因为学生是要优化的对象,$D_{\text{KL}}(p_s \| p_t)$ 给出"学生应该学什么"的方向(梯度方向)。

### 6.7 数值稳定性:为什么 `F.kl_div` 接受 `log_target`?

PyTorch 的 KL 散度函数:

```python
torch.nn.functional.kl_div(input, target, reduction='mean')
# input: log probabilities (shape = [N, *])
# target: probabilities OR log probabilities
```

**坑**:直接传 $p, q$ 会出问题。

**正确做法**:传 `log(p)`, `log(q)` 而不是 $p, q$。

```python
# ❌ 错:数值下溢
loss = F.kl_div(p, q)  # log(0) = -inf

# ✅ 对:用 log 输入
loss = F.kl_div(p.log(), q.log())  # 算 log(p) - log(q) = log(p/q)
```

**为什么**:KL 散度计算 $\log(p/q) = \log p - \log q$,直接算 $p/q$ 容易数值下溢(尤其 $p \ll q$ 时)。用 log 减法稳定。

**工程经验**:
- 永远传 `log_target=True`(默认值)
- 或者用 `torch.distributions.kl.kl_divergence(p, q)` 显式计算

### 6.8 性质:KL 散度 = 互信息 = 交叉熵 - 熵

**核心等式**(贯穿全章):

$$
D_{\text{KL}}(p \| q) = H(p, q) - H(p) = \mathbb{E}_{p}[-\log q] - \mathbb{E}_{p}[-\log p]
$$

直观:**用 $q$ 编码 $p$ 比用 $p$ 自己编码多花的 bits**。

**互信息和 KL 的等价**:
$$
I(X; Y) = D_{\text{KL}}(p(x, y) \| p(x) p(y))
$$

直观:**"联合分布"和"独立假设"的距离**。

**交叉熵分解**(§7 展开):
$$
H(p, q) = H(p) + D_{\text{KL}}(p \| q)
$$

**工程意义**:
- 训练分类器最小化交叉熵 = 最小化 KL 散度(因为 $H(p)$ 固定)
- 训练 VAE 最小化 KL = 拉近 $q(z|x)$ 和 $p(z)$
- 训练对比学习最小化 InfoNCE = 最大化互信息(下界)

**这三条 loss 表面不同,本质都是"用一种分布逼近另一种"的 KL 散度问题**。

### 6.9 本节回顾

**你刚建立的直觉**:
1. KL 散度 = 用 $q$ 编码 $p$ 多花的 bits = 期望 $\log(p/q)$
2. 非负、非对称、不满足三角不等式(不是距离)
3. 互信息 = $D_{\text{KL}}(p(x,y) \| p(x)p(y))$, 即"联合 vs 独立"
4. 交叉熵 = 熵 + KL, 训练分类器 = 最小化 KL
5. PyTorch `F.kl_div` 用 log 输入避免下溢

**下一步**:交叉熵。这个深度学习最常用的 loss,其实就是 KL 散度的"重新打包"。

## 7. 交叉熵与困惑度:深度学习的标准损失

### 7.1 交叉熵的定义

**定义 7.1 (交叉熵)**: 分布 $p$ 和 $q$ 的**交叉熵**:

$$
H(p, q) = -\mathbb{E}_{p(x)}[\log q(x)] = -\sum_x p(x) \log q(x)
$$

直观:**用 $q$ 编码 $p$ 样本的平均 bits 数**(没有"用 $p$ 自己"的优化)。

**与 KL 的关系**:
$$
H(p, q) = H(p) + D_{\text{KL}}(p \| q)
$$

**手算例**: $p = (0.5, 0.5)$, $q = (0.9, 0.1)$。

$$
H(p, q) = -0.5 \log 0.9 - 0.5 \log 0.1 = -0.5 \cdot (-0.105) - 0.5 \cdot (-2.303) = 0.053 + 1.151 = 1.204 \text{ bits}
$$

验证: $H(p) = 1$ bit, $D_{\text{KL}}(p \| q) = 0.511$ bits(从 §6.3), $H(p) + D_{\text{KL}} = 1.511$ bits。

等等,1.204 vs 1.511 不对。让我重新算: $\log 0.9 \approx -0.152$(底数 2),$\log 0.1 \approx -3.322$。

$$
H(p, q) = -0.5 \cdot (-0.152) - 0.5 \cdot (-3.322) = 0.076 + 1.661 = 1.737 \text{ bits}
$$

OK, 这次是 1.737。$D_{\text{KL}}(p \| q)$ 我在 §6.3 算的是 0.511 bits,所以 $H(p) + D_{\text{KL}} = 1 + 0.511 = 1.511$ bits。**对不上**。我手算有误。让我重新算 KL:

$$
D_{\text{KL}}(p \| q) = 0.5 \log_2(0.5/0.9) + 0.5 \log_2(0.5/0.1)
$$

$\log_2(0.5/0.9) = \log_2(0.5556) = -0.848$
$\log_2(0.5/0.1) = \log_2(5) = 2.322$

$D_{\text{KL}} = 0.5 \cdot (-0.848) + 0.5 \cdot 2.322 = -0.424 + 1.161 = 0.737$ bits

$H(p, q) = H(p) + D_{\text{KL}} = 1 + 0.737 = 1.737$ bits ✓

(我之前在 §6.3 算的 0.511 有误。)

### 7.2 关系:交叉熵 = 熵 + KL

$$
\boxed{H(p, q) = H(p) + D_{\text{KL}}(p \| q)}
$$

**核心洞察**:
- $H(p)$: $p$ 的"内在不确定性"(固定,不依赖 $q$)
- $D_{\text{KL}}(p \| q)$: $q$ 对 $p$ 的"拟合误差"
- $H(p, q)$: 总损失 = 内禀 + 误差

**训练意义**:
- 训练时, $p$ 是真实标签(固定),$H(p)$ 固定
- **最小化 $H(p, q)$ ⇔ 最小化 $D_{\text{KL}}(p \| q)$** (因为 $H(p)$ 不动)
- 所以**分类问题最小化交叉熵 = 最小化 KL 散度 = 极大似然估计**

这就是 MLE ↔ 交叉熵 ↔ KL 三位一体的根源(第 6 章 MLE 的角度)。

### 7.3 困惑度:2^H (perplexity)

**定义 7.3 (困惑度)**: 分布 $p$ 的**困惑度** = $2^{H(p)}$(单位 bit)或 $e^{H(p)}$(单位 nat)。

**直观**:**模型"困惑"到什么程度 = 等价于"在每个事件上,模型相当于均匀猜多少个选项"**。

**手算例**:
- 公平硬币: $H = 1$ bit, $\text{PPL} = 2^1 = 2$(困惑度 = 2 个等概率选项)
- 公平骰子: $H \approx 2.585$ bits, $\text{PPL} \approx 6$(困惑度 = 6 个等概率选项)
- 几乎确定硬币: $H \approx 0.0014$ bits, $\text{PPL} \approx 1.001$(困惑度 = 几乎 1 个选项)
- 1000 类均匀: $H = \log_2 1000 \approx 9.97$, $\text{PPL} = 1000$

**为什么 $\text{PPL} = 2^H$?**: 假设模型等概率猜 $K$ 个类,熵 = $\log_2 K$。$\text{PPL} = K$ = "等价的均匀猜类的数量"。

### 7.4 五个手算例子:LLM 困惑度

**例 1:完美模型**

真实分布 $p$,模型完美预测 $q = p$。$H(p, q) = H(p) = 2$ nats。 $\text{PPL} = e^2 \approx 7.39$。

**例 2:差模型**

模型均匀 $q = \text{Uniform}(K)$。$H(p, q) = -\sum p \log(1/K) = \log K$。
如果 $K = 1000$: $H(p, q) = \log 1000 \approx 6.91$ nats。 $\text{PPL} = e^{6.91} \approx 1000$。

**例 3:测试集中 50% 错**

模型对一半样本猜对,一半猜错(均匀猜 K)。每个样本的平均 CE:
$$
H = 0.5 \cdot H(p) + 0.5 \cdot \log K
$$
假设 $H(p) = 2$ nats, $K = 100$: $H = 1 + 0.5 \cdot \log 100 = 1 + 2.30 = 3.30$ nats。 $\text{PPL} = e^{3.30} \approx 27$。

**例 4:GPT-2 在 WikiText-103**

报告 PPL ≈ 29。这意味着模型"等价于均匀猜 29 个选项"。

**例 5:GPT-4 vs GPT-3.5**

GPT-4 在 MMLU 上 PPL ≈ 25, GPT-3.5 PPL ≈ 35。**PPL 越低,模型越"自信"**。

### 7.5 案例:为什么 CrossEntropy 是分类的标配损失?

**回顾**(第 3 章推导): 多分类问题的 one-hot 标签 $y$, 模型输出概率 $q$。

$$
H(y, q) = -\sum_i y_i \log q_i = -\log q_c \text{ (c 是真实类别)}
$$

**为什么不用别的损失?**

- **MSE**: 对概率输出是次优的(收敛慢,对极端值不敏感)
- **Hinge loss**: 只关注"对不对",不关注"有多对"
- **0-1 loss**: 不可微,无法反向传播

**CrossEntropy 优势**:
- 信息论角度:最小化 KL 散度 = 极大似然
- 数值稳定:有 log-sum-exp 技巧
- 梯度平滑:对 logits 的梯度是 $q - y$,直观

**工程实现**:
```python
# 等价但更稳定
F.cross_entropy(logits, labels)  # 内部 log_softmax + nll_loss
# 等价于
-(F.log_softmax(logits, dim=-1)).gather(1, labels.unsqueeze(1)).mean()
```

**手算例**: logits = [2.0, 1.0, 0.1], label = 0。

softmax = [0.659, 0.242, 0.099]。 $\text{CE} = -\log 0.659 \approx 0.417$ nats。 $\text{PPL} = e^{0.417} \approx 1.52$。

### 7.6 案例:为什么 LLM 用 perplexity 评估?

**场景**:你训练了一个 GPT,在验证集上 loss = 2.5 nats/token,你想告诉老板"模型有多好"。

**困惑度**: $\text{PPL} = e^{2.5} \approx 12.18$。一句话:**模型在每个 token 上"困惑度"等于 12 个等概率选项**。

**为什么用 PPL 不用 loss?**

1. **人话**: "loss 2.5" 没人懂,"PPL 12" 工程师秒懂
2. **跨数据集可比**: 不同数据集 token 长度不同, PPL 归一化到"每 token" 的"猜多少个"
3. **跨模型可比**: 不同模型的 vocabulary 大小可能不同, PPL 用 $2^H$ 统一到"bits/token"
4. **压缩比对应**: $\text{PPL} = 2^H$,$H$ = 编码每个 token 需要的平均 bits, 接近压缩算法

**bit per character (bpc) / bit per byte (bpb)**:

- $\text{bpc} = H / \log 2 / \text{char count}$
- $\text{bpb} = H / \log 2 / \text{byte count}$

例: WikiText-103, GPT-2, $\text{bpb} \approx 0.92$ (≈ 1 bit/byte)。这意味着模型能用 0.92 bit 编码每个字节,接近 ZIP 压缩水平。

### 7.7 案例:为什么 BCE Loss 几乎等于 KL 散度?

**回顾 BCE**: $y \in \{0, 1\}$, 预测 $\hat p = \sigma(z)$。

$$
\text{BCE} = -y \log \hat p - (1-y) \log(1-\hat p) = H(y, \hat p)
$$

其中 $H(y, \hat p)$ 是把 $y$ 当作 Bernoulli 分布的交叉熵。

**与 KL 的关系**:
$$
H(y, \hat p) = H(y) + D_{\text{KL}}(y \| \hat p)
$$

$y$ 是 one-hot(标签固定),$H(y) = 0$。所以:
$$
\text{BCE} = D_{\text{KL}}(y \| \hat p)
$$

训练 BCE = 训练"让 $\hat p$ 拟合 $y$"的 KL 散度。

### 7.8 本节回顾

**你刚建立的直觉**:
1. 交叉熵 = $H(p) + D_{\text{KL}}(p \| q)$, 训练交叉熵 = 训练 KL = MLE
2. 困惑度 = $2^H$, 人话版"loss"
3. PPL 跨数据集、跨模型可比, 接近压缩比
4. BCE = 二分类的交叉熵 = one-hot 标签下的 KL
5. CrossEntropy 是分类的"自然"损失: 它就是 MLE

## 8. JS 散度与其他 f-散度

### 8.1 JS 散度的定义

**定义 8.1 (JS 散度)**: 分布 $p, q$ 的**JS 散度**:

$$
D_{\text{JS}}(p \| q) = \frac{1}{2} D_{\text{KL}}(p \| m) + \frac{1}{2} D_{\text{KL}}(q \| m)
$$

其中 $m = (p + q) / 2$ 是"中间分布"。

**性质**:
- **对称**: $D_{\text{JS}}(p \| q) = D_{\text{JS}}(q \| p)$
- **有界**: $0 \leq D_{\text{JS}} \leq \log 2$(bit 单位)
- **非负**: $D_{\text{JS}} = 0$ iff $p = q$

### 8.2 f-散度族

**定义 8.2 (f-散度)**: 给定凸函数 $f$ (且 $f(1) = 0$), $p, q$ 的 f-散度:

$$
D_f(p \| q) = \mathbb{E}_{q(x)}[f(p(x)/q(x))] = \int q(x) f\left(\frac{p(x)}{q(x)}\right) dx
$$

**手算例**: 不同 $f$ 给出不同散度。

| $f(t)$ | 散度 | 别名 |
| :--- | :--- | :--- |
| $t \log t$ | $\int p \log(p/q) = D_{\text{KL}}(p \| q)$ | KL, 相对熵 |
| $-\log t$ | $\int q \log(q/p) = D_{\text{KL}}(q \| p)$ | 反向 KL |
| $(t-1) \log t$ | 略 | Jensen-Shannon |
| $(t-1)^2 / 2$ | $\frac{1}{2} \int (\sqrt p - \sqrt q)^2 = \frac{1}{2}\|\sqrt p - \sqrt q\|^2$ | **Hellinger 距离**(真距离!) |
| $\|t - 1\|$ | $\int \|p - q\|$ | **全变差距离**(真距离!) |

**关键**:
- $D_{\text{KL}}$ 是 f-散度,取 $f(t) = t \log t$
- $D_{\text{JS}}$ 是 f-散度,取 $f(t) = (t+1)\log((t+1)/2) + t \log t$ (简化版)
- **Hellinger 和 TV 是真距离**(满足三角不等式),KL 和 JS 不是

### 8.3 五个手算例子:JS vs KL

**例 1:两个高斯**

$p = \mathcal{N}(0, 1), q = \mathcal{N}(0, 1)$: $D_{\text{JS}} = 0$。

**例 2:两个高斯,均值不同**

$p = \mathcal{N}(0, 1), q = \mathcal{N}(3, 1)$: $D_{\text{JS}} \approx 1.0$ bit(经验值,接近上限 $\log 2$)

**例 3:两个 Bernoulli**

$p = (0.5, 0.5), q = (0.9, 0.1)$: $D_{\text{JS}} \approx 0.5$ bit(具体值手算稍繁)

**例 4:不同离散分布**

$p = (1, 0)$(全在 0),$q = (0, 1)$(全在 1):
- $D_{\text{KL}}(p \| q) = \infty$($p$ 在 0 有概率,$q$ 在 0 概率为 0)
- $D_{\text{JS}}(p \| q) = \log 2$($m = (0.5, 0.5)$,两个 $D_{\text{KL}}$ 都有限)

**直觉**:**JS 散度对"支撑集不重叠"是健壮的**,这是它在 GAN 中优于 KL 的原因(见 §8.4)。

**例 5:近似相等的两个分布**

$p \approx q$ 时,$D_{\text{KL}} \approx D_{\text{JS}} \approx \frac{1}{2}\|p - q\|^2$。

### 8.4 案例:为什么 GAN 用 JS 散度?

**经典 GAN loss**:
$$
\min_G \max_D \mathbb{E}_{p_{\text{data}}}[\log D(x)] + \mathbb{E}_{p_z}[\log(1 - D(G(z)))]
$$

**等价形式**:训练到最优时, $D^*(x) = p_{\text{data}}(x) / (p_{\text{data}}(x) + p_G(x))$, 此时:
$$
\mathcal{L}_{\text{GAN}} \approx 2 D_{\text{JS}}(p_{\text{data}} \| p_G) - 2 \log 2
$$

**为什么用 JS 不用 KL?**

1. **对称**: $D_{\text{JS}}(p \| q) = D_{\text{JS}}(q \| p)$,训练时没有方向偏好
2. **有界**: $D_{\text{JS}} \in [0, \log 2]$,梯度不会爆炸
3. **支撑集不重叠也 OK**: $D_{\text{JS}}$ 仍给出有意义的值(对比 $D_{\text{KL}} = \infty$)

**问题**: 实际训练中, $p_{\text{data}}$ 和 $p_G$ 几乎不重叠(高维), JS 散度的**梯度**会消失(常数 $\log 2$)。这是原始 GAN 训练不稳定的根因。

**WGAN 改进**: 用 Wasserstein 距离代替 JS 散度,即使不重叠也有非零梯度。

### 8.5 案例:为什么 f-散度在分布对齐中重要?

**对齐场景**:源分布 $p$, 目标分布 $q$。想找一个变换 $T$, 让 $T(p)$ 接近 $q$。

**不同 f-散度给出不同的"接近"含义**:

| f-散度 | 优化方向 | 适用场景 |
| :--- | :--- | :--- |
| $D_{\text{KL}}(q \| T(p))$ | 覆盖所有 mode | 完整重建 |
| $D_{\text{KL}}(T(p) \| q)$ | 集中某个 mode | 精确生成 |
| $D_{\text{JS}}$ | 折中 | GAN 训练 |
| Hellinger | 平滑,梯度好 | 强化学习 |
| Wasserstein | 几何距离 | 图像生成 |

**工程选择**:
- **VAE**: $D_{\text{KL}}(q \| p)$ (后验 → 先验)
- **GAN**: $D_{\text{JS}}$ (对称)
- **Wasserstein GAN**: Wasserstein 距离(几何意义强)
- **Hinge GAN**: Hinge 损失(类似 TV 距离)
- **f-GAN**: 通用 f-散度,可学习 $f$

### 8.6 性质:f-散度的统一视角

**变分表示(Donsker-Varadhan)**:
$$
D_f(p \| q) = \sup_{T: \Omega \to \mathbb{R}} \mathbb{E}_p[T(x)] - \mathbb{E}_q[f^*(T(x))
$$

其中 $f^*$ 是 $f$ 的 Fenchel 共轭。

**MINE 估计**(§5.7)就是用 $T$ (神经网络) 来近似 sup。这给出**互信息 = 某个 f-散度**的等价形式。

**工程意义**:任何一个 f-散度, 都可以用神经网络估计。**这是 InfoNCE / MINE / f-GAN / 对比学习的统一理论框架**。

### 8.7 本节回顾

**你刚建立的直觉**:
1. JS 散度 = KL 的对称版, 有界, 对支撑集不重叠健壮
2. f-散度族 = 用凸函数 $f$ 参数化的"距离"族
3. KL/JS/TV/Hellinger 都是 f-散度, 但只有 TV/Hellinger 是真距离
4. GAN 早期用 JS, 现代用 Wasserstein
5. 任何 f-散度都可以用神经网络估计(DV 表示)

```python
import torch
import torch.distributions as D

# 1. 离散分布的熵
p_bern = D.Bernoulli(probs=torch.tensor([0.5, 0.3, 0.1]))  # 3 个独立 Bernoulli

# tensor([0.6931, 0.6112, 0.3251])  对应 -p log p - (1-p) log(1-p)

p_cat = D.Categorical(probs=torch.tensor(`0.1, 0.2, 0.7`))
print("Categorical 熵:", p_cat.entropy())
# tensor([0.8018])  = -0.1 log 0.1 - 0.2 log 0.2 - 0.7 log 0.7

# 2. 连续分布的微分熵
p_normal = D.Normal(loc=0.0, scale=1.0)
print("N(0, 1) 微分熵:", p_normal.entropy())
# tensor(1.4189)  = 0.5 * log(2*pi*e*1) ≈ 1.4189

# 不同的 σ
for sigma in [0.5, 1.0, 2.0, 4.0]:
    print(f"N(0, {sigma}^2) 微分熵: {D.Normal(0, sigma).entropy().item():.4f}")
# 0.5 → 0.7257
# 1.0 → 1.4189
# 2.0 → 2.1121
# 4.0 → 2.8054
# 规律: 熵 ≈ 1.42 + log(sigma)

# 3. 手动算熵 (验证公式)
def entropy_categorical(probs, eps=1e-10):
    """H(p) = -sum p log p"""
    probs = torch.clamp(probs, eps, 1.0)
    return -(probs * probs.log()).sum()

p = torch.tensor([0.1, 0.2, 0.3, 0.4])
print("手动 Categorical 熵:", entropy_categorical(p))
# = 1.2799
# D.Categorical(probs=p.unsqueeze(0)).entropy() 也应该给 1.2799
```

### 实验 2:互信息的数值估计

```python
import torch
import torch.nn as nn

# 一个 toy 例子: X, Y 是二元相关变量
# 数据生成: Y = X XOR Z, Z 是 Bernoulli(0.1) 噪声
torch.manual_seed(42)
N = 100000
X = torch.randint(0, 2, (N,)).float()
Z = (torch.rand(N) < 0.1).float()
Y = (X + Z) % 2  # XOR

# 经验互信息
def empirical_mutual_info(X, Y, n_bins=2):
    """估计 I(X;Y) = H(X) + H(Y) - H(X,Y)"""
    # 用直方图估计联合分布
    p_xy = torch.zeros(n_bins, n_bins)
    for x, y in zip(X.long(), Y.long()):
        p_xy[x, y] += 1
    p_xy /= p_xy.sum()
    p_x = p_xy.sum(1, keepdim=True)
    p_y = p_xy.sum(0, keepdim=True)

    # 各种熵
    def H(p):
        p = p[p > 0]
        return -(p * p.log()).sum()

    return H(p_x.flatten()) + H(p_y.flatten()) - H(p_xy.flatten())

mi_emp = empirical_mutual_info(X, Y)
print(f"经验互信息: {mi_emp:.4f} nats")
# 理论值: 1 - H_2(0.1) = 1 - 0.3251 = 0.6749 nats
# (X 0/1 等概率, 知道 X 后 Y 几乎知道, 噪声率 0.1)

# 用 sklearn 的 mutual_info_score
from sklearn.metrics import mutual_info_score
mi_sk = mutual_info_score(X.long().numpy(), Y.long().numpy())
print(f"sklearn 互信息: {mi_sk:.4f} nats")
```

### 实验 3:KL 散度计算 (正态)

```python
import torch
import torch.distributions as D

# 1. 解析公式 vs PyTorch
mu1, sigma1 = 0.0, 1.0
mu2, sigma2 = 0.0, 2.0

p = D.Normal(mu1, sigma1)
q = D.Normal(mu2, sigma2)

# PyTorch 的 KL
kl_torch = D.kl.kl_divergence(p, q)
print(f"KL(N(0,1) || N(0,4)) PyTorch: {kl_torch:.4f} nats")
# 理论: log(2) + 1/(2*4) + 0 - 0.5 = 0.693 + 0.125 - 0.5 = 0.318

# 2. 手动用蒙特卡洛估计 (更通用)
def kl_mc(p, q, n_samples=100000):
    """D_KL(p||q) = E_p[log p - log q]"""
    x = p.sample((n_samples,))
    return (p.log_prob(x) - q.log_prob(x)).mean()

print(f"KL 蒙特卡洛: {kl_mc(p, q):.4f} nats")

# 3. F.kl_div 的使用 (注意数值稳定性)
import torch.nn.functional as F
log_p = p.log_prob(torch.linspace(-5, 5, 100))  # log 概率
log_q = q.log_prob(torch.linspace(-5, 5, 100))
# ❌ 错: 传 log 但 reduction='mean' 是按元素平均
# kl_wrong = F.kl_div(log_q, log_p, reduction='mean')  # 注意参数顺序!
# ✅ 对: input 是 log(input), target 是 log(target) 或概率
kl_correct = F.kl_div(log_q, log_p, log_target=True, reduction='sum')
print(f"F.kl_div: {kl_correct:.4f} (需要归一化才能和上面比较)")

# 4. 反向 KL: D_KL(q || p)
kl_reverse = D.kl.kl_divergence(q, p)
print(f"KL(N(0,4) || N(0,1)): {kl_reverse:.4f} nats")
# 注意: 0.318 != 反向值! 反向 = log(1/2) + 4/(2*1) + 0 - 0.5
#      = -0.693 + 2 - 0.5 = 0.807
```

### 实验 4:CrossEntropy vs KL 关系

```python
import torch
import torch.nn.functional as F

# 场景: 三分类, batch_size = 5
torch.manual_seed(0)
logits = torch.randn(5, 3)  # 模型输出
labels = torch.tensor([0, 2, 1, 0, 2])  # 真实标签

# 1. 标准的 CrossEntropy
ce = F.cross_entropy(logits, labels, reduction='mean')
print(f"CrossEntropy (mean): {ce:.4f}")

# 2. 分解: CE = H(p) + KL(p || q)
#    其中 p 是 one-hot 标签分布, q 是 softmax(logits)
probs_q = torch.softmax(logits, dim=-1)
labels_one_hot = F.one_hot(labels, num_classes=3).float()

# 手动算交叉熵
ce_manual = -(labels_one_hot * probs_q.log()).sum(dim=-1).mean()
print(f"CE 手动: {ce_manual:.4f}")

# 熵 H(p): one-hot 分布的熵 = 0
H_p = -(labels_one_hot * (labels_one_hot + 1e-10).log()).sum(dim=-1).mean()
print(f"H(p) = {H_p:.4f}  (one-hot 标签熵为 0)")

# KL(p || q)
kl = (labels_one_hot * (labels_one_hot.log() - probs_q.log())).sum(dim=-1).mean()
print(f"KL(p||q): {kl:.4f}")

# 验证: CE = H(p) + KL
print(f"CE = H(p) + KL: {H_p + kl:.4f}  (应等于 {ce:.4f})")

# 3. 标签平滑 (label smoothing)
def ce_with_smoothing(logits, labels, smoothing=0.1, num_classes=3):
    """标签平滑的 CE: 真实类权重 = 1 - smoothing, 其他类 = smoothing/(K-1)"""
    log_probs = F.log_softmax(logits, dim=-1)
    nll = -log_probs.gather(dim=-1, index=labels.unsqueeze(1)).squeeze(1)
    smooth_loss = -log_probs.mean(dim=-1)
    loss = (1 - smoothing) * nll + smoothing * smooth_loss
    return loss.mean()

print(f"CE with smoothing=0.1: {ce_with_smoothing(logits, labels):.4f}")
```

## 10. 常见误区 + Q&A (L7/L8 难度)

### 10.1 常见误区 (8 条)

**误区 1:"交叉熵 = 熵"**

❌ **错**。$H(p, q) = H(p) + D_{\text{KL}}(p \| q)$。**交叉熵 = 熵 + KL**。

- 交叉熵 $H(p, q)$: 用 $q$ 编码 $p$ 样本
- 熵 $H(p)$: 用 $p$ 自己编码
- KL 散度: 多花的 bits

**正解**:训练交叉熵 = 训练 KL(因为 $H(p)$ 固定)。但**报告**交叉熵时,要把"baseline $H(p)$"和"优化量"分开。

**误区 2:"KL 散度 = 距离"**

❌ **错**。KL 不满足三角不等式, 也不对称, 不是距离。

- 距离: 对称 + 三角不等式 + 非负
- KL: 非负 + **不对称** + **无三角不等式**

**正解**:要用"距离"时,选 Hellinger、TV、Wasserstein 距离。KL 只适合"单向"度量(从 $p$ 到 $q$)。

**误区 3:"KL 散度对称"**

❌ **错**。$D_{\text{KL}}(p \| q) \neq D_{\text{KL}}(q \| p)$(通常)。

**手算反例** (见 §6.2):
$p = (0.5, 0.5), q = (0.9, 0.1)$
$D_{\text{KL}}(p \| q) = 0.737$ bits
$D_{\text{KL}}(q \| p) = ?$ 也手算: $0.9 \log(0.9/0.5) + 0.1 \log(0.1/0.5) = 0.9 \cdot 0.848 + 0.1 \cdot (-2.322) = 0.531$ bits
$0.737 \neq 0.531$。

**工程影响**:
- $D_{\text{KL}}(p \| q)$: mode-seeking (集中某个 mode)
- $D_{\text{KL}}(q \| p)$: mode-covering (覆盖所有 mode)
- VAE 用前者, EM 算法用后者, 选错方向会有不同效果

**误区 4:"互信息 ∈ [0, 1]"**

❌ **错**。互信息**无上界**(可以任意大)。

- 下界: $I(X; Y) \geq 0$ ✓
- 上界: $I(X; Y) \leq \min(H(X), H(Y))$, 但 $H$ 可以任意大(连续变量)

**手算反例**: $X, Y$ 都是 $\mathcal{N}(0, 1)$, 相关 $\rho = 0.99$。

$$
I = -\frac{1}{2} \log(1 - 0.99^2) = -\frac{1}{2} \log(0.0199) \approx 1.96 \text{ nats}
$$

相关更高($\rho \to 1$)时, $I \to \infty$。

**正解**:互信息只有下界(非负),没有统一的上界。要给"互信息多大算大"必须**归一化**(如归一化互信息 NMI)。

**误区 5:"困惑度 = 交叉熵 × 某个常数"**

**对**。$\text{PPL} = 2^{H_{\text{bits}}} = e^{H_{\text{nats}}}$, 但容易混淆。

- 交叉熵是 nats, PPL = $e^H$
- 交叉熵是 bits, PPL = $2^H$
- **单位错了,差很多**(底数 2 vs $e$ 差 $\log 2$ 倍)

**手算**: H = 0.693 nats, PPL = $e^{0.693} = 2$。H = 1 bit, PPL = $2^1 = 2$。**不同单位给同一 PPL 2, 对应不同交叉熵**。

**正解**:报告 PPL 时**明确单位**和**底数**。PyTorch 默认用 nat, HuggingFace `perplexity` 通常给的就是 $e^H$。

**误区 6:"KL 散度 = 期望 log 比"**

**部分对**。定义上 $D_{\text{KL}}(p \| q) = \mathbb{E}_p[\log(p/q)]$, 但**期望是对 $p$ 算的**,不是对 $q$!

$$
D_{\text{KL}}(p \| q) = \int p(x) \log \frac{p(x)}{q(x)} dx \neq \int q(x) \log \frac{p(x)}{q(x)} dx
$$

**工程影响**:蒙特卡洛估计 KL 时, **必须从 $p$ 采样**, 不能从 $q$ 采样。

```python
# ✅ 对: 从 p 采样
x = p.sample((N,))
kl_est = (p.log_prob(x) - q.log_prob(x)).mean()

# ❌ 错: 从 q 采样
x = q.sample((N,))
kl_wrong = (p.log_prob(x) - q.log_prob(x)).mean()  # 不是 KL(p||q)
```

**误区 7:"F.kl_div 默认参数正确"**

❌ **错**。PyTorch 的 `F.kl_div` 有个反直觉的 API:

```python
torch.nn.functional.kl_div(input, target)
# input: 必须是 log(概率), 不是概率
# target: 概率 OR log 概率
# 公式: target * (log(target) - input), 不是 input - target!
```

**正确用法**:
```python
# 计算 KL(p||q), p 是 target, q 是 input
kl = F.kl_div(q.log(), p, log_target=False, reduction='batchmean')
# 等价: target * (log(target) - log(input)) = p * (log p - log q)
```

**误区 8:"互信息 = 0 ⇔ 独立"**

**对**, 但要小心**统计估计**。

- 理论上: $I(X; Y) = 0$ $\iff$ $X \perp Y$
- 实际上: 用样本估计的 $\hat I$ 几乎从不为 0, **有偏**且**有噪声**

**工程影响**:
- 互信息估计都有偏差, 样本量小时 $\hat I$ 会**严重高估**(MINE、KSG 都有这个问题)
- 报告互信息时**必须给出样本量**和**估计方法**
- 不要看 $\hat I = 0.01$ 就说"几乎独立"。可能是估计误差

### 10.2 面试 Q&A (L7/L8 难度, 5 题)

**Q1:交叉熵的工程意义?推导与 MLE 的关系?**

**答案**:

交叉熵 $H(p, q)$ 与极大似然估计 (MLE) 本质是同一件事,只是换了符号。

**推导**:
1. **建模**: 设真实分布 $p$, 模型分布 $q_\theta$。
2. **样本**: 从 $p$ 中独立采样 $x_1, ..., x_N$。
3. **似然**: $L(\theta) = \prod_i q_\theta(x_i)$。
4. **对数似然**: $\ell(\theta) = \sum_i \log q_\theta(x_i)$。
5. **平均**: $\frac{1}{N} \ell(\theta) = \frac{1}{N} \sum_i \log q_\theta(x_i) \xrightarrow{a.s.} \mathbb{E}_p[\log q_\theta(X)] = -H(p, q)$。
6. **最大化对数似然 = 最小化交叉熵** $\Leftrightarrow$ **最小化 KL 散度**(因为 $H(p)$ 固定)。

**工程意义**:
- CrossEntropy Loss = MLE 的副产品
- 训练时看不到 $H(p)$, 但 $H(p)$ 固定不影响优化
- 报告 loss 时常加 baseline $H(p)$, 得到**实际"拟合误差"** = KL

**加分**:
- KL 不对称 → 训练方向有讲究 (mode-seeking vs mode-covering)
- 标签平滑 = 软化 $H(p)$, 让 KL 有下界, 提升泛化

**Q2:为什么 KL 散度不对称?工程影响?**

**答案**:

**数学原因**:
$D_{\text{KL}}(p \| q) = \int p(x) \log \frac{p(x)}{q(x)} dx$, 是**关于 $p$ 的期望**,不是关于 $q$。

- 交换 $p, q$: 期望算子改变
- 唯一对称的分布: $p = q$ 时 $D_{\text{KL}} = 0$, 但其他时候不对称

**工程影响**:

1. **VAE**: $D_{\text{KL}}(q(z|x) \| p(z))$ 是 mode-seeking(后验推到先验的某个 mode)
   - 后果: posterior collapse(后验坍缩)
   - 解决: β-VAE, free bits

2. **EM 算法**: $D_{\text{KL}}(p(z|x) \| q(z))$ 是 mode-covering(后验覆盖所有 mode)
   - 后果: 算法稳定但慢
   - 这是为什么 EM 是稳定的, VAE 不稳定

3. **知识蒸馏**: $D_{\text{KL}}(p_{\text{student}} \| p_{\text{teacher}})$ 让学生输出拟合教师
   - 反过来 $D_{\text{KL}}(p_{\text{teacher}} \| p_{\text{student}})$ 给"教师应该向学生学"的方向, 没意义

4. **RL 策略**: $D_{\text{KL}}(\pi_{\text{old}} \| \pi_{\text{new}})$ 用于 PPO 的"信任域"
   - 反向 $D_{\text{KL}}(\pi_{\text{new}} \| \pi_{\text{old}})$ 给出不同的"保守性"

**Q3:互信息估计的方法?(MINE, InfoNCE)**

**答案**:

| 方法 | 估计目标 | 类型 | 训练稳定性 | 估计偏差 |
| :--- | :--- | :--- | :--- | :--- |
| MINE | 上界 | 神经网络 | 中(DV 技巧) | 中 |
| InfoNCE | 下界 | 神经网络 | 高 | 低(随 N 紧) |
| KSG | 无偏 | k-NN | 不需要训练 | 低 |
| KDE | 无偏 | 直方图 | 不需要训练 | 高(高维差) |

**MINE 公式** (Belghazi 2018):
$$
\hat I_{\text{MINE}} = \sup_T \mathbb{E}_{p(x,y)}[T_\theta(x,y)] - \log \mathbb{E}_{p(x)p(y)}[e^{T_\theta(x,y)}]
$$
- $T_\theta$ 是神经网络(鉴别器)
- 用 Donsker-Varadhan 表示
- 训练时用 EMA 修正偏差

**InfoNCE 公式** (Oord 2018):
$$
\mathcal{L}_{\text{InfoNCE}} = -\mathbb{E}\left[\log \frac{f(x_i, y_i)}{\sum_{j=1}^{N} f(x_i, y_j)}\right]
$$
- $f$ 是打分函数(余弦相似度 / MLP)
- 互信息下界: $I(X;Y) \geq \log N - \mathcal{L}_{\text{InfoNCE}}$
- $N$ 越大, 下界越紧
- 训练稳定(对比损失的标准)

**选择建议**:
- **工程实践**: InfoNCE (CLIP, SimCLR, MoCo)
- **理论研究**: MINE
- **离线分析**: KSG (k-NN based)
- **小数据**: KDE (但维度要低, < 5)

**Q4:为什么 LLM 用 perplexity 而不用 KL?**

**答案**:

**等价关系**:
$$
\text{PPL} = e^{H(p, q)} \neq e^{D_{\text{KL}}(p \| q)}
$$
PPL 和 KL 差一个 $e^{H(p)}$ 因子。

**为什么报告 PPL?**

1. **可读性**: "PPL = 30" 工程师秒懂(等价于 30 个等概率选项), "loss = 3.4" 需要单位换算
2. **跨数据集可比**: 不同数据集的 $H(p)$ 不同, KL 受 $H(p)$ 影响大; PPL 归一化掉 $H(p)$ 的影响
3. **跨模型可比**: 不同模型的 vocab 大小不同, KL 受 vocab 影响; PPL 归一化掉
4. **压缩比**: PPL 接近"压缩比"的倒数, 直接对应工业指标

**什么时候用 KL?**

- **训练过程中**: 监控 KL 散度(看模型学习进度)
- **分布对比**: $D_{\text{KL}}(p_1 \| p_2)$ 直接看两个分布差多少
- **生成模型评估**: FID 用 Inception 特征空间的高斯拟合, 本质是 KL

**Q5:InfoNCE loss 的信息论基础?**

**答案**:

**核心定理 (Poole 2019)**:

InfoNCE loss 是**互信息的下界**, 反过来也是**条件熵的上界**。

**证明思路**:

设 $x$ 是锚点, $y^+$ 是正样本(和 $x$ 配对), $y^-$ 是从先验采的 $N-1$ 个负样本。

InfoNCE loss:
$$
\mathcal{L} = -\mathbb{E}\left[\log \frac{f(x, y^+)}{f(x, y^+) + \sum_{y^-} f(x, y^-)}\right]
$$

互信息下界: $I(x; y) \geq \log(N) - \mathcal{L}$。

**直观**: $\mathcal{L}$ 是模型对"正样本的归一化分数"取负对数。$\mathcal{L}$ 越小, 正样本越被识别, 说明 $x$ 和 $y^+$ 的相关性越强(互信息越大)。

**工程启示**:

- **温度 $\tau$**: $\tau$ 小 → 分布尖 → 关注"最难的负样本" → 难学但精确
- **负样本数 $N$**: $N$ 大 → 估计紧但计算贵
- **对比学习 = 最大化互信息下界 = 拉近正样本对 + 推远负样本对**

**实际应用**:

- **CLIP**: 图像-文本对, 互信息 = "图文共享语义"
- **SimCSE**: 句子-自己的 dropout 版本, 互信息 = "句子不变语义"
- **MoCo**: 字典学习, 互信息 = "样本的判别性"
- **BYOL / SimSiam**: 不用负样本, 互信息用 EMA 编码器估计

### 11.8 本章的灵魂问题(最后一次回答)

> **"为什么 CrossEntropy 叫'交叉'熵?它和熵、KL、互信息、JS 是什么关系?"**

**一句话回答**:

> **熵 = 系统的内在不确定性 (期望 -log p)**。**KL 散度 = 一个分布拟合另一个的代价**。**交叉熵 = 熵 + KL, 是 MLE 的副产品**。**互信息 = 知道一个变量后另一个不确定性减少量 = 联合 vs 独立的 KL**。**JS 散度 = KL 的对称版, GAN 的核心**。这五个概念共享同一个根: **"信息 = -log p, 系统量 = 期望"**, 只是提问方式不同。**信息论 = 概率论的"度量延伸"**。Shannon 1948 年的天才洞察, 把通信工程变成了概率论的子学科, 也把深度学习的 loss 函数全部统一到了一个公式: $H(p, q) = H(p) + D_{\text{KL}}(p \| q)$。

这一章我们用熵、联合熵、条件熵、链式法则、互信息、KL、交叉熵、困惑度、JS 散度, 把"信息"和"概率"完整统一了。但**这只是开始**。接下来去 **5-信息论**, 你会看到这些概念如何变成信道容量、率失真、信息瓶颈, 如何解释 LLM、Diffusion、CLIP、对比学习的世界。

### A.1 熵的更多直觉:为什么"均匀"是最大熵?

#### A.1.1 微正则论证(Microcanonical Argument)

第 2.2 节说"公平硬币熵 = 1 bit,公平骰子熵 ≈ 2.58 bits"。为什么?**均匀分布熵最大**这件事有一个特别优雅的论证,我们用 ASCII 图走一遍。

假设我们有 $K$ 个"盒子",每个盒子里放一个"球",球的总数固定。问:**球在盒子里的分布** $p = (p_1, p_2, ..., p_K)$ **满足什么条件时,系统最"乱"**?

直观回答:**均匀**。因为如果不均匀,有些盒子多有些盒子少,系统就有了"结构",不那么乱。

数学证明用 **Lagrange 乘子**:

```text
目标:    max  H(p) = -Σ p_k log p_k
约束 1:  Σ p_k = 1     (概率和为 1)
约束 2:  p_k ≥ 0       (非负)
```

构造 Lagrangian:
$$
\mathcal{L} = -\sum_k p_k \log p_k - \lambda \left(\sum_k p_k - 1\right)
$$

对 $p_k$ 求偏导:
$$
\frac{\partial \mathcal{L}}{\partial p_k} = -\log p_k - 1 - \lambda = 0
$$

解得:
$$
p_k = e^{-(1+\lambda)} = \text{常数}
$$

由归一化 $\sum p_k = 1$ 得常数 $= 1/K$,所以 $p_k = 1/K$。**均匀分布是熵最大化的唯一解**。

#### A.1.2 物理直觉:为什么热力学第二定律说"熵增"?

如果你本科学过一点热力学,会知道孤立系统的熵"只会增加或保持不变"。这和上面的均匀分布熵最大**是同一件事**:

- 气体分子在盒子里的速度分布 → 趋向 **Maxwell-Boltzmann** (高斯)
- 气体在两个连通容器的分布 → 趋向均匀
- 信息论里的"消息分布"在编码后 → 趋向均匀 (算术编码)

**共同根**: 均匀 = 最无结构 = 最不确定 = 熵最大。

#### A.1.3 工程意义:为什么正态分布熵 = 0.5 log(2πeσ²)?

连续分布的微分熵(differential entropy)有个常见公式,很多工程师背过但不知道为什么:

$$
h(\mathcal{N}(\mu, \sigma^2)) = \frac{1}{2} \log(2\pi e \sigma^2)
$$

推导:

$$
h = -\int p(x) \log p(x) dx = -\int p(x) \log\left[\frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}\right] dx
$$

$$
= -\int p(x) \left[-\frac{1}{2}\log(2\pi\sigma^2) - \frac{(x-\mu)^2}{2\sigma^2}\right] dx
$$

$$
= \frac{1}{2}\log(2\pi\sigma^2) + \frac{1}{2}\int p(x) \frac{(x-\mu)^2}{\sigma^2} dx
$$

$$
= \frac{1}{2}\log(2\pi\sigma^2) + \frac{\sigma^2}{2\sigma^2} = \frac{1}{2}\log(2\pi e \sigma^2)
$$

用 PyTorch 验证:

```python
import torch
from torch.distributions import Normal

# 标准正态 N(0, 1)
dist = Normal(0.0, 1.0)
H = dist.entropy()  # tensor(1.4189)
print(f"H(N(0,1)) = {H.item():.4f} nats")  # 1.4189 nats
print(f"0.5 * log(2*pi*e) = {0.5 * torch.log(2 * torch.pi * torch.e).item():.4f}")  # 1.4189

# 验证 N(0, 2) 熵比 N(0, 1) 大
dist2 = Normal(0.0, 2.0)
print(f"H(N(0,2)) = {dist2.entropy().item():.4f} nats")  # 2.1125 nats
print(f"0.5 * log(2*pi*e*4) = {0.5 * torch.log(2 * torch.pi * torch.e * 4).item():.4f}")
```

**直觉**: $\sigma$ 越大,分布越"散",越不确定,熵越大。

#### A.1.4 熵的极值:Dirichlet 和 Multinomial

**Multinomial 分布的熵**: $\text{Mult}(n, p)$ (n 次独立试验,每次有 K 类,概率 $p$):

$$
H(\text{Mult}(n, p)) = \frac{1}{2}\log\left[(2\pi e)^{K-1} n \prod_{k=1}^K p_k\right] + O(1/n)
$$

(渐近公式,适用于 $n$ 大的时候。)

**Dirichlet 分布的熵**: $\text{Dir}(\alpha)$:

$$
H(\text{Dir}(\alpha)) = \log B(\alpha) + (\alpha_0 - K) \psi(\alpha_0) - \sum_{k=1}^K (\alpha_k - 1) \psi(\alpha_k)
$$

其中 $B$ 是 Beta 函数,$\psi$ 是 digamma 函数。这公式没人背,但工程上**LDA (Latent Dirichlet Allocation) 的 ELBO 会用到**。

### A.2 互信息的高级性质

#### A.2.1 互信息的"非负性"证明

互信息 $I(X; Y) \geq 0$ 是信息论最基本的定理之一。直观:知道 $Y$ 不会让 $X$ 变得更不确定。证明用 **Jensen 不等式**:

$$
I(X; Y) = \mathbb{E}_{p(x,y)}\left[\log \frac{p(x,y)}{p(x)p(y)}\right]
$$

$$
= \mathbb{E}_{p(x)}\left[\mathbb{E}_{p(y|x)}\left[\log \frac{p(y|x)}{p(y)}\right]\right]
$$

由 Jensen 不等式 (对数是凹函数):

$$
\mathbb{E}_{p(y|x)}\left[\log \frac{p(y|x)}{p(y)}\right] \leq \log \mathbb{E}_{p(y|x)}\left[\frac{p(y|x)}{p(y)}\right] = \log \sum_{y} p(y|x) \cdot \frac{p(y|x)}{p(y)}
$$

但 $\sum_y p(y|x) = 1$,所以:

$$
\log \sum_y p(y|x) \cdot \frac{p(y|x)}{p(y)} = \log \sum_y p(y|x) = \log 1 = 0
$$

所以 $I(X; Y) \leq 0$?等等,反了!我们用了错方向的 Jensen。正确做法:**对数是凹函数,所以** $\mathbb{E}[\log X] \leq \log \mathbb{E}[X]$ (Jensen 上界)。要证 $I \geq 0$,需要反方向的不等式:

$$
I(X; Y) = -\mathbb{E}_{p(x,y)}\left[\log \frac{p(x)p(y)}{p(x,y)}\right] \geq -\log \mathbb{E}_{p(x,y)}\left[\frac{p(x)p(y)}{p(x,y)}\right] = -\log 1 = 0
$$

**得证**。这个反方向的 Jensen 是互信息非负的核心。

#### A.2.2 数据处理不等式(Data Processing Inequality, DPI)

**定理**: 如果 $X \to Y \to Z$ 是马尔可夫链 (即 $X \perp Z | Y$),那么:
$$
I(X; Z) \leq I(X; Y)
$$

直观:数据处理不能"创造"信息,只能损失信息。这是信息论里**最深刻**的定理之一,直接导出了:

- 神经网络的**信息瓶颈**: $I(X; Z_{\text{深层}}) \leq I(X; Z_{\text{浅层}})$
- **无免费午餐**:压缩 / 编码不能增加信息
- **单调性**:深度增加 → 互信息不增

工程示例:

```python
import torch
import torch.nn as nn

# 模拟: X -> Y -> Z, Z 是 Y 的"压缩"
X = torch.randn(10000, 10)
Y = X @ torch.randn(10, 5) + 0.1 * torch.randn(10000, 5)
Z = Y[:, :2]  # 粗暴地"截断" Y 到 2 维

# 数值估计互信息 (用 KSG 或直方图)
# 这里用最粗糙的版本:把数据分 bin,数频次
def mi_estimate_bin(x, y, bins=20):
    """粗糙的互信息估计,用于演示"""
    xy = torch.stack([x.flatten(), y.flatten()], dim=1)
    p_xy = torch.histogramdd(xy, bins=[bins, bins]).hist
    p_x = p_xy.sum(dim=1)
    p_y = p_xy.sum(dim=0)
    p_xy = p_xy / p_xy.sum()
    p_x = p_x / p_x.sum()
    p_y = p_y / p_y.sum()

    mi = 0
    for i in range(bins):
        for j in range(bins):
            if p_xy[i,j] > 0 and p_x[i] > 0 and p_y[j] > 0:
                mi += p_xy[i,j] * torch.log(p_xy[i,j] / (p_x[i] * p_y[j]))
    return mi

# 选一维演示
print(f"I(X; Y) ≈ {mi_estimate_bin(X[:, 0], Y[:, 0]):.3f} nats")
print(f"I(X; Z) ≈ {mi_estimate_bin(X[:, 0], Z[:, 0]):.3f} nats")  # 应该更小
```

**实际工程**:DPI 告诉我们,如果你设计了一个"信息瓶颈"网络 (encoder → bottleneck → decoder),**bottleneck 越窄,信息损失越大**。这是 IB 理论的根基。

#### A.2.3 互信息的"链式法则"扩展

互信息有"两变量"和"三变量"两种链式法则:

**两变量**:
$$
I(X; Y, Z) = I(X; Y) + I(X; Z | Y)
$$

直观:知道 $Y, Z$ 提供的信息 = 知道 $Y$ 提供的信息 + 知道 $Y$ 后 $Z$ 多提供的信息。

**三变量的"互信息分解"(Partial Information Decomposition, PID)**:
$$
I(X; Y, Z) = I(X; Y) + I(X; Z) - \text{Redundancy} + \text{Synergy}
$$

其中:

- **冗余 (Redundancy)**: $Y$ 和 $Z$ **重叠**提供的信息
- **协同 (Synergy)**: $Y$ 和 $Z$ **组合才**提供的信息 (单独任何一个都不够)

工程例子:在多模态学习中:

- 图像和文本都包含"猫"这个概念 → 冗余
- 图像 (视觉特征) + 文本 (语义) 组合起来才能完整描述"猫" → 协同

PID 是 2010 年后才正式发展的,工程应用还在探索。

### A.3 KL 散度的更多性质

#### A.3.1 KL 散度 = f-散度族的特例

**f-散度**是一大类"距离"的总称:

$$
D_f(p \| q) = \mathbb{E}_{q(x)}\left[f\left(\frac{p(x)}{q(x)}\right)\right]
$$

其中 $f$ 是一个凸函数,满足 $f(1) = 0$。

**特例**:

```text
f(t)             →  散度名称
─────────────────────────────────
t log t          →  KL 散度 (前向)
-log t           →  KL 散度 (反向,即 D_KL(q||p))
(t-1)² / 2       →  χ² 散度
|t-1|            →  全变差 (TV) 距离的 1/2
(sqrt(t) - 1)²   →  Hellinger 距离
(t^α - 1) / (α(α-1)) →  Rényi α-散度
- (t+1) log((t+1)/2) + t log t →  Jensen-Shannon 散度(JS)
```

工程意义:不同的 f-散度有不同的"梯度行为"和"对抗鲁棒性"。**为什么 GAN 用 JS,VAE 用 KL?为什么 Diffusion 用简单的 L2?** 这些问题都和 f-散度族的性质有关。

#### A.3.2 为什么 KL 散度不是距离?

KL 散度**不**满足距离的三条公理:

1. **非负**: ✅ $D_{\text{KL}}(p \| q) \geq 0$,等号当且仅当 $p = q$
2. **对称**: ❌ $D_{\text{KL}}(p \| q) \neq D_{\text{KL}}(q \| p)$ (一般)
3. **三角不等式**: ❌ 不满足

直观:KL 是"用 q 编码 p 的代价",编码方向是单向的。如果 q 很差,代价特别大;反过来用 p 编码 q 可能没那么大。

**手算例子**:

```python
import torch
p = torch.tensor([0.5, 0.5])
q = torch.tensor([0.99, 0.01])

# 前向:用 q 编码 p
kl_pq = (p * (p / q).log()).sum()
# 反向:用 p 编码 q
kl_qp = (q * (q / p).log()).sum()

print(f"D_KL(p || q) = {kl_pq.item():.3f} nats")  # 2.310
print(f"D_KL(q || p) = {kl_qp.item():.3f} nats")  # 0.702
# 差很多!
```

**工程启示**:

- **VAE 用前向 KL** $D_{\text{KL}}(q(z|x) \| p(z))$ → 让 $q$ "覆盖" $p$,mode-covering
- **Wake-Sleep / 重要性采样用反向 KL** $D_{\text{KL}}(p \| q)$ → 让 $q$ "集中"在 $p$ 的峰上,mode-seeking

#### A.3.3 KL 散度的链式法则

类比互信息的链式法则:

$$
D_{\text{KL}}(p(x, y) \| q(x, y)) = D_{\text{KL}}(p(x) \| q(x)) + D_{\text{KL}}(p(y|x) \| q(y|x))
$$

**应用**: VAE 的 ELBO 推导里,这一步把联合 KL 拆成"先验 KL + 似然 KL"。

#### A.3.4 KL 散度与 MLE 的等价

**定理**: 极大似然估计 (MLE) = 最小化 $D_{\text{KL}}(p_{\text{data}} \| p_\theta)$。

**证明**:

$$
\arg\min_\theta D_{\text{KL}}(p_{\text{data}} \| p_\theta) = \arg\min_\theta \mathbb{E}_{p_{\text{data}}}\left[\log \frac{p_{\text{data}}(x)}{p_\theta(x)}\right]
$$

$$
= \arg\min_\theta \mathbb{E}_{p_{\text{data}}}[-\log p_\theta(x)] - \mathbb{E}_{p_{\text{data}}}[\log p_{\text{data}}(x)]
$$

第二项和数据无关,所以等价于:

$$
= \arg\min_\theta -\mathbb{E}_{p_{\text{data}}}[\log p_\theta(x)] = \arg\max_\theta \mathbb{E}_{p_{\text{data}}}[\log p_\theta(x)]
$$

右边是**对数似然期望** = MLE。

**工程意义**: 这就是为什么"训练分类器"和"最小化 KL 散度"是**同一件事**。负对数似然 (NLL) 损失 = 交叉熵 = MLE ≈ 最小化 KL。

#### A.3.5 KL 散度与"信息瓶颈"的关系

**信息瓶颈 (IB) 目标**:

$$
\min_{p(z|x)} I(X; Z) - \beta I(Z; Y)
$$

- 第一项: 让 $Z$ 少"记住" $X$ (压缩)
- 第二项: 让 $Z$ 多"预测" $Y$ (保持有用信息)
- $\beta$: 压缩和预测的权衡

用 KL 散度改写:

$$
I(X; Z) = D_{\text{KL}}(p(x, z) \| p(x) p(z))
$$

$$
I(Z; Y) = D_{\text{KL}}(p(z, y) \| p(z) p(y))
$$

IB 优化的是**两个 KL 散度的加权和**。

#### A.3.6 JS 散度的细节

**定义**:

$$
\text{JS}(p \| q) = \frac{1}{2} D_{\text{KL}}(p \| m) + \frac{1}{2} D_{\text{KL}}(q \| m)
$$

其中 $m = (p + q) / 2$。

**性质**:

- ✅ 对称
- ✅ 有界: $0 \leq \text{JS} \leq \log 2$
- ❌ 高维退化: 当 $p$ 和 $q$ 的支撑不相交时, $\text{JS} = \log 2$ (梯度消失)
- 这是原始 GAN 训练困难的核心原因之一 → WGAN 改用 Wasserstein 距离

**PyTorch 实现**:

```python
import torch
import torch.nn.functional as F

def js_divergence(p, q, eps=1e-8):
    """JS 散度,对称,单位 nats"""
    p = p + eps
    q = q + eps
    m = 0.5 * (p + q)
    return 0.5 * (F.kl_div(m.log(), p, reduction='sum') +
                   F.kl_div(m.log(), q, reduction='sum'))

p = torch.tensor([0.5, 0.5])
q = torch.tensor([0.9, 0.1])
print(f"JS(p, q) = {js_divergence(p, q):.3f}")  # 0.158 nats
```

#### A.3.7 Wasserstein 距离 (Earth Mover's Distance) 简介

虽然 Wasserstein 不是 f-散度,但工程上经常和 KL/JS 并提:

$$
W_p(p, q) = \left(\inf_{\gamma \in \Pi(p, q)} \mathbb{E}_{(x, y) \sim \gamma}[\|x - y\|^p]\right)^{1/p}
$$

直观: 把 $p$ "推"成 $q$ 需要的最小代价。

**Wasserstein vs KL/JS**:
- Wasserstein: 即使支撑不相交也有梯度 → GAN 训练更稳定
- KL/JS: 支撑不相交时梯度消失 → mode collapse

**WGAN 的核心**: 用 Wasserstein-1 距离代替 JS,提升训练稳定性。

### A.4 交叉熵的更多细节

#### A.4.1 数值稳定性:Log-Sum-Exp 技巧

交叉熵的朴素实现:
$$
H(p, q) = -\sum p(x) \log q(x)
$$

**坑**: 如果 $q(x) = 0$, $\log 0 = -\infty$。如果 $q(x)$ 很小,数值下溢。

**正确做法**:用 Log-Sum-Exp:

```python
import torch
import torch.nn.functional as F

# 朴素 (有风险)
def cross_entropy_naive(p, q):
    return -(p * q.log()).sum()

# 数值稳定: 减去 max
def cross_entropy_stable(logits, labels):
    """logits: (N, C), labels: (N,)"""
    log_probs = F.log_softmax(logits, dim=1)  # 自动 log-sum-exp 减 max
    return F.nll_loss(log_probs, labels)

# PyTorch 自带 (内部就是这么做的)
loss = F.cross_entropy(logits, labels)
```

**为什么 Log-Sum-Exp 工作**:

$$
\log \sum e^{x_i} = \max(x) + \log \sum e^{x_i - \max(x)}
$$

右边每一项 $x_i - \max(x) \leq 0$,所以 $e^{x_i - \max(x)} \leq 1$,求和不会爆。

#### A.4.2 Label Smoothing 的信息论解释

**Label smoothing**: 把 one-hot 标签 $y = (0, ..., 1, ..., 0)$ 改成 $y' = (0, ..., 1-\epsilon, ...) + \epsilon / K$。

直觉:防止模型"过自信" (overconfident)。

**信息论解释**: Label smoothing = 让模型学一个**混合分布**:
$$
y' = (1 - \epsilon) y + \epsilon u
$$
其中 $u$ 是均匀分布。

这相当于加了一个正则化:
$$
H(y', q) = (1 - \epsilon) H(y, q) + \epsilon H(u, q)
$$

**额外好处**: 防止 logit 变得极大 → 提升对抗鲁棒性 → 知识蒸馏的"软标签"。

PyTorch 实现:

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class CrossEntropyLabelSmoothing(nn.Module):
    def __init__(self, eps=0.1):
        super().__init__()
        self.eps = eps

    def forward(self, logits, labels):
        """labels: (N,) long tensor"""
        n_classes = logits.size(1)
        log_probs = F.log_softmax(logits, dim=1)

        # one-hot 编码
        one_hot = torch.zeros_like(log_probs).scatter(1, labels.unsqueeze(1), 1)
        # 平滑
        smooth = one_hot * (1 - self.eps) + self.eps / n_classes
        # 交叉熵
        loss = -(smooth * log_probs).sum(dim=1).mean()
        return loss

# 用法
loss_fn = CrossEntropyLabelSmoothing(eps=0.1)
logits = torch.randn(32, 10)
labels = torch.randint(0, 10, (32,))
loss = loss_fn(logits, labels)
```

#### A.4.3 焦点损失 (Focal Loss) 与信息论

**Focal Loss** (Lin et al., RetinaNet, 2017):
$$
\mathcal{L}_{\text{focal}} = -\alpha (1 - p_t)^\gamma \log p_t
$$

- $\gamma$ 越大,对"易分类"样本的抑制越强
- 解决类别不平衡问题

**信息论解释**: 加权交叉熵,权重是"信息量"的反函数。容易分类的样本 $p_t$ 大, $(1 - p_t)^\gamma$ 小,贡献小;难分类的样本 $p_t$ 小, $(1 - p_t)^\gamma$ 大,贡献大。

本质:**让模型更关注"意外"样本**——这又回到"信息 = 意外"。

```python
import torch
import torch.nn.functional as F

def focal_loss(logits, labels, alpha=0.25, gamma=2.0):
    """二分类 focal loss"""
    p = torch.sigmoid(logits)
    pt = p * labels + (1 - p) * (1 - labels)  # p for true class
    alpha_t = alpha * labels + (1 - alpha) * (1 - labels)
    loss = -alpha_t * (1 - pt) ** gamma * torch.log(pt + 1e-8)
    return loss.mean()

# 多分类版本
def focal_loss_multiclass(logits, labels, gamma=2.0):
    log_probs = F.log_softmax(logits, dim=1)
    probs = log_probs.exp()
    pt = probs.gather(1, labels.unsqueeze(1)).squeeze(1)
    loss = -((1 - pt) ** gamma * log_probs.gather(1, labels.unsqueeze(1)).squeeze(1))
    return loss.mean()
```

#### A.4.4 Perplexity 推导:为什么是 `exp(loss)`?

**困惑度 (Perplexity, PPL)**:
$$
\text{PPL}(p, q) = 2^{H(p, q)} = e^{H_{\text{nat}}(p, q)}
$$

直观: 困惑度 = "模型每个 token 的平均选择数"。

**例子**:

- 完美模型: 每次预测概率 1, PPL = 1
- 随机猜测 (K 分类): PPL = K
- LLM 训练到 loss = 2.5 nats/token → PPL = $e^{2.5} \approx 12.18$

**为什么 LLM 评估用 PPL 不用 loss**:
- PPL 有"选择数"的物理意义,容易解读
- PPL 是 base-$e$ 的, 跨 tokenization 不可比
- PPL (base-2) 才是真正"分支因子"

工程代码:

```python
import torch

def compute_perplexity(model, dataloader, device='cuda'):
    """计算 LLM 在数据集上的困惑度"""
    model.eval()
    total_loss = 0
    total_tokens = 0

    with torch.no_grad():
        for batch in dataloader:
            input_ids = batch['input_ids'].to(device)
            labels = batch['labels'].to(device)

            logits = model(input_ids).logits
            # 移位: 预测下一个 token
            shift_logits = logits[..., :-1, :].contiguous()
            shift_labels = labels[..., 1:].contiguous()

            loss = torch.nn.functional.cross_entropy(
                shift_logits.view(-1, shift_logits.size(-1)),
                shift_labels.view(-1),
                reduction='sum'
            )
            total_loss += loss.item()
            total_tokens += shift_labels.numel()

    avg_loss = total_loss / total_tokens  # nats per token
    perplexity = torch.exp(torch.tensor(avg_loss))
    return perplexity.item()

# 注意: 不同 tokenization 的 PPL 不能直接比较!
# 一个 32K vocab 的模型 PPL=20, 和一个 256K vocab 的模型 PPL=20, 完全不是同一件事
```

#### A.4.5 BPC (Bits Per Character) 和 BPE (Bytes Per Event)

**BPC**: 字符级的信息论度量,用于字符级语言模型 (char-LSTM, char-CNN):
$$
\text{BPC} = \frac{H(p, q)}{\log 2} \approx \frac{-\sum \log q(x_i)}{N \log 2}
$$

单位: bits/char。一个 100M 字符的语料,BPC = 1.2 意味着平均每字符用 1.2 bits 编码。

**类似度量**:
- **BPF** (bits per frame): 语音模型
- **BPB** (bits per byte): 字节级模型 (ByT5, CANINE)
- **BPT** (bits per token): 词元级模型 (GPT, BERT)

**经验值**:
- 英文文本压缩极限 (PPM 模型): 1.0 - 1.5 BPC
- GPT-2 on WebText: ~0.7 BPB
- 现代 LLM on web text: ~0.5 BPB

### A.5 互信息估计的更多细节

#### A.5.1 MINE (Mutual Information Neural Estimation)

**MINE** (Belghazi et al., ICML 2018): 用神经网络估计互信息。

**核心思想**: Donsker-Varadhan (DV) 表示。

$$
I(X; Y) = \sup_{T: \Omega \to \mathbb{R}} \mathbb{E}_{p(x, y)}[T(x, y)] - \log \mathbb{E}_{p(x) p(y)}[e^{T(x, y)}]
$$

其中 $T$ 是任意函数。深度学习里用神经网络 $T_\theta$ 逼近。

**算法**:

```python
import torch
import torch.nn as nn

class MINE(nn.Module):
    """Mutual Information Neural Estimation"""
    def __init__(self, x_dim, y_dim, hidden=128):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(x_dim + y_dim, hidden),
            nn.ReLU(),
            nn.Linear(hidden, hidden),
            nn.ReLU(),
            nn.Linear(hidden, 1)
        )

    def forward(self, x, y):
        """x, y: (N, dim)"""
        # joint sample
        joint = torch.cat([x, y], dim=1)
        # marginal sample: shuffle y
        y_shuffled = y[torch.randperm(y.size(0))]
        marginal = torch.cat([x, y_shuffled], dim=1)

        t_joint = self.net(joint)
        t_marginal = self.net(marginal)

        # DV 估计
        mi = t_joint.mean() - torch.log(torch.exp(t_marginal).mean() + 1e-8)
        return mi

# 训练
mine = MINE(x_dim=10, y_dim=5)
opt = torch.optim.Adam(mine.parameters(), lr=1e-3)

for step in range(1000):
    x = torch.randn(256, 10)
    y = 0.5 * x + 0.1 * torch.randn(256, 5)  # X 和 Y 有相关性

    mi_estimate = mine(x, y)
    loss = -mi_estimate  # 最大化 MI = 最小化 -MI

    opt.zero_grad()
    loss.backward()
    opt.step()

    if step % 100 == 0:
        print(f"Step {step}: MINE estimate = {mi_estimate.item():.3f}")
```

**坑**:
- MINE 估计**有偏**,需要 bias correction
- 需要 EMA (exponential moving average) 稳定训练
- 估计值的"绝对大小"不可靠,**排序**比数值重要

#### A.5.2 InfoNCE 的下界推导

**InfoNCE loss** (Oord et al., 2018):
$$
\mathcal{L}_{\text{NCE}} = -\mathbb{E}\left[\log \frac{f(x, y^+)}{f(x, y^+) + \sum_{y^-} f(x, y^-)}\right]
$$

其中 $f$ 是相似度函数 (如指数), $y^+$ 是正样本, $y^-$ 是 $N-1$ 个负样本。

**下界定理**:
$$
I(X; Y) \geq \log(N) - \mathcal{L}_{\text{NCE}}
$$

**推导** (直觉版):

定义条件分布:
$$
p(y | x) = \frac{p(x, y)}{\sum_y p(x, y)} \approx \frac{f(x, y)}{Z(x)}
$$

其中 $Z(x) = \sum_y f(x, y)$ 是配分函数。$N$ 个样本中 1 个正 + $N-1$ 个负 = 估计 $p(y^+|x)$:

$$
\mathcal{L}_{\text{NCE}} = -\mathbb{E}_X\left[\log \frac{p(y^+|x)}{p(y^+|x) + \sum_{y^-} p(y^-|x)}\right]
$$

最优解是 $p(y^+|x) = 1/N$ (均匀),此时 $\mathcal{L} = \log N$。

把 $I$ 和 $\mathcal{L}$ 联系起来需要 KL 散度的下界 (Gibbs 不等式变种),这里跳过细节。**结论**: 负样本越多,下界越紧。

#### A.5.3 NWJ 估计 (Nguyen-Wainwright-Jordan)

**NWJ** 是 MINE 的"无偏变种":
$$
\hat{I}_{\text{NWJ}} = \mathbb{E}_{p(x,y)}[T(x,y)] - \mathbb{E}_{p(x)p(y)}[e^{T(x,y) - 1}]
$$

梯度更稳定,不需要 EMA。

```python
def nwj_lower_bound(x, y, critic):
    """NWJ 互信息下界"""
    joint = critic(x, y)
    # 边际: shuffle
    y_marg = y[torch.randperm(y.size(0))]
    marginal = critic(x, y_marg)

    # NWJ 估计
    return joint.mean() - (torch.exp(marginal - 1)).mean()
```

#### A.5.4 KSG 估计 (基于 KNN)

**KSG** (Kraskov-Stögbauer-Grassberger, 2004): 基于 K-近邻的互信息估计,无偏,但高维灾难。

```python
import numpy as np
from sklearn.neighbors import NearestNeighbors

def ksg_mi(x, y, k=3):
    """KSG 互信息估计 (简化版)"""
    n = len(x)
    x = x.reshape(-1, 1) if x.ndim == 1 else x
    y = y.reshape(-1, 1) if y.ndim == 1 else y
    xy = np.hstack([x, y])

    # K 近邻
    nbrs = NearestNeighbors(n_neighbors=k+1).fit(xy)
    distances, _ = nbrs.kneighbors(xy)
    eps = distances[:, k]  # 第 k 个邻居的距离

    # 各自的 K 近邻数
    nx = NearestNeighbors(n_neighbors=k).fit(x)
    ny = NearestNeighbors(n_neighbors=k).fit(y)
    nx_count = np.array([len(nx.radius_neighbors([xi], radius=ei)[0]) - 1
                         for xi, ei in zip(x, eps)])
    ny_count = np.array([len(ny.radius_neighbors([yi], radius=ei)[0]) - 1
                         for yi, ei in zip(y, eps)])

    # KSG 公式
    mi = np.digamma(k) + np.digamma(n) - np.mean(np.digamma(nx_count + 1) + np.digamma(ny_count + 1))
    return max(0, mi)
```

**坑**: KSG 在**高维** (dim > 20) 会严重低估互信息,因为"维度灾难"让 KNN 距离分布都差不多。**深度学习用 MINE / InfoNCE,不用 KSG**。

### A.6 信息论与 VAE / Diffusion 的深入连接

#### A.6.1 VAE 的 ELBO 推导:信息论视角

**VAE 目标**: 最大化 $\log p(x)$。

**ELBO**:
$$
\log p(x) \geq \mathbb{E}_{q(z|x)}[\log p(x|z)] - D_{\text{KL}}(q(z|x) \| p(z))
$$

**信息论解读**:

- **重建项** $\mathbb{E}_{q(z|x)}[\log p(x|z)]$: 用 $z$ 重建 $x$ 的对数似然
- **正则项** $D_{\text{KL}}(q(z|x) \| p(z))$: 让 encoder 接近先验

**互信息视角**:

ELBO 还可以写成:
$$
\text{ELBO} = \mathbb{E}_{p(x)}[\log p(x)] - D_{\text{KL}}(q(z|x) \| p(z|x))
$$

也就是说, ELBO 损失 = 重构损失 + KL 距离**真正的**后验 vs **近似的**后验。

更深入: VAE 的隐变量 $z$ 和 $x$ 的互信息:
$$
I(z; x) = \mathbb{E}_{p(x)}[D_{\text{KL}}(q(z|x) \| p(z))]
$$

这是 ELBO 中 KL 项的**期望**!所以 KL 项 = 隐变量和数据的"信息量"。

**PyTorch 实现**:

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class VAE(nn.Module):
    def __init__(self, input_dim, hidden_dim, latent_dim):
        super().__init__()
        # Encoder
        self.fc_e1 = nn.Linear(input_dim, hidden_dim)
        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)
        # Decoder
        self.fc_d1 = nn.Linear(latent_dim, hidden_dim)
        self.fc_out = nn.Linear(hidden_dim, input_dim)

    def encode(self, x):
        h = F.relu(self.fc_e1(x))
        return self.fc_mu(h), self.fc_logvar(h)

    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        return mu + eps * std

    def decode(self, z):
        h = F.relu(self.fc_d1(z))
        return torch.sigmoid(self.fc_out(h))

    def forward(self, x):
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar)
        recon = self.decode(z)

        # 重构损失 (Bernoulli)
        recon_loss = F.binary_cross_entropy(recon, x, reduction='sum')
        # KL 散度
        kl = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
        return recon, mu, logvar, recon_loss, kl

# 训练
model = VAE(784, 400, 20)
opt = torch.optim.Adam(model.parameters(), lr=1e-3)

for epoch in range(50):
    for x, _ in dataloader:  # MNIST
        x = x.view(-1, 784)
        recon, mu, logvar, recon_loss, kl = model(x)
        loss = recon_loss + kl  # 负 ELBO
        opt.zero_grad()
        loss.backward()
        opt.step()
```

#### A.6.2 β-VAE: KL 项的"权重"控制了什么?

**β-VAE** (Higgins et al., 2017):
$$
\mathcal{L}_{\beta\text{-VAE}} = \mathbb{E}_{q(z|x)}[\log p(x|z)] - \beta D_{\text{KL}}(q(z|x) \| p(z))
$$

- $\beta = 1$: 标准 VAE
- $\beta > 1$: 更强的正则化 → 更"解耦"的表示 → 信息瓶颈效果
- $\beta < 1$: 更弱的正则化 → 更接近自编码器

**信息论解释**: $\beta$ 控制隐变量和输入的互信息 $I(z; x)$。

**Rate-Distortion** 视角:
$$
R(\beta) = \min_q I(z; x) \quad \text{s.t.} \quad \mathbb{E}_{p(x)}[\mathbb{E}_{q(z|x)}[-\log p(x|z)]] \leq D
$$

- $R$ = rate (信息量, bits)
- $D$ = distortion (失真)
- 凸函数 $R(D)$ 就是**率失真曲线**

VAE / β-VAE / VQ-VAE / Diffusion **全都是率失真曲线的不同参数化**。

#### A.6.3 Diffusion 的信息论视角

**Diffusion** (DDPM, Ho et al. 2020): 通过逐步加噪 → 去噪,学到数据分布。

**信息论视角**:

- **前向过程**: $x_0 \to x_1 \to ... \to x_T$ 是"信息衰减"过程: $I(x_t; x_0)$ 单调递减
- **反向过程**: $x_T \to ... \to x_0$ 是"信息恢复"过程
- **训练目标**: 预测噪声 = 预测 $I(x_t; x_0)$ 的损失
- **Score matching** = 估计 $\nabla_x \log p(x)$ = Fisher 信息

**和 VAE 的关系**: Diffusion 是**层级 VAE** (hierarchical VAE),$T$ 步隐变量。

**率失真视角**:
$$
\mathcal{L}_{\text{DDPM}} = \mathbb{E}_{t, x_0, \epsilon}\left[\|\epsilon - \epsilon_\theta(\sqrt{\bar\alpha_t} x_0 + \sqrt{1 - \bar\alpha_t} \epsilon, t)\|^2\right]
$$

这等价于**变分下界** (VLB) 的简化,VLB 是 KL 散度在每个时间步的累加。

### A.7 信息瓶颈 (IB) 与深度学习

#### A.7.1 IB 目标重述

$$
\mathcal{L}_{\text{IB}} = I(X; Z) - \beta I(Z; Y)
$$

**直觉**: 找一个表示 $Z$, 压缩 $X$ 但保留对 $Y$ 的预测能力。

#### A.7.2 深度 IB (VIB)

**VIB** (Alemi et al., 2017): 用神经网络实现 IB。

$$
\mathcal{L}_{\text{VIB}} = \mathbb{E}_{p(x)}[D_{\text{KL}}(q(z|x) \| p(z))] - \beta \mathbb{E}_{p(x, y)}[\log q(y|z)]
$$

- 第一项: 隐变量接近先验
- 第二项: 预测 $y$

**PyTorch 实现**:

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class VIB(nn.Module):
    """Variational Information Bottleneck"""
    def __init__(self, x_dim, z_dim, y_dim, hidden=256):
        super().__init__()
        # Encoder p(z|x)
        self.encoder = nn.Sequential(
            nn.Linear(x_dim, hidden), nn.ReLU(),
            nn.Linear(hidden, 2 * z_dim)  # 输出 mu, logvar
        )
        # Decoder q(y|z)
        self.decoder = nn.Sequential(
            nn.Linear(z_dim, hidden), nn.ReLU(),
            nn.Linear(hidden, y_dim)
        )
        self.z_dim = z_dim

    def forward(self, x):
        params = self.encoder(x)
        mu, logvar = params[:, :self.z_dim], params[:, self.z_dim:]
        # 重参数化
        z = mu + torch.exp(0.5 * logvar) * torch.randn_like(mu)
        y_pred = self.decoder(z)
        return y_pred, mu, logvar

def vib_loss(y_pred, y_true, mu, logvar, beta=1e-3):
    # 重建 / 预测损失
    pred_loss = F.cross_entropy(y_pred, y_true)
    # KL 散度 (高斯)
    kl = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    return pred_loss + beta * kl

# 训练
model = VIB(x_dim=784, z_dim=64, y_dim=10)
opt = torch.optim.Adam(model.parameters(), lr=1e-3)

for x, y in dataloader:
    y_pred, mu, logvar = model(x.view(-1, 784))
    loss = vib_loss(y_pred, y, mu, logvar, beta=1e-3)
    opt.zero_grad()
    loss.backward()
    opt.step()
```

#### A.7.3 对比学习 = IB 的下界

**SimCLR** (Chen et al., 2020) 的 loss:
$$
\mathcal{L}_{\text{SimCLR}} = -\log \frac{\exp(s(z_i, z_j)/\tau)}{\sum_k \exp(s(z_i, z_k)/\tau)}
$$

**信息论解释**: 这是 InfoNCE loss, 是 $I(z; y)$ 的下界(其中 $y$ 是"哪个是正样本")。

**IB 联系**: 对比学习 = **隐式地**最大化互信息下界 + 最小化表示冗余。

- 拉近正样本对 → 保留共享信息
- 推远负样本对 → 丢弃无关信息
- temperature $\tau$ 控制分布锐度 → 影响互信息估计的偏-方差

#### A.7.4 CLIP:跨模态互信息

**CLIP** (Radford et al., 2021): 学习图像和文本的共享表示。

**信息论目标**: 最大化
$$
I(\text{图像}; \text{文本}) \approx \log(\text{batch size}) - \mathcal{L}_{\text{CLIP}}
$$

- $I$ 越大, 跨模态对齐越好
- 实际上, CLIP 的 InfoNCE loss + 双向 = 互信息下界

**PyTorch 实现**:

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class CLIP(nn.Module):
    def __init__(self, image_dim, text_dim, embed_dim=512, temperature=0.07):
        super().__init__()
        self.image_proj = nn.Linear(image_dim, embed_dim)
        self.text_proj = nn.Linear(text_dim, embed_dim)
        self.logit_scale = nn.Parameter(torch.log(torch.tensor(1/temperature)))

    def forward(self, image_feat, text_feat):
        image_emb = F.normalize(self.image_proj(image_feat), dim=1)
        text_emb = F.normalize(self.text_proj(text_feat), dim=1)

        # 余弦相似度
        logits = image_emb @ text_emb.T * self.logit_scale.exp()
        return logits

def clip_loss(logits):
    """对称 InfoNCE"""
    n = logits.size(0)
    labels = torch.arange(n, device=logits.device)
    loss_i2t = F.cross_entropy(logits, labels)
    loss_t2i = F.cross_entropy(logits.T, labels)
    return (loss_i2t + loss_t2i) / 2

# 训练
clip = CLIP(image_dim=2048, text_dim=768)
opt = torch.optim.Adam(clip.parameters(), lr=1e-4)

for image_feat, text_feat in dataloader:
    logits = clip(image_feat, text_feat)
    loss = clip_loss(logits)
    opt.zero_grad()
    loss.backward()
    opt.step()
```

### A.8 信道容量 (Channel Capacity) 简介

#### A.8.1 什么是信道?

**信道**: $X \to Y$ 的条件分布 $p(y|x)$。

**例子**:
- 二元对称信道 (BSC): $p(y \neq x) = \epsilon$, $\epsilon$ 是翻转概率
- 加性高斯白噪声 (AWGN): $y = x + z$, $z \sim \mathcal{N}(0, \sigma^2)$
- 有损压缩: $p(\hat{x}|x)$ 是编码器 + 量化器

#### A.8.2 信道容量

**信道容量**: 信道能传输的最大信息率:
$$
C = \max_{p(x)} I(X; Y)
$$

**二元对称信道**:
$$
C_{\text{BSC}} = 1 - H(\epsilon)
$$

其中 $H(\epsilon) = -\epsilon \log \epsilon - (1-\epsilon) \log (1-\epsilon)$。

**AWGN**:
$$
C_{\text{AWGN}} = \frac{1}{2} \log\left(1 + \frac{P}{\sigma^2}\right)
$$

其中 $P$ 是信号功率, $\sigma^2$ 是噪声方差。

**工程意义**: 信道容量是**任何编码**能达到的速率上界(Shannon 第二定理)。

#### A.8.3 信道容量与神经网络

直觉类比:
- 神经网络层 = 信道
- 输入 $X$ → 输出 $Y$ → 互信息 $I(X; Y)$ = "这一层保留了多少信息"
- 深度学习 = 设计一个**好信道**, 让 $I(X; Y)$ 接近 $H(X)$ 但 $I(Y; \text{label})$ 大

**信息瓶颈 (IB) 和信道的联系**: IB 优化的是 $I(X; Z) - \beta I(Z; Y)$。当 $Z = Y$ 时(完美分类器), $I(X; Y)$ 是"信道"的有效带宽。

### A.9 率失真理论 (Rate-Distortion) 入门

#### A.9.1 核心问题

给定信源 $X \sim p(x)$, 找一个编码器 $q(\hat{x}|x)$ 让:

$$
\min_q I(X; \hat{X}) \quad \text{s.t.} \quad \mathbb{E}[d(X, \hat{X})] \leq D
$$

- $I(X; \hat{X})$ = 编码的**比特率** (rate)
- $d(X, \hat{X})$ = **失真** (distortion)
- $D$ = 允许的最大失真

率失真函数 $R(D)$ 描述最小率 vs 失真的权衡曲线。

#### A.9.2 高斯信源的率失真

如果 $X \sim \mathcal{N}(0, \sigma^2)$ 且 $d(x, \hat{x}) = (x - \hat{x})^2$:

$$
R(D) = \max\left(0, \frac{1}{2} \log \frac{\sigma^2}{D}\right)
$$

- $D = 0$: 无失真, $R \to \infty$
- $D = \sigma^2$: 失真和原信号一样大, $R = 0$ (用常数近似)

#### A.9.3 Rate-Distortion 与 VAE / Diffusion

**VAE**:
$$
R(D) = \min_q I(X; Z) \quad \text{s.t.} \quad \mathbb{E}[\text{recon error}] \leq D
$$

β-VAE 的 $\beta$ 就是 rate-distortion 权衡的"价格":

- 大 $\beta$ → 小 rate → 强压缩 → 失真大
- 小 $\beta$ → 大 rate → 弱压缩 → 失真小

**Diffusion**: 多步 VAE, $R(D)$ 曲线是**凸包络**。

#### A.9.4 Rate-Distortion Perceptron (RDP) 视角

**Blau & Michaeli, 2019**: 不同失真度量对应不同的率失真曲线。

- **MSE 失真**: 产生模糊图像
- **感知失真** (LPIPS): 产生锐利、真实图像
- **对抗失真** (GAN): 进一步提升感知质量

工程启示: 选什么失真度量 = 选率失真曲线 = 选图像质量倾向。

### A.10 f-散度家族总览

#### A.10.1 表格总结

| 散度 | $f(t)$ | 对称 | 边界 | 工程应用 |
| :--- | :--- | :--- | :--- | :--- |
| KL ($p \| q$) | $t \log t$ | ❌ | $[0, \infty)$ | VAE, MLE |
| KL ($q \| p$) | $-\log t$ | ❌ | $[0, \infty)$ | Wake-Sleep |
| JS | $\frac{1}{2}[(t+1)\log\frac{t+1}{2} - t\log t]$ | ✅ | $[0, \log 2]$ | 原始 GAN |
| Hellinger | $(\sqrt{t} - 1)^2$ | ✅ | $[0, 2]$ | 鲁棒估计 |
| TV | $\frac{1}{2}\|t - 1\|$ | ✅ | $[0, 1]$ | 假设检验 |
| $\chi^2$ | $(t-1)^2$ | ❌ | $[0, \infty)$ | 假设检验, 重要性加权 |
| Rényi $\alpha$ | $\frac{t^\alpha - 1}{\alpha(\alpha-1)}$ | ❌ | $[0, \infty)$ | 信息论, Rényi 熵 |

#### A.10.2 f-GAN (Nowozin et al., 2016)

**f-GAN**: 把 GAN 推广到任意 f-散度。

**目标**:
$$
\min_G \max_D \mathbb{E}_{p_{\text{data}}}[D(x)] - \mathbb{E}_{p_z}[f^*(D(G(z)))]
$$

其中 $f^*$ 是 $f$ 的 Fenchel 共轭, $D$ 是判别器 (输出任意实数)。

**特例**:
- $f(t) = t \log t$ (KL): GAN 等价于 JS-GAN
- $f(t) = \|t-1\|$ (TV): 训练困难
- $f(t) = (t-1)^2$ ($\chi^2$): 对应 LSGAN

#### A.10.3 实战: 选哪种 f-散度?

| 场景 | 推荐散度 | 原因 |
| :--- | :--- | :--- |
| MLE / 监督学习 | KL (前向) | MLE = 最小化 KL |
| VAE | KL (前向) | 推导简洁, mode-covering |
| GAN | Wasserstein / JS | 高维不退化 |
| 强化学习 | KL (反向) | 信任域 / TRPO |
| 知识蒸馏 | KL (前向) | 让学生学老师的分布 |
| 鲁棒估计 | Hellinger | 抗 outlier |
| 假设检验 | TV | 最优检验统计量 |

### A.11 互信息与因果推断

#### A.11.1 互信息 vs 因果关系

**重要警告**: $I(X; Y) > 0$ **不能**推出 $X$ 导致 $Y$。

**三种可能的因果**:
1. $X \to Y$ (因果)
2. $Y \to X$ (反因果)
3. $X \leftarrow Z \to Y$ (共同原因, confounding)

三者**都**会让 $I(X; Y) > 0$。

**条件互信息** $I(X; Y | Z)$ 可以区分:
- $X \to Y$, 条件化 $Z$ 不影响 $I(X; Y | Z)$
- $X \leftarrow Z \to Y$ (confounding), 条件化 $Z$ 让 $I(X; Y | Z) \approx 0$

#### A.11.2 PC 算法: 用条件互信息发现因果图

**PC 算法** (Spirtes-Glymour, 1991):
1. 完全图: 所有变量两两相连
2. 对每对 $(X_i, X_j)$, 测试 $I(X_i; X_j) = 0$ → 删边
3. 对每个三元组 $(X_i, X_j, X_k)$, 测试 $I(X_i; X_j | X_k) = 0$ → 删边
4. 定向边: 避免 v-structure (collider)

**坑**: 高维时,条件互信息估计**不可靠**。需要大量样本。

#### A.11.3 因果信息流 (Causal Information Flow)

**信息流** (Ay & Polani, 2008):
$$
C_{X \to Y} = I(X; Y) - I(X; Y | \text{do}(X))
$$

其中 $\text{do}(X)$ 是 do-calculus 的干预。

**直觉**: $C_{X \to Y}$ 是"$X$ 对 $Y$ 的因果贡献",排除了反向因果和 confounding。

工程应用: 因果发现、强化学习中的"信用分配"。

### A.12 互信息在特征选择中的应用

#### A.12.1 mRMR (Minimum Redundancy Maximum Relevance)

**mRMR** (Peng et al., 2005): 选特征子集 $S$ 最大化:

$$
\max_S \frac{1}{|S|} \sum_{x_i \in S} I(x_i; y) - \frac{1}{|S|^2} \sum_{x_i, x_j \in S} I(x_i; x_j)
$$

- 第一项: **相关性** (Relevance) = 特征和目标的互信息
- 第二项: **冗余** (Redundancy) = 特征之间的互信息

直观: 选"对目标有用,彼此不冗余"的特征。

```python
import numpy as np
from sklearn.feature_selection import mutual_info_regression

def mrmr_feature_selection(X, y, k=10):
    """mRMR 特征选择 (greedy)"""
    n_features = X.shape[1]
    selected = []
    candidates = list(range(n_features))

    # 第一轮: 选 MI(y; x_i) 最大的
    mi_with_y = mutual_info_regression(X, y)
    first = np.argmax(mi_with_y)
    selected.append(first)
    candidates.remove(first)

    # 后续轮: 选 (MI(y; x_i) - 平均 MI(x_i; x_j)) 最大的
    while len(selected) < k:
        scores = []
        for c in candidates:
            # 和 y 的 MI
            mi_y = mutual_info_regression(X[:, [c]], y)[0]
            # 和已选特征的平均 MI
            mi_x = np.mean([mutual_info_regression(X[:, [c]], X[:, [s]])[0]
                            for s in selected])
            scores.append(mi_y - mi_x)
        best = candidates[np.argmax(scores)]
        selected.append(best)
        candidates.remove(best)

    return selected
```

#### A.12.2 JMI (Joint Mutual Information)

**JMI** (Yang & Moody, 1999): 用联合互信息:
$$
JMI = \sum_{x_j \in S} I(x_i, x_j; y)
$$

选一个特征 $x_i$ 让它和已选特征的**组合**最大化互信息 $y$。

**和 mRMR 的对比**: JMI 选"组合后提供新信息"的特征,比 mRMR 更"协作"。

### A.13 常见工程坑: 信息论的"反直觉"

#### A.13.1 "低熵"不等于"好模型"

**反直觉**: 在分类中, 模型输出的**预测熵**低通常意味着"自信"。但**过自信** (overconfident) 是问题:
- 模型说: 99% 是猫, 1% 是狗
- 但实际上: 80% 是猫, 20% 是狗 (label smoothing 应该用)

**正确的"低熵"使用**:
- **测试时**: 预测熵高 = 模型不确定 → 让人类介入
- **训练时**: 用 label smoothing 防止熵过低
- **校准**: 校准后的熵才反映真实置信度

#### A.13.2 "低 KL"不等于"好生成"

**反直觉**: VAE 训练时 KL 项会下降,但**降太快**意味着"后验坍缩" (posterior collapse):
- encoder 输出 $q(z|x) \approx p(z)$ (忽略输入 $x$)
- 重建项必然很差
- KL 低但生成也是常数

**正确做法**: 监控重建项 + KL 项的**联合**下降,单独看 KL 没意义。

#### A.13.3 "高互信息"不等于"好表示"

**反直觉**: SimCLR 的 InfoNCE loss 低 → 互信息下界高 → **不**等于"好表示"。

**为什么**: InfoNCE 估计的是**互信息的下界**, 不是互信息本身。下界紧 ≠ 表示好。**评估表示**要看下游任务 (linear probe, kNN)。

#### A.13.4 "困惑度低"不等于"好语言模型"

**反直觉**: 训练集困惑度低 = 模型过拟合。**测试集**困惑度才是关键。

**正确流程**:
1. 训练集 PPL 持续下降
2. 验证集 PPL 降到最低点
3. 测试集 PPL (在验证集调好的超参下)
4. **不要在测试集上调超参!**

#### A.13.5 PPL 的"分布偏移"问题

**反直觉**: 在 Wikipedia 上训练的 PPL 30, 在 ArXiv 上 PPL 80。这**不是**模型变差, 是**分布偏移**。

**正确做法**:
- 报告 PPL **必须**说明是哪个数据集
- 跨数据集的 PPL 不可比
- PPL 的"绝对值"无意义, "相对值"才有用 (如: A 比 B 好)

### A.14 信息论与最优化

#### A.14.1 KL 散度 = 凸函数

KL 散度 $D_{\text{KL}}(p \| q)$ 在 $p$ 上是凸的, 在 $q$ 上也是凸的。

**工程意义**:
- KL 散度优化 → 凸优化 → 有全局最优
- 实际中, 期望用蒙特卡洛近似 → 凸性丧失
- 但很多算法 (EM, VAE) 仍有良好的收敛性质

#### A.14.2 互信息的对偶表示

**Donsker-Varadhan (DV) 表示**:
$$
I(X; Y) = \sup_{T} \mathbb{E}_{p(x, y)}[T(x, y)] - \log \mathbb{E}_{p(x) p(y)}[e^{T(x, y)}]
$$

这是 MINE 的基础。

**应用**: 用神经网络 $T_\theta$ 逼近最优 $T$, 训练出**可微的**互信息估计。

#### A.14.3 f-散度的对偶

$$
D_f(p \| q) = \sup_{T} \mathbb{E}_p[T(x)] - \mathbb{E}_q[f^*(T(x))]
$$

其中 $f^*$ 是 Fenchel 共轭。**GAN 的判别器** $D$ 就是 $T$ 的神经网络近似。

### A.15 信息论在强化学习中的应用

#### A.15.1 策略互信息 (Policy Mutual Information)

**状态-动作互信息**:
$$
I(S; A) = \mathbb{E}_{p(s, a)}\left[\log \frac{\pi(a|s)}{p(a)}\right]
$$

- $I(S; A)$ 大: 策略"依赖状态"
- $I(S; A)$ 小: 策略"随机"

**工程应用**: Soft Actor-Critic (SAC) 最大化:
$$
J_\pi = \mathbb{E}\left[\sum_t r(s_t, a_t) + \alpha I(S_t; A_t)\right]
$$

其中 $\alpha$ 控制"探索度": 大 $\alpha$ → 高互信息 → 多样化探索。

#### A.15.2 信任域策略优化 (TRPO / PPO)

**TRPO** 用 KL 散度约束策略更新:
$$
\max_\pi \mathbb{E}_\pi[r(s, a)] \quad \text{s.t.} \quad D_{\text{KL}}(\pi_{\text{old}} \| \pi) \leq \delta
$$

**信息论解释**: 限制每步更新的"信息量", 保证策略不"突变"。

**PPO** 用 clipped surrogate:
$$
L^{CLIP}(\theta) = \mathbb{E}_t[\min(r_t(\theta) A_t, \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon) A_t)]
$$

其中 $r_t(\theta) = \pi_\theta(a_t|s_t) / \pi_{\text{old}}(a_t|s_t)$ 是策略比。

直觉: $r_t \approx 1$ 时, 不更新; $r_t$ 偏离 1 时, 限幅。这等价于"近似的 KL 约束"。

#### A.15.3 好奇心驱动探索 (ICM)

**ICM** (Intrinsic Curiosity Module, Pathak et al., 2017):
- 训练一个"前向模型" 预测 $s_{t+1}$ from $(s_t, a_t)$
- 预测误差 = "好奇心奖励"
- 鼓励访问"难预测"的状态

**信息论解释**: 好奇心 = 互信息 $I(a; s_{t+1} | s_t)$ 的上界 (因为 $I \leq H$ 预测误差的期望)。

### A.16 信息论与图模型

#### A.16.1 马尔可夫网络的能量函数

**马尔可夫随机场** (MRF) 的联合分布:
$$
p(x) = \frac{1}{Z} \exp\left(-\sum_c E_c(x_c)\right)
$$

其中 $Z$ 是配分函数, $E_c$ 是团 (clique) 的能量。

**和熵的关系**:
$$
\log Z = -H(X) - \mathbb{E}_p\left[\sum_c E_c(x_c)\right]
$$

- $Z$ 大 → 熵 $H$ 大 → 系统"分散"
- $Z$ 小 → 熵 $H$ 小 → 系统"集中"

**工程**: 配分函数的估计是 MRF 训练的核心困难。**对比散度 (Contrastive Divergence, CD-k)** 是 Hinton 提出的快速估计方法。

#### A.16.2 信念传播 (Belief Propagation, BP)

**BP** 在图模型上传递"消息":
$$
m_{i \to j}(x_j) = \sum_{x_i} \phi_i(x_i) \phi_{ij}(x_i, x_j) \prod_{k \in N(i) \setminus j} m_{k \to i}(x_i)
$$

**信息论解释**: 每条消息是"局部信念",在图上传播后, 收敛到**边缘分布**或**最优 MAP 估计**。

**工程**: PyTorch Geometric 实现了多种 BP / GNN 变体。

#### A.16.3 变分自编码器 (VAE) 回顾

(已在 A.6.1 详细讨论, 这里补充一些细节。)

**ELBO 的两种推导**:

1. **Jensen 不等式**:
   $$
   \log p(x) = \log \int p(x|z) p(z) dz = \log \int q(z|x) \frac{p(x|z) p(z)}{q(z|x)} dz
   $$
   $$
   \geq \int q(z|x) \log \frac{p(x|z) p(z)}{q(z|x)} dz = \text{ELBO}
   $$

2. **KL 散度**:
   $$
   D_{\text{KL}}(q(z|x) \| p(z|x)) = \mathbb{E}_q[\log q(z|x) - \log p(z|x)]
   $$
   $$
   = \mathbb{E}_q[\log q(z|x) - \log p(x|z) - \log p(z)] + \log p(x)
   $$
   $$
   \Rightarrow \log p(x) - D_{\text{KL}}(q \| p(z|x)) = \text{ELBO}
   $$

**结论**: 最大化 ELBO = 最小化 $D_{\text{KL}}(q(z|x) \| p(z|x))$。

### A.17 信息论与对比学习的深入

#### A.17.1 SimCLR / MoCo / BYOL 的统一视角

| 方法 | 负样本 | 互信息下界 | 特点 |
| :--- | :--- | :--- | :--- |
| SimCLR | 显式 (大 batch) | InfoNCE | 简单, 依赖大 batch |
| MoCo | 字典 (队列) | InfoNCE | 小 batch 可用, momentum encoder |
| BYOL | 无 | 自蒸馏 | 不需要负样本, EMA target |
| SimSiam | 无 | Stop-gradient | 更简单, 仍有效 |
| Barlow Twins | 无 | 互相关矩阵 → 单位矩阵 | 损失设计独特 |
| VICReg | 无 | Variance-Invariance-Covariance Regularization | 三项损失 |

**信息论解释**: 所有这些方法**隐式地**最大化某种"互信息下界",但**显式的互信息**不重要,重要的是**下游任务表现**。

#### A.17.2 InfoNCE 的"温度"参数

**温度** $\tau$ 的作用:
$$
\text{logit}_{ij} = \frac{s(z_i, z_j)}{\tau}
$$

- $\tau$ 小 → 分布尖 → 关注"最难的负样本" → 难学但精确
- $\tau$ 大 → 分布平 → 关注"所有负样本" → 易学但粗糙

**经验值**:
- SimCLR: $\tau = 0.5$
- CLIP: $\tau = 0.07$ (可学习)
- MoCo: $\tau = 0.07$ 或 0.2

#### A.17.3 硬负样本 (Hard Negative Mining)

**硬负样本** = 和正样本相似但**不**是同一类的样本。

**信息论**: 硬负样本 = 互信息 $I(z_i; z_j)$ 接近 1 但**不是**正样本。

工程方法:
- **采样**: 从 batch 中选最相似的负样本
- **加权**: 给硬负样本更大权重
- **课程学习**: 训练初期用易负样本, 后期用硬负样本

**坑**: 太硬的负样本 → 模型学不到泛化, 只学"区分细微差别"。

### A.19 信息论与对抗鲁棒性

#### A.19.1 信息论视角的对抗攻击

**FGSM** (Fast Gradient Sign Method):
$$
x' = x + \epsilon \cdot \text{sign}(\nabla_x L(\theta, x, y))
$$

**信息论解释**: 在 $x$ 上加扰动 = 改变 $I(x; y)$? 不, 更准确:

对抗扰动试图在**保持 $I(x; y)$ 不变** (人类看不出差别) 的情况下, 让模型的**预测分布**变化。

**KL 散度视角**:
$$
\max_{\|\delta\| \leq \epsilon} D_{\text{KL}}(p_\theta(y|x) \| p_\theta(y|x+\delta))
$$

也就是: 在 $\epsilon$-ball 内找让模型预测变化最大的方向。

#### A.19.2 信息瓶颈与对抗鲁棒性

**IB 视角**: 鲁棒模型应该有**平滑的** $p(y|x)$。IB 强制 $I(Z; X)$ 小 → 表示压缩 → 对输入扰动不敏感。

**实验**: VIB 训练的模型比普通模型更鲁棒 (Alemi et al., 2017)。

### A.20 信息论的常见面试题

#### A.20.1 "熵、KL、互信息的关系"

**答案**:
$$
I(X; Y) = H(X) + H(Y) - H(X, Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)
$$

$$
H(p, q) = H(p) + D_{\text{KL}}(p \| q)
$$

$$
D_{\text{KL}}(p(x, y) \| p(x) p(y)) = I(X; Y)
$$

#### A.20.2 "为什么交叉熵可以用作损失?"

**答案**: 交叉熵 = 熵 + KL。训练数据 $p$ 固定, 所以 $H(p)$ 常数, 最小化交叉熵 = 最小化 KL = MLE。

#### A.20.3 "为什么 KL 散度不对称?"

**答案**: KL 是"用 q 编码 p 的代价", 编码方向是单向的。前向 KL (mode-covering) 适合 VAE, 反向 KL (mode-seeking) 适合睡眠算法。

#### A.20.4 "InfoNCE 为什么是互信息下界?"

**答案**: InfoNCE = 负对数似然, 优化 InfoNCE = 拉近正样本对。互信息 = 联合分布 vs 独立的 KL 散度, 衡量"两个变量的相关性"。InfoNCE 通过分类"哪个是正样本"间接估计互信息。

#### A.20.5 "VAE 的 KL 项是正则化吗?"

**答案**: 部分是。KL 项让 $q(z|x)$ 接近先验 $p(z)$, 防止过拟合。但**主要**作用是让 $z$ 的分布"可采样", 让生成器能工作。

#### A.20.6 "对比学习为什么不需要标签?"

**答案**: "正样本"通过**数据增强**生成 (同一图像的两个 augmentation), "负样本"是 batch 中的其他图像。InfoNCE loss 让正样本对的表示更近, 负样本对的表示更远, 不需要人工标签。

#### A.20.7 "Wasserstein 距离为什么比 JS 散度更适合 GAN?"

**答案**: 当真实分布和生成分布的支撑不相交时, JS 散度恒为 $\log 2$ (梯度消失), Wasserstein 距离仍然有梯度, 提供更稳定的训练信号。

#### A.21.2 工具函数库

```python
import torch
import torch.nn.functional as F

def entropy_from_logits(logits):
    """从 logits 计算预测熵 (bits)"""
    probs = F.softmax(logits, dim=-1)
    return -(probs * probs.log2()).sum(dim=-1)

def kl_categorical(p_logits, q_logits):
    """两个分类分布的 KL 散度"""
    p_log = F.log_softmax(p_logits, dim=-1)
    q_log = F.log_softmax(q_logits, dim=-1)
    p = p_log.exp()
    return (p * (p_log - q_log)).sum(dim=-1)

def js_distance(p, q):
    """JS 距离 (对称, 0 到 1)"""
    m = 0.5 * (p + q)
    return 0.5 * (F.kl_div(m.log(), p, reduction='batchmean') +
                   F.kl_div(m.log(), q, reduction='batchmean')) / 2

def info_nce(z1, z2, temperature=0.5):
    """对称 InfoNCE loss"""
    z1 = F.normalize(z1, dim=1)
    z2 = F.normalize(z2, dim=1)
    sim = z1 @ z2.T / temperature
    labels = torch.arange(z1.size(0), device=z1.device)
    return 0.5 * (F.cross_entropy(sim, labels) + F.cross_entropy(sim.T, labels))

def perplexity(loss):
    """loss -> perplexity (nats)"""
    return torch.exp(loss)
```

### A.22 信息论与因果涌现 (Causal Emergence)

#### A.22.1 什么是因果涌现?

**因果涌现** (Causal Emergence, Hoel et al., 2013): 宏观尺度的因果效应**强于**微观尺度。

**信息论指标**: **有效信息 (Effective Information, EI)**:
$$
EI = I(M_{\text{macro}}; M_{\text{macro}}') = \sum_{s} p(s) D_{\text{KL}}(p(s'|s) \| p(s'))
$$

其中 $p(s')$ 是"扰动后的分布", $p(s'|s)$ 是"从 $s$ 转移的条件分布"。

**直觉**: EI 大 = 系统对扰动"敏感" = 因果效应强 = 涌现。

#### A.22.2 工程应用: 神经网络压缩与可解释性

**发现**: 在某些神经网络中, 把多个神经元合并成一个"宏观变量", EI 反而增加 = **因果涌现**。

**工程意义**:
- 找到涌现的宏观变量 = 找到可解释的特征
- 用宏观变量重新训练 = 网络压缩 + 性能保持

这是**机械学习 (Mechanistic Interpretability)** 的核心。

### A.23 信息论与贝叶斯优化

#### A.23.1 期望改进 (Expected Improvement, EI)

**贝叶斯优化** 的核心是"获取函数" (acquisition function):

$$
EI(x) = \mathbb{E}[\max(f(x) - f^*, 0)]
$$

**信息论解释**: 最大化 $EI$ = 最大化"信息增益" (information gain):
$$
IG(x) = I(y; f(x) | D)
$$

其中 $D$ 是已观测数据。

**更直接的**: 最大化互信息 $I(y; x | D)$ = 选最"信息量大"的点评估。

#### A.23.2 信息论获取函数

- **Max Entropy Search**: 最大化 $H(y | D \cup \{x\})$ (最小化"观测后的熵")
- **Predictive Entropy Search**: 类似的思路
- **Knowledge Gradient**: 选"对未来最优解贡献最大"的点

**工程**: BoTorch (PyTorch 贝叶斯优化库) 实现了这些获取函数。

### A.24 信息论与异常检测

#### A.24.1 基于熵的异常检测

**KL 散度异常检测**:
- 训练: 估计正常数据分布 $p$
- 检测: 异常数据 $x$ 有 $D_{\text{KL}}(p_x \| p)$ 大 → 标记

**单类 SVM vs 信息论**:
- 单类 SVM: 学习一个边界
- 信息论方法: 学习正常数据的分布, 用 KL / 互信息检测

#### A.24.2 自回归模型的异常分数

**Density Estimation** 视角:
$$
\text{score}(x) = -\log p_\theta(x) = \sum_i -\log p_\theta(x_i | x_{<i})
$$

- 正常数据: 概率高, 分数低
- 异常数据: 概率低, 分数高

**应用**:
- 时序异常检测 (LSTM, Transformer)
- 图像异常检测 (PixelCNN, GPT-3 for code)

```python
def autoregressive_anomaly_score(model, x):
    """自回归模型的异常分数"""
    # x: (seq_len,)
    total_nll = 0
    for t in range(len(x)):
        pred = model(x[:t])  # 预测 x[t]
        nll = F.cross_entropy(pred, x[t:t+1])
        total_nll += nll.item()
    return total_nll
```

### A.25 信息论与决策树

#### A.25.1 信息增益 (Information Gain)

**决策树** (ID3, C4.5) 用**信息增益**选特征:
$$
IG(D, A) = H(D) - H(D | A) = H(D) - \sum_v \frac{|D_v|}{|D|} H(D_v)
$$

- $H(D)$: 数据集的不确定性
- $H(D | A)$: 按特征 $A$ 划分后的不确定性

**直观**: 选让不确定性减少最多的特征。

#### A.25.2 基尼系数 vs 信息熵

**基尼不纯度 (Gini Impurity)**:
$$
\text{Gini}(D) = 1 - \sum_k p_k^2
$$

**比较**:
- 信息熵: $H(D) = -\sum p_k \log p_k$
- 基尼: $\text{Gini}(D) = 1 - \sum p_k^2$

**性质**:
- 两者在 $p$ 均匀时都最大
- 基尼是熵的一阶泰勒近似
- 基尼计算更快 (没有 log)
- 信息熵对"概率差异"更敏感

**CART 算法** 用基尼, **ID3/C4.5** 用信息熵。**XGBoost 默认基尼**, 可切换。

```python
from sklearn.tree import DecisionTreeClassifier

# 信息熵
clf_entropy = DecisionTreeClassifier(criterion='entropy')
# 基尼
clf_gini = DecisionTreeClassifier(criterion='gini')
```

### A.26 信息论与神经网络初始化

#### A.26.1 Xavier / He 初始化的信息论解释

**Xavier 初始化** (Glorot):
$$
W \sim \mathcal{N}\left(0, \frac{2}{n_{\text{in}} + n_{\text{out}}}\right)
$$

**信息论解释**: 保持前向和反向传播时激活值的**方差一致**, 避免信号消失或爆炸。

**等价的互信息视角**: 保持层与层之间的**互信息** $I(z_l; z_{l+1})$ 在合理范围。

**Saxe et al., 2018**: 深度网络的"信息动力学":
- 初始: 各层互信息 ≈ 输入互信息
- 训练: 浅层互信息增加, 深层 (Tishby 信息瓶颈) 互信息减少
- 收敛: 各层互信息稳定

#### A.26.2 信息论视角的 BatchNorm

**BatchNorm** 的作用:
- 归一化激活值, 让分布更"稳定"
- 信息论解释: 限制激活值的**微分熵**, 防止过大或过小

**替代**:
- **LayerNorm**: 每层归一化, 不依赖 batch
- **GroupNorm**: 介于 BN 和 LN
- **信息论归一化**: 直接最小化激活值的熵 (理论)

### A.28 信息论的"哲学"反思

#### A.28.1 "信息"是什么? (工程师的答案)

**香农 (1948) 的答案**: 信息是"减少不确定性的量", 数学上等于 $-\log p$。

**工程师的答案**:
- 信息 = 你不知道但想知道的东西
- 信息量 = 那个东西的"意外程度"
- 信息论 = 用概率论度量"信息量"的工具

#### A.28.2 "信息"与"意义"

**反问**: "太阳从东边升起" 是 0 信息。但它**有意义** (是物理定律的体现)。

**答案**: 信息论度量"概率的稀有度", **不**度量"意义"。意义是人类赋予的。

**工程启示**:
- 信息论 loss 优化"概率匹配", 不保证"意义匹配"
- 评估 LLM 不能只看 PPL, 还要看下游任务 (翻译、问答、推理)
- "信息"≠"智能", 但**没有信息**就没有智能

#### A.28.3 "最大熵"原则

Jaynes (1957) 提出 **最大熵原则**: 在已知约束下, 选**熵最大**的分布。

**为什么**: 熵最大 = 不确定性最大 = 不引入额外假设 = 最"诚实"的估计。

**工程例子**:
- 语言模型: 已知 n-gram, 选最大熵的语言模型 (最大熵语言模型, Berger et al. 1996)
- 推荐系统: 已知用户偏好, 选最大熵的推荐分布
- 物理: 已知总能量, 选最大熵的微观状态分布 (Boltzmann 分布)

**最大熵的"哲学"**: 不要假设超出已知的信息, 这是"奥卡姆剃刀"的概率版本。

### A.29 信息论与自然语言处理

#### A.29.1 困惑度 (PPL) 的局限

**PPL** 是语言模型的"标准"评估指标, 但**有局限**:

1. **不评估生成质量**: 一个 PPL=10 的模型可能生成"语法正确但无意义"的句子
2. **不评估事实性**: 模型可能生成流畅但**错误**的事实
3. **不评估多样性**: 模型可能生成重复、模板化的回答
4. **不评估安全性**: 可能生成有害内容

**补充评估**:
- **BLEU / ROUGE**: 文本相似度 (用于翻译、摘要)
- **BERTScore**: 语义相似度
- **Human Eval**: 人类评估
- **TruthfulQA**: 事实性
- **HHH**: Helpfulness, Honesty, Harmlessness

#### A.29.2 语言模型的"信息论"训练目标

**标准 MLE**:
$$
\mathcal{L}_{\text{MLE}} = -\sum_t \log p(x_t | x_{<t})
$$

**困惑度**: $\text{PPL} = \exp(\mathcal{L}_{\text{MLE}} / N)$

**带 label smoothing**:
$$
\mathcal{L}_{\text{LS}} = -\sum_t \left[(1-\epsilon) \log p(x_t) + \frac{\epsilon}{V} \sum_{v} \log p(v)\right]
$$

**带 contrastive** (SimCSE 风格):
$$
\mathcal{L}_{\text{CL}} = \mathcal{L}_{\text{MLE}} + \alpha \mathcal{L}_{\text{InfoNCE}}
$$

**DPO (Direct Preference Optimization)**:
$$
\mathcal{L}_{\text{DPO}} = -\log \sigma\left(\beta \log \frac{\pi_\theta(y_w | x)}{\pi_{\text{ref}}(y_w | x)} - \beta \log \frac{\pi_\theta(y_l | x)}{\pi_{\text{ref}}(y_l | x)}\right)
$$

其中 $y_w$ 是优选回答, $y_l$ 是劣选回答。**信息论解释**: DPO 隐式地最大化"优选回答的边际似然"。

### A.30 信息论与计算机视觉

#### A.30.1 图像的信息论评估

**图像 PPL** (类比文本 PPL):
- 用 PixelCNN / VQVAE 估计 $\log p(x)$
- PPL = $\exp(-\log p(x) / N)$ (N 是像素数)
- **BPC** (bits per character) = $-\log_2 p(x) / N$

**FID (Fréchet Inception Distance)**:
- 用 Inception 网络提取特征
- 假设特征服从高斯分布, 计算 Fréchet 距离
$$
\text{FID} = \|\mu_1 - \mu_2\|^2 + \text{Tr}\left(\Sigma_1 + \Sigma_2 - 2(\Sigma_1 \Sigma_2)^{1/2}\right)
$$

**信息论解释**: FID 衡量"生成分布和真实分布在 Inception 特征空间上的距离"。

**与 IS (Inception Score) 的对比**:
- IS: 衡量生成图像的"多样性 + 信心" → 高 IS 意味着多样且确定
- FID: 衡量生成分布和真实分布的距离 → 低 FID 意味着接近真实

#### A.30.2 自监督视觉模型的信息论视角

**DINO** (Caron et al., 2021):
- 老师-学生网络, 用不同 augmentation 训练
- 中心化 + softmax
- 目标: 让学生学老师的"知识"

**信息论解释**: 隐式最大化同一图像不同增强的**互信息**。

**MAE (Masked Autoencoder)** (He et al., 2022):
- 随机 mask 75% 的 patch
- 重建 masked patches
- 目标: 学到"上下文预测能力"

**信息论解释**: MAE 隐式最大化 $I(\text{可见 patches}; \text{masked patches})$。

### A.31 信息论与可解释性 (Interpretability)

#### A.31.1 互信息与特征重要性

**置换特征重要性** (Permutation Feature Importance):
- 打乱一个特征, 看模型性能下降多少
- 下降多 = 特征重要

**信息论等价**:
$$
I(x_i; y) \approx \text{Performance}(\text{all}) - \text{Performance}(\text{shuffle } x_i)
$$

#### A.31.2 探针 (Probing) 与互信息

**线性探针** (Linear Probe):
- 冻结预训练模型的表示 $Z$
- 训练一个线性分类器 $y = W Z + b$ 预测某个属性
- 准确率高 = 表示 $Z$ 包含该属性的**信息** = 互信息 $I(Z; \text{属性})$ 大

**应用**:
- BERT 中间层是否包含词性信息? 训练线性探针 → 准确率
- 探针发现: 浅层包含更多词性信息, 深层更多语义信息

#### A.31.3 激活信息的可视化

**Activation Atlases** (OpenAI, 2019):
- 把激活值聚类, 可视化每个 cluster 的平均图像
- 信息论解释: cluster 的熵 = "概念的纯度"

### A.32 信息论与异常 / 对比 / 边界 (Out-of-Distribution) 检测

#### A.32.1 OOD 检测的信息论指标

**最大预测概率**:
$$
\text{score}(x) = \max_k p_\theta(y=k | x)
$$

高 = 模型对 $x$ 自信 = 可能是 ID (in-distribution)

**预测熵**:
$$
H(y | x) = -\sum_k p_\theta(y=k | x) \log p_\theta(y=k | x)
$$

低 = 模型自信 = 可能是 ID

**互信息 (MC Dropout)**:
$$
I(y; \text{weight}) = H(\mathbb{E}_{w}[p(y|x, w)]) - \mathbb{E}_w[H(p(y|x, w))]
$$

高 = 模型对 $x$ 意见一致 = 可能是 ID

**信息论视角**: OOD 检测 = 找一个**信息量**大的指标, 区分 ID 和 OOD。

#### A.32.2 OOD 与分布外泛化

**信息瓶颈** 视角: 鲁棒模型 = $I(Z; X)$ 适度 (不"过拟合"输入) + $I(Z; Y)$ 大 (保持预测能力)。

**实践**:
- 训练时: 加 IB 损失
- 推理时: 用探针 + 后处理

### A.33 信息论在数据压缩中的应用

#### A.33.1 无损压缩的极限: Shannon 熵

**定理** (Shannon 1948 第一定理): 任何无损压缩的**平均码长** $\geq$ 信源的熵 $H(X)$。

**工程意义**:
- 文本压缩 (gzip, bzip2) 接近文本熵
- PNG 图像压缩接近图像熵
- 任何"超过" 熵的压缩必有损

#### A.33.2 算术编码 (Arithmetic Coding)

**思想**: 把整条消息编码成一个**小数**, 区间长度 = 消息概率。

**例**: 消息 "HELL" (字母表 {E, H, L}, P=0.5, 0.3, 0.2):
- 初始: [0, 1)
- 'H' (0.3): [0, 0.3)
- 'E' (0.5): [0, 0.15)
- 'L' (0.2): [0.12, 0.15)
- 'L' (0.2): [0.144, 0.15)

编码: 区间内任意小数 (0.145) → 二进制表示

**信息论**: 算术编码几乎达到熵下界, 实际中非常接近最优。

#### A.33.3 有损压缩: 率失真

**JPEG, MP3, WebP** 都是率失真的实际应用:
- 选一个失真度量 (MSE, 感知)
- 优化码率 vs 失真

**JPEG 的率失真**:
- DCT 变换: 解耦频率
- 量化: 舍入高频 (损失信息)
- 熵编码: 算术 / Huffman 编码

**信息论视角**: JPEG 在 $D$(失真) 范围内, 接近最优 $R(D)$ 曲线。

### A.34 信息论与密码学

#### A.34.1 完美保密 (Perfect Secrecy)

**定义**: 密文 $C$ 不泄露明文 $P$ 的任何信息:
$$
I(P; C) = 0
$$

**One-Time Pad** 达到完美保密, 但需要密钥长度 = 消息长度。

**Shannon 定理**: 完美保密要求密钥长度 $\geq$ 消息熵。

#### A.34.2 计算保密 (Computational Security)

**实际系统** (AES, RSA) 不追求完美保密, 而是"在多项式时间内无法破解"。

**信息论视角**: 这些系统假设**攻击者的计算能力有限**, 所以 $I(P; C)$ 可以 $> 0$ 但难以利用。

#### A.34.3 信息论与差分隐私 (Differential Privacy)

**差分隐私**: 加噪声使单个样本的贡献"被淹没"。

**信息论解释**: 限制 $I(\text{单样本}; \text{输出})$, 防止数据被反推。

**DP-SGD** (Abadi et al., 2016):
- 梯度裁剪 (限制单个样本的贡献)
- 加高斯噪声 (增加随机性)
- 信息论保证: $I(\text{单样本}; \text{输出}) \leq \epsilon$

### A.36 信息论的"圣杯"问题

### A.38 信息论常见错误 (实战总结)

#### A.38.1 工程师常犯的 10 个信息论错误

1. **混淆熵和微分熵**: 离散熵 $\geq 0$, 微分熵**可以**为负!
2. **直接传概率到 `F.kl_div`**: 必须传 log, 否则数值下溢。
3. **混淆 log_base 2 和 e**: `cross_entropy` 默认 nats (底 e), 但 PPL 通常用 base e 转 base 2。
4. **认为 KL 是距离**: 不是, 不对称, 不满足三角不等式。
5. **InfoNCE loss 是 MI 的精确估计**: 实际是**下界**, N 越大越紧。
6. **低 PPL = 好模型**: 还要看下游任务, 看分布外泛化。
7. **直接用 `F.cross_entropy` 标签平滑**: PyTorch 不支持, 需要手写。
8. **PPL 跨数据集可比**: 不可比! PPL 必须在同一数据集、同一 tokenization 下比较。
9. **VAE 的 KL 越小越好**: 太小 → posterior collapse, 重建项必然变差。
10. **用 JS 散度训练 GAN 在高维**: 容易梯度消失, 推荐 WGAN。

#### A.38.2 调试清单

```python
def debug_information_theory_loss(loss_name, **kwargs):
    """调试信息论 loss 的常见问题"""
    issues = []

    if loss_name == 'cross_entropy':
        # 检查 logits 范围
        logits = kwargs.get('logits')
        if logits is not None and (logits.abs() > 100).any():
            issues.append("Logits 太大 (>100), 可能数值溢出, 考虑梯度裁剪")
        # 检查 labels 范围
        labels = kwargs.get('labels')
        n_classes = logits.size(-1) if logits is not None else None
        if labels is not None and n_classes is not None:
            if labels.max() >= n_classes or labels.min() < 0:
                issues.append(f"Labels 超出范围 [0, {n_classes})")

    if loss_name == 'kl_div':
        # 检查概率有效性
        p = kwargs.get('p')
        q = kwargs.get('q')
        if p is not None and (p < 0).any():
            issues.append("概率 p 包含负数!")
        if q is not None and (q < 0).any():
            issues.append("概率 q 包含负数!")
        if p is not None and abs(p.sum() - 1.0) > 1e-3:
            issues.append("概率 p 没归一化")
        if q is not None and abs(q.sum() - 1.0) > 1e-3:
            issues.append("概率 q 没归一化")

    return issues
```

### A.39 信息论的"算法手册"

#### A.39.1 速查表: 看到 loss / 指标 → 联想到信息论概念

| 看到的 loss / 指标 | 信息论概念 | 关键公式 |
| :--- | :--- | :--- |
| `cross_entropy` | 交叉熵 = 熵 + KL | $H(p,q) = H(p) + D_{KL}(p\|q)$ |
| `binary_cross_entropy` | 二元交叉熵 | $-[y \log \hat{y} + (1-y) \log(1-\hat{y})]$ |
| `kl_div` | KL 散度 | $\mathbb{E}_p[\log(p/q)]$ |
| `nll_loss` | 负对数似然 ≈ 交叉熵 | $-\log p(x)$ |
| `perplexity` | 困惑度 = exp(loss) | $e^{H(p,q)}$ |
| `F.kl_div(..., log_target=True)` | KL 散度 (log 输入版) | 见 §6.7 |
| `InfoNCE loss` | 互信息下界 | $\log N - \mathcal{L} \leq I(X;Y)$ |
| `MINE` | 互信息估计 (DV 表示) | 见 A.5.1 |
| `Wasserstein loss` | Wasserstein-1 距离 | $\sup \|f\|_L \mathbb{E}[f(x)] - \mathbb{E}[f(y)]$ |
| `Triplet loss` | 度量学习 | $\|f(x) - f(x^+)\| - \|f(x) - f(x^-)\| + \alpha$ |
| `ELBO` | 变分下界 | $\log p(x) \geq \mathbb{E}_q[\log p(x\|z)] - D_{KL}(q\|p)$ |
| `Focal loss` | 加权交叉熵 | $-\alpha (1-p)^\gamma \log p$ |
| `Label smoothing` | 软标签 + 熵正则 | 实际熵增加 |

#### A.39.2 速查表: 信息论概念 → 看到 loss / 指标

| 信息论概念 | 工程对应 |
| :--- | :--- |
| 熵 $H(X)$ | 困惑度、决策树的信息增益、熵正则化 |
| 联合熵 $H(X,Y)$ | 编码极限、特征组合的信息量 |
| 条件熵 $H(X\|Y)$ | 已知 $Y$ 后 $X$ 的不确定性、决策树的剩余不确定性 |
| 互信息 $I(X;Y)$ | InfoNCE、特征选择、对比学习 |

| JS 散度 | 原始 GAN |
| Wasserstein 距离 | WGAN |
| 交叉熵 $H(p,q)$ | 分类损失 |
| 微分熵 $h(X)$ | 连续分布的不确定性、归一化流 |
| 率失真 $R(D)$ | 图像压缩、VAE 权衡、Diffusion 视角 |
| 信道容量 $C$ | 信息论上界、IB 上界 |

### A.40 信息论的"工程箴言"

> 1. **"信息 = -log p"**: 这是整个信息论的根。记住它, 其他都是推论。
>
> 2. **"概率分布 = 系统, 期望 = 总览, 对数 = 惊讶度"**: 三者结合, 你就有了信息论。
>
> 3. **"训练 = 最小化 KL, 推理 = 利用信息"**: 这条主线贯穿 ML。
>
> 4. **"互信息 = 共享的不确定性"**: 知道一个变量, 另一个少了多少不确定性。
>
> 5. **"VAE 损失 = 重建 - KL": 不是正则化, 是变分下界。**
>
> 6. **"InfoNCE 是 MI 的下界, 不是 MI 本身"**: 别把下界当估计值。
>
> 7. **"困惑度低 ≠ 好模型, 困惑度跨集不可比"**: 评估要谨慎。
>
> 8. **"互信息 ≠ 因果"**: 互信息大可能是因果, 也可能是 confounding。
>
> 9. **"信息论给框架, 不是答案"**: 知道信息论帮你设计 loss, 不告诉你超参。
>
> 10. **"工程上, 熵/KL/MI 是 loss; 数学上, 它们是同一棵树"**: 同一棵树, 不同的提问。

### A.41 实战案例: 完整的信息论项目模板

下面是一个**完整的信息论项目模板**, 把本章所有概念串起来:

```python
"""
信息论完整项目模板: 文本分类 + 困惑度 + InfoNCE + VAE
展示如何用熵、KL、互信息构造一个完整 pipeline
"""
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch.utils.data import DataLoader

# ===== 1. 数据准备 =====
texts = ["machine learning is fun", "deep learning is powerful",
         "information theory is elegant", "i love neural networks"]
labels = [0, 0, 1, 0]  # 假设 1 = "技术性"

# ===== 2. 模型 =====
class TextEncoder(nn.Module):
    def __init__(self, vocab_size, embed_dim=64, hidden=128):
        super().__init__()
        self.embed = nn.Embedding(vocab_size, embed_dim)
        self.lstm = nn.LSTM(embed_dim, hidden, batch_first=True)
        self.proj = nn.Linear(hidden, 64)

    def forward(self, x):
        # x: (B, seq_len)
        e = self.embed(x)
        _, (h, _) = self.lstm(e)
        return F.normalize(self.proj(h.squeeze(0)), dim=-1)

# ===== 3. 损失 =====
def info_theory_loss(embeds, labels, temperature=0.5):
    """
    组合损失:
    - 分类交叉熵 (监督)
    - InfoNCE (对比学习)
    - 预测熵正则化 (防止过自信)
    """
    # 分类 loss
    logits = embeds @ embeds.T  # 占位
    class_loss = F.cross_entropy(logits, labels)

    # InfoNCE loss
    sim = embeds @ embeds.T / temperature
    n = sim.size(0)
    targets = torch.arange(n, device=sim.device)
    info_nce = F.cross_entropy(sim, targets)

    # 熵正则: 鼓励预测不太极端
    probs = F.softmax(logits, dim=-1)
    entropy = -(probs * probs.log()).sum(dim=-1).mean()

    return class_loss + 0.1 * info_nce - 0.01 * entropy

# ===== 4. 训练循环 =====
model = TextEncoder(vocab_size=1000, embed_dim=64, hidden=128)
opt = torch.optim.Adam(model.parameters(), lr=1e-3)

# 模拟数据
x_batch = torch.randint(0, 1000, (16, 10))
y_batch = torch.randint(0, 2, (16,))

for step in range(100):
    embeds = model(x_batch)
    loss = info_theory_loss(embeds, y_batch)
    opt.zero_grad()
    loss.backward()
    opt.step()

    if step % 20 == 0:
        # 监控: 熵 / 互信息 / KL
        with torch.no_grad():
            p = F.softmax(embeds @ embeds.T, dim=-1)
            H = -(p * p.log()).sum(dim=-1).mean()
            # 互信息: 估计 (粗略)
            mi_proxy = H - (-(p * torch.log(p.sum(0) / p.size(0))).sum())
        print(f"Step {step}: loss={loss.item():.3f}, H={H.item():.3f}, MI≈{mi_proxy.item():.3f}")
```

**信息流图**:

```text
输入文本
   │
   v
[Encoder (LSTM)]
   │
   v
归一化嵌入 (z)
   │
   ├─→ [分类头] ──→ 交叉熵损失
   ├─→ [对比损失] ──→ InfoNCE → 互信息下界
   ├─→ [熵正则] ──→ 防止过自信
   │
   v
总损失 = 分类 + α·InfoNCE - β·熵
   │
   v
反向传播 + 优化器
```

### A.43 信息论的"工程实战"补充

#### A.43.1 信息论在推荐系统中的应用

**协同过滤的信息论视角**:
- 用户-物品矩阵: 看作联合分布
- 推荐 = 最大化 $I(\text{用户}; \text{物品})$ 的下界

**具体算法**:
- **SLIM** (Sparse Linear Methods): 直接估计 item-item 相似度
- **EASE** (Embarrassingly Shallow Autoencoder): 闭式解, 信息论解释清晰
- **LightGCN**: 图卷积 + BPR 损失 (BPR 损失可解释为 pairwise 互信息)

#### A.43.2 信息论在 NLP 中的"评估"

**困惑度的边界**:
- 训练集 PPL: 模型拟合
- 验证集 PPL: 调参
- 测试集 PPL: 评估

**为什么 GPT-3 / GPT-4 的 PPL 持续下降**:
- 更大的模型
- 更多的数据
- 更好的 tokenization
- 更好的训练目标 (RLHF, DPO)

**PPL 的"内在问题"**:
- 没有事实性
- 没有多样性
- 没有安全性
- 没有推理能力

**新的评估**:
- **TruthfulQA**: 事实性
- **MMLU**: 多任务知识
- **HumanEval**: 代码生成
- **MT-Bench**: 多轮对话
- **AlpacaEval**: 指令跟随

#### A.43.3 信息论在 RLHF / DPO 中的应用

**RLHF** (Reinforcement Learning from Human Feedback):
1. 监督微调 (SFT): 标准 MLE
2. 奖励模型 (RM): 学习人类偏好
3. PPO 优化: 最大化奖励, 用 KL 约束防止偏离 SFT 模型太远

**信息论目标**:
- 最大化 $\mathbb{E}[\text{reward}]$
- 最小化 $D_{KL}(\pi_\theta \| \pi_{\text{SFT}})$ (防止 reward hacking)

**DPO** (Direct Preference Optimization):
- 直接用偏好数据训练, 不需要奖励模型
- 等价于 RLHF 的闭式解
- 损失函数: 偏好对的"对数几率"差

信息论解释: DPO 最大化"优选回答的边际似然 / 劣选回答的边际似然"。

### A.44 信息论的"陷阱"总结

#### A.44.1 信息论方法不是银弹

| 场景 | 信息论方法的局限 |
| :--- | :--- |
| 高维互信息估计 | 严重偏差, 需要大量样本 |
| 因果推断 | 互信息 $\neq$ 因果 |
| 小样本学习 | 信息论估计器方差大 |
| 离散-连续混合 | 估计困难, 缺乏统一框架 |
| 多模态融合 | 跨模态互信息定义模糊 |

#### A.44.2 什么时候**不**用信息论方法

1. **样本极少** (< 100): 信息论估计器方差大, 不如简单统计
2. **高维 (> 1000 维)**: 维度灾难, 互信息估计失效
3. **需要因果结论**: 信息论只能给相关性
4. **实时系统 (< 1ms)**: 信息论方法计算开销大
5. **离散-连续混合**: 缺乏统一估计方法

**替代方案**:
- 简单统计 (相关系数, 卡方)
- 经典 ML (SVM, 决策树)
- 深度学习 (直接训练, 不显式用信息论)

### A.45 信息论与"自监督学习"的深层联系

#### A.45.1 自监督 = 最大化互信息

**核心思想**: 自监督学习 = 没有标签的学习 = 找数据的**内在结构**。

**信息论视角**: 最大化**数据不同部分之间的互信息**。

**具体例子**:
- **BERT (MLM)**: 最大化 $I(\text{上下文}; \text{masked token})$
- **GPT (CLM)**: 最大化 $I(\text{前文}; \text{下一 token})$
- **SimCLR**: 最大化 $I(z_i; z_j)$ (同图像的不同增强)
- **MAE**: 最大化 $I(\text{可见 patches}; \text{masked patches})$
- **Wav2Vec**: 最大化 $I(\text{音频}; \text{离散单元})$

**统一框架**: 自监督 = **互信息最大化** + 表征学习。

#### A.45.2 信息论与"世界模型"

**世界模型** (World Models, Ha & Schmidhuber 2018):
- 学习环境的"压缩表示"
- 在表示空间做 planning

**信息论视角**:
- 编码器: 压缩 $X$ 到 $Z$, 最小化 $I(X; Z)$ (率)
- 解码器: 预测下一状态, 最大化 $I(Z; Y)$ (失真)
- 整体 = 率失真优化 = IB 目标

**工程**: Dreamer, IRIS, MuZero 等都用类似思想。

### A.46 信息论的"哲学"续

#### A.46.1 信息论的"局限性"

**Shannon 信息论不包含**:
- **意义** (semantics): 一段话"说了什么", 不是熵能度量的
- **价值** (value): 哪些信息"重要", 需要外部定义
- **因果** (causality): $I(X;Y)$ 大可能是因果, 也可能是 confounding
- **时间** (temporality): 时序信息是特殊的信息
- **空间** (spatiality): 空间信息需要专门建模

**补充理论**:
- **Algorithmic Information Theory** (Kolmogorov 复杂度): 用最短程序长度度量信息
- **Logical Information Theory** (Floridi): 信息 = 真实数据的减少
- **Pragmatic Information Theory** (Bar-Hillel & Carnap): 信息 + 上下文

**工程启示**: 信息论是**数学工具**, 不是"智能理论"。要用它设计 loss, 不要把它当万能钥匙。

#### A.46.2 "信息即物质"?

物理学家 John Wheeler 提出 "It from bit": 物理世界的基础是"信息"。

**信息论的支持**:
- 黑洞熵 (Bekenstein-Hawking): $S = A / 4 l_p^2$, 信息存在事件视界
- Landauer's principle: 擦除 1 bit 信息耗能 $\geq kT \ln 2$
- 量子纠缠 = 量子信息

**工程关联**: 量子计算 = 量子信息论 + 算法。

### A.48 信息论的"心法"

> **信息论的 3 个公理**:
> 1. 信息量 = $-\log p$ (公理 1)
> 2. 期望 = 系统的"总览" (公理 2)
> 3. KL 散度 = 唯一满足非负性的"距离" (公理 3)
>
> **3 个核心公式**:
> 1. $H(p, q) = H(p) + D_{KL}(p \| q)$
> 2. $I(X; Y) = D_{KL}(p(x, y) \| p(x) p(y))$
> 3. $\log p(x) = \text{score}(x)$ (score matching 的根)
>
> **3 个工程启示**:
> 1. 训练 = 最小化 KL (无论什么 loss)
> 2. 互信息是表征学习的"目标函数"
> 3. 困惑度 = 跨语言模型的"通用货币"

### A.50 本附录的"灵魂问题" (终极回答)

> **"信息论与概率论的关系是什么?"**
>
> **一句话**: 信息论是概率论的"度量延伸"。它用概率论的语言, 度量"不确定性"和"信息量"。Shannon 1948 年的天才观察是: **"信息"可以用概率严格定义**, 这个定义能解释通信、压缩、推断、学习的几乎所有事情。
>
> **核心公式**:
> - 熵: $H(X) = \mathbb{E}[-\log p(X)]$
> - KL 散度: $D_{KL}(p \| q) = \mathbb{E}_p[\log(p/q)]$
> - 互信息: $I(X; Y) = D_{KL}(p(x, y) \| p(x) p(y))$
> - 交叉熵: $H(p, q) = H(p) + D_{KL}(p \| q)$
>
> **统一视角**: 这四个概念都是"**期望 + 负对数**"的组合。一旦你接受这个公理, 整个信息论就是必然的。
>
> **工程意义**:
> - 训练 = 最小化 KL
> - 推理 = 利用互信息
> - 评估 = 用困惑度
> - 生成 = 用变分下界
> - 对比 = 用互信息下界
>
> **数学意义**: 信息论是**严格的数学**, 但有唯一的"哲学" (Shannon 公理)。它不是"另一种信息论", 而是**唯一**的信息论。
>
> **未来**: 信息论 + 深度学习 = **表征学习**。InfoNCE、IB、对比学习、Diffusion、RLHF ... 都在用信息论的语言。理解信息论, 你就理解了**现代 AI 的底层逻辑**。

**7. 实践建议**

结合 "第 11 章:信息论与概率的统一。熵·相对熵·互信息的概率解读" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "第 11 章:信息论与概率的统一。熵·相对熵·互信息的概率解读" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
