# 第04章-附录-离散数学在DL·搜推中的应用对标表

推荐二部图,代数结构(群)刻画等变网络,布尔代数刻画受限解码与逻辑门,Markov 链刻画随机游走/PageRank/MCMC,形式语言/自动机刻画 LLM 解码约束与语法校验,组合/复杂度刻画算法可行性边界。
>
> **本附录做四件事**:
> 1. 一张 **≥45 条**"离散数学概念 ↔ ML/DL 组件"对标总表(第 2 节)
> 2. **11 个按章节分组的速查表**(第 3 节),每张 6-10 行,翻到即用
> 3. 与 1-高数 / 2-线代 / 3-概率论 / 5-信息论 / 6-最优化 / 7-系统思维 的接口图(第 4 节)
> 4. 关键论文索引(第 5 节)
>
> **使用方式**:
> - 工程遇到具体问题(如"二部图匹配 → 什么召回?"),"工程应用"列反查
> - 想从 ML 组件反推数学基础(如"GAT → 注意力的图论"),按"ML/DL 对应物"列反查
> - 面试前翻末尾"快速回忆卡片"(按章节速查表的浓缩版)
> - 重要度 1-5 颗星,5 颗星 = 面试/工程必背
>
> **覆盖范围**:第 1-11 章全部概念 + GNN/搜推/RL/LLM 工业实践。配套:1-高数/附录、2-线代/附录、3-概率论/附录、5-信息论/附录、6-最优化/附录。

## 8. 快速回忆卡片(10 张)

**卡片 1:为什么推荐系统天然是二分图?**
> User-Item 交互矩阵 $M$ 的 0/1 模式 = 二分图 $V = U \cup I$, 边 $E \subseteq U \times I$。双塔召回 = 给 $U$ 和 $I$ 顶点分别 Embedding; 矩阵分解 = 在二分图上做链路预测; PinSage = 在二分图上做 PPR 采样 + 邻居聚合。

**卡片 2:邻接矩阵、拉普拉斯、GCN 三件套**
> $A$ 描述图结构, $L = D - A$ 编码"邻居平滑"(最小特征值 0 对应常数向量)。GCN 的 $\hat{A} = \tilde{D}^{-1/2}(A+I)\tilde{D}^{-1/2}$ 是 $L$ 的重归一化 → 一阶切比雪夫多项式近似 → 谱图卷积。空域视角:每个节点 = 邻居平均 + 自环。

**卡片 3:GCN vs GAT vs GraphSAGE 一句话区分**
> GCN = 邻居平均 + 线性变换 (Hamilton 等价于固定权重邻居聚合)。GAT = 邻居注意力权重 (异质图友好)。GraphSAGE = 邻居采样 + 通用聚合 (归纳式, 大图必备)。

**卡片 4:PageRank 怎么来的?**
> 阻尼随机游走 = "以 $d$ 概率点击链接 + 以 $1-d$ 概率跳到随机页面"。稳态分布 $\pi = (1-d)/n \cdot \mathbf{1} + d \cdot M \pi$ 解线性方程。PPR = 把"跳到随机页面"换成"跳回 source node",得到个性化排序。

**卡片 5:等变性 vs 不变性**
> 等变 $f(g \cdot x) = g \cdot f(x)$ (输出跟着输入变, 旋转 90° 输出也旋转 90°)。不变 $f(g \cdot x) = f(x)$ (输出不跟着变, 分类)。E(3)-NN 用等变编码 3D 原子坐标, AlphaFold2 用此编码蛋白质几何。

**卡片 6:CFG 受限解码怎么做?**
> LLM 想要生成"满足 JSON 模式的字符串"。思路:每步 token 候选 = 在 CFG 的 valid next token set 里, 通过 PDA (pushdown automaton) 维护语法状态。Outlines / Guidance / LMQL 等库的实现 = CYK 变体 + 词表 mask。

**卡片 7:Markov 链的稳态 = PageRank = 特征向量**
> $\pi P = \pi$, 即 $\pi$ 是 $P^T$ 特征值 1 的左特征向量。PageRank 加阻尼项 $d$ 保证该特征向量唯一且正 (Perron-Frobenius 定理)。幂迭代 = 反复乘 $P^T$, 几步就收敛。

**卡片 8:集合论 → Embedding → 神经网络的桥梁**
> 词表 = 有限集 $\{w_1, ..., w_V\}$, 查表 = 函数 $f: V \to \mathbb{R}^d$ (单射但非满射)。`nn.Embedding` = 实现这个函数。BPE tokenizer = 在字符集上做组合 $C(n,k)$, 鸽巢原理限制 vocab 大小。

**卡片 9:为什么决策树能用信息增益?**
> 信息增益 = $H(Y) - H(Y|X)$ = 用特征 $X$ 后熵的减少量。信息熵 $H(Y) = -\sum p \log p$ 来自 5-信息论。决策树 = 离散版 MLE, 在每个节点选"增益最大"的特征分裂。

**卡片 10:大 O 不是一切**
> Transformer self-attention 时间复杂度 $O(n^2)$, 但有大量常数优化 (Flash Attention)。HNSW 时间复杂度 $O(\log n)$, 但内存可能成为瓶颈。NP-hard 不等于不可解 = 启发式 + 近似。算法选型 = 复杂度 + 常数 + 工程约束。

## 9. 常见面试题精选

### 9.1 图与 GNN 方向

**Q1:GNN 中如何处理不同大小的邻域?**
> 答:三种方案 — (a) 固定邻域大小 (邻居采样, GraphSAGE); (b) 注意力加权 (GAT); (c) 多项式逼近 (ChebNet)。背后都是用"有限样本"近似"全邻域"的图论处理。

**Q2:为什么 GCN 浅层不能太深?**
> 答:过平滑(over-smoothing)。$L$ 的最小非零特征值对应常数向量, 反复乘 $\hat{A}$ 会让所有节点特征趋向一致。深层方案:GCNII (初始残差) / DropEdge (随机丢边) / PairNorm。

**Q3:PinSage 和 GraphSAGE 区别?**
> 答:PinSage (工业版 GraphSAGE) 用 PPR 采样代替均匀采样, 保证采样到"重要"邻居; 训练时使用 max-pool 聚合 + 难负采样 (hard negative); 针对 Pinterest 10 亿节点图优化。

### 9.2 概率与 Markov 方向

**Q4:PageRank 如何保证收敛?**
> 答:加阻尼项 $d \in (0,1)$ 让随机游走变成"原始 Markov 链 + 完全图扰动"。扰动后转移矩阵是 primitive(所有元素 > 0), 由 Perron-Frobenius 定理保证唯一正稳态分布。

**Q5:MCMC 和 PageRank 是什么关系?**
> 答:MCMC 是 Metropolis-Hastings 等采样算法, 用于从难采样分布中抽样; PageRank 是稳态分布求解, 也可视为 MCMC 的特例。MCMC 关注"样本", PageRank 关注"极限分布"。

### 9.3 自动机与 LLM 方向

**Q6:LLM 怎么生成 JSON?**
> 答:三种方案 — (a) Prompt engineering (容易漏字段); (b) Logit mask (每步只允许语法合法的 token, Outlines); (c) Grammar-constrained beam (CFG + CYK)。方案 (b)(c) 都需要词表的 DFA/PDA 维护。

**Q7:CYK 算法的复杂度?**
> 答:$O(n^3)$ 时间和 $O(n^2)$ 空间, $n$ 是 token 数。LLM 解码每步都跑 CYK 复杂度上界 $O(n^4)$。优化:增量式 CYK、early termination、token mask 复用。

### 9.4 复杂度与算法方向

**Q8:为什么 Transformer attention $O(n^2)$ 不实用?**
> 答:实际运行受 IO 限制 (HBM 带宽)。Flash Attention 用 tiling + 重计算把 $O(n^2)$ 内存降到 $O(n)$, 速度提升 2-4x。本质:大 O 不考虑常数, 工程需要考虑硬件特性。

**Q9:Beam Search 是 NP-hard 吗?**
> 答:精确解码 (argmax 序列) 是 NP-hard (组合搜索空间 $V^n$)。Beam Search 是近似算法, 复杂度 $O(V \cdot n \cdot b)$, $b$ 是 beam 宽度。Top-$k$ 采样 $\in$ NP 类 (多项式可验证)。

### 9.5 代数与等变方向

**Q10:为什么等变网络对分子建模重要?**
> 答:分子的物理性质 (能量、力) 在旋转/平移下不变。E(3)-NN 保证网络输出在 3D 旋转/平移下保持等变, 减少训练样本需求。AlphaFold2 用 IPA (Invariant Point Attention) 编码蛋白质几何。

## 10. 常见陷阱与误区

| 误区 | 真相 |
| :--- | :--- |
| "图就是邻接矩阵" | 大图稀疏时, 邻接矩阵内存爆炸, 应转用 COO/CSC 格式 |
| "PageRank 越大越重要" | 需要考虑 damping factor 和 teleport 概率, 孤岛节点分到 $(1-d)/n$ |
| "CFG 能描述所有自然语言" | 自然语言含上下文相关结构, 严格上需 1 型文法 |
| "图着色只要几色" | 一般图着色是 NP-hard, 启发式有 Welsh-Powell、DSATUR |
| "GNN 越深越好" | 过平滑导致节点同质, 通常 2-3 层效果最佳 |
| "MCMC 一定收敛" | 接受率低、burn-in 不足、混合慢都会导致不收敛 |
| "等变一定更好" | 等变约束限制网络容量, 数据充足时非等变可能更优 |
| "BPE vocab 越大越好" | 鸽巢原理 + OOV 频率 + 模型容量 trade-off, 通常 32K-100K |
| "Beam Search 一定能找到最优" | beam width 限制, 可能错过全局最优 |
| "P/NP 划分很清晰" | 实际中 P ⊆ NP ⊆ PSPACE, 严格证明 P ≠ NP 仍未解决 |

## 16. 深度补充: 离散数学核心

### 16.1 集合论

**定义**: 集合 = 不同对象的无序聚集, 元素 $a \in A$ 或 $a \notin A$。

**运算**: 并 $\cup$, 交 $\cap$, 差 $\setminus$, 补 $\bar A$, 笛卡尔积 $\times$。

**应用**: 推荐系统候选集, 搜索空间。

### 16.2 关系

**二元关系** $R \subseteq A \times B$:

- 自反: $(a, a) \in R$ for all $a$
- 对称: $(a, b) \in R \Rightarrow (b, a) \in R$
- 传递: $(a, b), (b, c) \in R \Rightarrow (a, c) \in R$
- 等价: 自反 + 对称 + 传递

**应用**: 图关系, 知识图谱。

### 16.3 函数

**满射**: $\forall b \in B, \exists a \in A$ 使 $f(a) = b$

**单射**: $f(a_1) = f(a_2) \Rightarrow a_1 = a_2$

**双射**: 满射 + 单射

### 16.4 集合的势

- 有限集: $|A| \in \mathbb{N}$
- 可数集: 与 $\mathbb{N}$ 双射
- 不可数: 实数集 $\mathbb{R}$

**应用**: 信息熵 $H = \log |A|$。

## 17. 图论深度

### 17.1 图的表示

- **邻接矩阵** $A \in \{0,1\}^{n \times n}$
- **邻接表**: 每个节点的邻居列表
- **边列表**: $(u, v)$ 对的集合

**稀疏图** ($|E| \ll n^2$) 用邻接表省空间。

### 17.2 图的类型

- **无向图**: 边无方向
- **有向图**: 边有方向
- **加权图**: 边有权重
- **多重图**: 允许重边
- **二部图**: 顶点分两部分

### 17.3 图的遍历

**BFS** (广度优先): $O(V + E)$, 找最短路径。

**DFS** (深度优先): $O(V + E)$, 拓扑排序。

### 17.4 最短路径

- **Dijkstra**: 单源最短路径, $O((V+E) \log V)$
- **Bellman-Ford**: 处理负权, $O(VE)$
- **Floyd-Warshall**: 全对最短, $O(V^3)$

### 17.5 最小生成树

- **Kruskal**: 按边权排序, $O(E \log E)$
- **Prim**: 按节点扩展, $O(V^2)$ 或 $O((V+E) \log V)$

### 17.6 拓扑排序

DAG 上线性排序, 入度为 0 的先出。

**应用**: 编译顺序, 课程先修。

### 17.7 强连通分量

Tarjan / Kosaraju 算法, $O(V + E)$。

### 17.8 最大流 / 最小割

**最大流**: Ford-Fulkerson, $O(VE \cdot \text{max flow})$。

**最小割**: 与最大流对偶。

**应用**: 推荐召回, 资源分配。

## 24. 计算复杂性

### 24.1 大 O / o / Ω / Θ

### 28.2 Trie

```python
class Trie:
    def __init__(self):
        self.children = {}
        self.is_end = False

    def insert(self, word):
        node = self
        for c in word:
            if c not in node.children:
                node.children[c] = Trie()
            node = node.children[c]
        node.is_end = True

    def search(self, word):
        node = self
        for c in word:
            if c not in node.children:
                return False
            node = node.children[c]
        return node.is_end
```

## 29. 数学例题

### 例题 29.1: 完全图

**题目**: $K_5$ 顶点数、边数?

**解答**: $n = 5$, $|E| = \binom{5}{2} = 10$。

### 例题 29.2: Dijkstra

**题目**: 求 $1 \to 5$ 最短路径。

边: $1-2(3), 1-3(2), 2-4(4), 3-4(1), 3-5(5), 4-5(2)$。

**解答**: $1 \to 3 \to 4 \to 5 = 2 + 1 + 2 = 5$。

### 例题 29.3: 鸽巢原理

**题目**: 13 个人的生日, 至少两人生日相同的概率?

**解答**: $1 - \frac{365!}{(365-13)! \cdot 365^{13}} \approx 0.81$ (假设均匀分布)。

### 例题 29.4: 排列组合

**题目**: $\binom{10}{3}$?

**解答**: $\frac{10 \cdot 9 \cdot 8}{3 \cdot 2 \cdot 1} = 120$。

### 例题 29.5: 树高与叶子

**题目**: 完全二叉树高 $h = 4$, 叶子数?

**解答**: $2^3 = 8$ (高 $h$ 的完全二叉树叶子 $= 2^{h-1}$)。

### 例题 29.6: GCD

**题目**: $\gcd(48, 18)$。

**解答**: $\gcd(48, 18) = \gcd(18, 12) = \gcd(12, 6) = \gcd(6, 0) = 6$。

### 例题 29.7: 哈希冲突

**题目**: 哈希表大小 100, 1000 个键。期望冲突次数?

**解答**: 生日悖论, 期望 $\approx 1000^2 / (2 \cdot 100) = 5000$。

### 例题 29.8: 图同构

**题目**: 两个图是否同构?

**解答**: 无已知多项式算法, GI-complete。

**答**: BFS: 最短路径, 层序遍历, 社交网络好友推荐。DFS: 拓扑排序, 强连通分量, 路径查找。

**答**: 信息增益 (ID3), 增益率 (C4.5), 基尼系数 (CART)。XGBoost / LightGBM 基于 CART。

---

### Q4: B-Tree 为什么用于数据库?

**答**: 减少磁盘 IO (节点大小对齐磁盘块), $O(\log n)$ 查询/插入。

### Q5: Trie 的应用?

**答**: 前缀查询, BPE Tokenizer, 自动补全, IP 路由。

---

### Q6: 鸽巢原理的应用?

**答**: 推荐长尾, 哈希冲突, 抽屉原理。

---

### Q7: P vs NP 实际意义?

**答**: P = 可解, NP = 可验证。SAT / TSP 是 NP-complete。**DL 训练 NP-hard** (通用情况)。

---

### Q8: 信息瓶颈意义?

**答**: 压缩输入但保留标签信息, DL 泛化的理论框架。

---

### Q9: LSH 近似相似度?

**答**: 高维空间中, 随机投影保近似距离, $O(1)$ 查询。

### Q10: 图嵌入 (Graph Embedding)?

**答**: DeepWalk (随机游走 + Word2Vec), node2vec, GraphSAGE, GAT。

---

### Q11: Tokenizer 为什么用 BPE?

**答**: 字符级灵活, 词级效率。BPE 折中, 频率合并高频对。

---

### Q12: Beam Search 是什么?

**答**: 维护 top-k 候选, 每步扩展。贪心 + 局部最优的折中。

---

### Q13: PageRank 算法?

**答**: 网页重要性 = 指向它的网页的重要性之和 (递归)。Power iteration 求主特征向量。

---

### Q14: GNN 的核心思想?

**答**: 邻居特征聚合 + 自身特征, $k$ 层后聚合 $k$ 跳邻居信息。

---

### Q15: 知识图谱嵌入?

**答**: TransE: $h + r \approx t$。把实体和关系嵌入到同一空间。

### 33.1 组合恒等式

$\binom{n}{k} = \binom{n}{n-k}$

### 33.2 Catalan 数

### 33.3 Stirling 数

$S(n, k)$: $n$ 元素分 $k$ 个非空子集的方式数。

### 33.4 Bell 数

$B_n$: $n$ 元素集合的所有划分总数。

$B_0 = 1, B_1 = 1, B_2 = 2, B_3 = 5, B_4 = 15$。

**反链**: 任意两元素不可比。

**Dilworth 定理**: 偏序最小链覆盖 = 最大反链大小。

**应用**: 推荐多样性 (反链覆盖)。

### 36.4 范畴论 (Cat)

**对象 + 态射 + 复合 + 单位**。

**应用**: 程序语义, 类型论, 神经网络架构。

### 36.5 拓扑 (Topology)

**开集 / 闭集 / 连续映射**。

**应用**: 数据流形, 信息几何, 持续学习。
