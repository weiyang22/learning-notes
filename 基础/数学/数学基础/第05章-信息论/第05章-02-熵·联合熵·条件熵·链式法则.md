## 1. 直觉引入

### 1.1 熵家族全景图:五个核心概念的关系

在第 1 章里我们知道了**信息熵** $H(X)$ 度量一个随机变量的"平均不确定性"。但真实世界的"不确定性"远不止一个变量:

- **两个变量的联合不确定性** = **联合熵** $H(X, Y)$
- **看到 $X$ 后, $Y$ 还剩多少不确定性** = **条件熵** $H(Y \mid X)$
- **$X$ 和 $Y$ 共享多少信息** = **互信息** $I(X; Y)$
- **多变量序列的总不确定性** = **联合熵的链式分解**

它们的关系用一个 ASCII 韦恩图就能说清楚:

```text
                    H(X) 圆
                ┌───────────────┐
                │               │
                │   H(X|Y)     │
                │   ┌───────┐   │
                │   │       │   │
                │   │ I(X;Y)│   │  ← 互信息: X 和 Y 共享的信息
                │   │ 交集  │   │     = H(X) - H(X|Y)
                │   │       │   │     = H(Y) - H(Y|X)
                │   └───────┘   │     = H(X) + H(Y) - H(X,Y)
                │   H(Y|X)     │
                │               │
                └───────────────┘
                    H(Y) 圆

H(X,Y) = H(X) + H(Y|X)         (链式法则: 左圆 = 圆 + 右侧月牙)
H(X,Y) = H(Y) + H(X|Y)         (链式法则: 右圆 = 圆 + 左侧月牙)
H(X) - H(X|Y) = I(X;Y)         (互信息 = X 的"独享信息"的减少量)
```

**关键等式**(本章反复用到):

$$H(X, Y) = H(X) + H(Y \mid X) = H(Y) + H(X \mid Y)$$

$$I(X; Y) = H(X) + H(Y) - H(X, Y) = H(X) - H(X \mid Y) = H(Y) - H(Y \mid X)$$

这五个量之间构成一个**完整的代数系统**,任何两个量可以推出其余三个。这就是为什么"熵家族"是信息论的核心,它们是相互定义的。

### 1.2 三个直觉例子

#### 例 1: 推荐系统的"用户兴趣分布"= 信息熵

设用户 Alice 的兴趣分布为:

$$P(\text{喜欢} | \text{Alice}) = (0.5, 0.3, 0.2) \quad \text{(3 类物品: 数码 / 服装 / 食品)}$$

**信息熵** $H(P)$:

$$H(P) = -(0.5 \log 0.5 + 0.3 \log 0.3 + 0.2 \log 0.2) \approx 1.485 \text{ bits}$$

**含义**:Alice 的兴趣有 1.485 bits 的"平均不确定性"。如果我让你猜 Alice 喜欢哪类,**最少需要 1.485 个二元问题**(在最优策略下)才能确定。

**对比**:如果 Alice 的兴趣很集中,比如 $(0.98, 0.01, 0.01)$,那 $H \approx 0.16$ bits,**几乎不用猜**(直接猜"数码"就对了)。**信息熵衡量"分布有多"分散"**。

```python
import torch
import numpy as np

def entropy(p, eps=1e-10):
    """H(P) = -sum p log p (自然对数,nats)"""
    p = np.asarray(p)
    p = np.clip(p, eps, 1.0)
    return -np.sum(p * np.log(p))

# Alice 兴趣分散
print(entropy([0.5, 0.3, 0.2]))   # 1.0297 nats ≈ 1.485 bits
# Alice 兴趣集中
print(entropy([0.98, 0.01, 0.01]))  # 0.1431 nats ≈ 0.206 bits
```

#### 例 2: 分类任务的"交叉熵损失"= 联合熵 + 散度

PyTorch 的 `nn.CrossEntropyLoss()` 输入是 logits, 公式是:

$$L = -\frac{1}{N} \sum_{i=1}^{N} \log \frac{e^{z_{i, y_i}}}{\sum_{j} e^{z_{i, j}}}$$

**信息论解读**:这就是**真实分布** $P$ (one-hot) 和**模型分布** $Q$ 的**交叉熵** $H(P, Q)$:

$$H(P, Q) = -\sum_x P(x) \log Q(x) = H(P) + D_{KL}(P \| Q)$$

**为什么用交叉熵作为损失?**
- 真实标签 $P$ 是固定的(熵 $H(P)$ 是个常数)
- 最小化 $H(P, Q) \iff$ 最小化 $D_{KL}(P \| Q) \iff$ 让 $Q$ 逼近 $P$

**所以"最小化交叉熵" = "最小化 KL 散度" = "让模型输出接近真实分布"**。这就是为什么 CrossEntropy 是分类任务的标配。

#### 例 3: 语言模型的"负对数似然"= 序列联合熵的估计

GPT 训练时, loss 是:

$$L = -\frac{1}{T} \sum_{t=1}^{T} \log P_\theta(x_t \mid x_{<t})$$

**信息论解读**:这就是**序列的负对数似然** (NLL),它是**联合熵** $H(X_1, \ldots, X_T)$ 的 Monte Carlo 估计:

$$H(X_1, \ldots, X_T) = -\mathbb{E}_{P_{\text{data}}}[\log P_\theta(X_1, \ldots, X_T)] = -\mathbb{E}\left[\sum_{t=1}^{T} \log P_\theta(X_t \mid X_{<t})\right]$$

**为什么是链式分解?** 因为联合分布难直接估计,但**条件分布** $P_\theta(X_t \mid X_{<t})$ 容易从自回归模型得到(Transformer 直接输出)。这个**链式法则**就是语言模型能训练的根本原因,见 §6。

### 1.3 工程师痛点:为什么"互信息"比"相关系数"更强?

推荐系统的工程师都知道**皮尔逊相关系数** $\rho(X, Y)$。但你可能踩过这个坑:

**$X$ 和 $Y$ 强非线性相关,但相关系数 = 0**:

```python
import numpy as np
np.random.seed(0)
x = np.random.uniform(-1, 1, 1000)
y = x ** 2 + 0.1 * np.random.randn(1000)  # y = x², 强非线性
print(np.corrcoef(x, y)[0, 1])  # ≈ 0.0  ← 相关性几乎为 0!
```

**但互信息 $I(X; Y) > 0$**:因为 $Y$ 显然依赖 $X$。

**根本原因**:**相关系数只测"线性关系"**,**互信息测"任意统计依赖"**。这是为什么对比学习用 InfoNCE 估计互信息,而不是用相关系数。详见 §5。

## 2. 信息熵 $H(X)$ 回顾

### 2.1 离散信息熵的定义

**定义**(Shannon 1948):离散随机变量 $X$ 在分布 $P$ 下的**信息熵**为:

$$H(X) = H(P) = -\sum_{x \in \mathcal{X}} P(x) \log P(x)$$

**约定**:$0 \log 0 = 0$(连续延拓),$\log$ 底数决定单位:
- $\log_2$:单位是 **bits**(信息论经典)
- $\ln$:单位是 **nats**(自然对数, ML 默认)
- 转换: $1 \text{ bit} = \ln 2 \approx 0.693$ nats

#### 直觉

- **自信息** $I(x) = -\log P(x)$:一个**事件** $x$ 发生带来的"惊讶度"
- **信息熵** $H(X)$:**自信息在分布 $P$ 下的期望**,即"平均惊讶度"
- 概率越小的事件,自信息越大;概率越大的事件,自信息越小

#### 例子: 抛硬币

- 公平硬币 $P = (0.5, 0.5)$:$H = -2 \times 0.5 \log 0.5 = \log 2 \approx 0.693$ nats
- 偏置硬币 $P = (0.9, 0.1)$:$H = -(0.9 \log 0.9 + 0.1 \log 0.1) \approx 0.325$ nats
- 确定硬币 $P = (1, 0)$:$H = 0$ nats(没不确定性)

**观察**:越偏置(分布越集中),熵越小。**完全确定时熵为 0**,**均匀分布时熵最大**(在给定支持集大小下)。

#### 例子: 分类任务的真实分布熵

设三分类任务,真实标签分布 $P = (0.5, 0.3, 0.2)$:

$$H(P) = -(0.5 \log 0.5 + 0.3 \log 0.3 + 0.2 \log 0.2) \approx 1.030 \text{ nats}$$

**含义**:这个分类任务有"1.030 nats 的内在不确定性"。即使模型完美,损失也至少是 1.030 nats(因为真实分布本身有熵)。

### 2.2 离散熵的工程意义

| 场景 | 熵的含义 |
| :--- | :--- |
| **分类标签分布** | 任务的"内在难度" |
| **模型输出分布** | 模型的"置信度"(均匀→不确定) |
| **决策树节点** | 节点样本的"混杂程度" |
| **语言模型困惑度** | 模型对下一个 token 的"预测难度" |
| **RL 策略** | 策略的"探索性"(高熵→更随机) |

**核心 takeaway**:**熵 = 分布的"分散度"**。一个高熵分布 = 难预测 / 难压缩 / 携带更多信息。

### 2.3 连续信息熵(微分熵)

#### 定义

对连续随机变量 $X$ (有概率密度 $f(x)$),**微分熵** (differential entropy) 定义为:

$$h(X) = -\int_{-\infty}^{\infty} f(x) \log f(x) \, dx$$

**注意**:
- 用小写 $h$ 区别于离散熵 $H$
- 微分熵**可以取负值**(因为 $f(x)$ 可以 > 1)
- 微分熵**不是**离散熵的直接推广, 它对坐标变换敏感(见 §8 误区 2)

#### 例子: 均匀分布 $U(0, a)$

$$h(X) = -\int_0^a \frac{1}{a} \log \frac{1}{a} \, dx = \log a$$

- $a = 1$: $h = 0$
- $a = 0.5$: $h = \log 0.5 \approx -0.693$ ← **负数!**

**这就是微分熵可以为负的第一个反例**。关键:$h(X)$ 衡量的是"概率密度的对数期望",不是真正的"信息量"(负的信息量没意义)。但**增量** $h(X) - h(Y)$ 仍然有意义。

#### 例子: 高斯分布 $N(\mu, \sigma^2)$ 的微分熵

$$h(X) = \frac{1}{2} \log(2 \pi e \sigma^2) = \frac{1}{2} \log(2 \pi e) + \log \sigma$$

$$\approx 1.419 + \log \sigma \quad \text{(nats)}$$

**关键观察**:
- **与均值 $\mu$ 无关**(只取决于方差 $\sigma^2$)
- $\sigma$ 越大,熵越大(分布越分散,不确定性越大)
- 推导见 `../../../基础/数学基础/第01章-高等数学/第01章-06-积分·测度·Lebesgue积分-概率与KL散度的数学基础.md`

```python
import numpy as np

def gaussian_differential_entropy(sigma):
    """h(N(μ, σ²)) = 0.5 * log(2πe σ²)"""
    return 0.5 * np.log(2 * np.pi * np.e * sigma ** 2)

# 标准差越大,熵越大
for sigma in [0.5, 1.0, 2.0, 5.0]:
    print(f"σ={sigma}: h = {gaussian_differential_entropy(sigma):.3f} nats")
# σ=0.5: 1.072 nats
# σ=1.0: 1.419 nats
# σ=2.0: 1.766 nats
# σ=5.0: 2.296 nats
```

#### 工程意义: VAE 损失中的高斯熵

**VAE**(变分自编码器)的损失函数:

$$L = \mathbb{E}_{q(z|x)}[\log p(x \mid z)] - D_{KL}(q(z \mid x) \| p(z))$$

其中先验 $p(z) = N(0, I)$。当 $q(z \mid x) = N(\mu, \sigma^2)$ 时, KL 散度有**解析形式**(因为涉及高斯微分熵):

$$D_{KL}(q \| p) = \log \frac{1}{\sigma} + \frac{\sigma^2 + \mu^2}{2} - \frac{1}{2}$$

这一项在 PyTorch 中直接算,不需要采样, 这就是**重参数化技巧** + **解析 KL** 的好处。详见 `rec教程 第 21 章`。

### 2.4 信息熵的三个公理化性质(Shannon 唯一性定理)

Shannon 证明了:**满足以下三个公理的任何函数 $H$,必是 $-c \sum p \log p$ 形式**。

| 公理 | 含义 |
| :--- | :--- |
| **连续性** | $H$ 是 $P$ 的连续函数 |
| **最大性** | $H$ 在均匀分布时最大(对给定支持集) |
| **可加性** | $H(X, Y) = H(X) + H(Y \mid X)$(链式法则) |

这三个公理**唯一**确定了 $H = -c \sum p \log p$。这就是"为什么信息熵是这个形式",**没有其他选择**。详见 `./第05章-01-Shannon信息论的诞生-从通信到信息.md`。

## 3. 联合熵 $H(X, Y)$

### 3.1 定义:两个变量的总不确定性

**定义**:两个离散随机变量 $(X, Y)$ 的**联合熵**为:

$$H(X, Y) = -\sum_{x \in \mathcal{X}} \sum_{y \in \mathcal{Y}} P(x, y) \log P(x, y)$$

**直观**:**同时知道 $X$ 和 $Y$ 所需的平均信息量** = "看到 $(X, Y)$ 联合事件的平均惊讶度"。

#### 例子: 两个独立硬币

设 $X, Y$ 独立,各为公平硬币($P(X = H) = P(Y = H) = 0.5$)。

联合分布 $P(X, Y)$:

| | $Y = H$ | $Y = T$ |
| :--- | :--- | :--- |
| $X = H$ | 0.25 | 0.25 |
| $X = T$ | 0.25 | 0.25 |

$$H(X, Y) = -4 \times 0.25 \log 0.25 = \log 4 = 2 \log 2 \approx 1.386 \text{ nats}$$

**注意**:
- $H(X) = H(Y) = \log 2 \approx 0.693$ nats
- $H(X, Y) = H(X) + H(Y)$(独立时**恰好**等于)

#### 例子: 完全相关(确定性函数 $Y = f(X)$)

设 $Y = X$(完全冗余),$P(X = 0) = P(X = 1) = 0.5$。

联合分布: $P(X = 0, Y = 0) = 0.5$, $P(X = 0, Y = 1) = 0$, $P(X = 1, Y = 0) = 0$, $P(X = 1, Y = 1) = 0.5$。

$$H(X, Y) = -2 \times 0.5 \log 0.5 = \log 2 \approx 0.693 \text{ nats}$$

**注意**:
- $H(X) = H(Y) = \log 2 \approx 0.693$ nats
- $H(X, Y) = H(X) = H(Y)$(完全冗余)

**两个极端**:
- 独立: $H(X, Y) = H(X) + H(Y)$(最大)
- 完全相关: $H(X, Y) = H(X) = H(Y)$(最小,等于单变量)

### 3.2 链式法则(首次出现): $H(X, Y) = H(X) + H(Y \mid X)$

#### 定理

对任意两个随机变量 $X, Y$:

$$H(X, Y) = H(X) + H(Y \mid X)$$

其中**条件熵** $H(Y \mid X) = \sum_{x} P(x) H(Y \mid X = x) = -\sum_x \sum_y P(x, y) \log P(y \mid x)$。

#### 证明(思路)

$$\begin{aligned}
H(X, Y) &= -\sum_{x, y} P(x, y) \log P(x, y) \\
&= -\sum_{x, y} P(x, y) \log [P(x) P(y \mid x)] \quad \text{(链式法则 } P(x,y) = P(x) P(y|x)) \\
&= -\sum_{x, y} P(x, y) [\log P(x) + \log P(y \mid x)] \\
&= -\sum_{x, y} P(x, y) \log P(x) - \sum_{x, y} P(x, y) \log P(y \mid x) \\
&= -\sum_x P(x) \log P(x) - \sum_{x, y} P(x, y) \log P(y \mid x) \\
&= H(X) + H(Y \mid X) \quad \blacksquare
\end{aligned}$$

#### 韦恩图(ASCII)

```text
              H(X) 圆
          ┌───────────────┐
          │               │
          │   ┌───────┐   │
          │   │  I    │   │   ← 中心 I = I(X;Y) (互信息)
   H(Y|X) │   │(交集) │   │     = H(X) - H(X|Y)
          │   │       │   │     = H(X) + H(Y) - H(X,Y)
          │   └───────┘   │
          │               │
          └───────────────┘
              H(Y) 圆

   整个矩形 = H(X,Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)
   中心 I    = 互信息  = H(X) - H(X|Y) = H(Y) - H(Y|X)
   左/右月牙 = H(X|Y), H(Y|X) (条件熵)
```

**关键读法**:
- **H(X, Y) = 整个矩形** = 同时知道 $X, Y$ 所需信息
- **H(X) = 左侧圆** = 只知道 $X$ 所需信息
- **H(Y) = 右侧圆** = 只知道 $Y$ 所需信息
- **I(X; Y) = 交集** = $X$ 和 $Y$ 共享的信息

### 3.3 不等式: $H(X, Y) \le H(X) + H(Y)$

**定理**:对任意 $X, Y$:

$$H(X, Y) \le H(X) + H(Y)$$

**等号成立当且仅当 $X \perp Y$** (独立)。

**直观**:知道 $X$ 后,$Y$ 至少不会变得"更不确定", 所以联合不确定性 ≤ 各自不确定性之和。

**工程意义**:
- **冗余减少不确定性**:两个变量完全相关时,联合熵 = 各自熵(没增加新信息)
- **独立增加不确定性**:两个变量独立时,联合熵 = 各自熵之和(没有信息共享)

#### 例子: 推荐系统的"双塔"评分

用户向量 $\mathbf{u}$ 和物品向量 $\mathbf{v}$ 的评分 $R = \mathbf{u} \cdot \mathbf{v}$(内积)。
- $H(\mathbf{u}, \mathbf{v}) \le H(\mathbf{u}) + H(\mathbf{v})$(用户和物品的独立部分)
- 如果用户兴趣高度集中,物品分布也集中,$H(\mathbf{u}, \mathbf{v})$ 远小于 $H(\mathbf{u}) + H(\mathbf{v})$(因为有"共现"信息)

### 3.4 联合熵的扩展到 $n$ 个变量

**定义** $n$ 个变量的**联合熵**:

$$H(X_1, X_2, \ldots, X_n) = -\sum_{x_1, \ldots, x_n} P(x_1, \ldots, x_n) \log P(x_1, \ldots, x_n)$$

**链式法则**(一般形式,见 §6):

$$H(X_1, \ldots, X_n) = \sum_{i=1}^{n} H(X_i \mid X_1, \ldots, X_{i-1})$$

**例**:三元联合熵 $H(X, Y, Z)$:

$$H(X, Y, Z) = H(X) + H(Y \mid X) + H(Z \mid X, Y)$$

**工程意义**:**序列模型(GPT)的训练目标 = 最小化序列联合熵的 Monte Carlo 估计**。详见 §6。

### 3.5 工程例子: 多任务学习的损失

**多任务学习**的总损失:

$$L = \alpha L_1 + \beta L_2 + \gamma L_3$$

每个任务的损失 $L_i$ 通常是**交叉熵** $H(P_i, Q_i)$(其中 $P_i$ 是任务 $i$ 的真实标签, $Q_i$ 是模型输出)。

**信息论视角**:
- 任务 $1$ 的真实标签熵: $H(P_1)$(任务的内在难度)
- 多任务联合熵: $H(P_1, P_2, P_3)$(所有任务的总信息量)
- 联合熵 $\le$ 各自熵之和(任务可能相关)
- **多任务学习能成功,正是因为任务间有共享结构**,所以联合熵 < 各自熵之和

## 4. 条件熵 $H(Y \mid X)$

### 4.1 定义:给定 $X$ 后 $Y$ 的剩余不确定性

**定义**:**条件熵** $H(Y \mid X)$ 是"给定 $X$ 后, $Y$ 的平均不确定性":

$$H(Y \mid X) = \sum_{x \in \mathcal{X}} P(x) H(Y \mid X = x)$$

其中 $H(Y \mid X = x) = -\sum_y P(y \mid x) \log P(y \mid x)$ 是**给定 $X = x$ 后 $Y$ 的熵**。

**展开式**:

$$H(Y \mid X) = -\sum_{x, y} P(x, y) \log P(y \mid x)$$

#### 直觉

- **$H(Y)$** = 不知道 $X$ 时, $Y$ 的不确定性
- **$H(Y \mid X)$** = 知道 $X$ 后, $Y$ 还剩多少不确定性
- **$H(Y) - H(Y \mid X) = I(X; Y)$** = $X$ 帮我们减少的 $Y$ 的不确定性(互信息)

#### 例子: 天气预报的"条件熵"

设"天气" $X \in \{\text{sun}, \text{rain}\}$, "是否带伞" $Y \in \{\text{yes}, \text{no}\}$。

**不知道天气时**:
- $P(Y = \text{yes}) = 0.4$, $P(Y = \text{no}) = 0.6$
- $H(Y) = -0.4 \log 0.4 - 0.6 \log 0.6 \approx 0.673$ nats

**知道天气时**:
- $P(Y = \text{yes} \mid X = \text{sun}) = 0.1$, $P(Y = \text{no} \mid X = \text{sun}) = 0.9$
- $P(Y = \text{yes} \mid X = \text{rain}) = 0.9$, $P(Y = \text{no} \mid X = \text{rain}) = 0.1$

$$H(Y \mid X = \text{sun}) = -0.1 \log 0.1 - 0.9 \log 0.9 \approx 0.325 \text{ nats}$$

$$H(Y \mid X = \text{rain}) \approx 0.325 \text{ nats}$$

假设 $P(X = \text{sun}) = P(X = \text{rain}) = 0.5$:

$$H(Y \mid X) = 0.5 \times 0.325 + 0.5 \times 0.325 = 0.325 \text{ nats}$$

**互信息** $I(X; Y) = H(Y) - H(Y \mid X) = 0.673 - 0.325 = 0.348$ nats(天气帮我们减少 0.348 nats 的"带伞"不确定性)。

### 4.2 性质: $H(Y \mid X) \le H(Y)$

**定理**:**条件熵永远 ≤ 边际熵**。

$$H(Y \mid X) \le H(Y)$$

**等号成立当且仅当 $X \perp Y$** (独立)。

**直观**:**知道 $X$ 永远不会让 $Y$ 更不确定**(在平均意义上)。最坏情况是 $X$ 与 $Y$ 无关(知道 $X$ 没帮助)。

**证明思路**:用 $H(Y \mid X)$ 是 $H(Y \mid X = x)$ 的凸组合(对 $x$ 加权平均),而凸组合 ≤ 最大值 = $H(Y)$。也可以用 Jensen 不等式直接证。

#### 例子: 推荐系统

- $H(\text{用户点击})$ = 不知道任何信息时,点击的不确定性(由先验分布决定)
- $H(\text{用户点击} \mid \text{用户特征})$ = 知道用户特征后,点击还剩多少不确定性
- **好的特征 → 条件熵远小于边际熵 → 互信息大**

### 4.3 链式法则(再叙): $H(X, Y) = H(X) + H(Y \mid X)$

**联合熵 = 边际 + 条件**(从 $X$ 的视角):

$$H(X, Y) = H(X) + H(Y \mid X)$$

**从 $Y$ 的视角**:

$$H(X, Y) = H(Y) + H(X \mid Y)$$

两个式子相减得**互信息**:

$$H(Y \mid X) - H(X \mid Y) = H(Y) - H(X)$$

**重新组织**:

$$H(X) - H(X \mid Y) = H(Y) - H(Y \mid X) = I(X; Y)$$

这就是"知道对方后自己减少的不确定性"。

### 4.4 工程核心: 决策树的特征选择 = 信息增益

**问题**:给定样本集合 $S$ 和特征 $A$,用 $A$ 划分 $S$ 后,目标变量 $Y$ 的不确定性减少多少?

**信息增益** (Information Gain) = **互信息** $I(Y; A)$:

$$\text{IG}(S, A) = H(Y) - H(Y \mid A) = H(Y) - \sum_{v \in \text{Values}(A)} \frac{|S_v|}{|S|} H(Y \mid A = v)$$

**决策树算法 (ID3 / C4.5)**:
- 在每个节点,遍历所有特征 $A$
- 选**信息增益最大**的特征做划分
- 递归建树

**为什么信息增益?**
- 信息增益大 = 知道 $A$ 后, $Y$ 的不确定性大幅减少 = $A$ 对预测 $Y$ 很有用
- 这正是**互信息**的含义

#### 例子: 决策树选"天气"还是"湿度"预测"是否打球"

样本(简化):

| 天气 | 湿度 | 是否打球 |
| :--- | :--- | :--- |
| 晴 | 高 | 否 |
| 晴 | 高 | 否 |
| 阴 | 高 | 是 |
| 雨 | 高 | 是 |
| 雨 | 低 | 是 |
| 雨 | 低 | 是 |
| 阴 | 低 | 是 |
| 晴 | 高 | 否 |
| 晴 | 低 | 是 |
| 雨 | 低 | 是 |

**手算信息增益**:

- 边际 $H(\text{打球}) = -0.4 \log 0.4 - 0.6 \log 0.6 \approx 0.673$ nats
- $H(\text{打球} \mid \text{天气})$:

| 天气 | 是 | 否 | $H$ |
| :--- | :--- | :--- | :--- |
| 晴 | 1 | 3 | $-(0.25 \log 0.25 + 0.75 \log 0.75) \approx 0.562$ |
| 阴 | 2 | 0 | $0$ |
| 雨 | 3 | 0 | $0$ |

$$H(\text{打球} \mid \text{天气}) = 0.4 \times 0.562 + 0.3 \times 0 + 0.3 \times 0 = 0.225 \text{ nats}$$

$$\text{IG}(\text{天气}) = 0.673 - 0.225 = 0.448 \text{ nats}$$

(继续算 $H(\text{打球} \mid \text{湿度})$ 也可以,决策树会选 IG 大的特征。)

```python
from collections import Counter
import numpy as np

def entropy(y):
    """H(Y) = -sum p log p"""
    counts = Counter(y)
    n = len(y)
    h = 0
    for c in counts.values():
        p = c / n
        if p > 0:
            h -= p * np.log(p)
    return h

def conditional_entropy(y, x):
    """H(Y|X) = sum_v P(X=v) H(Y|X=v)"""
    n = len(y)
    h = 0
    for v in set(x):
        mask = [xi == v for xi in x]
        yv = [y[i] for i in range(n) if mask[i]]
        h += (sum(mask) / n) * entropy(yv)
    return h

def information_gain(y, x):
    """IG(Y; X) = H(Y) - H(Y|X)"""
    return entropy(y) - conditional_entropy(y, x)

# 测试数据
weather = ['sun', 'sun', 'overcast', 'rain', 'rain', 'rain',
           'overcast', 'sun', 'sun', 'rain']
humidity = ['high', 'high', 'high', 'high', 'low', 'low',
            'low', 'high', 'low', 'low']
play = ['no', 'no', 'yes', 'yes', 'yes', 'yes', 'yes', 'no', 'yes', 'yes']

print(f"H(play)         = {entropy(play):.3f} nats")
print(f"H(play|weather) = {conditional_entropy(play, weather):.3f} nats")
print(f"IG(play;weather)= {information_gain(play, weather):.3f} nats")
print(f"IG(play;humidity)={information_gain(play, humidity):.3f} nats")
```

**注意**:**信息增益对取值多的特征有偏好**(因为划分更细, IG 倾向于更高)。C4.5 引入**信息增益比**修正: $\text{GainRatio} = \text{IG} / H(A)$。

### 4.5 条件熵的链式法则

**定理** (条件熵的链式法则):

$$H(X_1, \ldots, X_n \mid Y) = \sum_{i=1}^{n} H(X_i \mid X_1, \ldots, X_{i-1}, Y)$$

**直观**:**给定 $Y$ 的情况下, $X$ 序列的联合熵 = 各步条件熵之和**。

**工程应用**: Transformer 解码时, 给定上文 $Y$, 预测下一个 token 的总不确定性 = 各步条件熵之和。这正是**自回归语言模型的损失**。

## 5. 互信息 $I(X; Y)$ (引入)

> **本章只引入互信息的 4 种等价定义, 详细性质 (PMI / CMI / 数据处理不等式) 见 `./第05章-03-互信息·点互信息·条件互信息.md`。**

### 5.1 定义: $X$ 和 $Y$ 共享的信息

**定义**: $X$ 和 $Y$ 的**互信息** (Mutual Information):

$$I(X; Y) = H(X) + H(Y) - H(X, Y)$$

**直觉**:**$X$ 和 $Y$ 共同拥有的信息量**。可以理解为"知道 $X$ 后, $Y$ 的不确定性减少多少"。

#### 4 种等价定义

通过链式法则, 可以得到 4 个等价的表达:

| # | 公式 | 含义 |
| :--- | :--- | :--- |
| 1 | $I(X;Y) = H(X) + H(Y) - H(X,Y)$ | 联合熵的减少量 |
| 2 | $I(X;Y) = H(X) - H(X \mid Y)$ | 知道 $Y$ 后 $X$ 不确定性的减少量 |
| 3 | $I(X;Y) = H(Y) - H(Y \mid X)$ | 知道 $X$ 后 $Y$ 不确定性的减少量 |
| 4 | $I(X;Y) = D_{KL}(P_{X,Y} \| P_X \otimes P_Y)$ | 联合分布与独立分布的 KL 散度 |

**4 种定义数学上完全等价**, 描述同一物理量。**互信息 = 联合分布 vs 独立分布的差异** = "$X$ 和 $Y$ 距离独立有多远"。

#### 韦恩图(ASCII, 互信息 = 交集)

```text
           H(X)                   H(Y)
        ┌────────┐              ┌────────┐
       │          │            │          │
       │          │┌──────────┐│          │
       │          ││  互信息  ││          │
       │  H(X|Y)  ││ I(X;Y)   ││  H(Y|X)  │   ← 阴影矩形 = 交集
       │ (左月牙) ││  交集    ││ (右月牙) │     = I(X;Y)
       │          │└──────────┘│          │
       │          │            │          │
        └────────┘              └────────┘

H(X, Y)  = 整个并集 + 交集 = H(X) + H(Y|X) = H(Y) + H(X|Y)
H(X)     = 左圆  = H(X|Y) + I(X;Y)
H(Y)     = 右圆  = H(Y|X) + I(X;Y)
I(X;Y)   = 交集  = H(X) + H(Y) - H(X,Y)   ← 互信息 = 交集!
H(X|Y)   = 左圆独占的右侧月牙
H(Y|X)   = 右圆独占的左侧月牙
```

**关键观察**: 互信息**精确**等于韦恩图的**交集**部分(两个圆重叠的区域)。这与"条件熵 = 圆外的月牙"形成对照。

### 5.2 性质

**1. 非负性**: $I(X; Y) \ge 0$,**等号当且仅当 $X \perp Y$**。

**直观**: 知道 $X$ 不会让 $Y$ 更难预测(互信息不可能为负)。

**2. 对称性**: $I(X; Y) = I(Y; X)$(从哪个角度看都一样)。

**3. 上界**: $I(X; Y) \le \min(H(X), H(Y))$(互信息不超过边际熵的较小者)。

**4. 极端情况**:
- $X \perp Y$: $I(X; Y) = 0$(独立 → 无共享信息)
- $Y = f(X)$(确定性函数): $I(X; Y) = H(Y) = H(X)$(完全共享)

### 5.3 与相关系数的对比: 为什么互信息更强?

**皮尔逊相关系数** $\rho(X, Y)$:

$$\rho(X, Y) = \frac{\text{Cov}(X, Y)}{\sigma_X \sigma_Y}$$

**关键缺陷**:**只测"线性关系"**。

| | 相关系数 $\rho$ | 互信息 $I(X;Y)$ |
| :--- | :--- | :--- |
| 度量范围 | $[-1, 1]$ | $[0, \infty)$ |
| 测的关系 | 线性 | 任意统计依赖 |
| 独立性判定 | $\rho = 0$ 不一定独立 | $I = 0$ **等价**于独立 |
| 非线性敏感 | 不敏感 | 敏感 |
| 分布假设 | 隐含"线性 + 同方差" | 无 |

#### 反例: 抛物线关系

设 $X \sim U(-1, 1)$, $Y = X^2 + \epsilon$。

- $\text{Cov}(X, X^2) = 0$(奇函数, 积分为 0)→ $\rho \approx 0$
- 但 $Y$ 显然依赖 $X$ → $I(X; Y) > 0$

```python
import numpy as np
from sklearn.feature_selection import mutual_info_regression

np.random.seed(0)
x = np.random.uniform(-1, 1, 10000).reshape(-1, 1)
y = x.flatten() ** 2 + 0.1 * np.random.randn(10000)

# 相关系数
print(f"ρ(X, X²) = {np.corrcoef(x.flatten(), y)[0, 1]:.4f}")  # ≈ 0
# 互信息(用 KNN 估计)
mi = mutual_info_regression(x, y, n_neighbors=5)[0]
print(f"I(X; X²) ≈ {mi:.4f} nats")  # > 0
```

**结论**:**相关系数只是"线性相关的特例"**。**互信息捕获了所有统计依赖**,包括非线性、单调但不线性、阶梯函数等复杂关系。

#### 工程意义

**对比学习** (SimCLR, MoCo, CLIP) 用 **InfoNCE** 损失:

$$L_{\text{InfoNCE}} = -\mathbb{E}\left[\log \frac{\exp(s(x_i, y_i)/\tau)}{\sum_{j=1}^{N} \exp(s(x_i, y_j)/\tau)}\right]$$

这本质上是**互信息的下界**(详见第 7 章)。**如果用相关系数,会丢失所有非线性依赖,对比学习效果会差**。

### 5.4 互信息的估计: 难在哪儿?

互信息的**定义简单**,**估计困难**。原因:
- 不知道 $P(x, y)$ 的解析形式
- 高维时,$I(X; Y)$ 的计算涉及 $P(x, y)$ 的密度估计,误差大
- 实际数据是采样,样本数有限

**主要方法**:
| 方法 | 思想 | 局限 |
| :--- | :--- | :--- |
| **直方图估计** | 把数据离散化到格子 | 高维灾难 |
| **KDE** | 核密度估计 | 高维不可行 |
| **KNN 估计** (Kraskov et al.) | 基于 k 近邻距离 | 维度不能太高 |
| **MINE** (Belghazi et al. 2018) | 用神经网络估计 KL | 训练不稳定 |
| **InfoNCE** (van den Oord et al. 2018) | 用对比损失 | 是下界, 不是精确值 |

详见 `./第05章-03-互信息·点互信息·条件互信息.md`。

### 5.5 工程例子: 决策树、特征选择、变量筛选

**特征选择**的三种信息论指标:

| 指标 | 公式 | 用途 |
| :--- | :--- | :--- |
| **信息增益 (IG)** | $I(Y; A) = H(Y) - H(Y \mid A)$ | 决策树 ID3 |
| **信息增益比 (Gain Ratio)** | $I(Y; A) / H(A)$ | 决策树 C4.5(修正 IG 偏好) |
| **对称不确定性 (SU)** | $2 I(Y; A) / (H(Y) + H(A))$ | 特征筛选(归一化到 [0, 1]) |

**例子** (sklearn):

```python
from sklearn.feature_selection import mutual_info_classif
import numpy as np

X = np.random.randn(1000, 10)  # 10 个特征
y = (X[:, 0] + X[:, 1] ** 2 + 0.1 * np.random.randn(1000) > 0).astype(int)

# 估计每个特征与 y 的互信息
mi = mutual_info_classif(X, y, n_neighbors=5)
print("特征互信息:", mi)
# 第 0, 1 个特征(线性 + 平方依赖) 应该有高 MI
```

## 6. 链式法则 (一般形式)

### 6.1 定理: $n$ 个变量的联合熵 = 各步条件熵之和

**定理** (链式法则, Chain Rule for Entropy):

对任意 $n$ 个随机变量 $X_1, X_2, \ldots, X_n$:

$$H(X_1, X_2, \ldots, X_n) = \sum_{i=1}^{n} H(X_i \mid X_1, \ldots, X_{i-1})$$

**直观**:**联合不确定性 = 每一步的"边际"信息 + 条件信息** 之和。从 $X_1$ 开始,逐步加入 $X_2, X_3, \ldots$,每一步的"新信息"是条件熵。

#### 证明(归纳)

**基础**: $n = 2$ 时,$H(X_1, X_2) = H(X_1) + H(X_2 \mid X_1)$(已证于 §3)。

**归纳**: 假设对 $n - 1$ 成立。考虑:

$$H(X_1, \ldots, X_n) = H(X_1, \ldots, X_{n-1}) + H(X_n \mid X_1, \ldots, X_{n-1})$$

由归纳假设, $H(X_1, \ldots, X_{n-1}) = \sum_{i=1}^{n-1} H(X_i \mid X_1, \ldots, X_{i-1})$。代入得:

$$H(X_1, \ldots, X_n) = \sum_{i=1}^{n-1} H(X_i \mid X_1, \ldots, X_{i-1}) + H(X_n \mid X_1, \ldots, X_{n-1}) = \sum_{i=1}^{n} H(X_i \mid X_1, \ldots, X_{i-1}) \quad \blacksquare$$

### 6.2 例: 三元联合熵的两种展开

设 $X, Y, Z$:

$$H(X, Y, Z) = H(X) + H(Y \mid X) + H(Z \mid X, Y)$$

**解读**:
- $H(X)$: 先看到 $X$(基础信息)
- $H(Y \mid X)$: 已知 $X$, $Y$ 还剩多少
- $H(Z \mid X, Y)$: 已知 $X, Y$, $Z$ 还剩多少

**对称地**(从 $Y$ 开始):

$$H(X, Y, Z) = H(Y) + H(X \mid Y) + H(Z \mid X, Y)$$

两种展开的**差**就是 $H(X) + H(Y \mid X) - H(Y) - H(X \mid Y) = I(X; Y) - I(Y; X) = 0$。验证了 $I$ 的对称性。

### 6.3 链式法则的工程核心: 序列模型的 NLL 分解

**问题**: 语言模型 (GPT) 训练时, 损失函数为什么是:

$$L = -\frac{1}{T} \sum_{t=1}^{T} \log P_\theta(x_t \mid x_{<t})$$

**信息论解读**: 这就是**序列联合熵的 Monte Carlo 估计**!

**推导**:

由链式法则:

$$H(X_1, \ldots, X_T) = \sum_{t=1}^{T} H(X_t \mid X_{<t})$$

其中 $X_{<t} = (X_1, \ldots, X_{t-1})$。

**真实数据分布** $P_{\text{data}}$ 下的期望:

$$H(P_{\text{data}}) = -\mathbb{E}_{P_{\text{data}}}\left[\log P_{\text{data}}(X_1, \ldots, X_T)\right] = -\mathbb{E}\left[\sum_{t=1}^{T} \log P_{\text{data}}(X_t \mid X_{<t})\right]$$

**但**真实分布 $P_{\text{data}}$ 未知, 我们用**模型分布** $P_\theta$ 估计:

$$\text{NLL}(\theta) = -\mathbb{E}_{P_{\text{data}}}\left[\log P_\theta(X_1, \ldots, X_T)\right] = -\mathbb{E}\left[\sum_{t=1}^{T} \log P_\theta(X_t \mid X_{<t})\right]$$

**关键**:
- NLL 是**联合熵** $H(X_1, \ldots, X_T)$ 的 (用 $P_\theta$ 估计的) 形式
- 最小化 NLL ≈ 最小化**联合熵** ≈ 让模型学到的分布接近数据
- **链式分解让计算可行**: 不需要直接估计联合分布, 只需逐 token 估计条件分布

#### 为什么这能工作?

**问题**: 真实联合分布 $P_{\text{data}}(x_1, \ldots, x_T)$ 涉及所有 token 的组合 ($V^T$ 种, $V$ 是词表大小, 通常 3 万-10 万), 不可枚举。

**链式法则的好处**: 把它拆成 $T$ 个**条件分布** $P_\theta(x_t \mid x_{<t})$。每个条件分布只需要在词表 $V$ 上归一化(softmax), 复杂度 $O(V)$ per step。

**Transformer** 自回归 head 就是为这个设计的: 输入 $x_{<t}$, 输出 $V$ 维 logits, softmax 得到 $P_\theta(x_t \mid x_{<t})$。

#### 例子: GPT 训练一步

```python
import torch
import torch.nn as nn

# 假设 batch_size=2, 序列长度=4, 词表大小=100
logits = torch.randn(2, 4, 100, requires_grad=True)  # 模型输出
targets = torch.randint(0, 100, (2, 4))  # 真实 token

# PyTorch 的 CrossEntropyLoss 就是负对数似然
loss_fn = nn.CrossEntropyLoss()
loss = loss_fn(logits.view(-1, 100), targets.view(-1))
# loss = -mean(log P_θ(x_t | x_<t))

# 信息论: 这就是 -1/T * sum_t log P_θ(x_t | x_<t)
# = 联合熵 H(X_1, ..., X_T) 的 Monte Carlo 估计(用 P_θ 替代 P_data)
```

**完整推导**: $L = H(P_{\text{data}}, P_\theta) - H(P_{\text{data}})$(交叉熵 - 真实熵),见 `./第05章-05-交叉熵·困惑度·NLL.md`。

### 6.4 链式法则的其他形式

**条件版本的链式法则**:

$$H(X_1, \ldots, X_n \mid Y) = \sum_{i=1}^{n} H(X_i \mid X_1, \ldots, X_{i-1}, Y)$$

**KL 散度的链式法则**(第 4 章深入):

$$D_{KL}(P \| Q) = \sum_{i=1}^{n} \mathbb{E}_{P}\left[\log \frac{P(X_i \mid X_{<i})}{Q(X_i \mid X_{<i})}\right]$$

**互信息的链式法则**:

$$I(X_1, \ldots, X_n; Y) = \sum_{i=1}^{n} I(X_i; Y \mid X_1, \ldots, X_{i-1})$$

详见 `./第05章-03-互信息·点互信息·条件互信息.md`。

### 6.5 链式法则与图模型

**贝叶斯网络**对应**链式分解**:

$$P(x_1, \ldots, x_n) = \prod_{i=1}^{n} P(x_i \mid \text{parents}(x_i))$$

**马尔可夫链**的熵率:

$$H(\text{chain}) = \lim_{n \to \infty} \frac{1}{n} H(X_1, \ldots, X_n) = H(X_n \mid X_{n-1})$$

**应用**: 语言模型的**困惑度** (perplexity) = $2^{H(\text{chain})}$,熵率 = **平均每 token 的信息量**。

### 7.2 实验 2: 联合熵与条件熵

```python
import torch
import numpy as np

def joint_entropy(p_xy):
    """H(X, Y) = -sum_{x,y} p(x,y) log p(x,y)"""
    p_xy = np.clip(p_xy, 1e-10, 1.0)
    return -np.sum(p_xy * np.log(p_xy))

def marginal(p_xy, axis):
    """边际分布 p(x) 或 p(y)"""
    return np.sum(p_xy, axis=axis)

def conditional_entropy(p_xy):
    """H(Y|X) = -sum_{x,y} p(x,y) log p(y|x)
    = sum_x p(x) H(Y|X=x)"""
    p_x = marginal(p_xy, axis=1)  # 沿 y 求和
    p_y_given_x = p_xy / p_x[None, :]  # 广播
    h = 0
    for x in range(p_xy.shape[0]):
        h_y_x = -np.sum(p_y_given_x[:, x] * np.log(np.clip(p_y_given_x[:, x], 1e-10, 1)))
        h += p_x[x] * h_y_x
    return h

# 例子 1: X, Y 独立(均匀)
p_xy_indep = np.array([[0.25, 0.25], [0.25, 0.25]])
print(f"独立: H(X,Y) = {joint_entropy(p_xy_indep):.4f}, "
      f"H(Y|X) = {conditional_entropy(p_xy_indep):.4f}")

# 例子 2: 完全相关(Y = X)
p_xy_same = np.array([[0.5, 0.0], [0.0, 0.5]])
print(f"完全相同: H(X,Y) = {joint_entropy(p_xy_same):.4f}, "
      f"H(Y|X) = {conditional_entropy(p_xy_same):.4f}")

# 例子 3: 部分相关
p_xy_part = np.array([[0.3, 0.1], [0.1, 0.5]])
h_xy = joint_entropy(p_xy_part)
h_y_given_x = conditional_entropy(p_xy_part)
p_x = marginal(p_xy_part, axis=1)
p_y = marginal(p_xy_part, axis=0)
h_x = -np.sum(p_x * np.log(p_x))
h_y = -np.sum(p_y * np.log(p_y))
mi = h_x + h_y - h_xy
print(f"\n部分相关:")
print(f"  H(X)={h_x:.4f}, H(Y)={h_y:.4f}, H(X,Y)={h_xy:.4f}")
print(f"  H(Y|X)={h_y_given_x:.4f}")
print(f"  I(X;Y) = H(X)+H(Y)-H(X,Y) = {mi:.4f}")
print(f"  验证: H(X)-H(X|Y) ≈ {h_x - (h_xy - h_y):.4f}")
```

### 7.3 实验 3: 微分熵 (高斯分布)

```python
import numpy as np

def gaussian_differential_entropy(sigma):
    """h(N(μ, σ²)) = 0.5 * log(2πe σ²)"""
    return 0.5 * np.log(2 * np.pi * np.e * sigma ** 2)

# 不同 σ 的高斯熵
sigmas = [0.1, 0.5, 1.0, 2.0, 5.0, 10.0]
print("σ        h(X) (nats)")
for sigma in sigmas:
    h = gaussian_differential_entropy(sigma)
    print(f"{sigma:<8} {h:.4f}")

# 数值验证: 用 Monte Carlo 估计 h(X) = -E[log f(X)]
# f(x) = (1 / √(2πσ²)) exp(-(x-μ)² / 2σ²)
# log f(x) = -0.5 log(2πσ²) - (x-μ)² / 2σ²
# E[-log f(X)] = 0.5 log(2πσ²) + E[(X-μ)²] / 2σ² = 0.5 log(2πσ²) + 0.5

print("\n数值验证 (Monte Carlo):")
sigma = 2.0
n_samples = 1_000_000
samples = np.random.normal(0, sigma, n_samples)
# 估计 h(X) = -E[log f(X)]
log_density = -0.5 * np.log(2 * np.pi * sigma ** 2) - samples ** 2 / (2 * sigma ** 2)
h_numerical = -np.mean(log_density)
h_analytical = gaussian_differential_entropy(sigma)
print(f"  解析: {h_analytical:.4f}, 数值: {h_numerical:.4f}")
# 两者应该非常接近
```

log_probs = F.log_softmax(logits, dim=-1)  # (B, T, V)

nll_manual = nll_per_step.mean()
print(f"手动 NLL     = {nll_manual.item():.4f} nats")
print(f"一致性: {torch.allclose(nll, nll_manual)}")

# 3. 信息论解读: 这就是 H(X_1, ..., X_T) 的 Monte Carlo 估计
# (用 P_θ 替代 P_data)
print(f"\n信息论: NLL = 联合熵 H(X_1, ..., X_T) 的估计")
print(f"  链式法则: H(X_1..T) = H(X_1) + H(X_2|X_1) + ... + H(X_T|X_<T)")
print(f"  估计: -1/T * sum_t log P_θ(x_t | x_<t)")
print(f"  每步的 log P_θ(x_t | x_<t) = -H(X_t | X_<t) 的样本")

## 8. 常见误区 + 面试 Q&A + 互引

### 8.1 常见误区 (5 条工程师踩坑点)

#### 误区 1: ❌ "互信息 = 相关系数的平方"

**反例**: 互信息 $I(X; Y)$ 和相关系数 $\rho$ **没有简单公式关系**。

- $X \sim U(-1, 1), Y = X^2$: $\rho = 0$ 但 $I(X; Y) > 0$
- $X, Y$ 高斯时: $I(X; Y) = -\frac{1}{2} \log(1 - \rho^2)$(只对二元高斯成立)
- 一般情形: 没有通用公式

**判断**: 不要试图把 $I$ 和 $\rho$ 用公式联系起来。它们是不同坐标系下的"相关性"。

#### 误区 2: ❌ "微分熵一定是正数"

**反例**: 均匀分布 $U(0, 0.5)$ 的微分熵是 $\log(0.5) = -0.693$ nats,**负数**。

**根本原因**: 微分熵 $h(X) = -\int f(x) \log f(x) dx$ 是**密度的对数期望**, 当 $f(x) > 1$ 时(密度 > 1 是合法的, 概率密度可以任意大), $\log f(x) > 0$, 整体可以为负。

**判断**: 微分熵可以为负,但**增量** $h(X) - h(Y)$(对应 KL 散度)永远非负。

#### 误区 3: ❌ "联合熵 = 边际熵之和"

**反例**: $H(X, Y) \le H(X) + H(Y)$(独立时取等),一般严格小于。

**直观**: 两个变量如果有任何关联, 联合熵就比各自熵之和**小**(因为有"共享信息")。

**判断**: 用 $H(X, Y) = H(X) + H(Y \mid X)$(链式法则)更准确。$H(Y \mid X) \le H(Y)$,所以联合熵 ≤ 边际熵之和。

#### 误区 4: ❌ "条件熵 = 0 当且仅当 $Y$ 是 $X$ 的函数"

**精确说法**: $H(Y \mid X) = 0$ 当且仅当 $Y$ 是 $X$ 的**确定性函数**。

**反例**: 如果 $X$ 是 $Y$ 的"部分决定因素",但 $Y$ 还有其他噪声源, $H(Y \mid X) > 0$。例如:
- $X$ = 年龄, $Y$ = 收入。给定年龄, 收入仍有很大变数(教育、行业等)。$H(Y \mid X) > 0$。
- $H(Y \mid X) = 0$ 意味着"知道 $X$ 后, $Y$ 完全确定"(没有随机性)。

#### 误区 5: ❌ "信息增益 = 信息熵"

**精确区别**:
- **信息熵** $H(Y)$: 不知道任何特征时, $Y$ 的不确定性
- **信息增益** $I(Y; A) = H(Y) - H(Y \mid A)$: 用特征 $A$ 划分后, $Y$ 不确定性**减少的量**

**判断**: 信息增益**永远 ≤** 信息熵(因为 $H(Y \mid A) \ge 0$),**等于**信息熵当且仅当 $A$ 完全决定 $Y$。

### 8.2 面试 Q&A (L7/L8 难度)

#### Q1: 联合熵 $H(X, Y)$ 与 $H(X) + H(Y)$ 的关系? 什么时候取等号?

**标准答案**:

**关系**: $H(X, Y) \le H(X) + H(Y)$(联合熵不超过边际熵之和)。

**证明**: 由链式法则 $H(X, Y) = H(X) + H(Y \mid X)$, 而 $H(Y \mid X) \le H(Y)$(条件熵不超过边际熵, 因为知道 $X$ 不会让 $Y$ 更难预测)。所以 $H(X, Y) \le H(X) + H(Y)$。

**等号成立**当且仅当 $X \perp Y$(独立)。证明: $H(Y \mid X) = H(Y)$ 当且仅当 $X$ 与 $Y$ 独立(条件熵等于边际熵等价于独立)。

**直观解读**: 边际熵之和"假设"两个变量独立; 联合熵"考虑"了真实的相关性。如果独立, 两者相等; 如果相关, 联合熵更小(因为有共享信息)。

**面试加分**: 举具体例子。$X, Y$ 都是公平硬币:
- 独立: $H(X, Y) = \log 4 = 2 \log 2$, $H(X) + H(Y) = 2 \log 2$, 相等
- 完全相关 ($Y = X$): $H(X, Y) = \log 2$, $H(X) + H(Y) = 2 \log 2$, 联合熵更小

**工程意义**: 多任务学习中, 多个任务的联合熵 ≤ 各自熵之和(因为任务有"共享结构")。如果各任务独立, 多任务没增益; 如果强相关, 多任务能让模型学得更高效。

#### Q2: 条件熵 $H(Y \mid X)$ 的工程意义?

**标准答案**:

**核心含义**: 知道 $X$ 后, $Y$ 还剩多少"难以预测的部分"。

**三个工程应用**:

**1. 决策树特征选择** (ID3 / C4.5):
- 信息增益 $I(Y; A) = H(Y) - H(Y \mid A)$
- 选信息增益最大的特征
- 等价于最大化 $I(Y; A)$, 即最小化 $H(Y \mid A)$

**2. 特征工程**:
- 好的特征 → $H(Y \mid X)$ 小 → 互信息大
- 评估特征: 计算 $I(Y; X_i)$, 选 top-k

**3. 信息瓶颈 (Information Bottleneck)**:
- 找表征 $T$ 使得 $I(X; T)$ 小(压缩输入) 但 $I(T; Y)$ 大(保留预测信息)
- $I(T; Y) = H(Y) - H(Y \mid T)$, 所以最大化 $I(T; Y)$ 等价于最小化 $H(Y \mid T)$
- 详见 `./第05章-07-信息瓶颈IB·VIB·InfoNCE.md`

**面试加分**: 提到 $H(Y \mid X)$ **永远非负**, 且 $H(Y \mid X) = 0$ 当且仅当 $Y$ 是 $X$ 的确定性函数。

#### Q3: 微分熵可以是负数吗? 为什么?

**标准答案**:

**是的, 微分熵可以为负**。最简单反例: 均匀分布 $U(0, 0.5)$:

$$h(X) = -\int_0^{0.5} 2 \log 2 \, dx = -\log 0.5 = \log 2 \approx 0.693$$

不对, 重算: 均匀分布 $U(0, a)$ 的密度是 $f(x) = 1/a$, 所以:

$$h(X) = -\int_0^a \frac{1}{a} \log \frac{1}{a} \, dx = \log a$$

- $a = 0.5$: $h = \log 0.5 \approx -0.693$ nats ← **负数!**
- $a = 2$: $h = \log 2 \approx 0.693$ nats
- $a = 1$: $h = 0$ nats

**为什么可以负?**
- 微分熵 $h(X) = -\int f(x) \log f(x) dx$ 是**密度的对数期望**
- 当 $f(x) > 1$ 时, $\log f(x) > 0$, 整体可以为负
- **概率密度 $f(x)$ 可以 > 1**(因为它度量的是"每单位长度的概率", 不是概率本身)

**重要区分**:
- **离散熵** $H(X) = -\sum p \log p \ge 0$(因为 $0 \le p \le 1$, $\log p \le 0$)
- **微分熵** $h(X)$ 可以取任何实数(因为 $f(x) > 1$ 是合法的)
- 但**增量** $h(X) - h(Y)$ 仍然有意义(对应 KL 散度, 永远 $\ge 0$)

**面试加分**: 提到 KL 散度 $D_{KL}(P \| Q) = h(P) - h(Q) + \int (f_P - f_Q) dx$ 的形式(差分熵可以用 KL 表示)。

#### Q4: 决策树如何用信息增益 (互信息) 选特征?

**标准答案**:

**核心公式**: 信息增益 $\text{IG}(S, A) = I(Y; A) = H(Y) - H(Y \mid A)$。

**计算步骤**:

1. 算当前节点 $Y$ 的熵 $H(Y)$
2. 对每个候选特征 $A$:
   - 按 $A$ 的取值划分样本到子集
   - 算每个子集的熵 $H(Y \mid A = v)$
   - 加权求和: $H(Y \mid A) = \sum_v \frac{|S_v|}{|S|} H(Y \mid A = v)$
   - 信息增益 = $H(Y) - H(Y \mid A)$
3. 选信息增益最大的特征

**例子** (来自 §4.4): 预测"是否打球", 选"天气"或"湿度":
- $H(\text{打球}) = 0.673$ nats
- $H(\text{打球} \mid \text{天气}) = 0.225$ nats, IG = 0.448 nats
- (类似算 $H(\text{打球} \mid \text{湿度})$, 假设 IG = 0.151)
- 决策树选"天气"(IG 更大)

**ID3 的局限性**: 信息增益对取值多的特征有偏好(例如"用户 ID"这种唯一特征, IG 极大但无意义)。

**C4.5 修正**: 用**信息增益比** $\text{GainRatio} = \text{IG} / H(A)$ 修正偏好。

**CART**: 用**基尼系数** $G = 1 - \sum p_i^2$ 代替熵(计算更快, 效果类似)。

**面试加分**: 提到 CART 用基尼系数 $G = 1 - \sum p_i^2$ 作为替代, 因为 $G$ 与 $H$ 在小 $p$ 时近似($\log p \approx p - 1$),但 $G$ 计算更快(无对数)。

#### Q5: 序列模型 NLL 与联合熵的关系?

**标准答案**:

**NLL** (Negative Log-Likelihood):

$$\text{NLL}(\theta) = -\frac{1}{T} \sum_{t=1}^{T} \log P_\theta(x_t \mid x_{<t})$$

**联合熵**:

$$H(X_1, \ldots, X_T) = -\mathbb{E}_{P_{\text{data}}}\left[\log P_{\text{data}}(X_1, \ldots, X_T)\right]$$

**关系推导**:

由**链式法则**:

$$H(X_1, \ldots, X_T) = \sum_{t=1}^{T} H(X_t \mid X_{<t}) = -\mathbb{E}_{P_{\text{data}}}\left[\sum_{t=1}^{T} \log P_{\text{data}}(X_t \mid X_{<t})\right]$$

NLL 是用**模型分布** $P_\theta$ 替代**真实分布** $P_{\text{data}}$:

$$\text{NLL} = -\mathbb{E}_{P_{\text{data}}}\left[\sum_{t=1}^{T} \log P_\theta(X_t \mid X_{<t})\right] = H(P_{\text{data}}, P_\theta) - H(P_{\text{data}})$$

其中 $H(P_{\text{data}}, P_\theta)$ 是**交叉熵**, $H(P_{\text{data}})$ 是常数(真实数据的内在熵)。

**意义**:
- 最小化 NLL ≈ 最小化 $H(P_{\text{data}}, P_\theta) \approx$ 最小化 KL 散度 $D_{KL}(P_{\text{data}} \| P_\theta)$
- **让模型分布 $P_\theta$ 接近真实分布 $P_{\text{data}}$**

**为什么 NLL = 困惑度 (perplexity) 的对数?**

困惑度 $\text{PPL} = 2^{H(P)/T}$, 其中 $H(P)$ 是平均每 token 的 NLL(以 2 为底)。

**工程意义**:
- **困惑度 (PPL)** 是语言模型的标准评估指标, 直接对应平均每 token 的熵
- PPL = 100 意味着模型平均需要 100 次"猜测"才能选对下一个 token
- GPT-4 级别: PPL ≈ 10-20; 人类水平: PPL ≈ 5-10

**面试加分**: 提到**困惑度的物理解释**: 困惑度 = 模型"等效地"在多少个候选中均匀猜测(均匀分布困惑度 = 词表大小 $V$)。

## 8. 信息论深度补充

### 8.1 香农熵的公理化

香农证明满足下列公理的 $H$ 必为 $-\sum p \log p$:

1. **连续性**: $H$ 连续
2. **最大性**: 均匀分布熵最大
3. **可加性**: $H(X, Y) = H(X) + H(Y | X)$

### 8.2 联合熵的链式法则

$$H(X_1, \ldots, X_n) = \sum_{i=1}^n H(X_i | X_{i-1}, \ldots, X_1)$$

**应用**: 自回归 LLM 似然 = $\sum_t H(x_t | x_{<t})$。

### 8.3 条件熵的性质

- $H(Y | X) \le H(Y)$ (条件不增加熵)
- $H(Y | X) \ge 0$
- $H(Y | X) = H(Y)$ 当 $X, Y$ 独立

### 8.4 互信息的性质

- $I(X; Y) \ge 0$
- $I(X; Y) = I(Y; X)$
- $I(X; Y) \le \min(H(X), H(Y))$
- $I(X; Y) = 0$ 当 $X, Y$ 独立

### 8.5 互信息链式法则

$$I(X; Y, Z) = I(X; Y) + I(X; Z | Y)$$

### 8.6 数据处理不等式

Markov 链 $X \to Y \to Z$, $I(X; Z) \le I(X; Y)$。

### 8.7 Fano 不等式

$$P(\hat X \neq X) \ge \frac{H(X | Y) - 1}{\log |X|}$$

给定 $Y$ 后, 估计 $X$ 错误率的下界。

## 9. KL 散度的更多性质

### 9.1 链式法则

$$D_{KL}(P(X, Y) \| Q(X, Y)) = D_{KL}(P(X) \| Q(X)) + \mathbb{E}_{P(X)}[D_{KL}(P(Y|X) \| Q(Y|X))]$$

### 9.2 互信息下界

$$I(X; Y) = D_{KL}(P(X, Y) \| P(X) P(Y)) \ge 0$$

### 9.3 KL 与似然

$$\log p(D | \theta) = \log p(D) - D_{KL}(p_\theta(x) \| p(x))$$

MLE = 最小化 $D_{KL}(p_\theta \| p_{\text{data}})$。

### 9.4 KL 与 MLE 的关系

$$\theta_{\text{MLE}} = \arg\min_\theta D_{KL}(\hat p_{\text{data}} \| p_\theta)$$

经验分布与模型分布的 KL 最小化。

## 10. 熵率

**定义**: 随机过程 $\{X_i\}$ 的熵率

$$H = \lim_{n \to \infty} \frac{1}{n} H(X_1, \ldots, X_n)$$

(若极限存在)。

**Markov 链**: $H = H(X_2 | X_1) = H(X_n | X_{n-1})$ (平稳时)。

**应用**: 语言模型复杂度。

---

## 11. 信道容量

**定义**: 信道转移 $p(y | x)$, 信道容量

$$C = \max_{p(x)} I(X; Y)$$

**应用**: 信息论的核心定理, 通信极限。

## 14. 信息论在 LLM 的应用

### 14.1 PPL (困惑度)

$$\text{PPL} = 2^{H(P)} = \exp(-\frac{1}{T}\sum_t \log p(x_t | x_{<t}))$$

PPL = "平均分支因子", 越低越好。

### 14.2 Temperature Scaling

$$\text{softmax}(x / \tau)$$

- $\tau \to 0$: one-hot (硬)

- $\tau = 1$: 标准

**信息论**: $\tau$ 控制熵, $\tau$ 大 → 熵高 → 多样。

### 14.3 Beam Search 与熵

维持 top-k 高熵候选, 探索 vs 利用。

### 14.4 LLM 不确定性估计

多次采样 + 投票 / logit entropy / consistency。

## 15. 高级信息论

### 15.1 Renyi 散度

$$D_\alpha(P \| Q) = \frac{1}{\alpha - 1} \log \int p^\alpha q^{1-\alpha} dx$$

$\alpha = 1$: KL, $\alpha = 0.5$: -2 log(BC), $\alpha = 2$: log($\chi^2$)。

### 15.2 f-散度

$$D_f(P \| Q) = \int q f(p/q) dx$$

推广 KL 散度。

### 15.3 Bregman 散度

$$D_F(p, q) = F(p) - F(q) - \langle \nabla F(q), p - q \rangle$$

KL 散度是 $F = \sum x \log x$ 的 Bregman 散度。

### 15.4 Tsallis 熵

$$S_q = \frac{1 - \sum p_i^q}{q - 1}$$

$q \to 1$ 时退化为 Shannon 熵。

## 29. 信息论的"反直觉"集合

### 29.1 KL 不对称

$D_{KL}(p \| q) \neq D_{KL}(q \| p)$, 但 JS 对称。

- 相关系数: 线性关系
- 互信息: 任意关系 (非参数)

### 29.4 信息有成本

擦除 1 bit = $k_B T \ln 2$ 焦耳。

### 29.5 Shannon 熵 vs Gibbs 熵

Shannon: 离散概率
Gibbs: 连续相空间 (需量子修正)

### 110. 第 2 章:熵·联合熵·条件熵·链式法则——不确定性的度量 - 应用场景 视角

**核心议题**: 本节从应用场景视角切入,系统展开 "第 2 章:熵·联合熵·条件熵·链式法则——不确定性的度量" 的相关讨论。

**1. 背景与动机**

任何技术或方法的出现都不是孤立的,而是回应特定历史条件下的具体问题。"第 2 章:熵·联合熵·条件熵·链式法则——不确定性的度量" 的发展也不例外。要理解它,必须回到它出现的那个时间点,看清它要解决的真实问题是什么。当时的主流方案有哪些不足? 它的提出填补了哪些空白? 这些问题的回答,决定了我们今天该如何使用它。

从知识论角度看,**技术演进是问题驱动的**——不是先有方案再找问题,而是先有问题再有方案。这个观察可以帮助我们避免"拿着锤子找钉子"的陷阱,真正把方法用对地方。

历史维度上,我们看到三个规律:

1. **从特殊到一般**: 早期方法往往针对特定场景,后期抽象出通用框架。学习的认知规律也是先掌握具体案例,再抽象出一般模式。这种"自下而上"的学习方式,在机器学习模型的设计里反复出现。

2. **从手工到自动**: 经验规则逐步被数据驱动的方法取代。在早期,很多 AI 系统依赖人工编写的规则。统计学习方法的崛起让"从数据中学习"成为可能。深度学习进一步把特征工程也自动化了。今天的大模型时代,我们看到端到端学习从感知扩展到了推理与生成。

3. **从局部到全局**: 关注单个组件,演进到关注整个系统。早期模型评估只关注单点指标,现在更关注全链路的协同效应。这种"系统视角"的转变,与软件工程从单体架构到微服务架构的演进高度相似。

**2. 应用场景视角的展开**

从应用场景视角出发,我们可以把 "第 2 章:熵·联合熵·条件熵·链式法则——不确定性的度量" 拆解为以下几个层次:

**第一层: 概念层** —— 这是最抽象的层次,定义了我们要研究的对象是什么。例如,"推荐系统"在概念层是一个"为用户从物品集合中筛选合适物品"的问题。这个层次的特点是清晰、稳定、不易变化。一个好的概念定义应该具备几个特征:可操作性、可测量性、可扩展性。

**第二层: 模型层** —— 把概念实例化为数学模型。同一概念可以有不同的模型化方式,例如"推荐系统"可以是协同过滤、矩阵分解、深度学习等。模型的选择决定了后续算法的空间,也决定了能利用的归纳偏置(比如序列模型擅长捕捉时序依赖,图模型擅长建模关系结构)。模型选型是工程实践中最重要的决策之一。

**第三层: 算法层** —— 在选定模型下,具体的求解方法。这一层最活跃,新算法层出不穷。同一模型往往有多种算法,各有优劣。例如同样是优化深度网络,可以选择 SGD、Adam、L-BFGS 等不同算法。算法的选择要考虑收敛速度、数值稳定性、计算成本等多个维度。

**第四层: 工程层** —— 算法落地的实现细节,包括数据流水线、训练框架、推理优化、监控告警等。工程层是研究到生产的桥梁,决定了一个方法能否真正用起来。一个在论文里表现很好的算法,如果不能高效实现、不能稳定运行、不能快速迭代,就没有实际价值。工程能力是把研究转化为生产力的关键。

**第五层: 业务层** —— 在具体业务场景中的表现。同一技术在不同业务里效果差异巨大,因为业务目标、数据分布、用户行为都有差异。从业务视角看技术,我们必须回答几个问题:这个技术解决了什么业务问题?投入产出比如何?长期可持续吗?技术评估必须与业务目标对齐,否则容易陷入"技术自嗨"的陷阱。

**3. 数学形式化(简洁版)**

虽然我们强调应用场景视角,但数学形式化提供了共同语言。机器学习的核心问题可以表达为:给定输入样本,学习一个映射函数,使得函数输出与真实目标的差距最小化。这个抽象捕捉了分类、回归、生成等大多数任务的本质。

进一步,优化目标通常加入正则化项来控制模型复杂度,平衡经验风险与模型容量。统计学习理论给出了泛化误差的上界,告诉我们模型越复杂并不一定越好——**奥卡姆剃刀**在数学上有严格的形式化。

偏差-方差分解是另一个核心框架:误差可以分解为模型偏差(欠拟合)、方差(过拟合)和不可约噪声三部分。理解这个分解有助于诊断模型表现、选择合适复杂度。

在数值稳定性方面,有几个常见陷阱: 浮点数精度有限、Log-Sum-Exp 计算要减去最大值、Softmax 在大数值下会溢出。这些工程细节常常决定一个模型能否在生产环境稳定运行。

**4. 信息论视角**

信息论为"第 2 章:熵·联合熵·条件熵·链式法则——不确定性的度量" 提供了统一的视角:**学习的本质是从数据中提取与目标相关的信息**。

互信息衡量知道一个变量后,另一个变量不确定性减少的量。在机器学习中,它被广泛用于特征选择、表示学习、多模态对齐等场景。

KL 散度衡量两个概率分布的距离,在交叉熵损失、变分推断、策略梯度等场景无处不在。需要注意它是**不对称**的——不同方向有不同的解释。

信息瓶颈原则指出,我们应该寻找既紧凑又预测性强的表示。这一思想影响了大量表示学习方法的设计,包括对比学习、自监督学习、多模态预训练等。

**7. 实践建议**

结合 "第 2 章:熵·联合熵·条件熵·链式法则——不确定性的度量" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

3. **从局部到全局**: 关注单个组件,演进到关注整个系统。早期模型评估只关注单点指标,现在更关注全链路的协同效应。这种"系统视角"的转变,与软件工程从单体架构到微服务架构的演进高度相似。

**2. 形式化视角的展开**

从形式化视角出发,我们可以把 "第 2 章:熵·联合熵·条件熵·链式法则——不确定性的度量" 拆解为以下几个层次:

**第一层: 概念层** —— 这是最抽象的层次,定义了我们要研究的对象是什么。例如,"推荐系统"在概念层是一个"为用户从物品集合中筛选合适物品"的问题。这个层次的特点是清晰、稳定、不易变化。一个好的概念定义应该具备几个特征:可操作性、可测量性、可扩展性。

**第二层: 模型层** —— 把概念实例化为数学模型。同一概念可以有不同的模型化方式,例如"推荐系统"可以是协同过滤、矩阵分解、深度学习等。模型的选择决定了后续算法的空间,也决定了能利用的归纳偏置(比如序列模型擅长捕捉时序依赖,图模型擅长建模关系结构)。模型选型是工程实践中最重要的决策之一。

**第三层: 算法层** —— 在选定模型下,具体的求解方法。这一层最活跃,新算法层出不穷。同一模型往往有多种算法,各有优劣。例如同样是优化深度网络,可以选择 SGD、Adam、L-BFGS 等不同算法。算法的选择要考虑收敛速度、数值稳定性、计算成本等多个维度。

**第四层: 工程层** —— 算法落地的实现细节,包括数据流水线、训练框架、推理优化、监控告警等。工程层是研究到生产的桥梁,决定了一个方法能否真正用起来。一个在论文里表现很好的算法,如果不能高效实现、不能稳定运行、不能快速迭代,就没有实际价值。工程能力是把研究转化为生产力的关键。

**第五层: 业务层** —— 在具体业务场景中的表现。同一技术在不同业务里效果差异巨大,因为业务目标、数据分布、用户行为都有差异。从业务视角看技术,我们必须回答几个问题:这个技术解决了什么业务问题?投入产出比如何?长期可持续吗?技术评估必须与业务目标对齐,否则容易陷入"技术自嗨"的陷阱。

**3. 数学形式化(简洁版)**

虽然我们强调形式化视角,但数学形式化提供了共同语言。机器学习的核心问题可以表达为:给定输入样本,学习一个映射函数,使得函数输出与真实目标的差距最小化。这个抽象捕捉了分类、回归、生成等大多数任务的本质。

进一步,优化目标通常加入正则化项来控制模型复杂度,平衡经验风险与模型容量。统计学习理论给出了泛化误差的上界,告诉我们模型越复杂并不一定越好——**奥卡姆剃刀**在数学上有严格的形式化。

偏差-方差分解是另一个核心框架:误差可以分解为模型偏差(欠拟合)、方差(过拟合)和不可约噪声三部分。理解这个分解有助于诊断模型表现、选择合适复杂度。

在数值稳定性方面,有几个常见陷阱: 浮点数精度有限、Log-Sum-Exp 计算要减去最大值、Softmax 在大数值下会溢出。这些工程细节常常决定一个模型能否在生产环境稳定运行。

**4. 信息论视角**

信息论为"第 2 章:熵·联合熵·条件熵·链式法则——不确定性的度量" 提供了统一的视角:**学习的本质是从数据中提取与目标相关的信息**。

互信息衡量知道一个变量后,另一个变量不确定性减少的量。在机器学习中,它被广泛用于特征选择、表示学习、多模态对齐等场景。

KL 散度衡量两个概率分布的距离,在交叉熵损失、变分推断、策略梯度等场景无处不在。需要注意它是**不对称**的——不同方向有不同的解释。

信息瓶颈原则指出,我们应该寻找既紧凑又预测性强的表示。这一思想影响了大量表示学习方法的设计,包括对比学习、自监督学习、多模态预训练等。

**7. 实践建议**

结合 "第 2 章:熵·联合熵·条件熵·链式法则——不确定性的度量" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "第 2 章:熵·联合熵·条件熵·链式法则——不确定性的度量" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
