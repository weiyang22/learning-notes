# 第05章-附录-信息论在DL·搜推中的应用对标表

刻画变量相关与对比学习下界,KL/JS/f-散度刻画分布距离与 VAE/GAN 损失,交叉熵/NLL/困惑度刻画分类与语言模型标准损失,信源/信道编码定理刻画压缩与传输极限,率失真刻画生成模型的信息瓶颈,IB/VIB/InfoNCE 刻画表征学习,注意力/KV-Cache/CoT/RLHF 刻画 LLM 的信息流。
>
> **本附录做四件事**:
> 1. 一张 **≥45 条**"信息论概念 ↔ ML/DL 组件"对标总表(第 1 节)
> 2. **8 个按章节分组的速查表**(第 2 节),每张 6-10 行,翻到即用
> 3. 与 1-高数 / 2-线代 / 3-概率论 / 4-离散数学 / 6-最优化 / 7-系统思维 的接口图(第 3 节)
> 4. 关键论文索引(第 4 节)
>
> **使用方式**:
> - 工程遇到具体问题(如"对比学习 loss 怎么选"),按"工程应用"列反查
> - 想从 ML 组件反推信息论(如"CrossEntropyLoss 为何这样"),按"ML/DL 对应物"列反查
> - 面试前翻末尾"快速回忆卡片"
> - 重要度 1-5 颗星,5 颗星 = 面试/工程必背
>
> **覆盖范围**:第 1-8 章全部概念 + LLM/搜推/RL 工业实践。配套:1-高数/附录、2-线代/附录、3-概率论/附录、4-离散数学/附录、6-最优化/附录。

## 6. 快速回忆卡片 (20 张)

**卡片 1:为什么交叉熵是分类标准损失?**

> $H(P, Q) = H(P) + D_{KL}(P\|Q)$。$H(P)$ 是真实分布的熵(固定), 所以**最小化 $H(P,Q)$ = 最小化 $D_{KL}(P\|Q)$**。又 $D_{KL}(P\|Q) = -\sum P \log Q + \text{const}$, 极小化 = 极大化似然 = **MLE**。所以 CE 损失 = MLE 训练。

**卡片 2:KL 不对称的工程意义?**

> $D_{KL}(P\|Q)$ mode-seeking(集中于 P 的峰, 怕漏峰), $D_{KL}(Q\|P)$ mode-covering(覆盖 P 所有区域, 怕漏谷)。**VAE 用前者**: 变分后验 $q(z\|x)$ 拟合先验 $p(z)$, 防止 z 过于发散。**EM 用后者**: 用 $q$ 逼近 $p$, 希望覆盖所有峰。

**卡片 3:InfoNCE 为什么是互信息下界?**

> $L_{\text{InfoNCE}} = -\mathbb{E}\left[\log \frac{e^{f(x,y)}}{\sum_{y'} e^{f(x,y')}}\right]$, 用 1 个正样本 + $N-1$ 个负样本。**Poole 2019** 证明: $I(x;y) \ge \log N - L_{\text{InfoNCE}}$。$N$ 越大, 下界越紧, 优化 InfoNCE = 最大化互信息。**CLIP / SimCSE / MoCo 全基于此**。

**卡片 4:困惑度 PPL 为什么用 $2^H$?**

> PPL = $2^H$ 或 $e^H$, 跨数据集可比。直接用 $H$(交叉熵)会受 $\log$ 底影响, PPL 把熵转回"等概率分支数", 直观: "模型平均在几个 token 间不确定"。LLaMA/GPT 报告 PPL 而非 $H$。

**卡片 5:注意力机制的信息论解释?**

> Self-attention $\text{softmax}(QK^T/\sqrt d) V$ 中, $Q$ 是查询(query, "我要什么信息"), $K$ 是键(key, "我有什么标签"), $V$ 是值(value, "我携带的信息")。**softmax 权重 = 路由概率**, 决定每个 query 从每个 key 拿多少信息。**注意力 = 信息路由**, 这是 Transformer 强大表达力的本质。

**卡片 6:KV-Cache 为什么能加速推理?**

> LLM 自回归生成: 第 $t$ 步需要所有 $1..t$ 个 token 的 K/V 矩阵。如果每步重算, 复杂度 $O(n^2)$。**KV-Cache** 把历史的 K/V 缓存下来, 每步只算新 token 的 K/V, 复杂度 $O(n)$。**信息论视角**: Cache = "复用已计算的信息", 避免信息冗余计算。

**卡片 7:RLHF 为什么要加 KL 约束?**

> $\min_\pi \mathbb{E}_x[\text{KL}(\pi(\cdot\|x) \| \pi_0(\cdot\|x))] - \mathbb{E}[\text{reward}]$。KL 约束 $\pi$ 不要离 $\pi_0$(SFT 模型)太远。**信息论解释**: 防止策略漂移, 保持输出分布的"基本形态", 只微调 reward 方向。**InstructGPT / ChatGPT 都用此约束**。

**卡片 8:为什么温度 $T>1$ 在蒸馏中有用?**

> $\text{softmax}(z/T)$, $T$ 大 → 概率分布变平坦 → 暴露教师模型"软知识"(类别间相似度关系)。比如 BERT 蒸馏时, 教师可能给 [猫:0.7, 狗:0.2, 车:0.1], $T=10$ 后变 [0.35, 0.30, 0.25], 学生学到"猫和狗比猫和车更相似"。

**卡片 9:信源编码 vs 信道编码**

> **信源编码**: 压缩信源(去冗余), 极限 = 信息熵 $H(X)$。例: Huffman, 算术编码, PNG。**信道编码**: 加冗余抗噪, 极限 = 信道容量 $C$。例: 5G LDPC 码, 卫星 Reed-Solomon。**DL 类比**: 量化(信源)vs 校验和(信道)。**生成模型是信源编码**。

**卡片 10:信息瓶颈 IB 怎么理解?**

> $\min I(X;T) - \beta I(T;Y)$。**压缩项** $I(X;T)$: 减少 $T$ 保留的 $X$ 信息(防止过拟合)。**预测项** $I(T;Y)$: 最大化 $T$ 对 $Y$ 的预测能力。$\beta$ 控制"压缩 vs 预测"权衡。**$\beta$ 大 = 重压缩**(像 PCA), $\beta$ 小 = 重预测**(像监督学习)。**VIB** 用 KL 上界实现可微优化。

**卡片 11:为什么 VAE 用前向 KL 而不是反向 KL?**

> VAE 的目标: $q_\phi(z \mid x) \approx p(z)$。我们只能采样 $q_\phi$, 而 $p(z)$ 不可采样(复杂)。**反向 KL** $D_{KL}(q\|p) = \mathbb{E}_q[\log q - \log p]$, 期望在 $q$ 下, 可计算。**前向 KL** $D_{KL}(p\|q) = \mathbb{E}_p[\log p - \log q]$, 期望在 $p$ 下, 不可计算。**所以 VAE 选反向 KL**。

**卡片 12:扩散模型怎么用信息论解释?**

> 前向过程 $q(x_t \mid x_0)$ = 加噪(信息丢失), 满足 $I(x_0; x_t) \le I(x_0; x_{t-1})$ (DPI)。**反向过程** $p_\theta(x_{t-1} \mid x_t)$ = 去噪(信息恢复)。**总互信息路径** $x_0 \to x_T \to x_0$ 形成"信息瓶颈"。**率失真角度**: 不同 $t$ 对应不同 $R(D)$ 曲线。

**卡片 13:为什么 Label Smoothing 有正则化效果?**

> 真实标签 $y$ 改成 $y' = (1-\epsilon) y + \epsilon / K$。**信息论解释**: 减少标签的"信息量"(从 one-hot 的 $H = \log K$ 到软标签的 $H' = $ 较小), 防止模型 over-confident。**KL 角度**: 软标签相当于在 loss 中加 $D_{KL}(y' \| y)$ 修正, 抑制极值。

**卡片 14:SimCLR 损失 NT-Xent 怎么写?**

> $\mathcal{L}_{i,j} = -\log \frac{\exp(\text{sim}(z_i, z_j)/\tau)}{\sum_{k=1}^{2N} \mathbb{1}_{[k \neq i]} \exp(\text{sim}(z_i, z_k)/\tau)}$。其中 $\text{sim}(u, v) = u^T v / \|u\| \|v\|$。**关键**: $\tau$ 是温度参数, $\tau$ 小 → 分布尖锐(对难负样本敏感), $\tau$ 大 → 分布平滑。**默认 $\tau = 0.1$ 效果最好**。

**卡片 15:BPE 编码的信息论原理?**

> BPE = Byte Pair Encoding, 反复合并最频繁的对。**与 Huffman 的关系**: 都是"频率驱动合并"。**不同**: Huffman 在字符级, BPE 在子词级。**理论**: 合并过程类似信息论中的"等价类划分", 减少符号数, 压缩分布。

**卡片 16:为什么推荐系统召回用双塔 + InfoNCE?**

> 双塔: $u = f_\text{user}(x)$, $i = f_\text{item}(y)$。相似度 = $u \cdot i / \|u\|\|i\|$。**InfoNCE 训练**: 正样本 $(u, i^+)$, 负样本 $(u, i^-)$。**信息论**: 最大化 user-item 互信息, 即"用户-物品相关性的下界"。**DSSM / YouTubeDNN / Two-Tower 全部基于此**。

**卡片 17:FlashAttention 为什么比朴素 Attention 快?**

> 朴素: $S = QK^T$ 完整计算 → OOM 在长序列。**FlashAttention**: **分块计算 + 在线 softmax** + **不存中间矩阵**。**信息论视角**: 注意力是"信息查询", FlashAttention 通过分块避免 O(n²) 内存, 同时通过重计算 (recomputation) 保持数值稳定, 实际是"用 IO 换计算"。

**卡片 18:DPO 为什么能替代 RLHF?**

> RLHF: 两阶段(SFT → RM → PPO)。DPO: 直接优化 $\pi_\theta(y_w \mid x) / \pi_\theta(y_l \mid x)$。**核心洞察**: RLHF 目标可解析地反推回偏好优化, **不需要显式训练奖励模型**。**信息论**: DPO 隐式地最大化偏好对的似然比, 等价于"奖励最大化 + KL 约束"的闭式解。

**卡片 19:GRPO 与 PPO 的区别?**

> PPO: 训练**价值网络** $V(s)$ 作为 baseline。GRPO (Group Relative PO): **组内归一化** = 用同组多个采样的均值/标准差作为 baseline。**优点**: 不需要价值网络, 训练快 2-3 倍。**DeepSeek-R1 用 GRPO**。**信息论**: 减少"参考分布"的计算量。

**卡片 20:量化 (Quantization) 的率失真视角?**

> INT8 量化: $X \to \hat X = \text{round}(X / s) \cdot s$, 失真 $D = \mathbb{E}[(X - \hat X)^2]$。**率失真函数** $R(D)$ 给出"给定失真下, 最少比特数"。**INT8** ≈ 8 bit, **INT4** ≈ 4 bit。**LLM.int8()** 显式分解 outlier + 主体。**GPTQ** 逐层优化量化参数, 更接近率失真下界。

## 11. 信息论核心概念深度展开

### 11.1 信息量 $I(x) = -\log p(x)$ 的"3 层含义"

**直觉层**: 越不可能的事件, 信息量越大。

**数学层**: $I(x) = -\log p(x)$ 是**严格递减** + **可加** (独立事件 $I(x, y) = I(x) + I(y)$) 的唯一函数族 (Camel 定理)。

**工程层**:

- **通信**: 用 bit 数衡量"惊讶度", 编码长度 = 信息量
- **ML**: cross-entropy = NLL (训练目标)
- **推荐**: 长尾物品高信息量, 给低曝光

### 11.2 熵 $H(X)$ 的"4 个等价定义"

1. **不确定性**: $H(X) = $ 编码 $X$ 平均所需 bit 数
2. **信息量期望**: $H(X) = \mathbb{E}_{p(x)}[-\log p(x)]$
3. **最大离散**: $H_{\max}(n) = \log n$ (均匀分布)
4. **不等式**: $H(X) \le H_{\max}$, 等号 iff 均匀

### 11.3 联合熵 / 条件熵的"链式法则"

$$H(X, Y) = H(X) + H(Y | X) = H(Y) + H(X | Y)$$

**链式法则 (Chain Rule)**: $n$ 个变量的联合熵

$$H(X_1, \ldots, X_n) = \sum_{i=1}^n H(X_i | X_{i-1}, \ldots, X_1)$$

**应用**: Transformer 注意力机制的因果 mask (下三角), 保证 $H(X_t | X_{<t})$ 单向流动。

### 11.4 互信息的"5 个等价定义"

1. $I(X; Y) = H(X) - H(X | Y)$
2. $I(X; Y) = H(Y) - H(Y | X)$
3. $I(X; Y) = H(X) + H(Y) - H(X, Y)$
4. $I(X; Y) = D_{KL}(p(x, y) \| p(x) p(y))$
5. $I(X; Y) = \mathbb{E}_{p(x, y)}[\log \frac{p(x, y)}{p(x) p(y)}]$

**应用**:

- **对比学习**: 最大化图-文互信息 (CLIP)
- **特征选择**: 选与标签互信息高的特征
- **RL**: 状态-动作互信息作为探索奖励

### 11.5 KL 散度的"7 个性质"

1. **非负**: $D_{KL}(p \| q) \ge 0$, 等号 iff $p = q$
2. **不对称**: $D_{KL}(p \| q) \neq D_{KL}(q \| p)$
3. **不满足三角不等式**: 不是真距离
4. **Jensen 不等式**: $D_{KL}(p \| q) = \mathbb{E}_p[\log(p/q)] \ge \mathbb{E}_p[\log 1] = 0$
5. **变分形式**: $D_{KL}(p \| q) = \sup_f \mathbb{E}_p[f] - \log \mathbb{E}_q[e^f]$ (f-散度)
6. **链式法则**: $D_{KL}(p(x, y) \| q(x, y)) = D_{KL}(p(x) \| q(x)) + D_{KL}(p(y|x) \| q(y|x))$
7. **互信息下界**: $I(X; Y) = D_{KL}(p(x, y) \| p(x) p(y))$

### 11.6 f-散度族

$$D_f(p \| q) = \mathbb{E}_q\left[f\left(\frac{p(x)}{q(x)}\right)\right]$$

| f-divergence | 函数 $f$ | 备注 |
| :--- | :--- | :--- |
| KL | $x \log x$ | 标准, 非对称 |
| JS | $x \log x - (x+1) \log(x+1)$ | 对称, 0-1 |
| Hellinger | $(\sqrt{x} - 1)^2$ | 对称, 0-1 |
| Total Variation | $\|x - 1\| / 2$ | 对称 |
| $\chi^2$ | $x^2 - 1$ | Pearson |
| Reverse KL | $-\log x$ | $D_{KL}(q \| p)$ |
| $\alpha$-divergence | $\alpha$-参数化 | Rényi 推广 |

## 12. 信息论在 DL 中的 8 大应用领域

### 12.1 损失函数

| 损失 | 公式 | 信息论含义 |
| :--- | :--- | :--- |
| Cross-Entropy | $-\sum p \log q$ | 编码长度 |
| NLL | $-\log q(y\|x)$ | $-\log p$ 期望 |
| KL 散度 | $\sum p \log(p/q)$ | 分布差异 |
| JS 散度 | $\frac{1}{2}(KL(p\|m) + KL(q\|m))$ | 对称化 KL |
| Wasserstein | $W_p(p, q)$ | 几何距离 |
| MMD | $\|\mathbb{E}_p[\phi] - \mathbb{E}_q[\phi]\|$ | RKHS 距离 |

### 12.2 变分推断

$$\log p(x) \ge \mathbb{E}_{q(z|x)}[\log p(x|z)] - D_{KL}(q(z|x) \| p(z)) = \text{ELBO}$$

最大化 ELBO = 最小化 $D_{KL}(q(z|x) \| p(z|x))$ (变分下界)。

### 12.3 生成模型

| 模型 | 损失 | 信息论视角 |
| :--- | :--- | :--- |
| VAE | $-\text{ELBO}$ | 重构 + KL |
| Diffusion | $\|\epsilon - \epsilon_\theta(x_t, t)\|^2$ | Score matching |
| GAN | $\log D$ / $-\log D$ | 极大极小 |
| Flow | $-\log \|\det J\|$ | 可逆变换保持测度 |

### 12.4 注意力机制

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d}}\right) V$$

**信息论视角**: softmax 把 logits 转成概率, 加权聚合 = "软选择" 信息。

### 12.5 互信息最大化 (InfoMax)

- **对比学习**: $I(\text{image}; \text{text})$ 大 (CLIP)
- **表征学习**: $I(z; y)$ 大 (SimCLR)
- **RL 探索**: $I(s; a)$ 大 (鼓励多样性)

### 12.6 信息瓶颈 (IB)

$$\min_{p(z|x)} I(X; Z) - \beta I(Z; Y)$$

**压缩输入, 保留标签相关信息**。DL 泛化的理论框架。

### 12.7 率失真理论

$$R(D) = \min_{p(\hat x | x): \mathbb{E}[d(x, \hat x)] \le D} I(X; \hat X)$$

**R-D 权衡**: 压缩率 vs 失真。应用于量化、压缩、知识蒸馏。

### 12.8 通信信道视角

LLM 可视为"自然语言信道" - "压缩的语料"信道 - "生成"信道。**信息论是 LLM 训练的理论基础**。

## 13. 互信息估计 (Mutual Information Estimation)

### 13.1 难点

$I(X; Y) = D_{KL}(p(x, y) \| p(x) p(y))$ 在高维难直接算。

### 13.2 MINE (Mutual Information Neural Estimation)

$$I(X; Y) \ge \widehat{I}_{\text{MINE}} = \sup_T \mathbb{E}_{p(x,y)}[T] - \log \mathbb{E}_{p(x)p(y)}[e^T]$$

神经网络 $T_\theta$ 估计 MI 下界。

### 13.3 InfoNCE 下界

$$I(X; Y) \ge \log(N) - \mathcal{L}_{\text{InfoNCE}}$$

$N$ = batch 内负样本数。CLIP / SimCLR 用此。

### 13.4 蒙特卡洛估计

$$I(X; Y) \approx \frac{1}{n} \sum_{i=1}^n \log \frac{p(x_i, y_i)}{p(x_i) p(y_i)}$$

### 13.5 应用代码

```python
import torch

def mutual_info_estimate_joint(x, y, hidden=128):
    """MINE 风格 MI 估计."""
    T = torch.nn.Sequential(
        torch.nn.Linear(x.shape[-1] + y.shape[-1], hidden),
        torch.nn.ReLU(),
        torch.nn.Linear(hidden, 1),
    )
    optimizer = torch.optim.Adam(T.parameters(), lr=1e-3)
    for _ in range(1000):
        # 正样本 (联合分布)
        joint = torch.cat([x, y], dim=-1)
        # 负样本 (边缘分布)
        y_shuffled = y[torch.randperm(y.shape[0])]
        marginal = torch.cat([x, y_shuffled], dim=-1)
        t_joint = T(joint).mean()
        t_marginal = torch.log(torch.exp(T(marginal)).mean() + 1e-10)
        loss = -(t_joint - t_marginal)  # maximize MI
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
    return (t_joint - t_marginal).item()
```

## 14. 信息论与压缩感知

### 14.1 香农极限

无损压缩的下限: 平均码长 $\ge H(X)$ bit/符号。

**工程**: Huffman 编码, 算术编码接近香农极限。

### 14.2 率失真函数

$$R(D) = \min I(X; \hat X) \text{ s.t. } \mathbb{E}[d(X, \hat X)] \le D$$

$D$ 越大, $R$ 越小 (允许更多失真)。

### 14.3 量化与率失真

INT8 量化: $D$ = (量化误差), $R$ = 8 bit/参数。

**极致**: INT4 = $R = 4$ bit/参数, 失真更大。

### 14.4 LLM 量化

- FP32 (32 bit) → FP16 (16) → INT8 (8) → INT4 (4)
- 每步失真增大, 模型性能下降
- 信息论指导: 重要参数保留精度, 不重要量化

## 17. 信息论常用恒等式速查

### 17.1 熵

- $H(X) \ge 0$
- $H(X) \le H_{\max} = \log |X|$
- $H(X) = 0$ 当 $X$ 退化
- $H(X, Y) \le H(X) + H(Y)$, 等号 iff 独立

### 17.2 条件熵

- $H(Y | X) \ge 0$
- $H(Y | X) \le H(Y)$ (条件不增加熵)
- $H(Y | X) = 0$ 当 $Y = f(X)$

### 17.3 互信息

- $I(X; Y) \ge 0$
- $I(X; Y) = I(Y; X)$
- $I(X; Y) \le \min(H(X), H(Y))$
- $I(X; Y) = 0$ 当独立

### 17.4 链式法则

- $H(X_1, \ldots, X_n) = \sum_i H(X_i | X_{<i})$
- $I(X; Y, Z) = I(X; Y) + I(X; Z | Y)$
- $D_{KL}(P(X, Y) \| Q(X, Y)) = D_{KL}(P \| Q) + \mathbb{E}_P[D_{KL}(P(Y|X) \| Q(Y|X))]$

### 17.5 联合熵 - 互信息

$$H(X, Y) = H(X) + H(Y) - I(X; Y)$$

$$H(X | Y) = H(X) - I(X; Y)$$

### 17.6 不等式

- **Jensen**: $f(\mathbb{E}[X]) \le \mathbb{E}[f(X)]$, $f$ 凸
- **log-sum**: $\log \sum_i e^{x_i} \ge x_j$ (任一 $j$)
- **Gibbs**: $\log \mathbb{E}[e^X] \ge \mathbb{E}[X]$
- **Cauchy-Schwarz**: $(\mathbb{E}[XY])^2 \le \mathbb{E}[X^2] \mathbb{E}[Y^2]$

## 18. 完整代码实现

### 18.1 熵 / KL / MI 工具

```python
import numpy as np
import torch

def entropy(p, eps=1e-10):
    """信息熵 H(p)."""
    p = np.asarray(p) + eps
    return -np.sum(p * np.log(p))

def kl_divergence(p, q, eps=1e-10):
    """KL(p || q)."""
    p = np.asarray(p) + eps
    q = np.asarray(q) + eps
    return np.sum(p * np.log(p / q))

def js_divergence(p, q, eps=1e-10):
    """JS(p || q)."""
    p = np.asarray(p) + eps
    q = np.asarray(q) + eps
    m = 0.5 * (p + q)
    return 0.5 * (kl_divergence(p, m) + kl_divergence(q, m))

def mutual_info(p_xy, eps=1e-10):
    """I(X;Y) from joint distribution."""
    p_xy = np.asarray(p_xy) + eps
    p_x = p_xy.sum(axis=-1, keepdims=True)
    p_y = p_xy.sum(axis=-2, keepdims=True)
    return np.sum(p_xy * np.log(p_xy / (p_x @ p_y)))

# 测试
p = np.array([0.5, 0.5])
q = np.array([0.9, 0.1])
print(f"H(p) = {entropy(p):.4f}")  # 0.6931 (= log 2)
print(f"KL(p||q) = {kl_divergence(p, q):.4f}")  # 0.5108
print(f"JS(p,q) = {js_divergence(p, q):.4f}")  # 0.0580
```

### 18.3 互信息估计

```python
class MINEEstimator(torch.nn.Module):
    """MINE: Mutual Information Neural Estimation."""
    def __init__(self, x_dim, y_dim, hidden=128):
        super().__init__()
        self.T = torch.nn.Sequential(
            torch.nn.Linear(x_dim + y_dim, hidden),
            torch.nn.ReLU(),
            torch.nn.Linear(hidden, hidden),
            torch.nn.ReLU(),
            torch.nn.Linear(hidden, 1),
        )

    def forward(self, x, y):
        # 正样本
        joint = torch.cat([x, y], dim=-1)
        # 负样本
        y_perm = y[torch.randperm(y.shape[0])]
        marginal = torch.cat([x, y_perm], dim=-1)
        t_joint = self.T(joint).mean()
        t_marginal = torch.log(torch.exp(self.T(marginal)).mean() + 1e-10)
        return t_joint - t_marginal

# 训练
x = torch.randn(1000, 32)
y = x @ torch.randn(32, 16) + 0.1 * torch.randn(1000, 16)  # y 依赖 x
mine = MINEEstimator(32, 16)
optimizer = torch.optim.Adam(mine.parameters(), lr=1e-3)
for _ in range(500):
    mi = mine(x, y)
    loss = -mi
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
print(f"Estimated MI: {mi.item():.4f}")  # 应为正, 接近真实 MI
```

## 19. 数学例题

### 例题 19.1: 熵最大化

**题目**: 4 种结果 $\{1, 2, 3, 4\}$, 求最大熵分布。

**解答**: 均匀分布 $p = (1/4, 1/4, 1/4, 1/4)$, $H = \log 4 = 2$ bit。

---

### 例题 19.2: KL 不对称验证

**题目**: $p = (0.5, 0.5)$, $q = (0.9, 0.1)$, 算 $D_{KL}(p \| q)$ 和 $D_{KL}(q \| p)$。

**解答**:

- $D_{KL}(p \| q) = 0.5 \log(0.5/0.9) + 0.5 \log(0.5/0.1) = 0.5 \log(0.555) + 0.5 \log(5) = -0.294 + 0.805 = 0.510$
- $D_{KL}(q \| p) = 0.9 \log(0.9/0.5) + 0.1 \log(0.1/0.5) = 0.9 \log 1.8 + 0.1 \log 0.2 = 0.534 - 0.322 = 0.211$

**不对称**: $0.510 \neq 0.211$。

---

### 例题 19.3: 互信息计算

**题目**: $X \in \{0, 1\}$, $Y = X \oplus N$, $N \sim \text{Ber}(0.1)$。求 $I(X; Y)$。

**解答**:

- $H(Y) = H(0.5) = 1$ bit (对称)
- $H(Y | X) = H(N) = -0.9 \log 0.9 - 0.1 \log 0.1 \approx 0.469$ bit
- $I(X; Y) = H(Y) - H(Y | X) = 1 - 0.469 = 0.531$ bit

---

### 例题 19.4: 香农熵比较

**题目**: 三个分布 (a) 均匀 8 种, (b) 集中, (c) 长尾。哪个熵最大?

**解答**: (a) 最大 $H = \log 8 = 3$ bit。

---

### 例题 19.5: VAE ELBO

**题目**: $\mathcal{L} = \mathbb{E}_q[\log p(x|z)] - D_{KL}(q(z|x) \| p(z))$。$x = 1, z \sim \mathcal{N}(\mu, \sigma^2)$, $q(z|x) = \mathcal{N}(\mu_q, \sigma_q^2)$。求 KL 闭式。

**解答**: $D_{KL}(\mathcal{N}(\mu_q, \sigma_q^2) \| \mathcal{N}(0, 1)) = \frac{1}{2}(\mu_q^2 + \sigma_q^2 - 1 - \log \sigma_q^2)$。

---

### 例题 19.6: Cross-Entropy = KL + H

**题目**: $\text{CE}(p, q) = D_{KL}(p \| q) + H(p)$ 证明。

**解答**:

$$\text{CE}(p, q) = -\sum p \log q = -\sum p \log p + \sum p \log(p/q) = H(p) + D_{KL}(p \| q)$$

---

### 例题 19.7: InfoNCE 下界

**题目**: $N$ 个样本, 1 个正 $x^+$, $N-1$ 个负 $x^-$, 证明 $\text{InfoNCE} \ge -\log N + I(x; y)$。

**解答**: 用 Jensen 不等式 + 联合分布与边缘分布关系 (Oord 2018)。

---

### 例题 19.8: MINE 估计

**题目**: 用 MINE 估计 $I(X; Y)$, 其中 $Y = X + 0.1 \epsilon$, $\epsilon \sim \mathcal{N}(0, 1)$。预期值?

**解答**: $X, Y$ 几乎完全相关, MI 应大 ($\sim 6$ bit)。详见代码示例。

## 22. 面试高频 (15 题)

### Q1: 信息量 $I(x) = -\log p(x)$ 为什么取对数?

**答**: (1) 可加性: $I(x, y) = I(x) + I(y)$ (独立); (2) 单调性: $p$ 小 → $I$ 大; (3) 信息论基本定理保证唯一 (Camel 定理)。

---

### Q2: 交叉熵和 KL 散度的关系?

**答**: $\text{CE}(p, q) = H(p) + D_{KL}(p \| q)$。最小化 CE = 最小化 KL (因 $H(p)$ 与 $q$ 无关)。

---

### Q3: KL 散度不对称有什么实际影响?

**答**: 不能当距离用 (不满足三角不等式)。**前向 KL** ($D_{KL}(p \| q)$) zero-seeking, $q$ 在 $p$ 高密度区集中。**反向 KL** ($D_{KL}(q \| p)$) mass-covering, $q$ 覆盖 $p$ 全支持。

---

### Q4: VAE 的 ELBO 是什么?

**答**: $\text{ELBO} = \mathbb{E}_{q(z|x)}[\log p(x|z)] - D_{KL}(q(z|x) \| p(z))$。最大化 ELBO = 最小化 $D_{KL}(q(z|x) \| p(z|x))$, 即让 $q$ 近似后验。

---

### Q5: MINE 怎么估计互信息?

**答**: 用神经网络 $T_\theta$ 学习 critic, $\hat I = \mathbb{E}_{p(x,y)}[T] - \log \mathbb{E}_{p(x)p(y)}[e^T]$。**理论**: Donsker-Varadhan 表示的下界。

---

### Q6: CLIP 的 InfoNCE 损失?

**答**: $\mathcal{L} = -\frac{1}{N} \sum_i \log \frac{e^{\text{sim}(I_i, T_i)/\tau}}{\sum_j e^{\text{sim}(I_i, T_j)/\tau}}$。图文对为正, batch 内其他为负。理论下界: $I(\text{image}; \text{text}) \ge \log N - \mathcal{L}$。

---

### Q7: 率失真理论在 LLM 量化中如何应用?

**答**: 量化 = 给定 bit 数下, 最小化量化误差 (= 失真)。**Rate** = bit 数, **Distortion** = 量化误差。R(D) 函数给出理论下界。

---

### Q8: 互信息在 RL 中怎么用?

**答**: 作为探索奖励 (好奇心驱动): $r_t = I(s_t; a_t)$ 或 $I(s_t; s_{t+1})$ (信息增益)。让 agent 探索不确定状态。

---

### Q9: f-散度族有什么意义?

**答**: 一族推广, 包含 KL, JS, Hellinger, TV, $\chi^2$ 等。不同 f-divergence 有不同性质 (对称性, 范围), 适合不同场景。

---

### Q10: 信息瓶颈 (IB) 与 DL 泛化的关系?

**答**: IB 最小化 $I(X; Z) - \beta I(Z; Y)$, 找"压缩但保留标签信息"的表征。**理论解释 DL**: 深度网络层学会逐步压缩无关信息 (Shwartz-Ziv 2023)。

---

### Q11: JS 散度为什么常用于 GAN?

**答**: JS 对称, 范围 $[0, \log 2]$, 处处有限 (KL 在支撑不交时 = $\infty$)。但 Wasserstein 距离更优 (WGAN)。

---

### Q12: Softmax 输出的熵怎么解释?

**答**: 熵高 = 输出分布接近均匀 (不确定), 熵低 = one-hot (确定)。**应用**: label smoothing 增加熵, 改善泛化。

---

### Q13: 互信息为零意味着什么?

**答**: $I(X; Y) = 0$ 当且仅当 $X, Y$ 独立。**信息论角度**: $X$ 提供 0 信息 about $Y$。

---

### Q14: 解释 LLM 训练中的 KL 散度 (DPO 等)。

**答**: DPO 用 KL 约束, 防止新策略 $p_\theta$ 偏离参考策略 $p_{\text{ref}}$ 太多。$\mathcal{L}_{\text{DPO}} = -\log \sigma(\beta \log \frac{p_\theta(y_w|x)}{p_{\text{ref}}(y_w|x)} - \beta \log \frac{p_\theta(y_l|x)}{p_{\text{ref}}(y_l|x)})$。

---

### Q15: 香农熵 vs 量子熵?

**答**: 经典熵 $H = -\sum p \log p$。量子 von Neumann 熵 $S = -Tr(\rho \log \rho)$, $\rho$ 是密度矩阵。量子纠缠对应 $\rho_{AB}$ vs $\rho_A \otimes \rho_B$ 的 KL。

## 24. 信息论与最大熵原理

### 24.1 最大熵原理 (MaxEnt)

**定理 24.1 (MaxEnt)**: 给定约束 $\mathbb{E}_p[f_i(X)] = c_i$, 满足约束的所有分布中, 熵最大的:

$$p^*(x) = \frac{1}{Z} \exp\left(-\sum_i \lambda_i f_i(x)\right)$$

其中 $Z$ 是配分函数, $\lambda_i$ 由约束决定。

### 24.2 应用

- **Softmax 输出**: 概率单纯形上最大熵
- **Gibbs 分布**: 物理学平衡态
- **统计力学**: 熵 = 微观状态数对数
- **指数族**: 满足某些充分统计量约束的最大熵分布

### 24.3 与 DL 的联系

- Softmax = MaxEnt + 期望值约束
- Soft Actor-Critic (SAC) = MaxEnt RL
- 极大似然 = 经验分布的 KL 最小化

### 26.1 共同信息 (Common Information)

$$C(X; Y) = \max_{p(z|x), p(z|y)} I(X; Z) - I(Z; Y)$$

### 26.2 相关平衡 (Correlated Equilibrium)

$$\sum_{y} p(x, y) u_i(x, y) \ge \sum_y p(x, y) u_i(x, y') \quad \forall x, y, y'$$

信息论与博弈论的交叉。

## 27. 信息论与深度学习的"5 大公理"

### 27.1 公理 1: 信息有成本

存储 = 1 bit 信息。模型大小 = 信息容量。

### 27.2 公理 2: 信息有损失

### 27.3 公理 3: 信息可压缩

### 27.4 公理 4: 信息可分享

### 27.5 公理 5: 信息有上限

## 28. 信息论与因果推断

### 28.1 因果 vs 相关

- 相关: $I(X; Y) > 0$
- 因果: $X \to Y$ (干预后仍成立)

### 28.2 do-calculus

Pearl 因果框架区分:

- $P(Y | X)$: 观察
- $P(Y | do(X))$: 干预

信息论刻画: 干预改变分布结构。

### 28.3 反事实

$$I(Y_x; X_{x'}) \quad \text{(反事实信息)}$$

## 29. 高级话题: 信息论与注意力

### 29.1 注意力作为互信息最大化

$$\text{Attention}(Q, K, V) = \arg\max_{p} I(\text{idx}; V) \text{ s.t. } \sum p = 1$$

softmax 加权聚合 = 选择最相关的信息。

### 29.2 Multi-Head 互信息分解

每个 head 学不同的"信息子空间":

$$I(X; Y) \le \sum_{h=1}^H I(X_h; Y_h)$$

### 29.3 KV Cache 的信息论视角

KV Cache = 保留历史信息, 避免重复计算。

**信息下界**: KV Cache 至少保留 $I(\text{history}; \text{current})$ bit。

### 29.4 Sparse Attention 的率失真

Sparse attention = 选最相关 token, 损失 = 被丢 token 的信息损失。

理论: 选 top-k by score ≈ 信息保留最多的 k 个。

## 30. 信息论与 LLM 训练

### 30.1 语言建模 = 序列预测

$$p(\text{sequence}) = \prod_t p(x_t | x_{<t})$$

Cross-entropy = $-\frac{1}{T} \sum_t \log p(x_t | x_{<t})$。

### 30.2 困惑度 (Perplexity)

$$\text{PPL} = 2^{H(p)} = \exp(-\frac{1}{T}\sum \log p)$$

PPL 是"平均分支因子", 越低越好。

### 30.3 Scaling Laws

$$\text{CrossEntropy}(N, D) = a N^{-\alpha} + b D^{-\beta} + c$$

- $N$ = 模型参数
- $D$ = 训练数据
- $\alpha, \beta$ = scaling 指数

信息论推导: 数据提供 $-D \log 2$ bit 信息, 模型容量 $\approx \log N$ bit。

## 31. 信息论与决策理论

### 31.1 Shannon 信息与决策

决策 = 减少不确定性, 信息 = 决策的"价值"。

### 31.2 Value of Information (VOI)

$$\text{VOI} = \mathbb{E}[\text{utility}(a^* | X)] - \mathbb{E}[\text{utility}(a^*)]$$

即获取信息 $X$ 后的期望效用增量。

### 31.3 RL 中的探索

探索 = 获取 VOI 高的信息。UCB = 信息增益的上界。

## 32. 信息论与 Bayesian 推断

### 32.1 后验更新

$$p(\theta | D) \propto p(D | \theta) p(\theta)$$

信息论视角: 更新 = 把先验知识 $H(p(\theta))$ 减少到后验知识 $H(p(\theta | D))$。

### 32.2 Bayesian Information Criterion (BIC)

$$\text{BIC} = -2 \log L + k \log n$$

信息论惩罚, 防止过拟合。

### 32.3 Variational Bayes

用 $q(\theta)$ 近似后验, 最小化 $D_{KL}(q \| p(\theta | D))$。

## 34. 信息论与统计学习理论

### 34.1 PAC 学习

Probably Approximately Correct: 样本数 $n \ge O(\text{VC-dim} / \epsilon)$。

**信息论视角**: 学习 = 信息从训练样本到假设的传递。

### 34.2 Occam's Razor (信息论版)

最简模型 = 信息论上最可能正确的 (最短描述 = 最大压缩)。

### 34.3 Rademacher 复杂度

$$\text{Rad}(\mathcal{F}) = \mathbb{E}_\sigma \sup_{f \in \mathcal{F}} \frac{1}{n} \sum_i \sigma_i f(x_i)$$

衡量函数类的复杂度 (信息论视角: 与训练数据的"过拟合度")。

## 35. 信息论与计算复杂度

### 35.1 Kolmogorov 复杂度

$K(x)$ = 生成 $x$ 的最短程序长度。

**不可计算**: 没有算法能算 $K(x)$。

**应用**: MD5 / SHA 用近似 Kolmogorov 复杂度判断信息冗余。

### 35.2 Logical Depth

$L(x)$ = 生成 $x$ 的最短程序的运行时间。

**应用**: 加密货币工作量证明。

### 35.3 与 ML 的联系

- **最小描述长度 (MDL)**: $\min K(\text{model}) + K(\text{data} | \text{model})$
- **正则化**: 限制模型复杂度 ≈ 限制 $K(\text{model})$
- **架构搜索**: 选 $K(\text{arch})$ 最小 + 性能最好的
