# 第08章-03-条件数与病态问题

}{\sigma_{\min}(A)} = \frac{\lambda_{\max}}{\lambda_{\min}}\ \text{(对称正定时)}$$

即最大与最小奇异值之比。$\kappa$ 越大越**病态**。

- $\kappa \approx 1$: 良态, 输入扰动对输出影响小。
- $\kappa \gg 1$: 病态, 微小扰动被放大, 求解不稳定。

---

## 2. 几何意义: 各向异性

条件数刻画了空间被线性变换拉伸的**各向异性程度**。$\kappa=1$ 是圆(各方向一样), $\kappa$ 大是极扁的椭圆。

在优化里, loss 的 Hessian 条件数决定了等高线形状:
- 良态: 近似圆, 梯度直指最小值, 收敛快。
- 病态: 狭长峡谷, 梯度来回震荡, 收敛极慢。

---

## 3. 为什么病态让优化变慢

梯度下降在病态问题上的收敛率:

$$\text{误差衰减} \sim \left(\frac{\kappa - 1}{\kappa + 1}\right)^t$$

$\kappa$ 大时该比率接近 1 → 每步进展微小。这解释了为什么"未归一化的特征"训练慢: 不同尺度特征让 Hessian 病态。

---

## 4. 三种改善手段

### 4.1 归一化(降输入条件数)

特征标准化 / BatchNorm / LayerNorm 让各维度尺度一致, Hessian 更接近各向同性:

```python
x = (x - x.mean(0)) / (x.std(0) + 1e-8)   # 标准化 → 降条件数
```

### 4.2 自适应优化器(隐式预条件)

Adam/RMSProp 用二阶矩 $v$ 对每个参数做**自适应缩放**, 相当于对角预条件, 缓解各方向尺度不一:

$$\theta \leftarrow \theta - \frac{\eta}{\sqrt{v}+\varepsilon}\, m$$

这是"为什么 Adam 比 SGD 在病态问题上稳"的数学解释(见 第02章-线代 §5)。

### 4.3 预条件(Preconditioning)

求解 $Ax=b$ 时, 找 $M\approx A^{-1}$ 变成 $MAx=Mb$, 使 $\kappa(MA)\ll\kappa(A)$。二阶优化器(K-FAC/Shampoo)本质是近似 Hessian 预条件。

---

## 5. 病态的其他表现

- **线性回归共线特征**: $X^\top X$ 病态 → 权重方差大, 用 Ridge 正则(加 $\lambda I$)降条件数。
- **梯度爆炸/消失**: 深网雅可比连乘, 谱半径偏离 1。用残差 + 归一化(见 [deeplearning 3.2 ResNet](../../../../算法与AI/深度学习手撕/第03章-CNN卷积神经网络/第03章-02-ResNet深入.md))。
- **谱归一化**: 约束权重谱范数, 稳定 GAN 训练。

## 7. 条件数的严格数学定义

### 7.1 范数诱导条件数

**定义 7.1 (条件数)**: 对非奇异方阵 $A \in \mathbb{R}^{n \times n}$ 和向量范数 $\|\cdot\|$, 条件数定义为

$$\kappa(A) := \|A\| \cdot \|A^{-1}\|$$

这是 "放大倍数": $\|A^{-1} b - A^{-1} \hat b\| \le \|A^{-1}\| \cdot \|b - \hat b\|$, 联合 $\|A\|$ 得

$$\frac{\|A^{-1} b - A^{-1} \hat b\|}{\|A^{-1} b\|} \le \kappa(A) \frac{\|b - \hat b\|}{\|b\|}$$

即 **相对输出误差 ≤ κ(A) × 相对输入误差**。

### 7.2 谱条件数 (2-范数)

**定理 7.1 (谱条件数)**: 在 2-范数 (谱范数) 下, $\kappa_2(A) = \sigma_{\max}(A) / \sigma_{\min}(A)$, 即最大/最小奇异值之比。

**对称正定**: 当 $A \succ 0$, $\sigma_i = \lambda_i$, 故 $\kappa_2(A) = \lambda_{\max} / \lambda_{\min}$。

### 7.3 各种范数条件数对比

| 范数 | 条件数 | 计算难度 |
| :--- | :--- | :--- |
| 1-范数 (列和) | $\kappa_1(A) = \|A\|_1 \|A^{-1}\|_1$ | 中 |
| 2-范数 (谱) | $\kappa_2(A) = \sigma_{\max}/\sigma_{\min}$ | 难 (需 SVD) |
| $\infty$-范数 (行和) | $\kappa_\infty = \|A\|_\infty \|A^{-1}\|_\infty$ | 中 |
| Frobenius | 不常用 | — |

工程默认: $\kappa_2$ (谱条件数), 物理意义最强 (几何拉伸比)。

### 7.4 性质

**定理 7.2 (条件数基本性质)**: 对非奇异方阵 $A$:

1. $\kappa(A) \ge 1$ (因 $\|I\| = \|A A^{-1}\| \le \|A\| \|A^{-1}\| = \kappa(A)$)
2. $\kappa(cA) = \kappa(A)$ (尺度不变)
3. $\kappa(A^{-1}) = \kappa(A)$ (对称)
4. $\kappa(A^T A) = \kappa(A)^2$ (Gram 矩阵放大条件数!)
5. 对正交 $U$, $\kappa(UA) = \kappa(A)$ (旋转不变)

**关键洞察**: 第 4 条 → 线性回归中 $X^\top X$ 比 $X$ 条件数**平方**! 所以**岭回归** (Ridge) 加 $\lambda I$ 不仅降 $\kappa$, 还降 $\kappa^2$。

## 8. 几何意义: 各向异性深度分析

### 8.1 椭球变换

线性变换 $A$ 把单位球 $\{x: \|x\| = 1\}$ 映成椭球 $\{Ax: \|x\| = 1\}$。椭球的:

- 半长轴 = $\sigma_{\max}(A)$ (最大拉伸方向)
- 半短轴 = $\sigma_{\min}(A)$ (最小拉伸方向)
- 长宽比 = $\kappa(A)$ (各向异性度)

### 8.2 优化中的几何

损失函数的 Hessian $H \succ 0$ 决定 loss landscape 的局部形状:

- **球 (各向同性)**: $H = c I$, $\kappa = 1$, GD 直接指向最优。
- **扁椭球 (病态)**: $\kappa \gg 1$, GD 在小曲率方向快速前进, 大曲率方向震荡。

### 8.3 直观图

```text
    良态 (κ ≈ 1)              病态 (κ >> 1)
       ╱─────╲                  ╱──╲
      │       │                 │   │
      │   •   │                 │   ╲
      │       │                 │    ╲___
       ╲─────╱                  ╲___╲___
       等高线圆                  狭长峡谷
```

GD 路径:

- 良态: 直接指向圆心
- 病态: 在峡谷两边来回震荡, 缓慢前进

## 9. 条件数与线性方程组

### 9.1 扰动定理

**定理 9.1 (基本扰动定理)**: 解 $Ax = b$, $A$ 微扰 $\delta A$, $b$ 微扰 $\delta b$, 解变为 $\hat x = (A + \delta A)^{-1} (b + \delta b)$。当 $\kappa(A) \cdot \|\delta A\| / \|A\| < 1$ 时,

$$\frac{\|\hat x - x\|}{\|x\|} \le \frac{\kappa(A)}{1 - \kappa(A) \|\delta A\| / \|A\|} \left( \frac{\|\delta A\|}{\|A\|} + \frac{\|\delta b\|}{\|b\|} \right)$$

**简化**: $\frac{\|\hat x - x\|}{\|x\|} \lesssim 2 \kappa(A) \left( \frac{\|\delta A\|}{\|A\|} + \frac{\|\delta b\|}{\|b\|} \right)$

**含义**: $\kappa = 10^6$ 时, 输入 $10^{-6}$ 相对误差 → 输出 $\sim 1$ 相对误差!

### 9.2 残差 vs 误差

**定理 9.2 (残差-误差关系)**: $r = b - A \hat x$ (残差), $e = x - \hat x$ (误差), 有

$$\frac{\|e\|}{\|x\|} \le \kappa(A) \frac{\|r\|}{\|b\|}$$

**小残差 ≠ 小误差!** 例: $\kappa = 10^{10}$, $\|r\|/\|b\| = 10^{-10}$ 但 $\|e\|/\|x\| \le 1$ (误差可能 100%)。

**工程意义**: 解方程时残差小不代表解准。要用 $\hat \kappa(A)$ 估计实际条件数。

### 9.3 后向误差

**定义 9.1 (后向误差)**: 给定近似解 $\hat x$, 找最小的 $\delta A, \delta b$ 使 $\hat x$ 精确解 $(A + \delta A) x = b + \delta b$:

$$\eta(\hat x) = \frac{\|\delta A\| + \|\delta b\|/\|x\|}{\|A\|}$$

**小后向误差** ($\eta \ll 1$) 意味着 $\hat x$ 是某 "邻近问题" 的精确解, 数值上**稳定**。

### 9.4 例: Hilbert 矩阵

Hilbert 矩阵 $H_{ij} = 1/(i+j-1)$ 是经典病态例子:

$$H_5 = \begin{pmatrix} 1 & 1/2 & 1/3 & 1/4 & 1/5 \\ 1/2 & 1/3 & 1/4 & 1/5 & 1/6 \\ \vdots \end{pmatrix}$$

$\kappa_2(H_5) \approx 4.8 \times 10^5$, $\kappa_2(H_{10}) \approx 1.6 \times 10^{13}$。

```python
import numpy as np
from scipy.linalg import hilbert
H = hilbert(10)
cond = np.linalg.cond(H)
print(f"H_10 condition number: {cond:.3e}")  # ~1.6e13
```

## 10. 病态问题为何让 GD 慢

### 10.1 GD 收敛率分析

**定理 10.1 (强凸 + 光滑 GD 收敛)**: $f$ 是 $\mu$-强凸, $L$-光滑, 则 GD 收敛率:

$$\|x_{t+1} - x^*\|^2 \le \left(1 - \frac{\mu}{L}\right)^t \|x_0 - x^*\|^2$$

**收敛因子**: $1 - \mu/L = (κ - 1)/(κ + 1)$, 其中 $\kappa = L/\mu$ 是 Hessian 条件数。

**例**: $\kappa = 100$, 收敛因子 = $99/101 \approx 0.98$。每步误差减少 2%, 100 步减少 $0.98^{100} \approx 0.13$。需要 ~$\kappa$ 步才到 $1/e$。

$\kappa = 10^6$: 收敛因子 $\approx 1$, 实际不收敛。

### 10.2 GD 路径震荡

病态时 GD 沿小曲率方向快速走, 大曲率方向过冲 → 之字形 (zigzag)。

**理论**: 误差在 "坏方向" (大曲率) 衰减 $\sim (1 - \mu/L)^t$, "好方向" (小曲率) 衰减 $\sim t$ 级别 (代数)。

### 10.3 病态原因: 输入尺度

若输入 $x$ 各维尺度差 $10^3$ (如价格 vs 评分), loss landscape 病态。

```python
# 例: 病态特征导致病态 Hessian
x1 = np.random.randn(1000) * 0.001  # 小尺度
x2 = np.random.randn(1000) * 1000   # 大尺度
y = 2 * x1 + 3 * x2 + np.random.randn(1000) * 0.01

# 训练线性回归
X = np.stack([x1, x2], axis=1)
# Hessian ≈ X^T X, 特征值比 = (1000/0.001)^2 = 10^12 → 病态!
print(np.linalg.cond(X.T @ X))  # ~1e12
```

## 11. 改善手段: 三大策略

### 11.1 策略 A: 输入归一化

**标准化**: $x \leftarrow (x - \mu) / \sigma$, 各维度均值为 0, 方差为 1。

```python
# sklearn
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# DL 中
x = (x - x.mean()) / (x.std() + 1e-8)
```

**效果**: Hessian 各方向特征值接近, $\kappa$ 接近 1。

**DL 实现**: BatchNorm, LayerNorm, GroupNorm 都是这思路。

### 11.2 策略 B: 自适应优化器 (隐式预条件)

**Adam / RMSProp**: 对每个参数自适应缩放梯度, 等价对角预条件:

$$\theta \leftarrow \theta - \eta \frac{m_t}{\sqrt{v_t} + \varepsilon}$$

$m_t$ 是一阶矩 (动量), $v_t$ 是二阶矩。

**几何意义**: 把椭球 loss landscape "拉圆"。

```python
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
# vs
optimizer = torch.optim.SGD(model.parameters(), lr=1e-3)
# Adam 在病态问题上比 SGD 显著快
```

### 11.3 策略 C: 显式预条件

**预条件子**: 找 $M \approx A^{-1}$, 解决 $M A x = M b$ 代替 $Ax = b$, 让 $\kappa(MA) \ll \kappa(A)$。

**二阶优化器本质**: K-FAC 算 $M \approx H^{-1}$ (Hessian 逆近似)。

```python
# 简化对角预条件
M_inv_diag = 1.0 / (hessian_diag + eps)
x_new = x - lr * M_inv_diag * grad
```

**BFGS**: 近似 Hessian 逆, 更新 $M \approx H^{-1}$。

### 11.4 策略 D: 学习率调度

Warmup + cosine decay 也能缓解病态。

```python
scheduler = torch.optim.lr_scheduler.OneCycleLR(
    optimizer, max_lr=0.01, total_steps=10000,
    pct_start=0.1, anneal_strategy='cos'
)
```

### 11.5 策略对比

| 策略 | 适用 | 计算代价 |
| :--- | :--- | :--- |
| 归一化 | 数据预处理 | 低 (一次性) |
| 自适应优化器 (Adam) | 大部分场景 | 中 (二阶矩) |
| L-BFGS | 小数据, 凸问题 | 高 (内存 + 反传) |
| K-FAC | 中等模型 | 高 (矩阵估计) |
| Shampoo | 大 Transformer | 高 (SVD 近似) |
| 学习率调度 | 任何场景 | 低 |

## 12. 谱分解与条件数

### 12.1 对称矩阵

**定理 12.1 (谱定理)**: 对称 $A = A^\top$ 可对角化: $A = Q \Lambda Q^\top$, $Q$ 正交, $\Lambda = \text{diag}(\lambda_1, \ldots, \lambda_n)$。

条件数: $\kappa(A) = |\lambda_{\max}| / |\lambda_{\min}|$。

### 12.2 一般矩阵: SVD

**定理 12.2 (SVD)**: $A = U \Sigma V^\top$, $\Sigma = \text{diag}(\sigma_1, \ldots, \sigma_n)$, $\sigma_i$ 奇异值。

条件数: $\kappa(A) = \sigma_{\max} / \sigma_{\min}$。

### 12.3 应用: PCA 与低秩近似

PCA 找最大 $\sigma_i$ 对应的右奇异向量 $v_i$。**低秩近似**: $A \approx \sum_{i=1}^k \sigma_i u_i v_i^\top$, 误差 $\|A - A_k\| = \sigma_{k+1}$。

```python
import numpy as np
U, S, Vt = np.linalg.svd(A)
A_low_rank = U[:, :k] @ np.diag(S[:k]) @ Vt[:k, :]
```

### 12.4 伪逆

**Moore-Penrose 伪逆**: $A^+ = V \Sigma^+ U^\top$, $\Sigma^+ = \text{diag}(1/\sigma_i)$ (奇异值倒数)。

$\kappa(A) = \sigma_{\max} / \sigma_{\min}$ 越大, $A^+$ 越不稳定。

```python
A_pinv = np.linalg.pinv(A)
```

### 12.5 截断 SVD

数值稳定的伪逆: 截断小奇异值

$$A^+_\tau = V \text{diag}(1/\sigma_i \cdot [\sigma_i > \tau]) U^\top$$

```python
def truncated_pinv(A, tau=1e-10):
    U, S, Vt = np.linalg.svd(A, full_matrices=False)
    mask = S > tau
    S_inv = np.where(mask, 1.0 / S, 0.0)
    return (Vt.T * S_inv) @ U.T
```

## 13. 矩阵求逆稳定性

### 13.1 求逆 vs 求解

**重要原则**: **永远不解 $Ax = b$ 通过 $x = A^{-1} b$**。

理由:

1. $A^{-1}$ 计算成本 $O(n^3)$, 解线性方程组 $O(n^3)$ (LU 分解), 但 LU 后续解多组 $b$ 只需 $O(n^2)$。
2. 求逆稳定性差 (尤其病态 $A$)。

```python
# 错
x = np.linalg.inv(A) @ b

# 对
x = np.linalg.solve(A, b)
```

### 13.2 病态下 LU vs QR vs SVD

| 方法 | 适用 | 稳定性 |
| :--- | :--- | :--- |
| LU (无 pivot) | 一般方阵 | 不稳 (病态时差) |
| LU (部分 pivot) | 一般 | 中 (实践中够用) |
| QR (Householder) | 最小二乘 | 良 |
| SVD | 病态 / 伪逆 | 优 |

**SVD 解最小二乘**: $\min \|Ax - b\|_2$, 解 $x = A^+ b$, 稳定但慢。

### 13.3 Cholesky

正定矩阵 $A = L L^\top$, $L$ 下三角。$O(n^3/3)$, 比 LU 快 2x。

```python
import numpy as np
L = np.linalg.cholesky(A)  # A = L L^T
x = np.linalg.solve(L.T, np.linalg.solve(L, b))  # A x = b
```

### 13.4 病态下双精度

FP32 在 $\kappa > 10^6$ 时会丢精度, 用 FP64 算线性代数。

```python
x = np.linalg.solve(A.astype(np.float64), b.astype(np.float64))
```

## 14. 病态的常见场景

### 14.1 多重共线性

线性回归 $X^\top X$ 在特征共线时病态 → 解不稳定 → Ridge 正则。

$$\hat w = (X^\top X + \lambda I)^{-1} X^\top y$$

$\lambda > 0$ 抬高最小特征值: $\kappa(X^\top X + \lambda I) = (\lambda_{\max} + \lambda) / (\lambda_{\min} + \lambda)$, $\lambda_{\min} \to 0$ 时也能稳住。

### 14.2 病态优化 (沟壑)

深度学习 loss landscape 常有"沟壑": 一个方向曲率大 (陡), 另一个方向曲率小 (平)。GD 在沟壑中震荡。

**Adam / RMSProp 的核心动机**: 自适应缩放让不同曲率方向学习率自动平衡。

### 14.3 数值微分的病态

**中心差分**: $f'(x) \approx (f(x+h) - f(x-h)) / (2h)$

误差 $\approx h^2 f'''(x) / 6$ (截断) + $\varepsilon f(x) / h$ (浮点), 最优 $h = \sqrt{\varepsilon}$。

```python
def numerical_grad(f, x, eps=None):
    if eps is None:
        eps = np.finfo(float).eps ** 0.5  # ~1.5e-8
    return (f(x + eps) - f(x - eps)) / (2 * eps)
```

### 14.4 矩阵指数 / 对数

矩阵指数 $e^A$ 用 Padé 逼近, 但若 $A$ 病态, 数值不稳定。`scipy.linalg.expm` 用平衡缩放改善。

## 15. 完整代码实现

### 15.1 估计条件数

```python
import numpy as np

def estimate_condition(A, method='svd'):
    """估计矩阵 A 的条件数."""
    if method == 'svd':
        # 精确 (但慢, O(n^3))
        return np.linalg.cond(A)
    elif method == 'power':
        # 快速估计 (power iteration)
        s_max = power_iteration_singular(A)
        s_min = power_iteration_singular(np.linalg.inv(A))
        return s_max * s_min
    elif method == 'estimator':
        # scipy 内置快速估计 (LAPACK)
        from scipy.linalg import get_lapack_funcs
        # 注: numpy.linalg.cond 已经够用
        return np.linalg.cond(A)
```

### 15.2 Power Iteration 估计最大奇异值

```python
def power_iteration_singular(A, iters=100, tol=1e-6):
    """求 A 的最大奇异值."""
    n = A.shape[0]
    v = np.random.randn(n)
    v /= np.linalg.norm(v)
    for _ in range(iters):
        Av = A @ v
        sigma = np.linalg.norm(Av)
        v_new = Av / sigma
        if np.linalg.norm(v_new - v) < tol:
            break
        v = v_new
    return sigma
```

### 15.3 预条件共轭梯度 (PCG)

```python
def preconditioned_cg(A, b, M_inv, x0=None, tol=1e-6, max_iter=100):
    """预条件共轭梯度, 解 Ax = b."""
    n = len(b)
    x = np.zeros(n) if x0 is None else x0
    r = b - A @ x
    z = M_inv @ r
    p = z.copy()
    rs_old = r @ z
    for _ in range(max_iter):
        Ap = A @ p
        alpha = rs_old / (p @ Ap)
        x = x + alpha * p
        r = r - alpha * Ap
        if np.linalg.norm(r) < tol:
            break
        z = M_inv @ r
        rs_new = r @ z
        p = z + (rs_new / rs_old) * p
        rs_old = rs_new
    return x
```

### 15.4 病态矩阵求解

```python
def stable_solve(A, b, regularize=1e-10):
    """求解 Ax = b, 自动选择最稳定方法."""
    # 1. 检查条件数
    cond = np.linalg.cond(A)
    if cond < 1e6:
        # 良态: 直接 LU
        return np.linalg.solve(A, b)
    elif cond < 1e12:
        # 中等病态: 加 Tikhonov 正则
        n = A.shape[0]
        A_reg = A + regularize * np.eye(n)
        return np.linalg.solve(A_reg, b)
    else:
        # 严重病态: SVD + 截断
        U, S, Vt = np.linalg.svd(A)
        # 截断小奇异值
        S_inv = np.where(S > 1e-8, 1.0 / S, 0.0)
        A_pinv = (Vt.T * S_inv) @ U.T
        return A_pinv @ b
```

## 16. 数学例题

### 例题 16.1: 条件数计算

**题目**: $A = \text{diag}(1, 10^{-6})$, 求 $\kappa_2(A)$。

**解答**: $\sigma_{\max} = 1$, $\sigma_{\min} = 10^{-6}$, $\kappa = 10^6$。

**直觉**: $A$ 把 $x = (0, 1)$ 映成 $(0, 10^{-6})$, 把 $x = (1, 0)$ 映成 $(1, 0)$。拉伸比 $10^6$。

---

### 例题 16.2: 共线性特征

**题目**: $X \in \mathbb{R}^{n \times 2}$, 两列线性相关 ($x_2 = 2 x_1 + 0.001 \epsilon$)。$X^\top X$ 的条件数?

**解答**: $X^\top X$ 近似 rank-1 矩阵, $\lambda_{\min} \to 0$, $\kappa \to \infty$。

**工程**: Ridge 加 $\lambda I$, $\kappa$ 从 $\infty$ 降到 $(\lambda_{\max} + \lambda) / \lambda$, 选择 $\lambda$ 让 $\kappa < 10^3$。

---

### 例题 16.3: GD 病态步数估计

**题目**: $f(x) = \frac{1}{2} x^\top A x$, $A$ 对称正定, $\kappa = 100$。GD 需要多少步让误差 < $10^{-3}$?

**解答**: 收敛率 $(1 - \mu/L)^t = (1 - 1/\kappa)^t = (1 - 0.01)^t = 0.99^t$。

$0.99^t < 10^{-3} \Rightarrow t > \log(10^{-3}) / \log(0.99) = -3 / (-0.00435) \approx 690$ 步。

**对比**: $\kappa = 1$ (良态) 只需 $\sim 3$ 步。

---

### 例题 16.4: Hilbert 矩阵

**题目**: $H_{10}$ 的条件数?

**解答**: $\kappa_2(H_{10}) \approx 1.6 \times 10^{13}$。

**意义**: 解 $H_{10} x = b$ 在 FP64 下仍可能不准确, 需要 SVD + 截断。

---

### 例题 16.5: Adam 等价对角预条件

**题目**: 证明 Adam 是隐式对角预条件。

**解答**:

$$g^{\text{Adam}} = \frac{m_t}{\sqrt{v_t} + \varepsilon} \approx \frac{\nabla f}{\sqrt{\text{diag}(H) + \varepsilon}}$$

近似 Hessian 对角线, $\sqrt{v_t} \approx \sqrt{H_{ii}}$, 等价对角预条件子 $M \approx H^{-1/2}$。

(严格证明需要 $v_t \to E[\nabla^2 f]$ 的假设, 在一阶平稳下近似成立。)

---

### 例题 16.6: Ridge vs OLS 稳定性

**题目**: $X^\top X$ 病态 ($\kappa = 10^{12}$), 加 Ridge $\lambda = 10^{-3}$。新条件数?

**解答**: $\kappa_{\text{new}} = (\lambda_{\max} + \lambda) / (\lambda_{\min} + \lambda)$

设 $\lambda_{\max} = 10^{12}$, $\lambda_{\min} = 1$, $\lambda = 10^{-3}$。

$\kappa_{\text{new}} = (10^{12} + 10^{-3}) / (1 + 10^{-3}) \approx 10^{12}$, **几乎没改善!**

**对**: $\lambda$ 应与 $\lambda_{\min}$ 同阶。取 $\lambda = 1$, $\kappa_{\text{new}} = 10^{12} / 2 \approx 5 \times 10^{11}$, 仍差。

**更好**: 用 $\lambda$ 让 $\kappa_{\text{new}}$ 合理 (例如 $\lambda = 100$, $\kappa_{\text{new}} = 10^{12} / 101 \approx 10^{10}$, 仍差)。

**本质**: Ridge 改善条件数, 但需 $\lambda \gg \lambda_{\min}$。**最佳**: $\lambda = \sqrt{\lambda_{\max} \cdot \lambda_{\min}} \approx \lambda_{\max}/\sqrt{\kappa}$, 即 "Ledoit-Wolf 收缩"。

---

### 例题 16.7: Preconditioning 收敛加速

**题目**: GD 在 $\kappa = 1000$ 下需 1000 步到 $10^{-3}$ 误差。用预条件子 $M = H^{-1/2}$ 后多少步?

**解答**: 预条件后问题 $\kappa(MH) = \kappa(H^{-1/2} H H^{-1/2}) = \kappa(I) = 1$。**一步收敛!**

**工程意义**: 完美预条件 (Newton 法) 把 $\kappa$ 压到 1, 二次收敛。

---

### 例题 16.8: 自适应优化器的"形状"理解

**题目**: 为什么 Adam 在 loss landscape 各向异性时比 SGD 好?

**解答**: 设 loss landscape 等高线是椭圆 (Hessian 对角), 主轴 $a$ (小曲率), 短轴 $b$ (大曲率)。SGD 用相同 $\eta$, 在 $a$ 方向步小 (慢), 在 $b$ 方向步大 (震荡)。

Adam 的二阶矩 $v$ 估计各方向曲率, 在 $a$ 方向 $\sqrt{v_a}$ 小 → 步长大; 在 $b$ 方向 $\sqrt{v_b}$ 大 → 步长小。**自适应**让各方向收敛速度匹配。

## 17. 谱归一化 (Spectral Normalization)

### 17.1 概念

**谱归一化**: 强制 $\|W\|_2 = \sigma_{\max}(W) = 1$。

$$\bar W = W / \sigma_{\max}(W)$$

### 17.2 在 GAN 中的作用

GAN 的判别器 $D$ 是 Lipschitz 连续的, 若 $\|W\| > 1$, D 梯度爆炸。**谱归一化**约束 $\|W\| \le 1$, 让 D 1-Lipschitz。

```python
import torch.nn as nn
conv = nn.utils.spectral_norm(nn.Conv2d(64, 64, 3))
```

内部实现: power iteration 估计 $\sigma_{\max}$。

### 17.3 数学保证

对任意输入 $x$, $\|W x\| \le \|W\|_2 \|x\| = \|x\|$, 即 Lipschitz 常数 ≤ 1。

### 17.4 Power Iteration 实现

```python
def spectral_norm_via_power_iter(W, n_iters=10, u=None):
    """估计 W 的谱范数 = σ_max(W)."""
    if u is None:
        u = torch.randn(W.shape[0], device=W.device)
        u = u / u.norm()
    for _ in range(n_iters):
        v = W.T @ u
        v = v / v.norm()
        u = W @ v
        u = u / u.norm()
    sigma = u @ W @ v
    return sigma, u
```

## 18. 不同条件数与训练

### 18.1 Hessian 条件数

**定理 18.1 (Hessian 条件数与 GD 收敛)**: $\kappa(H) = L/\mu$, 决定 GD 收敛率。

**训练中的 $\kappa(H)$**:

- 训练初期: $\kappa \to \infty$ (随机初始化附近)
- 训练中期: $\kappa$ 适中
- 训练末期: $\kappa$ 可能再涨 (sharp minima)

### 18.2 Sharp vs Flat Minima

- **Sharp minimum**: Hessian 大特征值大, $\kappa$ 大, 泛化差。
- **Flat minimum**: $\kappa$ 小, 泛化好。

**SAM (Sharpness-Aware Minimization)**: 显式找 flat minima。

```python
# SAM 简化
def sam_step(model, loss_fn, x, y, rho=0.05):
    # 1. 第一次反传找对抗方向
    loss = loss_fn(model(x), y)
    grads = torch.autograd.grad(loss, model.parameters())
    g_norm = torch.norm(torch.stack([g.norm() for g in grads]))
    # 2. 扰动权重
    e_ws = [rho * g / g_norm for g in grads]
    for p, e in zip(model.parameters(), e_ws):
        p.data.add_(e)
    # 3. 第二次反传 + 还原
    loss = loss_fn(model(x), y)
    loss.backward()
    for p, e in zip(model.parameters(), e_ws):
        p.data.sub_(e)
    # 4. optimizer.step
    optimizer.step()
```

### 18.3 SAM 的数学

SAM 最小化 $\max_{\|\epsilon\| \le \rho} L(w + \epsilon)$, 即在 $\rho$-邻域内最坏的 loss。

等价最小化 $L(w) + \rho \|\nabla L\| + O(\rho^2)$, 鼓励 $\|\nabla L\|$ 小 → 平坦极小。

## 20. 面试高频 (15 题)

### Q1: 条件数的定义? 几何意义?

**答**: $\kappa(A) = \sigma_{\max}/\sigma_{\min}$。几何意义: 线性变换把单位球拉成椭球, 长短轴之比 = 条件数。值越大越 "各向异性", 椭球越扁。

---

### Q2: 为什么病态问题 GD 收敛慢?

**答**: Hessian 条件数 $\kappa = L/\mu$ 决定收敛率 $(1 - 1/\kappa)^t$。$\kappa = 10^6$ 时收敛因子 $\approx 1 - 10^{-6}$, 每步进展 $10^{-6}$, 实际不收敛。

---

### Q3: 三种改善病态的方法?

**答**: (1) **输入归一化**: 降 $X^\top X$ 条件数。(2) **自适应优化器**: 隐式对角预条件。(3) **显式预条件**: 找 $M \approx A^{-1}$。

---

### Q4: Ridge 正则如何改善条件数?

**答**: $X^\top X + \lambda I$ 的最小特征值从 $\lambda_{\min}$ 变成 $\lambda_{\min} + \lambda$, 抬高下限 → 条件数下降。但需 $\lambda \gg \lambda_{\min}$ 才显著改善。

---

### Q5: $\kappa(A^T A) = \kappa(A)^2$ 为什么重要?

**答**: 线性回归 $X^\top X$ 比 $X$ 条件数**平方**。这意味着即使 $X$ 条件数 100, $X^\top X$ 已 10000。这是为什么线性回归必须 Ridge。

---

### Q6: 残差小 ≠ 解准, 为什么?

**答**: 残差-误差关系: $\|e\|/\|x\| \le \kappa(A) \|r\|/\|b\|$。$\kappa = 10^{10}$ 时, $\|r\| = 10^{-10} \|b\|$ 看似小, 但 $\|e\| \le \|x\|$, 误差可能 100%。

---

### Q7: 谱归一化是什么? 为什么 GAN 用?

**答**: $\|W\|_2 = 1$ 的归一化。让 GAN 判别器 1-Lipschitz, 训练稳定。PyTorch `nn.utils.spectral_norm` 用 power iteration 实现。

---

### Q8: 预条件子 M 怎么选?

**答**: 三种思路: (1) **对角预条件**: $M = \text{diag}(H)$, 简单但只改善各向同性缩放。(2) **不完全 Cholesky**: $M = LL^\top \approx A$, 中等代价。(3) **Fisher / Hessian 近似**: K-FAC, Shampoo。

---

### Q9: 牛顿法收敛率? 为什么 DL 不用?

**答**: 二次收敛 (误差 $e_{t+1} \sim e_t^2$)。但每步需 Hessian 求逆 $O(d^3)$, DL 中 $d = 10^9$ 不可行。L-BFGS 用低秩近似降低代价。

---

### Q10: 什么时候用 FP64 解线性方程组?

**答**: 病态 ($\kappa > 10^6$) 时, FP32 精度不够 ($\varepsilon \approx 10^{-7}$, $\kappa \varepsilon \approx 1$, 误差 100%)。用 FP64 ($\varepsilon \approx 10^{-16}$) 解。科学计算默认 FP64。

---

### Q11: 为什么 LASSO 比 Ridge 慢?

**答**: LASSO 目标含 $\|w\|_1$ (非光滑), 无闭式解。Ridge 含 $\|w\|_2^2$ (光滑), 闭式解 $(X^\top X + \lambda I)^{-1} X^\top y$。LASSO 需次梯度 / 近端方法, 慢但稀疏。

---

### Q12: Sharp minimum 泛化差, 为什么?

**答**: 训练点附近 loss 剧烈变化 → 测试点在 "陡坡" 上, loss 大。**直观**: 训练 loss = 0 但 loss landscape 陡 → 测试 loss 大。

**SAM** 通过最小化邻域最大 loss, 找 flat minimum。

---

### Q13: 解释 Hilbert 矩阵为什么病态?

**答**: $H_{ij} = 1/(i+j-1)$ 是 "嵌套" 结构, 第 $i$ 行几乎是第 $i+1$ 行的倍数缩放。近似 rank-deficient → $\sigma_{\min} \to 0$, $\kappa$ 指数增长。

**应用**: 测试数值算法稳定性的标准例子。

---

### Q14: SVD 与特征分解的条件数关系?

**答**: 特征分解只对**对称矩阵**适用, SVD 对**任意矩阵**适用。$\kappa_2(A) = \sigma_{\max}/\sigma_{\min}$ (SVD), 对称时等于 $\lambda_{\max}/\lambda_{\min}$。

---

### Q15: Adam 为什么是"对角预条件"?

**答**: 假设 $v_t \to \text{diag}(H)$ (经验 Fisher 近似 Hessian 对角), 则

$$\frac{m_t}{\sqrt{v_t}} \approx \frac{\nabla f}{\sqrt{H_{ii}}} = H^{-1/2}_{\text{diag}} \nabla f$$

等价对角预条件子 $M = H^{-1/2}_{\text{diag}}$, 让各方向步长按曲率反比缩放。

## 22. 预条件子 (Preconditioner) 设计专题

### 22.1 Jacobi 预条件 (对角)

**定义**: $M = \text{diag}(A)$, 即 $M^{-1} = \text{diag}(1/A_{ii})$。

**优点**: 极简单, $O(n)$ 计算。**缺点**: 只解决各向同性缩放, 不能消除旋转各向异性。

**应用**: 对角占优矩阵 (如 PDE 离散), 效果惊人。

### 22.2 SSOR (对称连续过松弛)

**定义**: $A = D + L + L^\top$, SSOR 预条件子 $M = (D + L) D^{-1} (D + L)^\top / (2 - \omega)$, $\omega \in (0, 2)$。

**优点**: 比 Jacobi 强, 仍易计算。**缺点**: 需选 $\omega$ (调参)。

### 22.3 不完全 Cholesky (IC)

**定义**: $A \approx L L^\top$, 但 $L$ 稀疏 (drop tolerance 控制)。

**优点**: 强预条件, 接近 Cholesky 速度。**缺点**: 需选 drop tolerance, 实施复杂。

```python
import scipy.sparse as sp
from scipy.sparse.linalg import spsolve, splu
# IC 分解
from sksparse.cholmod import cholesky  # 需 pip install scikit-sparse
factor = cholesky(A_sparse, ordering_method='natural')
```

### 22.4 Algebraic Multigrid (AMG)

**思想**: 多尺度求解。在粗网格解低频误差, 细网格解高频。

**应用**: 大型稀疏线性系统 (PDE 离散)。DL 中少用, 但物理仿真重要。

### 22.5 预条件子的"质量"

**定义 22.1 (预条件效果)**: 预条件子 $M$ 的"质量"看 $\kappa(M A)$:

- $M = A^{-1}$: $\kappa(MA) = 1$ (完美)
- $M = I$: $\kappa(MA) = \kappa(A)$ (无作用)
- $M \approx A^{-1}$: $\kappa(MA) \approx 1$ (好)

**预条件开销**: $M$ 越复杂, 算 $M v$ 越贵。工程权衡。

## 23. K-FAC 详解

### 23.1 思想

把 Hessian 近似为 Fisher 信息矩阵 $F = \mathbb{E}[\nabla \log p(x|y) \nabla \log p(x|y)^\top]$, 再 block-diagonal 近似:

$$F \approx A \otimes G$$

$A$ = activation 外积, $G$ = gradient 外积, $\otimes$ = Kronecker 积。

### 23.2 数学

**定理 23.1 (K-FAC 近似)**: 对两层网络 $f = W_2 \sigma(W_1 x)$, Fisher block 矩阵 $F$ 近似为 $A \otimes G$, 其中 $A = \mathbb{E}[a a^\top]$, $G = \mathbb{E}[g g^\top]$, $a, g$ 是层 1 的激活和输出梯度。

**逆**: $F^{-1} = A^{-1} \otimes G^{-1}$, 即 $W \leftarrow W - \eta A^{-1} G W$。

### 23.3 PyTorch 实现 (简化)

```python
class KFACOptimizer(torch.optim.Optimizer):
    def __init__(self, params, lr=1e-2, damping=1e-3, T_inv=10):
        defaults = dict(lr=lr, damping=damping, T_inv=T_inv)
        super().__init__(params, defaults)
        # 累积 A, G 估计
        self.A = {}
        self.G = {}

    def step(self):
        for group in self.param_groups:
            for p in group['params']:
                if p.grad is None:
                    continue
                key = id(p)
                # 估计 A (activation 外积) 和 G (gradient 外积)
                if key not in self.A:
                    self.A[key] = torch.zeros(p.shape[1], p.shape[1])
                    self.G[key] = torch.zeros(p.shape[0], p.shape[0])
                a = p  # 简化: 用 p 自身
                g = p.grad
                self.A[key] = 0.95 * self.A[key] + 0.05 * a @ a.T / a.shape[0]
                self.G[key] = 0.95 * self.G[key] + 0.05 * g.T @ g / g.shape[0]
                # 逆
                A_inv = torch.linalg.inv(self.A[key] + group['damping'] * torch.eye_like(self.A[key]))
                G_inv = torch.linalg.inv(self.G[key] + group['damping'] * torch.eye_like(self.G[key]))
                # 更新
                update = G_inv @ p.grad @ A_inv
                p.data.add_(-group['lr'] * update)
```

### 23.4 K-FAC 优缺点

**优点**: 理论收敛率与 Newton 接近, 但内存 $O(d^2)$ (Hessian 逆的 block 形式)。

**缺点**: 实现复杂, 调参 (damping, T_inv), 大模型成本高。

## 24. Shampoo 算法

### 24.1 思想

对每个参数张量 $W \in \mathbb{R}^{m \times n}$, 维护左右累积:

$$L_t = \beta L_{t-1} + (1-\beta) W_t W_t^\top \in \mathbb{R}^{m \times m}$$

$$R_t = \beta R_{t-1} + (1-\beta) W_t^\top W_t \in \mathbb{R}^{n \times n}$$

### 24.2 更新规则

$$W \leftarrow W - \eta \cdot L_t^{-1/4} G_t R_t^{-1/4}$$

其中 $G_t$ 是梯度累积, $L_t^{-1/4}$ 用 Newton-Schulz 迭代 (数值稳定) 算。

### 24.3 性质

- 比 Adam 内存大 ($O(m^2 + n^2)$) 但收敛更快。
- 适合 Transformer 训练 (Google 内部使用)。
- 分布式实现: Shampoo 在 JAX/TPU 上高效。

### 24.4 Newton-Schulz 迭代求 $L^{-1/4}$

```python
def newton_schulz_inv_root(G, n_iters=5):
    """数值稳定地求 G^{-1/4}."""
    a, b, c = (3.4445, -4.7750, 2.0315)
    X = G / (torch.norm(G) + 1e-8)
    if G.size(0) > G.size(1):
        X = X.T
    for _ in range(n_iters):
        A = X @ X.T
        B = b * A + c * A @ A
        X = a * X + B @ X
    if G.size(0) > G.size(1):
        X = X.T
    return X
```

## 25. 共轭梯度 (CG) 与 Hessian-Free 优化

### 25.1 CG 基础

**算法 25.1 (共轭梯度法)**

**Input**: $A$ 对称正定, $b$

```text
x_0 = 0
r_0 = b
p_0 = r_0
for k = 0, 1, ...:
    α_k = (r_k^T r_k) / (p_k^T A p_k)
    x_{k+1} = x_k + α_k p_k
    r_{k+1} = r_k - α_k A p_k
    if ||r_{k+1}|| < tol: break
    β_k = (r_{k+1}^T r_{k+1}) / (r_k^T r_k)
    p_{k+1} = r_{k+1} + β_k p_k
```

**收敛**: 最多 $n$ 步收敛 (理论), 实践中早停。

### 25.2 Hessian-Free Newton

**算法 25.2 (Hessian-Free Newton)**

```text
for outer iteration:
    # 用 CG 算 Newton 方向: H^{-1} g (不显式构造 H)
    p = CG(lambda v: HVP(loss, v), g)
    # Line search
    α = line_search(f, x, p)
    x = x + α p
```

**优点**: 不需构造 Hessian (内存 $O(d)$), 适合大模型。

**缺点**: 每次 CG 内迭代需 HVP, 计算量大。

### 25.3 PyTorch HVP

```python
def hvp(loss, params, v):
    """Hessian-vector product."""
    grads = torch.autograd.grad(loss, params, create_graph=True)
    gv = sum((g * vi).sum() for g, vi in zip(grads, v))
    hv = torch.autograd.grad(gv, params)
    return hv

def conjugate_gradient(A_func, b, x0=None, tol=1e-6, max_iter=100):
    """CG for A x = b where A is linear operator."""
    x = torch.zeros_like(b) if x0 is None else x0
    r = b - A_func(x)
    p = r.clone()
    rs_old = r @ r
    for _ in range(max_iter):
        Ap = A_func(p)
        alpha = rs_old / (p @ Ap)
        x = x + alpha * p
        r = r - alpha * Ap
        rs_new = r @ r
        if rs_new.sqrt() < tol:
            break
        p = r + (rs_new / rs_old) * p
        rs_old = rs_new
    return x
```

## 30. 数值稳定的优化器

### 30.1 SGD with Momentum

```python
class SGDMomentum:
    def __init__(self, params, lr=1e-2, momentum=0.9):
        self.params = list(params)
        self.lr = lr
        self.momentum = momentum
        self.velocities = [torch.zeros_like(p) for p in self.params]

    def step(self):
        for p, v in zip(self.params, self.velocities):
            if p.grad is None:
                continue
            v.mul_(self.momentum).add_(p.grad)
            p.data.add_(-self.lr * v)
```

### 30.2 Adam (Adaptive Moment Estimation)

```python
class Adam:
    def __init__(self, params, lr=1e-3, betas=(0.9, 0.999), eps=1e-8):
        self.params = list(params)
        self.lr = lr
        self.beta1, self.beta2 = betas
        self.eps = eps
        self.m = [torch.zeros_like(p) for p in self.params]
        self.v = [torch.zeros_like(p) for p in self.params]
        self.t = 0

    def step(self):
        self.t += 1
        for p, m, v in zip(self.params, self.m, self.v):
            if p.grad is None:
                continue
            m.mul_(self.beta1).add_(1 - self.beta1, p.grad)
            v.mul_(self.beta2).addcmul_(1 - self.beta2, p.grad, p.grad)
            m_hat = m / (1 - self.beta1 ** self.t)
            v_hat = v / (1 - self.beta2 ** self.t)
            p.data.addcdiv_(-self.lr, m_hat, v_hat.sqrt() + self.eps)
```

### 30.3 AdamW (解耦权重衰减)

```python
class AdamW:
    def __init__(self, params, lr=1e-3, betas=(0.9, 0.999),
                 eps=1e-8, weight_decay=0.01):
        self.params = list(params)
        self.lr = lr
        self.beta1, self.beta2 = betas
        self.eps = eps
        self.weight_decay = weight_decay
        self.m = [torch.zeros_like(p) for p in self.params]
        self.v = [torch.zeros_like(p) for p in self.params]
        self.t = 0

    def step(self):
        self.t += 1
        for p, m, v in zip(self.params, self.m, self.v):
            if p.grad is None:
                continue
            # 权重衰减: 解耦, 直接衰减 w
            p.data.mul_(1 - self.lr * self.weight_decay)
            # Adam 更新
            m.mul_(self.beta1).add_(1 - self.beta1, p.grad)
            v.mul_(self.beta2).addcmul_(1 - self.beta2, p.grad, p.grad)
            m_hat = m / (1 - self.beta1 ** self.t)
            v_hat = v / (1 - self.beta2 ** self.t)
            p.data.addcdiv_(-self.lr, m_hat, v_hat.sqrt() + self.eps)
```

### 30.4 Lion (新优化器, 2023)

```python
class Lion:
    def __init__(self, params, lr=1e-4, betas=(0.9, 0.99),
                 weight_decay=0.01):
        self.params = list(params)
        self.lr = lr
        self.beta1, self.beta2 = betas
        self.weight_decay = weight_decay
        self.m = [torch.zeros_like(p) for p in self.params]

    def step(self):
        for p, m in zip(self.params, self.m):
            if p.grad is None:
                continue
            # 更新方向 = sign(β1 * m + (1-β1) * grad)
            update = self.beta1 * m + (1 - self.beta1) * p.grad
            p.data.add_(-self.lr * torch.sign(update))
            # 新动量 = β2 * m + (1-β2) * grad
            m.mul_(self.beta2).add_((1 - self.beta2) * p.grad)
            # 权重衰减
            p.data.mul_(1 - self.lr * self.weight_decay)
```

Lion 比 Adam 内存小 (无 $v$), 某些任务更优。

## 31. 预条件子的"自动"实现

### 31.1 Levenberg-Marquardt

LM 是阻尼牛顿法, 隐式预条件:

$$\Delta x = -(H + \lambda I)^{-1} g$$

$\lambda$ 大 → 类似 GD (稳定); $\lambda$ 小 → 类似 Newton (快)。

```python
def levenberg_marquardt_step(loss_fn, x, damping=1e-3):
    """LM 单步."""
    loss = loss_fn(x)
    grads = torch.autograd.grad(loss, x, create_graph=True)
    flat_g = torch.cat([g.reshape(-1) for g in grads])
    # 数值 HVP 算 Hessian (简化: 用 JVP)
    n = flat_g.numel()
    H = torch.zeros(n, n)
    for i in range(n):
        e_i = torch.zeros(n)
        e_i[i] = 1.0
        Hv = hvp(loss, [x], [e_i.reshape_as(x)])[0]
        H[i] = Hv.reshape(-1)
    # 更新
    update = torch.linalg.solve(H + damping * torch.eye(n), flat_g)
    return x - update.reshape_as(x)
```

### 31.2 Trust Region

信赖域方法: 在 $\|p\| \le \Delta$ 内最小化 $f(x + p)$ 的二次近似:

$$\min_p \frac{1}{2} p^\top H p + g^\top p \quad \text{s.t. } \|p\| \le \Delta$$

解: $\Delta$ 小 → 用 GD 方向; $\Delta$ 大 → 用 Newton 方向。

## 32. 数值稳定的伪逆实现

```python
def stable_pinv(A, rcond=None):
    """数值稳定的伪逆 (使用截断)."""
    if rcond is None:
        rcond = max(A.shape) * np.finfo(A.dtype).eps  # 默认截断阈值

    U, S, Vt = np.linalg.svd(A, full_matrices=False)
    # 截断小奇异值
    mask = S > rcond
    S_inv = np.where(mask, 1.0 / S, 0.0)
    return (Vt.T * S_inv) @ U.T
```

## 33. 总结: 条件数 vs 浮点精度

### 33.1 双精度关系

浮点相对精度 $\varepsilon$ 与条件数 $\kappa$ 共同决定**有效位数**:

$$\text{effective digits} \approx -\log_{10}(\varepsilon \cdot \kappa) - 1$$

例:

- $\varepsilon = 10^{-7}$ (FP32), $\kappa = 10^3$: $4 - 1 = 3$ 位有效数字
- $\varepsilon = 10^{-16}$ (FP64), $\kappa = 10^3$: $13$ 位
- $\varepsilon = 10^{-16}$ (FP64), $\kappa = 10^{10}$: $6$ 位

**工程**: 病态 ($\kappa > 10^6$) 必须用 FP64 解。

### 33.2 自动精度选择

| 条件数 | 推荐精度 |
| :--- | :--- |
| $\kappa < 10^3$ | FP32 足够 |
| $10^3 < \kappa < 10^6$ | FP32 + 谨慎 |
| $10^6 < \kappa < 10^{12}$ | 必须 FP64 |
| $\kappa > 10^{12}$ | 重新设计问题 |

### 37.1 实验 1: 条件数 vs 收敛速度

```python
import numpy as np
import matplotlib.pyplot as plt

# 不同条件数的二次函数
def make_quadratic(cond):
    """生成条件数 cond 的二次函数 f(x) = 0.5 x^T A x."""
    eigvals = np.array([cond, 1.0])
    eigvals = np.concatenate([eigvals, np.random.uniform(0.5, 1.5, 8)])
    Q, _ = np.linalg.qr(np.random.randn(10, 10))
    A = Q @ np.diag(eigvals) @ Q.T
    return A

def gradient_descent(A, x0, lr=0.05, n_steps=500):
    """梯度下降, 跟踪 ||x - x*||."""
    x_star = np.zeros_like(x0)
    errors = [np.linalg.norm(x0 - x_star)]
    x = x0.copy()
    for _ in range(n_steps):
        grad = A @ x
        x = x - lr * grad
        errors.append(np.linalg.norm(x - x_star))
    return errors

# 实验
plt.figure(figsize=(10, 6))
for cond in [1, 10, 100, 1000, 10000]:
    A = make_quadratic(cond)
    x0 = np.random.randn(10)
    errors = gradient_descent(A, x0)
    plt.semilogy(errors, label=f'κ={cond}')
plt.xlabel('Step')
plt.ylabel('||x - x*||')
plt.legend()
plt.title('GD 收敛 vs Hessian 条件数')
plt.grid()
plt.savefig('cond_vs_convergence.png')
plt.show()
```

### 37.4 实验 4: SAM 改善泛化

```python
# SAM 单步 (简化版)
def sam_step(model, loss_fn, x, y, rho=0.05, optimizer=None):
    # 第一次反传
    loss = loss_fn(model(x), y)
    grads = torch.autograd.grad(loss, model.parameters(), create_graph=False)
    g_norm = torch.norm(torch.stack([g.norm() for g in grads]))
    # 扰动
    e_ws = [rho * g / g_norm for g in grads]
    for p, e in zip(model.parameters(), e_ws):
        p.data.add_(e)
    # 第二次反传
    loss = loss_fn(model(x), y)
    grads = torch.autograd.grad(loss, model.parameters())
    # 还原
    for p, e in zip(model.parameters(), e_ws):
        p.data.sub_(e)
    # 更新
    optimizer.zero_grad()
    for p, g in zip(model.parameters(), grads):
        p.grad = g
    optimizer.step()
```

**效果**: 在 CIFAR-10 上 ResNet + SAM 比 baseline 提升 1-2% 测试准确率。

### 38.1 何时用 Eig vs SVD?

| 情况 | 推荐 | 原因 |
| :--- | :--- | :--- |
| 对称矩阵 $A = A^\top$ | Eig | SVD 退化情形, 更快 |

## 40. 数值稳定的高级应用: Online Learning 与 Bandit

### 40.1 FTRL (Follow The Regularized Leader)

$$\theta_t = \arg\min_\theta \sum_{s=1}^{t} L_s(\theta) + \frac{1}{2\eta} \|\theta\|^2$$

稀疏解 (L1) + 强凸 (L2), 在线学习的经典算法。

### 40.2 Online Newton Step

在线二阶方法, 利用累积梯度信息, 收敛率 $O(d \log T / T)$ 对强凸损失。

### 40.3 Bandit: UCB

$$\text{UCB}_i = \hat \mu_i + \sqrt{\frac{2 \log t}{n_i}}$$

"置信上界", 平衡 explore (大 $n_i$ 减小 → 大 UCB) 与 exploit (高 $\hat \mu_i$)。

### 40.4 Thompson Sampling

后验采样: $a_t \sim P(\text{reward} | \text{data})$, 选 $a_t = \arg\max_a \mathbb{E}[\text{reward} | a]$。

数值稳定: log 域算采样。

## 41. 数值稳定的 Bayesian 推理

### 41.1 Laplace 近似

$p(\theta | D) \approx \mathcal{N}(\theta^*, H^{-1})$, $H$ 是负对数后验的 Hessian。

```python
def laplace_approx(loss_fn, theta_star):
    """在 theta_star 处 Laplace 近似."""
    # 数值 Hessian
    n = theta_star.numel()
    H = torch.zeros(n, n)
    for i in range(n):
        e_i = torch.zeros(n)
        e_i[i] = 1.0
        e_i_t = e_i.reshape_as(theta_star)
        Hvp = numerical_hvp(loss_fn, theta_star, e_i_t)
        H[i] = Hvp.flatten()
    # 协方差 = H^{-1}
    cov = torch.linalg.inv(H)
    return theta_star, cov
```

### 41.2 变分推断 (VI)

用简单分布 $q(\theta)$ 近似后验 $p(\theta | D)$, 最小化 KL 散度。

ELBO: $\mathcal{L}(q) = \mathbb{E}_q[\log p(D|\theta)] - D_{KL}(q \| p)$

数值稳定: 用 `torch.distributions` 库 (内部已稳定)。

### 41.3 MCMC

Metropolis-Hastings / HMC 在高维难; 数值稳定关键在 log 域:

```python
def log_acceptance(p_new, p_old):
    """log p_new - log p_old 用于接受率."""
    return min(0.0, p_new - p_old)  # log 域
```

```python
        optimizer.step()
```

### 110. 条件数与病态问题 - 应用场景 视角

**核心议题**: 本节从应用场景视角切入,系统展开 "条件数与病态问题" 的相关讨论。

**1. 背景与动机**

任何技术或方法的出现都不是孤立的,而是回应特定历史条件下的具体问题。"条件数与病态问题" 的发展也不例外。要理解它,必须回到它出现的那个时间点,看清它要解决的真实问题是什么。当时的主流方案有哪些不足? 它的提出填补了哪些空白? 这些问题的回答,决定了我们今天该如何使用它。

从知识论角度看,**技术演进是问题驱动的**——不是先有方案再找问题,而是先有问题再有方案。这个观察可以帮助我们避免"拿着锤子找钉子"的陷阱,真正把方法用对地方。

历史维度上,我们看到三个规律:

1. **从特殊到一般**: 早期方法往往针对特定场景,后期抽象出通用框架。学习的认知规律也是先掌握具体案例,再抽象出一般模式。这种"自下而上"的学习方式,在机器学习模型的设计里反复出现。

2. **从手工到自动**: 经验规则逐步被数据驱动的方法取代。在早期,很多 AI 系统依赖人工编写的规则。统计学习方法的崛起让"从数据中学习"成为可能。深度学习进一步把特征工程也自动化了。今天的大模型时代,我们看到端到端学习从感知扩展到了推理与生成。

3. **从局部到全局**: 关注单个组件,演进到关注整个系统。早期模型评估只关注单点指标,现在更关注全链路的协同效应。这种"系统视角"的转变,与软件工程从单体架构到微服务架构的演进高度相似。

**2. 应用场景视角的展开**

从应用场景视角出发,我们可以把 "条件数与病态问题" 拆解为以下几个层次:

**第一层: 概念层** —— 这是最抽象的层次,定义了我们要研究的对象是什么。例如,"推荐系统"在概念层是一个"为用户从物品集合中筛选合适物品"的问题。这个层次的特点是清晰、稳定、不易变化。一个好的概念定义应该具备几个特征:可操作性、可测量性、可扩展性。

**第二层: 模型层** —— 把概念实例化为数学模型。同一概念可以有不同的模型化方式,例如"推荐系统"可以是协同过滤、矩阵分解、深度学习等。模型的选择决定了后续算法的空间,也决定了能利用的归纳偏置(比如序列模型擅长捕捉时序依赖,图模型擅长建模关系结构)。模型选型是工程实践中最重要的决策之一。

**第三层: 算法层** —— 在选定模型下,具体的求解方法。这一层最活跃,新算法层出不穷。同一模型往往有多种算法,各有优劣。例如同样是优化深度网络,可以选择 SGD、Adam、L-BFGS 等不同算法。算法的选择要考虑收敛速度、数值稳定性、计算成本等多个维度。

**第四层: 工程层** —— 算法落地的实现细节,包括数据流水线、训练框架、推理优化、监控告警等。工程层是研究到生产的桥梁,决定了一个方法能否真正用起来。一个在论文里表现很好的算法,如果不能高效实现、不能稳定运行、不能快速迭代,就没有实际价值。工程能力是把研究转化为生产力的关键。

**第五层: 业务层** —— 在具体业务场景中的表现。同一技术在不同业务里效果差异巨大,因为业务目标、数据分布、用户行为都有差异。从业务视角看技术,我们必须回答几个问题:这个技术解决了什么业务问题?投入产出比如何?长期可持续吗?技术评估必须与业务目标对齐,否则容易陷入"技术自嗨"的陷阱。

**3. 数学形式化(简洁版)**

虽然我们强调应用场景视角,但数学形式化提供了共同语言。机器学习的核心问题可以表达为:给定输入样本,学习一个映射函数,使得函数输出与真实目标的差距最小化。这个抽象捕捉了分类、回归、生成等大多数任务的本质。

进一步,优化目标通常加入正则化项来控制模型复杂度,平衡经验风险与模型容量。统计学习理论给出了泛化误差的上界,告诉我们模型越复杂并不一定越好——**奥卡姆剃刀**在数学上有严格的形式化。

偏差-方差分解是另一个核心框架:误差可以分解为模型偏差(欠拟合)、方差(过拟合)和不可约噪声三部分。理解这个分解有助于诊断模型表现、选择合适复杂度。

在数值稳定性方面,有几个常见陷阱: 浮点数精度有限、Log-Sum-Exp 计算要减去最大值、Softmax 在大数值下会溢出。这些工程细节常常决定一个模型能否在生产环境稳定运行。

**4. 信息论视角**

任何技术或方法的出现都不是孤立的,而是回应特定历史条件下的具体问题。"条件数与病态问题" 的发展也不例外。要理解它,必须回到它出现的那个时间点,看清它要解决的真实问题是什么。当时的主流方案有哪些不足? 它的提出填补了哪些空白? 这些问题的回答,决定了我们今天该如何使用它。

3. **从局部到全局**: 关注单个组件,演进到关注整个系统。早期模型评估只关注单点指标,现在更关注全链路的协同效应。这种"系统视角"的转变,与软件工程从单体架构到微服务架构的演进高度相似。

**2. 形式化视角的展开**

从形式化视角出发,我们可以把 "条件数与病态问题" 拆解为以下几个层次:

**第一层: 概念层** —— 这是最抽象的层次,定义了我们要研究的对象是什么。例如,"推荐系统"在概念层是一个"为用户从物品集合中筛选合适物品"的问题。这个层次的特点是清晰、稳定、不易变化。一个好的概念定义应该具备几个特征:可操作性、可测量性、可扩展性。

**第二层: 模型层** —— 把概念实例化为数学模型。同一概念可以有不同的模型化方式,例如"推荐系统"可以是协同过滤、矩阵分解、深度学习等。模型的选择决定了后续算法的空间,也决定了能利用的归纳偏置(比如序列模型擅长捕捉时序依赖,图模型擅长建模关系结构)。模型选型是工程实践中最重要的决策之一。

**第三层: 算法层** —— 在选定模型下,具体的求解方法。这一层最活跃,新算法层出不穷。同一模型往往有多种算法,各有优劣。例如同样是优化深度网络,可以选择 SGD、Adam、L-BFGS 等不同算法。算法的选择要考虑收敛速度、数值稳定性、计算成本等多个维度。

**第四层: 工程层** —— 算法落地的实现细节,包括数据流水线、训练框架、推理优化、监控告警等。工程层是研究到生产的桥梁,决定了一个方法能否真正用起来。一个在论文里表现很好的算法,如果不能高效实现、不能稳定运行、不能快速迭代,就没有实际价值。工程能力是把研究转化为生产力的关键。

**第五层: 业务层** —— 在具体业务场景中的表现。同一技术在不同业务里效果差异巨大,因为业务目标、数据分布、用户行为都有差异。从业务视角看技术,我们必须回答几个问题:这个技术解决了什么业务问题?投入产出比如何?长期可持续吗?技术评估必须与业务目标对齐,否则容易陷入"技术自嗨"的陷阱。

**3. 数学形式化(简洁版)**

虽然我们强调形式化视角,但数学形式化提供了共同语言。机器学习的核心问题可以表达为:给定输入样本,学习一个映射函数,使得函数输出与真实目标的差距最小化。这个抽象捕捉了分类、回归、生成等大多数任务的本质。

进一步,优化目标通常加入正则化项来控制模型复杂度,平衡经验风险与模型容量。统计学习理论给出了泛化误差的上界,告诉我们模型越复杂并不一定越好——**奥卡姆剃刀**在数学上有严格的形式化。

偏差-方差分解是另一个核心框架:误差可以分解为模型偏差(欠拟合)、方差(过拟合)和不可约噪声三部分。理解这个分解有助于诊断模型表现、选择合适复杂度。

在数值稳定性方面,有几个常见陷阱: 浮点数精度有限、Log-Sum-Exp 计算要减去最大值、Softmax 在大数值下会溢出。这些工程细节常常决定一个模型能否在生产环境稳定运行。

**4. 信息论视角**

信息论为"条件数与病态问题" 提供了统一的视角:**学习的本质是从数据中提取与目标相关的信息**。

互信息衡量知道一个变量后,另一个变量不确定性减少的量。在机器学习中,它被广泛用于特征选择、表示学习、多模态对齐等场景。

KL 散度衡量两个概率分布的距离,在交叉熵损失、变分推断、策略梯度等场景无处不在。需要注意它是**不对称**的——不同方向有不同的解释。

信息瓶颈原则指出,我们应该寻找既紧凑又预测性强的表示。这一思想影响了大量表示学习方法的设计,包括对比学习、自监督学习、多模态预训练等。

**7. 实践建议**

结合 "条件数与病态问题" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "条件数与病态问题" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
