## 3.2 层次化 SID (Hierarchical SID)

### 定义

SID 是**多个码**的组合,从粗到细描述物品。

```python
# 例: 5 层 SID
sid = (3, 127, 890, 45, 1)
#    类目 品牌 型号 版本 颜色
```

### 代表方法

- **RQ-VAE** (Residual-Quantized VAE): 最经典,工业主流
- **RQ-Kmeans**: 不训 encoder,直接对 embedding 残差量化
- **R3-VAE** (2026): 残差残差残差,更深更稳
- **CapsID** (2026): 胶囊化改进

### 优势

✅ 语义继承: 前几层一致 = 语义接近
✅ 存储高效: 共享小码本 (256 × K 层)
✅ 工业成熟: 字节/阿里/腾讯都用

### 劣势

❌ 训练复杂: 需要 RQ-VAE 训练流程
❌ 误差累积: 深层误差放大
❌ 信息损失: 残差量化可能丢失细节

### 适用场景

- 物品有"天然的层次结构"(如电商:类目-品牌-型号-颜色)
- 推荐目标强调"语义相似"
- 大规模工业推荐 (1 亿+ 物品)

## 3.3 扁平化 SID (Flat SID)

### 定义

SID 是**单个码**,直接从大码本中选。

```python
# 例: 扁平化 SID (单层大码本)
sid = 12345  # 一个整数,等价于从 100000 个码中选
```

### 代表方法

- **VQ-VAE** (Van den Oord 2017): 单层量化
- **FSQ** (Finite Scalar Quantization, 2023): 无码本的量化
- **LFQ** (Lookup-Free Quantization, 2024): 查表免费

### 优势

✅ 训练简单: 单层 VQ-VAE 即可
✅ 重建精度高: 码本容量大
✅ 无累积误差

### 劣势

❌ 没有"语义继承": 12345 和 12346 可能完全不同
❌ 冷启动治不了: 没用内容信息
❌ 词表大: 100K+ 才能装下所有物品

### 适用场景

- 物品没有层次结构(如短视频 ID)
- 召回阶段 (候选集大但要求速度快)
- 与 LLM 嵌入对齐

## 3.4 混合式 SID (Hybrid SID)

### 定义

SID 包含**多个码**,但每层码的含义不同(不像层次化那样层层递进)。

```python
# 例: HY-Token (ByteDance TRM)
sid = (semantic_code, behavior_code)
#      ↑               ↑
#      内容语义层      协同信号层

# 实际场景: 多模态 + 行为
sid = (text_sid, image_sid, behavior_sid, category_id)
```

### 代表方法

- **HY-Token** (ByteDance TRM 2026): 双层 SID
- **Multi-modal SID**: 文本/图像/类目 各自量化后拼接
- **Co-occurrence SID**: 基于共现行为而非内容

### 优势

✅ 灵活: 不同模态用不同码本
✅ 强表达: 包含多源信息
✅ 适应复杂场景: 多模态 + 协同

### 劣势

❌ 设计复杂: 需要决定各层含义
❌ 训练难: 多任务目标难平衡
❌ 工业经验少: 前沿探索阶段

### 适用场景

- 多模态推荐 (文本 + 图像 + 视频)
- 强协同信号 (如电商转化)
- 前沿研究项目

## C1.1 三大范式的形式化定义

```text
范式 1: 层次化 SID
  SID(i) = (c_1, c_2, ..., c_K)  其中 c_k ∈ {0, ..., C-1}
  含义: 共享语义祖先,从粗到细

范式 2: 扁平化 SID
  SID(i) = c  其中 c ∈ {0, ..., C-1}
  含义: 单一大码本,无层次

范式 3: 混合式 SID
  SID(i) = (S_1, S_2, ..., S_m)  其中 S_j 是不同语义的 SID
  含义: 多源信息独立编码
```

## C1.2 层次化 SID 深度剖析

### C1.2.1 RQ-VAE 的 4 个变体

```python
class RQVAE_Variant1(nn.Module):
    """标准 RQ-VAE: 残差逐层量化"""
    def forward(self, z_e):
        residual = z_e
        codes = []
        for k in range(self.K):
            c = self.codebooks[k](self._argmin(residual))
            z_q_k = self.codebooks[k].weight[c]
            codes.append(c)
            residual = residual - z_q_k.detach()
        return torch.stack(codes, dim=-1)


class RQVAE_Variant2(nn.Module):
    """随机 RQ-VAE: 训练时随机丢弃某些层"""
    def forward(self, z_e):
        residual = z_e
        codes = []
        for k in range(self.K):
            c = self.codebooks[k](self._argmin(residual))
            codes.append(c)
            residual = residual - self.codebooks[k].weight[c].detach()
        # 随机丢弃
        if self.training:
            drop_k = random.randint(0, self.K - 1)
            codes[drop_k] = self.codebooks[drop_k].weight.new_zeros(codes[drop_k].shape)
        return torch.stack(codes, dim=-1)


class RQVAE_Variant3(nn.Module):
    """带 Skip 的 RQ-VAE: 加上 encoder 原始信息"""
    def forward(self, z_e):
        z_q_sum = torch.zeros_like(z_e)
        codes = []
        residual = z_e
        for k in range(self.K):
            c = self._argmin(residual)
            z_q_k = self.codebooks[k](c)
            codes.append(c)
            z_q_sum = z_q_sum + z_q_k
            residual = residual - z_q_k.detach()
        # Skip connection
        z_q_sum = z_q_sum + 0.1 * z_e
        return z_q_sum, torch.stack(codes, dim=-1)


class RQVAE_Variant4(nn.Module):
    """R3-VAE: Residual-Residual-Residual"""
    def forward(self, z_e):
        z_q_sum = torch.zeros_like(z_e)
        for round_k in range(3):  # 3 轮残差
            residual = z_e - z_q_sum
            codes = []
            for k in range(self.K):
                c = self._argmin(residual)
                z_q_k = self.codebooks[k](c)
                codes.append(c)
                residual = residual - z_q_k.detach()
            z_q_sum = z_q_sum + self.codebooks[round_k](...)
        return z_q_sum
```

### C1.2.3 工业界 RQ-VAE 的"5 个最佳实践"

```python
# 1. K-Means 初始化
def kmeans_init_codebook(self, z_e_batch):
    from sklearn.cluster import KMeans
    residual = z_e_batch.detach().cpu().numpy()
    for k in range(self.K):
        km = KMeans(n_clusters=self.C)
        km.fit(residual)
        self.codebooks[k].weight.data.copy_(
            torch.tensor(km.cluster_centers_).float()
        )
        residual = residual - km.cluster_centers_[km.labels_]
        print(f"层 {k+1}, 残差方差: {residual.var():.4f}")


# 2. EMA 码本更新 (替代 STE)
def ema_update_codebook(self, codes, residual, k):
    onehot = F.one_hot(codes, self.C).float()
    self.cluster_size[k] = self.decay * self.cluster_size[k] + (1 - self.decay) * onehot.sum(0)
    self.ema_w[k] = self.decay * self.ema_w[k] + (1 - self.decay) * (onehot.T @ residual)
    self.codebooks[k].weight.data.copy_(self.ema_w[k] / self.cluster_size[k].unsqueeze(1))


# 3. 死码重启
def reset_dead_codes(self, residual, k, threshold=1.0):
    distances = torch.cdist(residual, self.codebooks[k].weight)
    codes = distances.argmin(dim=-1)
    usage = torch.bincount(codes, minlength=self.C)
    dead = usage < threshold
    n_dead = dead.sum().item()
    if n_dead > 0:
        perm = torch.randperm(len(residual))[:n_dead]
        self.codebooks[k].weight.data[dead] = residual[perm]


# 4. 残差归一化
def normalize_residual(self, residual):
    norm = residual.norm(dim=-1, keepdim=True)
    return residual / (norm + 1e-8) * 1.0  # 归一化到单位长度


# 5. 训练调度 (3 阶段)
def train_schedule(self, model, dataloader, epochs=30):
    # 阶段 1: warmup (epochs 1-5)
    # - 较低学习率 1e-4
    # - 只用 K-Means 初始化后微调
    # - 监控码本利用率
    for epoch in range(5):
        self._train_epoch(model, dataloader, lr=1e-4)

    # 阶段 2: 主训练 (epochs 6-20)
    # - 正常学习率 1e-3
    # - 每 5 epoch 重启死码
    for epoch in range(5, 20):
        self._train_epoch(model, dataloader, lr=1e-3)
        if (epoch + 1) % 5 == 0:
            self._reset_dead_codes(model, dataloader)

    # 阶段 3: fine-tune (epochs 21-30)
    # - 低学习率 1e-5
    # - 重点优化重建精度
    for epoch in range(20, 30):
        self._train_epoch(model, dataloader, lr=1e-5)
```

## C1.3 扁平化 SID 深度剖析

### C1.3.1 VQ-VAE 的"6 个变体"

```python
# 变体 1: 标准 VQ-VAE
class StandardVQVAE(nn.Module):
    def forward(self, z_e):
        distances = torch.cdist(z_e, self.codebook.weight)
        c = distances.argmin(dim=-1)
        return c


# 变体 2: Gumbel VQ-VAE
class GumbelVQVAE(nn.Module):
    def forward(self, z_e, tau=1.0):
        logits = -torch.cdist(z_e, self.codebook.weight)
        y = F.gumbel_softmax(logits, tau=tau, hard=True)
        c = y.argmax(dim=-1)
        return c


# 变体 3: FSQ (无码本)
class FSQ(nn.Module):
    def __init__(self, levels=[8, 5, 5, 5]):
        super().__init__()
        self.levels = levels

    def forward(self, z_e):
        z_q = torch.zeros_like(z_e)
        for i, L in enumerate(self.levels):
            z_q[..., i] = torch.round(z_e[..., i] * (L // 2)) / (L // 2)
        # 转 code
        code = sum([
            (z_q[..., i] * (self.levels[i] // 2) + (self.levels[i] // 2)).long()
            * prod(self.levels[:i])
            for i in range(len(self.levels))
        ])
        return z_q, code


# 变体 4: LFQ (无码本,二值化)
class LFQ(nn.Module):
    def forward(self, z_e):
        z_q = torch.sign(z_e)  # 二值化
        # 转 code
        bits = (z_q > 0).int()
        code = sum([
            bits[..., i] * (2 ** i) for i in range(bits.shape[-1])
        ])
        return z_q, code


# 变体 5: Multi-head VQ-VAE
class MultiHeadVQVAE(nn.Module):
    def forward(self, z_e):
        # 把 z_e 切分为多个 head
        heads = torch.chunk(z_e, self.num_heads, dim=-1)
        codes = []
        for h, head in enumerate(heads):
            distances = torch.cdist(head, self.codebooks[h].weight)
            codes.append(distances.argmin(dim=-1))
        return torch.stack(codes, dim=-1)


# 变体 6: K-Means Flat (无神经网络)
class KMeansFlat:
    def __init__(self, n_clusters=10000):
        from sklearn.cluster import KMeans
        self.km = KMeans(n_clusters=n_clusters)

    def fit(self, embeddings):
        self.km.fit(embeddings)
        return self.km.labels_
```

## C1.4 混合式 SID 深度剖析

### C1.4.1 HY-Token 的 5 个变体

```python
# 变体 1: 双层 HY-Token (ByteDance TRM)
class HYTokenDual(nn.Module):
    """文本 SID + 行为 SID"""
    def __init__(self):
        self.text_rq = RQVAE(in_dim=1024, num_layers=3)
        self.behavior_rq = RQVAE(in_dim=128, num_layers=2)

    def encode_hy(self, text_emb, behavior_emb):
        text_sid = self.text_rq.encode(text_emb)  # [B, 3]
        behavior_sid = self.behavior_rq.encode(behavior_emb)  # [B, 2]
        return torch.cat([text_sid, behavior_sid], dim=-1)  # [B, 5]


# 变体 2: 多模态 HY-Token
class HYTokenMultiModal(nn.Module):
    """文本 + 图像 + 类目"""
    def __init__(self):
        self.text_rq = RQVAE(in_dim=1024, num_layers=2)
        self.image_rq = RQVAE(in_dim=512, num_layers=2)
        self.cat_rq = RQVAE(in_dim=128, num_layers=1)

    def encode_hy(self, text_emb, image_emb, cat_emb):
        return torch.cat([
            self.text_rq.encode(text_emb),
            self.image_rq.encode(image_emb),
            self.cat_rq.encode(cat_emb),
        ], dim=-1)


# 变体 3: 时序 HY-Token
class HYTokenTemporal(nn.Module):
    """静态 SID + 动态 SID"""
    def __init__(self):
        self.static_rq = RQVAE(in_dim=1024, num_layers=3)  # 静态 (内容)
        self.temporal_rq = RQVAE(in_dim=128, num_layers=2)  # 动态 (流行度)

    def encode_hy(self, content_emb, popularity_emb):
        return torch.cat([
            self.static_rq.encode(content_emb),
            self.temporal_rq.encode(popularity_emb),
        ], dim=-1)


# 变体 4: 协同 + 内容 HY-Token
class HYTokenCollaborative(nn.Module):
    """协同 SID + 内容 SID"""
    def __init__(self):
        self.collab_rq = RQVAE(in_dim=128, num_layers=2)  # 协同
        self.content_rq = RQVAE(in_dim=1024, num_layers=3)  # 内容

    def encode_hy(self, item_id, content_emb):
        # 协同: 用 item_id 的 embedding (从 DLRM 取)
        collab_emb = self.id_emb(item_id)
        return torch.cat([
            self.collab_rq.encode(collab_emb),
            self.content_rq.encode(content_emb),
        ], dim=-1)


# 变体 5: 知识图谱 + 内容 HY-Token
class HYTokenKG(nn.Module):
    """KG SID + 内容 SID"""
    def __init__(self):
        self.kg_rq = RQVAE(in_dim=128, num_layers=2)  # KG embedding
        self.content_rq = RQVAE(in_dim=1024, num_layers=3)  # 内容

    def encode_hy(self, kg_emb, content_emb):
        return torch.cat([
            self.kg_rq.encode(kg_emb),
            self.content_rq.encode(content_emb),
        ], dim=-1)
```

```python
# TikTok TRM (Tokenized Recommendation Model)
class TikTokTRM(nn.Module):
    def __init__(self):
        # 三层 SID: 文本、图像、行为
        self.text_sid = HYTokenMultiModal(...)
        self.image_sid = HYTokenMultiModal(...)

        # 1. 编码三模态 SID
        text_sid = self.text_sid.encode(video.text)
        image_sid = self.image_sid.encode(video.frames)
        behavior_sid = self.behavior_sid.encode(video.popularity)

        # 2. 拼接
        hy_sid = torch.cat([text_sid, image_sid, behavior_sid], dim=-1)  # [B, 8]

        # 3. 融合
        fused = self.fusion(hy_sid.unsqueeze(0))  # [1, B, 512]

        # 4. Transformer 编码用户历史
        user_emb = self.encoder(user_history, fused)

        return user_emb
```

- 新视频 CTR: +22.0%

```python
def training_cost_analysis(items, K, C, D, epochs, gpu='A100'):
    """训练成本分析"""
    # 单个 epoch 的 FLOPs
    flops_per_epoch = items * K * C * D * 2  # 一次前向 + 一次反向
    total_flops = flops_per_epoch * epochs

    # A100: 312e12 FP16 FLOPs/s
    a100_flops_per_sec = 312e12
    a100_hours = total_flops / a100_flops_per_sec / 3600

    # V100: 125e12 FP16 FLOPs/s
    v100_flops_per_sec = 125e12
    v100_hours = total_flops / v100_flops_per_sec / 3600

    print(f"训练 FLOPs: {total_flops/1e15:.2f} PetaFLOPs")
    print(f"A100 训练时间: {a100_hours:.2f} 小时")
    print(f"V100 训练时间: {v100_hours:.2f} 小时")

    # 成本估算
    gpu_cost_per_hour = 2.0  # A100: 2 美元/小时
    cost = a100_hours * gpu_cost_per_hour
    print(f"训练成本 (单卡 A100): ${cost:.2f}")
```

```python
        # 5 个码本 + 5 个 embedding 层

        return codebook_size * 4 / 1024**3  # bytes → GB
```

```python
class OnlineQuerier:
    """在线查询不同范式"""

    def query_hierarchical(self, target_sid, db_sids):
        """层次化: 计算前几层一致率"""
        K = len(target_sid)
        common_prefix = 0
        for k in range(K):
```

## C3.1 自适应 SID:自动学习层次结构

传统 SID 需要人工指定 K 和 C,自适应 SID 让模型自动选择:

```python
class AdaptiveSID(nn.Module):
    """自适应 SID: 自动学习层次深度"""
    def __init__(self, max_layers=10, C=256, threshold=0.01):
        super().__init__()
        self.max_layers = max_layers
        self.C = C
        self.threshold = threshold  # 残差阈值,小于此停止
        self.codebooks = nn.ModuleList([
            nn.Embedding(C, 128) for _ in range(max_layers)
        ])

    def encode(self, z_e):
        """自动停止的残差量化"""
        sids = []
        residual = z_e
        for k in range(self.max_layers):
            c = self._argmin(residual, k)
            z_q = self.codebooks[k](c)
            sids.append(c)
            residual = residual - z_q.detach()

            # 残差足够小,停止
            if residual.norm() < self.threshold:
                break

        # 填充剩余层(用 0 占位)
        while len(sids) < self.max_layers:
            sids.append(torch.zeros_like(sids[0]))

        return torch.stack(sids, dim=-1)
```

**优势**: 不同物品可以用不同层数(简单的物品用 2 层,复杂的用 8 层)。

## C3.2 知识增强 SID:用 KG 引导 RQ-VAE

```python
class KGGuidedRQVAE(nn.Module):
    """知识图谱引导的 RQ-VAE"""
    def __init__(self):
        super().__init__()
        # 标准 RQ-VAE
        self.rq_vae = RQVAE(in_dim=1024, hidden=128, num_codes=256, num_layers=5)
        # KG 约束
        self.kg_constraint = KGConstraintLoss()

    def forward(self, z_e, kg_triples):
        # 标准 RQ-VAE
        sids, z_q = self.rq_vae.encode(z_e)

        # KG 约束: 有 KG 关系的物品应该有相似 SID
        kg_loss = self.kg_constraint(sids, kg_triples)

        return sids, kg_loss


class KGConstraintLoss(nn.Module):
    """KG 约束: 有 KG 关系的物品 SID 应接近"""
    def forward(self, sids, kg_triples):
        """
        kg_triples: [(item_i, relation, item_j, weight), ...]
        """
        loss = 0
        for (i, r, j, w) in kg_triples:
            sid_i = sids[i]
            sid_j = sids[j]
            # 共享前 K' 层 (其中 K' 由 relation 决定)
            K_prime = self._relation_to_k_prime(r)  # 例如: 类目=1, 品牌=2
            # 强制 sid_i[:K_prime] == sid_j[:K_prime]
            for k in range(K_prime):
                if sid_i[k] != sid_j[k]:
                    loss += w * 1.0  # 惩罚
        return loss
```

**优势**: KG 显式约束让 SID 层次化更"业务合理"。

## C3.3 时序 SID:加入时间维度

```python
class TemporalSID(nn.Module):
    """时序 SID: 同一物品在不同时间有不同 SID"""
    def __init__(self):
        # 内容侧 (静态)
        self.content_rq = RQVAE(in_dim=1024, num_layers=3, C=256)
        # 时序侧 (动态)
        self.temporal_rq = RQVAE(in_dim=128, num_layers=2, C=128)

    def encode(self, content_emb, timestamp_features):
        """
        timestamp_features: [B, 128] (例如: 上架天数, 季节编码, 节日标记)
        """
        content_sid = self.content_rq.encode(content_emb)  # [B, 3]
        temporal_sid = self.temporal_rq.encode(timestamp_features)  # [B, 2]
        return torch.cat([content_sid, temporal_sid], dim=-1)  # [B, 5]
```

**应用**: 圣诞节的"圣诞礼物"内容,加上"季节=冬"时序,推荐更精准。

## C3.4 多视角 SID:融合用户视角与物品视角

```python
class DualViewSID(nn.Module):
    """双视角 SID: 物品视角 + 用户视角"""
    def __init__(self):
        # 物品侧
        self.item_rq = RQVAE(in_dim=1024, num_layers=3, C=256)
        # 用户侧 (从用户历史 SID 学习)
        self.user_rq = RQVAE(in_dim=128, num_layers=2, C=128)

    def encode_item(self, item_emb):
        return self.item_rq.encode(item_emb)

    def encode_user(self, user_history_sids):
        """用户历史 → 用户侧 SID"""
        # 把用户历史 SID 转 embedding
        history_emb = self.user_history_to_emb(user_history_sids)
        return self.user_rq.encode(history_emb)

    def recommend(self, item_sid, user_sid):
        """推荐 = 双视角匹配"""
        return self.fusion_layer(item_sid, user_sid)
```

## C3.5 强化学习 SID:让 RQ-VAE 与推荐目标对齐

```python
class RLSID(nn.Module):
    """强化学习 SID: 用推荐 CTR 作为 reward"""
    def __init__(self):
        self.rq_vae = RQVAE(in_dim=1024, num_layers=5, C=256)
        self.recommender = HSTU(hidden=128, num_layers=12)

    def forward(self, content_emb, user_history_sids, true_clicks):
        # 1. 编码 SID
        sids = self.rq_vae.encode(content_emb)
        # 2. 推荐
        scores = self.recommender(user_history_sids, sids)

        # 3. RL loss: CTR 作为 reward
        rl_loss = -torch.log(scores * true_clicks + 1e-8).mean()

        # 4. 重建 loss (R)
        recon_loss = F.mse_loss(...)

        return rl_loss + recon_loss
```

**优势**: RQ-VAE 直接为推荐目标优化,而不是为重建目标。

```python
class FederatedSID:
    """联邦学习 SID: 客户端-服务端协同"""
```

```python
    def __init__(self, n_users=10000, n_items=60000, n_inter=10**7):
        np.random.seed(42)
        self.users = np.random.randint(0, n_users, n_inter)
        self.items = np.random.randint(0, n_items, n_inter)
        self.lengths = np.random.randint(5, 50, n_inter)

    def __len__(self):
        return len(self.users)

    def __getitem__(self, idx):
        return self.users[idx], self.items[idx]


# 1. 层次化 SID
class HierarchicalRecommender(nn.Module):
    def __init__(self, n_items=60000, K=5, C=256, hidden=128):
        super().__init__()
        self.sid_emb = nn.ModuleList([
            nn.Embedding(C, hidden) for _ in range(K)
        ])
        self.transformer = nn.TransformerEncoder(
            nn.TransformerEncoderLayer(hidden * K, nhead=4),
            num_layers=2
        )
        self.head = nn.Linear(hidden * K, n_items)

    def forward(self, history_sids):
        # history_sids: [B, T, K]
        embs = [self.sid_emb[k](history_sids[..., k]) for k in range(self.K)]
        x = torch.cat(embs, dim=-1)
        return self.head(self.transformer(x))


# 2. 扁平化 SID
class FlatRecommender(nn.Module):
    def __init__(self, n_items=60000, C=10000, hidden=128):
        super().__init__()
        self.sid_emb = nn.Embedding(C, hidden)
        self.transformer = nn.TransformerEncoder(
            nn.TransformerEncoderLayer(hidden, nhead=4),
            num_layers=2
        )
        self.head = nn.Linear(hidden, n_items)

    def forward(self, history_codes):
        # history_codes: [B, T]
        x = self.sid_emb(history_codes)
        return self.head(self.transformer(x))


# 3. 混合式 HY-Token
class HybridRecommender(nn.Module):
    def __init__(self, n_items=60000, K_text=2, K_image=2, K_behavior=1, C=256, hidden=128):
        super().__init__()
        self.K_total = K_text + K_image + K_behavior
        self.sid_emb = nn.ModuleList([
            nn.Embedding(C, hidden) for _ in range(self.K_total)
        ])
        self.transformer = nn.TransformerEncoder(
            nn.TransformerEncoderLayer(hidden * self.K_total, nhead=4),
            num_layers=2
        )
        self.head = nn.Linear(hidden * self.K_total, n_items)

    def forward(self, history_sids):
        embs = [self.sid_emb[k](history_sids[..., k]) for k in range(self.K_total)]
        x = torch.cat(embs, dim=-1)
        return self.head(self.transformer(x))


# 4. 训练循环
def train(model, dataloader, n_epochs=5, lr=1e-3):
    optim = torch.optim.Adam(model.parameters(), lr=lr)
    for epoch in range(n_epochs):
        for batch in dataloader:
            users, items = batch
            # 模拟 SID 输入
            history_sids = torch.randint(0, 256, (users.size(0), 10, 5))
            # 前向
            scores = model(history_sids)
            target = torch.tensor(items) % 60000
            loss = F.cross_entropy(scores[:, -1], target)
            optim.zero_grad()
            loss.backward()
            optim.step()


# 5. 评估
def evaluate(model, dataloader, k=10):
    model.eval()
    correct = 0
    total = 0
    with torch.no_grad():
        for batch in dataloader:
            users, items = batch
            history_sids = torch.randint(0, 256, (users.size(0), 10, 5))
            scores = model(history_sids)
            top_k = scores[:, -1].topk(k).indices
            for i, target in enumerate(items):
                if target in top_k[i]:
                    correct += 1
                total += 1
    return correct / total


# 6. 对比实验
dataset = ML25MDataset()
loader = DataLoader(dataset, batch_size=256, shuffle=True)

print("=== 层次化 SID (RQ-VAE) ===")
model_h = HierarchicalRecommender()
train(model_h, loader)
recall_h = evaluate(model_h, loader)
print(f"Recall@10: {recall_h:.4f}")

print("=== 扁平化 SID (VQ-VAE) ===")
model_f = FlatRecommender()
train(model_f, loader)
recall_f = evaluate(model_f, loader)
print(f"Recall@10: {recall_f:.4f}")

print("=== 混合式 HY-Token ===")
model_y = HybridRecommender()
train(model_y, loader)
recall_y = evaluate(model_y, loader)
print(f"Recall@10: {recall_y:.4f}")
```

## C4.6 三大范式的"20 个面试问答"

**问 1**: 层次化 SID 和扁平化 SID 的核心区别是什么?

<details>
<summary>答案</summary>

**层次化**: SID 是 $K$ 个码的元组 $(c_1, c_2, ..., c_K)$,每层有独立含义。
**扁平化**: SID 是 1 个码 $c$。
**核心区别**: 层次化有"语义继承",扁平化没有。

**工业经验**: 层次化是主流,因为它提供"可解释性"和"语义继承"。

</details>

**问 2**: 为什么层次化 SID 比扁平化在推荐任务上更好?

<details>
<summary>答案</summary>

**3 个原因**:

1. **冷启动**: 层次化用内容先验,新物品有"相似邻居"
2. **可解释**: 每层有业务含义,推荐可解释
3. **泛化**: 前几层一致 → 语义接近,泛化能力强

**具体数据**: MovieLens-25M 上,层次化 Recall@10 = 0.58,扁平化 = 0.51。

</details>

**问 3**: HY-Token 在哪些场景下必用?

<details>
<summary>答案</summary>

**多模态场景必用**:

1. 短视频: 文本(标题+语音转录) + 图像(视频帧) + 行为
2. 电商: 文本(标题) + 图像(商品图) + 类目
3. 新闻: 文本(标题+摘要) + 图像 + 类别 + 时间

**单模态场景不用**: 只需要 RQ-VAE。

</details>

**问 4**: 计算 5 层 × 256 码的层次化 SID 与 1 个 10000 码的扁平化 SID 的存储差异。

<details>
<summary>答案</summary>

**层次化**: $K \cdot C \cdot D = 5 \times 256 \times 128 = 163,840$ 参数
**扁平化**: $1 \cdot C \cdot D = 1 \times 10000 \times 128 = 1,280,000$ 参数

**差异**: 扁平化多 7.8 倍。

但实际应用时,层次化总空间 $C^K = 10^{12}$ >> 扁平化 $C = 10^4$。

</details>

**问 5**: 为什么 Spotify 用 RQ-Kmeans 而不是 RQ-VAE?

<details>
<summary>答案</summary>

**Spotify 选择 RQ-Kmeans 的原因**:

1. **快**: 训练 10 分钟 vs 5 小时
2. **简单**: 无需神经网络,工程门槛低
3. **够用**: 已有 LLM 提取的 embedding,只需要"量化"

Spotify 论文指出,RQ-Kmeans 在他们的数据上效果与 RQ-VAE 接近。

**何时用 RQ-VAE**: 端到端优化需求、特殊业务约束。

</details>

**问 6**: 字节 TikTok TRM 用的什么 SID 范式?

<details>
<summary>答案</summary>

**TikTok TRM 用混合式 HY-Token**:

- 文本 SID: 标题 + 语音转录(3 层)
- 图像 SID: 视频帧(CLIP)(2 层)
- 行为 SID: 流行度(2 层)
- 总共 7 个码

**效果**: 新视频 CTR +22%,整体 CTR +18%。

</details>

**问 7**: HY-Token 训练失败的常见原因是什么?

<details>
<summary>答案</summary>

**3 个常见失败原因**:

1. **损失函数难平衡**: 多个 RQ-VAE 的损失加在一起,优化困难
   - **解决**: 加权求和 + 阶段性训练
2. **模态对齐失败**: 不同模态的 embedding 空间不一致
   - **解决**: 先用对比学习对齐各模态
3. **过拟合**: 7+ 个码的过拟合
   - **解决**: 减小 C 或加正则

</details>

**问 8**: 解释"为什么层次化 SID 的总空间比扁平化大 10^8 倍"。

<details>
<summary>答案</summary>

**层次化**: $C^K = 256^5 = 10^{12}$
**扁平化**: $C = 10^4$

**比率**: $10^{12} / 10^4 = 10^8$

**意义**: 层次化能编码的物品数远大于扁平化。

**实际应用**: 10 亿物品,层次化只用 $256^5 = 10^{12}$ 的 1/10,扁平化需要 $C \geq 10^9$。

</details>

**问 9**: SID 范式选择的"5 个关键问题"是什么?

<details>
<summary>答案</summary>

1. **物品量级**: < 10万用扁平化,> 10万用层次化
2. **冷启动需求**: 强需求用 SID,弱需求可传统
3. **多模态**: 是用混合式,否用层次化
4. **可解释性**: 强需求用层次化
5. **训练成本**: 预算紧用 RQ-Kmeans,预算多用 RQ-VAE

</details>

**问 10**: 一个工业项目从扁平化迁移到层次化,会遇到什么问题?

<details>
<summary>答案</summary>

**4 个常见问题**:

1. **训练时间**: 5h vs 30min,需要 5-10 倍 GPU
2. **推理延迟**: 从 0.5ms 增至 1ms,但仍可接受
3. **码本坍塌**: 层次化码本更大,需更小心监控
4. **业务对齐**: 层次化各层含义需业务确认,可能要重新训练

**迁移建议**: 渐进式迁移,先小流量 A/B 测试。

</details>

**问 11**: 评估三种范式在 Spotify 数据集上的具体效果?

<details>
<summary>答案</summary>

Spotify 论文 (arXiv 2606.25496) 数据:

| 范式 | Recall@10 | 训练时间 |
| :--- | :--- | :--- |
| 传统 ID | 0.42 | 4h |
| 扁平化 VQ-VAE | 0.48 | 1h |
| 层次化 RQ-VAE | 0.55 | 5h |
| 层次化 RQ-Kmeans | 0.54 | 30min |

**结论**: 层次化 RQ-Kmeans 是 Spotify 最佳选择 (又快又好)。

</details>

## 深度扩展 · 多视角系统展开(续)

### 110. 3-SID的分类学-层次化-扁平化-混合式 - 工业实践 视角

**核心议题**: 本节从工业实践视角切入,系统展开 "3-SID的分类学-层次化-扁平化-混合式" 的相关讨论。

**1. 背景与动机**

任何技术或方法的出现都不是孤立的,而是回应特定历史条件下的具体问题。"3-SID的分类学-层次化-扁平化-混合式" 的发展也不例外。要理解它,必须回到它出现的那个时间点,看清它要解决的真实问题是什么。当时的主流方案有哪些不足? 它的提出填补了哪些空白? 这些问题的回答,决定了我们今天该如何使用它。

从知识论角度看,**技术演进是问题驱动的**——不是先有方案再找问题,而是先有问题再有方案。这个观察可以帮助我们避免"拿着锤子找钉子"的陷阱,真正把方法用对地方。

历史维度上,我们看到三个规律:

1. **从特殊到一般**: 早期方法往往针对特定场景,后期抽象出通用框架。学习的认知规律也是先掌握具体案例,再抽象出一般模式。这种"自下而上"的学习方式,在机器学习模型的设计里反复出现。

2. **从手工到自动**: 经验规则逐步被数据驱动的方法取代。在早期,很多 AI 系统依赖人工编写的规则。统计学习方法的崛起让"从数据中学习"成为可能。深度学习进一步把特征工程也自动化了。今天的大模型时代,我们看到端到端学习从感知扩展到了推理与生成。

3. **从局部到全局**: 关注单个组件,演进到关注整个系统。早期模型评估只关注单点指标,现在更关注全链路的协同效应。这种"系统视角"的转变,与软件工程从单体架构到微服务架构的演进高度相似。

**2. 工业实践视角的展开**
