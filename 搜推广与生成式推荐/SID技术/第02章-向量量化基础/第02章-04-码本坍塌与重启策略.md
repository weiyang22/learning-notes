## 4.1 什么是码本坍塌

**码本坍塌 (Codebook Collapse)**: 训练过程中,大量码本条目"无人使用",实际只用了 256 个里的 50 个。

```text
理论码本: [c0, c1, c2, ..., c255]  # 256 个
实际用到的: [c0, c3, c5, c10, c20, c50, c100]  # 只用 7 个
利用率: 7/256 = 2.7%
```

---

## 4.2 为什么会坍塌?

```python
# 场景: 训练早期,某个码 c42 离所有样本都很远
z_e_batch = ...  # [B, 128]
codebook = ...   # [256, 128]

# c42 永远不会被选中 (没人离它最近)
# → 它的梯度永远是 0
# → 它永远不会被更新
# → 它永远没人用
# → 死锁!
```

**根因**: 死循环。

---

## 4.3 三种解决方案

### 方案 1: 随机重启 (Codebook Reset)

每隔 N 步,重置"使用率低"的码本条目。

```python
def reset_dead_codes(model, z_e_batch, threshold=1.0):
    """重置使用率低于阈值的码本"""
    with torch.no_grad():
        # 计算每个码本的使用次数
        distances = torch.cdist(z_e_batch.unsqueeze(1), model.codebook.weight.unsqueeze(0))
        codes = distances.argmin(dim=-1)
        usage = torch.bincount(codes, minlength=model.codebook.num_embeddings)

        # 找到"死码"
        dead_mask = usage < threshold

        # 用当前 batch 的随机样本替换
        n_dead = dead_mask.sum().item()
        if n_dead > 0:
            random_samples = z_e_batch[torch.randperm(len(z_e_batch))[:n_dead]]
            model.codebook.weight.data[dead_mask] = random_samples
```

### 方案 2: EMA 统计强制最小使用率

```python
def ema_with_min_usage(cluster_size, threshold=1.0):
    """强制每个码至少被使用"""
    dead = cluster_size < threshold
    if dead.any():
        cluster_size[dead] = threshold  # 保底
    return cluster_size
```

### 方案 3: Gumbel-Softmax 软离散化

```python
# 让码本选择更"软",降低坍塌风险
y = F.gumbel_softmax(logits, tau=1.0, hard=True)
# 早期温度高 → 所有码都有机会被选中 → 不易坍塌
# 后期温度低 → 接近 argmin → 训练稳定
```

## 4.4 检测码本坍塌

```python
def compute_codebook_usage(model, dataloader):
    """计算码本利用率"""
    usage_count = torch.zeros(model.codebook.num_embeddings)
    total = 0

    model.eval()
    with torch.no_grad():
        for batch in dataloader:
            z_e = model.encoder(batch)
            codes, _ = model.quantize(z_e)
            for c in codes:
                usage_count[c] += 1
            total += len(codes)

    used = (usage_count > 0).sum().item()
    return used / model.codebook.num_embeddings

# 监控指标
usage = compute_codebook_usage(model, test_loader)
print(f"码本利用率: {usage:.1%}")  # 应该 > 70%
```

## 4.8 码本坍塌的深度分析

### 4.8.1 什么是码本利用率?

码本利用率定义为:

$$
U = \frac{|\{k : n_k > 0\}|}{K}
$$

其中:
- $n_k$ 是训练中码字 $k$ 被选中的次数
- $K$ 是码本大小
- $|\cdot|$ 是集合的基数 (count)

理想: $U = 1$ (所有码字都被使用)。

实际: $U = 0.3 \sim 0.7$ (部分码字没用)。

### 4.8.2 码本坍塌的形式

**形式 1: 轻度坍塌**

- 利用率 50-80%
- 部分码字没用
- 不影响训练,可以接受

**形式 2: 中度坍塌**

- 利用率 20-50%
- 大部分码字没用
- 训练变慢,重建变差

**形式 3: 重度坍塌**

- 利用率 < 20%
- 大量码字没用
- 训练失败

### 4.8.3 坍塌的数学刻画

设 $p_k$ 是码字 $k$ 被选中的概率。

**均匀分布**: $p_k = 1/K$, $H(p) = \log K$ (熵最大)

**完全坍塌**: $p_0 = 1$, 其他 = 0, $H(p) = 0$ (熵最小)

用熵衡量:

$$
H(p) = -\sum_k p_k \log p_k
$$

好的 VQ-VAE: $H(p) > 0.7 \log K$ (利用率 > 70%)。

### 4.8.4 坍塌的根因: 死循环

码本坍塌的本质是死循环:

```text
码字 c_42 没人选
   ↓
c_42 的梯度 = 0 (STE 不会更新)
   ↓
c_42 永远保持初始值
   ↓
c_42 离所有 z_e 都远
   ↓
c_42 还是没人选
   ↓
死循环!
```

这就是 §4.2 的死锁图。

## 4.9 解决方案详解

### 4.9.1 方案 1: 随机重启 (Codebook Reset)

**原理**: 每 N 步, 检测使用率, 重启使用率低的码字。

**代码**:

```python
@torch.no_grad()
def reset_dead_codes(model, z_e_batch, threshold=1.0):
    """重置使用率低于阈值的码"""
    # 1. 计算每个码的使用次数
    distances = torch.cdist(z_e_batch.unsqueeze(1),
                            model.codebook.weight.unsqueeze(0))
    codes = distances.argmin(dim=-1)
    usage = torch.bincount(codes, minlength=model.codebook.num_embeddings)

    # 2. 找死码
    dead_mask = usage < threshold

    # 3. 重启
    n_dead = dead_mask.sum().item()
    if n_dead > 0:
        # 用当前 batch 的样本替换
        random_samples = z_e_batch[torch.randperm(len(z_e_batch))[:n_dead]]
        model.codebook.weight.data[dead_mask] = random_samples
```

**优点**:
- 简单
- 有效

**缺点**:
- 重启可能破坏训练稳定性
- 需要选择合适的重启频率

**最佳实践**:
- 每 100-500 步重启一次
- 不要在训练初期重启 (码本还没稳定)
- 用 EMA 维护使用次数,而不是当前 batch

### 4.9.2 方案 2: EMA 强制最小使用率

**原理**: 在 EMA 更新中, 给 cluster_size 设置下限。

**代码**:

```python
def ema_with_min_usage(cluster_size, threshold=1.0):
    """强制每个码至少被使用"""
    dead = cluster_size < threshold
    if dead.any():
        cluster_size[dead] = threshold  # 保底
    return cluster_size
```

**优点**:
- 不需要重启
- 自动修复

**缺点**:
- 强制使用可能不自然

### 4.9.3 方案 3: Gumbel-Softmax 软离散化

**原理**: 用 Gumbel-Softmax 软选择, 避免硬坍塌。

**代码**:

```python
# Gumbel-Softmax 的 softmax 让每个码都有概率被选
y = F.gumbel_softmax(logits, tau=1.0, hard=True)
```

**优点**:
- 训练初期不易坍塌

**缺点**:
- 训练慢
- 高温时不稳定

### 4.9.4 方案 4: K-Means 初始化

**原理**: 训练前用 K-Means 初始化码本。

**代码**:

```python
from sklearn.cluster import KMeans

def init_codebook_with_kmeans(encoder, train_loader, num_codes, dim):
    """用 K-Means 初始化码本"""
    # 1. 收集所有 z_e
    z_e_all = []
    encoder.eval()
    with torch.no_grad():
        for batch in train_loader:
            x = batch[0].to(device)
            z_e = encoder(x)
            z_e_all.append(z_e.cpu())
    z_e_all = torch.cat(z_e_all, dim=0).numpy()

    # 2. K-Means 聚类
    kmeans = KMeans(n_clusters=num_codes, n_init=10, random_state=42)
    kmeans.fit(z_e_all)

    # 3. 用 cluster centers 初始化码本
    codebook = nn.Embedding(num_codes, dim)
    codebook.weight.data.copy_(torch.from_numpy(kmeans.cluster_centers_))
    return codebook
```

**优点**:
- 训练前就有合理的码本
- 大幅减少坍塌概率

**缺点**:
- 需要先跑一遍 encoder
- K-Means 也可能失败 (空 cluster)

### 4.9.5 方案 5: 拆分聚类 (Split Cluster)

**原理**: 把使用率高的码字拆成多个。

```python
@torch.no_grad()
def split_clusters(model, z_e_batch, usage_threshold=2.0):
    """把高频码字拆分成两个"""
    distances = torch.cdist(z_e_batch.unsqueeze(1),
                            model.codebook.weight.unsqueeze(0))
    codes = distances.argmin(dim=-1)
    usage = torch.bincount(codes, minlength=model.codebook.num_embeddings)

    # 找高频码字
    hot_mask = usage > usage_threshold * usage.mean()
    hot_indices = hot_mask.nonzero().squeeze(-1)

    # 把高频码字拆成两个 (各加一个小噪声)
    for idx in hot_indices:
        # 复制并加噪声
        new_vec = model.codebook.weight.data[idx] + 0.01 * torch.randn_like(model.codebook.weight.data[idx])
        # TODO: 需要额外的码字 slot
```

**优点**:
- 主动增加码字多样性

**缺点**:
- 实现复杂
- 需要预留码字 slot

### 4.9.6 方案 6: 聚类损失 (Cluster Loss)

**原理**: 在损失中加入"鼓励码字分散"的项。

```python
def cluster_loss(codebook, margin=1.0):
    """鼓励码字分散"""
    # 计算码字两两距离
    n = codebook.size(0)
    dists = torch.cdist(codebook, codebook)
    # 不算对角线 (自己到自己)
    mask = ~torch.eye(n, dtype=torch.bool, device=codebook.device)
    dists = dists[mask]
    # 让距离大于 margin
    loss = F.relu(margin - dists).mean()
    return loss
```

**优点**:
- 主动分散码字

**缺点**:
- 额外损失需要调权重
- 计算 O(K^2),K 大时慢

## 4.10 监控码本坍塌

### 4.10.1 监控指标

**指标 1: 码本利用率 (Usage Ratio)**

```python
@torch.no_grad()
def compute_usage_ratio(model, dataloader):
    """码本利用率"""
    usage = torch.zeros(model.codebook.num_embeddings)
    model.eval()
    for batch in dataloader:
        x = batch[0].to(device)
        z_e = model.encoder(x)
        codes = model.vq(z_e)[1]
        for c in codes.flatten():
            usage[c] += 1
    used = (usage > 0).sum().item()
    return used / model.codebook.num_embeddings
```

**指标 2: 使用分布的熵**

```python
@torch.no_grad()
def compute_usage_entropy(model, dataloader):
    """使用分布的熵"""
    usage = compute_usage(model, dataloader)
    p = usage / (usage.sum() + 1e-10)
    entropy = -(p * torch.log(p + 1e-10)).sum()
    max_entropy = torch.log(torch.tensor(float(model.codebook.num_embeddings)))
    return entropy / max_entropy
```

**指标 3: 每码使用次数直方图**

```python
@torch.no_grad()
def plot_usage_histogram(model, dataloader, save_path=None):
```

### 4.10.2 报警机制

```python
class CodebookMonitor:
    """码本监控器"""
    def __init__(self, num_codes, alert_threshold=0.5):
        self.num_codes = num_codes
        self.alert_threshold = alert_threshold

    def check(self, model, dataloader):
        usage = compute_usage_ratio(model, dataloader)
        entropy = compute_usage_entropy(model, dataloader)

        # 报警
        alerts = []
        if usage < self.alert_threshold:
            alerts.append(f"码本利用率过低: {usage:.2%} < {self.alert_threshold:.2%}")
        if entropy < 0.5:
            alerts.append(f"使用分布熵过低: {entropy:.2f}")

        return {
            "usage": usage,
            "entropy": entropy,
            "alerts": alerts,
        }
```

## 4.11 工业实践: 字节跳动 RQ-VAE 的码本管理

### 4.11.1 初始化策略

字节跳动推荐系统中的 RQ-VAE 初始化:

```python
def industrial_init_codebook(encoder, train_loader, num_codes, dim):
    """工业级码本初始化"""
    # 1. K-Means 初始化
    codebook = init_codebook_with_kmeans(encoder, train_loader, num_codes, dim)

    # 2. 微调: 在训练集上跑几个 epoch
    # 让码字与 z_e 分布对齐
    optimizer = torch.optim.Adam([codebook.weight], lr=1e-3)
    for _ in range(5):
        for batch in train_loader:
            x = batch[0].to(device)
            z_e = encoder(x).detach()
            # 最近码字
            d = torch.cdist(z_e.unsqueeze(1), codebook.weight.unsqueeze(0))
            codes = d.argmin(-1)
            # 损失: 让码字靠近被分配的 z_e
            loss = F.mse_loss(codebook(codes), z_e)
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()

    return codebook
```

### 4.11.2 训练时的监控

```python
class IndustrialCodebookManager:
    """工业级码本管理"""
    def __init__(self, num_codes, dim, decay=0.99, eps=1e-5,
                 warmup_steps=1000, reset_interval=200, usage_threshold=0.5):
        self.num_codes = num_codes
        self.dim = dim
        self.decay = decay
        self.eps = eps

        self.warmup_steps = warmup_steps
        self.reset_interval = reset_interval
        self.usage_threshold = usage_threshold

        # EMA 统计量
        self.cluster_size = torch.ones(num_codes)
        self.ema_w = None  # 后续初始化
        self.step = 0

    def update(self, z_e, codes):
        """EMA 更新码本"""
        self.step += 1
        onehot = F.one_hot(codes, self.num_codes).float()

        # 更新 cluster_size
        new_size = self.decay * self.cluster_size + (1 - self.decay) * onehot.sum(0)
        n = new_size.sum()
        self.cluster_size = (
            (new_size + self.eps) / (n + self.num_codes * self.eps) * n
        )

        # 更新 ema_w
        new_ema_w = self.decay * (self.ema_w if self.ema_w is not None else z_e.new_zeros(self.num_codes, self.dim)) + \
                    (1 - self.decay) * (onehot.T @ z_e)
        self.ema_w = new_ema_w

        return self.ema_w / self.cluster_size.unsqueeze(1)

    def should_reset(self):
        """判断是否应该重启"""
        if self.step < self.warmup_steps:
            return False
        return self.step % self.reset_interval == 0

    def reset_dead(self, z_e):
        """重启死码"""
        if not self.should_reset():
            return

        # 计算当前 batch 使用率
        d = torch.cdist(z_e.unsqueeze(1), self.ema_w.unsqueeze(0))
        codes = d.argmin(-1)
        usage = torch.bincount(codes, minlength=self.num_codes)

        # 找死码
        avg = usage.float().mean()
        dead_mask = usage.float() < self.usage_threshold * avg

        n_dead = dead_mask.sum().item()
        if n_dead > 0:
            # 用 z_e 的随机样本替换
            random_samples = z_e[torch.randperm(len(z_e))[:n_dead]]
            self.ema_w[dead_mask] = random_samples
            self.cluster_size[dead_mask] = 1.0
```

## 4.12 常见问题 FAQ

### Q1: 训练初期利用率低正常吗?

**答**: 正常。

训练初期码本还没稳定, 利用率可能只有 20-30%。

通常 5-10 epoch 后会恢复到 70%+。

### Q2: 利用率达到 100% 好吗?

**答**: 不一定。

100% 利用率可能是:
- 真好: 所有码字都被使用
- 假象: 训练数据少, 码字被强制使用

需要结合熵和训练数据量判断。

### Q3: 重启频率怎么选?

**答**: 默认 200 步一次。

- 训练初期: 频繁 (50-100 步)
- 训练后期: 较少 (500-1000 步)

### Q4: 重启用什么样本?

**答**: 用当前 batch 的样本。

不要用码本自身的复制, 容易重复坍塌。

### Q5: K-Means 初始化必要吗?

**答**: 强烈推荐。

K-Means 初始化让训练起点合理, 大幅减少坍塌概率。

工业实践: 不初始化 = 90% 概率坍塌, 初始化 = 10% 概率坍塌。

### Q6: 能不能用其他聚类算法?

**答**: 可以。

- K-Means: 最常用
- K-Means++: 更好的初始化
- Mini-Batch K-Means: 大规模
- GMM: 更灵活, 慢

工业推荐: Mini-Batch K-Means。

### Q7: 码本利用率和训练 loss 哪个重要?

**答**: 都重要, 但利用率更重要。

低利用率 = 训练失败。

低 loss 但低利用率 = 假象 (码本只用了 10%, 重建可能还行)。

### Q8: 监控频率怎么选?

**答**: 每 100-500 步一次。

- 太频繁: 计算开销
- 太稀少: 错过问题

```python
class DynamicSizeCodebook(nn.Module):
    """动态调整码本大小"""
    def __init__(self, initial_size=256, max_size=1024):
        super().__init__()
        self.current_size = initial_size
        self.max_size = max_size
        self.codebook = nn.Embedding(max_size, dim)

    def expand_if_needed(self, usage_threshold=0.8):
        """当利用率高时, 扩展码本"""
        usage_ratio = compute_usage_ratio(self)
        if usage_ratio > usage_threshold and self.current_size < self.max_size:
            # 扩展: 复制高频码字并加噪声
            n_new = min(self.max_size - self.current_size, self.current_size // 4)
            high_freq_indices = torch.topk(usage, n_new).indices
            for i, idx in enumerate(high_freq_indices):
                self.codebook.weight.data[self.current_size + i] = \
                    self.codebook.weight.data[idx] + 0.01 * torch.randn_like(self.codebook.weight.data[idx])
            self.current_size += n_new
```

### 4.18.2 码字合并

如果两个码字太近, 合并它们:

```python
@torch.no_grad()
def merge_close_codes(model, threshold=0.1):
    """合并相近的码字"""
    codebook = model.codebook.weight
    n = codebook.size(0)

    # 计算距离矩阵
    dists = torch.cdist(codebook, codebook)

    # 找太近的码字对
    close_mask = (dists < threshold) & (dists > 0)
    close_pairs = close_mask.nonzero()

    # 合并 (保留一个)
    merged = set()
    for i, j in close_pairs:
        if i.item() not in merged and j.item() not in merged:
            # 平均
            codebook.data[i] = (codebook[i] + codebook[j]) / 2
            codebook.data[j] = codebook.data[i]
            merged.add(j.item())
```

```python
@torch.no_grad()
def prune_unused_codes(model, min_usage=0.01):
    """删除使用率过低的码字"""
    usage = model.vq.usage_count
    used_mask = usage > min_usage
    n_used = used_mask.sum().item()

    if n_used < model.codebook.num_embeddings * 0.5:
        # 太少, 不剪枝
        return

    # 保留使用率高的码字

    new_codebook.weight.data.copy_(model.codebook.weight[keep_indices])

    # 替换
    model.codebook = new_codebook.to(model.codebook.weight.device)
```

## 4.19 工业级码本管理完整代码

```python
class IndustrialCodebookManager:
    """工业级码本管理: K-Means 初始化 + EMA 更新 + 监控 + 重启"""
    def __init__(self, num_codes, dim, decay=0.99, eps=1e-5,
                 warmup_steps=1000, reset_interval=200,
                 usage_threshold=0.5, enable_kmeans_init=True):
        self.num_codes = num_codes
        self.dim = dim
        self.decay = decay
        self.eps = eps

        self.warmup_steps = warmup_steps
        self.reset_interval = reset_interval
        self.usage_threshold = usage_threshold
        self.enable_kmeans_init = enable_kmeans_init

        # EMA 统计量
        self.codebook = nn.Embedding(num_codes, dim)
        self.register_buffer('cluster_size', torch.ones(num_codes))
        self.register_buffer('ema_w', self.codebook.weight.data.clone())
        self.register_buffer('usage_count', torch.zeros(num_codes))
        self.register_buffer('step', torch.tensor(0))

    def init_with_kmeans(self, encoder, dataloader):
        """K-Means 初始化"""
        if not self.enable_kmeans_init:
            return

        print("Running K-Means initialization...")
        z_e_list = []
        encoder.eval()
        with torch.no_grad():
            for batch in dataloader:
                x = batch[0].to(device)
                z_e_list.append(encoder(x).cpu())
        z_e_all = torch.cat(z_e_list, dim=0).numpy()

        from sklearn.cluster import MiniBatchKMeans
        kmeans = MiniBatchKMeans(
            n_clusters=self.num_codes,
            batch_size=1024,
            n_init=3,
            random_state=42
        )
        kmeans.fit(z_e_all)

        self.codebook.weight.data.copy_(
            torch.from_numpy(kmeans.cluster_centers_).float()
        )
        self.ema_w.data.copy_(self.codebook.weight.data)
        print(f"K-Means init done. Inertia: {kmeans.inertia_:.2f}")

    def update(self, z_e, codes):
        """EMA 更新码本"""
        self.step += 1
        B = z_e.size(0)

        with torch.no_grad():
            onehot = F.one_hot(codes, self.num_codes).float()

            # 更新 cluster_size
            new_size = self.decay * self.cluster_size + (1 - self.decay) * onehot.sum(0)
            n = new_size.sum()
            self.cluster_size = (
                (new_size + self.eps) / (n + self.num_codes * self.eps) * n
            )

            # 更新 ema_w
            self.ema_w = self.decay * self.ema_w + (1 - self.decay) * (onehot.T @ z_e)

            # 写入码本
            self.codebook.weight.data.copy_(
                self.ema_w / self.cluster_size.unsqueeze(1)
            )

            # 更新使用次数
            self.usage_count = 0.99 * self.usage_count + 0.01 * onehot.sum(0)

    def reset_dead(self, z_e):
        """重启死码"""
        if self.step < self.warmup_steps:
            return

        if self.step % self.reset_interval != 0:
            return

        avg = self.usage_count.float().mean()
        dead_mask = self.usage_count.float() < self.usage_threshold * avg

        n_dead = dead_mask.sum().item()
        if n_dead > 0:
            # 用 z_e 的随机样本替换
            random_samples = z_e[torch.randperm(len(z_e))[:n_dead]]
            self.codebook.weight.data[dead_mask] = random_samples
            self.ema_w[dead_mask] = random_samples
            self.cluster_size[dead_mask] = 1.0
            self.usage_count[dead_mask] = 1.0

            print(f"[Step {self.step}] 重启 {n_dead} 个死码")

    def get_metrics(self):
        """获取监控指标"""
        used = (self.usage_count > 0.01).float().sum().item()
        usage_ratio = used / self.num_codes

        # 熵
        p = self.usage_count / (self.usage_count.sum() + 1e-10)
        entropy = -(p * torch.log(p + 1e-10)).sum().item()
        max_entropy = torch.log(torch.tensor(float(self.num_codes)))
        normalized_entropy = entropy / max_entropy

        return {
            "usage_ratio": usage_ratio,
            "entropy": normalized_entropy,
            "max_usage": self.usage_count.max().item(),
            "min_usage": self.usage_count.min().item(),
        }
```

## 4.23 死码重启的高级策略

### 4.23.1 智能选择替换样本

不是所有 z_e 都适合替换死码。最好的策略是选 batch 中"远离活码"的样本:

```python
@torch.no_grad()
def reset_dead_smart(model, z_e, threshold=0.5):
    """智能重启: 选远离活码的样本"""
    # 1. 计算每个 z_e 到最近活码的距离
    active_mask = model.usage_count > threshold * model.usage_count.mean()
    active_codes = model.codebook.weight[active_mask]

    if len(active_codes) == 0:
        return  # 没有活码,无法比较

    # 2. 找死码
    dead_mask = ~active_mask
    n_dead = dead_mask.sum().item()

    if n_dead == 0:
        return

    # 3. 计算 z_e 到最近活码的距离
    d = torch.cdist(z_e.unsqueeze(1), active_codes.unsqueeze(0))  # [B, n_active]
    min_d_to_active = d.min(-1).values  # [B]

    # 4. 选距离最大的 n_dead 个样本
    top_indices = torch.topk(min_d_to_active, n_dead).indices

    # 5. 替换
    random_samples = z_e[top_indices]
    model.codebook.weight.data[dead_mask] = random_samples
    model.ema_w[dead_mask] = random_samples
    model.cluster_size[dead_mask] = 1.0
    model.usage_count[dead_mask] = 1.0
```

**优点**: 替换的样本"远离"现有码字, 增加多样性。

### 4.23.2 渐进式重启

不要一次性重启所有死码, 逐步重启:

```python
@torch.no_grad()
def reset_dead_progressive(model, z_e, max_per_step=10, threshold=0.5):
    """渐进式重启: 每次最多重启 max_per_step 个"""
    dead_mask = model.usage_count < threshold * model.usage_count.mean()
    dead_indices = dead_mask.nonzero().squeeze(-1)

    if len(dead_indices) == 0:
        return 0

    # 限制每次重启数量
    if len(dead_indices) > max_per_step:
        # 优先重启最久没用的
        dead_indices = dead_indices[
            torch.argsort(model.usage_count[dead_indices])
        ][:max_per_step]

    # 替换
    random_samples = z_e[torch.randperm(len(z_e))[:len(dead_indices)]]
    model.codebook.weight.data[dead_indices] = random_samples
    model.ema_w[dead_indices] = random_samples
    model.cluster_size[dead_indices] = 1.0
    model.usage_count[dead_indices] = 1.0

    return len(dead_indices)
```

### 4.23.3 软重启 (Soft Reset)

不完全替换, 而是把死码"拉向"最近的 z_e:

```python
@torch.no_grad()
def soft_reset(model, z_e, alpha=0.5, threshold=0.5):
    """软重启: 把死码拉向最近 z_e"""
    dead_mask = model.usage_count < threshold * model.usage_count.mean()
    dead_indices = dead_mask.nonzero().squeeze(-1)

    if len(dead_indices) == 0:
        return

    # 对每个死码, 找最近的 z_e
    for idx in dead_indices:
        d = torch.norm(z_e - model.codebook.weight.data[idx], dim=-1)
        nearest_idx = d.argmin()
        # 朝最近的 z_e 移动 alpha 步
        model.codebook.weight.data[idx] = (
            (1 - alpha) * model.codebook.weight.data[idx] +
            alpha * z_e[nearest_idx]
        )
        model.ema_w[idx] = model.codebook.weight.data[idx]
```

**优点**: 比硬重启更稳定, 不破坏训练。

### 4.24.5 分子 / 化学结构

- 复杂的离散空间
- 可能需要非常大的码本 (>10000)

### 4.27.1 RQ-VAE 中的坍塌

```python
    def __init__(self, num_layers, num_codes_per_layer):
```

### 4.27.3 RQ-VAE 的特殊重启

```python
@torch.no_grad()
def reset_dead_rq(rq_model, z_e_batch):
    """RQ-VAE 逐层重启"""
    residual = z_e_batch
    for i, vq in enumerate(rq_model.vqs):
        # 当前层的 VQ
        d = torch.cdist(residual.unsqueeze(1), vq.codebook.weight.unsqueeze(0))
        codes = d.argmin(-1)
        z_q = vq.codebook(codes)

        # 重启该层的死码
        vq.reset_dead_codes(residual)

        # 更新残差
        residual = residual - z_q.detach()

        # 检查残差的范数
        if residual.norm(dim=-1).mean() < 0.01:
            print(f"Layer {i}: 残差已很小, 无需更多层")
            break
```

```python
@torch.no_grad()
def compute_usage_ratio(model, dataloader):
    usage = torch.zeros(model.codebook.num_embeddings)
    model.eval()
    for batch in dataloader:
        x = batch[0].to(device)
        z_e = model.encoder(x)
        codes = model.vq(z_e)[1]
        for c in codes.flatten():
            usage[c] += 1

# 重启死码
@torch.no_grad()
def reset_dead(model, z_e, threshold=1.0):
    d = torch.cdist(z_e.unsqueeze(1), model.codebook.weight.unsqueeze(0))
    codes = d.argmin(-1)
    usage = torch.bincount(codes, minlength=model.codebook.num_embeddings)
    dead = usage < threshold
    if dead.any():
        model.codebook.weight.data[dead] = z_e[torch.randperm(len(z_e))[:dead.sum()]]
```

## 4.33 章节补充: 监控与可观测性

### 4.33.1 完整监控指标

一个完整的 VQ-VAE 监控系统应该追踪以下指标:

```python
class VQVAEMonitor:
    """完整的 VQ-VAE 监控器"""
    def __init__(self, num_codes, log_interval=100):
        self.num_codes = num_codes
        self.log_interval = log_interval
        self.history = defaultdict(list)
        self.tb_writer = SummaryWriter("runs/vqvae")

    def log(self, step, model, dataloader):
        if step % self.log_interval != 0:
            return

        # 1. 利用率
        usage = compute_usage(model, dataloader)
        usage_ratio = (usage > 0).float().mean().item()
        self.history["usage_ratio"].append((step, usage_ratio))
        self.tb_writer.add_scalar("codebook/usage_ratio", usage_ratio, step)

        # 2. 熵
        p = usage / (usage.sum() + 1e-10)
        entropy = -(p * torch.log(p + 1e-10)).sum().item()
        max_entropy = np.log(self.num_codes)
        normalized_entropy = entropy / max_entropy
        self.history["entropy"].append((step, normalized_entropy))
        self.tb_writer.add_scalar("codebook/entropy", normalized_entropy, step)

        # 3. 使用次数直方图
        self.tb_writer.add_histogram("codebook/usage_dist", usage, step)

        # 4. 码字范数分布
        norms = model.codebook.weight.norm(dim=-1)
        self.tb_writer.add_histogram("codebook/norms", norms, step)

        # 5. 码字两两距离
        dists = torch.cdist(model.codebook.weight, model.codebook.weight)
        mask = ~torch.eye(self.num_codes, dtype=torch.bool, device=dists.device)
        avg_dist = dists[mask].mean().item()
        self.history["avg_pairwise_dist"].append((step, avg_dist))
        self.tb_writer.add_scalar("codebook/avg_pairwise_dist", avg_dist, step)

        # 6. z_e 范数
        z_e_norms = []
        model.eval()
        with torch.no_grad():
            for batch in dataloader:
                x = batch[0].to(device)
                z_e = model.encoder(x)
                z_e_norms.append(z_e.norm(dim=-1))
        z_e_norms = torch.cat(z_e_norms)
        self.tb_writer.add_histogram("z_e/norms", z_e_norms, step)

        # 7. 重建 loss (可以加在训练循环中)
        # 这里省略

    def summary(self):
        """打印最近指标"""
        if not self.history["usage_ratio"]:
            return
        step, usage = self.history["usage_ratio"][-1]
        _, entropy = self.history["entropy"][-1]
        _, avg_dist = self.history["avg_pairwise_dist"][-1]

        print(f"[Step {step}] usage={usage:.2%}, entropy={entropy:.2%}, avg_dist={avg_dist:.4f}")
```

### 4.33.2 报警与自动重启

```python
class AutoRestartManager:
    """自动重启管理器"""
    def __init__(self, threshold=0.5, min_interval=200, alert_callback=None):
        self.threshold = threshold
        self.min_interval = min_interval
        self.last_reset_step = 0
        self.alert_callback = alert_callback

    def should_reset(self, step, model, dataloader):
        if step - self.last_reset_step < self.min_interval:
            return False

        usage = compute_usage_ratio(model, dataloader)
        if usage < self.threshold:
            if self.alert_callback:
                self.alert_callback(step, usage)
            return True
        return False

    def reset(self, model, z_e, step):
        n_reset = reset_dead_smart(model, z_e, threshold=self.threshold)
        self.last_reset_step = step
        print(f"[Auto-restart] Step {step}: 重启 {n_reset} 个死码")

# 使用
def alert_handler(step, usage):

    min_interval=200,
    alert_callback=alert_handler,
```

```python
class CodebookGenerator(nn.Module):
    """用 GAN 生成新码字 (探索性)"""

        super().__init__()
        self.num_codes = num_codes
        self.dim = dim
        self.noise_dim = noise_dim

        # 生成器: noise -> 码字
        self.generator = nn.Sequential(
            nn.Linear(noise_dim, 128), nn.ReLU(),
            nn.Linear(128, dim),
```
