## 1.4 用 LLM (如 Qwen) 提取 embedding

```python
from transformers import AutoModel
import torch

# 加载 Qwen
model = AutoModel.from_pretrained('Qwen/Qwen2-7B', device_map='cuda')
tokenizer = AutoTokenizer.from_pretrained('Qwen/Qwen2-7B')

# Last token pooling
def get_qwen_embedding(text):
    inputs = tokenizer(text, return_tensors='pt', truncation=True, max_length=512).to('cuda')
    with torch.no_grad():
        outputs = model(**inputs)
    # Last token 的 hidden state
    return outputs.last_hidden_state[0, -1, :].cpu().numpy()  # [4096]
```

## A.1 为什么需要"文本驱动 SID"——动机再述

文本驱动 SID 是 SID 家族里**最朴素**的一支，但它并非"过时的兜底方案"，而是有清晰的适用边界：

| 场景 | 文本驱动 SID 是否合适 | 备注 |
| :--- | :--- | :--- |
| 全新平台 / 全新业务（**零行为**） | ✅ 唯一可用 | 没有点击日志，只能用内容 |
| 行为稀疏的垂直类目（如 B 端工业品、医药） | ✅ 主用 | 用户行为本身就少 |
| 内容丰富、文本质量高（图书、新闻） | ✅ 主用 | 标题/摘要/正文本身就是强语义 |
| 短标题 + 强行为（短视频、电商主图） | ⚠️ 辅助 | 文本弱、行为强，应让位 |
| **纯视觉**品类（表情包、滤镜素材） | ❌ 失效 | 需走 §2 多模态融合 |

> **实战忠告**：文本驱动 SID 看起来"傻"，但在冷启动期是**最稳**的方案。永远不要在 0 行为数据时强上协同 SID。

## A.2 文本预处理：把"杂乱字段"压成"一段话"

### A.2.1 字段拼接的原则

物品的元数据往往有几十个字段（标题、品牌、类目、描述、SKU、属性、标签、价格、营销文案……），但**全字段拼入并不一定更好**。需要遵守三个原则：

1. **层次清晰**：用 `:` 区分字段名与字段值，用 `|` 分隔字段。
2. **长度可控**：拼好后建议 $\le 256$ token，否则 BERT 类模型前 128 token 会吃掉所有信息。
3. **去噪**：HTML 标签、特殊字符、表情、URL 应清洗掉。

### A.2.2 进阶：模板化 vs 自由拼接

| 方式 | 优点 | 缺点 |
| :--- | :--- | :--- |
| **模板化**（`标题: X \| 品牌: Y \| 类目: Z`） | 易于 LLM 识别字段边界 | 长尾字段被截断 |
| **自由拼接**（`X Y Z`） | 充分利用上下文窗口 | 字段间关系模糊 |
| **JSON 序列化** | 结构完整 | token 数翻倍，触发截断 |

**工业建议**：模板化为主，关键字段再展开描述。例如：

```python
def build_item_text_v2(item, max_len=512):
    """v2: 模板化 + 关键字段展开 + 长度截断"""
    parts = []

    # 1) 必填字段先填
    if item.get('title'):
        parts.append(f"标题: {item['title']}")
    if item.get('brand'):
        parts.append(f"品牌: {item['brand']}")
    if item.get('category_path'):
        # 类目路径, 如 "手机/智能手机/苹果"
        parts.append(f"类目: {'/'.join(item['category_path'])}")

    # 2) 强语义字段
    if item.get('tags'):
        parts.append(f"标签: {', '.join(item['tags'][:10])}")
    if item.get('description'):
        # 描述只取前 200 字
        parts.append(f"描述: {item['description'][:200]}")

    # 3) 价格/销量用结构化字段, 不用自然语言
    if item.get('price') is not None:
        parts.append(f"价格: {item['price']}元")

    text = ' | '.join(parts)
    # 截断到 max_len 字符, 避免 BERT 截断
    return text[:max_len]
```

### A.2.3 处理特殊类目

| 类目 | 文本特点 | 处理建议 |
| :--- | :--- | :--- |
| **图书** | 长描述、作者、ISBN | 截取前 100 字描述 + 作者 + 出版社 |
| **服装** | 颜色尺码、面料、款式 | 拆成结构化属性（颜色/尺码/面料/风格） |
| **3C 数码** | 配置参数多（CPU/内存/存储） | 用 KV 形式拼装，避免自然语言化 |
| **生鲜** | 产地、保质期、规格 | 产地 + 品类 + 规格 |
| **服务类**（机票/酒店） | 地点、时间、星级 | 出发地+目的地+星级+房型 |

## A.3 Sentence-Transformers 全套使用

### A.3.1 模型选择

| 模型 | 维度 | 大小 | 语言 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| `all-MiniLM-L6-v2` | 384 | 80 MB | 英文 | 英文轻量基线 |
| `all-mpnet-base-v2` | 768 | 420 MB | 英文 | 英文高质量 |
| `paraphrase-multilingual-MiniLM-L12-v2` | 384 | 470 MB | 多语 | 跨语言轻量 |
| `BAAI/bge-large-zh-v1.5` | 1024 | 1.3 GB | 中文 | 中文高质量（**首选**） |
| `BAAI/bge-large-en-v1.5` | 1024 | 1.3 GB | 英文 | 英文高质量 |
| `BAAI/bge-m3` | 1024 | 2.2 GB | 多语 | 多语 + 稠密检索 SOTA |

### A.3.2 完整 Pipeline

```python
from sentence_transformers import SentenceTransformer
import numpy as np
from typing import List, Dict
import torch

class TextToEmbedding:
    def __init__(self, model_name='BAAI/bge-large-zh-v1.5', device='cuda', batch_size=256):
        self.model = SentenceTransformer(model_name, device=device)
        self.batch_size = batch_size
        self.model.eval()

    @torch.no_grad()
    def encode(self, texts: List[str], normalize: bool = True) -> np.ndarray:
        """
        Args:
            texts: 文本列表
            normalize: 是否 L2 normalize (用于余弦相似度)
        Returns:
            [N, D] 的 numpy 数组
        """
        embeddings = self.model.encode(
            texts,
            batch_size=self.batch_size,
            show_progress_bar=True,
            normalize_embeddings=normalize,  # L2 normalize
            convert_to_numpy=True,
        )
        return embeddings  # [N, 1024]

# 使用
encoder = TextToEmbedding('BAAI/bge-large-zh-v1.5')
emb = encoder.encode([
    "标题: iPhone 15 256GB 黑色 | 品牌: 苹果 | 类目: 手机",
    "标题: Galaxy S24 256GB 蓝色 | 品牌: 三星 | 类目: 手机",
])
print(emb.shape)  # [2, 1024]
```

| 物品量 | 单卡 A100 时间 | 建议 |
| :--- | :--- | :--- |
| 100 万 | ~10 分钟 | 单卡 batch 256 |
| 1000 万 | ~2 小时 | 单卡 batch 512 / 多卡 |
| 1 亿 | ~20 小时 | 8 卡并行 / 蒸馏小模型 |

## A.4 用 LLM 提取 embedding

### A.4.1 为什么不用 LLM？

| 维度 | Sentence-BERT | LLM (Qwen/Llama) |
| :--- | :--- | :--- |
| 速度 | 快（1000+ qps） | 慢（50-100 qps） |
| 显存 | 低（1-2 GB） | 高（14 GB+） |
| 语义质量 | 中 | 高 |
| **冷启动长尾** | **差** | **好** |
| 可解释 | ❌ | ✅（可看 attention） |

**核心优势**：LLM 对**低资源/长尾**文本的理解能力远超 BERT。

### A.4.2 完整 Qwen 实现

```python
from transformers import AutoModel, AutoTokenizer
import torch
import numpy as np

class QwenEmbedding:
    def __init__(self, model_name='Qwen/Qwen2-1.5B', device='cuda', dtype=torch.float16):
        """
        推荐 1.5B 而不是 7B: 显存可控, 速度快 4 倍, 语义质量损失 < 1%。
        """
        self.tokenizer = AutoTokenizer.from_pretrained(model_name)
        self.model = AutoModel.from_pretrained(
            model_name,
            torch_dtype=dtype,
            device_map='cuda',
        ).eval()
        self.device = device

    @torch.no_grad()
    def encode(self, texts: List[str], max_length: int = 512) -> np.ndarray:
        # 1) Tokenize
        inputs = self.tokenizer(
            texts,
            padding=True,
            truncation=True,
            max_length=max_length,
            return_tensors='pt',
        ).to(self.device)

        # 2) Forward
        outputs = self.model(**inputs, output_hidden_states=False)
        last_hidden = outputs.last_hidden_state  # [B, T, D]

        # 3) Last-token pooling (decoder-only 模型)
        # 取每行最后一个有效 token 的 hidden state
        seq_lens = inputs.attention_mask.sum(dim=1) - 1  # [B]
        embeddings = last_hidden[torch.arange(last_hidden.size(0)), seq_lens]

        # 4) L2 normalize
        embeddings = embeddings / embeddings.norm(dim=-1, keepdim=True).clamp(min=1e-9)

        return embeddings.cpu().numpy()

    @torch.no_grad()
    def encode_batch(self, texts: List[str], batch_size: int = 32) -> np.ndarray:
        """大批量分批推理"""
        all_emb = []
        for i in range(0, len(texts), batch_size):
            batch = texts[i:i + batch_size]
            emb = self.encode(batch)
            all_emb.append(emb)
        return np.concatenate(all_emb, axis=0)


# 使用
encoder = QwenEmbedding('Qwen/Qwen2-1.5B')
texts = ["标题: iPhone 15 256GB 黑色 | 品牌: 苹果 | 类目: 手机"]
emb = encoder.encode(texts)  # [1, 1536]
```

### A.4.3 Last-token Pooling 的正确性

为什么 LLM 适合用 **last token pooling** 而不是 [CLS] / mean pooling？

| 方式 | 公式 | LLM 适用性 |
| :--- | :--- | :--- |
| [CLS] pooling | $h_{[\text{CLS}]}$ | ❌ LLM 无 [CLS] |
| Mean pooling | $\bar{h} = \frac{1}{T}\sum_t h_t$ | ⚠️ 受 padding 影响 |
| **Last token** | $h_{T}$ | ✅ 因果注意力保证了 $h_T$ 看到全部上文 |
| First token | $h_1$ | ❌ 仅看到第一个 token |

数学证明：

因果自回归 LLM 的第 $T$ 个 token 满足：

$$h_T = \text{Attention}(h_T; \{h_1, h_2, \dots, h_T\})$$

即 $h_T$ 通过多头注意力"加权求和"了**所有**之前位置的 hidden state，是一个**充分统计量**。因此 last token pooling 是 LLM 的最优选择。

> ⚠️ 注意：句子最后一个 token 通常是 EOS，必须保证 `attention_mask` 计算的 `seq_len - 1` 真的指向 EOS，否则要手动查找 `tokenizer.eos_token_id` 的位置。

## A.5 多语言与跨语言 embedding

### A.5.1 多语对齐基础

训练 Sentence-BERT 多语模型时，**双语平行句对**通过对比学习让两语言在共享空间里"靠在一起"：

$$\mathcal{L}_{\text{multi}} = -\log \frac{e^{\cos(f(x_i), f(x_i^+))/\tau}}{\sum_{j} e^{\cos(f(x_i), f(x_j))/\tau}}$$

其中 $x_i, x_i^+$ 是同义不同语言的句子（"iPhone 15" vs "iPhone 15"）。

### A.5.2 工业实践

```python
# 1) 选定多语模型
model = SentenceTransformer('sentence-transformers/distiluse-base-multilingual-cased-v2')  # 512 维
# 或更强: 'BAAI/bge-m3' (1024 维, 多语 SOTA)

# 2) 跨语言检索测试
cn = ["iPhone 15 256GB 黑色"]
en = ["iPhone 15 256GB Black"]
ja = ["iPhone 15 256GB ブラック"]
emb_cn = model.encode(cn)
emb_en = model.encode(en)
emb_ja = model.encode(ja)

# 三者余弦相似度
from numpy.linalg import norm
def cos(a, b): return (a @ b) / (norm(a) * norm(b))
print(cos(emb_cn[0], emb_en[0]))  # ~0.92
print(cos(emb_cn[0], emb_ja[0]))  # ~0.85
```

### A.5.3 跨语 SID 的坑

1. **小语种数据稀缺**：缅甸语、老挝语等小语种效果差。
2. **代码混合**（Code-Mixing）：中文+英文混杂的 query，embedding 偏移。
3. **品牌专名歧义**：英文品牌在中文语料里被翻译成"苹果"，但用户可能搜 Apple。

**对策**：多语模型 + 品牌词典 + 翻译回写。

## A.6 文本驱动的三大局限——深度分析

### A.6.1 无语义层次

文本 embedding 在向量空间里是**平铺的**：

```text
[1024 dim 连续向量]
   ↓ 没有"类目/品牌/型号"的分层
```

而 SID 是**离散码序列**：

```text
SID = (c1, c2, c3, c4, c5)  # 类目码, 品牌码, 系列码, 配置码, 颜色码
```

文本 embedding 本身没有这种层次结构，需通过 RQ-VAE 在**训练中**学到。

### A.6.2 长尾物品描述质量差

| 物品类型 | 文本长度 | 文本质量 | 文本驱动 SID 表现 |
| :--- | :--- | :--- | :--- |
| 头部品牌（iPhone） | 长（500+字） | 高（专业编辑） | 优 |
| 长尾白牌 | 短（< 50 字） | 低（用户自填） | 差 |
| 图文为主（小红书笔记） | 文本补充 | 中 | 中 |

**根本问题**：文本是"用户/编辑写的"，分布偏斜，长尾物品的文本**代表性不足**。

### A.6.3 无协同信号

最关键的局限：文本驱动 SID **完全不知道用户喜欢什么**。

例如：

- 物品 A（iPhone 15）和物品 B（小米 14）文本相似度 = 0.92（都是手机）
- 但购买 iPhone 的人通常不点小米，反之亦然
- 文本驱动 SID 会把它们放到同一桶，召回时混淆

→ **必须**叠加协同信号（见 §3 行为增强的 SID）。

### A.7.2 完整可运行示例

```python
"""
text_to_sid_pipeline.py
文本驱动 SID 的端到端 pipeline (教学版)
"""
import os
import numpy as np
import torch
import torch.nn as nn
import torch.nn.functional as F
from sentence_transformers import SentenceTransformer
from typing import List, Dict


# ===== Step 1: 文本预处理 =====
def build_item_text(item: Dict) -> str:
    parts = []
    if item.get('title'):
        parts.append(f"标题: {item['title']}")
    if item.get('brand'):
        parts.append(f"品牌: {item['brand']}")
    if item.get('category'):
        parts.append(f"类目: {item['category']}")
    if item.get('description'):
        parts.append(f"描述: {item['description']}")
    return ' | '.join(parts)


# ===== Step 2: 文本 → embedding =====
class TextEmbedder:
    def __init__(self, model_name='BAAI/bge-large-zh-v1.5', device='cuda'):
        self.model = SentenceTransformer(model_name, device=device)
        self.model.eval()

    @torch.no_grad()
    def encode(self, texts: List[str], bs: int = 256) -> np.ndarray:
        return self.model.encode(texts, batch_size=bs,
                                 normalize_embeddings=True,
                                 convert_to_numpy=True)


# ===== Step 3: RQ-VAE 量化 (内容侧) =====
class RQCodebook(nn.Module):
    """单层码本"""
    def __init__(self, num_codes: int, dim: int):
        super().__init__()
        self.embedding = nn.Embedding(num_codes, dim)
        nn.init.uniform_(self.embedding.weight, -1.0/num_codes, 1.0/num_codes)

    def forward(self, z):
        # z: [B, D]
        dist = torch.cdist(z.unsqueeze(1), self.embedding.weight.unsqueeze(0))  # [B, 1, K]
        code = dist.argmin(dim=-1).squeeze(1)  # [B]
        q = self.embedding(code)  # [B, D]
        return code, q


class RQVAE(nn.Module):
    """残差量化 VAE (简化版)"""
    def __init__(self, in_dim: int = 1024, hidden: int = 128,
                 num_codes: int = 256, num_layers: int = 5, beta: float = 0.25):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(in_dim, hidden),
            nn.ReLU(),
            nn.Linear(hidden, hidden),
        )
        self.codebooks = nn.ModuleList(
            [RQCodebook(num_codes, hidden) for _ in range(num_layers)]
        )
        self.decoder = nn.Sequential(
            nn.Linear(hidden, hidden),
            nn.ReLU(),
            nn.Linear(hidden, in_dim),
        )
        self.beta = beta

    def forward(self, x):
        # x: [B, in_dim]
        z = self.encoder(x)
        residual = z
        codes = []
        commit_loss = 0.0
        for cb in self.codebooks:
            code, q = cb(residual)
            codes.append(code)
            commit_loss = commit_loss + F.mse_loss(residual.detach(), q) \
                                       + self.beta * F.mse_loss(residual, q.detach())
            residual = residual - q
        z_q = z - (z - residual).detach() + (residual).detach() - residual.detach()  # ST
        recon = self.decoder(z_q)
        recon_loss = F.mse_loss(recon, x)
        loss = recon_loss + commit_loss
        return torch.stack(codes, dim=-1), loss  # [B, L]


# ===== Step 4: 训练 =====
def train_rqvae(embs: np.ndarray, epochs: int = 50, bs: int = 512, lr: float = 1e-3):
    rqvae = RQVAE(in_dim=embs.shape[1], hidden=128, num_codes=256, num_layers=5)
    opt = torch.optim.Adam(rqvae.parameters(), lr=lr)
    embs_t = torch.from_numpy(embs).float().cuda()
    N = embs_t.size(0)

    for ep in range(epochs):
        perm = torch.randperm(N)
        total_loss = 0.0
        for i in range(0, N, bs):
            idx = perm[i:i+bs]
            _, loss = rqvae(embs_t[idx])
            opt.zero_grad()
            loss.backward()
            opt.step()
            total_loss += loss.item()
        if ep % 10 == 0:
            print(f"epoch {ep}: loss={total_loss / (N // bs):.4f}")
    return rqvae


# ===== Step 5: 推理 =====
@torch.no_grad()
def predict_sid(rqvae, embs: np.ndarray, bs: int = 1024) -> np.ndarray:
    rqvae.eval()
    embs_t = torch.from_numpy(embs).float().cuda()
    all_codes = []
    for i in range(0, embs_t.size(0), bs):
        codes, _ = rqvae(embs_t[i:i+bs])
        all_codes.append(codes.cpu().numpy())
    return np.concatenate(all_codes, axis=0)


# ===== Step 6: 端到端 =====
def main():

        {'title': 'iPhone 15 256GB 黑色', 'brand': '苹果', 'category': '手机',

        {'title': '小米 14 256GB 白色', 'brand': '小米', 'category': '手机',
```

### A.10.3 RQ-VAE 训练问题

| 坑 | 表现 | 解法 |
| :--- | :--- | :--- |
| **码本坍塌** | 90% 样本落同一码 | 加 entropy 正则 |
| **死码** | 部分码永远不被用 | EMA 更新码本 / 强制 reset |
| **层数过深** | 重建过拟合 | 监控验证集 MSE |
| **embedding 未归一化** | 码本大小不稳定 | 训练前 L2 normalize |

```python
# 抗坍缩正则
def codebook_diversity_loss(code_usage):
    """
    code_usage: [B, K] 软分配概率
    强制 marginal 接近均匀分布
    """
    avg_prob = code_usage.mean(0)  # [K]
    entropy = -(avg_prob * (avg_prob + 1e-9).log()).sum()
    return -entropy  # 最大化熵

# 死码检测
def detect_dead_codes(rqvae, threshold=10):
    """返回每个码本的"死码"列表"""
    dead = []
    for l, cb in enumerate(rqvae.codebooks):
        usage = cb.usage  # 假设你累计了 usage
        dead_codes = (usage < threshold).nonzero().squeeze().tolist()
        dead.append(dead_codes)
    return dead
```

## B.1 BERT 编码原理

### B.1.1 Tokenization

BERT 用 **WordPiece** 算法：

```python
from transformers import AutoTokenizer
tokenizer = AutoTokenizer.from_pretrained('bert-base-chinese')

text = "iPhone 15 真好用"
tokens = tokenizer.tokenize(text)
# ['ip', '##hone', '15', '真', '好', '用']
ids = tokenizer.convert_tokens_to_ids(tokens)
# [9743, 26309, 8158, 4696, 1962, 1905]

# BPE 编码
print(tokenizer.encode(text))  # [101, ..., 102]  (101=[CLS], 102=[SEP])
```

每个 token 转成 **embedding 向量** + **positional encoding** + **segment embedding**，三者相加后送入 Transformer。

### B.1.2 多头自注意力

$$h_i = \text{Attention}(Q_i, K_i, V_i) = \text{softmax}\left(\frac{Q_i K_i^T}{\sqrt{d_k}}\right) V_i$$

$$\text{MultiHead}(Q, K, V) = \text{Concat}(h_1, \dots, h_H) W^O$$

其中 $Q = X W^Q, K = X W^K, V = X W^V$，$X$ 是输入 hidden states。

### B.1.3 [CLS] token 设计

BERT 在每个序列开头加一个 `[CLS]` token，其最后一层 hidden state 被设计为**整个序列的句向量**：

$$h_{[\text{CLS}]}^{(L)} = \text{BERT}([\text{CLS}], t_1, \dots, t_n)$$

训练时通过 Next Sentence Prediction (NSP) 任务，让 $h_{[\text{CLS}]}$ 学会"句子级别"的语义。

### B.1.4 Mean Pooling vs [CLS] Pooling

| 方式 | 公式 | 优点 | 缺点 |
| :--- | :--- | :--- | :--- |
| **[CLS]** | $h_{[\text{CLS}]}$ | 句向量，直接用 | 训练目标偏 NSP，与相似度弱相关 |
| **Mean** | $\frac{1}{T}\sum_t h_t$ | 平均所有 token | 受 padding 影响 |
| **Mean (去 pad)** | $\frac{\sum_t h_t \cdot m_t}{\sum_t m_t}$ | 排除 padding | 实现稍复杂 |
| **Max** | $\max_t h_t$ | 抓突出特征 | 不稳定 |
| **Last 4 层拼接** | $[h_t^{(L)}; h_t^{(L-1)}; h_t^{(L-2)}; h_t^{(L-3)}]$ | 兼顾多层信息 | 维度 4× |

**Sentence-BERT** 默认用 Mean Pooling（去 pad），效果最稳。

## B.2 BGE 的对比学习目标

BGE 用 **RetroMAE / Contrastive Learning** 训练：

### B.2.1 对比损失

给定一个 batch 内的 $N$ 个样本 $(x_i, y_i)$，其中 $y_i$ 是 $x_i$ 的正样本（同义），其他 $x_j$ 是负样本：

$$\mathcal{L} = -\frac{1}{N}\sum_{i=1}^{N} \log \frac{e^{s(f(x_i), f(y_i))/\tau}}{\sum_{j=1}^{N} e^{s(f(x_i), f(y_j))/\tau}}$$

其中 $s(\cdot, \cdot) = \cos(f(\cdot), f(\cdot))$ 是余弦相似度，$\tau$ 是温度（默认 0.05）。

### B.2.2 难负样本挖掘

BGE 训练时用**难负样本**（hard negatives）——和正样本相似度高但实际负样本：

- **随机负样本**：batch 内其他样本
- **难负样本**：和 query 相似度 top-K 高的负样本

$$\mathcal{L}_{\text{hard}} = -\log \frac{e^{s(q, p)/\tau}}{e^{s(q, p)/\tau} + \sum_{k=1}^{K} e^{s(q, h_k)/\tau} + \sum_{j \neq i} e^{s(q, n_j)/\tau}}$$

### B.2.3 BGE 的多阶段训练

| 阶段 | 数据 | 目标 |
| :--- | :--- | :--- |
| 预训练 | Wikipedia + 通用语料 | MLM（Masked Language Model） |
| 对比微调 | 检索正负样本对 | 对比学习 |
| **指令微调** | (query, positive, instruction) 三元组 | 适应不同任务指令 |

BGE 的指令微调让它对 query 端有**意图理解**能力：

```python
# BGE 推荐用法 (v1.5+)
query = "iPhone 15 的电池续航怎么样"
query_with_instruction = "为这个句子生成表示以用于检索相关文章：" + query

passage = "iPhone 15 内置 3349 mAh 电池..."
# passage 不加 instruction

emb_q = model.encode([query_with_instruction])
emb_p = model.encode([passage])
# 两者相似度远高于 不加 instruction 的版本
```

## B.3 LLM embedding 的数学基础

### B.3.1 因果自回归语言模型

LLM 用 **Causal Masked Attention**（每个位置只能看自己及之前）：

$$\text{CausalAttn}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}} + M\right)V$$

其中 $M$ 是下三角 mask：

$$M_{ij} = \begin{cases} 0 & \text{if } i \ge j \\ -\infty & \text{if } i < j \end{cases}$$

### B.3.2 Last Token 的"充分统计性"证明

**命题**：在 Causal Attention 下，$h_T$ 是 $\{h_1, h_2, \dots, h_T\}$ 的**充分统计量**。

**证明**：

1. 设 attention 输出为 $a_T = \sum_{t=1}^T \alpha_t h_t$，其中 $\alpha_t = \text{softmax}_t(Q K^T/\sqrt{d})$
2. 经过 FFN + LayerNorm 后：$h_T = \text{LN}(\text{FFN}(a_T) + a_T)$
3. 由于 $a_T$ 是 $\{h_t\}_{t=1}^T$ 的**线性组合**，$h_T$ 保留了**所有**之前位置的信息

因此 $h_T$ 是**整句**的 embedding 表示。

### B.3.3 LLM embedding 的层次化现象

研究表明，LLM 的中间层 hidden state 编码了不同粒度的语义：

| 层数 | 语义 | 用途 |
| :--- | :--- | :--- |
| 1-4 层 | 词级别 | 词性标注 |
| 5-16 层 | 短语级别 | 命名实体识别 |
| 17-24 层 | 句子级别 | 句向量 |
| **last 层** | **整篇文档** | **句子相似度** |

BGE-M3 用**最后 4 层加权**作为 embedding，兼顾多层信息。

## B.4 RQ-VAE 的量化误差上界

### B.4.1 单层 VQ 的量化误差

设 $e \in \mathbb{R}^D$ 是输入 embedding，$c_1, \dots, c_K$ 是码字，最近邻量化后：

$$\hat{e} = c_{k^*}, \quad k^* = \arg\min_k \|e - c_k\|^2$$

**量化误差**：$\|e - \hat{e}\|^2 \le \|e - c_k\|^2$ 对所有 $k$，最小的是 $k^*$。

**上界**：当码本足够多且分布均匀时，量化误差 $\le \frac{\text{Var}(e)}{K}$（与码本大小成反比）。

### B.4.2 多层 RQ 的残差收敛

RQ-VAE 的总量化误差：

$$\|e - \hat{e}\|^2 = \|r_L\|^2$$

其中 $r_L$ 是第 $L$ 层之后的剩余残差。

**收敛性**：如果每层量化误差 $\le \epsilon$，则：

$$\|r_L\|^2 \le (1-\eta)^L \|e\|^2$$

其中 $\eta$ 是衰减因子（$\eta \in (0, 1)$）。当 $L \to \infty$，残差趋于 0。

**实际**：5 层 RQ 已足够把残差压到 $\|e\|^2$ 的 5% 以内。

### B.4.3 容量守恒

SID 的总表达力（不同 SID 的数量）是：

$$|\mathcal{S}| = \prod_{l=1}^L K_l$$

例如：5 层码本 K=256：$|\mathcal{S}| = 256^5 \approx 10^{12}$，远超千万级物品量。

**分配原则**：

| 物品量 | 推荐码本分配 | 总容量 |
| :--- | :--- | :--- |
| 100 万 | K=[512, 256, 256, 128, 64] | $2.7 \times 10^{11}$ |
| 1000 万 | K=[1024, 512, 256, 256, 128] | $4.4 \times 10^{12}$ |
| 1 亿 | K=[2048, 1024, 512, 512, 256] | $5.5 \times 10^{13}$ |

## B.5 训练技巧数学

### B.5.1 学习率调度

RQ-VAE 训练用 **warmup + cosine decay**：

$$\eta(t) = \begin{cases} \eta_0 \cdot \frac{t}{T_w} & t < T_w \\ \eta_0 \cdot 0.5 \cdot (1 + \cos(\frac{t - T_w}{T - T_w} \pi)) & t \ge T_w \end{cases}$$

其中 $T_w$ 是 warmup 步数（常 1000-5000），$T$ 是总步数。

### B.5.2 EMA 码本更新

为防止码本"漂移"，用 EMA 更新：

$$c_k^{(t+1)} = (1-\beta) c_k^{(t)} + \beta \bar{c}_k$$

其中 $\bar{c}_k$ 是当前 batch 中分配到码 $k$ 的 embedding 平均值，$\beta$ 是动量（0.9-0.99）。

### B.5.3 Dead Code Revival

死码（长期未使用的码）通过以下方式复活：

```python
def revive_dead_codes(rqvae, embs, dead_threshold=100):
    """找到 dead code, 用样本均值替换"""
    with torch.no_grad():
        for cb in rqvae.codebooks:
            usage = cb.usage  # [K]
            dead_mask = usage < dead_threshold

            if dead_mask.any():
                # 用随机样本替换
                n_dead = dead_mask.sum().item()
                random_idx = torch.randperm(embs.size(0))[:n_dead]
                cb.embedding.weight[dead_mask] = embs[random_idx]
                cb.usage[dead_mask] = dead_threshold
```

## B.6 推理侧数学

### B.6.1 向量距离度量

SID 推理时常需"找相似 SID"。度量：

| 度量 | 公式 | 适用 |
| :--- | :--- | :--- |
| **Hamming 距离** | $\sum_l \mathbb{1}[s_l \neq t_l]$ | 离散码 |
| **编辑距离** | Levenshtein | 序列 |
| **Jaccard** | $\frac{\|S \cap T\|}{\|S \cup T\|}$ | 集合 |
| **Embedding 余弦** | $\cos(\text{decode}(s), \text{decode}(t))$ | 还原后比较 |

**常用**：

```python
def hamming_distance(sid1, sid2):
    """sid1, sid2: [L]"""
    return (sid1 != sid2).sum()

def sid_to_embedding(sid, codebooks):
    """[L] → [D]"""
    return sum(codebooks[l].embedding[sid[l]] for l in range(len(sid)))
```

### B.6.2 前缀分桶

SID 的第一层码 $c_1$ 是"粗类"，用它做**前缀分桶**：

```python
def bucket_by_first_code(sids, num_buckets=256):
    """所有 SID 按 c1 分桶"""
    buckets = {i: [] for i in range(num_buckets)}
    for item_id, sid in enumerate(sids):
        buckets[sid[0]].append(item_id)
    return buckets

# 召回时:
# 1) 用户 query → SID_q
# 2) 优先从 bucket[SID_q[0]] 里找
# 3) 其次从相邻桶 (SID_q[0] ± 1) 里找
```

## C.2 增量更新

### C.2.1 问题

- 每天新增 1% 物品（百万级）
- 旧物品描述也可能变化（标题修改、价格调整）
- 不能每天都跑全量（成本太高）

### C.2.2 方案：双轨制

```text
全量更新: 每月 1 次, 用最新全量数据重训 RQ-VAE, 重新打 SID
         → 耗时长, 1 次/30 天

增量更新: 每天, 用已有 RQ-VAE 编码新物品 / 变化物品
         → 几十分钟, 1 次/1 天
```

```python
def incremental_encode(new_items, rqvae_path, output_path):
    """增量打 SID"""
    # 加载已有 RQ-VAE
    rqvae = torch.load(rqvae_path)
    rqvae.eval()

    # 增量 embedding
    embedder = TextEmbedder('BAAI/bge-large-zh-v1.5')
    texts = [build_item_text(it) for it in new_items]
    embs = embedder.encode(texts)

    # 增量 SID
    sids = predict_sid(rqvae, embs)

    # 落盘
    out = pd.DataFrame({
        'item_id': [it['item_id'] for it in new_items],
        'sid': sids.tolist(),
    })
    out.to_parquet(output_path)
```

### C.2.3 增量时的一致性

- 新物品用**旧码本**编码 → 可能落在死码附近
- 解决：**定期全量重训**（每月）+ 增量日志补全（每日）

## D.1 模型选择类

**Q1: BGE-large-zh 和 M3 怎么选？**

A:
- **BGE-large-zh**：单语中文，1024 维，效果最强，单 GPU 快。
- **BGE-M3**：多语，1024 维 + 多向量，跨语言 + 长文本最优，慢 2 倍。
- 业务只有中文 → `bge-large-zh`；有英文/小语种 → `bge-m3`。

**Q2: LLM embedding 真的比 BERT 强吗？**

A: 在**通用语料**上，BGE-large 已接近 LLM embedding 质量；在**垂直领域**（医疗/法律/工业），LLM 显著优于 BERT，原因是预训练数据更广。

**Q3: 用 LLaMA 还是 Qwen？**

A:
- 中文场景 → **Qwen2**（中文数据多）
- 英文场景 → **LLaMA-3** / Mistral
- 多语 → **Qwen2**（中英都好）

## D.2 训练类

**Q4: 物品量多少才够训练 RQ-VAE？**

A: 经验值：
- 物品数 $\ge 10^4$：可训，但可能欠拟合
- 物品数 $\ge 10^5$：基本可用
- 物品数 $\ge 10^6$：效果稳定

**Q5: 训练多少 epoch？**

A:
- 默认 50 epoch，配合 early stopping（验证集 10 epoch 不下降则停）
- 用 cosine LR schedule
- batch size 512，单卡 A100，1M 物品约 30 分钟

**Q6: 码本层数怎么选？**

A:
- L=3：表达力 $K^3$，适合 10 万级物品
- L=5：表达力 $K^5$，适合千万级（默认）
- L=8：表达力 $K^8$，适合亿级

## D.3 效果类

**Q7: 为什么文本驱动 SID 召回了不相关物品？**

A: 文本相似 ≠ 用户偏好。例如"iPhone 15"和"小米 14"文本相似，但用户群体不同。
→ 解决：叠加协同信号（§3）或升级到 HY-Token（§6）。

**Q8: 怎么评估 SID 质量？**

A: 3 个核心指标：
1. **重建 MSE**：embedding 还原质量（$\le 0.05$ 算好）
2. **码本利用率**：$\ge 90\%$（无大量死码）
3. **下游 Recall@K**：在线 A/B 真实收益（提升 $\ge 5\%$ 算显著）

**Q9: 新品为什么没被召回？**

A:
- SID 表里没这个 item → 检查增量更新 pipeline
- SID 表里有，但召回时没匹配上 → 检查分桶逻辑
- 内容驱动召回本身的局限 → 加协同信号

## D.6 调试类

**Q16: 训练 loss 不下降？**

A: 检查：
1. 学习率是否过大（$\ge 1e-2$）→ 降到 $1e-3$
2. embedding 是否归一化 → L2 normalize
3. 码本是否初始化太小 → $\sim 1/K$
4. beta 是否过大 → 试 0.1

**Q17: 死码太多？**

A:
1. 学习率过小 → 调大
2. 码本初始化与数据分布不匹配 → 用 KMeans 初始化
3. EMA 动量过大 → 调小到 0.9
4. 加 entropy 正则

**Q18: 重建 MSE 很低但下游效果差？**

A: 这是"过拟合 RQ-VAE"的典型症状：
1. 模型层数过多 → 减到 5 层
2. hidden 过大 → 减到 128
3. 训练 epoch 过多 → 加 early stopping
4. 加 dropout

## E.4 多样性约束

```python
def rerank_with_diversity(items, scores, sids, lambda_div=0.3):
    """MMR 重排, 兼顾相关性和多样性"""
    selected = []
    candidates = list(zip(items, scores))

    while candidates and len(selected) < 100:
        # MMR: argmax [score(i) - lambda * max_{j in selected} sim(i, j)]
        best_i = None
        best_score = -float('inf')
        for i, (item_i, score_i) in enumerate(candidates):
            # 与已选最大相似度
            max_sim = max([
                hamming_distance(sids[item_i], sids[item_j])
                for item_j in selected
            ]) if selected else 0
            mmr = score_i - lambda_div * max_sim
            if mmr > best_score:
                best_score = mmr
                best_i = i
        selected.append(candidates[best_i][0])
        candidates.pop(best_i)

    return selected
```

## A. 文本预处理 pipeline 详解

### A.1 多源文本融合

物品的文本可能来自多个字段(标题/描述/评论/标签),需要智能融合:

```python
class ItemTextBuilder:
    """多源文本构建器: 根据字段重要性加权融合。"""
    def __init__(self, field_weights=None):
        # 默认权重: 标题 1.0, 品牌 0.8, 类目 0.7, 描述 0.5
        self.field_weights = field_weights or {
            'title': 1.0,
            'brand': 0.8,
            'category': 0.7,
            'description': 0.5,
            'tags': 0.6,
            'reviews': 0.3
        }
        # 字段模板
        self.templates = {
            'title': '标题: {value}',
            'brand': '品牌: {value}',
            'category': '类目: {value}',
            'description': '描述: {value}',
            'tags': '标签: {value}',
            'reviews': '评价: {value}'
        }

    def build(self, item):
        """按权重融合多个字段。"""
        parts = []
        for field, weight in self.field_weights.items():
            if item.get(field):
                value = item[field]
                if weight >= 0.7:
                    # 高权重字段直接保留
                    parts.append(self.templates[field].format(value=value))
                else:
                    # 低权重字段截断到一定长度
                    parts.append(self.templates[field].format(value=value[:100]))
        return ' | '.join(parts)

    def build_weighted_concat(self, item, model):
        """用模型分别编码, 加权融合(更准但慢)。"""
        embs = []
        weights = []
        for field, weight in self.field_weights.items():
            if item.get(field):
                emb = model.encode(self.templates[field].format(value=item[field]))
                embs.append(emb)
                weights.append(weight)
        weights = np.array(weights) / sum(weights)
        return np.average(embs, axis=0, weights=weights)
```

```python
def is_valid_text(text, min_length=10, max_length=512, banned_keywords=None):
    """判断文本是否有效。"""
    if not text or len(text) < min_length:
        return False
    if len(text) > max_length:
        return False
    if banned_keywords and any(kw in text for kw in banned_keywords):
        return False
    # 检查关键词密度(防止堆砌)
    words = text.split()
    if len(words) > 5:
        unique_ratio = len(set(words)) / len(words)
        if unique_ratio < 0.3:  # 重复词太多
            return False
    return True
```

### B.2 Embedding Pooling 策略

不同模型的 pooling 方式:

```python
class EmbeddingExtractor:
    """统一接口: 不同模型的不同 pooling。"""
    def __init__(self, model_name='BAAI/bge-large-zh-v1.5', pooling='cls'):
        from sentence_transformers import SentenceTransformer
        self.model = SentenceTransformer(model_name)
        self.pooling = pooling

    def encode(self, texts, batch_size=256):
        """根据模型类型选择 pooling。"""
        if self.pooling == 'cls':
            # BGE / BERT: CLS token
            embs = self.model.encode(texts, batch_size=batch_size, show_progress_bar=True)
        elif self.pooling == 'mean':
            # 平均池化
            embs = self.model.encode(texts, batch_size=batch_size, normalize_embeddings=True)
        elif self.pooling == 'last':
            # 最后一个 token (LLM 风格)
            import torch
            embs = []
            for text in texts:
                inputs = self.model.tokenizer(text, return_tensors='pt', truncation=True)
                with torch.no_grad():
                    out = self.model.auto_model(**inputs)
                embs.append(out.last_hidden_state[0, -1].numpy())
            embs = np.stack(embs)
        return embs
```

### B.3 多模型融合

用多个模型 ensemble embedding:

```python
class EnsembleEmbedding:
    """多模型 ensemble embedding。"""
    def __init__(self, models, weights=None):
        self.models = models
        self.weights = weights or [1.0 / len(models)] * len(models)

    def encode(self, texts):
        """对所有模型的结果加权平均。"""
        embs = []
        for model in self.models:
            emb = model.encode(texts)
            # 归一化(避免尺度不一致)
            emb = emb / np.linalg.norm(emb, axis=1, keepdims=True)
            embs.append(emb)
        # 加权平均
        return sum(w * e for w, e in zip(self.weights, embs))
```

- BGE + Qwen: 语义强但慢。

## D. 用 LLM 提取 Embedding (Qwen)

### D.1 基础用法

```python
class QwenEmbedder:
    """用 Qwen 提取 embedding (last token pooling)。"""
    def __init__(self, model_name='Qwen/Qwen2-7B', device='cuda'):
        from transformers import AutoModel, AutoTokenizer
        self.tokenizer = AutoTokenizer.from_pretrained(model_name)
        self.model = AutoModel.from_pretrained(model_name, device_map=device)
        self.device = device

    @torch.no_grad()
    def encode(self, texts, batch_size=8):
        """Qwen 的 last token pooling。"""
        all_embs = []
        for i in range(0, len(texts), batch_size):
            batch = texts[i:i+batch_size]
            inputs = self.tokenizer(
                batch, return_tensors='pt',
                truncation=True, max_length=512, padding=True
            ).to(self.device)
            outputs = self.model(**inputs)
            # Last token pooling
            embs = outputs.last_hidden_state[:, -1, :].cpu().numpy()
            all_embs.append(embs)
        return np.concatenate(all_embs, 0)
```

```python
def normalize_embeddings(embeddings):
    """L2 归一化。"""
    norms = np.linalg.norm(embeddings, axis=1, keepdims=True)
    norms = np.maximum(norms, 1e-12)  # 防止除零
    return embeddings / norms
```

```python
class MultilingualSIDTrainer:
    """多语言 SID 联合训练。"""
    def __init__(self, multilingual_model):
        self.model = multilingual_model

    def fit(self, items_zh, items_en, items_jp):
        """多语言物品混合训练 RQ-VAE。"""
        # 1. 提 embedding(统一空间)
        embs_zh = self.model.encode([item['title'] for item in items_zh])
        embs_en = self.model.encode([item['title'] for item in items_en])
        embs_jp = self.model.encode([item['title'] for item in items_jp])

        # 2. 合并所有 embedding
        all_embs = np.concatenate([embs_zh, embs_en, embs_jp], axis=0)

        # 3. RQ-Kmeans
        from sklearn.cluster import KMeans
        residual = all_embs.copy()
        sids = np.zeros((len(all_embs), 5), dtype=int)
        for l in range(5):
            km = KMeans(n_clusters=256, n_init=3, random_state=42).fit(residual)
            sids[:, l] = km.labels_
            residual = residual - km.cluster_centers_[km.labels_]
        return sids
```

### F.1 Embedding 质量评估

```python
class EmbeddingEvaluator:
    """Embedding 质量评估。"""
    def __init__(self, embeddings, items):
        self.embeddings = embeddings
        self.items = items

    def evaluate_retrieval(self, queries, ground_truth, k=10):
        """检索 Recall@K。"""
        import torch
        embs = torch.from_numpy(self.embeddings)
        recalls = []
        for query, gt in zip(queries, ground_truth):
            # 用 query embedding 检索
            q_emb = self.encode_one(query)
            sim = embs @ q_emb
            top_k = sim.topk(k).indices.tolist()
            # 计算 recall
            recall = len(set(top_k) & set(gt)) / len(gt)
            recalls.append(recall)
        return np.mean(recalls)

    def evaluate_alignment(self, item_pairs):
        """相似物品对的对齐度。"""
        sims = []
        for a, b in item_pairs:
            sim = np.dot(self.embeddings[a], self.embeddings[b])
            sims.append(sim)
        return {
            'mean_sim': np.mean(sims),
            'min_sim': np.min(sims),
            'max_sim': np.max(sims)
        }
```

```python
def evaluate_sid_quality(sids, items, k=10):
    """SID 质量评估: 召回率 + 类别一致性。"""
    from collections import Counter

    # 1. 同类目物品 SID 应相似
    cat_consistency = []
    cat_to_items = {}
    for i, item in enumerate(items):
        cat_to_items.setdefault(item['category'], []).append(i)
    for cat, indices in cat_to_items.items():
        if len(indices) < 2: continue
        # 同一类目内的 SID 距离
        sids_in_cat = sids[indices]
        avg_dist = np.mean([
            np.mean(sids_in_cat[0] != s) for s in sids_in_cat
        ])
        cat_consistency.append(1 - avg_dist / 5)  # 归一化

    # 2. 覆盖率
    coverage = len(np.unique(sids.flatten())) / (256 * 5)

    # 3. 码本利用率
    code_usage = [len(np.unique(sids[:, l])) / 256 for l in range(5)]

    return {
        'cat_consistency': np.mean(cat_consistency),
        'coverage': coverage,
        'code_usage_per_layer': code_usage
    }
```

```python
        new_words = words.copy()

            if random.random() < p:
```

```python
class EmbeddingCache:
    """Embedding 缓存,避免重复计算。"""
    def __init__(self, redis_client, ttl=86400 * 7):
        self.redis = redis_client
        self.ttl = ttl

    def get_or_compute(self, item_id, text, encoder):
        """查缓存, 没有则计算。"""
        key = f'emb:{item_id}'
        cached = self.redis.get(key)
        if cached is not None:
            return np.frombuffer(cached, dtype=np.float32)
        # 计算
        emb = encoder.encode([text])[0]
        # 缓存
        self.redis.setex(key, self.ttl, emb.astype(np.float32).tobytes())
        return emb
```

```python
    return issues
```
