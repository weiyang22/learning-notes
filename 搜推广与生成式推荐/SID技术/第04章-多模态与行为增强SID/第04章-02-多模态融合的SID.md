## 2.1 多模态融合的 3 种方式

```text
方式 1: 拼接 (Concatenate)
  text_emb || image_emb || cat_emb → RQ-VAE → SID

方式 2: 加权 (Weighted Sum)
  α·text_emb + β·image_emb + γ·cat_emb → RQ-VAE → SID

方式 3: Cross-Attention
  text_emb attends to image_emb, etc. → RQ-VAE → SID
```

## 3. CLIP-style 对比学习的数学基础

### 3.1 对比学习目标

给定 $N$ 个图文对 $(I_i, T_i)$,CLIP 训练一个视觉编码器 $f_v(\cdot)$ 和文本编码器 $f_t(\cdot)$,将两者映射到同一语义空间 $\mathbb{R}^d$,使得匹配的图文对距离小,不匹配的对距离大。

**对称 InfoNCE 损失**:

$$
\mathcal{L}_{\text{CLIP}} = -\frac{1}{N}\sum_{i=1}^{N}\left[\log\frac{\exp(s(I_i,T_i)/\tau)}{\sum_{j=1}^{N}\exp(s(I_i,T_j)/\tau)} + \log\frac{\exp(s(T_i,I_i)/\tau)}{\sum_{j=1}^{N}\exp(s(T_j,I_i)/\tau)}\right]
$$

其中相似度 $s(I,T) = \frac{f_v(I)^\top f_t(T)}{\|f_v(I)\|\|f_t(T)\|}$,$\tau$ 为温度参数。

### 3.2 梯度分析

对正样本 $(I_i, T_i)$,梯度方向倾向于:
$$
\frac{\partial \mathcal{L}}{\partial f_v(I_i)} \propto -\frac{1}{\tau}\left[\frac{1}{1 + \sum_{j\neq i}e^{s(I_i,T_j)/\tau}} \cdot \nabla_{f_v}\text{(correct term)} - \sum_{j\neq i}w_{ij}\nabla_{f_v}\text{(wrong terms)}\right]
$$

直观解读:
- **拉近**:匹配图文对的余弦相似度
- **推开**:不匹配对的相似度,权重由 $\tau$ 控制
- $\tau$ 越小 → 分布越尖锐 → 训练越难但表征越好

### 3.3 温度参数 $\tau$ 的影响

| $\tau$ 值 | 效果 | 适用场景 |
| :--- | :--- | :--- |
| $\tau \to 0$ | 接近 argmax,难负样本主导 | 已预训练,精调阶段 |
| $\tau = 0.07$ (CLIP 默认) | 中等锐度,平衡 | 通用场景 |
| $\tau \to \infty$ | 接近均匀分布,无效 | 不可用 |
| 可学习 $\tau$ | 自适应锐度 | 跨域/数据不均衡 |

### 3.4 多模态 SID 的扩展

将 CLIP 应用到 SID:
- **文本模态**:商品标题、描述、属性
- **图像模态**:商品主图、详情图
- **音频模态**(音乐/视频平台):音频片段
- **视频模态**:短视频帧序列

对齐后的多模态 embedding 通过 RQ-VAE/RQ-KMeans 量化得到 SID。

## 4. BLIP / BLIP-2 架构详解

### 4.1 BLIP (Bootstrapping Language-Image Pre-training)

**核心创新**:用 captioner + filter 的 bootstrapping 流程,自动生成高质量图文对,扩充训练数据。

**架构组件**:
1. **Image Encoder (ViT)**:提取图像特征
2. **Text Encoder (BERT-like)**:编码文本
3. **Image-grounded Text Encoder**:跨模态融合(ITM head + LM head)
4. **Image-grounded Text Decoder**:生成式 captioner

**三任务联合训练**:
- **ITC** (Image-Text Contrastive):对比学习
- **ITM** (Image-Text Matching):二分类匹配
- **LM** (Language Modeling):生成 caption

**总损失**:
$$
\mathcal{L}_{\text{BLIP}} = \alpha \mathcal{L}_{\text{ITC}} + \beta \mathcal{L}_{\text{ITM}} + \gamma \mathcal{L}_{\text{LM}}
$$

### 4.2 BLIP-2:更高效的 Q-Former

BLIP-2 引入 **Q-Former** 模块,大幅减少可训练参数。

**Q-Former 结构**:
- 一组可学习的 query token $Q \in \mathbb{R}^{N_q \times d}$
- 跨模态 attention:在 image features 上做 cross-attention
- 自注意力和前馈层堆叠 $L$ 层
- 输出 $N_q$ 个融合表征

**两阶段训练**:

**Stage 1: 视觉-语言对齐**
$$
\mathcal{L}_{\text{stage1}} = \mathcal{L}_{\text{ITC}} + \mathcal{L}_{\text{ITM}} + \mathcal{L}_{\text{ITG}}
$$
其中 $\mathcal{L}_{\text{ITG}}$ (Image-grounded Text Generation) 让 Q-Former 输出能用于文本生成。

**Stage 2: 视觉到语言模型的对齐**
冻结视觉编码器和 LLM,只训练 Q-Former 适配 LLM 输入空间:
$$
\mathbf{z}_{\text{LLM}} = \text{Linear}(\mathbf{q}_{\text{out}})
$$

### 4.3 Q-Former 的 SID 应用

将 Q-Former 输出视为多模态融合表征:
$$
\mathbf{e}_{\text{item}} = \text{RQ-VAE}(\text{Q-Former}(\mathbf{I}_i, \mathbf{T}_i))
$$

| 优势 | 说明 |
| :--- | :--- |
| 参数高效 | Q-Former 仅 ~188M 参数,vs CLIP 几个 B |
| 灵活融合 | query token 控制融合粒度 |
| 任务可扩展 | 同一 backbone 可做检索/生成/caption |

### 4.4 代码实现 (PyTorch 风格)

```python
import torch
import torch.nn as nn

class QFormerBlock(nn.Module):
    """Q-Former 单层:自注意力 + 跨模态交叉注意力 + FFN"""
    def __init__(self, dim=768, n_heads=12, ff_dim=3072):
        super().__init__()
        self.self_attn = nn.MultiheadAttention(dim, n_heads, batch_first=True)
        self.cross_attn = nn.MultiheadAttention(dim, n_heads, batch_first=True)
        self.norm1 = nn.LayerNorm(dim)
        self.norm2 = nn.LayerNorm(dim)
        self.norm3 = nn.LayerNorm(dim)
        self.ffn = nn.Sequential(
            nn.Linear(dim, ff_dim), nn.GELU(), nn.Linear(ff_dim, dim)
        )

    def forward(self, q, kv):
        # 自注意力:query token 之间
        q_norm = self.norm1(q)
        q = q + self.self_attn(q_norm, q_norm, q_norm)[0]
        # 跨模态交叉注意力:query attend 到 image/text features
        kv_norm = self.norm2(kv)
        q = q + self.cross_attn(q, kv_norm, kv_norm)[0]
        # FFN
        q = q + self.ffn(self.norm3(q))
        return q

class MultimodalQFormer(nn.Module):
    """多模态 Q-Former,用于生成融合表征"""
    def __init__(self, n_queries=32, dim=768, n_layers=12, img_dim=1024, txt_dim=768):
        super().__init__()
        # 可学习 query token
        self.queries = nn.Parameter(torch.randn(1, n_queries, dim) * 0.02)
        # 模态投影层
        self.img_proj = nn.Linear(img_dim, dim)
        self.txt_proj = nn.Linear(txt_dim, dim)
        # Q-Former 层
        self.layers = nn.ModuleList([
            QFormerBlock(dim) for _ in range(n_layers)
        ])
        self.out_dim = dim

    def forward(self, img_feats, txt_feats):
        """
        img_feats: [B, L_img, img_dim]
        txt_feats: [B, L_txt, txt_dim]
        returns: [B, n_queries, dim]
        """
        B = img_feats.size(0)
        # 投影到统一空间
        img = self.img_proj(img_feats)
        txt = self.txt_proj(txt_feats)
        kv = torch.cat([img, txt], dim=1)  # [B, L_img+L_txt, dim]
        # query token 广播
        q = self.queries.expand(B, -1, -1)
        # 逐层融合
        for layer in self.layers:
            q = layer(q, kv)
        return q

class MultimodalSIDEncoder(nn.Module):
    """完整的多模态 SID 编码器:ViT + Text Encoder + Q-Former + RQ-VAE"""
    def __init__(self, codebook_sizes=[256, 256, 256], codebook_dim=32):
        super().__init__()
        # 视觉编码器(可以是 frozen ViT)
        self.vision_encoder = ViTBackbone(pretrained=True)
        # 文本编码器
        self.text_encoder = TextEncoder(pretrained=True)
        # Q-Former 融合
        self.qformer = MultimodalQFormer()
        # 量化得到 SID
        self.rqvae = RQVAE(
            input_dim=self.qformer.out_dim,
            codebook_sizes=codebook_sizes,
            codebook_dim=codebook_dim
        )

    def encode_item(self, images, texts):
        """输入商品的多模态信息,输出 SID 序列"""
        # 提取各模态特征
        img_feats = self.vision_encoder(images)  # [B, L_img, 1024]
        txt_feats = self.text_encoder(texts)     # [B, L_txt, 768]
        # Q-Former 融合
        fused = self.qformer(img_feats, txt_feats)  # [B, n_queries, 768]
        # 取 [CLS] 或 mean pooling
        fused_repr = fused.mean(dim=1)  # [B, 768]
        # RQ 量化
        sid, commit_loss = self.rqvae(fused_repr)
        return sid, commit_loss

    def forward(self, images, texts):
        sid, commit_loss = self.encode_item(images, texts)
        return sid, commit_loss
```

## 5. 跨模态对齐损失详解

### 5.1 多对齐损失融合

实际工业系统中,通常会同时优化多个对齐目标:

**总对齐损失**:
$$
\mathcal{L}_{\text{align}} = \lambda_1\mathcal{L}_{\text{ITC}} + \lambda_2\mathcal{L}_{\text{ITM}} + \lambda_3\mathcal{L}_{\text{MIM}} + \lambda_4\mathcal{L}_{\text{MTM}} + \lambda_5\mathcal{L}_{\text{CLM}}
$$

各损失含义:
| 损失 | 全称 | 输入 | 目标 |
| :--- | :--- | :--- | :--- |
| $\mathcal{L}_{\text{ITC}}$ | Image-Text Contrastive | 图文对 | 拉近匹配对 |
| $\mathcal{L}_{\text{ITM}}$ | Image-Text Matching | 图文对 | 二分类是否匹配 |
| $\mathcal{L}_{\text{MIM}}$ | Masked Image Modeling | 掩码图 | 重建像素/patch |
| $\mathcal{L}_{\text{MTM}}$ | Masked Text Modeling | 掩码文本 | 预测掩码词 |
| $\mathcal{L}_{\text{CLM}}$ | Contrastive Language Modeling | 图+前缀文本 | 生成文本 |

### 5.2 难负样本挖掘 (Hard Negative Mining)

随机负样本在大规模 batch 上已足够好,但难负样本能进一步提升表征质量。

**Hard Negative 选择策略**:

1. **半难负样本 (Semi-Hard)**:相似度低于正样本但高于 margin
   $$s(I_i, T_j^-) < s(I_i, T_i^+) \text{ 且 } s(I_i, T_j^-) > s(I_i, T_i^+) - \alpha$$

2. **最硬负样本 (Hardest)**:batch 内最难区分的负样本
   $$T_j^- = \arg\max_{j \neq i} s(I_i, T_j)$$

3. **基于语义的难负样本**:同一类目但不同品牌/型号

**Mixup 增强**:
$$
\tilde{I} = \alpha I_a + (1-\alpha) I_b, \quad \tilde{T} = \alpha T_a + (1-\alpha) T_b
$$

### 5.3 温度 $\tau$ 的可学习策略

CLIP 默认 $\tau=0.07$,但工业系统常采用可学习温度:

```python
class LearnableTemperature(nn.Module):
    def __init__(self, init_tau=0.07, min_tau=0.01, max_tau=0.5):
        super().__init__()
        # 用 logit 参数化,确保数值稳定
        self.logit_tau = nn.Parameter(torch.tensor(self._to_logit(init_tau)))

    def _to_logit(self, tau):
        # tau ∈ (min, max), logit ∈ R
        return torch.log(torch.tensor((tau - 0.01) / (0.5 - tau)))

    @property
    def tau(self):
        return torch.sigmoid(self.logit_tau) * (0.5 - 0.01) + 0.01
```

### 5.4 工业实践:Scaling Law

CLIP 论文发现,**对齐质量与训练数据/模型规模呈幂律**:

$$
\text{Error} \propto N^{-\alpha}, \quad \alpha \approx 0.4 \sim 0.6
$$

实操建议:
- **小模型(< 100M)**:100M 图文对足够
- **中模型(100M~1B)**:1B~10B 图文对
- **大模型(> 1B)**:10B+ 图文对,继续涨点

## 6. 视觉-文本之外的模态融合

### 6.1 音频模态融合 (音乐/播客平台)

**音频特征提取**:
1. **Mel 频谱**:短时傅里叶变换 + Mel 滤波器组
2. **预训练模型**:PANNs (CNN14)、AST (Audio Spectrogram Transformer)
3. **自监督特征**:CLAP (Contrastive Language-Audio Pretraining)

**三模态融合 (Audio + Text + Visual)**:

```python
class TriModalFusion(nn.Module):
    """音频 + 文本 + 视觉 三模态融合"""
    def __init__(self, dim=768):
        super().__init__()
        # 模态投影
        self.audio_proj = nn.Linear(512, dim)
        self.text_proj = nn.Linear(768, dim)
        self.vision_proj = nn.Linear(1024, dim)
        # 跨模态 attention
        self.fusion = nn.TransformerDecoder(
            nn.TransformerDecoderLayer(d_model=dim, nhead=12, dim_feedforward=3072, batch_first=True),
            num_layers=6
        )
        # 模态权重学习
        self.modal_gate = nn.Sequential(
            nn.Linear(dim * 3, 3),
            nn.Softmax(dim=-1)
        )

    def forward(self, audio_feats, text_feats, vision_feats):
        a = self.audio_proj(audio_feats)
        t = self.text_proj(text_feats)
        v = self.vision_proj(vision_feats)
        # 拼接,送入 decoder
        memory = torch.cat([a, t], dim=1)  # 上下文
        fused = self.fusion(v, memory)     # 视觉 attend 到其他模态
        # 模态权重
        combined = torch.cat([a.mean(1), t.mean(1), v.mean(1)], dim=-1)
        weights = self.modal_gate(combined)  # [B, 3]
        # 加权融合
        out = (weights[:, 0:1] * a.mean(1) +
               weights[:, 1:2] * t.mean(1) +
               weights[:, 2:3] * v.mean(1))
        return out
```

### 6.2 视频模态融合 (短视频平台)

**视频特征层次**:
- **帧级 (Frame-level)**:每帧 CNN 特征 → 短视频"图像序列"
- **片段级 (Clip-level)**:几秒片段的时空特征
- **视频级 (Video-level)**:整视频的全局表征

**时空注意力**:
$$
\mathbf{e}_v = \text{TemporalAttn}(\text{SpatialAttn}(\mathbf{V})), \quad \mathbf{V} \in \mathbb{R}^{T \times P \times d}
$$

### 6.3 多模态缺失处理

**场景**:商品只有图,没有文字描述;或只有文字,没有图。

**策略**:
1. **缺失模态补零**:$\mathbf{e}_{\text{missing}} = \mathbf{0}$
2. **学得的 [MASK] token**:$\mathbf{e}_{\text{missing}} = \mathbf{e}_{\text{[MASK]}}$
3. **跨模态预测**:用现有模态预测缺失模态
   $$\hat{\mathbf{T}} = \text{Decoder}(\mathbf{I}), \quad \mathcal{L}_{\text{recon}} = \|\hat{\mathbf{T}} - \mathbf{T}\|^2$$

工业实践:通常**方案 2 最稳**,因为训练时随机 mask 模态,模型学到容错。

### 6.4 多模态融合的常见误区

| 误区 | 后果 | 正确做法 |
| :--- | :--- | :--- |
| 过早融合 (Early Fusion) | 模态对齐差,难收敛 | Late Fusion 或 Cross-Attention |
| 平均融合 (Mean Fusion) | 模态权重失衡 | 门控或注意力加权 |
| 模态缺失未处理 | 线上推理崩 | 学得 [MASK] token |
| 文本权重过大 | 视觉信息被淹没 | 文本长度截断,视觉增强 |
| 图像/文本未对齐 | 噪声监督 | 严格清洗,人工复核 |

## 7. 多模态 SID 的工程实现

### 7.1 离线训练流程

```python
# 多模态 SID 训练伪代码
def train_multimodal_sid(config):
    # 1. 准备数据
    train_loader = build_dataloader(
        parquet_path=config.parquet_path,
        image_dir=config.image_dir,
        text_fields=['title', 'description'],
        image_field='image_url',
        batch_size=2048,
        num_workers=16
    )
    # 2. 构建模型
    model = MultimodalSIDEncoder(
        codebook_sizes=[256, 256, 256],
        codebook_dim=32
    ).cuda()
    model = torch.nn.parallel.DistributedDataParallel(model)

    # 3. 优化器
    optimizer = torch.optim.AdamW([
        {'params': model.qformer.parameters(), 'lr': 1e-4},
        {'params': model.rqvae.parameters(), 'lr': 5e-4},
    ], weight_decay=0.01)
    scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=10)

    # 4. 训练循环
    for epoch in range(config.epochs):
        for batch in train_loader:
            images = batch['image'].cuda()  # [B, 3, 224, 224]
            texts = batch['text'].cuda()    # [B, L_txt]
            sid_target = batch['sid'].cuda() if 'sid' in batch else None

            # 前向
            sid_pred, commit_loss = model(images, texts)

            # 计算损失
            if sid_target is not None:
                # 有监督:交叉熵 + commit
                loss_ce = F.cross_entropy(
                    sid_pred.reshape(-1, sid_pred.size(-1)),
                    sid_target.reshape(-1)
                )
                loss = loss_ce + 0.25 * commit_loss
            else:
                # 自监督:重建损失
                reconstructed = model.decode(sid_pred, images, texts)
                loss_rec = F.mse_loss(reconstructed['image'], images)
                loss = loss_rec + 0.25 * commit_loss

            # 反向
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
        scheduler.step()
```

## 9. 高级话题

### 9.1 模态冲突与解耦

**问题**:文本和图像描述同一商品,但视角不同(如文本强调品牌,图像强调外观),简单对齐会引入噪声。

**解耦表征学习**:
$$
\mathbf{e} = \alpha \mathbf{e}_{\text{shared}} + \beta \mathbf{e}_{\text{unique}}^{\text{text}} + \gamma \mathbf{e}_{\text{unique}}^{\text{image}}
$$

约束:
- $\mathbf{e}_{\text{shared}}$:对比学习对齐
- $\mathbf{e}_{\text{unique}}^{\text{text}}$:仅从文本预测
- $\mathbf{e}_{\text{unique}}^{\text{image}}$:仅从图像预测
- 通过正交约束减少冗余:
  $$\mathbf{e}_{\text{shared}} \perp \mathbf{e}_{\text{unique}}^{\text{text}}, \quad \mathbf{e}_{\text{shared}} \perp \mathbf{e}_{\text{unique}}^{\text{image}}$$

### 9.2 模态缺失鲁棒性

训练时随机 drop 模态,迫使模型不依赖单一模态:

```python
def random_modal_drop(features, drop_prob=0.2):
    """训练时随机丢弃某些模态,提升鲁棒性"""
    B = features.size(0)
    mask = torch.bernoulli(torch.full((B, 1, 1), 1 - drop_prob)).to(features.device)
    return features * mask
```

## 10. 面试高频问题

### Q1: CLIP 是如何做跨模态对齐的?为什么对比学习有效?

**答**:CLIP 用对称 InfoNCE 损失,在 batch 内每个图文对作为正样本,其余作为负样本。对比学习有效的核心是:
1. **自监督信号**:无需人工标注,数据规模可极大规模化
2. **对齐空间**:图文共享同一向量空间,语义直接可比
3. **批内负样本**:N 个样本就有 N²-N 个负样本对,效率高
4. **温度参数**:控制分布锐度,可学习温度能自适应

### Q2: Q-Former 比简单 concat 优势在哪?

**答**:
1. **参数高效**:query token 控制融合粒度,不需要全量 cross-attention
2. **可解释性**:每个 query token 可学得不同语义角色
3. **任务灵活**:同一 Q-Former 可做检索/生成/caption
4. **训练稳定**:query token 作为 anchor,减少梯度震荡

### Q3: 多模态 SID 中,如果模态缺失怎么办?

**答**:三种策略:
1. **学得 [MASK] token**:训练时随机 mask 模态,推理时缺失模态用 [MASK] 代替
2. **跨模态预测**:用现有模态预测缺失模态的 embedding
3. **重训练**:每个模态组合训练一个模型(成本高,一般不取)

工业最常用方案 1,因为简单且鲁棒。

### Q4: 为什么 RQ-VAE 量化后还能保持语义?

**答**:RQ-VAE 通过残差量化:
1. 第一层粗粒度量化,把语义大致分类
2. 第二层在残差上细化,捕捉粗粒度忽略的差异
3. 第三层进一步细化
每层码本学得是**残差模式**,而非原始特征;只要残差结构稳定,语义就保留。

### Q5: 训练多模态 SID 时,温度 $\tau$ 怎么设?

**答**:三种策略:
1. **固定 $\tau=0.07$**:CLIP 默认,大多数场景够用
2. **可学习 $\tau$**:通过 logit 参数化,训练时自适应
3. **任务特定**:粗粒度任务用小 $\tau$(强调区分),细粒度任务用大 $\tau$(允许相似)

经验上,**可学习 $\tau$ + 任务微调**最稳。

### Q6: 多模态融合什么时候用 Early vs Late Fusion?

**答**:
- **Early Fusion**:特征层面拼接,适合模态高度相关、规模小的场景
- **Late Fusion**:决策层面加权,适合模态独立、规模大的场景
- **Cross-Attention**:中间融合,适合中等规模,目前主流

实际工业中,**Cross-Attention (Q-Former 风格)效果最好**,因为它结合了 early 和 late 的优点。

### Q7: 多模态 SID 推理延迟怎么优化?

**答**:多管齐下:
1. **视觉编码器蒸馏**:ViT-B → ViT-T(5× 加速)
2. **FP16/INT8 量化**:2× 加速
3. **批量推理**:动态 batch padding
4. **图像 embedding 缓存**:商品图更新不频繁,可缓存
5. **异步预处理**:图像下载与文本处理并行
6. **模型并行**:视觉和文本在不同 GPU

实际系统可把单次推理从 80ms 压到 15ms。

### Q8: 如何评估多模态 SID 的质量?

**答**:多维度评估:
1. **聚类质量**:NMI、ARI 评估 SID 内聚性
2. **检索质量**:Recall@K、NDCG@K 在评测集
3. **下游任务**:CTR、GMV 等业务指标
4. **冷启动**:新商品 vs 老商品 CTR 差异
5. **可视化**:t-SNE 看 SID 在语义空间的分布
6. **A/B 测试**:线上流量对比

```python
class RQVAE(nn.Module):
    """残差量化 VAE,生成层次化 SID"""
    def __init__(self, input_dim=768, n_layers=3, codebook_size=256, codebook_dim=32):
        super().__init__()
        # 编码器
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, 512), nn.ReLU(),
            nn.Linear(512, 256), nn.ReLU()
        )
        # 多层码本
        self.codebooks = nn.ModuleList([
            Codebook(256, 32) for _ in range(n_layers)
        ])
        self.n_layers = n_layers

    def forward(self, x):
        residual = self.encoder(x)
        codes = []
        commit_loss = 0.0
        for cb in self.codebooks:
            quantized, idx, cl = cb(residual)
            codes.append(idx)
            residual = residual - quantized
            commit_loss += cl
        return torch.stack(codes, dim=1), commit_loss  # [B, n_layers], 标量
```

## 13. 多模态对齐损失函数全解

### 13.1 Sigmoid 损失 (SigLIP)

Google 提出的 SigLIP 替代了 softmax-based CLIP:

**对比 CLIP 与 SigLIP**:
- CLIP:softmax over batch negatives
- SigLIP:sigmoid binary classification for each pair

**SigLIP 损失**:
$$
\mathcal{L}_{\text{SigLIP}} = -\frac{1}{N^2}\sum_{i,j}\left[y_{ij}\log\sigma(z_{ij}) + (1-y_{ij})\log(1-\sigma(z_{ij}))\right]
$$

其中 $z_{ij} = s(I_i, T_j) \cdot e^{\tau}$(可学习 bias),$y_{ij}=1$ 当且仅当 $i=j$。

**优势**:
1. **无需大 batch**:不像 CLIP 依赖大批量负样本
2. **训练更稳**:每对独立,梯度方差小
3. **可分布式**:分片计算再聚合
4. **效果好**:Google 在 4B 数据上 SOTA

**代码**:
```python
class SigLIPLoss(nn.Module):
    def __init__(self, init_logit_bias=-10.0):
        super().__init__()
        self.logit_bias = nn.Parameter(torch.tensor(init_logit_bias))
        self.logit_scale = nn.Parameter(torch.tensor(2.6593))  # log(exp(log(100/0.01)))

    def forward(self, img_emb, txt_emb):
        # img_emb, txt_emb: [B, d],已 L2 normalize
        z = img_emb @ txt_emb.T * self.logit_scale.exp() + self.logit_bias
        # 构造标签:对角线为 1
        target = torch.eye(z.size(0), device=z.device)
        loss = -F.logsigmoid(z * (2*target - 1)).mean()
        return loss
```

### 13.2 CoCa (Contrastive Captioner)

**架构**:视觉编码器 + 文本解码器,融合对比学习和 captioning。

**双损失**:
$$
\mathcal{L}_{\text{CoCa}} = \mathcal{L}_{\text{ITC}} + \mathcal{L}_{\text{Caption}}
$$

**特点**:
- ITC 部分用单模态编码器(early layer)
- Caption 部分用跨模态解码器(later layer)
- 渐进式融合,效果优于单一损失

### 13.4 模态平衡损失

**问题**:某些模态信号强,主导对齐;模态弱的被淹没。

**模态平衡损失**:
$$
\mathcal{L}_{\text{balanced}} = \sum_{m \in \{I,T\}} \frac{1}{\sigma_m^2}\mathcal{L}_m + \log \sigma_m^2
$$

其中 $\sigma_m$ 是可学习的模态噪声,Bayesian 框架自动平衡。

**直觉**:如果某模态损失太大,$\sigma$ 会变大,缩放该损失,达到平衡。

```python
class MultiScaleViT(nn.Module):
    """多尺度视觉特征提取"""
    def __init__(self):

        self.vit_small = ViT(img_size=112)   # 全局
        self.vit_base = ViT(img_size=224)   # 主体
        self.vit_large = ViT(img_size=448)   # 细节
        # 融合
        self.fusion = nn.Linear(768 + 768 + 768, 768)

    def forward(self, image):
        f_small = self.vit_small(F.interpolate(image, size=112))
        f_base = self.vit_base(image)
        f_large = self.vit_large(F.interpolate(image, size=448))
        # 拼接融合
        combined = torch.cat([f_small, f_base, f_large], dim=-1)
        return self.fusion(combined)
```

### 15.4 文本 Embedding 的缓存策略

**问题**:同一商品多次调用,文本编码重复。

**解决方案**:
1. **Redis 缓存**:key=`text_hash`,value=`embedding`
2. **LRU 内存缓存**:处理 batch 内的重复
3. **数据库**:商品库本身的 embedding 离线预存

```python
class CachedTextEncoder:
    def __init__(self, model, cache_size=10000):
        self.model = model
        self.cache = LRUCache(cache_size)

    def encode(self, texts):
        results = []
        uncached_idx = []
        uncached_texts = []
        for i, t in enumerate(texts):
            if t in self.cache:
                results.append(self.cache[t])
            else:
                results.append(None)
                uncached_idx.append(i)
                uncached_texts.append(t)
        if uncached_texts:
            new_emb = self.model(uncached_texts)
            for idx, emb in zip(uncached_idx, new_emb):
                results[idx] = emb
                self.cache[uncached_texts[uncached_idx.index(idx)]] = emb
        return torch.stack(results)
```

## 16. RQ-VAE 量化深度解析

### 16.1 RQ-VAE 的数学原理

**输入**:连续向量 $\mathbf{e} \in \mathbb{R}^d$
**输出**:$K$ 层码本索引 $(c_1, c_2, ..., c_K)$

**量化过程**:
$$
\mathbf{e}_1 = \text{Enc}(\mathbf{e})
$$
$$
\mathbf{q}_1 = \text{Codebook}_1.\text{lookup}(\arg\min_c \|\mathbf{e}_1 - C_1[c]\|^2)
$$
$$
\mathbf{r}_1 = \mathbf{e}_1 - \mathbf{q}_1 \quad (\text{残差})
$$
$$
\mathbf{q}_2 = \text{Codebook}_2.\text{lookup}(\arg\min_c \|\mathbf{r}_1 - C_2[c]\|^2)
$$
$$
\mathbf{r}_2 = \mathbf{r}_1 - \mathbf{q}_2
$$
$$
\vdots
$$
$$
\mathbf{q}_K = \text{Codebook}_K.\text{lookup}(\arg\min_c \|\mathbf{r}_{K-1} - C_K[c]\|^2)
$$

**重建**:
$$
\hat{\mathbf{e}} = \text{Dec}(\mathbf{q}_1 + \mathbf{q}_2 + ... + \mathbf{q}_K)
$$

### 16.2 损失函数

**总损失**:
$$
\mathcal{L}_{\text{RQ-VAE}} = \mathcal{L}_{\text{rec}} + \alpha\mathcal{L}_{\text{commit}} + \beta\mathcal{L}_{\text{codebook}}
$$

1. **重建损失**:
$$
\mathcal{L}_{\text{rec}} = \|\mathbf{e} - \hat{\mathbf{e}}\|^2 = \|\mathbf{e} - \text{Dec}(\sum_k \mathbf{q}_k)\|^2
$$

2. **Commit 损失**(编码器侧):
$$
\mathcal{L}_{\text{commit}} = \sum_{k=1}^K \|\mathbf{r}_{k-1} - \mathbf{q}_k\|^2
$$
推动编码器输出接近码本向量。

3. **Codebook 损失**(码本侧):
$$
\mathcal{L}_{\text{codebook}} = \sum_{k=1}^K \|\text{sg}(\mathbf{r}_{k-1}) - \mathbf{q}_k\|^2
$$
更新码本向量,使其接近残差。`sg` 是 stop-gradient。

### 16.3 码本 Collapse 问题

**现象**:部分码本向量从不被选中,等效码本容量减少。

**原因**:
- 训练初期随机初始化,部分码本远离数据
- 后续更新困难,陷入"赢家通吃"

**解决方案**:

| 方案 | 原理 | 效果 |
| :--- | :--- | :--- |
| **EMA 更新** | 指数移动平均更新码本 | 缓解但不能根治 |
| **Codebook Reset** | 周期性重置未使用码本 | 有效 |
| **Gumbel-Softmax** | 可微采样 | 探索更多码本 |
| **k-means 初始化** | 数据驱动的初始码本 | 显著改善 |
| **DDP Clustering** | 双码本同步更新 | 业界 SOTA |

**代码 (Codebook Reset)**:
```python
class CodebookWithReset(nn.Module):
    def __init__(self, size=256, dim=32, reset_threshold=1):
        super().__init__()
        self.embedding = nn.Embedding(size, dim)
        self.register_buffer('usage', torch.zeros(size))
        self.reset_threshold = reset_threshold

    def forward(self, residual):
        # 找最近码本
        dist = (residual.unsqueeze(1) - self.embedding.weight.unsqueeze(0)).pow(2).sum(-1)
        idx = dist.argmin(dim=-1)
        # 更新使用统计
        for i in idx.unique():
            self.usage[i] += 1
        # 重置低使用率码本
        if self.training and self.usage.min() < self.reset_threshold:
            rare_codes = (self.usage < self.reset_threshold).nonzero().squeeze()
            # 用数据随机采样替换
            n_reset = len(rare_codes)
            if len(residual) >= n_reset:
                new_idx = torch.randperm(len(residual))[:n_reset]
                self.embedding.weight.data[rare_codes] = residual[new_idx].detach()
                self.usage[rare_codes] = self.reset_threshold
        return self.embedding(idx), idx
```

### 16.4 K-means vs RQ-VAE 量化对比

| 维度 | K-means | RQ-VAE |
| :--- | :--- | :--- |
| 量化粒度 | 单一层级 | 多层残差 |
| 重建质量 | 一般 | 高 |
| 训练稳定性 | 易(k-means 收敛快) | 中(VAE 训练难) |
| 推理速度 | 快(单次 lookup) | 慢(K 次 lookup) |
| 适用场景 | 简单聚类 | 需要重建的场景 |

### 16.5 多模态场景的 RQ-VAE 改造

**挑战**:视觉、文本特征空间不同,直接量化效果差。

**方案 1:模态专用 RQ-VAE**
- 视觉 RQ-VAE:对图像 embedding 量化
- 文本 RQ-VAE:对文本 embedding 量化
- SID 由两路码本组合

**方案 2:统一空间 RQ-VAE**
- 先做 CLIP 对齐,把多模态映射到同一空间
- 在对齐空间做 RQ-VAE

**方案 3:Cross-modal RQ-VAE**(进阶)
- 编码器接受任意模态
- 共享码本
- 跨模态检索更自然

## 17. SID 评测体系

### 17.1 离线评测指标

| 指标 | 公式 | 含义 |
| :--- | :--- | :--- |
| **Codebook Utilization** | $\frac{\text{used codes}}{\text{total codes}}$ | 码本利用率 |
| **Reconstruction Error** | $\|\mathbf{e} - \hat{\mathbf{e}}\|^2$ | 重建质量 |
| **Cluster Purity** | $\frac{\text{正确聚类}}{\text{总数}}$ | 聚类纯度 |
| **NMI** | $\frac{2 I(U;V)}{H(U)+H(V)}$ | 归一化互信息 |
| **ARI** | $\frac{\text{RI} - E[\text{RI}]}{\max(\text{RI}) - E[\text{RI}]}$ | 调整兰德指数 |

### 17.2 检索质量评测

**评测集构造**:
- 用户-商品交互作为 ground truth
- 给定 SID 序列,检索 Top-K 商品
- 计算 Recall@K、NDCG@K、MAP@K

```python
def evaluate_retrieval(sid_model, eval_dataset, k_list=[10, 50, 100]):
    metrics = {f'recall@{k}': [] for k in k_list}
    for batch in eval_dataset:
        query_sid = sid_model.encode(batch['query'])
        retrieved = ann_search(query_sid, k=max(k_list))
        gt = set(batch['positive_items'])
        for k in k_list:
            hits = len(set(retrieved[:k]) & gt) / len(gt)
            metrics[f'recall@{k}'].append(hits)
    return {k: np.mean(v) for k, v in metrics.items()}
```

### 17.3 冷启动评测

**关键指标**:新品 CTR vs 老品 CTR 的比值
$$
\text{Cold Start Ratio} = \frac{\text{CTR}_{\text{new items}}}{\text{CTR}_{\text{old items}}}
$$

理想情况下,Ratio 越接近 1 越好(说明冷启动不依赖历史行为)。

### 17.4 A/B 测试

**设计原则**:
- **流量分桶**:用户 hash 模 100 分桶,实验组 vs 对照组各 50
- **最小样本量**:根据 baseline CTR 和最小可检测效应 (MDE) 计算
- **实验周期**:至少 7 天,覆盖工作日和周末
- **核心指标**:CTR、GMV、人均时长、次留等

**实验评估**:
```python
def ab_test_analysis(exp_data, ctrl_data, metric='ctr'):
    """A/B 测试统计分析"""
    from scipy import stats
    exp_mean = exp_data[metric].mean()
    ctrl_mean = ctrl_data[metric].mean()
    lift = (exp_mean - ctrl_mean) / ctrl_mean
    # t 检验
    t_stat, p_value = stats.ttest_ind(exp_data[metric], ctrl_data[metric])
    return {
        'exp_mean': exp_mean,
        'ctrl_mean': ctrl_mean,
        'lift': lift,
        'p_value': p_value,
        'significant': p_value < 0.05
    }
```

## 21. 常见问题排查手册

### Q:训练时 loss 不下降?
A:检查数据分布、学习率、模型初始化。先用小数据集验证 pipeline。

### Q:码本利用率只有 30%?
A:Codebook Collapse。1)k-means 初始化;2)EMA 更新;3)定期 reset。

### Q:线上推理延迟太高?
A:1)视觉编码器蒸馏;2)FP16 量化;3)TensorRT 加速;4)批量推理。

### Q:冷启动 CTR 没有提升?
A:1)检查 SID 是否进入召回;2)确认新商品 embedding 质量;3)A/B 测试流量分配。

### Q:多模态融合效果不如单模态?
A:1)模态对齐未做好;2)文本噪声大;3)图像质量差。需清洗数据。

### Q:多模态 SID vs 内容 SID 哪个好?
A:取决于场景。冷启动多 → 多模态;老品召回 → 内容 SID 或行为增强 SID。

### 24.6 多模态 Embedding 的归一化

**常见做法**:

```python
# L2 归一化
def l2_normalize(x):
    return x / x.norm(dim=-1, keepdim=True)

# 在编码器最后加归一化层
class NormalizedEncoder(nn.Module):
    def __init__(self, encoder):
        super().__init__()

        return l2_normalize(self.encoder(x))
```

**为什么需要**:cosine similarity 计算要求向量归一化,否则点积受向量长度影响。

## 25. 负样本挖掘策略详解

### 25.1 随机负样本 vs 难负样本

| 类型 | 优点 | 缺点 |
| :--- | :--- | :--- |
| 随机负样本 | 简单、分布均匀 | 信息量低 |
| 难负样本 | 信息量大、提升快 | 训练不稳 |
| 半难负样本 | 平衡 | 阈值难设 |

### 25.2 难负样本挖掘算法

**1. In-Batch 难负样本**:
```python
def get_hard_negatives_in_batch(emb, labels):
    """Batch 内最难负样本"""
    sim = emb @ emb.T  # [B, B]
    # mask 对角线(自己)
    sim.fill_diagonal_(-1)
    # 每个样本的难负样本
    hard_neg_idx = sim.argmax(dim=-1)  # [B]
    return emb[hard_neg_idx]
```

**2. 队列挖掘 (MoCo 风格)**:
```python
class HardNegativeQueue:
    """维护一个 embedding 队列,从中采样难负样本"""
    def __init__(self, size=65536, dim=128):
        self.queue = torch.randn(size, dim)
        self.queue = F.normalize(self.queue, dim=-1)
        self.ptr = 0

    def enqueue(self, embs):
        n = embs.size(0)
        self.queue[self.ptr:self.ptr+n] = embs.detach()
        self.ptr = (self.ptr + n) % self.queue.size(0)

    def sample_hard_neg(self, query_emb, k=10):
        """采样与 query 最相似的 k 个负样本"""
        sim = query_emb @ self.queue.T  # [B, size]
        hard_idx = sim.topk(k, dim=-1).indices
        return self.queue[hard_idx]  # [B, k, dim]
```

**3. 跨模态难负样本**:
```python
def cross_modal_hard_negative(img_emb, txt_emb, txt_pool, k=10):
    """给定图像,在文本池中找最难负样本"""
    sim = img_emb @ txt_pool.T  # [B, pool_size]
    # 排除自己
    sim[torch.arange(img_emb.size(0))] = -1
    hard_idx = sim.topk(k, dim=-1).indices
    return txt_emb[hard_idx.flatten()].reshape(img_emb.size(0), k, -1)
```

## 26. 多模态表征的解耦学习

### 26.1 解耦动机

**问题**:多模态融合后的表征可能纠缠不同语义维度(如风格、内容、用途),难以精细控制。

**目标**:把不同语义维度分开,使每个维度独立可控。

### 26.2 解耦表征学习

**总表征分解**:
$$
\mathbf{e} = \sum_{k=1}^{K} \alpha_k \mathbf{e}_k
$$

其中 $\mathbf{e}_k$ 是第 $k$ 个解耦因子,$\alpha_k$ 是系数。

**损失设计**:
1. **重构损失**:$\|\mathbf{e} - \sum_k \alpha_k \mathbf{e}_k\|^2$
2. **正交约束**:$\mathbf{e}_i \perp \mathbf{e}_j$
3. **独立性约束**:互信息 $I(\mathbf{e}_i; \mathbf{e}_j)$ 小

### 26.3 在 SID 上的应用

**层级化 SID**:
- **第一层**:类别(服饰/电子/食品)
- **第二层**:风格(运动/商务/休闲)
- **第三层**:品牌(品牌 A/品牌 B)
- **第四层**:具体款型

每层对应一个解耦因子,组合起来是完整 SID。

### 26.4 代码示例

```python
class DisentangledMultimodalEncoder(nn.Module):
    """解耦的多模态编码器"""
    def __init__(self, n_factors=4, dim=768):
        super().__init__()
        # 共享编码器
        self.shared_encoder = QFormerFusion()
        # 各因子头
        self.factor_heads = nn.ModuleList([
            nn.Sequential(
                nn.Linear(dim, dim),
                nn.ReLU(),
                nn.Linear(dim, dim)
            ) for _ in range(n_factors)
        ])
        # 系数预测
        self.coeff_predictor = nn.Linear(dim, n_factors)

    def forward(self, img, txt):
        shared = self.shared_encoder(img, txt)
        factors = [head(shared) for head in self.factor_heads]
        coefs = self.coeff_predictor(shared)  # [B, n_factors]
        # 加权组合
        combined = sum(c.unsqueeze(-1) * f for c, f in zip(coefs.unbind(-1), factors))
        return combined, factors, coefs
```

```python
class MultimodalSIDService:
    """多模态 SID 在线服务"""
    def __init__(self):
        self.model = self.load_model()  # TensorRT 优化
        self.cache = RedisClient()
        self.queue = KafkaConsumer('new-items')

    def get_sid(self, item_id, image_url, text):
        # 1. 查缓存
        cached = self.cache.get(f"sid:{item_id}")
        if cached:
            return cached

        # 2. 在线推理
        image = self.download_image(image_url)
        sid = self.model.encode(image, text)
        sid_str = '-'.join(map(str, sid.tolist()))

        # 3. 写缓存
        self.cache.set(f"sid:{item_id}", sid_str, ttl=86400)
        return sid_str

    def run(self):
        """消费者,异步计算新商品 SID"""
        for msg in self.queue:
            item = json.loads(msg.value)
            sid = self.get_sid(
                item['item_id'],
                item['image_url'],
                item['title']
            )
            # 推送下游
            self.publish_sid(item['item_id'], sid)
```

### 28.1 为什么需要可解释性

4. **合规要求**:GDPR 等法规要求可解释

### 28.2 可解释性方法

**1. 注意力可视化**:
```python
def visualize_attention(model, item_id):
    """可视化 SID 编码时的注意力权重"""
    img, txt = load_item(item_id)
    # 注册 hook 抓取 attention
    activations = []
    def hook(module, input, output):
        activations.append(output[1])  # attention weights
    handle = model.qformer.layers[-1].self_attn.register_forward_hook(hook)
    sid = model.encode(img, txt)
    handle.remove()
    # 可视化
    plot_attention(activations[-1], tokens=txt)
```

**2. 检索路径追踪**:
- 给定 query SID,展示从 query 到候选的相似度衰减链
- 高亮关键中间 SID

**3. SID 簇的语义标注**:
- 对每个码本簇,人工标注代表词
- 例如:码本 42 = "运动户外-上衣"

**4. 相似度分解**:
- 把 cos(query, item) 分解为各模态的贡献
- 例如:图像 0.6 + 文本 0.4 = 0.92

### 28.3 可解释性代码

```python
class ExplainableMultimodalSID:
    """可解释的多模态 SID 编码"""
    def __init__(self, encoder):
        self.encoder = encoder

    def encode_with_explanation(self, img, txt):
        # 多模态贡献分解
        img_emb = self.encoder.encode_image(img)
        txt_emb = self.encoder.encode_text(txt)
        fused = self.encoder.encode(img, txt)
        # 计算各模态贡献
        img_contrib = F.cosine_similarity(fused, img_emb, dim=-1)
        txt_contrib = F.cosine_similarity(fused, txt_emb, dim=-1)
        # 归一化
        total = img_contrib + txt_contrib
        img_weight = img_contrib / total
        txt_weight = txt_contrib / total
        # SID 量化
        sid = self.encoder.rqvae(fused)
        return {
            'sid': sid,
            'img_weight': img_weight,
            'txt_weight': txt_weight,
            'img_emb': img_emb,
            'txt_emb': txt_emb,
            'fused_emb': fused
        }
```

## 29. 多模态 SID 的特殊场景

### 29.1 多语言商品

**场景**:跨境电商,商品有多语言描述。

**方案**:
1. **统一翻译**:把所有文本翻译成英文或中文
2. **多语言编码器**:如 XLM-R、mBERT
3. **跨语言对齐**:用翻译对做监督

**实现**:
```python
class MultilingualEncoder(nn.Module):
    def __init__(self, model_name='xlm-roberta-base'):
        super().__init__()
        self.encoder = AutoModel.from_pretrained(model_name)
        # 投影到多模态空间
        self.proj = nn.Linear(self.encoder.config.hidden_size, 768)

    def forward(self, text, lang='zh'):
        features = self.encoder(**text)
        return self.proj(features.last_hidden_state)
```

### 29.2 隐私敏感场景

**场景**:用户数据不能离开本地(医疗、金融)。

**联邦多模态 SID**:
1. 本地训练编码器
2. 上传 embedding(SID)而非原始数据
3. 中心聚合 SID,形成全局字典

**差分隐私**:
```python
def add_dp_noise(emb, epsilon=1.0, delta=1e-5):
    """加差分隐私噪声"""
    sensitivity = 2.0  # L2 敏感度
    sigma = sensitivity * torch.sqrt(2 * torch.log(torch.tensor(1.25 / delta))) / epsilon
    noise = torch.randn_like(emb) * sigma
    return emb + noise
```

## 30. 多模态 SID 的边界与挑战

### 30.1 当前局限

| 局限 | 描述 | 缓解方案 |
| :--- | :--- | :--- |
| **模态偏差** | 文本主导,视觉信息被淹没 | 模态平衡损失 |
| **对齐偏差** | 训练数据有偏,真实分布不同 | 重要性采样 |
| **OOD 失效** | 训练未见过的新类目效果差 | 持续学习、few-shot |
| **解释不足** | 黑盒,难 debug | 注意力可视化 |
| **成本高** | 多模态模型大,推理慢 | 蒸馏、量化 |

### 30.2 未解决问题

1. **真正统一的语义空间**:目前多模态只是"对齐",还不是"统一"
2. **长尾模态**:某些模态数据少(如 3D 模型)
3. **多模态幻觉**:模型生成错误的多模态关联
4. **因果 vs 相关**:多模态对齐捕捉相关而非因果

### 30.3 未来方向

1. **World Model 驱动的 SID**:用世界模型生成虚拟样本
2. **神经符号融合**:符号推理 + 神经网络
3. **具身多模态**:通过交互学习多模态表征
4. **量子启发编码**:量子算法加速多模态对齐
