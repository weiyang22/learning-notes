## 3.1 动机

**内容驱动的局限**: 视觉相似的物品,行为可能完全不同(都是手机壳,但有些销量高,有些低)。

**协同信号**: 用户行为(点击/购买)是"用户真正喜欢什么"的强信号。

→ **内容+协同双信号融合** 是 ByteDance TRM 论文的核心结论。

## 3.3 行为增强的 SID 构建流程

```text
物品 i 的内容 embedding
  + 用户行为统计(点击次数, 转化率)
  → 拼接成"内容+行为" embedding
  → RQ-VAE → SID
```

```python
import numpy as np

def build_behavior_enhanced_emb(item_emb, behavior_stats):
    """内容 embedding + 行为统计"""
    # item_emb: [D]
    # behavior_stats: [4] = [曝光, 点击, 加车, 购买] 的归一化次数
    return np.concatenate([item_emb, behavior_stats])  # [D+4]


# 例
item_emb = np.random.randn(1024)  # 内容
behavior = np.array([1000, 50, 5, 1]) / 1000  # 归一化
enhanced_emb = build_behavior_enhanced_emb(item_emb, behavior)  # [1028]
```

## 3.4 行为序列作为辅助输入

```python
# 高级做法: 把行为序列也作为 RQ-VAE 的输入
def build_with_behavior_sequence(item_emb, behavior_seq):
    """
    item_emb: 物品内容 [D]
    behavior_seq: 用户行为序列 [(uid, action, timestamp), ...]
    """
    # 1. 物品本身
    emb = item_emb
    # 2. 加权行为
    weighted_emb = np.zeros_like(item_emb)
    for uid, action, ts in behavior_seq[-100:]:  # 最近 100 条
        weight = BEHAVIOR_WEIGHTS.get(action, 0)
        # 假设有 user_emb
        weighted_emb += weight * user_emb[uid]
    return emb + 0.5 * weighted_emb  # 拼接/相加
```

## 4. 行为信号的理论基础

### 4.1 协同过滤 vs 内容过滤

**内容过滤(Content-based)**:
- 基于商品特征(title, image, description)
- 优点:可解释、可冷启动
- 缺点:难以捕捉隐性偏好(用户喜欢某商品,但说不出为什么)

**协同过滤(Collaborative Filtering)**:
- 基于用户-商品交互矩阵
- 优点:捕捉群体智慧、隐式偏好
- 缺点:冷启动差、稀疏性问题

**公式对比**:

内容相似度:
$$
s_{\text{content}}(i, j) = \cos(f_{\text{content}}(i), f_{\text{content}}(j)) = \frac{\mathbf{e}_i^\top \mathbf{e}_j}{\|\mathbf{e}_i\|\|\mathbf{e}_j\|}
$$

协同相似度:
$$
s_{\text{collab}}(i, j) = \mathbf{p}_i^\top \mathbf{q}_j
$$
其中 $\mathbf{p}_i$ 是用户 $i$ 的隐向量,$\mathbf{q}_j$ 是商品 $j$ 的隐向量,从交互矩阵 $\mathbf{R}$ 学习。

### 4.2 矩阵分解与隐向量

**经典矩阵分解**:
$$
\mathbf{R} \approx \mathbf{P}^\top \mathbf{Q}
$$
其中 $\mathbf{R} \in \mathbb{R}^{m \times n}$,$\mathbf{P} \in \mathbb{R}^{k \times m}$,$\mathbf{Q} \in \mathbb{R}^{k \times n}$。

**损失函数**:
$$
\mathcal{L} = \sum_{(i,j) \in \Omega} (r_{ij} - \mathbf{p}_i^\top \mathbf{q}_j)^2 + \lambda(\|\mathbf{P}\|_F^2 + \|\mathbf{Q}\|_F^2)
$$

其中 $\Omega$ 是观测到的交互集合。

**SGD 更新**:
$$
\mathbf{p}_i \leftarrow \mathbf{p}_i + \eta((r_{ij} - \hat{r}_{ij})\mathbf{q}_j - \lambda \mathbf{p}_i)
$$
$$
\mathbf{q}_j \leftarrow \mathbf{q}_j + \eta((r_{ij} - \hat{r}_{ij})\mathbf{p}_i - \lambda \mathbf{q}_j)
$$

### 4.3 隐式反馈与显式反馈

| 类型 | 数据 | 偏好信号 | 例子 |
| :--- | :--- | :--- | :--- |
| 显式 | 评分(1-5 星) | 强 | 用户打分 |
| 隐式 | 点击/购买/停留 | 中 | 点击率 |
| 隐式负样本 | 曝光未点击 | 弱 | 曝光数据 |
| 行为序列 | 点击 + 时长 | 强 | 多步交互 |

### 4.4 行为序列的语义

**用户行为序列**:
$$
\mathcal{S}_u = \{(i_1, t_1, a_1), (i_2, t_2, a_2), ..., (i_n, t_n, a_n)\}
$$
其中 $i_k$ 是商品 ID,$t_k$ 是时间戳,$a_k$ 是行为类型。

**行为类型分级**:
1. **强正反馈**:购买、收藏、加购 → weight = 1.0
2. **正反馈**:点赞、完播 → weight = 0.7
3. **弱正反馈**:点击、滑动 → weight = 0.3
4. **负反馈**:点踩、跳出 → weight = -0.5
5. **曝光无点击**:weight = -0.1

## 5. 行为增强 SID 的算法

### 5.1 两阶段方法 (Two-Stage)

**Stage 1: 内容 SID 生成**
- 用文本/图像生成基础 SID
- 不依赖行为数据
- 适合冷启动

**Stage 2: 行为增强 SID 生成**
- 基于内容 SID + 行为数据
- 重新训练/微调编码器
- 适合热门 + 长尾

**融合方式**:
$$
\text{SID}_{\text{enhanced}} = \alpha \cdot \text{SID}_{\text{content}} + \beta \cdot \text{SID}_{\text{behavior}}
$$

### 5.2 联合训练方法 (Joint Training)

**总损失**:
$$
\mathcal{L} = \mathcal{L}_{\text{content}} + \gamma \mathcal{L}_{\text{behavior}}
$$

其中:
- $\mathcal{L}_{\text{content}}$:内容重建损失、对比损失
- $\mathcal{L}_{\text{behavior}}$:协同过滤损失(如 BPR)

**BPR 损失**:
$$
\mathcal{L}_{\text{BPR}} = -\sum_{(u, i^+, i^-)} \log \sigma(\hat{r}_{ui^+} - \hat{r}_{ui^-}) + \lambda \|\Theta\|^2
$$

其中 $i^+$ 是正样本,$i^-$ 是负样本。

### 5.3 自监督行为增强

**思路**:不依赖显式监督,行为数据自监督。

**对比学习**:
- 同用户的不同时间窗口行为 = 正样本
- 不同用户的行为 = 负样本
- 损失:InfoNCE

**代码**:
```python
class BehaviorContrastiveLearning(nn.Module):
    """行为对比学习"""
    def __init__(self, dim=768, temperature=0.07):
        super().__init__()
        self.temperature = temperature
        self.proj = nn.Linear(dim, dim)

    def forward(self, user_seq_emb, other_user_emb):
        """
        user_seq_emb: [B, dim], 用户行为序列表征
        other_user_emb: [B, dim], 其他用户表征(负样本)
        """
        z = F.normalize(self.proj(user_seq_emb), dim=-1)
        z_other = F.normalize(self.proj(other_user_emb), dim=-1)
        sim = z @ z_other.T / self.temperature
        labels = torch.arange(z.size(0)).to(z.device)
        return F.cross_entropy(sim, labels)
```

### 5.4 协同语义 (Collaborative Semantics)

**核心思想**:让 SID 表征不仅描述商品"是什么",还反映"被谁喜欢"。

**协同语义注入**:
1. **Embedding Co-training**:与用户/商品 ID embedding 联合训练
2. **Side Information**:把用户-商品交互作为额外特征
3. **Pre-training**:先做内容预训练,再做协同微调

### 5.5 三种主流融合架构

**架构 A:Concat 融合**
$$
\mathbf{e}_{\text{enhanced}} = [\mathbf{e}_{\text{content}}; \mathbf{e}_{\text{behavior}}]
$$

**架构 B:门控融合**
$$
\mathbf{g} = \sigma(\mathbf{W}_g [\mathbf{e}_{\text{content}}; \mathbf{e}_{\text{behavior}}])
$$
$$
\mathbf{e}_{\text{enhanced}} = \mathbf{g} \odot \mathbf{e}_{\text{content}} + (1-\mathbf{g}) \odot \mathbf{e}_{\text{behavior}}
$$

**架构 C:Cross-Attention 融合**
$$
\mathbf{e}_{\text{enhanced}} = \text{CrossAttn}(\mathbf{e}_{\text{content}}, \mathbf{e}_{\text{behavior}})
$$

### 5.6 行为增强的 PyTorch 实现

```python
class BehaviorEnhancedSIDEncoder(nn.Module):
    """行为增强的 SID 编码器"""
    def __init__(self, content_dim=768, behavior_dim=256, hidden_dim=512,
                 codebook_sizes=[256, 256, 256]):
        super().__init__()
        # 内容编码器(冻结或微调)
        self.content_encoder = ContentEncoder()  # ViT + Text + Q-Former
        # 行为编码器(从用户-商品交互学习)
        self.behavior_encoder = BehaviorEncoder(behavior_dim)
        # 融合
        self.fusion = GatedFusion(content_dim, behavior_dim, hidden_dim)
        # RQ-VAE
        self.rqvae = RQVAE(hidden_dim, codebook_sizes)

    def forward(self, item_content, behavior_seq):
        """
        item_content: 内容特征(图像、文本)
        behavior_seq: [B, L, behavior_dim], 该商品的行为上下文
        """
        content_emb = self.content_encoder(item_content)  # [B, content_dim]
        behavior_emb = self.behavior_encoder(behavior_seq)  # [B, behavior_dim]
        # 门控融合
        fused = self.fusion(content_emb, behavior_emb)  # [B, hidden_dim]
        # RQ 量化
        sid, commit_loss = self.rqvae(fused)
        return sid, commit_loss


class GatedFusion(nn.Module):
    """门控融合"""
    def __init__(self, dim_a, dim_b, out_dim):
        super().__init__()
        self.proj_a = nn.Linear(dim_a, out_dim)
        self.proj_b = nn.Linear(dim_b, out_dim)
        self.gate = nn.Sequential(
            nn.Linear(dim_a + dim_b, out_dim),
            nn.Sigmoid()
        )

    def forward(self, a, b):
        a_proj = self.proj_a(a)
        b_proj = self.proj_b(b)
        g = self.gate(torch.cat([a, b], dim=-1))
        return g * a_proj + (1 - g) * b_proj


class BehaviorEncoder(nn.Module):
    """行为编码器:把用户对该商品的所有交互编码"""
    def __init__(self, behavior_dim=256):
        super().__init__()
        self.proj = nn.Linear(behavior_dim, 256)
        self.attn = nn.MultiheadAttention(256, 8, batch_first=True)
        self.norm = nn.LayerNorm(256)

    def forward(self, behavior_seq):
        # behavior_seq: [B, L, behavior_dim]
        x = self.proj(behavior_seq)  # [B, L, 256]
        attn_out, _ = self.attn(x, x, x)
        return self.norm(attn_out.mean(dim=1))  # [B, 256]
```

## 6. 行为信号的工程化

### 6.1 行为数据预处理

```python
class BehaviorDataProcessor:
    """行为数据预处理 Pipeline"""
    def __init__(self, lookback_days=30):
        self.lookback_days = lookback_days

    def process_user_item_behavior(self, user_id, item_id, behavior_logs):
        """处理用户-商品行为数据"""
        # 1. 时间窗口过滤
        cutoff = datetime.now() - timedelta(days=self.lookback_days)
        recent = [b for b in behavior_logs if b['time'] > cutoff]
        # 2. 行为权重
        weights = []
        for b in recent:
            w = self._behavior_weight(b['type'])
            if w is not None:
                weights.append(w * self._time_decay(b['time']))
        # 3. 聚合
        if not weights:
            return torch.zeros(behavior_dim)
        agg = torch.tensor(weights).mean()
        return self._to_feature_vector(agg, recent)

    def _behavior_weight(self, action_type):
        return {
            'purchase': 1.0,
            'favorite': 0.8,
            'cart': 0.6,
            'like': 0.5,
            'click': 0.3,
            'view_3s': 0.2,
            'view': 0.1,
            'skip': -0.1
        }.get(action_type, None)

    def _time_decay(self, time):
        # 时间衰减:越近的行为权重越高
        days_ago = (datetime.now() - time).days
        return math.exp(-days_ago / 30)
```

### 6.2 行为序列的 embedding

**关键设计**:
1. **时间编码**:不同时间的行为不同权重
2. **行为类型编码**:不同 action 用不同 embedding
3. **序列建模**:LSTM / Transformer 编码序列

```python
class ActionEmbedding(nn.Module):
    """行为动作的 embedding"""
    def __init__(self, n_actions=10, dim=64):
        super().__init__()
        self.action_emb = nn.Embedding(n_actions, dim)
        self.time_proj = nn.Linear(1, dim)

    def forward(self, action_id, time_delta):
        a = self.action_emb(action_id)
        t = self.time_proj(time_delta.unsqueeze(-1).float())
        return a + t
```

### 6.3 冷启动的行为回填

**场景**:新商品无行为,需要预估"虚拟行为"。

**方法**:
1. **基于相似商品**:找最相似的 K 个老商品,行为均值作为虚拟行为
2. **基于内容预测**:用内容模型预测行为概率
3. **基于用户相似度**:喜欢类似商品的用户,可能也喜欢这个新商品

```python
def virtual_behavior_for_new_item(new_item, similar_items, behavior_data):
    """为新商品生成虚拟行为"""
    if not similar_items:
        return torch.zeros(behavior_dim)
    # 加权平均行为
    behaviors = []
    weights = []
    for sim_item in similar_items:
        b = behavior_data[sim_item['item_id']]
        w = sim_item['similarity']
        behaviors.append(b)
        weights.append(w)
    weights = torch.tensor(weights)
    weights = weights / weights.sum()
    behaviors = torch.stack(behaviors)
    return (weights.unsqueeze(-1) * behaviors).sum(dim=0)
```

## 7. 协同过滤的深度学习化

### 7.1 NCF (Neural Collaborative Filtering)

**架构**:
```text
User ID → Embedding → [GMF, MLP] → Concat → 预测
Item ID → Embedding → [GMF, MLP] ↗
```

**GMF 部分**: element-wise product,捕捉线性交互
**MLP 部分**: 多层非线性,捕捉复杂交互

### 7.2 双塔模型 (Two-Tower)

**用户塔**:用户特征 → user embedding
**商品塔**:商品特征(可包含内容 + 行为) → item embedding
**相似度**:$\text{sim}(u, i) = \cos(\mathbf{e}_u, \mathbf{e}_i)$

**优势**:可离线预计算商品 embedding,在线只算用户,速度快。

### 7.3 图神经网络 (GNN) 协同过滤

**LightGCN**:简化版 GCN,只用邻居聚合
$$
\mathbf{e}_u^{(k+1)} = \sum_{i \in \mathcal{N}(u)} \frac{1}{\sqrt{|\mathcal{N}(u)| |\mathcal{N}(i)|}} \mathbf{e}_i^{(k)}
$$
$$
\mathbf{e}_u = \sum_{k=0}^{K} \alpha_k \mathbf{e}_u^{(k)}
$$

**对 SID 的启示**:可以预训练 GNN 得到商品 embedding,然后量化得到 SID。

### 7.4 行为序列模型

**DIN (Deep Interest Network)**:
- 用户历史序列用 attention 加权
- attention weight 由候选商品决定
- "局部激活"用户兴趣

**DIN 数学**:
$$
\mathbf{e}_u = \sum_{j \in \text{history}} \text{Attention}(\mathbf{e}_j, \mathbf{e}_i) \cdot \mathbf{v}_j
$$
$$
\text{Attention}(\mathbf{e}_j, \mathbf{e}_i) = \frac{\exp(\text{MLP}(\mathbf{e}_j, \mathbf{e}_i))}{\sum_{k} \exp(\text{MLP}(\mathbf{e}_k, \mathbf{e}_i))}
$$

### 7.5 SASRec / BERT4Rec

**SASRec**:Self-Attentive Sequential Recommendation
- 单向 Transformer 编码用户序列
- 预测下一个商品

**BERT4Rec**:双向 Transformer
- Mask 预测(Cloze 任务)
- 训完后,取 [CLS] embedding 作为用户表征

**对 SID 的启示**:这些模型的中间层输出,可作为商品的"协同 embedding"。

## 9. 行为增强 SID 的挑战与局限

### 9.1 冷启动悖论

**矛盾**:
- 行为增强 SID 效果好 → 热门商品表现好
- 但冷启动商品没有行为 → 行为增强 SID 无效
- 长尾商品有少量行为 → 行为信号噪声大

**解决**:
1. **混合策略**:冷启动用内容 SID,有行为后切换
2. **少样本学习**:few-shot learning,见 [下一章](../第05章-统一语义空间与冷启动/第05章-03-冷启动数学解释.md)
3. **数据增强**:用相似商品的行为补充

### 9.2 行为稀疏性

**现实**:
- 95% 商品交互 < 10 次
- 长尾商品几乎无行为

**处理**:
- **数据增强**:相似商品行为共享
- **迁移学习**:从热门商品迁移
- **正则化**:行为信号做 L2 约束

### 9.3 行为偏差

**常见偏差**:
1. **位置偏差**:用户倾向于点击靠前的商品
2. **曝光偏差**:没曝光过的商品没数据
3. **流行度偏差**:热门商品行为更多

**解决**:
- **逆倾向加权 (IPW)**:$w = 1/P(\text{exposure})$
- **位置特征**:把位置作为额外特征
- **探索机制**:UCB / Thompson sampling

### 9.4 行为信号的时效性

**问题**:用户兴趣会变化,旧行为可能不相关。

**处理**:
1. **时间衰减**:$w = e^{-\lambda \Delta t}$
2. **滑动窗口**:只用最近 N 天的行为
3. **新鲜度特征**:把商品发布时间作为特征

## 10. 高级话题

### 10.1 多行为融合 (Multi-Behavior)

**场景**:用户有多种行为(浏览、加购、购买、分享)

**方法**:
- **Graph**:每种行为建一个图,最后融合
- **Attention**:不同行为用不同 attention
- **Meta-learning**:学习"如何融合"

**MBGCN (Multi-Behavior GCN)**:
$$
\mathbf{e}_u^{(k+1)} = \sum_{b \in \text{behaviors}} \alpha_b \cdot \text{GCN}_b(\mathbf{e}_u^{(k)})
$$

### 10.2 跨域行为迁移

**场景**:用户在 A 域的行为,辅助 B 域推荐。

**方法**:
1. **共享 embedding**:用户跨域共享 ID embedding
2. **EMCDR**:Embedding mapping
   $$\mathbf{e}_u^B = f(\mathbf{e}_u^A) = \mathbf{W}\mathbf{e}_u^A + \mathbf{b}$$
3. **PPGN**:Path-based 跨域图

### 10.3 行为与内容的因果建模

**问题**:行为相关性 ≠ 因果

**反事实推理**:
- 用户喜欢商品 X → 点击商品 Y
- 但 Y 的相似商品 Z,用户不一定点

**因果图**:
- 内容 → 兴趣 → 行为
- 兴趣是隐变量,需通过 do-calculus 推断

**应用**:
- **CausalRec**:因果增强的推荐
- **DeepRec**:反事实推理

### 10.4 隐私保护的行为建模

**挑战**:行为数据敏感,用户隐私要求高。

**方案**:
1. **联邦学习**:行为数据不出本地
2. **差分隐私**:行为 embedding 加噪
3. **同态加密**:加密计算相似度
4. **TEE**:可信执行环境

## 11. 面试高频问题

### Q1: 协同过滤和内容过滤的优缺点?

**答**:
- **协同过滤**:优点是能发现隐式偏好、群体智慧;缺点是冷启动差、稀疏问题
- **内容过滤**:优点是可解释、无冷启动;缺点是难以捕捉隐性偏好、过度依赖特征质量
- **实际系统**:两者融合,内容治冷启动,协同治长尾

### Q2: 行为增强 SID 如何处理冷启动?

**答**:三种策略:
1. **混合策略**:冷启动用内容 SID,有行为后切换到行为增强 SID
2. **数据增强**:用相似商品的行为补充
3. **渐进式融合**:行为信号权重随时间增加,从纯内容 → 50/50 → 纯行为

### Q3: BPR 损失和普通 BCE 损失的区别?

**答**:
- **BPR**:基于 pairwise ranking,$\log \sigma(\hat{r}_+ - \hat{r}_-)$,优化排序
- **BCE**:基于 pointwise,$-\log \sigma(\hat{r})$,优化绝对值
- **BPR 更适合推荐**:推荐关心排序,不关心绝对分数
- **BPR 不需要负样本标签**:只需"未交互的商品"作为负样本

### Q4: DIN 和普通 Attention 的区别?

**答**:
- **普通 Attention**:query-key-value 都来自同一序列
- **DIN Attention**:query 是候选商品,key/value 是用户历史
- **DIN 的 attention 是局部激活的**:用户历史中只有与候选商品相关的兴趣被激活
- **DIN 本质**:候选商品自适应的兴趣提取

### Q5: SASRec 和 DIN 的区别?

**答**:
- **SASRec**:用户序列内部 attention,单向 Transformer
- **DIN**:候选-历史 attention,无序列内 attention
- **SASRec 强**:长序列、全局模式
- **DIN 强**:候选相关、个性化 attention
- **工业常用 DIEN (DIN 演化版)**:序列 GRU + attention 抽取兴趣演化

### Q6: 协同语义注入会导致内容语义被淹没吗?

**答**:会!需要平衡:
1. **正则化**:$\mathcal{L} = \mathcal{L}_{\text{content}} + \lambda \mathcal{L}_{\text{collab}}$,$\lambda$ 不能太大
2. **解耦**:内容部分和协同部分分开,只在末端融合
3. **两阶段**:先内容预训练,再协同微调,内容损失保留
4. **多任务**:每个任务独立的输出头

### Q7: 如何评估行为增强 SID 的效果?

**答**:多维度评估:
1. **冷启动**:新品 CTR/Recall
2. **长尾**:长尾商品 CTR 提升
3. **行为一致性**:点击预测准确率
4. **A/B 测试**:CTR、GMV、留存
5. **冷热对比**:热门商品是否变差(防止过拟合长尾)

### Q8: 行为数据中的位置偏差怎么处理?

**答**:
1. **位置特征**:把位置作为输入特征
2. **IPW**:逆倾向加权,$w = 1/P(\text{position})$
3. **PAL**:Position-aware learning,加位置约束
4. **全位置随机**:线上随机化部分流量收集无偏数据
5. **两塔去偏**:用户-商品相关性预测 + 位置偏差预测,分开

### Q9: 行为稀疏性如何处理?

**答**:
1. **Embedding 共享**:相似商品共享 embedding
2. **Few-shot learning**:Meta-learning 学习快速适应
3. **数据增强**:相似商品行为均值
4. **正则化**:$\ell_2$、Dropout 防止过拟合
5. **混合模型**:高频用行为 ID,低频用内容

### Q10: 协同过滤的隐向量维度怎么选?

**答**:
- **经验法则**:$\min(m,n)^{1/4}$,其中 $m$ 是用户数,$n$ 是商品数
- **太小**:欠拟合,无法捕捉复杂模式
- **太大**:过拟合,泛化差
- **工业实践**:64~256 维,网格搜索调优
- **AutoML**:NAS 自动选维度

### 12.1 完整的行为增强 SID 训练流程

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class FullBehaviorEnhancedSIDPipeline:
    """完整的行为增强 SID 训练 Pipeline"""
    def __init__(self, config):
        self.config = config
        # 内容编码器(可用预训练 ViT+BERT)
        self.content_encoder = self._build_content_encoder()
        # 行为编码器
        self.behavior_encoder = self._build_behavior_encoder()
        # 融合
        self.fusion = GatedFusion(
            dim_a=768, dim_b=256, out_dim=512
        )
        # RQ-VAE 量化
        self.rqvae = RQVAE(
            input_dim=512,
            codebook_sizes=[256, 256, 256],
            codebook_dim=32
        )
        # 优化器
        self.optimizer = torch.optim.AdamW([
            {'params': self.content_encoder.parameters(), 'lr': 1e-5},
            {'params': self.behavior_encoder.parameters(), 'lr': 1e-3},
            {'params': self.fusion.parameters(), 'lr': 1e-4},
            {'params': self.rqvae.parameters(), 'lr': 5e-4}
        ], weight_decay=0.01)

    def train_step(self, batch):
        """单步训练"""
        # 1. 内容特征
        img = batch['image'].cuda()
        txt = batch['text'].cuda()
        content_emb = self.content_encoder(img, txt)  # [B, 768]
        # 2. 行为特征
        behavior_seq = batch['behavior'].cuda()  # [B, L, 256]
        behavior_emb = self.behavior_encoder(behavior_seq)  # [B, 256]
        # 3. 融合
        fused = self.fusion(content_emb, behavior_emb)  # [B, 512]
        # 4. RQ 量化
        sid_pred, commit_loss = self.rqvae(fused)
        # 5. 计算损失
        # 内容重建损失
        recon = self.rqvae.decode(sid_pred)
        loss_content = F.mse_loss(recon, fused.detach())
        # 协同 BPR 损失(基于用户-商品交互)
        loss_bpr = self._compute_bpr_loss(fused, batch)
        # 总损失
        loss = loss_content + 0.5 * loss_bpr + 0.25 * commit_loss
        # 反向
        self.optimizer.zero_grad()
        loss.backward()
        torch.nn.utils.clip_grad_norm_(self.parameters(), 1.0)
        self.optimizer.step()
        return {
            'loss': loss.item(),
            'loss_content': loss_content.item(),
            'loss_bpr': loss_bpr.item(),
            'commit_loss': commit_loss.item()
        }

    def _compute_bpr_loss(self, item_emb, batch):
        """BPR 损失"""
        user_emb = batch['user_emb'].cuda()  # [B, 256]
        pos_emb = item_emb  # 当前商品
        # 采样负样本
        neg_idx = torch.randint(0, self.config.n_items, (item_emb.size(0),)).cuda()
        neg_emb = self._get_item_embedding(neg_idx)
        # BPR
        pos_score = (user_emb * pos_emb).sum(dim=-1)
        neg_score = (user_emb * neg_emb).sum(dim=-1)
        loss = -F.logsigmoid(pos_score - neg_score).mean()
        return loss
```

```python
class BehaviorAugmentedSampler:
    """行为增强采样器"""
    def __init__(self, interaction_data, n_neg=4):
        self.interactions = interaction_data
        self.n_neg = n_neg

        # 1. 采样正样本(用户点击过的商品)

        neg_samples = self._sample_negatives(
            [s['user_id'] for s in pos_samples]

            'user_id': [...],
```

```python
def diagnose_ab_test(exp_data, ctrl_data):
    """A/B 测试诊断"""
    metrics = {}
    # 1. 分桶流量均衡性
    metrics['traffic_balance'] = abs(
        exp_data['user_count'] - ctrl_data['user_count']
    ) / ctrl_data['user_count']
    # 2. 关键指标差异
    for metric in ['ctr', 'gmv', 'retention']:
        ctrl_mean = ctrl_data[metric].mean()
        exp_mean = exp_data[metric].mean()
        lift = (exp_mean - ctrl_mean) / ctrl_mean
        metrics[f'{metric}_lift'] = lift
    # 3. 显著性
    from scipy import stats
    _, p = stats.ttest_ind(exp_data['ctr'], ctrl_data['ctr'])
    metrics['p_value'] = p
    return metrics
```

```python
class CurriculumTrainer:
    """课程学习训练器"""
    def __init__(self, model, config):
        self.model = model
        self.config = config

    def train(self):
        for epoch in range(self.config.n_epochs):
            # 阶段 1: 纯内容
            if epoch < self.config.content_epochs:
                weight_behavior = 0.0
            # 阶段 2: 内容为主,行为辅助
            elif epoch < self.config.content_behavior_epochs:
                progress = (epoch - self.config.content_epochs) / (
                    self.config.content_behavior_epochs - self.config.content_epochs
                )
                weight_behavior = 0.5 * progress
            # 阶段 3: 内容 + 行为均衡
            else:
                weight_behavior = 0.5
            for batch in self.dataloader:
                loss = self.model.compute_loss(batch)
                total_loss = loss['content'] + weight_behavior * loss['behavior']
                total_loss.backward()
                self.optimizer.step()
```

### 20.2 时间感知的训练

**核心**:最近的行为比远期行为更重要。

```python
class TimeAwareSampler:
    """时间感知采样器"""
    def __init__(self, decay_factor=0.95):
        self.decay = decay_factor

    def sample_weights(self, behaviors):
        """为每个行为分配权重,最近行为权重大"""
        now = time.time()
        weights = []
        for b in behaviors:
            days_ago = (now - b['time']) / 86400
            w = self.decay ** days_ago
            weights.append(w)
        return np.array(weights)

    def weighted_sample(self, behaviors, n):
        """按权重采样"""
        weights = self.sample_weights(behaviors)
        weights = weights / weights.sum()
        idx = np.random.choice(len(behaviors), size=n, replace=False, p=weights)
        return [behaviors[i] for i in idx]
```

```python
class IncrementalTrainer:
    """增量训练器"""
    def __init__(self, model, old_model=None):
        self.model = model
        self.old_model = old_model  # 用于蒸馏

    def train_step(self, new_batch):
        # 1. 新数据损失
        loss_new = self.model.compute_loss(new_batch)
        # 2. 蒸馏损失(防止遗忘)
        if self.old_model is not None:
            with torch.no_grad():
                old_output = self.old_model(new_batch)
            new_output = self.model(new_batch)
            loss_distill = F.kl_div(
                F.log_softmax(new_output, dim=-1),
                F.softmax(old_output, dim=-1),
                reduction='batchmean'
            )
            loss = loss_new + 0.5 * loss_distill
        else:
            loss = loss_new
        return loss
```

### 21.3 PCGrad (Projecting Conflicting Gradients)

**思想**:任务梯度冲突时,投影到不冲突方向。

```python
def pcgrad_step(losses, shared_params):
    """PCGrad:处理多任务梯度冲突"""
    # 1. 计算每个任务的梯度
    grads = []
    for loss in losses:
        g = torch.autograd.grad(loss, shared_params, retain_graph=True)
        grads.append(g)
    # 2. 对每对任务,投影冲突梯度
    for i in range(len(losses)):
        for j in range(len(losses)):
            if i == j:
                continue
            # 检查是否冲突
            g_i = grads[i]
            g_j = grads[j]
            dot_product = sum((a * b).sum() for a, b in zip(g_i, g_j))
            if dot_product < 0:  # 冲突
                # 投影 g_i 到 g_j 的正交方向
                proj = dot_product / sum((b * b).sum() for b in g_j)
                g_i = [a - proj * b for a, b in zip(g_i, g_j)]
                grads[i] = g_i
    # 3. 应用平均梯度
    avg_grad = [sum(g[k] for g in grads) / len(grads) for k in range(len(grads[0]))]
    for p, g in zip(shared_params, avg_grad):
        p.grad = g
```

## 22. 行为增强的离线评估

### 22.1 评估指标详解

**Recall@K**:
$$
\text{Recall@K} = \frac{1}{|U|}\sum_{u \in U} \frac{|\text{TopK}_u \cap \text{Relevant}_u|}{|\text{Relevant}_u|}
$$

**NDCG@K**:
$$
\text{NDCG@K} = \frac{1}{\text{IDCG@K}}\sum_{i=1}^{K} \frac{2^{rel_i} - 1}{\log_2(i+1)}
$$

**Hit Rate@K**:
$$
\text{HR@K} = \frac{1}{|U|}\sum_{u \in U} \mathbb{1}[\text{Relevant}_u \cap \text{TopK}_u \neq \emptyset]
$$

### 22.2 冷启动专项评估

## 23. 强化学习与 SID

### 23.1 RL 视角下的推荐

**MDP 框架**:
- **状态 $s_t$**:用户历史 + 当前上下文
- **动作 $a_t$**:推荐的商品(SID)
- **奖励 $r_t$**:点击 + 0.3, 购买 + 1.0, 跳过 -0.1
- **策略 $\pi(a|s)$**:推荐策略

**目标**:最大化长期奖励 $\sum_{t} \gamma^t r_t$

### 23.2 Deep Q-Network (DQN) for RecSys

**DQN 损失**:
$$
\mathcal{L}_{\text{DQN}} = (r_t + \gamma \max_{a'} Q(s_{t+1}, a') - Q(s_t, a_t))^2
$$

**SID 作为 action space**:
- 每个商品 → SID
- action = 选择某个 SID
- Q 值 = 用户-商品 CTR 预估

### 23.3 Actor-Critic 框架

**Actor**:$\pi_\theta(a|s)$,策略网络
**Critic**:$V_\phi(s)$,价值网络

**梯度**:
$$
\nabla_\theta J = \mathbb{E}[\nabla_\theta \log \pi_\theta(a|s) \cdot (r - V_\phi(s))]
$$

### 23.4 RL + SID 的应用

**淘宝"猜你喜欢"**:
- 状态:用户近 7 天行为
- 动作:推荐 50 个商品
- 奖励:CTR + GMV

**抖音推荐**:
- 状态:用户最近 5 个视频
- 动作:下一个视频
- 奖励:完播 + 点赞 + 关注

```python
def ab_test_analysis(exp_data, ctrl_data, metrics):

    results = {}
    for metric in metrics:
        ctrl_val = ctrl_data[metric].mean()
        exp_val = exp_data[metric].mean()
        lift = (exp_val - ctrl_val) / ctrl_val
        # t 检验
        from scipy import stats
        t_stat, p_value = stats.ttest_ind(
            exp_data[metric], ctrl_data[metric]
```

```python
    """MoE 行为增强 SID"""
    def __init__(self, n_experts=4, dim=512):
        super().__init__()
        # 内容专家
        self.content_experts = nn.ModuleList([
            ContentExpert() for _ in range(n_experts)
        ])
        # 行为专家
        self.behavior_experts = nn.ModuleList([
            BehaviorExpert() for _ in range(n_experts)
        ])
        # 路由器
        self.gate = nn.Linear(dim, n_experts)

    def forward(self, content, behavior):
        # 路由
        gate_input = torch.cat([content.mean(-1, keepdim=True),
                                behavior.mean(-1, keepdim=True)], dim=-1)
        weights = F.softmax(self.gate(gate_input), dim=-1)  # [B, n_experts]
        # 各专家输出
        outputs = []
        for i in range(self.n_experts):
            c_e = self.content_experts[i](content)
            b_e = self.behavior_experts[i](behavior)
            outputs.append(c_e + b_e)
        # 加权融合
        result = sum(w.unsqueeze(-1) * o for w, o in zip(weights.unbind(-1), outputs))
        return result
```

### 29.3 MoE 的负载均衡

**问题**:路由器倾向于选部分专家,其他专家闲置。

**辅助损失**:
$$
\mathcal{L}_{\text{load}} = \alpha \sum_{i=1}^{E} \left(\frac{1}{B}\sum_{j=1}^{B} p_{ij}\right) \left(\frac{1}{B}\sum_{j=1}^{B} f_{ij}\right)
$$

其中 $p_{ij}$ 是路由器概率,$f_{ij}$ 是实际路由到专家 $i$ 的比例。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "3-行为增强的SID" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
