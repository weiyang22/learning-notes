# 3. 混合粒度的码本设计

> **本章定位**: 怎么设计层次化的码本
> **预计时长**: 45 分钟

---

## 3.1 粒度的概念

```text
粗粒度 (c1): 类目(电子/服装/食品)   →  1024 码
中粒度 (c2): 品牌(苹果/三星)        →   512 码
细粒度 (c3): 型号(iPhone 15/16)     →   256 码
更细 (c4):  配置(256GB/512GB)       →   256 码
最细 (c5):  颜色(黑色/白色)          →   128 码
```

---

## 3.2 混合粒度的优势

- **粗粒度**: 召回快,语义广
- **细粒度**: 排序准,语义精

## 3.4 层次性从哪来:RQ 的残差结构

为什么"靠前码字=粗类、靠后=细节"?这来自 **残差量化的机制**:第一层 KMeans 在完整 embedding 上聚类 → 抓最大方差方向(粗粒度类目);后续层在**残差**上聚类 → 抓越来越细的差异(见 [第03章-01 RQ-VAE核心](../第03章-RQ-VAE与残差量化/第03章-01-RQ-VAE的核心思想.md))。

> 所以层次性是 RQ 的**自然倾向**,但"c1恰好=类目"需要验证/引导,不是保证(见 [第10章-05 可解释性前提](../第10章-SID与下游任务集成/第10章-05-SID与冷启动与可解释性.md))。

---

## 3.5 码本大小的分配原则

粗层码本大、细层码本小的直觉:

- **粗粒度需大码本**:类目/主题种类多,要足够码字区分;且这层碰撞代价最大(错了整个语义就偏)。
- **细粒度可小码本**:在已确定粗类的残差上,细分选项有限(同型号手机就几种颜色)。
- **容量守恒**:总表达力 $\prod K_l$ 要覆盖物料量并留冗余(见 [第12章-03 Scaling](../第12章-生成式检索与约束解码/第12章-03-SID生成模型的Scaling.md)),按层分配而非平均。

---

## 3.6 混合粒度的下游用法

层次结构支持**由粗到细**的检索/排序:

| 用法 | 利用哪层 |
| :--- | :--- |
| 粗召回(前缀分桶) | c1-c2(快、广) |
| 精排特征 | 全部码字(准) |
| 多样性打散 | 按 c1 去重(不同类目) |
| 可解释 | 逐层贴标签 |

这是 SID 相对"扁平向量"的独特价值——一套编码同时支持多粒度操作。

## A.1 什么是"粒度"——再定义

### A.1.1 三层粒度模型

SID 的粒度本质是 **embedding 空间中语义层次的反映**。我们用三层模型来理解：

```text
细粒度 (Fine-grained):   区分个体 → "iPhone 15 黑色 256GB"
中粒度 (Mid-grained):    区分品类 → "iPhone 15 系列"
粗粒度 (Coarse-grained): 区分大类 → "手机"
```

这种三层模型可以推广到 N 层：

$$G = \{g_1, g_2, \dots, g_N\}, \quad g_1 \succ g_2 \succ \dots \succ g_N$$

其中 $\succ$ 表示"粒度更细"。

### A.1.2 粒度的形式化

设物品 $i$ 的 SID 为 $s_i = (c_1, c_2, \dots, c_L)$，其中 $c_l$ 是第 $l$ 层的码。定义**粒度函数**：

$$\text{grain}(l) = \frac{1}{K_l} \sum_{k=1}^{K_l} P(c_l = k) \cdot \text{Entropy}(c_l = k)$$

直觉上：
- 粗粒度：码本小但语义广 → 熵大
- 细粒度：码本大但语义窄 → 熵小

### A.1.3 RQ-VAE 自然涌现层次

RQ-VAE 训练后，每层码的**实际熵**会自然分化：

```python
# 统计每层码的熵
def per_layer_entropy(sids):
    """sids: [N, L]"""
    L = sids.shape[1]
    entropies = []
    for l in range(L):
        counts = np.bincount(sids[:, l], minlength=K_l)
        probs = counts / counts.sum()
        entropy = -(probs * np.log(probs + 1e-9)).sum()
        entropies.append(entropy)
    return entropies  # 一般 entropies[0] > entropies[1] > ... > entropies[L-1]
```

经验数据：

| 层 | 平均熵 | 含义 |
| :--- | :--- | :--- |
| c1 | 5.2 | 类目级（8-16 个大类） |
| c2 | 4.5 | 品牌/系列 |
| c3 | 3.8 | 型号 |
| c4 | 2.9 | 配置 |
| c5 | 1.8 | 颜色 |

→ **层次是涌现的**，但需要监督引导（如类目约束）。

## A.2 混合粒度的优势深度分析

### A.2.1 召回阶段：粗粒度优先

**动机**：召回阶段需要从海量物品中快速筛出候选。如果用细粒度，需要遍历所有物品，计算量 $O(N)$；用粗粒度先分桶，再在桶内检索，计算量降为 $O(N/K_1)$。

```text
1M 物品, 1024 桶 → 每桶 ~1000 物品
桶内检索 P99 < 5 ms
vs 全量 P99 < 50 ms
```

**例**：

```python
# 粗粒度分桶
def coarse_bucket_recall(query_emb, rqvae, buckets, k=100):
    # 1) query → 粗粒度码 c1
    c1 = rqvae.encode(query_emb)[0, 0]  # 第一层码

    # 2) 在 c1 桶里找 top-K
    candidates = buckets[c1]

    # 3) 桶内 ANN 检索
    candidate_embs = np.array([sid_to_emb(sid) for sid in candidates])
    scores = candidate_embs @ query_emb
    top_k_idx = np.argsort(-scores)[:k]
    return [candidates[i] for i in top_k_idx]
```

### A.2.2 排序阶段：全粒度

排序阶段使用全部 5 层码作为特征：


### A.2.3 多样性打散

按 c1 分桶做多样性：

```python
def rerank_diversity(candidates, scores, sids, lambda_div=0.3, top_k=100):
    """MMR 重排, 按 c1 多样性"""
    selected = []
    c1_count = defaultdict(int)

    while len(selected) < top_k and candidates:
        best_idx = -1
        best_score = -float('inf')
        for i, (item, score) in enumerate(zip(candidates, scores)):
            c1 = sids[item][0]
            penalty = lambda_div * c1_count[c1]
            mmr = score - penalty
            if mmr > best_score:
                best_score = mmr
                best_idx = i

        selected.append(candidates[best_idx])
        c1_count[sids[candidates[best_idx]][0]] += 1
        candidates.pop(best_idx)

    return selected
```

## A.3 码本大小的分配原则——深度数学

### A.3.1 容量守恒

总表达力：

$$C = \prod_{l=1}^{L} K_l$$

需满足：

$$C \ge N \cdot \alpha$$

其中 $N$ 是物品量，$\alpha$ 是冗余系数（建议 $\alpha \ge 2$）。

### A.3.2 分配策略

**策略 1：等比分配**

$$K_l = K_0 \cdot r^{L-l}$$

其中 $K_0$ 是第一层码本大小，$r$ 是衰减率（如 0.5）。

**例**：$L=5, K_0=1024, r=0.5$ → $K = [1024, 512, 256, 128, 64]$，总容量 $1024 \cdot 512 \cdot 256 \cdot 128 \cdot 64 = 1.1 \times 10^{12}$

**策略 2：等容量分配**

让每层独立表达力相同：$K_l = C^{1/L}$。

**例**：$L=5, C=10^{12}$ → $K_l \approx 251$（各层约 256）

**策略 3：业务驱动**

按业务需求分配：

| 层 | 业务意义 | 推荐 $K_l$ |
| :--- | :--- | :--- |
| c1 | 大类（手机/电脑/服装） | 16-64 |
| c2 | 中类（手机品牌） | 64-256 |
| c3 | 小类（型号） | 256-1024 |
| c4 | 配置 | 256-1024 |
| c5 | 颜色/尺寸 | 64-256 |

### A.3.3 实验对比

| 方案 | K 分配 | 总容量 | Recall@100 | 训练时长 |
| :--- | :--- | :--- | :--- | :--- |
| 等比 (r=0.5) | [1024, 512, 256, 128, 64] | $1.1 \times 10^{12}$ | 0.78 | 4 h |
| 等容量 | [251, 251, 251, 251, 251] | $10^{12}$ | 0.75 | 4 h |
| 业务驱动 | [32, 128, 512, 256, 128] | $6.9 \times 10^{10}$ | 0.82 | 3 h |

→ **业务驱动** 在大多数场景下最优。

## A.4 码本维度的设计

### A.4.1 维度选择

每层码本的维度 $d_l$ 通常一致（简化实现）或递减（粗粒度需要更高维）：

```python
config = {
    'c1': {'num_codes': 32,  'dim': 256},  # 粗粒度高维
    'c2': {'num_codes': 128, 'dim': 128},
    'c3': {'num_codes': 512, 'dim': 128},
    'c4': {'num_codes': 256, 'dim': 64},
    'c5': {'num_codes': 128, 'dim': 32},   # 细粒度低维
}
```

### A.4.2 维度与码本的关系

$$\text{表达能力} \propto K_l \cdot d_l$$

但实际有效维度受限于 embedding 维度 $D$。一般：

$$d_l \le \frac{D}{2}$$

**经验**：embedding 1024 维时，码本维度 64-256 最优。

### A.4.3 维度实验

| 配置 | c1 维 | c5 维 | Recall@100 | 训练速度 |
| :--- | :--- | :--- | :--- | :--- |
| A | 64 | 32 | 0.72 | 1.0× |
| B | 128 | 32 | 0.78 | 0.9× |
| C | 256 | 32 | 0.80 | 0.7× |
| D | 256 | 64 | 0.81 | 0.6× |

→ 粗粒度维度更重要。

## A.5 层次性的来源——再讨论

### A.5.1 RQ 的数学机制

RQ-VAE 的第 $l$ 层量化残差：

$$r_l = z - \sum_{i=1}^{l-1} q_i$$

其中 $z$ 是编码后的 embedding，$q_i$ 是第 $i$ 层的量化向量。

**核心**：第 1 层在完整 $z$ 上聚类 → 抓**最大方差方向**（粗粒度）。第 $l$ 层在残差 $r_l$ 上聚类 → 抓越来越细的差异。

### A.5.2 数学证明：层次涌现

设 $z = z_{\text{coarse}} + z_{\text{fine}}$，其中 $z_{\text{coarse}}$ 是大类分量，$z_{\text{fine}}$ 是细节分量。

第 1 层聚类在 $z$ 上，最小化：

$$\sum_i \|z_i - c_{\pi(i)}\|^2 = \sum_i \|z_{\text{coarse}, i} + z_{\text{fine}, i} - c_{\pi(i)}\|^2$$

由于 $\|z_{\text{coarse}}\| \gg \|z_{\text{fine}}\|$（粗粒度方差更大），聚类主要由 $z_{\text{coarse}}$ 决定 → 第 1 层码 ≈ 类目。

第 2 层在残差 $r_2 = z - q_1$ 上聚类，$r_2$ 包含 $z_{\text{fine}}$ + 一些粗粒度残差。由于粗粒度已被 $q_1$ 抓住，$r_2$ 主要由 $z_{\text{fine}}$ 决定 → 第 2 层码 ≈ 中粒度。

依此类推，层次自然涌现。

### A.5.3 引导层次性的方法

如果层次"自然涌现"不理想（c1 不像类目），可用监督引导：

```python
class HierarchicalRQVAE(nn.Module):
    """带类目监督的 RQ-VAE"""
    def __init__(self, ...):
        super().__init__()
        self.rqvae = RQVAE(...)
        # 第 1 层码 → 类目分类器
        self.c1_to_category = nn.Linear(d_c1, num_categories)

    def forward(self, x, category_label):
        sids, loss = self.rqvae(x)
        # 类目监督损失
        c1_emb = self.rqvae.codebooks[0].embedding(sids[:, 0])
        pred_category = self.c1_to_category(c1_emb)
        category_loss = F.cross_entropy(pred_category, category_label)
        loss = loss + 0.5 * category_loss
        return sids, loss
```

## A.6 码本大小 vs 重建误差

### A.6.1 理论关系

设输入 $z \in \mathbb{R}^D$，码本 $C = \{c_1, \dots, c_K\}$。KMeans 量化误差：

$$\epsilon(K) \le C \cdot \sigma^2 / K$$

其中 $\sigma^2$ 是数据方差，$C$ 是常数。

### A.6.2 多层 RQ 的总误差

$$\epsilon_{\text{total}} = \sum_{l=1}^{L} \epsilon_l \le \sum_l C \cdot \sigma_l^2 / K_l$$

其中 $\sigma_l^2$ 是第 $l$ 层残差的方差（随 $l$ 递减）。

### A.6.3 实验曲线

| K | L=3 重建 MSE | L=5 重建 MSE | L=8 重建 MSE |
| :--- | :--- | :--- | :--- |
| 64 | 0.18 | 0.08 | 0.04 |
| 128 | 0.12 | 0.05 | 0.025 |
| 256 | 0.08 | 0.03 | 0.015 |
| 512 | 0.06 | 0.025 | 0.012 |
| 1024 | 0.05 | 0.02 | 0.010 |

**经验法则**：L=5, K=256 是性价比最优。

## A.7 完整可运行代码

### A.7.1 混合粒度码本训练

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import numpy as np
from sklearn.cluster import KMeans


class HierarchicalCodebook(nn.Module):
    """单层码本"""
    def __init__(self, num_codes, dim, decay=0.99, eps=1e-5):
        super().__init__()
        self.num_codes = num_codes
        self.dim = dim
        self.decay = decay
        self.eps = eps

        # 码本向量
        self.embedding = nn.Embedding(num_codes, dim)
        nn.init.uniform_(self.embedding.weight, -1.0 / num_codes, 1.0 / num_codes)

        # EMA 统计
        self.register_buffer('cluster_size', torch.zeros(num_codes))
        self.register_buffer('embed_avg', self.embedding.weight.data.clone())
        self.register_buffer('inited', torch.tensor(False))

    def init_with_kmeans(self, data):
        """用 KMeans 初始化码本"""
        kmeans = KMeans(n_clusters=self.num_codes, n_init=3)
        kmeans.fit(data.cpu().numpy())
        self.embedding.weight.data = torch.from_numpy(kmeans.cluster_centers_).float()
        self.embed_avg.data = self.embedding.weight.data.clone()
        self.inited.fill_(True)

    @torch.no_grad()
    def ema_update(self, x, codes):
        """EMA 更新码本"""
        # 计算每个码的样本数和均值
        onehot = F.one_hot(codes, self.num_codes).float()  # [B, K]
        cluster_size = onehot.sum(0)  # [K]
        embed_sum = onehot.t() @ x  # [K, D]

        # EMA
        self.cluster_size.mul_(self.decay).add_(cluster_size, alpha=1 - self.decay)
        self.embed_avg.mul_(self.decay).add_(embed_sum, alpha=1 - self.decay)

        # 归一化
        n = self.cluster_size.sum()
        cluster_size = (self.cluster_size + self.eps) / (n + self.num_codes * self.eps) * n
        embed_normalized = self.embed_avg / cluster_size.unsqueeze(1)

        # 更新码本
        self.embedding.weight.data.copy_(embed_normalized)


class HierarchicalRQVAE(nn.Module):
    """混合粒度的残差量化 VAE"""
    def __init__(self, in_dim=1024, hidden=128,
                 layer_configs=None, beta=0.25):
        super().__init__()
        if layer_configs is None:
            layer_configs = [
                {'num_codes': 32,  'dim': 256},  # c1
                {'num_codes': 128, 'dim': 128},  # c2
                {'num_codes': 512, 'dim': 128},  # c3
                {'num_codes': 256, 'dim': 64},   # c4
                {'num_codes': 128, 'dim': 32},   # c5
            ]
        self.L = len(layer_configs)
        self.layer_configs = layer_configs

        # 编码器
        self.encoder = nn.Sequential(
            nn.Linear(in_dim, hidden),
            nn.ReLU(),
            nn.Linear(hidden, hidden),
        )

        # 多层码本
        self.codebooks = nn.ModuleList([
            HierarchicalCodebook(cfg['num_codes'], cfg['dim'])
            for cfg in layer_configs
        ])

        # 每层投影 (从统一 hidden 到该层 dim)
        self.layer_projs = nn.ModuleList([
            nn.Linear(hidden, cfg['dim']) for cfg in layer_configs
        ])

        # 解码器
        self.decoder = nn.Sequential(
            nn.Linear(hidden, hidden),
            nn.ReLU(),
            nn.Linear(hidden, in_dim),
        )

        self.beta = beta

    def init_codebooks(self, embs):
        """用 KMeans 初始化所有码本"""
        with torch.no_grad():
            z = self.encoder(embs)
            residual = z
            for l in range(self.L):
                z_l = self.layer_projs[l](residual)
                # KMeans 初始化
                kmeans = KMeans(n_clusters=self.layer_configs[l]['num_codes'], n_init=3)
                kmeans.fit(z_l.cpu().numpy())
                self.codebooks[l].embedding.weight.data = \
                    torch.from_numpy(kmeans.cluster_centers_).float()
                # 更新残差
                dist = torch.cdist(z_l.unsqueeze(1),
                                  self.codebooks[l].embedding.weight.unsqueeze(0))
                code = dist.argmin(-1).squeeze(1)
                q = self.codebooks[l].embedding(code)
                residual = residual - self.layer_projs[l](residual) + q  # 近似残差

    def forward(self, x, return_codes=False):
        z = self.encoder(x)
        residual = z
        codes = []
        commit_loss = 0.0

        for l in range(self.L):
            z_l = self.layer_projs[l](residual)
            cb = self.codebooks[l]

            # 量化
            dist = torch.cdist(z_l.unsqueeze(1), cb.embedding.weight.unsqueeze(0))
            code = dist.argmin(-1).squeeze(1)
            q = cb.embedding(code)

            # 承诺损失
            commit_loss = commit_loss + F.mse_loss(z_l.detach(), q) \
                                       + self.beta * F.mse_loss(z_l, q.detach())

            # 直通估计
            z_q = z_l + (q - z_l).detach()

            # 更新残差 (在统一 hidden 空间)
            # 简化: 用线性映射回 hidden
            residual = residual - self.layer_projs[l](residual) + self.layer_projs[l](z_q)
            # 等价于: residual = residual - z_l + z_q (在 hidden 空间的近似)

            # 更新码本 (EMA)
            if self.training:
                cb.ema_update(z_l, code)

            codes.append(code)

        # 重建
        recon = self.decoder(residual)
        recon_loss = F.mse_loss(recon, x)

        loss = recon_loss + commit_loss

        codes = torch.stack(codes, dim=-1)

        if return_codes:
            return codes, loss, recon
        return codes, loss

    @torch.no_grad()
    def encode(self, x):
        codes, _ = self.forward(x)
        return codes


# ===== 训练循环 =====
def train_hierarchical_rqvae(embs, layer_configs, epochs=50, bs=512, lr=1e-3):
    model = HierarchicalRQVAE(in_dim=embs.shape[1], layer_configs=layer_configs)
    model = model.cuda()
    opt = torch.optim.Adam(model.parameters(), lr=lr)

    embs_t = torch.from_numpy(embs).float().cuda()
    N = embs_t.size(0)

    # KMeans 初始化
    print("初始化码本...")
    model.init_codebooks(embs_t[:50000])

    for ep in range(epochs):
        model.train()
        perm = torch.randperm(N)
        total_loss = 0.0
        for i in range(0, N, bs):
            idx = perm[i:i+bs]
            codes, loss = model(embs_t[idx])
            opt.zero_grad()
            loss.backward()
            opt.step()
            total_loss += loss.item()

        if ep % 5 == 0:
            print(f"Epoch {ep}: loss={total_loss / (N // bs):.4f}")

    return model
```

## A.12 思考题答案

**A1**: 粗粒度层需要更多码字来区分语义大类（如类目），且这层错了整体方向就偏，代价最大。

**A2**: 自然涌现，但可能不完美。可加类目监督损失引导。

**A3**: 业务驱动的码本与真实业务层次匹配，每层码的"业务意义"更强。

**A4**: 粗粒度先做前缀分桶（O(N/K_1)），再在桶内做细粒度 ANN。

**A5**: 加类目分类损失 $\mathcal{L}_{c1} = \text{CE}(\text{Classifier}(c1\_emb), \text{true\_category})$。

**A6**: 在大多数场景下，码本大小更重要（决定表达力），维度次之（决定精细度）。

**A7**: 电商 5 层最常见（类目/品牌/型号/配置/颜色），具体看业务。

## 附录 D：完整数学推导

## D.1 RQ 的最优码本

给定残差 $\{r_i\}$，第 $l$ 层码本 $\{c_k\}$ 优化目标：

$$\min_{c_k} \sum_i \|r_i^{(l)} - c_{\pi(i)}\|^2$$

最优解：

$$c_k = \frac{1}{|\{i: \pi(i)=k\}|} \sum_{i: \pi(i)=k} r_i^{(l)}$$

即每个码 = 分配到它的样本的均值（KMeans 中心）。

## D.2 收敛性证明

设第 $l$ 层量化误差 $\epsilon_l = \|r_l - q_l\|^2$。

**命题**：$r_{l+1} = r_l - q_l$，且 $E[\|r_{l+1}\|^2] < E[\|r_l\|^2]$。

**证明**：
$$E[\|r_{l+1}\|^2] = E[\|r_l - q_l\|^2] = E[\|r_l\|^2] - E[\|q_l\|^2] < E[\|r_l\|^2]$$

因为 $q_l$ 是 $r_l$ 的非零投影，$\|q_l\|^2 > 0$。

→ 残差单调递减 → 收敛。

## D.3 容量守恒的严格表述

**定理**：对于 $L$ 层 RQ-VAE，码本大小 $\{K_l\}_{l=1}^L$，其能表示的不同 SID 数为 $\prod_{l=1}^L K_l$。

**证明**：每个 SID = $(c_1, \dots, c_L)$，每个 $c_l \in \{0, \dots, K_l-1\}$ → 笛卡尔积。

**推论**：若需覆盖 $N$ 个物品，需 $\prod K_l \ge N \cdot \alpha$，其中 $\alpha$ 是冗余系数。

## 附录 H：码本设计的进阶话题

## H.1 自适应层数

传统做法固定 L=5。但有些场景需要自适应层数：

```python
class AdaptiveRQVAE(nn.Module):
    """自适应层数的 RQ-VAE"""
    def __init__(self, max_layers=10, threshold=0.01):
        super().__init__()
        self.max_layers = max_layers
        self.threshold = threshold
        self.codebooks = nn.ModuleList([RQCodebook(...) for _ in range(max_layers)])

    def forward(self, x):
        residual = self.encoder(x)
        codes = []
        for l in range(self.max_layers):
            cb = self.codebooks[l]
            q, code = cb(residual)
            codes.append(code)

            # 检查残差是否已足够小
            residual_new = residual - q
            if residual_new.norm(dim=-1).mean() < self.threshold:
                break

            residual = residual_new

        # 用 [PAD] 码填充未使用的层
        while len(codes) < self.max_layers:
            codes.append(torch.zeros_like(codes[0]))

        return torch.stack(codes, dim=-1)
```

## H.2 动态码本（可变容量）

```python
class DynamicCodebook(nn.Module):
    """码本大小可动态调整"""
    def __init__(self, max_codes=2048, dim=128):
        super().__init__()
        self.max_codes = max_codes
        self.dim = dim
        # 所有码存成一个 buffer
        self.register_buffer('codes', torch.zeros(max_codes, dim))
        self.register_buffer('active_mask', torch.zeros(max_codes, dtype=torch.bool))
        self.n_active = 0

    def activate_codes(self, indices):
        """激活新的码"""
        self.active_mask[indices] = True
        self.n_active = self.active_mask.sum().item()

    def deactivate_codes(self, indices):
        """停用码"""
        self.active_mask[indices] = False
        self.n_active = self.active_mask.sum().item()

    def forward(self, x):
        active_codes = self.codes[self.active_mask]  # [n_active, dim]
        dist = torch.cdist(x.unsqueeze(1), active_codes.unsqueeze(0))
        idx_local = dist.argmin(-1)
        idx_global = self.active_mask.nonzero().squeeze()[idx_local]
        return idx_global, active_codes[idx_local]
```

## H.3 码本预训练

直接用 KMeans 预训练码本，比随机初始化更快收敛：

```python
def pretrain_codebooks(embs, layer_configs):
    """用 KMeans 预训练所有码本"""
    residual = embs.clone()
    codebooks = []

    for cfg in layer_configs:
        K, dim = cfg['num_codes'], cfg['dim']
        # 投影
        z = nn.Linear(residual.shape[1], dim).cuda()
        residual_proj = z(residual.cuda())
        # KMeans
        kmeans = KMeans(n_clusters=K, n_init=3).fit(residual_proj.cpu().numpy())
        centers = torch.from_numpy(kmeans.cluster_centers_).float()
        # 更新残差
        dist = torch.cdist(residual_proj, centers)
        idx = dist.argmin(-1)
        q = centers[idx]
        residual = residual - q.cpu()
        codebooks.append((z, centers))

    return codebooks
```

```python
            RQCodebook(K, target_dim) for K in [...]

            # 用老码本还原
            z = self.projs[l](source_codebooks[l].embedding[code])

            new_codes.append(dist.argmin().item())
        return new_codes
```

## 附录 J：码本与召回精度的关系

## J.1 理论分析

设召回的物品集合 $R$，真实相关集合 $T$：

$$\text{Recall@K} = \frac{|R \cap T|}{K}$$

**码本对召回的影响**：
1. 码本太小 → 大量物品坍缩到同码 → 召回精度下降
2. 码本太大 → 表达力过强 → 训练数据不足 → 过拟合

## J.2 实验数据

| K | L | 物品量 | Recall@100 |
| :--- | :--- | :--- | :--- |
| 64 | 5 | 100万 | 0.62 |
| 256 | 5 | 100万 | 0.78 |
| 1024 | 5 | 100万 | 0.81 |
| 256 | 5 | 1000万 | 0.65 |
| 1024 | 5 | 1000万 | 0.78 |
| 4096 | 5 | 1000万 | 0.83 |
| 256 | 8 | 1000万 | 0.79 |
| 1024 | 8 | 1000万 | 0.85 |

**结论**：
- K 越大越好，但有饱和点
- L 越大越好，但训练更慢
- 物品量与 K 需匹配

## J.3 经验法则

$$K_{\text{optimal}} \approx \sqrt[L]{N \cdot \alpha}$$

其中 $N$ 是物品量，$\alpha$ 是冗余系数（推荐 2-5）。

例：$N=1000万, L=5, \alpha=4$ → $K \approx 84$（推荐 128-256）

## K.1 码本大小怎么定？

**A**: 看业务规模和层次需求。粗粒度层按业务类目数（如 10-50）；细粒度层按物品数估算（$K_{\text{optimal}} \approx \sqrt[L]{N}$）。

**A**:
1. KMeans 初始化（比随机好）
2. 类目监督损失
3. 监控每层熵

**A**: 新品用内容 SID，协同 SID 用回退码（详见 [附录-HY-Token实现.md](第06章-附录-HY-Token实现.md)）。

## K.5 码本需要多久更新一次？

**A**: 业务稳定时每月一次，物品变化快时每周一次。

```python
class DynamicGranularity(nn.Module):
    """动态粒度"""
    def __init__(self, codebooks):
        super().__init__()
        self.codebooks = codebooks

    def forward(self, x, user_granularity_pref):
        """user_granularity_pref: 用户偏好的粒度级别"""
        z = self.encoder(x)
        codes = []
        residual = z
        for l in range(user_granularity_pref):
            # 只用前 L' 层
            code, q = self.codebooks[l](residual)
            codes.append(code)
            residual = residual - q
        return codes
```

## S.2 实现代码

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class MultiModalCodebook(nn.Module):
    """多模态混合粒度码本"""
    def __init__(self, text_dim=768, img_dim=1024, vid_dim=4096,
                 common_dim=512, L=5, K_list=[32, 128, 512, 256, 128]):
        super().__init__()
        self.L = L

        # 各模态投影到公共空间
        self.text_proj = nn.Sequential(
            nn.Linear(text_dim, common_dim),
            nn.LayerNorm(common_dim),
        )
        self.img_proj = nn.Sequential(
            nn.Linear(img_dim, common_dim),
            nn.LayerNorm(common_dim),
        )
        self.vid_proj = nn.Sequential(
            nn.Linear(vid_dim, common_dim),
            nn.LayerNorm(common_dim),
        )

        # 跨模态 Cross-Attention
        self.fusion = nn.MultiheadAttention(common_dim, num_heads=8)

        # 每层码本
        self.codebooks = nn.ModuleList([
            RQCodebook(K_list[l], common_dim) for l in range(L)
        ])

    def forward(self, text_emb, img_emb, vid_emb):
        t = self.text_proj(text_emb)
        i = self.img_proj(img_emb)
        v = self.vid_proj(vid_emb)

        # Stack & Cross-Attention
        embs = torch.stack([t, i, v], dim=1)  # [B, 3, D]
        fused, _ = self.fusion(embs, embs, embs)
        z = fused.mean(dim=1)  # [B, D]

        # RQ
        codes, z_q, loss = self.rq(z)
        return codes, loss
```

## T.1 用 RL 优化码本分配

```python
class RQWithRL(nn.Module):
    """RL 优化码本分配 (PPO 风格)"""
    def __init__(self, num_levels=5, codebook_size=256, dim=128):
        super().__init__()
        self.codebooks = nn.ParameterList([
            nn.Parameter(torch.randn(codebook_size, dim) * 0.1)
            for _ in range(num_levels)
        ])
        # Policy head: 输出每层的码分布
        self.policy = nn.Linear(dim, num_levels * codebook_size)

    def forward(self, z, reward=None):
        residual = z
        codes = []
        log_probs = []
        for l in range(self.L):
            cb = self.codebooks[l]
            dist = torch.cdist(residual, cb)
            # 用 policy 调整分布
            logits = -dist + self.policy(residual).view(-1, self.L, self.K)[:, l]
            probs = F.softmax(logits, dim=-1)

            # 采样
            idx = torch.multinomial(probs, 1).squeeze(-1)
            log_prob = torch.log(probs.gather(1, idx.unsqueeze(1))).squeeze(1)
            log_probs.append(log_prob)

            q = cb[idx]
            residual = residual - q
            codes.append(idx)

        # PPO 损失 (如果有 reward)
        if reward is not None:
            advantage = reward - reward.mean()
            policy_loss = -(torch.stack(log_probs, -1).sum(-1) * advantage).mean()
            return torch.stack(codes, -1), policy_loss
        return torch.stack(codes, -1), 0.0
```

```python
class FederatedCodebook:
    """联邦码本: 多家公司联合训练"""
    def __init__(self, num_clients, K=256, D=128):
        self.num_clients = num_clients
        self.global_codebook = torch.randn(K, D) * 0.1
        self.local_codebooks = [self.global_codebook.clone() for _ in range(num_clients)]

    def client_update(self, client_id, embs, lr=0.01):
        """客户端本地更新"""
        # KMeans on local data
        kmeans = KMeans(n_clusters=self.K).fit(embs.cpu().numpy())
        local_cb = torch.from_numpy(kmeans.cluster_centers_).float()

        # 加权平均: global * (1-lr) + local * lr
        self.local_codebooks[client_id] = (
            self.global_codebook * (1 - lr) + local_cb * lr
        )

    def aggregate(self):
        """服务端聚合"""
        all_local = torch.stack(self.local_codebooks)  # [num_clients, K, D]
        self.global_codebook = all_local.mean(0)
        # 同步给所有客户端
        for i in range(self.num_clients):
            self.local_codebooks[i] = self.global_codebook.clone()
```

## V.1 在线 KMeans 增量更新

```python
class OnlineKMeans:
    """在线 KMeans 增量更新码本"""
    def __init__(self, K=256, D=128, lr=0.01, decay=0.99):
        self.K, self.D = K, D
        self.lr = lr
        self.decay = decay
        self.codebook = torch.randn(K, D) * 0.1
        self.count = torch.zeros(K)

    def update_batch(self, new_embs):
        """增量更新"""
        # 1) 分配
        dist = torch.cdist(new_embs, self.codebook)
        idx = dist.argmin(-1)

        # 2) 对每个 cluster 增量更新中心
        for k in range(self.K):
            mask = idx == k
            if mask.sum() > 0:
                cluster_embs = new_embs[mask].mean(0)
                self.codebook[k] = (1 - self.lr) * self.codebook[k] + self.lr * cluster_embs
                self.count[k] = self.decay * self.count[k] + (1 - self.decay) * mask.sum().item()

    def detect_drift(self, new_embs):
        """检测数据漂移"""
        # 用 KL 散度比较新旧分布
        new_dist = self.compute_distribution(new_embs)
        old_dist = self.count / self.count.sum()
        kl_div = F.kl_div(new_dist.log(), old_dist, reduction='batchmean')
        return kl_div > 0.1  # 阈值
```

```python
    """码本漂移检测"""
    def __init__(self, threshold=0.1):
        self.threshold = threshold
        self.history = []

    def update(self, current_dist):
        self.history.append(current_dist)
        if len(self.history) < 10:
            return False
        # 比较当前 vs 10 个时间步前
        kl = F.kl_div(current_dist.log(), self.history[-10], reduction='batchmean')
        return kl > self.threshold
```

## A. 容量守恒的数学理论

### A.1 总表达容量公式

设 $K_l$ 为第 $l$ 层的码本大小,$L$ 为总层数,$D_l$ 为第 $l$ 层的 embedding 维度,则总表达力:

$$
C_{\text{total}} = \prod_{l=1}^{L} K_l \cdot \prod_{l=1}^{L} D_l
$$

但**实际有效容量**比乘积小,因为:
- 嵌入空间中的"死区"占相当比例。
- 残差量化存在信息损失。
- 训练数据通常不均匀。

**经验公式**:

$$
C_{\text{effective}} = \alpha \cdot \prod_l K_l, \quad \alpha \approx 0.3 \sim 0.6
$$

### A.2 容量需求

设物品数为 $N$,需要 $C_{\text{effective}} \geq 2N$(留冗余),即:

$$
\prod_{l=1}^{L} K_l \geq \frac{2N}{\alpha}
$$

例: $N = 10^8$ 物品, $\alpha = 0.4$:
- $\prod K_l \geq 5 \times 10^8 = 5 \times 10^8$。
- $L = 5, K_l = 256$:$\prod K_l = 256^5 \approx 1.1 \times 10^9$ ✅(满足)。
- $L = 4, K_l = 256$:$\prod K_l = 256^4 \approx 4.3 \times 10^9$ ✅(满足)。
- $L = 3, K_l = 256$:$\prod K_l = 256^3 \approx 1.7 \times 10^7$ ❌(不满足)。

→ 大规模推荐至少需要 $L = 4 \sim 5$。

---

## B. 码本大小分配的最优化

### B.1 优化目标

在固定总容量预算 $\prod K_l = K^*$ 下,最大化表达力。这是个**资源分配问题**:

$$
\max_{K_1, ..., K_L} \sum_{l=1}^{L} I(K_l; \text{Data}_l)
$$

其中 $I$ 是互信息(第 $l$ 层码本与数据的互信息)。

经验:**粗层码本大,细层码本小**,因为:
1. 粗层需要更细的区分(类目多)。
2. 细层在固定粗类内的方差更小(用更少码字即可)。

### B.2 几何衰减

**经验法则**: 码本大小按几何衰减:

$$
K_l = K_1 \cdot r^{l-1}, \quad r \in (0.7, 0.95)
$$

例: $K_1 = 1024, r = 0.8, L = 5$:
- $K_1 = 1024$
- $K_2 = 819$
- $K_3 = 655$
- $K_4 = 524$
- $K_5 = 419$

实际常用 round 到 2 的幂:1024 / 1024 / 512 / 512 / 256 / 128。

### B.3 信息论解释

每层码本与数据的互信息(粗层 $I_1$, 细层 $I_L$):

$$
I_{\text{total}} = I_1 + I_2 + ... + I_L
$$

且粗层与细层有冗余(层次性):

$$
I_l \leq I_{l-1}, \quad I_{\text{total}} \leq L \cdot I_1
$$

工业数据(短视频/电商):

| 层级 | 互信息 | 含义 |
| :--- | :--- | :--- |
| 1 | 4.2 bits | 类目(电子/服装/食品) |
| 2 | 3.5 bits | 子类目(手机/电脑/电视) |
| 3 | 2.8 bits | 品牌(苹果/华为/三星) |
| 4 | 1.9 bits | 系列(iPhone 15/16) |
| 5 | 0.8 bits | 配置(128G/256G) |

总互信息 ~ 13 bits(2^13 = 8192 类),但实际用 5 层码本表达 ~ 1 万亿。

### C.2 引导层次性

如果训练后发现**粗层不是类目化**,可以用后处理引导:

```python
class HierarchyGuidedQuantizer:
    """用类目信息引导粗层码本。"""
    def __init__(self, num_categories, base_quantizer):
        self.cat_to_code = {}                # 类目 → 码字
        self.code_counter = 0
        self.base = base_quantizer

    def fit(self, items, embeddings):
        """第一层: 用类目强制聚类; 后面的层: 正常残差量化。"""
        from sklearn.cluster import KMeans
        # 第 1 层: 用类目做初始化
        cat_centers = []
        for cat in range(self.num_categories):
            mask = items['category'] == cat
            if mask.sum() > 0:
                center = embeddings[mask].mean(0)
                cat_centers.append(center)
                self.cat_to_code[cat] = self.code_counter
                self.code_counter += 1

        # 用类目中心初始化第一层码本
        self.base.codebooks[0].weight.data = torch.stack(cat_centers)

        # 后面的层: 正常 RQ-Kmeans
        sids = self.base.quantize_all(embeddings)
        return sids
```

## D. 码本大小的动态调整

### D.1 监控每层利用率

```python
class AdaptiveCodebook:
    """根据每层利用率动态调整码本大小。"""
    def __init__(self, num_layers=5, max_codes=1024):
        self.num_layers = num_layers
        self.codebook_sizes = [256] * num_layers      # 初始
        self.max_codes = max_codes
        self.usage_history = []

    def on_epoch_end(self, sids):
        """根据本轮的码本利用率调整大小。"""
        for l in range(self.num_layers):
            usage = (torch.bincount(sids[:, l], minlength=self.codebook_sizes[l]) > 0).float().mean()
            self.usage_history.append((l, usage))

            # 利用率 < 50% → 减小码本
            if usage < 0.5 and self.codebook_sizes[l] > 64:
                self.codebook_sizes[l] //= 2
            # 利用率 > 90% → 增大码本
            elif usage > 0.9 and self.codebook_sizes[l] < self.max_codes:
                self.codebook_sizes[l] *= 2
```

### D.2 基于数据量的自适应

```python
class DataAdaptiveCodebook:
    """根据训练数据量自适应码本。"""
    def fit_size(self, n_items):
        """每个物品 ~2-5 个码字的容量分配。"""
        target_capacity = n_items * 3                       # 3x 冗余
        # 5 层, 几何分配
        for L in range(3, 7):
            K_avg = target_capacity ** (1/L)
            if 64 <= K_avg <= 1024:
                # 找到了合理的 L
                # 几何分配
                K1 = min(1024, int(K_avg * 1.5))
                ratio = 0.8
                return [int(K1 * ratio ** l) for l in range(L)]
        return [256, 256, 256, 256, 256]  # 默认
```

## F. 码本大小的搜索算法

### F.1 网格搜索

```python
def grid_search_codebook_sizes(items, embeddings):
    """网格搜索最优码本大小。"""
    import itertools
    L_range = [3, 4, 5, 6]
    K_choices = [64, 128, 256, 512, 1024]

    best_score = -1
    best_config = None

    for L, K1, K_L in itertools.product(L_range, K_choices, K_choices):
        # 几何分配
        ratio = (K_L / K1) ** (1 / (L - 1))
        sizes = [int(K1 * ratio ** l) for l in range(L)]

        # 评估
        sids = rq_kmeans(embeddings, sizes)
        score = evaluate_sids(items, sids)

        if score > best_score:
            best_score = score
            best_config = {'L': L, 'sizes': sizes}

    return best_config
```

```python
import optuna

def bayesian_search(items, embeddings):
    """用 Optuna 做贝叶斯优化。"""
    def objective(trial):
        L = trial.suggest_int('L', 3, 6)
        K1 = trial.suggest_categorical('K1', [256, 512, 1024])
        ratio = trial.suggest_float('ratio', 0.7, 0.95)
```
