## 4.2 KNN 兜底

```python
def encode_new_item(item_emb, rq_model, knn_index, top_k=5):
    """新物品: KNN 找最近的物品, 用邻居的 SID"""
    if item_emb is None:
        # 完全没 embedding → KNN
        _, neighbors = knn_index.search(item_emb, top_k)
        # 用邻居 SID 的众数
        neighbor_sids = [item_sids[n] for n in neighbors]
        return majority_vote(neighbor_sids)
    else:
        # 有 embedding → 直接 RQ
        return rq_model.encode(item_emb[None])[0]
```

## 4.3 冷启动的三个层次(按信息可得性)

新物品能算多好的 SID,取决于有多少信息:

| 情况 | 可用信息 | SID 策略 |
| :--- | :--- | :--- |
| **有内容** | 文本/图像 | LLM/多模态提取 embedding → RQ 查表(质量最好) |
| **仅有属性** | 品类/标签/价格 | 属性 embedding → RQ 查表 |
| **啥都没有** | 只有 id | **KNN 兜底**:找相似老物品借 SID,或给默认簇 |

> 核心洞察:**SID 本身就是"半个冷启动解药"**——因为它基于内容/语义,新物品哪怕零行为,也能凭内容落到正确的语义簇,被相似老物品的"邻域"带出来。这是纯行为 ID(冷启动死穴)做不到的。

---

## 4.4 为什么 SID 天然缓解冷启动(数学直觉)

传统 ItemID Embedding:新物品的 embedding 是随机初始化,没有行为就学不动 → 冷启动无解。

SID:新物品的码字由**内容/语义**决定,而这些码字的 embedding 是**所有共享该码字的物品一起训练**的。所以新物品一入库就"继承"了同簇老物品的表示 → **参数共享带来的冷启动泛化**。详见 [第05章-03 冷启动数学解释](../第05章-统一语义空间与冷启动/第05章-03-冷启动数学解释.md)。

## 4.8 冷启动的"数学解释" (深入)

### 4.8.1 传统 ItemID Embedding 的冷启动灾难

```text
Item ID 1:  [random_init_emb]    # 随机初始化
Item ID 2:  [random_init_emb]    # 随机初始化
Item ID 3:  [random_init_emb]    # 随机初始化

新物品 Item ID N+1:  [random_init_emb]  # 同样随机初始化

模型训练后:
  - 老物品的 embedding 被行为数据更新
  - 新物品的 embedding 几乎不变 (没行为)
  - 新物品被召回的机会 ≈ 0
```

**问题**: 新物品从冷启动到产生足够行为, 通常需要 1-2 周时间。这段时间完全"埋没"。

### 4.8.2 SID 为什么能解决 (数学)

新物品的 SID 码字由内容/语义决定:

```text
老物品 A: [text_emb] → RQ → SID = (3, 5, 2)
老物品 B: [text_emb] → RQ → SID = (3, 5, 2)  # 与 A 共享码字
老物品 C: [text_emb] → RQ → SID = (3, 5, 2)  # 与 A 共享码字
新物品 D: [text_emb] → RQ → SID = (3, 5, 2)  # 内容像, 分到同码

模型学到的 "SID (3,5,2) → embedding" 是 A, B, C 共同贡献的:
  SID_emb(3,5,2) = emb_A + emb_B + emb_C (训练时累计)

新物品 D 一入库:
  D_emb = SID_emb(3,5,2) = emb_A + emb_B + emb_C

  # D 的 embedding 自动从 A, B, C 那里"借"来了语义
```

**核心洞察**: **码字是"参数共享"的载体**。同码字的物品共享学习到的 embedding, 新物品自动获得这个共享表示。

## 4.9 冷启动的三层信息层次 (深入展开)

### 4.9.1 第一层: 有内容 (文本/图像)

```python
def encode_with_content_emb(item, content_encoder, rq_model):
    """有内容: 最佳质量"""

```

**质量**: ★★★★★
**覆盖率**: 80-90% 的物品 (有文本/图像)

### 4.9.2 第二层: 仅有属性 (品类/标签/价格)

```python
def encode_with_attr_emb(item, attr_encoder, rq_model):
    """仅有属性: 中等质量"""
    # 1. 把属性转成 embedding
    attr_str = item.category + ' ' + ' '.join(item.tags) + ' ' + str(item.price)
    emb = sentence_bert.encode(attr_str)

    # 2. 用现有码本 encode
    sid = rq_model.encode(emb[None])[0]

    return sid, 'attr'
```

**质量**: ★★★☆
**覆盖率**: 10-15% 的物品

### 4.9.3 第三层: 全无信息 (只有 ID)

```python
def encode_with_knn(item, faiss_index, item_sids, knn_k=5):
    """全无信息: KNN 借邻居 SID"""
    # 1. 用 sid 编码其他属性 (hash / 类别等)
    fallback_emb = extract_some_embedding(item)  # 任意可用信息

    # 2. 在 FAISS 找 K 个最近邻
    _, neighbors = faiss_index.search(fallback_emb[None], knn_k)

    # 3. 邻居 SID 投票
    neighbor_sids = [item_sids[n] for n in neighbors[0]]

    # 4. 逐位投票
    sid = majority_vote(neighbor_sids)

    return sid, 'knn'
```

**质量**: ★★☆
**覆盖率**: 5-10% 的物品

### 4.9.4 三层策略的组合

实际生产中, 三层都要做:

```python
def encode_new_item(item, content_encoder, attr_encoder, rq_model, faiss_index, item_sids):
    """组合策略"""
    # 1. 优先用内容
    if item.has_content:
        emb = content_encoder.encode(item.content)
        sid = rq_model.encode(emb[None])[0]
        return sid, 'content'

    # 2. 退而求其次用属性
    if item.has_attrs:
        emb = attr_encoder.encode(item.attrs)
        sid = rq_model.encode(emb[None])[0]
        return sid, 'attr'

    # 3. 最后用 KNN 兜底
    if some_embedding_available(item):
        sid = encode_with_knn(item, faiss_index, item_sids)
        return sid, 'knn'

    # 4. 终极兜底: 默认 SID
    return [0] * 5, 'default'
```

## 4.10 内容 embedding 的"多源融合"

现实中新物品可能有多种信息, 怎么融合?

### 4.10.1 加权融合

```python
def multi_source_embedding(item, sources=['text', 'image', 'attr'], weights=[0.6, 0.3, 0.1]):
    """多源 embedding 加权融合"""
    embeddings = []
    actual_weights = []

    for src, w in zip(sources, weights):
        if hasattr(item, src) and getattr(item, src) is not None:
            emb = encode_one_source(item, src)  # 用对应编码器
            embeddings.append(emb)
            actual_weights.append(w)

    if not embeddings:
        return None

    # 加权平均
    weights_sum = sum(actual_weights)
    weights_normalized = [w / weights_sum for w in actual_weights]
    final_emb = sum(e * w for e, w in zip(embeddings, weights_normalized))
    return final_emb
```

### 4.10.2 拼接融合

```python
def concat_embedding(item):
    """拼接多源 embedding"""
    embs = []
    if item.has_text:
        embs.append(sentence_bert.encode(item.text))
    if item.has_image:
        embs.append(clip.encode(item.image))
    # 拼接 → 投影到固定维度
    if embs:
        return mlp_projector(torch.cat(embs, dim=-1))
    return None
```

### 4.10.3 Cross-Attention 融合 (高级)

```python
class MultiSourceFusion(nn.Module):
    """Cross-Attention 多源融合"""
    def __init__(self, dim_text=384, dim_image=512, dim_out=128):
        super().__init__()
        self.text_proj = nn.Linear(dim_text, dim_out)
        self.image_proj = nn.Linear(dim_image, dim_out)
        self.attention = nn.MultiheadAttention(dim_out, num_heads=4)
        self.fusion = nn.Linear(dim_out, dim_out)

    def forward(self, text_emb, image_emb, attr_emb=None):
        # 投影到同一维度
        text = self.text_proj(text_emb)
        image = self.image_proj(image_emb)

        # 拼接为序列
        seq = torch.stack([text, image, attr_emb] if attr_emb else [text, image], dim=0)

        # Cross-attention
        fused, _ = self.attention(seq, seq, seq)

        # 加权融合
        return self.fusion(fused.mean(dim=0))
```

## 4.11 KNN 兜底的"工程实现"

### 4.11.1 完整 KNN 兜底流程

```python
def knn_fallback(new_item_emb, faiss_index, item_sids, item_embs, k=5, version='v2'):
    """KNN 兜底完整实现"""
    # 1. 找 K 个最近邻
    distances, neighbors = faiss_index.search(
        new_item_emb[None].astype('float32'), k
    )

    # 2. 距离过滤 (太远的不算邻居)
    valid_neighbors = neighbors[0][distances[0] < 0.5]

    if len(valid_neighbors) == 0:
        # 没有近邻, 用全局最热门 SID
        return get_popular_sid(version), 'no_neighbors'

    # 3. 距离加权投票
    K = len(self.codebooks)
    sid = [0] * K
    for k_idx in range(K):
        # 累积每个 SID 码字的加权得分
        score = defaultdict(float)
        for n, d in zip(valid_neighbors, distances[0][:len(valid_neighbors)]):
            n_sid = item_sids[n][k_idx]
            weight = 1.0 / (d + 1e-6)
            score[n_sid] += weight

        # 选最高分
        sid[k_idx] = max(score, key=score.get)

    return sid, 'knn'
```

### 4.11.2 距离阈值的"行业经验"

| 距离阈值 | 含义 |
| :--- | :--- |
| < 0.3 | 非常相似, KNN 投票可靠 |
| 0.3-0.5 | 较相似, KNN 投票还可以 |
| 0.5-0.8 | 一般相似, KNN 投票有风险 |
| > 0.8 | 不相似, 放弃 KNN, 用默认 SID |

**调优**: 用 A/B 实验测试不同阈值。

### 4.11.3 邻居数 K 的选择

| K | 优缺点 |
| :--- | :--- |
| K=1 | 最近邻决定, 可能不准 |
| K=3 | 平衡 |
| K=5 | 工业默认 (Spotify / YouTube 用) |
| K=10 | 更鲁棒, 但可能引入噪声 |
| K=20 | 过度平滑, 失去个性化 |

**工业经验**: K=5 是甜点。

## 4.13 增量入库的"流式架构"

### 4.13.1 实时入库的 Kafka 流水线

```text
Kafka Topic: new_items
  ↓ (每个新物品)
Content Encoder (LLM) → embedding
  ↓
RQ-Kmeans encode → SID
  ↓
SID Database (写入)
  ↓
FAISS Index (增量更新)
  ↓
Cache invalidate (Redis)
  ↓
Online service ready
```

### 4.13.2 流式编码实现

```python
class StreamingSIDEncoder:
    """流式 SID 编码器: 处理 Kafka 流"""
    def __init__(self):
        self.kafka_consumer = KafkaConsumer('new_items')
        self.content_encoder = ContentEncoder()  # LLM
        self.attr_encoder = AttrEncoder()
        self.rq_model = RQModel.load('models/rq_vae.pt')
        self.knn = KNNFallback(faiss_index, item_sids)
        self.sid_db = SIDDatabase()
        self.cache = RedisCache()

    def run(self):
        """持续处理 Kafka 流"""
        for message in self.kafka_consumer:
            item = parse_item(message)

            # 1. 提取 embedding
            emb = self.extract_embedding(item)
            if emb is None:
                continue

            # 2. 计算 SID
            try:
                sid = self.rq_model.encode(emb[None])[0]
                source = 'rq_encode'
            except Exception as e:
                logger.error(f"Encode failed: {e}, falling back to KNN")
                sid = self.knn.encode_knn(emb)
                source = 'knn_fallback'

            # 3. 写入 SID 数据库
            self.sid_db.put(item.id, sid)

            # 4. 失效缓存
            self.cache.delete(f"sid:v2:{item.id}")

            # 5. 通知下游
            self.notify(item.id, sid)

            logger.info(f"Encoded item {item.id}: SID={sid.tolist()}, source={source}")

    def extract_embedding(self, item):
        """提取 embedding, 多源融合"""
        if item.has_text:
            return self.content_encoder.encode(item.text)
        elif item.has_attrs:
            return self.attr_encoder.encode(item.attrs)
        return None
```

**吞吐量**: 单实例可处理 100-1000 items/s。

## 4.14 增量入库的"FAISS 索引更新"

### 4.14.1 增量更新 vs 全量重建

| | 增量更新 | 全量重建 |
| :--- | :--- | :--- |
| 时延 | 快 (单 item < 1s) | 慢 (全量 1 小时+) |
| 一致性 | 容易保证 | 复杂 (有索引切换) |
| 适用 | 低频 (每天几千) | 高频 (每天几万+) |

工业推荐系统一般用**双索引策略**:

```python
class DualIndexManager:
    """双 FAISS 索引管理器"""
    def __init__(self):
        self.active_index = None  # 当前使用
        self.building_index = None  # 正在构建

    def incremental_update(self, new_items):
        """增量更新 (添加到 active_index)"""
        embeddings = np.stack([item.emb for item in new_items])
        sids = np.stack([item.sid for item in new_items])
        self.active_index.add_with_ids(embeddings, sids)

    def full_rebuild(self, all_items):
        """全量重建 (异步在 building_index)"""
        # 1. 创建新索引
        new_index = faiss.IndexIVFPq(...)

        # 2. 训练
        embs = np.stack([item.emb for item in all_items])
        new_index.train(embs)

        # 3. 添加
        new_index.add_with_ids(embs, ids)

        # 4. 原子切换
        self.building_index = new_index
        self.active_index, self.building_index = self.building_index, self.active_index
```

### 4.14.2 定期全量重建的策略

```text
每日全量重建:
  - 凌晨低峰期执行
  - 完成后切换索引
  - 旧索引保留 1 天 (回滚点)

每周全量重建:
  - 周日深夜执行
  - 处理本周新加入物品

触发式重建:
  - 碰撞率 > 5% 阈值
  - 长尾物品召回覆盖率显著下降
```

## 4.15 冷启动的"探索-利用" (Exploration-Exploitation)

### 4.15.1 E&E 问题

新物品一上架, 有两个选择:
- **利用 (Exploitation)**: 推荐相似老物品 (确定性强)
- **探索 (Exploration)**: 给新物品曝光机会 (未来收益)

**矛盾**: 利用是短期最优, 探索是长期最优。

### 4.15.2 经典解法: UCB (Upper Confidence Bound)

$$\text{UCB}(i) = \hat{r}(i) + c \cdot \sqrt{\frac{\ln N}{n_i}}$$

其中:
- $\hat{r}(i)$ 是物品 $i$ 的估计收益
- $n_i$ 是物品 $i$ 被推荐次数
- $N$ 是总推荐次数
- $c$ 是探索系数

**含义**: 推荐"估计收益 + 不确定性"的物品。

### 4.15.3 Thompson Sampling

```python
def thompson_sampling(item):
    """贝叶斯采样"""
    alpha = item.alpha  # 成功次数 + 1
    beta = item.beta    # 失败次数 + 1

    # 从 Beta 分布采样
    sample = np.random.beta(alpha, beta)
    return sample
```

### 4.15.5 多臂老虎机实现

```python
class MABNewItemRouter:
    """多臂老虎机式新物品路由"""
    def __init__(self, n_arms=10):
        self.alphas = np.ones(n_arms)  # Beta 先验
        self.betas = np.ones(n_arms)

    def select_arm(self):
        """Thompson sampling 选择"""
        samples = np.random.beta(self.alphas, self.betas)
        return np.argmax(samples)

    def update(self, arm, reward):
        """更新参数"""
        if reward > 0:
            self.alphas[arm] += reward
        else:
            self.betas[arm] += 1 - reward
```

### 4.19.1 完整的冷启动处理流水线

```python
class CompleteColdStartPipeline:
    """完整的冷启动处理流水线"""
    def __init__(self):
        self.content_encoder = ContentEncoder()  # LLM
        self.attr_encoder = AttrEncoder()
        self.rq_model = RQModel.load('models/rq.pt')
        self.faiss_index = FaissIndex.load('models/faiss.index')
        self.item_sids = ItemSids.load('models/sids.parquet')
        self.sid_db = SIDDatabase()
        self.cache = RedisCache()
        self.metrics = MetricsCollector()

    def process_new_item(self, item):
        """处理一个新物品的完整流程"""
        start_time = time.time()

        # 1. 提取 embedding
        emb = self.extract_embedding(item)
        if emb is None:
            self.metrics.no_embedding.inc()
            return None

        # 2. 计算 SID (尝试多种策略)
        sid, source = self.compute_sid(item, emb)
        self.metrics.encoding_source.labels(source=source).inc()

        # 3. 写入 SID 数据库
        self.sid_db.put(item.id, sid)

        # 4. 失效缓存
        self.cache.delete(f"sid:v2:{item.id}")

        # 5. 监控埋点
        latency = time.time() - start_time
        self.metrics.latency.observe(latency)

        logger.info(f"Processed item {item.id}: SID={sid.tolist()}, source={source}, latency={latency:.2f}s")

        return sid

    def extract_embedding(self, item):
        """提取 embedding"""
        # 尝试内容
        if item.has_text:
            return self.content_encoder.encode(item.text)

        if item.has_image:
            return self.content_encoder.encode_image(item.image)

        # 退属性
        if item.has_attrs:
            return self.attr_encoder.encode(item.attrs)

        return None

    def compute_sid(self, item, emb):
        """计算 SID"""
        # 1. 尝试 RQ 直接 encode
        if emb is not None:
            try:
                sid = self.rq_model.encode(emb[None])[0]
                return sid.tolist(), 'rq_encode'
            except Exception as e:
                logger.warning(f"RQ encode failed: {e}")

        # 2. 退 KNN
        try:
            sid = self.knn_fallback(emb)
            if sid is not None:
                return sid, 'knn'
        except Exception as e:
            logger.warning(f"KNN fallback failed: {e}")

        # 3. 默认 SID
        return [0] * 5, 'default'

    def knn_fallback(self, emb):
        """KNN 兜底"""
        distances, neighbors = self.faiss_index.search(
            emb[None].astype('float32'), k=5
        )

        # 距离过滤
        valid = [
            (n, d) for n, d in zip(neighbors[0], distances[0])
            if d < 0.5
        ]

        if not valid:
            return None

        # 逐位投票
        sid = [0] * 5
        for k_idx in range(5):
            scores = defaultdict(float)
            for n, d in valid:
                w = 1.0 / (d + 1e-6)
                scores[self.item_sids[n][k_idx]] += w
            sid[k_idx] = max(scores, key=scores.get)

        return sid
```

### 4.19.3 异常处理

```python
class SafeSIDProcessor:
    """带异常处理的 SID 处理器"""
    def __init__(self, fallback_sid_func):
        self.fallback_sid_func = fallback_sid_func
        self.retry_count = 3

    def process(self, item):
        """带重试的处理"""
        for attempt in range(self.retry_count):
            try:
                sid = self._process_with_timeout(item, timeout=2.0)
                return sid
            except TimeoutError:
                logger.warning(f"Timeout, attempt {attempt + 1}")
                continue
            except Exception as e:
                logger.error(f"Error: {e}")
                break

        # 所有尝试失败, 用最终兜底
        return self.fallback_sid_func(item)

    def _process_with_timeout(self, item, timeout):
        """带超时的处理"""
        import signal

        def handler(signum, frame):
            raise TimeoutError()

        signal.signal(signal.SIGALRM, handler)
        signal.alarm(int(timeout))

        try:
            return self._process(item)
        finally:
            signal.alarm(0)
```

```python
    """内容感知 DLRM"""
    def __init__(self, n_items, item_emb_dim=128, content_dim=384):
        super().__init__()
        # 物品 ID embedding (老物品用)
        self.item_emb = nn.Embedding(n_items, item_emb_dim)

        # 内容编码器 (新物品用)
        self.content_proj = nn.Linear(content_dim, item_emb_dim)

        # 融合层
        self.fusion = nn.Sequential(
            nn.Linear(item_emb_dim * 2, item_emb_dim),
            nn.ReLU(),
        )

    def forward(self, item_id, content_emb=None):
        """支持 (item_id only) 或 (item_id + content)"""
        id_emb = self.item_emb(item_id)

        if content_emb is not None:
            content_proj = self.content_proj(content_emb)
            fused = self.fusion(torch.cat([id_emb, content_proj], dim=-1))
            return fused
        return id_emb
```

## 4.24 冷启动的"反模式"

### 4.24.1 反模式 1: 强制默认 SID

现象: 所有新物品都赋 SID = (0, 0, 0, 0, 0)。

危害: 新品聚一类, 信号混淆。

**对策**: KNN 兜底 + 距离过滤。

### 4.24.2 反模式 2: 新物品用 ItemID Embedding

现象: 新物品直接用 ItemID Embedding 查询。

危害: 新物品 emb 不准, 召回错误。

**对策**: 新物品用 SID, 老物品用 ItemID。

### 4.24.3 反模式 3: 忽略新物品

现象: 新物品直接用 KNN 邻居 SID, 忽略自身特征。

危害: 失去个性化。

**对策**: 内容 embedding 优先, KNN 兜底。

### 4.24.4 反模式 4: 重训码本太频繁

现象: 每周重训码本, 索引重建。

危害: 团队精力消耗大。

**对策**: 季度重训, 触发式重训。

## 4.32 冷启动的"FAQ"

### Q1: 一天新物品入库 100 万, 系统吃得消吗?

A: 看架构。常见配置:
- LLM 编码: 8 卡 A100 → 1 万 items/min
- RQ 编码: 1 卡 → 100 万 items/s (CPU 都够)
- SID 数据库写入: 千亿级写入 QPS
- FAISS 增量更新: 1 万 items/s

**结论**: 吃得消, 但要看磁盘 IO 和 FAISS 更新。

### Q2: 新物品什么时候才能"毕业"?

A: 3 个判断标准:
1. 行为数 > 100 (足够的统计样本)
2. 评分稳定 (ctr 波动 < 10%)
3. 进入热门排行榜

**工业经验**: 1-2 周左右。

### Q3: 冷启动和"重训 SID"的关系?

A: 互不干扰:
- **冷启动**: 用现有码本 + KNN, 不重训
- **重训**: 整个码本重新学, 变更所有物品 SID

冷启动对日常运营友好, 重训对架构性变更。

### Q4: 冷启动怎么处理"违规物品"?

A: 流程:
1. 新物品入库前, 过内容审核 (暴恐 / 黄赌毒 / 假货)
2. 不通过的物品直接拒绝入库
3. 通过的物品才有 SID

SID 不解决内容审核问题, 内容审核在前面。

### Q5: 新物品的"灰度"怎么做?

A: 新物品也走灰度:
1. 新物品先在内部试运营, SID 计算并入库
2. 给 5% 用户曝光, 看 CTR
3. CTR 达标 → 扩大曝光
4. CTR 不达标 → 内容可能有问题, 调整

```python
class RQSIDEncoder:
    """RQ-Kmeans SID 编码器"""
    def __init__(self, codebooks: np.ndarray, K: int = 5):
        self.codebooks = codebooks  # [K, C, dim]
        self.K = K
        self.C = codebooks.shape[1]
        self.dim = codebooks.shape[2]

    def encode(self, embedding: np.ndarray) -> np.ndarray:
        """embedding → SID"""
        if embedding.ndim == 1:
            embedding = embedding[None, :]
        residual = embedding.copy()
        sids = np.zeros(len(embedding), dtype=np.int32)
        for k in range(self.K):
            # 距离
            dist = np.linalg.norm(
                residual[:, None, :] - self.codebooks[k][None, :, :],
                axis=2,
            )
            codes = dist.argmin(axis=1)
            sids = np.column_stack([sids, codes]) if sids.ndim == 1 else np.column_stack([sids, codes])
            residual = residual - self.codebooks[k][codes]
        if len(sids.shape) > 1:
            return sids[:, -self.K:]
        return sids[-self.K:]

    def save(self, path):
        np.savez(path, codebooks=self.codebooks, K=self.K)


# ============================================================================
# KNN 兜底
# ============================================================================

class KNNFallback:
    """KNN 兜底: 用近邻 SID 投票"""
    def __init__(self, faiss_index, item_sids: Dict, k=5, distance_threshold=0.5):
        self.faiss_index = faiss_index
        self.item_sids = item_sids
        self.k = k
        self.distance_threshold = distance_threshold

    def encode(self, embedding: np.ndarray, item_id: str = "unknown") -> Optional[np.ndarray]:
        """根据邻居 SID 投票, 返回 SID"""
        if embedding is None:
            return None

        # 1. 找 K 个最近邻
        distances, neighbors = self.faiss_index.search(
            embedding[None].astype('float32'), self.k
        )

        # 2. 距离过滤
        valid = [
            (n, d) for n, d in zip(neighbors[0], distances[0])
            if d < self.distance_threshold and n != item_id
        ]

        if not valid:
            return None  # 没有有效邻居

        # 3. 逐位投票
        sid = np.zeros(self.K, dtype=np.int32)
        for k_idx in range(self.K):
            scores = defaultdict(float)
            for n, d in valid:
                if n in self.item_sids:
                    w = 1.0 / (d + 1e-6)
                    scores[self.item_sids[n][k_idx]] += w
            if scores:
                sid[k_idx] = max(scores, key=scores.get)

        return sid

class ColdStartPipeline:
    """完整的冷启动流水线"""
    def __init__(self):
        self.content_encoder = ContentEncoder()
        self.rq_encoder = RQSIDEncoder(codebooks=self._load_codebooks())
        self.knn_fallback = KNNFallback(faiss_index=self._load_faiss(), item_sids={})
        self.sid_db = SIDDatabase(postgres_url='postgresql://localhost/sid')
        self.faiss_manager = FaissIndexManager(dim=384)
        self.cache = redis.Redis(host='localhost', port=6379, db=0)
        self.metrics = MetricsCollector()

    def _load_codebooks(self):
        # 实际从文件加载
        return np.random.randn(5, 256, 384).astype(np.float32)

    def _load_faiss(self):
        # 实际从文件加载
        index = faiss.IndexFlatL2(384)
        # 填充一些测试数据
        return index

    def process(self, item: Item) -> tuple:
        """处理一个新物品, 返回 (sid, source)"""
        start = time.time()
        try:
            # 1. 提取 embedding
            emb = self.content_encoder(item)
            if emb is None:
                emb = self._attr_fallback(item)
                source = 'attr_fallback'
            else:
                source = 'content'

            if emb is None:
                # 极简兜底
                return np.zeros(self.rq_encoder.K, dtype=np.int32), 'default'

            # 2. 转 numpy
            emb_np = emb.detach().cpu().numpy().flatten()
            if emb_np.shape[0] != self.rq_encoder.dim:
                # 维度不匹配, 调整
                if emb_np.shape[0] > self.rq_encoder.dim:
                    emb_np = emb_np[:self.rq_encoder.dim]
                else:
                    emb_np = np.pad(emb_np, (0, self.rq_encoder.dim - emb_np.shape[0]))

            # 3. RQ 编码
            try:
                sid = self.rq_encoder.encode(emb_np)
                source = 'rq_encode'
            except Exception as e:
                logger.warning(f"RQ encode failed: {e}")
                sid = self.knn_fallback.encode(emb_np, item.item_id)
                source = 'knn_fallback' if sid is not None else 'default'
                if sid is None:
                    sid = np.zeros(self.rq_encoder.K, dtype=np.int32)
                    source = 'default'

            # 4. 写数据库
            self.sid_db.put(item.item_id, sid, source)

            # 5. 失效缓存
            self.cache.delete(f"sid:v2:{item.item_id}")

            # 6. 监控
            latency = time.time() - start
            self.metrics.encoding_latency.observe(latency)
            self.metrics.encoding_source.labels(source=source).inc()

            return sid, source

        except Exception as e:
            self.metrics.errors.labels(error_type=type(e).__name__).inc()
            logger.error(f"Processing failed for {item.item_id}: {e}")
            return np.zeros(self.rq_encoder.K, dtype=np.int32), 'error'

    def _attr_fallback(self, item: Item) -> torch.Tensor:
        """属性 fallback embedding"""
        text = ''
        if item.category:
            text += item.category + ' '
        if item.tags:
            text += ' '.join(item.tags) + ' '
        if item.price:
            text += f'price_{int(item.price)}'

        if text.strip():
            return self.content_encoder.text_model.encode(text)
        return None
```

**7. 实践建议**

结合 "4-冷启动与新物品融合" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "4-冷启动与新物品融合" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
