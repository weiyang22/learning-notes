## 0. 公共组件：SID 嵌入层

所有下游任务都先把离散 SID 映射回稠密向量。这是 SID 复用性的根基——**一次量化，处处可用**。

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SIDEmbedding(nn.Module):
    """把 [B, L] 的层次 SID 映射为 [B, D] 稠密向量。

    两种聚合方式:
      - 'sum':  各层 embedding 相加, 对应 RQ 的"残差累加"语义, 参数少
      - 'concat': 拼接后线性投影, 表达力更强, 常用于精排
    """
    def __init__(self, num_levels=3, codebook_size=256, dim=64, agg='sum'):
        super().__init__()
        self.agg = agg
        self.embs = nn.ModuleList(
            [nn.Embedding(codebook_size, dim) for _ in range(num_levels)]
        )
        if agg == 'concat':
            self.proj = nn.Linear(num_levels * dim, dim)

    def forward(self, sid):                      # sid: [B, L]
        parts = [emb(sid[:, i]) for i, emb in enumerate(self.embs)]
        if self.agg == 'sum':
            return torch.stack(parts, 0).sum(0)  # [B, D]
        return self.proj(torch.cat(parts, -1))   # [B, D]
```

> **要点**: `sum` 聚合与 RQ-VAE 的重建过程同构（`z ≈ Σ_l codebook_l[sid_l]`），因此天然继承了"粗层管大类、细层管细节"的层次语义。

## 1. 例 1：TIGER 生成式推荐

**思路**（见 [10-01](第10章-01-SID与生成式推荐-TIGER-OneRec.md)）：把用户历史 item 的 SID 展平成 token 序列，用一个 seq2seq/decoder 自回归**生成**下一个 item 的 SID。检索 = 解码。

```python
class TIGERRecommender(nn.Module):
    """最小 TIGER: 用户历史 SID 序列 -> 生成 target item 的 L 个码。

    词表设计: 每层码用"层偏移"隔开, 避免不同层的 code=5 撞在一起。
      token(level l, code c) = l * K + c
    """
    def __init__(self, num_levels=3, codebook_size=256, dim=128, n_layers=4, n_heads=4):
        super().__init__()
        self.L, self.K = num_levels, codebook_size
        vocab = num_levels * codebook_size + 2      # +BOS +EOS
        self.bos, self.eos = vocab - 2, vocab - 1
        self.tok_emb = nn.Embedding(vocab, dim)
        self.pos_emb = nn.Embedding(512, dim)
        layer = nn.TransformerDecoderLayer(dim, n_heads, dim * 4, batch_first=True)
        self.decoder = nn.TransformerDecoder(layer, n_layers)
        self.head = nn.Linear(dim, vocab)

    def _flatten(self, sids):                       # sids: [B, T, L] -> [B, T*L]
        B, T, L = sids.shape
        offset = torch.arange(L, device=sids.device) * self.K
        return (sids + offset).reshape(B, T * L)

    def _embed(self, x):
        pos = torch.arange(x.size(1), device=x.device)
        return self.tok_emb(x) + self.pos_emb(pos)[None]

    @staticmethod
    def _causal(n):
        return torch.triu(torch.full((n, n), float('-inf')), diagonal=1)

    def forward(self, hist_sids, tgt_sids):
        """hist_sids: [B, T, L] 历史; tgt_sids: [B, L] 目标 (teacher forcing)。"""
        src = self._flatten(hist_sids)                                   # [B, T*L]
        tgt_flat = self._flatten(tgt_sids.unsqueeze(1))                  # [B, L]
        bos = torch.full((tgt_sids.size(0), 1), self.bos, device=src.device)
        tgt_in = torch.cat([bos, tgt_flat[:, :-1]], dim=1)               # 右移: [B, L]
        mem = self._embed(src)
        out = self.decoder(self._embed(tgt_in), mem,
                           tgt_mask=self._causal(tgt_in.size(1)))
        return self.head(out)                                            # [B, L, vocab]

# 训练时就是标准的 next-token 交叉熵:
# logits = model(hist, tgt)          # [B, L, V]
# tgt_tokens = model._flatten(tgt.unsqueeze(1))  # [B, L]
# loss = F.cross_entropy(logits.reshape(-1, V), tgt_tokens.reshape(-1))
```

> **关键收益**: item 空间从"百万级 ID 分类"压缩成"L 步 × K 类生成"，参数和显存都从 `O(N_item)` 降到 `O(L·K)`，且新 item 只要能算出 SID 就能被生成（**冷启动友好**）。检索阶段用 **beam search + Trie 约束解码**保证生成的是合法 SID（见第 12 章）。

## 2. 例 2：MMoE 多任务

**思路**（见 [10-02](第10章-02-SID与多任务学习.md)）：SID embedding 作为共享底座特征，喂进 MMoE，多个 gate 为 CTR/CVR 等任务分配专家。

```python
class SIDMMoE(nn.Module):
    def __init__(self, num_levels=3, codebook_size=256, dim=64,
                 n_experts=4, n_tasks=2, hidden=128):
        super().__init__()
        self.sid_emb = SIDEmbedding(num_levels, codebook_size, dim, agg='concat')
        self.experts = nn.ModuleList(
            [nn.Sequential(nn.Linear(dim, hidden), nn.ReLU()) for _ in range(n_experts)]
        )
        self.gates = nn.ModuleList([nn.Linear(dim, n_experts) for _ in range(n_tasks)])
        self.towers = nn.ModuleList([nn.Linear(hidden, 1) for _ in range(n_tasks)])

    def forward(self, sid):
        x = self.sid_emb(sid)                                      # [B, D]
        expert_out = torch.stack([e(x) for e in self.experts], 1)  # [B, E, H]
        outs = []
        for gate, tower in zip(self.gates, self.towers):
            w = F.softmax(gate(x), dim=-1).unsqueeze(-1)           # [B, E, 1]
            mixed = (w * expert_out).sum(1)                        # [B, H]
            outs.append(torch.sigmoid(tower(mixed)))               # [B, 1]
        return torch.cat(outs, -1)                                 # [B, n_tasks]=(ctr,cvr)

# 多任务 loss: 各任务 BCE 加权
# pred = model(sid); loss = bce(pred[:,0], click) + 0.5 * bce(pred[:,1], convert)
```

> **为什么用 SID 而非原始 ID**: 长尾 item 的原始 ID embedding 训练不充分；SID 的粗层被大量 item 共享，长尾 item 借共享码本"蹭"到充分训练的表征，多任务下**长尾 AUC 更稳**。

## 3. 例 3：知识蒸馏

**思路**（见 [10-03](第10章-03-SID与知识蒸馏.md)）：大教师模型（原始 ID + 大 embedding）指导小学生模型（SID embedding），学生用极小参数逼近教师打分。

```python
class SIDStudent(nn.Module):
    def __init__(self, num_levels=3, codebook_size=256, dim=32):
        super().__init__()
        self.sid_emb = SIDEmbedding(num_levels, codebook_size, dim, agg='sum')
        self.mlp = nn.Sequential(nn.Linear(dim, 64), nn.ReLU(), nn.Linear(64, 1))

    def forward(self, sid):
        return self.mlp(self.sid_emb(sid)).squeeze(-1)             # [B] logit

def distill_step(student, teacher_logit, sid, hard_label,
                 T=2.0, alpha=0.7, opt=None):
    """teacher_logit: 教师输出的 logit (已离线算好, [B]); hard_label: 0/1 真值。"""
    s_logit = student(sid)
    # 软标签: 温度平滑后的二分类 KL (对二分类退化为 soft-BCE)
    p_t = torch.sigmoid(teacher_logit / T)
    p_s = torch.sigmoid(s_logit / T)
    soft = F.binary_cross_entropy(p_s, p_t) * (T * T)
    hard = F.binary_cross_entropy_with_logits(s_logit, hard_label.float())
    loss = alpha * soft + (1 - alpha) * hard
    if opt:
        opt.zero_grad(); loss.backward(); opt.step()
    return loss.item()
```

> **落地价值**: 教师 embedding 表可能几十 GB，学生只有 `L·K·dim`（这里 3×256×32 ≈ 2.4 万参数）。线上用学生模型做**粗排/召回打分**，时延和显存都大幅下降，软标签保住了教师的排序结构，效果损失可控。

## 4. 例 4：PPO 强化学习

**思路**（见 [10-04](第10章-04-SID与强化学习.md)）：把生成式推荐当作序列决策——每一步在 SID 词表上采样一个 code，用长期反馈（成交、时长）作为 reward，用 PPO 微调生成策略，纠正纯 next-token 交叉熵只顾单点点击的短视。

```python
class SIDPolicy(nn.Module):
    """状态 = 已生成的前缀 SID 的编码; 动作 = 下一层的 code。这里给出单步策略头。"""
    def __init__(self, state_dim=128, codebook_size=256):
        super().__init__()
        self.actor = nn.Linear(state_dim, codebook_size)   # 动作分布
        self.critic = nn.Linear(state_dim, 1)              # 价值基线

    def forward(self, state):                              # state: [B, state_dim]
        return F.log_softmax(self.actor(state), -1), self.critic(state).squeeze(-1)

def ppo_update(policy, states, actions, old_logp, returns, adv,
               opt, clip=0.2, vf_coef=0.5, ent_coef=0.01, epochs=4):
    for _ in range(epochs):
        logp_all, value = policy(states)
        logp = logp_all.gather(1, actions.unsqueeze(1)).squeeze(1)
        ratio = (logp - old_logp).exp()
        clipped = torch.clamp(ratio, 1 - clip, 1 + clip) * adv   # 裁剪的策略目标
        pg_loss = -torch.min(ratio * adv, clipped).mean()
        v_loss = F.mse_loss(value, returns)
        entropy = -(logp_all.exp() * logp_all).sum(-1).mean()
        loss = pg_loss + vf_coef * v_loss - ent_coef * entropy
        opt.zero_grad(); loss.backward(); opt.step()
    return loss.item()

# reward 设计: 生成完整 SID 后, 用真实/仿真的长期收益 (GMV、观看时长) 作 reward,
# advantage = returns - value (GAE 更佳), 即可把"业务目标"直接注入生成策略。
```

> **注意**: RL 微调容易把生成分布带偏、生成非法 SID。实践中要 (1) 加 KL 惩罚约束不偏离 SFT 策略太远；(2) 解码时叠加 Trie 约束只允许合法 code。这与 RLHF 中"PPO + KL-to-ref"完全同构。

## 5. 例 5：业务可解释性

**思路**（见 [10-05](第10章-05-SID与冷启动与可解释性.md)）：SID 的层次结构天然可读——粗层=大类，细层=细分。把码本聚类到人类标签后，SID 就成了"可解释的商品指纹"。

```python
class SIDExplainer:
    """给码本层贴人读标签, 输出'为什么推荐'的可解释路径。"""
    def __init__(self, level_label_maps):
        # level_label_maps[l][code] = 人读标签, 由离线聚类 + 少量人工/LLM 标注得到
        self.maps = level_label_maps

    def explain_item(self, sid):
        """sid: List[int], 长度 L。返回从粗到细的语义路径。"""
        return " > ".join(self.maps[l].get(c, f"code_{c}") for l, c in enumerate(sid))

    def explain_reco(self, user_hist_sids, cand_sid):
        """给出候选与用户历史在哪一层'语义命中', 作为推荐理由。"""
        for l in range(len(cand_sid)):
            hit = any(h[l] == cand_sid[l] for h in user_hist_sids)   # 该层是否与历史共码
            if hit:
                label = self.maps[l].get(cand_sid[l], f"code_{cand_sid[l]}")
                return f"你常看「{label}」类，为你推荐同类新品：{self.explain_item(cand_sid)}"
        return f"探索性推荐：{self.explain_item(cand_sid)}"

# 用法:
# maps = [{12: '电子/手机'}, {7: '安卓旗舰'}, {3: '拍照强'}]
# ex = SIDExplainer(maps)
# ex.explain_item([12, 7, 3])            -> '电子/手机 > 安卓旗舰 > 拍照强'
# ex.explain_reco(`12,7,1`, [12,7,3]) -> '你常看「安卓旗舰」类, 为你推荐同类新品: ...'
```

> **价值**: 传统 ID embedding 是黑盒，无法回答"为什么推它"。SID 把推荐理由**结构化**到码本层级，既能对用户展示（提升信任），也能对运营/审核解释（合规），还能做**冷启动**——新品只要有 SID，就能挂到已有语义类目下参与召回。

## 附录 A - 公共组件深度解析

## A.1 SIDEmbedding 的三种聚合方式

### A.1.1 Sum 聚合(默认)

```python
class SIDEmbeddingSum(nn.Module):
    """Sum 聚合:与 RQ-VAE 残差累加语义一致。"""
    def __init__(self, num_levels=3, codebook_size=256, dim=64):
        super().__init__()
        self.embs = nn.ModuleList([nn.Embedding(codebook_size, dim) for _ in range(num_levels)])

    def forward(self, sid):
        # sid: [B, L]
        parts = [emb(sid[:, i]) for i, emb in enumerate(self.embs)]
        return torch.stack(parts, 0).sum(0)  # [B, D]
```

**优点**: 参数少,与 RQ-VAE 残差累加语义对齐。
**缺点**: 表达力有限,层间交互建模不够。

### A.1.2 Concat 聚合

```python
class SIDEmbeddingConcat(nn.Module):
    """Concat 聚合:每层独立,后接投影。"""
    def __init__(self, num_levels=3, codebook_size=256, dim=64):
        super().__init__()
        self.embs = nn.ModuleList([nn.Embedding(codebook_size, dim) for _ in range(num_levels)])
        self.proj = nn.Linear(num_levels * dim, dim)

    def forward(self, sid):
        # sid: [B, L]
        parts = [emb(sid[:, i]) for i, emb in enumerate(self.embs)]  # L 个 [B, D]
        return self.proj(torch.cat(parts, -1))  # [B, D]
```

**优点**: 表达力强,每层独立编码语义。
**缺点**: 参数多 (proj 层),参数量 = $L \times D^2$。

### A.1.3 Attention 聚合

```python
class SIDEmbeddingAttention(nn.Module):
    """Attention 聚合:层间 attention,自适应加权。"""
    def __init__(self, num_levels=3, codebook_size=256, dim=64, n_heads=4):
        super().__init__()
        self.embs = nn.ModuleList([nn.Embedding(codebook_size, dim) for _ in range(num_levels)])
        self.attn = nn.MultiheadAttention(dim, n_heads, batch_first=True)
        self.query = nn.Parameter(torch.randn(1, 1, dim))

    def forward(self, sid):
        # sid: [B, L]
        parts = torch.stack([emb(sid[:, i]) for i, emb in enumerate(self.embs)], 1)  # [B, L, D]
        # 用 query 聚合所有层
        B = sid.size(0)
        q = self.query.expand(B, -1, -1)  # [B, 1, D]
        out, _ = self.attn(q, parts, parts)  # [B, 1, D]
        return out.squeeze(1)  # [B, D]
```

**优点**: 自适应层间加权,表达力最强。
**缺点**: 计算量大,训练慢。

### A.1.4 聚合方式对比

| 方式 | 参数量 | 表达力 | 训练速度 | 推荐场景 |
| :--- | :--- | :--- | :--- | :--- |
| Sum | $L \times K \times D$ | 低 | 快 | 召回、粗排 |
| Concat | $L \times K \times D + L \times D^2$ | 中 | 中 | 精排、多任务 |
| Attention | $L \times K \times D + 4D^2$ | 高 | 慢 | 高质量推荐 |

## A.2 词表设计:层偏移

### A.2.1 为什么需要层偏移?

TIGER / OneRec 把 SID 展平成 token 序列,如果直接拼接:
```text
[item1_layer0, item1_layer1, item1_layer2, item2_layer0, ...]
```
问题: layer0 的 code=5 和 layer1 的 code=5 是同一个 token,模型无法区分。

**解决**: 给每层加偏移 `offset = layer_index * codebook_size`:
```text
token(l, c) = l * K + c
```
这样 layer0 的 code=5 → token=5, layer1 的 code=5 → token=K+5 = 261。

```python
def tokenize_sid(sid, K=256):
    """sid: [B, L] → tokens: [B, L*K]"""
    L = sid.size(-1)
    offset = torch.arange(L, device=sid.device) * K
    return sid + offset
```

### A.2.2 词表设计进阶

```python
# 加 BOS / EOS / PAD
vocab = L * K + 3
BOS = vocab - 3
EOS = vocab - 2
PAD = vocab - 1

def encode_with_special(sid, K=256, L=3, max_len=20):
    """编码 SID 序列,加特殊 token。"""
    # [BOS, layer0, layer1, layer2, EOS, PAD, ...]
    tokens = []
    tokens.append(torch.full((sid.size(0),), BOS, device=sid.device))
    for l in range(L):
        offset = l * K
        tokens.append(sid[:, l] + offset)
    tokens.append(torch.full((sid.size(0),), EOS, device=sid.device))
    while len(tokens) < max_len:
        tokens.append(torch.full((sid.size(0),), PAD, device=sid.device))
    return torch.stack(tokens, -1)  # [B, max_len]
```

## B.1 TIGER 的完整架构

### B.1.1 训练阶段的细节

```python
class TIGERTrainer:
    """TIGER 的训练循环。"""
    def __init__(self, model, lr=1e-3, batch_size=256, grad_clip=1.0):
        self.model = model.cuda()
        self.opt = torch.optim.AdamW(self.model.parameters(), lr=lr, weight_decay=1e-4)
        self.batch_size = batch_size
        self.grad_clip = grad_clip

    def train_step(self, batch):
        """
        batch: {
            'hist_sids': [B, T, L],     # 用户历史 SID 序列
            'target_sid': [B, L],        # 目标 item SID
        }
        """
        hist = batch['hist_sids'].cuda()
        target = batch['target_sid'].cuda()

        # Forward
        logits = self.model(hist, target[:, :-1])  # [B, L-1, vocab]

        # Target tokens (扁平化)
        target_tokens = self.model._flatten(target.unsqueeze(1))  # [B, L]
        target_tokens = target_tokens[:, 1:]  # 去掉第一个 (BOS)

        # Cross-entropy
        loss = F.cross_entropy(
            logits.reshape(-1, logits.size(-1)),
            target_tokens.reshape(-1),
            ignore_index=PAD_IDX
        )

        # Backward
        self.opt.zero_grad()
        loss.backward()
        torch.nn.utils.clip_grad_norm_(self.model.parameters(), self.grad_clip)
        self.opt.step()

        return loss.item()
```

### B.1.2 推理阶段的细节

```python
class TIGERBeamSearchInference:
    """TIGER 的 beam search 推理,带 Trie 约束。"""
    def __init__(self, model, trie, beam_size=10, max_len=20):
        self.model = model.eval().cuda()
        self.trie = trie
        self.beam_size = beam_size
        self.max_len = max_len

    @torch.no_grad()
    def predict(self, hist_sid, top_k=10):
        """
        hist_sid: [1, T, L] 用户历史
        返回: top_k 个候选 SID
        """
        # 初始 beam: (score, seq)
        beams = [(0.0, [])]

        for step in range(self.model.L):
            candidates = []
            for score, seq in beams:
                # 把已有 seq 转成模型输入
                if step == 0:
                    inp = self.model.bos_token
                else:
                    inp = self.model.encode_seq([seq])  # [1, L]

                # Forward
                logits = self.model(hist_sid, inp)  # [1, L, vocab]
                logits_step = logits[0, step]  # 当前步的 logits
                probs = F.log_softmax(logits_step, dim=-1)

                # Trie 约束
                if self.trie is not None and step > 0:
                    valid_mask = self.trie.get_valid_codes(tuple(seq), step)
                    probs = probs.masked_fill(~valid_mask, -1e9)

                # Top-k
                top_k_vals, top_k_idx = probs.topk(self.beam_size)
                for prob, code in zip(top_k_vals.tolist(), top_k_idx.tolist()):
                    new_seq = seq + [code]
                    candidates.append((score + prob, new_seq))

            # 保留 top beam_size
            beams = sorted(candidates, key=lambda x: x[0], reverse=True)[:self.beam_size]

        # 完整 SID 列表,按 score 排序
        return [seq for _, seq in beams[:top_k]]
```

### B.1.3 Trie 的实现

```python
class Trie:
    """SID 合法性的前缀树。

    每个节点:
        - children: dict {code: TrieNode}
        - is_end: bool, 是否是一个合法 SID 的终点

    插入: 从根节点出发,逐层插入 code,最后一层标记 is_end=True
    查询: 从根节点出发,逐层匹配 code
    """
    def __init__(self):
        self.root = {}
        self.is_end = False

    def insert(self, sid):
        """插入一个合法 SID。"""
        node = self.root
        for code in sid:
            if code not in node:
                node[code] = {}
            node = node[code]
        node['_end_'] = True  # 标记终点

    def is_valid(self, sid):
        """检查 SID 是否合法。"""
        node = self.root
        for code in sid:
            if code not in node:
                return False
            node = node[code]
        return node.get('_end_', False)

    def get_valid_codes(self, prefix_sid, level):
        """返回 prefix_sid + level 位置上所有合法的 code。

        Args:
            prefix_sid: 前缀 SID (不含 level 位置)
            level: 当前层 (0-indexed)

        Returns:
            bool tensor [K], True 表示合法
        """
        node = self.root
        for code in prefix_sid:
            if code not in node:
                return torch.zeros(K, dtype=torch.bool)
            node = node[code]
        # level == len(prefix_sid),返回所有子节点
        valid = torch.zeros(K, dtype=torch.bool)
        for code in node:
            if code != '_end_':
                valid[code] = True
        return valid
```

**为什么需要 Trie**: RQ-Kmeans 训练时,所有 $L$ 层码本可以组合成 $K^L$ 个理论 SID,但实际数据只覆盖其中一部分。生成式模型如果不限约束,可能生成"训练集从未见过"的 SID,检索时找不到对应物品。

## B.2 TIGER 的改进变体

### B.2.1 Prefix Beam Search

标准 beam search 可能在某步选了一个"局部最优但最终不合理"的 token。Prefix Beam Search 在每步保留**前缀**(而非完整序列):

```python
def prefix_beam_search(self, hist_sid, beam_size=10):
    """Prefix Beam Search:按前缀去重,每步只保留 beam_size 个不同前缀。"""
    beams = [(0.0, [])]

    for step in range(self.L):
        # 把同一前缀的 score 合并
        prefix_scores = {}
        for score, seq in beams:
            if tuple(seq) not in prefix_scores:
                prefix_scores[tuple(seq)] = []
            # ... 计算每个前缀的后续概率 ...

        # 选 top beam_size 前缀
        sorted_prefixes = sorted(prefix_scores.items(), key=lambda x: x[1], reverse=True)[:beam_size]
        new_beams = [(score, list(seq)) for seq, score in sorted_prefixes]
        beams = new_beams

    return beams
```

### B.2.2 Diverse Beam Search

鼓励生成**多样性**的候选:

```python
def diverse_beam_search(self, hist_sid, beam_size=10, diversity=0.5):
    """Diverse Beam Search:惩罚相似候选。"""
    beams = [(0.0, [])]
    groups = beam_size // 5  # 5 个 group

    for step in range(self.L):
        group_results = []
        for g in range(groups):
            # 每个 group 用不同的 diversity penalty
            penalty = diversity * g
            candidates = []
            for score, seq in beams:
                logits = self.model(hist_sid, seq)
                probs = F.log_softmax(logits[0, step], -1)
                # 减去已用 token 的概率
                for prev_seq in [b for b in beams if b[1] != seq]:
                    for code in prev_seq[1]:
                        probs[code] -= penalty

                top_k = probs.topk(self.beam_size)
                for prob, code in zip(top_k.values, top_k.indices):
                    candidates.append((score + prob, seq + [code]))

            # 每个 group 选 top 1
            group_results.append(max(candidates, key=lambda x: x[0]))

        beams = group_results

    return beams
```

### B.2.3 Nucleus (Top-p) Sampling

不想用 beam search?用 nucleus sampling:

```python
def nucleus_sample(self, hist_sid, p=0.9, max_len=20):
    """Nucleus Sampling:从累积概率 ≥ p 的最小 token 集合里采样。"""
    seq = []
    for step in range(self.L):
        logits = self.model(hist_sid, seq)
        probs = F.softmax(logits[0, step], -1)

        # Sort by probability
        sorted_probs, sorted_idx = probs.sort(descending=True)
        cumsum = sorted_probs.cumsum(0)

        # Find smallest set with cumsum >= p
        cutoff = (cumsum >= p).nonzero()[0].item()
        candidates = sorted_idx[:cutoff + 1]
        cand_probs = sorted_probs[:cutoff + 1]
        cand_probs = cand_probs / cand_probs.sum()  # Renormalize

        # Sample
        idx = torch.multinomial(cand_probs, 1).item()
        seq.append(candidates[idx].item())

    return seq
```

```python
def get_cosine_schedule(optimizer, warmup_steps=1000, total_steps=10000):
    """Cosine schedule with warmup."""
    def lr_lambda(step):
        if step < warmup_steps:
            return step / warmup_steps
```

```python
def augment_user_history(hist_sids, aug_prob=0.1):
    """用户历史数据增强:
```

### B.3.3 负采样

TIGER 是生成式,不需要显式负采样。但**对比学习**风格的辅助任务可以提升效果:

```python
def in_batch_negative_loss(anchor_sid, positive_sid, temperature=0.07):
    """In-batch 负采样:同 batch 内的其他样本当负样本。"""
    B = anchor_sid.size(0)

    # Encode
    anchor_emb = F.normalize(anchor_sid, dim=-1)  # [B, D]
    positive_emb = F.normalize(positive_sid, dim=-1)  # [B, D]

    # Similarity matrix
    sim = anchor_emb @ positive_emb.T / temperature  # [B, B]

    # Diagonal 是正样本
    labels = torch.arange(B, device=anchor_sid.device)
    return F.cross_entropy(sim, labels)
```

### C.1.3 任务冲突的检测与解决

```python
class TaskConflictDetector:
    """检测任务梯度冲突,自动调整 MMoE。"""
    def __init__(self, n_tasks):
        self.n_tasks = n_tasks
        self.grad_history = []

    def detect_conflict(self, gradients):
        """
        gradients: list of [n_tasks] tensors, 每个任务的梯度
        返回: 冲突矩阵 [n_tasks, n_tasks], -1 冲突, +1 一致
        """
        grads = torch.stack(gradients)  # [n_tasks, D]
        sim_matrix = F.cosine_similarity(grads.unsqueeze(0), grads.unsqueeze(1), dim=-1)
        return sim_matrix  # < 0 表示冲突

    def adjust_weights(self, gradients, loss_weights):
        """根据冲突调整任务权重。"""
        conflict = self.detect_conflict(gradients)
        # 对冲突大的任务降低权重
        new_weights = loss_weights * torch.sigmoid(conflict.sum(0))
        return new_weights / new_weights.sum()
```

## C.2 MMoE + SID 的工业实践

### C.2.1 长尾 item 的特殊处理

```python
class LongTailMMoE(nn.Module):
    """MMoE + SID + 长尾 item 增强。"""
    def __init__(self, num_levels=3, codebook_size=256, dim=64, n_experts=4, n_tasks=2):
        super().__init__()
        self.sid_emb = SIDEmbedding(num_levels, codebook_size, dim, agg='concat')
        self.experts = nn.ModuleList([
            nn.Sequential(nn.Linear(dim, 128), nn.ReLU()) for _ in range(n_experts)
        ])
        self.gates = nn.ModuleList([nn.Linear(dim, n_experts) for _ in range(n_tasks)])
        self.towers = nn.ModuleList([nn.Linear(128, 1) for _ in range(n_tasks)])

    def forward(self, sid, item_freq):
        """
        sid: [B, L]
        item_freq: [B] item 流行度
        """
        x = self.sid_emb(sid)  # [B, D]

        # 流行度编码
        freq_emb = torch.log1p(item_freq).unsqueeze(-1)  # [B, 1]
        x = torch.cat([x, freq_emb], -1)

        expert_out = torch.stack([e(x) for e in self.experts], 1)
        outs = []
        for gate, tower in zip(self.gates, self.towers):
            w = F.softmax(gate(x), dim=-1).unsqueeze(-1)
            mixed = (w * expert_out).sum(1)
            outs.append(torch.sigmoid(tower(mixed)))
        return torch.cat(outs, -1)
```

### C.2.2 多任务 label 的处理

```python
class ESMMLabelGenerator:
    """ESMM:把 CVR 转成"点击且转化"的形式,解决 SSB 问题。"""
    def __init__(self):
        pass

    def generate_labels(self, click, convert):
        """
        click: [N] 0/1
        convert: [N] 0/1
        返回:
            ctr_label: click
            ctcvr_label: click AND convert
            cvr_label: convert where click = 1, else -1 (mask)
        """
        ctr = click.float()
        ctcvr = (click & convert).float()
        # CVR 标签只在点击样本上有意义
        cvr = torch.where(click.bool(), convert.float(), torch.tensor(-1.0))
        return ctr, ctcvr, cvr


def esmm_loss(ctr_pred, cvr_pred, ctr_label, ctcvr_label, cvr_label):
    """ESMM 的复合 loss。"""
    ctr_loss = F.binary_cross_entropy(ctr_pred, ctr_label)

    # pCTCVR = pCTR * pCVR
    ctcvr_pred = ctr_pred * cvr_pred
    ctcvr_loss = F.binary_cross_entropy(ctcvr_pred, ctcvr_label)

    # CVR 只在点击样本上算
    mask = (cvr_label >= 0).float()
    cvr_loss = (F.binary_cross_entropy(cvr_pred, cvr_label.clamp(0, 1), reduction='none') * mask).sum() / mask.sum()

    return ctr_loss + ctcvr_loss + cvr_loss
```

### D.1.1 优先采样困难样本

```python
class HardSampleDistill:
    """对教师和学生差异大的样本加权。"""
    def __init__(self, teacher, student, hard_weight=2.0):
        self.teacher = teacher
        self.student = student
        self.hard_weight = hard_weight

    def compute_loss(self, x, y):
        with torch.no_grad():
            t_logit = self.teacher(x)
        s_logit = self.student(x)

        # 难度权重:KL 越大,权重越高
        kl = F.kl_div(
            F.log_softmax(s_logit, -1),
            F.softmax(t_logit, -1),
            reduction='none'
        ).sum(-1)  # [B]

        # 加权
        weight = 1.0 + (kl > kl.median()).float() * self.hard_weight
        return (F.cross_entropy(s_logit, y, reduction='none') * weight).mean()
```

```python
class MultiTeacherEnsemble:
    """多教师集成蒸馏。"""

        self.student = student
        self.weights = weights or [1.0 / len(teachers)] * len(teachers)
```

### E.1.2 Reward 标准化

```python
class RunningMeanStd:
    """Reward 的 running mean/std,用于标准化。"""
    def __init__(self, epsilon=1e-4, shape=()):
        self.mean = np.zeros(shape, dtype=np.float64)
        self.var = np.ones(shape, dtype=np.float64)
        self.count = epsilon

    def update(self, x):
        batch_mean = np.mean(x, axis=0)
        batch_var = np.var(x, axis=0)
        batch_count = x.shape[0]

        delta = batch_mean - self.mean
        tot_count = self.count + batch_count

        new_mean = self.mean + delta * batch_count / tot_count
        m_a = self.var * self.count
        m_b = batch_var * batch_count
        M2 = m_a + m_b + np.square(delta) * self.count * batch_count / tot_count
        new_var = M2 / tot_count

        self.mean = new_mean
        self.var = new_var
        self.count = tot_count

    def normalize(self, x):
        return (x - self.mean) / (np.sqrt(self.var) + 1e-8)

# 在 RL 里
reward_rms = RunningMeanStd()
rewards_normalized = reward_rms.normalize(rewards)
```

### E.1.3 GAE 的向量化计算

```python
def compute_gae_vectorized(rewards, values, dones, gamma=0.99, lam=0.95):
    """向量化 GAE, 比 for 循环快。"""
    T = rewards.shape[0]
    advantages = torch.zeros_like(rewards)
    last_gae = 0

    # 反向计算
    for t in reversed(range(T)):
        if t == T - 1:
            next_value = 0
        else:
            next_value = values[t + 1]
        delta = rewards[t] + gamma * next_value * (1 - dones[t]) - values[t]
        last_gae = delta + gamma * lam * (1 - dones[t]) * last_gae
        advantages[t] = last_gae

    returns = advantages + values
    return advantages, returns
```

## E.2 RL 在生产中的踩坑案例

### E.2.1 案例 1:Reward Hacking 导致业务指标下降

**现象**: 离线 RL 训练 reward 持续上升,但 A/B 实验 CTR 下降。

**原因**: Reward model 把"短点击"当成好信号,模型学推"标题党"。

**解决**:
1. Reward 加 dwell_time 阈值(必须停留 > 5s)
2. Reward 加多样性正则
3. 在线监控核心业务指标,告警时立即回滚

### E.2.2 案例 2:KL 爆炸导致完全偏离 SFT

**现象**: 训练 1000 步后,策略生成的 SID 与 SFT 模型完全不同。

**原因**: KL 系数太小 (0.001),学生快速跑偏。

**解决**:
1. KL 系数设为 0.05~0.1
2. 加 LR warmup
3. 监控 KL 超过 0.5 时立即停止

### E.2.3 案例 3:策略坍塌到单一动作

**现象**: 训练后期,模型只生成一个 SID。

**原因**: Entropy bonus 太小 (0.001),策略过度集中。

**解决**:
1. Entropy 系数设为 0.05~0.1
2. 加 temperature 采样 (decoding 时 T=1.5)
3. 加多样化 batch 训练

```python
class SIDLabelGenerator:
    """从 item 内容 + SID 聚类结果,生成码本标签。"""
    def __init__(self, encoder, kmeans):
        self.encoder = encoder  # Sentence-BERT
        self.kmeans = kmeans

    def generate_labels_for_code(self, code, items_in_code):
        """
        code: int, 码字
        items_in_code: List[str], 该码字下的 item 描述
        返回: 人读标签

        # 1) 取所有 item 的 embedding
        embs = self.encoder.encode(items_in_code)

        # 4) 用 LLM 生成标签

        label = self.extract_keywords(most_rep_item)

        return label
```

```python
        level_label_maps: List[Dict[int, str]]
        level_label_maps[0]: 粗层标签 (类目)
        level_label_maps[1]: 细层标签 (子分类)
        """
        self.maps = level_label_maps

    def get_path(self, sid):
        """sid: [L] → '粗 > 中 > 细' 路径"""
        return ' > '.join(self.maps[l].get(sid[l].item(), f'code_{sid[l]}') for l in range(len(sid)))

    def get_category(self, sid):
        """只取粗层。"""
        return self.maps[0].get(sid[0].item(), f'code_{sid[0]}')
```

```python
class DiversifiedExplainer:
    """生成多样化的推荐理由,避免重复。"""
    def __init__(self, label_maps):
        self.maps = label_maps
        self.templates = [
            "你常看「{category}」类,为你推荐同类新品",
            "你最近在关注「{tag}」,这个或许也合你口味",
            "基于你「{history_item}」的浏览,推荐「{new_item}」",
            "探索性推荐:{category} 中的新发现",
        ]

    def explain(self, user_hist, cand_sid, history_items_titles, cand_title):
        # 找出命中层
        hit_layer = -1
        for l in range(len(cand_sid)):
            if any(h[l] == cand_sid[l] for h in user_hist):
                hit_layer = l
                break

        if hit_layer >= 0:
            category = self.maps[hit_layer].get(cand_sid[hit_layer].item(), "")
            history_item = history_items_titles[-1] if history_items_titles else ""
            template = random.choice(self.templates[:3])
            return template.format(
                category=category,
                tag=category,
                history_item=history_item,
                new_item=cand_title
            )
        else:
            return random.choice(self.templates[3:]).format(category="新领域")
```

```python
class FullPipeline:
    """完整 SID 推荐 pipeline,组合 5 个示例。"""
    def __init__(self):
        # 召回:TIGER 生成
        self.tiger = TIGERRecommender()
        # 粗排:MMoE + SID
        self.mmoe = SIDMMoE()
        # 精排:MMoE 蒸馏教师 → 学生
        self.teacher_mmoe = SIDMMoE(large=True)
        self.student_mmoe = SIDMMoE(large=False)
        # RL 微调:PPO
        self.ppo_policy = PPOWithSID()
        # 可解释
        self.explainer = SIDExplainer(level_label_maps)

    def serve(self, user_hist_sids, candidates_sids, item_freq):
        """
        user_hist_sids: [T, L] 用户历史
        candidates_sids: [N, L] 候选
        返回: top_k 推荐 + 解释
        """
        # 1) Recall:TIGER 生成候选
        with torch.no_grad():
            recall_sids = self.tiger.generate(user_hist_sids.unsqueeze(0), top_k=100)

        # 2) Coarse:MMoE 打分
        coarse_scores = self.mmoe(recall_sids)  # [N, 2] = (ctr, cvr)
        top_100_idx = coarse_scores[:, 0].topk(100).indices
        coarse_sids = recall_sids[top_100_idx]

        # 3) Fine:蒸馏学生打分
        fine_scores = self.student_mmoe(coarse_sids)  # [N]
        top_10_idx = fine_scores.topk(10).indices
        fine_sids = coarse_sids[top_10_idx]

        # 4) Explain
        explanations = [self.explainer.explain_reco(user_hist_sids, sid) for sid in fine_sids]

        return fine_sids, explanations
```

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math
from typing import Optional, Tuple, List


class PositionalEncoding(nn.Module):
    """Sinusoidal 位置编码"""
    def __init__(self, dim, max_len=512):
        super().__init__()
        pe = torch.zeros(max_len, dim)
        position = torch.arange(0, max_len).unsqueeze(1).float()
        div_term = torch.exp(torch.arange(0, dim, 2).float() * -(math.log(10000.0) / dim))
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        self.register_buffer('pe', pe.unsqueeze(0))

    def forward(self, x):
        return x + self.pe[:, :x.size(1)]


class FlashMultiHeadAttention(nn.Module):
    """多头注意力 (兼容 Flash Attention)"""
    def __init__(self, dim, n_heads, dropout=0.1):
        super().__init__()
        assert dim % n_heads == 0
        self.dim = dim
        self.n_heads = n_heads
        self.head_dim = dim // n_heads
        self.qkv = nn.Linear(dim, 3 * dim)
        self.out_proj = nn.Linear(dim, dim)
        self.dropout = dropout

    def forward(self, x, mask=None):
        B, T, D = x.shape
        qkv = self.qkv(x).reshape(B, T, 3, self.n_heads, self.head_dim).permute(2, 0, 3, 1, 4)
        q, k, v = qkv[0], qkv[1], qkv[2]  # [B, H, T, D_h]
        # PyTorch 2.0+ 的 scaled_dot_product_attention 自动使用 Flash Attention
        out = F.scaled_dot_product_attention(q, k, v, attn_mask=mask, dropout_p=self.dropout if self.training else 0.0)
        out = out.transpose(1, 2).reshape(B, T, D)
        return self.out_proj(out)


class TransformerDecoderBlock(nn.Module):
    """Transformer Decoder 块"""
    def __init__(self, dim, n_heads, ff_dim, dropout=0.1):
        super().__init__()
        self.self_attn = FlashMultiHeadAttention(dim, n_heads, dropout)
        self.norm1 = nn.LayerNorm(dim)
        self.ff = nn.Sequential(
            nn.Linear(dim, ff_dim), nn.GELU(), nn.Dropout(dropout),
            nn.Linear(ff_dim, dim), nn.Dropout(dropout)
        )
        self.norm2 = nn.LayerNorm(dim)
        self.dropout = nn.Dropout(dropout)

    def forward(self, x, mask=None):
        x = x + self.dropout(self.self_attn(self.norm1(x), mask))
        x = x + self.dropout(self.ff(self.norm2(x)))
        return x


class IndustrialTIGER(nn.Module):
    """工业级 TIGER: 多任务生成式推荐"""

    def __init__(self, L=3, K=256, dim=256, n_layers=6, n_heads=8,
                 ff_dim=1024, max_seq_len=256, dropout=0.1):
        super().__init__()
        self.L, self.K = L, K
        vocab = L * K + 2
        self.bos_id = vocab - 2
        self.eos_id = vocab - 1
        # SID Token Embedding (共享给所有层, 通过偏移区分)
        self.tok_emb = nn.Embedding(vocab, dim, padding_idx=0)
        # 位置编码
        self.pos_enc = PositionalEncoding(dim, max_seq_len * L + 10)
        # Transformer Decoder (多层)
        self.blocks = nn.ModuleList([
            TransformerDecoderBlock(dim, n_heads, ff_dim, dropout)
            for _ in range(n_layers)
        ])
        self.norm = nn.LayerNorm(dim)
        # 多任务输出头
        self.sid_heads = nn.ModuleList([nn.Linear(dim, K) for _ in range(L)])
        self.ctr_head = nn.Linear(dim, 1)
        self.cvr_head = nn.Linear(dim, 1)
        self.dwell_head = nn.Linear(dim, 1)
        # 初始化
        self._init_weights()

    def _init_weights(self):
        for p in self.parameters():
            if p.dim() > 1:
                nn.init.xavier_uniform_(p)

    def flatten_sid(self, sids):
        """[B, T, L] -> [B, T*L], 加层偏移"""
        B, T, L = sids.shape
        offset = torch.arange(L, device=sids.device) * self.K
        return (sids + offset).reshape(B, T * L)

    def forward(self, hist_sids, tgt_sids=None, return_hidden=False):
        """
        hist_sids: [B, T, L] 用户历史
        tgt_sids:  [B, L] 训练时目标 SID
        """
        src = self.flatten_sid(hist_sids)  # [B, T*L]
        src_emb = self.pos_enc(self.tok_emb(src))

        if self.training and tgt_sids is not None:
            # 训练: teacher forcing
            tgt_flat = self.flatten_sid(tgt_sids.unsqueeze(1))
            bos = torch.full((tgt_sids.size(0), 1), self.bos_id, device=src.device)
            tgt_in = torch.cat([bos, tgt_flat[:, :-1]], dim=1)
            tgt_emb = self.pos_enc(self.tok_emb(tgt_in))
            causal = torch.triu(torch.full((tgt_in.size(1), tgt_in.size(1)), float('-inf')), 1).to(src.device)
            out = tgt_emb
            for block in self.blocks:
                out = block(out, causal)
            out = self.norm(out)
            # 每层一个分类头
            sid_logits = torch.stack([self.sid_heads[l](out[:, l, :]) for l in range(self.L)], 1)
            # 多任务预测 (用最后一个 token)
            last_hidden = out[:, -1, :]
            ctr = torch.sigmoid(self.ctr_head(last_hidden)).squeeze(-1)
            cvr = torch.sigmoid(self.cvr_head(last_hidden)).squeeze(-1)
            dwell = F.softplus(self.dwell_head(last_hidden)).squeeze(-1)
            if return_hidden:
                return sid_logits, ctr, cvr, dwell, last_hidden
            return sid_logits, ctr, cvr, dwell
        else:
            return self.generate(src_emb)

    @torch.no_grad()
    def generate(self, src_emb, beam_size=20, max_len=None):
        """自回归生成 (greedy, 完整版用 beam_search_with_trie)"""
        max_len = max_len or self.L
        B = src_emb.size(0)
        tgt = torch.full((B, 1), self.bos_id, device=src_emb.device, dtype=torch.long)
        for step in range(max_len):
            tgt_emb = self.pos_enc(self.tok_emb(tgt))
            causal = torch.triu(torch.full((tgt.size(1), tgt.size(1),), float('-inf')), 1).to(src_emb.device)
            out = tgt_emb
            for block in self.blocks:
                out = block(out, causal)
            out = self.norm(out)
            next_logit = self.sid_heads[step](out[:, -1, :])
            next_code = next_logit.argmax(-1, keepdim=True)
            offset = step * self.K
            tgt = torch.cat([tgt, next_code + offset], dim=1)
        return tgt[:, 1:]
```

## 1.3 Trie 约束解码

```python
class TrieNode:
    """Trie 节点: 用于约束 SID 解码"""
    def __init__(self):
        self.children = {}
        self.is_leaf = False


class SIDTrie:
    """码本合法性 Trie"""

    def __init__(self, valid_sids):
        """
        valid_sids: List[Tuple[int, ...]] 所有合法 SID 组合
        """
        self.root = TrieNode()
        for sid in valid_sids:
            self._insert(sid)

    def _insert(self, sid):
        node = self.root
        for code in sid:
            if code not in node.children:
                node.children[code] = TrieNode()
            node = node.children[code]
        node.is_leaf = True

    def is_prefix_valid(self, prefix_codes):
        """检查 prefix 是否可能是合法 SID 的前缀"""
        node = self.root
        for code in prefix_codes:
            if code not in node.children:
                return False
            node = node.children[code]
        return True

    def is_complete(self, codes):
        """检查 codes 是否是完整合法 SID"""
        node = self.root
        for code in codes:
            if code not in node.children:
                return False
            node = node.children[code]
        return node.is_leaf

    def get_valid_codes(self, prefix_codes):
        """返回当前 prefix 下合法的下一码"""
        node = self.root
        for code in prefix_codes:
            if code not in node.children:
                return []
            node = node.children[code]
        return list(node.children.keys())


def beam_search_with_trie(model, hist_sids, trie: SIDTrie,
                          beam_size=20, temperature=1.0, max_len=None):
    """Beam Search + Trie 约束解码"""
    model.eval()
    L = model.L
    max_len = max_len or L
    B = hist_sids.size(0)

    results = []
    for b in range(B):
        # 每个样本独立 beam search
        src_emb = model.pos_enc(model.tok_emb(model.flatten_sid(hist_sids[b:b+1])))
        # 初始 beam: (累积 log prob, SID 序列)
        beams = [(0.0, [model.bos_id])]
        completed = []

        for step in range(max_len):
            candidates = []
            for logp, seq in beams:
                # 当前 SID 解码 (去掉层偏移)
                prefix_codes = [(c % model.K) for c in seq[1:]]  # 跳过 BOS
                # 校验 Trie
                valid_next = trie.get_valid_codes(prefix_codes) if trie else list(range(model.K))
                if not valid_next:
                    continue
                # 模型前向
                tgt = torch.tensor([seq], device=src_emb.device)
                tgt_emb = model.pos_enc(model.tok_emb(tgt))
                causal = torch.triu(torch.full((tgt.size(1), tgt.size(1)), float('-inf')), 1).to(src_emb.device)
                out = tgt_emb
                for block in model.blocks:
                    out = block(out, causal)
                out = model.norm(out)
                next_logit = model.sid_heads[step](out[:, -1, :]) / temperature
                next_logp = F.log_softmax(next_logit, dim=-1)[0]  # [K]

                # Top-K 候选 (限制在 valid_next)
                for v in valid_next:
                    new_logp = logp + next_logp[v].item()
                    new_seq = seq + [step * model.K + v]
                    candidates.append((new_logp, new_seq))

            # 取 top beam_size
            candidates.sort(key=lambda x: -x[0])
            beams = candidates[:beam_size]
            # 检查完成的序列
            new_beams = []
            for logp, seq in beams:
                if len(seq) == max_len + 1:  # BOS + L 码
                    completed.append((logp, seq[1:]))
                else:
                    new_beams.append((logp, seq))
            beams = new_beams
            if not beams:
                break

        # 加上未完成的 beams (用最后一个概率)
        completed.extend(beams)
        completed.sort(key=lambda x: -x[0])
        # 转换回 SID (去掉偏移)
        best_seq = completed[0][1] if completed else [0] * L
        sid = [c % model.K for c in best_seq[:L]]
        results.append(sid)

    return torch.tensor(results, device=hist_sids.device)
```

## 1.4 训练循环 (含 AMP + EMA + 梯度累积)

```python
import copy

class TIGERTrainer:
    """工业级 TIGER 训练器"""

    def __init__(self, model, train_loader, val_loader, lr=1e-3,
                 weight_decay=1e-4, use_amp=True, grad_accum=4, ema_decay=0.999):
        self.model = model.cuda()
        self.train_loader = train_loader
        self.val_loader = val_loader
        self.use_amp = use_amp
        self.grad_accum = grad_accum
        # EMA 模型 (用于推理和评估)
        self.ema_model = copy.deepcopy(model).eval().requires_grad_(False)
        self.ema_decay = ema_decay
        # 优化器
        self.opt = torch.optim.AdamW(model.parameters(), lr=lr, weight_decay=weight_decay)
        self.scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(self.opt, T_max=20)
        # AMP
        self.scaler = torch.amp.GradScaler('cuda') if use_amp else None
        # 损失权重
        self.task_weights = {"sid": 1.0, "ctr": 0.3, "cvr": 0.2, "dwell": 0.1}

    def compute_loss(self, batch):
        """多任务联合损失"""
        sid_logits, ctr, cvr, dwell = self.model(batch["hist_sids"], batch["tgt_sid"])
        # SID 多层 CE
        sid_loss = sum(F.cross_entropy(sid_logits[:, l, :], batch["tgt_sid"][:, l])
                       for l in range(self.model.L))
        # 多任务 BCE / MSE
        ctr_loss = F.binary_cross_entropy(ctr, batch["click"].float())
        cvr_loss = F.binary_cross_entropy(cvr, batch["convert"].float())
        dwell_loss = F.mse_loss(dwell, batch["dwell_time"].float())
        # 加权求和
        total = (self.task_weights["sid"] * sid_loss +
                 self.task_weights["ctr"] * ctr_loss +
                 self.task_weights["cvr"] * cvr_loss +
                 self.task_weights["dwell"] * dwell_loss)
        return total, {"sid": sid_loss.item(), "ctr": ctr_loss.item(),
                       "cvr": cvr_loss.item(), "dwell": dwell_loss.item()}

    def train_epoch(self, epoch):
        self.model.train()
        self.opt.zero_grad()
        total_loss = 0
        for i, batch in enumerate(self.train_loader):
            batch = {k: v.cuda(non_blocking=True) for k, v in batch.items()}
            with torch.amp.autocast('cuda', enabled=self.use_amp):
                loss, metrics = self.compute_loss(batch)
                loss = loss / self.grad_accum

            if self.use_amp:
                self.scaler.scale(loss).backward()
            else:
                loss.backward()

            if (i + 1) % self.grad_accum == 0:
                if self.use_amp:
                    self.scaler.unscale_(self.opt)
                torch.nn.utils.clip_grad_norm_(self.model.parameters(), 1.0)
                if self.use_amp:
                    self.scaler.step(self.opt)
                    self.scaler.update()
                else:
                    self.opt.step()
                self.opt.zero_grad()
                # 更新 EMA
                self._update_ema()
            total_loss += loss.item() * self.grad_accum
        self.scheduler.step()
        return total_loss / len(self.train_loader)

    def _update_ema(self):
        """更新 EMA 模型"""
        with torch.no_grad():
            for ema_p, p in zip(self.ema_model.parameters(), self.model.parameters()):
                ema_p.data.mul_(self.ema_decay).add_(p.data, alpha=1 - self.ema_decay)
            for ema_b, b in zip(self.ema_model.buffers(), self.model.buffers()):
                ema_b.data.copy_(b.data)

    @torch.no_grad()
    def validate(self):
        """验证 Recall@K"""
        self.ema_model.eval()
        hits = {10: 0, 50: 0, 100: 0}
        total = 0
        for batch in self.val_loader:
            batch = {k: v.cuda() for k, v in batch.items()}
            # 用 EMA 模型生成
            pred = self.ema_model(batch["hist_sids"])  # [B, L]
            # Recall@K: 计算真实 SID 是否在 Top-K 中 (需要候选集)
            # 简化: 假设 pred 完全匹配就算命中
            for k in hits:
                hits[k] += (pred[:, :1] == batch["tgt_sid"][:, :1]).any(-1).sum().item()
            total += batch["tgt_sid"].size(0)
        return {f"Recall@{k}": v / total for k, v in hits.items()}
```

## 2.1 完整 MMoE 实现 (含 PLE 和 ESMM)

```python
class Expert(nn.Module):
    """单个专家网络"""
    def __init__(self, in_dim, hidden_dim, dropout=0.1):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, hidden_dim),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU()
        )

    def forward(self, x):
        return self.net(x)


class Gate(nn.Module):
    """门控网络: 输出专家权重"""
    def __init__(self, in_dim, n_experts):
        super().__init__()
        self.fc = nn.Linear(in_dim, n_experts)

    def forward(self, x):
        return F.softmax(self.fc(x), dim=-1)


class MMoELayer(nn.Module):
    """MMoE 层: 多专家 + 多门控"""
    def __init__(self, in_dim, hidden_dim, n_experts, n_tasks):
        super().__init__()
        self.experts = nn.ModuleList([Expert(in_dim, hidden_dim) for _ in range(n_experts)])
        self.gates = nn.ModuleList([Gate(in_dim, n_experts) for _ in range(n_tasks)])

    def forward(self, x):
        # x: [B, D]
        expert_outs = torch.stack([e(x) for e in self.experts], dim=1)  # [B, E, H]
        task_outs = []
        for gate in self.gates:
            w = gate(x).unsqueeze(-1)  # [B, E, 1]
            mixed = (w * expert_outs).sum(dim=1)  # [B, H]
            task_outs.append(mixed)
        return torch.stack(task_outs, dim=1)  # [B, T, H]


class TaskTower(nn.Module):
    """任务塔: 每个任务一个"""
    def __init__(self, hidden_dim, out_dim=1):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim // 2),
            nn.ReLU(),
            nn.Dropout(0.1),
            nn.Linear(hidden_dim // 2, out_dim)
        )

    def forward(self, x):
        return self.net(x)


class PLELayer(nn.Module):
    """PLE: 渐进式分层提取 (RecSys 2020)"""
    def __init__(self, in_dim, hidden_dim, n_shared_experts, n_task_experts, n_tasks):
        super().__init__()
        # 共享专家
        self.shared_experts = nn.ModuleList([Expert(in_dim, hidden_dim) for _ in range(n_shared_experts)])
        # 任务专属专家
        self.task_experts = nn.ModuleList([
            nn.ModuleList([Expert(in_dim, hidden_dim) for _ in range(n_task_experts)])
            for _ in range(n_tasks)
        ])
        # 门控 (每任务: shared + 自己的 experts)
        self.gates = nn.ModuleList([
            Gate(in_dim, n_shared_experts + n_task_experts)
            for _ in range(n_tasks)
        ])

    def forward(self, x):
        # 共享专家输出
        shared_outs = torch.stack([e(x) for e in self.shared_experts], dim=1)  # [B, E_s, H]
        task_outs = []
        for t in range(len(self.task_experts)):
            task_expert_outs = torch.stack([e(x) for e in self.task_experts[t]], dim=1)  # [B, E_t, H]
            all_experts = torch.cat([shared_outs, task_expert_outs], dim=1)  # [B, E_s+E_t, H]
            w = self.gates[t](x).unsqueeze(-1)  # [B, E_s+E_t, 1]
            mixed = (w * all_experts).sum(dim=1)  # [B, H]
            task_outs.append(mixed)
        return torch.stack(task_outs, dim=1)  # [B, T, H]


class IndustrialMMoESID(nn.Module):
    """工业级 MMoE × SID + PLE + ESMM"""

    def __init__(self, L=3, K=256, sid_dim=64, hidden=128,
                 n_experts=4, n_shared_experts=4, n_task_experts=2,
                 n_tasks=3, n_layers=2, use_ple=True):
        super().__init__()
        # SID Embedding (concat 聚合)
        self.sid_embs = nn.ModuleList([nn.Embedding(K, sid_dim) for _ in range(L)])
        self.sid_proj = nn.Linear(L * sid_dim, sid_dim)
        # MMoE / PLE 层
        self.use_ple = use_ple
        self.layers = nn.ModuleList()
        in_dim = sid_dim
        for _ in range(n_layers):
            if use_ple:
                self.layers.append(PLELayer(in_dim, hidden, n_shared_experts, n_task_experts, n_tasks))
            else:
                self.layers.append(MMoELayer(in_dim, hidden, n_experts, n_tasks))
            in_dim = hidden
        # 任务塔
        self.towers = nn.ModuleList([TaskTower(hidden, 1) for _ in range(n_tasks)])
        # ESMM: CVR = CTR × CTCVR
        self.n_tasks = n_tasks

    def sid_to_vec(self, sid):
        """[B, L] -> [B, D]"""
        parts = [emb(sid[:, l]) for l, emb in enumerate(self.sid_embs)]
        return self.sid_proj(torch.cat(parts, dim=-1))

    def forward(self, sid):
        x = self.sid_to_vec(sid)  # [B, D]
        for layer in self.layers:
            outs = layer(x)  # [B, T, H]
            x = outs.flatten(1) if not self.use_ple else outs.mean(dim=1)
        # 多任务预测
        preds = [torch.sigmoid(self.towers[t](outs[:, t, :])).squeeze(-1)
                 for t in range(self.n_tasks)]
        return torch.stack(preds, dim=-1)  # [B, n_tasks]


class ESMMLoss(nn.Module):
    """ESMM 损失: 解决 CVR 样本稀疏"""
    def __init__(self, ctr_weight=1.0, ctcvr_weight=1.0):
        super().__init__()
        self.ctr_weight = ctr_weight
        self.ctcvr_weight = ctcvr_weight

    def forward(self, preds, labels):
        """
        preds:  [B, 2] = (pctr, pctcvr)
        labels: [B, 2] = (click, convert)
        """
        pctr, pctcvr = preds[:, 0], preds[:, 1]
        click, convert = labels[:, 0], labels[:, 1]
        # pCVR = pCTCVR / pCTR (无偏估计)
        pcvr = pctcvr / (pctr + 1e-7)
        # CTR 损失 (全样本)
        ctr_loss = F.binary_cross_entropy(pctr, click.float())
        # CTCVR 损失 (有点击的样本)
        ctcvr_loss = F.binary_cross_entropy(pctcvr, convert.float())
        return self.ctr_weight * ctr_loss + self.ctcvr_weight * ctcvr_loss
```

## 第 3 部分 - 例 3 扩展: 知识蒸馏 5 种变体

## 3.1 Hinton KD (经典)

$$
\mathcal{L}_{\text{Hinton}} = \alpha T^2 \text{KL}(\sigma(\mathbf{z}_S / T) \| \sigma(\mathbf{z}_T / T)) + (1-\alpha) \text{CE}(\mathbf{z}_S, \mathbf{y})
$$

```python
class HintonKD(nn.Module):
    """Hinton 蒸馏"""
    def __init__(self, T=2.0, alpha=0.7):
        super().__init__()
        self.T = T
        self.alpha = alpha

    def forward(self, s_logits, t_logits, hard_label):
        soft = F.kl_div(
            F.log_softmax(s_logits / self.T, -1),
            F.softmax(t_logits / self.T, -1),
            reduction='batchmean'
        ) * (self.T ** 2)
        hard = F.cross_entropy(s_logits, hard_label)
        return self.alpha * soft + (1 - self.alpha) * hard
```

## 3.2 DKD (Decoupled KD, CVPR 2022)

DKD 把 KL 拆成 target class 和 non-target class 两部分, 分别加权:

$$
\mathcal{L}_{\text{DKD}} = \alpha \text{KL}(\mathbf{b}_T \| \mathbf{b}_S) + \beta \text{KL}(\tilde{\mathbf{b}}_T \| \tilde{\mathbf{b}}_S)
$$

其中 $\mathbf{b}$ 是 target class 概率, $\tilde{\mathbf{b}}$ 是 non-target。

```python
class DKDLoss(nn.Module):
    """Decoupled Knowledge Distillation"""
    def __init__(self, T=2.0, alpha=1.0, beta=8.0):
        super().__init__()
        self.T = T
        self.alpha = alpha  # target class 权重
        self.beta = beta   # non-target class 权重

    def forward(self, s_logits, t_logits, hard_label):
        # 温度软化
        p_t = F.softmax(t_logits / self.T, dim=-1)  # [B, K]
        p_s = F.log_softmax(s_logits / self.T, dim=-1)
        # 拆分: target class vs non-target
        B, K = p_t.shape
        # Target class 概率
        target_p_t = p_t.gather(1, hard_label.unsqueeze(1))  # [B, 1]
        target_p_s = p_s.gather(1, hard_label.unsqueeze(1))
        target_loss = F.kl_div(target_p_s.log(), target_p_t, reduction='batchmean')
        # Non-target 概率 (归一化)
        mask = torch.ones_like(p_t).scatter_(1, hard_label.unsqueeze(1), 0)
        non_t_p_t = (p_t * mask) / (p_t * mask).sum(-1, keepdim=True).clamp(min=1e-7)
        non_t_p_s = (p_s.exp() * mask) / (p_s.exp() * mask).sum(-1, keepdim=True).clamp(min=1e-7)
        non_t_loss = F.kl_div(non_t_p_s.log(), non_t_p_t, reduction='batchmean')
        return self.alpha * target_loss + self.beta * non_t_loss
```

## 3.3 Feature KD (中间层对齐)

$$
\mathcal{L}_{\text{FKD}} = \sum_{l} \| \mathbf{f}_S^{(l)} - \text{proj}(\mathbf{f}_T^{(l)}) \|^2
$$

```python
class FeatureKD(nn.Module):
    """中间层特征蒸馏"""
    def __init__(self, teacher_dims, student_dims, proj_dim=128):
        super().__init__()
        # 每层一个投影头 (对齐维度)
        self.projs = nn.ModuleList([
            nn.Linear(s_dim, proj_dim) for s_dim in student_dims
        ])
        self.teacher_projs = nn.ModuleList([
            nn.Linear(t_dim, proj_dim) for t_dim in teacher_dims
        ])

    def forward(self, s_features, t_features):
        loss = 0
        for s_proj, t_proj, s_f, t_f in zip(self.projs, self.teacher_projs, s_features, t_features):
            loss = loss + F.mse_loss(s_proj(s_f), t_proj(t_f.detach()))
        return loss
```

## 3.4 MiniLLM (反向 KD, 2024)

传统 KD 用 hard label 作目标, MiniLLM 用 teacher 的 **生成结果** 作目标 (sequence-level):

```python
class MiniLLMKD(nn.Module):
    """MiniLLM 反向 KD"""
    def __init__(self, T=1.0, alpha=0.5):
        super().__init__()
        self.T = T
        self.alpha = alpha

    def forward(self, s_logits, t_logits, t_seq):
        """
        t_seq: [B, L] 教师生成的序列 (作为目标)
        """
        # 反向 KL (student 更集中, teacher 更分散)
        loss_seq = F.cross_entropy(
            s_logits.reshape(-1, s_logits.size(-1)),
            t_seq.reshape(-1),
            ignore_index=-100
        )
        # 前向 KL (辅助)
        loss_kl = F.kl_div(
            F.log_softmax(s_logits / self.T, -1),
            F.softmax(t_logits / self.T, -1),
            reduction='batchmean'
        ) * (self.T ** 2)
        return self.alpha * loss_kl + (1 - self.alpha) * loss_seq
```

## 3.5 GKD (On-Policy Distillation, 2024)

用 student 自己的采样序列作为训练目标, 然后对齐 teacher 在这些序列上的概率:

```python
class GKDLoss(nn.Module):
    """Generalized On-Policy Distillation"""
    def __init__(self, T=1.0, alpha=0.5, lambda_=0.5):
        super().__init__()
        self.T = T
        self.alpha = alpha
        self.lambda_ = lambda_  # on-policy 数据比例

    def forward(self, s_logits, t_logits, hard_label, is_on_policy):
        # 反向 KL
        loss = F.kl_div(
            F.log_softmax(s_logits / self.T, -1),
            F.softmax(t_logits / self.T, -1),
            reduction='none'
        ).sum(-1) * (self.T ** 2)
        # On-policy 数据加权
        weight = torch.where(is_on_policy, self.lambda_, 1 - self.lambda_)
        return (loss * weight).mean()
```

## 4.1 PPO 完整实现

```python
class PPOActorCritic(nn.Module):
    """Actor-Critic: 输出 SID 生成策略 + 价值"""
    def __init__(self, state_dim=256, codebook_size=256, n_layers=3):
        super().__init__()
        self.shared = nn.Sequential(
            nn.Linear(state_dim, 512), nn.ReLU(),
            nn.Linear(512, 512), nn.ReLU()
        )
        # Actor: 输出每层码本的概率
        self.actor = nn.ModuleList([
            nn.Linear(512, codebook_size) for _ in range(n_layers)
        ])
        # Critic: 输出状态价值
        self.critic = nn.Linear(512, 1)

    def forward(self, state):
        """state: [B, state_dim] -> (logits_list, value)"""
        h = self.shared(state)
        logits_list = [F.log_softmax(a(h), -1) for a in self.actor]
        value = self.critic(h).squeeze(-1)
        return logits_list, value


class PPOTrainer:
    """PPO 训练器"""
    def __init__(self, model, ref_model, lr=1e-5, clip=0.2,
                 vf_coef=0.5, ent_coef=0.01, gamma=0.99, gae_lambda=0.95,
                 clip_grad=0.5, epochs=4):
        self.model = model
        self.ref_model = ref_model  # 冻结的 SFT 模型
        self.opt = torch.optim.Adam(model.parameters(), lr=lr)
        self.clip = clip
        self.vf_coef = vf_coef
        self.ent_coef = ent_coef
        self.gamma = gamma
        self.gae_lambda = gae_lambda
        self.clip_grad = clip_grad
        self.epochs = epochs

    def compute_gae(self, rewards, values, dones):
        """广义优势估计"""
        advantages = torch.zeros_like(rewards)
        last_gae = 0
        T = rewards.size(0)
        for t in reversed(range(T)):
            if t == T - 1:
                next_value = 0
            else:
                next_value = values[t + 1]
            delta = rewards[t] + self.gamma * next_value * (1 - dones[t]) - values[t]
            last_gae = delta + self.gamma * self.gae_lambda * (1 - dones[t]) * last_gae
            advantages[t] = last_gae
        returns = advantages + values
        return advantages, returns

    def ppo_loss(self, states, actions, old_logps, advantages, returns):
        """PPO 损失 (含 KL 约束)"""
        new_logits_list, new_values = self.model(states)
        # 每层动作的 log prob
        new_logps = torch.stack([
            new_logits_list[l].gather(1, actions[:, l:l+1]).squeeze(-1)
            for l in range(len(new_logits_list))
        ], dim=-1).sum(-1)
        # 重要性比率
        ratio = (new_logps - old_logps).exp()
        # 裁剪目标
        surr1 = ratio * advantages
        surr2 = ratio.clamp(1 - self.clip, 1 + self.clip) * advantages
        policy_loss = -torch.min(surr1, surr2).mean()
        # 价值损失
        value_loss = F.mse_loss(new_values, returns)
        # 熵正则
        entropy = sum(
            -(logits.exp() * logits).sum(-1).mean()
            for logits in new_logits_list
        ) / len(new_logits_list)
        return policy_loss + self.vf_coef * value_loss - self.ent_coef * entropy

    def step(self, trajectories):
        """单步 PPO 更新"""
        # trajectories: dict with states, actions, rewards, old_logps, dones
        states = trajectories["states"]
        actions = trajectories["actions"]
        rewards = trajectories["rewards"]
        old_logps = trajectories["old_logps"]
        dones = trajectories["dones"]
        # 计算 GAE
        with torch.no_grad():
            _, values = self.model(states)
            advantages, returns = self.compute_gae(rewards, values, dones)
            # 优势归一化
            advantages = (advantages - advantages.mean()) / (advantages.std() + 1e-8)

        # 多 epoch 更新
        total_loss = 0
        for _ in range(self.epochs):
            loss = self.ppo_loss(states, actions, old_logps, advantages, returns)
            self.opt.zero_grad()
            loss.backward()
            torch.nn.utils.clip_grad_norm_(self.model.parameters(), self.clip_grad)
            self.opt.step()
            total_loss += loss.item()
        return total_loss / self.epochs
```

## 4.2 GRPO 完整实现 (推荐场景特别适合)

```python
class GRPOTrainer:
    """GRPO: 去 critic, 组内归一化 (DeepSeek 2024)"""

    def __init__(self, model, ref_model, lr=1e-5, clip=0.2, kl_coef=0.04,
                 group_size=8, clip_grad=0.5):
        self.model = model
        self.ref_model = ref_model
        self.opt = torch.optim.Adam(model.parameters(), lr=lr)
        self.clip = clip
        self.kl_coef = kl_coef
        self.group_size = group_size
        self.clip_grad = clip_grad

    def grpo_loss(self, prompts, sampled_sids, sampled_logps, rewards):
        """GRPO 损失"""
        # 1. 组内归一化
        advantages = (rewards - rewards.mean()) / (rewards.std() + 1e-8)
        # 2. 计算新 log prob
        new_logps = self.model.compute_log_prob(prompts, sampled_sids)
        with torch.no_grad():
            ref_logps = self.ref_model.compute_log_prob(prompts, sampled_sids)
        # 3. 重要性比率
        ratio = (new_logps - sampled_logps).exp()
        # 4. PPO 裁剪目标
        surr1 = ratio * advantages
        surr2 = ratio.clamp(1 - self.clip, 1 + self.clip) * advantages
        policy_loss = -torch.min(surr1, surr2).mean()
        # 5. KL 散度 (防止偏离 SFT)
        kl = (new_logps - ref_logps).mean()
        return policy_loss + self.kl_coef * kl

    def step(self, prompts, sampled_sids, sampled_logps, rewards):
        loss = self.grpo_loss(prompts, sampled_sids, sampled_logps, rewards)
        self.opt.zero_grad()
        loss.backward()
        torch.nn.utils.clip_grad_norm_(self.model.parameters(), self.clip_grad)
        self.opt.step()
        return {"policy_loss": loss.item(), "kl": kl.item()}
```

## 4.3 Reward 设计 (多目标 + 多样性正则)

```python
class MultiObjectiveReward:
    """多目标 reward + 多样性正则"""

    def __init__(self, weights, diversity_bonus=0.05):
        self.weights = weights  # {"ctr": 0.5, "cvr": 0.3, "dwell": 0.2}
        self.diversity_bonus = diversity_bonus

    def compute(self, batch_feedback, candidate_sids, historical_sids):
        """
        batch_feedback: dict with click, convert, dwell_time
        candidate_sids: [B, L] 生成的 SID
        historical_sids: [B, T, L] 用户历史
        """
        # 1. 多目标加权
        r = 0
        for k, w in self.weights.items():
            r = r + w * self._normalize(batch_feedback[k])
        # 2. 多样性: 候选与历史的 SID 距离
        diversity = self._compute_diversity(candidate_sids, historical_sids)
        r = r + self.diversity_bonus * diversity
        # 3. 探索奖励 (避免 reward hacking)
        novelty = self._compute_novelty(candidate_sids)
        r = r + 0.02 * novelty
        return r

    def _normalize(self, x):
        """归一化到 [0, 1]"""
        if x.max() > 0:
            return (x - x.min()) / (x.max() - x.min() + 1e-8)
        return torch.zeros_like(x)

    def _compute_diversity(self, cands, history):
        """计算候选与历史的 SID 距离"""
        B, L = cands.shape
        total_dist = 0
        for l in range(L):
            cand_codes = cands[:, l:l+1]  # [B, 1]
            hist_codes = history[..., l]  # [B, T]
            # 每个候选与历史的最小距离
            match = (cand_codes == hist_codes).any(dim=1, keepdim=True)  # [B, 1]
            total_dist = total_dist + (~match).float()
        return (total_dist / L).squeeze(-1)

    def _compute_novelty(self, cands):
        """新颖性: 候选码的稀有度"""
        # 简化: 用 embedding 距离代替 (实际查码本频率)
        return torch.rand(cands.size(0))  # 占位


# 用法
reward_fn = MultiObjectiveReward(
    weights={"ctr": 0.5, "cvr": 0.3, "dwell": 0.2},
    diversity_bonus=0.05
)
rewards = reward_fn.compute(
    batch_feedback={"ctr": click, "cvr": convert, "dwell": dwell_time},
    candidate_sids=sampled_sids,
    historical_sids=user_hist
)
```

```python
class CodebookLabeler:
    """码本自动标签生成器"""
    def __init__(self, item_metadata):
        """
        item_metadata: DataFrame with item_id, title, description, category, ...
        """
        self.metadata = item_metadata

    def label_codebook(self, item2sid, level=0, top_k=10):
        """
        给第 level 层的码字打标签
        item2sid: dict {item_id: sid_tuple}
        返回: {code: 'label'}
        """
        from collections import defaultdict
        code2items = defaultdict(list)
        for item_id, sid in item2sid.items():
            code2items[sid[level]].append(item_id)
        labels = {}
        for code, items in code2items.items():
            # 取 top_k 物品的元数据生成标签
            top_items = self.metadata[self.metadata["item_id"].isin(items[:top_k])]
            label = self._generate_label(top_items)
            labels[code] = label
        return labels

    def _generate_label(self, items_df):
        """从物品生成人读标签 (用 LLM 或 TF-IDF)"""
        # 简化: 用类目众数
        if "category" in items_df.columns:
            return items_df["category"].mode().iloc[0]
        # 用标题关键词
        from collections import Counter
        words = " ".join(items_df["title"].tolist()).split()
        common = Counter(words).most_common(2)
        return " ".join([w for w, _ in common])
```

## 5.3 完整解释 pipeline

```python
class ExplanationPipeline:
    """端到端解释 pipeline"""

    def __init__(self, label_maps, label_descriptions=None):
        """
        label_maps: list of dict, 每层一个
          [0]: {0: '动作片', 1: '爱情片', ...}
        label_descriptions: 可选, 每层更详细的描述
        """
        self.maps = label_maps
        self.descriptions = label_descriptions or label_maps

    def explain_item(self, sid):
        """返回层次化语义路径"""
        parts = []
        for l, code in enumerate(sid):
            label = self.maps[l].get(code, f"#{code}")
            parts.append(label)
        return " > ".join(parts)

    def explain_reco_with_score(self, user_hist_sids, cand_sid, top_k=3):
        """返回 top_k 解释 (按得分排序)"""
        explanations = []
        for l in range(len(cand_sid)):
            # 该层是否有历史命中
            matched = [h for h in user_hist_sids if h[l] == cand_sid[l]]
            if matched:
                label = self.maps[l].get(cand_sid[l], f"#{cand_sid[l]}")
                # 命中次数作为得分
                score = len(matched)
                explanations.append((score, l, label))
        # 按得分排序
        explanations.sort(key=lambda x: -x[0])
        # 构造自然语言
        if not explanations:
            return [f"探索性推荐: {self.explain_item(cand_sid)}"]
        top = explanations[:top_k]
        primary = top[0][2]
        result = f"你常看「{primary}」类, 为你推荐: {self.explain_item(cand_sid)}"
        return [result]

    def explain_batch(self, user_hist_batch, cand_batch, top_k=3):
        """批量解释"""
        return [
            self.explain_reco_with_score(hist, cand, top_k)
            for hist, cand in zip(user_hist_batch, cand_batch)
        ]
```

```python
class OneRec(nn.Module):
    """阿里 OneRec: 端到端生成式推荐"""
    def __init__(self, content_dim=1024, sid_L=3, sid_K=8192, dim=512, n_layers=12):
        super().__init__()
        # 内容编码器
        self.content_encoder = ContentEncoder(content_dim)
        # RQ-VAE
        self.rqvae = RQVAE(input_dim=content_dim, hidden=256, L=sid_L, K=sid_K)
        # Transformer (端到端)
        self.encoder = nn.TransformerEncoder(
            nn.TransformerEncoderLayer(dim, 8, dim * 4, batch_first=True),
            num_layers=n_layers
        )
        # 输出头
        self.heads = nn.ModuleList([nn.Linear(dim, sid_K) for _ in range(sid_L)])

    def forward(self, user_hist_content, target_content):
        """端到端: 历史 → 下一个 item"""
        # 1. 内容编码
        hist_emb = self.content_encoder(user_hist_content)  # [B, T, D]
        # 2. RQ 量化到 SID
        hist_sids, _ = self.rqvae.encode(hist_emb)
        # 3. 序列建模
        sid_emb = self.sid_to_emb(hist_sids)
        out = self.encoder(sid_emb)
        # 4. 预测下一 item SID
        return torch.stack([h(out[:, -1]) for h in self.heads], 1)
```

## 第 9 部分 - 进阶: 跨域 SID

## 9.1 跨域 SID 概述

**问题**: 不同业务域 (淘宝 + 闲鱼 + 飞猪) 各自训 SID, 用户跨域行为难打通。

**解法**: 用**统一码本** + 域特异投影:

```python
class CrossDomainSID(nn.Module):
    """跨域 SID: 统一码本 + 域投影"""
    def __init__(self, L=3, K=256, content_dim=128, n_domains=3):
        super().__init__()
        # 统一码本 (跨域共享)
        self.shared_codebook = nn.ParameterList([
            nn.Parameter(torch.randn(K, content_dim)) for _ in range(L)
        ])
        # 域特异投影
        self.domain_projs = nn.ModuleList([
            nn.Linear(content_dim, content_dim) for _ in range(n_domains)
        ])
        # 域 embedding
        self.domain_emb = nn.Embedding(n_domains, content_dim)

    def encode(self, content_emb, domain_id):
        """跨域编码"""
        # 域投影
        x = self.domain_projs[domain_id](content_emb) + self.domain_emb(domain_id)
        # RQ 编码 (用统一码本)
        sids = []
        residual = x
        for cb in self.shared_codebook:
            dist = torch.cdist(residual.unsqueeze(1), cb.unsqueeze(0))
            k = torch.argmin(dist, dim=-1).squeeze(-1)
            sids.append(k)
            residual = residual - cb[k]
        return torch.stack(sids, -1)
```

## 9.2 联邦 SID (隐私合规)

**问题**: 不同公司想联合训 SID, 但不能共享原始数据。

**解法**: 联邦学习 + 安全聚合:

```python
class FederatedSIDTrainer:
    """联邦 SID 训练 (简化)"""
    def __init__(self, n_clients, codebook_size=256, L=3):
        self.n_clients = n_clients
        self.global_codebooks = [torch.randn(codebook_size, 128) for _ in range(L)]

    def client_train(self, client_data, epochs=5):
        """客户端本地训练"""
        codebooks = [cb.clone() for cb in self.global_codebooks]
        for epoch in range(epochs):
            residual = client_data["embeddings"]
            for l in range(len(codebooks)):
                # 本地 K-means
                km = KMeans(n_clusters=len(codebooks[l]))
                km.fit(residual)
                codebooks[l] = torch.tensor(km.cluster_centers_)
                residual = residual - codebooks[l][km.labels_]
        return codebooks

    def aggregate(self, client_codebooks):
        """服务端安全聚合 (FedAvg)"""
        aggregated = []
        for l in range(len(self.global_codebooks)):
            stacked = torch.stack([cc[l] for cc in client_codebooks], 0)
            aggregated.append(stacked.mean(0))
        self.global_codebooks = aggregated
```

## 第 11 部分 - 在线学习与增量更新

## 11.1 在线学习的必要性

工业推荐系统的物品分布**漂移严重**:
- 新物品每天新增 1-10%
- 用户兴趣每月漂移 5-15%
- 季节性事件 (双十一、春节) 短期变化 50%+

**离线周级重训不够**, 必须支持:
- 增量更新 (新物品立即生成 SID)
- 在线学习 (用户反馈快速回灌)
- 概念漂移检测 (自动触发重训)

## 11.2 在线 SID 更新 Pipeline

```python
class OnlineSIDUpdater:
    """在线 SID 增量更新"""

    def __init__(self, codebooks, sid_K=256, drift_threshold=0.1):
        self.codebooks = codebooks  # 当前码本
        self.sid_K = sid_K
        self.drift_threshold = drift_threshold
        self.update_buffer = []  # 待更新样本
        self.drift_score = 0.0

    def add_item(self, content_emb, sid=None):
        """新增物品"""
        if sid is None:
            sid = self.encode_sid(content_emb)
        # 记录到 buffer
        self.update_buffer.append((content_emb, sid))
        # 触发条件: buffer 满 / 时间到 / 检测到漂移
        if len(self.update_buffer) >= 1000:
            self.incremental_update()

    def detect_drift(self, new_data):
        """检测概念漂移"""
        from scipy.stats import ks_2samp
        # 用新数据分布 vs 当前数据分布
        stat, p_value = ks_2samp(new_data, self.historical_data)
        self.drift_score = 1 - p_value
        return self.drift_score > self.drift_threshold

    def incremental_update(self):
        """增量更新码本 (只更新部分码字)"""
        if not self.update_buffer:
            return
        new_embs = np.stack([e for e, _ in self.update_buffer])
        # 1. 找到被新物品命中的码字 (高频码)
        new_sids = [s for _, s in self.update_buffer]
        code_freq = Counter(c for sid in new_sids for c in sid)
        hot_codes = [c for c, cnt in code_freq.most_common(50)]
        # 2. 只更新 hot_codes 对应的码字
        residual = new_embs.copy()
        for l in range(len(self.codebooks)):
            codes = self.encode_layer(residual, self.codebooks[l])
            residual = residual - self.codebooks[l][codes]
            # 更新 hot codes 的中心
            for c in hot_codes:
                mask = (codes == c)
                if mask.sum() > 0:
                    self.codebooks[l][c] = new_embs[mask].mean(0)
        self.update_buffer = []
```

## 11.3 在线学习与 SID 的协同

```python
class SIDWithOnlineLearning(nn.Module):
    """SID + 在线学习"""
    def __init__(self, L=3, K=256, dim=128):
        super().__init__()
        self.codebooks = nn.ParameterList([
            nn.Parameter(torch.randn(K, dim) * 0.1) for _ in range(L)
        ])
        # 在线学习率
        self.online_lr = 0.001
        # 用户反馈 buffer
        self.feedback_buffer = []

    def online_update(self, item_embs, sids, rewards):
        """根据用户反馈在线更新"""
        # 1. 收集反馈
        self.feedback_buffer.append((item_embs, sids, rewards))
        if len(self.feedback_buffer) < 100:
            return
        # 2. 批量更新码字 (强化被点击的码字)
        all_embs = torch.cat([b[0] for b in self.feedback_buffer], 0)
        all_sids = torch.cat([b[1] for b in self.feedback_buffer], 0)
        all_rewards = torch.cat([b[2] for b in self.feedback_buffer], 0)
        # 3. 加权更新码本
        with torch.no_grad():
            for l in range(len(self.codebooks)):
                codes = all_sids[:, l]
                for c in range(self.codebooks[l].size(0)):
                    mask = (codes == c)
                    if mask.sum() == 0:
                        continue
                    # 加权平均
                    weights = all_rewards[mask].softmax(0)
                    target = (weights.unsqueeze(-1) * all_embs[mask]).sum(0)
                    # 平滑更新
                    self.codebooks[l].data[c] = (
                        1 - self.online_lr
                    ) * self.codebooks[l].data[c] + self.online_lr * target
        self.feedback_buffer = []
```

## 12.1 LLM-as-Tokenizer

```python
class LLMTokenizer:
    """LLM 作为 Tokenizer"""
    def __init__(self, llm_client):
        self.llm = llm_client

    def tokenize(self, item_info):
        """用 LLM 生成语义层次标签"""
        prompt = f"""为以下商品生成 3 层语义标签:
        物品: {item_info}

        输出格式 (每行一个标签):
        第 1 层 (大类): ...
        第 2 层 (子类): ...
        第 3 层 (细分): ...
        """
        return self.llm.generate(prompt)
```

## 7. 场景 6: 多模态融合召回

### 7.1 概述

把文本/图像/类目/品牌等异构特征融合后做 SID,提升召回质量。

```python
class MultiModalSIDRetriever(nn.Module):
    """多模态 SID 召回: 文本 + 图像 + 类目融合后, 生成式召回。"""
    def __init__(self, text_enc, image_enc, cat_emb, brand_emb,
                 L=4, K=256, dim=128):
        super().__init__()
        # 各模态编码器
        self.text_enc = text_enc        # 文本 (BGE / Sentence-BERT)
        self.image_enc = image_enc      # 图像 (CLIP / ViT)
        self.cat_emb = cat_emb          # 类目 (Embedding)
        self.brand_emb = brand_emb      # 品牌 (Embedding)
        # 融合
        self.fusion = nn.Sequential(
            nn.Linear(dim * 4, dim * 2),
            nn.ReLU(),
            nn.Linear(dim * 2, dim),
            nn.LayerNorm(dim)
        )
        # SID embedding
        self.L, self.K = L, K
        self.code_embs = nn.ModuleList([nn.Embedding(K, dim) for _ in range(L)])

    def forward(self, item_feat):
        """item_feat: dict with text/image/cat/brand."""
        t = self.text_enc(item_feat['text'])         # [B, D]
        i = self.image_enc(item_feat['image'])       # [B, D]
        c = self.cat_emb(item_feat['cat_id'])        # [B, D]
        b = self.brand_emb(item_feat['brand_id'])    # [B, D]
        x = self.fusion(torch.cat([t, i, c, b], -1)) # [B, D]
        # 多层码
        sids = []
        residual = x
        for l, cb in enumerate(self.code_embs):
            code = residual @ cb.weight.T
            code = code.argmax(-1)
            sids.append(code)
            residual = residual - cb(code)
        return torch.stack(sids, -1)  # [B, L]
```

### 7.2 多模态融合权重

不同模态的权重需要学习:

```python
class WeightedFusion(nn.Module):
    """学习融合权重 + 残差连接。"""
    def __init__(self, modalities, dim):
        super().__init__()
        self.modalities = modalities  # ['text', 'image', 'cat', 'brand']
        self.weights = nn.Parameter(torch.ones(len(modalities)))
        self.proj = nn.ModuleList([nn.Linear(dim, dim) for _ in modalities])

    def forward(self, feats):
        """feats: list of [B, D]"""
        w = F.softmax(self.weights, 0)
        out = sum(wi * proj(f) for wi, proj, f in zip(w, self.proj, feats))
        return out
```

## 8. 场景 7: 长短期双塔召回(LBS / LBS 推荐)

### 8.1 概念

- **长期塔**:用户历史累计兴趣(SID embedding 平均)。
- **短期塔**:用户最近 N 次行为(Transformer 编码)。

```python
class DualTowerRetriever(nn.Module):
    """长短期双塔召回。"""
    def __init__(self, L=4, K=256, dim=128, max_seq=128):
        super().__init__()
        # 共享 SID embedding
        self.sid_embs = nn.ModuleList([nn.Embedding(K, dim) for _ in range(L)])
        # 长期塔: 用户历史平均
        self.long_tower = nn.Sequential(
            nn.Linear(dim, dim), nn.ReLU(),
            nn.Linear(dim, dim), nn.LayerNorm(dim)
        )
        # 短期塔: Transformer
        enc_layer = nn.TransformerEncoderLayer(dim, nhead=4, dim_feedforward=dim*4, batch_first=True)
        self.short_tower = nn.TransformerEncoder(enc_layer, num_layers=2)

    def encode_user_long(self, hist_sids):
        """长期兴趣: 历史 SID embedding 平均。"""
        x = sum(emb(hist_sids[:, :, l]).mean(1) for l, emb in enumerate(self.sid_embs))
        return self.long_tower(x)        # [B, D]

    def encode_user_short(self, hist_sids):
        """短期兴趣: Transformer 编码。"""
        x = torch.stack([emb(hist_sids[:, :, l]) for l, emb in enumerate(self.sid_embs)], 2)
        x = x.flatten(1, 2)                # [B, T*L, D]
        return self.short_tower(x).mean(1)  # [B, D]

    def encode_item(self, sid):
        """物品塔。"""
        return sum(emb(sid[:, l]) for l, emb in enumerate(self.sid_embs))

    def score(self, user_hist, cand_sid, mode='long'):
        u = self.encode_user_long(user_hist) if mode == 'long' else self.encode_user_short(user_hist)
        i = self.encode_item(cand_sid)
        return (u * i).sum(-1)
```

### 8.2 长短期融合

```python
def long_short_fusion(long_score, short_score, alpha=0.7):
    """长期主导,短期辅助。"""
    return alpha * long_score + (1 - alpha) * short_score
```

### 9.2 联邦 RQ-VAE

```python
class FederatedRQVAE:
    """联邦 RQ-VAE: 各方本地训码本, 中心聚合。"""
    def __init__(self, local_codebooks):
        # local_codebooks: 每个客户端的码本
        self.codebooks = local_codebooks

    def federated_quantize(self, embeddings_list, all_sids_list):
        """中心聚合: 各方传 (embedding, sid) 对, 中心训统一码本。"""
        # 1. 收集各方的 (embedding, sid)
        all_pairs = []
        for embs, sids in zip(embeddings_list, all_sids_list):
            for emb, sid in zip(embs, sids):
                all_pairs.append((emb, sid))
        # 2. 用聚合数据训中心码本 (R-Kmeans)
        embeddings = torch.stack([p[0] for p in all_pairs])
        sids = torch.stack([p[1] for p in all_pairs])
        # 3. RQ-Kmeans 在中心码本上跑
        global_codebook = RQKmeans(embeddings, K=256, L=4)
        return global_codebook

    def local_inference(self, local_emb, global_codebook):
        """本地: 用全局码本对本地 embedding 做量化。"""
        return global_codebook.quantize(local_emb)
```

### 9.3 隐私保护

```python
class DPSIDGeneration:
    """差分隐私 SID 生成。"""
    def __init__(self, epsilon=1.0, sensitivity=1.0):
        self.epsilon = epsilon
        self.sensitivity = sensitivity

    def add_noise(self, embedding):
        """给 embedding 加 Laplace 噪声。"""
        scale = self.sensitivity / self.epsilon
        noise = torch.distributions.Laplace(0, scale).sample(embedding.shape)
        return embedding + noise

    def generate_sid(self, embedding, codebook):
        noised_emb = self.add_noise(embedding)
        return codebook.quantize(noised_emb)
```

### 10.1 完整部署流程

```python
class SIDDeploymentPipeline:
    """SID 完整部署 pipeline: 训练 → 蒸馏 → 量化 → 服务。"""
    def __init__(self):
        self.sid_quantizer = RQVAE()        # §03
        self.big_teacher = TIGER()           # §10-01
        self.student_kd = MiniTIGER()        # §10-03
        self.rl_policy = PPOWithSID()        # §10-04
        self.trie = SIDTrie()

    def phase1_train_teacher(self, data):
        """Phase 1: 训大模型。"""
        for _ in range(10):  # epochs
            for batch in data:
                loss = F.cross_entropy(self.big_teacher(batch['x']), batch['target'])
                loss.backward(); opt.step()

    def phase2_distill(self, data):
        """Phase 2: 蒸馏到小模型。"""
        for _ in range(5):
            for batch in data:
                with torch.no_grad():
                    t_logits = self.big_teacher(batch['x'])
                s_logits = self.student_kd(batch['x'])
                loss = kd_loss(s_logits, t_logits, T=2.0, alpha=0.7)
                loss.backward(); opt.step()

    def phase3_rl_finetune(self, env):
        """Phase 3: RL 微调。"""
        for _ in range(3):
            traj = env.rollout(self.student_kd, self.trie)
            self.rl_policy.update(traj)

    def phase4_quantize(self):
        """Phase 4: INT8 量化。"""
        self.student_kd = torch.quantization.quantize_dynamic(
            self.student_kd, {nn.Linear}, dtype=torch.qint8
        )

    def phase5_export_onnx(self):
        """Phase 5: ONNX 导出。"""
        torch.onnx.export(self.student_kd, dummy_input, "sid_model.onnx")

    def deploy(self):
        """部署到生产。"""
        return self.student_kd
```

## 12. A/B 测试框架

### 12.1 流量分桶

```python
class ABSplitter:
    """A/B 流量分桶。"""
    def __init__(self, buckets=100):
        self.buckets = buckets

    def get_bucket(self, user_id):
        """用 user_id 哈希分桶。"""
        return hash(user_id) % self.buckets

    def assign(self, user_id, treatment_ratio):
        """按比例分配到 treatment/control。"""
        b = self.get_bucket(user_id)
        return 'treatment' if b < self.buckets * treatment_ratio else 'control'
```

### 12.2 样本量计算

```python
def required_sample_size(baseline_ctr, mde=0.01, alpha=0.05, power=0.8):
    """计算 A/B 所需每组样本量。

    baseline_ctr: 当前 CTR (e.g., 0.05)
    mde: 最小可检测相对效应 (e.g., 0.01 = 1% 提升)
    alpha: 显著性水平
    power: 统计功效
    """
    from scipy.stats import norm
    z_alpha = norm.ppf(1 - alpha / 2)
    z_beta = norm.ppf(power)
    p1 = baseline_ctr
    p2 = baseline_ctr * (1 + mde)
    sigma = np.sqrt(p1 * (1 - p1) + p2 * (1 - p2))
    n = ((z_alpha + z_beta) * sigma / (p2 - p1)) ** 2
    return int(n)
```

### 12.3 A/B 结果分析

```python
def ab_analysis(control, treatment, alpha=0.05):
    """A/B 结果分析: t-test + 置信区间。"""
    from scipy.stats import ttest_ind
    t, p = ttest_ind(control, treatment)
    lift = np.mean(treatment) / np.mean(control) - 1
    # 置信区间
    se = np.sqrt(np.var(control)/len(control) + np.var(treatment)/len(treatment))
    ci_low = lift - 1.96 * se / np.mean(control)
    ci_high = lift + 1.96 * se / np.mean(control)
    return {
        'p_value': p,
        'significant': p < alpha,
        'lift': lift,
        'ci': (ci_low, ci_high)
    }
```

## 17. 工业 case: Meta HSTU

Meta HSTU (Hierarchical Sequential Transduction Unit) 把推荐视为序列转换:

```python
class HSTU(nn.Module):
    """HSTU: 层次化序列转换单元。"""
    def __init__(self, L=4, K=256, dim=128, n_layers=4):
        super().__init__()
        self.code_embs = nn.ModuleList([nn.Embedding(K, dim) for _ in range(L)])
        # HSTU 层 (类似 Transformer 但有稀疏注意力)
        self.hstu_layers = nn.ModuleList([
            HSTULayer(dim, n_heads=4, dropout=0.1) for _ in range(n_layers)
        ])
        self.head = nn.Linear(dim, K)

    def forward(self, user_hist_sids):
        """user_hist_sids: [B, T, L]"""
        x = sum(emb(user_hist_sids[:, :, l]) for l, emb in enumerate(self.code_embs))
        for layer in self.hstu_layers:
            x = layer(x)
        return self.head(x)  # [B, T, K]
```

HSTU 关键创新:
- **稀疏注意力**:长序列友好。
- **多任务头**:支持召回/排序同时训。
