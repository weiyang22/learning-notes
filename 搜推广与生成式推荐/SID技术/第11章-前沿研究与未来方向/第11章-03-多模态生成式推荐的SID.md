## 3.5 多模态 SID 的核心难点

### 难点一:模态对齐
视频(4096维)、音频(1024)、图像(768)的 embedding 尺度、分布、语义粒度都不同。直接拼接量化 → 高维模态主导。解法:
- **对比学习对齐**(CLIP 式):让配对的跨模态 embedding 靠近,再统一量化。
- **各模态独立量化 + 拼接**:每模态一套码本,SID = (视频SID, 音频SID, ...)。

### 难点二:高维量化
视频 embedding 维度高,RQ-VAE 训练慢、码本易坍缩。解法:先降维(PCA/投影)再量化,或用 FSQ 等免码本量化(见 [11-01 高效编码](第11章-01-2026年最新SID研究.md))。

### 难点三:模态缺失
不是所有物品都有全部模态(有的没音频)。SID 设计要支持**缺模态降级**:缺失模态用默认码字或从其他模态推断。

---

## 3.6 多模态如何增强生成式推荐

多模态 SID 让生成式推荐(见 第12章)能:
- **跨模态检索**:用文本 query 生成视频 item 的 SID(文搜视频)。
- **冷启动更强**:新视频哪怕零播放,凭视觉/音频内容也能落到正确语义簇。
- **统一建模**:图文音视频物料在一个 SID 空间,一个生成模型通吃。

这是短视频/直播等富媒体场景 SID 的主战场,也是 2026 的研究前沿。

## 3.1 视频 SID 完整工程方案

### 3.1.1 视频特征提取

视频推荐 (抖音/TikTok/Shorts) 的物品是短视频, 特征来源:

| 模态 | 编码器 | 输出维度 | 推理速度 |
| :--- | :--- | :--- | :--- |
| 视频帧 | VideoMAE-base | 768 | 30 ms/clip |
| 视频帧 | VideoMAE-large | 1024 | 80 ms/clip |
| 视频帧 | VideoLLaMA-7B | 4096 | 250 ms/clip |
| 音频 | BEATs-base | 512 | 10 ms/clip |
| 文本标题 | BGE-large-zh | 1024 | 5 ms/text |
| 文本标题 | m3e-large | 768 | 5 ms/text |
| 封面图 | CLIP-ViT-L/14 | 768 | 20 ms/image |

**典型 pipeline**:

```python
class VideoFeatureExtractor:
    def __init__(self, device='cuda'):
        self.video_model = VideoMAE.from_pretrained('videomae-base').to(device).eval()
        self.audio_model = BEATs.from_pretrained('beats-base').to(device).eval()
        self.text_model = SentenceTransformer('BAAI/bge-large-zh-v1.5').to(device)

    def extract(self, video_path):
        # 1. 抽帧 (16 帧)
        frames = extract_frames(video_path, n_frames=16)  # [16, 3, 224, 224]
        # 2. 抽音频
        audio = extract_audio(video_path)  # [T]
        # 3. 抽标题 (从 metadata)
        title = get_video_title(video_path)

        with torch.no_grad():
            # 视频特征
            video_feat = self.video_model(frames.unsqueeze(0).cuda()).last_hidden_state.mean(dim=1)  # [1, 768]
            # 音频特征
            audio_feat = self.audio_model(audio.unsqueeze(0).cuda())  # [1, 512]
            # 文本特征
            text_feat = self.text_model.encode([title])  # [1, 1024]

        return {
            'video': video_feat.cpu().numpy(),
            'audio': audio_feat.cpu().numpy(),
            'text': text_feat,
        }
```

### 3.1.2 多模态融合

**方案 1: 简单求和 + 投影**

```python
class SimpleFusion(nn.Module):
    def __init__(self, video_dim=768, audio_dim=512, text_dim=1024, fused_dim=128):
        super().__init__()
        self.proj_v = nn.Linear(video_dim, fused_dim)
        self.proj_a = nn.Linear(audio_dim, fused_dim)
        self.proj_t = nn.Linear(text_dim, fused_dim)

    def forward(self, video, audio, text):
        v = self.proj_v(video)  # [B, 128]
        a = self.proj_a(audio)
        t = self.proj_t(text)
        return v + a + t  # 求和
```

**方案 2: Cross-Attention 融合**

```python
class CrossAttentionFusion(nn.Module):
    def __init__(self, video_dim=768, audio_dim=512, text_dim=1024, fused_dim=128, n_heads=4):
        super().__init__()
        self.proj_v = nn.Linear(video_dim, fused_dim)
        self.proj_a = nn.Linear(audio_dim, fused_dim)
        self.proj_t = nn.Linear(text_dim, fused_dim)
        self.attn = nn.MultiheadAttention(fused_dim, n_heads, batch_first=True)

    def forward(self, video, audio, text):
        v = self.proj_v(video).unsqueeze(1)  # [B, 1, 128]
        a = self.proj_a(audio).unsqueeze(1)
        t = self.proj_t(text).unsqueeze(1)
        # 拼接 + 自注意力
        modalities = torch.cat([v, a, t], dim=1)  # [B, 3, 128]
        fused, _ = self.attn(modalities, modalities, modalities)
        return fused.mean(dim=1)  # [B, 128]
```

**方案 3: Token-level 融合 (细粒度)**

```python
class TokenLevelFusion(nn.Module):
    def __init__(self, video_dim=768, audio_dim=512, text_dim=1024, fused_dim=128):
        super().__init__()
        self.proj_v = nn.Linear(video_dim, fused_dim)
        self.proj_a = nn.Linear(audio_dim, fused_dim)
        self.proj_t = nn.Linear(text_dim, fused_dim)

    def forward(self, video_tokens, audio_tokens, text_tokens):
        # video_tokens: [B, T_v, D_v]
        v = self.proj_v(video_tokens)  # [B, T_v, 128]
        a = self.proj_a(audio_tokens)  # [B, T_a, 128]
        t = self.proj_t(text_tokens)   # [B, T_t, 128]
        # 拼接
        return torch.cat([v, a, t], dim=1)  # [B, T_v+T_a+T_t, 128]
```

### 3.1.3 高维量化的优化

视频 embedding 通常是 768-4096 维, 直接 RQ-VAE 训练慢且码本易坍缩。优化方法:

1. **PCA 降维**:
```python
from sklearn.decomposition import PCA

pca = PCA(n_components=128)
video_embs_128 = pca.fit_transform(video_embs_768)
# 然后 RQ-VAE 在 128 维上训练
```

2. **分块量化**:
```python
class ChunkedQuantizer(nn.Module):
    def __init__(self, input_dim=4096, chunk_size=128, num_codes=256, num_layers=4):
        super().__init__()
        self.chunk_size = chunk_size
        self.num_chunks = input_dim // chunk_size
        self.quantizers = nn.ModuleList([
            RQVAE(chunk_size, num_codes, num_layers)
            for _ in range(self.num_chunks)
        ])

    def forward(self, x):
        # x: [B, 4096]
        chunks = x.reshape(-1, self.num_chunks, self.chunk_size)  # [B, 32, 128]
        sids_list = []
        for i, q in enumerate(self.quantizers):
            sids = q.encode(chunks[:, i])  # [B, K]
            sids_list.append(sids)
        return torch.cat(sids_list, dim=-1)  # [B, 32*K]
```

3. **FSQ 替代 VQ-VAE**:
```python
# FSQ 不需要码本, 高维也不坍缩
class FSQ(nn.Module):
    def __init__(self, levels=[8, 5, 5, 5]):  # 8*5*5*5 = 1000 code
        super().__init__()
        self.levels = levels

    def forward(self, z):
        # z: [B, D=4]
        quantized = torch.round(z * (torch.tensor(self.levels).float().to(z.device) - 1) / 2)
        return quantized
```

### 3.2.2 Spotify 案例的 RQ-Kmeans

```python
import faiss
import numpy as np


def spotify_audio_sid(audio_embeddings, num_codes=256, num_layers=3):
    """Spotify 风格的 RQ-Kmeans for 音频"""
    residual = audio_embeddings.copy()
    sids = np.zeros((audio_embeddings.shape[0], num_layers), dtype=np.int32)
    codebooks = []

    for layer in range(num_layers):
        km = faiss.Kmeans(
            d=audio_embeddings.shape[1],
            k=num_codes,
            gpu=True,
            niter=20,
            spherical=True,  # 余弦相似度
        )
        km.train(residual)
        codebook = km.centroids
        codebooks.append(codebook)
        _, codes = km.index.search(residual, 1)
        sids[:, layer] = codes.flatten()
        residual = residual - codebook[codes.flatten()]

    return sids, codebooks
```

### 3.2.3 音频多版本 SID

同一首歌的多个版本 (studio / live / remix) 共享流派码, 但版本码独立:

```python
def multi_version_sid(audio_emb_live, audio_emb_studio, audio_emb_remix):
    """为同一首歌的多个版本生成 SID"""
    sid_live = rq_vae.encode(audio_emb_live)
    sid_studio = rq_vae.encode(audio_emb_studio)
    sid_remix = rq_vae.encode(audio_emb_remix)

    # 前 K-1 层共享 (流派/年代), 最后一层独立 (版本)
    shared_layers = 2
    sid_live[-1] = 0
    sid_studio[-1] = 1
    sid_remix[-1] = 2

    return sid_live, sid_studio, sid_remix
```

```python
class EcommerceImageSID(nn.Module):
    """电商图像 SID (Pinterest/Shopify 风格)"""
    def __init__(self):
        super().__init__()
        # 冻结的 CLIP
        self.clip = CLIPModel.from_pretrained('openai/clip-vit-large-patch14')
        for p in self.clip.parameters():
            p.requires_grad = False
        # 投影
        self.proj = nn.Linear(768, 128)
        # RQ-VAE
        self.rq_vae = RQVAE(input_dim=128, num_codes=256, num_layers=4)

    def forward(self, images):
        # images: [B, 3, 224, 224]
        with torch.no_grad():
            img_emb = self.clip.get_image_features(pixel_values=images)  # [B, 768]
        z_e = self.proj(img_emb)  # [B, 128]
        return self.rq_vae.encode(z_e)  # [B, 4]
```

```python
# Pinterest 离线 pipeline
def pinterest_sid_pipeline(pin_images, pin_titles):
```

## 3.4 多模态融合的深度方案

### 3.4.1 对比学习对齐 (CLIP-style)

```python
class MultimodalContrastive(nn.Module):
    """对比学习对齐多模态"""
    def __init__(self, video_dim=768, audio_dim=512, text_dim=1024, dim=512):
        super().__init__()
        self.proj_v = nn.Linear(video_dim, dim)
        self.proj_a = nn.Linear(audio_dim, dim)
        self.proj_t = nn.Linear(text_dim, dim)
        self.temperature = nn.Parameter(torch.tensor(0.07))

    def forward(self, video, audio, text):
        v = F.normalize(self.proj_v(video), dim=-1)  # [B, 512]
        a = F.normalize(self.proj_a(audio), dim=-1)
        t = F.normalize(self.proj_t(text), dim=-1)

        # 视频-文本对比
        logits_vt = v @ t.T / self.temperature  # [B, B]
        labels = torch.arange(v.shape[0], device=v.device)
        loss_vt = F.cross_entropy(logits_vt, labels)

        # 视频-音频对比
        logits_va = v @ a.T / self.temperature
        loss_va = F.cross_entropy(logits_va, labels)

        # 音频-文本对比
        logits_at = a @ t.T / self.temperature
        loss_at = F.cross_entropy(logits_at, labels)

        return (loss_vt + loss_va + loss_at) / 3
```

### 3.4.2 模态拼接 + RQ-VAE

```python
class ConcatThenRQ(nn.Module):
    """先对齐到同维度, 拼接, 再 RQ-VAE"""
    def __init__(self, dim=128, num_codes=256, num_layers=4):
        super().__init__()
        self.proj_v = nn.Linear(768, dim)
        self.proj_a = nn.Linear(512, dim)
        self.proj_t = nn.Linear(1024, dim)
        # 拼接 → 384 维
        self.rq_vae = RQVAE(input_dim=dim * 3, num_codes=num_codes, num_layers=num_layers)

    def forward(self, video, audio, text):
        v = self.proj_v(video)  # [B, 128]
        a = self.proj_a(audio)
        t = self.proj_t(text)
        # 拼接 (而不是求和, 保留模态信息)
        fused = torch.cat([v, a, t], dim=-1)  # [B, 384]
        return self.rq_vae.encode(fused)
```

### 3.4.3 各模态独立量化 + 拼接

```python
class IndependentQuantize(nn.Module):
    """每模态独立量化, SID 拼接"""
    def __init__(self, num_codes=256, num_layers=4):
        super().__init__()
        self.proj_v = nn.Linear(768, 128)
        self.proj_a = nn.Linear(512, 128)
        self.proj_t = nn.Linear(1024, 128)
        # 每模态独立 RQ-VAE
        self.rq_v = RQVAE(input_dim=128, num_codes=num_codes, num_layers=num_layers)
        self.rq_a = RQVAE(input_dim=128, num_codes=num_codes, num_layers=num_layers)
        self.rq_t = RQVAE(input_dim=128, num_codes=num_codes, num_layers=num_layers)

    def forward(self, video, audio, text):
        v = self.proj_v(video)
        a = self.proj_a(audio)
        t = self.proj_t(text)
        sid_v = self.rq_v.encode(v)  # [B, K]
        sid_a = self.rq_a.encode(a)
        sid_t = self.rq_t.encode(t)
        # 拼接 SID
        return torch.cat([sid_v, sid_a, sid_t], dim=-1)  # [B, 3K]
```

**优缺点**:

| 方案 | 优点 | 缺点 |
| :--- | :--- | :--- |
| 求和 + RQ | 简单, SID 短 (K) | 模态信息丢失 |
| Concat + RQ | 保留模态 | SID 长 (K 但输入 384 维) |
| 独立量化 + 拼接 | 完全独立 | SID 很长 (3K), Transformer 慢 |

## 3.5 模态缺失处理

### 3.5.1 真实场景的模态缺失

| 物品类型 | 视频 | 音频 | 文本 |
| :--- | :--- | :--- | :--- |
| 短视频 | ✅ | ✅ | ✅ |
| 图文笔记 | ❌ | ❌ | ✅ |
| 纯音乐 | ❌ | ✅ | ⚠️ |
| 商品 | ⚠️ | ❌ | ✅ |
| 新闻 | ❌ | ❌ | ✅ |

缺模态不能直接置零, 否则训练时编码器会学到"零向量 = 缺模态"的捷径。

### 3.5.2 缺模态降级策略

**策略 1: Learnable Null Token**

```python
class NullTokenFusion(nn.Module):
    def __init__(self, dim=128):
        super().__init__()
        self.null_v = nn.Parameter(torch.zeros(dim))
        self.null_a = nn.Parameter(torch.zeros(dim))
        self.null_t = nn.Parameter(torch.zeros(dim))
        self.proj_v = nn.Linear(768, dim)
        self.proj_a = nn.Linear(512, dim)
        self.proj_t = nn.Linear(1024, dim)

    def forward(self, video, audio, text, video_mask, audio_mask, text_mask):
        # video_mask: [B] 1 表示有效, 0 表示缺失
        v_emb = self.proj_v(video) if video is not None else self.null_v.unsqueeze(0)
        a_emb = self.proj_a(audio) if audio is not None else self.null_a.unsqueeze(0)
        t_emb = self.proj_t(text) if text is not None else self.null_t.unsqueeze(0)
        # 用 mask 加权
        v_emb = v_emb * video_mask.unsqueeze(-1)
        a_emb = a_emb * audio_mask.unsqueeze(-1)
        t_emb = t_emb * text_mask.unsqueeze(-1)
        # 求和 + 归一化
        return v_emb + a_emb + t_emb
```

**策略 2: Modality Dropout (训练时随机丢)**

```python
class ModalityDropout(nn.Module):
    def __init__(self, drop_prob=0.3):
        super().__init__()
        self.drop_prob = drop_prob

    def forward(self, v, a, t, training=True):
        if not training:
            return v, a, t
        # 训练时随机丢掉某个模态
        if torch.rand(1).item() < self.drop_prob:
            v = torch.zeros_like(v)
        if torch.rand(1).item() < self.drop_prob:
            a = torch.zeros_like(a)
        if torch.rand(1).item() < self.drop_prob:
            t = torch.zeros_like(t)
        return v, a, t
```

**策略 3: 模态可用性指示**

```python
class ModalityAwareFusion(nn.Module):
    def __init__(self, dim=128):
        super().__init__()
        self.proj_v = nn.Linear(768, dim)
        self.proj_a = nn.Linear(512, dim)
        self.proj_t = nn.Linear(1024, dim)
        self.gate = nn.Sequential(
            nn.Linear(3, 16),
            nn.ReLU(),
            nn.Linear(16, 3),
            nn.Softmax(dim=-1),
        )

    def forward(self, v, a, t, v_mask, a_mask, t_mask):
        # v_mask: [B], 1/0
        v_emb = self.proj_v(v)
        a_emb = self.proj_a(a)
        t_emb = self.proj_t(t)
        # 用 mask 算 gate
        mask = torch.stack([v_mask, a_mask, t_mask], dim=-1).float()  # [B, 3]
        gate = self.gate(mask)  # [B, 3]
        # 加权融合
        return v_emb * gate[:, 0:1] + a_emb * gate[:, 1:2] + t_emb * gate[:, 2:3]
```

## 3.7 多模态 SID 的评估

### 3.7.1 模态对齐质量

```python
def evaluate_modal_alignment(video_embs, text_embs):
    """评估视频-文本对齐质量"""
    # 1. 归一化
    video_embs = F.normalize(video_embs, dim=-1)
    text_embs = F.normalize(text_embs, dim=-1)

    # 2. 相似度矩阵
    sim = video_embs @ text_embs.T  # [N, N]

    # 3. Recall@K (对角线元素命中率)
    N = sim.shape[0]
    correct_1 = (sim.argmax(dim=-1) == torch.arange(N)).float().mean()

    # 4. R@5, R@10
    top5_correct = sum((sim.topk(5, dim=-1).indices == torch.arange(N).unsqueeze(-1)).any(dim=-1)).float() / N
    top10_correct = sum((sim.topk(10, dim=-1).indices == torch.arange(N).unsqueeze(-1)).any(dim=-1)).float() / N

    return {
        'R@1': correct_1.item(),
        'R@5': top5_correct.item(),
        'R@10': top10_correct.item(),
    }
```

## 3.11 面试 Q&A

**Q1: 多模态融合的 3 种主流方式?**

A:

1. **早融合**: 拼接 + 单 RQ-VAE。简单但模态信息混在一起。
2. **晚融合**: 各模态独立 RQ-VAE, SID 拼接。模态独立但 SID 长。
3. **跨模态对齐 + 融合**: CLIP-style 对比学习对齐到同空间, 再融合。质量最高但训练复杂。

**Q2: 缺模态怎么办?**

A:

- Learnable null token (学一个"空"向量代替)
- Modality dropout (训练时随机丢, 模拟缺模态)
- Modality-aware fusion (用 mask 算 gate)

**Q3: 视频 SID 维度那么高, 怎么量化?**

A:

- PCA 降维
- 分块量化 (把 4096 分成 32 个 128 维块, 各跑 RQ-VAE)
- FSQ 替代 VQ-VAE (无码本, 高维也稳)

## 3.16 多模态 SID 进阶内容

### 3.16.1 多模态对齐的数学理论

**理论基础**: 不同模态的 embedding 空间天然不同 (例如视觉空间与文本空间)。要让它们在 RQ-VAE 量化前在同一空间, 需要对齐。

**对齐的目标函数**:

$$
\mathcal{L}_{\text{align}} = -\log \frac{\exp(\text{sim}(v_i, t_i) / \tau)}{\sum_{j=1}^N \exp(\text{sim}(v_i, t_j) / \tau)}
$$

其中 $\text{sim}(v, t) = \frac{v \cdot t}{\|v\| \|t\|}$ 是余弦相似度, $\tau$ 是温度。

**为什么有效**: InfoNCE 损失最大化匹配对的互信息, 最小化非匹配对的互信息, 强制模型把匹配的跨模态对拉近。

**温度 $\tau$ 的影响**:
- $\tau \to 0$: softmax 接近 argmax, 对齐严格但易过拟合。
- $\tau \to \infty$: softmax 接近均匀分布, 对齐松弛。

推荐: $\tau = 0.07$ (CLIP 默认值)。

### 3.16.2 多模态融合的图模型视角

把多模态融合看成**图神经网络**:

```python
class GraphMultimodalFusion(nn.Module):
    """用 GNN 融合多模态"""
    def __init__(self, dim=128):
        super().__init__()
        self.node_v = nn.Linear(768, dim)
        self.node_a = nn.Linear(512, dim)
        self.node_t = nn.Linear(1024, dim)
        # 边权重 (可学习)
        self.edge_va = nn.Parameter(torch.tensor(0.5))
        self.edge_vt = nn.Parameter(torch.tensor(0.5))
        self.edge_at = nn.Parameter(torch.tensor(0.5))
        # GNN 层
        self.gnn = GCNConv(dim, dim)

    def forward(self, video, audio, text):
        v = self.node_v(video).unsqueeze(1)  # [B, 1, D]
        a = self.node_a(audio).unsqueeze(1)
        t = self.node_t(text).unsqueeze(1)
        # 拼接成图 (3 个节点)
        x = torch.cat([v, a, t], dim=1)  # [B, 3, D]
        # 邻接矩阵
        adj = torch.tensor([
            [1, self.edge_va, self.edge_vt],
            [self.edge_va, 1, self.edge_at],
            [self.edge_vt, self.edge_at, 1],
        ], device=x.device)
        # GCN
        out = self.gnn(x, adj)  # [B, 3, D]
        return out.mean(dim=1)  # [B, D]
```

### 3.16.3 多模态 SID 的鲁棒性

**对抗扰动**: 视频可能被加噪声 (压缩、滤镜), 音频可能被加噪。

```python
class RobustMultimodalSID(nn.Module):
    """鲁棒的多模态 SID"""
    def __init__(self, base_model):
        super().__init__()
        self.base = base_model
        self.augment = nn.Sequential(
            # 模态 dropout
            nn.Dropout(0.2),
            # 高斯噪声
            AddGaussianNoise(std=0.05),
        )

    def forward(self, video, audio, text, training=True):
        if training:
            video = self.augment(video)
            audio = self.augment(audio)
            text = self.augment(text)
        return self.base(video, audio, text)
```

```python
        self.base = base_model
        # 新模态编码器
        if new_modality_encoder:
            self.new_modality = new_modality_encoder
            # 投影到已有空间
            self.new_proj = nn.Linear(new_modality_encoder.dim, 128)

    def add_modality(self, new_encoder):
        """热加载新模态"""
        self.new_modality = new_encoder
        self.new_proj = nn.Linear(new_encoder.dim, 128)
```

## 3.18 多模态 SID 的局限与未来

### 局限

1. **计算成本高**: 多模态编码器推理慢, 离线预计算压力大。
2. **存储大**: 融合 embedding 128 维 × 亿级 = 50 GB+。
3. **冷启动仍不完美**: 极冷启动 (零元数据) 仍需类目兜底。
4. **多模态不对齐**: 不同模态的质量差异 (短视频可能有音频没字幕)。

### 未来方向

1. **轻量多模态**: MobileCLIP / MobileBEATs, 让多模态在端侧运行。
2. **统一多模态大模型**: ImageBind / InternVideo, 一个 encoder 处理所有模态。
3. **生成式多模态**: 用 LLM 直接生成多模态 SID。
4. **3D 多模态**: PointNet++ / NeRF 编码 3D 物品。
5. **跨域多模态**: 电商 + 内容 + 社交 多域统一 SID。

- [ ] 推理延迟预算? (决定融合复杂度)

```python
import torch
from torch.utils.data import Dataset, DataLoader
import numpy as np
import decord  # 高效视频读取


class MultimodalDataset(Dataset):
    """多模态数据集 (视频 + 音频 + 文本)"""

    def __init__(self, video_paths, audio_paths, titles, sids=None, max_frames=16):
        """
        video_paths: list of str, 视频文件路径
        audio_paths: list of str, 音频文件路径
        titles: list of str, 文本标题
        sids: [N, K] numpy, 预计算的 SID (训练时为 None)
        """
        self.video_paths = video_paths
        self.audio_paths = audio_paths
        self.titles = titles
        self.sids = sids
        self.max_frames = max_frames

    def __len__(self):
        return len(self.video_paths)

    def __getitem__(self, idx):
        # 1. 视频抽帧
        try:
            vr = decord.VideoReader(self.video_paths[idx])
            frame_indices = np.linspace(0, len(vr) - 1, self.max_frames).astype(int)
            frames = vr.get_batch(frame_indices).asnumpy()  # [T, H, W, C]
            frames = torch.from_numpy(frames).permute(0, 3, 1, 2).float() / 255.0
            # 标准化 (ImageNet mean/std)
            frames = (frames - torch.tensor([0.485, 0.456, 0.406]).view(1, 3, 1, 1)) / \
                     torch.tensor([0.229, 0.224, 0.225]).view(1, 3, 1, 1)
        except Exception as e:
            # 视频损坏 → 用零帧
            frames = torch.zeros(self.max_frames, 3, 224, 224)

        # 2. 音频
        try:
            import librosa
            audio, sr = librosa.load(self.audio_paths[idx], sr=16000, duration=10.0)
            audio = torch.from_numpy(audio).float()
            if len(audio) < 16000 * 10:
                audio = torch.nn.functional.pad(audio, (0, 16000 * 10 - len(audio)))
        except:
            audio = torch.zeros(16000 * 10)

        # 3. 文本
        title = self.titles[idx]

        # 4. SID (如果有)
        sid = self.sids[idx] if self.sids is not None else torch.zeros(4, dtype=torch.long)

        return {
            'frames': frames,           # [T, 3, H, W]
            'audio': audio,              # [16000 * 10]
            'title': title,              # str
            'sid': torch.tensor(sid, dtype=torch.long),  # [K]
        }


def collate_multimodal(batch):
    """collate function"""
    frames = torch.stack([b['frames'] for b in batch])
    audio = torch.stack([b['audio'] for b in batch])
    titles = [b['title'] for b in batch]
    sids = torch.stack([b['sid'] for b in batch])
    return {
        'frames': frames,
        'audio': audio,
        'titles': titles,
        'sids': sids,
    }
```

```python
import torch
import torch.nn as nn
from torch.utils.data import DataLoader
from torch.optim import AdamW
from torch.optim.lr_scheduler import CosineAnnealingLR


def train_multimodal_rq_vae(
    train_dataset,
    val_dataset=None,
    epochs=50,
    batch_size=32,
    lr=1e-3,
    device='cuda',
    save_path='multimodal_rq_vae.pt',
):
    """完整训练多模态 RQ-VAE"""

    # 1. 模型
    from sid_implementation.multimodal import MultimodalSID
    model = MultimodalSID(
        num_codes=256,
        num_layers=4,
        latent_dim=128,
    ).to(device)

    # 2. 数据
    train_loader = DataLoader(
        train_dataset,
        batch_size=batch_size,
        shuffle=True,
        num_workers=8,
        collate_fn=collate_multimodal,
        pin_memory=True,
    )

    # 3. 优化器
    optimizer = AdamW([
        {'params': model.rq_vae.parameters(), 'lr': lr},
        {'params': model.fusion.parameters(), 'lr': lr * 0.1},  # fusion 用更小的 LR
    ])
    scheduler = CosineAnnealingLR(optimizer, T_max=epochs)

    # 4. 训练循环
    best_loss = float('inf')
    for epoch in range(epochs):
        model.train()
        total_loss = 0
        total_recon = 0
        total_commit = 0

        for batch_idx, batch in enumerate(train_loader):
            frames = batch['frames'].to(device)
            audio = batch['audio'].to(device)
            titles = batch['titles']
            sids_target = batch['sids'].to(device)

            # 前向
            output = model(frames, audio, titles)
            x_recon = output['recon']
            sids_pred = output['sids']

            # 损失
            recon_loss = nn.functional.mse_loss(x_recon, output['target'])
            commit_loss = output['commit_loss']
            loss = recon_loss + commit_loss

            # 反向
            optimizer.zero_grad()
            loss.backward()
            torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
            optimizer.step()

            total_loss += loss.item()
            total_recon += recon_loss.item()
            total_commit += commit_loss.item()

            if batch_idx % 100 == 0:
                print(f"Epoch {epoch}, Batch {batch_idx}: "
                      f"loss = {loss.item():.4f}, "
                      f"recon = {recon_loss.item():.4f}, "
                      f"commit = {commit_loss.item():.4f}")

        scheduler.step()

        avg_loss = total_loss / len(train_loader)
        print(f"Epoch {epoch}: avg_loss = {avg_loss:.4f}")

        # 保存最优模型
        if avg_loss < best_loss:
            best_loss = avg_loss
            torch.save({
                'model': model.state_dict(),
                'epoch': epoch,
                'loss': avg_loss,
            }, save_path)
            print(f"Saved best model to {save_path}")

    return model
```

### 3.22.1 完整的 A/B 测试设计

```python
class MultimodalSIDABTest:
    """多模态 SID 的 A/B 测试"""

    def __init__(self, control_sids, treatment_sids, traffic_split=0.5):
        self.control = control_sids  # 文本 only
        self.treatment = treatment_sids  # 多模态
        self.traffic_split = traffic_split
        self.metrics = {'control': [], 'treatment': []}

    def assign(self, user_id):
        """分桶"""
        if hash(user_id) % 100 < self.traffic_split * 100:
            return 'treatment'
        return 'control'

    def get_sids(self, user_id, item_id):
        bucket = self.assign(user_id)
        if bucket == 'treatment':
            return self.treatment.get(item_id)
        return self.control.get(item_id)

    def log_impression(self, user_id, item_id, clicked, watched_time):
        bucket = self.assign(user_id)
        self.metrics[bucket].append({
            'user_id': user_id,
            'item_id': item_id,
            'clicked': clicked,
            'watched_time': watched_time,
        })

    def compute_metrics(self):
        """统计指标"""
        results = {}
        for bucket in ['control', 'treatment']:
            data = self.metrics[bucket]
            if not data:
                continue
            ctr = sum(d['clicked'] for d in data) / len(data)
            avg_time = sum(d['watched_time'] for d in data) / len(data)
            results[bucket] = {'ctr': ctr, 'avg_time': avg_time, 'n': len(data)}
        return results

    def statistical_significance(self):
        """z-test 检测显著性"""
        from scipy import stats
        control_data = self.metrics['control']
        treatment_data = self.metrics['treatment']

        if not control_data or not treatment_data:
            return None

        # CTR z-test
        c_control = sum(d['clicked'] for d in control_data) / len(control_data)
        c_treatment = sum(d['clicked'] for d in treatment_data) / len(treatment_data)

        p_pooled = (sum(d['clicked'] for d in control_data) +
                   sum(d['clicked'] for d in treatment_data)) / \
                  (len(control_data) + len(treatment_data))
        se = (p_pooled * (1 - p_pooled) *
              (1/len(control_data) + 1/treatment_data and 1/len(treatment_data)))[0]
        z = (c_treatment - c_control) / (se ** 0.5 + 1e-10)
        p_value = 2 * (1 - stats.norm.cdf(abs(z)))

        return {
            'lift': (c_treatment - c_control) / c_control,
            'z_score': z,
            'p_value': p_value,
            'significant': p_value < 0.05,
        }
```

### 3.23.1 实时监控指标

```python
class MultimodalSIDMonitor:
    """多模态 SID 实时监控"""

    def __init__(self):
        self.metrics = {}

    def log_request(self, modality_combo, sid, latency):
        """记录每次请求"""
        key = '_'.join(sorted(modality_combo))
        if key not in self.metrics:
            self.metrics[key] = []
        self.metrics[key].append({
            'sid': sid,
            'latency': latency,
            'timestamp': time.time(),
        })

    def check_anomalies(self):
        """异常检测"""
        alerts = []
        for key, logs in self.metrics.items():
            if not logs:
                continue
            recent = [l for l in logs if time.time() - l['timestamp'] < 3600]  # 最近 1 小时
            if not recent:
                continue
            # 1. 延迟告警
            avg_latency = np.mean([l['latency'] for l in recent])
            if avg_latency > 100:  # ms
                alerts.append(f"{key}: avg_latency {avg_latency:.1f}ms > 100ms")
            # 2. 唯一 SID 数告警 (监控多样性)
            unique_sids = len(set(tuple(l['sid']) for l in recent))
            if unique_sids < 100:
                alerts.append(f"{key}: unique_sids {unique_sids} too low")
        return alerts
```

## 3.24 多模态 SID 与 LLM 的协同 (预告第 11 章-02)

```python
class LLMMultimodalSID(nn.Module):
    """LLM 作为多模态 SID 编码器"""
    def __init__(self):
        super().__init__()
        # 冻结的 LLaVA / InternVL (多模态大模型)
        self.llm = LlavaForConditionalGeneration.from_pretrained('llava-v1.6-7b')
        for p in self.llm.parameters():
            p.requires_grad = False
        # 投影
        self.proj = nn.Linear(4096, 128)
        # RQ-VAE
        self.rq_vae = RQVAE(input_dim=128, num_codes=256, num_layers=4)

    def forward(self, video_frames, audio, text):
        # 1. LLM 处理多模态输入
        inputs = self.processor(
            text=text,
            images=video_frames,
            return_tensors='pt'
        ).to('cuda')
        # 2. LLM 前向 (冻结)
        with torch.no_grad():
            outputs = self.llm(**inputs)
            # 取最后一层 hidden state 平均
            llm_emb = outputs.last_hidden_state.mean(dim=1)  # [B, 4096]
        # 3. 投影 + 量化
        z_e = self.proj(llm_emb)
        return self.rq_vae.encode(z_e)  # [B, 4]
```

**优势**:

- LLM 已经见过海量图文, 语义理解远超小 encoder。
- 一次调用处理所有模态, 不用单独编码再融合。
- 缺模态自动处理 (LLM 内部就能处理)。

**劣势**:

- 推理慢: 7B 模型 200ms/物品。
- 显存大: 14 GB+。
- 只能离线预计算。

详见 [第11章-02-LLM与SID的双向赋能.md](第11章-02-LLM与SID的双向赋能.md)。

## 3.25 终极思考: SID 是否会替代 Embedding?

**回答**: 不会, 而是**共存**。

**Embedding 的优势**:
- 精确 (连续空间)
- 适合 ANN 检索 (FAISS)
- 适合多模态融合

**SID 的优势**:
- 离散 (可生成)
- 冷启动好
- 与 LLM/Transformer 兼容

**未来**: 混合架构

- **Embedding 做粗排**: FAISS 检索 top-1000 候选。
- **SID 做精排 + 生成**: Transformer 自回归生成 top-10。
- **冷启动专用 SID**: 新物品走多模态 SID 兜底。

这是 2026-2028 的趋势。

### 3.26.1 视频特征缓存

视频特征计算昂贵, 应缓存到 Redis 或文件系统:

```python
import hashlib
from pathlib import Path


class VideoFeatureCache:
    """视频特征缓存"""
    def __init__(self, cache_dir='cache/video_features'):
        self.cache_dir = Path(cache_dir)
        self.cache_dir.mkdir(parents=True, exist_ok=True)

    def _get_cache_path(self, video_path):
        """根据视频路径的 hash 找缓存"""
        h = hashlib.md5(video_path.encode()).hexdigest()
        return self.cache_dir / f"{h}.pt"

    def get_or_compute(self, video_path, extractor_fn):
        """拿缓存, 没有就计算"""
        cache_path = self._get_cache_path(video_path)
        if cache_path.exists():
            return torch.load(cache_path)
        # 计算
        features = extractor_fn(video_path)
        torch.save(features, cache_path)
        return features


# 使用
cache = VideoFeatureCache()
extractor = VideoFeatureExtractor()

def get_features(video_path):
    return cache.get_or_compute(video_path, extractor.extract)
```

### 3.26.3 内存优化

亿级 SID 表 + 码本可能上 GB:

```python
class MemoryEfficientSIDTable:
    """内存高效的 SID 表"""
    def __init__(self, num_items, num_layers=4, num_codes=256):
        # int8 节省 4x
        self.sids = np.zeros((num_items, num_layers), dtype=np.int8)
        # float16 节省 2x
        self.codebooks = [np.zeros((num_codes, 128), dtype=np.float16)
                          for _ in range(num_layers)]

    def get_sid(self, item_id):
        return self.sids[item_id]

    def decode_sid(self, sid):
        """sid → embedding"""
        emb = np.zeros(128, dtype=np.float32)
        for k in range(len(sid)):
            emb += self.codebooks[k][int(sid[k])].astype(np.float32)
        return emb

    def memory_usage_mb(self):
        sid_mb = self.sids.nbytes / 1024 / 1024
        cb_mb = sum(cb.nbytes for cb in self.codebooks) / 1024 / 1024
        return sid_mb + cb_mb


# 1000 万物品, 4 层, 128 维
# int8 SID: 1000万 × 4 = 40 MB
# float16 codebook: 4 × 256 × 128 × 2 byte = 0.25 MB
# 总计: 40.25 MB (对比 int32+float32: 644 MB)
```

```python
import torch


def batch_decode_sids_gpu(sids_tensor, codebooks_tensor):
    """批量 GPU 解码 SID → embedding
```

### 3.26.5 ANN 索引构建

```python
import faiss
import numpy as np


def build_sid_faiss_index(sid_embeddings, dim=128):
    """建 FAISS 索引"""
    N = sid_embeddings.shape[0]

    # 选择索引类型
    if N < 100000:
        # 小规模: Flat
        index = faiss.IndexFlatIP(dim)
    elif N < 1000000:
        # 中规模: IVF
        quantizer = faiss.IndexFlatIP(dim)
        index = faiss.IndexIVFFlat(quantizer, dim, int(np.sqrt(N)), 20)
        index.train(sid_embeddings)
    else:
        # 大规模: IVFPQ
        quantizer = faiss.IndexFlatIP(dim)
        index = faiss.IndexIVFPQ(quantizer, dim, int(np.sqrt(N)),
                                   16,  # nbits
                                   8)   # M
        index.train(sid_embeddings)

    # 归一化 (cosine)
    faiss.normalize_L2(sid_embeddings)
    index.add(sid_embeddings)
    return index
```

```python
class DistilledMultimodalSID(nn.Module):
    """蒸馏的小模型"""
    def __init__(self, teacher, student_dim=64):
        super().__init__()
        self.teacher = teacher  # 冻结的大模型
        # 学生: 更小
        self.student = MultimodalSID(latent_dim=student_dim, num_layers=2)

    def distillation_loss(self, video, audio, text, alpha=0.5):
        with torch.no_grad():
            teacher_emb = self.teacher.encode(video, audio, text)
        student_emb = self.student.encode(video, audio, text)
        # Embedding 蒸馏
        loss_emb = F.mse_loss(student_emb, teacher_emb)
        # SID 蒸馏 (用 soft label)
        teacher_logits = self.teacher.rq_vae.encode_logits(video, audio, text)
        student_logits = self.student.rq_vae.encode_logits(video, audio, text)
        loss_sid = F.kl_div(
            F.log_softmax(student_logits / 2, dim=-1),
            F.softmax(teacher_logits / 2, dim=-1),
            reduction='batchmean'
        ) * 4  # 温度 2
        return alpha * loss_emb + (1 - alpha) * loss_sid
```

```python
class SafeMultimodalSID(nn.Module):
    """带内容安全的多模态 SID"""
```

### 3.28.2 公平性

不同地区 / 语种的物品 SID 分布可能不均:

```python
def check_fairness(sids_by_region):
    """检查 SID 公平性"""
    # 1. 每个区域的物品数
    region_counts = {r: len(s) for r, s in sids_by_region.items()}
    # 2. 计算 Gini 系数 (越接近 0 越公平)
    counts = sorted(region_counts.values())
    n = len(counts)
    gini = (2 * sum((i + 1) * c for i, c in enumerate(counts)) - (n + 1) * sum(counts)) / (n * sum(counts))
    return {
        'region_counts': region_counts,
        'gini': gini,
        'fair': gini < 0.3,
    }
```

**7. 实践建议**

结合 "3-多模态生成式推荐的SID" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "3-多模态生成式推荐的SID" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
