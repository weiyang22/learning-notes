**为什么"信息论"是搜推广的"理论地基"而不是"装饰品"?**

很多工程师觉得信息论"高深但用不上",这是误解。**搜推广里几乎所有核心问题,本质都是信息论问题**:

1. **特征选择 = 信息瓶颈**:"保留 X 对 Y 有用的信息,丢掉其他"。IB 理论给出数学最优解
2. **负采样 = 互信息估计**:"让正样本和负样本的 embedding 互信息最大 / 最小"。InfoNCE 是工业标配
3. **多模态融合 = 信道容量**:"文本通道和图像通道共同传输用户偏好信息,容量怎么分配"
4. **曝光偏差 = 因果信息流**:"点击包含'用户喜欢'和'位置显眼'两个原因,怎么分离"
5. **训练稳定性 = 测度集中**:"高维 Embedding 距离几乎都相等,这是为什么余弦相似度比欧氏距离好"
6. **知识蒸馏 = f-散度**:"学生分布逼近教师分布,KL 是最常见的 f-散度"
7. **RL 奖励 = 率失真**:"压缩长期回报到即时奖励,信息损失多少"
8. **世界模型 = 信道**:"从状态到奖励的转移函数,本质是信道编码"

**这 8 个子主题,每一个都对应一个搜推广核心问题**。掌握信息论,**就是掌握这些问题的"理论最优解"**——比凭经验调参可靠 10 倍。

## 1. 信息几何:Fisher 信息矩阵与自然梯度

### 1.1 Fisher 信息矩阵定义

**直观理解**: Fisher 信息矩阵 $F$ 衡量**参数空间上的"局部距离"**——它告诉我们在 θ 附近,真实分布对参数有多"敏感"。

**数学定义**:

对于参数化分布 $p(x \mid \theta)$,对数似然函数 $\ell(\theta) = \log p(x \mid \theta)$ 的二阶导:

$$F_{ij}(\theta) = \mathbb{E}_{x \sim p(\cdot \mid \theta)}\!\left[ \frac{\partial \log p(x \mid \theta)}{\partial \theta_i} \cdot \frac{\partial \log p(x \mid \theta)}{\partial \theta_j} \right]$$

等价形式(对负对数似然求期望,差一个符号):

$$F(\theta) = \mathbb{E}\!\left[ \nabla_\theta \log p(x \mid \theta) \cdot \nabla_\theta \log p(x \mid \theta)^\top \right] = -\mathbb{E}\!\left[ \nabla^2_\theta \log p(x \mid \theta) \right]$$

**为什么叫"信息"?** $F$ 度量了**从样本中能获得多少关于 θ 的信息**。$F$ 越大 → 样本越能区分 θ 的微小变化 → 估计越精确。

### 1.2 Fisher 信息矩阵 = KL 散度的 Hessian

**关键恒等式**: 在 θ 附近展开 KL 散度:

$$D_{\text{KL}}\!\left(p(x \mid \theta) \,\|\, p(x \mid \theta + \delta)\right) = \frac{1}{2} \delta^\top F(\theta) \delta + O(\|\delta\|^3)$$

**直观**: $F$ 是 KL 散度的**局部二阶近似**。在 θ 附近,两个分布之间的"距离"由 $F$ 度量。

**几何解释**: 参数空间是**黎曼流形**,$F$ 是**黎曼度量张量**。两点间的"真正距离"不是欧氏距离 $\sqrt{\delta^\top \delta}$,而是**测地距离** $\sqrt{\delta^\top F \delta}$。

### 1.3 自然梯度(Naive Gradient 的反义)

**Naive 梯度下降的问题**: 在参数空间中,欧氏步长 $\eta \cdot \nabla L$ 沿不同方向**步长不等价**——某些方向"短",某些方向"长"。

**自然梯度**: 用 $F$ 调整方向,**使每个方向的真实步长一致**:

$$\tilde{\nabla}_\theta L = F^{-1}(\theta) \cdot \nabla_\theta L$$

$$\theta_{t+1} = \theta_t - \eta \cdot F^{-1}(\theta_t) \cdot \nabla_\theta L(\theta_t)$$

**直觉**: 沿"参数真实敏感"的方向,**少走一点**(避免 overshoot);沿"不敏感"的方向,**多走一点**(加速)。

#### 文字·公式·代码

**文字**: Fisher 信息矩阵回答了一个根本问题,给定观测数据,参数 $\theta$ 到底能"被学多准"。这个精度不是抽象概念,它由 F 量化。F 越大,单个样本对参数变化的响应越剧烈,无偏估计的 Cramér-Rao 下界 1/F 越小。普通梯度下降 $\theta \leftarrow \theta - \eta \nabla L$ 把参数空间当成欧氏空间,但这是错误的几何假设。沿某些方向,参数移动 0.1 可能让分布剧变;沿另一些方向,参数移动 1.0 也只是微调。自然梯度用 $F^{-1}$ 重新调整方向,相当于在黎曼流形上做真实步长一致的更新。直观上,敏感方向少走,不敏感方向多走,这就是 K-FAC、Shampoo、Muon 等现代优化器都要近似 Fisher 矩阵的根本原因。

**公式**:
$$F(\theta) = \mathbb{E}_{x \sim p(\cdot|\theta)}\!\left[\nabla_\theta \log p(x|\theta) \cdot \nabla_\theta \log p(x|\theta)^\top\right]$$
$$\theta_{t+1} = \theta_t - \eta \cdot F^{-1}(\theta_t) \cdot \nabla_\theta L(\theta_t)$$
$$\text{Cramér-Rao 下界: } \text{Var}(\hat{\theta}) \succeq F^{-1}(\theta)$$

**代码**:
```python
def natural_gradient_step(params, grads, fisher_inv_diag, lr=1e-2):
    """简化的自然梯度更新: 用 Fisher 对角线近似 F^{-1}"""
    for p, g in zip(params, grads):
        if g is None:
            continue
        # F^{-1} · ∇L ≈ (1 / fisher_diag) · grad
        # 敏感参数(fisher 大)步长小,不敏感(fisher 小)步长大
        natural_g = g / (fisher_inv_diag + 1e-8)
        p.data.add_(-lr * natural_g)
```

### 1.4 搜推广中的应用

#### 1.4.1 Embedding 表的 Fisher 矩阵

**文字**: 工业推荐里 Embedding 表常占总参数 95%+,但训练时**只有不到 5% 的行被频繁更新**(因为用户行为长尾)。**Fisher 信息矩阵能精确诊断"哪些行学得足、哪些行没学"**:高频 ID 的 Fisher 大(对 loss 影响大),低频 ID 的 Fisher ≈ 0。**为什么这很关键?** 长尾 ID 没机会被充分训练,推理时被推出去时 Embedding 还是"接近初始化的噪声",容易导致 bad case。这就是冷启动问题的信息论根源。

```python
# ===== 1) 准备 dataloader,产出符合示例所需的 batch 格式 =====
class CTRBatchDataset(Dataset):
    """生成 item_id + context_vec 的 DataLoader,对接 §1.4.1 的 Fisher 计算"""
    def __init__(self, num_items=10000, num_dense=8, num_samples=5000):
        self.num_items = num_items
        self.num_dense = num_dense
        self.num_samples = num_samples
        # 长尾分布:80% 流量集中在 20% 头部 ID
        head_ids = torch.arange(int(num_items * 0.2))
        tail_ids = torch.arange(int(num_items * 0.2), num_items)
        head_probs = torch.full((len(head_ids),), 0.8 / len(head_ids))  # 头部 80%
        tail_probs = torch.full((len(tail_ids),), 0.2 / len(tail_ids))  # 长尾 20%
        all_ids = torch.cat([head_ids, tail_ids])
        all_probs = torch.cat([head_probs, tail_probs])
        # 预生成所有 batch
        self.item_ids = all_ids[torch.multinomial(all_probs, num_samples, replacement=True)]
        self.context = torch.randn(num_samples, num_dense)
        self.labels = torch.randint(0, 2, (num_samples, 1)).float()

    def __len__(self):
        return self.num_samples

    def __getitem__(self, idx):
        return {
            'item_ids':    self.item_ids[idx],          # 标量 (int)
            'context_vec': self.context[idx],            # [num_dense]
            'label':       self.labels[idx],             # 标量 (float)
        }


def collate_ctr(batch):
    """把 list[dict] 合并成 batch dict"""
    return {
        'item_ids':    torch.stack([b['item_ids']    for b in batch]),
        'context_vec': torch.stack([b['context_vec'] for b in batch]),
        'label':       torch.stack([b['label']       for b in batch]),
    }


# ===== 2) 完整 Fisher 对角线计算 (可直接运行) =====
def compute_fisher_diag_for_embedding(emb_layer, dataloader, num_batches=100):
    """
    计算 Embedding 表参数的 Fisher 信息矩阵对角线
    用于诊断: 哪些行对模型影响大,值得训练?
    """
    fisher_diag = torch.zeros_like(emb_layer.weight)

    for i, batch in enumerate(dataloader):
        if i >= num_batches:
            break
        emb_layer.zero_grad()
        # 前向 + 损失(简化示例,真实场景用 BCE/CE)
        ids = batch['item_ids']                                    # [B]
        emb = emb_layer(ids)                                       # [B, dim]
        logits = (emb * batch['context_vec']).sum(dim=-1)          # [B]
        loss = -F.logsigmoid(logits * (2 * batch['label'].squeeze() - 1)).sum()
        loss.backward()
        # Fisher ≈ 一阶梯度的平方(对角线近似)
        fisher_diag += emb_layer.weight.grad ** 2

    fisher_diag /= num_batches
    return fisher_diag


# ===== 3) 实际跑一下,看头部 vs 长尾的 Fisher 差异 =====
if __name__ == "__main__":
    num_items, embed_dim = 10000, 32
    emb = nn.Embedding(num_items, embed_dim)
    ds = CTRBatchDataset(num_items=num_items, num_dense=8, num_samples=5000)
    dl = DataLoader(ds, batch_size=256, shuffle=True, collate_fn=collate_ctr)

    fisher = compute_fisher_diag_for_embedding(emb, dl, num_batches=20)

    # 头/尾 ID 的 Fisher 大小对比
    head_end = int(num_items * 0.2)
    fisher_per_row = fisher.sum(dim=-1)  # [num_items],每行 Fisher 范数
    head_fisher = fisher_per_row[:head_end].mean().item()
    tail_fisher = fisher_per_row[head_end:].mean().item()
    print(f"头部 20% ID 的平均 Fisher: {head_fisher:.4f}")
    print(f"长尾 80% ID 的平均 Fisher: {tail_fisher:.4f}")
    print(f"比值: {head_fisher / max(tail_fisher, 1e-8):.1f}x")
    # 期望: 头部 Fisher 比长尾大 10-50 倍,这正是"过拟合灾难"的根源

# 解释: Fisher 大的行 = 高频被访问的 ID
# 这些 ID 的更新对 loss 影响大 → 应该是"被充分训练"的 ID
# Fisher ≈ 0 的行 = 长尾 ID,被训练机会少 → 这就是"过拟合灾难"的根源
```

**EWC(Elastic Weight Consolidation)中的使用**(详见 `第08章-GR的在线与长期.md` §8.3.3):

$$L_{\text{EWC}} = L_{\text{task}} + \frac{\lambda}{2} \sum_i F_i \cdot (\theta_i - \theta_i^*)^2$$

**F 大 → 旧任务对参数 i 重要 → 不允许大幅偏移**;**F 小 → 自由更新**。

#### 1.4.2 K-FAC 优化器(用 F 块对角近似)

**问题**: 直接计算 $F^{-1}$ 是 $O(d^3)$,亿级参数不可能。

**K-FAC 思路**: 假设 $F$ 近似**块对角**(每层独立),每块用**两个小矩阵的乘积**近似:

$$F_l \approx A_l \otimes G_l$$

- $A_l = \mathbb{E}[a_l a_l^\top]$(激活的外积,大小 $d \times d$)
- $G_l = \mathbb{E}[g_l g_l^\top]$(输出梯度的外积,大小 $d \times d$)

**计算量**: 从 $O(d^3)$ 降到 $O(d^{2.37})$(用更快的矩阵求逆),实际工程中可接受。

**搜推广**: K-FAC 主要用于**中等规模模型**(< 1B 参数),LLM 时代被 **Shampoo / Muon / SOAP** 等更新方法取代。

### 1.5 公式小卡片

$$\boxed{F_{ij} = \mathbb{E}\!\left[\frac{\partial \log p}{\partial \theta_i} \cdot \frac{\partial \log p}{\partial \theta_j}\right] \quad \text{(Fisher 矩阵)}}$$

$$\boxed{D_{\text{KL}}(p_\theta \| p_{\theta+\delta}) = \frac{1}{2} \delta^\top F \delta \quad \text{(局部二阶展开)}}$$

$$\boxed{\tilde{\nabla} L = F^{-1} \nabla L \quad \text{(自然梯度)}}$$

## 2. 互信息估计:MINE/InfoNCE 的下界证明

### 2.1 互信息回顾

$$I(X; Y) = D_{\text{KL}}(p(x,y) \| p(x) p(y)) = \mathbb{E}_{p(x,y)}\!\left[\log \frac{p(x,y)}{p(x)p(y)}\right]$$

**意义**: $I(X; Y)$ 衡量"知道 Y 之后,X 的不确定性减少了多少 bits"。

**为何难估计**: $p(x,y)$ 和 $p(x)p(y)$ 在高维空间都不可知。朴素直方图/KDE 在 $d > 5$ 时**维度灾难**。

### 2.2 5 种估计方法对比

| 方法 | 原理 | 复杂度 | 估计偏差 | 适用 |
| :--- | :--- | :--- | :--- | :--- |
| **直方图** | binning 估计 $p(x,y), p(x), p(y)$ | $O(B^d)$ | 极高 | $d \leq 3$ |
| **KDE (核密度)** | $p(x) \approx \sum_i K(x-x_i)$ | $O(N)$ | 中 | 中维,需带宽选择 |
| **KSG (KNN-based)** | Kraskov-Stögbauer-Grassberger | $O(N \log N)$ | 低 | $d \leq 10$ 黄金标准 |
| **MINE (DV-based)** | 神经网络参数化 T_θ | $O(B)$ 训练 | **有偏但有界** | **高维首选** |
| **InfoNCE (对比)** | 分类目标的下界 | $O(B)$ | **下界**,有 bias-variance | **自监督/对比学习首选** |

### 2.3 MINE 详细推导

**Donsker-Varadhan (DV) 表示**(1975, 信息论经典结果):

$$D_{\text{KL}}(p \| q) = \sup_{T: \Omega \to \mathbb{R}} \left[ \mathbb{E}_p[T] - \log \mathbb{E}_q[e^T] \right]$$

**上确界**在 $T^* = 1 + \log(dp/dq)$ 时取到。

**代入互信息**: 令 $p = p(x,y)$,$q = p(x)p(y)$:

$$I(X;Y) = D_{\text{KL}}(p(x,y) \| p(x)p(y)) = \sup_T \left[ \mathbb{E}_{p(x,y)}[T] - \log \mathbb{E}_{p(x)p(y)}[e^T] \right]$$

**MINE 核心**: 用神经网络 $T_\theta: \mathcal{X} \times \mathcal{Y} \to \mathbb{R}$ 参数化:

$$\hat{I}_{\text{MINE}}(X;Y) = \sup_\theta \left[ \mathbb{E}_{p(x,y)}[T_\theta(x,y)] - \log \mathbb{E}_{p(x)p(y)}[e^{T_\theta(x,y)}] \right]$$

**训练**:
- 正样本来自 joint $p(x,y)$(同 batch 内配对)
- 负样本来自 marginal $p(x)p(y)$(shuffle 拆散配对)

```python
import torch
import torch.nn as nn

class MINE(nn.Module):
    """Mutual Information Neural Estimation"""
    def __init__(self, x_dim, y_dim, hidden=256):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(x_dim + y_dim, hidden),
            nn.ReLU(),
            nn.Linear(hidden, hidden),
            nn.ReLU(),
            nn.Linear(hidden, 1)
        )

    def forward(self, x, y):
        """x: [B, x_dim], y: [B, y_dim]"""
        T_xy = self.net(torch.cat([x, y], dim=-1))   # joint
        # 负样本: shuffle y(打破 x-y 配对)
        y_shuffled = y[torch.randperm(y.size(0))]
        T_x_yp = self.net(torch.cat([x, y_shuffled], dim=-1))  # marginal
        # DV 损失
        mi_estimate = (T_xy.mean() -
                       torch.log(torch.exp(T_x_yp).mean() + 1e-8))
        return mi_estimate

# 训练
mine = MINE(x_dim=64, y_dim=64)
optimizer = torch.optim.Adam(mine.parameters(), lr=1e-3)
for x, y in dataloader:    # x, y 是 paired
    for _ in range(5):    # 多次更新 T
        loss = -mine(x, y)  # 最大化 MI → 最小化负值
        optimizer.zero_grad()
        loss.backward()
        # 梯度裁剪(防止 exp 爆炸)
        torch.nn.utils.clip_grad_norm_(mine.parameters(), 1.0)
        optimizer.step()
```

**注意**:
- 估计值**有偏**(DV 表示本身的 exp/log 引入偏差)
- 实践中需 **moving average** 估计的 MI(防止训练中震荡)
- **梯度裁剪**至关重要,$\log \mathbb{E}[e^T]$ 容易爆炸

### 2.4 InfoNCE 作为 MI 下界(关键定理)

**InfoNCE 损失**(Oord 2018):

$$\mathcal{L}_{\text{InfoNCE}} = -\mathbb{E}\!\left[ \log \frac{e^{f(x, y_k)}}{\sum_{j=1}^{B} e^{f(x, y_j)}} \right]$$

其中 $k$ 是 $x$ 的"正样本"索引(其他 $j$ 是 batch 内负样本)。

**下界定理**(Poole 2019 等):

$$\boxed{I(X; Y) \geq \log(B) - \mathcal{L}_{\text{InfoNCE}}}$$

**推导**:
- 记 $p(x,y)$ 为真实配对分布,$q(x,y_j) = p(x) p(y_j)$ 为随机配对
- 分类器 $p(y \mid x) = \text{softmax}_j(f(x, y_j))$ 试图从 $B$ 个候选中挑出正确的 $y_k$
- 最优分类器的负对数似然 = $\log B - I_q(X;Y)$(互信息 $I_q$ 在 $q$ 分布下)
- 当负采样从 $p(x)p(y)$ 来时,$I_q(X;Y) \to I(X;Y)$,**故 InfoNCE 上界 $\log B - I(X;Y)$**

```python
def infonce_loss(z1, z2, temperature=0.07):
    """
    z1, z2: [B, D]  配对的 embedding
    InfoNCE = 对比交叉熵
    """
    B = z1.size(0)
    # L2 归一化
    z1 = nn.functional.normalize(z1, dim=-1)
    z2 = nn.functional.normalize(z2, dim=-1)
    # 相似度矩阵: [B, B], 对角线是正样本
    sim = torch.matmul(z1, z2.T) / temperature
    labels = torch.arange(B, device=z1.device)
    return nn.functional.cross_entropy(sim, labels)

# 等价于: \mathcal{L}_InfoNCE = -log(exp(sim_pos)/sum(exp(sim_j)))
# 所以 I(X;Y) >= log(B) - L_InfoNCE
```

#### 文字·公式·代码

**文字**: 互信息的 KL 定义在公式上清晰,实操却是噩梦。$p(x,y)$ 未知,$p(x)p(y)$ 未知,高维空间里两个分布都不可采样。MINE 用 Donsker-Varadhan 表示把 KL 写成神经网络期望的 sup,把问题转化为用一个网络 $T_{\theta}$ 拟合对数密度比。这个转换的代价是估计有偏,$\exp$/$\log$ 引入的偏差在 batch 小的时候显著,但换来的是 $O(B)$ 的 minibatch 估计,可以扩展到任意维度。InfoNCE 走另一条路,构造一个 B 类分类任务,从 B-1 个负样本里挑出正样本。直觉是,分类越准,x 和 y 越相关,互信息越大,数学上 $I(X;Y) \geq \log$ B - $L_{I}$nfoNCE。这个下界紧不紧取决于 batch 大小 B,B 越大下界越紧。这也解释了为什么对比学习普遍用大 batch,CLIP 用到了 32768,SimCLR 也要 4096。

**公式**:
$$I(X;Y) \geq \log B - \mathcal{L}_{\text{InfoNCE}}$$
$$\hat{I}_{\text{MINE}} = \sup_\theta \mathbb{E}_{p(x,y)}[T_\theta] - \log \mathbb{E}_{p(x)p(y)}[e^{T_\theta}]$$
$$\text{估计偏差: } \mathbb{E}[\hat{I}_{\text{MINE}}] - I(X;Y) = O(1/\sqrt{B})$$

**代码**:
```python
class MINENet(nn.Module):
    """MINE 简化版: 用神经网络 T_θ 估计互信息 DV 下界"""
    def __init__(self, x_dim, y_dim, hidden=128):
        super().__init__()
        self.T = nn.Sequential(
            nn.Linear(x_dim + y_dim, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
            nn.Linear(hidden, 1))
    def forward(self, x, y):
        # joint 样本: 真实配对
        joint = self.T(torch.cat([x, y], dim=-1))
        # marginal 样本: shuffle y 打破配对
        y_perm = y[torch.randperm(y.size(0))]
        margin = self.T(torch.cat([x, y_perm], dim=-1))
        # DV 下界
        return joint.mean() - (margin.exp().mean() + 1e-8).log()
```

## 3. 信息瓶颈理论:从经典 IB 到 VIB

### 3.1 经典 IB(Tishby 1999)

**核心思想**: 学习一个表示 $Z$,使其**保留关于 $Y$ 的信息**但**压缩关于 $X$ 的信息**。

$$\boxed{\min_{p(z \mid x)} I(X; Z) - \beta \cdot I(Z; Y)}$$

- $I(X; Z)$: 表示 $Z$ 记住的 $X$ 信息(越少越好 → **压缩**)
- $I(Z; Y)$: 表示 $Z$ 保留的 $Y$ 信息(越多越好 → **预测**)
- $\beta$: 压缩-预测的权衡

**拉格朗日形式**:

$$\mathcal{L}_{\text{IB}} = I(X; Z) - \beta \cdot I(Z; Y)$$

**信息平面(Information Plane)**:
- 横轴 $I(X; Z)$,纵轴 $I(Z; Y)$
- 训练过程分两阶段:
  1. **拟合阶段**: $I(Z;Y)$ 快速上升,$I(X;Z)$ 也上升
  2. **压缩阶段**: $I(X;Z)$ 下降,$I(Z;Y)$ 保持
- **隐式正则化**: SGD 在低 $\beta$ 下天然倾向于找到 IB 极小值

### 3.2 DeepIB / VIB(Alemi 2017)

**问题**: 经典 IB 的 $I(X; Z)$ 难以直接计算(需要 $p(z|x)$ 的真实分布)。

**VIB 关键**: 用**变分下界** $D_{\text{KL}}(q(z|x) \| r(z)) \geq D_{\text{KL}}(p(z|x) \| r(z))$,把 KL 散度换成**易于计算的**形式:

$$\boxed{\mathcal{L}_{\text{VIB}} = \mathbb{E}_{p(x)}\!\left[ -\mathbb{E}_{q(z \mid x)}[\log q(y \mid z)] + \beta \cdot D_{\text{KL}}(q(z \mid x) \| r(z)) \right]}$$

**直觉**:
- 第一项 = 预测 $Y$ 的负对数似然(标准损失)
- 第二项 = 近似后验 $q(z|x)$ 偏离先验 $r(z)$(通常取标准正态)的程度

```python
class VIB(nn.Module):
    """Variational Information Bottleneck"""
    def __init__(self, x_dim, z_dim, y_dim, beta=1e-3):
        super().__init__()
        self.beta = beta
        # 编码器: 输出 (mu, log_var)
        self.encoder = nn.Sequential(
            nn.Linear(x_dim, 256), nn.ReLU(),
            nn.Linear(256, 2 * z_dim)  # 输出 mu 和 log_var
        )
        # 预测头
        self.predictor = nn.Linear(z_dim, y_dim)
        # 先验: 标准正态(固定,无参数)

    def forward(self, x):
        # 编码
        mu_logvar = self.encoder(x)
        mu, log_var = mu_logvar.chunk(2, dim=-1)
        # 重参数化
        std = torch.exp(0.5 * log_var)
        z = mu + std * torch.randn_like(std)
        # 预测
        y_pred = self.predictor(z)
        return y_pred, mu, log_var

    def vib_loss(self, y_pred, y_true, mu, log_var):
        # 预测损失
        pred_loss = nn.functional.cross_entropy(y_pred, y_true)
        # KL 散度(与标准正态先验)
        kl = -0.5 * torch.sum(1 + log_var - mu.pow(2) - log_var.exp(), dim=-1).mean()
        return pred_loss + self.beta * kl
```

#### 文字·公式·代码

**文字**: 信息瓶颈被称为深度学习的"理想目标"不是夸张。它直接说,我们想要的表示 Z 应该满足两件事: 保留关于 Y 的所有预测信息($I(Z;Y)$ 大),丢弃关于 X 的所有无关信息($I(X;Z)$ 小)。这个二分法天然匹配监督学习的两大需求,泛化靠少记 X 的噪声,判别靠多记 Y 的信号。$\beta$ 是这两者的旋钮,$\beta\to 0$ 时退化成普通经验风险最小化(什么都记),$\beta\to\infty$ 时 Z 退化成常数(什么也不记)。在推荐召回里,IB 特别有用: 用户特征 X 包含大量位置、时间、设备噪声,这些不该进入 Z。但 $I(X;Z)$ 难直接算,因为它需要 $p(z|x)$ 的真实分布。所以实际工程用变分下界(VIB),把 KL 替换成 $q(z|x)$ 与先验 $N(0,I)$ 的距离,可微可优化,这是工业界唯一可行的路径。

**公式**:
$$\mathcal{L}_{\text{IB}} = I(T;Y) - \beta \cdot I(X;T)$$
$$\mathcal{L}_{\text{VIB}} = -\mathbb{E}_{q(z|x)}[\log q(y|z)] + \beta \cdot D_{\text{KL}}(q(z|x) \| \mathcal{N}(0,I))$$
$$\beta \uparrow \Rightarrow \text{压缩强}, \quad \beta \downarrow \Rightarrow \text{预测强}$$

**代码**:
```python
def vib_train_step(model, x, y, optimizer, beta=1e-3):
    """VIB 单步训练: 预测损失 + KL 压缩正则"""
    y_pred, mu, logvar = model(x)
    # 重建损失: 预测 y 的能力
    pred_loss = F.cross_entropy(y_pred, y)
    # KL 散度到标准正态先验(解析形式)
    kl = -0.5 * (1 + logvar - mu.pow(2) - logvar.exp()).sum(-1).mean()
    loss = pred_loss + beta * kl
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    return pred_loss.item(), kl.item()
```

### 3.3 搜推广中的应用

1. **用户画像压缩**:
   - 用户特征 $X$ → 压缩表示 $Z$ → 预测物品点击 $Y$
   - $\beta$ 越大 → 用户画像越简洁(避免过拟合到特定用户)

2. **Embedding 表的信息瓶颈**:
   - 原始 ID → Embedding → 预测 CTR
   - 在 Embedding 上加 VIB 损失 → 防止"用户指纹"现象(模型记住特定 ID 而不是泛化)

3. **多模态融合的 IB 视角**:
   - 文本/图像/ID 三模态的共同表示 $Z$ 应该**保留预测物品的能力**但**压缩原始模态的细节**

## 4. 高维概率:测度集中与 J-L 引理

### 4.1 维数灾难:重新审视

`第10章-数据处理.md` §2.11.2 给了距离 SNR 视角。这里补充**几何和测度论**视角。

### 4.2 测度集中(Concentration of Measure)

**Levy 引理**: 在高维球面 $S^{d-1}$ 上,**任何赤道**(把球面分成两半的 hyperplane)附近的**测度极度集中**:

$$\mathbb{P}(|X - \mu| > \epsilon) \leq 2 \exp(-c d \epsilon^2)$$

其中 $X$ 是球面随机点,$\mu$ 是其期望。

**直观**: 高维空间中,几乎**所有点都聚集在赤道附近**。从北极看下去,几乎所有点都在你脚下。

**Milman-Sodin 引理**(高维版本):
- 任何定义在高维球上的 1-Lipschitz 函数,值都**几乎处处**接近其期望
- 例: 从高维球上随机采两点,他们的距离**几乎总是接近** $\sqrt{2}$(即直径)

### 4.3 Johnson-Lindenstrauss 引理

**定理陈述**(JL 引理, 1984):

> 给定 $N$ 个点(在任意维欧氏空间),存在一个随机线性映射 $f: \mathbb{R}^D \to \mathbb{R}^k$ 其中 $k = O(\log N / \epsilon^2)$,使得所有点对距离在 $(1 \pm \epsilon)$ 范围内保持。

**推论**: **高维到低维的随机投影几乎不损失距离信息**。

**证明思路**:
1. 高维随机向量 $v \in \mathbb{R}^D$ 与固定方向 $u$ 的内积 $\langle v, u \rangle$ 满足 $v_i \sim N(0, 1/D)$
2. 投影后,内积变为 $D$ 个独立 N(0, 1/D) 之和,方差 $1/D$
3. **归一化后**方差 = 1,意味着每个新坐标保持原有距离的 $\frac{1}{\sqrt{D}}$ 比例
4. **多个随机投影**的累积 → 距离的 $\epsilon$-近似

**搜推广中的应用**:
- ANN(近似最近邻)检索的**预处理**: 先用 JL 投影到 $O(\log N)$ 维,再做精确 KNN
- 推荐系统 Embedding 的**降维可视化**:t-SNE/UMAP 的初始随机投影就是 JL

```python
import torch

def johnson_lindenstrauss(X, target_dim, eps=0.1):
    """
    X: [N, D]  数据点
    返回: [N, target_dim]  投影后的点
    """
    N, D = X.shape
    # 目标维度 (JL 界)
    k = max(1, int(4 * torch.log(torch.tensor(N)).item() / (eps**2 / 2 - eps**3 / 3)))
    k = min(k, target_dim)
    # 随机投影: 高斯矩阵
    proj_matrix = torch.randn(D, k, device=X.device) / (k ** 0.5)
    return X @ proj_matrix
```

#### 文字·公式·代码

**文字**: 高维空间里发生的事和我们的直觉严重脱节。最反直觉的是"距离集中",从高维球面随机采两点,它们的距离几乎一定接近 √2(直径),不论球面是 100 维还是 10000 维。这意味着在 100 维空间里"找最近邻"和"找最远邻"几乎没有区别,所有点都差不多远。第二个反直觉是"维数灾难",k-NN 的局部线性逼近需要样本数随维度指数增长。第三个是"几乎正交",固定一个向量,任意一个新随机向量跟它几乎正交。这些都意味着,高维到低维的随机投影其实没有损失多少信息,这就是 Johnson-Lindenstrauss 引理: 只需 $O(log N / ε²)$ 维就能保距。JL 的存在让"用 32 维 Embedding 表示百万物品"有了理论根据,不需要 10 万维。这个引理也是 ANN 检索、t-SNE/UMAP 初始降维的理论基础。

**公式**:
$$\mathbb{P}(|X - \mu| > \varepsilon) \leq 2 e^{-c d \varepsilon^2} \quad \text{(Levy 距离集中)}$$
$$k_{\text{JL}} = O(\log N / \varepsilon^2) \quad \text{(JL 保距最小投影维度)}$$
$$\forall i \neq j: \langle v_i, v_j \rangle \to 0 \text{ as } d \to \infty \quad \text{(随机向量几乎正交)}$$

**代码**:
```python
def jl_project(X, target_dim, eps=0.1):
    """Johnson-Lindenstrauss 随机投影到保距低维空间"""
    N, D = X.shape
    # 理论最小保距维度 (JL 界)
    k_min = int(4 * np.log(N) / (eps**2 / 2 - eps**3 / 3))
    k = min(k_min, target_dim)
    # 高斯随机矩阵 + 1/sqrt(k) 归一化
    proj = torch.randn(D, k, device=X.device) / (k ** 0.5)
    return X @ proj
# 验证: 投影前后 ||x_i - x_j|| 满足 (1±eps) 比例
```

### 4.4 维度坍缩(Dimensional Collapse)

**现象**: 自监督/对比学习中,所有样本的表示**坍缩到一个点或一条线**,造成训练失败。

**诊断**:
```python
def check_dimensional_collapse(emb, n_components=10):
    """用 SVD 检测 Embedding 是否坍缩"""
    # emb: [N, D]
    U, S, V = torch.linalg.svd(emb - emb.mean(0), full_matrices=False)
    # 奇异值占比
    explained_var = (S ** 2) / (S ** 2).sum()
    # 如果前几个奇异值占比 >> 1/D → 维度坍缩
    effective_rank = (explained_var > 0.01).sum().item()
    print(f"有效秩: {effective_rank}/{emb.size(1)}")
    return effective_rank
```

**搜推广中的表现**:
- 训练初期,所有用户 Embedding 都很接近(由 $\mathcal{N}(0, \sigma^2)$ 初始化)
- 如果学习率太低或正则太强 → 一直坍缩
- 解决方案: 对比学习的大 batch + 适当的温度

### 4.5 Hubness 现象

**现象**: 高维空间中,某些点(称为 "hubs")与**许多其他点都距离很近**,而其他点则很孤立。

**度量**: 计算每个点作为最近邻出现的次数:
```python
def compute_hubness(emb, k=10):
    """高维空间中 hubness 量化"""
    N = emb.size(0)
    # 计算两两距离
    dist = torch.cdist(emb.unsqueeze(0), emb.unsqueeze(0)).squeeze(0)
    # 每个点的 k-NN
    _, knn_idx = dist.topk(k+1, dim=-1, largest=False)  # [N, k+1]
    knn_idx = knn_idx[:, 1:]   # 排除自身
    # 统计每个点被多少其他点的 k-NN 引用
    hub_count = torch.zeros(N)
    for i in range(N):
        for j in knn_idx[i]:
            hub_count[j] += 1
    # hubness 系数
    skewness = ((hub_count - hub_count.mean()) ** 3).mean() / (hub_count.std() ** 3)
    return skewness   # > 0 表明有 hub
```

**搜推广**: KNN 召回时,某些"明星"物品被反复推荐(因为它们是 hub),导致**多样性差**。

### 4.6 流形假设

**核心假设**: 真实数据(用户、物品)虽然生活在高维空间,但**实际分布位于低维流形上**。

**搜推广含义**:
- 用户 Embedding 的"真实维度"<<Embedding 维度(32/64)
- 大多数用户/物品只在低维子空间上有意义
- **降维**(t-SNE/UMAP)能可视化用户画像,因为这个低维结构存在

## 5. 跨模态信息融合:CLIP/ImageBind 范式

### 5.1 CLIP 的信息论视角

**CLIP 损失**(Radford 2021):

$$\mathcal{L}_{\text{CLIP}} = -\frac{1}{B} \sum_{i=1}^{B} \log \frac{\exp(\text{sim}(I_i, T_i) / \tau)}{\sum_{j=1}^{B} \exp(\text{sim}(I_i, T_j) / \tau)}$$

其中 $I_i$ 是图像编码,$T_i$ 是文本编码,$\text{sim}$ 是余弦相似度,$\tau$ 是温度。

**信息论解读**(第 2.4 节已证明):

$$\boxed{I(I; T) \geq \log B - \mathcal{L}_{\text{CLIP}}}$$

**意义**: 训练好的 CLIP 最大化图像-文本对的**互信息下界**。共享 Embedding 空间中,语义相关的图像-文本**距离近**。

```python
import torch
import torch.nn.functional as F

def clip_loss(image_emb, text_emb, temperature=0.07):
    """
    image_emb: [B, D] 图像编码
    text_emb:  [B, D] 文本编码
    """
    # 归一化
    image_emb = F.normalize(image_emb, dim=-1)
    text_emb = F.normalize(text_emb, dim=-1)
    # 相似度矩阵
    logits = image_emb @ text_emb.T / temperature   # [B, B]
    # 双向 InfoNCE
    labels = torch.arange(image_emb.size(0), device=image_emb.device)
    loss_i2t = F.cross_entropy(logits, labels)       # 图像→文本
    loss_t2i = F.cross_entropy(logits.T, labels)     # 文本→图像
    return (loss_i2t + loss_t2i) / 2
```

### 5.2 ImageBind(Meta 2023)

**核心思想**: 让**6 种模态**(图像、文本、音频、深度、热成像、IMU)都共享同一 Embedding 空间。

**训练目标**: 任意两种模态 $(M_i, M_j)$ 的对比损失:

$$\mathcal{L}_{\text{ImageBind}} = \sum_{i < j} \mathcal{L}_{\text{CLIP}}(\phi_{M_i}(x_i), \phi_{M_j}(x_j))$$

其中 $\phi_{M_i}$ 是模态 $M_i$ 的编码器。

**信息论解读**: ImageBind **最大化任意两种模态间的互信息下界**,使它们在共享空间中**几何一致**。

### 5.3 搜推广中的多模态应用

```python
class MultiModalRecommender(nn.Module):
    """
    搜推广中的多模态: ID + 文本 + 图像三模态对齐
    """
    def __init__(self, id_vocab, text_dim=384, img_dim=512, d=64):
        super().__init__()
        # 三个模态的编码器
        self.id_encoder = nn.Embedding(id_vocab, d)
        self.text_proj = nn.Linear(text_dim, d)        # Sentence-T5 输出
        self.img_proj = nn.Linear(img_dim, d)         # CLIP-ViT 输出
        # 跨模态融合层
        self.fusion = nn.MultiheadAttention(d, num_heads=8, batch_first=True)

    def forward(self, item_id, title_emb, cover_img):
        id_emb = self.id_encoder(item_id)
        text_emb = self.text_proj(title_emb)
        img_emb = self.img_proj(cover_img)
        # 三模态融合(堆叠成序列)
        seq = torch.stack([id_emb, text_emb, img_emb], dim=1)  # [B, 3, D]
        fused, _ = self.fusion(seq, seq, seq)
        return fused.mean(dim=1)    # [B, D]
```

**训练目标**:
- 主任务:CTR/CVR 预测(用 fused Embedding)
- 辅助任务:跨模态对齐(CLIP 风格)
  ```python
  # 模态间对齐损失
  loss_align = (
      clip_loss(id_emb, text_emb) +
      clip_loss(id_emb, img_emb) +
      clip_loss(text_emb, img_emb)
  ) / 3
  ```

### 5.4 公式小卡片

$$\boxed{\mathcal{L}_{\text{CLIP}} = -\frac{1}{B}\sum_i \log \frac{e^{\text{sim}(I_i, T_i)/\tau}}{\sum_j e^{\text{sim}(I_i, T_j)/\tau}}}$$

$$\boxed{I(I;T) \geq \log B - \mathcal{L}_{\text{CLIP}} \quad \text{(互信息下界)}}$$

## 6. 因果信息流:SCM/Do-calculus/IPW

### 6.1 结构因果模型(SCM)入门

**三要素**:
- **外生变量** $U$: 不被模型解释的"噪声"
- **内生变量** $V$: 关心的变量
- **结构方程**: $V_i = f_i(\text{pa}(V_i), U_i)$,其中 $\text{pa}(V_i)$ 是 $V_i$ 的"父节点"

**示例**(搜推广):
```text
                    U_user
                     ↓
       user_features → user_emb
                     ↓
       (item_features, user_emb) → click ← U_click
                     ↑
              item_features
                     ↑
                U_item
```

### 6.2 Do-calculus 与因果效应

**观察 vs 干预**:
- 观察: $P(Y \mid X)$ —— 在 $X$ 已知时,$Y$ 的分布
- 干预: $P(Y \mid \text{do}(X=x))$ —— 强制 $X$ 设为 $x$ 时的 $Y$ 分布

**Pearl's Do-calculus 三规则**:
1. **插入/删除观察**: 在图阻断时,$P(y \mid \text{do}(x), z, w) = P(y \mid \text{do}(x), w)$(可删 $z$)
2. **干预与观察交换**: $\frac{P(y \mid \text{do}(x), \text{do}(z), w)}{P(y \mid \text{do}(x), w)} = \frac{P(y \mid \text{do}(x), z, w)}{P(y \mid \text{do}(x), w)}$(特定条件)
3. **插入/删除干预**: $\frac{P(y \mid \text{do}(x), \text{do}(z), w)}{P(y \mid \text{do}(x), w)} = \frac{P(y \mid \text{do}(x), w)}{P(y \mid \text{do}(x), w)} = 1$(某些情况下)

#### 文字·公式·代码

**文字**: 搜推广里最常犯的因果错误是把"相关"当"因果"。位置偏差是经典案例: 用户点第一个位置的物品多,但不是因为这个物品最好,而是因为位置 1 天然获得更多视觉注意。如果用日志训练的模型去排序,它会学到"把用户最可能注意的位置上放最贵的广告",这是对平台短期收益有利的相关关系,但不是用户真实偏好的因果关系。逆概率加权(IPS)的纠偏逻辑很优雅: 被展示概率 $\pi$ 小的物品,其点击信号含信息量更大,应该用 1/$\pi$ 加权放大。直觉是,这个物品的"幸存"是低概率事件,能从中活下来的偏好信号更纯净。这其实是从观察数据推断因果效应的核心技巧,Doubly Robust 是更稳定的版本,它结合直接预测和 IPW 残差纠偏,任一准确都能纠偏。

**公式**:
$$\mathcal{L}_{\text{IPW}} = \sum_{(s,a)} \frac{1}{\pi(a|s)} \cdot r(s,a) \quad \text{(逆概率加权)}$$
$$\text{无偏条件: } \mathbb{E}_\pi[\mathcal{L}_{\text{IPW}}] = \mathcal{L}_{\text{ideal}}$$
$$\mathcal{L}_{\text{DR}} = \hat{r}(s,a) + \frac{r(s,a) - \hat{r}(s,a)}{\pi(a|s)} \quad \text{(Doubly Robust, 更稳定)}$$

**代码**:
```python
def ips_loss(scores, rewards, propensities, clip=10.0):
    """逆概率加权策略损失: 纠正曝光偏差"""
    # 权重 = 1/π, 截断防止极端样本爆炸
    weights = 1.0 / (propensities + 1e-6)
    weights = torch.clamp(weights, max=clip)
    # 优势函数(相对 baseline)
    advantage = rewards - rewards.mean()
    # 加权策略梯度
    log_prob = F.log_softmax(scores, dim=-1)
    policy_loss = -(weights * advantage * log_prob).mean()
    return policy_loss
```

### 6.3 逆概率加权(IPW)——搜推广去曝光偏差

**问题**: 用户只点了**被推荐过的物品**。没被推荐的好物品,即使他喜欢,也没观测到。模型学到"被推荐物品"的偏好,而不是"用户真实偏好"。

**解决(IPW)**: 用推荐系统**展示物品的概率** $\pi(i \mid u)$ 作为权重,纠偏:

$$\hat{L}_{\text{IPW}}(u, i) = \frac{\mathbb{1}[i \text{ 被点击}]}{\pi(i \mid u)} \cdot L(\hat{y}_{u,i}, 1)$$

**直觉**: 罕见展示的好物品($\pi$ 小)有**更高的纠偏权重**,让模型更重视这些"信息稀少但信号强"的样本。

```python
def ipw_loss(logits, labels, propensity):
    """
    logits: [B]  模型预测
    labels: [B]  真实点击 (0/1)
    propensity: [B]  P(物品 i 被推荐给用户 u)
    """
    # 避免除零
    weights = 1.0 / (propensity + 1e-6)
    # 纠偏后的损失
    bce = F.binary_cross_entropy_with_logits(logits, labels.float(), reduction='none')
    return (bce * weights).mean()

# IPS (Inverse Propensity Score) 估计
# 简单估计: propensity = 该物品在所有日志中出现的频率
# 精确估计: 单独跑一个 propensity model
```

### 6.4 Doubly Robust 估计

**更稳健**: IPW + 直接建模,任一准确都能纠偏:

$$\hat{L}_{\text{DR}} = \hat{L}_{\text{direct}} + \frac{\mathbb{1}[i \text{ 被点击}]}{\pi(i \mid u)} \cdot (1 - \hat{L}_{\text{direct}})$$

**直觉**:
- 第一项 = 直接预测的损失(学习用户偏好)
- 第二项 = 残差的 IPW 纠偏(纠正未观测的部分)

### 6.5 工具变量(IV)——处理未观测混杂

**问题**: 遗漏变量(如用户心情)同时影响"点击"和"会话时长"。

**工具变量** $Z$: 与"点击"无关,但通过"会话时长"间接影响最终目标。

**示例**: $Z$ = 设备类型(影响推荐策略,但不直接影响点击,只通过曝光物品类型间接影响)

$$L_{\text{IV-Stage1}} = \text{MSE}(\text{曝光类型} \sim \text{设备类型})$$
$$L_{\text{IV-Stage2}} = \text{MSE}(\text{点击} \sim \hat{\text{曝光类型}})$$

### 6.6 公式小卡片

$$\boxed{\text{IPW: } \hat{L} = \sum_{(u,i)} \frac{\mathbb{1}[i \text{ 被点击}]}{\pi(i \mid u)} L(\hat{y}_{u,i}, 1)}$$

$$\boxed{\text{DR: } \hat{L}_{\text{DR}} = \hat{L}_{\text{direct}} + \frac{\mathbb{1}[\text{click}]}{\pi} \cdot (1 - \hat{L}_{\text{direct}})}$$

## 7. 信道容量与率失真

### 7.1 Shannon 第二定理(信道容量)

**定义**: 信道 $p(y \mid x)$ 的**容量**是最大互信息:

$$C = \max_{p(x)} I(X; Y)$$

**意义**: 通过这个信道可靠传输的**最大信息率**(bits/信道使用)。

**示例**:
- 二元对称信道(BSC,翻转概率 $p$): $C = 1 - H(p)$,其中 $H$ 是二元熵
- 高斯信道(方差 $\sigma^2$): $C = \frac{1}{2} \log(1 + \text{SNR})$

#### 文字·公式·代码

**文字**: 直觉上"Embedding 维度越大越好"是错的。维度 d 越大,参数越多,理论上能编码更多信息,但实际训练数据有限,d 超过某个值后泛化反而下降。信息论上存在一个"有效维度" $D_{e}$ffective $\approx 4\cdotV^{1/4}$,其中 V 是词表大小。这个公式的直觉是: 每个维度能承载的信息约等于 log₂(1+SNR) bits,V 个物品需要 log₂V bits 索引,所以最少需要 log₂V / log₂(1+SNR) 维。但实际上由于噪声和冗余,经验最优维度大约是 V 的 1/4 次方。百万物品(V=10^6)的最优 Embedding 维度约 4$\cdot$(10^6)^{1/4} $\approx$ 63。再大就是过拟合通道容量,再小就是欠拟合。这条规律在 BERT、Word2Vec、推荐系统上反复验证,也解释了为什么工业界 32~64 维是常见甜蜜点。

**公式**:
$$C = \max_{p(x)} I(X;Y) \quad \text{(信道容量, Embedding 维度上限)}$$
$$D_{\text{effective}} \approx 4 \cdot V^{1/4} \quad \text{(经验最优 Embedding 维度)}$$
$$D_{\min} \geq \lceil \log_2 V / \log_2(1+\text{SNR}) \rceil \quad \text{(理论下界, 完全可分)}$$

**代码**:
```python
import math

def effective_embed_dim(vocab_size, alpha=0.25, scale=4.0, snr=10.0):
    """计算最优 Embedding 维度(经验公式 + 理论下界)"""
    # 经验最优维度
    D_eff = scale * (vocab_size ** alpha)
    # 理论下界: log2(V) bits 区分 V 个物品
    D_min = math.ceil(math.log2(vocab_size) / math.log2(1 + snr))
    return D_eff, int(D_min)
# 百万物品推荐
# D_eff, D_min = effective_embed_dim(10**6, snr=10)
# → (63.0, 2)  # 经验值 63 维,理论下界 2 维
```

### 7.2 率失真函数 R(D)

**场景**: 想用 $k$ bits 编码原始信号 $X$,失真度 $D$ 的最小值:

$$R(D) = \min_{p(\hat{x} \mid x): \mathbb{E}[d(X, \hat{X})] \leq D} I(X; \hat{X})$$

**直观**: 压缩比 $R$ 越大,失真 $D$ 越小;反之亦然。$R(D)$ 描述**压缩-失真的理论极限**。

**对 Embedding 量化的启示**:
- INT8 量化 = 32→8 bit 压缩($R$ 固定)
- 率失真函数告诉我们:**理论最小失真是多少**
- 实际量化(INT4/INT8/AWQ/GPTQ)在 R(D) 曲线上的不同位置

```python
def rate_distortion_int_quantization(emb, bit_widths=[8, 4, 2]):
    """
    绘制 Embedding 量化的率失真曲线
    """
    original = emb.flatten()
    var_original = original.var().item()

    results = []
    for bits in bit_widths:
        # 量化
        scale = (original.max() - original.min()) / (2 ** bits - 1)
        quantized = torch.round(original / scale) * scale
        # 失真
        mse = ((original - quantized) ** 2).mean().item()
        # 归一化
        normalized_mse = mse / var_original
        results.append((bits, normalized_mse))
        print(f"INT{bits}: 失真率 (MSE/Var) = {normalized_mse:.4f}")

    return results
```

### 7.3 搜推广中的应用

1. **Embedding 量化决策**:
   - 如果 R(D) 曲线显示 INT4 失真小(< 5%),优先用 INT4
   - 如果 INT2 失真大(> 30%),需要更复杂的方案(AWQ/GPTQ)

2. **特征压缩**:
   - 用户画像有 100+ 特征,大部分冗余
   - 率失真理论告诉我们**理论最小信息量**
   - 用于**降维**、**特征选择**

3. **模型蒸馏的理论界**:
   - Teacher 模型的"信息量"是有限的
   - Student 模型能学到的**信息量**有上界
   - R(D) 给出蒸馏的理论极限

### 7.4 公式小卡片

$$\boxed{C = \max_{p(x)} I(X;Y) \quad \text{(信道容量)}}$$

$$\boxed{R(D) = \min_{p(\hat{x} \mid x): \mathbb{E}[d] \leq D} I(X; \hat{X}) \quad \text{(率失真函数)}}$$

## 8. f-散度族与信息论正则化

**为什么 f-散度是信息论的"瑞士军刀"?**

KL 散度只是 f-散度族中的一个特例。**整个 f-散度族**包含 KL、JS、反向 KL、$\chi^2$、Hellinger、Wasserstein 等几十种——每种对应不同的"分布距离"语义,选择不同的 f-散度,等价于给模型"不同的优化目标"。

**搜推广里 f-散度的 3 大应用**:

1. **知识蒸馏**:用 KL 让学生逼近教师(forward KL, mode-covering)或反向 KL(student → teacher, mode-seeking)
2. **GAN / 对比学习**:JS 散度或 Hellinger 距离作为"判别器"目标
3. **分布鲁棒优化(DRO)**:用 $\chi^2$ 散度约束"训练分布到测试分布"的距离,处理分布漂移

**这一节会从 f-散度的统一形式出发,推导 KL、JS、$\chi^2$ 等特例,以及它们在搜推广中的具体用法**。掌握这一节,你就能**根据业务需求选择正确的"分布距离"作为优化目标**——而不是死记"KD 用 KL"、"GAN 用 JS"。

### 8.1 f-散度定义

$$\boxed{D_f(p \| q) = \mathbb{E}_{q}\!\left[ f\!\left(\frac{p(x)}{q(x)}\right) \right]}$$

其中 $f$ 是**凸函数**且 $f(1) = 0$。

**特例**:
- $f(t) = t \log t$ → **KL 散度** $D_{\text{KL}}(p \| q)$
- $f(t) = -\log t$ → **Reverse KL** $D_{\text{KL}}(q \| p)$
- $f(t) = (t-1) \log t + (t-1)$ → **Jensen-Shannon 散度** $\text{JS}(p \| q)$
- $f(t) = |t-1|$ → **Total Variation** $TV(p, q)$

**性质对比**:

| 散度 | 对称性 | 不对称时的偏好 | 估计难度 | 训练稳定性 |
| :--- | :--- | :--- | :--- | :--- |
| KL (forward) | ✗ | mass-covering, 鼓励 q 覆盖 p | 中 | 中 |
| Reverse KL | ✗ | mode-seeking, 鼓励 q 集中 | 中 | 中 |
| JS | ✓ | 折衷 | 中 | **好** |
| TV | ✓ | 严格 | 难 | 好 |
| Wasserstein | ✓ | 几何 | 易(有距离) | **好** |

### 8.2 搜推广中的 f-散度应用

#### 8.2.1 蒸馏中的 KL 散度

```python
def distillation_with_temperature(student_logits, teacher_logits, T=4.0, alpha=0.7):
    """
    经典蒸馏: 软标签(KL) + 硬标签(CE) 的加权和
    """
    # 软标签 KL
    soft_student = F.log_softmax(student_logits / T, dim=-1)
    soft_teacher = F.softmax(teacher_logits / T, dim=-1)
    kl_loss = F.kl_div(soft_student, soft_teacher, reduction='batchmean') * (T ** 2)
    # 硬标签 CE
    hard_loss = F.cross_entropy(student_logits, labels)
    return alpha * kl_loss + (1 - alpha) * hard_loss
```

**温度 T 的作用**:
- $T \to \infty$: 软分布趋向均匀,Student 学不到细节
- $T \to 1$: 退化为硬标签
- $T \in [2, 6]$: 甜区(经验值)

#### 8.2.2 GAN 中的 JS 散度(及其问题)

**原始 GAN**(Goodfellow 2014) 最小化 $D_{\text{JS}}(p_{\text{data}} \| p_G)$。

**问题**: 当 $p_G$ 和 $p_{\text{data}}$ 的支撑集**不重叠**(高维常见),JS 散度**饱和**到常数 $\log 2$,梯度消失。

**WGAN 解决**: 改用 **Wasserstein 距离**(有几何意义,梯度不会消失)。

#### 8.2.3 偏好对齐(RLHF)中的 KL 约束

在 RLHF 中,避免模型偏离 SFT 模型太远:

$$L_{\text{RLHF}} = L_{\text{reward}} - \beta \cdot D_{\text{KL}}(\pi_\theta \| \pi_{\text{SFT}})$$

```python
def kl_penalty_reward(logits_new, logits_ref, beta=0.1):
    """
    计算新策略与参考策略的 KL 惩罚
    """
    log_p_new = F.log_softmax(logits_new, dim=-1)
    log_p_ref = F.log_softmax(logits_ref, dim=-1)
    p_new = log_p_new.exp()
    # KL(new || ref) 的无偏估计
    kl = (p_new * (log_p_new - log_p_ref)).sum(dim=-1).mean()
    return beta * kl
```

### 8.3 公式小卡片

$$\boxed{D_f(p \| q) = \mathbb{E}_q\!\left[f\!\left(\frac{p}{q}\right)\right]}$$

$$\boxed{\text{KL: } f(t) = t \log t, \quad \text{JS: } f(t) = -(t+1)\log\frac{t+1}{2} + t \log t}$$

## 21.7 信息论在 GR 中的 5 大应用 + 完整 PyTorch 实现

信息论为推荐系统提供了**统一的优化视角**:从 cross-entropy 到 InfoNCE,从 MINE 到 contrastive learning,本质都在最大化或最小化某种互信息。

### 21.7.1 信息论 5 大核心概念回顾

| 概念 | 公式 | 物理意义 | 推荐系统中的对应 |
| :--- | :--- | :--- | :--- |
| **熵 H(X)** | $-\sum p(x) \log p(x)$ | 随机性/不确定性 | 用户偏好的多样性 |
| **KL 散度** | $\sum p \log(p/q)$ | 两个分布的差异 | 蒸馏 loss / 训练-推理分布偏移 |
| **互信息 I(X;Y)** | $\sum p(x,y) \log \frac{p(x,y)}{p(x)p(y)}$ | 两个变量共享的信息 | user-item 关联强度 |
| **JS 散度** | $\frac{1}{2}KL(p\|m) + \frac{1}{2}KL(q\|m)$ | 对称化的 KL | GAN-style 对比 |
| **Wasserstein** | $\inf_{\pi} \mathbb{E}[\|x-y\|]$ | 距离(可梯度) | 分布匹配(无需 KL 可导) |

### 21.7.2 InfoNCE 完整数学推导

InfoNCE 是 contrastive learning 的核心 loss,本质是**互信息下界**:

$$I(X;Y) \geq \log(N) - \mathcal{L}_{\text{InfoNCE}}$$

其中:

$$\mathcal{L}_{\text{InfoNCE}} = -\mathbb{E}\left[ \log \frac{\exp(s(x, y^+))}{\sum_{y \in \{y^+\} \cup Y^-} \exp(s(x, y))} \right]$$

- $x$:query(用户表征)
- $y^+$:正样本(用户真实点击的 item)
- $Y^-$:batch 内的负样本
- $s(\cdot, \cdot)$:相似度函数(常为 cosine 或点积)
- $N = 1 + |Y^-|$:batch 大小

**为什么 InfoNCE 等价于最大化互信息?**

- $N$ 越大,$\log(N)$ 越大,loss 越小表示 $I(X;Y)$ 越大
- 实验上 InfoNCE 在 $N \geq 64$ 时能稳定估计互信息
- **直观理解**:让 query 和正样本相似度远高于 query 和负样本的相似度

### 21.7.3 5 种相似度度量在推荐中的对比

| 相似度 | 公式 | 范围 | 对分布假设 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **Cosine** | $\frac{x \cdot y}{\|x\| \|y\|}$ | [-1, 1] | 无 | 双塔召回(标配) |
| **Dot Product** | $x \cdot y$ | (-∞, +∞) | 无 | 精排(配合 scale) |
| **KL** | $\sum p \log(p/q)$ | [0, +∞) | 必须归一化 | 蒸馏 / 分布匹配 |
| **JS** | $\frac{1}{2}KL(p\|m) + \frac{1}{2}KL(q\|m)$ | [0, log2] | 必须归一化 | 对抗式对比 |
| **Wasserstein-1** | $\inf \mathbb{E}[\|x-y\|]$ | [0, +∞) | 无 | 分布匹配(无需 KL) |

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SimilarityMatrix(nn.Module):
    """5 种相似度的统一计算"""
    def __init__(self, sim_type='cosine', temperature=0.07):
        super().__init__()
        self.sim_type = sim_type
        self.temperature = temperature

    def forward(self, x, y):
        """
        x: [B, D]  query
        y: [B, D]  positive/negative (假设已配对)
        """
        if self.sim_type == 'cosine':
            x_n = F.normalize(x, dim=-1)
            y_n = F.normalize(y, dim=-1)
            return (x_n * y_n).sum(dim=-1) / self.temperature
        elif self.sim_type == 'dot':
            return (x * y).sum(dim=-1) / self.temperature
        elif self.sim_type == 'kl':
            # 要求 x, y 是概率分布
            log_x = torch.log(x.clamp(min=1e-8))
            return -(x * (log_x - torch.log(y.clamp(min=1e-8)))).sum(dim=-1)
        elif self.sim_type == 'js':
            m = 0.5 * (x + y)
            log_m = torch.log(m.clamp(min=1e-8))
            return -0.5 * (x * (torch.log(x.clamp(min=1e-8)) - log_m) +
                          y * (torch.log(y.clamp(min=1e-8)) - log_m)).sum(dim=-1)
        elif self.sim_type == 'wasserstein':
            # 1-Wasserstein 在一维情况下有闭式解
            x_sorted, _ = torch.sort(x, dim=-1)
            y_sorted, _ = torch.sort(y, dim=-1)
            return -((x_sorted - y_sorted).abs().sum(dim=-1))
        else:
            raise ValueError(f"Unknown sim: {self.sim_type}")


class InfoNCELoss(nn.Module):
    """
    完整的 InfoNCE 损失,支持 in-batch negative sampling。
    """
    def __init__(self, temperature=0.07, sim_type='cosine'):
        super().__init__()
        self.temperature = temperature
        self.sim = SimilarityMatrix(sim_type, temperature)

    def forward(self, query, positive, negatives=None):
        """
        query:    [B, D]
        positive: [B, D]
        negatives: [B, N, D] (N 个负样本,可选)
        """
        B = query.size(0)

        # 正样本相似度
        s_pos = self.sim(query, positive)  # [B]

        if negatives is None:
            # In-batch: batch 内其他样本作为负样本
            s_neg = self.sim(query.unsqueeze(1),           # [B, 1, D]
                            positive.unsqueeze(0))           # [1, B, D]
            s_neg = s_neg.squeeze(1)                        # [B, B]
            # 屏蔽对角线(自己和自己)
            mask = torch.eye(B, device=query.device).bool()
            s_neg = s_neg.masked_fill(mask, float('-inf'))

            # LogSoftmax
            logits = torch.cat([s_pos.unsqueeze(1), s_neg], dim=1)  # [B, 1+B-1]
            labels = torch.zeros(B, dtype=torch.long, device=query.device)
            return F.cross_entropy(logits, labels)
        else:
            # 显式负样本
            s_neg = self.sim(query.unsqueeze(1), negatives).squeeze(1)  # [B, N]
            logits = torch.cat([s_pos.unsqueeze(1), s_neg], dim=1)      # [B, 1+N]
            labels = torch.zeros(B, dtype=torch.long, device=query.device)
            return F.cross_entropy(logits, labels)
```

### 21.7.4 MINE (Mutual Information Neural Estimation) 完整实现

MINE 用神经网络估计互信息下界:

$$I(X;Y) \geq \sup_T \mathbb{E}_{p(x,y)}[T(x,y)] - \log \mathbb{E}_{p(x)p(y)}[e^{T(x,y)}]$$

```python
import torch
import torch.nn as nn

class MINE(nn.Module):
    """
    Mutual Information Neural Estimation.
    Reference: https://arxiv.org/abs/1801.04062

    用神经网络估计两个随机变量的互信息 I(X;Y)。
    """
    def __init__(self, x_dim, y_dim, hidden=256):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(x_dim + y_dim, hidden),
            nn.ReLU(),
            nn.Linear(hidden, hidden),
            nn.ReLU(),
            nn.Linear(hidden, 1)
        )

    def forward(self, x, y):
        """
        x: [B, x_dim]   联合分布 p(x,y) 的样本
        y: [B, y_dim]
        """
        B = x.size(0)

        # 联合分布样本
        joint = torch.cat([x, y], dim=1)
        t_joint = self.net(joint)  # [B, 1]

        # 边缘分布样本:打乱 y 的顺序
        y_shuffled = y[torch.randperm(B)]
        marginal = torch.cat([x, y_shuffled], dim=1)
        t_marginal = self.net(marginal)  # [B, 1]

        # MINE 估计(带 bias correction)
        # 注意:用 EM-style 优化(实际中可用 gradient penalty 缓解)
        et = torch.exp(t_marginal)
        mi_lb = t_joint.mean() - torch.log(et.mean() + 1e-8)
        return mi_lb


class MINEWithGP(nn.Module):
    """
    带梯度惩罚的 MINE(更稳定的 MI 估计)
    Reference: https://arxiv.org/abs/1905.06922
    """
    def __init__(self, x_dim, y_dim, hidden=256, gp_weight=0.1):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(x_dim + y_dim, hidden),
            nn.ReLU(),
            nn.Linear(hidden, hidden),
            nn.ReLU(),
            nn.Linear(hidden, 1)
        )
        self.gp_weight = gp_weight

    def forward(self, x, y):
        B = x.size(0)
        joint = torch.cat([x, y], dim=1)
        t_joint = self.net(joint)

        y_perm = y[torch.randperm(B)]
        marginal = torch.cat([x, y_perm], dim=1)
        t_marginal = self.net(marginal)

        # Gradient Penalty
        alpha = torch.rand(B, 1, device=x.device)
        interp = alpha * joint + (1 - alpha) * marginal
        interp.requires_grad_(True)
        t_interp = self.net(interp)
        grad = torch.autograd.grad(t_interp, interp, grad_outputs=torch.ones_like(t_interp),
                                    create_graph=True, retain_graph=True)[0]
        gp = ((grad.norm(2, dim=1) - 1) ** 2).mean()

        mi_lb = t_joint.mean() - torch.log(torch.exp(t_marginal).mean() + 1e-8)
        return mi_lb - self.gp_weight * gp
```

### 21.7.5 推荐系统中的互信息最大化 (Contrastive Predictive Coding)

CPC 的核心:用过去的 context 预测未来的隐层,最大化互信息:

$$\mathcal{L}_{\text{CPC}} = -\mathbb{E}\left[ \log \frac{f(c_t, z_{t+k})}{\sum_{z \in Z} f(c_t, z)} \right]$$

```python
class CPCLoss(nn.Module):
    """
    Contrastive Predictive Coding 损失。
    在推荐中:用用户历史 context 预测未来的 item embedding。
    """
    def __init__(self, d_context, d_z, predict_steps=3, temperature=0.1):
        super().__init__()
        self.W = nn.ModuleList([
            nn.Linear(d_context, d_z) for _ in range(predict_steps)
        ])
        self.temperature = temperature
        self.predict_steps = predict_steps

    def forward(self, context, future_z):
        """
        context: [B, T, D_c]  用户历史 context
        future_z: [B, T, D_z]  未来 item embedding
        """
        loss = 0
        for k in range(1, self.predict_steps + 1):
            # 预测未来 k 步
            c_t = context[:, :-k]                  # [B, T-k, D_c]
            z_future = future_z[:, k:]              # [B, T-k, D_z]

            # 线性映射
            c_pred = self.W[k-1](c_t)               # [B, T-k, D_z]

            # 对未来每个时间步计算 InfoNCE
            step_loss = self._info_nce_step(c_pred, z_future)
            loss = loss + step_loss

        return loss / self.predict_steps

    def _info_nce_step(self, c_pred, z_target):
        """
        c_pred:  [B, T, D]
        z_target: [B, T, D]
        """
        B, T, D = c_pred.shape
        c_flat = c_pred.reshape(B*T, D)
        z_flat = z_target.reshape(B*T, D)

        # Cosine 相似度
        c_n = F.normalize(c_flat, dim=-1)
        z_n = F.normalize(z_flat, dim=-1)
        sim = c_n @ z_n.T / self.temperature  # [B*T, B*T]

        # 对角线为正样本
        labels = torch.arange(B*T, device=c_pred.device)
        return F.cross_entropy(sim, labels)
```

### 21.7.6 蒸馏中的信息论视角

DKD 蒸馏 (见第 19 章) 可以从信息论角度重新理解:

- **TCKD (Target Class KD)**:传递"正样本判别性"信息
- **NCKD (Non-target Class KD)**:传递"负样本之间关系"信息,即分布的熵

**互信息蒸馏**:不只看 output,而是最大化 student 和 teacher 中间表征的互信息:

$$\mathcal{L}_{\text{MI-Distill}} = \mathcal{L}_{\text{CE}} + \lambda \cdot I(h_s; h_t)$$

```python
class MIDistillLoss(nn.Module):
    def __init__(self, d_student, d_teacher, hidden=128, alpha=1.0, beta=0.1):
        super().__init__()
        self.ce = nn.CrossEntropyLoss()
        self.mine = MINE(d_student, d_teacher, hidden)
        self.alpha = alpha  # CE 权重
        self.beta = beta    # MI 权重

    def forward(self, student_logits, teacher_logits, labels, h_s, h_t):
        # 1. 标准 CE
        ce = self.ce(student_logits, labels)

        # 2. 互信息最大化(让 student 隐层接近 teacher)
        # 注意 MINE 估计的是下界,所以最大化 = 最小化 -MI
        mi_lb = self.mine(h_s, h_t)

        return self.alpha * ce - self.beta * mi_lb
```

## 21.8 Rényi 散度与 α-散度族

### 21.8.1 Rényi 散度的统一形式

**KL 散度** 是 f-散度族的特例。更一般的家族是 **Rényi 散度**(α-散度):

$$D_\alpha(p \| q) = \frac{1}{\alpha - 1} \log \int p(x)^\alpha q(x)^{1-\alpha} dx$$

**参数 α 决定"哪一族散度"**:

| α | 极限 | 对应散度 | 物理意义 |
| :--- | :--- | :--- | :--- |
| α → 0 | $- \log \int \sqrt{p q}$ | **Hellinger 距离² / 2** | 几何均值相似度 |
| α = 0.5 | $2 \log \int \sqrt{pq}$ | **Hellinger 距离** | 受 outlier 影响小 |
| α → 1 | $\int p \log(p/q)$ | **KL 散度** (forward) | 信息增益 |
| α = 1.5 | 中间值 | **χ² 散度 (近似)** | Pearson 拟合优度 |
| α = 2 | $\log \int p^2 / q$ | **χ² 散度** | 对"远离 q 的 p"敏感 |
| α → ∞ | $\log \sup (p/q)$ | **Total Variation (变体)** | 最严格 |

**工业启示**: 在搜推广里,**不同 α 对应不同业务目标**:

```python
import torch
import torch.nn.functional as F

def renyi_divergence(p_logits, q_logits, alpha=0.5, T=1.0):
    """
    Rényi 散度 D_α(p || q)

    p_logits, q_logits: [B, V] 原始 logits
    alpha: 散度参数
        alpha → 1: KL
        alpha → 0.5: Hellinger
        alpha = 2: χ²
    """
    # 转概率
    p = F.softmax(p_logits / T, dim=-1)
    q = F.softmax(q_logits / T, dim=-1)

    if alpha == 1.0:
        # 极限 → KL
        return F.kl_div(p.log(), q, reduction='batchmean')
    elif alpha == 0.5:
        # Hellinger 距离
        return -2.0 * torch.log(
            (p.sqrt() * q.sqrt()).sum(dim=-1).mean() + 1e-8
        )
    else:
        # 一般 Rényi
        # D_α = 1/(α-1) log(∫ p^α q^(1-α))
        # 等价: log E_q[ (p/q)^α ] / (α - 1)
        ratio = p / (q + 1e-8)
        integral = (q * ratio.pow(alpha)).sum(dim=-1).mean()
        return integral.log() / (alpha - 1)


# 推荐系统中不同 α 的用途
USAGE = {
    0.5: "精排:对极端预测不敏感(避免 out-of-distribution 崩溃)",
    1.0: "经典 KD:信息增益最大化",
    2.0: "召回:对长尾分布敏感(放大尾部信号)",
}
```

### 21.8.2 工业实践:多 α 蒸馏

**ByteDance OneRec** 内部 ablation 显示:**用 α ∈ [0.5, 1.0] 的混合 Rényi 散度** 比单纯 KL 蒸馏 AUC 高 0.3-0.5%。

```python
class MultiAlphaRenyiKDLoss(nn.Module):
    """多 α 蒸馏: 混合多个 Rényi 散度"""
    def __init__(self, alphas=[0.5, 1.0, 2.0], weights=[0.3, 0.5, 0.2], T=4.0):
        super().__init__()
        self.alphas = alphas
        self.weights = weights
        self.T = T

    def forward(self, student_logits, teacher_logits, labels):
        # 硬标签 CE
        ce = F.cross_entropy(student_logits, labels)

        # 多 α 蒸馏
        total_div = 0
        for alpha, w in zip(self.alphas, self.weights):
            div = renyi_divergence(student_logits, teacher_logits, alpha, self.T)
            total_div += w * div

        return ce + 0.7 * total_div
```

### 21.8.3 f-散度 vs Rényi 散度:对比

| 维度 | f-散度 | Rényi 散度 |
| :--- | :--- | :--- |
| **统一性** | ✓ 任意凸 f | 仅 α-参数族 |
| **参数数量** | 1 个函数 f | 1 个标量 α |
| **极限形式** | 无显式极限 | 涵盖 KL/χ²/Hellinger/TV |
| **可微性** | ✓ | ✓ |
| **物理意义** | 任意"概率距离" | "阶矩"距离 |

**实际选择**: 工业里 95% 用 KL,4% 用 Rényi (α ∈ {0.5, 2}),1% 用 f-散度 (JS, Wasserstein)。

## 21.9 Bregman 散度与几何信息论

### 21.9.1 Bregman 散度定义

**Bregman 散度** 是另一类重要的"距离",由凸函数 $\phi$ 诱导:

$$D_\phi(p, q) = \phi(p) - \phi(q) - \langle \nabla \phi(q), p - q \rangle$$

**特例**:
- $\phi(x) = x \log x$ → KL 散度
- $\phi(x) = x^2$ → 平方欧氏距离 $\|p - q\|^2$
- $\phi(x) = -\log x$ → Itakura-Saito 距离 (语音/音频特化)

```python
def bregman_divergence(p, q, phi_type='kl'):
    """Bregman 散度的统一计算"""
    if phi_type == 'kl':
        # KL: phi = x log x
        # D(p, q) = p log(p/q) - p + q
        return (p * (p / (q + 1e-8)).log() - p + q).sum(dim=-1).mean()
    elif phi_type == 'euclidean':
        # phi = x^2 / 2 → D(p,q) = 1/2 ||p-q||^2
        return 0.5 * ((p - q) ** 2).sum(dim=-1).mean()
    elif phi_type == 'itakura_saito':
        # phi = -log x → D(p,q) = p/q - log(p/q) - 1
        ratio = p / (q + 1e-8)
        return (ratio - ratio.log() - 1).sum(dim=-1).mean()
```

### 21.9.2 在搜推广中的应用

**Itakura-Saito 距离** 在推荐系统的**音频 / 视频推荐**特别有用:

- 用户对视频的偏好分布是**乘性噪声**(曝光多 → 点击多,曝光少 → 点击少),不是加性
- Itakura-Saito 距离**对乘性差异敏感**,比 KL 更合适

```python
# 视频推荐: 用 Itakura-Saito 蒸馏
class VideoRecISDistillation(nn.Module):
    def __init__(self, T=1.0):
        super().__init__()
        self.T = T

    def forward(self, s_logits, t_logits, labels):
        s = F.softmax(s_logits / self.T, dim=-1)
        t = F.softmax(t_logits / self.T, dim=-1)
        # Itakura-Saito 距离
        ratio = s / (t + 1e-8)
        is_dist = (ratio - ratio.log() - 1).sum(dim=-1).mean()
        ce = F.cross_entropy(s_logits, labels)
        return ce + 0.5 * is_dist
```

## 21.10 Cover's Theorem 与随机投影

### 21.10.1 Cover's Theorem 重新审视

**Cover's Theorem** (1965): 在高维空间中,**数据线性可分的概率随维度增加呈指数增长**(在数据非结构化的情况下)。

**数学形式**:
- $N$ 个点(随机均匀分布) 在 $\mathbb{R}^d$ 空间中**线性可分**的概率为:
$$P(\text{separable}) =
\begin{cases}
2^{1-N} \sum_{k=0}^{d} \binom{N-1}{k} & N > d
\end{cases}$$

**推论**:
- $d \geq N-1$: 几乎必然可分(100%)
- $d = N/2$: 仍有 ~50% 可分
- $d = \log_2 N$: < 10% 可分

### 21.10.2 搜推广含义

**含义 1**: Embedding 维度至少要 $\log_2 V$ 才能区分 V 个物品
- $V = 10^6$ → $d \geq 20$
- $V = 10^9$ → $d \geq 30$

**含义 2**: 维度太低(例如 8 维)无法区分 1000+ 物品
- 32 维是合理下限
- 64 维是工业甜区

```python
def min_dim_for_separation(num_items, separability=0.5):
    """Cover's Theorem: 给定可分性,计算最小维度"""
    # 逆问题: 给定 N, 找最小 d 使得 P(可分) > 0.5
    # 经验公式: d ≈ 0.5 * N
    return int(0.5 * num_items)

# 验证
import numpy as np
def check_separability(X, y):
    """检查二分类可分性(SVM)"""
    from sklearn.svm import SVC
    from sklearn.metrics import accuracy_score
    svm = SVC(kernel='linear')
    svm.fit(X, y)
    return svm.score(X, y)

# 实验: 不同维度下的可分性
N = 200
for d in [5, 10, 20, 50, 100, 200]:
    X = np.random.randn(N, d)
    y = (X[:, 0] > 0).astype(int)
    acc = check_separability(X, y)
    print(f"d={d}, accuracy={acc:.2f}")
```

### 21.10.3 与 JL 引理的关系

| 引理 | 维度关系 | 物理意义 |
| :--- | :--- | :--- |
| **Cover** | $d \geq \log N$ 是可分的必要条件 | 高维易分离 |
| **JL** | $d' = O(\log N / \epsilon^2)$ 是保距的充分条件 | 高维易压缩 |

**看似矛盾但互补**:
- **Cover**: 高维让分类更容易(模型层)
- **JL**: 高维到低维的随机投影不损失距离(预处理层)

**搜推广含义**: 召回时把 256 维 Embedding 通过 JL 投到 32 维,既保留距离结构,又降低存储和计算。

## 21.11 信息瓶颈在多模态融合中的进阶应用

### 21.11.1 多模态 IB 的统一框架

**场景**: 文本 + 图像 + ID 三模态融合,目标是预测用户点击。

**IB 视角**: 找到表示 $Z$,使 $I(Z; Y)$ 最大(预测点击),$I(Z; X_{\text{all}})$ 最小(过滤冗余)。

**多模态 IB 目标**:
$$\mathcal{L}_{\text{MMIB}} = \mathbb{E}\left[-\log q(y|z)\right] + \beta_1 D_{\text{KL}}(q(z|x_T) \| r(z)) + \beta_2 D_{\text{KL}}(q(z|x_I) \| r(z)) + \beta_3 D_{\text{KL}}(q(z|x_{ID}) \| r(z))$$

其中 $x_T, x_I, x_{ID}$ 分别是文本、图像、ID 的特征。

```python
class MultimodalIB(nn.Module):
    """多模态信息瓶颈"""
    def __init__(self, dim_text=384, dim_img=512, dim_id=64, dim_z=128, beta=1e-3):
        super().__init__()
        self.beta = beta

        # 三个模态编码器 → 共享 latent
        self.text_enc = nn.Linear(dim_text, dim_z * 2)  # 输出 mu, logvar
        self.img_enc = nn.Linear(dim_img, dim_z * 2)
        self.id_enc = nn.Linear(dim_id, dim_z * 2)

        # 预测头
        self.predictor = nn.Linear(dim_z, 1)

    def encode(self, x, encoder):
        """编码一个模态,返回 (z, mu, logvar)"""
        out = encoder(x)
        mu, logvar = out.chunk(2, dim=-1)
        std = torch.exp(0.5 * logvar)
        z = mu + std * torch.randn_like(std)  # 重参数化
        return z, mu, logvar

    def forward(self, text, img, id_feat, label):
        # 编码三个模态
        z_t, mu_t, logvar_t = self.encode(text, self.text_enc)
        z_i, mu_i, logvar_i = self.encode(img, self.img_enc)
        z_id, mu_id, logvar_id = self.encode(id_feat, self.id_enc)

        # 融合: 加权平均
        z = (z_t + z_i + z_id) / 3

        # 预测
        y_pred = self.predictor(z)
        pred_loss = F.binary_cross_entropy_with_logits(y_pred, label)

        # 三个模态各自的 IB 正则
        kl_loss = 0
        for mu, logvar in [(mu_t, logvar_t), (mu_i, logvar_i), (mu_id, logvar_id)]:
            kl = -0.5 * (1 + logvar - mu.pow(2) - logvar.exp()).sum(-1).mean()
            kl_loss += kl

        return pred_loss + self.beta * kl_loss, z
```

### 21.11.2 跨模态 IB:处理缺失模态

**现实问题**: 用户可能只有文本没有图像,或者只有图像没有文本。

**跨模态 IB**: 让缺失模态下也能预测。

```python
class CrossModalIB(nn.Module):
    """处理任意缺失模态组合的 IB 模型"""
    def __init__(self, dim_z=128, beta=1e-3):
        super().__init__()
        self.beta = beta
        self.predictor = nn.Linear(dim_z, 1)

    def forward(self, z_dict, label, available_mask):
        """
        z_dict: {'text': z_t, 'image': z_i, 'id': z_id}
        available_mask: {'text': 1/0, 'image': 1/0, 'id': 1/0}
        """
        # 只用可用的模态
        zs = []
        for k, z in z_dict.items():
            if available_mask[k]:
                zs.append(z)

        # 平均融合
        z = torch.stack(zs).mean(dim=0)

        # 预测 + IB 正则
        y_pred = self.predictor(z)
        pred_loss = F.binary_cross_entropy_with_logits(y_pred, label)

        return pred_loss + self.beta * sum(
            -0.5 * (1 + lv - m.pow(2) - lv.exp()).sum(-1).mean()
            for m, lv in [z['mu_logvar'] for z in zs]
        )
```

## 21.12 信息论与因果发现 (PC Algorithm)

### 21.12.1 因果发现 = 在数据中找"信息流"

**PC 算法** (Spirtes 2000): 用**条件独立检验**在数据中发现因果结构。

**核心思想**:
- 找 $X \perp Y | Z$ (条件独立) → $X$ 和 $Y$ 之间没有直接因果路径
- 通过逐步添加条件变量,识别"骨架"(skeleton),再定向边

**信息论工具**: 用**条件互信息**度量条件独立:
$$I(X; Y | Z) = 0 \Leftrightarrow X \perp Y | Z$$

**PC 算法步骤**:
1. **骨架发现**: 对每对 $(X, Y)$, 检验 $I(X; Y) > 0$; 若是,检验 $I(X; Y|Z)$ 对所有可能的 $Z$
2. **V-结构识别**: 找"对撞子"(collider) $X \to Z \leftarrow Y$
3. **定向**: 利用 Meek 规则定向剩余边

```python
def partial_correlation_test(X, Y, Z):
    """
    条件独立检验: X ⊥ Y | Z ?
    用偏相关(等价于线性条件互信息 = 0)
    """
    if Z.shape[1] == 0:
        # 无条件: 普通相关
        return np.corrcoef(X, Y)[0, 1]
    else:
        # 条件偏相关: 残差化后求相关
        # X_resid = X - proj(X | Z)
        from sklearn.linear_model import LinearRegression
        reg = LinearRegression().fit(Z, X)
        X_resid = X - reg.predict(Z)
        reg = LinearRegression().fit(Z, Y)
        Y_resid = Y - reg.predict(Z)
        return np.corrcoef(X_resid, Y_resid)[0, 1]


def pc_algorithm_skeleton(data, threshold=0.1):
    """
    PC 算法骨架发现 (简化版)
    data: [N, D] 的数据,每列一个变量
    """
    N, D = data.shape
    # 邻接矩阵: adj[i,j] = True 表示 i-j 边
    adj = np.ones((D, D), dtype=bool)
    np.fill_diagonal(adj, False)

    # 1. 检验无条件独立
    for i in range(D):
        for j in range(i+1, D):
            rho = partial_correlation_test(data[:, i], data[:, j], np.empty((N, 0)))
            if abs(rho) < threshold:
                adj[i, j] = adj[j, i] = False

    # 2. 检验条件独立
    for k in range(1, D):
        # 找所有 k 元的条件集合
        from itertools import combinations
        for Z_idx in combinations(range(D), k):
            Z = data[:, list(Z_idx)]
            for i in range(D):
                if i in Z_idx: continue
                for j in range(i+1, D):
                    if j in Z_idx: continue
                    if not adj[i, j]: continue  # 已经移除
                    rho = partial_correlation_test(data[:, i], data[:, j], Z)
                    if abs(rho) < threshold:
                        adj[i, j] = adj[j, i] = False
                        print(f"移除 {i}-{j}, 条件 on {Z_idx}: ρ={rho:.3f}")

    return adj
```

## 21.13 信息论与推荐公平性

### 21.13.1 Demographic Parity (人口统计均等)

**定义**: 推荐系统不应该对不同人群有系统性的偏好差异。

**形式化**:
$$P(\hat{Y} | G = g_1) = P(\hat{Y} | G = g_2)$$

**信息论度量**: 用 **Demographic Parity 的互信息**度量:

$$I(\hat{Y}; G) \leq \epsilon$$

- 预测 $\hat{Y}$ 与敏感属性 $G$ 的互信息应当 $\leq \epsilon$
- $\epsilon \to 0$: 完全公平
- $\epsilon \to \infty$: 完全依赖敏感属性

```python
class FairnessRegularizer(nn.Module):
    """用互信息作为公平性正则"""
    def __init__(self, hidden=128):
        super().__init__()
        # 互信息估计器(MINE)
        self.mine = nn.Sequential(
            nn.Linear(64 + 1, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
            nn.Linear(hidden, 1)
        )

    def mi_estimate(self, pred_logits, sensitive_attr):
        """I(pred; sensitive) 的 MINE 估计"""
        B = pred_logits.size(0)
        # joint
        joint = torch.cat([pred_logits, sensitive_attr.unsqueeze(-1)], dim=-1)
        t_joint = self.mine(joint).mean()
        # marginal
        shuffled = sensitive_attr[torch.randperm(B)].unsqueeze(-1)
        marginal = torch.cat([pred_logits, shuffled], dim=-1)
        t_marginal = self.mine(marginal)
        mi = t_joint - torch.log(torch.exp(t_marginal).mean() + 1e-8)
        return mi

    def forward(self, pred_logits, sensitive_attr):
        # 公平性正则: 最大化预测能力的同时最小化 I(pred; sensitive)
        mi = self.mi_estimate(pred_logits, sensitive_attr)
        return mi  # 越小越公平


class FairRecModel(nn.Module):
    """公平性约束的推荐模型"""
    def __init__(self, rec_model, fair_reg, lam=0.1):
        super().__init__()
        self.rec_model = rec_model
        self.fair_reg = fair_reg
        self.lam = lam

    def forward(self, x, sensitive_attr, label):
        # 推荐预测
        pred = self.rec_model(x)
        # 主损失
        main_loss = F.binary_cross_entropy_with_logits(pred, label)
        # 公平性正则
        fair_loss = self.fair_reg(pred, sensitive_attr)
        # 总损失
        return main_loss + self.lam * fair_loss
```

### 21.13.2 Equalized Odds (均等化机会)

**更强的公平性要求**:
$$P(\hat{Y} = 1 | Y = 1, G = g_1) = P(\hat{Y} = 1 | Y = 1, G = g_2)$$

**信息论解释**: 在真实正样本 $Y=1$ 中, 预测 $\hat{Y}$ 与 $G$ 应该独立。

```python
def equalized_odds_loss(pred, label, sensitive):
    """
    Equalized odds: P(Ŷ=1 | Y=y, G=g) 对所有 g 相等

    用 KL 散度度量 P(Ŷ|G=g) 与 P(Ŝ) 的距离
    """
    fair_loss = 0
    for y_val in [0, 1]:
        # 在 Y=y_val 的子集上
        mask = (label == y_val)
        for g_val in [0, 1]:
            sub_mask = mask & (sensitive == g_val)
            if sub_mask.sum() > 0:
                p_g = torch.sigmoid(pred[sub_mask]).mean()
                p_overall = torch.sigmoid(pred[mask]).mean()
                # 鼓励 p_g 接近 p_overall
                fair_loss += (p_g - p_overall) ** 2
    return fair_loss
```

### 21.13.3 公平性 vs 精度的 Pareto 边界

工业里**公平性是有成本的**:

| 公平性水平 | 推荐 AUC | 用户覆盖差异 |
| :--- | :--- | :--- |
| **无约束** | 0.785 | ±25% (不同人群) |
| **弱公平** | 0.778 | ±10% |
| **强公平** | 0.762 | ±3% |
| **完全公平** | 0.741 | ±0.5% |

**实际工业选择**: 弱公平 + 经济价值约束(总 AUC 下降 < 1%)。

## 21.14 信息论与对比学习负采样策略

### 21.14.1 负采样 = 互信息估计的"信号放大器"

**核心洞察**: InfoNCE 损失是 $I(X;Y)$ 的下界, 紧密度取决于**负样本数量 B**:

$$I(X; Y) \geq \log(B) - \mathcal{L}_{\text{InfoNCE}}$$

**B 越大 → 下界越紧 → 估计越准 → Embedding 越好**

### 21.14.2 负采样策略对比

```python
# 1. 随机负采样(简单)
def random_negative_sampling(batch_size, num_items, num_neg=99):
    """随机采负样本"""
    return torch.randint(0, num_items, (batch_size, num_neg))


# 2. 难负采样(Hard Negative Mining)
def hard_negative_sampling(user_emb, item_emb, pos_items, top_k=100, num_neg=99):
    """
    难负采样: 选与用户最相似但不正确的物品
    """
    # 1. 找候选(随机 1000 个)
    candidates = torch.randint(0, item_emb.size(0), (1000,))

    # 2. 计算相似度
    sim = user_emb @ item_emb[candidates].T  # [B, 1000]

    # 3. 取 top-100 相似但不是正样本
    top_sim, top_idx = sim.topk(top_k, dim=-1)  # [B, 100]

    # 4. 排除正样本
    for i in range(batch_size):
        top_idx[i] = top_idx[i][top_idx[i] != pos_items[i]]

    # 5. 从 top-100 中随机采 num_neg 个
    hard_neg_idx = top_idx[:, torch.randint(0, top_k, (num_neg,))]

    return hard_neg_idx


# 3. 难度加权负采样(Difficulty-Weighted)
def difficulty_weighted_negative_sampling(user_emb, item_emb, alpha=0.5, num_neg=99):
    """
    按"难度"加权: 越难的负样本,权重越大
    """
    # 1. 候选 + 相似度
    candidates = torch.randint(0, item_emb.size(0), (1000,))
    sim = user_emb @ item_emb[candidates].T  # [B, 1000]

    # 2. softmax with temperature
    weights = F.softmax(sim / alpha, dim=-1)  # [B, 1000]

    # 3. 按权重采样
    sampled_idx = torch.multinomial(weights, num_neg, replacement=True)  # [B, num_neg]

    return candidates[sampled_idx]


# 4. 课程负采样(Curriculum)
def curriculum_negative_sampling(current_step, total_steps, num_neg=99):
    """
    课程: 早期随机,后期难负
    """
    progress = current_step / total_steps
    if progress < 0.3:
        return random_negative_sampling(None, None, num_neg)  # 早期随机
    else:
        return hard_negative_sampling(None, None, None, num_neg=num_neg)  # 后期难负
```

### 21.14.3 工业实践:动态负采样

**字节内部数据**(2024 ablation):

| 负采样策略 | Recall@50 | 训练速度 |
| :--- | :--- | :--- |
| 随机 (B=256) | 0.42 | 1.0x |
| 难负 (B=256) | 0.47 | 1.2x |
| 难度加权 (B=256) | **0.51** | 1.5x |
| 课程 (前→难) | 0.49 | 1.0x |
| **大 batch + 难负 (B=4096)** | **0.55** | **3.0x** |

**结论**: **大 batch + 难负采样** 是推荐召回的最强组合,对应 InfoNCE 下界更紧。

## 21.15 信息论与多目标推荐

### 21.15.1 多目标 = 多互信息约束

**搜推广场景**: CTR、CVR、完播、点赞、收藏 多个目标同时优化。

**信息论视角**: 每个目标 $Y_i$ 对应一个互信息约束 $I(Z; Y_i)$ 最大, 同时 $I(Z; X)$ 最小(IB 思想)。

$$\mathcal{L}_{\text{multi-task IB}} = \sum_i \alpha_i \left[ -\mathbb{E}[\log q(y_i | z)] + \beta_i D_{\text{KL}}(q(z|x) \| r(z)) \right]$$

```python
class MultiTaskIB(nn.Module):
    """多任务信息瓶颈: CTR + CVR + 完播 + 点赞"""
    def __init__(self, dim_x, dim_z, num_tasks=4, beta=1e-3):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(dim_x, 256), nn.ReLU(),
            nn.Linear(256, 2 * dim_z)
        )
        # 多个预测头
        self.heads = nn.ModuleList([nn.Linear(dim_z, 1) for _ in range(num_tasks)])
        self.beta = beta

    def forward(self, x, task_labels):
        """
        x: [B, D_x] 输入特征
        task_labels: list of [B] 多个任务的标签
        """
        mu_logvar = self.encoder(x)
        mu, logvar = mu_logvar.chunk(2, dim=-1)
        z = mu + torch.exp(0.5 * logvar) * torch.randn_like(mu)

        # 预测每个任务
        total_loss = 0
        for i, head in enumerate(self.heads):
            pred = head(z).squeeze(-1)
            loss_i = F.binary_cross_entropy_with_logits(pred, task_labels[i].float())
            total_loss += loss_i

        # IB 正则
        kl = -0.5 * (1 + logvar - mu.pow(2) - logvar.exp()).sum(-1).mean()

        return total_loss + self.beta * kl
```

### 21.15.2 任务间互信息约束(去耦合)

**问题**: 多任务学习中, 任务间存在"跷跷板"——优化 CTR 损害 CVR。

**信息论解决**: 让任务的 latent 表示 **$I(Z_{CTR}; Z_{CVR})$ 小**:

$$\mathcal{L} = \mathcal{L}_{\text{multi-task}} + \gamma \cdot I(Z_{CTR}; Z_{CVR})$$

```python
class DecoupledMultiTaskIB(nn.Module):
    """去耦合多任务 IB: 让不同任务的表示互信息小"""
    def __init__(self, dim_x, dim_z, num_tasks=4, beta=1e-3, gamma=0.1):
        super().__init__()
        # 每个任务一个独立的编码器
        self.encoders = nn.ModuleList([
            nn.Sequential(
                nn.Linear(dim_x, 256), nn.ReLU(),
                nn.Linear(256, 2 * dim_z)
            ) for _ in range(num_tasks)
        ])
        self.heads = nn.ModuleList([nn.Linear(dim_z, 1) for _ in range(num_tasks)])
        self.beta = beta
        self.gamma = gamma

    def forward(self, x, task_labels):
        zs, mus, logvars = [], [], []
        for enc in self.encoders:
            ml = enc(x)
            mu, logvar = ml.chunk(2, dim=-1)
            z = mu + torch.exp(0.5 * logvar) * torch.randn_like(mu)
            zs.append(z)
            mus.append(mu)
            logvars.append(logvar)

        # 各任务损失
        total_loss = 0
        for i, head in enumerate(self.heads):
            pred = head(zs[i]).squeeze(-1)
            total_loss += F.binary_cross_entropy_with_logits(pred, task_labels[i].float())

        # IB 正则(各任务独立)
        for mu, logvar in zip(mus, logvars):
            kl = -0.5 * (1 + logvar - mu.pow(2) - logvar.exp()).sum(-1).mean()
            total_loss += self.beta * kl

        # 去耦合: 各任务表示间的互信息小
        # 用皮尔逊相关近似 (实际用 MINE 更准)
        for i in range(len(zs)):
            for j in range(i+1, len(zs)):
                # 标准化
                zi_n = (zs[i] - zs[i].mean(0)) / (zs[i].std(0) + 1e-8)
                zj_n = (zs[j] - zs[j].mean(0)) / (zs[j].std(0) + 1e-8)
                # 互相关矩阵的 Frobenius 范数
                corr = (zi_n.T @ zj_n) / zs[i].size(0)
                decouple_loss = corr.norm()
                total_loss += self.gamma * decouple_loss

        return total_loss
```

## 21.16 信息论与异常检测(对数似然法)

### 21.16.1 异常 = 低似然 = 高信息增益

**核心思想**: 如果一个样本的**对数似然**在模型下很低,**说明它包含模型不知道的"新信息"** → 可能是异常。

**信息论形式化**: 异常分数 = $-\log p(x | \theta)$ (负对数似然)

**在搜推广中**:
- 异常用户行为(刷单、爬虫): NLL 异常高 → 标记为异常
- 异常物品(违规内容): 用物品 Embedding 的重构误差度量

```python
class AnomalyDetector(nn.Module):
    """基于信息论的异常检测: VAE 重构误差"""
    def __init__(self, dim_input, dim_z=64):
        super().__init__()
        # VAE
        self.encoder = nn.Sequential(
            nn.Linear(dim_input, 256), nn.ReLU(),
            nn.Linear(256, 2 * dim_z)
        )
        self.decoder = nn.Sequential(
            nn.Linear(dim_z, 256), nn.ReLU(),
            nn.Linear(256, dim_input)
        )

    def forward(self, x):
        # 编码
        ml = self.encoder(x)
        mu, logvar = ml.chunk(2, dim=-1)
        z = mu + torch.exp(0.5 * logvar) * torch.randn_like(mu)
        # 重构
        x_hat = self.decoder(z)
        # 重构误差
        recon_error = ((x - x_hat) ** 2).sum(dim=-1)
        # KL 正则
        kl = -0.5 * (1 + logvar - mu.pow(2) - logvar.exp()).sum(-1)
        # 异常分数 = 重构误差 - KL(信息增益视角)
        anomaly_score = recon_error - kl
        return anomaly_score


# 工业做法: 训练时计算"正常用户分布"的异常分数阈值
def train_anomaly_detector(model, normal_data, n_epochs=10):
    """训练时记录正常数据的 anomaly_score 分布"""
    scores = []
    for epoch in range(n_epochs):
        for batch in normal_data:
            score = model(batch)
            scores.extend(score.tolist())

    # 用 99.5% 分位数作为阈值
    threshold = np.percentile(scores, 99.5)
    return threshold


# 在线推理
def is_anomaly(model, x, threshold):
    score = model(x)
    return (score > threshold).item()
```

### 21.16.2 在推荐风控的应用

**抖音反作弊系统**(2024 数据):

| 用户类型 | 异常分数均值 | 阈值 (95%) | 标记 |
| :--- | :--- | :--- | :--- |
| **正常用户** | 12.3 | 28.5 | 0.5% 误报 |
| **刷手用户** | 56.7 | 28.5 | 92% 召回 |
| **爬虫** | 89.2 | 28.5 | 99% 召回 |

## 21.17 信息论与注意力机制 (Attention as Info Bottleneck)

### 21.17.1 Attention 的信息论解释

**Self-Attention** 的核心: 用 query-key 相似度给 value 加权:

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d}}\right) V$$

**信息论解释**:
- $QK^\top$ 是**互信息估计**的 soft 形式
- $\text{softmax}$ 是**信息瓶颈**(保留 top-k 的高 MI value)
- 输出 $V$ 是**信息加权**后的表征

### 21.17.2 推荐系统中的 Attention-IB

```python
class AttentionIB(nn.Module):
    """用 Attention 实现信息瓶颈"""
    def __init__(self, dim_input, dim_z, num_heads=4):
        super().__init__()
        self.attn = nn.MultiheadAttention(dim_input, num_heads, batch_first=True)
        self.proj = nn.Linear(dim_input, dim_z)
        self.beta = 1e-3

    def forward(self, x, mask=None):
        """
        x: [B, L, D] 序列特征
        """
        # Self-attention
        attn_out, attn_weights = self.attn(x, x, x, attn_mask=mask)

        # 投影到 latent
        z = self.proj(attn_out.mean(dim=1))  # [B, dim_z]

        return z, attn_weights


class AttentionIBLoss(nn.Module):
    """Attention IB 的训练损失"""
    def __init__(self, beta=1e-3):
        super().__init__()
        self.beta = beta

    def forward(self, attn_weights, target_attn=None):
        """
        attn_weights: [B, L, L] 注意力图
        target_attn: [B, L, L] 教师注意力图(可选)
        """
        if target_attn is not None:
            # 蒸馏注意力图
            return self.beta * F.kl_div(
                F.log_softmax(attn_weights, dim=-1),
                F.softmax(target_attn, dim=-1),
                reduction='batchmean'
            )
        else:
            # 自监督: 让注意力稀疏(信息瓶颈)
            entropy = -(attn_weights * (attn_weights + 1e-8).log()).sum(dim=-1).mean()
            return self.beta * (-entropy)  # 负熵 = 鼓励稀疏
```

## 21.18 信息论与持续学习 (Continual Learning)

### 21.18.1 灾难性遗忘 = 互信息丢失

**问题**: 模型在新任务上训练时,旧任务性能下降。

**信息论解释**: 旧任务的信息 $I(Z; Y_{\text{old}})$ 在新任务训练中下降。

**解决**: EWC (Elastic Weight Consolidation), 用 Fisher 信息加权正则:

$$L_{\text{EWC}} = L_{\text{task}} + \frac{\lambda}{2} \sum_i F_i (\theta_i - \theta_i^*)^2$$

其中 $F_i$ 是 Fisher 信息(详见 §1.4.1)。

```python
class EWC:
    """Elastic Weight Consolidation"""
    def __init__(self, model, dataloader, lambda_=1000):
        self.model = model
        self.lambda_ = lambda_
        # 计算 Fisher 信息
        self.fisher = self._compute_fisher(model, dataloader)
        # 保存旧参数
        self.old_params = {n: p.clone() for n, p in model.named_parameters()}

    def _compute_fisher(self, model, dataloader):
        fisher = {n: torch.zeros_like(p) for n, p in model.named_parameters()}
        model.eval()
        for batch in dataloader:
            model.zero_grad()
            loss = compute_loss(model, batch)  # 用户定义
            loss.backward()
            for n, p in model.named_parameters():
                if p.grad is not None:
                    fisher[n] += p.grad ** 2
        # 归一化
        for n in fisher:
            fisher[n] /= len(dataloader)
        return fisher

    def penalty(self, model):
        """EWC 正则"""
        loss = 0
        for n, p in model.named_parameters():
            if n in self.fisher:
                loss += (self.fisher[n] * (p - self.old_params[n]) ** 2).sum()
        return self.lambda_ * loss
```

### 21.18.2 推荐系统的"概念漂移"

**现实**: 用户兴趣随时间漂移(新年 / 大促 / 季节),模型需要持续学习。

**信息论方法**:
- 用 KL 监测**分布漂移** $D_{\text{KL}}(p_t \| p_{t-1})$
- 当漂移 > 阈值,触发重训
- 用 EWC 保留旧知识

```python
def detect_concept_drift(model_old, model_new, val_data, threshold=0.05):
    """检测概念漂移: KL(新 || 旧) > 阈值"""
    with torch.no_grad():
        old_logits = model_old(val_data)
        new_logits = model_new(val_data)
    kl = F.kl_div(
        F.log_softmax(new_logits, dim=-1),
        F.softmax(old_logits, dim=-1),
        reduction='batchmean'
    )
    if kl > threshold:
        print(f"概念漂移! KL = {kl:.4f} > {threshold}")
        return True
    return False
```

## 21.19 信息论与推荐系统的"冷启动"问题

### 21.19.1 冷启动 = 互信息极低

**冷启动**: 新用户 / 新物品没有足够历史,$I(Z; Y)$ 很低。

**信息论视角**:
- 已知信息 $X$ 极少
- 互信息 $I(Z; Y) \approx 0$
- 无法预测

### 21.19.2 信息论方法解决冷启动

**1. 用 side information 增加 $I(X; Y)$**
- 新用户的注册信息(性别/年龄/兴趣标签)→ 提供初始信息
- 新物品的属性(类目/品牌/价格)→ 提供初始信息

**2. 用元学习快速适应**
- MAML 在多个相似任务上预训练
- 新任务上只用少量样本适应

**3. 用 side-information 蒸馏**
- 教师的预测包含 side info 信息
- 学生蒸馏教师的"先验"

```python
class ColdStartRec(nn.Module):
    """冷启动推荐: 用 side information"""
    def __init__(self, user_feature_dim, item_feature_dim, dim_z=128):
        super().__init__()
        # 用户特征编码
        self.user_enc = nn.Sequential(
            nn.Linear(user_feature_dim, 256), nn.ReLU(),
            nn.Linear(256, dim_z)
        )
        # 物品特征编码
        self.item_enc = nn.Sequential(
            nn.Linear(item_feature_dim, 256), nn.ReLU(),
            nn.Linear(256, dim_z)
        )

    def forward(self, user_feats, item_feats):
        u_z = self.user_enc(user_feats)
        i_z = self.item_enc(item_feats)
        # 双塔
        score = (u_z * i_z).sum(dim=-1)
        return score


class ColdStartWithMeta(nn.Module):
    """元学习解决冷启动: MAML"""
    def __init__(self, base_model, inner_lr=1e-2, meta_lr=1e-3):
        super().__init__()
        self.base_model = base_model
        self.inner_lr = inner_lr
        self.meta_lr = meta_lr
        # 元学习器
        self.meta_opt = torch.optim.Adam(self.base_model.parameters(), lr=meta_lr)

    def adapt_and_predict(self, support_set, query_set):
        """
        support_set: 新用户/物品的少量样本
        query_set: 待预测样本
        """
        # 1. 内循环: 在 support_set 上快速适应
        fast_weights = {n: p for n, p in self.base_model.named_parameters()}
        for _ in range(5):  # 5 步梯度下降
            support_loss = compute_loss(self.base_model, support_set)
            grads = torch.autograd.grad(support_loss, fast_weights.values(), create_graph=True)
            fast_weights = {n: p - self.inner_lr * g for (n, p), g in zip(fast_weights.items(), grads)}

        # 2. 在 query_set 上预测(用 fast_weights)
        pred = functional_call(self.base_model, fast_weights, query_set)
        return pred
```

### 110. 信息论深层次理解 - 工程视角 视角

**核心议题**: 本节从工程视角视角切入,系统展开 "信息论深层次理解" 的相关讨论。

**1. 背景与动机**

任何技术或方法的出现都不是孤立的,而是回应特定历史条件下的具体问题。"信息论深层次理解" 的发展也不例外。要理解它,必须回到它出现的那个时间点,看清它要解决的真实问题是什么。当时的主流方案有哪些不足? 它的提出填补了哪些空白? 这些问题的回答,决定了我们今天该如何使用它。

从知识论角度看,**技术演进是问题驱动的**——不是先有方案再找问题,而是先有问题再有方案。这个观察可以帮助我们避免"拿着锤子找钉子"的陷阱,真正把方法用对地方。

历史维度上,我们看到三个规律:

1. **从特殊到一般**: 早期方法往往针对特定场景,后期抽象出通用框架。学习的认知规律也是先掌握具体案例,再抽象出一般模式。这种"自下而上"的学习方式,在机器学习模型的设计里反复出现。

2. **从手工到自动**: 经验规则逐步被数据驱动的方法取代。在早期,很多 AI 系统依赖人工编写的规则。统计学习方法的崛起让"从数据中学习"成为可能。深度学习进一步把特征工程也自动化了。今天的大模型时代,我们看到端到端学习从感知扩展到了推理与生成。

3. **从局部到全局**: 关注单个组件,演进到关注整个系统。早期模型评估只关注单点指标,现在更关注全链路的协同效应。这种"系统视角"的转变,与软件工程从单体架构到微服务架构的演进高度相似。

**2. 工程视角视角的展开**

从工程视角视角出发,我们可以把 "信息论深层次理解" 拆解为以下几个层次:

**第一层: 概念层** —— 这是最抽象的层次,定义了我们要研究的对象是什么。例如,"推荐系统"在概念层是一个"为用户从物品集合中筛选合适物品"的问题。这个层次的特点是清晰、稳定、不易变化。一个好的概念定义应该具备几个特征:可操作性、可测量性、可扩展性。

**第二层: 模型层** —— 把概念实例化为数学模型。同一概念可以有不同的模型化方式,例如"推荐系统"可以是协同过滤、矩阵分解、深度学习等。模型的选择决定了后续算法的空间,也决定了能利用的归纳偏置(比如序列模型擅长捕捉时序依赖,图模型擅长建模关系结构)。模型选型是工程实践中最重要的决策之一。

**第三层: 算法层** —— 在选定模型下,具体的求解方法。这一层最活跃,新算法层出不穷。同一模型往往有多种算法,各有优劣。例如同样是优化深度网络,可以选择 SGD、Adam、L-BFGS 等不同算法。算法的选择要考虑收敛速度、数值稳定性、计算成本等多个维度。

**第四层: 工程层** —— 算法落地的实现细节,包括数据流水线、训练框架、推理优化、监控告警等。工程层是研究到生产的桥梁,决定了一个方法能否真正用起来。一个在论文里表现很好的算法,如果不能高效实现、不能稳定运行、不能快速迭代,就没有实际价值。工程能力是把研究转化为生产力的关键。

**第五层: 业务层** —— 在具体业务场景中的表现。同一技术在不同业务里效果差异巨大,因为业务目标、数据分布、用户行为都有差异。从业务视角看技术,我们必须回答几个问题:这个技术解决了什么业务问题?投入产出比如何?长期可持续吗?技术评估必须与业务目标对齐,否则容易陷入"技术自嗨"的陷阱。

**3. 数学形式化(简洁版)**

虽然我们强调工程视角视角,但数学形式化提供了共同语言。机器学习的核心问题可以表达为:给定输入样本,学习一个映射函数,使得函数输出与真实目标的差距最小化。这个抽象捕捉了分类、回归、生成等大多数任务的本质。

进一步,优化目标通常加入正则化项来控制模型复杂度,平衡经验风险与模型容量。统计学习理论给出了泛化误差的上界,告诉我们模型越复杂并不一定越好——**奥卡姆剃刀**在数学上有严格的形式化。

偏差-方差分解是另一个核心框架:误差可以分解为模型偏差(欠拟合)、方差(过拟合)和不可约噪声三部分。理解这个分解有助于诊断模型表现、选择合适复杂度。

在数值稳定性方面,有几个常见陷阱: 浮点数精度有限、Log-Sum-Exp 计算要减去最大值、Softmax 在大数值下会溢出。这些工程细节常常决定一个模型能否在生产环境稳定运行。

**4. 信息论视角**

信息论为"信息论深层次理解" 提供了统一的视角:**学习的本质是从数据中提取与目标相关的信息**。

互信息衡量知道一个变量后,另一个变量不确定性减少的量。在机器学习中,它被广泛用于特征选择、表示学习、多模态对齐等场景。

KL 散度衡量两个概率分布的距离,在交叉熵损失、变分推断、策略梯度等场景无处不在。需要注意它是**不对称**的——不同方向有不同的解释。

信息瓶颈原则指出,我们应该寻找既紧凑又预测性强的表示。这一思想影响了大量表示学习方法的设计,包括对比学习、自监督学习、多模态预训练等。

**5. 算法实现(骨架)**

虽然我们强调"工程视角" 视角,但落到代码层面是类似的骨架:

```python
def train_model(data, model_class, config):
    """通用训练函数骨架"""
    model = model_class(config)
    optimizer = create_optimizer(model, config)
    scheduler = create_scheduler(optimizer, config)
    
    for epoch in range(config.epochs):
        for batch in data:

            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            scheduler.step()
```

**7. 实践建议**

结合 "信息论深层次理解" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

**第三层: 算法层** —— 在选定模型下,具体的求解方法。这一层最活跃,新算法层出不穷。同一模型往往有多种算法,各有优劣。例如同样是优化深度网络,可以选择 SGD、Adam、L-BFGS 等不同算法。算法的选择要考虑收敛速度、数值稳定性、计算成本等多个维度。

**第四层: 工程层** —— 算法落地的实现细节,包括数据流水线、训练框架、推理优化、监控告警等。工程层是研究到生产的桥梁,决定了一个方法能否真正用起来。一个在论文里表现很好的算法,如果不能高效实现、不能稳定运行、不能快速迭代,就没有实际价值。工程能力是把研究转化为生产力的关键。

**第五层: 业务层** —— 在具体业务场景中的表现。同一技术在不同业务里效果差异巨大,因为业务目标、数据分布、用户行为都有差异。从业务视角看技术,我们必须回答几个问题:这个技术解决了什么业务问题?投入产出比如何?长期可持续吗?技术评估必须与业务目标对齐,否则容易陷入"技术自嗨"的陷阱。

**3. 数学形式化(简洁版)**

虽然我们强调召回视角视角,但数学形式化提供了共同语言。机器学习的核心问题可以表达为:给定输入样本,学习一个映射函数,使得函数输出与真实目标的差距最小化。这个抽象捕捉了分类、回归、生成等大多数任务的本质。

进一步,优化目标通常加入正则化项来控制模型复杂度,平衡经验风险与模型容量。统计学习理论给出了泛化误差的上界,告诉我们模型越复杂并不一定越好——**奥卡姆剃刀**在数学上有严格的形式化。

偏差-方差分解是另一个核心框架:误差可以分解为模型偏差(欠拟合)、方差(过拟合)和不可约噪声三部分。理解这个分解有助于诊断模型表现、选择合适复杂度。

在数值稳定性方面,有几个常见陷阱: 浮点数精度有限、Log-Sum-Exp 计算要减去最大值、Softmax 在大数值下会溢出。这些工程细节常常决定一个模型能否在生产环境稳定运行。

**4. 信息论视角**

信息论为"信息论深层次理解" 提供了统一的视角:**学习的本质是从数据中提取与目标相关的信息**。

互信息衡量知道一个变量后,另一个变量不确定性减少的量。在机器学习中,它被广泛用于特征选择、表示学习、多模态对齐等场景。

KL 散度衡量两个概率分布的距离,在交叉熵损失、变分推断、策略梯度等场景无处不在。需要注意它是**不对称**的——不同方向有不同的解释。

信息瓶颈原则指出,我们应该寻找既紧凑又预测性强的表示。这一思想影响了大量表示学习方法的设计,包括对比学习、自监督学习、多模态预训练等。

**7. 实践建议**

结合 "信息论深层次理解" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "信息论深层次理解" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
