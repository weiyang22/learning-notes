## 1. 特征类型与处理

| 类型 | 例子 | 处理 |
| :--- | :--- | :--- |
| 类别(稀疏 ID) | user_id, item_id, city | Embedding 查表 |
| 数值(稠密) | 价格, 时长, CTR | 归一化 / 分桶离散化 |
| 序列 | 历史点击 item 列表 | 池化 / 注意力(DIN) |
| 交叉 | user_city × item_cat | 显式或模型学习 |

**关键实践**:
- **数值分桶**: 连续值分桶后 Embedding, 引入非线性、抗异常值。
- **高基数 ID**: hash trick 降维或频次过滤长尾。
- **特征穿越(leakage)**: 严禁用未来信息(如用当天之后的行为), 是线上崩的头号原因。

## 2. 为什么要显式特征交叉

DNN 理论上能学任意函数, 但对**低阶交叉**(如"年轻人×电子产品")学习效率低、需大量数据。显式交叉把先验结构注入模型, 少数据也能学好 —— 归纳偏置的又一例(见 [工程能力第01章](../../基础/工程基础/工程能力/第01章-模型架构设计方法论.md))。

## 3. FM: 因子分解机

二阶交叉 $\sum_{i<j} \langle v_i, v_j\rangle x_i x_j$。用隐向量点积表示交叉权重, 解决了组合稀疏(没共现过的特征对也能泛化)。

**$O(nk)$ 化简**(核心技巧):

$$\sum_{i<j}\langle v_i,v_j\rangle x_ix_j = \frac12\sum_{f=1}^{k}\Big[\big(\sum_i v_{i,f}x_i\big)^2 - \sum_i v_{i,f}^2x_i^2\Big]$$

```python
import torch, torch.nn as nn

class FM(nn.Module):
    def __init__(self, num_feat, k):
        super().__init__()
        self.linear = nn.Embedding(num_feat, 1)     # 一阶
        self.v = nn.Embedding(num_feat, k)          # 二阶隐向量
        self.bias = nn.Parameter(torch.zeros(1))
    def forward(self, idx):                          # idx: (B, F) 特征 id
        first = self.linear(idx).sum(1).squeeze(-1)
        vx = self.v(idx)                             # (B, F, k)
        square_of_sum = vx.sum(1).pow(2)             # (∑v)²
        sum_of_square = vx.pow(2).sum(1)             # ∑v²
        second = 0.5 * (square_of_sum - sum_of_square).sum(1)
        return self.bias + first + second
```

## 4. DeepFM: FM + DNN 并联

Wide(FM 记忆低阶) + Deep(DNN 泛化高阶), **共享 Embedding**, 无需人工交叉特征。

```python
class DeepFM(nn.Module):
    def __init__(self, num_feat, F, k, hidden=[256,128]):
        super().__init__()
        self.fm = FM(num_feat, k)
        self.emb = nn.Embedding(num_feat, k)
        layers, d = [], F*k
        for h in hidden:
            layers += [nn.Linear(d, h), nn.ReLU()]; d = h
        layers += [nn.Linear(d, 1)]
        self.dnn = nn.Sequential(*layers)
    def forward(self, idx):
        fm_out = self.fm(idx)
        deep = self.dnn(self.emb(idx).flatten(1)).squeeze(-1)
        return torch.sigmoid(fm_out + deep)
```

## 5. DCN: 显式高阶交叉(Cross Network)

每层 $x_{l+1} = x_0 x_l^\top w_l + b_l + x_l$, $L$ 层得到有界的 $L{+}1$ 阶交叉, 参数量线性。

```python
class CrossNet(nn.Module):
    def __init__(self, dim, layers=3):
        super().__init__()
        self.w = nn.ParameterList([nn.Parameter(torch.randn(dim)) for _ in range(layers)])
        self.b = nn.ParameterList([nn.Parameter(torch.zeros(dim)) for _ in range(layers)])
    def forward(self, x0):
        x = x0
        for w, b in zip(self.w, self.b):
            xw = (x * w).sum(1, keepdim=True)        # x_l^T w  (标量)
            x = x0 * xw + b + x                       # 显式交叉 + 残差
        return x
```

**DCN-v2** 把向量 $w$ 换成矩阵 $W$, 表达力更强, 是工业主流。

## 9. 特征工程的深度展开

### 9.1 数值特征的深度处理

**数值特征的"陷阱"**:
- 不同量纲 (价格 0.1 vs 10000)
- 异常值 (99 分位 vs 1 分位)
- 长尾分布 (90% 集中在 10% 范围)

#### 9.1.1 标准化 vs 归一化 vs 分桶

**Z-Score 标准化**:
$$x' = \frac{x - \mu}{\sigma}$$

```python
def z_score(x, mean, std):
    return (x - mean) / (std + 1e-8)
```

**Min-Max 归一化**:
$$x' = \frac{x - \min}{\max - \min}$$

```python
def min_max(x, min_v, max_v):
    return (x - min_v) / (max_v - min_v + 1e-8)
```

**Log 变换**:
$$x' = \log(1 + x)$$

```python
def log_transform(x):
    return np.log1p(x)
```

**分桶 (Bucket/Binning)**:
```python
def bucketize(x, num_buckets=10, strategy='quantile'):
    if strategy == 'quantile':
        # 按分位数分桶
        quantiles = np.percentile(x, np.linspace(0, 100, num_buckets + 1))
        return np.digitize(x, quantiles[1:-1])
    elif strategy == 'uniform':
        # 等距分桶
        bins = np.linspace(x.min(), x.max(), num_buckets + 1)
        return np.digitize(x, bins[1:-1])
```

**对比**:

| 方法 | 优点 | 缺点 | 适用 |
| :--- | :--- | :--- | :--- |
| Z-Score | 保分布形状 | 受异常值影响 | 近似高斯分布 |
| Min-Max | 固定 [0,1] | 受异常值影响 | 神经网络输入 |
| Log | 压长尾 | 仅适用于 > 0 | 价格/时长 |
| 分桶 | 抗异常值 | 信息损失 | 高基数数值 |

**实践**: 推荐用"分桶 + Embedding", 而不是直接数值输入。

### 9.2 类别特征的深度处理

#### 9.2.1 高基数特征的处理

**问题**: user_id 有 1 亿个, 直接 Embedding 表太大。

**方案**:

| 方案 | 内存 | 精度 | 适用 |
| :--- | :--- | :--- | :--- |
| Hash Trick | 1/100 | 略降 | 中等基数 |
| 分桶 Embedding | 1/10 | 中 | 高基数 |
| 频率过滤 | 1/5 | 长尾差 | 极长尾 |
| 双塔拆分 | 各 1/2 | 中 | 高基数但语义可分 |

**Hash Trick 实现**:
```python
class HashEmbedding(nn.Module):
    """哈希 Embedding"""
    def __init__(self, num_buckets, embed_dim):
        super().__init__()
        self.embedding = nn.Embedding(num_buckets, embed_dim)
        self.num_buckets = num_buckets

    def forward(self, ids):
        hashed = ids % self.num_buckets
        return self.embedding(hashed)
```

#### 9.2.2 多值类别特征

**场景**: 用户兴趣标签 (多标签), 物品类目 (一级/二级/三级)。

**处理**:
- **Pooling**: 平均/最大/注意力池化
- **Flatten**: 拆成多个独立特征

```python
class MultiCategoryEmbedding(nn.Module):
    """多类目 Embedding"""
    def __init__(self, num_categories, embed_dim):
        super().__init__()
        self.embedding = nn.Embedding(num_categories, embed_dim)

    def forward(self, category_ids):
        # category_ids: (B, L) 多类目
        emb = self.embedding(category_ids)  # (B, L, d)
        return emb.mean(dim=1)  # 平均池化
```

#### 9.2.3 类目层级编码

```python
class HierarchicalCategoryEmbedding(nn.Module):
    """层级类目 Embedding"""
    def __init__(self, num_cat_per_level, embed_dim):
        super().__init__()
        self.embeddings = nn.ModuleList([
            nn.Embedding(num_cat, embed_dim)
            for num_cat in num_cat_per_level
        ])

    def forward(self, cat_ids_per_level):
        # cat_ids_per_level: list of (B,) 每个层级一个 ID
        embs = [emb(cat) for emb, cat in zip(self.embeddings, cat_ids_per_level)]
        return torch.cat(embs, dim=-1)  # 拼接各层级
```

### 9.3 序列特征的深度处理

**序列特征类型**:

| 序列 | 长度 | 处理 |
| :--- | :--- | :--- |
| 用户点击序列 | 50-500 | 池化/注意力 (DIN) |
| 用户购买序列 | 10-100 | Transformer (DIEN) |
| 短期 session | 5-50 | GRU / Transformer |
| 长期累积 | 100+ | 平均池化 / 聚类 |

**DIN 处理序列**:
```python
class DINAttention(nn.Module):
    def __init__(self, embed_dim):
        super().__init__()
        self.local_act = nn.Sequential(
            nn.Linear(4 * embed_dim, 80), nn.ReLU(),
            nn.Linear(80, 1)
        )

    def forward(self, target_emb, history_embs, mask=None):
        # target_emb: (B, d), history_embs: (B, L, d)
        L = history_embs.size(1)
        target_expanded = target_emb.unsqueeze(1).expand(-1, L, -1)
        attn_input = torch.cat([
            history_embs, target_expanded,
            history_embs * target_expanded,
            history_embs - target_expanded
        ], dim=-1)
        attn_weights = self.local_act(attn_input).squeeze(-1)
        if mask is not None:
            attn_weights = attn_weights.masked_fill(mask == 0, -1e9)
        attn_weights = F.softmax(attn_weights, dim=-1)
        user_interest = (history_embs * attn_weights.unsqueeze(-1)).sum(dim=1)
        return user_interest
```

### 9.4 上下文特征

- 设备: 类目化 + Embedding

```python
def time_embedding(hour, dim=16):
    """时间周期性编码"""
    angle = 2 * np.pi * hour / 24
    return torch.tensor([
        np.sin(angle * (i // 2 + 1)) if i % 2 == 0 else np.cos(angle * (i // 2 + 1))
        for i in range(dim)
    ])
```

### 9.6 特征穿越 (Feature Leakage) 的检测

**常见穿越场景**:

| 场景 | 危害 | 检测 |
| :--- | :--- | :--- |
| 用当天之后的行为 | 离线高, 线上崩 | 时间戳检查 |
| 用当前曝光的物品 | 离线高, 线上崩 | 标签检查 |
| 训练时用 validation 集 | 评估失真 | 严格切分 |
| 特征处理不一致 | 离线/在线不一致 | 统一 SDK |

**检测代码**:
```python
def check_feature_leakage(train_data, valid_data):
    """检测特征穿越"""
    # 1) 时间戳检查
    train_max_time = train_data['timestamp'].max()
    valid_min_time = valid_data['timestamp'].min()
    assert train_max_time < valid_min_time, "时间穿越!"

    # 2) 物品 ID 检查
    train_items = set(train_data['item_id'].unique())
    valid_items = set(valid_data['item_id'].unique())
    # 验证集物品在训练集出现比例
    overlap = len(train_items & valid_items) / len(valid_items)
    print(f"物品覆盖率: {overlap:.2%}")  # 应该接近 1.0

    # 3) 标签分布检查
    train_pos_rate = train_data['label'].mean()
    valid_pos_rate = valid_data['label'].mean()
    diff = abs(train_pos_rate - valid_pos_rate)
    if diff > 0.05:
        print(f"标签分布差异大: {diff:.2%}")
```

### 9.7 特征选择

**特征选择方法**:

| 方法 | 类型 | 优点 | 缺点 |
| :--- | :--- | :--- | :--- |
| Filter (方差/相关) | 统计 | 快 | 忽略交互 |
| Wrapper (RFE) | 模型 | 精确 | 慢 |
| Embedded (Lasso) | 模型 | 兼顾 | 依赖模型 |

**实践**: 工业界常用"重要性排序 + 业务理解":
1. 用模型计算特征重要性
2. 业务方 review 每个特征
3. 砍掉不重要 + 不合理的特征

```python
def feature_importance(model, val_data):
    """特征重要性"""
    importances = {}
    for name, _ in model.named_parameters():
        if 'weight' in name:
            importances[name] = torch.abs(model.state_dict()[name]).mean().item()
    return sorted(importances.items(), key=lambda x: -x[1])
```

### 9.8 特征归一化的细节

**在线/离线归一化的差异**:

**离线**: 用训练集统计的 mean/std。

**在线**: 用同样的 mean/std (从特征服务获取)。

**坑**: 如果训练集 mean/std 与线上不一致, 离线涨线上跌。

**解决**: 特征服务统一维护 mean/std, 训练和推理都用同一份。

```python
class FeatureScaler:
    """特征缩放器"""
    def __init__(self, mean, std):
        self.mean = torch.tensor(mean)
        self.std = torch.tensor(std)

    def __call__(self, x):
        return (x - self.mean) / (self.std + 1e-8)

    def save(self, path):
        torch.save({'mean': self.mean, 'std': self.std}, path)

    @classmethod
    def load(cls, path):
        d = torch.load(path)
        return cls(d['mean'], d['std'])
```

## 10. 特征交叉的深度展开

### 10.1 显式交叉 vs 隐式交叉

**显式交叉**: 模型结构中显式建模特征交叉。
- LR (手动)
- FM (二阶)
- DCN (高阶)
- xDeepFM (向量级外积)

**隐式交叉**: 模型通过多层神经网络隐式学习交叉。
- DNN (任意阶, 但低阶难学)
- Attention (序列内交叉)
- Transformer (任意交叉)

**实践**:
- 小数据 + 强先验 → 显式交叉 (FM/DCN)
- 大数据 + 弱先验 → 隐式交叉 (DNN/Attention)
- 工业界: 显式 + 隐式并联 (DeepFM)

### 10.2 FM 家族的演进

#### 10.2.1 FM (2010)

$$\text{FM}(x) = w_0 + \sum_i w_i x_i + \sum_{i<j} \langle v_i, v_j\rangle x_i x_j$$

**优势**: 解决稀疏组合 (没共现也能泛化)。

**复杂度**: $O(n^2 k) \to O(nk)$ (平方和差)。

#### 10.2.2 FFM (Field-aware FM, 2016)

**改进**: 每个特征在不同 field 有不同隐向量。

```python
class FFM(nn.Module):
    def __init__(self, num_features, num_fields, k):
        super().__init__()
        # 每个特征在每个 field 有一个隐向量
        self.v = nn.Parameter(torch.randn(num_features, num_fields, k))
        self.linear = nn.Embedding(num_features, 1)

    def forward(self, x):
        # x: (B, F) 特征 ID
        # field_idx: (F,) 每个特征属于哪个 field
        # 计算二阶交叉
        # ...
```

**缺点**: 参数爆炸 ($n \times f \times k$), 工业不常用。

#### 10.2.3 AFM (Attentional FM, 2017)

**改进**: FM 的二阶交叉用 Attention 加权。

```python
class AFM(nn.Module):
    """Attentional FM"""
    def __init__(self, num_feat, k):
        super().__init__()
        self.v = nn.Embedding(num_feat, k)
        self.attention = nn.Sequential(
            nn.Linear(k, 16), nn.ReLU(),
            nn.Linear(16, 1)
        )

    def forward(self, idx):
        vx = self.v(idx)  # (B, F, k)
        # 二阶交互
        interactions = []
        for i in range(vx.size(1)):
            for j in range(i+1, vx.size(1)):
                interactions.append(vx[:, i] * vx[:, j])
        interactions = torch.stack(interactions, dim=1)  # (B, F*(F-1)/2, k)
        # Attention
        attn_weights = self.attention(interactions).squeeze(-1)
        attn_weights = F.softmax(attn_weights, dim=-1)
        # 加权
        weighted = (interactions * attn_weights.unsqueeze(-1)).sum(dim=1)
        return weighted
```

**优势**: 区分不同交互的重要性。

#### 10.2.4 DeepFM (2017)

**改进**: FM + DNN 并联, 共享 Embedding。

详见 [第24章-特征工程与特征交叉 第4节](#4-deepfm-fm--dnn-并联)。

#### 10.2.5 xDeepFM (2018)

**改进**: 用 CIN (Compressed Interaction Network) 做"向量级外积"。

```python
class CIN(nn.Module):
    """Compressed Interaction Network"""
    def __init__(self, num_feat, k, layer_sizes=[128, 128]):
        super().__init__()
        self.layer_sizes = layer_sizes
        self.W = nn.ParameterList()
        for size in layer_sizes:
            self.W.append(nn.Parameter(torch.randn(num_feat, size)))

    def forward(self, x0):
        # x0: (B, F, k)
        x = x0
        outputs = [x0.sum(dim=1)]  # 一阶
        for size in self.layer_sizes:
            # 外积: (B, F, k, 1) * (B, 1, k, F) -> (B, F, F, k)
            outer = torch.einsum('bik,bjk->bijk', x0, x)
            # 卷积: 用 W 投影
            # ... 简化
            x = x  # 简化
            outputs.append(x.sum(dim=1))
        return torch.cat(outputs, dim=-1)
```

**特点**: 表达力强, 但参数多, 训练慢。

#### 10.2.6 AutoInt (2019)

**改进**: 用自注意力做高阶交叉。

```python
class AutoInt(nn.Module):
    """Automatic Feature Interaction"""
    def __init__(self, num_feat, k, n_layers=3, n_heads=2):
        super().__init__()
        self.emb = nn.Embedding(num_feat, k)
        self.attn_layers = nn.ModuleList([
            nn.MultiheadAttention(k, n_heads) for _ in range(n_layers)
        ])

    def forward(self, idx):
        # idx: (B, F)
        x = self.emb(idx)  # (B, F, k)
        x = x.transpose(0, 1)  # (F, B, k)
        for attn in self.attn_layers:
            x, _ = attn(x, x, x)
        x = x.transpose(0, 1)  # (B, F, k)
        return x.sum(dim=1)  # 池化
```

**特点**: 自动学习交叉, 可解释 (注意力权重可视化)。

### 10.3 DCN 家族的细节

#### 10.3.1 DCN (2017)

$$x_{l+1} = x_0 \odot (W_l x_l + b_l) + x_l$$

**结构**: L 层得到有界的 $L+1$ 阶交叉。

**复杂度**: $O(L \cdot d)$, 比 DNN 节省。

#### 10.3.2 DCN-v2 (2020)

**改进**: 把 $W$ 从向量升级为矩阵。

$$x_{l+1} = x_0 \odot (W_l x_l + b_l) + x_l$$

其中 $W_l \in \mathbb{R}^{d \times d}$。

```python
class DCNv2(nn.Module):
    """DCN-v2"""
    def __init__(self, dim, n_layers=3):
        super().__init__()
        self.W = nn.ParameterList([
            nn.Parameter(torch.randn(dim, dim) * 0.01) for _ in range(n_layers)
        ])
        self.b = nn.ParameterList([
            nn.Parameter(torch.zeros(dim)) for _ in range(n_layers)
        ])

    def forward(self, x0):
        x = x0
        for w, b in zip(self.W, self.b):
            xw = x @ w  # (B, d)
            x = x0 * xw + b + x  # 残差
        return x
```

**效果**: 比 DCN-v1 表达力更强, 工业主流。

#### 10.3.3 DCN-Mix (2023)

**改进**: 混合专家 (MoE) 的 Cross Network。

```python
class DCNMix(nn.Module):
    """DCN with MoE"""
    def __init__(self, dim, num_experts=4, n_layers=3):
        super().__init__()
        self.experts = nn.ModuleList([
            nn.Linear(dim, dim) for _ in range(num_experts)
        ])
        self.gates = nn.Linear(dim, num_experts)
        self.n_layers = n_layers

    def forward(self, x0):
        x = x0
        for _ in range(self.n_layers):
            expert_outs = torch.stack([e(x) for e in self.experts], dim=1)
            gate_w = F.softmax(self.gates(x), dim=-1).unsqueeze(-1)
            x_moe = (expert_outs * gate_w).sum(dim=1)
            x = x0 * x_moe + x
        return x
```

### 10.4 特征交叉的工业实践

#### 10.4.1 阿里 DIEN

在 DIN 基础上加兴趣演化:
- GRU 建模兴趣时序
- AU (Activation Unit) 计算兴趣权重
- 兴趣抽取 + 兴趣演化

```python
class DIEN(nn.Module):
    """Deep Interest Evolution Network"""
    def __init__(self, num_items, embed_dim=32):
        super().__init__()
        self.item_emb = nn.Embedding(num_items, embed_dim)
        # 兴趣抽取
        self.gru = nn.GRU(embed_dim, embed_dim, batch_first=True)
        # 兴趣演化 (AU)
        self.attention = nn.Sequential(
            nn.Linear(4 * embed_dim, 80), nn.ReLU(),
            nn.Linear(80, 1)
        )
        # 输出
        self.mlp = nn.Sequential(
            nn.Linear(embed_dim * 3, 200), nn.ReLU(),
            nn.Linear(200, 80), nn.ReLU(),
            nn.Linear(80, 1)
        )

    def forward(self, user_feat, history, neg_history, target_item):
        # 兴趣抽取
        history_emb = self.item_emb(history)  # (B, L, d)
        interest, _ = self.gru(history_emb)

        # 兴趣演化 (辅助损失: 预测下一个点击)
        # ...

        # Target-Item Attention
        target_emb = self.item_emb(target_item)
        attn_input = torch.cat([interest, target_emb.unsqueeze(1).expand_as(interest),
                                interest * target_emb.unsqueeze(1),
                                interest - target_emb.unsqueeze(1)], dim=-1)
        attn_weights = F.softmax(self.attention(attn_input).squeeze(-1), dim=-1)
        user_interest = (interest * attn_weights.unsqueeze(-1)).sum(dim=1)

        # 拼接
        x = torch.cat([user_feat, user_interest, target_emb], dim=-1)
        return torch.sigmoid(self.mlp(x).squeeze(-1))
```

#### 10.4.3 字节 BST (Behavior Sequence Transformer)

```python
class BST(nn.Module):
    """Behavior Sequence Transformer"""
    def __init__(self, num_items, embed_dim=32, n_layers=2, n_heads=4):
        super().__init__()
        self.item_emb = nn.Embedding(num_items, embed_dim)
        self.position_emb = nn.Embedding(500, embed_dim)
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=embed_dim, nhead=n_heads, dim_feedforward=128
        )
        self.transformer = nn.TransformerEncoder(encoder_layer, num_layers=n_layers)
        self.head = nn.Sequential(
            nn.Linear(embed_dim, 64), nn.ReLU(),
            nn.Linear(64, 1)
        )

    def forward(self, history, target_item):
        B, L = history.shape
        positions = torch.arange(L, device=history.device).unsqueeze(0).expand(B, -1)
        h = self.item_emb(history) + self.position_emb(positions)
        h = self.transformer(h.transpose(0, 1)).transpose(0, 1)  # (B, L, d)
        # 取最后一个或池化
        seq_emb = h.mean(dim=1)
        target_emb = self.item_emb(target_item)
        x = seq_emb + target_emb
        return torch.sigmoid(self.head(x).squeeze(-1))
```

### 10.5 特征交叉的"度"如何把握

**过度交叉** (n 阶交互):
- 参数量爆炸
- 训练慢
- 容易过拟合

**过少交叉** (1 阶):
- 表达力不足
- 性能有限

**实践**: 2-3 阶交互最常用 (FM/DCN 2-3 层)。

### 10.6 特征交叉 vs GR (生成式推荐)

**GR 的视角**: 注意力机制隐式建模所有特征交叉。

**关系**:
- GR 用 Attention 实现"全连接"交叉
- 显式交叉 (FM/DCN) 在 GR 中仍可用, 作为辅助
- 冷启动/小数据时, 显式交叉更稳

**实践**: GR + DCN-v2 双塔, 互补长短。

```python
class GRWithDCN(nn.Module):
    """GR + DCN 混合"""
    def __init__(self, num_feat, embed_dim=32):
        super().__init__()
        self.emb = nn.Embedding(num_feat, embed_dim)
        # DCN 分支
        self.dcn = DCNv2(embed_dim, n_layers=2)
        # Attention 分支 (GR)
        self.attn = nn.MultiheadAttention(embed_dim, nhead=4)
        # 融合
        self.head = nn.Linear(embed_dim * 2, 1)

    def forward(self, x):
        # DCN 分支
        dcn_out = self.dcn(x)
        # Attention 分支
        attn_out, _ = self.attn(x, x, x)
        # 融合
        fused = torch.cat([dcn_out, attn_out.mean(dim=1)], dim=-1)
        return torch.sigmoid(self.head(fused).squeeze(-1))
```

## 12. 特征工程的常见坑

### 12.1 坑 1: 特征穿越 (Leakage)

**症状**: 离线 AUC 高, 线上 AUC 跌。

**原因**: 用未来信息训练 (如用当天的后续点击)。

**解决**: 严格按时间切分, 排除穿越。

### 12.2 坑 2: 特征不一致

**症状**: 离线涨, 线上不涨。

**原因**: 训练和推理时的特征处理方式不同。

**解决**: 统一特征处理 SDK, 训练/推理共用。

### 12.3 坑 3: 特征分布漂移

**症状**: 模型上线一段时间后效果下降。

**原因**: 用户行为/物品分布变化。

**解决**: 在线监控特征分布, 周期性重训。

### 12.4 坑 4: 长尾物品特征稀缺

**症状**: 长尾物品 Embedding 质量差。

**原因**: 出现频次低, 训练不充分。

**解决**: 频率归一化 + 共享 Embedding。

### 12.5 坑 5: 特征维度爆炸

**症状**: 模型过大, 训练慢。

**原因**: 一次性 Embedding 维度堆太高。

**解决**: 分层 Embedding + 维度搜索。

### 12.6 坑 6: 数值未归一化

**症状**: Loss 不收敛。

**原因**: 不同量纲特征影响梯度。

**解决**: 训练前必须归一化。

## 13. 特征交叉的常见面试题

### 13.1 FM 怎么把 O(n²) 降到 O(nk)?

**答案**: 平方和差恒等式。
$$\sum_{i<j}\langle v_i, v_j\rangle x_i x_j = \frac{1}{2}\left[(\sum_i v_i x_i)^2 - \sum_i v_i^2 x_i^2\right]$$

**计算**: $O(nk)$ (平方), 而不是 $O(n^2 k)$。

### 13.2 DeepFM wide 和 deep 共享什么?

**答案**: 共享 Embedding 层。

**意义**:
- 减少参数 (不需要两套 Embedding)
- 训练更高效 (共享梯度)

### 13.3 DCN 每层交叉阶数怎么增长?

**答案**: 每层 +1 阶。

**例如**: 3 层 DCN 得到 4 阶交互 (4-way interaction)。

**理由**: $x_{l+1} = x_0 \odot (W_l x_l + b_l) + x_l$, $x_l$ 是 $l+1$ 阶, $x_0 \odot x_l$ 是 $l+2$ 阶。

### 13.4 DeepFM vs DCN 怎么选?

| 维度 | DeepFM | DCN |
| :--- | :--- | :--- |
| 交叉方式 | FM (2阶) + DNN (高阶) | Cross Network (显式高阶) |
| 参数 | 多 (FM + DNN) | 省 (仅 Cross) |
| 表达力 | 中 | 高 |
| 可解释 | 中 | 高 (Cross 阶数清晰) |

**实践**: 数据量大用 DCN, 数据量小用 DeepFM。

### 13.5 显式交叉与隐式交叉哪个好?

**显式交叉**:
- 优点: 训练高效, 少数据可用, 可解释
- 缺点: 表达力有限

**隐式交叉 (DNN/Attention)**:
- 优点: 表达力强, 通用
- 缺点: 低阶难学, 数据需求大

**实践**: 两者结合 (DeepFM 风格), 工业标配。

### 13.6 特征工程如何避免穿越?

1. 严格按时间切分训练/验证
2. 排除"未来信息"特征
3. 实时特征用 "请求时刻之前" 的数据
4. 离线/在线特征处理一致
5. 加穿越检测代码 (见 9.6)

### 13.7 Embedding 维度怎么选?

**经验公式**: $d = \min(64, \max(8, \text{vocab}^{0.25} \times 4))$。

**例子**: vocab=1万 → d=32, vocab=100万 → d=64, vocab=1亿 → d=64。

**调整**: 用 PCA 看"保留 95% 能量"的维度。

### 13.8 类别特征用 Embedding 还是 One-hot?

**Embedding** 几乎总是更好:
- 参数少 (vocab × d, vs vocab × num_feat)
- 端到端学习
- 共享信息

**One-hot** 仅用于:
- 类别少 (< 10)
- 需要显式权重解释

### 13.9 数值特征用连续值还是分桶?

**分桶 + Embedding** 通常更好:
- 抗异常值
- 引入非线性
- 与类别特征统一处理

**连续值** 适用于:
- 归一化后近似高斯分布
- 与其他特征 scale 一致

## 14. 特征交叉的工业级代码

### 14.1 完整 DNN+DCN 混合模型

```python
class DNNDCN(nn.Module):
    """DNN + DCN 混合排序模型"""
    def __init__(self, num_features_list, embed_dim=16, dcn_layers=3, hidden=[256, 128, 64]):
        super().__init__()
        # Embedding 层
        self.embeddings = nn.ModuleList([
            nn.Embedding(num_feat, embed_dim) for num_feat in num_features_list
        ])
        input_dim = embed_dim * len(num_features_list)

        # DCN 分支
        self.dcn = DCNv2(input_dim, n_layers=dcn_layers)

        # DNN 分支
        layers = []
        d = input_dim
        for h in hidden:
            layers += [nn.Linear(d, h), nn.ReLU(), nn.BatchNorm1d(h), nn.Dropout(0.2)]
            d = h
        self.dnn = nn.Sequential(*layers)

        # 输出
        self.head = nn.Linear(input_dim + hidden[-1], 1)

    def forward(self, features):
        # features: list of (B,) 特征 ID
        embs = [emb(f) for emb, f in zip(self.embeddings, features)]
        x = torch.cat(embs, dim=-1)

        # DCN
        dcn_out = self.dcn(x)

        # DNN
        dnn_out = self.dnn(x)

        # 融合
        fused = torch.cat([dcn_out, dnn_out], dim=-1)
        return torch.sigmoid(self.head(fused).squeeze(-1))
```

### 14.2 训练 Pipeline

```python
class FeatureCrossTrainer:
    """特征交叉训练器"""
    def __init__(self, model, lr=1e-3, weight_decay=1e-5):
        self.model = model
        self.optimizer = torch.optim.AdamW(
            [
                {'params': model.embeddings.parameters(), 'lr': 1e-2},  # Embedding 单独大 lr
                {'params': model.dcn.parameters(), 'lr': 5e-4},
                {'params': model.dnn.parameters(), 'lr': 5e-4},
                {'params': model.head.parameters(), 'lr': 1e-3}
            ],
            weight_decay=weight_decay
        )
        self.scheduler = torch.optim.lr_scheduler.StepLR(self.optimizer, step_size=10, gamma=0.5)

    def train_step(self, batch):
        # 解析特征
        features = [batch[f] for f in batch if f.startswith('feat_')]
        labels = batch['label']

        # 前向
        logits = self.model(features)
        loss = F.binary_cross_entropy_with_logits(logits, labels.float())

        # 反向
        self.optimizer.zero_grad()
        loss.backward()
        torch.nn.utils.clip_grad_norm_(self.model.parameters(), 1.0)
        self.optimizer.step()

        return loss.item()
```

### 14.3 特征工程 Pipeline

```python
class FeaturePipeline:
    """特征工程 Pipeline"""
    def __init__(self):
        self.feature_encoders = {}
        self.scalers = {}

    def register_categorical(self, name, vocab):
        """注册类别特征"""
        self.feature_encoders[name] = CategoricalEncoder(vocab)

    def register_numerical(self, name, mean, std):
        """注册数值特征"""
        self.scalers[name] = FeatureScaler(mean, std)

    def process(self, raw_features):
        """处理原始特征"""
        processed = {}
        for name, value in raw_features.items():
            if name in self.feature_encoders:
                processed[name] = self.feature_encoders[name].transform(value)
            elif name in self.scalers:
                processed[name] = self.scalers[name](value)
            else:
                processed[name] = value
        return processed
```

## 16. 特征工程与 GR 的深度结合

### 16.1 GR 如何"自动"做特征工程

**GR 的视角**: 不需要显式特征工程。

- 输入: ID 序列 (用户行为序列 + 目标物品)

- 输出: 排序分数

**优势**:
- 不需要特征工程
- 端到端
- 跨域迁移容易

**劣势**:
- 训练数据需求大
- 训练成本高
- 难解释

### 16.2 显式特征在 GR 中的作用

**现状**: 即使有 GR, 工业仍保留显式特征。

**原因**:
1. **冷启动**: 新用户/新物品没有足够行为序列
2. **侧信息**: 价格、品牌等"非行为"信息 GR 难用
3. **可解释**: 显式特征便于调试和归因
4. **效率**: 显式特征快速, 比 GR 注意力快

**实践**: GR 主干 + 显式特征 (DCN-v2) 辅助。

```python
class GRWithFeatureCross(nn.Module):
    """GR + 显式特征交叉"""
    def __init__(self, num_features_list, num_items, embed_dim=32):
        super().__init__()
        # 显式特征 Embedding
        self.feature_emb = nn.ModuleList([
            nn.Embedding(num_feat, embed_dim) for num_feat in num_features_list
        ])
        self.dcn = DCNv2(embed_dim * len(num_features_list), n_layers=2)

        # GR 主干 (Transformer)
        self.item_emb = nn.Embedding(num_items, embed_dim)
        self.transformer = nn.TransformerDecoder(...)

        # 融合
        self.fusion = nn.Linear(embed_dim * 2, 1)

    def forward(self, features, history, target):
        # 显式特征交叉
        feat_embs = [emb(f) for emb, f in zip(self.feature_emb, features)]
        feat_x = torch.cat(feat_embs, dim=-1)
        dcn_out = self.dcn(feat_x)

        # GR 主干
        history_emb = self.item_emb(history)
        target_emb = self.item_emb(target)
        gr_out = self.transformer(history_emb, target_emb)

        # 融合
        fused = torch.cat([dcn_out, gr_out], dim=-1)
        return self.fusion(fused)
```

#### 18.1.3 多模态融合

**早期融合**: 特征拼接
$$f_{\text{multi}} = [\text{text}; \text{image}; \text{behavior}]$$

**中期融合**: 跨模态 Attention
$$\text{Attn}(Q_{\text{text}}, K_{\text{image}}, V_{\text{image}})$$

**晚期融合**: 各自打分, 最后融合
$$\text{score} = w_t \cdot s_t + w_i \cdot s_i + w_b \cdot s_b$$

```python
class MultimodalFusion(nn.Module):
    """多模态融合"""
    def __init__(self, text_dim=768, image_dim=2048, hidden_dim=256):
        super().__init__()
        self.text_proj = nn.Linear(text_dim, hidden_dim)
        self.image_proj = nn.Linear(image_dim, hidden_dim)
        # 跨模态 Attention
        self.cross_attn = nn.MultiheadAttention(hidden_dim, num_heads=4)
        # 输出
        self.head = nn.Sequential(
            nn.Linear(hidden_dim * 2, 64), nn.ReLU(),
            nn.Linear(64, 1)
        )

    def forward(self, text_feat, image_feat):
        t = self.text_proj(text_feat).unsqueeze(0)  # (1, B, d)
        i = self.image_proj(image_feat).unsqueeze(0)  # (1, B, d)
        # 跨模态 Attention
        attn_out, _ = self.cross_attn(t, i, i)
        attn_out = attn_out.squeeze(0)
        # 拼接
        fused = torch.cat([attn_out, t.squeeze(0)], dim=-1)
        return self.head(fused)
```

```python
class TemporalFeatureEncoder:
    """时间特征编码"""
    def __init__(self, dim=16):
        self.dim = dim

    def encode_hour(self, hour):
        """小时编码"""
        angle = 2 * np.pi * hour / 24
        return np.array([
            np.sin(angle * (i // 2 + 1)) if i % 2 == 0 else np.cos(angle * (i // 2 + 1))
            for i in range(self.dim)
        ])

    def encode_day_of_week(self, dow):
        """星期编码"""
        angle = 2 * np.pi * dow / 7
        return np.array([
            np.sin(angle * (i // 2 + 1)) if i % 2 == 0 else np.cos(angle * (i // 2 + 1))
            for i in range(self.dim)
        ])

    def encode_relative_time(self, dt, current_dt):
        """相对时间编码"""
        delta = (current_dt - dt).total_seconds() / 3600  # 小时
        return np.log1p(delta)  # log 变换
```

### 18.5 自动化特征工程 (AutoFE)

**AutoFE**: 用算法自动发现好的特征。

**方法**:

- 神经网络自动学习 (AutoInt, AutoFM)
- LLM 引导的特征工程

```python
class AutoFE:
    """自动化特征工程"""
    def __init__(self, base_features, model):
        self.base_features = base_features
        self.model = model

    def search(self, n_iterations=100):
        """特征组合搜索"""
        best_features = self.base_features
        best_score = self.evaluate(best_features)

        for _ in range(n_iterations):
            # 1) 随机组合
            new_features = self.random_combine(self.base_features)
            # 2) 评估
            new_score = self.evaluate(new_features)
            if new_score > best_score:
                best_score = new_score
                best_features = new_features

        return best_features

    def random_combine(self, features):
        """随机特征组合"""
        ops = ['+', '-', '*', '/']
        new_feature = {}
        for _ in range(3):
            f1 = random.choice(features)
            f2 = random.choice(features)
            op = random.choice(ops)
            new_feature[f'{f1}_{op}_{f2}'] = self.apply_op(f1, f2, op)
        return new_feature
```

### 18.6 特征工程的常见陷阱与解决

**陷阱 1: 特征穿越 (Feature Leakage)**

```python
def detect_leakage(train_df, valid_df):
    """检测特征穿越"""
    # 1) 时间穿越
    train_max_time = train_df['timestamp'].max()
    valid_min_time = valid_df['timestamp'].min()
    if train_max_time >= valid_min_time:
        return "Time leakage detected!"

    # 2) 物品穿越
    train_items = set(train_df['item_id'].unique())
    valid_items = set(valid_df['item_id'].unique())
    if len(train_items & valid_items) / len(valid_items) < 0.5:
        return "Item coverage too low!"

    # 3) 标签穿越
    if 'next_click_time' in train_df.columns:
        return "Possible future leakage: next_click_time!"

    return "OK"
```

**陷阱 2: 特征分布不一致**

```python
def check_distribution_drift(train_feat, valid_feat, online_feat):
    """检查特征分布漂移"""
    from scipy.stats import ks_2samp
    drift_score_1 = ks_2samp(train_feat, valid_feat).statistic
    drift_score_2 = ks_2samp(train_feat, online_feat).statistic
    if drift_score_1 > 0.1 or drift_score_2 > 0.1:
        return f"Distribution drift detected! ks={drift_score_1:.3f}, online={drift_score_2:.3f}"
    return "OK"
```

### 20.1 怎么判断特征工程是否到位?

| :--- | :--- |

| 业务理解 | 特征归因 |

**标志**:
- AUC 涨到合理水平 (不过拟合)
- 特征重要性分布合理 (Top 特征是核心业务特征)
- 离线涨, 线上也涨

### 20.2 数值特征分桶后, 模型如何学?

**学法**: 把分桶 ID 当类别特征, Embedding 后输入模型。

```python
class BucketizedEmbedding(nn.Module):
    """分桶后 Embedding"""
    def __init__(self, num_buckets, embed_dim=16):
        super().__init__()
        self.embedding = nn.Embedding(num_buckets, embed_dim)

    def forward(self, bucket_ids):

```

**优势**:
- 引入非线性 (分桶边界跳跃)
- 抗异常值 (统一处理)
- 与类别特征统一处理

### 20.3 时序特征如何避免穿越?

**原则**: 只能用"过去"的信息, 不用"未来"的信息。

**例子**:
- ✅ "距上次点击时间" (基于历史)
- ❌ "距下次点击时间" (未来)
- ✅ "近 7 天点击次数" (历史聚合)
- ❌ "未来 7 天点击次数" (未来)

### 20.4 Embedding 是否需要共享?

**共享 Embedding** 的场景:
- 召回-粗排-精排 (减少参数, 训练高效)
- 多任务学习 (CTR + CVR 共享物品 Embedding)

**不共享** 的场景:
- 不同场景的 Embedding (电商 vs 视频)
- 不同任务的 Embedding (CTR Embedding vs CVR Embedding)

**实践**: 业务相关共享, 不相关独立。

### 20.5 特征交叉的阶数上限?

**经验**: 2-3 阶足够。

**理由**:
- 高阶交互数据稀疏 (4 阶组合可能 0 样本)
- 高阶交互参数量爆炸
- 高阶交互训练慢

**DCN 3-4 层** 是工业典型配置。

### 20.6 怎么判断显式交叉 vs 隐式交叉哪个好?

**经验**:
- 数据量 < 1亿: 显式交叉 (FM/DCN) 更稳
- 数据量 > 10亿: 隐式交叉 (DNN) 表达力更强
- 工业: 两者并联 (DeepFM 风格)

**A/B 测试** 是唯一判断方法。

### 20.7 多模态特征的难点?

1. **维度差异**: 文本 768 维, 图像 2048 维
2. **语义对齐**: 文本 "好看的电影" 对应哪些视觉特征
3. **缺失处理**: 文本缺失、图像缺失
4. **跨模态检索**: 文本→图像匹配

**解决**: 跨模态预训练 (CLIP) + 多模态融合网络。

### 20.8 Embedding 初始化用什么?

## 24. 特征工程的"工程哲学"

### 24.1 特征工程是 80/20 法则的体现

**80% 的效果来自 20% 的核心特征**:
- 用户画像 (年龄/性别/地域)
- 物品画像 (类目/品牌/价格)
- 行为历史 (点击/购买)
- Context (时间/位置)

**20% 的优化带来 80% 的边际效果**:
- 多模态 Embedding
- 跨域知识
- 因果特征

**实践**: 先做核心特征, 再做边角优化。

### 24.2 特征工程的"四象限"

按"重要性 × 难度"分:

| | 低难度 | 高难度 |
| :--- | :--- | :--- |
| **高价值** | 数值分桶、ID Embedding | 多模态 Embedding |
| **低价值** | 时序拆分、频次统计 | 因果特征、联邦特征 |

**实践**: 先做"高价值低难度", 再做"高价值高难度"。

### 24.3 特征工程的"工程化思维"

**特征流水线**:
```text
原始数据 → 特征抽取 → 特征转换 → 特征存储 → 特征服务
   ↓          ↓           ↓         ↓         ↓
  业务       工程        数学      工程       工程
```

**特征监控**:
- 覆盖率 (缺失率)
- 分布 (KS 检验)
- 时延 (P99)
- 重要性 (SHAP)

**特征版本**:
- 训练/推理用同一份
- 变更记录 (Changelog)
- 灰度发布

### 24.4 特征工程的"业务理解"

**业务理解 > 模型技巧**:
- 电商: 价格、销量、品牌最重要
- 信息流: 时长、互动最重要
- 视频: 完播率、作者最重要

**业务理解的方法**:
1. 与业务方深度沟通
2. 数据分析 (EDA)
3. 特征归因
4. 离线/在线对比

### 24.5 特征工程的"复利效应"

**差的特征有"负债"**:

- 一个不一致特征, 调试一周

**实践**: 严格保证特征质量, 不留隐患。

## 26. 特征工程的常见反模式

### 26.1 反模式 1: 过度依赖模型, 忽视特征

**症状**: 用 SOTA 模型 + 简单特征, 效果还是差。

**原因**: 特征工程不到位, 模型学不到东西。

**解决**: 回过头来做特征, 别迷信 SOTA 模型。

### 26.2 反模式 2: 特征堆砌

**症状**: 加 1000 个特征, 模型效果差。

**原因**: 噪声特征干扰 + 过拟合。

**解决**: 特征选择, 只保留 Top-K 重要特征。

### 26.3 反模式 3: 忽视一致性

**症状**: 离线涨, 线上不涨。

**原因**: 训练/推理特征处理不一致。

**解决**: 统一 SDK, 强制类型检查。

### 26.4 反模式 4: 忽视穿越

**症状**: 离线 AUC 高得离谱, 线上崩。

**原因**: 用了未来信息。

**解决**: 严格按时间切分, 加穿越检测。

### 26.5 反模式 5: 忽视长尾

**症状**: 头部物品表现好, 长尾物品表现差。

**原因**: 长尾物品训练数据少, Embedding 质量差。

**解决**: 频率归一化 + 共享 Embedding + 内容特征。

## 27. 特征工程与 LLM 的结合

### 27.1 LLM 作为特征提取器

**用法**: 用 LLM 编码文本特征。

```python
class LLMFeatureEncoder:
    """LLM 特征编码"""
    def __init__(self, model_name='sentence-transformers/all-MiniLM-L6-v2'):
        from sentence_transformers import SentenceTransformer
        self.model = SentenceTransformer(model_name)

    def encode(self, texts):
        return self.model.encode(texts, convert_to_tensor=True)
```

### 27.2 LLM 作为特征工程助手

**用法**: 让 LLM 帮你设计新特征。

```python
def llm_suggest_features(feature_names, business_problem):
    prompt = f"""业务问题: {business_problem}
已有特征: {feature_names}

请建议 10 个新的特征组合或衍生特征, 要求:
1. 业务上有意义
2. 数据上可获取
3. 对模型有信息量

请按"特征名 - 计算方式 - 预期效果"格式输出。
"""
    return llm.generate(prompt)
```

### 27.3 LLM 推理时的特征融合

**用法**: LLM 推理时直接消费文本特征。

```python
class LLMRankerWithFeatures:
    """LLM + 显式特征融合"""
    def __init__(self):
        self.llm = LLMModel(...)
        self.feature_proj = nn.Linear(num_features, d_model)
        self.fusion = nn.Linear(d_model * 2, 1)

    def forward(self, text, features):
        # LLM 编码
        text_emb = self.llm.encode(text)  # (B, d)
        # 显式特征
        feat_emb = self.feature_proj(features)  # (B, d)
        # 融合
        fused = torch.cat([text_emb, feat_emb], dim=-1)
        return self.fusion(fused)
```

### 110. 第 24 章:特征工程与特征交叉 - 工程视角 视角

**核心议题**: 本节从工程视角视角切入,系统展开 "第 24 章:特征工程与特征交叉" 的相关讨论。

**1. 背景与动机**

任何技术或方法的出现都不是孤立的,而是回应特定历史条件下的具体问题。"第 24 章:特征工程与特征交叉" 的发展也不例外。要理解它,必须回到它出现的那个时间点,看清它要解决的真实问题是什么。当时的主流方案有哪些不足? 它的提出填补了哪些空白? 这些问题的回答,决定了我们今天该如何使用它。

从知识论角度看,**技术演进是问题驱动的**——不是先有方案再找问题,而是先有问题再有方案。这个观察可以帮助我们避免"拿着锤子找钉子"的陷阱,真正把方法用对地方。

历史维度上,我们看到三个规律:

1. **从特殊到一般**: 早期方法往往针对特定场景,后期抽象出通用框架。学习的认知规律也是先掌握具体案例,再抽象出一般模式。这种"自下而上"的学习方式,在机器学习模型的设计里反复出现。

2. **从手工到自动**: 经验规则逐步被数据驱动的方法取代。在早期,很多 AI 系统依赖人工编写的规则。统计学习方法的崛起让"从数据中学习"成为可能。深度学习进一步把特征工程也自动化了。今天的大模型时代,我们看到端到端学习从感知扩展到了推理与生成。

3. **从局部到全局**: 关注单个组件,演进到关注整个系统。早期模型评估只关注单点指标,现在更关注全链路的协同效应。这种"系统视角"的转变,与软件工程从单体架构到微服务架构的演进高度相似。

**2. 工程视角视角的展开**

从工程视角视角出发,我们可以把 "第 24 章:特征工程与特征交叉" 拆解为以下几个层次:

**第一层: 概念层** —— 这是最抽象的层次,定义了我们要研究的对象是什么。例如,"推荐系统"在概念层是一个"为用户从物品集合中筛选合适物品"的问题。这个层次的特点是清晰、稳定、不易变化。一个好的概念定义应该具备几个特征:可操作性、可测量性、可扩展性。
