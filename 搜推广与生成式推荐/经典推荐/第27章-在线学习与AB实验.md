## 1. 为什么要在线/增量学习

- **时效性**: 新闻/短视频/电商大促, 兴趣与物料分钟级变化, 天级全量训练太慢。
- **分布漂移**: 用户行为、物料分布持续变化, 离线模型很快过时。
- **冷启动**: 新物料需要尽快积累反馈进入模型。

**方案谱系**: 全量离线 → 天级增量 → 小时级增量 → 实时流式(online learning)。越实时工程越复杂, 按业务时效需求选。

---

## 2. 实时训练 pipeline

```text
用户实时行为 → 消息队列(Kafka) → 实时特征拼接(样本流)
   → 流式训练(参数服务器/FTRL/在线SGD) → 模型热更新 → 在线服务
```

关键组件:
- **实时样本**: 曝光与反馈(点击/转化)join, 处理**延迟反馈**(转化可能几小时后到)。
- **在线优化器**: FTRL(稀疏 + 正则, 经典 CTR 在线学习)或在线 SGD/Adam。
- **模型热更新**: 增量更新 Embedding + 定期全量校准, 防在线漂移累积。

```python
# FTRL 在线更新单特征权重 (概念)
def ftrl_update(z, n, g, alpha=0.1, beta=1.0, l1=1.0, l2=1.0):
    sigma = ((n + g*g)**0.5 - n**0.5) / alpha
    z += g - sigma * w_prev
    n += g*g
    if abs(z) <= l1:
        w = 0.0                        # L1 稀疏化
    else:
        w = -(z - _sign(z)*l1) / ((beta + n**0.5)/alpha + l2)
    return w, z, n
```

## 3. 延迟反馈问题

转化(购买)往往在曝光后数小时才发生。若样本立即标"负"再纠正, 会引入偏差。方案:
- **等待窗口**: 延迟到窗口关闭再定标(牺牲时效)。
- **延迟反馈建模**: 建模转化延迟分布(如指数), 用重要性加权纠偏(DFM)。

## 4. AB 实验设计(科学迭代的核心)

### 4.1 基本要素

- **随机分流**: 用户 hash 分桶, 保证组间同质。
- **唯一变量**: 实验组与对照组只差一个改动。
- **核心指标 + 护栏指标**: 如 CTR↑ 但要看时长/留存不掉(护栏)。

### 4.2 显著性检验

判断差异是真实还是噪声。两组转化率用**双样本比例检验**:

```python
from scipy import stats
import numpy as np
def ab_significance(clicks_a, n_a, clicks_b, n_b):
    p_a, p_b = clicks_a/n_a, clicks_b/n_b
    p = (clicks_a + clicks_b)/(n_a + n_b)          # 合并比例
    se = np.sqrt(p*(1-p)*(1/n_a + 1/n_b))
    z = (p_b - p_a)/se
    pval = 2*(1 - stats.norm.cdf(abs(z)))          # 双尾 p 值
    return z, pval                                 # pval<0.05 认为显著
```

### 4.3 常见陷阱

- **样本量不足**: 需按最小可检测效应(MDE)算样本量, 否则无统计功效。
- **多重检验**: 同时看多指标, 假阳性膨胀 → Bonferroni 校正。
- **偷看(peeking)**: 反复看结果提前下结论, 用序贯检验或固定时长。
- **辛普森悖论**: 分层与整体结论相反, 注意分流均匀。

## 5. 反馈闭环与偏差治理

模型影响曝光 → 曝光影响反馈 → 反馈训练模型, 形成闭环, 易放大偏差:

| 偏差 | 成因 | 缓解 |
| :--- | :--- | :--- |
| 位置偏差 | 高位天然高点击 | 位置作特征 / 倾向得分 |
| 曝光偏差 | 只见曝光过的 item | 探索 / 全空间建模 |
| 流行度偏差 | 热门被反复推 | 去偏采样 / 因果推断 |
| 幸存者偏差 | 只学到被推荐的反馈 | 随机流量收集无偏数据 |

**探索-利用(E&E)**: 用 ε-greedy / Thompson Sampling / UCB 给新物料曝光机会, 打破闭环(见 [数学基础 系统思维案例8](../../基础/数学/数学基础/第07章-系统思维/第07章-08-案例Exploration-Exploitation.md))。

## 7. 在线学习的深度展开

### 7.1 在线学习的工业必要性

**业务场景的时效性需求**:

| 业务 | 时效性需求 | 离线训练的局限 |
| :--- | :--- | :--- |
| 新闻 | 秒级 | 天级不够 |
| 短视频 | 分钟级 | 小时级不够 |
| 直播 | 秒级 | 完全不够 |
| 电商 (大促) | 小时级 | 天级勉强 |
| 音乐 | 天级 | 离线 OK |
| 阅读 | 天级 | 离线 OK |

**结论**: 内容时效性越强的业务, 越需要在线学习。

### 7.2 在线学习 vs 离线学习的本质区别

**离线学习**:
- 数据: 全量历史数据
- 频率: 天/周
- 反馈: 完整 (点击/转化已发生)
- 优势: 数据全, 训练稳定

**在线学习**:
- 数据: 增量流式数据
- 频率: 分钟/秒级
- 反馈: 部分 (转化未发生)
- 优势: 时效性高

**挑战**:
- 数据不完整 (转化延迟)
- 概念漂移 (Concept Drift)
- 训练/服务同步
- 系统复杂度高

### 7.3 实时训练 Pipeline 的细节

**完整架构**:

```text
用户实时行为 → Kafka → Flink (特征拼接 + 样本生成)
                          ↓
                      消息队列
                          ↓
                   Parameter Server (FTRL/AwS)
                          ↓
                   模型参数 → 在线服务
                          ↓
                       用户看到推荐
```

**关键组件**:

**1. 实时特征服务**:
```python
class RealtimeFeatureService:
    def __init__(self):
        self.redis = RedisClient()
        self.kafka = KafkaConsumer('user_actions')

    def get_user_features(self, user_id):
        # 从 Redis 获取实时特征
        features = self.redis.hgetall(f'user:{user_id}')
        return features

    def consume_actions(self):
        for msg in self.kafka:
            user_id = msg.value['user_id']
            action = msg.value['action']
            # 更新实时特征
            self.redis.hincrby(f'user:{user_id}', f'action_{action}', 1)
            self.redis.hset(f'user:{user_id}', 'last_action_time', msg.timestamp)
```

**2. 样本生成**:
```python
class SampleGenerator:
    """样本生成器: 曝光 + 反馈 join"""
    def __init__(self):
        self.exposure_buffer = {}  # user_id -> [exposure_log]

    def on_exposure(self, user_id, items, timestamp):
        """曝光事件"""
        self.exposure_buffer.setdefault(user_id, []).append({
            'items': items, 'timestamp': timestamp
        })

    def on_click(self, user_id, item_id, timestamp):
        """点击事件"""
        # 找到对应曝光
        for exp in self.exposure_buffer.get(user_id, []):
            if item_id in exp['items']:
                return {
                    'user_id': user_id,
                    'item_id': item_id,
                    'label': 1,
                    'exposure_time': exp['timestamp'],
                    'click_time': timestamp
                }
        return None
```

**3. 在线优化器**:
```python
class FTRLOnline:
    """FTRL 在线优化器"""
    def __init__(self, alpha=0.1, beta=1.0, l1=1.0, l2=1.0):
        self.alpha = alpha
        self.beta = beta
        self.l1 = l1
        self.l2 = l2
        self.z = {}  # 累计梯度
        self.n = {}  # 梯度平方和

    def update(self, feature_id, gradient):
        """单次参数更新"""
        if feature_id not in self.z:
            self.z[feature_id] = 0.0
            self.n[feature_id] = 0.0

        # FTRL 更新公式
        self.n[feature_id] += gradient ** 2
        sigma = (np.sqrt(self.n[feature_id]) - np.sqrt(self.n[feature_id] - gradient**2)) / self.alpha
        self.z[feature_id] += gradient - sigma * self._get_weight(feature_id)

        # 计算新权重 (含 L1 稀疏)
        if abs(self.z[feature_id]) <= self.l1:
            return 0.0
        else:
            sign = np.sign(self.z[feature_id])
            return -(self.z[feature_id] - sign * self.l1) / (
                (self.beta + np.sqrt(self.n[feature_id])) / self.alpha + self.l2
            )
```

### 7.5 概念漂移 (Concept Drift) 的处理

**类型**:
- **突然漂移**: 突发事件 (新闻)
- **渐变漂移**: 季节性变化 (节假日)
- **增量漂移**: 用户偏好缓慢变化

**检测方法**:

```python
class DriftDetector:
    """概念漂移检测"""
    def __init__(self, window_size=1000):
        self.window_size = window_size
        self.reference_window = []
        self.current_window = []

    def add(self, sample):
        """添加样本"""
        self.current_window.append(sample)
        if len(self.current_window) > self.window_size:
            self.reference_window = self.current_window[:self.window_size // 2]
            self.current_window = self.current_window[self.window_size // 2:]

    def detect(self):
        """检测漂移"""
        if len(self.reference_window) < 100 or len(self.current_window) < 100:
            return False

        # 用 KS 检验比较两个窗口的分布
        from scipy.stats import ks_2samp
        ks_stat, p_value = ks_2samp(
            self.reference_window, self.current_window
        )
        return p_value < 0.01  # 显著漂移
```

**应对**:
- 滑动窗口训练
- 在线持续学习
- 周期性全量重训

### 7.6 在线学习的常见坑

**坑 1: 在线学习与离线模型冲突**

在线 FTRL 实时更新 Embedding, 但全量训练每 N 天一次, 两者不同步。

**解决**: 在线只更新"热特征" Embedding, 冷特征等全量训练。

**坑 2: 转化延迟未处理**

电商场景, 转化 (购买) 可能在曝光后 24 小时才发生, 在线立即标"负"会引入偏差。

**解决**: 见下文"延迟反馈"。

**坑 3: 在线训练算力爆炸**

分钟级训练, 每秒上万样本, 算力需求大。

**解决**:
- 用 Parameter Server 异步训练
- 只更新"高活跃"用户/物品
- 用简单模型 (LR/FM) 在线训练

## 8. 延迟反馈 (Delayed Feedback) 的深度展开

### 8.1 延迟反馈的本质

**场景**: 电商转化可能在曝光后 24-72 小时才发生。

**问题**:
- 样本立即标"负" → 错把"未来会转化"的样本当负样本
- 样本等待 72 小时 → 损失时效性

**折中**: 用统计模型建模延迟分布。

### 8.2 延迟反馈模型 (DFM)

**假设**: 转化延迟服从某分布 (常用指数分布)。

$$P(\text{conversion at time } t | \text{will convert}) = \lambda e^{-\lambda t}$$

```python
class DelayedFeedbackModel:
    """延迟反馈模型"""
    def __init__(self):
        self.lambda_param = nn.Parameter(torch.tensor(1.0))  # 指数分布参数

    def predict_conversion_prob(self, exposure_time, current_time):
        """预测转化概率"""
        elapsed = current_time - exposure_time
        # P(未转化 | 曝光 t 秒后)
        p_not_yet = torch.exp(-self.lambda_param * elapsed)
        return 1 - p_not_yet
```

**训练**:
- 正样本 (有转化): 直接用真实标签
- 负样本 (无转化): 用 P(确实未转化) 加权

```python
def delayed_loss(pred_logits, true_labels, exposure_times, current_time):
    """延迟反馈损失"""
    loss = 0
    for logit, label, t_exp, t_curr in zip(pred_logits, true_labels, exposure_times, current_time):
        elapsed = t_curr - t_exp
        # 负样本的转化概率 (基于指数分布)
        p_conversion = 1 - torch.exp(-lambda * elapsed)
        # 重要性权重
        weight = label + (1 - label) * p_conversion
        loss += weight * F.binary_cross_entropy_with_logits(logit, label)
    return loss / len(pred_logits)
```

## 9. A/B 实验的深度展开

### 9.1 A/B 实验的工业必要性

**核心作用**:
1. **效果验证**: 模型改动是否真的有效?
2. **风险控制**: 全量上线前小流量验证
3. **决策依据**: 数据驱动, 而非拍脑袋
4. **归因分析**: 哪个改动贡献最大?

**没有 A/B 的代价**:
- 全量上线失败, 损失业务
- 工程师拍脑袋, 错误决策
- 难以归因, 难复盘

### 9.2 A/B 实验的统计学基础

#### 9.2.1 假设检验

**H0 (零假设)**: 实验组和对照组没有差异。
**H1 (备择假设)**: 实验组和对照组有差异。

**两类错误**:
- **第一类错误 (Type I)**: 拒绝正确的 H0, 假阳性
- **第二类错误 (Type II)**: 接受错误的 H0, 假阴性

**显著性水平 α**: P(Type I error) ≤ α, 通常 0.05。
**统计功效 1-β**: P(Type II error) ≤ β, 通常 0.8。

#### 9.2.2 z 检验 (大样本比例检验)

两组转化率比较:

$$Z = \frac{p_B - p_A}{\sqrt{p(1-p)(1/n_A + 1/n_B)}}$$

其中 $p = \frac{n_A p_A + n_B p_B}{n_A + n_B}$。

**p-value**: 双尾 $p = 2(1 - \Phi(|Z|))$。

```python
def z_test_two_proportions(clicks_a, n_a, clicks_b, n_b):
    p_a = clicks_a / n_a
    p_b = clicks_b / n_b
    p_pool = (clicks_a + clicks_b) / (n_a + n_b)
    se = np.sqrt(p_pool * (1 - p_pool) * (1/n_a + 1/n_b))
    z = (p_b - p_a) / se
    p_value = 2 * (1 - stats.norm.cdf(abs(z)))
    return z, p_value
```

**判断**:
- p-value < 0.05 → 拒绝 H0, 显著
- p-value < 0.01 → 强显著
- p-value < 0.001 → 极强显著

#### 9.2.3 样本量计算

**公式**:

$$n = \frac{(Z_{\alpha/2} + Z_\beta)^2 \cdot (p_A(1-p_A) + p_B(1-p_B))}{(p_B - p_A)^2}$$

**简化 (两组等样本量)**:

$$n = \frac{2 \cdot (Z_{\alpha/2} + Z_\beta)^2 \cdot p(1-p)}{(MDE)^2}$$

其中 MDE = Minimum Detectable Effect, 最小可检测效应。

```python
def sample_size(p_baseline, mde, alpha=0.05, power=0.8):
    """计算所需样本量"""
    from scipy.stats import norm
    z_alpha = norm.ppf(1 - alpha/2)  # 1.96
    z_beta = norm.ppf(power)          # 0.84

    p_treatment = p_baseline + mde
    p_pool = (p_baseline + p_treatment) / 2

    n = 2 * (z_alpha + z_beta) ** 2 * p_pool * (1 - p_pool) / (mde ** 2)
    return int(np.ceil(n))
```

**例子**:
- 基线 CTR = 5%
- MDE = 0.5% (相对 10%)
- α = 0.05, power = 0.8
- → 所需样本量 = ~60,000 / 组

### 9.3 流量分桶 (Traffic Splitting)

**核心要求**:
- **随机性**: 用户 hash 分桶
- **均匀性**: 实验组/对照组用户同质
- **稳定性**: 同一个用户始终在同一组

**实现**:

```python
import hashlib

def get_bucket(user_id, num_buckets=100):
    """根据 user_id 哈希分桶"""
    h = hashlib.md5(user_id.encode()).hexdigest()
    bucket = int(h, 16) % num_buckets
    return bucket

# 分流
def route(user_id):
    bucket = get_bucket(user_id)
    if bucket < 50:
        return 'control'  # 0-49
    elif bucket < 100:
        return 'treatment'  # 50-99
```

**哈希函数选择**:
- MD5: 快, 均匀
- SHA-1: 更均匀, 稍慢
- MurmurHash: 工业首选

**分桶粒度**:

- 1000 桶: 更细 (允许 5% 流量实验)
- 10000 桶: 极细 (允许 1% 实验)

### 9.4 多重检验问题

**问题**: 同时看 10 个指标, 至少 1 个假阳性的概率 = 1 - (1-0.05)^10 ≈ 40%。

**解决**:

#### 9.4.1 Bonferroni 校正

**思想**: 调整显著性水平, $\alpha' = \alpha / m$。

```python
def bonferroni_correct(p_values, alpha=0.05):
    m = len(p_values)
    corrected_alpha = alpha / m
    return [p < corrected_alpha for p in p_values]
```

**缺点**: 过于保守, 真实差异可能漏掉。

#### 9.4.2 BH-FDR (Benjamini-Hochberg)

**思想**: 控制"假发现率" (False Discovery Rate) 而非"族错误率"。

```python
def bh_fdr_correct(p_values, alpha=0.05):
    m = len(p_values)
    sorted_idx = np.argsort(p_values)
    sorted_p = np.array(p_values)[sorted_idx]

    # 找最大的 k, 使 p_(k) <= k/m * alpha
    thresholds = np.arange(1, m+1) / m * alpha
    significant = sorted_p <= thresholds
    if significant.any():
        max_k = np.max(np.where(significant)[0])
        # 前 max_k+1 个拒绝
        rejected = np.zeros(m, dtype=bool)
        rejected[sorted_idx[:max_k+1]] = True
    else:
        rejected = np.zeros(m, dtype=bool)

    return rejected
```

**优势**: 不如 Bonferroni 保守, 保留更多真实差异。

#### 9.6.2 实验期间的监控

**核心指标监控**:
- 主指标 (Primary): 实验目标
- 护栏指标 (Guardrail): 不希望变差的指标
- 反向指标 (Anti-metric): 绝对不能跌的指标

```python
class ExperimentMonitor:
    """实验监控"""
    def __init__(self, design):
        self.design = design
        self.metrics = {m: {'control': [], 'treatment': []} for m in design.guardrail_metrics + [design.primary_metric]}

    def record(self, group, metric_name, value):
        self.metrics[metric_name][group].append(value)

    def check_significance(self, metric_name, alpha=0.05):
        """检查显著性"""
        ctrl = self.metrics[metric_name]['control']
        treat = self.metrics[metric_name]['treatment']

        # 简化: 用 CTR 转化率
        ctr_c = np.mean(ctrl)
        ctr_t = np.mean(treat)
        z, p = z_test_two_proportions(
            int(np.sum(ctrl)), len(ctrl),
            int(np.sum(treat)), len(treat)
        )
        return {'z': z, 'p_value': p, 'significant': p < alpha, 'lift': (ctr_t - ctr_c) / ctr_c}

    def check_guardrail(self):
        """检查护栏指标"""
        violations = []
        for m in self.design.guardrail_metrics:
            result = self.check_significance(m)
            if result['p_value'] < 0.01 and result['lift'] < -0.02:
                violations.append((m, result['lift']))
        return violations
```

```python
def interleave_results(rank_a, rank_b):
    """交叉两个排序结果"""
    # 1) 合并候选
    merged = list(set(rank_a) | set(rank_b))
    # 2) 随机选 A 或 B 排序
    final = []
    for item in merged:
        if random.random() < 0.5:
            final.append(('A', item))
        else:
            final.append(('B', item))
    # 3) 按各自排序再排
    final.sort(key=lambda x: (rank_a if x[0] == 'A' else rank_b).index(x[1]))
    return final
```

**优势**: 样本效率高 (同一用户对比两个模型)。
**挑战**: 实现复杂, 用户感知可能混乱。

## 10. 反馈闭环与偏差治理

### 10.1 反馈闭环的形成

```text
模型推荐 → 用户曝光 → 用户反馈 → 训练数据 → 模型更新
   ↑                                              ↓
   └──────────────────────────────────────────────┘
```

**问题**: 模型只见到"自己推过的物品"的反馈, 形成反馈闭环, 放大偏差。

### 10.2 主要偏差类型

#### 10.2.1 位置偏差 (Position Bias)

**现象**: 高位天然高点击, 与物品质量无关。

**成因**: 用户倾向于点击排在前面的物品。

**解决**:

```python
# 1) 位置作特征
class PositionAwareModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.position_emb = nn.Embedding(max_position, embed_dim)
        self.main_model = MainModel(...)

    def forward(self, user_feat, item_feat, position):
        # 把位置作为特征
        pos_emb = self.position_emb(position)
        combined = torch.cat([user_feat, item_feat, pos_emb], dim=-1)
        return self.main_model(combined)

# 2) 倾向得分 (IPS) 校正
def ips_corrected_ctr(clicks, impressions, position_propensity):
    """IPS 校正后的 CTR"""
    weighted_clicks = clicks / position_propensity
    return weighted_clicks.sum() / impressions.sum()
```

#### 10.2.2 曝光偏差 (Exposure Bias)

**现象**: 模型没见过"未曝光"物品的反馈。

**成因**: 只训练曝光过的样本。

**解决**:

```python
# ESMM (Entire Space Multi-task Model)
# 在全空间建模, 而不是只在曝光空间
class ESMM(nn.Module):
    def __init__(self):
        self.ctr_tower = nn.Sequential(...)  # 预测点击
        self.ctcvr_tower = nn.Sequential(...)  # 预测点击且转化

    def forward(self, x):
        pctr = torch.sigmoid(self.ctr_tower(x))
        pctcvr = torch.sigmoid(self.ctcvr_tower(x))
        pcvr = pctcvr / pctr.clamp(min=1e-6)
        return pctr, pcvr, pctcvr
```

#### 10.2.3 流行度偏差 (Popularity Bias)

**现象**: 热门物品被反复推, 长尾物品无曝光。

**成因**: 训练数据中热门物品占比高, 模型偏向热门。

**解决**:

```python
# 1) 加权采样 (inverse propensity)
def weighted_sample(items, weights):
    weights = np.array(weights) ** -0.5  # 频次的 -0.5 次方
    weights = weights / weights.sum()
    return np.random.choice(items, p=weights)

# 2) 频率归一化 Embedding
class FreqNormalizedEmbedding(nn.Module):
    """频率归一化 Embedding"""
    def __init__(self, num_items, embed_dim, alpha=0.5):
        super().__init__()
        self.embedding = nn.Embedding(num_items, embed_dim)
        self.alpha = alpha

    def forward(self, ids, frequencies):
        # 加权 Embedding
        emb = self.embedding(ids)
        # 频率倒数加权
        weight = 1.0 / (frequencies ** self.alpha)
        return emb * weight.unsqueeze(-1)
```

#### 10.2.4 幸存者偏差 (Survivorship Bias)

**现象**: 只学到"被推荐且被反馈"的物品, 忽略"被推荐但无反馈"的物品。

**解决**: 用随机流量收集无偏数据。

```python
# 随机流量 (5-10% 流量, 随机推荐)
class ExploreTraffic:
    """探索流量"""
    def __init__(self, explore_ratio=0.1):
        self.explore_ratio = explore_ratio

    def should_explore(self, user_id):
        return get_bucket(user_id, 100) < self.explore_ratio * 100

    def random_recommend(self, all_items, top_k=10):
        """随机推荐"""
        return np.random.choice(all_items, size=top_k, replace=False)
```

### 10.3 探索-利用 (Exploration-Exploitation)

**核心权衡**: 利用已知好物品 vs 探索新物品。

#### 10.3.1 ε-Greedy

```python

        # 探索: 随机
```

**优点**: 简单。
**缺点**: 探索无目的。

#### 10.3.2 UCB (Upper Confidence Bound)

$$\text{score}(i) = \hat{r}_i + c \cdot \sqrt{\frac{\ln T}{n_i}}$$

```python
class UCB:
    def __init__(self, c=1.0):
        self.c = c
        self.counts = defaultdict(int)
        self.rewards = defaultdict(float)
        self.t = 0

    def select(self, items):
        self.t += 1
        scores = []
        for item in items:
            if self.counts[item] == 0:
                return item  # 未探索过的优先
            ucb = self.rewards[item] / self.counts[item] + \
                  self.c * np.sqrt(np.log(self.t) / self.counts[item])
            scores.append((ucb, item))
        return max(scores)[1]
```

#### 10.3.3 Thompson Sampling

用后验分布采样:

```python
class ThompsonSampling:
    def __init__(self, alpha=1, beta=1):
        self.alpha = alpha
        self.beta = beta
        self.alphas = defaultdict(lambda: alpha)
        self.betas = defaultdict(lambda: beta)

    def select(self, items):
        samples = []
        for item in items:
            sample = np.random.beta(self.alphas[item], self.betas[item])
            samples.append((sample, item))
        return max(samples)[1]

    def update(self, item, reward):
        if reward == 1:
            self.alphas[item] += 1
        else:
            self.betas[item] += 1
```

#### 10.3.4 LinUCB (Contextual Bandit)

UCB + 上下文特征:

$$\hat{r}_i = \theta_i^\top x_i$$
$$\text{score}(i) = \hat{r}_i + c \cdot \sqrt{x_i^\top A_i^{-1} x_i}$$

```python
class LinUCB:
    def __init__(self, dim, alpha=1.0):
        self.alpha = alpha
        self.A = defaultdict(lambda: np.eye(dim))
        self.b = defaultdict(lambda: np.zeros(dim))

    def select(self, items, contexts):
        scores = []
        for item, x in zip(items, contexts):
            A_inv = np.linalg.inv(self.A[item])
            theta = A_inv @ self.b[item]
            # UCB
            ucb = x @ theta + self.alpha * np.sqrt(x @ A_inv @ x)
            scores.append((ucb, item))
        return max(scores)[1]

    def update(self, item, context, reward):
        self.A[item] += np.outer(context, context)
        self.b[item] += reward * context
```

```text
   ↓                    ↓
   数据                  Embedding
   模型参数
```

**PS 关键组件**:

```python
class ParameterServer:
    """Parameter Server 实现"""
    def __init__(self):
        self.embeddings = {}  # 稀疏参数
        self.dense_params = {}  # 稠密参数

    def pull(self, keys):
        """Worker 拉取参数"""
        return {k: self.embeddings.get(k, self._default_init(k)) for k in keys}

    def push(self, grads):
        """Worker 推送梯度"""
        for key, grad in grads.items():
            if key not in self.embeddings:
                self.embeddings[key] = self._default_init(key)
            # 异步更新
            self.embeddings[key] -= self.lr * grad

    def _default_init(self, key):
        return np.random.randn(embed_dim) * 0.01
```

**同步模式**:
- **同步 SGD**: 所有 Worker 等齐 (慢)
- **异步 SGD**: 各 Worker 独立更新 (快, 但有 staleness 问题)

### 15.4 在线学习与离线训练的协调

**策略**:

| 策略 | 频率 | 说明 |
| :--- | :--- | :--- |
| 在线 FTRL | 分钟级 | 只更新热特征 Embedding |
| 离线全量 | 天级 | 全参数更新 |
| 增量微调 | 小时级 | 在线模型微调 |

**实现**:

```python
class HybridTrainer:
    """在线 + 离线混合训练"""
    def __init__(self, model, ps):
        self.model = model
        self.ps = ps

    def online_step(self, batch):
        """在线学习: 只更新 Embedding"""
        # 1) 拉 Embedding
        embeddings = self.ps.pull(batch['item_ids'])
        # 2) 前向
        logits = self.model(batch['features'], embeddings)
        loss = F.binary_cross_entropy_with_logits(logits, batch['label'])
        # 3) 反向
        loss.backward()
        # 4) 只推送 Embedding 梯度
        self.ps.push(self._extract_emb_grads())

    def offline_step(self, batch):
        """离线全量训练"""
        # 1) 全参数前向
        logits = self.model(batch['features'])
        loss = F.binary_cross_entropy_with_logits(logits, batch['label'])
        # 2) 全参数反向
        loss.backward()
        # 3) 更新所有参数
        self.optimizer.step()
```

```python
class TrafficSplitter:
    """流量分流服务"""
    def __init__(self):
        self.experiments = {}  # exp_id -> config

    def register_experiment(self, exp_id, buckets, hash_seed='default'):
        """注册实验"""
        self.experiments[exp_id] = {
            'buckets': buckets,  # {group_name: (start, end)}
            'hash_seed': hash_seed
        }

    def route(self, user_id, exp_id):
        """路由用户到实验组"""
        if exp_id not in self.experiments:
            return 'control'

        exp = self.experiments[exp_id]
        # 用 user_id + 哈希种子分流
        h = hashlib.md5(f"{user_id}_{exp['hash_seed']}".encode()).hexdigest()
        bucket = int(h, 16) % 100

        for group_name, (start, end) in exp['buckets'].items():
            if start <= bucket < end:
                return group_name
        return 'control'

    def get_experiment_config(self, user_id, request):
        """获取用户的所有实验配置"""
        configs = {}
        for exp_id in self.experiments:
            group = self.route(user_id, exp_id)
            configs[exp_id] = group
        return configs
```

```python
class MetricCalculator:
    """指标计算服务"""
    def __init__(self):
        self.exposure_count = defaultdict(int)
        self.click_count = defaultdict(int)
        self.conversion_count = defaultdict(int)

    def record_exposure(self, user_id, group, item_id):
        """记录曝光"""
        self.exposure_count[(group, item_id)] += 1

    def record_click(self, user_id, group, item_id):
        """记录点击"""
        self.click_count[(group, item_id)] += 1

    def calculate_ctr(self, group):
        """计算 CTR"""
        exposures = sum(v for (g, _), v in self.exposure_count.items() if g == group)
        clicks = sum(v for (g, _), v in self.click_count.items() if g == group)
        return clicks / exposures if exposures > 0 else 0

    def calculate_with_significance(self, group_a='control', group_b='treatment'):
        """计算带显著性的指标"""
        ctr_a = self.calculate_ctr(group_a)
        ctr_b = self.calculate_ctr(group_b)

        n_a = sum(v for (g, _), v in self.exposure_count.items() if g == group_a)
        n_b = sum(v for (g, _), v in self.exposure_count.items() if g == group_b)
        k_a = sum(v for (g, _), v in self.click_count.items() if g == group_a)
        k_b = sum(v for (g, _), v in self.click_count.items() if g == group_b)

        z, p_value = z_test_two_proportions(k_a, n_a, k_b, n_b)
        return {
            'ctr_a': ctr_a,
            'ctr_b': ctr_b,
            'lift': (ctr_b - ctr_a) / ctr_a,
            'z_score': z,
            'p_value': p_value,
```

```python
class BiasMonitor:
    """偏差监控"""
    def __init__(self):
        self.metrics = {}

    def monitor_position_bias(self, predictions, positions, clicks):
        """监控位置偏差"""
        from sklearn.metrics import roc_auc_score
        # 1) 计算位置归因
        position_ctr = defaultdict(list)
        for pred, pos, click in zip(predictions, positions, clicks):
            position_ctr[pos].append((pred, click))

        # 2) 监控每个位置的实际 vs 预测 CTR
        for pos, items in position_ctr.items():
            preds, actuals = zip(*items)
            pred_ctr = np.mean(preds)
            actual_ctr = np.mean(actuals)
            ratio = actual_ctr / pred_ctr
            if abs(ratio - 1) > 0.3:
                self.metrics[f'position_{pos}_bias'] = ratio

    def monitor_popularity_bias(self, predictions, item_freq, clicks):
        """监控流行度偏差"""
        # 1) 把物品按频率分桶
        buckets = {'head': [], 'mid': [], 'tail': []}
        for pred, freq, click in zip(predictions, item_freq, clicks):
            if freq > 10000:
                buckets['head'].append((pred, click))
            elif freq > 100:
                buckets['mid'].append((pred, click))
            else:
                buckets['tail'].append((pred, click))

        # 2) 监控每个桶的偏差
        for bucket_name, items in buckets.items():
            if not items:
                continue
            preds, actuals = zip(*items)
            self.metrics[f'{bucket_name}_bias'] = np.mean(actuals) / np.mean(preds)
```

## 18. 在线学习与 AB 实验的常见反模式

### 18.1 反模式 1: 在线学习与离线训练不同步

**症状**: 在线模型与离线模型参数不一致。

**原因**: 在线训练异步, 离线训练同步。

**解决**: 统一 Parameter Server, 严格 sync。

### 18.2 反模式 2: 实验组对照组不均匀

**症状**: 实验开始前对照组已经显著好于实验组。

**原因**: 流量分桶不均匀。

**解决**: 加大分桶粒度 (1000+), 用 murmurhash。

### 18.3 反模式 3: 实验跑太久

**症状**: 实验跑了 30 天, 浪费流量。

**原因**: 没有预设终止条件。

**解决**: 实验设计时规定 MDE + 时长, 达到就停。

### 18.4 反模式 4: 多重检验忽略

**症状**: 看到 10 个指标有 1 个显著就上线。

**原因**: 没用 Bonferroni/BH-FDR 校正。

**解决**: 多指标必须校正。

### 18.5 反模式 5: 偷看实验结果

**症状**: 实验跑 1 天就下结论。

**原因**: 业务压力大。

**解决**: 实验规范, 跑满预设时长。

### 18.6 反模式 6: 没有护栏指标

**症状**: 主指标涨, 但用户流失加剧。

**原因**: 没监控护栏。

**解决**: 必设护栏 (留存/负反馈/多样性)。

```python
class MABExperiment:
    """MAB 实验: 多臂老虎机"""
    def __init__(self, arms):
        self.arms = arms
        self.counts = {arm: 0 for arm in arms}
        self.rewards = {arm: 0 for arm in arms}

    def select_arm(self):
        """Thompson Sampling"""
        samples = {}
        for arm in self.arms:
            alpha = self.rewards[arm] + 1
            beta = self.counts[arm] - self.rewards[arm] + 1
            samples[arm] = np.random.beta(alpha, beta)
        return max(samples, key=samples.get)

    def update(self, arm, reward):
        self.counts[arm] += 1
        self.rewards[arm] += reward
```

#### 21.1.1 经验回放 (Experience Replay)

```python
class ExperienceReplay:
    """经验回放"""
    def __init__(self, capacity=100000):
        self.buffer = deque(maxlen=capacity)

    def add(self, sample):
        self.buffer.append(sample)

    def sample(self, batch_size):
        return random.sample(self.buffer, batch_size)

    def get_mixed_batch(self, new_data, replay_ratio=0.3):
        """混合新数据和回放数据"""
        n_replay = int(batch_size * replay_ratio)
        replay_batch = self.sample(n_replay)
        new_batch = random.sample(new_data, batch_size - n_replay)
        return replay_batch + new_batch
```

#### 21.1.2 EWC (Elastic Weight Consolidation)

**思想**: 重要参数更新小, 不重要参数更新大。

```python
class EWC:
    """弹性权重整合"""
    def __init__(self, model, importance=1000):
        self.model = model
        self.importance = importance
        self.old_params = {}
        self.fisher = {}

    def compute_fisher(self, dataloader):
        """计算 Fisher 信息矩阵"""
        self.fisher = {n: torch.zeros_like(p) for n, p in self.model.named_parameters()}
        for batch in dataloader:
            self.model.zero_grad()
            loss = compute_loss(self.model, batch)
            loss.backward()
            for n, p in self.model.named_parameters():
                if p.grad is not None:
                    self.fisher[n] += p.grad ** 2
        # 归一化
        for n in self.fisher:
            self.fisher[n] /= len(dataloader)

    def penalty(self):
        """EWC 惩罚项"""
        loss = 0
        for n, p in self.model.named_parameters():
            if n in self.old_params:
                loss += (self.fisher[n] * (p - self.old_params[n]) ** 2).sum()
        return loss * self.importance
```

### 21.2 元学习 (Meta-Learning) 在在线学习中的应用

**MAML (Model-Agnostic Meta-Learning)**:

**目标**: 学一个"易于微调"的初始模型。

```python
class MAML:
    """MAML 算法"""
    def __init__(self, model, inner_lr=0.01, outer_lr=1e-3):
        self.model = model
        self.inner_lr = inner_lr
        self.outer_lr = outer_lr
        self.meta_optimizer = torch.optim.Adam(model.parameters(), lr=outer_lr)

    def inner_loop(self, support_set):
        """内循环: 在 support set 上微调"""
        # 1) 保存原参数
        original_params = {n: p.clone() for n, p in self.model.named_parameters()}

        # 2) 微调
        for batch in support_set:
            loss = compute_loss(self.model, batch)
            grads = torch.autograd.grad(loss, self.model.parameters())
            for p, g in zip(self.model.parameters(), grads):
                p.data -= self.inner_lr * g

        # 3) 恢复 (MAML 用计算图保留原参数)
        # 实际实现用 functional forward
        return original_params

    def outer_loop(self, task_batch):
        """外循环: 更新元参数"""
        meta_loss = 0
        for task in task_batch:
            # 内循环
            self.inner_loop(task['support'])
            # 在 query set 上算损失
            query_loss = compute_loss(self.model, task['query'])
            meta_loss += query_loss

        # 元优化
        self.meta_optimizer.zero_grad()
        meta_loss.backward()
        self.meta_optimizer.step()
```

**应用**:
- 冷启动用户/物品 (快速适应)
- 跨域迁移 (源域 → 目标域)
- 个性化 (不同用户不同模型)

### 21.3 在线学习的安全性

**问题**: 在线学习可能被恶意利用 (例如刷单、刷流量)。

**解决**:

```python
class SecureOnlineTrainer:
    """安全的在线训练器"""
    def __init__(self):

    def filter_samples(self, batch):

        if self.fraud_detector.is_suspicious(batch['user_id']):

        # 3) 异常模式检测
        if self.fraud_detector.is_bot_pattern(batch):
```

### 21.4 在线学习的算力优化

**挑战**: 分钟级训练, 算力爆炸。

**优化策略**:

| 策略 | 效果 |
| :--- | :--- |
| 只更新高活跃 Embedding | 减少 90% 更新量 |
| 用 LRU 缓存冷 Embedding | 减少内存 |
| 异步 PS 训练 | 提高吞吐 |
| 量化 (FP16/BF16) | 减少 50% 显存 |
| 稀疏更新 | 减少 70% 计算量 |

```python
class SparseOnlineTrainer:
    """稀疏更新的在线训练器"""
    def __init__(self, model, update_threshold=0.01):
        self.model = model
        self.update_threshold = update_threshold

    def should_update_embedding(self, embedding_id, current_grad):
        """判断是否需要更新"""
        grad_norm = current_grad.norm().item()
        return grad_norm > self.update_threshold

    def selective_update(self, batch):
        """选择性更新"""
        self.optimizer.zero_grad()
        loss = compute_loss(self.model, batch)
        loss.backward()

        # 只更新重要的 Embedding
        for n, p in self.model.named_parameters():
            if 'embedding' in n and p.grad is not None:
                if not self.should_update_embedding(n, p.grad):
                    p.grad = None  # 不更新
                else:
                    p.grad *= 0.5  # 降低学习率

        self.optimizer.step()
```

### 22.1 因果推断在 AB 中的应用

**问题**: A/B 看到的是"观测效应", 不是"因果效应"。

**因果推断方法**:

```python
class CausalABAnalysis:
    """因果 AB 分析"""
    def __init__(self):
        self.uplift_model = None

    def estimate_ate(self, control_outcome, treatment_outcome):
        """平均处理效应 ATE"""
        return np.mean(treatment_outcome) - np.mean(control_outcome)

    def estimate_cate(self, features, treatment, outcome):
        """条件平均处理效应 CATE"""
        # 用 uplift model
        from sklearn.ensemble import GradientBoostingRegressor
        # 双模型法
        model_treat = GradientBoostingRegressor()
        model_ctrl = GradientBoostingRegressor()

        # 分别训练
        model_treat.fit(features[treatment == 1], outcome[treatment == 1])
        model_ctrl.fit(features[treatment == 0], outcome[treatment == 0])

        # 预测
        pred_treat = model_treat.predict(features)
        pred_ctrl = model_ctrl.predict(features)
        cate = pred_treat - pred_ctrl
        return cate
```

### 22.2 实验设计的常见错误

#### 22.2.1 错误 1: SRM (Sample Ratio Mismatch)

**问题**: 实验组和对照组的样本量比例与设计不一致。

**原因**: 哈希函数不均匀 / 用户流失 / 流量劫持。

**检测**: 用 Chi-square 检验样本量比例。

**修复**: 重新分桶, 加大样本。

#### 22.2.2 错误 2: 干扰 (Interference)

**问题**: 同一用户在不同实验组 (例如社交网络)。

**解决**: 用 cluster randomization (按社交圈分桶)。

#### 22.2.3 错误 3: 长期效应

**问题**: 实验短期涨, 长期跌。

**解决**: 实验至少跑 7-14 天, 看长期指标。

#### 22.2.4 错误 4: 季节性

**问题**: 周末数据与工作日数据不同。

**解决**: 实验跨周末, 或分周期看。

### 22.3 高级实验设计

#### 22.3.1 Switchback 实验

**场景**: 不能随机分用户 (例如广告投放)。

**方法**: 按时段切换实验组。

```python
class SwitchbackExperiment:
    """Switchback 实验"""
    def __init__(self, period_minutes=60):
        self.period = period_minutes
        self.current_group = 'control'

    def get_current_group(self, current_time):
        """根据时间决定组别"""
        period_idx = current_time // (self.period * 60)
        if period_idx % 2 == 0:
            return 'control'
        return 'treatment'
```

#### 22.3.2 Geo 实验

**场景**: 不能按用户分 (例如外卖), 按地区分。

**方法**: 不同城市用不同模型。

#### 22.3.3 Cluster 实验

**场景**: 干扰问题严重 (社交网络)。

**方法**: 按"群组"分桶 (例如按社区)。

## 23. 反馈闭环治理的高级主题

### 23.1 因果反馈闭环

**问题**: 反馈闭环导致模型偏差, 用因果方法纠正。

**方法**:

```python
class CausalFeedbackLoopCorrector:
    """因果反馈闭环纠正器"""
    def __init__(self):
        self.propensity_estimator = PropensityEstimator()

    def correct_with_ips(self, exposure, click, propensity):
        """IPS 校准"""
        # 校正点击率
        corrected_ctr = (click / propensity).mean()
        return corrected_ctr

    def doubly_robust_estimation(self, exposure, click, propensity, predictions):
        """双重稳健估计"""
        # DR 估计
        dr_estimate = (
            predictions.mean() +  # 直接法
            (exposure / propensity * (click - predictions)).mean()  # 校正项
        )
        return dr_estimate
```

### 23.2 反事实评估 (Counterfactual Evaluation)

**目标**: 用历史数据评估新策略。

**方法**: IPS 估计

$$\hat{V}_{\text{IPS}} = \frac{1}{n}\sum_{i=1}^n \frac{r_i \cdot \pi(a_i|x_i)}{\pi_0(a_i|x_i)}$$

```python
class CounterfactualEvaluator:
    """反事实评估器"""
    def __init__(self):
        self.logging_policy = None
        self.target_policy = None

    def estimate_ips(self, logged_data):
        """IPS 估计"""
        n = len(logged_data)
        weighted_rewards = []
        for log in logged_data:
            context = log['context']
            action = log['action']
            reward = log['reward']

            # logging policy 的概率
            p_logging = self.logging_policy.predict_proba(context, action)
            # target policy 的概率
            p_target = self.target_policy.predict_proba(context, action)

            # 加权
            weight = p_target / (p_logging + 1e-6)
            weighted_rewards.append(weight * reward)

        return np.mean(weighted_rewards)
```

## 26. 在线学习与 AB 实验的常见误区

### 26.1 误区 1: 在线学习比离线学习更准

**正解**: 在线学习的优势是**时效性**, 不是**准确性**。
- 在线学习时效性高, 但数据少, 易过拟合
- 离线学习数据全, 训练稳定, 但时效性差

**实践**: 在线 + 离线混合, 取长补短。

### 26.2 误区 2: AB 实验小流量就能上线

**正解**: 小流量只是验证, 大流量才稳定。
- 小流量容易受噪声影响
- 大流量才能见真实效果

**实践**: 小流量 → 大流量 → 全量, 三阶段。

### 26.3 误区 3: 显著性高就一定有效

**正解**: 显著性只表示"不是偶然", 不表示"业务价值大"。
- 显著性高但 lift 0.1% → 业务意义不大
- 显著性低但 lift 5% → 可能样本量不足

**实践**: 显著性 + lift 双重判断。

### 26.4 误区 4: 反馈闭环无法避免

**正解**: 反馈闭环是结构性问题, 但可以用工程手段缓解。
- 探索流量 (5-10%)
- 全空间建模 (ESMM)
- 频率归一化
- 因果校准
