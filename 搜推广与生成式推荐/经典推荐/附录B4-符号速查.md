### B.8.10 信息论公式速查

**基本量:**

| 名称 | 公式 | 说明 |
| :--- | :--- | :--- |
| Self-Information | $I(x) = -\log_2 p(x)$ (bits) 或 $-\ln p(x)$ (nats) | 单事件的信息量 |
| Shannon Entropy | $H(X) = -\sum_x p(x) \log p(x)$ | 不确定性 |
| Differential Entropy | $h(X) = -\int p(x) \log p(x) dx$ | 连续随机变量 |
| Joint Entropy | $H(X,Y) = -\sum_{x,y} p(x,y) \log p(x,y)$ | |
| Conditional Entropy | $H(X \mid Y) = -\sum p(x,y) \log p(x \mid y)$ | 已知Y后X的不确定性 |
| Mutual Information | $I(X;Y) = H(X) - H(X \mid Y) = D_{\text{KL}}(p(x,y) \| p(x)p(y))$ | 共享信息 |
| Conditional MI | $I(X;Y \mid Z) = H(X \mid Z) - H(X \mid Y,Z)$ | |
| KL Divergence | $D_{\text{KL}}(P \| Q) = \int p \log(p/q)$ | 非对称 |
| JS Divergence | $D_{\text{JS}}(P \| Q) = \frac{1}{2} D_{\text{KL}}(P \| M) + \frac{1}{2} D_{\text{KL}}(Q \| M)$, $M = (P+Q)/2$ | 对称 |
| Cross-Entropy | $H(P,Q) = -\mathbb{E}_P[-\log Q] = H(P) + D_{\text{KL}}(P \| Q)$ | 分类损失 |
| Renyi Entropy | $H_\alpha(X) = \frac{1}{1-\alpha} \log \sum p^\alpha$ | $\alpha \to1$ 得 Shannon |
| Renyi Divergence | $D_\alpha(P \| Q) = \frac{1}{\alpha-1} \log \sum p^\alpha q^{1-\alpha}$ | |
| Tsallis Entropy | $H_q(X) = \frac{1}{q-1}(1 - \sum p^q)$ | |
| f-divergence | $D_f(P \| Q) = \mathbb{E}_Q[f(P/Q) - f(1)]$ | 一般化 |
| Total Correlation | $C(X_1,...,X_n) = \sum H(X_i) - H(X_1,...,X_n)$ | 多变量冗余 |
| Dual Total Correlation | $D(X_1,...,X_n) = H(X_1,...,X_n) - H(X_i \mid X_{-i})$ | 协同信息 |

| Entropy Chain Rule | $H(X_1,...,X_n) = \sum_i H(X_i \mid X_{1:i-1})$ | |
| Information Bottleneck | $\min I(X;T) - \beta I(T;Y)$ | 信息瓶颈 |
| Co-information | $I(X;Y;Z) = I(X;Y) - I(X;Y \mid Z)$ | |
| Interaction Information | 同 co-information | |

### B.8.13 常见分布采样速查

**逆 CDF 采样(连续分布):**

1. 生成 $U \sim U(0,1)$
2. 求解 $F^{-1}(U)$

| 分布 | $F^{-1}(u)$ |
| :--- | :--- |
| Exponential | $-\ln(1-u)/\lambda$ |
| Cauchy | $\mu + \gamma \tan(\pi(u-0.5))$ |
| Laplace | $\mu - b \text{sign}(u-0.5) \ln(1-2\|u-0.5\|)$ |
| Logistic | $\mu + s\ln(u/(1-u))$ |
| Weibull | $\lambda(-\ln(1-u))^{1/k}$ |
| Pareto | $x_m/(1-u)^{1/\alpha}$ |
| Gumbel | $\mu - \beta \ln(-\ln u)$ |
| Log-Normal | $\exp(\mu + \sigma \Phi^{-1}(u))$ |

**拒绝采样(Rejection Sampling):**

1. 选建议分布 $q(z)$, 满足 $kq(z) \ge p(z) \forall z$
2. 采样 $z \sim q, u \sim U(0,1)$
3. 接受 iff $u < p(z)/(kq(z))$
4. 接受率 $\ge 1/k$

**Box-Muller 高斯采样:**

```text
$U_1, U_2 \sim U(0,1)$
$Z_0 = \sqrt{-2\ln U_1} \cos(2\pi U_2)$
$Z_1 = \sqrt{-2\ln U_1} \sin(2\pi U_2)$
$Z_0, Z_1 \sim \mathcal{N}(0,1)$
```

**Marsaglia-Tsang Ziggurat(N(0,1)):**

1. 预计算256层阶梯
2. 快速采样(每步平均 ~2.7次随机数)
3. 比Box-Muller快

**Beta 采样:**

1. $X_1, X_2 \sim \text{Gamma}(\alpha, 1)$
2. $X = X_1/(X_1+X_2) \sim \text{Beta}(\alpha, \beta)$

**Dirichlet 采样:**

1. $X_i \sim \text{Gamma}(\alpha_i, 1)$
2. $X_i = X_i / \sum_j X_j$, 则 $\mathbf{X} \sim \text{Dir}(\boldsymbol\alpha)$

**多项式采样:**

1. 累积分布 $F_k = \sum_{i \le k} p_i$
2. $U \sim U(0,1)$
3. 返回 $k$ s.t. $F_{k-1} < U \le F_k$

**别名方法(Alias Method, 离散):**

- 预处理 $O(n)$, 采样 $O(1)$
- 适合静态离散分布
- Walker alias / Vose alias

**Gumbel-Max Trick:**

- 采样 $k = \arg\max_i (\log p_i + g_i)$, $g_i \sim \text{Gumbel}(0,1)$
- 等价于从 $\text{Cat}(\mathbf{p})$ 采样

**Gumbel-Softmax 重参数:**

- $y_i = \exp((\log p_i + g_i)/\tau) / \sum_j \exp((\log p_j + g_j)/\tau)$
- $\tau \to0$ 退化为 Gumbel-Max

**VAE 重参数:**

- $z = \mu_\phi(x) + \sigma_\phi(x) \odot \epsilon$, $\epsilon \sim \mathcal{N}(0, I)$

**MCMC 采样方法:**

| 方法 | 适用 | 备注 |
| :--- | :--- | :--- |
| Metropolis-Hastings | 一般 | $\min(1, p(x')q(x\mid x')/(p(x)q(x'\mid x)))$ |
| Gibbs | 条件分布已知 | 逐变量更新 |
| HMC | 连续光滑 | Hamiltonian dynamics |
| NUTS | 连续光滑 | HMC + 自动步长 |
| Langevin | 连续 | $x_{t+1} = x_t + (\eta/2)\nabla \log p(x_t) + \sqrt\eta \epsilon$ |
| Rejection | 已知包络 | 接受率 $\ge 1/k$ |
| Importance | 期望估计 | $\mathbb{E}_p[f] \approx \sum w_i f(x_i)$ |
| Slice | 1-D | 切片采样 |
| Population | 多链 | 多峰 |
| SMC | 序贯 | 粒子滤波 |

**蒙特卡洛估计:**

- $\mathbb{E}_{x \sim p}[f(x)] \approx \frac{1}{N}\sum f(x_i)$, $x_i \sim p$
- 方差 $= \text{Var}[f(x)]/N$
- 重要性采样: $\mathbb{E}_{p}[f] = \mathbb{E}_{q}[f p/q] \approx \frac{1}{N}\sum f(x_i) p(x_i)/q(x_i)$

### B.9.1 反向模式自动微分

**工业入口**：推荐模型训练中的多层计算图。先明确张量、概率或估计量的语义，再讨论实现。

| 记号 | 含义 | 工程检查 |
| :--- | :--- | :--- |
| $J_f(x)=\\partial f/\\partial x$ | 本节核心对象 | 检查维度与定义域 |
| $n$ | 样本数或序列长度 | 检查空批次和极小批次 |
| $d$ | 表征维度 | 检查缩放项与内存复杂度 |

**核心公式**：

$$
$\\bar{x}=J_f(x)^\\top\\bar{y}$
$$

**推导与阅读顺序**：

1. 写出输入、输出、参数的形状，不允许只写标量公式。
2. 标注随机变量由哪个分布产生，训练分布与曝光分布是否一致。
3. 将复合函数拆成局部算子，逐个写 Jacobian 或向量—Jacobian 积。
4. 检查极端输入：全零、全相等、超大 logits、空 mask 与长尾样本。
5. 用有限差分或双精度基线核对关键导数，而不是只看 loss 能否下降。
