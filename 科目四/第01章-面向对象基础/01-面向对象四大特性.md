# 01. 面向对象四大特性

> 设计模式的基础是面向对象 (Object-Oriented Programming, OOP). 掌握 OOP 四大特性, 才能理解模式为什么要这样设计.

---

## 1. 抽象 (Abstraction)

**定义**: 抽取共同特征, 忽略非本质细节.

**目的**: 简化复杂系统, 只关注"做什么"而非"怎么做".

**示例**:

```python
# 抽象: 不关心具体是哪种动物, 只关心"会叫"
class Animal:
    def speak(self):  # 抽象方法
        raise NotImplementedError("子类必须实现")

# 实现: 具体动物具体叫法
class Dog(Animal):
    def speak(self):
        return "汪汪"

class Cat(Animal):
    def speak(self):
        return "喵喵"
```

**关键概念**:

| 概念 | 说明 |
| :--- | :--- |
| **抽象类** | 包含抽象方法 (未实现方法) 的类, 不能直接 new, 必须由子类实现 |
| **接口** | 纯抽象规范, Java 8 后可有默认实现 |
| **抽象 vs 具体** | 抽象关注"是什么/做什么", 具体关注"怎么做" |

---

## 2. 封装 (Encapsulation)

**定义**: 把数据和对数据的操作捆绑在一起, 隐藏内部细节, 只暴露必要的接口.

**核心原则**: **信息隐藏 (Information Hiding)**.

```python
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance  # 私有属性 (双下划线)

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("金额必须为正")
        self.__balance += amount

    def get_balance(self):
        return self.__balance

# 使用
acc = BankAccount(100)
acc.deposit(50)
print(acc.get_balance())  # 150
# acc.__balance = -1000  # ❌ 不能直接访问私有属性
```

**封装的好处**:
- ✅ 数据保护, 防止外部随意修改
- ✅ 修改内部实现不影响外部调用
- ✅ 类的 API 简洁清晰

**封装级别** (Python):

| 名称 | 语法 | 含义 |
| :--- | :--- | :--- |
| public | `name` | 完全公开 |
| protected | `_name` | 约定不公开 (子类可访问) |
| private | `__name` | 名称修饰, 实际外部不可访问 |

---

## 3. 继承 (Inheritance)

**定义**: 子类复用父类的属性和方法, 并可扩展或修改.

**关键点**:
- **"是一个" (is-a)** 关系: Dog **is-a** Animal
- 继承表达**共性**, 子类表达**特性**
- Java/Python 等单继承, C++ 支持多继承

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def eat(self):
        print(f"{self.name} 吃东西")

class Dog(Animal):  # 继承 Animal
    def __init__(self, name, breed):
        super().__init__(name)  # 调用父类构造
        self.breed = breed

    def bark(self):
        print(f"{self.name}: 汪汪")

d = Dog("小黑", "柴犬")
d.eat()   # 继承自 Animal
d.bark()  # Dog 自己的方法
```

**继承的优缺点**:

| 优点 | 缺点 |
| :--- | :--- |
| 代码复用 | 强耦合 (改父类影响所有子类) |
| 表达层次结构 | "脆弱基类" 问题 |
| 支持多态 | 继承层次过深 (继承地狱) |

> **设计原则**: 优先使用**组合** (has-a), 而不是**继承** (is-a). 详见 SOLID 的 "组合优于继承".

---

## 4. 多态 (Polymorphism)

**定义**: 同一操作作用于不同对象, 可以有不同的解释, 产生不同的执行结果.

**多态的 3 种实现方式**:

### 4.1 子类继承 (运行时多态)

```python
class Animal:
    def speak(self):
        raise NotImplementedError

class Dog(Animal):
    def speak(self):
        return "汪汪"

class Cat(Animal):
    def speak(self):
        return "喵喵"

def make_speak(animal: Animal):
    print(animal.speak())  # 同一调用, 不同行为

make_speak(Dog())  # 汪汪
make_speak(Cat())  # 喵喵
```

### 4.2 抽象方法/接口 (Python `abc`)

```python
from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self):
        pass

class Circle(Shape):
    def __init__(self, r): self.r = r
    def area(self): return 3.14 * self.r ** 2

class Square(Shape):
    def __init__(self, s): self.s = s
    def area(self): return self.s ** 2

shapes = [Circle(2), Square(3)]
for s in shapes:
    print(s.area())  # 12.56 / 9
```

### 4.3 鸭子类型 (Python 特色)

```python
# 不需要继承, 只要有同名方法就是"同类型"
class Duck:
    def quack(self): print("嘎嘎")
    def fly(self): print("鸭子飞")

class Person:
    def quack(self): print("人在模仿鸭子叫")
    def fly(self): print("人在跑")

def duck_test(thing):
    thing.quack()
    thing.fly()

duck_test(Duck())    # 嘎嘎 / 鸭子飞
duck_test(Person())  # 人在模仿... / 人在跑
```

## 5. SOLID 原则预览

SOLID 是面向对象设计的 **5 大原则**, 由 Robert C. Martin 提出:

| 字母 | 原则 | 含义 |
| :--- | :--- | :--- |
| **S** | Single Responsibility | 单一职责: 一个类只做一件事 |
| **O** | Open/Closed | 开闭原则: 对扩展开放, 对修改关闭 |
| **L** | Liskov Substitution | 里氏替换: 子类必须能替换父类 |
| **I** | Interface Segregation | 接口隔离: 不要强迫依赖不需要的接口 |
| **D** | Dependency Inversion | 依赖倒置: 依赖抽象而非具体 |

详见 [第05章 设计原则与 SOLID](../第05章-设计原则与SOLID/).

## 6. 实战思考

### Q1: 抽象 vs 接口 区别?

| 抽象类 | 接口 |
| :--- | :--- |
| 可以有实现的方法 | Java 8 前不能有任何实现 |
| 用于代码复用 + 强制规范 | 仅定义规范 |
| 单继承 (一个类只能继承一个抽象类) | 多实现 (一个类可以实现多个接口) |
| "是一个" | "能做什么" |

### Q2: 什么时候用继承, 什么时候用组合?

**继承 (is-a)**:
- 子类是父类的特殊化
- 子类复用父类大量代码
- 关系长期稳定

**组合 (has-a)**:
- 类之间是 "拥有" 关系
- 行为可以动态切换
- 优先使用组合, 更灵活

```python
# 组合示例: 策略模式
class Car:
    def __init__(self, engine):  # Car HAS-A Engine
        self.engine = engine
    def start(self):
        self.engine.run()

class ElectricEngine:
    def run(self): print("电机启动")
class GasEngine:
    def run(self): print("汽油机启动")

Car(ElectricEngine()).start()  # 电机启动
Car(GasEngine()).start()       # 汽油机启动
```

## 7. 小结

✅ **抽象**: 抽取共性, 定义接口

✅ **封装**: 隐藏细节, 暴露接口, 保护数据

✅ **继承**: 复用代码, 表达 "是一个"

✅ **多态**: 同一调用, 不同行为, 增强灵活性

> 4 大特性**协同工作**: 抽象定义接口 → 继承复用代码 → 多态实现灵活 → 封装保护细节.
