# 04. 建造者模式 (Builder)

> **一句话**: 将一个**复杂对象**的构建过程与它的**表示**分离, 使得同样的构建过程可以创建不同的表示.

---

## 1. 核心问题

**构造器参数过多**的痛点:

```python
# ❌ 反例: 构造器地狱 (Telescoping Constructor)
class HttpRequest:
    def __init__(self, url, method, headers, body, timeout,
                 retries, proxy, cookies, follow_redirects,
                 verify_ssl, auth):
        # 10 个参数, 调用时一脸懵
        ...

# 调用时
HttpRequest(url, "GET", None, None, 30, 3, None, None,
             True, True, None)
# 一堆 None 不知道哪个对应哪个参数
```

**问题**:
- 构造器参数太多, 可读性差
- 重叠构造器 (不同参数组合) 爆炸
- 构造过程与表示耦合

---

## 2. 模式结构

```text
                  ┌────────────────────┐
                  │  <<Builder>>        │
                  │   Builder           │
                  ├────────────────────┤
                  │ +buildPartA()       │
                  │ +buildPartB()       │
                  │ +buildPartC()       │
                  │ +getResult(): Prod. │
                  └────────────────────┘
                           △
                           │ (实现)
            ┌──────────────┴──────────────┐
            │                             │
  ┌────────────────────┐      ┌────────────────────┐
  │ ConcreteBuilderA   │      │ ConcreteBuilderB   │
  ├────────────────────┤      ├────────────────────┤
  │+buildPartA()       │      │+buildPartA()       │
  │+buildPartB()       │      │+buildPartB()       │
  │+buildPartC()       │      │+buildPartC()       │
  └────────────────────┘      └────────────────────┘
            △                             △
            │ (指挥)                      │
            └──────────────┬──────────────┘
                           │
                  ┌────────────────────┐
                  │     Director        │  ← 可选
                  ├────────────────────┤
                  │ +construct()       │
                  └────────────────────┘
```

## 3. Python 实现

### 3.1 经典实现

```python
from abc import ABC, abstractmethod

# 1. 复杂产品
class Computer:
    def __init__(self):
        self.cpu = None
        self.memory = None
        self.disk = None
        self.gpu = None
    
    def __str__(self):
        return f"Computer(cpu={self.cpu}, memory={self.memory}, disk={self.disk}, gpu={self.gpu})"

# 2. 抽象建造者
class ComputerBuilder(ABC):
    def __init__(self):
        self.computer = Computer()
    
    @abstractmethod
    def build_cpu(self): pass
    @abstractmethod
    def build_memory(self): pass
    @abstractmethod
    def build_disk(self): pass
    
    def build_gpu(self):
        self.computer.gpu = "集成显卡"
    
    def get_result(self):
        return self.computer

# 3. 具体建造者
class GamingPCBuilder(ComputerBuilder):
    def build_cpu(self):
        self.computer.cpu = "Intel i9-13900K"
    def build_memory(self):
        self.computer.memory = "64GB DDR5"
    def build_disk(self):
        self.computer.disk = "2TB NVMe SSD"
    def build_gpu(self):
        self.computer.gpu = "RTX 4090"

class OfficePCBuilder(ComputerBuilder):
    def build_cpu(self):
        self.computer.cpu = "Intel i5-13400"
    def build_memory(self):
        self.computer.memory = "16GB DDR4"
    def build_disk(self):
        self.computer.disk = "512GB SSD"
    # 继承默认的集成显卡

# 4. 使用
gaming_pc = GamingPCBuilder()
gaming_pc.build_cpu()
gaming_pc.build_memory()
gaming_pc.build_disk()
gaming_pc.build_gpu()
print(gaming_pc.get_result())
# Computer(cpu=Intel i9..., memory=64GB DDR5, disk=2TB NVMe, gpu=RTX 4090)
```

### 3.2 指挥者 (Director) - 简化构建

```python
class Director:
    def __init__(self, builder: ComputerBuilder):
        self.builder = builder
    
    def construct(self):
        self.builder.build_cpu()
        self.builder.build_memory()
        self.builder.build_disk()
        self.builder.build_gpu()  # 公共步骤

# 使用
director = Director(GamingPCBuilder())
director.construct()
print(director.builder.get_result())
```

### 3.3 流式 API (最 Pythonic)

```python
class Computer:
    def __init__(self):
        self.cpu = None
        self.memory = None
        self.disk = None
    
    def __str__(self):
        return f"Computer[{self.cpu}, {self.memory}, {self.disk}]"

class ComputerBuilder:
    def __init__(self):
        self.computer = Computer()
    
    def cpu(self, value):
        self.computer.cpu = value
        return self  # 返回 self 支持链式调用
    
    def memory(self, value):
        self.computer.memory = value
        return self
    
    def disk(self, value):
        self.computer.disk = value
        return self
    
    def build(self):
        return self.computer

# 流式调用 - 极其优雅
pc = (ComputerBuilder()
      .cpu("Intel i9")
      .memory("64GB")
      .disk("2TB")
      .build())

print(pc)  # Computer[Intel i9, 64GB, 2TB]
```

### 3.4 真实案例: HTTP 请求

```python
class HttpRequest:
    def __init__(self):
        self.url = None
        self.method = "GET"
        self.headers = {}
        self.params = {}
        self.body = None
        self.timeout = 30
    
    def __repr__(self):
        return f"<Request {self.method} {self.url}>"

class RequestBuilder:
    def __init__(self):
        self.req = HttpRequest()
    
    def url(self, url):
        self.req.url = url
        return self
    
    def method(self, method):
        self.req.method = method
        return self
    
    def header(self, key, value):
        self.req.headers[key] = value
        return self
    
    def param(self, key, value):
        self.req.params[key] = value
        return self
    
    def body(self, body):
        self.req.body = body
        return self
    
    def timeout(self, seconds):
        self.req.timeout = seconds
        return self
    
    def build(self):
        if self.req.url is None:
            raise ValueError("URL 不能为空")
        return self.req

# 使用
req = (RequestBuilder()
       .url("https://api.example.com/users")
       .method("POST")
       .header("Authorization", "Bearer xxx")
       .header("Content-Type", "application/json")
       .param("page", 1)
       .body('{"name": "test"}')
       .timeout(60)
       .build())
```

## 4. Java 实现

### 4.1 StringBuilder (JDK 内置)

```java
StringBuilder sb = new StringBuilder();
sb.append("Hello")
  .append(" ")
  .append("World")
  .toString();
// "Hello World"
```

### 4.2 标准实现

```java
public class Computer {
    private String cpu;
    private String memory;
    private String disk;
    // getters...
}

public class ComputerBuilder {
    private Computer computer = new Computer();
    
    public ComputerBuilder cpu(String cpu) {
        computer.setCpu(cpu);
        return this;
    }
    
    public ComputerBuilder memory(String memory) {
        computer.setMemory(memory);
        return this;
    }
    
    public ComputerBuilder disk(String disk) {
        computer.setDisk(disk);
        return this;
    }
    
    public Computer build() {
        if (computer.getCpu() == null) {
            throw new IllegalStateException("CPU 必填");
        }
        return computer;
    }
}

// 使用
Computer pc = new ComputerBuilder()
    .cpu("i9")
    .memory("64GB")
    .disk("2TB")
    .build();
```

### 4.3 Lombok @Builder (Java 最佳实践)

```java
import lombok.Builder;
import lombok.Data;

@Data
@Builder
public class Computer {
    private String cpu;
    private String memory;
    private String disk;
    private String gpu;
}

// Lombok 自动生成建造者!
Computer pc = Computer.builder()
    .cpu("i9")
    .memory("64GB")
    .disk("2TB")
    .gpu("RTX 4090")
    .build();
```

## 6. 优缺点

### 优点

✅ **链式调用**: 优雅, 可读

✅ **可选参数**: 不用传一堆 None

✅ **分步构建**: 清晰表达构建过程

✅ **不可变对象**: build() 后不能改, 线程安全

### 缺点

❌ **代码冗长**: 需写 builder 类

❌ **必须提前设计**: 产品结构变化要改 builder

❌ **小型对象过度设计**: 字段少的对象用普通构造器更简单

## 7. 实战思考

### Q1: 建造者 vs 简单构造器?

| 建造者 | 简单构造器 |
| :--- | :--- |
| 可选参数多 | 必填参数少 |
| 分步构建 | 一次性构建 |
| 链式调用 | 一次性调用 |
| 不可变 | 可变 |

### Q2: 建造者 vs 工厂方法?

| 建造者 | 工厂方法 |
| :--- | :--- |
| 关注**构建过程** (怎么造) | 关注**创建谁** (造什么) |
| 一个产品, 多种表示 | 一类产品, 多个产品 |
| 链式调用 | 单次创建 |

**组合使用**: 工厂方法返回不同建造者, 建造者构造不同表示.

```java
// 工厂返回建造者
GUIFactory factory = new WindowsFactory();
Application app = (Application) factory.createApp();
// 建造者构造应用
app.builder()
   .setTitle("Hello")
   .setSize(800, 600)
   .build();
```

### Q3: 什么时候用建造者?

✅ **参数 ≥ 4 个** 的对象 (尤其有可选参数)

✅ **构造过程分多步** (如 "先 CPU → 再内存 → 再硬盘")

✅ **希望不可变对象** (build 后不能再改)

❌ **简单对象** (1-3 个字段): 直接用 `@dataclass` 或 datacaclass

❌ **总是构造相同**: 用普通构造器就够
