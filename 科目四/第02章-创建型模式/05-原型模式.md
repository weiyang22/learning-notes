# 05. 原型模式 (Prototype)

> **一句话**: 用**原型实例**指定创建对象的种类, 通过**拷贝**这些原型创建新对象.

---

## 1. 核心问题

什么时候 `new` 不如 `clone`?

- ✅ 对象创建**成本高** (如数据库连接)
- ✅ 对象内部**状态复杂**, 构造器参数爆炸
- ✅ 需要**保留对象历史** (撤销/快照)
- ✅ 想**避免继承**, 但想保留配置

---

## 2. 模式结构

```text
                ┌────────────────────────┐
                │    <<Prototype>>        │
                │      Prototype         │
                ├────────────────────────┤
                │ +clone(): Prototype     │
                └──────────△─────────────┘
                           │ (实现)
        ┌──────────────────┴──────────────────┐
        │                                     │
  ┌────────────────────┐          ┌────────────────────┐
  │ ConcretePrototypeA │          │ ConcretePrototypeB │
  ├────────────────────┤          ├────────────────────┤
  │ -field1             │          │ -field1             │
  │ -field2             │          │ -field2             │
  ├────────────────────┤          ├────────────────────┤
  │+clone(): Prototype │          │+clone(): Prototype │
  │+operation1()       │          │+operation2()       │
  └────────────────────┘          └────────────────────┘
              △                                △
              │ (克隆)                       │
       ┌──────┴────────┐                ┌───────┴────────┐
       │  Copy of A    │                │  Copy of B      │
       └───────────────┘                └────────────────┘
```

**核心**: 通过 `clone()` 创建新对象, 而不是 `new`.

---

## 3. 浅拷贝 vs 深拷贝

### 3.1 浅拷贝 (Shallow Copy)

```python
import copy

list1 = [[1, 2], [3, 4]]
list2 = copy.copy(list1)  # 浅拷贝
list2[0][0] = 99
print(list1)  # [[99, 2], [3, 4]]  ← 原始对象被改变!
```

**问题**: 浅拷贝**共享**嵌套对象引用. 修改副本影响原对象.

### 3.2 深拷贝 (Deep Copy)

```python
list1 = [[1, 2], [3, 4]]
list2 = copy.deepcopy(list1)  # 深拷贝
list2[0][0] = 99
print(list1)  # [[1, 2], [3, 4]]  ← 原对象安全
print(list2)  # [[99, 2], [3, 4]]
```

## 4. Python 实现

### 4.1 标准实现

```python
from abc import ABC, abstractmethod
from copy import deepcopy

class Prototype(ABC):
    @abstractmethod
    def clone(self):
        pass

class Sheep(Prototype):
    def __init__(self, name, color, weight=10):
        self.name = name
        self.color = color
        self.weight = weight
        self.friends = []  # 引用类型字段
    
    def clone(self):
        # 深拷贝 (推荐)
        return deepcopy(self)
    
    def __str__(self):
        return f"Sheep({self.name}, {self.color}, {self.weight}kg, friends={self.friends})"

# 原型
original = Sheep("多利", "white")
original.friends.append("Tom")

# 克隆
clone1 = original.clone()
clone1.name = "克隆1"
clone1.friends.append("Jerry")

print(original)  # 多利 没有 Jerry
print(clone1)    # 克隆1 有 Tom + Jerry
```

### 4.2 注册表模式 (常用)

```python
import copy

class PrototypeRegistry:
    """原型注册表: 存储常用原型, 通过 key 克隆"""
    def __init__(self):
        self._prototypes = {}
    
    def register(self, key, prototype):
        self._prototypes[key] = prototype
    
    def clone(self, key, **attrs):
        prototype = self._prototypes.get(key)
        if not prototype:
            raise ValueError(f"原型 {key} 未注册")
        
        obj = copy.deepcopy(prototype)
        obj.__dict__.update(attrs)  # 覆盖属性
        return obj

# 使用
registry = PrototypeRegistry()
registry.register("gaming_pc", GamingPCBuilder().build())
registry.register("office_pc", OfficePCBuilder().build())

# 克隆并定制
my_pc = registry.clone("gaming_pc", memory="128GB")
```

### 4.3 Python 自带的 copy 模块

```python
import copy

# 对象必须可被 copy (没有 __deepcopy__ 等特殊需求)
obj1 = SomeClass()
obj2 = copy.copy(obj1)      # 浅拷贝
obj3 = copy.deepcopy(obj1)  # 深拷贝
```

## 5. Java 实现

### 5.1 Cloneable 接口

```java
public abstract class Shape implements Cloneable {
    public String color;
    
    @Override
    public Shape clone() {
        try {
            return (Shape) super.clone();
        } catch (CloneNotSupportedException e) {
            throw new RuntimeException(e);
        }
    }
}

public class Circle extends Shape {
    public int radius;
    
    @Override
    public Circle clone() {
        Circle c = (Circle) super.clone();
        // 浅拷贝即可, radius 是基本类型
        return c;
    }
}

public class DeepShape extends Shape {
    public int[] data;  // 引用类型
    
    @Override
    public DeepShape clone() {
        DeepShape d = (DeepShape) super.clone();
        d.data = data.clone();  // 深拷贝数组
        return d;
    }
}
```

### 5.2 深拷贝工具

```java
// 使用序列化实现深拷贝
public static <T extends Serializable> T deepCopy(T obj) {
    try {
        ByteArrayOutputStream baos = new ByteArrayOutputStream();
        new ObjectOutputStream(baos).writeObject(obj);
        ByteArrayInputStream bais = new ByteArrayInputStream(baos.toByteArray());
        return (T) new ObjectInputStream(bais).readObject();
    } catch (Exception e) {
        throw new RuntimeException(e);
    }
}
```

## 6. 实际应用

### 6.1 JavaScript 原型继承

JavaScript 的对象系统就是原型模式:

```javascript
const animal = {
    speak() { return "..."; }
};

const dog = Object.create(animal);
dog.bark = function() { return "汪汪"; };

dog.speak();  // 继承自 animal
dog.bark();   // 自己的方法
```

### 6.2 Java Object.clone()

```java
// 所有 Object 子类都能 clone
// 但要实现 Cloneable 接口
Date today = new Date();
Date tomorrow = (Date) today.clone();
```

### 6.3 Spring Bean Scope="prototype"

```java
@Bean
@Scope("prototype")  // 每次 getBean 都创建新实例
public UserService userService() {
    return new UserService();
}

// 每次调用都新建对象
UserService s1 = ctx.getBean("userService");
UserService s2 = ctx.getBean("userService");
s1 != s2;  // true
```

### 6.4 数据库查询结果

```java
// 从数据库查询的 ResultSet 转对象时
// 通常用 BeanUtils.copyProperties 或 MapStruct 克隆
UserDTO dto = new UserDTO();
BeanUtils.copyProperties(entity, dto);
// 类似原型模式
```

### 6.5 撤销/快照

```java
// 备忘录模式的基础
Document doc = ...;
Document snapshot = doc.clone();  // 保存快照
// 修改 doc
doc.restore(snapshot);  // 撤销
```

## 7. 优缺点

### 优点

✅ **创建复杂对象更快**: 比 new 高效 (尤其是数据库查询后)

✅ **保留对象关系**: 深拷贝保留所有嵌套结构

✅ **动态添加/删除产品**: 注册表模式灵活

✅ **减少继承**: 用克隆代替继承来配置对象

### 缺点

❌ **深拷贝开销大**: 嵌套深的对象克隆慢

❌ **循环引用问题**: A 包含 B, B 包含 A → 死循环

❌ **必须实现 clone**: 增加开发复杂度

❌ **浅拷贝陷阱**: 默认 clone 是浅拷贝, 必须显式深拷贝

## 8. 实战思考

### Q1: 什么时候用原型模式?

✅ **对象创建成本高** (数据库/网络/文件)

✅ **避免复杂的构造器**: 配置项多

✅ **动态加载类**: 注册表模式

✅ **快照/撤销**: 备忘录模式基础

❌ **简单对象**: 直接 `new` 更快

❌ **循环引用**: 可能栈溢出

### Q2: 浅拷贝 vs 深拷贝 怎么选?

| 场景 | 选择 |
| :--- | :--- |
| 对象只有基本类型字段 | 浅拷贝 |
| 有不可变引用 (tuple, frozenset) | 浅拷贝 |
| 有可变引用 (list, dict, set) | **深拷贝** |
| 性能敏感 | 浅拷贝 + 手动深拷贝特定字段 |
| 完全独立副本 | 深拷贝 |

### Q3: 原型 vs 工厂?

| 原型 | 工厂 |
| :--- | :--- |
| 已有对象**克隆**新对象 | 通过类名/参数**创建**新对象 |
| 运行时决定 | 编译时决定 |
| 灵活 (运行时配置) | 规范 (面向接口) |

**结合使用**: 工厂返回原型, 然后克隆原型.

```java
class PrototypeFactory {
    private Map<String, Prototype> prototypes = new HashMap<>();
    
    public void register(String key, Prototype p) {
        prototypes.put(key, p);
    }
    
    public Prototype create(String key) {
        return prototypes.get(key).clone();
    }
}
```
