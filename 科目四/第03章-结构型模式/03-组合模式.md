# 03. 组合模式 (Composite)

> **一句话**: 将对象组合成**树形结构**以表示"**部分-整体**"的层次结构, 使客户端对**单个对象**和**组合对象**的使用具有**一致性**.

**别名**: 对象树 (Object Tree), 部分-整体模式 (Part-Whole)

---

## 1. 核心问题

假设你在做一个文件管理器, 需要同时处理**文件**和**目录**:

```text
📁 /home/user/
├── 📄 readme.txt           (文件)
├── 📁 projects/            (目录)
│   ├── 📄 main.py          (文件)
│   ├── 📄 test.py          (文件)
│   └── 📁 docs/            (目录)
│       └── 📄 api.md       (文件)
└── 📄 todo.md              (文件)
```

**问题**:
- 文件有大小, 目录也有大小 (所有子文件总和)
- 文件能删除, 目录也能删除 (删除自己及所有子节点)
- 文件能显示, 目录也能显示 (递归显示所有子节点)

**用继承解决?** ❌

```java
// 错误: 文件和目录用 if-else 区分
if (node instanceof File) {
    ((File) node).getSize();
} else if (node instanceof Directory) {
    ((Directory) node).calculateSize();  // 还要遍历子节点
}
// 加新类型 (软链接)? 又得改所有调用处!
```

**用组合模式解决?** ✅ 让文件和目录**实现同一个接口**, 客户端**统一调用**.

## 2. UML 类图

```text
                ┌─────────────────────────┐
                │   <<Component>>          │ ← 抽象组件
                │   FileSystemNode        │
                ├─────────────────────────┤
                │ +name: String           │
                │ +display(depth): void   │
                │ +getSize(): int         │
                │ +add(node): void        │
                │ +remove(node): void     │
                │ +getChild(i): Node      │
                └───────────△─────────────┘
                            │ (实现)
                ┌───────────┴─────────────┐
                │                         │
        ┌───────────────────┐    ┌──────────────────────┐
        │     Leaf          │    │   Composite          │
        │     File          │    │   Directory          │
        ├───────────────────┤    ├──────────────────────┤
        │ -size: int        │    │ -children: List<Node> │
        ├───────────────────┤    ├──────────────────────┤
        │ +display(depth)   │    │ +display(depth)      │
        │ +getSize()        │    │ +getSize()           │ ← 递归求和
        │ +add() ❌         │    │ +add(node)           │
        │ +remove() ❌      │    │ +remove(node)        │
        └───────────────────┘    │ +getChild(i)         │
                                 └──────────┬───────────┘
                                            │ 持有
                                            │ children
                                            ▼
                                 ┌──────────────────────┐
                                 │  FileSystemNode (递归) │
                                 └──────────────────────┘
```

**关键点**:
- `Component` 是**统一接口** (文件和目录都实现)
- `Leaf` (文件) **不能** add/remove, 抛异常或空实现
- `Composite` (目录) **持有** Component 集合, **递归调用**

## 3. Python 实现

```python
"""
组合模式 - 文件系统示例
演示: 文件和目录组成树, 统一接口操作
"""
from abc import ABC, abstractmethod
from typing import List


# ===== 1. 抽象组件 (Component) =====
class FileSystemNode(ABC):
    """文件系统节点 - 文件和目录的共同接口"""

    def __init__(self, name: str):
        self.name = name

    @abstractmethod
    def display(self, depth: int = 0) -> None:
        """显示节点 (文件和目录统一接口)"""
        pass

    @abstractmethod
    def get_size(self) -> int:
        """获取大小 (文件和目录统一接口)"""
        pass

    # 默认实现: 叶节点不支持增删, 抛异常
    def add(self, node: 'FileSystemNode') -> None:
        raise NotImplementedError("文件不支持 add 操作")

    def remove(self, node: 'FileSystemNode') -> None:
        raise NotImplementedError("文件不支持 remove 操作")

    def get_child(self, index: int) -> 'FileSystemNode':
        raise NotImplementedError("文件不支持 get_child 操作")


# ===== 2. 叶节点 (Leaf) - 文件 =====
class File(FileSystemNode):
    """文件 - 叶子节点"""

    def __init__(self, name: str, size: int):
        super().__init__(name)
        self.size = size  # KB

    def display(self, depth: int = 0) -> None:
        print(f"{'  ' * depth}📄 {self.name} ({self.size}KB)")

    def get_size(self) -> int:
        return self.size


# ===== 3. 组合节点 (Composite) - 目录 =====
class Directory(FileSystemNode):
    """目录 - 可以包含文件或其他目录"""

    def __init__(self, name: str):
        super().__init__(name)
        self.children: List[FileSystemNode] = []

    def display(self, depth: int = 0) -> None:
        print(f"{'  ' * depth}📁 {self.name}/")
        for child in self.children:
            child.display(depth + 1)  # 递归调用子节点 display

    def get_size(self) -> int:
        # 递归累加所有子节点大小
        total = 0
        for child in self.children:
            total += child.get_size()
        return total

    def add(self, node: FileSystemNode) -> None:
        self.children.append(node)
        print(f"  ✓ 已添加 {node.name} 到 {self.name}/")

    def remove(self, node: FileSystemNode) -> None:
        self.children.remove(node)
        print(f"  ✓ 已从 {self.name}/ 移除 {node.name}")

    def get_child(self, index: int) -> FileSystemNode:
        return self.children[index]


# ===== 4. 客户端使用 =====
def main():
    print("=" * 50)
    print("示例 1: 构造文件系统树")
    print("=" * 50)

    # 创建目录
    home = Directory("home")
    user = Directory("user")
    home.add(user)

    # 在 user/ 下添加文件
    user.add(File("readme.txt", 5))
    user.add(File("todo.md", 2))

    # 创建子目录 projects/
    projects = Directory("projects")
    user.add(projects)

    # projects/ 下添加文件
    projects.add(File("main.py", 10))
    projects.add(File("test.py", 8))

    # projects/docs/ 子目录
    docs = Directory("docs")
    projects.add(docs)
    docs.add(File("api.md", 3))

    # 统一接口调用: 显示整棵树
    print("\n--- 文件系统树 ---")
    home.display()

    # 统一接口调用: 计算总大小
    print("\n--- 总大小 ---")
    print(f"home/ 总大小: {home.get_size()}KB")
    print(f"projects/ 总大小: {projects.get_size()}KB")

    # 客户端无需区分 File 和 Directory
    print("\n--- 删除文件 ---")
    readme = user.get_child(0)
    user.remove(readme)
    print(f"删除后 home/ 总大小: {home.get_size()}KB")


if __name__ == "__main__":
    main()
```

## 4. Java 实现

```java
import java.util.ArrayList;
import java.util.List;

// ===== 1. 抽象组件 =====
public abstract class FileSystemNode {
    protected String name;

    public FileSystemNode(String name) {
        this.name = name;
    }

    public abstract void display(int depth);
    public abstract int getSize();

    public void add(FileSystemNode node) {
        throw new UnsupportedOperationException("不支持 add");
    }

    public void remove(FileSystemNode node) {
        throw new UnsupportedOperationException("不支持 remove");
    }

    public FileSystemNode getChild(int index) {
        throw new UnsupportedOperationException("不支持 getChild");
    }
}

// ===== 2. 叶子节点 - 文件 =====
public class File extends FileSystemNode {
    private int size;

    public File(String name, int size) {
        super(name);
        this.size = size;
    }

    @Override
    public void display(int depth) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < depth; i++) sb.append("  ");
        System.out.println(sb + "📄 " + name + " (" + size + "KB)");
    }

    @Override
    public int getSize() {
        return size;
    }
}

// ===== 3. 组合节点 - 目录 =====
public class Directory extends FileSystemNode {
    private List<FileSystemNode> children = new ArrayList<>();

    public Directory(String name) {
        super(name);
    }

    @Override
    public void display(int depth) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < depth; i++) sb.append("  ");
        System.out.println(sb + "📁 " + name + "/");
        for (FileSystemNode child : children) {
            child.display(depth + 1);
        }
    }

    @Override
    public int getSize() {
        int total = 0;
        for (FileSystemNode child : children) {
            total += child.getSize();
        }
        return total;
    }

    @Override
    public void add(FileSystemNode node) {
        children.add(node);
    }

    @Override
    public void remove(FileSystemNode node) {
        children.remove(node);
    }

    @Override
    public FileSystemNode getChild(int index) {
        return children.get(index);
    }
}

// ===== 4. 客户端 =====
public class Client {
    public static void main(String[] args) {
        Directory home = new Directory("home");
        Directory user = new Directory("user");
        home.add(user);

        user.add(new File("readme.txt", 5));
        user.add(new File("todo.md", 2));

        Directory projects = new Directory("projects");
        user.add(projects);
        projects.add(new File("main.py", 10));

        home.display(0);          // 统一接口
        System.out.println("总大小: " + home.getSize() + "KB");  // 统一接口
    }
}
```

## 5. 实际应用

### 5.1 Swing / JavaFX 组件树

```java
// Swing 容器和组件都是 Component 的子类
Container panel = new JPanel();
panel.add(new JButton("按钮"));   // add 组件
panel.add(new JLabel("标签"));   // add 组件

// 容器和组件**统一处理**: 都能 add, paint, getSize
// 这就是组合模式!
```

### 5.2 HTML DOM 树

```javascript
// DOM 是天然的组合模式
// Node (Component) - 抽象
// Element (Composite) - 可以有子节点 (div, ul)
// TextNode (Leaf) - 叶子

const div = document.createElement('div');
div.appendChild(document.createElement('p'));   // 组合
div.appendChild(document.createTextNode('Hi')); // 叶子
// 统一操作: div.appendChild(), div.removeChild()
```

### 5.3 组织架构 (HR 系统)

```java
// 员工 (Employee) 既可以是普通员工 (Leaf), 也可以是经理 (有下属)
```

## 6. 优缺点

### 优点

| 优点 | 说明 |
| :--- | :--- |
| ✅ **统一处理** | 客户端不区分叶子和组合, 简化代码 |
| ✅ **易扩展** | 新增节点类型 (软链接?) 不影响现有代码 |
| ✅ **符合开闭原则** | 增节点不动旧代码 |
| ✅ **递归自然** | 树形操作 (大小/删除) 天然递归 |

### 缺点

| 缺点 | 说明 |
| :--- | :--- |
| ❌ **限制类型** | Component 接口难以同时满足叶子和组合的所有需求 |
| ❌ **接口污染** | Leaf 必须实现 add/remove 等不适用方法 (即使抛异常) |
| ❌ **类型检查** | 客户端可能仍需 `instanceof` 检查 (违反透明性) |
| ❌ **设计复杂** | 树过深时调试困难 |

## 7. 实战思考

### Q1: 组合 vs 继承?

| 组合 | 继承 |
| :--- | :--- |
| "has-a" 关系 | "is-a" 关系 |
| 运行时灵活组合 | 编译时确定 |
| 文件系统/UI 树 | 类型层次 |

```python
# 组合: 树形结构, 部分-整体
tree.add(leaf)
tree.add(branch)

# 继承: 类型层次
class Dog(Animal): pass

# 组合模式 = 树形 + 统一接口
```

### Q2: 如何处理 Leaf 的 add/remove?

**三种方案**:

| 方案 | 优点 | 缺点 |
| :--- | :--- | :--- |
| ① 抛异常 | 安全 | 客户端需捕获 |
| ② 空实现 | 简单 | 隐藏了错误 |
| ③ 不在 Leaf 声明 | 干净 | 客户端类型不安全 |

```python
# 方案 ① (Python 推荐): 抛 NotImplementedError
class File(FileSystemNode):
    def add(self, node):
        raise NotImplementedError("File 不能 add")

# 方案 ③ (类型安全): 用 isinstance 检查
if isinstance(node, Directory):
    node.add(child)
```

### Q3: 真实项目里如何选择?

| 场景 | 推荐模式 |
| :--- | :--- |
| **文件/目录、组织架构** | ✅ 组合模式 |
| **UI 组件树 (Vue/React)** | ✅ 组合模式 (天然) |
| **菜单和菜单项** | ✅ 组合模式 |
| **仅 2 层结构** | ❌ 直接组合更简单 |
| **节点类型差异极大** | ❌ 不要强行组合 |
