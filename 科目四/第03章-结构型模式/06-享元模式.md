# 06. 享元模式 (Flyweight)

> **一句话**: 运用**共享技术**有效地支持**大量细粒度**的对象, 减少创建对象的数量.

**别名**: 蝇量模式, 轻量级模式

---

## 1. 核心问题

围棋棋盘上, 一个 19×19 的棋盘共有 **361 个交叉点**, 如果每个点都是一个独立对象:

```python
# ❌ 反例: 每个棋子都 new 一次
class ChessPiece:
    def __init__(self, color, x, y):
        self.color = color  # 颜色 (黑/白) - 只有 2 种!
        self.x = x          # 位置 x - 19 种
        self.y = y          # 位置 y - 19 种
        self.image = self.load_image()  # 图片 (几十 KB)

# 361 个棋子, 每个都有自己的图片对象
# 内存浪费! 颜色只有 2 种, 但 new 了 361 次
```

**关键观察**:
- 棋子的**颜色**只有 2 种 (黑/白), 但**实例**有 361 个
- **大量重复**的部分: 颜色、形状、图片
- 每个棋子**真正不同**的: 坐标 (x, y)

**享元模式解决**: 把**共享的部分** (内部状态) 抽出来**缓存复用**, **不共享的部分** (外部状态) 传给方法.

| 状态 | 说明 | 例子 |
| :--- | :--- | :--- |
| **内部状态** (Intrinsic) | 可共享, 存储在享元中 | 颜色、图片 |
| **外部状态** (Extrinsic) | 不可共享, 由客户端传入 | 坐标 |

## 3. Python 实现

```python
"""
享元模式 - 围棋棋子
演示: 共享颜色相同的棋子, 节省内存
"""
from typing import Dict


# ===== 1. 享元类 (Flyweight) =====
class ChessPiece:
    """
    享元对象 - 围棋棋子
    内部状态: 颜色、图片 (可共享)
    外部状态: 坐标 (不存储, 由方法传入)
    """

    def __init__(self, color: str):
        # 内部状态: 创建后不变, 可共享
        self.color = color
        self.image = self._load_image(color)
        print(f"  [创建] {color}色棋子 (加载图片资源)")

    def _load_image(self, color: str):
        """模拟加载图片 (开销大)"""
        # 真实场景: 从文件/网络加载图片, 占内存
        return f"<{color}色棋子图片 100KB>"

    def display(self, x: int, y: int):
        """
        显示棋子 - 外部状态 (x, y) 由参数传入
        """
        symbol = "●" if self.color == "黑" else "○"
        return f"{symbol} ({x},{y})"


# ===== 2. 享元工厂 (FlyweightFactory) =====
class PieceFactory:
    """
    享元工厂 - 管理共享对象
    关键: get_piece 返回相同颜色的同一实例
    """

    def __init__(self):
        self._pieces: Dict[str, ChessPiece] = {}  # 缓存池

    def get_piece(self, color: str) -> ChessPiece:
        """
        获取享元 - 如果已存在, 返回缓存; 否则创建
        """
        if color not in self._pieces:
            self._pieces[color] = ChessPiece(color)
        return self._pieces[color]

    def get_pool_size(self) -> int:
        """返回池中对象数"""
        return len(self._pieces)


# ===== 3. 棋盘 (客户端) =====
class ChessBoard:
    """围棋棋盘"""

    def __init__(self, size: int = 19):
        self.size = size
        self.factory = PieceFactory()
        # 存储所有棋子位置
        self.pieces = []  # [(piece, x, y)]

    def place_piece(self, color: str, x: int, y: int):
        """放置棋子"""
        # 关键: get_piece 返回共享对象, 不是新对象
        piece = self.factory.get_piece(color)
        self.pieces.append((piece, x, y))

    def display(self):
        """显示棋盘"""
        for piece, x, y in self.pieces:
            print(f"  {piece.display(x, y)}")

    def show_statistics(self):
        """显示统计"""
        print(f"\n  📊 棋盘统计:")
        print(f"  - 棋盘大小: {self.size}x{self.size}")
        print(f"  - 棋子总数: {len(self.pieces)}")
        print(f"  - 享元对象数: {self.factory.get_pool_size()}")
        print(f"  - 节省内存: {len(self.pieces) - self.factory.get_pool_size()} 个对象")


# ===== 4. 演示 =====
def main():
    print("=" * 50)
    print("享元模式 - 围棋棋子演示")
    print("=" * 50)

    # 不使用享元模式会创建 361 个对象
    # 使用享元模式只创建 2 个对象 (黑 + 白)
    board = ChessBoard(19)

    # 模拟落子
    print("\n--- 模拟对局落子 ---")
    moves = [
        ("黑", 3, 3), ("白", 15, 15),
        ("黑", 3, 15), ("白", 15, 3),
        ("黑", 10, 10), ("白", 5, 5),
        ("黑", 8, 8), ("白", 12, 12),
        ("黑", 9, 9), ("白", 11, 11),
    ]

    for color, x, y in moves:
        board.place_piece(color, x, y)
        print(f"  落子: {color} ({x},{y})")

    # 显示棋盘
    print("\n--- 棋盘显示 ---")
    board.display()

    # 显示统计: 只创建了 2 个享元对象, 但棋盘上有 10 个棋子
    board.show_statistics()

    # 验证: 相同颜色的棋子是同一对象
    print("\n--- 对象身份验证 ---")
    black1 = board.factory.get_piece("黑")
    black2 = board.factory.get_piece("黑")
    print(f"  黑棋 1 是不是 黑棋 2? {black1 is black2}")  # True
    print(f"  → 享元模式生效, 共享对象成功!")


if __name__ == "__main__":
    main()
```

## 4. Java 实现

```java
import java.util.HashMap;
import java.util.Map;

// ===== 1. 享元类 =====
public class ChessPiece {
    private final String color;  // 内部状态 (可共享)
    private final String image;  // 内部状态 (可共享)

    public ChessPiece(String color) {
        this.color = color;
        this.image = "<" + color + "色棋子 100KB>";
        System.out.println("  [创建] " + color + "色棋子");
    }

    public String display(int x, int y) {
        String symbol = "黑".equals(color) ? "●" : "○";
        return symbol + " (" + x + "," + y + ")";
    }
}

// ===== 2. 享元工厂 =====
public class PieceFactory {
    private final Map<String, ChessPiece> pieces = new HashMap<>();

    public ChessPiece getPiece(String color) {
        if (!pieces.containsKey(color)) {
            pieces.put(color, new ChessPiece(color));
        }
        return pieces.get(color);
    }

    public int getPoolSize() {
        return pieces.size();
    }
}

// ===== 3. 棋盘 =====
public class ChessBoard {
    private final PieceFactory factory = new PieceFactory();

    public ChessPiece placePiece(String color, int x, int y) {
        return factory.getPiece(color);
    }
}

// ===== 4. 客户端 =====
public class Client {
    public static void main(String[] args) {
        PieceFactory factory = new PieceFactory();
        // 361 个棋子, 但只有 2 个享元对象
        ChessPiece p1 = factory.getPiece("黑");
        ChessPiece p2 = factory.getPiece("白");
        System.out.println(p1.display(3, 3));
        System.out.println(p2.display(15, 15));
        System.out.println("享元池大小: " + factory.getPoolSize());  // 2
    }
}
```

## 5. 实际应用

### 5.1 Java Integer 缓存池 (经典!)

```java
// Integer.valueOf 用了享元模式!
Integer a = Integer.valueOf(100);
Integer b = Integer.valueOf(100);
System.out.println(a == b);  // true (同一对象!)

// 因为 Integer 缓存了 -128 ~ 127 的值
// 这就是享元模式: 共享小整数

// 但超出范围:
Integer c = Integer.valueOf(200);
Integer d = Integer.valueOf(200);
System.out.println(c == d);  // false (新对象)
```

### 5.2 Java String 常量池

```java
// String 字面量用了享元模式
String s1 = "hello";
String s2 = "hello";
System.out.println(s1 == s2);  // true (同一对象!)

// 因为 String 池共享了字符串常量
// 这是 JVM 级别的享元实现
```

### 5.3 数据库连接池

```python
# 数据库连接池 - 享元思想
# 连接对象很重 (网络握手), 应该共享

class ConnectionPool:
    """享元式连接池"""

    def __init__(self, max_size: int = 10):
        self._pool = []
        self._max_size = max_size

    def get_connection(self):
        """获取连接 (共享已有连接)"""
        if self._pool:
            conn = self._pool.pop()
            print(f"  → 从池中复用连接 (剩余 {len(self._pool)})")
            return conn
        else:
            print(f"  → 创建新连接")
            return self._create_new_connection()

    def release(self, conn):
        """归还连接到池"""
        self._pool.append(conn)
        print(f"  ← 连接已归还 (池中 {len(self._pool)} 个)")

# HikariCP, Druid 都是享元思想的应用
```

### 5.4 字体渲染 (字符池)

```java
// 文本编辑器中, 相同字符共享字形数据
// 例如字符 'a' 的字形对象, 文档中所有 'a' 共享

class CharacterFlyweight {
    private char symbol;       // 内部状态
    private FontData font;     // 内部状态 (字体数据)

    public void display(int x, int y, int size) {
        // x, y, size 是外部状态
        font.render(symbol, x, y, size);
    }
}

// 文档中可能有几万个 'a', 但只创建一个 'a' 的字形对象
```

### 5.5 JavaScript 字符串驻留 (String Interning)

```javascript
// V8 引擎对短字符串做了享元
const a = "hello";

console.log(a === b);  // true (共享)

// 数字小整数也共享
const x = 100;

```

## 6. 优缺点

### 优点

| 优点 | 说明 |
| :--- | :--- |
| ✅ **大幅节省内存** | 大量重复对象只存一份 |
| ✅ **提高性能** | 减少对象创建开销 |
| ✅ **集中管理** | 工厂统一管理共享对象 |
| ✅ **可扩展** | 新增享元只需扩展工厂 |

### 缺点

| 缺点 | 说明 |
| :--- | :--- |
| ❌ **关注点分离** | 必须区分内部/外部状态 |
| ❌ **线程安全** | 共享对象需要考虑并发 |
| ❌ **逻辑复杂** | 外部状态传入增加复杂度 |
| ❌ **不适合所有场景** | 对象差异大时反而难共享 |

## 7. 实战思考

### Q1: 享元 vs 单例?

| 享元 | 单例 |
| :--- | :--- |
| **多个共享对象** (池) | **唯一一个对象** |
| 按 key 区分 | 全局唯一 |
| 工厂管理 | 类自己管理 |

```python
# 单例: 一个类只有 1 个实例
class Singleton:
    _instance = None
    def __new__(cls):
        if not cls._instance:
            cls._instance = super().__new__(cls)
        return cls._instance

# 享元: 一个工厂管理多个共享实例
class FlyweightFactory:
    def get(self, key):
        if key not in self.pool:
            self.pool[key] = Flyweight(key)
        return self.pool[key]
# pool 有多个, 但每个 key 只一个
```

### Q2: 享元 vs 对象池?

| 享元 | 对象池 |
| :--- | :--- |
| **生命周期与进程一致** | 对象**借出/归还** |
| 不需要主动释放 | 借出后必须归还 |
| 不可变对象 | 可变对象 |
| 节省存储 | 节省创建开销 |

```python
# 享元: 对象一直共享, 永不释放
black_piece = factory.get("黑")  # 一直在

# 对象池: 用完还回来
conn = pool.get_connection()  # 借出
try:
    conn.execute(...)
finally:
    pool.release(conn)  # 必须归还
```

### Q3: 什么时候用享元?

✅ **对象数量极大** (成千上万), 且**重复多**

✅ **可以分离内部/外部状态**

✅ **对象可共享**, 不需要独立标识

❌ **对象差异大** → 没法共享, 不必用

❌ **对象有独立可变状态** → 共享会导致问题

❌ **数量不多** → 直接 new 更简单

## 8. 小结

✅ **核心**: **共享**内部状态, **分离**外部状态, 减少对象数量

✅ **应用**: Integer 缓存, String 池, 连接池, 字符渲染

✅ **关键**: 区分**可共享** (颜色) 和**不可共享** (坐标) 部分
