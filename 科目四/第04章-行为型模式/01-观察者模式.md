# 01. 观察者模式 (Observer)

> **一句话**: 定义对象间一种**一对多**的依赖关系, 当一个对象状态发生改变时, 所有依赖它的对象都得到通知并被**自动更新**.

**别名**: 发布-订阅 (Pub-Sub), 事件监听器 (Event Listener)

---

## 1. 核心问题

需要一种机制, 当某件事发生时, 多个其他对象**自动**做出反应:

- 股价变动 → 多个投资者的持仓界面刷新
- 用户点击按钮 → 触发多个事件 (日志/统计/动画)
- 主题切换 → 通知所有 UI 组件重新渲染
- Kafka 消息 → 多个消费者各自处理

**问题**: 如果用紧耦合:

```python
# ❌ 紧耦合: 股价类直接依赖所有投资者类
class Stock:
    def __init__(self):
        self.investor_a = InvestorA()  # 硬编码
        self.investor_b = InvestorB()
        self.investor_c = InvestorC()
    
    def price_changed(self):
        self.investor_a.update()
        self.investor_b.update()
        self.investor_c.update()
```

**问题**:
- Stock 知道所有观察者, 违反开闭原则
- 加新观察者要改 Stock 代码
- 观察者之间没有统一接口

## 2. 模式结构

```text
              ┌────────────────────┐
              │   <<Subject>>       │
              │      Subject        │
              ├────────────────────┤
              │ -observers: List    │
              ├────────────────────┤
              │ +attach(o)          │
              │ +detach(o)          │
              │ +notify()           │
              └──────────△─────────┘
                         │ (继承)
        ┌────────────────┴─────────────────┐
        │                                  │
  ┌─────────────────┐         ┌─────────────────┐
  │ ConcreteSubject  │         │ ConcreteSubject  │
  │ (Stock)          │         │ (Weather)        │
  ├─────────────────┤         ├─────────────────┤
  │ -state           │         │ -temperature     │
  │ +getState()      │         │ +getTemperature()│
  │ +setState()      │         │ +setTemperature()│
  └─────────────────┘         └─────────────────┘
                △                          △
                │ 通知 (notify)             │
       ┌────────┴────────────────────┐
       │   <<Observer>>                │
       │      Observer                 │
       ├────────────────────────────────┤
       │ +update(subject)             │
       └────────△───────────────────────┘
                │ (实现)
       ┌────────┴───────────────────────┐
       │                                │
  ┌──────────────┐            ┌──────────────┐
  │ InvestorA    │            │ InvestorB    │
  ├──────────────┤            ├──────────────┤
  │+update()     │            │+update()     │
  └──────────────┘            └──────────────┘
```

**4 个角色**:
- **Subject**: 主题 (被观察)
- **Observer**: 观察者接口
- **ConcreteSubject**: 具体主题
- **ConcreteObserver**: 具体观察者

## 3. Python 实现

### 3.1 自带实现

```python
from abc import ABC, abstractmethod
from typing import List

# 1. 抽象观察者
class Observer(ABC):
    @abstractmethod
    def update(self, subject): pass

# 2. 抽象主题
class Subject(ABC):
    def __init__(self):
        self._observers: List[Observer] = []
    
    def attach(self, observer: Observer):
        if observer not in self._observers:
            self._observers.append(observer)
    
    def detach(self, observer: Observer):
        if observer in self._observers:
            self._observers.remove(observer)
    
    def notify(self):
        for obs in self._observers:
            obs.update(self)

# 3. 具体主题: 股票
class Stock(Subject):
    def __init__(self, symbol, price):
        super().__init__()
        self.symbol = symbol
        self._price = price
    
    @property
    def price(self):
        return self._price
    
    @price.setter
    def price(self, value):
        if value == self._price:
            return
        self._price = value
        print(f"\n[Stock] {self.symbol} 价格变更为 {value}")
        self.notify()

# 4. 具体观察者
class Investor(Observer):
    def __init__(self, name):
        self.name = name
    
    def update(self, subject: Stock):
        print(f"  [Investor {self.name}] 收到通知: "
              f"{subject.symbol} = {subject.price}")

# 使用
apple = Stock("AAPL", 150.0)
alice = Investor("Alice")
bob = Investor("Bob")

apple.attach(alice)
apple.attach(bob)

apple.price = 155.0
# [Stock] AAPL 价格变更为 155.0
#   [Investor Alice] 收到通知: AAPL = 155.0
#   [Investor Bob] 收到通知: AAPL = 155.0

apple.detach(alice)
apple.price = 160.0
# [Stock] AAPL 价格变更为 160.0
#   [Investor Bob] 收到通知: AAPL = 160.0
```

### 3.2 Python 内置 `property` 简化

```python
# 实际上 Python 的 property + observer 模式可以这样用
class Stock:
    def __init__(self, price):
        self._price = price
        self.observers = []
    
    @property
    def price(self):
        return self._price
    
    @price.setter
    def price(self, value):
        self._price = value
        for cb in self.observers:
            cb(self)

stock = Stock(100)
stock.observers.append(lambda s: print(f"观察者1: {s.price}"))
stock.observers.append(lambda s: print(f"观察者2: {s.price}"))
stock.price = 200
# 观察者1: 200
# 观察者2: 200
```

## 4. Java 实现

```java
import java.util.ArrayList;
import java.util.List;

// 抽象观察者
interface Observer {
    void update(Subject subject);
}

// 抽象主题
abstract class Subject {
    private List<Observer> observers = new ArrayList<>();
    
    public void attach(Observer o) {
        observers.add(o);
    }
    
    public void detach(Observer o) {
        observers.remove(o);
    }
    
    protected void notifyObservers() {
        for (Observer o : observers) {
            o.update(this);
        }
    }
}

// 具体主题
class Stock extends Subject {
    private double price;
    private String symbol;
    
    public Stock(String symbol, double price) {
        this.symbol = symbol;
        this.price = price;
    }
    
    public double getPrice() { return price; }
    
    public void setPrice(double price) {
        if (this.price != price) {
            this.price = price;
            notifyObservers();  // 自动通知
        }
    }
}

// 具体观察者
class Investor implements Observer {
    private String name;
    
    public Investor(String name) {
        this.name = name;
    }
    
    public void update(Subject subject) {
        Stock stock = (Stock) subject;
        System.out.println("投资者 " + name + " 收到通知: "
                          + stock.getPrice());
    }
}

// 使用
Stock apple = new Stock("AAPL", 150);
apple.attach(new Investor("Alice"));
apple.attach(new Investor("Bob"));
apple.setPrice(155);
// 投资者 Alice 收到通知: 155.0
// 投资者 Bob 收到通知: 155.0
```

## 5. 实际应用

### 5.1 JavaScript DOM 事件

```javascript
// 浏览器中的 addEventListener 就是观察者模式
button.addEventListener('click', function(event) {
    console.log('点击了!');
});
// click 事件触发, 通知所有监听器
```

### 5.2 Spring ApplicationEvent

```java
// 自定义事件
public class OrderCreatedEvent extends ApplicationEvent {
    private final Order order;
    public OrderCreatedEvent(Object source, Order order) {
        super(source);
        this.order = order;
    }
    public Order getOrder() { return order; }
}

// 发布者
@Service
public class OrderService {
    @Autowired
    private ApplicationEventPublisher publisher;
    
    public void createOrder(Order order) {
        // 保存...
        publisher.publishEvent(new OrderCreatedEvent(this, order));
    }
}

// 监听者
@Component
public class EmailListener implements ApplicationListener<OrderCreatedEvent> {
    public void onApplicationEvent(OrderCreatedEvent event) {
        sendEmail(event.getOrder());
    }
}
```

### 5.3 Vue.js 响应式

```javascript
// Vue 的响应式原理就是观察者模式 + 依赖收集
// 数据变化 → 自动通知依赖该数据的视图
const data = reactive({ count: 0 });
effect(() => console.log(data.count));
data.count++;  // 自动触发 effect
// 0
// 1
```

### 5.4 Kafka 消息队列

```
Producer -> Topic -> Consumer Group
                  ↓
        Observer 1 / Observer 2 / Observer 3
        (订阅同一个 Topic)
```

### 5.5 JavaScript EventEmitter

```javascript
const EventEmitter = require('events');
const emitter = new EventEmitter();

emitter.on('data', (chunk) => console.log('收到:', chunk));
emitter.emit('data', 'Hello');
// 收到: Hello
```

## 6. 优缺点

### 优点

✅ **解耦**: 主题不知观察者具体是谁

✅ **动态关系**: 运行时添加/删除观察者

✅ **广播通信**: 一对多自动通知

✅ **符合开闭**: 新增观察者不改主题

### 缺点

❌ **循环依赖风险**: 观察者 A 改变状态也触发 B 通知, 可能无限循环

❌ **顺序无保证**: 观察者接收通知的顺序不确定

❌ **性能开销**: 大量观察者时通知慢

❌ **内存泄漏风险**: 忘记取消订阅导致对象无法回收

## 7. 实战思考

### Q1: 观察者 vs 发布订阅?

| 观察者 | 发布订阅 |
| :--- | :--- |
| Subject 直接知道 Observer | 通过 Broker (消息中间件) 解耦 |
| 同步通知 | 异步通知 |
| 紧耦合 (Java Swing) | 松耦合 (Kafka) |
| 单进程 | 可跨进程 |

**演进**: 观察者模式 → 当 Subject 和 Observer 中间加入 **Broker/EventBus**, 就变成发布订阅.

### Q2: 内存泄漏怎么办?

```python
# 1. 主动解绑
emitter.off('data', handler)

# 2. 用弱引用 (Python)
import weakref
emitter.on('data', weakref.ref(handler))

# 3. Vue 用 lifecycle hooks 自动清理
onMounted(() => emitter.on('data', handler))
onUnmounted(() => emitter.off('data', handler))
```

### Q3: 同步还是异步通知?

| 同步 | 异步 |
| :--- | :--- |
| 简单直接 | 不阻塞主流程 |
| 可能阻塞调用方 | 需要队列/线程池 |
| 异常会传播 | 异常被吞掉 |
| 实时性 | 可能有延迟 |
