# 03. 命令模式 (Command)

> **一句话**: 将**请求**封装为**对象**, 从而使你可以用不同的请求对客户进行**参数化**; 对请求排队或记录请求日志, 以及支持**可撤销**的操作.

---

## 1. 核心问题

调用方需要和接收方**解耦**, 同时要支持:

- 🕐 **排队** 请求 (任务队列)
- 📝 **记录** 请求 (日志/审计)
- ↩️ **撤销** 操作 (Ctrl+Z)
- 📡 **广播** 请求 (事件总线)

```python
# ❌ 反例: 调用方直接知道具体接收方
class TextEditor:
    def __init__(self):
        self.bold_button = BoldButton()  # 紧耦合
        self.save_button = SaveButton()
    
    def on_bold_click(self):
        self.bold_button.execute()
        # 怎么记录? 怎么撤销? 怎么队列?
```

## 2. 模式结构

```text
                    ┌─────────────────────┐
                    │   <<Command>>        │
                    │      Command         │
                    ├─────────────────────┤
                    │ +execute(): void    │
                    │ +undo(): void       │
                    └──────────△──────────┘
                               │ (实现)
       ┌───────────────────────┼───────────────────────┐
       │                       │                       │
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│ ConcreteCmdA │      │ ConcreteCmdB │      │ ConcreteCmdC │
├──────────────┤      ├──────────────┤      ├──────────────┤
│-receiver    │      │-receiver    │      │-receiver    │
├──────────────┤      ├──────────────┤      ├──────────────┤
│+execute()   │      │+execute()   │      │+execute()   │
│+undo()      │      │+undo()      │      │+undo()      │
└──────────────┘      └──────────────┘      └──────────────┘
       △                       △                       △
       └───────────────────────┼───────────────────────┘
                               │
                    ┌──────────▼──────────┐
                    │     Invoker        │
                    ├─────────────────────┤
                    │ -commands: List     │  ← 存储命令历史
                    ├─────────────────────┤
                    │ +execute(c)         │
                    │ +undo()             │
                    └─────────────────────┘
                               │
                    ┌──────────▼──────────┐
                    │     Receiver       │  ← 真正执行操作的对象
                    ├─────────────────────┤
                    │ +action()          │
                    └─────────────────────┘
```

**4 个角色**:
- **Command**: 抽象命令
- **ConcreteCommand**: 具体命令 (绑定 Receiver)
- **Invoker**: 调用者 (持有命令历史)
- **Receiver**: 接收者 (真正干活)

## 3. Python 实现

### 3.1 文本编辑器示例 (经典)

```python
from abc import ABC, abstractmethod
from typing import List

# 1. 接收者
class TextDocument:
    def __init__(self):
        self.text = ""
        self.cursor = 0
    
    def insert(self, pos, char):
        self.text = self.text[:pos] + char + self.text[pos:]
        self.cursor = pos + 1
    
    def delete(self, pos):
        char = self.text[pos]
        self.text = self.text[:pos] + self.text[pos+1:]
        self.cursor = pos
        return char

# 2. 抽象命令
class Command(ABC):
    @abstractmethod
    def execute(self): pass
    @abstractmethod
    def undo(self): pass

# 3. 具体命令: 插入
class InsertCommand(Command):
    def __init__(self, doc: TextDocument, pos: int, char: str):
        self.doc = doc
        self.pos = pos
        self.char = char
    
    def execute(self):
        self.doc.insert(self.pos, self.char)
    
    def undo(self):
        self.doc.delete(self.pos)

# 4. 调用者
class Editor:
    def __init__(self, doc: TextDocument):
        self.doc = doc
        self.history: List[Command] = []  # 命令历史
    
    def execute(self, cmd: Command):
        cmd.execute()
        self.history.append(cmd)
    
    def undo(self):
        if self.history:
            cmd = self.history.pop()
            cmd.undo()

# 5. 使用
doc = TextDocument()
editor = Editor(doc)

editor.execute(InsertCommand(doc, 0, "H"))
editor.execute(InsertCommand(doc, 1, "e"))
editor.execute(InsertCommand(doc, 2, "l"))
editor.execute(InsertCommand(doc, 3, "l"))
editor.execute(InsertCommand(doc, 4, "o"))
print(doc.text)  # Hello

editor.undo()
print(doc.text)  # Hell
editor.undo()
print(doc.text)  # Hel
```

### 3.2 命令队列 (任务调度)

```python
from collections import deque

class TaskQueue:
    """命令队列: 先进先出执行"""
    def __init__(self):
        self.queue = deque()
    
    def add_command(self, cmd):
        self.queue.append(cmd)
    
    def execute_all(self):
        results = []
        while self.queue:
            cmd = self.queue.popleft()
            results.append(cmd.execute())
        return results

# 使用
queue = TaskQueue()
queue.add_command(InsertCommand(doc, 5, " World"))
queue.add_command(InsertCommand(doc, 11, "!"))
queue.execute_all()
print(doc.text)  # Hello World!
```

### 3.3 宏命令 (复合命令)

```python
class MacroCommand(Command):
    """复合命令: 一组命令组合"""
    def __init__(self, commands: List[Command]):
        self.commands = commands
    
    def execute(self):
        for cmd in self.commands:
            cmd.execute()
    
    def undo(self):
        # 反向撤销
        for cmd in reversed(self.commands):
            cmd.undo()

# 使用
macro = MacroCommand([
    InsertCommand(doc, 5, ","),
    InsertCommand(doc, 6, " Python"),
])
macro.execute()  # Hello, Python!
macro.undo()      # Hello
```

## 4. Java 实现

```java
// 抽象命令
public interface Command {
    void execute();
    void undo();
}

// 具体命令: 开灯
public class LightOnCommand implements Command {
    private Light light;
    
    public LightOnCommand(Light light) {
        this.light = light;
    }
    
    public void execute() {
        light.on();
    }
    
    public void undo() {
        light.off();
    }
}

// 接收者
public class Light {
    public void on() { System.out.println("灯开"); }
    public void off() { System.out.println("灯关"); }
}

// 调用者
public class RemoteControl {
    private Command[] onCommands;
    private Command[] offCommands;
    private Stack<Command> history = new Stack<>();
    
    public RemoteControl() {
        onCommands = new Command[7];
        offCommands = new Command[7];
    }
    
    public void setCommand(int slot, Command onCmd, Command offCmd) {
        onCommands[slot] = onCmd;
        offCommands[slot] = offCmd;
    }
    
    public void onButton(int slot) {
        onCommands[slot].execute();
        history.push(onCommands[slot]);
    }
    
    public void offButton(int slot) {
        offCommands[slot].execute();
        history.push(offCommands[slot]);
    }
    
    public void undoButton() {
        if (!history.isEmpty()) {
            history.pop().undo();
        }
    }
}
```

```java
// SQL 语句就是命令
Statement stmt = connection.createStatement();

stmt.execute("UPDATE users SET ...");   // 命令
connection.rollback();                  // 撤销
```

@Service
public class OrderService {

## 6. 优缺点

### 优点

✅ **解耦**: 调用者和接收者解耦

✅ **可撤销**: 容易实现 undo

✅ **可队列**: 命令对象天然可存储/序列化

✅ **可宏**: 组合多个命令

✅ **可扩展**: 新增命令容易

### 缺点

❌ **类数量多**: 每个操作一个命令类

❌ **复杂**: 实现比直接调用复杂

## 7. 实战思考

### Q1: 命令 vs 策略?

| 命令 | 策略 |
| :--- | :--- |
| 行为型 | 行为型 |
| **动作** (做什么) | **算法** (怎么做) |
| Receiver 是关键 | 关注算法切换 |
| 可撤销 | 不关注撤销 |
| 队列/日志 | 一般不用 |

### Q2: 命令 vs 责任链?

| 命令 | 责任链 |
| :--- | :--- |
| 一个命令**一个**接收者 | 一个请求**多个**处理器 |
| 处理完结束 | 沿链传递 |

### Q3: 撤销怎么实现?

```python
class Command:
    def execute(self): pass
    def undo(self): pass
    # 关键: execute 时保存状态, undo 时恢复
```
