# 05. 迭代器模式 (Iterator)

> **一句话**: 提供一种方法**顺序访问**一个聚合对象中各个元素, 而又**无须暴露**该对象的内部表示.

---

## 1. 核心问题

不同集合数据结构 (列表/树/图) 的**遍历方式**不同:

```python
# ❌ 反例: 客户端知道集合的内部结构
class Tree:
    def get_children(self, node):
        return node.children

# 客户端必须知道这是树, 才能遍历
def traverse(tree):
    queue = [tree.root]
    while queue:
        node = queue.pop(0)  # 队列式遍历
        print(node)
        queue.extend(node.children)
# 加新数据结构 (如网状图) 要改所有遍历代码
```

## 2. 模式结构

```text
              ┌──────────────────────┐
              │   <<Iterator>>        │
              │      Iterator         │
              ├──────────────────────┤
              │ +first(): void       │
              │ +next(): void        │
              │ +isDone(): boolean   │
              │ +currentItem(): T    │
              └──────────△───────────┘
                         │ (实现)
                ┌────────┴────────┐
                │                 │
       ┌─────────────────┐  ┌─────────────────┐
       │ ConcreteIterA   │  │ ConcreteIterB   │
       │ (列表迭代器)     │  │ (树迭代器)        │
       ├─────────────────┤  ├─────────────────┤
       │+first()         │  │+first()         │
       │+next()          │  │+next()          │
       │+isDone()        │  │+isDone()        │
       │+currentItem()   │  │+currentItem()   │
       └─────────────────┘  └─────────────────┘
              △                        △
              │ (使用)                │
       ┌────────┴────────┐                │
       │  <<Aggregate>> │  ← 集合        │
       │   Aggregate    │                │
       ├────────────────┤                │
       │+createIter()   │                │
       └─────────────────┘
```

**4 个角色**:
- **Iterator**: 抽象迭代器
- **ConcreteIterator**: 具体迭代器
- **Aggregate**: 抽象集合 (创建迭代器)
- **ConcreteAggregate**: 具体集合

## 3. Python 实现

### 3.1 自定义迭代器

```python
from abc import ABC, abstractmethod

# 1. 抽象迭代器
class Iterator(ABC):
    @abstractmethod
    def has_next(self) -> bool: pass
    
    @abstractmethod
    def next(self): pass

# 2. 抽象集合
class Aggregate(ABC):
    @abstractmethod
    def create_iterator(self) -> Iterator: pass

# 3. 具体迭代器: 倒序遍历列表
class ReverseListIterator(Iterator):
    def __init__(self, collection):
        self._collection = collection
        self._index = len(collection) - 1
    
    def has_next(self) -> bool:
        return self._index >= 0
    
    def next(self):
        value = self._collection[self._index]
        self._index -= 1
        return value

# 4. 具体集合
class MyList(Aggregate):
    def __init__(self, items):
        self._items = list(items)
    
    def create_iterator(self) -> Iterator:
        return ReverseListIterator(self._items)
    
    def __iter__(self):
        return ReverseListIterator(self._items)

# 使用
items = MyList([1, 2, 3, 4, 5])
it = items.create_iterator()
while it.has_next():
    print(it.next())
# 5, 4, 3, 2, 1
```

### 3.2 Python 内置迭代器

```python
# Python 的 for 循环就是迭代器模式
for x in [1, 2, 3]:  # 列表迭代器
    print(x)

# 自定义迭代器类
class CountDown:
    def __init__(self, start):
        self.current = start
    
    def __iter__(self):  # 返回迭代器
        return self
    
    def __next__(self):  # 返回下一个值
        if self.current <= 0:
            raise StopIteration
        self.current -= 1
        return self.current + 1

# 使用
for i in CountDown(3):
    print(i)  # 3, 2, 1
```

### 3.3 生成器 (最 Pythonic)

```python
def count_down(start):
    """生成器: 简化迭代器"""
    while start > 0:
        yield start
        start -= 1

# 使用
for i in count_down(3):
    print(i)  # 3, 2, 1

# 生成器自动实现迭代器协议
```

### 3.4 树的中序遍历

```python
class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class InOrderIterator:
    """二叉树中序迭代器: 左 -> 根 -> 右"""
    def __init__(self, root):
        self.stack = []
        self._push_left(root)
    
    def _push_left(self, node):
        while node:
            self.stack.append(node)
            node = node.left
    
    def __iter__(self):
        return self
    
    def __next__(self):
        if not self.stack:
            raise StopIteration
        node = self.stack.pop()
        self._push_left(node.right)
        return node.val

# 使用
#     2
#    / \
#   1   3
root = TreeNode(2, TreeNode(1), TreeNode(3))
for val in InOrderIterator(root):
    print(val)  # 1, 2, 3
```

## 4. Java 实现

```java
// 抽象迭代器
public interface Iterator<T> {
    boolean hasNext();
    T next();
}

// 具体迭代器
public class ArrayIterator<T> implements Iterator<T> {
    private T[] array;
    private int index = 0;
    
    public ArrayIterator(T[] array) {
        this.array = array;
    }
    
    public boolean hasNext() {
        return index < array.length;
    }
    
    public T next() {
        return array[index++];
    }
}

// 抽象集合
public interface Iterable<T> {
    Iterator<T> iterator();
}

// 使用 Java 内置
List<String> list = Arrays.asList("a", "b", "c");
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    System.out.println(it.next());
}
```

## 5. 实际应用

### 5.1 Java 集合框架

```java
// Java 所有集合都实现了 Iterator
List<String> list = Arrays.asList("a", "b", "c");
Set<String> set = Set.of("x", "y", "z");
Map<String, Integer> map = Map.of("a", 1);

list.iterator();    // ArrayList 的迭代器
set.iterator();     // HashSet 的迭代器
map.entrySet().iterator();  // Map.Entry 的迭代器
```

### 5.2 Java Stream API

```java
// Stream 底层是迭代器 + 函数式
List<Integer> list = Arrays.asList(1, 2, 3, 4, 5);
int sum = list.stream()
    .filter(n -> n % 2 == 0)
    .map(n -> n * 2)
    .reduce(0, Integer::sum);
```

### 5.3 Python for 循环

```python
# 所有可迭代对象都实现了 __iter__
# list, dict, set, str, tuple, file, generator...
for char in "hello":
    print(char)  # h, e, l, l, o
```

### 5.4 JavaScript Iterable

```javascript
// ES6 引入了 Iterable 协议
const iterable = {
    [Symbol.iterator]() {
        let i = 0;
        return {
            next() {
                return i < 3 
                    ? { value: i++, done: false }
                    : { done: true };
            }
        };
    }
};

for (const v of iterable) {
    console.log(v);
}
// 0, 1, 2
```

### 5.5 数据库游标

```java
// JDBC ResultSet 本质是迭代器
ResultSet rs = stmt.executeQuery("SELECT * FROM users");
while (rs.next()) {  // 迭代器
    String name = rs.getString("name");
}
```

## 6. 优缺点

### 优点

✅ **统一接口**: for 循环适用于所有集合

✅ **封装内部**: 客户端不知树/图细节

✅ **多种遍历**: 同一集合可有多种迭代器 (正序/反序/DFS/BFS)

✅ **延迟遍历**: 节省内存

### 缺点

❌ **增加类**: 每个集合需要配迭代器

❌ **简单集合过度设计**: list 不需要自定义迭代器

## 7. 实战思考

### Q1: 迭代器 vs 生成器?

| 迭代器 | 生成器 |
| :--- | :--- |
| 类 (有状态) | 函数 (有 yield) |
| 显式实现协议 | 自动实现协议 |
| 复杂逻辑用类 | 简单逻辑用函数 |

Python 中**优先用生成器**.

### Q2: 迭代器 vs forEach?

| 迭代器 | forEach |
| :--- | :--- |
| 可以中断 (break) | 不能中断 |
| 可以拿到元素 | 只能消费 |
| 函数式风格 | 命令式风格 |

### Q3: 什么时候自己写迭代器?

✅ **复杂数据结构**: 树/图/自定义结构

✅ **多种遍历方式**: BFS/DFS/中序

✅ **惰性求值**: 数据很大, 流式处理

❌ **普通列表/字典**: 直接用内置

---

## 8. 小结

✅ **核心**: 把遍历逻辑从集合中分离

✅ **Pythonic**: 用 `__iter__` + `__next__` 或 `yield`

✅ **应用**: for 循环, 数据库游标, 流式 API
