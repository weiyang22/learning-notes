# 07. 备忘录模式 (Memento)

> **一句话**: 在不破坏封装性的前提下, **捕获一个对象的内部状态**, 并在该对象之外保存这个状态, 这样以后就可将该对象**恢复到原先保存的状态**.

**别名**: Token (令牌), Snapshot (快照)

---

## 1. 核心问题

需要保存和恢复对象的**内部状态**, 但不破坏封装性:

```python
# ❌ 反例: 直接访问对象内部状态
class Editor:
    def __init__(self):
        self.text = ""
        self.cursor = 0
        self.font_size = 12

class BackupManager:
    def save(self, editor):
        return {
            "text": editor.text,        # ❌ 破坏封装
            "cursor": editor.cursor,
            "font_size": editor.font_size
        }
```

**问题**:
- 暴露对象内部结构
- 加新字段要改所有调用方
- 状态可能在传输中被修改

---

## 2. 模式结构

```text
┌──────────────────────┐         ┌─────────────────┐
│     Originator        │         │    Memento      │
├──────────────────────┤         ├─────────────────┤
│ -state               │◄────────│ -state          │
├──────────────────────┤ 创建     ├─────────────────┤
│+createMemento()     │         │+getState()      │
│+restore(m: Memento)  │         │+setState()      │
└──────────────────────┘         └─────────────────┘
        △                                  △
        │                                  │
        │                                  │
┌──────────────────────┐                 │
│     Caretaker        │                 │
├──────────────────────┤                 │
│ -mementos: Stack      │ ◄───────────────┘
├──────────────────────┤
│+backup()             │
│+undo()               │
└──────────────────────┘
```

**3 个角色**:
- **Originator**: 发起人, 创建和恢复备忘录
- **Memento**: 备忘录, 存储 Originator 内部状态
- **Caretaker**: 管理者, 维护备忘录历史 (栈)

## 3. Python 实现

```python
from dataclasses import dataclass, field
from typing import List

# 1. 备忘录 (存储状态)
@dataclass
class EditorMemento:
    text: str
    cursor: int
    font_size: int
    
    # 仅 Originator 能修改
    def __setattr__(self, key, value):
        if key not in ('text', 'cursor', 'font_size'):
            raise AttributeError("只读")
        super().__setattr__(key, value)

# 2. 发起人
class Editor:
    def __init__(self):
        self.text = ""
        self.cursor = 0
        self.font_size = 12
    
    def type(self, text):
        self.text += text
        self.cursor += len(text)
    
    def set_font_size(self, size):
        self.font_size = size
    
    # 创建备忘录 (复制状态)
    def save(self) -> EditorMemento:
        return EditorMemento(
            text=self.text,
            cursor=self.cursor,
            font_size=self.font_size
        )
    
    # 恢复备忘录
    def restore(self, m: EditorMemento):
        self.text = m.text
        self.cursor = m.cursor
        self.font_size = m.font_size
    
    def __str__(self):
        return f"Editor(text={self.text!r}, cursor={self.cursor}, size={self.font_size})"

# 3. 管理者 (历史栈)
class History:
    def __init__(self):
        self._stack: List[EditorMemento] = []
    
    def push(self, m: EditorMemento):
        self._stack.append(m)
    
    def pop(self) -> EditorMemento:
        if not self._stack:
            raise IndexError("没有历史可撤销")
        return self._stack.pop()

# 使用
editor = Editor()
history = History()

editor.type("Hello")
history.push(editor.save())
print(editor)  # Editor(text='Hello', cursor=5, size=12)

editor.type(" World")
history.push(editor.save())
print(editor)  # Editor(text='Hello World', cursor=11, size=12)

editor.set_font_size(16)
print(editor)  # Editor(text='Hello World', cursor=11, size=16)

# 撤销
editor.restore(history.pop())
print(editor)  # Editor(text='Hello World', cursor=11, size=12)

editor.restore(history.pop())
print(editor)  # Editor(text='Hello', cursor=5, size=12)
```

## 4. Java 实现

```java
// 备忘录
public class EditorMemento {
    private final String text;
    private final int cursor;
    private final int fontSize;
    
    public EditorMemento(String text, int cursor, int fontSize) {
        this.text = text;
        this.cursor = cursor;
        this.fontSize = fontSize;
    }
    
    public String getText() { return text; }
    public int getCursor() { return cursor; }
    public int getFontSize() { return fontSize; }
}

// 发起人
public class Editor {
    private String text = "";
    private int cursor = 0;
    private int fontSize = 12;
    
    public void type(String s) {
        text += s;
        cursor += s.length();
    }
    
    public EditorMemento save() {
        return new EditorMemento(text, cursor, fontSize);
    }
    
    public void restore(EditorMemento m) {
        text = m.getText();
        cursor = m.getCursor();
        fontSize = m.getFontSize();
    }
}

// 管理者
public class History {
    private final Stack<EditorMemento> stack = new Stack<>();
    
    public void save(Editor editor) {
        stack.push(editor.save());
    }
    
    public void undo(Editor editor) {
        if (!stack.isEmpty()) {
            editor.restore(stack.pop());
        }
    }
}
```

## 6. 优缺点

### 优点

✅ **保护封装**: 不暴露 Originator 内部细节

✅ **简化 Originator**: Originator 不用自己管理历史

✅ **支持多级撤销**: 栈结构天然支持

✅ **可序列化**: 备忘录可序列化用于持久化

### 缺点

❌ **资源消耗**: 大量状态保存耗内存/磁盘

❌ **性能**: 频繁保存快照影响性能

❌ **深拷贝开销**: 复杂对象快照成本高

## 7. 实战思考

### Q1: 备忘录 vs 命令?

| 备忘录 | 命令 |
| :--- | :--- |
| **状态**捕获 | **行为**封装 |
| 用于撤销 (回到之前) | 用于执行/重做 |
| 保存完整状态 | 不保存状态 |

**组合使用**: 命令模式 + 备忘录 → 撤销重做系统
- 每个命令执行后保存一个备忘录
- 撤销时弹出备忘录 + 调用命令的 undo

### Q2: 深拷贝 vs 浅拷贝?

备忘录创建时, 应**深拷贝**状态:

```python
# ❌ 浅拷贝: 后续修改会影响备忘录
memento.text = editor.text  # 共享引用!

# ✅ 深拷贝: 备忘录独立
memento.text = copy.deepcopy(editor.text)
```

### Q3: 什么时候用备忘录?

✅ **需要撤销/重做**: 编辑器、绘图工具

✅ **快照/事务**: 数据库, 游戏

✅ **状态恢复**: 配置回滚

❌ **不需要历史**: 普通业务对象

❌ **状态极大**: 备忘录成本太高, 考虑增量保存
