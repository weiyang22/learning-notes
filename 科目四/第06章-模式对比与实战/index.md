## 🎯 GoF 23 种模式完整索引

### 5 种创建型模式

| 模式 | 一句话 | 适用场景 |
| :--- | :--- | :--- |
| [单例](../第02章-创建型模式/01-单例模式.md) | 一个类只有一个实例 | 全局唯一 (配置/池) |
| [工厂方法](../第02章-创建型模式/02-工厂方法模式.md) | 子类决定创建哪个对象 | 框架扩展点 |
| [抽象工厂](../第02章-创建型模式/03-抽象工厂模式.md) | 创建一族相关对象 | 跨平台 UI/数据库 |
| [建造者](../第02章-创建型模式/04-建造者模式.md) | 分步构建复杂对象 | 多参数对象 |
| [原型](../第02章-创建型模式/05-原型模式.md) | 克隆而非新建 | 对象创建成本高 |

## 🔗 与其他章节的关联

### 第01章: 基础
设计模式的基础是面向对象, 不懂 OOP 无法理解模式为什么这样设计.

### 第02-04章: 模式详解
每种模式的动机 / 结构 / 实现 / 应用 / 优缺点.

### 第05章: SOLID 原则
SOLID 是设计模式背后的**原则**. 模式是原则的具体实现.

| SOLID 原则 | 对应模式 |
| :--- | :--- |
| **S** Single Responsibility | 单职责 |
| **O** Open/Closed | 工厂方法, 抽象工厂, 装饰器, 策略 |
| **L** Liskov Substitution | 模板方法, 工厂方法 |
| **I** Interface Segregation | 适配器, 外观, 代理 |
| **D** Dependency Inversion | 工厂方法, 抽象工厂, 策略, 代理 |

## 💡 实战选择指南

### 按问题类型选择

| 问题 | 推荐模式 |
| :--- | :--- |
| 全局唯一对象 | 单例 |
| 创建对象但不知具体类 | 工厂方法 |
| 创建一族相关对象 | 抽象工厂 |
| 多参数对象构建 | 建造者 |
| 对象创建成本高 | 原型 |
| 旧接口与新系统不兼容 | 适配器 |
| 抽象和实现独立变化 | 桥接 |
| 树形结构 | 组合 |
| 动态添加职责 | 装饰器 |
| 简化复杂子系统 | 外观 |
| 大量相似对象 | 享元 |
| 控制对象访问 | 代理 |
| 状态变化通知 | 观察者 |
| 算法可替换 | 策略 |
| 请求作为对象 | 命令 |
| 多步处理 | 责任链 |
| 集合遍历 | 迭代器 |
| 对象间网状通信 | 中介者 |
| 撤销/重做 | 备忘录 |
| 行为随状态变 | 状态 |
| 算法框架 | 模板方法 |
| 操作与数据结构分离 | 访问者 |
| 自定义语法 | 解释器 |

### 按 SOLID 反推

| 违反的原则 | 用什么模式 |
| :--- | :--- |
| SRP 违反 | 拆分类 |
| OCP 违反 | 工厂 + 策略 |
| LSP 违反 | 重构继承 |
| ISP 违反 | 接口隔离 + 适配器 |
| DIP 违反 | 抽象工厂 + 依赖注入 |
