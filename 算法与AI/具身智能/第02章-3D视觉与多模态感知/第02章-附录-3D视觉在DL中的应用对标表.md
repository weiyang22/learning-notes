# 附录:3D 视觉在 DL 中的应用对标表

> **编者按**:3D 视觉是具身智能的"眼睛"。2D 检测回答"图中有几个立方体",3D 视觉回答"立方体在哪、姿态如何、能不能抓"。
>
> 这一章涉及的数据集/模型/仿真器/团队数量爆炸式增长:室内 ScanNet / Matterport3D,室外 KITTI / nuScenes / Waymo,物体 ShapeNet / ModelNet / YCB,神经渲染 NeRF / 3DGS,SLAM ORB-SLAM / VINS,检测 VoteNet / PointRCNN,仿真 Habitat / Isaac Sim。
>
> **本附录做四件事**:
> 1. 一张 **≥40 条** "数据集 / 模型 / 论文"对标总表(第 1-3 节)
> 2. 仿真器与平台速查(第 4 节)
> 3. 中文具身视觉团队与开源资源(第 5 节)
> 4. 关键论文时间线(2016-2026)
>
> **使用方式**:
> - 工程选型:按任务类型(室内 vs 室外 vs 物体)反查数据集
> - 训练加速:按模型类别(检测/分割/NeRF)找对应实现
> - 面试准备:末尾"快速回忆卡片"覆盖核心创新点
> - 重要度 1-5 颗星,5 颗星 = 工业界 / 面试必背
>
> **覆盖范围**:相机模型 / 点云 / 体素 / NeRF / 3DGS / SLAM / 3D 检测 / 3D 分割 / 多模态融合 9 大主题。配套:数学基础各附录、第 7 章仿真器附录、第 8 章 VLA 附录。

## 7. 快速回忆卡片 (20 张)

**卡片 1:PointNet 为什么有效?**

> **核心**: max-pool 是**对称函数**,对输入顺序不敏感。点云是**无序集合**,传统 CNN 不适用。PointNet 用 **MLP 提取每点特征 + max-pool 取全局特征**,数学上等价于拟合 Hausdorff 距离。**缺点**: 没考虑局部结构 → PointNet++ 解决 (采样 + 分组)。

**卡片 2:VoteNet 的关键创新?**

> **Hough Voting**: 物体中心点在 3D 空间中投票,每个 seed point 生成 vote,聚类生成 proposal。**创新点**: 把 2D 检测中的 Hough Voting 扩展到 3D,解决点云中"物体中心没有点"的问题 (只有表面点)。**Score**: ScanNet mAP 62.9,显著超越之前。

**卡片 3:NeRF 的核心数学是什么?**

> **NeRF** = MLP 拟合 5D 函数 $(\mathbf{x}, \mathbf{d}) \to (\mathbf{c}, \sigma)$。**体渲染**: $\mathbf{C} = \int T(t) \sigma(\mathbf{r}(t)) \mathbf{c}(\mathbf{r}(t), \mathbf{d}) dt$,其中 $T(t) = \exp(-\int_0^t \sigma ds)$。**训练**: 沿像素射线采样点,查询 MLP,加法累积颜色。**位置编码** $\gamma(\mathbf{x})$ 让 MLP 拟合高频细节。

**卡片 4:Instant-NGP 为什么快?**

> **核心**: 多分辨率**哈希编码** + 小型 MLP。传统 NeRF 用频率位置编码 + 大 MLP (256 维 × 8 层),慢。**Hash 编码**: 把空间分为多分辨率网格,每网格顶点用哈希表存可学习特征,查表得到特征向量 → 小 MLP 即可。**训练时间**: NeRF 1-2 天 → Instant-NGP 5-10 分钟 (100x 加速)。

**卡片 5:3DGS 为什么实时?**

> **核心**: 用**显式 3D 高斯椭球**表示场景,每个高斯有位置、协方差、颜色、不透明度。**渲染**: 把高斯投影到 2D,按深度排序,用 alpha-blending 合成像素。**优化**: 用 SfM 点云初始化,优化高斯参数。**速度**: 训练 1 小时,渲染 30+ FPS (1080p)。**代表论文**: SIGGRAPH 2023 best paper。

**卡片 6:ORB-SLAM2 vs ORB-SLAM3?**

> **ORB-SLAM2** (2017): 支持 Mono/RGB-D/Stereo,基于 ORB 特征 + BA + 闭环。**ORB-SLAM3** (2020): 增加 **IMU 紧耦合**、**多 Atlas**、**鱼眼相机**、改进回环。**核心模块**: Tracking (前端) + Local Mapping (局部 BA) + Loop Closing (回环 + 全局 BA)。**工业地位**: 学术界标配,工程稳定。

**卡片 7:VINS-Mono 为什么是 VIO 经典?**

> **核心**: 紧耦合 **视觉 + IMU** 的 VIO (Visual-Inertial Odometry)。**前端**: Harris 角点 + LK 光流;**后端**: 滑窗 BA (优化相机位姿 + IMU bias + 3D 点);**初始化**: 视觉 SFM + IMU 静置标定;**回环**: DBoW2 + 4DoF 图优化。**GitHub 14k stars**, 工程代码稳定。

**卡片 8:BEVFusion 为什么是工业标配?**

> **核心**: 把**多传感器 (Camera + LiDAR + Radar)** 特征统一到 **BEV (Bird's Eye View)** 空间,在 BEV 空间融合 + 检测。**优势**: ① 几何对齐简单 (BEV → 物理世界);② 传感器解耦 (任一可单独工作);③ 端到端训练。**nuScenes 70.2 NDS**,自动驾驶标配。

**卡片 9:PointNet++ 与 PointNet 的关键区别?**

> **PointNet**: 全局 max-pool,**没考虑局部结构**。**PointNet++**: 引入**层次化** (Set Abstraction):① FPS (最远点采样);② Ball Query (K 近邻分组);③ PointNet 提取局部特征。**反向 Set Abstraction**: 插值回原始点云,得到逐点特征。**效果**: 局部 + 全局信息结合,S3DIS 分割 mIoU 提升 10+。

**卡片 10:DUSt3R 为什么是 3D 视觉新范式?**

> **核心**: 抛弃传统 SfM (特征点 + 三角化 + BA),用 **Transformer 端到端**预测两张图之间的**密集 3D 点云对齐** (pointmap regression)。**无需**相机内参外参 (从图像中学习)。**优点**: 全局最优、对遮挡鲁棒、端到端。**MASt3R-SLAM**: 把 DUSt3R 扩展到 SLAM,实时建图 + 跟踪。

**卡片 11:为什么需要 3D 视觉 (而不是 2D)?**

> 2D 检测只能给出**像素框**,无法给出**深度、尺寸、姿态**。机器人需要:① **3D 位置** (抓取点在哪);② **6D 位姿** (如何抓);③ **避障** (路径规划);④ **重建** (建图)。**2D 只能识别,3D 才能行动**。

**卡片 12:NeRF vs 3DGS,工业选哪个?**

> **NeRF**: 隐式 MLP,内存省 (1 个网络 / 场景),但训练慢 (小时级),渲染慢 (秒级)。**3DGS**: 显式高斯,内存大 (数 GB / 场景),但训练快 (分钟级),渲染**实时** (30+ FPS)。**选型**: 实时应用 (AR/VR/具身) → 3DGS;研究 / 资源受限 → NeRF。

**卡片 13:自动驾驶 3D 检测的 fusion 怎么选?**

> **早期 fusion** (PointPainting): 投影 2D 分割到 LiDAR,简单但易丢失信息。**中期 fusion** (TransFusion): 用 Transformer cross-attention,在 BEV 融合,精度最高。**晚期 fusion** (CenterPoint 变体): 独立检测 + 后融合,鲁棒但精度低。**工业默认**: TransFusion 或 BEVFusion。

**卡片 14:具身智能为什么用仿真器?**

> ① **数据稀缺**: 真实机器人数据昂贵 (1 条轨迹 $10-$100)。② **安全**: 仿真训练避免硬件损坏。③ **可扩展**: 仿真器并行 1000+ 环境,真实世界无法做到。④ **可重现**: 完全可控的环境。**代表**: Habitat (室内), Isaac Sim (工业), Genesis (2024 通用)。

**卡片 15:Point Transformer 为什么 SOTA?**

> **核心**: 把 Transformer 的 self-attention 扩展到点云,用**向量注意力** (vector attention) 而非标量。**创新**: ① 位置编码 (相对位置 + 绝对位置);② 减法关系 (subtraction) 编码局部几何;③ 残差 + 归一化。**Point Transformer V3 (2024)**: 稀疏窗口注意力,S3DIS mIoU 74+。

**卡片 16:为什么 PV-RCNN 在 KITTI 长期霸榜?**

> **核心**: ① 体素化生成 3D proposal;② 用 **Voxel Set Abstraction** 把多尺度体素特征聚合到 key points;③ 精化阶段融合点 + 体素特征。**两阶段架构**: 体素 (高效 proposal) + 点 (精化定位)。**缺点**: 速度较慢 (5 FPS),不适合自动驾驶实时。

**卡片 17:CenterPoint 为何成为 LiDAR 检测标配?**

> **核心**: 把 3D 检测变成**关键点检测** + **属性回归**。① 预测 heatmap (物体中心);② 中心点特征回归 (尺寸、朝向、速度);③ 二阶段精化。**优势**: 简洁、anchor-free、速度快。**nuScenes 65.5 NDS**,自动驾驶开源标配。

**卡片 18:点云 / 体素 / NeRF / Mesh 各有什么优劣?**

> **点云**: 简单、稀疏,适合 LiDAR,缺点: 无连接信息。**体素**: 规则、可用 3D CNN,缺点: 内存大 (3D 体素立方增长)。**NeRF**: 连续、可微分、紧凑,缺点: 训练慢。**Mesh**: 显式表面,适合渲染,缺点: 重建难。**选型**: LiDAR → 点云; RGB-D → 体素; 静态场景 → NeRF / 3DGS; 实时渲染 → Mesh / 3DGS。

**卡片 19:3D 视觉的工业落地难点是什么?**

> ① **数据**: 真实 3D 标注成本高 (一张点云标注 $10+);② **泛化**: 仿真到真实 (Sim2Real) gap 大;③ **实时性**: 3D 模型通常 5-10 FPS,工业要求 30+ FPS;④ **传感器**: LiDAR 贵 ($1000+),相机深度有限;⑤ **场景**: 长尾场景 (罕见物体) 难处理。

**卡片 20:Open X-Embodiment 为什么重要?**

> **核心**: Google DeepMind + 60+ 实验室合作,统一 **60+ 机器人数据集** (130 万条轨迹)。**意义**: ① 跨机器人**通用策略** (RT-X);② 预训练基础模型;③ 标准化评测。**类比**: 类似 NLP 的 Pile / C4。**未来**: 具身 GPT-3 时刻。

## 11. 3D 视觉数学基础速查 (相机模型 + 变换 + 体渲染)

> 本节是面试 + 工程实现最常翻的速查,涵盖 §1 相机模型、§2 点云、§4 SLAM、§5 3D 检测共同的数学基底。

### 11.1 针孔相机模型

世界坐标 $\mathbf{X}_w \in \mathbb{R}^3$ 投影到像素 $\mathbf{u} \in \mathbb{R}^2$:

$$\mathbf{u} = \pi(\mathbf{K} [\mathbf{R} | \mathbf{t}] \mathbf{X}_w)$$

内参 $\mathbf{K} = \begin{bmatrix} f_x & s & c_x \\ 0 & f_y & c_y \\ 0 & 0 & 1 \end{bmatrix}$, $\pi$ 是透视除法 $(x,y,z) \mapsto (x/z, y/z)$。

**畸变** (Brown-Conrady): 径向 $x' = x(1 + k_1 r^2 + k_2 r^4 + k_3 r^6)$, 切向 $x'' = x' + 2 p_1 x' y' + p_2(r^2 + 2x'^2)$。**标定工具**: OpenCV `calibrateCamera`, Kalibr (IMU+相机), COLMAP 自带。

### 11.2 刚体变换与李群

**$SO(3)$**: 旋转矩阵群,$\mathbf{R}^T \mathbf{R} = \mathbf{I}, \det \mathbf{R} = 1$。
**$SE(3)$**: 刚体变换,$\mathbf{T} = \begin{bmatrix} \mathbf{R} & \mathbf{t} \\ \mathbf{0} & 1 \end{bmatrix}$。
**李代数** $\mathfrak{se}(3)$: 6 维向量 $\boldsymbol{\xi} = (\boldsymbol{\phi}, \boldsymbol{\rho})$ 描述切空间微元。**指数映射** $\mathbf{R} = \exp(\boldsymbol{\phi}^\wedge)$, 其中 $\boldsymbol{\phi}^\wedge$ 反对称矩阵。

**SLAM BA 优化**: 在 $SE(3)$ 流形上做扰动, $\mathbf{T}_{new} = \exp(\delta \boldsymbol{\xi}) \mathbf{T}_{old}$, 避免过参数化。**库**: g2o (C++)、GTSAM (因子图, 最强表达力)、Ceres (Google, 工业最稳)。

### 11.3 三角化与 BA

**三角化** (Triangulation): 已知两视图 $\mathbf{T}_1, \mathbf{T}_2$ 和像素 $\mathbf{u}_1, \mathbf{u}_2$, 求 3D 点。
- **DLT 线性法**: $\mathbf{u}_1 \times (\mathbf{P}_1 \mathbf{X}) = 0$, SVD 求 $\mathbf{A} \mathbf{X} = 0$。
- **深度法** (现代 SLAM): 从 $\mathbf{C}_1$ 沿射线 $\mathbf{r} = \mathbf{K}^{-1} \mathbf{u}_1$ 找深度 $d$, $\mathbf{X} = d \cdot \mathbf{r} + \mathbf{C}_1$。

**Bundle Adjustment (BA)**: 调整相机位姿和 3D 点最小化重投影误差:

$$\min_{\{\mathbf{T}_i\}, \{\mathbf{X}_j\}} \sum_{i,j} \rho\left( \|\pi(\mathbf{K} \mathbf{T}_i \mathbf{X}_j) - \mathbf{u}_{ij}\|^2 \right)$$

$\rho$ 是 Huber 损失抗 outlier。**Schur 补** 利用"相机-点"二分稀疏性, 大幅加速。

### 11.4 体渲染 (NeRF 核心)

沿射线 $\mathbf{r}(t) = \mathbf{o} + t \mathbf{d}$ 累积颜色:

$$\mathbf{C}(\mathbf{r}) = \int_{t_n}^{t_f} T(t) \sigma(\mathbf{r}(t)) \mathbf{c}(\mathbf{r}(t), \mathbf{d}) dt, \quad T(t) = \exp\left(-\int_{t_n}^{t} \sigma ds\right)$$

$T(t)$ 物理意义: 射线在 $t$ 处不被吸收的概率 (Beer-Lambert 定律)。**离散化**: $\hat{\mathbf{C}} = \sum_i T_i \alpha_i \mathbf{c}_i$, $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$。**分层采样**: 粗采样画 PDF, 密度高区域精采样。

### 11.5 3DGS 数学

每高斯由 $(\boldsymbol{\mu}, \boldsymbol{\Sigma}, \alpha, \text{SH})$ 描述。**协方差分解** (保证正定): $\boldsymbol{\Sigma} = \mathbf{R} \mathbf{S} \mathbf{S}^T \mathbf{R}^T$。**2D 投影**: 雅可比 $\boldsymbol{\Sigma}' = \mathbf{J} \mathbf{W} \boldsymbol{\Sigma} \mathbf{W}^T \mathbf{J}^T$。**像素合成** (alpha-blending): $\mathbf{C} = \sum_{i} \mathbf{c}_i \alpha_i \prod_{j<i}(1 - \alpha_j)$。

### 11.6 评估指标速查

| 任务 | 指标 | 公式 | 备注 |
| :--- | :--- | :--- | :--- |
| 3D 检测 (mAP) | $\text{mAP} = \frac{1}{N}\sum \text{AP}_c$ | KITTI 11-point | nuScenes 用 NDS |
| 3D 检测 (NDS) | $\text{NDS} = \frac{1}{10}[5\cdot\text{mAP} + \sum(1-\min(1,m))]$ | 综合 5 个 metric | nuScenes |
| 语义分割 (mIoU) | $\frac{1}{C}\sum_c\frac{TP}{TP+FP+FN}$ | 类别平均 | - |
| NeRF (PSNR) | $10\log_{10}(1/\text{MSE})$ | 越高越好 | SOTA > 30 dB |
| NeRF (SSIM) | $\frac{(2\mu_x\mu_y+c_1)(2\sigma_{xy}+c_2)}{(\mu_x^2+\mu_y^2+c_1)(\sigma_x^2+\sigma_y^2+c_2)}$ | 0-1, 越高越好 | - |
| NeRF (LPIPS) | VGG 特征距离 | 越低越好 | - |

### 12.2 PointNet 点云分类 (ModelNet40)

```python
import torch
import torch.nn as nn

class PointNet(nn.Module):
    """核心: max-pool 是对称函数, 解决点云无序性。"""
    def __init__(self, n_classes=40):
        super().__init__()
        self.mlp = nn.Sequential(
            nn.Conv1d(3, 64, 1), nn.BatchNorm1d(64), nn.ReLU(),
            nn.Conv1d(64, 64, 1), nn.BatchNorm1d(64), nn.ReLU(),
            nn.Conv1d(64, 64, 1), nn.BatchNorm1d(64), nn.ReLU(),
            nn.Conv1d(64, 128, 1), nn.BatchNorm1d(128), nn.ReLU(),
            nn.Conv1d(128, 1024, 1), nn.BatchNorm1d(1024), nn.ReLU(),
        )
        self.head = nn.Sequential(
            nn.Linear(1024, 512), nn.BatchNorm1d(512), nn.ReLU(), nn.Dropout(0.3),
            nn.Linear(512, 256), nn.BatchNorm1d(256), nn.ReLU(), nn.Dropout(0.3),
            nn.Linear(256, n_classes),
        )
    def forward(self, x):
        # x: (B, 3, N) 点云
        feat = self.mlp(x)  # (B, 1024, N)
        global_feat, _ = feat.max(dim=2)  # (B, 1024) max-pool 对称
        return self.head(global_feat)


model = PointNet().cuda()
```

### 12.3 NeRF 体渲染 (核心)

```python
import torch
import torch.nn as nn

def positional_encoding(x, L=10):
    """位置编码: 让 MLP 拟合高频细节。NeRF 关键技巧。"""
    freqs = 2.0 ** torch.arange(L, device=x.device) * torch.pi
    scaled = x.unsqueeze(-1) * freqs  # (..., D, L)
    return torch.cat([x, torch.sin(scaled).flatten(-2), torch.cos(scaled).flatten(-2)], dim=-1)


def volume_render(rays_o, rays_d, mlp, n_samples=64, near=2.0, far=6.0):
    """体渲染: 沿射线采样 + alpha-compositing。"""
    t = torch.linspace(near, far, n_samples, device=rays_o.device)
    pts = rays_o.unsqueeze(1) + rays_d.unsqueeze(1) * t.unsqueeze(0).unsqueeze(-1)  # (B, n, 3)
    dirs = rays_d.unsqueeze(1).expand_as(pts)
    pts_flat = pts.reshape(-1, 3)
    dirs_flat = dirs.reshape(-1, 3)
    pts_enc = positional_encoding(pts_flat, L=10)  # (B*n, 63)
    dirs_enc = positional_encoding(dirs_flat, L=4)  # (B*n, 27)
    out = mlp(torch.cat([pts_enc, dirs_enc], dim=-1))
    rgb = torch.sigmoid(out[:, :3]).reshape(-1, n_samples, 3)
    sigma = torch.relu(out[:, 3]).reshape(-1, n_samples)
    deltas = (far - near) / (n_samples - 1)
    alpha = 1.0 - torch.exp(-sigma * deltas)
    trans = torch.cumprod(1.0 - alpha + 1e-10, dim=1)
    trans = torch.cat([torch.ones_like(trans[:, :1]), trans[:, :-1]], dim=1)
    weights = alpha * trans
    return (weights.unsqueeze(-1) * rgb).sum(dim=1)  # (B, 3)


class NeRFMLP(nn.Module):
    """8 层 + skip, 256 维。"""
    def __init__(self, in_dim=63, dir_dim=27, hidden=256):
        super().__init__()
        self.layers = nn.ModuleList([nn.Linear(in_dim, hidden), nn.ReLU()])
        for _ in range(7):
            self.layers.append(nn.Linear(hidden, hidden))
            self.layers.append(nn.ReLU())
        self.skip = nn.Linear(in_dim + hidden, hidden)
        self.sigma_head = nn.Linear(hidden, 1)
        self.dir_layer = nn.Linear(hidden + dir_dim, hidden // 2)
        self.rgb_head = nn.Linear(hidden // 2, 3)
    def forward(self, x):
        pts_enc, dirs_enc = x[:, :63], x[:, 63:]
        h = pts_enc
        for i, layer in enumerate(self.layers):
            h = layer(h)
            if i == 9:  # skip at 5th layer
                h = self.skip(torch.cat([h, pts_enc], dim=-1))
        sigma = self.sigma_head(h)
        h_rgb = self.dir_layer(torch.cat([h, dirs_enc], dim=-1))
        return torch.cat([self.rgb_head(h_rgb), sigma], dim=-1)


mlp = NeRFMLP().cuda()
rays_o = torch.randn(64, 3).cuda()
rays_d = torch.nn.functional.normalize(torch.randn(64, 3), dim=-1).cuda()
images = volume_render(rays_o, rays_d, mlp)
print(f"NeRF: rendered {images.shape}, MLP {sum(p.numel() for p in mlp.parameters())/1e6:.2f}M params")
```

```python
import torch
import torch.nn as nn

class VoteNetHead(nn.Module):
    """投票头: 预测每个 seed point 到物体中心的偏移。"""
    def __init__(self, in_dim=256, n_classes=18):
        super().__init__()
        self.vote_mlp = nn.Sequential(
            nn.Conv1d(in_dim, 256, 1), nn.BatchNorm1d(256), nn.ReLU(),
            nn.Conv1d(256, 256, 1), nn.BatchNorm1d(256), nn.ReLU(),
            nn.Conv1d(256, 3 + 1 + n_classes, 1),  # offset + score + cls
        )

        # seed_xyz: (B, 3, N_seed), seed_feat: (B, C, N_seed)
        B, _, N = seed_xyz.shape
        out = self.vote_mlp(seed_feat)
        offset, score, cls = out[:, :3], out[:, 3:4], out[:, 4:]
        return seed_xyz + offset, score, cls  # 投票位置 = seed + offset
```

### 12.5 3DGS 投影

```python
import torch

def project_gaussians(means3D, scales, quats, K, viewmat):
    """3DGS 投影: 3D 高斯 -> 2D 椭圆。"""
    N = means3D.shape[0]
    # 1) 四元数 -> 旋转
    q = quats / quats.norm(dim=-1, keepdim=True)
    R = torch.zeros(N, 3, 3, device=means3D.device)
    R[:, 0, 0] = 1 - 2*(q[:, 2]**2 + q[:, 3]**2)
    R[:, 0, 1] = 2*(q[:, 1]*q[:, 2] - q[:, 0]*q[:, 3])
    R[:, 0, 2] = 2*(q[:, 1]*q[:, 3] + q[:, 0]*q[:, 2])
    R[:, 1, 0] = 2*(q[:, 1]*q[:, 2] + q[:, 0]*q[:, 3])
    R[:, 1, 1] = 1 - 2*(q[:, 1]**2 + q[:, 3]**2)
    R[:, 1, 2] = 2*(q[:, 2]*q[:, 3] - q[:, 0]*q[:, 1])
    R[:, 2, 0] = 2*(q[:, 1]*q[:, 3] - q[:, 0]*q[:, 2])
    R[:, 2, 1] = 2*(q[:, 2]*q[:, 3] + q[:, 0]*q[:, 1])
    R[:, 2, 2] = 1 - 2*(q[:, 1]**2 + q[:, 2]**2)
    # 2) 3D 协方差
    S = torch.diag_embed(scales)
    cov3D = R @ S @ S.transpose(-1, -2) @ R.transpose(-1, -2)
    # 3) 视图变换
    means3D_h = torch.cat([means3D, torch.ones(N, 1, device=means3D.device)], dim=1)
    means_cam = (viewmat @ means3D_h.T).T[:, :3]
    depths = means_cam[:, 2].clamp(min=1e-3)
    # 4) 2D 雅可比
    fx, fy = K[0, 0], K[1, 1]
    J = torch.zeros(N, 2, 3, device=means3D.device)
    J[:, 0, 0] = fx / depths
    J[:, 0, 2] = -fx * means_cam[:, 0] / depths**2
    J[:, 1, 1] = fy / depths
    J[:, 1, 2] = -fy * means_cam[:, 1] / depths**2
    W = viewmat[:3, :3]
    cov2D = J @ W @ cov3D @ W.T @ J.transpose(-1, -2)
    # 5) 像素中心
    means2D = (K[:2, :3] @ means_cam.T).T
    means2D[:, 0] /= depths
    means2D[:, 1] /= depths
    return means2D, cov2D, depths


N = 1000
means3D = torch.randn(N, 3).cuda() * 5
scales = torch.rand(N, 3).cuda() * 0.1
quats = torch.zeros(N, 4).cuda(); quats[:, 0] = 1.0
K = torch.tensor([[500, 0, 320], [0, 500, 240], [0, 0, 1]], dtype=torch.float).cuda()
viewmat = torch.eye(4).cuda()
m2D, c2D, dep = project_gaussians(means3D, scales, quats, K, viewmat)
print(f"3DGS: {N} gaussians -> 2D {m2D.shape}, cov {c2D.shape}, depth {dep.shape}")
```

> L7/L8 必备。每题 30-60 字, 精炼作答。"★" 提示是给评审者留印象点。

### 14.1 基础与数学

**Q1: 解释 $SE(3)$ 与 $\mathfrak{se}(3)$ 的关系。为什么 SLAM 用李代数优化?**

> $SE(3)$ 是刚体变换群, 求导困难。$\mathfrak{se}(3)$ 是 $SE(3)$ 在单位元的切空间, 6 维向量 $\boldsymbol{\xi} = (\boldsymbol{\phi}, \boldsymbol{\rho})$。SLAM BA 优化时, 扰动 $\delta \boldsymbol{\xi}$ 加在切空间: $\mathbf{T}_{new} = \exp(\delta \boldsymbol{\xi}) \mathbf{T}_{old}$。**好处**: 优化无约束 (6 维实数), 避免过参数化 (4 元素四元数单位约束), 数值稳定。
> ★ 流形上的 Gauss-Newton (Sophus / GTSAM 实现)。

**Q2: PointNet 用了 max-pool 而不是 sum/mean, 为什么?**

> max-pool 是**对称函数** (输入顺序无关), 满足点云无序性。sum/mean 线性, max-pool 是非线性的"特征选择器", 哪个通道响应最大就激活该全局特征。数学上等价于拟合 Hausdorff 距离下界。
> ★ max-pool 的"最关键"特征选择, 是 PointNet 表达力的核心。

**Q3: NeRF 训练慢, Instant-NGP 怎么加速 100 倍?**

> **核心**: 多分辨率**哈希位置编码**。传统 NeRF 用频率位置编码 (Fourier), 高频细节需要深网络。**Hash 编码**: 空间分成多分辨率网格 (16-256 级), 每级顶点特征存到哈希表 (固定大小, 允许碰撞), 三线性插值得到特征, 输入小 MLP (3-5 层) 即可。**结果**: 训练 1-2 天 → 5-10 分钟。
> ★ Hash 表 + 小 MLP, NVIDIA 关键工程优化。

### 14.2 检测与分割

**Q4: VoteNet 为什么用 Hough Voting?**

> 点云中**物体中心没有点** (只有表面点), 没法直接 anchor-free (类似 CenterNet)。**Hough Voting** 让每个 seed point 投一票到"猜测"的物体中心, 聚类 (FPS + 聚合) 生成 proposal。**创新**: 把广义 Hough 变换扩展到 3D, 解决"中心空洞"问题。ScanNet mAP 62.9。
> ★ VoteNet 是 3D 检测从 anchor-based → anchor-free 的桥梁。

**Q5: 解释 BEV (Bird's Eye View) 在自动驾驶的核心价值。**

> ① **几何对齐**: BEV 是物理世界俯视图, 相机/LiDAR 投影统一; ② **传感器解耦**: 任一缺失仍可工作; ③ **时序融合**: 同一物体跨帧对齐易, 便于 track; ④ **下游规划**: 规划模块天然吃 BEV 占据。**Tesla BEV + Transformer** 2022 量产, 国内 2023 跟进。
> ★ BEV 是自动驾驶 3D 感知的"通用语"。

**Q6: PV-RCNN 为什么在 KITTI 长期霸榜? 现在还 SOTA 吗?**

> **核心**: 体素 (高效 proposal) + 点 (精化定位) 双分支。① 体素化生成 3D RoI; ② Voxel Set Abstraction 把多尺度体素特征聚到 key points; ③ RefineNet 融合点+体素精化。**KITTI mAP 83.9** (3D, car)。**现在 (2024)**: Waymo 已被 CenterPoint/TransFusion 超越, KITTI 仍 PV-RCNN 强项 (小目标+单帧)。**速度 5 FPS, 不适合实时**。
> ★ PV-RCNN = 两阶段, CenterPoint = 单阶段, 工业选 CenterPoint。

**Q7: Point Transformer V3 vs V2, 关键改进是什么?**

> V2 (2022): 分组向量注意力, dense attention, 内存大。**V3 (2024)** 关键改进: ① **稀疏窗口注意力** (类似 Swin, 限制到局部窗口, 复杂度 O(N)); ② **序列化 + Padding** 让 GPU 利用率高; ③ **零中心化 + 缩放** 训练稳定。**效果**: ScanNet mIoU 75.4, **训练快 3x, 内存少 10x**。
> ★ V3 把"点云 Transformer"工程化, SOTA 2024-2025。

### 14.3 NeRF / 3DGS

**Q8: 3DGS vs NeRF, 工业选哪个?**

> **3DGS**: 显式 3D 高斯, 训练 1 小时, 渲染**实时** (1080p 30+ FPS), 内存大 (数 GB)。**NeRF**: 隐式 MLP, 训练 1-2 天, 渲染慢 (秒级), 内存小 (1 网络)。**选型**: 实时 AR/VR/具身 → 3DGS; 离线渲染/资源受限 → NeRF; 大场景 → Scaffold-GS; 动态 → 4DGS。**2024**: 工业 AR/VR 几乎全选 3DGS, 学术 NeRF 主流。
> ★ 显式 vs 隐式, 实时 vs 紧凑, 是核心 trade-off。

**Q9: NeRF 的体渲染公式 $\mathbf{C} = \int T(t) \sigma(t) \mathbf{c}(t) dt$, 物理意义?**

> $\sigma(t)$ 是射线在 $t$ 处的**体素密度** (单位长度吸收率), $\mathbf{c}(t)$ 是**该点发光颜色**。$T(t) = \exp(-\int_0^t \sigma ds)$ 是**累积透射率** (从相机到 $t$ 不被吸收的概率)。整个积分是**沿射线的体素颜色加权累积**, 类似 Beer-Lambert 定律。**离散化**: 拆成 $N$ 段, 段内近似常数, alpha-blending。
> ★ 物理上, NeRF = "3D 空间中的发光云" + 射线追踪。

**Q10: 3DGS 协方差为什么分解成 $\mathbf{R} \mathbf{S} \mathbf{S}^T \mathbf{R}^T$? 直接学习不香吗?**

> 直接学习 9 元素 3x3 矩阵必须保证**正定** (否则不能作协方差), 优化时易违反约束。**分解** $\mathbf{R}$ (旋转) + $\mathbf{S}$ (缩放), 都无约束 (旋转用 4 元素四元数, 缩放 3 个正数), 优化稳定。**几何含义**: 先旋转对齐, 再各向异性缩放。
> ★ 重参数化让"约束优化" → "无约束优化", 工程关键。

### 14.4 SLAM

**Q11: ORB-SLAM3 vs VINS-Mono, 工程怎么选?**

> **ORB-SLAM3** (2020, Zaragoza): 特征点法, Mono/Stereo/RGB-D + IMU, Atlas 多地图。**优点**: 精度高、回环强、室内好。**缺点**: ORB 描述子慢, 纹理弱场景失效。**VINS-Mono** (2017, HKUST): 紧耦合 VIO, Harris + LK 光流 + 滑窗 BA。**优点**: 轻量、IMU 紧耦合、高速运动鲁棒。**缺点**: 室外大场景回环弱。**选型**: 室内/静态 → ORB-SLAM3; 无人机/高速 → VINS-Mono; 室外/自动驾驶 → 配 LiDAR (LIO-SAM)。
> ★ 特征点 vs 直接法, 室内 vs 室外, 是核心 trade-off。

**Q12: DUSt3R 为什么被称为 "3D 视觉新范式"?**

> 传统 pipeline: 特征点 → 匹配 → SfM 三角化 → BA, 模块化, 易累积误差。**DUSt3R** (2024, Naver): **Transformer 端到端**预测两图密集 3D 点云对齐 (pointmap), **不需要**相机内参外参 (从图像学习), **不需要**特征点。**结果**: 全局最优、对遮挡鲁棒、端到端训练。**MASt3R-SLAM** (2024): 进一步扩展到实时 SLAM。
> ★ 抛弃 SfM 全套, 端到端回归, 是范式跃迁 (类似 2D 检测 R-CNN → DETR)。

### 14.5 具身 + VLA

**Q13: Open X-Embodiment 为什么重要? 它的类比是什么?**

> **核心**: Google DeepMind 牵头, 60+ 实验室合作, 整合 **60+ 机器人数据集** (130 万轨迹, 22 种机器人)。**意义**: ① 跨机器人**通用策略** (RT-X); ② 预训练基础模型; ③ 标准化评测。**类比**: NLP 的 Pile / C4 (大语料预训练), 或 ImageNet (图像基础)。**未来**: 具身 GPT-3 时刻, π0 (2024) 已在路上。
> ★ OpenX = 具身 ImageNet, 让通用机器人成为可能。

**Q14: VLA (Vision-Language-Action) 模型的核心结构是什么?**

> VLA = VLM (Vision-Language Model) + Action Head。**典型结构** (RT-2, π0): ① 视觉编码器 (SigLIP / DINOv2); ② LLM backbone (PaLI-X / Llama); ③ Action decoder (流式/chunk 输出)。**输入**: 图像 + 语言指令 + 历史状态; **输出**: 7-DoF 动作 (xyz + rpy + gripper)。**训练**: VLM 初始化 + OpenX 微调。**挑战**: 推理延迟 (VLM 大), 工程上用 action chunking (一次输出 7-50 步)。
> ★ VLA = "大模型 + 机器人" 的桥梁, 2024 年 SOTA。

**Q15: 3D-VLA 与 VLA 的关键差异? 为什么需要 3D?**

> 传统 VLA 吃 2D 图像, 缺乏**空间推理** (在哪/深度/姿态)。**3D-VLA** (2024, 清华): 把 3D 几何作为额外 token 输入。**改进**: ① 3D 位置编码 (类似 PETR); ② 3D 场景图 (物体关系); ③ 显式深度监督。**效果**: 长视野任务 (整理桌子/做饭) 成功率 +15-20%。**SpatialVLA** (2024, 北大): 加空间推理 (ego-centric 坐标系)。
> ★ 3D = 物理世界对齐, 具身必备。

### 14.6 工程与部署

**Q16: 3D 视觉模型部署到边缘 (Jetson Orin) 怎么优化?**

> ① **TensorRT** (NVIDIA): FP32 → FP16/INT8, 层融合, kernel 自动调优, 加速 3-10x; ② **CUDA Graph**: 减少 kernel launch 开销; ③ **稀疏化**: MinkowskiEngine (稀疏卷积, 比 dense 快 10x); ④ **量化**: PTQ (训练后) 或 QAT (训练时), INT8 精度损失 < 2%; ⑤ **模型剪枝**: 通道剪枝, 减少 30-50% 计算。**Jetson Orin 254 TOPS**, 3D 检测 30 FPS 可达 (PointPillars + TensorRT)。
> ★ 工程优化 = 算子 + 量化 + 稀疏 + 部署, 缺一不可。

## 📚 深度扩展: 3D 视觉应用对标表

> 本节对正文做工业落地向的纵深扩展, 兼顾理论与 PyTorch 实现.

### 一、理论深耕 — 公式与可证伪假设

#### 1.1 具身控制的统一范式

把具身决策视为在状态 $s \in \mathcal{S}$, 动作 $a \in \mathcal{A}$, 奖励 $r \in \mathbb{R}$ 上的 POMDP:

$$
\pi_\theta(a\mid s)=\arg\max_\theta \mathbb{E}_{a\sim\pi_\theta}\!\Big[\sum_{t}\gamma^t r(s_t,a_t)\Big]
$$

其中 $s_t$ 通常是部分可观测的, 因此常用**历史观测编码** $h_t=\text{Enc}(o_{1:t})$ 替代状态. 现代 VLA 用 LLM Tokenizer 编码 $h_t$, 由下一个 token 解码动作.

#### 1.2 模仿学习的 DAgger 修正

设 expert policy $\pi^*$ 与 imitator $\pi_\theta$, BC 损失:

$$
\mathcal{L}_\text{BC}(\theta) = -\mathbb{E}_{(s,a)\sim\pi^*}\!\big[\log \pi_\theta(a\mid s)\big]
$$

DAgger 引入 on-policy 状态分布:

$$
\mathcal{L}_\text{DAgger}(\theta) = -\mathbb{E}_{s\sim\pi_\theta}\!\big[\log \pi_\theta(a\mid s)\big]
$$

实践 DAgger 在长尾状态上更鲁棒, 但工程上需要 online rollout, 开销大.

#### 1.3 Sim2Real 域随机化的理论支持

设仿真器环境 $\mathcal{E}_\text{sim}$ 与真实环境 $\mathcal{E}_\text{real}$ 的差距 $\Delta(\cdot,\cdot)$ 度量 (常用 FID 或物理量误差), 域随机化目标:

$$
\min_\theta \max_\phi \mathbb{E}_{\xi\sim\Omega_\phi}\!\big[\mathcal{L}(\pi_\theta;\mathcal{E}_\text{sim}(\xi))\big] \quad\text{s.t.}\ \Delta\big(\mathcal{E}_\text{sim}(\xi),\mathcal{E}_\text{real}\big)\le\epsilon
$$

实践中 `xi` 涵盖视觉 (光照/纹理) + 物理 (摩擦/质量) + 传感器噪声; 增加到 `xi` 维度虽多, 但每个取值域不必连续 (离散化即可).

#### 1.4 VLA 的 token 化动作表征

把连续动作 $a \in \mathbb{R}^n$ 离散化为 $K$ 个 token:

$$
a \mapsto (t_1,\dots,t_K), \quad t_i=\arg\min_{k}\|\frac{2k-K-1}{K-1}-a_i/d\|_2
$$

再以自回归 Transformer 学习 $p(t_i \mid t_{<i}, h_t)$. 该表征与文本/视觉 token 同构, 是 VLA 复用 LLM 主干的物理基础.

### 二、PyTorch 完整实现

#### 2.1 一个最小 VLA 决策头

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class ActionTokenizer(nn.Module):
    def __init__(self, action_dim, num_bins=256):
        super().__init__()
        self.num_bins = num_bins
        self.action_dim = action_dim
        self.bin_centers = torch.linspace(-1.0, 1.0, num_bins)

    def encode(self, a):
        centers = self.bin_centers.to(a.device)
        a_exp = a.unsqueeze(-1)
        c_exp = centers.view(1, 1, -1)
        idx = (a_exp - c_exp).abs().argmin(-1)
        return idx

    def decode(self, idx):
        centers = self.bin_centers.to(idx.device)
        return centers[idx]


class MinimalVLA(nn.Module):
    def __init__(self, d_llm=512, action_dim=7, num_bins=256, num_layers=2, nhead=8):
        super().__init__()
        self.action_tok = ActionTokenizer(action_dim, num_bins)
        self.token_emb = nn.Embedding(num_bins, d_llm)
        self.in_proj = nn.Linear(d_llm * 2, d_llm)
        layer = nn.TransformerDecoderLayer(
            d_model=d_llm, nhead=nhead, dim_feedforward=d_llm * 4,
            dropout=0.1, batch_first=True, activation='gelu')
        self.decoder = nn.TransformerDecoder(layer, num_layers=num_layers)
        self.out = nn.Linear(d_llm, num_bins)

    def forward(self, text_emb, vision_emb, prev_action=None):
        B = text_emb.shape[0]
        if prev_action is None:
            prev_action = torch.zeros(B, 7, dtype=torch.long, device=text_emb.device)
        prev_tok = self.token_emb(prev_action)
        ctx = self.in_proj(torch.cat([text_emb, vision_emb], dim=1))
        tgt = prev_tok
        causal = torch.triu(torch.ones(tgt.size(1), tgt.size(1), device=tgt.device), 1).bool()
        h = self.decoder(tgt, ctx, tgt_mask=causal)
        return self.out(h)
```

#### 2.2 模仿学习 (BC) 训练循环

```python
def bc_step(model, obs, action, optimizer, device):
    model.train()
    text_emb = obs['text'].to(device)
    vision_emb = obs['vision'].to(device)
    action = action.to(device)
    logits = model(text_emb, vision_emb, prev_action=action[:, :-1])
    targets = action[:, 1:]
    loss = F.cross_entropy(logits.reshape(-1, logits.size(-1)), targets.reshape(-1))
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    return loss.item()
```

#### 2.3 PPO 在仿真器中的训练循环骨架

```python
import torch
from torch.distributions import Categorical

def ppo_step(actor, critic, optimizer, batch_obs, batch_act, batch_adv, batch_old_logp, batch_ret,
             eps_clip=0.2, vf_coef=0.5, ent_coef=0.01):
    logits = actor(batch_obs)
    dist = Categorical(logits=logits)
    logp = dist.log_prob(batch_act)
    ratio = (logp - batch_old_logp).exp()
    surr1 = ratio * batch_adv
    surr2 = torch.clamp(ratio, 1 - eps_clip, 1 + eps_clip) * batch_adv
    policy_loss = -torch.min(surr1, surr2).mean()
    value_loss = ((critic(batch_obs) - batch_ret) ** 2).mean()
    ent = dist.entropy().mean()
    loss = policy_loss + vf_coef * value_loss - ent_coef * ent
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    return loss.item(), policy_loss.item(), value_loss.item(), ent.item()
```

### 三、工业 / 学术案例 — Google RT-2 / OpenVLA / Diffusion Policy / π0

#### 3.1 RT-2 (Google, 2023)

- **思路**: 直接 fine-tune PaLM-E / PaLM-XS 在机器人轨迹 + 文本指令上, 共享 token 表.
- **优势**: 零样本迁移到新指令; 大模型预训练知识继承.
- **限制**: 推理贵, 延迟 200-500ms, 不适合实时闭环.
- **可借鉴**: 视觉-语言联合 token 化, 多个模态共用 transformer 解码器.

#### 3.2 OpenVLA (2024)

- **思路**: 7B 参数开源 VLA, 用 SigLIP + Llama 2 7B 拼装.
- **数据**: Open X-Embodiment, 800k+ episodes.
- **结果**: 单 GPU 推理 < 100ms, 在多个桌面操作任务上击败 RT-2.
- **可借鉴**: 数据混合策略, 训练用 cosine LR + 2 epoch warmup.

#### 3.3 Diffusion Policy (2024)

- **思路**: 把动作序列视为 $T_a$ 步的扩散过程, DDPM 训练; 在线 5-step DDIM 推理.
- **优势**: 多模态动作分布自然建模; 长 horizon 稳定.
- **限制**: 推理需多次 UNet forward, 仿真器训练时间约为 VLA 的 4 倍.
- **可借鉴**: 把 action chunking (16 步) 用 diffusion 一次输出, 闭环稳定性提高.

#### 3.4 π0 (Physical Intelligence, 2024)

- **思路**: VLM 主干 + flow matching 动作输出, 在 5+ 真实家庭任务上 90%+ 成功率.
- **数据**: 跨 embodiment 混合 + 仿真-真实联合.
- **可借鉴**: flow matching 替代 diffusion, 推理次数从 5-10 降到 1-3.

### 五、常见陷阱与最佳实践

1. **仿真-真实差距**: 仿真里成功率 95% 不代表现实 60%; 必须做域随机化.
2. **动作归一化**: 训练时务必把连续动作除以最大动作范围 + clip 到 `+-1`, 否则 loss 数值不稳.
3. **VLA 长尾**: VLA 在训练集之外的指令上可能"瞎做"; 至少保留 10% 真实人类指令测试.
4. **PPO 数值不稳定**: reward scale 影响极大, 推荐 `r / std(recent_rewards)`.
5. **域随机化调参**: 物理参数采样范围太宽会导致策略不收敛; 推荐逐步扩大.
6. **VLA 显存**: 7B 模型 + 20 帧视觉序列在 A100 上 30GB+; 推荐 gradient checkpointing + fp16.
7. **Diffusion Policy 推理**: DDIM 步数从 100 降到 5 时, 性能略有下降但速度飞快, 工业首选.
8. **数据混合**: 多 embodiment 训练时, 数据量占比应大致按"1/N"稀释.

### 一、完整训练管线 (PyTorch Lightning 风格, 不依赖 Lightning)

```python
import torch
import torch.nn as nn
from torch.utils.data import DataLoader, Dataset
from torch.cuda.amp import autocast, GradScaler

class NPZDataset(Dataset):
    # numpy / parquet 通用 dataset
    def __init__(self, path, columns, label_col, length=1024):
        import numpy as np
        arr = np.load(path)
        self.x = {c: arr[c] for c in columns}
        self.y = arr[label_col]
        self.length = length
    def __len__(self):
        return self.length
    def __getitem__(self, i):
        return ({k: torch.as_tensor(v[i]) for k, v in self.x.items()},
                torch.as_tensor(self.y[i], dtype=torch.float32))


def train_one_epoch(model, loader, optimizer, scaler, device, log_every=200, max_step=10000):
    model.train()
    total_loss, n_seen, n_step = 0.0, 0, 0
    for x, y in loader:
        x = {k: v.to(device, non_blocking=True) for k, v in x.items()}
        y = y.to(device, non_blocking=True)
        optimizer.zero_grad(set_to_none=True)
        with autocast(dtype=torch.bfloat16):
            logits = model(**x)
            loss = nn.functional.binary_cross_entropy_with_logits(logits, y)
        scaler.scale(loss).backward()
        scaler.unscale_(optimizer)
        torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
        scaler.step(optimizer); scaler.update()
        total_loss += loss.item() * y.size(0); n_seen += y.size(0); n_step += 1
        if n_step % log_every == 0:
            print(f"step={n_step} loss={total_loss/max(n_seen,1):.4f}")
        if n_step >= max_step:
            break
    return total_loss / max(n_seen, 1)


def evaluate(model, loader, device):
    model.eval()
    preds, labels = [], []
    with torch.no_grad(), autocast(dtype=torch.bfloat16):
        for x, y in loader:
            x = {k: v.to(device, non_blocking=True) for k, v in x.items()}
            p = torch.sigmoid(model(**x)).cpu().numpy()
            preds.append(p); labels.append(y.numpy())
    import numpy as np
    p = np.concatenate(preds); l = np.concatenate(labels)
    from sklearn.metrics import roc_auc_score, log_loss
    return {"auc": roc_auc_score(l, p), "logloss": log_loss(l, p)}
```

#### 1.2 AdamW + cosine LR with warmup

```python
from torch.optim.lr_scheduler import LambdaLR
import math

def cosine_warmup(optimizer, warmup_steps, total_steps):
    def fn(step):
        if step < warmup_steps:
            return step / max(1, warmup_steps)
        progress = (step - warmup_steps) / max(1, total_steps - warmup_steps)
        return 0.5 * (1.0 + math.cos(math.pi * progress))
    return LambdaLR(optimizer, fn)

optimizer = torch.optim.AdamW(model.parameters(), lr=3e-4, betas=(0.9, 0.95), weight_decay=0.05)
```

#### 3.3 显著性检验 (z-test for CTR)

```python
import math
def z_test(p1, n1, p2, n2):
    p_pool = (p1*n1 + p2*n2) / (n1 + n2)
    se = math.sqrt(p_pool * (1 - p_pool) * (1/n1 + 1/n2))
    z = (p2 - p1) / se
    from math import erf, sqrt
    pval = 2 * (1 - 0.5 * (1 + erf(abs(z) / sqrt(2))))
    return z, pval
```

### 五、Debug 与故障排查

#### 5.1 Loss = NaN 排查清单

1. bf16 下溢出: 切换 fp32 验证.
2. 学习率太大: 降 10x 再试.
3. 标签有 -1 / 异常值: print 唯一值.
4. 注意力 mask 反转: 用浮点加性 mask (`(1-m)*-1e4`).
5. 类别不平衡: focal loss 或 class weight.

#### 5.2 AUC 不涨 / 降

1. 训练/测试 leakage: 检查 train/eval pipeline 一致性.
2. 标签错位: 检查 time-based split.
3. 特征漂移: 监控 PSI, 加回旧域样本.
4. 模型容量不够: 加宽 / 加深.

#### 5.3 推理延迟高

1. ONNX 算子: 用 TRT 替代部分 cuda kernel.
2. 动态 shape: 用 dynamic_axes + 静态 shape 预热.
3. cache miss: Faiss HNSW 改 IVF + PQ.
4. 序列化: pickle vs msgpack, 序列化占比 30% 时该压缩.
