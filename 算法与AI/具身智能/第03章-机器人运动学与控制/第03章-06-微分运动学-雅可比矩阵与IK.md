## 1. 直觉引入:从位置到速度

### 1.1 为什么"位置 IK"在工程里不够用?

第 1 章的 IK 解法是**位置 IK**——给定末端目标位姿 $\boldsymbol{x}^d \in SE(3)$,求关节角 $\boldsymbol{q}^d \in \mathbb{R}^n$ 使得 $\text{FK}(\boldsymbol{q}^d) = \boldsymbol{x}^d$。这是一个**代数方程**,数值解法有:

- **解析法 (闭式)**:只对 6 DOF 且满足 Pieper 准则 (3 个相邻关节轴交于一点) 的机器人有解,通用性差。
- **数值法**:伪逆法、牛顿-拉夫森、LM 算法——本质都是"迭代求解非线性方程"。

但工业机器人控制**不是"给一个点,跳过去"**,而是**"给一条轨迹,沿着走"**。轨迹跟踪需要**关节速度** $\dot{\boldsymbol{q}}$,不是**关节位置** $\boldsymbol{q}$。这个区别带来了三个工程需求:

| 需求 | 位置 IK 的局限 | 微分 IK 的解法 |
| :--- | :--- | :--- |
| **速度平滑** | 离散跳点之间无中间速度规划 | $\dot{q} = J^+ \dot{x}^d$ 直接给速度 |
| **奇异点处理** | 伪逆迭代可能不收敛 | DLS 阻尼最小二乘,自动降速 |
| **约束处理** | 关节限位碰撞难以整合 | 加权最小二乘 / 二次规划 |

**关键观察**:轨迹跟踪的控制频率通常是 100 Hz - 1 kHz,在这么短的时间窗口内,**末端运动的"瞬时速度"几乎就是位置的一阶导**。这就引出了本章核心方程:

$$\dot{\boldsymbol{x}} = J(\boldsymbol{q}) \dot{\boldsymbol{q}}$$

这就是**雅可比矩阵 (Jacobian)** 的定义:**关节速度到末端速度的线性映射**。

### 1.2 一个真实工程 bug:画圆轨迹的"抽搐"

让我们看一个**典型的新人 bug**——用位置 IK 跟踪一个圆形轨迹:

```python
# ===== 错误做法:位置 IK 直接跳点 =====
import numpy as np

def position_ik_circle(robot, center, radius, n_points=100):
    """位置 IK:在圆周上等距采样 100 个点,逐个解 IK"""
    thetas = np.linspace(0, 2 * np.pi, n_points)
    joint_path = []
    for theta in thetas:
        x_d = center + radius * np.array([np.cos(theta), np.sin(theta), 0])
        # 每个点单独解 IK,关节角之间无关联
        q_d = robot.ik_numerical(x_d, q_init=joint_path[-1] if joint_path else None)
        joint_path.append(q_d)
    return np.array(joint_path)
```

这段代码跑出来**看起来**能画圆,但放到真实机器人上有两个问题:

1. **相邻点的关节角差分不一定小**——IK 解有多个分支 (8 个解对 6 DOF 机器人),算法可能从分支 A 跳到分支 B,关节角剧烈跳变。
2. **奇异点附近的解发散**——当圆周穿过奇异构型 (例如腕部对齐),$J$ 秩亏损,IK 数值震荡。

**正确做法:微分 IK,每个控制周期解"速度"**。

```python
# ===== 正确做法:微分 IK + DLS =====
def differential_ik_circle(robot, q_current, center, radius, theta, dt=0.01, lam=0.01):
    """微分 IK:用雅可比反解速度"""
    # 1. 当前末端位姿
    x_current = robot.fk(q_current)[:3, 3]
    # 2. 目标点
    x_d = center + radius * np.array([np.cos(theta), np.sin(theta), 0])
    # 3. 末端期望速度 (PD 控制:追踪目标点)
    x_dot_desired = (x_d - x_current) / dt
    # 4. 雅可比 (3 维位置部分,简化)
    J = robot.jacobian_position(q_current)  # 3 x n
    # 5. DLS 解关节速度
    q_dot = J.T @ np.linalg.solve(J @ J.T + lam**2 * np.eye(3), x_dot_desired)
    return q_dot
```

**核心区别**:位置 IK 解的是**静态方程**,微分 IK 解的是**动态方程**——后者天然适合实时控制 (1 kHz 频率更新)。

### 1.3 雅可比矩阵在机器人里的 4 个角色

雅可比矩阵不仅是"速度映射",它在整个机器人栈里扮演 4 个角色,理解这一点是 L7 工程师和 L6 工程师的分水岭:

| 角色 | 公式 | 工程意义 |
| :--- | :--- | :--- |
| **速度映射** | $\dot{\boldsymbol{x}} = J \dot{\boldsymbol{q}}$ | 关节速度 → 末端速度 |
| **静力映射** | $\boldsymbol{\tau} = J^\top \boldsymbol{F}$ | 末端力 → 关节力矩 (虚功原理) |
| **灵敏度分析** | $\delta \boldsymbol{x} = J \delta \boldsymbol{q}$ | 小扰动下末端变化 (用于误差分析) |
| **约束投影** | $\dot{\boldsymbol{q}} = J^+ \dot{\boldsymbol{x}}$ + 零空间 | 操作空间约束投影到关节空间 |

**直觉类比**:

```text
雅可比矩阵在机器人里 = Jacobian 在深度学习里
─────────────────────────────────────────
∂L/∂w (梯度)        → ∂x/∂q (末端对关节的灵敏度)
反向传播            → 力矩映射 τ = J^T F
Hessian 近似        → 二阶微分运动学 (加速度)
```

这就是为什么 L7 工程师面试时常说:**"雅可比就是机器人学的梯度"**——同一个数学对象在不同领域扮演同一个角色。

### 1.4 与仿真器接口:为什么 MuJoCo / Isaac Gym 都暴露雅可比?

仿真器 (MuJoCo, Isaac Gym, Drake) 都暴露雅可比接口,因为:

1. **正向动力学**:$\boldsymbol{\tau} = M(\boldsymbol{q}) \ddot{\boldsymbol{q}} + C(\boldsymbol{q}, \dot{\boldsymbol{q}}) \dot{\boldsymbol{q}} + \boldsymbol{g}(\boldsymbol{q})$——这个方程本身**与雅可比无关**,但**约束动力学** (例如机械臂末端接触桌面) 需要雅可比把"末端约束"投影到关节空间。
2. **接触动力学**:接触力 $\lambda$ 通过 $J^\top \lambda$ 加到关节力矩,这是第 4 章力控制的核心。
3. **微分仿真**:MuJoCo 的 `mjd_subQuat` 等子函数需要雅可比更新状态。
4. **视觉伺服**:基于图像的视觉伺服 (IBVS) 用**图像雅可比** $L = \partial \boldsymbol{s} / \partial \boldsymbol{q}$ (其中 $\boldsymbol{s}$ 是图像特征),本质还是 $L \dot{\boldsymbol{q}} = \dot{\boldsymbol{s}}$。

**真实接口示例 (Pinocchio)**:

```python
import pinocchio as pin

model = pin.buildModelFromUrdf("ur5.urdf")
data = model.createData()

q = pin.neutral(model)  # 零构型
pin.forwardKinematics(model, data, q)

# 计算世界坐标系下的雅可比 (6 × n 矩阵)
J = pin.computeJointJacobian(model, data, q, model.nq)
# J[:3, :] 是线速度部分, J[3:, :] 是角速度部分
```

工业代码 90% 的 IK / 力控 / MPC 都长这样:**FK 算位姿,雅可比算局部灵敏度,然后解线性方程**。

## 2. 雅可比矩阵推导

### 2.1 几何雅可比 (Geometric Jacobian)

**定义**:对于 $n$ 自由度机械臂,雅可比矩阵 $J(\boldsymbol{q}) \in \mathbb{R}^{6 \times n}$ 的第 $i$ 列是**第 $i$ 个关节轴在世界坐标系下的 6 维旋量 (twist)**:

$$J(\boldsymbol{q}) = \begin{bmatrix} \boldsymbol{z}_0 \times (\boldsymbol{p}_{ee} - \boldsymbol{p}_0) & \boldsymbol{z}_1 \times (\boldsymbol{p}_{ee} - \boldsymbol{p}_1) & \cdots & \boldsymbol{z}_{n-1} \times (\boldsymbol{p}_{ee} - \boldsymbol{p}_{n-1}) \\ \boldsymbol{z}_0 & \boldsymbol{z}_1 & \cdots & \boldsymbol{z}_{n-1} \end{bmatrix}$$

其中:

- $\boldsymbol{z}_i$ 是第 $i$ 个关节的旋转轴 (在基坐标系下),$\boldsymbol{p}_i$ 是第 $i$ 个关节的原点
- $\boldsymbol{p}_{ee}$ 是末端执行器位置
- $\times$ 是叉乘

**物理意义**:每列向量描述"如果只动第 $i$ 个关节 (其他关节固定),末端会产生什么样的线速度 + 角速度"。

**推导**:对正运动学 $\boldsymbol{x} = \text{FK}(\boldsymbol{q})$ 求时间导:

$$\dot{\boldsymbol{x}} = \frac{\partial \text{FK}}{\partial \boldsymbol{q}} \dot{\boldsymbol{q}} = J(\boldsymbol{q}) \dot{\boldsymbol{q}}$$

直接对 $\text{FK}$ 求偏导得到的 $J$ 叫**解析雅可比**;利用关节轴几何关系得到的 $J$ 叫**几何雅可比**。两者**数值上相等**,但**形式不同**。

### 2.2 几何雅可比的递推公式

工业代码不直接展开上面那个 $6 \times n$ 矩阵,而是用**递推公式**——遍历运动链,从基座到末端逐关节累加:

```text
算法:compute_geometric_jacobian(q)
───────────────────────────────────
输入: q (关节角向量)
输出: J (6 × n 矩阵)

1. 正向运动学, 计算每个关节的 {}^0 T_i (世界系下的变换)
2. 对于每个关节 i = 1, ..., n:
     z_i = {}^0 R_i 的第三列    # 关节轴在世界系的方向
     p_i = {}^0 T_i 的平移部分   # 关节原点在世界系的位置
     p_ee = {}^0 T_ee 的平移部分 # 末端位置

     # 第 i 列
     J_linear = z_i × (p_ee - p_i)
     J_angular = z_i
     J[:, i] = [J_linear; J_angular]
3. 返回 J
```

**Pinocchio 的实现就是这种递推**——时间复杂度 $O(n)$,空间复杂度 $O(n)$。

### 2.3 解析雅可比 (Analytic Jacobian)

**定义**:直接对 $\text{FK}(\boldsymbol{q})$ 求偏导:

$$J_{\text{ana}}(\boldsymbol{q}) = \frac{\partial \text{FK}}{\partial \boldsymbol{q}}$$

如果 $\text{FK}$ 输出 $\boldsymbol{x} \in \mathbb{R}^6$ 用欧拉角表示姿态,那 $J_{\text{ana}}$ 的前 3 行是 $\partial \boldsymbol{p}_{ee} / \partial \boldsymbol{q}$,后 3 行是 $\partial \boldsymbol{\phi} / \partial \boldsymbol{q}$ (欧拉角对关节角的偏导)。

**几何雅可比 vs 解析雅可比的区别**:

| | 几何雅可比 | 解析雅可比 |
| :--- | :--- | :--- |
| **后 3 行** | 末端角速度 $\boldsymbol{\omega}$ 在世界系的投影 | 欧拉角变化率 $(\dot{\phi}, \dot{\theta}, \dot{\psi})$ |
| **物理意义** | 直接对应"刚体瞬时旋转" | 取决于姿态参数化 (欧拉角 / 四元数) |
| **欧拉奇异点** | 无 (角速度总是 well-defined) | 万向锁附近发散 |
| **数值计算** | 需要逐关节变换 | 直接自动微分 |

**关键关系**:当姿态用**四元数**或**旋转矩阵**表示时,几何雅可比 = 解析雅比后者 (欧拉角) 需要乘一个**坐标变换矩阵** $T(\boldsymbol{\phi})$:

$$J_{\text{ana}} = \begin{bmatrix} I & 0 \\ 0 & T(\boldsymbol{\phi}) \end{bmatrix} J_{\text{geo}}$$

其中 $T(\boldsymbol{\phi})$ 是欧拉角变化率到角速度的雅可比:

$$T(\boldsymbol{\phi}) = \begin{bmatrix} 1 & 0 & -\sin\theta \\ 0 & \cos\phi & \cos\theta \sin\phi \\ 0 & -\sin\phi & \cos\theta \cos\phi \end{bmatrix}$$

**工程含义**:如果你用欧拉角表示末端姿态,**万向锁 (Gimbal Lock)** 附近 $T$ 奇异,**解析雅可比的最后 3 行爆炸**,但**几何雅可比没事**——这是为什么工业代码 (Pinocchio, Drake) 默认输出**几何雅可比**。

### 2.4 与坐标系的关系

雅可比矩阵**依赖于坐标系选择**。常见三种坐标系:

| 坐标系 | 符号 | 物理意义 | 应用场景 |
| :--- | :--- | :--- | :--- |
| **世界系 (Base)** | ${}^0 J$ | 关节轴在世界坐标系下表示 | 大多数控制场景 |
| **末端系 (EE)** | ${}^{ee} J$ | 关节轴在末端坐标系下表示 | 力控制 / 视觉伺服 |
| **工具系 (Tool)** | ${}^{tool} J$ | 工具中心点 (TCP) 处 | 焊接 / 喷涂 |

**变换公式**:

$${}^{ee} J = \begin{bmatrix} {}^{ee} R_0 & 0 \\ 0 & {}^{ee} R_0 \end{bmatrix} {}^0 J$$

其中 ${}^{ee} R_0$ 是世界系到末端系的旋转矩阵。

**工程含义**:操作空间控制 (第 4 章) 通常用 ${}^{ee} J$,因为力 $F$ 通常定义在末端系;"逆运动学 + 雅可比"通常用 ${}^0 J$。

### 2.5 时变雅可比 (时间导数)

雅可比矩阵本身是 $\boldsymbol{q}$ 的函数,$\boldsymbol{q}$ 随时间变化,所以 $J$ 也随时间变化:

$$\frac{d}{dt} J(\boldsymbol{q}(t)) = \sum_{i=1}^n \frac{\partial J}{\partial q_i} \dot{q}_i$$

工程上 $\dot{J}$ 主要用于:

1. **加速度层控制**:$\ddot{\boldsymbol{x}} = J \ddot{\boldsymbol{q}} + \dot{J} \dot{\boldsymbol{q}}$——加速度正运动学
2. **前馈补偿**:动力学方程 $M \ddot{q} + C \dot{q} + g = \tau$ 中的科氏项需要 $\dot{J}$
3. **导纳控制**:接触力变化率计算需要 $\dot{J}$

**计算方法**:

- **解析法**:对 $J$ 表达式求偏导,需要 $\partial^2 \text{FK} / \partial q_i \partial q_j$ (二阶偏导)——计算量大。
- **数值法 (有限差分)**:

$$\dot{J} \approx \frac{J(\boldsymbol{q} + \epsilon \dot{\boldsymbol{q}}) - J(\boldsymbol{q})}{\epsilon}$$

简单但有数值误差,$\epsilon$ 取 $10^{-8}$ 到 $10^{-6}$。

- **自动微分 (PyTorch)**:把 $\text{FK}$ 写成可微函数,`torch.autograd.grad` 自动算。

### 2.6 雅可比的物理解释:旋量 (Twist)

**旋量 (Twist)**:描述刚体瞬时运动的 6 维向量 $\boldsymbol{V} = (\boldsymbol{v}, \boldsymbol{\omega})$,其中 $\boldsymbol{v}$ 是线速度,$\boldsymbol{\omega}$ 是角速度。

雅可比矩阵的**每一列**就是一个旋量:**第 $i$ 个关节以单位角速度旋转时,末端产生的瞬时运动**。

```text
第 i 关节以单位角速度旋转 → 末端产生旋量 J[:, i]:

  ┌─────────────────┐
  │ 线速度 v_i      │  =  z_i × (p_ee - p_i)
  ├─────────────────┤
  │ 角速度 ω_i      │  =  z_i
  └─────────────────┘

其中 z_i 是第 i 关节的旋转轴方向 (世界系)
```

**关键洞察**:末端速度 $\dot{\boldsymbol{x}}$ 是所有关节速度的**线性组合**,组合系数是 $J$ 的列向量:

$$\dot{\boldsymbol{x}} = \sum_{i=1}^n J[:, i] \cdot \dot{q}_i$$

这就是为什么**关节轴对齐会让 $J$ 的列相关**——两个关节产生相同的旋量,组合自由度从 6 降到 5 (奇异)。

## 3. 速度与力的映射

### 3.1 速度映射: $\dot{\boldsymbol{x}} = J \dot{\boldsymbol{q}}$

这是本章**最核心的方程**——末端速度 = 雅可比 × 关节速度。

**直观理解**:6 自由度机械臂有 6 个关节,理论上 $J$ 是 $6 \times 6$ 方阵,在**非奇异点**可逆,所以:

$$\dot{\boldsymbol{q}} = J^{-1} \dot{\boldsymbol{x}} \quad (\text{非奇异})$$

但**多数机器人不是方阵可逆的**——例如 7 DOF 机械臂 $J \in \mathbb{R}^{6 \times 7}$ (6 行,7 列),欠定;冗余机器人 $J^\top J \in \mathbb{R}^{7 \times 7}$ 但 $\det = 0$。

### 3.2 伪逆 (Moore-Penrose Pseudoinverse)

**定义**:对于非方阵或奇异方阵,伪逆 $J^+$ 是满足以下四个条件的**唯一**广义逆:

1. $J J^+ J = J$
2. $J^+ J J^+ = J^+$
3. $(J J^+)^\top = J J^+$
4. $(J^+ J)^\top = J^+ J$

**最小二乘性质**:$\dot{\boldsymbol{q}} = J^+ \dot{\boldsymbol{x}}$ 是方程 $J \dot{\boldsymbol{q}} = \dot{\boldsymbol{x}}$ 的**最小范数解**——在所有满足 $J \dot{\boldsymbol{q}} = \dot{\boldsymbol{x}}$ 的解中,$\|J^+ \dot{\boldsymbol{x}}\|_2$ 最小。

**计算公式**:

- **满秩方阵** ($J$ 是 $n \times n$ 可逆):$J^+ = J^{-1}$
- **行满秩** ($J$ 是 $m \times n$,$m < n$,rank $=m$):$J^+ = J^\top (J J^\top)^{-1}$
- **列满秩** ($J$ 是 $m \times n$,$m > n$,rank $=n$):$J^+ = (J^\top J)^{-1} J^\top$

**NumPy 调用**:

```python
J_pinv = np.linalg.pinv(J)  # 奇异值截断默认 1e-15
```

### 3.3 零空间 (Null Space) 与冗余机器人

对于 $n > 6$ (冗余机器人,例如 7 DOF Franka),$J \dot{\boldsymbol{q}} = \dot{\boldsymbol{x}}$ 有**无穷多解**——任意满足 $\dot{\boldsymbol{q}}_0 \in \mathcal{N}(J)$ 的 $\dot{\boldsymbol{q}}_0$ 都可以加到特解上:

$$\dot{\boldsymbol{q}} = J^+ \dot{\boldsymbol{x}} + (I - J^+ J) \dot{\boldsymbol{q}}_0$$

其中 $(I - J^+ J)$ 是**零空间投影矩阵**,$\dot{\boldsymbol{q}}_0$ 是任意关节速度,$(I - J^+ J) \dot{\boldsymbol{q}}_0$ 投影到 $J$ 的零空间,**不影响末端运动**。

**工程意义**:零空间运动可以做**次级任务**——避障、关节限位、奇异性回避:

```text
冗余机器人的速度分解:
─────────────────────────────────────
  ẋ = J q̇  = J q̇_pinv + J (I - J^+ J) q̇_0
        ↑                  ↑
   末端速度 (任务)    零空间速度 (次级,不影响末端)
```

**示例**:7 DOF 机械臂从 A 到 B,你可以让它"边走边缩肘"——肘部角度改变,但末端路径不变。

### 3.4 力映射: $\boldsymbol{\tau} = J^\top \boldsymbol{F}$ (虚功原理)

**核心命题**:末端施加的力 $\boldsymbol{F} \in \mathbb{R}^6$ (3 维力 + 3 维力矩) 等效于关节力矩:

$$\boxed{\boldsymbol{\tau} = J^\top \boldsymbol{F}}$$

**推导 (虚功原理)**:

考虑虚位移 $\delta \boldsymbol{q}$,关节力矩做虚功 $\boldsymbol{\tau}^\top \delta \boldsymbol{q}$,末端力做虚功 $\boldsymbol{F}^\top \delta \boldsymbol{x}$。

虚功相等 (力是位移的共轭):

$$\boldsymbol{\tau}^\top \delta \boldsymbol{q} = \boldsymbol{F}^\top \delta \boldsymbol{x}$$

代入 $\delta \boldsymbol{x} = J \delta \boldsymbol{q}$:

$$\boldsymbol{\tau}^\top \delta \boldsymbol{q} = \boldsymbol{F}^\top J \delta \boldsymbol{q}$$

由于 $\delta \boldsymbol{q}$ 任意:

$$\boldsymbol{\tau}^\top = \boldsymbol{F}^\top J \implies \boldsymbol{\tau} = J^\top \boldsymbol{F}$$

**工程含义**:

1. **力控制**:知道末端受力,用 $\boldsymbol{\tau} = J^\top \boldsymbol{F}$ 算出关节力矩。
2. **静力平衡**:机械臂在接触约束下平衡时,约束力通过 $J^\top$ 加到关节。
3. **导纳控制**:接触力 → 关节力矩 → 位移补偿 (第 4 章核心)。

### 3.5 操作空间 vs 关节空间

两种控制框架的核心区别:

| 框架 | 控制变量 | 物理意义 | 优点 | 缺点 |
| :--- | :--- | :--- | :--- | :--- |
| **关节空间** | $\boldsymbol{q}, \dot{\boldsymbol{q}}, \boldsymbol{\tau}$ | 直接控制每个电机 | 数学简单 | 任务描述困难 |
| **操作空间** | $\boldsymbol{x}, \dot{\boldsymbol{x}}, \boldsymbol{F}$ | 在末端位姿空间控制 | 任务直观 | 需逆运动学 |

**操作空间动力学 (Khatib 1987)**:

$$M_x(\boldsymbol{q}) \ddot{\boldsymbol{x}} + \boldsymbol{C}_x(\boldsymbol{q}, \dot{\boldsymbol{q}}) \dot{\boldsymbol{x}} + \boldsymbol{g}_x(\boldsymbol{q}) = \boldsymbol{F}$$

其中:

- $M_x = (J M^{-1} J^\top)^{-1}$ (操作空间惯量)
- $\boldsymbol{C}_x = M_x (J M^{-1} C - \dot{J}) \dot{\boldsymbol{q}}$ (操作空间科氏)
- $\boldsymbol{g}_x = M_x J M^{-1} \boldsymbol{g}$ (操作空间重力)

**直观理解**:$M_x$ 是"末端感知的惯量"——把整个机械臂的惯量投影到末端,反映"末端感受到的轻重"。

### 3.6 完整的速度 / 力映射代码

```python
import numpy as np

class VelocityForceMapping:
    """演示 ẋ = J q̇ 和 τ = J^T F"""

    def __init__(self, robot):
        self.robot = robot  # 提供 fk(q) 和 jacobian(q)

    def velocity_to_joint(self, x_dot_desired, q):
        """末端速度 → 关节速度 (DLS)"""
        J = self.robot.jacobian(q)
        lam = 0.01  # 阻尼项
        # J^T (J J^T + λ² I)^{-1} x_dot
        q_dot = J.T @ np.linalg.solve(J @ J.T + lam**2 * np.eye(6), x_dot_desired)
        return q_dot

    def force_to_joint_torque(self, F_ee, q):
        """末端力 → 关节力矩 (虚功原理)"""
        J = self.robot.jacobian(q)
        tau = J.T @ F_ee  # 6 维力 → n 维力矩
        return tau

    def joint_to_ee_velocity(self, q_dot, q):
        """关节速度 → 末端速度"""
        J = self.robot.jacobian(q)
        x_dot = J @ q_dot  # n 维关节速度 → 6 维末端速度
        return x_dot

    def verify_consistency(self, q, q_dot, F_ee):
        """验证虚功原理: τ^T q̇ = F^T ẋ"""
        tau = self.force_to_joint_torque(F_ee, q)
        x_dot = self.joint_to_ee_velocity(q_dot, q)
        lhs = tau @ q_dot  # 关节空间虚功
        rhs = F_ee @ x_dot  # 操作空间虚功
        return np.isclose(lhs, rhs, atol=1e-6)
```

**重要**:虚功原理**任何时刻成立**,无论雅可比是否奇异——这是几何上的恒等式,不依赖数值稳定性。

## 4. 奇异点分析

### 4.1 雅可比秩的物理意义

**定义**:雅可比矩阵 $J \in \mathbb{R}^{m \times n}$ 的秩 $\text{rank}(J)$ 等于**机器人当前构型下能独立控制的方向数**。

| 机器人 DOF | 末端任务空间 | 雅可比形状 | 最大秩 | 满秩条件 |
| :--- | :--- | :--- | :--- | :--- |
| 6 DOF | 6 维 (位置 + 姿态) | $6 \times 6$ | 6 | 非奇异构型 |
| 7 DOF | 6 维 | $6 \times 7$ | 6 | 任意构型 (欠定) |
| 4 DOF SCARA | 4 维 (z + 姿态) | $4 \times 4$ | 4 | 非奇异构型 |
| 3 DOF 平面 | 3 维 | $3 \times 3$ | 3 | 非奇异 |

**关键事实**:

- $\text{rank}(J) < \min(m, n)$ 时,**雅可比秩亏损**,机器人**至少丢失一个独立运动方向**
- $\text{rank}(J) = \min(m, n)$ 时,**满秩**,所有方向都能动
- $\det(J J^\top) = 0$ 是**奇异点**的代数判据

### 4.2 奇异值分解 (SVD) 解读

**SVD 分解**:$J = U \Sigma V^\top$,其中:

- $U \in \mathbb{R}^{m \times m}$:左奇异向量,正交
- $\Sigma = \text{diag}(\sigma_1, ..., \sigma_r, 0, ..., 0)$:奇异值,$\sigma_1 \geq \sigma_2 \geq ... \geq \sigma_r > 0$
- $V \in \mathbb{R}^{n \times n}$:右奇异向量,正交
- $r = \text{rank}(J)$

**物理意义**:

- **$\sigma_i$ 越大**,沿 $\boldsymbol{u}_i$ 方向的运动越"容易" (关节速度 $\to$ 末端速度的放大系数)
- **$\sigma_i$ 越小**,沿 $\boldsymbol{u}_i$ 方向的运动越"困难"
- **$\sigma_{\min} = 0$**:奇异点,该方向**完全不能动**

**几何可视化**:

```text
J = U Σ V^T

关节空间 q̇          末端空间 ẋ
   ┌──┐              ┌──────────┐
   │  │    J          │          │
   │  │ ────────────→ │ ẋ = J q̇ │
   │  │              │          │
   └──┘              └──────────┘

   n 维                m 维

   右奇异向量 v_i      左奇异向量 u_i
   (关节运动方向)      (末端运动方向)

   奇异值 σ_i: 关节运动到末端运动的"放大系数"
```

**操作椭球 (Manipulability Ellipsoid)**:

单位关节速度 $\|\dot{\boldsymbol{q}}\| = 1$ 对应的所有末端速度 $\dot{\boldsymbol{x}} = J \dot{\boldsymbol{q}}$ 构成一个**椭球**:

$$\dot{\boldsymbol{x}}^\top (J J^\top)^{-1} \dot{\boldsymbol{x}} = 1$$

椭球的**主轴**长度是 $\sigma_i$ (奇异值),**主轴方向**是 $\boldsymbol{u}_i$ (左奇异向量)。

**直观**:椭球越"圆",机器人越"灵活";椭球越"扁",某些方向动不了。

### 4.3 奇异构型实例

#### 4.3.1 腕部对齐 (Wrist Alignment)

**定义**:6 DOF 机械臂的腕部 3 个关节 (关节 4, 5, 6) **轴线共线**——3 个轴对齐成一条线。

**为什么奇异**:

```text
6 DOF 机械臂奇异构型:

              z_4   z_5   z_6
               │     │     │
               │     │     │  ← 三个轴共线
               ●─────●─────●
              /             \
             /               \
          关节 3           末端

z_4, z_5, z_6 共线 → 3 个腕关节只能产生"绕同一条轴的旋转"
                  → 绕另外两条轴的力矩 = 0
                  → J 秩亏损 (从 6 降到 5)
```

**UR5 实例**:当关节 4 = 关节 5 = 关节 6 = 0 时,3 个腕关节轴都竖直向上,完全共线。

#### 4.3.2 边界伸直 (Elbow Lock)

**定义**:机械臂**完全伸直**——所有关节折叠成一条直线。

**为什么奇异**:

```text
完全伸直构型:

   关节 1 ──── 关节 2 ──── 关节 3 ──── 末端
                ●           ●           ●
                ↑           ↑           ↑
              z_2 ⊥ z_1   z_3 ⊥ z_2   ... 共面?

如果所有关节轴共面 → 沿平面外方向不可达
                  → J 秩亏损
```

#### 4.3.3 其他常见奇异

| 机器人 | 奇异构型 | 物理意义 |
| :--- | :--- | :--- |
| **SCARA** | 第 1, 2 关节共线 | 末端 x 方向不可达 |
| **PUMA** | 腕对齐 + 边界伸直 | 双重奇异,最严重 |
| **Franka (7 DOF)** | 肘部折叠 / 过度伸直 | 零空间退化 |
| **Delta 并联** | 末端靠近中心 | 运动学奇异 |

### 4.4 奇异点附近的鲁棒控制

#### 4.4.1 数值病态的表现

奇异点附近,$\sigma_{\min} \to 0$,伪逆 $J^+ = V \Sigma^{-1} U^\top$ 中 $1/\sigma_{\min} \to \infty$。

**后果**:

1. 关节速度 $\dot{\boldsymbol{q}} = J^+ \dot{\boldsymbol{x}}$ **爆炸**
2. 即使末端目标 $\dot{\boldsymbol{x}}$ 很小,关节速度可能到 1000+ rad/s
3. 触发关节限位保护,机器人紧急停止

**数值例子**:

```python
import numpy as np

# 模拟奇异点附近的伪逆
J = np.array([[1, 0], [0, 1e-10]])  # σ_min = 1e-10
J_pinv = np.linalg.pinv(J)
x_dot = np.array([0.001, 0])  # 末端速度 1 mm/s
q_dot = J_pinv @ x_dot
print(f"q_dot = {q_dot}")  # q_dot = [0.001, 1e7]  ← 第二个关节速度 10^7!
```

#### 4.4.2 奇异回避策略

工业上有 5 种主流策略:

| 策略 | 公式 | 优点 | 缺点 |
| :--- | :--- | :--- | :--- |
| **DLS (阻尼最小二乘)** | $J^\top (J J^\top + \lambda^2 I)^{-1}$ | 简单,自动降速 | 牺牲精度 |
| **截断 SVD** | $V \tilde{\Sigma}^{-1} U^\top$,$\tilde{\Sigma}^{-1}_{ii} = 1/\sigma_i$ if $\sigma_i > \epsilon$ else 0 | 保留"可动方向" | 需要选 $\epsilon$ |
| **零空间避奇异** | $\dot{\boldsymbol{q}}_0 = k \nabla w(\boldsymbol{q})$ (可操作度梯度) | 主动远离奇异 | 计算梯度 |
| **任务优先级** | 分层二次规划 | 多约束协同 | 求解慢 |
| **柔顺控制** | 阻抗控制替代位置控制 | 自然处理奇异 | 不适合精定位 |

**最常用**:DLS + 可操作度梯度避奇异 (5.3 节)。

## 5. 阻尼最小二乘 (DLS)

### 5.1 伪逆的局限

**伪逆法问题**:
1. 奇异点附近 $\dot{\boldsymbol{q}}$ 爆炸
2. 关节限位无法处理
3. 没有"代价最小"的语义

**改进思路**:在最小二乘目标里加一个**正则化项**:

$$\min_{\dot{\boldsymbol{q}}} \|J \dot{\boldsymbol{q}} - \dot{\boldsymbol{x}}\|^2 + \lambda^2 \|\dot{\boldsymbol{q}}\|^2$$

这就是**阻尼最小二乘 (DLS, Damped Least Squares)**,也叫 **Levenberg-Marquardt**。

### 5.2 DLS 公式推导

将目标函数展开,对 $\dot{\boldsymbol{q}}$ 求导:

$$\mathcal{L} = (J \dot{\boldsymbol{q}} - \dot{\boldsymbol{x}})^\top (J \dot{\boldsymbol{q}} - \dot{\boldsymbol{x}}) + \lambda^2 \dot{\boldsymbol{q}}^\top \dot{\boldsymbol{q}}$$

$$\frac{\partial \mathcal{L}}{\partial \dot{\boldsymbol{q}}} = 2 J^\top (J \dot{\boldsymbol{q}} - \dot{\boldsymbol{x}}) + 2 \lambda^2 \dot{\boldsymbol{q}} = 0$$

$$(J^\top J + \lambda^2 I) \dot{\boldsymbol{q}} = J^\top \dot{\boldsymbol{x}}$$

$$\boxed{\dot{\boldsymbol{q}} = (J^\top J + \lambda^2 I)^{-1} J^\top \dot{\boldsymbol{x}}}$$

等价形式 (行满秩时):

$$\dot{\boldsymbol{q}} = J^\top (J J^\top + \lambda^2 I)^{-1} \dot{\boldsymbol{x}}$$

### 5.3 DLS 的物理直觉

**为什么阻尼项能解决奇异问题?**

直观解释:DLS 解是方程 $J \dot{\boldsymbol{q}} = \dot{\boldsymbol{x}}$ 的**近似解**——它不要求精确满足,而是找"既接近末端速度,关节速度又小"的妥协解。

```text
DLS 的 trade-off:

  精确性                    关节速度大小
  (||J q̇ - ẋ|| 小)   ↔   (||q̇|| 小)
       ↑                        ↑
       │       λ 调节两者权重     │
       └────────────────────────┘

  λ = 0  → 退化为伪逆 (精确但可能爆炸)
  λ = ∞ → q̇ = 0 (无运动)
  λ 适中 → 平滑过渡
```

**自适应 $\lambda$**:Wampler (1986) 建议 $\lambda$ 随 $\sigma_{\min}$ 变化:

$$\lambda = \begin{cases} 0 & \sigma_{\min} > \epsilon_1 \\ \lambda_0 \left(1 - \frac{\sigma_{\min}}{\epsilon_1}\right) & \text{otherwise} \end{cases}$$

奇异点附近 $\sigma_{\min} \to 0$,$\lambda$ 自动变大,关节速度自动降下来。

### 5.4 可操作度 (Manipulability)

**Yoshikawa (1985) 可操作度**:

$$w(\boldsymbol{q}) = \sqrt{\det(J(\boldsymbol{q}) J(\boldsymbol{q})^\top)}$$

**物理意义**:

- $w = 0$:**奇异点**,某些方向完全不能动
- $w$ 大:机器人姿态"灵活",各个方向都能动
- $w$ 的单位:$w \in [\text{m}]^3$ (3 维线速度时) 或 $[\text{rad}]^3$ (3 维角速度时)

**对 6 DOF 机器人**:

$$w = \sigma_1 \sigma_2 \sigma_3 \sigma_4 \sigma_5 \sigma_6 = \prod_{i=1}^6 \sigma_i$$

即所有奇异值的乘积。

**工程应用**:

1. **路径规划**:选择 $w(\boldsymbol{q})$ 大的中间点,远离奇异
2. **梯度下降避奇异**:$\dot{\boldsymbol{q}}_0 = k \nabla w$,其中 $\nabla w = \frac{\partial w}{\partial \boldsymbol{q}}$
3. **性能评估**:统计工作空间内 $w$ 的分布,衡量设计优劣

### 5.5 DLS 工业实现

**完整代码**:

```python
import numpy as np

def dls_ik(x_dot_desired, q, robot, lam=0.01, lam_min=1e-4, lam_max=1.0):
    """
    阻尼最小二乘 IK,带自适应阻尼

    参数:
      x_dot_desired: 末端期望速度 (6,)
      q: 当前关节角 (n,)
      robot: 提供 jacobian(q)
      lam: 阻尼项 (自适应调整)

    返回:
      q_dot: 关节速度 (n,)
    """
    J = robot.jacobian(q)  # 6 x n

    # 自适应阻尼:基于最小奇异值
    U, sigma, Vt = np.linalg.svd(J, full_matrices=False)
    sigma_min = sigma[-1]  # 最小奇异值

    if sigma_min < 0.01:  # 接近奇异
        # Wampler 自适应:σ_min → 0, λ → λ_max
        lam_adaptive = lam * (0.01 / (sigma_min + 1e-10))
        lam_adaptive = np.clip(lam_adaptive, lam_min, lam_max)
    else:
        lam_adaptive = lam

    # DLS 解
    JJt = J @ J.T  # 6 x 6
    q_dot = J.T @ np.linalg.solve(JJt + lam_adaptive**2 * np.eye(6), x_dot_desired)

    return q_dot, lam_adaptive, sigma_min


# 测试
class DummyRobot:
    def jacobian(self, q):
        # UR5 简化为 2 关节平面机械臂
        L1, L2 = 1.0, 1.0

        s12, c12 = np.sin(q[0] + q[1]), np.cos(q[0] + q[1])
        return np.array([
            [-L1*s1 - L2*s12, -L2*s12],
            [ L1*c1 + L2*c12,  L2*c12],
            [0, 0]  # 平面机械臂只有 2 维任务
        ])

robot = DummyRobot()
q_singular = np.array([0.0, np.pi])  # 边界伸直 (奇异)
x_dot = np.array([0.001, 0, 0])  # 末端期望速度

# 裸伪逆 (爆炸)

q_dot_pinv = np.linalg.pinv(J) @ x_dot
print(f"Pseudoinverse: q_dot = {q_dot_pinv}")  # 巨大数值

# DLS (平稳)
q_dot_dls, lam, sigma_min = dls_ik(x_dot, q_singular, robot, lam=0.01)

```


### 5.6 DLS vs 截断 SVD 对比

两种方法的取舍:

| | DLS | 截断 SVD |
| :--- | :--- | :--- |
| **公式** | $J^\top (J J^\top + \lambda^2 I)^{-1}$ | $V \tilde{\Sigma}^{-1} U^\top$ |
| **奇异点附近** | 末端速度**降低**(自动降速) | 末端速度**保持**(但某些方向丢弃) |
| **参数** | $\lambda$ (一个标量) | $\epsilon$ (截断阈值) |
| **平滑性** | 平滑 (连续可微) | 不连续 ($\sigma < \epsilon$ 切换) |
| **工业首选** | ✓ (Universal Robots, KUKA) | ✗ (主要用于离线分析) |

**经验法则**:实时控制用 DLS;离线分析用 SVD 解读结构。

## 6. 运动学约束

### 6.1 关节限位

**问题**:每个关节有物理限位 $\boldsymbol{q}_{\min} \leq \boldsymbol{q} \leq \boldsymbol{q}_{\max}$,IK 解可能违反。

**常见方法**:

#### 方法 1:伪逆 + 梯度投影 (零空间避限)

$$\dot{\boldsymbol{q}} = J^+ \dot{\boldsymbol{x}} + (I - J^+ J) \dot{\boldsymbol{q}}_0$$

其中 $\dot{\boldsymbol{q}}_0 = -\nabla h(\boldsymbol{q})$,$h(\boldsymbol{q})$ 是"关节限位代价":

$$h(\boldsymbol{q}) = \sum_{i=1}^n \frac{(q_i - q_{i,\text{mid}})^2}{(q_{i,\max} - q_{i,\min})^2}$$

零空间项 $(I - J^+ J) \dot{\boldsymbol{q}}_0$ **不影响末端运动**,只调整关节配置,自然避开限位。

#### 方法 2:加权最小二乘 (WLS)

$$\min_{\dot{\boldsymbol{q}}} \|J \dot{\boldsymbol{q}} - \dot{\boldsymbol{x}}\|^2 + \|\boldsymbol{W} \dot{\boldsymbol{q}}\|^2$$

其中 $\boldsymbol{W}$ 是对角权重矩阵,接近限位时增大权重:

$$W_{ii} = \begin{cases} 1 + k \left(\frac{q_{i,\max} - q_i}{q_{i,\text{safe}}}\right)^2 & q_i \text{ 接近上限} \\ 1 + k \left(\frac{q_i - q_{i,\min}}{q_{i,\text{safe}}}\right)^2 & q_i \text{ 接近下限} \\ 1 & \text{otherwise} \end{cases}$$

#### 方法 3:QP (二次规划)

$$\begin{aligned}
\min_{\dot{\boldsymbol{q}}} \quad & \|J \dot{\boldsymbol{q}} - \dot{\boldsymbol{x}}\|^2 + \epsilon \|\dot{\boldsymbol{q}}\|^2 \\
\text{s.t.} \quad & \dot{\boldsymbol{q}}_{\min} \leq \dot{\boldsymbol{q}} \leq \dot{\boldsymbol{q}}_{\max} \\
& \boldsymbol{q}_{\min} \leq \boldsymbol{q} + \dot{\boldsymbol{q}} \Delta t \leq \boldsymbol{q}_{\max}
\end{aligned}$$

工业首选:QP 求解器 (OSQP, qpOASES) 100 Hz 解算没问题。

### 6.2 碰撞避免

**问题**:机械臂连杆之间不能互相碰撞,也不能与环境碰撞。

**方法 1:虚拟力场 (Potential Field)**

每个障碍物产生一个排斥力:

$$\boldsymbol{F}_{\text{rep}} = k \left(\frac{1}{d(\boldsymbol{q})} - \frac{1}{d_0}\right) \frac{1}{d(\boldsymbol{q})^2} \nabla d$$

其中 $d(\boldsymbol{q})$ 是机械臂到障碍物的距离,$d_0$ 是影响距离。

通过雅可比映射到关节空间:$\boldsymbol{\tau}_{\text{rep}} = J^\top \boldsymbol{F}_{\text{rep}}$。

**方法 2:采样避障 (Sampling-based)**

在关节速度空间随机采样,选择代价最小 (碰撞代价 + 任务代价) 的:

```python
def collision_aware_ik(x_dot, q, robot, obstacles, n_samples=100):
    J = robot.jacobian(q)
    q_dot_pinv = np.linalg.pinv(J) @ x_dot

    best_q_dot = q_dot_pinv
    best_cost = np.inf

    for _ in range(n_samples):
        # 零空间随机扰动
        q_dot_null = np.random.randn(robot.n)
        q_dot_null -= J.T @ np.linalg.lstsq(J, q_dot_null, rcond=None)[0]
        q_dot = q_dot_pinv + 0.1 * q_dot_null

        # 检查碰撞
        q_next = q + q_dot * 0.01
        cost = collision_cost(q_next, robot, obstacles)
        if cost < best_cost:
            best_cost = cost
            best_q_dot = q_dot

    return best_q_dot
```

### 6.3 闭链约束

**闭链 (Closed-chain)**:机械臂末端接触固定表面 (例如桌面),形成闭环约束。

**约束方程**:

$$\phi(\boldsymbol{q}) = \boldsymbol{p}_{ee}(\boldsymbol{q}) - \boldsymbol{p}_{\text{surface}} = 0$$

对时间求导:

$$\dot{\phi} = \frac{\partial \phi}{\partial \boldsymbol{q}} \dot{\boldsymbol{q}} = J_{\text{constraint}} \dot{\boldsymbol{q}} = 0$$

即 $J_{\text{constraint}} \dot{\boldsymbol{q}} = 0$——约束方向上的关节速度必须为 0。

**处理方法**:

1. **坐标缩减**:选独立关节 (例如 5 个),求解后算从动关节
2. **拉格朗日乘子**:约束力 $\lambda$ 通过 $\boldsymbol{\tau}_{\text{constraint}} = J_{\text{constraint}}^\top \lambda$ 加到动力学
3. **投影零空间**:解空间 = $\mathcal{N}(J_{\text{constraint}})$,所有解都满足约束

```python
"""
UR5 雅可比矩阵计算 + 奇异点分析
依赖: numpy, matplotlib (可选)
"""
import numpy as np

class UR5:
    """UR5 机械臂运动学模型"""

    # UR5 DH 参数 (标准 DH, 单位: 米)
    DH = [
        # [d,      a,     alpha,  theta_offset]
        [0.089159,  0.0,        np.pi/2,  0.0],
        [0.0,      -0.425,      0.0,      0.0],
        [0.0,      -0.39225,    0.0,      0.0],
        [0.10915,   0.0,        np.pi/2,  0.0],
        [0.09465,   0.0,       -np.pi/2,  0.0],
        [0.0823,    0.0,        0.0,      0.0],
    ]

    def __init__(self):
        self.n = 6

    def _dh_transform(self, d, a, alpha, theta):
        """DH 变换矩阵"""
        ct, st = np.cos(theta), np.sin(theta)
        ca, sa = np.cos(alpha), np.sin(alpha)
        return np.array([
            [ct, -st*ca,  st*sa, a*ct],
            [st,  ct*ca, -ct*sa, a*st],
            [0,   sa,     ca,    d   ],
            [0,   0,      0,     1   ]
        ])

    def fk(self, q):
        """正运动学,返回末端 4x4 变换矩阵"""
        T = np.eye(4)
        for i, (d, a, alpha, theta_off) in enumerate(self.DH):
            theta = q[i] + theta_off
            T = T @ self._dh_transform(d, a, alpha, theta)
        return T

    def jacobian(self, q):
        """
        几何雅可比 (世界坐标系)
        返回 6x6 矩阵,前 3 行星期速度,后 3 行角速度
        """
        # 累积每个关节的变换
        Ts = [np.eye(4)]  # T_0 = I
        T = np.eye(4)
        for i, (d, a, alpha, theta_off) in enumerate(self.DH):
            theta = q[i] + theta_off
            T = T @ self._dh_transform(d, a, alpha, theta)
            Ts.append(T.copy())

        # 末端位置
        p_ee = Ts[-1][:3, 3]

        # 雅可比每列
        J = np.zeros((6, self.n))
        for i in range(self.n):
            z_i = Ts[i][:3, 2]  # 第 i 关节 z 轴 (世界系)
            p_i = Ts[i][:3, 3]  # 第 i 关节原点 (世界系)
            J[:3, i] = np.cross(z_i, p_ee - p_i)  # 线速度
            J[3:, i] = z_i  # 角速度

        return J
```

### 7.3 DLS IK 实现 + 仿真

```python
import numpy as np

class DLSInverseKinematics:
    """DLS IK 求解器,带奇异点可视化"""

    def __init__(self, robot, dt=0.01, lam=0.01):
        self.robot = robot
        self.dt = dt
        self.lam = lam

    def step(self, q, x_desired):
        """一步 IK:当前关节角 q → 关节速度"""
        # 当前末端位姿
        T_current = self.robot.fk(q)
        p_current = T_current[:3, 3]

        # 末端速度 (PD 控制:追踪目标)
        position_error = x_desired - p_current
        K_p = 5.0  # 比例增益
        x_dot = K_p * position_error

        # 雅可比 (只取线速度部分)
        J = self.robot.jacobian(q)
        J_pos = J[:3, :]  # 3 x n

        # 自适应阻尼
        sigma = np.linalg.svd(J_pos, compute_uv=False)
        sigma_min = sigma[-1]
        lam_adaptive = self.lam if sigma_min > 0.01 else self.lam * (0.01 / (sigma_min + 1e-8))

        # DLS 解
        JJt = J_pos @ J_pos.T
        q_dot = J_pos.T @ np.linalg.solve(JJt + lam_adaptive**2 * np.eye(3), x_dot)

        return q_dot, lam_adaptive, sigma_min

    def track_trajectory(self, q_init, trajectory, n_steps):
        """
        跟踪给定轨迹 (list of 3D points)
        返回关节轨迹 + 诊断信息
        """
        q_traj = [q_init.copy()]
        diag = {'lam': [], 'sigma_min': [], 'q_dot_norm': []}

        q = q_init.copy()
        for step in range(n_steps):
            t = step * self.dt
            idx = min(int(t * 10), len(trajectory) - 1)  # 假设轨迹按 100Hz 采样
            x_d = trajectory[idx]

            q_dot, lam, sigma_min = self.step(q, x_d)

            # 积分 (欧拉法)
            q = q + q_dot * self.dt
            q_traj.append(q.copy())

            diag['lam'].append(lam)
            diag['sigma_min'].append(sigma_min)
            diag['q_dot_norm'].append(np.linalg.norm(q_dot))

        return np.array(q_traj), diag
```

### 7.4 雅可比 vs 数值微分验证

```python
def verify_jacobian(robot, q, eps=1e-6):
    """用有限差分验证雅可比"""
    J_analytic = robot.jacobian(q)
    J_numeric = np.zeros_like(J_analytic)

    for i in range(robot.n):
        q_plus = q.copy(); q_plus[i] += eps
        q_minus = q.copy(); q_minus[i] -= eps

        T_plus = robot.fk(q_plus)
        T_minus = robot.fk(q_minus)

        # 线速度列: ∂p/∂q_i ≈ (p+ - p-) / (2ε)
        J_numeric[:3, i] = (T_plus[:3, 3] - T_minus[:3, 3]) / (2 * eps)

        # 角速度列: 旋转矩阵差分 → 轴角
        R_plus = T_plus[:3, :3]
        R_minus = T_minus[:3, :3]
        R_diff = R_plus @ R_minus.T
        # 罗德里格斯公式
        trace = np.trace(R_diff)
        angle = np.arccos(np.clip((trace - 1) / 2, -1, 1))
        if angle < 1e-10:
            axis = np.zeros(3)
        else:
            axis = np.array([R_diff[2,1] - R_diff[1,2],
                             R_diff[0,2] - R_diff[2,0],
                             R_diff[1,0] - R_diff[0,1]]) / (2 * np.sin(angle))
        J_numeric[3:, i] = axis * angle / (2 * eps)

    error = np.linalg.norm(J_analytic - J_numeric)
    return error, J_analytic, J_numeric


# 测试
```

## 8. 与其他章节的关系

### 8.1 → 第 4 章 力控制 (阻抗与导纳)

**核心连接**:操作空间力控制直接用 $\boldsymbol{\tau} = J^\top \boldsymbol{F}$。

- **阻抗控制**:在末端系定义虚拟刚度 $K_x$ 和阻尼 $D_x$,产生参考力 $\boldsymbol{F} = K_x (\boldsymbol{x}_d - \boldsymbol{x}) + D_x (\dot{\boldsymbol{x}}_d - \dot{\boldsymbol{x}})$,然后 $\boldsymbol{\tau} = J^\top \boldsymbol{F}$。
- **导纳控制**:传感器测力 $\boldsymbol{F}_{\text{ext}}$,计算位置补偿 $\Delta \boldsymbol{x} = M_x^{-1} \boldsymbol{F}_{\text{ext}}$,再用 IK 反解关节角。

**本章提供**:雅可比矩阵计算、$\boldsymbol{\tau} = J^\top$ 公式、可操作度分析 (操作空间控制的稳定性边界)。

### 8.2 → 第 5 章 轨迹优化 (MPC)

**核心连接**:MPC 的"运动学约束" 就是 $\dot{\boldsymbol{x}} = J \dot{\boldsymbol{q}}$。

**MPC 形式**:

$$\begin{aligned}
\min_{\boldsymbol{q}_{0:T}, \boldsymbol{u}_{0:T-1}} \quad & \sum_{t=0}^{T-1} \|\boldsymbol{x}_t - \boldsymbol{x}_t^d\|_{Q}^2 + \|\boldsymbol{u}_t\|_{R}^2 \\
\text{s.t.} \quad & \boldsymbol{x}_{t+1} = \text{FK}(\boldsymbol{q}_{t+1}) \\
& \dot{\boldsymbol{q}}_t = \boldsymbol{u}_t \\
& \boldsymbol{q}_{\min} \leq \boldsymbol{q}_t \leq \boldsymbol{q}_{\max}
\end{aligned}$$

**雅可可比作用**:

1. **线性化约束**:$\dot{\boldsymbol{x}}_t \approx J(\boldsymbol{q}_t) \dot{\boldsymbol{q}}_t$ (避免非线性 FK)
2. **iLQG / DDP**:用 $J$ 算一阶泰勒展开,用 $\dot{J}$ 算二阶项
3. **末端约束**(例如"末端不能进入禁区"):$\boldsymbol{x}_t \notin \mathcal{X}_{\text{forbidden}}$,通过 $J$ 把"末端速度约束"投影到"关节速度约束"

**本章提供**:雅可比矩阵计算 + 时间导数 $\dot{J}$ + DLS 数值方法。

### 8.3 → 第 7 章 附录 (Pinocchio 与 Drake)

**核心连接**:Pinocchio 是工业级 C++/Python 库,直接暴露雅可比计算。

**对应 API**:

```python
# 本章的 FK = Pinocchio 的 forwardKinematics
pin.forwardKinematics(model, data, q)
p_ee = data.oMf[model.nq - 1].translation  # 末端位置

# 本章的可操作度 = Pinocchio + 公式计算
J = pin.computeJointJacobian(model, data, q, model.nq)
w = np.sqrt(np.linalg.det(J @ J.T))
```

**工业实践**:90% 的现代机器人栈 (Franka, Mujoco, Drake) 都用 Pinocchio 算雅可比。本章的"手动 DH 推导"主要是教学,生产代码直接调库。

### 8.4 → 第 2 章 动力学 (Lagrange / Newton-Euler)

**核心连接**:雅可比出现在动力学方程的**约束投影**部分。

**闭链动力学**:

$$M \ddot{\boldsymbol{q}} + C \dot{\boldsymbol{q}} + \boldsymbol{g} = \boldsymbol{\tau} + J_{\text{constraint}}^\top \lambda$$

其中 $J_{\text{constraint}}$ 是约束雅可比 (例如末端固定在桌面),$\lambda$ 是拉格朗日乘子 (约束力)。

**本章提供**:$J^\top$ 的物理意义 (虚功原理),直接用于第 2 章的约束动力学。

## 9. 与数学基础的关系

### 9.1 数学基础/2-线代/4-特征值·谱定理 ← SVD

**核心定理**:任何矩阵 $J \in \mathbb{R}^{m \times n}$ 都可以分解为 $J = U \Sigma V^\top$,其中 $U, V$ 是正交矩阵,$\Sigma$ 是对角矩阵 (奇异值)。

**应用**:

- **奇异点分析**:$\sigma_{\min}$ 衡量"距离奇异点的距离"
- **可操作度椭球**:主轴方向 = $\boldsymbol{u}_i$,长度 = $\sigma_i$
- **截断 SVD IK**:保留大奇异值,丢弃小奇异值,得到鲁棒解

**本章用到的具体内容**:

- $\Sigma$ 的对角线元素就是 $J^\top J$ 的特征值的平方根
- 矩阵 $J^\top J$ 的特征向量就是 $V$ 的列
- 当 $\sigma_{\min} = 0$ 时,$J$ 不可逆 (秩亏损)

### 9.2 数学基础/2-线代/1-向量·内积·范数

**应用**:

- **关节速度范数**:$\|\dot{\boldsymbol{q}}\|_2 = \sqrt{\sum_i \dot{q}_i^2}$ 衡量"关节运动量"
- **伪逆的最小范数性质**:$\dot{\boldsymbol{q}} = J^+ \dot{\boldsymbol{x}}$ 在所有解中范数最小
- **DLS 的目标函数**:$\|J \dot{\boldsymbol{q}} - \dot{\boldsymbol{x}}\|^2 + \lambda^2 \|\dot{\boldsymbol{q}}\|^2$

**本章用到的具体内容**:

- $\mathbb{R}^n$ 中的范数、投影、正交性
- 内积 $\langle \boldsymbol{a}, \boldsymbol{b} \rangle = \boldsymbol{a}^\top \boldsymbol{b}$ 用于推导 DLS
- 零空间 $\mathcal{N}(J) = \{\boldsymbol{q} : J \boldsymbol{q} = 0\}$

### 9.3 数学基础/1-高数/3-多元微分 ← 偏导数

**核心**:雅可比矩阵**就是**偏导数矩阵。

$$J(\boldsymbol{q}) = \frac{\partial \text{FK}(\boldsymbol{q})}{\partial \boldsymbol{q}} = \begin{bmatrix} \frac{\partial x_1}{\partial q_1} & \cdots & \frac{\partial x_1}{\partial q_n} \\ \vdots & \ddots & \vdots \\ \frac{\partial x_m}{\partial q_1} & \cdots & \frac{\partial x_m}{\partial q_n} \end{bmatrix}$$

**应用**:

- **链式法则**:$\frac{\partial \text{loss}}{\partial \boldsymbol{q}} = \left(\frac{\partial \text{FK}}{\partial \boldsymbol{q}}\right)^\top \frac{\partial \text{loss}}{\partial \boldsymbol{x}} = J^\top \frac{\partial \text{loss}}{\partial \boldsymbol{x}}$
- **自动微分**:PyTorch 的 `torch.autograd.grad` 直接算雅可比 (计算图视角)
- **梯度下降**:$\Delta \boldsymbol{q} = -\eta \nabla_{\boldsymbol{q}} \mathcal{L}(\boldsymbol{q})$ 在物理引擎中就是 $-\eta J^\top \nabla_{\boldsymbol{x}} \mathcal{L}$

### 9.4 数学基础/2-线代/3-矩阵分解 ← LU/Cholesky

**应用**:DLS 的核心是解线性方程组 $(J^\top J + \lambda^2 I) \dot{\boldsymbol{q}} = J^\top \dot{\boldsymbol{x}}$。

- $J^\top J$ 对称正定 → **Cholesky 分解**:$J^\top J + \lambda^2 I = L L^\top$,然后前向-后向替换
- 比 LU 快 ~2x,是工业代码首选
- NumPy: `scipy.linalg.solve(J.T @ J + lam**2 * np.eye(n), J.T @ x_dot)` 内部自动选 Cholesky

### 9.5 数学基础/3-概率论/2-多元高斯 ← 椭球分布

**应用**:可操作度椭球的**概率解释**:

如果关节速度 $\dot{\boldsymbol{q}} \sim \mathcal{N}(\boldsymbol{0}, \Sigma_q)$,那末端速度 $\dot{\boldsymbol{x}} = J \dot{\boldsymbol{q}}$ 也是高斯:

$$\dot{\boldsymbol{x}} \sim \mathcal{N}(\boldsymbol{0}, J \Sigma_q J^\top)$$

等概率密度面是椭球,主轴方向 = $\boldsymbol{u}_i$ ($J$ 的左奇异向量),长度 = $\sqrt{\lambda_i}$ ($\Sigma_x$ 的特征值)。

如果 $\Sigma_q = I$ (各关节独立等方差),末端椭球主轴长度 = $\sigma_i$ ($J$ 的奇异值)。

**意义**:可操作度椭球可以理解为"末端速度的概率分布等高线"——这就是 Yoshikawa $w$ 与**信息论指标**之间的桥梁。

## 10. 常见误区

### 10.1 "雅可比总是方阵"

**误区**:很多新人以为 $J$ 一定是 $n \times n$ (跟机械臂 DOF 相同)。

**事实**:

- 6 DOF 机械臂:$J \in \mathbb{R}^{6 \times 6}$ (方阵)
- 7 DOF Franka:$J \in \mathbb{R}^{6 \times 7}$ (欠定,行数 < 列数)
- 4 DOF SCARA + 末端 3D 位置:$J \in \mathbb{R}^{3 \times 4}$ (欠定)
- 6 DOF + 末端 3D 位置 + 1D 姿态:$J \in \mathbb{R}^{4 \times 6}$ (超定,行数 > 列数)
- 末端只关心位置:$J \in \mathbb{R}^{3 \times 6}$ (欠定)

**核心**:雅可比的行数 = 任务空间维数 (你想控制几个方向),列数 = 关节数。

### 10.2 "伪逆是万能的"

**误区**:"反正 IK 解不出来就用伪逆,准没错。"

**事实**:伪逆在奇异点附近**数值爆炸**:

```python
J = np.array([[1, 0], [0, 1e-10]])  # 几乎奇异
J_pinv = np.linalg.pinv(J)
print(J_pinv @ np.array([1e-3, 0]))  # 输出 [1e-3, 1e7] ← 爆炸!
```

**正确做法**:

1. 加阻尼项 (DLS)
2. 检查最小奇异值,接近 0 时切换策略
3. 用截断 SVD 替代全 SVD

### 10.3 "奇异点只在边界"

**误区**:奇异只在"机械臂完全伸直"或"完全折叠"时出现。

**事实**:奇异**在构型空间内是一个 5 维超曲面** (6 DOF 机器人的 $\det J = 0$ 是 1 个代数方程,描述 5 维流形),任何沿这个曲面的构型都是奇异。

**实例**:

- UR5 腕对齐:**所有**满足 $q_5 = 0$ 的构型都奇异 (3 维子空间)
- UR5 边界伸直:特定角度组合 (2 维子空间)
- 共面奇异:某些连续角度组合 (4 维子空间)

**工业教训**:UR5 的工作空间内有**连续区域**是奇异的,不只是离散的"边界点"。

### 10.4 "几何雅可比 = 解析雅可比"

**误区**:这两个名字的雅可比是同一个东西。

**事实**:当姿态用**四元数**或**旋转矩阵**表示时,数值上相等;但用**欧拉角**表示时,**后 3 行不同**:

$$J_{\text{ana}} = \begin{bmatrix} I & 0 \\ 0 & T(\boldsymbol{\phi}) \end{bmatrix} J_{\text{geo}}$$

其中 $T(\boldsymbol{\phi})$ 是欧拉角到角速度的变换矩阵,万向锁附近 $T$ 奇异。

**工程含义**:Pinocchio / Drake 默认输出**几何雅可比**,因为它对欧拉奇异**免疫**。

### 10.5 "可操作度越大越好"

**误区**:选可操作度 $w$ 大的构型,机器人一定"更灵活"。

**事实**:$w$ 是**体积度量**,不是**形状度量**——椭球"狭长但体积大"也可能 $w$ 大,但实际某些方向机动性差。

**更好的指标**:

- **条件数**$\kappa = \sigma_{\max} / \sigma_{\min}$:越小越"各向同性"
- **最小奇异值**$\sigma_{\min}$:越小越接近奇异
- **各向同性点** ($\kappa = 1$):椭球是球形,所有方向等灵活

**FRANKA 的特殊构型**:Franka 的"中间肘部位置" 是各向同性点,所有方向同等灵活。

### 10.6 "操作空间控制一定优于关节空间"

**误区**:操作空间直观,所以一定好。

**事实**:

| 框架 | 适用场景 | 不适用场景 |
| :--- | :--- | :--- |
| **操作空间** | 末端任务 (画画、抓取) | 多关节协同 (双足、灵巧手) |
| **关节空间** | 多关节优化 (跳跃、跑) | 末端精度任务 |

**反例**:人形机器人跑步,**操作空间控制完全错**——它需要关节空间的协调,而不是末端轨迹。

### 10.7 "雅可比用一次算一次"

**误区**:每次需要雅可比都重新算 (O(n) 计算)。

**事实**:

- **缓存**:如果 $J$ 在前向运动学之后计算, $J$ 可以**几乎免费**获得 (递推已经算过每个 $T_i$)
- **增量更新**:$\boldsymbol{q}$ 变化很小时, $\Delta J \approx \sum_i (\partial J / \partial q_i) \Delta q_i$
- **有限差分**:$\dot{J} \approx (J(\boldsymbol{q} + \Delta \boldsymbol{q}) - J(\boldsymbol{q})) / \Delta t$,一次正运动学调用即可

**工业实践**:1000 Hz 控制循环里,**每帧都算雅可比** (Pinocchio 1 ms 内算完),不缓存。

### 10.8 "雅可比=Jacobian 在数学里的定义"

**误区**:雅可比是机器人学特殊概念。

**事实**:**数学里 Jacobian 就是偏导数矩阵**——任何从 $\mathbb{R}^n$ 到 $\mathbb{R}^m$ 的可微函数 $f$ 都有雅可比 $J_f = \partial f / \partial x$。

机器人学的"雅可比" 只是 $J_{\text{FK}}$ 在 $\boldsymbol{q}$ 处求值——同一个数学对象在不同领域扮演不同角色 (深度学习里是梯度反向传播,机器人里是速度映射)。

## 11. L7/L8 面试 Q&A

### Q1: 雅可比矩阵的几何意义是什么?

**答案**:

雅可比矩阵 $J(\boldsymbol{q}) \in \mathbb{R}^{m \times n}$ 是 $\text{FK}$ 函数在 $\boldsymbol{q}$ 处的偏导数矩阵,**几何上是关节速度空间到末端速度空间的线性映射**。

具体来说:

- **每列 $J[:, i]$** 是旋量 (twist),描述"只动第 $i$ 个关节时末端的瞬时线速度 + 角速度"
- **每行 $J[i, :]$** 描述"末端第 $i$ 个方向速度对每个关节速度的敏感度"
- **$\text{rank}(J)$** 等于当前构型下能独立控制的末端方向数
- **$\sigma_{\min}(J)$** 衡量"距离奇异点的距离"

**面试加分**:提到"雅可比 = 偏导数矩阵 = 同一数学对象在机器人里扮演速度映射角色,深度学习里扮演梯度反向传播角色"。

### Q2: 几何雅可比 vs 解析雅可比的区别?

**答案**:

两者在姿态用四元数或旋转矩阵表示时数值相等,用欧拉角表示时**最后 3 行不同**:

$$J_{\text{analytic}} = \begin{bmatrix} I & 0 \\ 0 & T(\boldsymbol{\phi}) \end{bmatrix} J_{\text{geometric}}$$

- **几何雅可比**:后 3 行是末端**角速度** $\boldsymbol{\omega}$ (3 维向量),万向锁处无奇异
- **解析雅可比**:后 3 行是欧拉角**变化率** $(\dot{\phi}, \dot{\theta}, \dot{\psi})$,万向锁处 $T(\boldsymbol{\phi})$ 奇异

**工程上**:工业库 (Pinocchio, Drake, MuJoCo) 默认输出几何雅可比,因为它**对所有姿态参数化都数值稳定**。

**面试加分**:知道"解析雅可比 = 几何雅可比 × 欧拉角变换矩阵",知道万向锁影响。

### Q3: 奇异点怎么处理?

**答案**:

4 种主流方法,从简单到复杂:

1. **DLS (阻尼最小二乘)**:

$$\dot{\boldsymbol{q}} = J^\top (J J^\top + \lambda^2 I)^{-1} \dot{\boldsymbol{x}}$$

奇异点附近 $\sigma_{\min} \to 0$,但 $\lambda^2 I$ 阻止 $J J^\top$ 不可逆,自动降速。简单,工业首选。

2. **截断 SVD**:

$$J = U \Sigma V^\top, \quad \tilde{\Sigma}^{-1}_{ii} = \begin{cases} 1/\sigma_i & \sigma_i > \epsilon \\ 0 & \sigma_i \leq \epsilon \end{cases}$$

奇异方向直接丢弃,精确但不平滑。

3. **可操作度梯度避奇异**:在零空间加 $\dot{\boldsymbol{q}}_0 = k \nabla w(\boldsymbol{q})$,主动远离奇异。

4. **任务优先级 / QP**:多约束二次规划,关节限位、避障、奇异避让协同处理。

**面试加分**:能解释 DLS 为什么"自动降速" (阻尼项 $\lambda^2 I$ 在 $\sigma_{\min} \to 0$ 时主导),能说出可操作度 $w = \sqrt{\det(J J^\top)}$ 的物理意义。

### Q4: DLS 的物理直觉是什么?

**答案**:

DLS 的目标函数:

$$\min_{\dot{\boldsymbol{q}}} \|J \dot{\boldsymbol{q}} - \dot{\boldsymbol{x}}\|^2 + \lambda^2 \|\dot{\boldsymbol{q}}\|^2$$

"既让末端速度接近期望,又让关节速度小"——两个目标的权衡,$\lambda$ 控制权重。

**奇异点附近**:

- **精确解** $\dot{\boldsymbol{q}} = J^+ \dot{\boldsymbol{x}}$ 让第一个目标为 0,但 $\sigma_{\min} \to 0$ 时 $\|\dot{\boldsymbol{q}}\| \to \infty$ (关节速度爆炸)
- **DLS 解** 牺牲一点末端精度 ($\|J \dot{\boldsymbol{q}} - \dot{\boldsymbol{x}}\|^2 > 0$),换取 $\|\dot{\boldsymbol{q}}\|$ 有界

直观类比:**DLS 像汽车的"限速"**——奇异点附近"路不好走",DLS 自动限速,保证安全通过。

**面试加分**:能写出 DLS 的展开形式,能解释 $\lambda$ 怎么影响"末端精度 vs 关节速度",能提到**自适应 $\lambda$** (Wampler)。

### Q5: 操作空间控制的工业应用?

**答案**:

3 个典型工业场景:

1. **力控装配 (KUKA, ABB)**:汽车装配中,机器人需要在指定方向施加精确力。操作空间力控制直接定义"末端坐标系" 的虚拟刚度 $K_x$,然后 $\boldsymbol{\tau} = J^\top (K_x (\boldsymbol{x}_d - \boldsymbol{x}) + D_x (\dot{\boldsymbol{x}}_d - \dot{\boldsymbol{x}}))$。

2. **视觉伺服 (Cognex, Keyence)**:相机反馈给出"末端应该到哪",直接转操作空间速度指令,用 DLS IK 解关节速度。

3. **协作机器人 (UR5, Franka)**:协作机器人需要"软接触",阻抗控制在末端系定义,自然处理碰撞。

**反例**:人形机器人跑步、双臂协同**不适合**操作空间——它们需要关节空间全局协调。

**面试加分**:能列出 2-3 个真实工业案例 (KUKA, Franka, UR),能说出"为什么操作空间直观但不是万能"。

### Q6: 雅可比和 Hessian 的关系?

**答案**:

雅可比 $J = \partial f / \partial \boldsymbol{x}$ 是一阶偏导数矩阵,Hessian $H = \partial^2 f / \partial \boldsymbol{x}^2$ 是二阶偏导数张量。

机器人里的对应:

- **一阶微分运动学**:$\dot{\boldsymbol{x}} = J \dot{\boldsymbol{q}}$ (雅可比)
- **二阶微分运动学**:$\ddot{\boldsymbol{x}} = J \ddot{\boldsymbol{q}} + \dot{J} \dot{\boldsymbol{q}}$ (含 $\dot{J}$)

$\dot{J}$ 的计算需要**对 $J$ 求偏导**,本质是 $\partial^2 \text{FK} / \partial \boldsymbol{q}^2$。

**应用**:加速度控制、前馈补偿、导纳控制需要 $\dot{J}$。

**面试加分**:能解释 $\dot{J}$ 的物理意义 (末端的"科氏加速度"),知道它出现在动力学方程中。

### Q7: 7 DOF 机械臂的零空间运动有什么用?

**答案**:

7 DOF 机械臂 (Franka, Kinova) 比 6 DOF 多 1 个自由度,**冗余**——任务空间 (6 维) < 关节空间 (7 维),方程 $J \dot{\boldsymbol{q}} = \dot{\boldsymbol{x}}$ 有**无穷多解**。

零空间 $\mathcal{N}(J)$ 是 $J$ 的零空间,即满足 $J \boldsymbol{v} = 0$ 的所有 $\boldsymbol{v}$。

零空间运动**不影响末端**:

$$\dot{\boldsymbol{q}} = \underbrace{J^+ \dot{\boldsymbol{x}}}_{\text{任务}} + \underbrace{(I - J^+ J) \dot{\boldsymbol{q}}_0}_{\text{零空间}}$$

第二个项 $(I - J^+ J) \dot{\boldsymbol{q}}_0$ 投影到零空间,末端速度不变,但关节配置变化。

**应用**:

1. **避奇异**:$\dot{\boldsymbol{q}}_0 = k \nabla w(\boldsymbol{q})$,主动增大可操作度
2. **避关节限位**:$\dot{\boldsymbol{q}}_0 = -\nabla h(\boldsymbol{q})$,$h$ 是关节限位代价
3. **避障**:$\dot{\boldsymbol{q}}_0 = -\nabla d(\boldsymbol{q})$,远离障碍物
4. **能耗优化**:$\dot{\boldsymbol{q}}_0 = -\nabla \boldsymbol{\tau}^\top \dot{\boldsymbol{q}}$,最小化力矩

**面试加分**:能写出零空间投影算子 $(I - J^+ J)$,能给出至少 2 个零空间次级任务的例子。

### 核心公式

| 名称 | 公式 | 物理意义 |
| :--- | :--- | :--- |
| 速度映射 | $\dot{\boldsymbol{x}} = J \dot{\boldsymbol{q}}$ | 关节速度 → 末端速度 |
| 力映射 | $\boldsymbol{\tau} = J^\top \boldsymbol{F}$ | 末端力 → 关节力矩 |
| 伪逆 IK | $\dot{\boldsymbol{q}} = J^+ \dot{\boldsymbol{x}}$ | 最小范数解 |
| DLS IK | $\dot{\boldsymbol{q}} = J^\top (J J^\top + \lambda^2 I)^{-1} \dot{\boldsymbol{x}}$ | 阻尼最小二乘 |

## 13. 雅可比结构的 ASCII 图解

### 13.1 雅可比矩阵的视觉分解

雅可比矩阵 $J \in \mathbb{R}^{6 \times n}$ 的**每一列**是旋量,**每一行**是任务方向。

```text
雅可比矩阵 J (6 x n) 的物理结构:

        joint 1   joint 2  ...  joint n
        ───────   ───────       ───────
linear  │ z_1×r_1 │ z_2×r_2 │...│ z_n×r_n │  ← 线速度 (3 维)
angular │   z_1   │   z_2   │...│   z_n   │  ← 角速度 (3 维)
        ───────   ───────       ───────

符号说明:
  z_i = 第 i 关节旋转轴 (世界系)
  r_i = p_ee - p_i (末端 - 第 i 关节原点)
  z_i × r_i = 叉乘,产生该关节对末端的线速度贡献
```

### 13.3 SVD 分解的几何视图

SVD $J = U \Sigma V^\top$ 把雅可比拆成"旋转-缩放-旋转"三步:

```text
Step 1: 关节速度 q̇ ∈ ℝⁿ → V^T → 主轴坐标 q̇' = V^T q̇
Step 2: q̇' ∈ ℝⁿ → Σ → 中间坐标 ẋ' = Σ q̇'
Step 3: ẋ' ∈ ℝᵐ → U → 末端速度 ẋ = U ẋ'

完整公式: ẋ = U Σ V^T q̇

物理直觉:
- V 的列 = 关节空间的"自然运动方向"(零空间正交基)
- U 的列 = 末端空间的"自然运动方向"(任务空间正交基)
- Σ = 两个自然坐标系之间的缩放因子
```

### 14.1 为什么用 PyTorch 自动微分算雅可比?

传统 DH 推导 + 叉乘公式虽然清晰,但有两个局限:

1. **重写繁琐**:换机器人需要重新写 DH 参数表和递推公式
2. **$\dot{J}$ 难求**:对 $J$ 求偏导需要二阶微分,手写痛苦

PyTorch 自动微分 (autograd) 直接绕开这两个问题:

- **FK 写成可微函数**:`p_ee = f(q)`,自动得到 $J = \partial f / \partial q$
- **二阶微分**:`grad(grad(f, q), q)` 直接得到 Hessian
- **GPU 加速**:批量构型并行算雅可比

### 14.2 PyTorch 雅可比实现 (通用版)

```python
import torch
import numpy as np

class UR5Torch:
    """UR5 + PyTorch autograd 雅可比"""
    DH = torch.tensor([
        [0.089159, 0.0, np.pi/2, 0.0],
        [0.0, -0.425, 0.0, 0.0],
        [0.0, -0.39225, 0.0, 0.0],
        [0.10915, 0.0, np.pi/2, 0.0],
        [0.09465, 0.0, -np.pi/2, 0.0],
        [0.0823, 0.0, 0.0, 0.0],
    ])

    def __init__(self, device='cpu'):
        self.n = 6
        self.device = device

    def _dh_transform(self, d, a, alpha, theta):
        ct, st = torch.cos(theta), torch.sin(theta)
        ca, sa = torch.cos(alpha), torch.sin(alpha)
        return torch.stack([
            torch.stack([ct, -st*ca, st*sa, a*ct]),
            torch.stack([st, ct*ca, -ct*sa, a*st]),
            torch.stack([torch.zeros_like(ct), sa, ca, d]),
            torch.stack([torch.zeros_like(ct), torch.zeros_like(ct),
                         torch.zeros_like(ct), torch.ones_like(ct)])
        ])

    def fk(self, q):
        q = q.to(self.device)
        T = torch.eye(4, device=self.device)
        for i in range(self.n):
            d, a, alpha, theta_off = self.DH[i].to(self.device)
            T = T @ self._dh_transform(d, a, alpha, q[i] + theta_off)
        return T[:3, 3]

    def jacobian_autograd(self, q):
        """用 autograd 计算雅可比 (线速度部分 3 x n)"""
        q = q.detach().clone().requires_grad_(True).to(self.device)
        p_ee = self.fk(q)
        J = torch.zeros(3, self.n, device=self.device)
        for i in range(3):
            grad_outputs = torch.zeros(3, device=self.device)
            grad_outputs[i] = 1.0
            grad = torch.autograd.grad(outputs=p_ee, inputs=q,
                                       grad_outputs=grad_outputs,
                                       retain_graph=True)[0]
            J[i] = grad
        return J

    def jacobian_full(self, q):
        """完整雅可比 (6 x n),含角速度部分 (几何递推)"""
        q = q.to(self.device)
        Ts = [torch.eye(4, device=self.device)]
        T = torch.eye(4, device=self.device)
        for i in range(self.n):
            d, a, alpha, theta_off = self.DH[i].to(self.device)
            T = T @ self._dh_transform(d, a, alpha, q[i] + theta_off)
            Ts.append(T.clone())
        p_ee = Ts[-1][:3, 3]
        J = torch.zeros(6, self.n, device=self.device)
        for i in range(self.n):
            z_i = Ts[i][:3, 2]
            p_i = Ts[i][:3, 3]
            J[:3, i] = torch.cross(z_i, p_ee - p_i)
            J[3:, i] = z_i
        return J


# 测试对比
```

```python
def jacobian_dot_simple(robot, q, q_dot, eps=1e-6):
    """
    有限差分计算 J̇

    公式: ẋ = J q̇
         ẍ = J q̈ + J̇ q̇
    其中 J̇ ≈ (J(q + q̇·ε) - J(q)) / ε
    """
    q = q.detach()
    J_curr = robot.jacobian_full(q)
    J_next = robot.jacobian_full(q + q_dot * eps)
    return (J_next - J_curr) / eps
```

### 15.1 完整 PyTorch IK 求解器

```python
import torch, numpy as np

class TorchIKSolver:
    """PyTorch IK 求解器: DLS + 自适应阻尼"""

    def __init__(self, robot, device='cpu', dt=0.01, lam=0.01):
        self.robot = robot
        self.device = device
        self.dt = dt
        self.lam = lam
        self.lam_max = 1.0

    def step(self, q, x_desired):
        """单步 IK:返回关节速度 q_dot + 诊断"""
        q = q.to(self.device).requires_grad_(False)
        x_desired = x_desired.to(self.device)
        x_current = self.robot.fk(q).detach()
        K_p = 5.0
        position_error = x_desired - x_current
        x_dot = K_p * position_error
        J = self.robot.jacobian_autograd(q)
        sigma_min = torch.linalg.svdvals(J)[-1].item()
        lam_adaptive = (min(self.lam * (0.01 / (sigma_min + 1e-10)), self.lam_max)
                        if sigma_min < 0.01 else self.lam)
        JJt = J @ J.T
        q_dot = J.T @ torch.linalg.solve(JJt + lam_adaptive**2 * torch.eye(3, device=self.device), x_dot)
        info = {'lam': lam_adaptive, 'sigma_min': sigma_min,
                'position_error': position_error.norm().item()}
        return q_dot.detach(), info

    def solve(self, q_init, x_target, max_steps=500, tol=1e-4):
        """迭代求解 IK,返回 q_sol 和 history"""
        q = q_init.clone().to(self.device)
        history = {'q_dot_norms': [], 'errors': [], 'lams': [], 'sigmas': []}
        for step in range(max_steps):
            q_dot, info = self.step(q, x_target)
            q = q + q_dot * self.dt
            history['q_dot_norms'].append(q_dot.norm().item())
            history['errors'].append(info['position_error'])
            history['lams'].append(info['lam'])
            history['sigmas'].append(info['sigma_min'])
            if info['position_error'] < tol:
                print(f"收敛:步数 {step+1}, 误差 {info['position_error']:.2e}")
                return q, history
        print(f"未收敛:误差 {info['position_error']:.2e}")
        return q, history


# 测试:UR5 跟踪空间目标
robot_torch = UR5Torch(device='cpu')
solver = TorchIKSolver(robot_torch, dt=0.05, lam=0.01)
q_init = torch.tensor([0.0, -np.pi/4, np.pi/2, 0.0, np.pi/4, 0.0])
x_target = torch.tensor([0.4, 0.2, 0.3])
q_sol, hist = solver.solve(q_init, x_target, max_steps=300)
x_achieved = robot_torch.fk(q_sol).detach().numpy()
print(f"误差: {np.linalg.norm(x_target.numpy() - x_achieved):.2e}")
print(f"最大关节速度: {max(hist['q_dot_norms']):.2f} rad/s")
```

### 15.2 批量 IK 求解 (GPU 加速)

```python
def batch_ik_solve(robot, q_init_batch, x_target_batch, max_steps=200, dt=0.05, lam=0.01):
    """批量 IK 求解 (GPU 加速)。输入: (B, n), (B, 3)。返回: (B, n)"""
    q = q_init_batch.clone()
    for step in range(max_steps):
        x_current = robot.fk_batch(q)
        error = x_target_batch - x_current
        J = robot.jacobian_batch(q)
        sigma_min = torch.linalg.svdvals(J)[:, -1]
        lam_adaptive = torch.where(sigma_min < 0.01,
                                    torch.clamp(lam * 0.01 / (sigma_min + 1e-10), max=1.0),
                                    torch.full_like(sigma_min, lam))
        JJt = torch.einsum('bij,bik->bjk', J, J)
        lam_diag = (lam_adaptive ** 2).view(-1, 1, 1)
        eye = torch.eye(3, device=q.device).unsqueeze(0)
        JJt_reg = JJt + lam_diag * eye
        x_dot = 5.0 * error
        q_dot = torch.einsum('bji,bj->bi', J,
                             torch.linalg.solve(JJt_reg, x_dot.unsqueeze(-1)).squeeze(-1))
        q = q + q_dot * dt
        if torch.all(error.norm(dim=-1) < 1e-4):
            break
    return q
```

### 15.3 求解器在视觉伺服中的应用

```python
class VisualServoController:
    """基于视觉伺服的实时 IK 控制"""

    def __init__(self, robot, K_p=2.0, K_d=0.5):
        self.robot = robot
        self.K_p = K_p
        self.K_d = K_d
        self.prev_error = None

    def compute_control(self, q, x_target):
        """计算关节速度 (含 PD 项)"""
        x_current = self.robot.fk(q).detach()
        error = x_target - x_current
        if self.prev_error is None:
            self.prev_error = error
        error_dot = (error - self.prev_error) / 0.01

        x_dot = self.K_p * error + self.K_d * error_dot
        J = self.robot.jacobian_autograd(q)
        sigma_min = torch.linalg.svdvals(J)[-1].item()
        lam = 0.05 if sigma_min < 0.05 else 0.01

        JJt = J @ J.T
        q_dot_cmd = J.T @ torch.linalg.solve(JJt + lam**2 * torch.eye(3), x_dot)
        self.prev_error = error
        return q_dot_cmd.detach()
```

### 16.3 工业案例 1:UR5 协作机器人的 IK 实现

```python
class UR5_DLS_IK:
    """UR5 的 DLS IK"""

    def __init__(self):
        self.lam_default = 0.01
        self.lam_max = 0.5
        self.sigma_threshold = 0.001

    def ik_step(self, q, x_target, dt=0.008):

        x_current = self._fk_position(q)
        J = self._jacobian(q)
        sigma_min = np.linalg.svd(J, compute_uv=False)[-1]
        lam = (self.lam_max if sigma_min < self.sigma_threshold
               else min(self.lam_default * (0.01 / sigma_min), self.lam_max)
               if sigma_min < 0.01 else self.lam_default)
        q_dot = J.T @ np.linalg.solve(J @ J.T + lam**2 * np.eye(6), (x_target - x_current) / dt)
        q_dot = np.clip(q_dot, -2.0, 2.0)  # 速度限位
        return np.clip(q + q_dot * dt, -np.pi, np.pi)  # 关节限位
```

**核心思想**:**DLS + 自适应阻尼 + 速度限位 + 关节限位**。

### 16.4 工业案例 2:Franka 的零空间 IK

Franka 7 DOF 机械臂需要**零空间投影**才能保证末端精度:

```python
class FrankaNullSpaceIK:
    """Franka 7 DOF 的零空间 IK"""

    def __init__(self):
        self.n = 7
        self.lam = 0.05

    def ik_step_with_nullspace(self, q, x_target, q_null_target):
        """IK + 零空间运动, q_null_target: 期望的"姿态偏好" (例如肘部角度)"""
        J = self._jacobian(q)
        x_dot = (x_target - self._fk_position(q)) / 0.01
        JJt = J @ J.T
        q_dot_task = J.T @ np.linalg.solve(JJt + self.lam**2 * np.eye(6), x_dot)
        # 零空间次级任务: 让肘部接近 q_null_target
        q_null_dot = 1.0 * (q_null_target - q[3])  # Franka 关节 4 是肘部
        J_pinv = J.T @ np.linalg.inv(JJt + self.lam**2 * np.eye(6))
        null_proj = np.eye(7) - J_pinv @ J
        q_dot_null = null_proj @ np.array([0, 0, 0, q_null_dot, 0, 0, 0])
        return q + (q_dot_task + q_dot_null) * 0.01
```

**Franka 的特殊性**:7 DOF 比 6 DOF 多一个自由度,这个自由度**完全不影响末端**——可以拿来做姿态优化。

```python
import ikfast_ur5  # IKFast 生成的模块
import numpy as np

def ikfast_solve(p_ee, R_ee, q_init=None):
    """
    用 IKFast 解 UR5 IK
    返回多个解 (最多 16 个,UR5 通常 8 个)
    """
    p_flat = p_ee.flatten().tolist()
    R_flat = R_ee.flatten().tolist()

    sols_flat = ikfast_ur5.get_ik(p_flat + R_flat)
    if sols_flat is None or len(sols_flat) == 0:
        return []

    n_solutions = len(sols_flat) // 6
    solutions = [sols_flat[i*6:(i+1)*6] for i in range(n_solutions)]

    # 如果有初始关节角,选距离最近的解
    if q_init is not None:
        distances = [np.linalg.norm(s - q_init) for s in solutions]
        best_idx = np.argmin(distances)
        return [solutions[best_idx]] + [s for i, s in enumerate(solutions) if i != best_idx]
    return solutions
```

```python
def bullet_ik_step(robot_id, end_effector_idx, target_pos, target_orn, q_current):
    """PyBullet IK 的内部逻辑简化"""
    p.resetJointStates(robot_id, range(num_joints), q_current)
    current_state = p.getLinkState(robot_id, end_effector_idx)
    p_current = np.array(current_state[0])
    p_err = np.array(target_pos) - p_current
    x_err = np.concatenate([p_err, np.zeros(3)])  # 简化

    J = p.calculateJacobian(robot_id, end_effector_idx, [0, 0, 0],
                           list(q_current), [0]*num_joints, [0]*num_joints)
    lam = 0.01
    J_full = np.vstack(J)
    JJt = J_full @ J_full.T
    q_dot = J_full.T @ np.linalg.solve(JJt + lam**2 * np.eye(6), x_err)
```

## 20. 进阶 L7/L8 面试 Q&A

### Q8: 雅可比矩阵的时间导数 $\dot{J}$ 怎么算?

**答案**:

$\dot{J}$ 是二阶微分运动学的核心: $\ddot{\boldsymbol{x}} = J \ddot{\boldsymbol{q}} + \dot{J} \dot{\boldsymbol{q}}$。

物理意义:**末端加速度 = 雅可比 × 关节加速度 + 雅可比变化率 × 关节速度**。

**3 种计算方法**:

1. **解析法** (最精确,最慢): $\dot{J}_{ij} = \sum_{k=1}^n \frac{\partial^2 \text{FK}_i}{\partial q_j \partial q_k} \dot{q}_k$
2. **有限差分** (工程首选): $\dot{J} \approx \frac{J(\boldsymbol{q} + \epsilon \dot{\boldsymbol{q}}) - J(\boldsymbol{q})}{\epsilon}$, $\epsilon \sim 10^{-7}$
3. **自动微分** (PyTorch):

```python
q = q.detach().requires_grad_(True)
J = compute_jacobian(q)
J_dot = torch.autograd.grad(J.sum(), q, create_graph=True)[0] @ q_dot
```

**应用**:加速度控制、导纳控制、动力学前馈。

### Q9: SVD 截断 (Truncated SVD) vs DLS 怎么选?

**答案**:

**SVD 截断**:

```python
U, sigma, Vt = np.linalg.svd(J)
sigma_inv = np.where(sigma > eps, 1/sigma, 0)
J_pinv = Vt.T @ np.diag(sigma_inv) @ U.T
```

**保留能动的方向,丢弃不能动的**——奇异方向直接归零。

**DLS**:

```python
J_dls = J.T @ np.linalg.inv(J @ J.T + lam**2 * np.eye(6))
```

**所有方向都保留,但奇异方向被"软化"**——阻尼项阻止矩阵不可逆。

**对比**:

| | SVD 截断 | DLS |
| :--- | :--- | :--- |
| **奇异方向** | 完全丢弃 (速度 0) | 速度降低但不归零 |
| **连续性** | 不连续 ($\sigma = \epsilon$ 切换) | 连续可微 |
| **参数敏感性** | $\epsilon$ 必须严格选 | $\lambda$ 容错性高 |
| **工业首选** | 离线分析 | 实时控制 |

**实际案例**:UR 用 DLS ($\lambda = 0.01$);KUKA 用 SVD 截断 ($\epsilon = 10^{-4}$)。

### Q10: 雅可比矩阵在 MPC 里怎么用?

**答案**:

MPC 的核心:

$$\begin{aligned}
\min \quad & \sum_{t=0}^{T-1} \|\boldsymbol{x}_t - \boldsymbol{x}_t^d\|_Q^2 + \|\boldsymbol{u}_t\|_R^2 \\
\text{s.t.} \quad & \dot{\boldsymbol{x}}_t = J(\boldsymbol{q}_t) \dot{\boldsymbol{q}}_t \\
& \boldsymbol{q}_{\min} \leq \boldsymbol{q}_t \leq \boldsymbol{q}_{\max}
\end{aligned}$$

**雅可比的 4 个作用**:

1. **线性化运动学约束**:避免直接用非线性 $\text{FK}$
2. **末端约束投影**:把"末端禁区约束"转为"关节速度约束"
3. **可达性分析**:$J J^\top$ 的特征值决定任务空间每个方向的"代价权重"
4. **iLQG / DDP**:用 $J$ 算一阶,用 $\dot{J}$ 算二阶

**实例**:机械臂避障 MPC

```python
for t in range(T_horizon):
    p_ee = fk(q_pred[t])
    d_obs = p_ee - obstacle_pos
    d_norm = np.linalg.norm(d_obs)
    if d_norm < safe_distance:
        v_avoid = d_obs / d_norm
        constraint = v_avoid @ J(q_pred[t]) @ q_dot[t] >= v_min
        mpc_constraints.append(constraint)
```

### Q11: 操作空间控制 (OSC) 和关节空间阻抗控制有什么区别?

**答案**:

**OSC**: $\ddot{\boldsymbol{x}}_d = \Lambda_x^{-1} (\boldsymbol{F}_{\text{task}} - \mu_x \dot{\boldsymbol{x}}) + \dot{J} \dot{\boldsymbol{q}} - J M^{-1} C \dot{\boldsymbol{q}}$ (直接控制末端加速度)

**关节空间阻抗**: $\boldsymbol{\tau} = M (\ddot{\boldsymbol{q}}_d + K_p (\boldsymbol{q}_d - \boldsymbol{q}) + K_d (\dot{\boldsymbol{q}}_d - \dot{\boldsymbol{q}}))$ (控制关节力矩)

**核心区别**:

| | OSC | 关节空间阻抗 |
| :--- | :--- | :--- |
| **控制变量** | 末端加速度 | 关节力矩 |
| **任务描述** | 直观 (末端目标) | 间接 (关节目标) |
| **计算成本** | 高 ($M_x$, $J^\top$) | 低 |
| **奇异点** | 需要 DLS 处理 | 自然处理 |

**什么时候用**:
- **OSC**:末端任务 (画画、抓取、力控装配)
- **关节空间**:关节协同 (跑步、跳跃、双臂协作)

### Q12: 基于学习的 IK (Neural IK) 跟传统 IK 怎么比?

**答案**:

**Neural IK 思路**:用神经网络直接学"末端位姿 → 关节角":

$$f_\theta: \mathbb{R}^6 \to \mathbb{R}^n, \quad \boldsymbol{q} = f_\theta(\boldsymbol{x}_{\text{target}})$$

**优势**:推理快 (< 1 μs GPU)、天然可微、可学复杂映射 (灵巧手 / 软体)。

**劣势**:需要训练数据、精度有限 (1e-3 rad)、泛化性差。

**典型架构**:

```python
class NeuralIK(nn.Module):
    def __init__(self, n=6):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(7, 128),  # 6 维 target + 1 维 last q
            nn.ReLU(),
            nn.Linear(128, 128), nn.ReLU(),
            nn.Linear(128, n),
        )

    def forward(self, x_target, q_last):
        return self.net(torch.cat([x_target, q_last]))
```

**训练损失** (复合):

$$\mathcal{L} = \|\boldsymbol{q}_{\text{pred}} - \boldsymbol{q}_{\text{gt}}\|^2 + \lambda \|\text{FK}(\boldsymbol{q}_{\text{pred}}) - \boldsymbol{x}_{\text{target}}\|^2$$

**工业现状**:6 DOF 工业机器人传统 IK 仍是主流 (IKFast, DLS);灵巧手 / 软体 Neural IK 更适合。

### Q13: 雅可比在接触力学里扮演什么角色?

**答案**:

接触力学的核心方程:

$$M(\boldsymbol{q}) \ddot{\boldsymbol{q}} + C(\boldsymbol{q}, \dot{\boldsymbol{q}}) \dot{\boldsymbol{q}} + \boldsymbol{g}(\boldsymbol{q}) = \boldsymbol{\tau} + J_c^\top \boldsymbol{\lambda}_c$$

其中 $\boldsymbol{\lambda}_c$ 是接触力,$J_c$ 是接触雅可比,$J_c^\top \boldsymbol{\lambda}_c$ 是接触力映射到关节的力矩。

**接触雅可比的作用**:接触约束 ($J_c \dot{\boldsymbol{q}} = 0$)、接触力分布、摩擦锥约束 ($\|\boldsymbol{\lambda}_{\text{tangential}}\| \leq \mu \lambda_{\text{normal}}$)。

**实例**:机械臂末端按压桌面

```python
J_c = J_pos[:3, :]  # 3 x n
lambda_normal = compute_normal_force()
lambda_tangent = lambda_normal * mu
tau_contact = J_c.T @ np.array([lambda_tangent[0], lambda_tangent[1], lambda_normal])
```

**MuJoCo / Drake 用 $J^\top$ 投影接触力**:这是工业物理引擎处理接触的标准方法。

### Q14: 7 DOF 机器人的"零空间漂移"是什么问题,怎么解决?

**答案**:

**问题**:7 DOF 机械臂的零空间 $\mathcal{N}(J)$ 是 1 维——多一个自由度可以"肘部移动",但静止时如果不断积分零空间速度,关节角会**漂移**到限位。

**原因**:

$$\dot{\boldsymbol{q}} = J^+ \dot{\boldsymbol{x}} + \underbrace{(I - J^+ J) \dot{\boldsymbol{q}}_0}_{\text{零空间项}}$$

零空间项投影后**仍然存在**,持续积分导致漂移。

**解决方案**:

1. **零空间回零 (Null Space Regulation)**:

$$\dot{\boldsymbol{q}}_0 = -k (\boldsymbol{q} - \boldsymbol{q}_{\text{rest}})$$

其中 $\boldsymbol{q}_{\text{rest}}$ 是"自然姿态"。

2. **零空间限位**:

```python
h = sum(((q[i] - q_mid[i]) / (q_max[i] - q_min[i]))**2)
grad_h = 2 * (q - q_mid) / (q_max - q_min)**2
q_dot_null = -grad_h * (I - J_pinv @ J)
```

3. **零空间避障**:类似思路,远离障碍物。

**Franka 的 libfranka 实现**:

```python
# Franka 默认每帧加零空间回零
q_null_dot = -0.5 * (q - q_rest)
q_dot_null = (np.eye(7) - J_pinv @ J) @ q_null_dot
q_dot_total = q_dot_task + q_dot_null
```

### 22.4 Sim2Real 雅可比辨识

在线辨识残差 $\Delta J = J_{real} - J_{sim}$:

```python
class OnlineJacobianEstimator:
    def __init__(self, n=6, m=6, lr=0.01):
        self.J_hat = np.eye(m, n) * 0.1
        self.lr = lr
    def update(self, q_dot, x_dot_measured):
        error = self.J_hat @ q_dot - x_dot_measured
        self.J_hat -= self.lr * np.outer(error, q_dot)
```

**3. 数学形式化(简洁版)**

进一步,优化目标通常加入正则化项来控制模型复杂度,平衡经验风险与模型容量。统计学习理论给出了泛化误差的上界,告诉我们模型越复杂并不一定越好——**奥卡姆剃刀**在数学上有严格的形式化。

偏差-方差分解是另一个核心框架:误差可以分解为模型偏差(欠拟合)、方差(过拟合)和不可约噪声三部分。理解这个分解有助于诊断模型表现、选择合适复杂度。

在数值稳定性方面,有几个常见陷阱: 浮点数精度有限、Log-Sum-Exp 计算要减去最大值、Softmax 在大数值下会溢出。这些工程细节常常决定一个模型能否在生产环境稳定运行。

**7. 实践建议**

结合 "第 6 章:微分运动学——雅可比矩阵与 IK" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "第 6 章:微分运动学——雅可比矩阵与 IK" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
