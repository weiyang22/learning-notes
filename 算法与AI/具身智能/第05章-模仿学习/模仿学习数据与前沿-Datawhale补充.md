## 二、核心补充内容

### 2.1 示范数据的采集-清洗-配比流水线（every-embodied 数据线）

本地第05章-06 讲"数据增强"；every-embodied 补上游的完整流水线，建议并入整章开头：

```text
采集（遥操作/VR/动捕）→ 清洗（剔除失败 episode、掐头去尾、时戳对齐）
→ 标注（任务语言描述、成功标记）
→ 配比（任务间均衡、抗灾难遗忘的混合比例）
→ 版本化（数据集 tag 与模型 checkpoint 对应）
```

**清洗三查**：(a) 遥操作抖动段（速度/加速度离群）裁剪；(b) 相机-状态时戳漂移超阈值帧丢弃；(c) 失败尝试保留与否按用途定——BC 只留成功，DAgger 类需要失败分布。

### 2.2 LeRobot 数据格式：事实标准（every-embodied 03 章）

LeRobot 的数据格式已成为开源 VLA/模仿学习的交换标准（π0、SmolVLA 等都以此为接口，与《VLA 清单补充》联动）：

- **episode 组织**：每个 episode = 多相机视频流 + 逐帧状态/动作张量 + 任务文本，统一索引表；
- **对齐原则**：视频按帧索引与状态对齐（不做每帧存图——体积差一个量级）；
- **跨硬件复用**：同格式下换机械臂只需改配置（关节空间/末端空间、自由度映射），数据可再训练——这是"换硬件不换数据资产"的关键。

### 2.3 与本地算法节的映射：数据问题如何催生算法

把本地 7 节算法放回"数据缺陷"的因果链上（这一视角让章节顺序不再是罗列）：

| 数据缺陷 | 催生的算法（本地节） |
| :--- | :--- |
| 人类示教的因果混淆（人眼在环） | BC 的因果混淆问题 → 01 节 |
| 分布漂移（策略遇到没见过的状态） | DAgger 主动聚合纠正 → 02 节 |
| 多模态动作分布（均值回归） | IBC 条件扩散 → 03 节 |
| 缺机器人数据、任务泛化 | 目标条件策略 → 04 节；人类视频学习 → 05 节 |
| 示范质量方差 | 数据增强与扰动 → 06 节 |

## 三、可直接动手的实践

1. 用 LeRobot 格式录制 10 个 episode 的拾放任务（真机或仿真回放），完整走一遍 2.1 流水线并记录每步淘汰率；
2. 对同一份清洗前后数据各训一个 BC，对比成功率——量化"数据治理"的收益；
3. 按数据版本 tag 管理一次实验：数据集改动 → 重新配比 → 训练，记录数据版本与模型版本的对应表。
