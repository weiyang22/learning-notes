# 第01章-01-激活函数

## 1.1 激活函数

---

## 1. 内容介绍

激活函数 (Activation Function) 是神经网络的核心组件, 给线性变换引入**非线性**, 让网络能拟合复杂函数.

没有激活函数, 多层神经网络等价于单层线性模型, 无法解决 XOR 等非线性问题.

---

## 2. 为什么这么做

历史 4 个阶段:

```text
感知机 (1958) → Sigmoid 主导 (1986-2010) → ReLU 复兴 (2012) → GELU/SwiGLU (LLM 时代, 2017+)
```

**核心问题**:
- Sigmoid 在深层网络中导致**梯度消失** (反向传播时梯度相乘, 远端层梯度趋近于 0)
- ReLU 解决了梯度消失, 但有"神经元死亡"问题
- GELU 平滑了 ReLU, 在 Transformer 中表现更好
- SwiGLU 在 LLaMA 等 SOTA LLM 中被广泛采用

---

## 3. 这么做的原因 (候选方案对比)

| 函数 | 公式 | 优点 | 缺点 |
|---|---|---|---|
| Sigmoid | $\sigma(x) = \frac{1}{1+e^{-x}}$ | 平滑, 输出 [0,1] | 梯度消失, 不是 0 中心 |
| Tanh | $\tanh(x)$ | 输出 [-1, 1], 0 中心 | 仍有梯度消失 |
| ReLU | $\max(0, x)$ | 简单, 缓解梯度消失 | 神经元死亡, 不是 0 中心 |
| Leaky ReLU | $\max(0.01x, x)$ | 解决死亡 | 略复杂 |
| GELU | $x \cdot \Phi(x)$ | 平滑, Transformer 默认 | 计算稍复杂 |
| SwiGLU | $x \cdot \text{SiLU}(\text{gate})$ | SOTA LLM 标配 | 3 个权重矩阵 |

**为什么 Transformer 用 GELU?**
- 相比 ReLU, 在零点附近更平滑, 保留了"负值小幅激活"的信号
- 实验证明在 Transformer 中 GELU 略优于 ReLU
- 计算上, $\text{GELU}(x) \approx 0.5x(1 + \tanh(\sqrt{2/\pi}(x + 0.044715 x^3)))$ 用 tanh 近似

---

## 4. 解决了什么问题

- **梯度消失**: ReLU 系列解决
- **神经元死亡**: Leaky ReLU 解决
- **LLM 大模型激活**: SwiGLU 在 LLaMA / Mistral 中成为标配
- **Softmax 数值溢出**: log-sum-exp 技巧

---

## 5. 意义

激活函数的发展史 = 深度学习的发展史. 选错激活函数 → 训练失败.

---

## 6. 公式表达

```text
Sigmoid:      σ(x) = 1 / (1 + exp(-x))
              σ'(x) = σ(x) * (1 - σ(x))

Tanh:         tanh(x) = (e^x - e^-x) / (e^x + e^-x)

ReLU:         ReLU(x) = max(0, x)
              ReLU'(x) = 1 if x > 0 else 0

GELU:         GELU(x) = x * Φ(x)
              ≈ 0.5x * (1 + tanh(√(2/π) * (x + 0.044715x³)))

SwiGLU:      SwiGLU(a, b) = a * SiLU(b)
              SiLU(x) = x * σ(x)

Softmax:      softmax(x_i) = exp(x_i) / Σ exp(x_j)
              log-softmax(x_i) = x_i - log(Σ exp(x_j))
```

## 9. 答案

### 答案 1: Sigmoid (数值稳定)

```python
import numpy as np

def sigmoid(x):
    """
    数值稳定技巧:
    - x > 0: 用 1 / (1 + exp(-x))
    - x < 0: 用 exp(x) / (1 + exp(x)), 避免 exp 大数
    """
    x = np.asarray(x, dtype=np.float32)
    # 统一写法: 1 / (1 + exp(-|x|)) * sign
    # 但最简写法: 用 np.where 分支
    pos = 1.0 / (1.0 + np.exp(-x))
    neg = np.exp(x) / (1.0 + np.exp(x))
    return np.where(x >= 0, pos, neg)

# 验证
x = np.array([-1000, -1, 0, 1, 1000])
print(sigmoid(x))
# [0.  0.26894142 0.5 0.7310586 1.]
```

**复杂度**: $O(n)$, 无溢出.

### 答案 2: Softmax (log-sum-exp 优化)

```python
def softmax(x):
    """
    数值稳定技巧: 减去 max
    softmax(x_i) = exp(x_i - max) / Σ exp(x_j - max)
    """
    x = np.asarray(x)
    x_max = np.max(x, axis=-1, keepdims=True)
    e_x = np.exp(x - x_max)
    return e_x / np.sum(e_x, axis=-1, keepdims=True)

# 验证
x = np.array([[1, 2, 3], [1000, 1001, 1002]])  # 第二行大数
print(softmax(x))
# [[0.09003057 0.24472847 0.66524096]
#  [0.09003057 0.24472847 0.66524096]]  # 数值稳定!
```

**复杂度**: $O(n)$, 无溢出.

### 答案 3: ReLU / GELU

```python
def relu(x):
    return np.maximum(0, x)

def gelu(x):
    """
    近似公式: 0.5x(1 + tanh(√(2/π)(x + 0.044715x³)))
    """
    return 0.5 * x * (1 + np.tanh(np.sqrt(2 / np.pi) * (x + 0.044715 * x**3)))
```

### 答案 4: SwiGLU (LLaMA FFN)

```python
def silu(x):
    """SiLU(x) = x * sigmoid(x)"""
    return x * sigmoid(x)

def swiglu_ffn(x, W_gate, W_up, W_down):
    """
    x: (B, T, d_model)
    W_gate, W_up: (d_model, d_ff)
    W_down: (d_ff, d_model)
    out: (B, T, d_model)
    """
    gate = silu(x @ W_gate)  # (B, T, d_ff)
    up = x @ W_up              # (B, T, d_ff)
    return (gate * up) @ W_down  # (B, T, d_model)
```

**复杂度**: $O(B \cdot T \cdot d_{model} \cdot d_{ff})$, 与标准 FFN 相同.

## 10. 反向传播视角: 手撕各激活函数导数

面试常追问"写出 backward"。激活层的反向 = 上游梯度 × 本地导数(链式法则):

```python
def relu_backward(dout, x):
    return dout * (x > 0)                       # x>0 处梯度直通, 否则截断

def sigmoid_backward(dout, x):
    s = sigmoid(x)
    return dout * s * (1 - s)                   # σ'(x)=σ(1-σ)

def tanh_backward(dout, x):
    t = np.tanh(x)
    return dout * (1 - t**2)                    # tanh'=1-tanh²

def gelu_backward(dout, x):
    # d/dx [0.5x(1+tanh(g(x)))], g(x)=√(2/π)(x+0.044715x³)
    c = np.sqrt(2/np.pi)
    g = c*(x + 0.044715*x**3)
    t = np.tanh(g)
    dg = c*(1 + 3*0.044715*x**2)
    dx = 0.5*(1+t) + 0.5*x*(1-t**2)*dg
    return dout * dx
```

**Softmax 的雅可比**是满矩阵: $\frac{\partial s_i}{\partial z_j}=s_i(\delta_{ij}-s_j)$。但与交叉熵合并后极简: $\frac{\partial L}{\partial z}=s-y$(见 [1.2 损失函数](第01章-02-损失函数.md)与 [数学第08章 LogSumExp](../../../基础/数学/数学基础/第08章-数值计算与稳定性/第08章-02-数值稳定性与LogSumExp.md))。这就是为什么框架把 softmax+CE 合并成一个算子。

## 11. PyTorch autograd 版(自定义激活)

```python
import torch

class GELUFn(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x):
        ctx.save_for_backward(x)
        c = (2/torch.pi)**0.5
        return 0.5*x*(1+torch.tanh(c*(x+0.044715*x**3)))
    @staticmethod
    def backward(ctx, dout):
        (x,) = ctx.saved_tensors
        c = (2/torch.pi)**0.5
        g = c*(x+0.044715*x**3); t = torch.tanh(g)
        dg = c*(1+3*0.044715*x**2)
        return dout*(0.5*(1+t)+0.5*x*(1-t**2)*dg)
```

实际中直接用 `F.gelu` / `F.silu`;手写用于理解与面试。

## 12. 选型决策与工程陷阱

**选型决策树**:
```text
是 LLM/Transformer FFN?  → SwiGLU (LLaMA/Qwen) 或 GELU (GPT/BERT)
是 CNN 隐藏层?          → ReLU (快) / 需负值信号则 Leaky ReLU / Mish
是输出层?
   ├ 二分类            → Sigmoid
   ├ 多分类            → Softmax
   └ 回归              → 无激活(线性)
门控/注意力权重         → Sigmoid / Softmax
```

**常见陷阱**:
| 现象 | 原因 | 对策 |
| :--- | :--- | :--- |
| Dead ReLU(大量神经元恒为 0) | LR 过大 / 初始化差, 落入负区不再更新 | 降 LR / He 初始化 / Leaky ReLU |
| 梯度消失(深层不更新) | Sigmoid/Tanh 饱和区导数≈0 | 换 ReLU 系 + 残差 + 归一化 |
| 输出层用错激活 | 回归加了 Sigmoid 压死值域 | 回归输出层不加激活 |
| Softmax NaN | 未减 max, exp 溢出 | 减最大值(见第2/6节) |

**Dead ReLU 诊断**:
```python
# 统计某层激活为 0 的比例, 长期 >90% 说明神经元死亡
dead_ratio = (activations == 0).float().mean().item()
```

**补充激活家族**:
- **Mish** $x\tanh(\text{softplus}(x))$:比 ReLU 平滑,CV 中偶有增益。
- **GLU 家族**(GLU/GeGLU/SwiGLU):门控 = 一路做值、一路做"开关",表达力更强,现代 LLM FFN 主流。

## 13. 激活函数的反向传播详解(各类)

### 13.1 链式法则基础

反向传播的数学基础是链式法则。对于复合函数 $L = f(g(h(x)))$:

$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial f} \cdot \frac{\partial f}{\partial g} \cdot \frac{\partial g}{\partial h} \cdot \frac{\partial h}{\partial x}$$

在神经网络中,激活层的反向传播公式统一为:

$$\frac{\partial L}{\partial x_i} = \sum_j \frac{\partial L}{\partial y_j} \cdot \frac{\partial y_j}{\partial x_i}$$

其中 $\mathbf{y} = f(\mathbf{x})$ 是激活函数的输出。

### 13.2 标量激活函数反向传播

**Algorithm: ReLU 反向传播**

```text
输入: 上游梯度 dout, 输入 x
输出: 输入梯度 dx

1. dx = dout * (x > 0)        # x > 0 处梯度直通
2. return dx
```

**Algorithm: Sigmoid 反向传播**

```text
输入: 上游梯度 dout, 输入 x
输出: 输入梯度 dx

1. s = sigmoid(x)             # 前向缓存
2. dx = dout * s * (1 - s)     # σ'(x) = σ(x)(1 - σ(x))
3. return dx
```

**Algorithm: Tanh 反向传播**

```text
输入: 上游梯度 dout, 输入 x
输出: 输入梯度 dx

1. t = tanh(x)
2. dx = dout * (1 - t**2)      # tanh'(x) = 1 - tanh²(x)
3. return dx
```

### 13.3 GELU 反向传播

GELU 的精确形式为 $G(x) = x \Phi(x)$,其中 $\Phi(x)$ 是标准正态分布 CDF。其 tanh 近似为:

$$G(x) \approx 0.5x \left(1 + \tanh\left(\sqrt{\frac{2}{\pi}}\left(x + 0.044715x^3\right)\right)\right)$$

定义内部变量:

$$g(x) = \sqrt{\frac{2}{\pi}}\left(x + 0.044715x^3\right), \quad t = \tanh(g(x))$$

则:

$$\frac{dG}{dx} = 0.5(1+t) + 0.5x(1-t^2) \cdot \frac{dg}{dx}$$

其中:

$$\frac{dg}{dx} = \sqrt{\frac{2}{\pi}}\left(1 + 3 \cdot 0.044715 x^2\right)$$

**Algorithm: GELU 反向传播**

```text
输入: 上游梯度 dout, 输入 x
输出: 输入梯度 dx

1. c = sqrt(2/π)
2. g = c * (x + 0.044715 * x³)
3. t = tanh(g)
4. dg = c * (1 + 3 * 0.044715 * x²)
5. dx = 0.5*(1+t) + 0.5*x*(1-t²)*dg
6. return dout * dx
```

### 13.4 Softmax 反向传播(完整雅可比)

Softmax $\mathbf{s} = \text{softmax}(\mathbf{z})$ 是**向量化**激活,每个输出分量 $s_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$ 都依赖所有输入 $z_j$,所以反向传播是**满雅可比矩阵**:

$$\frac{\partial s_i}{\partial z_j} = \begin{cases} s_i(1 - s_j) & \text{if } i = j \\ -s_i s_j & \text{if } i \neq j \end{cases} = s_i (\delta_{ij} - s_j)$$

写成矩阵形式:

$$J_{\text{softmax}} = \text{diag}(\mathbf{s}) - \mathbf{s}\mathbf{s}^T$$

因此梯度为:

$$\frac{\partial L}{\partial \mathbf{z}} = J_{\text{softmax}}^T \frac{\partial L}{\partial \mathbf{s}} = \mathbf{s} \odot \frac{\partial L}{\partial \mathbf{s}} - \mathbf{s}\left(\mathbf{s}^T \frac{\partial L}{\partial \mathbf{s}}\right)$$

**关键洞察**:当 Softmax 与交叉熵损失合并时,雅可比极大简化:

$$L = -\sum_i y_i \log s_i, \quad \frac{\partial L}{\partial \mathbf{z}} = \mathbf{s} - \mathbf{y}$$

这就是为什么所有深度学习框架(Caffe、PyTorch、TensorFlow)都把 `softmax + cross_entropy` 实现为单个 fused operator,既数值稳定又省显存。

**Algorithm: Softmax + CE 合并反向传播**

```text
输入: 上游梯度 dout (此处为 1), softmax 输出 s, 真实标签 y (one-hot 或 index)
输出: 输入梯度 dx

1. dx = s - y                 # 一行搞定!
2. return dx
```

**Algorithm: Softmax 独立反向传播(非合并)**

```text
输入: 上游梯度 dout (形状 [B, C]), softmax 输出 s (形状 [B, C])
输出: 输入梯度 dx (形状 [B, C])

1. # dx_i = s_i * (dout_i - Σ_j dout_j * s_j)
2. dot = sum(dout * s, axis=-1, keepdims=True)   # [B, 1]
3. dx = s * (dout - dot)
4. return dx
```

### 13.5 SwiGLU 反向传播

SwiGLU 是 LLaMA 的 FFN 核心,定义:

$$\text{SwiGLU}(\mathbf{x}) = \text{SiLU}(\mathbf{x} W_{\text{gate}}) \odot (\mathbf{x} W_{\text{up}})$$

其中 $\text{SiLU}(x) = x \cdot \sigma(x)$,其导数为:

$$\frac{d}{dx}\text{SiLU}(x) = \sigma(x) + x \sigma(x)(1 - \sigma(x)) = \sigma(x)(1 + x(1-\sigma(x)))$$

**Algorithm: SwiGLU 反向传播**

```text
输入: dout, x, W_gate, W_up
输出: dx, dW_gate, dW_up

1. g = x @ W_gate               # gate 分支
2. u = x @ W_up                 # up 分支
3. s = sigmoid(g)
4. silu_g = g * s
5. # 前向: y = silu_g * u
6. # 反向到 gate: dy/dg = dsilu_g * u = (σ(1+g(1-σ))) * u
7. dsilu = s * (1 + g*(1-s))   # SiLU 导数
8. dg = dout * u * dsilu       # [B, T, d_ff]
9. du = dout * silu_g
10. dx = dg @ W_gate.T + du @ W_up.T
11. dW_gate = x.T @ dg
12. dW_up = x.T @ du
13. return dx, dW_gate, dW_up
```

### 13.6 完整示例: 4 层 MLP 反向传播

**Algorithm: 4 层 MLP 前向 + 反向**

```text
输入: x (B, 784), 标签 y (B, 10)
网络: Linear(784→256) → ReLU → Linear(256→128) → ReLU → Linear(128→10) → Softmax

前向:
  h1 = x @ W1 + b1              # [B, 256]
  a1 = relu(h1)                 # [B, 256]
  h2 = a1 @ W2 + b2             # [B, 128]
  a2 = relu(h2)                 # [B, 128]
  h3 = a2 @ W3 + b3             # [B, 10]
  s = softmax(h3)               # [B, 10]
  L = -log(s[y])                # NLL

反向:
  dL/dh3 = s - one_hot(y)       # softmax+CE 合并 → 一行!
  dW3 = a2.T @ dL/dh3
  da2 = dL/dh3 @ W3.T
  dh2 = da2 * (h2 > 0)          # ReLU backward
  dW2 = a1.T @ dh2
  da1 = dh2 @ W2.T
  dh1 = da1 * (h1 > 0)
  dW1 = x.T @ dh1

关键点:
  - 每一层都需缓存前向激活用于反向
  - 链式法则逐层回传
  - ReLU 的 mask 直接相乘
```

### 13.7 自动微分视角: 手动 vs PyTorch

```python
import torch
import torch.nn as nn

# 手动实现 (理解)
def manual_mlp_backward(x, W1, b1, W2, b2, W3, b3, y):
    # 前向
    h1 = x @ W1 + b1
    a1 = torch.relu(h1)
    h2 = a1 @ W2 + b2
    a2 = torch.relu(h2)
    h3 = a2 @ W3 + b3
    s = torch.softmax(h3, dim=-1)
    L = -torch.log(s[torch.arange(len(y)), y]).mean()

    # 反向
    dh3 = s.clone()
    dh3[torch.arange(len(y)), y] -= 1
    dh3 /= len(y)

    dW3 = a2.T @ dh3
    da2 = dh3 @ W3.T
    dh2 = da2 * (h2 > 0)

    dW2 = a1.T @ dh2
    da1 = dh2 @ W2.T
    dh1 = da1 * (h1 > 0)

    dW1 = x.T @ dh1

    return L, dW1, dW2, dW3

# PyTorch autograd (实战)
model = nn.Sequential(nn.Linear(784, 256), nn.ReLU(),
                      nn.Linear(256, 128), nn.ReLU(),
                      nn.Linear(128, 10))
criterion = nn.CrossEntropyLoss()  # 内含 softmax
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

for x, y in dataloader:
    optimizer.zero_grad()
    logits = model(x)
    loss = criterion(logits, y)
    loss.backward()       # autograd 自动求梯度
    optimizer.step()      # 梯度下降
```

**对比**: autograd 与手写结果一致,但 autograd 通用性强、不易出错。面试时手写展示理解,工程时用 autograd。

### 13.8 数值梯度检查 (Gradient Check)

**Algorithm: 数值梯度检查**

```text
输入: 模型 f, 参数 θ, 损失 L, ε=1e-5
输出: 误差 = ||解析梯度 - 数值梯度||

1. # 数值梯度
2. θ_plus = θ + ε
3. θ_minus = θ - ε
4. grad_num = (L(θ_plus) - L(θ_minus)) / (2ε)

5. # 解析梯度 (autograd)
6. loss = f(θ)
7. loss.backward()
8. grad_ana = θ.grad

9. # 比较
10. rel_error = |grad_num - grad_ana| / (|grad_num| + |grad_ana| + 1e-12)
11. if rel_error < 1e-5:
12.     print("梯度正确")
13. else:
14.     print("梯度可能有误!")
```

```python
def gradient_check(f, theta, eps=1e-5):
    """数值梯度 vs 解析梯度"""
    # 解析梯度
    theta = theta.clone().requires_grad_(True)
    loss = f(theta)
    loss.backward()
    grad_analytical = theta.grad.clone()

    # 数值梯度
    grad_numerical = torch.zeros_like(theta)
    it = torch.nditer(theta, flags=['multi_index'])
    while not it.finished:
        idx = it.multi_index
        theta_plus = theta.detach().clone()
        theta_minus = theta.detach().clone()
        theta_plus[idx] += eps
        theta_minus[idx] -= eps
        loss_plus = f(theta_plus)
        loss_minus = f(theta_minus)
        grad_numerical[idx] = (loss_plus - loss_minus) / (2 * eps)
        it.iter_next()

    # 相对误差
    rel_err = (grad_analytical - grad_numerical).abs() / \
              (grad_analytical.abs() + grad_numerical.abs() + 1e-12)
    return rel_err.max().item()
```

## 14. 数值稳定性与混合精度

### 14.1 数值问题的三大来源

**来源 1: 指数溢出 (Exponential Overflow)**

Sigmoid 的朴素实现 $\sigma(x) = 1/(1+e^{-x})$:

- 当 $x = 1000$ 时, $e^{-1000} \approx 0$,但浮点数表示为下溢 0 → $\sigma = 1$, 正确
- 当 $x = -1000$ 时, $e^{1000}$ 溢出 → inf → $\sigma = 0/inf = NaN$ ❌

**来源 2: Softmax 溢出**

朴素实现 $\text{softmax}(x_i) = e^{x_i}/\sum_j e^{x_j}$:

- 输入 $x = [1000, 1001, 1002]$ 时, 所有 $e^{x_i}$ 都溢出为 inf
- inf/inf = NaN

**来源 3: 对数零 (Log of Zero)**

交叉熵 $-log(s_i)$:

- 若 $s_i = 0$ (预测完全错误且梯度已饱和), $-log(0) = inf$ → 训练爆炸

### 14.2 Log-Sum-Exp 技巧

**核心恒等式**:

$$\log \sum_i e^{x_i} = m + \log \sum_i e^{x_i - m}, \quad \text{其中 } m = \max_i x_i$$

数学推导:

$$\log \sum_i e^{x_i} = \log \sum_i e^{x_i - m} \cdot e^m = \log(e^m \cdot \sum_i e^{x_i - m}) = m + \log \sum_i e^{x_i - m}$$

由于 $x_i - m \leq 0$, $e^{x_i - m} \in (0, 1]$, 无溢出。

**Algorithm: 数值稳定 Softmax**

```text
输入: x 形状 [..., C]
输出: 形状 [..., C], 每行和为 1

1. m = max(x, dim=-1, keepdim=True)        # [B, 1]
2. e = exp(x - m)                          # 无溢出
3. p = e / sum(e, dim=-1, keepdim=True)    # 归一化
4. return p
```

**Algorithm: 数值稳定 Log-Softmax**

```text
输入: x 形状 [..., C]
输出: log_softmax(x)

1. m = max(x, dim=-1, keepdim=True)
2. s = x - m - log(sum(exp(x - m), dim=-1, keepdim=True))
3. return s
```

### 14.3 PyTorch 数值稳定实现

```python
import torch
import torch.nn.functional as F

# 数值稳定 (推荐)
log_probs = F.log_softmax(logits, dim=-1)  # 内部用 log-sum-exp

# 朴素 (会出问题)
log_probs_naive = torch.log(torch.softmax(logits, dim=-1))
# 问题: softmax 输出有微小误差, log 后放大, 可能出现 -inf

# 对比
x = torch.tensor([1000.0, 1001.0, 1002.0])
print(F.log_softmax(x, dim=-1))
# tensor([-2.4076, -1.4076, -0.4076])  ✓
print(torch.log(torch.softmax(x, dim=-1)))
# tensor([-inf, -inf, -inf])  ✗
```

### 14.4 GELU / SiLU 的数值安全实现

```python
def silu_safe(x):
    """SiLU = x * sigmoid(x), 数值稳定版"""
    # 直接计算: sigmoid 在 x 极大时接近 1, 在 x 极小时接近 0, 不会溢出
    return x * torch.sigmoid(x)

# 不需要特殊处理: torch.sigmoid 内部已用 log1p 等技巧

def gelu_safe(x, approximate='none'):
    """
    GELU 数值稳定实现
    - approximate='none': 精确 erf 形式
    - approximate='tanh': tanh 近似形式
    """
    if approximate == 'none':
        # GELU(x) = 0.5x(1 + erf(x/sqrt(2)))
        return 0.5 * x * (1.0 + torch.erf(x / torch.sqrt(torch.tensor(2.0))))
    else:
        # tanh 近似
        c = (2.0 / torch.pi) ** 0.5
        return 0.5 * x * (1.0 + torch.tanh(c * (x + 0.044715 * x**3)))
```

### 14.5 混合精度训练 (Mixed Precision / AMP)

**核心思想**: FP32 用于权重更新, FP16/BF16 用于前向/反向计算,节省显存 50%+ 加速 2-3x。

**关键问题**: FP16 精度有限 (5 位尾数),容易下溢到 0,导致梯度消失。

**解决方案: Loss Scaling**

```text
Algorithm: Dynamic Loss Scaling

1. 初始化 scale = 2^16 = 65536
2. 前向: scaled_loss = loss * scale
3. 反向: scaled_loss.backward()  # 梯度也乘 scale, 避免下溢
4. 检查是否有 inf/nan:
   - 若无 inf/nan: unscale gradients (除以 scale), 更新权重, scale *= 2
   - 若有 inf/nan: skip update, scale /= 2
5. 重复
```

**PyTorch AMP 实现**:

```python
from torch.cuda.amp import autocast, GradScaler

scaler = GradScaler()  # 自动处理 loss scaling

for x, y in dataloader:
    optimizer.zero_grad()

    # autocast 上下文自动转换 FP16/BF16
    with autocast(device_type='cuda', dtype=torch.float16):
        logits = model(x)
        loss = criterion(logits, y)

    # scaled backward
    scaler.scale(loss).backward()

    # unscale + step
    scaler.step(optimizer)
    scaler.update()
```

### 14.6 BF16 vs FP16 vs FP32

| 格式 | 位宽 | 指数位 | 尾数位 | 范围 | 精度 |
|---|---|---|---|---|---|
| FP32 | 32 | 8 | 23 | ±3.4e38 | 高 |
| FP16 | 16 | 5 | 10 | ±6.5e4 | 低 (易下溢) |
| BF16 | 16 | 8 | 7 | ±3.4e38 (同 FP32) | 极低 (易溢出) |

**BF16 优势**: 与 FP32 同等指数范围,无需 loss scaling,适合 LLM 训练 (Transformer 激活值范围大)。

**FP16 优势**: 精度高 2-3 位,适合 CNN / CV 任务 (激活值范围小)。

### 14.7 激活值统计与诊断

```python
# 检查激活值分布
def check_activation_stats(model, dataloader):
    stats = {}
    hooks = []

    def hook_fn(name):
        def hook(module, input, output):
            if torch.is_tensor(output):
                stats[name] = {
                    'mean': output.mean().item(),
                    'std': output.std().item(),
                    'max': output.max().item(),
                    'min': output.min().item(),
                    'has_nan': torch.isnan(output).any().item(),
                    'has_inf': torch.isinf(output).any().item(),
                    'saturated': ((output.abs() > 5).float().mean()).item()
                }
        return hook

    for name, module in model.named_modules():
        if isinstance(module, (nn.ReLU, nn.GELU, nn.SiLU, nn.Sigmoid, nn.Tanh)):
            hooks.append(module.register_forward_hook(hook_fn(name)))

    # 前向一批数据
    for x, y in dataloader:
        _ = model(x.cuda())
        break

    # 清理
    for h in hooks:
        h.remove()

    return stats

# 典型健康范围:
#   ReLU:   mean>0, std>0, saturated < 50%
#   Sigmoid: mean ~0.5, std < 0.5, saturated < 20%
#   GELU:   mean ~0, std ~0.5, saturated < 10%
```

### 14.8 梯度爆炸/消失的检测与处理

```python
def check_gradient_health(model):
    """检查梯度范数"""
    total_norm = 0
    layer_norms = {}

    for name, param in model.named_parameters():
        if param.grad is not None:
            norm = param.grad.norm().item()
            layer_norms[name] = norm
            total_norm += norm ** 2

    total_norm = total_norm ** 0.5

    if total_norm > 10:
        print(f"⚠️ 梯度爆炸: {total_norm:.2f}")
        # 处理: 梯度裁剪
        torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
    elif total_norm < 1e-7:
        print(f"⚠️ 梯度消失: {total_norm:.2e}")
        # 处理: 残差连接 / 归一化 / 换激活函数

    return total_norm, layer_norms
```

**常见处理方法**:

| 问题 | 解决方案 |
| :--- | :--- |
| 梯度爆炸 | 梯度裁剪 (clip_grad_norm_) / 降低 LR / 权重衰减 |
| 梯度消失 | 残差连接 / BatchNorm / LayerNorm / ReLU |
| Dead ReLU | Leaky ReLU / PReLU / 降 LR / He 初始化 |
| Softmax NaN | log-sum-exp / 温度缩放 |

### 14.9 温度缩放 (Temperature Scaling)

**用途**: 控制 Softmax 输出分布的"锐度",常用于知识蒸馏。

$$\text{softmax}(\mathbf{x}/T)_i = \frac{e^{x_i/T}}{\sum_j e^{x_j/T}}$$

- $T < 1$: 分布更尖锐 (更 confident)
- $T > 1$: 分布更平滑 (更 soft), 用于蒸馏教师模型

```python
def softmax_with_temperature(logits, T=1.0, dim=-1):
    """带温度的 softmax"""
    scaled_logits = logits / T
    return F.softmax(scaled_logits, dim=dim)

# 蒸馏示例
teacher_logits = model_teacher(x) / T_soft   # T_soft=4 让教师分布平滑
student_logits = model_student(x)
loss = F.kl_div(F.log_softmax(student_logits/T, dim=-1),
                F.softmax(teacher_logits, dim=-1),
                reduction='batchmean') * (T**2)
```

## 15. 各架构的激活函数选型

### 15.1 选型总览

| 架构 | 推荐激活 | 备选 | 理由 |
|---|---|---|---|
| **MLP/CNN** (传统) | ReLU | Leaky ReLU | 简单、稀疏、计算快 |
| **ResNet** | ReLU | ReLU6 | 残差已解决梯度消失 |
| **Transformer** (BERT/GPT) | GELU | ReLU | 平滑, 实验略优 |
| **LLM FFN** (LLaMA) | SwiGLU | GeGLU | 门控增强表达力 |
| **Vision Transformer** | GELU | SiLU | 与 BERT 一致 |
| **RNN/LSTM** | Tanh | — | 历史选择, 0 中心 |
| **GAN 生成器** | ReLU/Leaky ReLU | — | 配合 BN |
| **GAN 判别器** | Leaky ReLU | — | 负值信号重要 |
| **扩散模型** | SiLU | Mish | UNet 默认 |
| **输出层: 二分类** | Sigmoid | — | 概率 ∈ [0,1] |
| **输出层: 多分类** | Softmax | — | 归一化概率 |
| **输出层: 回归** | 无 (线性) | Clamp | 任意实数 |
| **注意力权重** | Softmax | Sigmoid (线性注意力) | 归一化 |

### 15.2 CNN 中的激活函数

**经典选型**:

```text
Conv → BN → ReLU                         # ResNet 标准
Conv → BN → ReLU → Conv → BN → (残差)    # 残差块
```

**为什么 ReLU 在 CNN 中获胜?**

1. **计算极快**: max(0, x) 比 tanh/sigmoid 快一个数量级
2. **稀疏激活**: 平均 50% 神经元为 0,网络表达更高效
3. **缓解梯度消失**: 正区间梯度恒为 1
4. **与 BN 协同**: BN 把输入拉到 0 附近,激活分布健康

**ReLU6 (MobileNet)**: $\min(\max(0, x), 6)$, 在低精度 (INT8) 推理时更鲁棒。

```python
# MobileNet V2 倒残差块
nn.Sequential(
    nn.Conv2d(in_ch, 6*in_ch, 1, bias=False),
    nn.BatchNorm2d(6*in_ch),
    nn.ReLU6(inplace=True),       # ReLU6 而非 ReLU
    nn.Conv2d(6*in_ch, 6*in_ch, 3, padding=1, groups=6*in_ch, bias=False),
    nn.BatchNorm2d(6*in_ch),
    nn.ReLU6(inplace=True),
    nn.Conv2d(6*in_ch, out_ch, 1, bias=False),
    nn.BatchNorm2d(out_ch),
)
```

### 15.3 Transformer 中的激活函数

**BERT/GPT**: GELU

```python
class TransformerBlock(nn.Module):
    def __init__(self, d_model, nhead, dim_ff):
        super().__init__()
        self.attn = nn.MultiheadAttention(d_model, nhead, batch_first=True)
        self.norm1 = nn.LayerNorm(d_model)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, dim_ff),
            nn.GELU(),                          # ← GELU!
            nn.Linear(dim_ff, d_model),
        )
        self.norm2 = nn.LayerNorm(d_model)

    def forward(self, x, mask=None):
        x = x + self.attn(self.norm1(x), self.norm1(x), self.norm1(x), attn_mask=mask)[0]
        x = x + self.ffn(self.norm2(x))
        return x
```

**为什么 GELU 而非 ReLU?**

论文《Gaussian Error Linear Units (Hendrycks & Gimpel, 2016)》证明:

- 在 Transformer 中, GELU 比 ReLU 略优 (GLUE/MT-NN 等基准)
- GELU 在 $x \approx 0$ 处的平滑性避免了 ReLU 的"硬拐点"
- 保留了"小幅负值信号",ReLU 直接截断为 0

### 15.4 LLM 中的激活函数: GLU 家族

**GLU (Gated Linear Unit)** 是一类门控激活:

$$\text{GLU}(\mathbf{x}, \mathbf{W}, \mathbf{V}, \mathbf{b}, \mathbf{c}) = (\mathbf{x}\mathbf{W} + \mathbf{b}) \odot \sigma(\mathbf{x}\mathbf{V} + \mathbf{c})$$

**变体**:

| 名称 | 门函数 | 输出 |
|---|---|---|
| GLU | $\sigma$ | $a \odot \sigma(b)$ |
| Bilinear | 无门控 | $a \odot b$ |
| ReGLU | ReLU | $a \odot \text{ReLU}(b)$ |
| GEGLU | GELU | $a \odot \text{GELU}(b)$ |
| SwiGLU | SiLU | $a \odot \text{SiLU}(b)$ |

**LLM 中的实现**:

```text
SwiGLU FFN (LLaMA):
  out = (SiLU(xW_gate) ⊙ xW_up) W_down

GeGLU FFN (GPT-2/J):
  out = (GELU(xW_gate) ⊙ xW_up) W_down
```

**为什么 GLU 在 LLM 中胜出?**

1. **门控机制**: 门控分支可"开关"信息流, 增强表达力
2. **参数效率**: 3 个矩阵而非 2 个,但 LLM 普遍使用 GLU
3. **实验优势**: LLaMA 论文对比 GLU 变体, SwiGLU 最优

### 15.5 扩散模型中的激活函数

**Stable Diffusion / DiT**: SiLU

```python
class TimestepEmbedSequential(nn.Sequential):
    """DiT 块: SiLU + AdaLN"""
    def forward(self, x, emb):
        for layer in self:
            if isinstance(layer, ResBlock):
                x = layer(x, emb)
            elif isinstance(layer, AttentionBlock):
                x = layer(x)
            elif isinstance(layer, nn.SiLU):    # ← SiLU
                x = layer(x)
        return x
```

**为什么 SiLU?**

- SiLU = Swish = $x \cdot \sigma(x)$, 无界、有下界、平滑
- 在 UNet 中表现稳定, 避免 ReLU 的梯度硬拐点
- 比 GELU 略简单

### 15.6 RNN 中的激活函数

**LSTM/GRU**:

```text
LSTM cell:
  i = σ(W_i [h_{t-1}, x_t] + b_i)        # 输入门 (sigmoid)
  f = σ(W_f [h_{t-1}, x_t] + b_f)        # 遗忘门 (sigmoid)
  o = σ(W_o [h_{t-1}, x_t] + b_o)        # 输出门 (sigmoid)
  g = tanh(W_g [h_{t-1}, x_t] + b_g)     # 候选 (tanh)
  c_t = f ⊙ c_{t-1} + i ⊙ g
  h_t = o ⊙ tanh(c_t)                    # 状态 (tanh)
```

**为什么 LSTM 用 Sigmoid + Tanh?**

- Sigmoid 输出 [0,1], 适合"门控" (0=关闭, 1=开启)
- Tanh 输出 [-1,1], 适合"状态"表示
- 这是历史选择, 现代 Transformer 已替代

### 15.7 输出层激活函数

| 任务 | 输出范围 | 激活函数 |
|---|---|---|
| 二分类 | [0,1] | Sigmoid |
| 多分类 (互斥) | 概率分布 | Softmax |
| 多标签分类 | [0,1]^K | Sigmoid (每类独立) |
| 回归 (任意实数) | ℝ | 无 (线性) |
| 回归 [0,1] | [0,1] | Sigmoid |
| 回归 [0,∞) | [0,∞) | ReLU / Softplus |
| 回归 [-1,1] | [-1,1] | Tanh |

```python
# 二分类
self.out = nn.Linear(d_model, 1)
self.act = nn.Sigmoid()
prob = self.act(self.out(x))  # [B, 1]

# 多分类
self.out = nn.Linear(d_model, num_classes)
logits = self.out(x)  # [B, num_classes]
probs = F.softmax(logits, dim=-1)  # 或在 loss 内合并

# 回归

```

### 16.1 LLaMA 系列 (Meta)

**LLaMA-1 (2023.02)**: SwiGLU FFN

```python
# 简化版 LLaMA FFN
class LLaMAFFN(nn.Module):
    def __init__(self, d_model, d_ff, multiple_of=256):
        super().__init__()
        # 3 个矩阵 (而非传统的 2 个)
        self.w_gate = nn.Linear(d_model, d_ff, bias=False)
        self.w_up = nn.Linear(d_model, d_ff, bias=False)
        self.w_down = nn.Linear(d_ff, d_model, bias=False)

    def forward(self, x):
        # SwiGLU: (SiLU(x @ W_gate) ⊙ (x @ W_up)) @ W_down
        gate = F.silu(self.w_gate(x))
        up = self.w_up(x)
        return self.w_down(gate * up)

# LLaMA 7B 配置
d_model = 4096
d_ff = 11008        # 约 8/3 * d_model, 对齐 multiple_of
n_heads = 32
n_layers = 32
```

- $d_{ff} = \frac{8}{3} d_{model} \approx 2.67 d_{model}$, 对齐到 `multiple_of` (256)
- 无 bias (除 RMSNorm 外)
- SwiGLU 比标准 FFN 多一个矩阵,但效果更好

```python
class DeepSeekMoEFFN(nn.Module):
    """DeepSeek MoE FFN, 每个 token 选择 top-k 专家"""
    def __init__(self, d_model, d_ff, n_experts=160, top_k=6):
        super().__init__()
        self.n_experts = n_experts
        self.top_k = top_k

        # 每个专家都是 SwiGLU
        self.gate_proj = nn.Parameter(torch.randn(n_experts, d_model, d_ff))
        self.up_proj = nn.Parameter(torch.randn(n_experts, d_model, d_ff))
        self.down_proj = nn.Parameter(torch.randn(n_experts, d_ff, d_model))

        # 路由门控 (路由专家选择)
        self.router = nn.Linear(d_model, n_experts, bias=False)

    def forward(self, x):
        # 路由: 每个 token 选 top_k 专家
        scores = self.router(x)            # [B, T, n_experts]
        topk_scores, topk_idx = scores.topk(self.top_k, dim=-1)  # [B, T, k]
        topk_weights = F.softmax(topk_scores, dim=-1)            # [B, T, k]

        # 专家计算 (向量化)
        # 简化: 实际实现用 group_gemm 或 all-to-all 通信
        outs = []
        for k in range(self.top_k):
            expert_idx = topk_idx[..., k]  # [B, T]
            # 收集对应专家的权重
            W_g = self.gate_proj[expert_idx]  # [B, T, d_ff, d_model]
            W_u = self.up_proj[expert_idx]
            W_d = self.down_proj[expert_idx]

            gate = F.silu(x @ W_g)
            up = x @ W_u
            out = (gate * up) @ W_d
            outs.append(out)

        # 加权求和
        return sum(topk_weights[..., k:k+1] * outs[k] for k in range(self.top_k))
```

**DeepSeek 激活函数创新**:
- **SwiGLU** 作为基础专家激活
- **MoE 路由**: 稀疏激活, 每个 token 只激活 top_k=6 个专家 (共 160 个)
- **共享专家**: 部分专家始终激活, 捕获通用模式

**方法 3: torch.autograd.Function (手写反向)**

```python
class SwishFunction(torch.autograd.Function):
    """SiLU/Swish: x * sigmoid(x), 自定义反向"""

    @staticmethod
    def forward(ctx, x):
        sigmoid_x = torch.sigmoid(x)
        ctx.save_for_backward(x, sigmoid_x)
        return x * sigmoid_x

    @staticmethod
    def backward(ctx, dout):
        x, sigmoid_x = ctx.saved_tensors
        # d/dx [x * σ(x)] = σ(x) + x * σ(x) * (1 - σ(x))
        grad = sigmoid_x + x * sigmoid_x * (1 - sigmoid_x)
        return dout * grad

# 使用
class Swish(nn.Module):
    def forward(self, x):
        return SwishFunction.apply(x)
```

### 17.3 实战案例: Adaptive Parametric Activation

**APE (Adaptive Piecewise Linear)**: 学到的分段线性激活

```python
class AdaptivePReLU(nn.Module):
    """
    自适应 PReLU: 每通道学习不同的负斜率 + 偏置
    f(x) = max(0, x) + alpha * min(0, x) + beta
    """
    def __init__(self, n_channels):
        super().__init__()
        self.alpha = nn.Parameter(torch.full((n_channels,), 0.25))
        self.beta = nn.Parameter(torch.zeros(n_channels))

    def forward(self, x):
        # x 形状 [..., C]
        alpha = self.alpha.view(1, 1, -1)  # 广播到 [B, T, C]
        beta = self.beta.view(1, 1, -1)
        pos = F.relu(x)
        neg = alpha * (x - pos)  # = alpha * min(0, x)
        return pos + neg + beta
```

### 17.4 Mish 激活函数完整实现

**Mish**: $f(x) = x \cdot \tanh(\text{softplus}(x)) = x \cdot \tanh(\ln(1 + e^x))$

```python
class MishFunction(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x):
        # softplus(x) = log(1 + exp(x)) 数值稳定: max(x, 0) + log1p(exp(-|x|))
        sp = F.softplus(x)
        th = torch.tanh(sp)
        ctx.save_for_backward(x, sp, th)
        return x * th

    @staticmethod
    def backward(ctx, dout):
        x, sp, th = ctx.saved_tensors
        # dMish/dx = tanh(softplus(x)) + x * sech²(softplus(x)) * sigmoid(x)
        # = th + x * (1 - th²) * σ(x)
        grad = th + x * (1 - th**2) * torch.sigmoid(x)
        return dout * grad

class Mish(nn.Module):
    def forward(self, x):
        return MishFunction.apply(x)
```

### 17.5 Maxout 激活

**Maxout**: $f(\mathbf{x}) = \max_{k=1,\ldots,K} (\mathbf{W}_k \mathbf{x} + \mathbf{b}_k)$

Maxout 可以学习任意凸函数激活,本质上是"激活函数的学习"。

```python
class Maxout(nn.Module):
    """K 个线性层, 取每个元素的最大值"""
    def __init__(self, in_features, out_features, k=2):
        super().__init__()
        self.k = k
        self.fc = nn.Linear(in_features, out_features * k)

    def forward(self, x):
        # [B, out_features * k]
        out = self.fc(x)
        # 重塑为 [B, out_features, k]
        out = out.view(x.size(0), -1, self.k)
        # 取每个元素的最大值
        return out.max(dim=-1)[0]
```

### 题目 2: Softmax + CrossEntropy 反向传播推导

**问题**: 证明 Softmax + CrossEntropy 合并后,梯度为 $\frac{\partial L}{\partial \mathbf{z}} = \mathbf{s} - \mathbf{y}$。

**答案**:

设 $L = -\sum_i y_i \log s_i$, 其中 $s_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$。

**步骤 1**: 求 $\frac{\partial L}{\partial z_k}$

$$\frac{\partial L}{\partial z_k} = -\sum_i y_i \frac{1}{s_i} \frac{\partial s_i}{\partial z_k}$$

**步骤 2**: 求 $\frac{\partial s_i}{\partial z_k}$

- 当 $i = k$ 时: $\frac{\partial s_i}{\partial z_k} = s_i(1 - s_k)$
- 当 $i \neq k$ 时: $\frac{\partial s_i}{\partial z_k} = -s_i s_k$

合并: $\frac{\partial s_i}{\partial z_k} = s_i(\delta_{ik} - s_k)$

**步骤 3**: 合并

$$\frac{\partial L}{\partial z_k} = -\sum_i y_i \frac{1}{s_i} \cdot s_i (\delta_{ik} - s_k) = -\sum_i y_i (\delta_{ik} - s_k)$$

$$= -y_k + \sum_i y_i s_k = s_k - y_k \quad (\text{因} \sum_i y_i = 1)$$

即: $\frac{\partial L}{\partial \mathbf{z}} = \mathbf{s} - \mathbf{y}$。∎

### 题目 3: ReLU vs Sigmoid 在深度网络中的表现

**问题**: 为什么 ReLU 比 Sigmoid 更适合深度网络?

**答案**:

| 维度 | Sigmoid | ReLU |
|---|---|---|
| 梯度消失 | 严重 ($\max \sigma' = 0.25$) | 正区间无消失 |
| 计算复杂度 | exp | max |
| 稀疏性 | 无 | 50% 激活 |
| 收敛速度 | 慢 | 快 (5-10x) |
| Dead Neuron | 无 | 有 (但可救) |

**定量分析**: 100 层网络中, 反向传播梯度经过 100 层 Sigmoid:

$$\left(\max \sigma'\right)^{100} = 0.25^{100} \approx 10^{-60}$$

→ 梯度消失到浮点数精度以下, 无法更新。

ReLU: $\left(\max \text{ReLU}'\right)^{100} = 1^{100} = 1$, 不消失。

### 题目 5: SwiGLU vs 标准 FFN

**问题**: SwiGLU 比标准 FFN 多一个矩阵,为什么反而更好?

**答案**:

标准 FFN: $y = W_2 \cdot \text{ReLU}(W_1 x + b_1) + b_2$

SwiGLU FFN: $y = W_{\text{down}} \cdot (\text{SiLU}(W_{\text{gate}} x) \odot W_{\text{up}} x)$

**优势**:
1. **门控机制**: $\text{SiLU}(W_{\text{gate}} x)$ 学习"开/关"信号, 控制信息流
2. **参数效率**: 3 个矩阵 (W_gate, W_up, W_down) 总参数量略多 (50%), 但效果提升更显著
3. **LLaMA 实验**: 相同 FLOPs 下, SwiGLU 比 ReLU FFN 困惑度低 5-10%

### 题目 6: GELU 公式推导

**问题**: 从概率角度推导 GELU = $x \cdot \Phi(x)$。

**答案**:

定义: $x$ 是输入, $\Phi(x) = P(X \leq x)$ 是标准正态 CDF。

将 $x$ 乘以一个伯努利随机变量 $I$:

$$\tilde{x} = x \cdot I, \quad I \sim \text{Bernoulli}(\Phi(x))$$

则 $\mathbb{E}[\tilde{x}] = x \cdot \Phi(x)$, 即 GELU。

**直觉**: 输入 $x$ 越大,保留概率 $\Phi(x)$ 越大;输入 $x$ 越小,保留概率越小。平滑版的"随机失活"。

### 题目 7: 混合精度训练为何能加速?

**问题**: BF16 精度低于 FP32,为什么训练反而更快?

**答案**:

1. **显存减半**: BF16 占 2 字节, FP32 占 4 字节 → 显存节省 50%,可训练更大模型/更大 batch
2. **计算加速**: Tensor Core 专门优化 BF16/FP16 矩阵乘法,峰值 FLOPS 是 FP32 的 2-8 倍 (A100: FP32=19.5 TFLOPS, BF16=312 TFLOPS)
3. **带宽优化**: 数据传输量减半
4. **BF16 与 FP32 同等动态范围**: 无需 loss scaling,简化流程

**代价**: 精度降低,需谨慎处理累加 (用 FP32 accumulator)。

### 题目 8: 为什么 SwiGLU 用三个矩阵而非两个?

**问题**: GLU 变体中,SwiGLU 用 W_gate/W_up/W_down 三个矩阵,而不是 W1/W2 两个。设计理由?

**答案**:

- **两个矩阵的 FFN**: $W_2 \cdot \text{act}(W_1 x)$, act 是元素级非线性
- **三个矩阵的 GLU**: $W_{\text{down}} \cdot (\text{act}(W_{\text{gate}} x) \odot W_{\text{up}} x)$, 门控 + 值 两路

**为什么三矩阵更好**:

1. **门控与值的解耦**: 一路学"开关", 一路学"内容", 表达力更强
2. **乘性交互**: 门控信号与值信号相乘, 比纯加性交互 (标准 FFN) 表达力更强
3. **LLaMA 实验**: 同 FLOPs 下, SwiGLU 优于标准 FFN

**参数对比**:
- 标准 FFN: $2 \times d_m \times d_{ff}$
- SwiGLU: $3 \times d_m \times d_{ff}$

LLaMA 通过减小 $d_{ff}$ 抵消参数增长, 设为 $d_{ff} = \frac{8}{3} d_m$。

### 题目 9: Softmax 输出全 0/全 1 的原因与修复

**问题**: 训练时 loss 突然变成 inf/NaN, softmax 输出接近 0/1。原因? 修复?

**答案**:

**原因**: 输入 logits 过大, softmax 过度自信, argmax 概率接近 1, 其它接近 0。Log 后, log(0) = -inf, 与真实 label 相乘得 -inf, loss = inf。

**修复方案**:

```python
# 方案 1: 梯度裁剪
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)

# 方案 2: Label smoothing
loss = F.cross_entropy(logits, y, label_smoothing=0.1)

# 方案 3: 数值稳定 softmax (已内置, 确认使用)
log_probs = F.log_softmax(logits, dim=-1)

# 方案 4: 温度缩放 (降低 logits 锐度)
logits = logits / 2.0  # T=2 让分布更平滑

# 方案 5: 权重约束
torch.nn.utils.parameters_to_vector(model.parameters()).clamp(-10, 10)
```

### 题目 10: 如何选择激活函数的初始化?

**问题**: ReLU 配套用什么初始化? 为什么?

**答案**:

**He 初始化 (Kaiming)**: $\text{Var}(W) = \frac{2}{n_{\text{in}}}$

**推导**: 前向传播时,第 $l$ 层激活的方差:

$$\text{Var}(a^l) = n_{\text{in}} \cdot \text{Var}(W) \cdot \text{Var}(a^{l-1}) \cdot \frac{1}{2}$$

(因 ReLU 砍掉一半负值)

为保持 $\text{Var}(a^l) = \text{Var}(a^{l-1})$, 需要:

$$n_{\text{in}} \cdot \text{Var}(W) \cdot \frac{1}{2} = 1 \Rightarrow \text{Var}(W) = \frac{2}{n_{\text{in}}}$$

**PyTorch**:

```python
nn.init.kaiming_normal_(m.weight, mode='fan_in', nonlinearity='relu')

# 对比
nn.init.xavier_normal_(m.weight)  # 用于 Tanh/Sigmoid, Var(W) = 1/n
```

### 题目 11: Softmax 温度对训练的影响

**问题**: 蒸馏中,教师用 T=4,学生用 T=1。问:学生蒸馏时用 T=1 还是 T=4 计算 logits?

**答案**:

蒸馏时,学生用 T=4 计算 soft logits,与教师的 T=4 logits 对齐:

```python
teacher_logits_T4 = teacher(x) / T_soft  # 教师用 T=4
student_logits_T4 = student(x) / T_soft  # 学生用 T=4

# KL 散度 loss
loss_soft = F.kl_div(
    F.log_softmax(student_logits_T4, dim=-1),
    F.softmax(teacher_logits_T4, dim=-1),
    reduction='batchmean'
) * (T_soft ** 2)  # 乘 T² 补偿温度对梯度的影响

# 硬目标 loss (学生用 T=1)
loss_hard = F.cross_entropy(student(x), y)

# 总 loss
loss = α * loss_soft + (1 - α) * loss_hard
```

**原因**: T=4 让分布平滑,学生学到更多"暗知识";T² 补偿梯度尺度。

### 题目 12: ReLU 零梯度的本质

**问题**: ReLU 在 $x < 0$ 时梯度为 0, 是否意味着这些神经元"永远不更新"?

**答案**:

**不是永远不更新**,只是**当前 batch 不更新**。如果后续输入使该神经元激活 (输入 $x > 0$),就会重新更新。

**Dead ReLU 的真实含义**: 一旦神经元在某次更新后落入负区, 且 bias 大幅为负, 它就永远输出 0。

**修复**:

```python
# Leaky ReLU
nn.LeakyReLU(negative_slope=0.01)

# PReLU (可学习斜率)
nn.PReLU(num_parameters=1)

# 降学习率, 避免大步跨过激活区
optimizer = torch.optim.SGD(model.parameters(), lr=0.001)
```

### 题目 13: Softmax 与 Sigmoid 的关系

**问题**: Softmax 与 Sigmoid 在二分类时等价吗? 多分类时区别?

**答案**:

**二分类时**: 等价

$$\text{softmax}([x_1, x_2]) = \left[\frac{e^{x_1}}{e^{x_1}+e^{x_2}}, \frac{e^{x_2}}{e^{x_1}+e^{x_2}}\right]$$

设 $p_1 = \sigma(z) = \frac{1}{1+e^{-z}}$, $p_2 = 1 - p_1$。

令 $z = x_1 - x_2$, 则:

$$\frac{e^{x_1}}{e^{x_1}+e^{x_2}} = \frac{e^{x_1-x_2}}{e^{x_1-x_2}+1} = \frac{1}{1+e^{-(x_1-x_2)}} = \sigma(x_1-x_2)$$

所以 Softmax([x1, x2]) = [σ(x1-x2), 1-σ(x1-x2)]。

**多分类时**: Sigmoid 各自独立,Softmax 互斥

- **Sigmoid**: $K$ 个独立二分类,可同时为 1 (多标签: 猫 + 狗)
- **Softmax**: 强制 $\sum = 1$ (互斥多分类: 猫 OR 狗 OR 鸟)

### 题目 14: 为什么 SwiGLU 比 GeLU/GLU 在 LLaMA 中更好?

**问题**: LLaMA 论文对比了 4 种 FFN 变体 (ReLU/GeLU/SwiGLU/GeGLU),SwiGLU 最优。设计原因?

**答案**:

LLaMA 论文 (Touvron et al. 2023) 消融实验:

| FFN 变体 | WikiText PPL | 参数量 |
|---|---|---|
| ReLU | 5.94 | 2d² |
| GeLU | 5.94 | 2d² |
| SwiGLU | 5.62 | 3d² (但 d_ff 减小) |
| GeGLU | 5.67 | 3d² |

SwiGLU 略优于 GeGLU, 优于 ReLU/GeLU。

**设计原因**:

1. **SiLU 无上界**: SwiGLU 输出无上界,允许激活值"放大",表达力更强
2. **下界 -0.28**: SiLU 在 x≈-1.28 处有最小值 ≈ -0.28, 提供平滑的"负激活"
3. **自门控**: SiLU = $x \cdot \sigma(x)$, 门控和值共用一份输入, 信息流更高效

### 题目 15: BN/ReLU 的顺序之争

**问题**: Conv → BN → ReLU 还是 Conv → ReLU → BN? 为什么?

**答案**:

**现代共识**: Conv → BN → ReLU (post-activation)

```python
nn.Sequential(
    nn.Conv2d(in_ch, out_ch, 3, padding=1),
    nn.BatchNorm2d(out_ch),
    nn.ReLU(inplace=True)
)
```

**原因**:

1. **BN 在 ReLU 前**: BN 把数据拉回 N(0,1) 分布,ReLU 砍掉一半负值
2. **BN 在 ReLU 后**: ReLU 输出非负,BN 的"0 中心化"失效, 反而引入偏移
3. **实验验证**: ResNet 原论文使用 Conv → BN → ReLU, 表现最佳

**例外**: 部分工作使用 ReLU → BN (如 MobileNet V2 的某些变体), 效果接近。

### 题目 16: SwiGLU 在 KV Cache 下的显存占用

**问题**: LLaMA 推理时,SwiGLU FFN 的显存占用是否比标准 FFN 多? 为什么?

**答案**:

**训练时**: SwiGLU FFN 的 W_gate/W_up/W_down 三个矩阵比标准 FFN 的 W1/W2 多 50% 显存。

但 LLaMA 通过减小 $d_{ff}$ 抵消:

- 标准 FFN: $d_{ff} = 4 d_{model}$, 参数量 $2 \times 4 d^2 = 8d^2$
- SwiGLU: $d_{ff} = \frac{8}{3} d_{model}$, 参数量 $3 \times \frac{8}{3} d^2 = 8d^2$

**相同**! 实际训练总参数量一致。

**推理时 (KV Cache)**:

SwiGLU FFN 的激活值 $a = \text{SiLU}(x W_g) \odot (x W_u)$ 形状 [B, T, $d_{ff}$], 比标准 FFN 的中间激活 [B, T, $4d_m$] 略小。

### 题目 17: Softmax 与 Attention 的关系

**问题**: Transformer 中的 Attention 为什么用 Softmax? 能否用 Sigmoid 替代?

**答案**:

**Attention 公式**: $\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V$

**为什么 Softmax?**

1. **归一化权重**: Softmax 输出 $\sum = 1$, 作为权重解释性强 (概率分布)
2. **互斥性**: 同一 query 对不同 key 的注意力是互斥的 (总和固定, 一个高其它就低)
3. **梯度友好**: 与 log 配合后梯度稳定

**能否用 Sigmoid?**

**可以**,但效果不同:

```python
# Sigmoid Attention (线性注意力变体)
attn_weights = torch.sigmoid(Q @ K.T / sqrt(d_k))  # 范围 [0,1], 非互斥
out = attn_weights @ V
```

**问题**:
- Sigmoid 不强制 $\sum = 1$, 不同 key 的权重独立
- 多个 key 可能同时高, 稀释了注意力
- 实际: **线性注意力** (Performer, Linear Transformer) 用 $\phi(Q) \cdot \phi(K)^T$ 替代 softmax, 完全去掉 softmax

### 题目 18: 自定义激活函数的显存开销

**问题**: 用 `torch.autograd.Function` 自定义激活函数,会缓存哪些显存? 如何节省?

**答案**:

```python
class CustomActivation(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x):
        ctx.save_for_backward(x)        # 缓存 x
        # 可选: 缓存中间变量
        # ctx.intermediate = ...
        return output

    @staticmethod
    def backward(ctx, dout):
        x, = ctx.saved_tensors
        return grad
```

**显存开销**: `save_for_backward` 会保留张量到反向传播结束。

**节省技巧**:

1. **不缓存中间变量**: 反向时重新计算 (耗时换显存)
2. **及时释放**: `del ctx.saved_tensors` (PyTorch 内部管理, 不建议手动)
3. **梯度检查点**: 不缓存激活, 反向时重算

```python
# 节省显存版: 只缓存最小必要信息
class CustomActivationV2(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x):
        ctx.save_for_backward(x)
        return x * torch.sigmoid(x)

    @staticmethod
    def backward(ctx, dout):
        x, = ctx.saved_tensors
        # 重新计算中间变量
        s = torch.sigmoid(x)
        return dout * (s + x * s * (1 - s))
```

## 19. 总结与速查

### 19.1 激活函数速查表

| 函数 | 公式 | 范围 | 导数 | 用途 |
|---|---|---|---|---|
| Sigmoid | $\frac{1}{1+e^{-x}}$ | [0,1] | $\sigma(1-\sigma)$ | 二分类输出 |
| Tanh | $\frac{e^x-e^{-x}}{e^x+e^{-x}}$ | [-1,1] | $1-\tanh^2$ | RNN 状态 |
| ReLU | $\max(0,x)$ | [0,∞) | $\mathbb{1}_{x>0}$ | CNN 隐藏层 |
| Leaky ReLU | $\max(0.01x,x)$ | ℝ | 1 或 0.01 | 防 Dead ReLU |
| PReLU | $\max(\alpha x, x)$ | ℝ | 1 或 $\alpha$ | 可学习负斜率 |
| ELU | $x$ if $x>0$ else $\alpha(e^x-1)$ | [-α,∞) | 1 或 $\alpha e^x$ | 输出均值接近 0 |
| SiLU/Swish | $x\sigma(x)$ | [-0.28,∞) | $\sigma(1+x(1-\sigma))$ | LLM/扩散 |
| GELU | $x\Phi(x)$ | (-0.17,∞) | 复杂 | Transformer |
| Mish | $x\tanh(\text{softplus}(x))$ | (-0.31,∞) | 复杂 | 视觉/检测 |
| Softmax | $\frac{e^{x_i}}{\sum e^{x_j}}$ | (0,1), 和=1 | 满雅可比 | 多分类输出 |
| LogSoftmax | $x_i - \log\sum e^{x_j}$ | (-∞,0) | 1 | 与 NLL 配套 |

### 19.2 选型决策

```text
LLM/Transformer FFN → SwiGLU (LLaMA) / GELU (BERT)
CNN 隐藏层          → ReLU (默认) / Leaky ReLU / Mish
扩散 UNet           → SiLU
RNN 状态            → Tanh
门控信号             → Sigmoid
输出层: 二分类       → Sigmoid
输出层: 多分类       → Softmax (在 loss 中合并)
输出层: 回归         → 无激活
注意力权重           → Softmax / Sigmoid (线性注意力)
```

### 19.3 数值稳定清单

- [x] Softmax: 减去 max
- [x] LogSoftmax: 用 log-sum-exp
- [x] Sigmoid: 分支处理 (正/负)
- [x] CrossEntropy: 与 LogSoftmax 合并
- [x] BF16 训练: 替代 FP16,无需 loss scaling
- [x] 梯度裁剪: 防爆炸
- [x] 激活值监控: 诊断饱和/死亡

### 19.4 关键陷阱

1. **Softmax 不减 max**: 大数 → NaN
2. **回归输出用 Sigmoid**: 值域受限
3. **Sigmoid/Tanh 在深层网络**: 梯度消失
4. **ReLU 学习率过大**: Dead ReLU
5. **Softmax + CE 不合并**: 显存翻倍 + 数值不稳定

### 110. 激活函数 (Sigmoid / ReLU / GELU / Softmax) - 优化视角 视角

**核心议题**: 本节从优化视角视角切入,系统展开 "激活函数 (Sigmoid / ReLU / GELU / Softmax)" 的相关讨论。

**1. 背景与动机**

任何技术或方法的出现都不是孤立的,而是回应特定历史条件下的具体问题。"激活函数 (Sigmoid / ReLU / GELU / Softmax)" 的发展也不例外。要理解它,必须回到它出现的那个时间点,看清它要解决的真实问题是什么。当时的主流方案有哪些不足? 它的提出填补了哪些空白? 这些问题的回答,决定了我们今天该如何使用它。

从知识论角度看,**技术演进是问题驱动的**——不是先有方案再找问题,而是先有问题再有方案。这个观察可以帮助我们避免"拿着锤子找钉子"的陷阱,真正把方法用对地方。

历史维度上,我们看到三个规律:

1. **从特殊到一般**: 早期方法往往针对特定场景,后期抽象出通用框架。学习的认知规律也是先掌握具体案例,再抽象出一般模式。这种"自下而上"的学习方式,在机器学习模型的设计里反复出现。

2. **从手工到自动**: 经验规则逐步被数据驱动的方法取代。在早期,很多 AI 系统依赖人工编写的规则。统计学习方法的崛起让"从数据中学习"成为可能。深度学习进一步把特征工程也自动化了。今天的大模型时代,我们看到端到端学习从感知扩展到了推理与生成。

3. **从局部到全局**: 关注单个组件,演进到关注整个系统。早期模型评估只关注单点指标,现在更关注全链路的协同效应。这种"系统视角"的转变,与软件工程从单体架构到微服务架构的演进高度相似。

**2. 优化视角视角的展开**

从优化视角视角出发,我们可以把 "激活函数 (Sigmoid / ReLU / GELU / Softmax)" 拆解为以下几个层次:

**第一层: 概念层** —— 这是最抽象的层次,定义了我们要研究的对象是什么。例如,"推荐系统"在概念层是一个"为用户从物品集合中筛选合适物品"的问题。这个层次的特点是清晰、稳定、不易变化。一个好的概念定义应该具备几个特征:可操作性、可测量性、可扩展性。

**第二层: 模型层** —— 把概念实例化为数学模型。同一概念可以有不同的模型化方式,例如"推荐系统"可以是协同过滤、矩阵分解、深度学习等。模型的选择决定了后续算法的空间,也决定了能利用的归纳偏置(比如序列模型擅长捕捉时序依赖,图模型擅长建模关系结构)。模型选型是工程实践中最重要的决策之一。

**第三层: 算法层** —— 在选定模型下,具体的求解方法。这一层最活跃,新算法层出不穷。同一模型往往有多种算法,各有优劣。例如同样是优化深度网络,可以选择 SGD、Adam、L-BFGS 等不同算法。算法的选择要考虑收敛速度、数值稳定性、计算成本等多个维度。

**第四层: 工程层** —— 算法落地的实现细节,包括数据流水线、训练框架、推理优化、监控告警等。工程层是研究到生产的桥梁,决定了一个方法能否真正用起来。一个在论文里表现很好的算法,如果不能高效实现、不能稳定运行、不能快速迭代,就没有实际价值。工程能力是把研究转化为生产力的关键。

**第五层: 业务层** —— 在具体业务场景中的表现。同一技术在不同业务里效果差异巨大,因为业务目标、数据分布、用户行为都有差异。从业务视角看技术,我们必须回答几个问题:这个技术解决了什么业务问题?投入产出比如何?长期可持续吗?技术评估必须与业务目标对齐,否则容易陷入"技术自嗨"的陷阱。

**3. 数学形式化(简洁版)**

虽然我们强调优化视角视角,但数学形式化提供了共同语言。机器学习的核心问题可以表达为:给定输入样本,学习一个映射函数,使得函数输出与真实目标的差距最小化。这个抽象捕捉了分类、回归、生成等大多数任务的本质。

进一步,优化目标通常加入正则化项来控制模型复杂度,平衡经验风险与模型容量。统计学习理论给出了泛化误差的上界,告诉我们模型越复杂并不一定越好——**奥卡姆剃刀**在数学上有严格的形式化。

偏差-方差分解是另一个核心框架:误差可以分解为模型偏差(欠拟合)、方差(过拟合)和不可约噪声三部分。理解这个分解有助于诊断模型表现、选择合适复杂度。

在数值稳定性方面,有几个常见陷阱: 浮点数精度有限、Log-Sum-Exp 计算要减去最大值、Softmax 在大数值下会溢出。这些工程细节常常决定一个模型能否在生产环境稳定运行。

**4. 信息论视角**
