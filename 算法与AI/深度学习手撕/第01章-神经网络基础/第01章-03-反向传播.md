# 第01章-03-反向传播

传播 (Backpropagation, 简称 BP) 是神经网络训练的**核心算法**, 用链式法则从输出层向输入层反向计算每个参数的梯度.

BP + 梯度下降 = 神经网络训练的完整流程.

---

## 2. 为什么这么做

**问题**:
- 神经网络有百万/亿参数, 怎么高效算所有梯度?
- 直接数值微分 (有限差分) 慢且不准
- 符号微分 (手动求导) 复杂, 网络一变就要重写

**解决方案**:
- **计算图**: 把网络拆成"基本算子" (+, *, sin, exp, matmul)
- **链式法则**: 复合函数求导 = 各层导数相乘
- **反向模式自动微分**: 一次反向遍历, 算出所有参数的梯度

**复杂度**: 与前向传播同阶 $O(\text{网络大小})$, 是"魔法".

---

## 3. 这么做的原因 (方案对比)

| 方案 | 复杂度 | 精度 | 实用性 |
|---|---|---|---|
| 数值微分 ($O(n)$ 每个参数) | $O(n^2)$ | 低 (浮点误差) | 慢, 不实用 |
| 符号微分 (手写求导) | 网络一变就重写 | 精确 | 难维护 |
| 前向自动微分 | $O(n)$ | 精确 | 慢 (适合输入少) |
| **反向自动微分 (BP)** | $O(n)$ | 精确 | **主流, PyTorch/TF 用** |

**为什么反向?**
- 对每个参数 $\theta_i$, 求 $\partial L / \partial \theta_i$
- 输出 $L$ 是一个标量, 反向遍历"反向求导"只需一次
- 前向模式需要 $n$ 次 (每个输入都跑一遍), 反向只需 1 次

---

## 4. 解决了什么问题

- **梯度高效计算**: $O(n)$ 时间算出所有 $n$ 个参数的梯度
- **训练大规模网络**: BP 让百万/亿参数网络训练可行
- **深度学习基础**: 一切训练 (SGD/Adam/RLHF) 都基于 BP

---

## 5. 意义

- 1986 年 Rumelhart 等人提出 BP, 引发神经网络第二次高潮
- 现代深度学习框架 (PyTorch/TensorFlow/JAX) 都基于反向自动微分
- 理解 BP 才能 debug 梯度消失/爆炸

---

## 6. 公式表达

**链式法则** (核心):
```text
L = f(g(h(x)))
dL/dx = (dL/df) * (df/dg) * (dg/dh) * (dh/dx)
```

**计算图 (前向)**:
```text
x → [线性层 W₁·x+b₁] → [激活 σ] → [线性层 W₂] → [softmax] → L
```

**反向传播** (从右向左):
```text
∂L/∂ŷ → ∂L/∂W₂ = ŷ·∂L/∂ŷ → ∂L/∂h = W₂·∂L/∂ŷ → ∂L/∂σ = ... → ∂L/∂W₁
```

**梯度累加**:
```text
∂L/∂W = Σ_samples ∂L/∂W (单个样本)
```

## 9. 答案

### 答案 1: 2 层 MLP 梯度手推

```text
设:
  z₁ = W₁·x + b₁         (d_hid)
  h = ReLU(z₁) = max(0, z₁) (d_hid)
  y = W₂·h + b₂          (d_out)
  L = (1/2) (y - t)²

反向:

∂L/∂y = (y - t)

∂L/∂W₂ = ∂L/∂y · h.T           (d_out, d_hid)
∂L/∂b₂ = ∂L/∂y                 (d_out,)

∂L/∂h = W₂.T · ∂L/∂y           (d_hid,)

∂L/∂z₁ = ∂L/∂h ⊙ (z₁ > 0)     (ReLU 梯度, ⊙ 是 element-wise)

∂L/∂W₁ = ∂L/∂z₁ · x.T         (d_hid, d_in)
∂L/∂b₁ = ∂L/∂z₁               (d_hid,)
```

### 答案 2: 数值微分验证

```python
import numpy as np

def numerical_gradient(f, x, h=1e-5):
    """中心差分"""
    grad = np.zeros_like(x)
    it = np.nditer(x, flags=['multi_index'])
    while not it.finished:
        idx = it.multi_index
        old = x[idx]
        x[idx] = old + h
        fx_plus = f(x)
        x[idx] = old - h
        fx_minus = f(x)
        grad[idx] = (fx_plus - fx_minus) / (2 * h)
        x[idx] = old
        it.iternext()
    return grad

def check_gradient(analytical_grad, numerical_grad, tol=1e-5):
    """相对误差 < tol 则 OK"""
    abs_err = np.abs(analytical_grad - numerical_grad)
    rel_err = abs_err / (np.abs(analytical_grad) + np.abs(numerical_grad) + 1e-8)
    max_rel = rel_err.max()
    return max_rel < tol, max_rel
```

### 答案 3: 2 层 MLP 反向传播

```python
import numpy as np

class TwoLayerMLP:
    def __init__(self, d_in, d_hid, d_out):
        self.W1 = np.random.randn(d_in, d_hid) * 0.1
        self.b1 = np.zeros(d_hid)
        self.W2 = np.random.randn(d_hid, d_out) * 0.1
        self.b2 = np.zeros(d_out)

    def forward(self, x):
        self.x = x
        self.z1 = x @ self.W1 + self.b1
        self.h = np.maximum(0, self.z1)  # ReLU
        self.y = self.h @ self.W2 + self.b2
        return self.y

    def backward(self, t):
        """L = 0.5 * (y - t)² → ∂L/∂y = y - t"""
        B = self.x.shape[0]
        dy = self.y - t  # (B, d_out)

        # ∂L/∂W₂ = h.T @ dy
        dW2 = self.h.T @ dy / B  # (d_hid, d_out)
        db2 = np.mean(dy, axis=0)  # (d_out,)

        # ∂L/∂h = dy @ W2.T
        dh = dy @ self.W2.T  # (B, d_hid)

        # ∂L/∂z₁ = dh ⊙ ReLU'(z₁)
        dz1 = dh * (self.z1 > 0)  # (B, d_hid)

        # ∂L/∂W₁ = x.T @ dz1
        dW1 = self.x.T @ dz1 / B  # (d_in, d_hid)
        db1 = np.mean(dz1, axis=0)  # (d_hid,)

        return dW1, db1, dW2, db2
```

### 答案 4: 简易 autograd (类 PyTorch micrograd)

```python
import numpy as np

class Value:
    """自动微分的 Value 类"""
    def __init__(self, data, _children=(), _op='', label=''):
        self.data = float(data)
        self.grad = 0.0
        self._backward = lambda: None
        self._children = set(_children)
        self._op = _op
        self.label = label

    def __add__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data + other.data, (self, other), '+')

        def _backward():
            self.grad += out.grad
            other.grad += out.grad
        out._backward = _backward
        return out

    def __mul__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data * other.data, (self, other), '*')

        def _backward():
            self.grad += other.data * out.grad
            other.grad += self.data * out.grad
        out._backward = _backward
        return out

    def __neg__(self): return self * -1
    def __sub__(self, other): return self + (-other)
    def __pow__(self, n): return Value(self.data ** n, (self,), f'**{n}')

    def tanh(self):
        t = np.tanh(self.data)
        out = Value(t, (self,), 'tanh')
        def _backward():
            self.grad += (1 - t**2) * out.grad
        out._backward = _backward
        return out

    def backward(self):
        # 拓扑序
        topo = []
        visited = set()
        def build(v):
            if v not in visited:
                visited.add(v)
                for child in v._children:
                    build(child)
                topo.append(v)
        build(self)

        # 反向遍历
        self.grad = 1.0
        for v in reversed(topo):
            v._backward()

# 使用示例
a = Value(2.0, label='a')
b = Value(-3.0, label='b')
c = a * b; c.label = 'c'
d = a + c; d.label = 'd'
f = d.tanh(); f.label = 'f'
f.backward()
print(f.grad)  # 1
print(a.grad, b.grad)  # 反向传播结果
```

## 深入: 矩阵形式反向传播(必背)

标量 autograd 好懂,实战是张量。核心(设 $Y=XW+b$,上游 $\bar Y=\partial L/\partial Y$):

$$\frac{\partial L}{\partial W}=X^\top\bar Y,\quad \frac{\partial L}{\partial X}=\bar Y W^\top,\quad \frac{\partial L}{\partial b}=\sum_{\text{batch}}\bar Y$$

**形状对齐口诀**:梯度形状必须等于被求导变量形状,以此反推转置位置。上面的两层 MLP 反向就是这三条 + 激活导数的反复应用。

---

## 深入: 自动微分的两种模式

- **反向模式**:一次前向 + 一次反向,一次算出对**所有参数**的梯度。DL 用它(参数多、输出 loss 是标量)。
- **前向模式**:适合输入少输出多,DL 少用。

PyTorch = 动态计算图 + 反向模式 AD;`loss.backward()` 就是按图拓扑逆序调用每个算子 `backward`(见 [数学第01章-04 自动微分](../../../基础/数学/数学基础/第01章-高等数学/第01章-04-链式法则·自动微分·计算图-loss-backward-的本质.md))。

## 深入: 梯度消失/爆炸的根源与对策

深层梯度是**雅可比连乘** $\prod_l J_l$:各 $J_l$ 谱范数 <1 → 指数消失,>1 → 指数爆炸。

## 5. 矩阵形式反向传播(必背)

### 5.1 为什么需要矩阵形式

标量 BP 推导直观,但实战全是张量 (Tensor)。把 BP 提升到矩阵/张量层面有三个核心收益:

1. **GPU 友好**: 一次矩阵乘法代替 N 次标量循环, 充分利用 SIMT。
2. **代码即公式**: 一行 `dW = X.T @ dY` 直接对应 $\frac{\partial L}{\partial W}=X^\top \bar Y$。
3. **通用算子**: Conv/RNN/Attention 都是"广义线性算子 + 激活", 一套规则可套用。

**核心原则**: **梯度形状 = 被求导变量形状**。这条口诀让我们不必死记转置方向——只要形状对, 转置位置自动落定。

---

### 5.2 线性层 (Linear / Dense / FC) 的三大梯度

设前向:
$$Y = X W + b,\quad X\in\mathbb{R}^{B\times d_{in}},\ W\in\mathbb{R}^{d_{in}\times d_{out}},\ b\in\mathbb{R}^{d_{out}},\ Y\in\mathbb{R}^{B\times d_{out}}$$

上游梯度 (从后面传回来): $\bar Y=\partial L/\partial Y\in\mathbb{R}^{B\times d_{out}}$。

**求 $\partial L/\partial W$**:
逐元素展开 $Y_{ij}=\sum_k X_{ik}W_{kj}+b_j$, 因此
$$\frac{\partial L}{\partial W_{kj}}=\sum_i \frac{\partial L}{\partial Y_{ij}}\frac{\partial Y_{ij}}{\partial W_{kj}}=\sum_i \bar Y_{ij}\cdot X_{ik}=[X^\top \bar Y]_{kj}$$

$$\boxed{\frac{\partial L}{\partial W}=X^\top \bar Y}\quad (d_{in}\times d_{out})$$

**求 $\partial L/\partial X$**:
$$[\bar X]_{ik}=\sum_j \bar Y_{ij}\cdot W_{kj}=[\bar Y W^\top]_{ik}$$

$$\boxed{\frac{\partial L}{\partial X}=\bar Y W^\top}\quad (B\times d_{in})$$

**求 $\partial L/\partial b$**:
$b_j$ 对所有样本 $i$ 共享, 要沿 batch 维度累加:
$$\boxed{\frac{\partial L}{\partial b}=\sum_{i=1}^B \bar Y_{i,:}}\quad (d_{out})$$

> **口诀**: 哪个维度出现 $\bar Y$ 出现, 哪个变量就跟 $X$ 对应位置对齐。$W$ 在 $X$ 右侧 → $X^\top$ 在左; 反向回传时 $\bar X$ 必须与 $Y$ 同形状 → $\bar Y W^\top$。

### 5.3 PyTorch 验证矩阵 BP

```python
import torch
import torch.nn.functional as F

torch.manual_seed(0)
B, d_in, d_out = 4, 3, 5
X = torch.randn(B, d_in, requires_grad=False)
W = torch.randn(d_in, d_out, requires_grad=True)
b = torch.randn(d_out, requires_grad=True)

# 前向
Y = X @ W + b                       # (B, d_out)
loss = (Y ** 2).sum()               # 标量
loss.backward()

# 手算矩阵 BP
dY = 2.0 * Y                        # dL/dY
dW_manual = X.T @ dY                # (d_in, d_out)

dX_manual = dY @ W.T                # (B, d_in)

assert torch.allclose(b.grad, db_manual, atol=1e-6), "db mismatch!"
assert torch.allclose(dX_manual, X.new_zeros_like(X) + 0)  # X 不需要梯度

```

### 5.4 激活函数的 BP

激活是 element-wise, 梯度最简单: 把上游梯度乘以局部导数即可。

| 激活 | 前向 $y$ | 反向 $\partial L/\partial x$ |
| :--- | :--- | :--- |
| ReLU | $\max(0,x)$ | $\bar y \odot (x>0)$ |
| Sigmoid | $\sigma(x)$ | $\bar y \odot \sigma(x)(1-\sigma(x))$ |
| Tanh | $\tanh(x)$ | $\bar y \odot (1-\tanh^2(x))$ |
| GELU | $x\Phi(x)$ | $\bar y \odot [\Phi(x)+x\phi(x)]$ |
| Softmax (CE) | $\text{softmax}(x)$ | $\bar y \odot \text{softmax}(x) - \text{onehot}(t)$ |

```python
def relu_backward(dY, X):
    """ReLU 反向: 上游梯度乘以 (X > 0) 掩码"""
    return dY * (X > 0).float()

def sigmoid_backward(dY, Y):
    """sigmoid 反向: Y 已经是 σ(X), 直接用 Y(1-Y)"""
    return dY * Y * (1 - Y)

def softmax_ce_backward(Y, t):
    """Softmax + 交叉熵的反向, PyTorch 内部就是这么做的"""
    B = Y.shape[0]
    grad = Y.clone()
    grad[range(B), t] -= 1
    return grad / B
```

> **关键洞察**: Softmax + CrossEntropy 的反向**不需要除以 batch**, 但 PyTorch 默认 `/B` 是约定俗成, 让 loss 和 grad 同步缩放。实际看你 loss 公式。

### 5.5 Softmax + CrossEntropy 的完整 BP 推导

设 logits $z\in\mathbb{R}^{C}$, softmax $p_i=e^{z_i}/\sum_j e^{z_j}$, one-hot 标签 $t_i$, 损失:
$$L=-\sum_i t_i \log p_i$$

对 $z_k$ 求导:
$$\frac{\partial L}{\partial z_k}=-\sum_i t_i\frac{1}{p_i}\frac{\partial p_i}{\partial z_k}$$

而 softmax 的雅可比:
$$\frac{\partial p_i}{\partial z_k}=\begin{cases}p_i(1-p_k) & i=k \\ -p_i p_k & i\ne k\end{cases}$$

代入化简 (利用 $\sum_i t_i=1$):
$$\boxed{\frac{\partial L}{\partial z_k}=p_k - t_k}$$

简洁优雅——这是深度学习最重要的公式之一。

```python
def softmax_ce_forward_backward(z, t):
    """
    Softmax + CE 的前向 + 反向
    z: (B, C) logits
    t: (B,)   labels
    """
    # 数值稳定: 减去 max
    z_shift = z - z.max(dim=1, keepdim=True).values
    exp = z_shift.exp()
    p = exp / exp.sum(dim=1, keepdim=True)         # (B, C)
    B = z.shape[0]
    loss = -z_shift[range(B), t].log().sum() / B
    # 反向: 直接 p - t
    grad = p.clone()
    grad[range(B), t] -= 1.0
    grad /= B
    return loss, grad
```

### 5.6 BatchNorm / LayerNorm 的 BP 速览

归一化层的 BP 比较复杂, 因为涉及均值/方差对所有样本的耦合。

**BatchNorm 前向** (per-channel):
$$\mu_c=\frac{1}{B}\sum_i x_{ic},\quad \sigma^2_c=\frac{1}{B}\sum_i (x_{ic}-\mu_c)^2$$
$$\hat x_{ic}=\frac{x_{ic}-\mu_c}{\sqrt{\sigma^2_c+\epsilon}},\quad y_{ic}=\gamma_c\hat x_{ic}+\beta_c$$

**反向**: 已知 $\bar y_{ic}=\partial L/\partial y_{ic}$, 求 $\bar x_{ic}$:

$$\bar x_{ic}=\frac{1}{\sqrt{\sigma^2_c+\epsilon}}\left[\bar y_{ic}\gamma_c - \frac{1}{B}\sum_j \bar y_{jc}\gamma_c - \frac{\hat x_{ic}}{B}\sum_j \bar y_{jc}\gamma_c\hat x_{jc}\right]$$

参数梯度:
$$\frac{\partial L}{\partial \gamma_c}=\sum_i \bar y_{ic}\hat x_{ic},\quad \frac{\partial L}{\partial \beta_c=\sum_i \bar y_{ic}}$$

> **实战提示**: 推理时 BN 用 running mean/var, 不需要反向; 只有训练阶段需要复杂 BP。

---

### 5.7 矩阵 BP 的"形状对齐"心法

实战中遇到新算子 (Conv / Attention / Embedding), 反向公式记不清怎么办?

1. **写出 forward shape**: `Y = f(X; W)` 列出每个变量形状。
2. **上游 $\bar Y$ shape = Y shape**。
3. **逐元素展开**, 用 $\sum_{j}\bar Y_{ij}W_{jk}$ 这类点积写出 $\bar W$。
4. **形状对齐**: 让 $\bar W$ 与 $W$ 同 shape, 转置位置自动落定。
5. **数值 check**: 用 `torch.autograd.gradcheck` 验证 (见 Ch8)。

> 例: Embedding `Y = X @ W`, $X$ 是 one-hot → 梯度 `dW = X.T @ dY` 退化为 `dW[t] += dY`, 因为只更新被查的行。

---

### 5.8 面试真题

**Q1**: 写出 `Linear` 层反向传播三个梯度公式, 并解释为什么 $\partial L/\partial b$ 要沿 batch 求和。

> 答: $\partial L/\partial W=X^\top\bar Y$, $\partial L/\partial X=\bar Y W^\top$, $\partial L/\partial b=\sum_i\bar Y_i$。因为 $b$ 是个 (与 batch 无关的) 共享向量, 每个 $b_j$ 在所有样本上都贡献到 $Y_{ij}$, 因此梯度要累加所有样本的贡献。

**Q2**: Softmax + CE 的反向为什么是 $p-t$ 这样简洁的形式?

> 答: 利用 $\sum_i t_i=1$, 雅可比矩阵中 $i=k$ 和 $i\ne k$ 两项合并, $-p_k\sum_i t_i+p_k\sum_i t_i - (t_k - p_k t_k) = p_k - t_k$。本质是 softmax + CE 联合优化的"魔法"。

**Q3**: 激活函数的 BP 为什么这么"简单"?

> 答: element-wise 算子的 Jacobian 是对角阵, 矩阵乘法退化为 element-wise 乘 ($\odot$), 没有维度耦合。

---

### 5.9 本节小结

- **核心三公式**: $X^\top\bar Y$ / $\bar Y W^\top$ / $\sum\bar Y$——所有 Linear 层 BP 都是这三条。
- **形状对齐**: 梯度形状 = 被求导变量形状, 用此反推转置。
- **激活 element-wise**: $\bar x = \bar y \odot \sigma'(x)$。
- **Softmax+CE 联合**: $\bar z = p - t$, 最简最美的反向公式。

> 下一节我们把这些"标量规则"推广到 Conv / RNN / Attention 等"非 element-wise"算子。

## 6. 各种层的反向传播实现 (Conv / RNN / Attention)

### 6.1 Conv2D 的反向传播

卷积是 DL 最常用的算子, BP 看着吓人, 实质是 **"卷积的转置 = 转置卷积"**。

**前向**:
$$Y_{i,j,k}=\sum_{c}\sum_{u,v} X_{i+u,j+v,c}\cdot W_{u,v,c,k}+b_k$$

记 kernel 大小 $K\times K$, stride $S$, padding $P$。

**反向 $\partial L/\partial X$**:
本质是 $\bar Y$ 与"翻转 kernel"的全卷积 (零填充 stride 1):
$$\bar X = \text{conv\_transpose2d}(\bar Y,\ W,\ \text{stride}=S)$$

**反向 $\partial L/\partial W$**:
本质是 $\bar Y$ 与 $X$ 的"互相关":
$$\bar W = \text{conv2d}(X,\ \bar Y,\ \text{stride}=1)$$

**反向 $\partial L/\partial b$**:
沿 batch + 空间维度累加:
$$\bar b_k = \sum_{i,j,n}\bar Y_{i,j,k,n}$$

```python
import torch
import torch.nn.functional as F

def conv2d_forward_backward(X, W, b, stride=1, padding=0):
    """
    用 PyTorch 验证 conv2d 的三个梯度公式
    """
    X = X.detach().requires_grad_(True)
    W = W.detach().requires_grad_(True)
    b = b.detach().requires_grad_(True)

    Y = F.conv2d(X, W, b, stride=stride, padding=padding)
    loss = Y.pow(2).sum()
    loss.backward()

    # 手算反向
    dY = 2.0 * Y                                # dL/dY
    # dW: 用 dY 和 X 做 conv (等价于 PyTorch 实现)
    dW_manual = F.conv2d(X.transpose(0, 1),    # NCHW -> CNHW
                         dY.transpose(0, 1),
                         padding=stride - 1).transpose(0, 1)
    # 注: 严格推导见教科书, 这里简化为 conv2d 的"梯度也是 conv2d"

    # dX: 用 dY 和翻转 W 做 conv_transpose
    dX_manual = F.conv_transpose2d(dY, W, stride=stride, padding=padding)
    # db: 沿 N, H, W 维度求和
    db_manual = dY.sum(dim=(0, 2, 3))

    assert torch.allclose(W.grad, dW_manual, atol=1e-4), "dW mismatch"
    assert torch.allclose(X.grad, dX_manual, atol=1e-4), "dX mismatch"
    assert torch.allclose(b.grad, db_manual, atol=1e-4), "db mismatch"
    print("Conv2D BP 验证通过")

# 示例
X = torch.randn(2, 3, 8, 8)
W = torch.randn(4, 3, 3, 3)
b = torch.randn(4)
conv2d_forward_backward(X, W, b)
```

> **核心洞察**: Conv 的反向 = Conv / ConvTranspose。"卷积算子的梯度还是卷积算子", 这是为什么 cuDNN 能把 conv 反向做到极致。

### 6.2 MaxPool / AvgPool 的 BP

**MaxPool**: 前向记录每个池化窗口的 argmax, 反向时只把 $\bar Y$ 放回 max 位置, 其余为 0。

**AvgPool**: 前向均分到窗口各位置, 反向时 $\bar Y$ 均分到对应输入位置。

```python
class MaxPool2d:
    """手写 MaxPool2d 前向 + 反向"""
    def __init__(self, kernel_size, stride=None):
        self.k = kernel_size
        self.s = stride or kernel_size

    def forward(self, X):
        # X: (N, C, H, W)
        N, C, H, W = X.shape
        h_out = (H - self.k) // self.s + 1
        w_out = (W - self.k) // self.s + 1

        # 展开窗口: (N, C, h_out, w_out, k, k)
        X_windows = X.unfold(2, self.k, self.s).unfold(3, self.k, self.s)
        # 记录 argmax
        self.argmax = X_windows.argmax(dim=(-1, -2))
        # 取 max
        Y = X_windows.max(dim=-1).values.max(dim=-1).values
        return Y

    def backward(self, dY):
        # 把 dY 散回 max 位置
        N, C, h_out, w_out = dY.shape
        dX = torch.zeros_like(self._X)
        # 用 scatter 实现 (简化: 假设 kernel=stride, 无重叠)
        idx_h = (self.argmax // self.k) * self.s
        idx_w = (self.argmax % self.k) * self.s
        # 逐位置 scatter
        for i in range(self.k):
            for j in range(self.k):
                mask = (self.argmax == i * self.k + j)
                dX[:, :, idx_h + i, idx_w + j] += dY * mask.float()
        return dX
```

> **工程实践**: 工业代码通常不手写 maxpool 反向, 直接用 PyTorch; 但面试可能让你手推公式。

### 6.3 RNN (LSTM/GRU) 的 BPTT

循环神经网络的 BP 沿时间反向传播 (**B**ack**P**ropagation **T**hrough **T**ime), 关键问题: 沿时间步累乘权重矩阵 $W_{hh}$, 容易梯度消失/爆炸。

**简化 RNN 前向**:
$$h_t = \tanh(W_{xh}x_t + W_{hh}h_{t-1} + b)$$

**BPTT 反向**:
$$\frac{\partial L}{\partial W_{hh}}=\sum_{t=1}^T \sum_{k=1}^t \frac{\partial h_t}{\partial h_k}\cdot \frac{\partial h_k}{\partial W_{hh}}$$

其中 $\frac{\partial h_t}{\partial h_k}=\prod_{i=k+1}^t \text{diag}(1-\tanh^2(W_{xh}x_i+W_{hh}h_{i-1}+b))\cdot W_{hh}$。

**LSTM 通过门控缓解梯度消失**:
遗忘门 $f_t$ 让 cell state $c_t$ 的梯度直接通过:
$$c_t = f_t \odot c_{t-1} + i_t \odot \tilde c_t \Rightarrow \frac{\partial c_t}{\partial c_{t-1}}=\text{diag}(f_t)$$

只要 $f_t\approx 1$, 梯度长距离传播。

```python
def lstm_forward_backward(x_seq, h0, c0, W_ih, W_hh, b_ih, b_hh):
    """
    LSTM 单步 BPTT 简化演示 (PyTorch nn.LSTM 已封装)
    """
    # 实际工程直接用 nn.LSTM, 这里展示原理
    H = h0.size(-1)
    T = x_seq.size(0)

    h = h0
    c = c0
    for t in range(T):
        x = x_seq[t]
        gates = x @ W_ih.T + h @ W_hh.T + b_ih + b_hh
        i, f, g, o = gates.chunk(4, dim=-1)
        i = torch.sigmoid(i); f = torch.sigmoid(f)
        g = torch.tanh(g); o = torch.sigmoid(o)
        c = f * c + i * g
        h = o * torch.tanh(c)

    # 反向时沿时间从 T 反向到 1, 累加梯度
    # 实际由 autograd 自动处理
    return h, c
```

> **面试要点**: BPTT 是 RNN 的 BP, 不是另一种算法; 梯度消失的根因是 $\prod W_{hh}\cdot\text{diag}(\sigma')$。

### 6.4 Self-Attention 的 BP

Self-Attention 是 Transformer 的核心, BP 涉及多个矩阵乘法 + Softmax + Mask。

**前向** (单头):
$$Q=X W_Q,\ K=X W_K,\ V=X W_V$$
$$A=\text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}+\text{mask}\right)$$
$$Y=A V$$

**反向 (关键公式)**:
设 $\bar Y=\partial L/\partial Y$:

$$\bar V = A^\top \bar Y$$
$$\bar A = \bar Y V^\top$$
$$\bar P = \bar A \odot A - A \odot (\bar A \odot A)\cdot \mathbf{1}\cdot\mathbf{1}^\top\quad (\text{Softmax 反向})$$

其中 $P = \text{softmax}(\cdot)$, 简化:
$$\bar P = A \odot (\bar A - \sum_j \bar A_{ij} A_{ij})$$

继续:
$$\bar{QK^\top} = \bar P / \sqrt{d_k}$$
$$\bar Q = \bar{QK^\top} K,\quad \bar K = (\bar{QK^\top})^\top Q$$

最后:
$$\bar{W_Q}=X^\top \bar Q,\ \bar{W_K}=X^\top \bar K,\ \bar{W_V}=X^\top \bar V$$
$$\bar X = \bar Q W_Q^\top + \bar K W_K^\top + \bar V W_V^\top$$

```python
import torch
import torch.nn.functional as F

def attention_forward_backward(X, W_q, W_k, W_v):
    """Self-Attention 前向 + 手算反向"""
    X = X.detach().requires_grad_(True)
    W_q = W_q.detach().requires_grad_(True)
    W_k = W_k.detach().requires_grad_(True)
    W_v = W_v.detach().requires_grad_(True)

    Q = X @ W_q; K = X @ W_k; V = X @ W_v
    d = Q.size(-1)
    scores = Q @ K.transpose(-2, -1) / (d ** 0.5)
    A = F.softmax(scores, dim=-1)
    Y = A @ V
    Y.pow(2).sum().backward()

    # 手算反向
    dY = 2.0 * Y
    dV_manual = A.transpose(-2, -1) @ dY
    dA_manual = dY @ V.transpose(-2, -1)
    # softmax 反向: dScores = A * (dA - sum(dA*A, dim=-1, keepdim=True))
    dScores = A * (dA_manual - (dA_manual * A).sum(dim=-1, keepdim=True))
    dScores /= d ** 0.5

    dQ_manual = dScores @ K
    dK_manual = dScores.transpose(-2, -1) @ Q
    dWq_manual = X.transpose(-2, -1) @ dQ_manual
    dWk_manual = X.transpose(-2, -1) @ dK_manual
    dWv_manual = X.transpose(-2, -1) @ dV_manual

    assert torch.allclose(W_q.grad, dWq_manual, atol=1e-4)
    assert torch.allclose(W_k.grad, dWk_manual, atol=1e-4)
    assert torch.allclose(W_v.grad, dWv_manual, atol=1e-4)
    print("Self-Attention BP 验证通过")
```

> **Flash-Attention 优化**: 前向时把 softmax 反向重写为"在线算法", 减少显存 IO。面试可提一嘴。

### 6.5 Embedding 层的 BP

Embedding 是"查表", $X$ 是整数索引, $W\in\mathbb{R}^{V\times d}$。

**前向**: `Y[i] = W[X[i]]`

**反向**: 只更新被查过的行:
$$\frac{\partial L}{\partial W_{v,:}}=\sum_{i:X_i=v} \bar Y_{i,:}$$

```python
def embedding_backward(dY, X, num_embeddings, embedding_dim):
    """
    dY: (B, T, d)
    X:  (B, T) long
    """
    dW = torch.zeros(num_embeddings, embedding_dim, device=dY.device)
    dW.index_add_(0, X.flatten(), dY.reshape(-1, embedding_dim))
    return dW
```

### 6.6 Dropout 的 BP

Dropout 前向以概率 $p$ 随机置 0, 反向时对应位置也要置 0 (用相同 mask):

```python
class Dropout:
    def __init__(self, p=0.5):
        self.p = p

    def forward(self, X, training=True):
        if not training:
            return X
        self.mask = (torch.rand_like(X) > self.p).float() / (1 - self.p)
        return X * self.mask

    def backward(self, dY):
        return dY * self.mask
```

> **关键**: 训练/推理必须一致地应用 mask; `inverted dropout` 用的 `/ (1-p)` 补偿期望。

### 6.7 面试汇总表

| 算子 | 反向核心 | 复杂度 |
| :--- | :--- | :--- |
| Linear | 3 个矩阵乘法 | $O(B d_{in} d_{out})$ |
| Conv2d | conv / conv_transpose | $O(B C H W k^2)$ |
| MaxPool | argmax scatter | $O(B C H W)$ |
| RNN | BPTT (时间连乘) | $O(T \cdot \|\theta\|)$ |
| LSTM | BPTT + 门控稳定 | $O(T \cdot 4H^2)$ |
| Attention | 4 个 matmul + softmax 反 | $O(T^2 d)$ |
| Embedding | index_add | $O(N_{\text{used}})$ |
| Dropout | mask | $O(N)$ |

- Conv 的 BP 仍是 Conv/ConvTranspose; cuDNN 性能极致。
- RNN 用 BPTT, 梯度消失/爆炸根因是时间维度连乘。
- Attention 的 BP 公式多, 但拆开都是矩阵 BP + Softmax 反。
- 实战用框架, 面试能手推关键算子即可。

## 7. 计算图与自动微分 (Autograd)

### 7.1 计算图 (Computation Graph)

**定义**: 计算图是有向无环图 (DAG), 节点是**算子**或**变量**, 边是数据流方向。

```text
x ─┐
   ├─→ [+] ─→ z ─→ [exp] ─→ y ─→ [sum] ─→ L
b ─┘                            ↑
                                 └── ∂L/∂y
```

**两种范式**:
1. **静态图 (TF1.x / Theano)**: 先构建完整图, 再喂数据; 优化在编译期完成。
2. **动态图 (PyTorch / TF2 Eager)**: 边执行边建图, 灵活, 易 debug。

> PyTorch 默认动态图, 但 `torch.compile` (Dynamo) 可以捕获并图优化。

---

### 7.2 拓扑序与反向遍历

反向传播需要按**拓扑逆序**遍历图 (后向先于前向完成)。

```python
def topo_sort(root):
    """Kahn 算法或 DFS 生成拓扑序"""
    topo = []
    visited = set()
    def build(v):
        if v not in visited:
            visited.add(v)
            for child in v._prev:
                build(child)
            topo.append(v)
    build(root)
    return topo

def backward(root):
    topo = topo_sort(root)
    root.grad = 1.0
    for v in reversed(topo):
        v._backward()  # 调用算子的局部反向函数
```

### 7.3 PyTorch autograd 三大核心

**(1) `torch.Tensor`**
- `.requires_grad=True` 启动追踪
- `.grad` 保存梯度
- `.grad_fn` 指向创建该 tensor 的算子 (Function)
- `.is_leaf` 标记是否叶子节点

**(2) `torch.autograd.Function`**
- 自定义算子的基类, 实现 `forward()` 和 `backward()`
- `ctx` 用于保存反向需要的信息

**(3) `torch.autograd.grad` / `.backward()`**
- 计算并填充 `.grad`

```python
import torch

class MyReLU(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x):
        ctx.save_for_backward(x)
        return x.clamp(min=0)

    @staticmethod
    def backward(ctx, grad_output):
        x, = ctx.saved_tensors
        return grad_output * (x > 0).float()

# 使用
x = torch.randn(3, requires_grad=True)
y = MyReLU.apply(x)
y.sum().backward()
print(x.grad)
```

### 7.4 微分方程视角

设网络是 ODE $\dot x = f_\theta(x, t)$, 反向模式 AD 等价于求解伴随方程 (adjoint method):
$$\dot \bar x = -\left(\frac{\partial f}{\partial x}\right)^\top \bar x$$

ODE-Net / Neural ODE 用此节省内存 (无需存中间状态)。

---

### 7.5 反向模式 vs 前向模式

| | 反向模式 (Reverse) | 前向模式 (Forward) |
| :--- | :--- | :--- |
| 计算次数 | 1 次 (反向) | n 次 (每个输入一次) |
| 适合 | 输出标量, 输入多 (loss 对 params) | 输入少, 输出多 (Jacobian-vector) |
| 代表 | PyTorch, TF, JAX | JAX (jvp), ForwardDiff.jl |
| 内存 | 需存中间激活 | 不需存 |

PyTorch 默认**反向模式**, 因为 loss 是标量、params 是百万维, 反向一次出全部梯度。

### 7.6 计算图优化 (Graph Optimization)

现代框架对计算图做大量优化:

- **算子融合 (Operator Fusion)**: 把多个小算子合并成一个 CUDA kernel, 减少 launch overhead。
  - 例: `bias + ReLU` → 单一 fused kernel
- **常量折叠**: 编译期计算常量表达式。
- **死代码消除**: 删除结果未使用的算子。
- **内存复用**: 原地算子减少分配。

`torch.compile` (TorchInductor) 自动做这些优化。

### 7.8 `torch.no_grad()` 与 `detach()` 的本质

- `torch.no_grad()`: 上下文管理器, 内部所有 op 不建图, 用于推理/评估。
- `x.detach()`: 返回一个**共享存储但不追踪梯度**的 tensor。

**何时用**:
- 评估指标计算: `with torch.no_grad(): ...`
- 切断计算图分支: `loss_a + x.detach() * 0` 让 $x$ 不影响 $loss_a$ 的梯度
- EMA 更新: `ema_param = ema_param * 0.99 + param.detach() * 0.01`

### 7.9 自定义 autograd 完整示例: 二阶多项式

```python
import torch

class Poly2(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x, a, b, c):
        # y = a*x^2 + b*x + c
        ctx.save_for_backward(x)
        ctx.a, ctx.b = a, b
        return a * x ** 2 + b * x + c

    @staticmethod
    def backward(ctx, grad_output):
        x, = ctx.saved_tensors
        # dy/dx = 2*a*x + b; dy/da = x^2; dy/db = x; dy/dc = 1
        return grad_output * (2 * ctx.a * x + ctx.b), \
               grad_output * (x ** 2), \
               grad_output * x, \
               grad_output

x = torch.tensor(3.0, requires_grad=True)
a = torch.tensor(1.0, requires_grad=True)
b = torch.tensor(2.0, requires_grad=True)
c = torch.tensor(0.5, requires_grad=True)

y = Poly2.apply(x, a, b, c)
y.backward()

# 验证
print("dy/dx =", x.grad.item(), "expected:", 2*1*3 + 2)  # 8
print("dy/da =", a.grad.item(), "expected:", 9)          # x^2
print("dy/db =", b.grad.item(), "expected:", 3)          # x
print("dy/dc =", c.grad.item(), "expected:", 1)
```

### 7.10 面试题精选

**Q1**: PyTorch 的动态图和 TF1.x 的静态图各有什么优劣?

> 答: 动态图灵活、易调试、所见即所得; 静态图可优化、能序列化部署到生产。TF2 Eager 已基本靠拢 PyTorch 的动态图。

**Q2**: `loss.backward()` 之后, 中间变量的 `.grad` 默认是什么?

> 答: 默认是 `None`。PyTorch 只保留**叶子节点** (叶子参数) 的梯度, 中间激活通过 `retain_graph=True` 或 hook 才能保留。

**Q3**: 如何在反向时节省显存?

> 答: (1) `with torch.no_grad()` 不建图; (2) `checkpoint` 用时间换空间; (3) gradient accumulation 减少中间状态; (4) FP16/BF16 减半精度; (5) ZeRO / FSDP 分片。

- **计算图 = DAG**, 反向 = 拓扑逆序遍历。
- **PyTorch 三件套**: Tensor / Function / backward。
- **反向模式**适配 DL (loss 标量, params 高维)。
- **图优化** (算子融合) 是工业级性能关键。

## 8. 梯度检查 (Gradient Check) 与数值稳定性

### 8.1 数值微分: 中心差分

中心差分公式:
$$f'(x)\approx \frac{f(x+h)-f(x-h)}{2h}$$

误差 $O(h^2)$, 选 $h=10^{-5}$ 平衡截断/舍入误差。

```python
def numerical_grad(f, x, h=1e-5):
    """中心差分, 返回与 x 同形状的梯度"""
    grad = np.zeros_like(x)
    it = np.nditer(x, flags=['multi_index'])
    while not it.finished:
        idx = it.multi_index
        old = x[idx]
        x[idx] = old + h
        fx_plus = f(x).copy()
        x[idx] = old - h
        fx_minus = f(x).copy()
        grad[idx] = (fx_plus - fx_minus) / (2 * h)
        x[idx] = old
        it.iternext()
    return grad
```

**为什么不用前向差分** $(f(x+h)-f(x))/h$?
误差 $O(h)$, 即使 $h=10^{-5}$ 也比中心差分精度差 4 个数量级。

### 8.2 torch.autograd.gradcheck

PyTorch 内置 `gradcheck` 用数值微分自动验证自定义算子:

```python
import torch

class MyOp(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x, w):
        ctx.save_for_backward(x, w)
        return x @ w

    @staticmethod
    def backward(ctx, grad_output):
        x, w, = ctx.saved_tensors
        return grad_output @ w.T, x.T @ grad_output

x = torch.randn(3, 4, dtype=torch.double, requires_grad=True)
w = torch.randn(4, 5, dtype=torch.double, requires_grad=True)

# gradcheck 用 double 精度, 用微小扰动
torch.autograd.gradcheck(MyOp.apply, (x, w), eps=1e-6, atol=1e-4)
torch.autograd.gradgradcheck(MyOp.apply, (x, w), eps=1e-6, atol=1e-4)  # 二阶检查
```

> **实战**: 每写一个自定义算子, 都必须跑 `gradcheck`, 这是工业级铁律。

### 8.3 梯度消失 (Vanishing Gradient)

**根因**: 深层网络梯度是雅可比连乘 $\prod_l J_l$, 若每个 $\|J_l\|<1$, 梯度指数衰减到 0。

**典型症状**:
- 训练 loss 不下降, 但模型不是随机
- 浅层梯度接近 0 (打印各层梯度范数可见)
- sigmoid/tanh 饱和区也加剧

**对策**:
1. **ReLU 替代 sigmoid**: ReLU 梯度恒为 1 (正半轴), 不衰减。
2. **残差连接 (ResNet)**: $\partial y/\partial x = 1 + \partial F/\partial x$, 多了一条"直通车"。
3. **归一化 (BN/LN)**: 保持激活分布稳定。
4. **He/Xavier 初始化**: 让前向后向方差一致。
5. **LSTM/GRU**: 门控让梯度不衰减。

```python
def check_vanishing_grad(model, x):
    """打印每层梯度范数, 看是否递减"""
    y = model(x).sum()
    y.backward()
    for name, p in model.named_parameters():
        if p.grad is not None:
            print(f"{name:30s} grad norm: {p.grad.norm():.4e}")
```

---

### 8.4 梯度爆炸 (Exploding Gradient)

**根因**: $\|J_l\|>1$ → 指数爆炸; 常见于 RNN 长序列、深度无残差网络。

**对策**:
1. **梯度裁剪 (Gradient Clipping)**:
   - By value: $g=\max(-\tau,\min(g,\tau))$
   - By norm: $g=g\cdot\min(1,\tau/\|g\|)$ ← 更常用
2. **权重初始化**: Xavier/He
3. **小学习率**: 缓解但不根本
4. **LayerNorm**: 在 RNN 中常用

```python
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
# 或者手动:
for p in model.parameters():
    if p.grad is not None:
        p.grad.data.clamp_(-1.0, 1.0)
```

### 8.5 NaN / Inf 排查清单

| 现象 | 常见原因 | 排查 |
| :--- | :--- | :--- |
| loss=NaN | log(0), 除 0, 数值溢出 | `torch.isnan(loss)` |
| grad=NaN | 链上某处 NaN 传入 | hook 每层, 定位第一处 |
| loss=Inf | exp 溢出, lr 过大 | 减小 lr, 改用 bf16 |
| grad=Inf | 同上 | 加 grad clip |

```python
def check_finite(model):
    """训练循环中检查 NaN/Inf"""
    for name, p in model.named_parameters():
        if not torch.isfinite(p).all():
            raise RuntimeError(f"Non-finite weight in {name}")
        if p.grad is not None and not torch.isfinite(p.grad).all():
            raise RuntimeError(f"Non-finite grad in {name}")
```

### 8.6 数值稳定性技巧

**(1) log-sum-exp 稳定化**:
$$\log\sum_i e^{x_i}=\max(x)+\log\sum_i e^{x_i-\max(x)}$$

```python
def logsumexp(x, dim=-1):
    m, _ = x.max(dim=dim, keepdim=True)
    return m.squeeze(dim) + (x - m).exp().sum(dim=dim).log()
```

**(2) Softmax 稳定**:
减 max 后再 exp, 避免溢出。

**(3) LayerNorm 后向数值稳定**:
对 $\sqrt{\sigma^2+\epsilon}$, $\epsilon$ 防 0; 反向时 $\partial \bar x/\partial \sigma^2$ 项要小心除 0。

**(4) AMP (Automatic Mixed Precision)**:
fp32 存 master weight, fp16/bf16 算前向 + 反向; loss scaling 防梯度 underflow。

```python
scaler = torch.amp.GradScaler('cuda')
with torch.amp.autocast('cuda'):
    loss = model(x)
scaler.scale(loss).backward()
scaler.unscale_(optimizer)
torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
scaler.step(optimizer)
scaler.update()
```

| dtype | 范围 | 精度 | 用途 |
| :--- | :--- | :--- | :--- |
| fp32 | ±3.4e38 | ~7 位 | 默认 |
| fp16 | ±6.5e4 | ~3 位 | 推理/加速 |
| bf16 | ±3.4e38 | ~3 位 | 训练 (Ampere+) |
| fp8 (E4M3) | ±448 | ~2 位 | LLM 推理 |

### 8.8 面试题精选

**Q1**: 如何系统排查梯度消失?

> 答: (1) 打印每层 grad norm, 看是否递减到 0; (2) 换 ReLU/残差/LN; (3) 用 Xavier/He 初始化; (4) 减小网络深度验证假设; (5) 用 `torch.autograd.gradcheck` 确认算子正确。

**Q2**: 为什么 AMP 用 loss scaling 而不是梯度缩放?

> 答: fp16 范围小, 小梯度易 underflow; 乘一个很大系数 $S$ (如 65536), 让 fp16 梯度变成 fp16 范围内的"大数", 再反传; 反传后除 $S$ 还原。Loss scaling 比 grad scaling 更简单, 因为只动 loss 一个数。

**Q3**: `gradcheck` 用什么 dtype? 为什么?

> 答: float64。因为数值差分需要高精度避免自身误差淹没分析梯度; float32 数值误差可能让相对误差 > 1e-3。

- **梯度爆炸**: 梯度裁剪是兜底。
- **数值稳定**: log-sum-exp 减 max, AMP + bf16 + loss scaling。
- **NaN 排查**: hook 定位, 永远不要"硬扛 NaN 训练"。

## 9. 高阶梯度 (Higher-Order) 与元学习

### 9.1 为什么需要高阶梯度

普通 BP 只算一阶梯度, 但很多场景需要 $\frac{\partial^2 L}{\partial \theta^2}$ 或更高阶:

- **二阶优化**: Newton / L-BFGS / K-FAC
- **元学习 (MAML)**: 梯度的梯度
- **物理仿真 + PDE**: Neural ODE 的 adjoint
- **Hessian 分析**: loss landscape 可视化

---

### 9.2 一阶 vs 二阶方法

| 方法 | 信息 | 步 | 复杂度 | 收敛 |
| :--- | :--- | :--- | :--- | :--- |
| SGD | $\nabla L$ | $-\eta \nabla L$ | $O(n)$ | 慢, 易震荡 |
| Newton | $\nabla L, H=\nabla^2 L$ | $-H^{-1}\nabla L$ | $O(n^3)$ | 快, 二次 |
| L-BFGS | $\nabla L$, 梯度历史近似 | quasi-Newton | $O(n)$ | 快 |
| K-FAC | Fisher 矩阵分块近似 | 自然梯度 | $O(n^{1.5})$ | 中等 |
| Adam | 一阶 + 自适应 | $-\eta \hat m/\sqrt{\hat v}$ | $O(n)$ | 实用首选 |

---

### 9.3 Hessian 矩阵

Hessian $H_{ij}=\partial^2 L/\partial\theta_i\partial\theta_j$ 表征 loss 在 $\theta$ 处的曲率。

**作用**:
- 判断局部极小 vs 鞍点 (Hessian 特征值正负)
- 二阶优化的核心
- loss landscape 分析

**计算**:
- **显式**: `torch.autograd.functional.hessian(loss_fn, params)` — 慢
- **Hutchinson 估计**: $\text{tr}(H)\approx \mathbb E_v[v^\top H v]$, 用 HVP

```python
def hessian_vector_product(loss_fn, params, v):
    """HVP: H @ v, 用反向模式 BP 一次搞定"""
    # 1) 一阶梯度
    grads = torch.autograd.grad(loss_fn, params, create_graph=True)
    grad_flat = torch.cat([g.flatten() for g in grads])
    # 2) 梯度对 v 再求导
    v_flat = torch.cat([vv.flatten() for vv in v])
    hvp = torch.autograd.grad(grad_flat @ v_flat, params)
    return hvp

def hessian_trace(loss_fn, params, num_samples=10):
    """Hutchinson 估计 tr(H)"""
    trace = 0
    for _ in range(num_samples):
        v = [torch.randn_like(p) for p in params]
        hvp = hessian_vector_product(loss_fn, params, v)
        trace += sum((h * vv).sum() for h, vv in zip(hvp, v))
    return trace.item() / num_samples
```

---

### 9.4 L-BFGS 优化器

L-BFGS 用最近 $m$ 步的梯度/参数差, 近似 Hessian 的逆, 内存 $O(mn)$ 而非 $O(n^2)$。

```python
optimizer = torch.optim.LBFGS(model.parameters(), lr=1.0, max_iter=20, history_size=100)

def closure():
    optimizer.zero_grad()
    output = model(x)
    loss = criterion(output, y)
    loss.backward()
    return loss

optimizer.step(closure)
```

> 适用: 小批量凸优化 / 物理仿真; 大模型训练仍是 Adam 系列。

---

### 9.5 元学习 (MAML) 与"梯度的梯度"

**MAML (Model-Agnostic Meta-Learning)** 核心思想: 找一组参数, 让它在**任意任务**上**一步 fine-tune 后**就能泛化。

**数学**:
$$\theta^* = \arg\min_\theta \sum_{\text{task } \tau} L_\tau(\theta - \alpha \nabla_\theta L_\tau(\theta))$$

即 $\theta$ 的更新方向本身依赖 $\theta$ 的梯度, 这是**二阶梯度**!

```python
# MAML 简化伪代码
inner_lr = 0.01
meta_lr = 0.001
theta = init_params()

for task_batch in dataloader:
    meta_grad = 0
    for task in task_batch:
        # 内循环: 在 task 上做一次更新
        theta_prime = theta - inner_lr * grad(L_task, theta)
        # 外循环: 用更新后的参数在 query 集上算 meta loss
        meta_loss += L_query(theta_prime, task)
    # 对 theta 求 meta_loss 的梯度 (包含二阶项)
    meta_grad = grad(meta_loss, theta, create_graph=True)
    theta = theta - meta_lr * meta_grad
```

> **关键**: `create_graph=True` 让一阶梯度的反向图保留, 才能继续对 $\theta$ 求导。

---

### 9.6 Neural ODE 与 Adjoint Method

Neural ODE 把层视为 ODE 的离散化: $x(t+1)=x(t)+f_\theta(x(t), t)$。

**问题**: 反向时需要存每层状态, 显存 $O(T)$。

**Adjoint Method**: 引入伴随变量 $a(t)=\partial L/\partial x(t)$, 解反向 ODE:
$$\dot a(t) = -a(t)^\top \frac{\partial f_\theta}{\partial x(t)}$$

**优点**: 只需当前状态, 显存 $O(1)$。
**代价**: 多一次 ODE 求解。

```python
from torchdiffeq import odeint

class ODEFunc(torch.nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.net = torch.nn.Sequential(
            torch.nn.Linear(dim, dim),
            torch.nn.Tanh(),
            torch.nn.Linear(dim, dim))

    def forward(self, t, x):
        return self.net(x)

func = ODEFunc(2)
y0 = torch.tensor([1.0, 0.0], requires_grad=True)
t = torch.linspace(0, 1, 100)

# 前向 ODE
y = odeint(func, y0, t, method='dopri5')
loss = y[-1].sum()

# Adjoint 反向 (torchdiffeq 自动处理)
loss.backward()
print(y0.grad)
```

---

### 9.7 Fisher 信息矩阵 (FIM)

Fisher $F = \mathbb E[\nabla\log p(y|x)\nabla\log p(y|x)^\top]$, 是 KL 散度的局部二阶近似, 用于:

- **自然梯度**: $\Delta\theta = F^{-1}\nabla L$, 比 SGD 更优
- **TRPO/PPO**: 用 Fisher 限制 KL 步长
- **Kronegcker-Factored Approximate Curvature (K-FAC)**: 加速自然梯度

> 训练大模型时, 完整 FIM 不可行, 用对角 / 分块 / K-FAC 近似。

---

### 9.8 面试题精选

**Q1**: 简述 MAML 为什么需要二阶梯度?

> 答: 因为元优化目标是"内循环更新后"的表现, 而内循环更新本身依赖 $\theta$。展开后 meta loss 对 $\theta$ 的导数包含 $(\nabla L_\tau(\theta))$ 的导数, 即二阶项。简化版 FOMAML 忽略二阶, 牺牲精度换速度。

**Q2**: 训练 LLM 为什么不直接用二阶方法?

> 答: Hessian $O(n^2)$ 内存 + $O(n^3)$ 反演, 对亿级参数不可行。即使 L-BFGS 也要存历史梯度, 内存压力远大于 Adam 系列。工程上 Adam + 梯度裁剪已经"够好"。

**Q3**: `create_graph=True` 的本质是什么?

> 答: 让反向传播**保留计算图**, 这样一阶梯度本身仍是叶子节点的函数, 可以再次反向。是所有二阶方法的基础开关。

---

### 9.9 本节小结

- **一阶 vs 二阶**: Adam 实用首选, 二阶用在凸优化/小模型/物理仿真。
- **HVP**: 一次反向算出 Hessian-vector product, $O(n)$ 而非 $O(n^2)$。
- **MAML**: 元学习需要二阶, FOMAML 简化为只保一阶。
- **Neural ODE**: Adjoint 方法把反向从"存储所有状态"变成"重解 ODE"。

## 10. 工业实践 + 面试题汇总

### 10.1 工业级训练循环模板

```python
import torch
import torch.nn as nn
from torch.utils.data import DataLoader

def train(model, dataset, epochs=10, lr=1e-3, batch_size=64, device='cuda'):
    model.to(device)
    optimizer = torch.optim.AdamW(model.parameters(), lr=lr, weight_decay=1e-2)
    scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=epochs)
    scaler = torch.amp.GradScaler('cuda')

    loader = DataLoader(dataset, batch_size=batch_size, shuffle=True, num_workers=4)
    for epoch in range(epochs):
        model.train()
        for x, y in loader:
            x, y = x.to(device), y.to(device)
            optimizer.zero_grad(set_to_none=True)

            with torch.amp.autocast('cuda', dtype=torch.bfloat16):
                logits = model(x)
                loss = nn.functional.cross_entropy(logits, y)

            scaler.scale(loss).backward()
            scaler.unscale_(optimizer)
            torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
            scaler.step(optimizer)
            scaler.update()
            scheduler.step()
```

**关键点**:
- `set_to_none=True` 比 `zero_grad()` 省一次显存分配
- `bfloat16` 比 `float16` 不需要 loss scaling
- 梯度裁剪防爆
- Cosine scheduler 平滑学习率

### 10.2 显存优化 6 大技巧

1. **Gradient Accumulation**: 多个 micro-batch 累积梯度再 update
   ```python
   for i, (x, y) in enumerate(loader):
       loss = model(x, y) / accum_steps
       loss.backward()
       if (i + 1) % accum_steps == 0:
           optimizer.step()
           optimizer.zero_grad()
   ```

2. **Gradient Checkpointing**: 时间换空间, 不存中间激活
   ```python
   from torch.utils.checkpoint import checkpoint

   ```

3. **Mixed Precision (AMP)**: fp16/bf16 减半精度

4. **ZeRO / FSDP**: 分片 optimizer state, gradient, parameter
   ```python
   from torch.distributed.fsdp import fully_shard
   model = fully_shard(model)
   ```

5. **LoRA / Adapter**: 只训低秩矩阵, 主参数冻结

6. **Offloading**: CPU/NVMe swap (DeepSpeed)

### 模板 1: 手撕 `numpy` 版 SGD + Momentum

```python
import numpy as np

class SGDWithMomentum:
    def __init__(self, params, lr=1e-2, momentum=0.9):
        self.lr = lr
        self.momentum = momentum
        self.vel = [np.zeros_like(p) for p in params]
        self.params = params

    def step(self, grads):
        for p, v, g in zip(self.params, self.vel, grads):
            v[...] = self.momentum * v + g            # 累积速度
            p[...] -= self.lr * v                     # 沿速度更新

class Adam:
    def __init__(self, params, lr=1e-3, b1=0.9, b2=0.999, eps=1e-8):
        self.lr, self.b1, self.b2, self.eps = lr, b1, b2, eps
        self.m = [np.zeros_like(p) for p in params]
        self.v = [np.zeros_like(p) for p in params]
        self.t = 0
        self.params = params

    def step(self, grads):
        self.t += 1
        for p, m, v, g in zip(self.params, self.m, self.v, grads):
            m[...] = self.b1 * m + (1 - self.b1) * g
            v[...] = self.b2 * v + (1 - self.b2) * (g ** 2)
            m_hat = m / (1 - self.b1 ** self.t)
            v_hat = v / (1 - self.b2 ** self.t)
            p[...] -= self.lr * m_hat / (np.sqrt(v_hat) + self.eps)
```

### 模板 2: 手撕 `numpy` 版 BatchNorm (前向 + 反向)

```python
class BatchNorm1d:
    def __init__(self, dim, eps=1e-5, momentum=0.1):
        self.gamma = np.ones(dim)
        self.beta = np.zeros(dim)
        self.eps = eps
        self.momentum = momentum
        self.running_mean = np.zeros(dim)
        self.running_var = np.ones(dim)

    def forward(self, x, training=True):
        if training:
            mu = x.mean(axis=0)
            var = x.var(axis=0)
            self.x_hat = (x - mu) / np.sqrt(var + self.eps)
            self.running_mean = (1 - self.momentum) * self.running_mean + self.momentum * mu
            self.running_var = (1 - self.momentum) * self.running_var + self.momentum * var
        else:
            self.x_hat = (x - self.running_mean) / np.sqrt(self.running_var + self.eps)
        return self.gamma * self.x_hat + self.beta

    def backward(self, dY):
        B = dY.shape[0]
        dx_hat = dY * self.gamma
        dvar = (dx_hat * (self.x_hat * -0.5 * (self._var + self.eps) ** -1.5)).sum(axis=0)
        dmu = (dx_hat * -1 / np.sqrt(self._var + self.eps)).sum(axis=0) \
              + dvar * (-2 * (self._x - self._mu)).mean(axis=0)
        dX = dx_hat / np.sqrt(self._var + self.eps) \
             + dvar * 2 * (self._x - self._mu) / B \
             + dmu / B
        dgamma = (dY * self.x_hat).sum(axis=0)
        dbeta = dY.sum(axis=0)
        return dX, dgamma, dbeta
```

### 模板 3: 手撕 Softmax + CE + 反向

```python
def softmax_ce(z, t):
    """
    z: (B, C) logits
    t: (B,) labels
    return: loss (scalar), d_logits (B, C)
    """
    z_shift = z - z.max(axis=1, keepdims=True)
    exp = np.exp(z_shift)
    p = exp / exp.sum(axis=1, keepdims=True)
    B = z.shape[0]
    loss = -np.log(p[np.arange(B), t]).mean()
    grad = p.copy()
    grad[np.arange(B), t] -= 1
    grad /= B
    return loss, grad
```

```python
class Dropout:
    def __init__(self, p=0.5):
        self.p = p

    def forward(self, x, training=True):
        if not training:
            return x
        self.mask = (np.random.rand(*x.shape) > self.p) / (1 - self.p)
        return x * self.mask

    def backward(self, dy):
        return dy * self.mask
```

```python
def gradient_check(model, x, t, eps=1e-5, tol=1e-5):
    """用中心差分验证解析梯度"""
    # 解析梯度
    y = model.forward(x)
    grads = model.backward(t)

    # 数值梯度
    flat_params = model.flatten()
    flat_grads_num = np.zeros_like(flat_params)

    for i in range(flat_params.size):
        old = flat_params[i]

        flat_params[i] = old + eps
        model.unflatten(flat_params)
        loss_plus = model.loss(x, t)

        flat_params[i] = old - eps
        model.unflatten(flat_params)
        loss_minus = model.loss(x, t)

        flat_params[i] = old
        flat_grads_num[i] = (loss_plus - loss_minus) / (2 * eps)

    model.unflatten(flat_params)

    rel_err = np.abs(flat_grads_num - np.concatenate([g.flatten() for g in grads]))
    rel_err = rel_err / (np.abs(flat_grads_num) + np.abs(np.concatenate([g.flatten() for g in grads])) + 1e-8)
    max_err = rel_err.max()

    print(f"Max relative error: {max_err:.2e}")
    assert max_err < tol, "Gradient check FAILED!"
    print("Gradient check PASSED")
```

## 深度扩展 · 多视角系统展开(续)

### 110. 反向传播 (Backpropagation) 与计算图 - 优化视角 视角

**核心议题**: 本节从优化视角视角切入,系统展开 "反向传播 (Backpropagation) 与计算图" 的相关讨论。

**1. 背景与动机**

任何技术或方法的出现都不是孤立的,而是回应特定历史条件下的具体问题。"反向传播 (Backpropagation) 与计算图" 的发展也不例外。要理解它,必须回到它出现的那个时间点,看清它要解决的真实问题是什么。当时的主流方案有哪些不足? 它的提出填补了哪些空白? 这些问题的回答,决定了我们今天该如何使用它。

从知识论角度看,**技术演进是问题驱动的**——不是先有方案再找问题,而是先有问题再有方案。这个观察可以帮助我们避免"拿着锤子找钉子"的陷阱,真正把方法用对地方。

历史维度上,我们看到三个规律:

1. **从特殊到一般**: 早期方法往往针对特定场景,后期抽象出通用框架。学习的认知规律也是先掌握具体案例,再抽象出一般模式。这种"自下而上"的学习方式,在机器学习模型的设计里反复出现。

2. **从手工到自动**: 经验规则逐步被数据驱动的方法取代。在早期,很多 AI 系统依赖人工编写的规则。统计学习方法的崛起让"从数据中学习"成为可能。深度学习进一步把特征工程也自动化了。今天的大模型时代,我们看到端到端学习从感知扩展到了推理与生成。

3. **从局部到全局**: 关注单个组件,演进到关注整个系统。早期模型评估只关注单点指标,现在更关注全链路的协同效应。这种"系统视角"的转变,与软件工程从单体架构到微服务架构的演进高度相似。

**2. 优化视角视角的展开**

从优化视角视角出发,我们可以把 "反向传播 (Backpropagation) 与计算图" 拆解为以下几个层次:

**第一层: 概念层** —— 这是最抽象的层次,定义了我们要研究的对象是什么。例如,"推荐系统"在概念层是一个"为用户从物品集合中筛选合适物品"的问题。这个层次的特点是清晰、稳定、不易变化。一个好的概念定义应该具备几个特征:可操作性、可测量性、可扩展性。

**第二层: 模型层** —— 把概念实例化为数学模型。同一概念可以有不同的模型化方式,例如"推荐系统"可以是协同过滤、矩阵分解、深度学习等。模型的选择决定了后续算法的空间,也决定了能利用的归纳偏置(比如序列模型擅长捕捉时序依赖,图模型擅长建模关系结构)。模型选型是工程实践中最重要的决策之一。

**第三层: 算法层** —— 在选定模型下,具体的求解方法。这一层最活跃,新算法层出不穷。同一模型往往有多种算法,各有优劣。例如同样是优化深度网络,可以选择 SGD、Adam、L-BFGS 等不同算法。算法的选择要考虑收敛速度、数值稳定性、计算成本等多个维度。

**第四层: 工程层** —— 算法落地的实现细节,包括数据流水线、训练框架、推理优化、监控告警等。工程层是研究到生产的桥梁,决定了一个方法能否真正用起来。一个在论文里表现很好的算法,如果不能高效实现、不能稳定运行、不能快速迭代,就没有实际价值。工程能力是把研究转化为生产力的关键。

**第五层: 业务层** —— 在具体业务场景中的表现。同一技术在不同业务里效果差异巨大,因为业务目标、数据分布、用户行为都有差异。从业务视角看技术,我们必须回答几个问题:这个技术解决了什么业务问题?投入产出比如何?长期可持续吗?技术评估必须与业务目标对齐,否则容易陷入"技术自嗨"的陷阱。

**3. 数学形式化(简洁版)**

虽然我们强调优化视角视角,但数学形式化提供了共同语言。机器学习的核心问题可以表达为:给定输入样本,学习一个映射函数,使得函数输出与真实目标的差距最小化。这个抽象捕捉了分类、回归、生成等大多数任务的本质。

进一步,优化目标通常加入正则化项来控制模型复杂度,平衡经验风险与模型容量。统计学习理论给出了泛化误差的上界,告诉我们模型越复杂并不一定越好——**奥卡姆剃刀**在数学上有严格的形式化。

偏差-方差分解是另一个核心框架:误差可以分解为模型偏差(欠拟合)、方差(过拟合)和不可约噪声三部分。理解这个分解有助于诊断模型表现、选择合适复杂度。

在数值稳定性方面,有几个常见陷阱: 浮点数精度有限、Log-Sum-Exp 计算要减去最大值、Softmax 在大数值下会溢出。这些工程细节常常决定一个模型能否在生产环境稳定运行。

**4. 信息论视角**

信息论为"反向传播 (Backpropagation) 与计算图" 提供了统一的视角:**学习的本质是从数据中提取与目标相关的信息**。

互信息衡量知道一个变量后,另一个变量不确定性减少的量。在机器学习中,它被广泛用于特征选择、表示学习、多模态对齐等场景。

KL 散度衡量两个概率分布的距离,在交叉熵损失、变分推断、策略梯度等场景无处不在。需要注意它是**不对称**的——不同方向有不同的解释。

**3. 数学形式化(简洁版)**

虽然我们强调可视化视角,但数学形式化提供了共同语言。机器学习的核心问题可以表达为:给定输入样本,学习一个映射函数,使得函数输出与真实目标的差距最小化。这个抽象捕捉了分类、回归、生成等大多数任务的本质。

进一步,优化目标通常加入正则化项来控制模型复杂度,平衡经验风险与模型容量。统计学习理论给出了泛化误差的上界,告诉我们模型越复杂并不一定越好——**奥卡姆剃刀**在数学上有严格的形式化。

偏差-方差分解是另一个核心框架:误差可以分解为模型偏差(欠拟合)、方差(过拟合)和不可约噪声三部分。理解这个分解有助于诊断模型表现、选择合适复杂度。

在数值稳定性方面,有几个常见陷阱: 浮点数精度有限、Log-Sum-Exp 计算要减去最大值、Softmax 在大数值下会溢出。这些工程细节常常决定一个模型能否在生产环境稳定运行。

**4. 信息论视角**

信息论为"反向传播 (Backpropagation) 与计算图" 提供了统一的视角:**学习的本质是从数据中提取与目标相关的信息**。

互信息衡量知道一个变量后,另一个变量不确定性减少的量。在机器学习中,它被广泛用于特征选择、表示学习、多模态对齐等场景。

KL 散度衡量两个概率分布的距离,在交叉熵损失、变分推断、策略梯度等场景无处不在。需要注意它是**不对称**的——不同方向有不同的解释。

信息瓶颈原则指出,我们应该寻找既紧凑又预测性强的表示。这一思想影响了大量表示学习方法的设计,包括对比学习、自监督学习、多模态预训练等。

**7. 实践建议**

结合 "反向传播 (Backpropagation) 与计算图" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "反向传播 (Backpropagation) 与计算图" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
