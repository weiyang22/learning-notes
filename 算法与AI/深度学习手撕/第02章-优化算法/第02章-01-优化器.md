## 2.1 优化器 (SGD / Momentum / Adam / AdamW)

---

## 1. 内容介绍

优化器 (Optimizer) 是**根据梯度更新参数**的算法, 是深度学习训练的"引擎".

从 1951 年随机梯度下降 (SGD) 到 2014 年 Adam, 优化器经历了多次重大演进.

---

## 2. 为什么这么做

**问题**:
- SGD 在病态曲率 (如峡谷) 中震荡严重, 收敛慢
- 学习率难调, 太大不收敛, 太小慢
- 不同参数需要不同学习率 (稀疏特征 vs 稠密)

**解决思路**:
- **动量 (Momentum)**: 用历史梯度平滑, 加速收敛
- **自适应学习率 (AdaGrad/RMSProp)**: 每个参数维护自己的学习率
- **Adam**: 动量 + 自适应 = 一统江湖
- **AdamW**: 修正 Adam 的权重衰减实现错误 (2017)

---

## 3. 这么做的原因 (方案对比)

| 优化器 | 关键思想 | 优点 | 缺点 |
|---|---|---|---|
| SGD | 沿负梯度方向走 | 简单, 泛化好 | 慢, 易震荡 |
| SGD + Momentum | 加速度 (动量) | 加速, 抗震荡 | 需调超参 |
| AdaGrad | 累积平方梯度, 自适应 | 适合稀疏 | 学习率单调减, 后段停滞 |
| RMSProp | 指数移动平均平方梯度 | 解决 AdaGrad 问题 | 仍需调 |
| **Adam** | 一阶矩 + 二阶矩 | 收敛快, 鲁棒 | 泛化可能差于 SGD |
| **AdamW** | 修正 Adam 权重衰减 | 泛化接近 SGD + 收敛快 | 默认首选 |

**为什么 AdamW 取代 Adam?**
- Adam 的 $L_2$ 正则化实际是"加到 loss 的梯度上", 与自适应学习率耦合
- 正确的权重衰减应**直接衰减权重** (decoupled), 与梯度无关
- AdamW (2017) 修正了这个错误, 泛化显著提升
- 几乎所有现代 LLM (GPT / LLaMA / BERT) 都用 AdamW

---

## 4. 解决了什么问题

- **病态曲率**: 动量解决
- **不同参数需要不同学习率**: 自适应学习率解决
- **训练 LLM 大模型**: AdamW 是事实标准
- **学习率调度**: 配合 Cosine / Warmup

---

## 5. 意义

**优化器的发展 = 深度学习训练的瓶颈突破**.

- SGD (1951): 起点
- Momentum (1964): 物理直觉
- AdaGrad (2011): 自适应
- Adam (2014): 一统江湖
- AdamW (2017): 修正 + 实用

---

## 6. 公式表达

```text
SGD:           θ ← θ - lr · g

Momentum:      v ← μv + g
               θ ← θ - lr · v

AdaGrad:       s ← s + g²
               θ ← θ - lr / (√s + ε) · g

RMSProp:       s ← ρs + (1-ρ) g²
               θ ← θ - lr / (√s + ε) · g

Adam:          m ← β₁ m + (1-β₁) g
               v ← β₂ v + (1-β₂) g²
               m̂ = m / (1 - β₁^t)
               v̂ = v / (1 - β₂^t)
               θ ← θ - lr · m̂ / (√v̂ + ε)

AdamW:         θ ← θ - lr · m̂ / (√v̂ + ε)   # 梯度更新
               θ ← θ - lr · λ · θ              # 权重衰减 (decoupled)
```

## 9. 答案

### 答案 1: SGD + Momentum

```python
import numpy as np

class SGD:
    def __init__(self, params, lr=0.01, momentum=0.0):
        self.params = list(params)
        self.lr = lr
        self.momentum = momentum
        if momentum > 0:
            self.velocities = [np.zeros_like(p) for p in self.params]

    def step(self):
        for i, p in enumerate(self.params):
            if self.momentum > 0:
                self.velocities[i] = self.momentum * self.velocities[i] + p.grad
                p.data -= self.lr * self.velocities[i]
            else:
                p.data -= self.lr * p.grad

    def zero_grad(self):
        for p in self.params:
            p.grad = np.zeros_like(p.data)
```

### 答案 2: Adam

```python
class Adam:
    def __init__(self, params, lr=1e-3, betas=(0.9, 0.999), eps=1e-8):
        self.params = list(params)
        self.lr = lr
        self.beta1, self.beta2 = betas
        self.eps = eps
        self.t = 0
        self.m = [np.zeros_like(p.data) for p in self.params]
        self.v = [np.zeros_like(p.data) for p in self.params]

    def step(self):
        self.t += 1
        for i, p in enumerate(self.params):
            g = p.grad
            self.m[i] = self.beta1 * self.m[i] + (1 - self.beta1) * g
            self.v[i] = self.beta2 * self.v[i] + (1 - self.beta2) * g ** 2
            # 偏差修正
            m_hat = self.m[i] / (1 - self.beta1 ** self.t)
            v_hat = self.v[i] / (1 - self.beta2 ** self.t)
            p.data -= self.lr * m_hat / (np.sqrt(v_hat) + self.eps)

    def zero_grad(self):
        for p in self.params:
            p.grad = np.zeros_like(p.data)
```

### 答案 3: AdamW (Decoupled Weight Decay)

```python
class AdamW:
    def __init__(self, params, lr=1e-3, betas=(0.9, 0.999),
                 eps=1e-8, weight_decay=0.01):
        self.params = list(params)
        self.lr = lr
        self.beta1, self.beta2 = betas
        self.eps = eps
        self.weight_decay = weight_decay
        self.t = 0
        self.m = [np.zeros_like(p.data) for p in self.params]
        self.v = [np.zeros_like(p.data) for p in self.params]

    def step(self):
        self.t += 1
        for i, p in enumerate(self.params):
            g = p.grad
            # Adam 梯度更新
            self.m[i] = self.beta1 * self.m[i] + (1 - self.beta1) * g
            self.v[i] = self.beta2 * self.v[i] + (1 - self.beta2) * g ** 2
            m_hat = self.m[i] / (1 - self.beta1 ** self.t)
            v_hat = self.v[i] / (1 - self.beta2 ** self.t)
            p.data -= self.lr * m_hat / (np.sqrt(v_hat) + self.eps)
            # 解耦的权重衰减 (关键!)
            p.data -= self.lr * self.weight_decay * p.data

    def zero_grad(self):
        for p in self.params:
            p.grad = np.zeros_like(p.data)
```

**关键区别**: AdamW 的 `weight_decay` 直接作用在权重上, 不进入梯度; Adam 的 L2 正则会进入梯度, 与自适应学习率耦合.

### 答案 4: SGD vs Adam 对比

```python
def rosenbrock(x, y):
    return (1 - x) ** 2 + 100 * (y - x ** 2) ** 2

def demo_optimizers():
    """Rosenbrock 函数上对比优化器"""
    np.random.seed(0)

    # 3 个起点相同的优化器
    x_sgd = np.array([-1.5, 1.5])
    x_mom = x_sgd.copy()
    x_adam = x_sgd.copy()

    lr = 0.001
    momentum = 0.9
    beta1, beta2 = 0.9, 0.999
    eps = 1e-8
    m = np.zeros(2); v = np.zeros(2); t = 0
    v_mom = np.zeros(2)

    for step in range(5000):
        # SGD
        g_sgd = np.array([
            -2 * (1 - x_sgd[0]) + 200 * 2 * (x_sgd[1] - x_sgd[0]**2) * (-2 * x_sgd[0]),
            200 * 2 * (x_sgd[1] - x_sgd[0]**2)
        ])
        x_sgd -= lr * g_sgd

        # SGD + Momentum
        v_mom = momentum * v_mom + g_sgd
        g_mom = np.array([
            -2 * (1 - x_mom[0]) + 200 * 2 * (x_mom[1] - x_mom[0]**2) * (-2 * x_mom[0]),
            200 * 2 * (x_mom[1] - x_mom[0]**2)
        ])
        x_mom -= lr * v_mom

        # Adam
        t += 1
        g_adam = np.array([
            -2 * (1 - x_adam[0]) + 200 * 2 * (x_adam[1] - x_adam[0]**2) * (-2 * x_adam[0]),
            200 * 2 * (x_adam[1] - x_adam[0]**2)
        ])
        m = beta1 * m + (1 - beta1) * g_adam
        v = beta2 * v + (1 - beta2) * g_adam ** 2
        m_hat = m / (1 - beta1**t)
        v_hat = v / (1 - beta2**t)
        x_adam -= lr * m_hat / (np.sqrt(v_hat) + eps)

        if step % 1000 == 0:
            print(f"Step {step}: SGD={x_sgd}, Mom={x_mom}, Adam={x_adam}")
```

## 10. SGD 的收敛性分析

### 10.1 凸情形下的收敛速度

**假设**:
- $f$ 是 $L$-光滑的凸函数 (即 $\nabla f$ 是 $L$-Lipschitz)
- $f$ 是 $\mu$-强凸

**定理 (Robbins-Monro 1951)**:
- **凸**: $\mathbb{E}[f(\bar\theta_T) - f^*] \le \frac{\|\theta_0 - \theta^*\|^2}{2\eta T} + \frac{\eta L \sigma^2}{2\mu T}$
  - 收敛到 $O(\log T / T)$
- **强凸**: $\mathbb{E}[f(\bar\theta_T) - f^*] \le O(1/T)$

其中 $\bar\theta_T = \frac{1}{T}\sum_t \theta_t$.

### 10.2 推导要点

定义 $\mathbb{E}_t[g_t] = \nabla f(\theta_t)$ (无偏估计), 令 $\delta_t = g_t - \nabla f(\theta_t)$ (噪声).

$$\|\theta_{t+1} - \theta^*\|^2 = \|\theta_t - \eta g_t - \theta^*\|^2 = \|\theta_t - \theta^*\|^2 - 2\eta\langle g_t, \theta_t - \theta^*\rangle + \eta^2\|g_t\|^2$$

取期望, 用凸性 $\langle \nabla f, \theta_t - \theta^*\rangle \ge f(\theta_t) - f(\theta^*)$:

$$\mathbb{E}[\|\theta_{t+1} - \theta^*\|^2] \le \|\theta_t - \theta^*\|^2 - 2\eta (f(\theta_t) - f(\theta^*)) + \eta^2 \mathbb{E}[\|g_t\|^2]$$

迭代求和即得.

### 10.3 病态曲率问题

考虑 $f(\theta) = \theta_1^2 + 100 \theta_2^2$ (条件数 100):
- Hessian 条件数大 → SGD 沿 $\theta_2$ 方向震荡
- 学习率必须极小, 否则发散
- 解法: 动量 / 自适应 / 二阶

## 11. Momentum 完整推导

### 11.1 物理直觉

把梯度看作"力", 速度看作"动量":
- $v_{t+1} = \mu v_t - \eta \nabla f(\theta_t)$ (加入摩擦项)
- $\theta_{t+1} = \theta_t + v_{t+1}$

**直觉**: 沿梯度方向累积速度, 像球在山谷中滚动, 有惯性.

### 11.2 收敛速度 (强凸)

$$\mathbb{E}[\|\theta_t - \theta^*\|^2] \le (1 - \eta\mu)^t \|\theta_0 - \theta^*\|^2$$

即几何收敛, 收敛率 $\rho = 1 - \eta\mu$.

最优 $\mu = \frac{\sqrt{L} - \sqrt{\mu}}{\sqrt{L} + \sqrt{\mu}}$, 最优 $\eta = \frac{1}{L}$, 收敛率 $\left(\frac{\sqrt{L} - \sqrt{\mu}}{\sqrt{L} + \sqrt{\mu}}\right)^2$.

**加速效果**: 比 SGD 快 $O(\sqrt{L/\mu})$ 倍.

### 11.3 Nesterov 加速

```python
# Nesterov Accelerated Gradient (NAG)
v_{t+1} = μ v_t - η ∇f(θ_t + μ v_t)   # 看前面
θ_{t+1} = θ_t + v_{t+1}
```

**核心**: 不在当前 $\theta_t$ 求梯度, 而在"预计下一步" $\theta_t + \mu v_t$ 处求梯度.

**收敛速度**: $O(1/T^2)$ (凸 + 光滑), 远快于 Momentum 的 $O(1/T)$.

### 11.4 完整 PyTorch 实现 (含 Nesterov)

```python
import numpy as np

class SGDMomentum:
    """
    SGD with (Nesterov) Momentum
    Reference: PyTorch torch.optim.SGD
    """
    def __init__(self, params, lr=0.01, momentum=0.9, weight_decay=0.0,
                 dampening=0.0, nesterov=False):
        self.params = list(params)
        self.lr = lr
        self.momentum = momentum
        self.weight_decay = weight_decay
        self.dampening = dampening
        self.nesterov = nesterov

        if momentum != 0:
            for p in self.params:
                self.state[p] = {'momentum_buffer': np.zeros_like(p.data)}

    def step(self):
        for p in self.params:
            g = p.grad
            if self.weight_decay != 0:
                g = g + self.weight_decay * p.data
            if self.momentum != 0:
                buf = self.state[p]['momentum_buffer']
                if 'step' not in self.state[p]:
                    # 第一帧: buf = g * (1 - dampening)
                    buf = g * (1 - self.dampening)
                else:
                    buf = self.momentum * buf + (1 - self.dampening) * g
                self.state[p]['momentum_buffer'] = buf
                if self.nesterov:
                    g = g + self.momentum * buf
                else:
                    g = buf
            p.data -= self.lr * g

    def zero_grad(self):
        for p in self.params:
            p.grad = None
```

## 12. AdaGrad 完整推导

### 12.1 算法

```python
# AdaGrad (Duchi et al. 2011)
s_t = s_{t-1} + g_t²
θ_t = θ_{t-1} - η / (√s_t + ε) · g_t
```

**核心思想**: 每个参数根据其历史梯度大小自适应学习率.

### 12.2 收敛性证明 (凸 + 光滑)

$$\sum_{t=1}^{T} \frac{\langle g_t, \theta_t - \theta^*\rangle}{\sqrt{s_{tt}}} \le \frac{\|\theta_0 - \theta^*\|_\infty^2}{2\eta} \sqrt{T} + \eta \cdot O(\log T)$$

关键: $s_t$ 单调不减, 自适应步长单调不增.

### 12.3 为什么适合稀疏特征?

考虑 embedding 矩阵 $W$, 某行几乎不更新 (稀疏用户):
- $s_t$ 很小 → $\eta/\sqrt{s_t}$ 大 → 大步长
- 频繁更新的行: $s_t$ 大 → 小步长

等价于"对频繁特征做平滑, 对罕见特征做激进更新".

### 12.4 缺陷: 学习率单调减

$$s_t = \sum_{\tau=1}^t g_\tau^2 \to \infty \Rightarrow \eta/\sqrt{s_t} \to 0$$

后期学习率过小, 训练停滞. 这是 RMSProp / Adam 要解决的问题.

### 12.5 完整 PyTorch 实现

```python
class AdaGrad:
    """AdaGrad - Duchi et al. 2011"""
    def __init__(self, params, lr=0.01, lr_decay=0, weight_decay=0, eps=1e-10):
        self.params = list(params)
        self.lr = lr
        self.lr_decay = lr_decay
        self.weight_decay = weight_decay
        self.eps = eps
        self.state = {}
        for p in self.params:
            self.state[p] = {'sum': np.zeros_like(p.data), 'step': 0}

    def step(self):
        for p in self.params:
            g = p.grad
            if self.weight_decay != 0:
                g = g + self.weight_decay * p.data
            state = self.state[p]
            state['sum'] += g ** 2
            std = np.sqrt(state['sum']) + self.eps
            p.data -= self.lr * g / std

    def zero_grad(self):
        for p in self.params:
            p.grad = None
```

## 13. RMSProp 完整推导

### 13.1 算法

```python
# RMSProp (Hinton 2012, lecture notes)
s_t = ρ s_{t-1} + (1 - ρ) g_t²
θ_t = θ_{t-1} - η / (√s_t + ε) · g_t
```

用 EMA 替代累积, 解决 AdaGrad 学习率单调减问题.

### 13.2 EMA 的效果

$$s_t = (1-\rho) \sum_{\tau=1}^t \rho^{t-\tau} g_\tau^2$$

相当于对历史 $g^2$ 做加权平均, 权重以 $\rho^t$ 衰减. 有效窗口 ≈ $\frac{1}{1-\rho}$ 步.

典型 $\rho=0.99$ → ~100 步有效窗口.

### 13.3 完整 PyTorch 实现

```python
class RMSProp:
    """RMSProp - Hinton 2012"""
    def __init__(self, params, lr=1e-2, alpha=0.99, eps=1e-8,
                 weight_decay=0, momentum=0, centered=False):
        self.params = list(params)
        self.lr = lr
        self.alpha = alpha
        self.eps = eps
        self.weight_decay = weight_decay
        self.momentum = momentum
        self.centered = centered
        self.state = {}
        for p in self.params:
            self.state[p] = {
                'square_avg': np.zeros_like(p.data),
                'momentum_buffer': np.zeros_like(p.data),
                'grad_avg': np.zeros_like(p.data)
            }

    def step(self):
        for p in self.params:
            g = p.grad
            if self.weight_decay != 0:
                g = g + self.weight_decay * p.data
            state = self.state[p]
            square_avg = state['square_avg']
            square_avg = self.alpha * square_avg + (1 - self.alpha) * g ** 2
            state['square_avg'] = square_avg
            if self.centered:
                grad_avg = state['grad_avg']
                grad_avg = self.alpha * grad_avg + (1 - self.alpha) * g
                state['grad_avg'] = grad_avg
                avg = np.sqrt(square_avg - grad_avg ** 2 + self.eps)
            else:
                avg = np.sqrt(square_avg + self.eps)
            if self.momentum > 0:
                buf = state['momentum_buffer']
                buf = self.momentum * buf + g / avg
                state['momentum_buffer'] = buf
                p.data -= self.lr * buf
            else:
                p.data -= self.lr * g / avg

    def zero_grad(self):
        for p in self.params:
            p.grad = None
```

## 14. Adam 完整推导

### 14.1 算法

```python
# Adam (Kingma & Ba 2015)
m_t = β₁ m_{t-1} + (1-β₁) g_t           # 一阶矩 (均值)
v_t = β₂ v_{t-1} + (1-β₂) g_t²          # 二阶矩 (未中心化方差)
m̂_t = m_t / (1 - β₁^t)                  # 偏差修正
v̂_t = v_t / (1 - β₂^t)                  # 偏差修正
θ_t = θ_{t-1} - η · m̂_t / (√v̂_t + ε)
```

### 14.2 偏差修正 (Bias Correction) 推导

初始化 $m_0 = 0$, 递推:

$$m_t = (1-\beta_1) \sum_{\tau=1}^t \beta_1^{t-\tau} g_\tau = \mathbb{E}[g_t] \cdot (1 - \beta_1^t)$$

所以 $\mathbb{E}[m_t] = (1-\beta_1^t) \cdot \mathbb{E}[g_t]$.

要估计 $\mathbb{E}[g_t]$, 除以 $(1-\beta_1^t)$ 即可:

$$\hat m_t = \frac{m_t}{1-\beta_1^t} \to \mathbb{E}[g_t] \text{ as } t \to \infty$$

### 14.3 为什么需要 $v$?

$\hat m_t / (\sqrt{\hat v_t} + \epsilon)$ 等价于"近似单位方差的更新方向":
- 梯度大的参数: $v$ 大 → 步长小
- 梯度小的参数: $v$ 小 → 步长大

类似 RMSProp 的自适应, 但结合动量.

### 14.4 Adam vs SGD 经验对比

| 维度 | SGD | Adam |
|---|---|---|
| 收敛速度 | 慢 (尤其病态曲率) | 快 |
| 泛化 | 更好 (CIFAR, ImageNet) | 略差 |
| 超参敏感 | 中 | 低 (默认超参工作) |
| 显存 | 小 | 大 (2x 参数) |
| 适用 | CNN 经典 | Transformer, RL |

### 14.5 Adam 的收敛性反例 (Reddi et al. 2018)

构造一个简单的凸函数, Adam 不收敛 (但 AMSGrad 可以).

**反例**: $f_t(\theta) = \begin{cases} C\theta & \text{if } t \mod 2 = 1 \\ -C\theta & \text{otherwise} \end{cases}$

其中 $C > 0$ 很大. Adam 会因 $v_t$ 的不规则更新而震荡, 不收敛.

### 14.6 完整 PyTorch 实现

```python
class Adam:
    """Adam - Kingma & Ba 2015"""
    def __init__(self, params, lr=1e-3, betas=(0.9, 0.999), eps=1e-8,
                 weight_decay=0, amsgrad=False):
        self.params = list(params)
        self.lr = lr
        self.beta1, self.beta2 = betas
        self.eps = eps
        self.weight_decay = weight_decay
        self.amsgrad = amsgrad
        self.state = {}
        for p in self.params:
            self.state[p] = {
                'step': 0,
                'exp_avg': np.zeros_like(p.data),
                'exp_avg_sq': np.zeros_like(p.data),
                'max_exp_avg_sq': np.zeros_like(p.data)
            }

    def step(self):
        for p in self.params:
            g = p.grad
            if self.weight_decay != 0:
                g = g + self.weight_decay * p.data
            state = self.state[p]
            state['step'] += 1
            step = state['step']
            exp_avg = state['exp_avg']
            exp_avg_sq = state['exp_avg_sq']
            exp_avg = self.beta1 * exp_avg + (1 - self.beta1) * g
            exp_avg_sq = self.beta2 * exp_avg_sq + (1 - self.beta2) * g ** 2
            state['exp_avg'] = exp_avg
            state['exp_avg_sq'] = exp_avg_sq
            if self.amsgrad:
                max_exp_avg_sq = state['max_exp_avg_sq']
                max_exp_avg_sq = np.maximum(max_exp_avg_sq, exp_avg_sq)
                state['max_exp_avg_sq'] = max_exp_avg_sq
                denom = np.sqrt(max_exp_avg_sq) + self.eps
            else:
                denom = np.sqrt(exp_avg_sq) + self.eps
            bias_correction1 = 1 - self.beta1 ** step
            bias_correction2 = 1 - self.beta2 ** step
            step_size = self.lr / bias_correction1
            p.data -= step_size * exp_avg / denom

    def zero_grad(self):
        for p in self.params:
            p.grad = None
```

## 15. AdamW 完整推导

### 15.1 为什么需要 AdamW?

Loshchilov & Hutter (2017) 指出 Adam 的 L2 实现存在严重问题:

```python
# 标准 Adam + L2 正则:
loss = loss + λ/2 * ||θ||²
g = g + λ * θ          # L2 加入梯度
# 然后 Adam 更新
m = β₁m + (1-β₁)g
v = β₂v + (1-β₂)g²
θ -= η m̂ / (√v̂ + ε)
```

**问题**: L2 项 $\lambda\theta$ 进入 $v_t$, 导致**自适应步长变化**:
- 参数 $\theta$ 大 (需要强衰减): $\lambda\theta$ 大 → $v_t$ 大 → 步长小 ✓
- 参数 $\theta$ 大但 $g$ 小 (实际不需要强衰减): $v_t$ 小 → 步长大 ✗

**根本错误**: 衰减强度被错误的因子 $\sqrt{v_t}$ 调制.

### 15.2 AdamW: Decoupled Weight Decay

```python
# AdamW: 把 weight decay 从梯度中分离
g = g                               # 纯梯度 (无 L2)
m = β₁m + (1-β₁)g
v = β₂v + (1-β₂)g²
θ -= η m̂ / (√v̂ + ε)                # 梯度更新
θ -= η λ θ                          # 直接衰减权重 (解耦)
```

**效果**: weight decay 强度与参数绝对值线性相关, 与梯度无关.

### 15.3 数学等价性 (一阶 Taylor)

考虑经典 Tikhonov 正则: $\min_\theta \mathcal{L}(\theta) + \frac{\lambda}{2}\|\theta\|^2$

梯度: $\nabla_\theta(\mathcal{L} + \frac{\lambda}{2}\|\theta\|^2) = \nabla \mathcal{L} + \lambda\theta$

**一阶 Taylor 展开** (假设 $\eta$ 很小):

$$\theta_{t+1} = \theta_t - \eta(\nabla\mathcal{L} + \lambda\theta_t) \approx \theta_t(1 - \eta\lambda) - \eta\nabla\mathcal{L}$$

AdamW 实际就是: $\theta_t \leftarrow \theta_t(1 - \eta\lambda) - \eta \cdot \text{adam\_update}$

**结论**: AdamW 等价于"解耦的正则化", 与"加在 loss 上的 L2" 在一阶近似下数学等价, 但**对 Adam 自适应机制的污染更小**.

### 15.4 完整 PyTorch 实现

```python
class AdamW:
    """AdamW - Loshchilov & Hutter 2019 (arXiv 2017)"""
    def __init__(self, params, lr=1e-3, betas=(0.9, 0.999), eps=1e-8,
                 weight_decay=0.01):
        self.params = list(params)
        self.lr = lr
        self.beta1, self.beta2 = betas
        self.eps = eps
        self.weight_decay = weight_decay
        self.state = {}
        for p in self.params:
            self.state[p] = {
                'step': 0,
                'exp_avg': np.zeros_like(p.data),
                'exp_avg_sq': np.zeros_like(p.data)
            }

    def step(self):
        for p in self.params:
            g = p.grad
            state = self.state[p]
            state['step'] += 1
            step = state['step']
            exp_avg = state['exp_avg']
            exp_avg_sq = state['exp_avg_sq']
            exp_avg = self.beta1 * exp_avg + (1 - self.beta1) * g
            exp_avg_sq = self.beta2 * exp_avg_sq + (1 - self.beta2) * g ** 2
            state['exp_avg'] = exp_avg
            state['exp_avg_sq'] = exp_avg_sq
            bias_correction1 = 1 - self.beta1 ** step
            bias_correction2 = 1 - self.beta2 ** step
            step_size = self.lr / bias_correction1
            # 关键: weight decay 与梯度更新独立
            p.data.mul_(1 - self.lr * self.weight_decay)
            denom = np.sqrt(exp_avg_sq / bias_correction2) + self.eps
            p.data.addcdiv_(exp_avg, denom, value=-step_size)

    def zero_grad(self):
        for p in self.params:
            p.grad = None
```

### 15.5 AdamW 的泛化优势

实证 (Loshchilov & Hutter 2019):
- CIFAR-10 ResNet: AdamW vs Adam+L2 → +0.3% test acc
- CIFAR-100 WideResNet: +1.0% test acc
- ImageNet: +0.2-0.5% top-1

**直觉**: 解耦的 weight decay 让所有参数均匀衰减, 避免"对某些参数过拟合"的偏好.

## 16. AMSGrad (Reddi et al. 2018)

### 16.1 动机

Reddi et al. 发现 Adam 不一定收敛 (凸情形), 提出 AMSGrad:

```python
# AMSGrad
v_t = β₂ v_{t-1} + (1-β₂) g_t²
v̂_t = max(v̂_{t-1}, v_t)            # 关键: 用 max 而非 EMA
θ_t = θ_{t-1} - η / √v̂_t · m̂_t
```

### 16.2 为什么 max?

保证 $v̂_t$ 单调不减 → 步长 $\eta/\sqrt{v̂_t}$ 单调不增 → 收敛.

### 16.3 PyTorch 内置

```python
optimizer = torch.optim.Adam(params, lr=1e-3, amsgrad=True)
```

### 16.4 评价

- **理论**: 收敛性证明完整
- **实践**: 实证略优于 Adam, 但不及 AdamW
- **现状**: 学术讨论多, 工业少用

## 18. AdaBound / AMSBound (Luo et al. 2019)

### 18.1 思想

把 Adam 的学习率上下界限制到 [η_l, η_u] 范围, 让训练末期接近 SGD:

```python
# AdaBound
lr_lower, lr_upper = 0.0, 0.01
η_adaptive = η / (√v̂_t + ε)
η_bounded = clip(η_adaptive, lr_lower, lr_upper)
θ_t = θ_{t-1} - η_bounded · m̂_t
# lr_lower, lr_upper 随时间从 [0, ∞) 收敛到 [η_sgd, η_sgd]
```

### 18.2 优势

- 早期: 像 Adam (自适应快)
- 末期: 像 SGD (泛化好)

### 18.3 实现

```python
class AdaBound:
    def __init__(self, params, lr=1e-3, betas=(0.9, 0.999), eps=1e-8,
                 weight_decay=0, final_lr=0.1, gamma=1e-3):
        self.params = list(params)
        self.lr = lr
        self.beta1, self.beta2 = betas
        self.eps = eps
        self.weight_decay = weight_decay
        self.final_lr = final_lr
        self.gamma = gamma
        self.state = {}
        self.base_lrs = [lr] * len(self.params)
        for p in self.params:
            self.state[p] = {
                'step': 0,
                'exp_avg': np.zeros_like(p.data),
                'exp_avg_sq': np.zeros_like(p.data)
            }

    def step(self):
        for p in self.params:
            g = p.grad
            if self.weight_decay != 0:
                g = g + self.weight_decay * p.data
            state = self.state[p]
            state['step'] += 1
            step = state['step']
            exp_avg = state['exp_avg']
            exp_avg_sq = state['exp_avg_sq']
            exp_avg = self.beta1 * exp_avg + (1 - self.beta1) * g
            exp_avg_sq = self.beta2 * exp_avg_sq + (1 - self.beta2) * g ** 2
            state['exp_avg'] = exp_avg
            state['exp_avg_sq'] = exp_avg_sq
            # bound learning rate
            step_size = self.lr / (1 - self.beta1 ** step)
            lower = self.final_lr * (1 - 1 / (self.gamma * step + 1))
            upper = self.final_lr * (1 + 1 / (self.gamma * step))
            denom = np.sqrt(exp_avg_sq / (1 - self.beta2 ** step)) + self.eps
            p.data -= step_size * np.clip(exp_avg / denom, lower / step_size, upper / step_size)

    def zero_grad(self):
        for p in self.params:
            p.grad = None
```

## 19. RAdam (Liu et al. 2020)

### 19.1 思想

修正 Adam 训练前期的方差问题 (steps 太少导致 $\hat v_t$ 不稳定):

```python
# RAdam
m_t = β₁ m_{t-1} + (1-β₁) g_t
v_t = β₂ v_{t-1} + (1-β₂) g_t²
m̂_t = m_t / (1-β₁^t)
# 关键: 用 SMA (Simple Moving Average) 修正步长
ρ_t = ρ_∞ - 2 * t * β₂^t / (1 - β₂^t)
if ρ_t > 4:    # 方差稳定, 用自适应步长
    l_t = √(((ρ_t - 4) * (ρ_t - 2) * ρ_∞) / ((ρ_∞ - 4) * (ρ_∞ - 2) * ρ_t))
else:          # 方差不稳定, 用非自适应步长
    l_t = 1
θ_t = θ_{t-1} - η · l_t · m̂_t / (√v_t + ε)
```

### 19.2 关键优势

- 不需要 warmup (自适应)
- 训练初期自动稳定

### 19.3 PyTorch

```python
optimizer = torch.optim.RAdam(params, lr=1e-3, betas=(0.9, 0.999))
```

## 20. Lion (Chen et al. 2023, Google)

### 20.1 核心思想

只维护一阶动量 $m$, 用符号函数决定方向:

```python
# Lion
m_t = β₁ m_{t-1} + (1-β₁) g_t
update = sign(β₁ m_{t-1} + (1-β₁) g_t)    # 符号更新
θ_t = θ_{t-1} - η · update
m_t = β₂ m_{t-1} + (1-β₂) g_t             # 更新后用 β₂ 而非 β₁
```

### 20.2 与 Adam 对比

| 维度 | AdamW | Lion |
|---|---|---|
| 状态 | m + v | 仅 m |
| 显存 | 2x 参数 | 1x 参数 |
| 更新 | 连续值 | ±1 |
| LR | 小 (1e-4~1e-3) | 大 3-10x |
| wd | 标准 | 标准 |

### 20.3 完整 PyTorch 实现

```python
class Lion:
    """Lion optimizer - Chen et al. 2023 (Google)"""
    def __init__(self, params, lr=1e-4, betas=(0.9, 0.99), weight_decay=0.0):
        self.params = list(params)
        self.lr = lr
        self.beta1, self.beta2 = betas
        self.weight_decay = weight_decay
        self.state = {}
        for p in self.params:
            self.state[p] = {'exp_avg': np.zeros_like(p.data)}

    def step(self):
        for p in self.params:
            g = p.grad
            if self.weight_decay != 0:
                p.data *= (1 - self.lr * self.weight_decay)
            state = self.state[p]
            exp_avg = state['exp_avg']
            update = self.beta1 * exp_avg + (1 - self.beta1) * g
            p.data -= self.lr * np.sign(update)
            exp_avg = self.beta2 * exp_avg + (1 - self.beta2) * g
            state['exp_avg'] = exp_avg

    def zero_grad(self):
        for p in self.params:
            p.grad = None
```

### 20.4 工业应用

- Google 内部大规模实验
- 论文报告: 在 ImageNet, GLUE, WikiText 上比 AdamW 高 0.5-2%
- LLM 训练 (PaLM-2 等) 部分模块用 Lion
- **推荐 lr**: 3e-5 ~ 3e-4 (比 AdamW 小 3-10 倍)

### 20.5 论文

Chen, X., et al. (2023). "Symbolic Discovery of Optimization Algorithms." arXiv:2302.06675.

## 21. Sophia (Liu et al. 2023, Stanford)

### 21.1 核心思想

用 Hessian 对角线估计作为预条件子 (二阶方法):

```python
# Sophia (Hutchinson 估计 Hessian 对角线)
h_t = β₂ h_{t-1} + (1-β₂) H_diag(g_t)        # 滑动平均
m_t = β₁ m_{t-1} + (1-β₁) g_t
m̂_t = m_t / (1-β₁^t)
θ_t = θ_{t-1} - η · m̂_t / max(h_t, ε)         # 类似 Newton 法的更新
```

### 21.2 Hutchinson 估计 Hessian 对角线

$$H_{ii} = \mathbb{E}_{v \sim \mathcal{N}(0, I)}[(v_i \cdot (Hv)_i)]$$

实际:
```python
v = torch.randn_like(p)
Hv = torch.autograd.grad((g * v).sum(), p, retain_graph=True)[0]
h = v * Hv  # estimator of H_diag
```

### 21.3 论文报告

- GPT-2 medium: 比 AdamW 加速 2x
- 显存比 AdamW 略多 (需保存 h)
- 适合 ≥1B 模型

### 21.4 实现 (简化)

```python
class Sophia:
    """Sophia - Liu et al. 2023 (simplified)"""
    def __init__(self, params, lr=1e-4, betas=(0.9, 0.99), eps=1e-12,
                 weight_decay=0.1, hessian_beta=0.99):
        self.params = list(params)
        self.lr = lr
        self.beta1, self.beta2 = betas
        self.eps = eps
        self.weight_decay = weight_decay
        self.hessian_beta = hessian_beta
        self.state = {}
        for p in self.params:
            self.state[p] = {
                'exp_avg': np.zeros_like(p.data),
                'hessian': np.zeros_like(p.data)
            }

    def step(self):
        for p in self.params:
            g = p.grad
            if self.weight_decay != 0:
                p.data *= (1 - self.lr * self.weight_decay)
            state = self.state[p]
            exp_avg = state['exp_avg']
            exp_avg = self.beta1 * exp_avg + (1 - self.beta1) * g
            state['exp_avg'] = exp_avg
            hessian = state['hessian']
            # 简化: 假设 hessian 已被外部估计更新
            # 实际需要 Hutchinson 估计
            p.data -= self.lr * exp_avg / (np.maximum(hessian, self.eps))

    def zero_grad(self):
        for p in self.params:
            p.grad = None
```

## 22. AdaFactor (Shazeer & Stern 2018)

### 22.1 核心思想

把 $v_t$ 的存储从 $O(d)$ 降到 $O(d/n)$, 通过矩阵分解:

```python
# AdaFactor
v_t = β₂ v_{t-1} + (1-β₂) g_t²      # 行和列分别维护
# R_t (row sum), C_t (col sum)
R_t = sum_i (v_t[i, :])             # 行聚合
C_t = sum_j (v_t[:, j])             # 列聚合
# 重构: v_t ≈ R_t * C_t / sum(R_t)
v̂_t = R_t * C_t / (sum(R_t) + eps)
θ_t -= η m̂ / (√v̂_t + ε)
```

### 22.2 优势

- 优化器状态: O(d) → O(√d)
- 适合 T5 / PaLM 等超大 Transformer

### 22.3 PyTorch / HF 实现

```python
from transformers import Adafactor
optimizer = Adafactor(model.parameters(), lr=1e-3, scale_parameter=False, relative_step=False)
```

## 23. Shampoo (Gupta et al. 2018, Anil et al. 2021)

### 23.1 核心思想

对每一层参数矩阵 $W \in \mathbb{R}^{m \times n}$, 维护两个预条件子 $L_t, R_t$:

```python
# Shampoo
L_t = β L_{t-1} + (1-β) G_t G_t^T     # m x m
R_t = β R_{t-1} + (1-β) G_t^T G_t     # n x n
# 预条件更新: W ← W - η L^{-1/4} G R^{-1/4}
```

### 23.2 复杂度

- L^{-1/4}: 通过 Newton-Schulz 迭代 (5-10 次) 近似
- 总复杂度: O(mn + m^3 + n^3) per step
- 实际通过分块降低常数

### 23.3 论文报告

- 在 GPT-3 175B 上, 比 Adam 收敛快 2x
- Google 内部用

### 23.4 实现

- 库: https://github.com/google-research/google-research/tree/master/shampoo
- 分布式版: distributed_shampoo

## 24. K-FAC (Martens & Grosse 2015)

### 24.1 核心思想

用 Kronecker 分解近似 Fisher 信息矩阵:

$$F \approx A \otimes G$$

其中 $A = \mathbb{E}[a a^T]$ (激活协方差), $G = \mathbb{E}[g g^T]$ (梯度协方差).

### 24.2 更新

```python
# K-FAC
F^{-1} = G^{-1} ⊗ A^{-1}
θ ← θ - η · vec^{-1}(G^{-1} · G_actual · A^{-1})
```

### 24.3 复杂度

- Fisher 完整: O(d²)
- Kronecker 分解: O(m² + n²) (m, n 为层维度)
- 求逆: O(m³ + n³) (周期性, 非每步)

### 24.4 适用

- CNN / RNN
- 中等规模 (< 1B 参数)
- 计算资源允许时显著加速收敛

```python

optimizer = torch.optim.AdamW(model.parameters(), lr=1e-4, weight_decay=0.01)

# 2. 定义 scheduler
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=1000)

# 3. 训练循环
for epoch in range(epochs):
    model.train()
    for x, y in train_loader:
        optimizer.zero_grad()
        loss = criterion(model(x), y)
        loss.backward()
        # 可选: 梯度裁剪
        torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
        optimizer.step()
    scheduler.step()
```

## 31. 面试常问问题

### Q1: 解释 SGD 的局限, 为什么需要 Momentum?

SGD 在病态曲率 (高条件数 Hessian) 上反复震荡, 收敛慢. Momentum 累积历史梯度, 提供"惯性", 抑制震荡.

### Q2: Adam 的 m 和 v 各自估计什么?

m 是梯度的一阶矩 (均值) 估计, v 是二阶矩 (未中心化方差) 估计. 都用 EMA 平滑.

### Q3: 偏差修正为什么必要?

m₀ = v₀ = 0 导致早期 m, v 系统性偏小, 除以 (1-β^t) 抵消.

### Q4: AdamW 和 Adam + L2 的区别?

L2 进入梯度, 与自适应学习率耦合 (衰减强度取决于该参数的梯度方差). AdamW 直接衰减权重, 与梯度无关, 是真正的 decoupled weight decay.

### Q5: 解释 Lion 的核心思想?

只用一阶动量, 用符号函数决定方向. 节省 50% 优化器状态, lr 通常需要 3-10x 减小.

### Q6: 为什么 LLM 训练用 β₂=0.95 而非 0.999?

β₂=0.95 对应 ~20 步有效窗口, 适合 LLM 训练的梯度噪声尺度. 0.999 太久, 早期噪声持续影响.

### Q7: 训练时 loss spike 到 NaN, 你的排查顺序?

1. 降低学习率 / 10
2. 加梯度裁剪
3. 检查数据是否有异常
4. 混合精度溢出 (改 bf16)
5. 优化器状态损坏 (重启)

### Q8: 为什么优化器状态要保存为 fp32?

fp16 状态会下溢, 导致训练崩溃. fp32 状态安全但贵. 折中: 8-bit Adam (bitsandbytes).

### Q9: 解释 AMSGrad 的修复.

用 max(v̂_{t-1}, v_t) 替代 EMA, 保证步长单调不增, 修复 Adam 在凸情形的不收敛反例.

### Q10: AdaBound 的核心思想?

把自适应步长上下界限制, 早期像 Adam (快), 末期像 SGD (泛化好).

## 36. 优化器的"陷阱与调试"

### 36.1 常见陷阱


### 40.1 自定义优化器

```python
class MyOptimizer(torch.optim.Optimizer):
    def __init__(self, params, lr=1e-3, momentum=0.9):
        defaults = dict(lr=lr, momentum=momentum)
        super().__init__(params, defaults)

    @torch.no_grad()
    def step(self):
        for group in self.param_groups:
            for p in group['params']:
                if p.grad is None:
                    continue
                g = p.grad
                state = self.state[p]
                if len(state) == 0:
                    state['momentum_buffer'] = torch.zeros_like(p)
                buf = state['momentum_buffer']
                buf.mul_(group['momentum']).add_(g)
                p.add_(buf, alpha=-group['lr'])
```

   - 答案: A

5. Lion 相比 AdamW 的主要优势？
   - A. 收敛更快

   - D. 数值更稳定
   - 答案: B

### 46.2 简答题

6. 解释为什么 SGD + BN 在 CNN 上效果好?
   - BN 让 loss landscape 更平滑, SGD 的固定步长就能稳定下降. Adam 自适应反而不如 SGD 直接.

7. 为什么 LLM 训练几乎都用 β2=0.95 而非 0.999?
   - β2=0.95 有效窗口约 20 步, 与 LLM 梯度噪声尺度匹配. 0.999 太长, 早期噪声持续影响.

8. 解释 AMSGrad 如何修复 Adam 不收敛的反例.
   - 用 max(v̂_{t-1}, v_t) 替代 v_t, 保证步长单调不增, 满足 Robbins-Monro 收敛条件.

9. 解释 Lion 为什么能用更小的 lr (3-10x).
   - 符号更新天然归一化, 每次更新幅度恒定 (lr). 不像 Adam 需要 sqrt(v) 调制.

10. 解释 AdaFactor 如何节省显存.
    - 用 $v_t \approx R_t C_t / sum(R)$ 分解存储, 从 O(d) 降到 O(√d).

### 110. 优化器 (SGD / Momentum / AdaGrad / Adam / AdamW) - 优化视角 视角

**核心议题**: 本节从优化视角视角切入,系统展开 "优化器 (SGD / Momentum / AdaGrad / Adam / AdamW)" 的相关讨论。

**1. 背景与动机**

任何技术或方法的出现都不是孤立的,而是回应特定历史条件下的具体问题。"优化器 (SGD / Momentum / AdaGrad / Adam / AdamW)" 的发展也不例外。要理解它,必须回到它出现的那个时间点,看清它要解决的真实问题是什么。当时的主流方案有哪些不足? 它的提出填补了哪些空白? 这些问题的回答,决定了我们今天该如何使用它。

从知识论角度看,**技术演进是问题驱动的**——不是先有方案再找问题,而是先有问题再有方案。这个观察可以帮助我们避免"拿着锤子找钉子"的陷阱,真正把方法用对地方。

历史维度上,我们看到三个规律:

1. **从特殊到一般**: 早期方法往往针对特定场景,后期抽象出通用框架。学习的认知规律也是先掌握具体案例,再抽象出一般模式。这种"自下而上"的学习方式,在机器学习模型的设计里反复出现。

2. **从手工到自动**: 经验规则逐步被数据驱动的方法取代。在早期,很多 AI 系统依赖人工编写的规则。统计学习方法的崛起让"从数据中学习"成为可能。深度学习进一步把特征工程也自动化了。今天的大模型时代,我们看到端到端学习从感知扩展到了推理与生成。

3. **从局部到全局**: 关注单个组件,演进到关注整个系统。早期模型评估只关注单点指标,现在更关注全链路的协同效应。这种"系统视角"的转变,与软件工程从单体架构到微服务架构的演进高度相似。

**2. 优化视角视角的展开**

从优化视角视角出发,我们可以把 "优化器 (SGD / Momentum / AdaGrad / Adam / AdamW)" 拆解为以下几个层次:

**第一层: 概念层** —— 这是最抽象的层次,定义了我们要研究的对象是什么。例如,"推荐系统"在概念层是一个"为用户从物品集合中筛选合适物品"的问题。这个层次的特点是清晰、稳定、不易变化。一个好的概念定义应该具备几个特征:可操作性、可测量性、可扩展性。

**第二层: 模型层** —— 把概念实例化为数学模型。同一概念可以有不同的模型化方式,例如"推荐系统"可以是协同过滤、矩阵分解、深度学习等。模型的选择决定了后续算法的空间,也决定了能利用的归纳偏置(比如序列模型擅长捕捉时序依赖,图模型擅长建模关系结构)。模型选型是工程实践中最重要的决策之一。

**第三层: 算法层** —— 在选定模型下,具体的求解方法。这一层最活跃,新算法层出不穷。同一模型往往有多种算法,各有优劣。例如同样是优化深度网络,可以选择 SGD、Adam、L-BFGS 等不同算法。算法的选择要考虑收敛速度、数值稳定性、计算成本等多个维度。

**第四层: 工程层** —— 算法落地的实现细节,包括数据流水线、训练框架、推理优化、监控告警等。工程层是研究到生产的桥梁,决定了一个方法能否真正用起来。一个在论文里表现很好的算法,如果不能高效实现、不能稳定运行、不能快速迭代,就没有实际价值。工程能力是把研究转化为生产力的关键。

**第五层: 业务层** —— 在具体业务场景中的表现。同一技术在不同业务里效果差异巨大,因为业务目标、数据分布、用户行为都有差异。从业务视角看技术,我们必须回答几个问题:这个技术解决了什么业务问题?投入产出比如何?长期可持续吗?技术评估必须与业务目标对齐,否则容易陷入"技术自嗨"的陷阱。

**3. 数学形式化(简洁版)**

虽然我们强调优化视角视角,但数学形式化提供了共同语言。机器学习的核心问题可以表达为:给定输入样本,学习一个映射函数,使得函数输出与真实目标的差距最小化。这个抽象捕捉了分类、回归、生成等大多数任务的本质。

进一步,优化目标通常加入正则化项来控制模型复杂度,平衡经验风险与模型容量。统计学习理论给出了泛化误差的上界,告诉我们模型越复杂并不一定越好——**奥卡姆剃刀**在数学上有严格的形式化。

偏差-方差分解是另一个核心框架:误差可以分解为模型偏差(欠拟合)、方差(过拟合)和不可约噪声三部分。理解这个分解有助于诊断模型表现、选择合适复杂度。

在数值稳定性方面,有几个常见陷阱: 浮点数精度有限、Log-Sum-Exp 计算要减去最大值、Softmax 在大数值下会溢出。这些工程细节常常决定一个模型能否在生产环境稳定运行。

**4. 信息论视角**

信息论为"优化器 (SGD / Momentum / AdaGrad / Adam / AdamW)" 提供了统一的视角:**学习的本质是从数据中提取与目标相关的信息**。

互信息衡量知道一个变量后,另一个变量不确定性减少的量。在机器学习中,它被广泛用于特征选择、表示学习、多模态对齐等场景。

KL 散度衡量两个概率分布的距离,在交叉熵损失、变分推断、策略梯度等场景无处不在。需要注意它是**不对称**的——不同方向有不同的解释。

信息瓶颈原则指出,我们应该寻找既紧凑又预测性强的表示。这一思想影响了大量表示学习方法的设计,包括对比学习、自监督学习、多模态预训练等。

**5. 算法实现(骨架)**

虽然我们强调"优化视角" 视角,但落到代码层面是类似的骨架:

```python
def train_model(data, model_class, config):
    """通用训练函数骨架"""
    model = model_class(config)
    optimizer = create_optimizer(model, config)
    scheduler = create_scheduler(optimizer, config)
    
    for epoch in range(config.epochs):
        for batch in data:
            loss = compute_loss(model, batch)
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            scheduler.step()
    return model
```

更详细的代码放在附录或专门的实现章节,本节不重复。

**6. 评估方法**

评估 "优化器 (SGD / Momentum / AdaGrad / Adam / AdamW)" 的实际表现,需要多维度指标:

| 维度 | 指标 | 目标 |
| :--- | :--- | :--- |
| **准确性** | Accuracy / F1 / AUC | 越高越好 |
| **效率** | Latency / Throughput | 越低越好 |
| **鲁棒性** | Robustness / Calibration | 越高越好 |
| **公平性** | Fairness metrics | 符合业务 |
| **可解释性** | Explainability | 满足合规 |

**7. 实践建议**

结合 "优化器 (SGD / Momentum / AdaGrad / Adam / AdamW)" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "优化器 (SGD / Momentum / AdaGrad / Adam / AdamW)" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。

**9. 与相关主题的关系**

"优化器 (SGD / Momentum / AdaGrad / Adam / AdamW)" 与以下主题密切相关:

- **上游**: 数据质量、特征工程、业务理解。这些决定了模型的天花板。
- **下游**: 工程部署、效果监控、迭代优化。这些决定了模型的下限。
- **平行**: 类似方法、竞争方案、补充技术。了解竞品才能做得更好。

理清这些关系,有助于建立完整的知识图谱。技术学习不能孤立,要在关系网络中理解。每一个技术节点都与其他节点相连,只看到一个节点会失去全局视野。

```python
            loss = compute_loss(model, batch)
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            scheduler.step()
    return model
```

**7. 实践建议**

结合 "优化器 (SGD / Momentum / AdaGrad / Adam / AdamW)" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "优化器 (SGD / Momentum / AdaGrad / Adam / AdamW)" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
