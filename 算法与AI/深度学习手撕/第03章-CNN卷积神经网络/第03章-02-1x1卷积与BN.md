# 第03章-02-1x1卷积与BN


## 1. 1x1 卷积

### 1.1 内容介绍

**1x1 卷积** 是 $1 \times 1$ 的卷积核, 看似"无意义", 实际是**通道变换**的利器.

### 1.2 为什么这么做

**问题**: 普通卷积参数爆炸 ($k^2 \cdot C_{in} \cdot C_{out}$).

**1x1 卷积**:
- $1^2 \cdot C_{in} \cdot C_{out} = C_{in} \cdot C_{out}$ 参数
- 在不改变空间尺寸下, 改变通道数
- 用于: **瓶颈层 (bottleneck)**、降维/升维

### 1.3 公式

```text
输入: (B, C_in, H, W)
1x1 卷积 (C_out 个 1x1 核): 输出 (B, C_out, H, W)
```

## 2. BatchNorm (批归一化)

### 2.1 内容介绍

**BatchNorm** (Ioffe 2015) 是 CNN 训练的关键技术, 对每个 mini-batch 的激活做归一化.

### 2.2 为什么这么做

**问题**: Internal Covariate Shift, 训练不稳定.

**解决**: 强制让每层输入的均值=0, 方差=1, 加上可学习的 γ, β.

### 2.3 公式

```text
训练:
  μ = mean(x, axis=batch)      # 跨 batch 维
  σ² = var(x, axis=batch)
  x_norm = (x - μ) / √(σ² + ε)
  y = γ · x_norm + β            # γ, β 可学习

推理 (用 moving average):
  μ_running, σ²_running 是训练时累积的
```

### 2.4 实现

```python
import numpy as np

class BatchNorm1D:
    def __init__(self, num_features, eps=1e-5, momentum=0.9):
        self.gamma = np.ones(num_features)
        self.beta = np.zeros(num_features)
        self.eps = eps
        self.momentum = momentum
        self.running_mean = np.zeros(num_features)
        self.running_var = np.ones(num_features)
        self.training = True

    def forward(self, x):
        # x: (N, num_features)  N = batch size
        if self.training:
            mean = x.mean(axis=0)
            var = x.var(axis=0)
            # 更新 running
            self.running_mean = (1 - self.momentum) * self.running_mean + self.momentum * mean
            self.running_var = (1 - self.momentum) * self.running_var + self.momentum * var
        else:
            mean = self.running_mean
            var = self.running_var

        x_norm = (x - mean) / np.sqrt(var + self.eps)
        return self.gamma * x_norm + self.beta

    def train(self): self.training = True
    def eval(self): self.training = False
```

## 3. 深度可分离卷积 (Depthwise Separable Conv)

### 3.1 内容介绍

**MobileNet (2017)** 提出的高效卷积, 把标准卷积分解为两步, **参数减少 8-9 倍**.

### 3.2 为什么这么做

**问题 (端侧部署)**:
- 标准卷积参数多, 端侧跑不动
- 需要高效 CNN

**深度可分离卷积**:
- **Depthwise Conv**: 每个输入通道单独卷积 (空间)
- **Pointwise Conv**: 1x1 卷积 (通道变换)
- 组合: 等价于标准卷积, 但参数少

### 3.3 公式

```text
标准卷积: k × k × C_in × C_out 参数
深度可分离:
  Depthwise: k × k × C_in  (每通道一个 k×k 核)
  Pointwise: 1 × 1 × C_in × C_out
  总: k × k × C_in + C_in × C_out

压缩比: 1/C_out + 1/k²
  k=3: 1/9 + 1/C_out ≈ 1/9 (9 倍)
```

### 3.4 实现

```python
def depthwise_conv2d(x, kernel, bias=None, padding=0, stride=1):
    """
    x: (B, C, H, W)
    kernel: (C, 1, k, k)  每个通道一个核
    """
    B, C, H, W = x.shape
    _, _, k, _ = kernel.shape

    if padding > 0:
        x = np.pad(x, ((0, 0), (0, 0), (padding, padding), (padding, padding)))

    H_out = (H + 2 * padding - k) // stride + 1
    W_out = (W + 2 * padding - k) // stride + 1

    out = np.zeros((B, C, H_out, W_out))
    for b in range(B):
        for c in range(C):
            for i in range(H_out):
                for j in range(W_out):
                    patch = x[b, c, i*stride:i*stride+k, j*stride:j*stride+k]
                    out[b, c, i, j] = np.sum(patch * kernel[c, 0]) + (bias[c] if bias is not None else 0)
    return out

def pointwise_conv2d(x, kernel, bias=None):
    """1x1 卷积"""
    B, C_in, H, W = x.shape
    C_out = kernel.shape[0]
    kernel = kernel.reshape(C_out, C_in)
    out = np.einsum('bciw,oc->bow', x, kernel)
    if bias is not None:
        out = out + bias[None, :, None, None]
    return out

def depthwise_separable_conv2d(x, dw_kernel, pw_kernel, pw_bias=None, stride=1, padding=0):
    """深度可分离卷积 = Depthwise + Pointwise"""
    x = depthwise_conv2d(x, dw_kernel, stride=stride, padding=padding)
    x = pointwise_conv2d(x, pw_kernel, pw_bias)
    return x
```

### 3.5 复杂度对比

```text
标准 3x3 卷积: 3 × 3 × C_in × C_out
深度可分离 3x3: 3 × 3 × C_in + C_in × C_out

压缩比 = (3*3*C_in + C_in*C_out) / (3*3*C_in*C_out) = 1/C_out + 1/9

例: C_in=C_out=64: 压缩 = 1/64 + 1/9 ≈ 12.4 倍
```

## 6. 理论深化：1x1 卷积、BN 与深度可分离卷积

### 6.1 1x1 卷积是逐位置共享的线性层

设 $X\in\mathbb{R}^{B\times C_{in}\times H\times W}$，固定空间位置 $(h,w)$ 后，通道向量满足：

$$y_{b,h,w}=Wx_{b,h,w}+b,\quad W\in\mathbb{R}^{C_{out}\times C_{in}}$$

它只混合通道、不混合空间位置，并在全部 $H\times W$ 个位置共享同一个 $W$。换成 NHWC 布局后，对最后一维应用 `nn.Linear` 与 1x1 卷积数学等价。

参数量为 $C_{in}C_{out}$，MACs 为 $BHW C_{in}C_{out}$。标准 $k\times k$ 卷积的参数量和 MACs 分别多一个 $k^2$ 因子。

连续两个无激活的 1x1 卷积可合并为 $W_2W_1$；若中间维度为 $r$，则 $rank(W_2W_1)\le r$。加入 ReLU、SiLU 后不再能线性合并。

对单个位置，上游梯度 $g$ 给出 $\partial L/\partial x=W^Tg$、$\partial L/\partial W=gx^T$；完整特征图对 batch 与空间位置求和。

### 6.2 BatchNorm 的训练统计与梯度

CNN 第 $c$ 个通道在 $m=BHW$ 个元素上统计：

$$\mu_c=\frac1m\sum_i x_{ic},\qquad \sigma_c^2=\frac1m\sum_i(x_{ic}-\mu_c)^2$$

$$\hat{x}_{ic}=\frac{x_{ic}-\mu_c}{\sqrt{\sigma_c^2+\epsilon}},\qquad y_{ic}=\gamma_c\hat{x}_{ic}+\beta_c$$

令 $g_i=\partial L/\partial y_i$，则 $\partial L/\partial\beta=\sum_i g_i$、$\partial L/\partial\gamma=\sum_i g_i\hat{x}_i$，且：

$$\frac{\partial L}{\partial x_i}=\frac{\gamma}{m\sqrt{\sigma^2+\epsilon}}\left(mg_i-\sum_jg_j-\hat{x}_i\sum_jg_j\hat{x}_j\right)$$

训练态使用当前 batch 统计并更新 running statistics；推理态使用 running statistics。部署前忘记 `eval()` 会让输出依赖同批其他样本。

PyTorch 更新式为 $r_{new}=(1-a)r_{old}+a r_{batch}$，其中 `momentum=a`；这与一些文献把旧值系数称为 momentum 的约定相反。

### 6.3 Conv-BN 推理融合

若卷积输出为 $z=Wx+b$，则固定 BN 统计量后可写为：

$$W'_o=\frac{\gamma_o}{\sqrt{\sigma_o^2+\epsilon}}W_o$$

$$b'_o=\beta_o+\frac{\gamma_o}{\sqrt{\sigma_o^2+\epsilon}}(b_o-\mu_o)$$

融合减少一次算子调用和中间张量读写，只适用于推理态；训练时 BN 统计量仍在变化，不能这样替代。

### 6.4 深度可分离卷积是受约束的核分解

标准核 $K_{o,c,u,v}$ 同时耦合空间与通道；深度可分离卷积约束为 $K_{o,c,u,v}=P_{o,c}D_{c,u,v}$。

$$\frac{MACs_{dw+pw}}{MACs_{standard}}=\frac{1}{C_{out}}+\frac{1}{k^2}$$

该分解减少理论计算但限制表达集合。depthwise 卷积算术强度较低，常受显存带宽限制，所以 MACs 降幅不等于真实延迟降幅。

## 7. PyTorch 完整实现与最小自检

```python
import copy
import torch
from torch import nn

class ConvBNAct(nn.Sequential):
    def __init__(self, c_in, c_out, kernel_size=1, stride=1, groups=1):
        super().__init__(
            nn.Conv2d(c_in, c_out, kernel_size, stride,
                      kernel_size // 2, groups=groups, bias=False),
            nn.BatchNorm2d(c_out),
            nn.SiLU(inplace=True),
        )

class DepthwiseSeparableConv(nn.Module):
    def __init__(self, c_in, c_out, stride=1):
        super().__init__()
        self.depthwise = ConvBNAct(c_in, c_in, 3, stride, groups=c_in)
        self.pointwise = ConvBNAct(c_in, c_out, 1)

    def forward(self, x):
        return self.pointwise(self.depthwise(x))

class InvertedResidual(nn.Module):
    def __init__(self, c_in, c_out, stride=1, expand_ratio=6):
        super().__init__()
        hidden = int(round(c_in * expand_ratio))
        layers = []
        if hidden != c_in:
            layers.append(ConvBNAct(c_in, hidden, 1))
        layers.extend([
            ConvBNAct(hidden, hidden, 3, stride, groups=hidden),
            nn.Conv2d(hidden, c_out, 1, bias=False),
            nn.BatchNorm2d(c_out),
        ])
        self.block = nn.Sequential(*layers)
        self.use_residual = stride == 1 and c_in == c_out

    def forward(self, x):
        y = self.block(x)
        return x + y if self.use_residual else y

def fuse_conv_bn_eval(conv, bn):
    assert not conv.training and not bn.training
    fused = copy.deepcopy(conv)
    weight = conv.weight
    bias = conv.bias
    if bias is None:
        bias = torch.zeros(conv.out_channels, device=weight.device, dtype=weight.dtype)
    scale = bn.weight / torch.sqrt(bn.running_var + bn.eps)
    fused.weight = nn.Parameter(weight * scale[:, None, None, None])
    fused.bias = nn.Parameter(bn.bias + (bias - bn.running_mean) * scale)
    return fused

@torch.no_grad()
def demo():
    torch.manual_seed(0)
    x = torch.randn(2, 16, 32, 32)
    block = DepthwiseSeparableConv(16, 24).eval()
    assert block(x).shape == (2, 24, 32, 32)
    conv = nn.Conv2d(16, 24, 1, bias=False).eval()
    bn = nn.BatchNorm2d(24).eval()
    fused = fuse_conv_bn_eval(conv, bn)
    torch.testing.assert_close(fused(x), bn(conv(x)), rtol=1e-5, atol=1e-6)

if __name__ == "__main__":
    demo()
```

### 10.1 逐像素线性映射

- 一句话定义：围绕 **逐像素线性映射** 建立可计算、可复现、可部署的判断。
- 理论抓手：$y=Wx+b$。
- PyTorch 对应：`nn.Conv2d(..., kernel_size=1)`。
- 论文坐标：Network in Network。
- 工业映射：移动端图像分类：单张 224×224 输入，关注 Top-1、p95 延迟、内存与功耗。
- 输入检查：写清 `B, C_in, H, W`、dtype、device 与内存格式。
- 输出检查：确认通道数、空间尺寸和广播语义符合接口契约。
- 参数检查：区分可训练参数、冻结参数和 running statistics。
- 复杂度检查：分别报告参数量、MACs、FLOPs 与激活字节数。
- 数值检查：比较 FP32 基线与 AMP、融合或量化后的误差。
- 梯度检查：确认梯度存在且有限，排除错误的 detach 与原地修改。
- 模式检查：训练调用 `train()`，验证、导出与服务调用 `eval()`。
- 性能检查：预热、同步、多次重复，报告 median 与 p95。
- 硬件检查：在目标 GPU、CPU 或 NPU 上实测，不能只比较 FLOPs。
- 数据检查：小 batch、极端分辨率和长尾类别进入回归集。
- 论文检查：核对原文结构图、公式、表格和消融，不只记二手结论。
- 复现顺序：先最小模块，再依次加入 BN、激活、残差、融合和量化。
- 常见误区：参数减少不代表延迟、显存、功耗同比例下降。

## 12. 结论

1x1 卷积负责通道变换，BatchNorm 负责训练统计与可学习重标定，depthwise separable convolution 负责拆分空间与通道计算。

工程判断必须超越参数量和 FLOPs：同时检查数值一致性、目标硬件延迟、显存、功耗、量化误差和线上分布漂移。
