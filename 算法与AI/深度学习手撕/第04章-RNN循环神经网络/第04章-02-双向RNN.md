# 第04章-02-双向RNN


- **双向 RNN (BiRNN)**: 同时用前向和后向两个 RNN 扫描序列, 每个位置的表示融合"过去+未来"上下文。
- **Seq2Seq**: Encoder 把变长输入压成上下文向量, Decoder 自回归生成变长输出。
- **注意力**: 解决 Seq2Seq 的"信息瓶颈"——Decoder 每步动态读取 Encoder 所有隐状态。

---

## 2. 为什么这么做

**单向 RNN 的缺陷**: 位置 $t$ 只能看到 $x_1..x_t$。但很多任务(NER、翻译、纠错)需要看完整句子才能判断当前词。

> 例: "他说的**苹果**很甜" vs "他买了**苹果**手机" —— 判断"苹果"含义要看后文。

**双向**: 前向隐状态 $\overrightarrow{h_t}$ 编码 $x_1..x_t$, 后向 $\overleftarrow{h_t}$ 编码 $x_T..x_t$, 拼接得 $h_t=[\overrightarrow{h_t};\overleftarrow{h_t}]$。

**注意 BiRNN 不能做自回归生成**(会看到未来, 信息泄露), 只用于编码/标注类任务。

---

## 3. 方案对比

| 方案 | 上下文 | 能否生成 | 典型用途 |
|---|---|---|---|
| 单向 RNN | 仅过去 | ✅ | 语言模型、Decoder |
| 双向 RNN | 过去+未来 | ❌ | NER、编码器 |
| Seq2Seq (无注意力) | 固定上下文向量 | ✅ | 短序列翻译 |
| Seq2Seq + Attention | 动态全局 | ✅ | 长序列翻译(Transformer 前身) |

**信息瓶颈**: 无注意力时整个句子被压进一个定长向量, 长句性能急剧下降。注意力让 Decoder 每步"回看"源序列, 是通向 Transformer 的关键一步。

---

## 4. 手撕实现

### 4.1 双向 RNN(手动拼接两个方向)

```python
import torch
import torch.nn as nn

class BiRNN(nn.Module):
    def __init__(self, input_size, hidden_size):
        super().__init__()
        self.fwd = nn.GRU(input_size, hidden_size, batch_first=True)
        self.bwd = nn.GRU(input_size, hidden_size, batch_first=True)

    def forward(self, x):                        # x: (B, T, D)
        out_f, _ = self.fwd(x)                    # 前向
        out_b, _ = self.bwd(torch.flip(x, [1]))  # 反向: 先翻转时间轴
        out_b = torch.flip(out_b, [1])           # 翻回来对齐位置
        return torch.cat([out_f, out_b], dim=-1) # (B, T, 2H)
```

### 4.2 Seq2Seq + Bahdanau 注意力

```python
class Attention(nn.Module):
    """Bahdanau (加性) 注意力: score = vᵀ tanh(W_q q + W_k k)"""
    def __init__(self, h):
        super().__init__()
        self.Wq, self.Wk = nn.Linear(h, h), nn.Linear(h, h)
        self.v = nn.Linear(h, 1, bias=False)

    def forward(self, dec_h, enc_out):           # dec_h:(B,H) enc_out:(B,T,H)
        q = self.Wq(dec_h).unsqueeze(1)          # (B,1,H)
        score = self.v(torch.tanh(q + self.Wk(enc_out))).squeeze(-1)  # (B,T)
        attn = torch.softmax(score, dim=-1)      # 注意力权重
        ctx = torch.bmm(attn.unsqueeze(1), enc_out).squeeze(1)        # (B,H)
        return ctx, attn

class Decoder(nn.Module):
    def __init__(self, vocab, emb, h):
        super().__init__()
        self.emb = nn.Embedding(vocab, emb)
        self.attn = Attention(h)
        self.rnn = nn.GRUCell(emb + h, h)
        self.out = nn.Linear(h, vocab)

    def step(self, tok, dec_h, enc_out):
        e = self.emb(tok)                        # (B, emb)
        ctx, attn = self.attn(dec_h, enc_out)    # (B, H)
        dec_h = self.rnn(torch.cat([e, ctx], -1), dec_h)
        return self.out(dec_h), dec_h, attn
```

### 4.3 训练(Teacher Forcing)

```python
def train_step(enc_out, dec_h0, tgt, decoder):
    """Teacher Forcing: 用真实上一个 token 作输入"""
    dec_h, loss = dec_h0, 0.0
    tok = tgt[:, 0]                              # <BOS>
    for t in range(1, tgt.size(1)):
        logit, dec_h, _ = decoder.step(tok, dec_h, enc_out)
        loss += nn.functional.cross_entropy(logit, tgt[:, t])
        tok = tgt[:, t]                          # 训练用真值(而非预测)
    return loss / (tgt.size(1) - 1)
```

> **Teacher Forcing 权衡**: 训练快、稳定, 但存在 exposure bias(推理时用自己的预测, 分布不一致)。缓解: scheduled sampling。

## 7. BiRNN 数学形式化

### 7.1 单向 RNN 回顾

给定输入序列 $\mathbf{X} = (\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_T)$, $\mathbf{x}_t \in \mathbb{R}^{d}$:

$$\mathbf{h}_t = f(\mathbf{h}_{t-1}, \mathbf{x}_t; \theta)$$

其中 $f$ 可以是 vanilla RNN (tanh)、LSTM、GRU. 隐状态 $\mathbf{h}_t \in \mathbb{R}^H$ 编码"截至 $t$ 时刻的所有信息".

### 7.2 双向 RNN 的形式化

双向 RNN 同时维护两个方向的隐状态:

$$\overrightarrow{\mathbf{h}}_t = f(\overrightarrow{\mathbf{h}}_{t-1}, \mathbf{x}_t; \theta_f)$$
$$\overleftarrow{\mathbf{h}}_t = f(\overleftarrow{\mathbf{h}}_{t+1}, \mathbf{x}_t; \theta_b)$$

最终表示:
$$\mathbf{y}_t = [\overrightarrow{\mathbf{h}}_t; \overleftarrow{\mathbf{h}}_t] \in \mathbb{R}^{2H}$$

或可学习融合:
$$\mathbf{y}_t = \mathbf{W}_f \overrightarrow{\mathbf{h}}_t + \mathbf{W}_b \overleftarrow{\mathbf{h}}_t + \mathbf{b}$$

### 7.3 为什么 BiRNN 有效?

**信息论视角**: 单向 RNN 的 $\mathbf{h}_t$ 只能编码 $P(\mathbf{x}_{t+1:T} | \mathbf{x}_{1:t})$ 的部分信息. BiRNN 同时编码过去+未来, 提供更丰富的上下文.

**经验结论** (Graves 2013):
- NER / POS: BiLSTM 显著优于单向 (F1 +2-5%)
- 语音识别: BiLSTM 比单向低 10-20% WER
- 翻译: BiLSTM Encoder 是 Transformer 前的标配

### 7.4 BiRNN 的局限

| 局限 | 影响 | 解决 |
|---|---|---|
| 不能做语言模型 | 信息泄露 | 仅用于编码/标注 |
| 训练慢 (两遍) | 1.5-2x 时间 | 截断 / 并行 |
| 显存大 | 2x 隐状态 | 反向时按需重算 |

### 7.5 PyTorch nn.Module 完整实现

```python
import torch
import torch.nn as nn

class BiLSTMEncoder(nn.Module):
    """标准 BiLSTM 编码器, 输出每个时间步的拼接表示"""
    def __init__(self, input_size, hidden_size, num_layers=1, dropout=0.3, bidir=True):
        super().__init__()
        self.lstm = nn.LSTM(
            input_size=input_size,
            hidden_size=hidden_size,
            num_layers=num_layers,
            batch_first=True,
            bidirectional=bidir,
            dropout=dropout if num_layers > 1 else 0
        )
        self.hidden_size = hidden_size
        self.output_size = hidden_size * (2 if bidir else 1)

    def forward(self, x, lengths=None):
        # x: (B, T, D)
        if lengths is not None:
            # pack 加速 + 处理变长
            packed = nn.utils.rnn.pack_padded_sequence(
                x, lengths.cpu(), batch_first=True, enforce_sorted=False
            )
            packed_out, (h_n, c_n) = self.lstm(packed)
            out, _ = nn.utils.rnn.pad_packed_sequence(packed_out, batch_first=True)
        else:
            out, (h_n, c_n) = self.lstm(x)
        return out, (h_n, c_n)

class BiLSTMTagger(nn.Module):
    """BiLSTM + CRF 风格的标注器 (简化版, 线性投影代替 CRF)"""
    def __init__(self, vocab_size, embedding_dim, hidden_size, num_tags):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim, padding_idx=0)
        self.encoder = BiLSTMEncoder(embedding_dim, hidden_size, num_layers=2, dropout=0.3)
        self.dropout = nn.Dropout(0.3)
        self.classifier = nn.Linear(self.encoder.output_size, num_tags)

    def forward(self, x, lengths=None):
        # x: (B, T) token ids
        emb = self.embedding(x)              # (B, T, E)
        emb = self.dropout(emb)
        out, _ = self.encoder(emb, lengths)  # (B, T, 2H)
        out = self.dropout(out)
        logits = self.classifier(out)        # (B, T, num_tags)
        return logits
```

## 8. Seq2Seq 完整理论

### 8.1 Encoder-Decoder 框架

**Encoder**: 把变长输入 $\mathbf{X} = (\mathbf{x}_1, \dots, \mathbf{x}_T)$ 编码为定长上下文向量 $\mathbf{c}$:

$$\mathbf{c} = q(\mathbf{h}_1^T, \mathbf{h}_2^T, \dots, \mathbf{h}_T^T; \theta_e)$$

朴素实现: $\mathbf{c} = \mathbf{h}_T$ (最后一个隐状态).

**Decoder**: 自回归生成变长输出 $\mathbf{Y} = (\mathbf{y}_1, \dots, \mathbf{y}_{T'})$:

$$p(\mathbf{y}_t | \mathbf{y}_{<t}, \mathbf{c}) = g(\mathbf{y}_{t-1}, \mathbf{s}_t, \mathbf{c}; \theta_d)$$

其中 $\mathbf{s}_t$ 是 decoder 隐状态.

### 8.2 朴素 Seq2Seq 的"信息瓶颈"

整个输入被压成一个定长向量 $\mathbf{c}$:
- 短句 (< 20 token): 可以
- 长句 (> 50 token): 性能急剧下降

**直觉**: 想象把整段对话压成一个 emoji, 然后只看着这个 emoji 复述对话 → 必然丢失细节.

### 8.3 训练: Teacher Forcing

Decoder 的输入是 ground-truth 上一个 token (而非模型自己的预测):

```python
def train_seq2seq(encoder, decoder, src, tgt, teacher_forcing_ratio=0.5):
    enc_out, enc_hidden = encoder(src)
    dec_input = tgt[:, 0:1]  # <BOS>
    dec_hidden = enc_hidden
    loss = 0
    for t in range(1, tgt.size(1)):
        pred, dec_hidden = decoder(dec_input, dec_hidden, enc_out)
        loss += criterion(pred, tgt[:, t])
        # Teacher forcing: 以 teacher_forcing_ratio 概率使用真值
        teacher_force = torch.rand(1).item() < teacher_forcing_ratio
        dec_input = tgt[:, t:t+1] if teacher_force else pred.argmax(-1, keepdim=True)
    return loss / (tgt.size(1) - 1)
```

### 8.4 推理: 自回归生成

```python
def greedy_decode(decoder, enc_out, enc_hidden, max_len, bos_idx, eos_idx):
    dec_input = torch.tensor(`bos_idx`)
    dec_hidden = enc_hidden
    outputs = []
    for _ in range(max_len):
        pred, dec_hidden = decoder(dec_input, dec_hidden, enc_out)
        next_token = pred.argmax(-1)
        if next_token.item() == eos_idx:
            break
        outputs.append(next_token.item())
        dec_input = next_token
    return outputs
```

### 8.5 Beam Search 推理

贪婪搜索容易陷入局部最优. Beam Search 保留 top-k 候选:

```python
def beam_search(decoder, enc_out, enc_hidden, max_len, bos_idx, eos_idx, beam_size=5):
    # 初始: <BOS>, log_prob=0
    sequences = [([bos_idx], 0.0, enc_hidden)]
    finished = []
    for _ in range(max_len):
        all_candidates = []
        for seq, score, hidden in sequences:
            if seq[-1] == eos_idx:
                finished.append((seq, score))
                continue
            dec_input = torch.tensor(`seq[-1`])
            pred, new_hidden = decoder(dec_input, hidden, enc_out)
            log_probs = torch.log_softmax(pred, dim=-1)
            top_k = torch.topk(log_probs, beam_size)
            for k in range(beam_size):
                candidate = (seq + [top_k.indices[0, k].item()],
                             score + top_k.values[0, k].item(),
                             new_hidden)
                all_candidates.append(candidate)
        # 保留 top beam_size
        sequences = sorted(all_candidates, key=lambda x: x[1], reverse=True)[:beam_size]
        if not sequences:
            break
    # 选最佳
    finished.extend(sequences)
    best = max(finished, key=lambda x: x[1])
    return best[0]
```

### 8.6 Length Normalization (长度归一化)

Beam search 偏好短序列 (累计负 log 概率). 解决: 长度归一化:

$$\text{score} = \frac{1}{T^\alpha} \sum_{t=1}^T \log p(\mathbf{y}_t | \mathbf{y}_{<t}, \mathbf{c})$$

$\alpha$ 通常 0.6-0.7.

### 8.7 Coverage Penalty (覆盖惩罚)

解决 attention 重复关注同一位置:

$$ \text{score} = \sum_{t=1}^T \log p(\mathbf{y}_t | \mathbf{y}_{<t}, \mathbf{c}) - \beta \sum_i \log(\min(\sum_t \alpha_{t,i}, 1)) $$

Wu et al. 2016 GNMT 使用.

## 9. Attention 机制完整推导

### 9.1 朴素 Seq2Seq 的痛点

注意力机制由 Bahdanau et al. (2014) 提出, 解决"信息瓶颈":

**思想**: Decoder 每一步都能"看到"Encoder 的所有隐状态, 通过加权平均动态选取相关部分.

### 9.2 Bahdanau (加性) 注意力

给定 decoder 当前隐状态 $\mathbf{s}_{t-1}$ (作为 query) 和 encoder 所有隐状态 $\mathbf{H} = (\mathbf{h}_1, \dots, \mathbf{h}_T)$ (作为 keys/values):

**对齐分数** (alignment score):
$$e_{t,i} = \mathbf{v}^\top \tanh(\mathbf{W}_s \mathbf{s}_{t-1} + \mathbf{W}_h \mathbf{h}_i)$$

**注意力权重** (归一化):
$$\alpha_{t,i} = \frac{\exp(e_{t,i})}{\sum_{j=1}^T \exp(e_{t,j})}$$

**上下文向量**:
$$\mathbf{c}_t = \sum_{i=1}^T \alpha_{t,i} \mathbf{h}_i$$

### 9.3 Decoder 更新

Decoder 隐状态更新 (Luong 风格):
$$\mathbf{s}_t = f(\mathbf{s}_{t-1}, [\mathbf{y}_{t-1}; \mathbf{c}_t])$$

输出概率:
$$p(\mathbf{y}_t | \mathbf{y}_{<t}, \mathbf{X}) = \text{softmax}(\mathbf{W}_o [\mathbf{s}_t; \mathbf{c}_t])$$

### 9.4 Luong (乘性) 注意力

Luong et al. (2015) 提出更简单的形式:

$$e_{t,i} = \mathbf{s}_{t-1}^\top \mathbf{W}_a \mathbf{h}_i$$

或 dot-product:
$$e_{t,i} = \mathbf{s}_{t-1}^\top \mathbf{h}_i$$

### 9.5 注意力变体总结

| 类型 | 公式 | 复杂度 | 用途 |
|---|---|---|---|
| 加性 (Bahdanau) | $v^T \tanh(W_s s + W_h h)$ | O(d²) | 经典 NMT |
| 乘性 (Luong) | $s^T W_a h$ | O(d²) | 简化版 |
| 点积 | $s^T h$ | O(d) | 要求维度相同 |
| 缩放点积 | $s^T h / \sqrt{d}$ | O(d) | Transformer 默认 |
| 双线性 | $s^T W_a h$ | O(d²) | 通用 |

### 9.6 PyTorch 完整 nn.Module

```python
class BahdanauAttention(nn.Module):
    """Bahdanau (加性) 注意力. Reference: Bahdanau et al. 2014"""
    def __init__(self, hidden_size):
        super().__init__()
        self.W_h = nn.Linear(hidden_size, hidden_size, bias=False)  # encoder projection
        self.W_s = nn.Linear(hidden_size, hidden_size, bias=False)  # decoder projection
        self.v = nn.Linear(hidden_size, 1, bias=False)

    def forward(self, dec_hidden, enc_outputs, mask=None):
        # dec_hidden: (B, H)
        # enc_outputs: (B, T, H)
        # mask: (B, T), True 表示 padding
        B, T, H = enc_outputs.size()
        # 投影
        proj_enc = self.W_h(enc_outputs)         # (B, T, H)
        proj_dec = self.W_s(dec_hidden).unsqueeze(1)  # (B, 1, H)
        # tanh + v^T
        scores = self.v(torch.tanh(proj_enc + proj_dec)).squeeze(-1)  # (B, T)
        if mask is not None:
            scores = scores.masked_fill(mask, float('-inf'))
        attn_weights = torch.softmax(scores, dim=-1)  # (B, T)
        # 加权求和
        context = torch.bmm(attn_weights.unsqueeze(1), enc_outputs).squeeze(1)  # (B, H)
        return context, attn_weights

class LuongAttention(nn.Module):
    """Luong (乘性) 注意力. Reference: Luong et al. 2015"""
    def __init__(self, hidden_size, method='general'):
        super().__init__()
        self.method = method
        if method == 'general':
            self.W = nn.Linear(hidden_size, hidden_size, bias=False)
        elif method == 'concat':
            self.W = nn.Linear(hidden_size * 2, hidden_size, bias=False)
            self.v = nn.Linear(hidden_size, 1, bias=False)
        # method == 'dot' 无参数

    def forward(self, dec_hidden, enc_outputs, mask=None):
        # dec_hidden: (B, H), enc_outputs: (B, T, H)
        if self.method == 'dot':
            scores = torch.bmm(enc_outputs, dec_hidden.unsqueeze(-1)).squeeze(-1)  # (B, T)
        elif self.method == 'general':
            scores = torch.bmm(self.W(enc_outputs), dec_hidden.unsqueeze(-1)).squeeze(-1)
        elif self.method == 'concat':
            T = enc_outputs.size(1)
            dec_expanded = dec_hidden.unsqueeze(1).expand(-1, T, -1)
            scores = self.v(torch.tanh(self.W(torch.cat([enc_outputs, dec_expanded], -1)))).squeeze(-1)
        if mask is not None:
            scores = scores.masked_fill(mask, float('-inf'))
        attn_weights = torch.softmax(scores, dim=-1)
        context = torch.bmm(attn_weights.unsqueeze(1), enc_outputs).squeeze(1)
        return context, attn_weights
```

## 10. 完整 Seq2Seq + Attention 实现

### 10.1 Encoder

```python
class Seq2SeqEncoder(nn.Module):
    """BiLSTM Encoder"""
    def __init__(self, vocab_size, embed_size, hidden_size, num_layers=1, dropout=0.3):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_size, padding_idx=0)
        self.lstm = nn.LSTM(
            embed_size, hidden_size, num_layers=num_layers,
            batch_first=True, bidirectional=True, dropout=dropout if num_layers > 1 else 0
        )
        self.hidden_proj = nn.Linear(hidden_size * 2, hidden_size)
        # 双向需要合并 h, c 为 decoder 初始状态
        self.h_proj = nn.Linear(hidden_size * 2 * num_layers, hidden_size * num_layers)
        self.c_proj = nn.Linear(hidden_size * 2 * num_layers, hidden_size * num_layers)
        self.num_layers = num_layers
        self.hidden_size = hidden_size

    def forward(self, src, src_lengths=None):
        emb = self.embedding(src)
        if src_lengths is not None:
            packed = nn.utils.rnn.pack_padded_sequence(
                emb, src_lengths.cpu(), batch_first=True, enforce_sorted=False
            )
            packed_out, (h, c) = self.lstm(packed)
            out, _ = nn.utils.rnn.pad_packed_sequence(packed_out, batch_first=True)
        else:
            out, (h, c) = self.lstm(emb)
        # h, c: (num_layers * 2, B, H)
        # 拼接双向 → (num_layers, B, 2H) → 投影到 H
        B = h.size(1)
        h = h.view(self.num_layers, 2, B, self.hidden_size)
        c = c.view(self.num_layers, 2, B, self.hidden_size)
        h_cat = torch.cat([h[:, 0], h[:, 1]], dim=-1)  # (num_layers, B, 2H)
        c_cat = torch.cat([c[:, 0], c[:, 1]], dim=-1)
        # 投影
        h_proj = self.h_proj(h_cat.permute(1, 0, 2).reshape(B, -1)).view(B, self.num_layers, self.hidden_size).permute(1, 0, 2).contiguous()
        c_proj = self.c_proj(c_cat.permute(1, 0, 2).reshape(B, -1)).view(B, self.num_layers, self.hidden_size).permute(1, 0, 2).contiguous()
        return out, (h_proj, c_proj)  # out: (B, T, 2H), (h, c): (num_layers, B, H)
```

### 10.2 Decoder

```python
class Seq2SeqDecoder(nn.Module):
    """LSTM Decoder + Bahdanau Attention"""
    def __init__(self, vocab_size, embed_size, hidden_size, num_layers=1, dropout=0.3):
        super().__init__()
        self.vocab_size = vocab_size
        self.hidden_size = hidden_size
        self.embedding = nn.Embedding(vocab_size, embed_size, padding_idx=0)
        self.attention = BahdanauAttention(hidden_size * 2)  # encoder 是双向 2H
        self.lstm = nn.LSTMCell(embed_size + hidden_size * 2, hidden_size)
        self.out_proj = nn.Linear(hidden_size + hidden_size * 2, vocab_size)
        self.dropout = nn.Dropout(dropout)

    def forward(self, tgt, dec_hidden, dec_cell, enc_outputs, src_mask=None):
        # tgt: (B, T_t)
        # dec_hidden: (B, H), dec_cell: (B, H)
        # enc_outputs: (B, T_s, 2H)
        B, T_t = tgt.size()
        outputs = []
        attn_weights_all = []
        input_t = tgt[:, 0]  # <BOS>
        for t in range(1, T_t):
            emb = self.dropout(self.embedding(input_t))  # (B, E)
            # attention
            context, attn_weights = self.attention(dec_hidden, enc_outputs, src_mask)
            # LSTM step
            lstm_input = torch.cat([emb, context], dim=-1)
            dec_hidden, dec_cell = self.lstm(lstm_input, (dec_hidden, dec_cell))
            # 输出投影
            output = self.out_proj(torch.cat([dec_hidden, context], dim=-1))
            outputs.append(output)
            attn_weights_all.append(attn_weights)
            # Teacher forcing: 用真值
            input_t = tgt[:, t]
        outputs = torch.stack(outputs, dim=1)  # (B, T_t-1, V)
        attn_weights_all = torch.stack(attn_weights_all, dim=1)  # (B, T_t-1, T_s)
        return outputs, attn_weights_all, dec_hidden, dec_cell

    def step(self, input_t, dec_hidden, dec_cell, enc_outputs, src_mask=None):
        """单步推理用"""
        emb = self.embedding(input_t)
        context, attn_weights = self.attention(dec_hidden, enc_outputs, src_mask)
        lstm_input = torch.cat([emb, context], dim=-1)
        dec_hidden, dec_cell = self.lstm(lstm_input, (dec_hidden, dec_cell))
        output = self.out_proj(torch.cat([dec_hidden, context], dim=-1))
        return output, dec_hidden, dec_cell, attn_weights
```

### 10.3 完整 Seq2Seq

```python
class Seq2Seq(nn.Module):
    """Encoder-Decoder + Attention"""
    def __init__(self, src_vocab, tgt_vocab, embed_size, hidden_size,
                 num_layers=1, dropout=0.3):
        super().__init__()
        self.encoder = Seq2SeqEncoder(src_vocab, embed_size, hidden_size, num_layers, dropout)
        self.decoder = Seq2SeqDecoder(tgt_vocab, embed_size, hidden_size, num_layers, dropout)
        self.tgt_vocab = tgt_vocab

    def forward(self, src, tgt, src_lengths=None):
        # 1. Encode
        enc_outputs, (h, c) = self.encoder(src, src_lengths)
        # 2. Build src mask
        if src_lengths is not None:
            src_mask = torch.arange(src.size(1), device=src.device).unsqueeze(0) >= src_lengths.unsqueeze(1)
        else:
            src_mask = None
        # 3. Decode (teacher forcing)
        dec_hidden = h[-1]  # 最后一层
        dec_cell = c[-1]
        outputs, attn, _, _ = self.decoder(tgt, dec_hidden, dec_cell, enc_outputs, src_mask)
        return outputs, attn

    def greedy_decode(self, src, max_len, bos_idx, eos_idx, src_lengths=None):
        enc_outputs, (h, c) = self.encoder(src, src_lengths)
        if src_lengths is not None:
            src_mask = torch.arange(src.size(1), device=src.device).unsqueeze(0) >= src_lengths.unsqueeze(1)
        else:
            src_mask = None
        dec_hidden = h[-1]
        dec_cell = c[-1]
        input_t = torch.full((src.size(0),), bos_idx, device=src.device, dtype=torch.long)
        outputs = []
        attns = []
        for _ in range(max_len):
            output, dec_hidden, dec_cell, attn = self.decoder.step(
                input_t, dec_hidden, dec_cell, enc_outputs, src_mask
            )
            next_token = output.argmax(-1)
            if (next_token == eos_idx).all():
                break
            outputs.append(next_token)
            attns.append(attn)
            input_t = next_token
        return torch.stack(outputs, dim=1) if outputs else torch.zeros(src.size(0), 0, dtype=torch.long, device=src.device)
```

## 11. Beam Search 完整实现

```python
class BeamHypothesis:
    def __init__(self, tokens, log_prob, hidden, cell):
        self.tokens = tokens
        self.log_prob = log_prob
        self.hidden = hidden
        self.cell = cell

    def extend(self, token, log_prob, hidden, cell):
        return BeamHypothesis(
            self.tokens + [token],
            self.log_prob + log_prob,
            hidden, cell
        )

    def avg_log_prob(self, alpha=0.7):
        return self.log_prob / (len(self.tokens) ** alpha)

def beam_search_decode(model, src, src_len, bos_idx, eos_idx,
                       max_len=50, beam_size=5, alpha=0.7):
    """完整的 beam search 推理"""
    model.eval()
    with torch.no_grad():
        enc_outputs, (h, c) = model.encoder(src, src_len)
        if src_len is not None:
            src_mask = (torch.arange(src.size(1), device=src.device).unsqueeze(0)
                        >= src_len.unsqueeze(1))
        else:
            src_mask = None
        dec_hidden = h[-1]
        dec_cell = c[-1]
        # 初始: 每个 sample 一个 beam
        beams = [[BeamHypothesis([bos_idx], 0.0, dec_hidden[i:i+1], dec_cell[i:i+1])]
                 for i in range(src.size(0))]
        completed = [[] for _ in range(src.size(0))]
        for step in range(max_len):
            new_beams = [[] for _ in range(src.size(0))]
            for b_idx, beam_list in enumerate(beams):
                # 收集当前所有候选
                candidates = []
                for hyp in beam_list:
                    input_t = torch.tensor([hyp.tokens[-1]], device=src.device)
                    enc_out_b = enc_outputs[b_idx:b_idx+1]
                    if src_mask is not None:
                        src_mask_b = src_mask[b_idx:b_idx+1]
                    else:
                        src_mask_b = None
                    output, new_h, new_c, _ = model.decoder.step(
                        input_t, hyp.hidden, hyp.cell, enc_out_b, src_mask_b
                    )
                    log_probs = torch.log_softmax(output, dim=-1)
                    top_k = torch.topk(log_probs, beam_size)
                    for k in range(beam_size):
                        token = top_k.indices[0, k].item()
                        new_log_prob = hyp.log_prob + top_k.values[0, k].item()
                        candidates.append((hyp, token, new_log_prob, new_h, new_c))
                # 选 top beam_size (按 avg_log_prob)
                candidates.sort(key=lambda x: x[2] / ((len(x[0].tokens) + 1) ** alpha),
                                reverse=True)
                for hyp, token, new_log_prob, new_h, new_c in candidates[:beam_size]:
                    new_hyp = hyp.extend(token, new_log_prob, new_h, new_c)
                    if token == eos_idx:
                        completed[b_idx].append(new_hyp)
                    else:
                        new_beams[b_idx].append(new_hyp)
                beams = new_beams
                if all(len(b) == 0 for b in beams):
                    break
        # 选最佳
        results = []
        for b_idx in range(src.size(0)):
            if completed[b_idx]:
                best = max(completed[b_idx], key=lambda x: x.avg_log_prob(alpha))
            else:
                best = max(beams[b_idx], key=lambda x: x.avg_log_prob(alpha))
            results.append(best.tokens)
        return results
```

## 12. Scheduled Sampling (缓解 Exposure Bias)

### 12.1 问题

Teacher Forcing 训练: 用真值 token 作输入. 但推理时用模型自己的预测 → 分布不一致 (exposure bias).

### 12.2 解决方案

训练时以一定概率使用模型预测, 而非真值:

```python
def train_with_scheduled_sampling(model, src, tgt, src_len, sampling_prob):
    enc_outputs, (h, c) = model.encoder(src, src_len)
    dec_hidden = h[-1]
    dec_cell = c[-1]
    input_t = tgt[:, 0]
    loss = 0
    for t in range(1, tgt.size(1)):
        output, dec_hidden, dec_cell, _ = model.decoder.step(
            input_t, dec_hidden, dec_cell, enc_outputs
        )
        loss_t = criterion(output, tgt[:, t])
        loss += loss_t
        # Scheduled sampling: 以 sampling_prob 使用模型预测
        if torch.rand(1).item() < sampling_prob:
            input_t = output.argmax(-1)
        else:
            input_t = tgt[:, t]
    return loss / (tgt.size(1) - 1)

# 训练过程中 sampling_prob 从 0 线性增长到 0.5
def get_sampling_prob(epoch, total_epochs, max_prob=0.5):
    return max_prob * epoch / total_epochs
```

## 13. PackedSequence (变长序列加速)

```python
# 处理变长序列, 避免 padding 计算浪费
import torch.nn.utils.rnn as rnn_utils

def pack_padded_sequences(src, src_lengths):
    # 按长度降序排序
    sorted_lengths, idx = torch.sort(src_lengths, descending=True)
    sorted_src = src[idx]
    packed = rnn_utils.pack_padded_sequence(
        sorted_src, sorted_lengths.cpu(), batch_first=True, enforce_sorted=False
    )
    return packed, idx

def unpack_padded_sequences(packed_out, idx, original_lengths):
    out, _ = rnn_utils.pad_packed_sequence(packed_out, batch_first=True)
    # 恢复原始顺序
    _, reverse_idx = torch.sort(idx)
    out = out[reverse_idx]
    return out
```

**意义**: RNN 计算量与序列长度成正比, padding 会浪费大量计算. PackedSequence 让 RNN 只算到实际长度.

## 14. BiLSTM-CRF (命名实体识别工业方案)

### 14.1 思路

NER 的标准方案 (Lample et al. 2016):
1. 字符级 BiLSTM 编码每个词 (处理 OOV)
2. 词级 BiLSTM 编码上下文
3. CRF 层做序列标注 (全局最优)

### 14.2 PyTorch 实现 (简化)

```python
class BiLSTMCRF(nn.Module):
    """BiLSTM + CRF for NER"""
    def __init__(self, vocab_size, tagset_size, embed_size, hidden_size):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_size, padding_idx=0)
        self.lstm = nn.LSTM(embed_size, hidden_size, batch_first=True, bidirectional=True)
        self.hidden2tag = nn.Linear(hidden_size * 2, tagset_size)
        # CRF transition matrix
        self.transitions = nn.Parameter(torch.randn(tagset_size, tagset_size))
        self.transitions.data[START_TAG_IDX, :] = -10000
        self.transitions.data[:, END_TAG_IDX] = -10000
        self.tagset_size = tagset_size

    def _forward_alg(self, feats):
        """前向算法计算归一化"""
        init_alphas = torch.full((1, self.tagset_size), -10000.)
        init_alphas[0][START_TAG_IDX] = 0.
        forward_var = init_alphas.expand(feats.size(0), -1)
        for t in range(feats.size(1)):
            emit_score = feats[:, t].unsqueeze(-1)  # (B, T, 1)
            tag_var = forward_var.unsqueeze(1) + self.transitions + emit_score  # (B, T_t, T_t)
            max_tag_var, _ = tag_var.max(dim=1)
            forward_var = max_tag_var + torch.logsumexp(tag_var - max_tag_var.unsqueeze(1), dim=1)
        terminal_var = forward_var + self.transitions[END_TAG_IDX]
        alpha = torch.logsumexp(terminal_var, dim=1)
        return alpha

    def _score_sentence(self, feats, tags):
        """给定 tag 序列, 计算其得分"""
        score = torch.zeros(feats.size(0))
        for t in range(feats.size(1)):
            emit = feats[:, t].gather(1, tags[:, t:t+1]).squeeze(-1)
            trans = self.transitions[tags[:, t], tags[:, t+1]] if t < feats.size(1) - 1 else \
                    self.transitions[tags[:, t], END_TAG_IDX]
            score = score + emit + trans
        return score

    def neg_log_likelihood(self, sentence, tags):
        feats = self._get_lstm_features(sentence)
        forward_score = self._forward_alg(feats)
        gold_score = self._score_sentence(feats, tags)
        return (forward_score - gold_score).mean()

    def _get_lstm_features(self, sentence):
        emb = self.embedding(sentence)
        lstm_out, _ = self.lstm(emb)
        lstm_feats = self.hidden2tag(lstm_out)
        return lstm_feats

    def _viterbi_decode(self, feats):
        backpointers = []
        init_vvars = torch.full((1, self.tagset_size), -10000.)
        init_vvars[0][START_TAG_IDX] = 0
        forward_var = init_vvars
        for feat in feats:
            bptrs_t = []
            viterbivars_t = []
            for next_tag in range(self.tagset_size):
                next_tag_var = forward_var + self.transitions[next_tag]
                best_tag_id = torch.argmax(next_tag_var)
                bptrs_t.append(best_tag_id)
                viterbivars_t.append(next_tag_var[0][best_tag_id])
            forward_var = (torch.tensor(viterbivars_t) + feat).view(1, -1)
            backpointers.append(bptrs_t)
        terminal_var = forward_var + self.transitions[END_TAG_IDX]
        best_tag_id = torch.argmax(terminal_var)
        path_score = terminal_var[0][best_tag_id]
        best_path = [best_tag_id]
        for bptrs_t in reversed(backpointers):
            best_tag_id = bptrs_t[best_tag_id]
            best_path.append(best_tag_id)
        best_path.reverse()
        return path_score, best_path

    def forward(self, sentence):
        feats = self._get_lstm_features(sentence)
        score, tag_seq = self._viterbi_decode(feats[0])
        return score, tag_seq
```

## 18. BiRNN vs Transformer 何时用?

- 特殊场景 (极长序列): S4 / Mamba / Transformer-XL / Reformer

## 19. BiRNN 的常见坑

### 19.1 双向 + 自回归生成

**致命**: BiRNN 不能用于 Decoder, 会看到未来 → 信息泄露.

**解决**: Encoder 用双向, Decoder 只能用单向.

### 19.2 变长序列

**问题**: padding 让 RNN 计算浪费.
**解决**: PackedSequence.

### 19.3 梯度爆炸

**问题**: RNN 反向传播容易梯度爆炸.
**解决**: Gradient clipping (clip=1.0).

### 19.4 隐状态爆炸 (内存)

**问题**: 1.5B token 训练, 隐状态累积占大量内存.
**解决**: Truncated BPTT + detach.

### 19.5 训练不稳定

**问题**: LSTM 训练初期可能损失不下降.
**解决**: 降低学习率 / 预训练 Embedding / 减小初始化.

        data.append((src_tensor, tgt_tensor))

test_data = data_process(test_iter)

    tgt_padded = nn.utils.rnn.pad_sequence(tgt_batch, padding_value=PAD_IDX, batch_first=True)
    return src_padded, tgt_padded, torch.tensor(src_lens), torch.tensor(tgt_lens)

        train_loss += loss.item()

## 22. Seq2Seq 的 PyTorch 1.12+ 简化写法

PyTorch 1.12 引入了 `Transformer` 模块, 可以更简洁地写:

```python
import torch.nn as nn

class SimpleSeq2Seq(nn.Module):
    """简化版: Transformer 风格 Seq2Seq"""
    def __init__(self, src_vocab, tgt_vocab, d_model=256, nhead=8, num_layers=3):
        super().__init__()
        self.src_embed = nn.Embedding(src_vocab, d_model, padding_idx=0)
        self.tgt_embed = nn.Embedding(tgt_vocab, d_model, padding_idx=0)
        self.pos_embed = nn.Embedding(5000, d_model)
        self.transformer = nn.Transformer(
            d_model=d_model, nhead=nhead,
            num_encoder_layers=num_layers, num_decoder_layers=num_layers,
            dim_feedforward=512, dropout=0.3, batch_first=True
        )
        self.out = nn.Linear(d_model, tgt_vocab)

    def forward(self, src, tgt, src_mask=None, tgt_mask=None):
        B, T_s = src.shape
        _, T_t = tgt.shape
        pos_s = torch.arange(T_s, device=src.device).unsqueeze(0).expand(B, -1)
        pos_t = torch.arange(T_t, device=tgt.device).unsqueeze(0).expand(B, -1)
        src_emb = self.src_embed(src) + self.pos_embed(pos_s)
        tgt_emb = self.tgt_embed(tgt) + self.pos_embed(pos_t)
        out = self.transformer(src_emb, tgt_emb,
                                src_mask=src_mask, tgt_mask=tgt_mask)
        return self.out(out)
```

虽然 Transformer 是主流, 但 BiRNN 在以下场景仍有价值:

- Google 的流式语音识别
- Encoder: BiLSTM, Predictor: LSTM, Joint: feedforward
- 适合实时 ASR (300ms 延迟)

## 29. 常见面试问题

### Q1: 为什么 BiRNN 不能做语言模型?

A: BiRNN 会看到未来 token (后向 RNN), 导致训练时目标 token 已被输入, 信息泄露. 训练 loss 虚低, 推理时无未来信息, 性能崩.

### Q2: Seq2Seq 的"信息瓶颈"是什么?

A: 整个输入压成一个定长向量 c. 长序列丢失细节. 注意力机制让 Decoder 每步动态读取所有 Encoder 状态.

### Q3: Bahdanau 和 Luong attention 的区别?

A: Bahdanau 加性 (tanh(Ws + Uh)), Luong 乘性 (s^T U h 或 s^T h). Bahdanau 略好但贵, Luong 更简洁.

### Q4: 为什么要除以 sqrt(d)?

A: 在 dot-product attention 中, 当 d 大时, 点积方差大, softmax 接近 one-hot, 梯度消失. 除以 sqrt(d) 让方差归一.

### Q5: Beam Search 为什么能提升翻译质量?

A: 贪婪搜索每步取 argmax, 易陷入局部最优. Beam Search 保留 top-k 候选, 探索更广.

### Q6: Teacher Forcing 是什么? 有什么问题?

A: 训练时用真值 token 作输入, 加速稳定. 但暴露偏差 (exposure bias): 推理时分布不一致. 缓解: scheduled sampling.

### Q7: 为什么 BiLSTM-CRF 比单独 BiLSTM 在 NER 上好?

A: CRF 层建模标签转移约束 (B-PER 后面不能跟 I-LOC), 利用全局标签序列信息, 减少非法序列.

### Q8: 解释 PackedSequence.

A: 把变长序列打包, RNN 只计算到实际长度, 避免 padding 浪费. 训练加速显著 (尤其 padding 比例高时).

## 33. RNN 的"梯度问题"深入

### 33.1 梯度消失与爆炸 (数学推导)

RNN 反向传播 (BPTT):

$$\frac{\partial \mathcal{L}_t}{\partial \mathbf{h}_k} = \frac{\partial \mathcal{L}_t}{\partial \mathbf{h}_t} \prod_{i=k+1}^{t} \frac{\partial \mathbf{h}_i}{\partial \mathbf{h}_{i-1}} = \frac{\partial \mathcal{L}_t}{\partial \mathbf{h}_t} \prod_{i=k+1}^{t} \mathbf{W}_h^\top \cdot \text{diag}(\sigma'(\cdot))$$

如果 $\mathbf{W}_h$ 的特征值 $\lambda < 1$, 梯度指数衰减 (消失); $|\lambda| > 1$, 梯度指数增长 (爆炸).

### 33.2 LSTM 如何解决

LSTM 的 cell state 更新:

$$\mathbf{c}_t = \mathbf{f}_t \odot \mathbf{c}_{t-1} + \mathbf{i}_t \odot \tilde{\mathbf{c}}_t$$

如果遗忘门 $\mathbf{f}_t \approx 1$, 梯度可以无衰减地流过时间.

### 33.3 实践中的处理

```python
# 梯度裁剪
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)

# LSTM 替代 vanilla RNN
self.rnn = nn.LSTM(input_size, hidden_size, batch_first=True)

# 残差连接
out = out + residual
```

## 36. 进阶 RNN 变体

### 36.1 QRNN (Quasi-Recurrent Neural Networks)

用卷积替代 RNN 的循环计算, 实现并行:

```python
class QRNN(nn.Module):
    def __init__(self, input_size, hidden_size, kernel_size=2):
        super().__init__()
        self.conv = nn.Conv1d(input_size, 3 * hidden_size, kernel_size)
        self.hidden_size = hidden_size

    def forward(self, x):
        # x: (B, T, D)
        # 卷积
        gates = self.conv(x.transpose(1, 2)).transpose(1, 2)  # (B, T, 3H)
        z, f, o = gates.chunk(3, dim=-1)
        z = torch.tanh(z)
        f = torch.sigmoid(f)
        o = torch.sigmoid(o)
        # 并行扫描 (Quasi)
        h = []
        h_prev = torch.zeros_like(z[:, 0])
        for t in range(z.size(1)):
            h_t = f[:, t] * h_prev + (1 - f[:, t]) * z[:, t]
            h.append(h_t)
            h_prev = h_t
        h = torch.stack(h, dim=1)  # (B, T, H)
        return o * h
```

**优势**: 训练并行 (比 LSTM 快 2-4x), 推理可并行
**劣势**: 长期依赖能力略弱

### 36.2 SRU (Simple Recurrent Unit)

类似 QRNN, 但用更简单的门控:

```python
class SRU(nn.Module):
    """SRU: 高速 RNN"""
    def __init__(self, input_size, hidden_size):
        super().__init__()
        self.linear = nn.Linear(input_size, 3 * hidden_size)
        self.hidden_size = hidden_size

    def forward(self, x):
        gates = self.linear(x)  # (B, T, 3H)
        u, r, c = gates.chunk(3, dim=-1)
        u = torch.tanh(u)
        r = torch.sigmoid(r)
        c = torch.sigmoid(c)
        # 并行扫描
        h = []
        c_prev = c[:, 0]
        for t in range(x.size(1)):
            c_t = c[:, t]
            h_t = r[:, t] * u[:, t] + (1 - r[:, t]) * c_prev * u[:, t]
            # 实际 SRU 公式略复杂
            h.append(h_t)
            c_prev = c_t
        return torch.stack(h, dim=1)
```

### 36.3 引申: 线性 RNN / S4 / Mamba

## 45. BiRNN 与 Attention 的协同

### 45.1 Soft Attention (Bahdanau/Luong)

```python
class Seq2SeqWithAttention(nn.Module):
    """BiLSTM Encoder + Attention + LSTM Decoder"""
    def __init__(self, src_vocab, tgt_vocab, embed_size, hidden_size):
        super().__init__()
        self.encoder = nn.LSTM(embed_size, hidden_size, bidirectional=True, batch_first=True)
        self.decoder = nn.LSTM(embed_size + hidden_size * 2, hidden_size, batch_first=True)
        self.attention = BahdanauAttention(hidden_size * 2)
        self.out = nn.Linear(hidden_size, tgt_vocab)

    def forward(self, src, tgt):
        enc_out, (h, c) = self.encoder(src)
        # 处理双向 h, c 为 decoder 初始状态
        h = torch.cat([h[0], h[1]], dim=-1)
        c = torch.cat([c[0], c[1]], dim=-1)
        # Decoder
        outputs = []
        dec_input = tgt[:, 0:1]  # <BOS>
        for t in range(1, tgt.size(1)):
            emb = self.decoder_embedding(dec_input)
            ctx, _ = self.attention(h, enc_out)
            lstm_in = torch.cat([emb, ctx.unsqueeze(1)], dim=-1)
            out, (h, c) = self.decoder(lstm_in, (h, c))
            outputs.append(self.out(out))
            dec_input = tgt[:, t:t+1]  # teacher forcing
        return torch.cat(outputs, dim=1)
```

## 46. RNN-T (Recurrent Neural Network Transducer)

### 46.1 介绍

RNN-T 是流式 ASR 的事实标准 (Google, Apple, 阿里):

```text
         ┌─────────────┐
         │   Encoder   │  BiLSTM, 处理音频
         │   (audio)   │
         └──────┬──────┘
                │
                ↓
        ┌───────────────┐
        │   Predictor   │  LSTM, 处理历史文本
        │   (text)      │
        └───────┬───────┘
                ↓
        ┌───────────────┐
        │    Joint      │  feedforward
        │   network     │
        └───────┬───────┘
                ↓
              output
```

### 46.2 PyTorch 实现 (简化)

```python
class RNNT(nn.Module):
    """RNN-T for streaming ASR"""
    def __init__(self, input_size, vocab_size, hidden_size=512, num_layers=3):
        super().__init__()
        self.encoder = nn.LSTM(input_size, hidden_size, num_layers=num_layers,
                               batch_first=True, bidirectional=True)
        self.predictor = nn.LSTM(vocab_size, hidden_size, num_layers=2, batch_first=True)
        self.joint = nn.Sequential(
            nn.Linear(hidden_size * 2 + hidden_size, hidden_size),
            nn.Tanh(),
            nn.Linear(hidden_size, vocab_size)
        )
        self.vocab_size = vocab_size

    def forward(self, audio, text):
        # audio: (B, T_a, D_audio)
        # text: (B, T_t, V) one-hot
        enc_out, _ = self.encoder(audio)  # (B, T_a, 2H)
        pred_out, _ = self.predictor(text)  # (B, T_t, H)
        # Joint: outer sum
        B, T_a, _ = enc_out.shape
        _, T_t, _ = pred_out.shape
        enc_exp = enc_out.unsqueeze(2).expand(-1, -1, T_t, -1)  # (B, T_a, T_t, 2H)
        pred_exp = pred_out.unsqueeze(1).expand(-1, T_a, -1, -1)  # (B, T_a, T_t, H)
        joint_in = torch.cat([enc_exp, pred_exp], dim=-1)
        out = self.joint(joint_in)  # (B, T_a, T_t, V)
        return out
```

## 56. 完整训练 RNN 的工程模板

```python
import torch
import torch.nn as nn
from torch.utils.data import Dataset, DataLoader
from torch.nn.utils.rnn import pad_sequence

class RNNDataset(Dataset):
    def __init__(self, sequences, labels):
        self.sequences = sequences
        self.labels = labels

    def __len__(self):
        return len(self.sequences)

    def __getitem__(self, idx):
        return self.sequences[idx], self.labels[idx]

def collate_fn(batch):
    sequences, labels = zip(*batch)
    seq_lens = torch.tensor([len(s) for s in sequences])
    padded = pad_sequence(sequences, batch_first=True, padding_value=0)
    labels = torch.stack(labels)
    return padded, labels, seq_lens

def train_rnn(model, train_loader, val_loader, optimizer, criterion, device, epochs=10):
    best_val_acc = 0
    for epoch in range(epochs):
        # 训练
        model.train()
        train_loss = 0
        for src, labels, src_len in train_loader:
            src = src.to(device)
            labels = labels.to(device)
            optimizer.zero_grad()
            logits = model(src)  # 模型已处理变长
            loss = criterion(logits, labels)
            loss.backward()
            torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
            optimizer.step()
            train_loss += loss.item()
        # 验证
        model.eval()
        val_correct = 0
        val_total = 0
        with torch.no_grad():
            for src, labels, src_len in val_loader:
                src = src.to(device)
                labels = labels.to(device)
                logits = model(src)
                preds = logits.argmax(-1)
                val_correct += (preds == labels).sum().item()
                val_total += labels.size(0)
        val_acc = val_correct / val_total
        print(f'Epoch {epoch}: train_loss={train_loss/len(train_loader):.4f}, val_acc={val_acc:.4f}')
        if val_acc > best_val_acc:
            best_val_acc = val_acc
            torch.save(model.state_dict(), 'best.pt')
```

## 57. RNN 在 GPU 上的注意事项

### 57.1 cuDNN 优化

PyTorch 默认用 cuDNN 加速 LSTM/GRU. 但有条件:

1. 输入不需要 PackedSequence (cuDNN 自动处理)
2. 权重连续
3. `batch_first` 设置正确
4. 没有自定义 cell

### 57.2 显存估算

- LSTM 权重: $4 \times H \times (D + H + 1)$ per layer (per direction)
- 隐藏状态: $B \times T \times H \times 2$ (forward + backward)
- Cell state: 同上
- 梯度: 等于权重 × 2

**例子**: BiLSTM, D=128, H=256, B=64, T=128
- 权重: $4 \times 256 \times (128+256+1) \times 2 = 791K$ params/layer
- 隐藏状态: $64 \times 128 \times 256 \times 2 \times 2 = 8.4M$ values
- 显存: 约 30MB / layer (fp32)

        if 'bias' in name:
            n = p.size(0)

            p.data[n//4:n//2].fill_(1.0)  # forget gate bias = 1
