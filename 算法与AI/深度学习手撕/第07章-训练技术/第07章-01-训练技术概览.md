## 2. Dropout 详解

### 2.1 内容介绍

**Dropout** (Hinton, 2012) 在训练时随机"丢弃"一部分神经元, 防止过拟合.

---

### 2.2 为什么这么做

**问题**:
- 大网络容易过拟合 (训练集好, 测试集差)
- 集成学习 (ensemble) 效果好但慢

**解决**:
- 训练时随机"关闭"部分神经元
- 推理时用全部神经元
- 等价于训练大量"子网络"的集成

---

### 2.3 公式

```text
训练:  y = (x * mask) / (1 - p)   (Inverted Dropout, 推荐)
推理:  y = x
```

**关键**: 训练时除以 (1-p), 让训练/推理期望一致 (无需额外处理).

---

### 2.4 实现

```python
import numpy as np

class Dropout:
    def __init__(self, p=0.5):
        """p: 丢弃概率"""
        self.p = p
        self.training = True

    def forward(self, x):
        if not self.training:
            return x
        # Inverted Dropout: 训练时缩放
        mask = (np.random.rand(*x.shape) > self.p) / (1 - self.p)
        return x * mask

    def train(self):
        self.training = True

    def eval(self):
        self.training = False

# 验证
drop = Dropout(p=0.5)
x = np.ones((3, 4))
drop.train()
print("训练模式 (随机 dropout):")
print(drop.forward(x))
drop.eval()
print("\n推理模式 (无 dropout):")
print(drop.forward(x))
```

## 2A. Dropout 理论的深度展开

### 2A.1 历史与动机

Dropout 由 Srivastava、Hinton、Krizhevsky、Sutskever、Salakhutdinov 于 2014 年在 JMLR 上正式发表 (论文: "Dropout: A Simple Way to Prevent Neural Networks from Overfitting")。其思想可以追溯到 Hinton 2012 年在 NIPS 研讨会上的口头报告, 以及同年的 Denoising Autoencoder 思想 (Vincent et al., 2010)。

**过拟合的根源**: 模型参数量 $p$ 与训练样本量 $N$ 之比 $\rho = p/N$ 过大, 经验风险最小化会拟合噪声而非真实函数。Dropout 通过在每次前向时随机"砍掉"部分连接, 等价于对网络权重施加一个隐式的 $\ell_2$ 正则化 (取决于具体配置, 详见 §2A.4)。

### 2A.2 数学形式化

设某层输入 $\mathbf{x} \in \mathbb{R}^d$, 输出 $\mathbf{y} = \mathbf{W}\mathbf{x} + \mathbf{b}$。
Inverted Dropout 在训练时:

$$
\mathbf{m} \sim \text{Bernoulli}(1-p)^d, \quad
\tilde{\mathbf{x}} = \frac{\mathbf{m}}{1-p} \odot \mathbf{x}, \quad
\mathbf{y} = \mathbf{W}\tilde{\mathbf{x}} + \mathbf{b}
$$

其中 $p$ 为丢弃概率 (默认 0.5), $\odot$ 为逐元素乘。

**期望不变性**:

$$
\mathbb{E}[\tilde{\mathbf{x}}_i] = \mathbb{E}\!\left[\frac{m_i}{1-p}\right] x_i = \frac{1-p}{1-p} x_i = x_i
$$

即训练时输出与不 dropout 时同分布, 推理时可直接使用全部神经元, 无需额外缩放 —— 这是 **Inverted Dropout** 优于 **Vanilla Dropout** 的核心原因。Vanilla Dropout 在训练时不缩放, 推理时需要乘以 $(1-p)$, 实现繁琐且容易出错。

### 2A.3 Dropout 与模型集成

Srivastava et al. 证明: 使用 $n$ 个神经元的网络 + Dropout, 等价于训练 $\sum_{k=0}^{n}\binom{n}{k}$ 个共享参数的"瘦子网络"的集成。
- $n=100$ 时, 子网络数为 $1.27 \times 10^{30}$, 远超任何显式 ensemble 的可能规模。
- 但这些子网络的参数被指数级共享, 训练一次即可获得 ensemble 效果。

从 Bayesian 角度看, Dropout 是 **MC Dropout** (Monte Carlo Dropout, Gal & Ghahramani 2016) 的特例, 后者把 dropout 当作变分推断的高斯先验采样, 可用于获得预测不确定性。

### 2A.4 隐式正则化等价

Wager et al. (2013) 在 "Adaptive Dropout" 中证明: 对线性回归 + Dropout, 等价于对权重加 **adaptive L2 正则**:

$$
\mathcal{L}_{\text{dropout}} = \frac{1}{2N}\sum_i (y_i - \mathbf{w}^T\mathbf{x}_i)^2 + \lambda \|\mathbf{w}\|^2 / \xi
$$

其中 $\lambda$ 与输入方差有关 (体现"自适应")。对深度非线性网络, 该等价不完全成立, 但 $\ell_2$ 兼容性提供了直觉 —— 训练时打开 Dropout 通常可以适度减小 weight decay。

### 2A.5 Dropout 的变体

| 变体 | 论文 | 关键思想 | 典型应用 |
|---|---|---|---|
| **Spatial Dropout** | Tompson et al. 2014 | 丢弃整个 feature map channel | CNN |
| **DropBlock** | Ghiasi et al. 2018 | 丢弃连续块 (rectangular region) | CNN, 强于普通 Dropout |
| **DropConnect** | Wan et al. 2013 | 随机丢弃权重而非激活 | MLP / CNN |
| **Alpha Dropout** | Klambauer et al. 2017 | 配合 SELU 保持均值/方差 | 自归一化网络 (SNN) |
| **DropPath** (Stochastic Depth) | Huang et al. 2016 | 随机跳过整条残差分支 | ResNet, Vision Transformer |
| **Gaussian Dropout** | Srivastava 2013 | 激活乘 $1+\epsilon, \epsilon \sim \mathcal{N}(0, p)$ | 连续可微, 用于 RNN |
| **Variational Dropout** | Kingma et al. 2015 | 每层共享 mask, 降低方差 | RNN |
| **MC Dropout** | Gal & Ghahramani 2016 | 推理时多次采样近似贝叶斯 | 不确定性估计 |
| **Concrete Dropout** | Gal et al. 2017 | 可学习 dropout rate | AutoML, 调超参 |
| **R-Drop** | Liang et al. 2021 | 同一输入两次 forward, 迫使两次分布一致 | LLM, NLP 微调 |
| **DropAttention** | Zehui et al. 2021 | 注意力权重的 dropout | Transformer |
| **FlashAttention Dropout** | Dao et al. 2022 | 在 flash attention 内部做 dropout | LLM 长序列 |

### 2A.6 Spatial Dropout 实现

```python
import torch
import torch.nn as nn

class SpatialDropout(nn.Module):
    """
    对 Conv feature map 的整个 channel 做 dropout
    输入: (B, C, H, W), 沿 C 维度生成 mask
    """
    def __init__(self, p=0.2):
        super().__init__()
        self.p = p

    def forward(self, x):
        if not self.training or self.p == 0:
            return x
        # (B, 1, 1, 1) → broadcast 到 (B, C, H, W)
        mask = (torch.rand(x.size(0), 1, 1, 1, device=x.device) > self.p).float()
        return x * mask / (1 - self.p)
```

**为什么需要 Spatial Dropout**: 普通 Dropout 独立地丢弃每个像素, 但相邻像素高度相关, 实际去激活作用很弱 (channel mask 实际只丢少量信息)。Spatial Dropout 整 channel 丢弃, 强制模型不要过度依赖某一个特征图, 在语义分割、目标检测上提升显著 (3-5 mIoU)。

### 2A.7 DropBlock 实现 (CNN 强过拟合场景)

```python
class DropBlock(nn.Module):
    """
    DropBlock (Ghiasi et al., 2018)
    思想: 在 feature map 上采样一个 block_size × block_size 的连续区, 整块丢 0
    比普通 dropout 更强, 因为它删除了语义信息, 而非仅丢独立像素
    """
    def __init__(self, block_size=7, p=0.1):
        super().__init__()
        self.block_size = block_size
        self.p = p

    def forward(self, x):
        if not self.training or self.p == 0:
            return x
        B, C, H, W = x.shape
        gamma = (self.p * H * W) / (self.block_size ** 2) / \
                ((H - self.block_size + 1) * (W - self.block_size + 1))

        # 1. 采样中心点 (B, C, H-bs+1, W-bs+1)
        mask = torch.rand(B, C, H - self.block_size + 1, W - self.block_size + 1,
                          device=x.device).lt(gamma).float()

        # 2. 转置卷积扩展 mask
        mask = F.conv_transpose2d(
            mask, weight=torch.ones(1, 1, self.block_size, self.block_size, device=x.device),
            stride=1, groups=1
        )
        # 3. 裁剪回 H x W
        m1s = mask.shape
        mask = mask[:, :, :H, :W]
        mask = torch.cat([torch.zeros(B, C, H, W - m1s[3], device=x.device), mask], dim=3)
        mask = torch.cat([torch.zeros(B, C, H - m1s[2], W, device=x.device), mask], dim=2)

        # 4. 归一化 + 应用
        mask = mask * (mask.numel() / mask.sum().clamp(min=1e-8))
        return x * mask * (1.0 - self.p)  # 避免除零
```

**学术结果**: ResNet-50 + DropBlock 在 ImageNet 上 +0.6% top-1 (76.5% → 77.1%); 在 COCO 检测上 mAP 提升 ~1.5。

### 2A.8 DropPath / Stochastic Depth 实现

```python
class DropPath(nn.Module):
    """
    Stochastic Depth (Huang et al., 2016) / DropPath
    训练时随机跳过残差块, 推理时全程使用, 乘 survival prob
    关键创新: 加 survival rate 衰减, 让深层 skip 概率更高, 平衡期望
    """
    def __init__(self, drop_prob=0.1):
        super().__init__()
        self.drop_prob = drop_prob

    def forward(self, x):
        if not self.training or self.drop_prob == 0:
            return x
        keep_prob = 1 - self.drop_prob
        # per-sample 决策, 不同 sample 不同路径
        shape = (x.shape[0],) + (1,) * (x.ndim - 1)
        mask = torch.rand(shape, device=x.device) < keep_prob
        return x * mask / keep_prob  # inverted rescale
```

**在 Vision Transformer 中的使用**: `timm` 的 ViT 几乎所有模型都使用 `drop_path_rate` 在每个 attention/FFN 之间 (Linear → DropPath → Residual → Linear → DropPath → Residual), ViT-Large 默认 0.1, BeiT/PVT 等大模型用 0.3-0.5。

### 2A.9 现代 Dropout 选择建议

```text
CNN 小模型 (ResNet-18/34): 普通 Dropout + 轻量 Spatial Dropout
CNN 大模型 (ResNet-50+): DropBlock (block_size=7, p=0.1)
ViT: DropPath 0.1-0.5 (按模型规模递增)
BERT: 注意力 + hidden + 嵌入 三处 dropout 0.1
LLM (decoder only): 注意力 dropout 0.0, hidden dropout 0.0 (避免熵坍缩)
  + R-Drop 或只在 embedding 层 dropout
GAN: G/D 都用 Dropout, 但 BatchNorm 不在 G
```

## 3. 混合精度训练 (AMP)

### 3.1 为什么

**问题**:
- FP32 训练慢, 占显存
- 近年 GPU (V100, A100) 有 FP16 / BF16 加速 (Tensor Cores)

**解决**:
- 前向 + 反向用 FP16 / BF16
- 优化器状态 (master weights) 用 FP32
- Loss Scaling 防 FP16 梯度下溢

---

### 3.2 实现 (伪代码)

```python
class MixedPrecisionTrainer:
    """
    简化版 AMP 训练
    实际 PyTorch: torch.cuda.amp.autocast + GradScaler
    """
    def __init__(self, model, optimizer, loss_scale=2**14):
        self.model = model
        self.optimizer = optimizer
        # FP32 master weights
        self.master_params = [p.data.copy() for p in model.params]
        self.loss_scale = loss_scale

    def step(self, x, y):
        # 1. 前向 (FP16)
        with autocast(dtype='float16'):
            y_pred = self.model.forward(x.astype(np.float16))
            loss = compute_loss(y_pred, y)

        # 2. 反向 (FP16, loss scaled)
        scaled_loss = loss * self.loss_scale
        grads = self.model.backward(scaled_loss)

        # 3. 梯度 unscale
        grads = [g / self.loss_scale for g in grads]

        # 4. 检查 NaN/Inf (skip if any)
        if any(np.isnan(g).any() or np.isinf(g).any() for g in grads):
            return None  # skip update

        # 5. 更新 FP32 master weights
        for p, g, mp in zip(self.model.params, grads, self.master_params):
            mp -= self.optimizer.lr * g
            p.data = mp.astype(p.dtype)  # cast back to FP16 for forward
```

### 3A.3 Gradient Accumulation + AMP 实战

当单卡 batch 装不下有效 batch size 时, 用梯度累积模拟大 batch, 配合 AMP 是 LLM 标配:

```python
import torch
from torch.cuda.amp import autocast, GradScaler

scaler = GradScaler()
accum_steps = 8  # 等效 batch = micro_batch × 8
optimizer.zero_grad()

for i, (x, y) in enumerate(loader):
    with autocast(dtype=torch.bfloat16):  # BF16 通常不需要 scaler
        loss = model(x, y) / accum_steps   # 关键: 除以 accum_steps

    scaler.scale(loss).backward()  # BF16 模式 scaler.scale 是 noop

    if (i + 1) % accum_steps == 0:
        # gradient clipping on FP32 master weights
        scaler.unscale_(optimizer)
        torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
        scaler.step(optimizer)
        scaler.update()
        optimizer.zero_grad()
```

**为什么除以 accum_steps**: 累积 $k$ 次梯度等价于 batch 扩大 $k$ 倍, 但 loss 没除会导致梯度放大 $k$ 倍, 配合 Adam 的自适应步长可以工作, 但 clip 阈值要同步改, 而且梯度中的随机性被放大。除以 accum_steps 让累积等价于真实大 batch, 方便超参迁移。

### 3A.4 学习率调度全景

```python
import math

def get_lr(step, warmup, max_steps, max_lr, min_lr):
    """Llama 风格 cosine warmup"""
    if step < warmup:
        return max_lr * step / warmup
    if step > max_steps:
        return min_lr
    decay_ratio = (step - warmup) / (max_steps - warmup)
    coeff = 0.5 * (1 + math.cos(math.pi * decay_ratio))
    return min_lr + coeff * (max_lr - min_lr)

def get_lr_sqrt(step, warmup, max_lr):
    """GPT-3 风格: warmup 后保持恒定"""
    if step < warmup:
        return max_lr * step / warmup
    return max_lr

def get_lr_wsd(step, warmup, max_steps, max_lr, min_lr):
    """WSD (Warmup-Stable-Decay), MiniCPM, 3阶段"""
    decay_start = int(max_steps * 0.8)
    if step < warmup:
        return max_lr * step / warmup
    if step < decay_start:
        return max_lr
    decay_ratio = (step - decay_start) / (max_steps - decay_start)
    return max_lr - (max_lr - min_lr) * decay_ratio

def get_lr_cosine_warm_restarts(step, T_0, T_mult, max_lr, min_lr):
    """SGDR / cosine annealing warm restarts"""
    pass  # 不展开, 实际不如 wsd 流行
```

**实战选型**:
- **LLM pretraining (100B+)**: cosine warmup + cool down, 0.1% warmup, decay 到 10% max_lr
- **LLM finetuning**: cosine, warmup 50 步, decay 到 0
- **Stable training (RLHF / DPO)**: WSD (更稳定, 不依赖总步数)
- **CV**: cosine with restarts 或 step decay (ResNet 原始配方)
- **GAN**: 恒定 lr 或 linear decay, 不用 cosine

| 策略 | 切分对象 | 通信 | 显存节省 | 适用 |
|---|---|---|---|---|
| **DDP** | 切 batch | AllReduce | 激活/梯度等比 ÷ N | 模型 < 单卡 |
| **FSDP** | 切模型状态 | AllGather | 权重也 ÷ N | 模型 > 单卡, 不用 PP |
| **TP (1D/2D/2.5D/3D)** | 切 matmul 内维度 | AllReduce / AllGather | 权重 ÷ TP_size | 单层太大 (大 hidden) |
| **PP** | 切层 | P2P 传递 activation | 激活 ÷ PP_size | 模型深 |
| **EP** | 切专家 | AllToAll | 仅 MoE 适用 | MoE 模型 |
| **CP** | 切序列 | AllGather + Reduce | 长序列 | 8K+ context |

**DeepSeek-V3 256 卡 (8K H100) 的混合策略**: TP=8 (节点内 NVLink) + EP=8 (专家并行, 总 256 expert) + PP=4 (流水线) + DP=2 (mini-batch), 通过精心调度让 MoE 的 AllToAll 延迟被 EP 通信隐藏。

### 3A.6 ZeRO 优化的三阶段

DeepSpeed (Rasley et al. 2020) 的 ZeRO 把 optimizer state 分阶段切分:

```text
阶段                 Pos       Grad      OptState     通信
---------------------------------------------------------------
ZeRO-1 (DP=64)       全        全        切 64 份     ↓ 4×
ZeRO-2               全        切 64 份  切 64 份     ↓ 8×
ZeRO-3               切 64 份  切 64 份  切 64 份     ↓ 内存 ≈ 单卡
```

**ZeRO-3 + RAR (Replicated AllGather Reduction)**: FSDP 默认实现的通信优化, 前向时 only-gather 当前用到的 layer, 反向完成后立即 free。

### 3A.7 FSDP vs DDP: 选择标准

```python
from torch.distributed.fsdp import fully_shard
```

## 4A. 权重初始化 (动量开始前的隐藏前提)

权重初始化决定了训练的起点。错误初始化 → 梯度爆炸 / 消失 → 训不出。

### 4A.1 早期: 零初始化 / 随机小值

**全零初始化** ❌: 所有神经元学到相同特征 (对称性问题)。
**随机小值** ❌: 网络越深越容易梯度消失 (sigmoid 时代)。

### 4A.2 He/Xavier 初始化

**Xavier (Glorot, 2010)**: 假设激活线性, 使前向/反向方差稳定:

$$
\text{Var}(W) = \frac{2}{n_\text{in} + n_\text{out}}
$$

适用于 tanh / sigmoid (近似线性的饱和点附近)。

**He (He et al., 2015)**: 修正为 ReLU 单侧抑制:

$$
\text{Var}(W) = \frac{2}{n_\text{in}}
$$

**推导** (He 论文):
- ReLU 后, 方差减半: $\text{Var}(\text{ReLU}(z)) = \frac{1}{2}\text{Var}(z)$ (假设 $z$ 均值为 0 的对称分布)
- 想保持 $\text{Var}(\text{ReLU}(W x)) = \text{Var}(x)$
- $\text{Var}(Wx) = n_\text{in} \text{Var}(W) \text{Var}(x) = 2 \text{Var}(x)$
- 所以 $\text{Var}(W) = 2/n_\text{in}$

```python
# PyTorch 默认
nn.Linear(in_features, out_features)  # weight ~ U(-√(1/in), √(1/in))
                                       # 但用的是 kaiming_uniform_, 见下

nn.init.kaiming_normal_(layer.weight, mode='fan_in', nonlinearity='relu')
nn.init.xavier_normal_(layer.weight, gain=1.0)
```

### 4A.3 深度缩放 (DeepScale)

GPT-2 / GPT-3 / LLaMA 用的初始化: 让更深网络仍能稳定训练。

```python
def init_weights(module, std=0.02):
    """LLaMA 风格的 init"""
    if isinstance(module, nn.Linear):
        nn.init.normal_(module.weight, mean=0.0, std=std)
        if module.bias is not None:
            nn.init.zeros_(module.bias)
    elif isinstance(module, nn.Embedding):
        nn.init.normal_(module.weight, mean=0.0, std=std)

# 在残差层的最后一层, 缩小 init std
def init_residual(layer, n_layers, std=0.02):
    """DeepScale init, GPT-2 / 3 的关键技巧"""
    # 最后一层用 std / sqrt(2 * n_layers)
    scale = std / math.sqrt(2 * n_layers)
    nn.init.normal_(layer.weight, std=scale)
```

### 4A.4 μP (Maximal Update Parametrization, Yang & Hu 2021)

跨模型尺寸的超参迁移: 让小模型的最优超参在大模型上仍然最优。关键 trick: 把 init scale, lr, init density 与宽度成反比/正比映射。Hegde 等用 μP 在 1.2B 模型上找到的 lr 直接迁移到 6.7B GPT 模型, 无需重新调参。

### 4A.5 谱归一化与正交初始化

**Spectral Normalization** (Miyato et al., 2018): 通过 power iteration 把权重矩阵的最大奇异值限制为 1, 强制 Lipschitz ≤ 1, 是 GAN 训练的标配。

```python

# 每次 forward 都做一次 power iteration 更新 u, v
```

**正交初始化** (Saxe et al., 2014): 用随机正交矩阵初始化, 比 Glorot 更保守。

## 4B. 梯度处理

### 4B.1 梯度裁剪 (Gradient Clipping)

```python
# 1. 阈值裁剪 (used in RNN, GPT-3)
torch.nn.utils.clip_grad_value_(model.parameters(), clip_value=0.5)

# 2. 范数裁剪 (更常用)
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
# 计算总范数 ||g||_2, 若 > max_norm, 缩放 g * max_norm / ||g||_2
```

**理论**: Pascanu et al. 2013 在 "On the difficulty of training recurrent neural networks" 中证明, 梯度爆炸 (||g|| → ∞) 是 RNN/Transformer 训练的主要障碍, clip-by-norm 是有效解。

**LLaMA / GPT 系列** 默认 `max_norm=1.0`, 配合 warmup 是稳定训练标配。

### 4B.2 梯度累积 + 梯度裁剪的交互

```text
原始 large-batch 等价 update:
    total_grad = sum of k micro grads
    clip(total_grad, max_norm)

工程实现 (节省显存):
    for i in 0..k:
        loss_i.backward()  # 累加到 .grad
    clip(total_grad, max_norm)  # 裁剪累加后的梯度
```

⚠️ **常见错误**: 在每个 micro-step 后做 clip, 这等同于裁剪了 $k$ 次, 等价于把所有梯度按 $1/k^{0.5}$ 缩放 (clip-norm 是仿射变换, 不是线性), 与 large-batch 真实行为不等价。**正确做法**: 累加, 然后裁剪 (Megatron / LLaMA 训练源码)。

### 4B.3 大模型训练: 跳过 step (Rollover)

如果某 step 检测到 NaN/Inf, 不能瞎更新参数:

```python
for step, batch in enumerate(loader):
    loss = compute(model, batch)
    scaler.scale(loss).backward()
    scaler.unscale_(optimizer)

    # 检查全局 inf/nan
    inf_nan = check_global_grad_norm(model.parameters())  # 跨卡同步
    if inf_nan == float('inf'):
        print(f'step {step}: skip due to grad explosion')
        optimizer.zero_grad()  # 清掉, 不要用 stale grad
        continue

    scaler.step(optimizer)
    scaler.update()
    optimizer.zero_grad()
```

**LLaMA-3 训练**:
- 每 step 都检查 gradient norm (跨节点 AllReduce)
- 若 norm > threshold (e.g. > 1e4), 该 step 跳过 (lr update 仍然记录, 但不更新参数)
- 同时动态调整 lr (类似 GradScaler)
- 出现频率 < 0.01%, 通常是某 batch 数据问题

### 4B.4 梯度噪声 (Jacobian Regularization 等隐式正则)

对 loss 加 Jacobian 范数正则可以提升对抗鲁棒性:

$$
\mathcal{L} = \mathcal{L}_{\text{task}} + \lambda \mathbb{E}_x \|\nabla_x f(x)\|_F^2
$$

实现昂贵 (前向 + 反向 + 反向的反向), 一般用 Neumann series 近似。DeepMind, OpenAI 在对抗训练中用过。

### 4C.2 AdamW 全实现 (理解 optimizer state)

```python
class AdamW:
    """
    AdamW (Loshchilov & Hutter 2019)
    关键: weight_decay 与 lr-based update 解耦, 写为:
        theta = theta - lr * (m_hat / (sqrt(v_hat) + eps) + lambda * theta)
    Adam (L2 + lr-decoupled) 的等价形式 weight_decay 与 momentum 耦合, 在高 lr 下会失效
    """
    def __init__(self, params, lr=1e-3, betas=(0.9, 0.999), eps=1e-8, weight_decay=0.01):
        self.params = list(params)
        self.lr = lr
        self.b1, self.b2 = betas
        self.eps = eps
        self.wd = weight_decay
        # 状态: 每参数 (m, v, step)
        self.state = {id(p): {'m': torch.zeros_like(p), 'v': torch.zeros_like(p), 't': 0}
                      for p in self.params}

    def step(self):
        for p in self.params:
            st = self.state[id(p)]
            st['t'] += 1
            g = p.grad

            # 1. 衰减一阶矩
            st['m'].mul_(self.b1).add_(g, alpha=1 - self.b1)
            # 2. 衰减二阶矩
            st['v'].mul_(self.b2).addcmul_(g, g, value=1 - self.b2)
            # 3. bias correction
            bc1 = 1 - self.b1 ** st['t']
            bc2 = 1 - self.b2 ** st['t']
            m_hat = st['m'] / bc1
            v_hat = st['v'] / bc2

            # 4. update (解耦的 weight decay + Adam 部分)
            p.data.add_(p.data, alpha=-self.lr * self.wd)              # weight decay
            p.data.addcdiv_(m_hat, v_hat.sqrt_().add_(self.eps), value=-self.lr)
```

**为什么 AdamW 优于 Adam + L2 decay**:
- Adam 的 L2 是通过 loss 加 $\lambda \|w\|^2$, 求导得 $\nabla L + \lambda w$, 再进入 Adam 的自适应 (除以 $\sqrt{v+\epsilon}$)
- AdamW 把 $\lambda w$ 直接施加在 update 上, 不被 $\sqrt{v}$ 缩放
- 配合高 lr + 强 wd (如 0.1), Adam 才能 work (否则 wd 实质无效)

### 4C.3 Lion (Chen et al., 2023)

```python
class Lion:
    """
    Lion: sign(m) update (只用一阶矩, 但用 momentum 的符号)
    显存: 每个标量只需存 m, 不需要 v → 优化器状态减半
    速度: 1.3-1.5x faster on most tasks
    """
    def __init__(self, params, lr=1e-4, betas=(0.9, 0.99), weight_decay=0.0):
        self.params = list(params)
        self.lr = lr
        self.b1, self.b2 = betas
        self.wd = weight_decay
        self.state = {id(p): {'m': torch.zeros_like(p)} for p in self.params}

    def step(self):
        for p in self.params:
            st = self.state[id(p)]
            g = p.grad
            # update 用符号
            update = st['m'].mul(self.b1).add(g, alpha=1 - self.b1).sign()
            p.data.add_(update, alpha=-self.lr)
            # 然后用更慢的 b2 更新 m
            st['m'].mul_(self.b2).add_(g, alpha=1 - self.b2)
            if self.wd:
                p.data.mul_(1 - self.lr * self.wd)
```

| 优化器 | 隐式正则 |

### 4D.2 Mixup 实现

```python
def mixup_data(x, y, alpha=0.4):
    """Mixup (Zhang et al. 2017)
    训练: 用混合样本, 标签用 one-hot 凸组合"""
    lam = np.random.beta(alpha, alpha)  # 0.5 左右概率大
    idx = torch.randperm(x.size(0)).to(x.device)
    mixed_x = lam * x + (1 - lam) * x[idx]
    y_a, y_b = y, y[idx]
    return mixed_x, y_a, y_b, lam

# 训练 loop
mixed_x, y_a, y_b, lam = mixup_data(x, y)
pred = model(mixed_x)
loss = lam * criterion(pred, y_a) + (1 - lam) * criterion(pred, y_b)
```

**Mixup 的理论**: 线性插值 → 模型被迫学到线性插值空间 → 减少对对抗样本的敏感度 (训练时加 $x_a + x_b$ 等于分类器学到方向无关, 是 Lipschitz 的隐式正则)。

## 4E. Label Smoothing

```python
class LabelSmoothingCrossEntropy(nn.Module):
    """
    Label Smoothing (Szegedy et al. 2016, Inception-v2)
    思想: 把硬标签 [0, 1, 0] 改成 [eps/K, 1-eps*(K-1)/K, eps/K], 防 over-confidence
    """
    def __init__(self, eps=0.1):
        super().__init__()
        self.eps = eps

    def forward(self, pred, target):
        n_class = pred.size(1)
        log_prob = F.log_softmax(pred, dim=1)
        # one-hot smoothed
        with torch.no_grad():
            true_dist = torch.zeros_like(log_prob)
            true_dist.fill_(self.eps / n_class)
            true_dist.scatter_(1, target.unsqueeze(1), 1 - self.eps * (n_class - 1) / n_class)
        return torch.mean(torch.sum(-true_dist * log_prob, dim=1))
```

**为什么有效**:
- 防止模型输出极接近 0/1 的 logits (over-confidence), 进而改善 calibration
- 等价于对 logits 加 $\ell_2$ 正则 (Müller et al. 2019 证明)
- 在 ImageNet 上 ImageNet-ResNet152 + label smoothing 0.1, top-1 +0.4%

**LLM 中的 label smoothing** ❌: decoder-only LM 通常不用, 因为:
- 验证 perplexity 不一定更好
- 模型对核心 token 的"高置信度"是 Next Token Prediction 的固有特性

## 4F. EMA (Exponential Moving Average)

```python
class EMA:
    """
    模型参数指数滑动平均 (Polyak averaging 的在线版)
    评估用 EMA 参数, 通常比 raw 参数高 0.2-0.5%
    """
    def __init__(self, model, decay=0.999):
        self.decay = decay
        self.shadow = {n: p.clone().detach() for n, p in model.named_parameters()}
        self.buffers = {n: b.clone().detach() for n, b in model.named_buffers()}

    def update(self, model):
        for n, p in model.named_parameters():
            self.shadow[n].mul_(self.decay).add_(p.data, alpha=1 - self.decay)
        for n, b in model.named_buffers():
            if b.dtype in (torch.float32, torch.float64):
                self.buffers[n].copy_(b)

    def apply_to(self, model):
        # 把 EMA 参数写入 model (用于 eval)
        self.original = {n: p.clone() for n, p in model.named_parameters()}
        for n, p in model.named_parameters():
            p.data.copy_(self.shadow[n])

    def restore(self, model):
        for n, p in model.named_parameters():
            p.data.copy_(self.original[n])
```

**SWA (Stochastic Weight Averaging, Izmailov et al. 2018)**: 类似 EMA, 但在 SGD 的后期每 $k$ 步平均一次, 找更宽的极小值。

**Lookahead Optimizer** (Zhang et al., 2019): 维护 slow weights, 每 $k$ 步把 fast weights 按 $\alpha$ 朝 slow 拉一步, 等价于"大胆探索, 稳保守积"。

## 4H. 分布式训练的梯度同步原语

### 4H.1 集合通信核心

```python
import torch.distributed as dist

# 1. AllReduce (求和 / 求平均)
dist.all_reduce(tensor, op=dist.ReduceOp.SUM)

# 2. Broadcast (一节点广播)
dist.broadcast(tensor, src=0)

# 3. AllGather (各节点 gather 所有)
gathered = [torch.zeros_like(tensor) for _ in range(world_size)]
dist.all_gather(gathered, tensor)

# 4. ReduceScatter (每个节点收到不同的子集)
dist.reduce_scatter(output, input_list, op=dist.ReduceOp.SUM)

# 5. AllToAll (专家并行)
dist.all_to_all(output, input)
```

### 4H.2 Ring AllReduce 原理

```text
N 节点:
    1. scatter-reduce: N-1 步, 每步 N-1 节点传 1 个 chunk
    2. allgather:      N-1 步, 每步传 1 个 chunk

每步通信量 = (N-1)/N * M ≈ M

相比 naive AllReduce (每节点广播到所有, 通信量 ≈ N*M),
Ring 把通信量从 O(N*M) 降到 O(M), 与 N 无关。
这就是 NVLink + InfiniBand 集群可扩展到 1000 卡的关键。
```

### 4H.3 Ring AllReduce 手写简化版

```python
def ring_allreduce_sum(tensor, world_size):
    """
    假设 world_size 节点 + tensor 大小可被 world_size 整除
    """
    chunk_size = tensor.numel() // world_size
    chunks = tensor.view(world_size, chunk_size).chunk(world_size, dim=0)

    # 阶段 1: scatter-reduce
    for step in range(world_size - 1):
        send_idx = (rank - step) % world_size
        recv_idx = (rank - step - 1) % world_size
        # 发送 chunks[send_idx], 接收累加到 chunks[recv_idx]
        ...

    # 阶段 2: allgather
    for step in range(world_size - 1):
        send_idx = (rank - step + 1) % world_size
```

## 4I. 检查点策略 (Checkpointing)

### 4I.1 同步检查点 (Naive)

```python
# 每 N 步保存, 同步等待所有卡, 然后写盘
if step % save_every == 0:
    dist.barrier()
    if rank == 0:
        torch.save({
            'model': model.state_dict(),
            'optimizer': optimizer.state_dict(),
            'scaler': scaler.state_dict(),
            'step': step,
        }, checkpoint_path)
```

**缺点**: 慢 (PyTorch save 序列化), 单点写盘; 如果训练到第 10000 步挂了, 全重训。

### 4I.2 异步检查点 (LLaMA 风格)

```python
import threading
save_queue = queue.Queue()

def save_worker():
    while True:
        item = save_queue.get()
        # 异步写盘 + 上传 OSS
        torch.save(item, ...)
        upload_to_oss(...)

threading.Thread(target=save_worker, daemon=True).start()

# 训练 loop
if step % save_every == 0:
    save_queue.put_nowait({'model': model.state_dict(), 'step': step})
```

### 4I.3 弹性恢复 (Elastic Checkpointing)

```python
# 保存: shard (ZeRO-3 类似, 把 sharded 参数各自保到不同文件)
# 恢复: 加载当前可见 rank 的 shard; 多卡加载多 shard 恢复
# 优点: 即使硬件故障导致卡数减少, 也能从断点续训
```

### 4I.4 PyTorch DCP (Distributed Checkpoint)

```python
# PyTorch 2.0+ 推荐, 取代 torch.save
from torch.distributed.checkpoint import save, load_state_dict

state_dict = {'model': model.state_dict(), 'optim': optimizer.state_dict()}
save(state_dict, checkpoint_id=checkpoint_path)
```

DCP 的核心创新: 写文件是 rank-parallel 的, 每 rank 写它负责的部分, 不再单点写盘; 加载可以灵活改变并行策略 (例如 64 卡保存, 32 卡恢复)。

## 4L. 现代训练: FlashAttention 视角

### 4L.1 标准 Attention 的 IO 瓶颈

标准实现 (Q,K,V 各 (N, d), 输出 (N,d)):

```python
S = Q @ K.T  # (N, N) — O(N²) 显存!
P = softmax(S, dim=-1)
O = P @ V  # (N, d)
```

序列长 32K 时, 单 attention 的 $S$ 矩阵 = $32K \times 32K$ = 1G float = 4GB, 一个 layer 就爆显存; context 196K 完全不可能。

### 4L.2 FlashAttention 的核心

IO-aware kernel:
- 块式把 Q 分 chunk, K,V 也分 chunk, 进 SRAM
- 用 online softmax (Milakov & Gimelshein 2018) 在 block 内维护 log-sum-exp
- 直接在 SRAM 中 attention + softmax, 不写回 HBM
- 显存 $O(N)$ 而非 $O(N^2)$, 速度 2-4×

### 4L.3 FlashAttention v3 的硬件特性

- 利用 H100 的 TMA (Tensor Memory Accelerator) async copy
- 利用 H100 的 4th-gen Tensor Core 的 FP8/BF16/FP16
- warp-specialization (producer/consumer pattern)

```python
from flash_attn import flash_attn_func
# 输入: (batch, seqlen, nheads, headdim)
# dtype: bf16 / fp16
out = flash_attn_func(q, k, v, causal=True)  # 内部自动用 FA2/FA3
```

### 4N.1 损失 spike 处理 (回退 step + 降 lr)

```text
现象: GPT-3 训练 loss 偶发 spike (几十亿步一次)
```

## 4O. 数据并行扩展效率

**Amdahl 定律的应用**:

$$
\text{Speedup} = \frac{1}{(1 - p) + p/N}
$$

其中 $p$ 是可并行比例, $N$ 是 worker 数。
- 即使 $p=0.99$, 1024 worker 上限 speedup = 91×; 4096 节点 → 96.6×, 硬极限
- 数据加载 / IO / 通信 都属于 $(1-p)$

**LLM 训练的 practical efficient**:
- 256 卡 H100 cluster, GPT-3 175B, MFU ≈ 47% (PaLM-540B 报告)
- 现代 Megatron-Core + FP8 可达 MFU > 60% (B200 上)
- 突破 Amdahl: 通过 **overlap** (计算和通信重叠) + **压缩通信** (FP8 grad)

## 4R. 自适应与对抗性训练

### 4R.1 Sharpness-Aware Minimization (SAM)

```python
class SAM:
    """
    Foret et al. 2021
    找最坏的近邻梯度方向, 用对抗 step 抬高 model sharpness, 再更新
    通常提 0.3-1.0% top-1, 但需要 2 倍前向+反向
    """
    def __init__(self, base_optimizer, rho=0.05):
        self.base_optimizer = base_optimizer
        self.rho = rho

    def first_step(self):
        # 1. 计算 grad e_norm = grad / ||grad||
        grad_norm = torch.norm(
            torch.stack([p.grad.norm(p=2) for p in self.base_optimizer.param_groups[0]['params']]), p=2
        )
        scale = self.rho / (grad_norm + 1e-12)

        # 2. 存 w + e_norm 作为临时参数
        self.e_w = [p.grad * scale for p in self.base_optimizer.param_groups[0]['params']]
        for p, e in zip(self.base_optimizer.param_groups[0]['params'], self.e_w):
            p.data.add_(e)  # 临时 grad ascent

    def second_step(self):
        # 3. 回到原 w, 用上一步的梯度正常 SGD
        for p, e in zip(self.base_optimizer.param_groups[0]['params'], self.e_w):
            p.data.sub_(e)
        self.base_optimizer.step()
        self.base_optimizer.zero_grad()
```

### 4R.2 对抗训练 (Adversarial Training)

```python
# FGSM / PGD 用于对抗鲁棒性
def pgd_attack(model, x, y, eps=8/255, alpha=2/255, steps=10):
    x_adv = x.clone().detach() + torch.empty_like(x).uniform_(-eps, eps)
    for _ in range(steps):
        x_adv.requires_grad_(True)
        loss = F.cross_entropy(model(x_adv), y)
        grad = torch.autograd.grad(loss, x_adv)[0]
        x_adv = x_adv.detach() + alpha * grad.sign()
        x_adv = (x + (x_adv - x).clamp(-eps, eps)).clamp(0, 1)
    return x_adv
```

```python
    按 GPT-3 paper 的 rough estimate:
      FLOPs per token ≈ 6 × N (前向2N, 反向4N)
```

## 附录 B: 训练代码模板 (端到端)

```python
import torch
import torch.nn as nn
from torch.cuda.amp import autocast
from torch.utils.data import DataLoader

def train(model, dataset, lr=3e-4, batch_size=128, max_steps=10000, accum=1):
    """最小可复现训练 loop, BF16 + AdamW + grad-clip"""
    device = "cuda"
    model = model.to(device)
    optim = torch.optim.AdamW(model.parameters(), lr=lr, weight_decay=0.1)
    loader = DataLoader(dataset, batch_size=batch_size, num_workers=4, pin_memory=True)

    model.train()
    step = 0
    while step < max_steps:
        for batch in loader:
            x, y = batch[0].to(device, non_blocking=True), batch[1].to(device, non_blocking=True)

            with autocast("cuda", dtype=torch.bfloat16):
                logits = model(x)
                loss = nn.functional.cross_entropy(
                    logits.view(-1, logits.size(-1)), y.view(-1)
                ) / accum

            loss.backward()

            if (step + 1) % accum == 0:
                torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
                optim.step()
                optim.zero_grad()

            step += 1
            if step % 100 == 0:
                print(f"step {step}: loss={loss.item()*accum:.4f}")
            if step >= max_steps:
                break
```

## 附录 D: Norm 系列详解 (深入展开)

### D.1 BatchNorm 完整理论

**Ioffe & Szegedy 2015** "Batch Normalization: Accelerating Deep Network Training by Reducing Internal Covariate Shift"。

**问题**: Internal Covariate Shift (ICS) — 训练时, 每层输入的分布在每次参数更新后都会变化, 导致下游层需要不断适应 → 学习率必须小 → 训练慢。

**解**: 对每个 mini-batch, 把每层的输入归一到 0 均值 1 方差:

$$
\hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}, \quad y_i = \gamma \hat{x}_i + \beta
$$

- $\mu_B, \sigma_B^2$ 是 batch 统计量
- $\gamma, \beta$ 是可学习参数 (允许网络学 "我不需要被归一")

**BN 的反向传播** (工程化关键):
- $\partial \mathcal{L}/\partial \gamma = \sum (\partial \mathcal{L}/\partial y_i) \cdot \hat{x}_i$
- $\partial \mathcal{L}/\partial \beta = \sum (\partial \mathcal{L}/\partial y_i)$
- $\partial \mathcal{L}/\partial x_i$ 需要对所有 $j$ 求依赖 (因为 $\mu_B, \sigma_B$ 是 batch 聚合) — 比一般层多 1 个 batch-size 的通信

**训练/推理不一致**:
- 训练用 batch stat $\mu_B, \sigma_B$ (有随机性)
- 推理用 running average $\mu_{EMA}, \sigma_{EMA}$ (固定)
- momentum = 0.1 决定 EMA 速度

```python
class BatchNorm1D:
    def __init__(self, n_features, eps=1e-5, momentum=0.1):
        self.gamma = np.ones(n_features)
        self.beta = np.zeros(n_features)
        self.running_mean = np.zeros(n_features)
        self.running_var = np.ones(n_features)
        self.eps = eps
        self.momentum = momentum
        self.training = True

    def forward(self, x):  # x: (B, F)
        if self.training:
            mu = x.mean(axis=0)
            var = x.var(axis=0)
            self.running_mean = self.momentum * mu + (1 - self.momentum) * self.running_mean
            self.running_var = self.momentum * var + (1 - self.momentum) * self.running_var
        else:
            mu = self.running_mean
            var = self.running_var

        x_norm = (x - mu) / np.sqrt(var + self.eps)
        return self.gamma * x_norm + self.beta
```

**BN 与 Distributed Training 的陷阱**: SyncBN (跨卡同步 batch stat)。否则小 batch + 多卡 = 实际 batch=batch_size/local_rank, BN 失效。

### D.2 LayerNorm 完整理论

**Ba, Kiros & Hinton 2016** "Layer Normalization"。

BN 的问题在 RNN: 序列内/间不同时刻的 batch stat 无法对齐。LN 改为**对每个样本单独**求 mean/var, 跨特征维度:

$$
\mu^{(i)} = \frac{1}{H}\sum_{j=1}^{H} x_{ij}, \quad
\sigma^{(i)2} = \frac{1}{H}\sum_{j=1}^{H}(x_{ij} - \mu^{(i)})^2
$$

$$
\hat{x}_{ij} = \frac{x_{ij} - \mu^{(i)}}{\sqrt{\sigma^{(i)2} + \epsilon}}, \quad
y_{ij} = \gamma_j \hat{x}_{ij} + \beta_j
$$

**关键差别**:
- BN: stat 跨 batch, 同一 channel 共享 → 受 batch size 影响
- LN: stat 跨 feature, 每个样本独立 → 不受 batch size 影响 (适合 batch=1, RL, 长序列)

**现代 LN 的输入 shape**:
- Transformer PreNorm 版: 形如 (B, T, D), 沿 D 归一化
- 视觉 ViT: 形如 (B, T, D), 沿 D 归一化
- RNN: 沿 hidden 维度归一化

### D.3 RMSNorm

**Zhang & Sennrich 2019** "Root Mean Square Layer Normalization"。

观察: LN 中减去均值的操作对训练**几乎没用**, 主要起作用的是缩放:

$$
\bar{a}_i = \frac{a_i}{\text{RMS}(a)} \cdot g_i, \quad \text{RMS}(a) = \sqrt{\frac{1}{n}\sum_i a_i^2}
$$

- 省去均值计算, 比 LN 快 10-30%
- LLaMA / Gemma / Mistral 默认使用

### D.4 GroupNorm

**Wu & He 2018** "Group Normalization".

介于 BN 和 LN 之间: 把 channel 分成 $G$ 组, 每组内做 BN:

```python
# input (B, C, H, W), 分 G 组, 每组 C/G channels
# 在 (C/G, H, W) 内求 mean/var
```

对小 batch (检测/分割) 比 LN 更准, 比 BN 更不依赖 batch size。

### D.5 BN / LN / GN 选择

| 维度 | BN | LN | GN |
|---|---|---|---|
| 适用 | CNN, 大 batch | Transformer | CNN, 小 batch |
| batch 依赖 | 强 | 无 | 弱 |
| 推理平均 | 是 | 否 | 否 |
| 训练噪声 | 有 | 几乎无 | 几乎无 |

## 附录 E: DistributedDataParallel (DDP) 原理解析

### E.1 DDP 的算法流程 (PyTorch)

```text
启动:
1. 初始化 process group (NCCL/Gloo)
2. 每个 rank 拥有完整 model replica
3. broadcast 初始参数 (rank 0 → all)
   或者各 rank 都从同一 ckpt 加载

每个 step:
1. 各 rank 加载不同 batch (DistributedSampler)
2. 各 rank 前向 + 反向, 得到 local gradients
3. DDP hook: 反向时, 每当一个 parameter 的 grad 计算完成,
   异步启动 AllReduce (梯度桶 batched)
4. 各 rank 同步得到 global gradient (= sum of all local grads)
5. 各 rank 独立 step (因为梯度同步, 所以 update 一致)

注: DDP 的 reduce 是 SUM 而非 AVG! 等价于 batch_size 翻 N 倍。
    配合学习率线性缩放规则 (Goyal 2017), lr ← 4 → 4*8 = 32 (8 卡)
```

### E.2 Bucket 机制

PyTorch DDP 反向时按 parameter bucket 合并通信:

- 把 parameter 按 size 反向排序
- 相邻 parameter 同桶, 默认 25MB / 桶
- 桶满后启动 AllReduce
- 通信与反向并行 (overlap)

### E.3 Gradient Bucketing 示例

```python
from torch.nn.parallel import DistributedDataParallel as DDP

model = Model().cuda(rank)
model = DDP(model, device_ids=[rank],
            find_unused_parameters=False,  # 全部用上
            gradient_as_bucket_view=True,   # 启用 bucket 优化
            bucket_cap_mb=25)
```

如果 model 里有 unused parameters (例如 conditional computation), 必须 `find_unused_parameters=True`, 否则会卡住; 但开启会损失效率。

### E.4 DistributedSampler

```python

```

## 附录 F: Activation Checkpointing (梯度重计算)

### F.1 原理

```python
# 前向时, 只保存输入 x, 不保存每一层的激活
# 反向时, 重新计算一次前向, 然后正常反向
# 显存: 存 O(sqrt(N)) 的激活 (而不是 N 层)
# 代价: 多 33% 计算 (前向重做 1 次, 反向原本就是 1 次)
```

### F.2 PyTorch 实现

```python
from torch.utils.checkpoint import checkpoint

class CheckpointedBlock(nn.Module):
    def __init__(self, block):
        super().__init__()
        self.block = block

    def forward(self, x):
        # use_reentrant=False 是 PyTorch 2.0+ 推荐
        return checkpoint(self.block, x, use_reentrant=False)
```

更激进: Megatron-LM 选择性 checkpoint, 只 check 注意力部分 (FFN 留下), 平衡重算和显存。

### F.3 FlashAttention 集成

```python
# torch 2.4+ 推荐用法
class TransformerBlock(nn.Module):
    def __init__(self, d_model, n_heads):
        self.attn = FlashAttention(d_model, n_heads)
        self.ffn = nn.Sequential(nn.Linear(d_model, 4*d_model), nn.GELU(), nn.Linear(4*d_model, d_model))
        self.norm1 = nn.RMSNorm(d_model)
        self.norm2 = nn.RMSNorm(d_model)

    def forward(self, x, **kwargs):
        # 不 ckpt: ffn 显存不高, ckpt 也会让 FlashAttention 重做 attention
        a = self.attn(self.norm1(x), **kwargs)
        x = x + a
        # ckpt ffn: 节省激活
        f = checkpoint(self.ffn, self.norm2(x), use_reentrant=False)
        x = x + f
        return x
```

## 附录 H: 全套现代训练 Stack PyTorch 代码 (compact)

```python
import torch
import torch.nn as nn
from torch.utils.data import DataLoader
from torch.cuda.amp import autocast
from torch.utils.checkpoint import checkpoint
from torch.distributed.fsdp import fully_shard
import bitsandbytes as bnb

def get_model():
    """小模型, 用于演示完整栈"""
    return nn.Sequential(
        nn.Embedding(50000, 4096),
        nn.Linear(4096, 4096),
        nn.GELU(),
        nn.LayerNorm(4096),
        nn.Linear(4096, 50000),
    )

def main():
    model = get_model().cuda()

    # 1. FSDP (单卡演示, 不起作用)
    #   for layer in model:
    #       fully_shard(layer)
    #   fully_shard(model)

    # 2. 8-bit optim (节省内存)
    optim = bnb.optim.AdamW8bit(model.parameters(), lr=3e-4, weight_decay=0.1)

    # 3. BF16 autocast (无 scaler)
    for step in range(100):
        x = torch.randint(0, 50000, (16, 1024), device='cuda')

        with autocast("cuda", dtype=torch.bfloat16):
            logits = model(x)
            loss = nn.functional.cross_entropy(
                logits.view(-1, 50000), x.view(-1).roll(-1)
            )

        # 4. Grad clip
        loss.backward()
        grad_norm = nn.utils.clip_grad_norm_(model.parameters(), 1.0)

        # 5. Skip on bad grad
        if grad_norm.isfinite() and grad_norm < 1e3:
            optim.step()
        optim.zero_grad()

        if step % 10 == 0:
            print(f"step {step}: loss={loss.item():.4f}, grad_norm={grad_norm:.2f}")

if __name__ == "__main__":
    main()
```
