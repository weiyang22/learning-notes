## 1. 数组的物理结构

### 1.1 严格定义

**数组 (Array)** = 同类型元素的**连续内存**序列. 通过**下标** (index) 在 $O(1)$ 时间内随机访问任意元素.

```text
内存布局示意 (每个格子 4 字节):
地址:   0x100  0x104  0x108  0x10C  0x110  0x114
元素:   nums[0] nums[1] nums[2] nums[3] nums[4] nums[5]
         10      20      30      40      50      60

nums[i] 的地址 = base_address + i * element_size
```

### 1.2 关键特性

| 操作 | 时间复杂度 | 原因 |
|---|---|---|
| 随机访问 `nums[i]` | $O(1)$ | 地址计算公式 |
| 按值查找 `nums.index(x)` | $O(n)$ | 必须遍历 |
| 末尾追加 `nums.append(x)` | 摊还 $O(1)$ | 动态扩容 |
| 头部插入 `nums.insert(0, x)` | $O(n)$ | 所有元素后移 |
| 中间插入/删除 | $O(n)$ | 后续元素移动 |

### 1.3 缓存友好性 (Cache Locality)

数组是**连续内存**, CPU 加载一个元素时, 会把相邻的元素也加载到缓存行 (cache line, 通常 64 字节). 顺序遍历数组时, **缓存命中率高**.

**对比**: 链表的节点分散在内存各处, 每次访问都是缓存未命中.

**LeetCode 启示**: 在 Python 中, 数组遍历比链表遍历快 5-10 倍, 不只是常数差异.

### 1.4 静态数组 vs 动态数组

| 类型 | 容量固定? | 扩容机制 | 代表 |
|---|---|---|---|
| 静态数组 | 固定 | 无 | C 数组, Java 原始数组 |
| 动态数组 | 可变 | 容量不够时扩容 + 复制 | C++ vector, Python list, Java ArrayList |

**动态数组扩容策略**:
- 几何级数: 容量翻倍 → 摊还 $O(1)$ 插入
- 线性: 容量 +k → 摊还 $O(k)$
- Python 实际策略: `capacity = capacity + (capacity >> 3) + 3 if capacity < 9 else capacity + (capacity >> 1)`, 即 1.5 倍左右

## 2. Python list 内部实现

### 2.1 CPython list 结构

```c
// CPython listobject.h
typedef struct {
    PyObject_VAR_HEAD              // ob_refcnt, ob_type, ob_size
    PyObject **ob_item;            // 指向元素指针数组
    Py_ssize_t allocated;          // 已分配容量
} PyListObject;
```

关键点: list 存的是**指针**, 不是元素本身. 这意味着:
- `list[0] = 1; list[0] = "abc"` 都可以, 因为指针类型相同
- 但每个元素本身还是独立的对象, 有自己的内存

### 2.2 Python list 操作的真实复杂度

```python
nums = []
nums.append(1)        # 末尾追加, 摊还 O(1)
nums.insert(0, 0)     # 头部插入, O(n)
nums.pop()            # 末尾弹出, O(1)
nums.pop(0)           # 头部弹出, O(n)
nums[0] = 99          # 按索引修改, O(1)
nums.index(1)         # 查找, O(n)
nums.extend([1,2,3])  # 批量追加, 摊还 O(k)
nums.reverse()        # 原地反转, O(n)
nums.sort()           # 原地排序, O(n log n), Timsort
nums.copy()           # 浅拷贝, O(n)
nums.clear()          # 清空, O(n)
nums.remove(1)        # 删除第一个 1, O(n)
nums.count(1)         # 计数, O(n)
1 in nums             # 包含, O(n)
```

### 2.3 list 的隐藏开销

```python
import sys

print(sys.getsizeof([1]))           # 64 字节 (指针数组)
print(sys.getsizeof([1, 2, 3]))     # 88 字节 (3 个指针)

```

每个指针 8 字节, list 本身还有约 56 字节开销.

### 2.4 list vs tuple vs array

| 类型 | 可变? | 用途 |
|---|---|---|
| `list` | ✅ | 通用, 95% 场景 |
| `tuple` | ❌ | 不可变, hashable, 函数返回值 |
| `array.array` | ✅ | C 风格紧凑数组, 省内存 |
| `numpy.ndarray` | ✅ | 数值计算, 向量化 |
| `collections.deque` | ✅ | 双端队列, O(1) 头尾操作 |

```python

import numpy as np

dq.appendleft(1)              # O(1)
dq.popleft()                  # O(1)
```

## 3. 数组核心操作模板

### 3.1 基本操作

```python
from typing import List

# 反转数组(原地)
def reverse(nums: List[int]) -> None:
    left, right = 0, len(nums) - 1
    while left < right:
        nums[left], nums[right] = nums[right], nums[left]
        left += 1
        right -= 1

# 找最大/最小
max_val = max(nums)       # O(n), Python C 实现, 快
min_val = min(nums)       # O(n)

# 找最大/最小索引
max_idx = nums.index(max(nums))   # 两次 O(n)
# 单次扫描:
max_idx, max_val = max(enumerate(nums), key=lambda x: x[1])  # 一次 O(n)

# 数组去重(保留顺序)
def deduplicate(nums: List[int]) -> List[int]:
    seen = set()
    res = []
    for x in nums:
        if x not in seen:
            seen.add(x)
            res.append(x)
    return res

# 数组去重(不保留顺序,更快)
def deduplicate_fast(nums: List[int]) -> List[int]:
    return list(set(nums))

# 数组分块
def chunk(arr: List, size: int) -> List[List]:
    return [arr[i:i+size] for i in range(0, len(arr), size)]

# 数组平铺(2D → 1D)
flat = [x for row in matrix for x in row]
# 或
flat = sum(matrix, [])         # 注意 sum 起点, 对 int 列表 OK
# 或
flat = list(itertools.chain.from_iterable(matrix))

# 数组旋转 k 位
def rotate(nums: List[int], k: int) -> None:
    """三次反转, O(n) 时间, O(1) 空间"""
    n = len(nums)
    k %= n
    nums[:n-k] = reversed(nums[:n-k])
    nums[n-k:] = reversed(nums[n-k:])
    nums[:] = reversed(nums)
```

### 3.2 高级操作

```python
# 数组压缩(连续区间)
def compress(nums: List[int]) -> List[List[int]]:
    """[1,2,3,5,7,8] → [[1,3], [5,5], [7,8]]"""
    if not nums: return []
    res = []
    start = end = nums[0]
    for x in nums[1:]:
        if x == end + 1:
            end = x
        else:
            res.append([start, end])
            start = end = x
    res.append([start, end])
    return res

# 数组填充
arr = [0] * 10                    # 全 0
arr = [[0] * n for _ in range(m)]  # 二维, 正确(每行独立)
# ❌ 错: arr = [[0] * n] * m      # 共享同一行!

# 数组去重 + 排序(常见前置)
def dedup_sorted(nums: List[int]) -> List[int]:
    return sorted(set(nums))

# 数组最大值索引(用于贪心)
def argmax(nums: List[int]) -> int:
    return max(range(len(nums)), key=lambda i: nums[i])

# 数组累积
from itertools import accumulate
prefix = list(accumulate(nums, initial=0))  # 前缀和
# 等价于 [0, a, a+b, a+b+c, ...]
```

## 4. 一维前缀和 (深度)

### 4.1 定义

**前缀和 (Prefix Sum)**: 设 $S_i = \sum_{j=0}^{i-1} a_j$, 即前 $i$ 个元素之和. 约定 $S_0 = 0$.

```text
a:    a[0] a[1] a[2] a[3] a[4]
      ↓    ↓    ↓    ↓    ↓
S:   [0,   a0,  a0+a1, a0+a1+a2, ...]
```

数组下标约定: prefix 多 1 位, prefix[i] = a[0] + a[1] + ... + a[i-1]

### 4.2 区间和公式

子数组 $a[l..r]$ 的和:
$$\sum_{j=l}^{r} a_j = S_{r+1} - S_l$$

因为 $S_{r+1} = a_0 + \cdots + a_l + \cdots + a_r$, $S_l = a_0 + \cdots + a_{l-1}$, 相减就是 $a_l + \cdots + a_r$.

### 4.3 构造算法

```python
def build_prefix(nums: List[int]) -> List[int]:
    """构造前缀和数组"""
    n = len(nums)
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i+1] = prefix[i] + nums[i]
    return prefix

# 复杂度: O(n) 时间, O(n) 额外空间
```

### 4.4 查询算法

```python
def range_sum(prefix: List[int], l: int, r: int) -> int:
    """查询 nums[l..r] 的和(包含两端)"""
    return prefix[r+1] - prefix[l]

# 复杂度: O(1) 时间, O(1) 空间
```

### 4.5 复杂度严格推导

构造: 1 次循环, n 次加法, $O(n)$ 时间, $O(n)$ 空间(额外数组).
查询: 2 次减法, $O(1)$ 时间.

**对比**: 不预处理, 每次查询 $O(n)$ 求和. n 次查询时:
- 无前缀和: $O(n \cdot q)$ (q 查询次数)
- 有前缀和: $O(n + q)$ ← 当 $q \gg n$ 时优势巨大

### 4.6 应用场景

| 场景 | 优势 |
|---|---|
| 静态数组多次区间和查询 | $O(n + q)$ vs $O(nq)$ |
| 子数组和等于 K | $O(n)$ 用哈希表 |
| 差分数组配套 | 区间更新 |
| 二维矩阵区域和 | 见下文 |

### 4.7 工业级变种: 加权前缀和

```python
# 加权前缀和: 每个元素有权重
def weighted_prefix(nums: List[float], weights: List[float]) -> List[float]:
    """S_i = w_0*a_0 + w_1*a_1 + ... + w_{i-1}*a_{i-1}"""
    n = len(nums)
    prefix = [0.0] * (n + 1)
    for i in range(n):
        prefix[i+1] = prefix[i] + weights[i] * nums[i]
    return prefix
```

应用: 加权平均, 指数移动平均 (EMA).

### 4.8 例题: LeetCode 560 - 和为 K 的子数组 (Medium)

**题目**: 给定整数数组 `nums` 和 `k`, 统计连续子数组和等于 `k` 的个数.

**解法**: 前缀和 + 哈希

```python
def subarraySum(nums: List[int], k: int) -> int:
    """
    S_r - S_l = k ⟺ S_l = S_r - k
    用哈希存 S_l 出现次数
    """
    from collections import defaultdict
    cnt = defaultdict(int)
    cnt[0] = 1           # 空前缀, 出现 1 次

    cur = 0              # 当前前缀和
    res = 0
    for x in nums:
        cur += x
        if cur - k in cnt:
            res += cnt[cur - k]
        cnt[cur] += 1

    return res
```

**复杂度**: $O(n)$ 时间, $O(n)$ 空间.

**关键洞察**: "和为 K" 转换为 "前缀和差为 K".

### 4.9 例题: LeetCode 238 - 除自身以外数组的乘积 (Medium)

**题目**: 给数组 `nums`, 返回 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积. 不能用除法, $O(n)$ 时间.

**解法**: 前缀积 + 后缀积

```python
def productExceptSelf(nums: List[int]) -> List[int]:
    n = len(nums)
    left = [1] * n      # left[i] = nums[0] * ... * nums[i-1]
    right = [1] * n     # right[i] = nums[i+1] * ... * nums[n-1]

    for i in range(1, n):
        left[i] = left[i-1] * nums[i-1]
    for i in range(n - 2, -1, -1):
        right[i] = right[i+1] * nums[i+1]

    return [left[i] * right[i] for i in range(n)]

# 空间优化: O(1)
def productExceptSelf(nums: List[int]) -> List[int]:
    n = len(nums)
    res = [1] * n

    # 第一遍: left 累积到 res
    for i in range(1, n):
        res[i] = res[i-1] * nums[i-1]

    # 第二遍: 用 right 累积乘到 res
    right = 1
    for i in range(n - 1, -1, -1):
        res[i] *= right
        right *= nums[i]

    return res
```

**复杂度**: $O(n)$ 时间, $O(1)$ 额外空间.

## 5. 二维前缀和 (深度)

### 5.1 定义

二维前缀和 $S[i][j]$ = 子矩阵 `matrix[0..i-1][0..j-1]` 的元素和.

```text
          j-1
   ┌──────┐
   │      │
i-1┤   S[i][j]
   │      │
   └──────┘
```

### 5.2 递推公式

$$S[i][j] = \text{matrix}[i-1][j-1] + S[i-1][j] + S[i][j-1] - S[i-1][j-1]$$

解释:
- 加上当前元素 `matrix[i-1][j-1]`
- 加上左边矩阵 `S[i-1][j]`(高 i-1)
- 加上上边矩阵 `S[i][j-1]`(宽 j-1)
- 减去左上角重复部分 `S[i-1][j-1]`

### 5.3 构造算法

```python
def build_2d_prefix(matrix: List[List[int]]) -> List[List[int]]:
    if not matrix: return []
    m, n = len(matrix), len(matrix[0])
    prefix = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m):
        for j in range(n):
            prefix[i+1][j+1] = (
                matrix[i][j]
                + prefix[i][j+1]
                + prefix[i+1][j]
                - prefix[i][j]
            )
    return prefix
```

**复杂度**: $O(mn)$ 时间, $O(mn)$ 空间.

### 5.4 区域和查询

子矩阵 `(r1,c1)` 到 `(r2,c2)` 的和:

$$\text{sum} = S[r_2+1][c_2+1] - S[r_1][c_2+1] - S[r_2+1][c_1] + S[r_1][c_1]$$

```text
       c1     c2
   r1 ┌──────┐
      │      │
   r2 │      │
      └──────┘
```

### 5.5 完整模板

```python
class NumMatrix:
    """LeetCode 304 二维区域和检索 - 不可变"""

    def __init__(self, matrix: List[List[int]]):
        if not matrix:
            self.prefix = []
            return
        m, n = len(matrix), len(matrix[0])
        self.prefix = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(m):
            for j in range(n):
                self.prefix[i+1][j+1] = (
                    matrix[i][j]
                    + self.prefix[i][j+1]
                    + self.prefix[i+1][j]
                    - self.prefix[i][j]
                )

    def sumRegion(self, r1: int, c1: int, r2: int, c2: int) -> int:
        return (
            self.prefix[r2+1][c2+1]
            - self.prefix[r1][c2+1]
            - self.prefix[r2+1][c1]
            + self.prefix[r1][c1]
        )
```

### 5.6 复杂度分析

- 构造: $O(mn)$ 时间
- 查询: $O(1)$ 时间
- 空间: $O(mn)$

对比无前缀和时, 每次查询需要 $O((r_2-r_1+1)(c_2-c_1+1))$ 求和.

### 5.7 例题: LeetCode 661 - 图片平滑器 (Easy)

**题目**: 图像平滑器, 周围 9 个格子的均值(包括自己).

```python
def imageSmoother(M: List[List[int]]) -> List[List[int]]:
    if not M: return []
    m, n = len(M), len(M[0])
    res = [[0] * n for _ in range(m)]
    for i in range(m):
        for j in range(n):
            s, cnt = 0, 0
            for di in (-1, 0, 1):
                for dj in (-1, 0, 1):
                    ni, nj = i + di, j + dj
                    if 0 <= ni < m and 0 <= nj < n:
                        s += M[ni][nj]
                        cnt += 1
            res[i][j] = s // cnt
    return res
```

**复杂度**: $O(mn \cdot 9) = O(mn)$ 时间.

### 5.8 进阶: 三维前缀和

三维前缀和 $S[i][j][k]$ = 子立方体 `(0,0,0)` 到 `(i-1,j-1,k-1)` 的元素和.

递推:
$$S[i][j][k] = a_{ijk} + S[i-1,j,k] + S[i,j-1,k] + S[i,j,k-1] - S[i-1,j-1,k] - S[i-1,j,k-1] - S[i,j-1,k-1] + S[i-1,j-1,k-1]$$

查询: 子立方体 `(x1,y1,z1)` 到 `(x2,y2,z2)` 用容斥原理.

应用: 3D 图像处理, 时间空间数据 (经度-纬度-高度).

## 6. 差分数组 (深度)

### 6.1 动机

**问题**: 对数组的**区间** `[l, r]` 加 `val`, 有很多次操作, 最后输出最终数组.

**暴力**: 每次操作 $O(n)$, 总 $O(nq)$ — 太慢.

**差分数组**: 把"区间操作"转化为"端点操作", 每次 $O(1)$, 总 $O(n + q)$.

### 6.2 定义

**差分数组**: $D[i] = a[i] - a[i-1]$, 即原数组的相邻元素差.

约定 $D[0] = a[0]$.

**核心性质**: 对 $a$ 在区间 `[l, r]` 加 `val`, 等价于:
- `D[l] += val`
- `D[r+1] -= val`(若 $r+1 < n$)

最后还原: $a[i] = a[i-1] + D[i]$ (累加).

### 6.3 为什么?

设操作前 $a_l, a_{l+1}, \ldots, a_r$.
操作后 $a_l + v, a_{l+1} + v, \ldots, a_r + v$.

差分 $D_l$ 操作后 = $(a_l + v) - a_{l-1}$ = $D_l + v$. (正确)
差分 $D_{r+1}$ 操作后 = $a_{r+1} - (a_r + v)$ = $D_{r+1} - v$. (正确)
其他 $D_i (l < i \le r)$ 不变, 因为分子分母都加了 $v$. (正确)

### 6.4 完整模板

```python
class DifferenceArray:
    """差分数组: 支持区间加, 最后输出"""

    def __init__(self, nums: List[int]):
        n = len(nums)
        self.diff = [0] * (n + 1)
        self.diff[0] = nums[0]
        for i in range(1, n):
            self.diff[i] = nums[i] - nums[i-1]

    def range_add(self, l: int, r: int, val: int) -> None:
        """区间 [l, r] 加 val"""
        self.diff[l] += val
        self.diff[r+1] -= val

    def result(self) -> List[int]:
        """还原原数组"""
        n = len(self.diff) - 1
        res = [0] * n
        res[0] = self.diff[0]
        for i in range(1, n):
            res[i] = res[i-1] + self.diff[i]
        return res
```

### 6.5 复杂度

- 构造: $O(n)$
- 每次区间操作: $O(1)$
- 还原: $O(n)$
- 总 $q$ 次操作: $O(n + q)$

### 6.6 应用: 拼车 (LeetCode 1094)

**题目**: 假设你是一位顺风车司机, 车上最初有 `capacity` 个空座位. 给定行程 `trips[i] = [numPassengers, from, to]`, 乘客上下车点在 `from` 和 `to`. 判断是否能完成所有行程(任何时刻不超过 `capacity`).

**解法**: 差分数组, 每个行程看作区间 `[from, to-1]` 加 `numPassengers`.

```python
def carPooling(trips: List[List[int]], capacity: int) -> bool:
    # 差分
    diff = [0] * 1001
    for num, frm, to in trips:
        diff[frm] += num
        diff[to] -= num   # 在 to 处下车

    # 还原 + 检查
    cur = 0
    for x in diff:
        cur += x
        if cur > capacity:
            return False
    return True
```

**复杂度**: $O(n + 1000)$ 时间.

### 6.7 二维差分

类似二维前缀和, 二维差分可以 $O(1)$ 完成"子矩阵加 val"操作.

```python
class Diff2D:
    def __init__(self, m: int, n: int):
        self.m, self.n = m, n
        self.diff = [[0] * (n + 2) for _ in range(m + 2)]

    def rect_add(self, r1: int, c1: int, r2: int, c2: int, val: int):
        """子矩阵 (r1,c1)-(r2,c2) 加 val"""
        self.diff[r1][c1] += val
        self.diff[r1][c2+1] -= val
        self.diff[r2+1][c1] -= val
        self.diff[r2+1][c2+1] += val

    def result(self) -> List[List[int]]:
        # 二维前缀和还原
        for i in range(self.m):
            for j in range(self.n):
                self.diff[i+1][j+1] += (
                    self.diff[i][j+1]
                    + self.diff[i+1][j]
                    - self.diff[i][j]
                )
        return [row[:self.n] for row in self.diff[:self.m]]
```

应用: 工业图像处理 (区域曝光调整).

### 6.8 离散化差分

如果坐标范围很大但稀疏 (如 `[0, 10^9]`), 但操作数小 (如 $10^5$), 用离散化:

```python
def discretized_diff(ops: List[Tuple[int, int, int]], coords: List[int]) -> List[int]:
    """ops: [(l, r, val)], coords: 所有出现过的坐标"""
    sorted_coords = sorted(set(coords))
    rank = {c: i for i, c in enumerate(sorted_coords)}

    diff = [0] * (len(sorted_coords) + 1)
    for l, r, val in ops:
        diff[rank[l]] += val
        diff[rank[r] + 1] -= val

    # 还原
    res = [0] * len(sorted_coords)
    cur = 0
    for i, x in enumerate(sorted_coords):
        cur += diff[i]
        res[i] = cur

    # 还原到原坐标
    return {c: v for c, v in zip(sorted_coords, res)}
```

### 7.2 算法

```python
def discretize(arr):
    """原数组 → 离散化(从 0 开始)"""
    sorted_unique = sorted(set(arr))
    rank = {v: i for i, v in enumerate(sorted_unique)}
    return [rank[x] for x in arr]
```

### 7.4 例题: LeetCode 493 - 翻转对 (Hard)

**题目**: 给数组 `nums`, 统计满足 `i < j` 且 `nums[i] > 2 * nums[j]` 的对数.

**暴力**: $O(n^2)$.
**离散化 + BIT**: $O(n \log n)$.

```python
from typing import List

class Fenwick:
    """树状数组(BIT), 支持单点更新 + 前缀和查询"""
    def __init__(self, n):
        self.tree = [0] * (n + 1)

    def update(self, i, delta):
        i += 1
        while i < len(self.tree):
            self.tree[i] += delta
            i += i & -i

    def query(self, i):
        """前 i 个元素的和(包含 i)"""
        i += 1
        s = 0
        while i > 0:
            s += self.tree[i]
            i -= i & -i
        return s

def reversePairs(nums: List[int]) -> int:
    # 离散化: 所有 nums[i] 和 2*nums[i] 都参与
    all_vals = nums + [2*x for x in nums]
    sorted_vals = sorted(set(all_vals))
    rank = {v: i for i, v in enumerate(sorted_vals)}

    bit = Fenwick(len(sorted_vals))
    res = 0
    # 从右向左遍历
    for x in reversed(nums):
        # 统计右边 < x/2 的个数
        threshold = x / 2  # 注意 2x 可能奇偶
        # 找 < threshold 的最大 rank
        idx = bisect.bisect_left(sorted_vals, threshold)
        if idx > 0:
            res += bit.query(idx - 1)
        # 把 x 加入
        bit.update(rank[x], 1)
    return res
```

**复杂度**: $O(n \log n)$ 时间, $O(n)$ 空间.

**5 种解法对比**:

|---|---|---|

| **哈希表** ★ | $O(n)$ | $O(n)$ |

```python
def twoSum(nums: List[int], target: int) -> List[int]:
    seen = {}                  # 值 → 索引
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i
    return []
```

### 8.2 LeetCode 53 - 最大子数组和 (Easy, DP/前缀和)

**题目**: 找连续子数组使其和最大.

**示例**:
```text
输入: [-2,1,-3,4,-1,2,1,-5,4]
输出: 6 (子数组 [4,-1,2,1])
```

**3 种解法对比**:

| 解法 | 时间 | 空间 |
|---|---|---|
| 暴力枚举所有子数组 | $O(n^3)$ 或 $O(n^2)$ | $O(1)$ |
| **Kadane DP** ★ | $O(n)$ | $O(1)$ |
| 前缀和 + 最小前缀 | $O(n)$ | $O(1)$ |
| 分治 | $O(n \log n)$ | $O(\log n)$ |

**Kadane 算法**:

```python
def maxSubArray(nums: List[int]) -> int:
    """Kadane: dp[i] = 以 nums[i] 结尾的最大子数组和"""
    cur = max_val = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)
        max_val = max(max_val, cur)
    return max_val
```

**状态转移分析**:
- 对每个元素, 要么"加入前面的子数组"(cur + x), 要么"作为新子数组的起点"(x)
- 取最大值

**为什么最优?**: 数学归纳. 设 `dp[i-1]` 是以 `nums[i-1]` 结尾的最大子数组和, 那么:
- 以 `nums[i]` 结尾的最大和 = `max(dp[i-1] + nums[i], nums[i])`
- 因为必须包含 `nums[i]`, 要么接前面的, 要么重新开始

**前缀和法**:

```python
def maxSubArray_prefix(nums: List[int]) -> int:
    """用前缀和找最大差值"""
    min_prefix = 0     # 0 个元素的前缀和
    cur = 0
    max_val = float('-inf')
    for x in nums:
        cur += x
        max_val = max(max_val, cur - min_prefix)
        min_prefix = min(min_prefix, cur)
    return max_val
```

**分治法**:

```python
def maxSubArray_divide(nums: List[int], lo: int = 0, hi: int = None) -> int:
    """分治: max(左, 右, 跨中点)"""
    if hi is None: hi = len(nums) - 1
    if lo == hi: return nums[lo]
    mid = (lo + hi) // 2
    left = maxSubArray_divide(nums, lo, mid)
    right = maxSubArray_divide(nums, mid + 1, hi)

    # 跨中点
    left_max = nums[mid]
    s = 0
    for i in range(mid, lo - 1, -1):
        s += nums[i]
        left_max = max(left_max, s)

    right_max = nums[mid + 1]
    s = 0
    for i in range(mid + 1, hi + 1):
        s += nums[i]
        right_max = max(right_max, s)

    return max(left, right, left_max + right_max)
```

**复杂度**: $T(n) = 2T(n/2) + O(n) \to O(n \log n)$, 空间 $O(\log n)$.

**边界处理**:
- 全负数: 必须选最大的负数
- 全 0: 返回 0

### 8.7 LeetCode 498 - 对角线遍历 (Medium)

```python
def findDiagonalOrder(mat: List[List[int]]) -> List[int]:
    if not mat: return []
    m, n = len(mat), len(mat[0])
    res = []
    for d in range(m + n - 1):
        if d % 2 == 0:
            # 偶数对角线: 向上
            i = min(d, m - 1)
            j = d - i
            while i >= 0 and j < n:
                res.append(mat[i][j])
                i -= 1
                j += 1
        else:
            # 奇数对角线: 向下
            j = min(d, n - 1)
            i = d - j
            while i < m and j >= 0:
                res.append(mat[i][j])
                i += 1
                j -= 1
    return res
```

```python
            res.append(matrix[top][j])

        # 右列
        for i in range(top, bottom + 1):

        if top <= bottom:
            for j in range(right, left - 1, -1):
                res.append(matrix[bottom][j])
            bottom -= 1

        if left <= right:
            for i in range(bottom, top - 1, -1):
                res.append(matrix[i][left])
            left += 1
```

### 9.5 莫队算法 (Mo's Algorithm)

处理"区间查询, 不同区间有大量重叠"的离线算法.

```python
# 莫队模板
def mo_solve(arr, queries):
    """queries: [(l, r)]"""
    # 1. 排序
    block_size = int(len(arr) ** 0.5) + 1
    queries_with_idx = sorted(
        enumerate(queries),
        key=lambda x: (x[1][0] // block_size, x[1][1] if (x[1][0] // block_size) % 2 == 0 else -x[1][1])
    )

    # 2. 维护滑动窗口 [cur_l, cur_r] 的答案
    cur_l, cur_r = 0, -1
    cur_ans = 0
    answers = [0] * len(queries)

    for idx, (l, r) in queries_with_idx:
        while cur_l > l:
            cur_l -= 1
            add(arr[cur_l])
        while cur_r < r:
            cur_r += 1
            add(arr[cur_r])
        while cur_l < l:
            remove(arr[cur_l])
            cur_l += 1
        while cur_r > r:
            remove(arr[cur_r])
            cur_r -= 1
        answers[idx] = cur_ans

    return answers
```

应用: 区间不同元素个数, 区间第 k 大.

### 12.5 高级数组处理技巧

```python
# 1. 双指针原地删除
def remove_duplicates_inplace(nums):
    """已排序数组, 原地去重, 返回新长度"""
    if not nums: return 0
    slow = 0
    for fast in range(1, len(nums)):
        if nums[fast] != nums[slow]:
            slow += 1
            nums[slow] = nums[fast]
    return slow + 1

# 2. 一次遍历找最值
def find_min_max(arr):
    """一次遍历同时找最小最大(3n/2 - 2 比较, 比 2n 比较少)"""
    if not arr: return None
    if len(arr) == 1: return arr[0], arr[0]

    if arr[0] > arr[1]:
        max_val, min_val = arr[0], arr[1]
    else:
        max_val, min_val = arr[1], arr[0]

    for i in range(2, len(arr) - 1, 2):
        if arr[i] > arr[i+1]:
            max_val = max(max_val, arr[i])
            min_val = min(min_val, arr[i+1])
        else:
            max_val = max(max_val, arr[i+1])
            min_val = min(min_val, arr[i])

    if len(arr) % 2 == 1:
        max_val = max(max_val, arr[-1])
        min_val = min(min_val, arr[-1])

    return min_val, max_val

# 3. 滑动窗口最大值(用 deque)
from collections import deque
def sliding_window_max(nums, k):
    """返回每个 k 长度窗口的最大值"""
    if not nums: return []
    dq = deque()  # 存索引, 单调递减
    res = []

    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] < x:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            res.append(nums[dq[0]])

    return res

# 4. 多数元素(Boyer-Moore)
def majority_element(nums):
    candidate = None
    count = 0
    for x in nums:
        if count == 0:
            candidate = x
            count = 1
        elif x == candidate:
            count += 1
        else:
            count -= 1
    return candidate
```

### 15.2 缓存系统

LRU 缓存(LeetCode 146): 双向链表 + 哈希表.

```python
class Node:
    def __init__(self, key, val):
        self.key = key
        self.val = val
        self.prev = None
        self.next = None

class LRUCache:
    def __init__(self, capacity):
        self.cap = capacity
        self.cache = {}
        self.head = Node(0, 0)  # dummy
        self.tail = Node(0, 0)
        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev

    def _add_to_head(self, node):
        node.next = self.head.next
        node.prev = self.head
        self.head.next.prev = node
        self.head.next = node

    def get(self, key):
        if key in self.cache:
            node = self.cache[key]
            self._remove(node)
            self._add_to_head(node)
            return node.val
        return -1

    def put(self, key, value):
        if key in self.cache:
            self._remove(self.cache[key])
        node = Node(key, value)
        self.cache[key] = node
        self._add_to_head(node)
        if len(self.cache) > self.cap:
            lru = self.tail.prev
            self._remove(lru)
            del self.cache[lru.key]
```

## 17. 附录: 高频面试问题与标准答案

### Q1: Python list 和 C++ vector 的区别?

| 维度 | Python list | C++ vector |
|---|---|---|
| 元素类型 | 任意类型 | 单一类型 |
| 实现 | 指针数组 | 连续内存 |
| 大小 | 动态 | 动态 |
| 性能 | 慢 (解释) | 快 (编译) |

### Q2: 为什么数组按下标访问是 O(1)?

因为**地址计算公式**: `address = base + i * size`, 只需一次加法和一次乘法(都是 O(1)).

### Q3: 数组和链表的本质区别?

数组是**连续内存**, 链表是**分散内存** (通过指针链接).

数组优势: 缓存友好, 随机访问快.
链表优势: 插入删除快, 不需要预分配.

### Q4: 什么是动态数组? 为什么 append 平均 O(1)?

动态数组在容量不足时**翻倍扩容**, 单次插入最坏 $O(n)$ 但摊还 $O(1)$.

### Q5: Python list 的 in 操作时间复杂度?

$O(n)$. 因为是线性查找.

要 $O(1)$ 用 set: `if x in some_set`.

### Q6: 前缀和为什么能加速?

把"区间和查询"从 $O(n)$ 降到 $O(1)$, 代价是 $O(n)$ 预处理.

多次查询($q$ 次):
- 无前缀和: $O(nq)$
- 有前缀和: $O(n + q)$

### Q7: 差分数组为什么能加速区间更新?

把"区间更新"从 $O(n)$ 降到 $O(1)$ 端点修改. 多次更新后单次还原, 总 $O(n + q)$.

### Q8: 二维前缀和的推导?

$S[i+1][j+1] = M[i][j] + S[i][j+1] + S[i+1][j] - S[i][j]$ (容斥).

区域和查询 = 容斥 4 项.

### Q9: 离散化的本质是什么?

把**大值域**映射到**小值域**(从原值到 rank), 同时保留**相对大小**.

例: $[10^9, 5, 10^9, 7] \to [2, 0, 2, 1]$.

### Q10: 矩阵旋转 90° 的最少操作?

**两步**: 转置 + 水平翻转. 时间 $O(n^2)$, 空间 $O(1)$.

**3. 数学形式化(简洁版)**

虽然我们强调思维框架视角,但数学形式化提供了共同语言。机器学习的核心问题可以表达为:给定输入样本,学习一个映射函数,使得函数输出与真实目标的差距最小化。这个抽象捕捉了分类、回归、生成等大多数任务的本质。

进一步,优化目标通常加入正则化项来控制模型复杂度,平衡经验风险与模型容量。统计学习理论给出了泛化误差的上界,告诉我们模型越复杂并不一定越好——**奥卡姆剃刀**在数学上有严格的形式化。

**4. 信息论视角**

信息论为"数组基础" 提供了统一的视角:**学习的本质是从数据中提取与目标相关的信息**。

KL 散度衡量两个概率分布的距离,在交叉熵损失、变分推断、策略梯度等场景无处不在。需要注意它是**不对称**的——不同方向有不同的解释。

信息瓶颈原则指出,我们应该寻找既紧凑又预测性强的表示。这一思想影响了大量表示学习方法的设计,包括对比学习、自监督学习、多模态预训练等。

**7. 实践建议**

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "数组基础" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
