## 1. 二分查找的本质

### 1.1 适用条件

二分要求问题具有**单调性**:

- **有序数组** 中查找 → 单调性天然存在
- **答案空间** 上单调 → 二分答案(关键)

### 1.2 时间复杂度

每次排除一半 → $T(n) = T(n/2) + O(1)$, 主定理 → $O(\log n)$.

### 1.3 数学基础

$\log_2 10^9 \approx 30$, 所以 $10^9$ 个元素只需 30 次比较. 这就是二分的强大之处.

### 1.4 应用范围

- 找具体值
- 找边界(左/右)
- 找峰值
- 求满足条件的最值

## 2. 三种标准模板 (★ 必会)

### 2.1 模板对比

| 模板 | 区间 | while | 适用 |
|---|---|---|---|
| 标准二分 | `[left, right]` 闭 | `left <= right` | 找任意一个 |
| 找左边界 | `[left, right)` 半开 | `left < right` | 找第一个 ≥ |
| 找右边界 | `[left, right)` 半开 | `left < right` | 找第一个 > |

### 2.2 模板 1: 标准二分(找任意一个)

```python
def binary_search(nums, target):
    """找任意一个等于 target 的位置, 不存在返回 -1"""
    left, right = 0, len(nums) - 1   # [left, right]
    while left <= right:
        mid = left + (right - left) // 2  # 防溢出
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

**关键**:
- 闭区间 `[left, right]`, 所以 `left <= right`
- mid 命中后直接返回
- 不命中时, mid 可以排除, 所以 `left = mid + 1` 或 `right = mid - 1`

### 2.3 模板 2: 找左边界 (lower_bound)

```python
def lower_bound(nums, target):
    """找第一个 >= target 的位置, 没有则返回 len(nums)"""
    left, right = 0, len(nums)       # [left, right)
    while left < right:
        mid = left + (right - left) // 2
        if nums[mid] < target:
            left = mid + 1           # mid 一定不是答案
        else:
            right = mid              # mid 可能是答案, 保留
    return left
```

**关键**:
- 半开区间 `[left, right)`, 所以 `left < right`
- `nums[mid] < target` 时, mid 一定不是答案(因为 < target)
- `nums[mid] >= target` 时, mid 可能是答案(因为 ≥ target)

### 2.4 模板 3: 找右边界 (upper_bound)

```python
def upper_bound(nums, target):
    """找第一个 > target 的位置, 没有则返回 len(nums)"""
    left, right = 0, len(nums)       # [left, right)
    while left < right:
        mid = left + (right - left) // 2
        if nums[mid] <= target:
            left = mid + 1           # mid 一定不是答案
        else:
            right = mid              # mid 可能是答案
    return left
```

### 2.5 模板对比图

```text
数组: [1, 2, 3, 3, 3, 5, 7]
target = 3

左边界 (lower_bound): 第一个 3 的位置 = 2
右边界 (upper_bound): 第一个 > 3 的位置 = 5

3 的个数 = 5 - 2 = 3
```

### 2.6 完整 Python 工具包

```python
import bisect

# bisect_left = lower_bound
# bisect_right = upper_bound

a = [1, 2, 3, 3, 3, 5, 7]
print(bisect.bisect_left(a, 3))     # 2
print(bisect.bisect_right(a, 3))    # 5

# insort = 排序插入
bisect.insort(a, 4)                # a = [1, 2, 3, 3, 3, 4, 5, 7]
```

## 3. 边界与单调性(防死循环)

### 3.1 死循环案例分析

```python
# ❌ 死循环: lo, hi 都不动
while lo < hi:
    mid = (lo + hi) // 2
    if check(mid):
        hi = mid
    else:
        lo = mid       # ❌ 应该是 lo = mid + 1
# 当 lo + 1 = hi 时, mid = lo, lo 永远不变!

# ✅ 正确
while lo < hi:
    mid = (lo + hi) // 2
    if check(mid):
        hi = mid
    else:
        lo = mid + 1
```

### 3.2 单调性原则

**二分答案的关键**: `check(mid)` 必须满足单调性.

- 求**最小**可行值: `check(x)` 可行 → `check(x-1)` 也可行
- 求**最大**可行值: `check(x)` 可行 → `check(x+1)` 也可行

如果不满足, 二分答案失效.

### 3.3 检查清单

| 检查项 | 问题 |
|---|---|
| 区间对吗 | 闭/半开 |
| while 条件 | `<=` 还是 `<` |
| mid 计算 | 防溢出 |
| 更新方向 | `lo = mid + 1` 还是 `lo = mid` |
| 返回值 | `left` / `right` / `mid` |

## 4. 旋转数组二分(变形)

### 4.1 旋转数组定义

把有序数组从某点切开, 前后两半交换位置. 例:
```text
原:    [1, 2, 3, 4, 5, 6, 7]
旋转:  [4, 5, 6, 7, 1, 2, 3]   (旋转点 = 3)
```

### 4.2 关键观察

旋转后, **至少有一半是有序的**. 例如:
```text
[4, 5, 6, 7, 1, 2, 3]
 ↑-------↑     ↑--↑
   有序左半    有序右半
```

### 4.3 LeetCode 33 - 搜索旋转排序数组 (Medium)

```python
def search(nums, target):
    """O(log n)"""
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid

        # 判断哪半有序
        if nums[left] <= nums[mid]:
            # 左半有序
            if nums[left] <= target < nums[mid]:
                right = mid - 1
            else:
                left = mid + 1
        else:
            # 右半有序
            if nums[mid] < target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1
    return -1
```

**复杂度**: 每次排除一半, $O(\log n)$.

### 4.4 LeetCode 81 - 搜索旋转排序数组 II (Medium)

**变种**: 数组可能有重复元素.

```python
def search(nums, target):
    """O(log n) 平均, O(n) 最坏"""
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return True
        if nums[left] == nums[mid] == nums[right]:
            left += 1
            right -= 1
        elif nums[left] <= nums[mid]:
            if nums[left] <= target < nums[mid]:
                right = mid - 1
            else:
                left = mid + 1
        else:
            if nums[mid] < target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1
    return False
```

**注意**: 重复元素时, 最坏可能退化为 $O(n)$.

### 4.5 LeetCode 153 - 找旋转数组的最小值 (Medium)

```python
def findMin(nums):
    """O(log n)"""
    left, right = 0, len(nums) - 1
    while left < right:
        mid = left + (right - left) // 2
        if nums[mid] > nums[right]:
            # 最小值在右半
            left = mid + 1
        else:
            # 最小值在左半(含 mid)
            right = mid
    return nums[left]
```

### 4.6 LeetCode 154 - 找旋转数组的最小值 II (含重复)

```python
def findMin(nums):
    left, right = 0, len(nums) - 1
    while left < right:

        if nums[mid] > nums[right]:
            left = mid + 1
        elif nums[mid] < nums[right]:

            right -= 1      # 相等时, 缩小右边界
```

## 5. 山脉数组二分

### 5.1 山脉数组定义

`A[0] < A[1] < ... < A[i] > A[i+1] > ... > A[n-1]`, 严格先增后减.

### 5.2 LeetCode 162 - 找峰值 (Medium)

**题目**: `nums[i] ≠ nums[i+1]`, 找任意一个峰值.

```python
def findPeakElement(nums):
    """O(log n)"""
    left, right = 0, len(nums) - 1
    while left < right:
        mid = left + (right - left) // 2
        if nums[mid] > nums[mid + 1]:
            # 峰值在左半(含 mid)
            right = mid
        else:
            # 峰值在右半
            left = mid + 1
    return left
```

### 5.4 LeetCode 1095 - 山脉数组中查找目标值 (Hard)

```python
def findInMountainArray(target, mountain_arr):
    n = mountain_arr.length()

    # 1. 找峰顶
    lo, hi = 0, n - 1
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if mountain_arr.get(mid) < mountain_arr.get(mid + 1):
            lo = mid + 1
        else:
            hi = mid
    peak = lo

    # 2. 左半升序二分
    lo, hi = 0, peak
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if mountain_arr.get(mid) < target:
            lo = mid + 1
        else:
            hi = mid
    if mountain_arr.get(lo) == target:
        return lo

    # 3. 右半降序二分
    lo, hi = peak, n - 1
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if mountain_arr.get(mid) > target:
            lo = mid + 1
        else:
            hi = mid
    if mountain_arr.get(lo) == target:
        return lo
    return -1
```

## 6. 二分答案(关键思想)

### 6.1 适用场景

问法通常包含:
- "求满足条件的**最小**值"
- "求满足条件的**最大**值"
- "最大值的**最小**化"
- "最小值的**最大**化"

### 6.2 套路模板

```python
def binary_answer(lo, hi):
    """
    通用二分答案模板
    lo..hi 是答案的可能范围
    """
    while lo < hi:
        mid = (lo + hi) // 2
        if check(mid):           # 验证 mid 是否可行
            hi = mid             # 求最小可行: 可行 → 缩小上界
        else:
            lo = mid + 1         # 不可行 → 增大下界
    return lo

# 求最大可行: 反过来
def binary_answer_max(lo, hi):
    while lo < hi:
        mid = (lo + hi + 1) // 2   # 注意 +1 防死循环
        if check(mid):
            lo = mid             # 可行 → 增大下界
        else:
            hi = mid - 1         # 不可行 → 缩小上界
    return lo
```

### 6.3 单调性核心

`check(mid)` 必须满足:
- 求**最小**可行: `check(x)` 可行 $\Rightarrow$ `check(x-1)` 也可行
- 求**最大**可行: `check(x)` 可行 $\Rightarrow$ `check(x+1)` 也可行

### 6.4 答案范围估计

```python
# 答案下界: 能多小就多小
lo = min_possible

# 答案上界: 能多大就多大
hi = max_possible

# 例: 二分速度, lo = 1, hi = max(piles)
```

### 6.5 经典题: LeetCode 875 - 爱吃香蕉的珂珂

```python
def minEatingSpeed(piles, H):
    """最小速度 K, 使 H 小时内吃完"""
    lo, hi = 1, max(piles)

    def can_finish(K):
        hours = sum((p + K - 1) // K for p in piles)   # 向上取整
        return hours <= H

    while lo < hi:
        mid = (lo + hi) // 2
        if can_finish(mid):
            hi = mid
        else:
            lo = mid + 1

    return lo
```

**复杂度**: $O(n \log \max(\text{piles}))$.

### 6.6 经典题: LeetCode 1011 - 在 D 天内送达包裹

```python
def shipWithinDays(weights, D):
    lo, hi = max(weights), sum(weights)

    def can_ship(capacity):
        days, cur = 1, 0
        for w in weights:
            if cur + w <= capacity:
                cur += w
            else:
                days += 1
                cur = w
                if days > D:
                    return False
        return True

    while lo < hi:
        mid = (lo + hi) // 2
        if can_ship(mid):
            hi = mid
        else:
            lo = mid + 1

    return lo
```

```python
def splitArray(nums, m):
```

```python
def minDays(bloomDay, m, k):
```

## 7. 二分 + 验证函数

### 7.1 LeetCode 774 - 最小化最大值距离 (Hard)

```python
def minmaxGasDist(stations, K):
    """在 stations 上加 K 个加油站, 最小化最大相邻距离"""
    lo, hi = 0, stations[-1] - stations[0]

    def can_gap(gap):
        """能否在 gap 距离内完成 K 个加油站"""
        needed = 0
        for i in range(1, len(stations)):
            needed += int((stations[i] - stations[i-1]) / gap) - (1 if (stations[i] - stations[i-1]) % gap == 0 else 0)
            if needed > K:
                return False
        return needed <= K

    # 浮点二分
    for _ in range(60):    # 2^-60 ≈ 10^-18 精度
        mid = (lo + hi) / 2
        if can_gap(mid):
            hi = mid
        else:
            lo = mid
    return lo
```

### 7.2 LeetCode 778 - 水位上升的泳池游泳 (Hard)

```python
import heapq
from typing import List

class Solution:
    def swimInWater(self, grid: List[List[int]]) -> int:
        """从 (0,0) 到 (n-1,n-1), 最小化路径上的最大水位"""
        n = len(grid)
        if n == 1: return 0

        # 用 Dijkstra 求最短路(以 max(grid[i][j]) 为代价)
        heap = [(grid[0][0], 0, 0)]
        visited = set()

        while heap:
            t, i, j = heapq.heappop(heap)
            if (i, j) in visited: continue
            visited.add((i, j))

            if (i, j) == (n-1, n-1):
                return t

            for di, dj in ((-1, 0), (1, 0), (0, -1), (0, 1)):
                ni, nj = i + di, j + dj
                if 0 <= ni < n and 0 <= nj < n and (ni, nj) not in visited:
                    heapq.heappush(heap, (max(t, grid[ni][nj]), ni, nj))
```

### 7.3 二分答案 + 复杂验证函数

```python
def find_min_max(arr, predicate):
    """
    二分求满足 predicate 的最小值
    predicate(x) 必须单调
    """
    lo, hi = 0, len(arr)
    while lo < hi:
        mid = (lo + hi) // 2
        if predicate(arr[:mid+1]):
            hi = mid
        else:
            lo = mid + 1
    return lo
```

## 8. 浮点二分

### 8.1 模板

```python
def float_binary(lo, hi, precision=1e-7):
    """浮点二分, 精度 precision"""
    for _ in range(100):    # 迭代次数足够多
        mid = (lo + hi) / 2
        if check(mid):
            hi = mid
        else:
            lo = mid
    return lo
# 100 次迭代: 2^-100 ≈ 7.9e-31, 远超 double 精度
```

### 8.2 LeetCode 786 - 第 K 个最小的素数分数 (Hard)

```python
def kthSmallestPrimeFraction(arr, k):
    """O((N+M) log(max_val/min_val))"""
    n = len(arr)
    lo, hi = 0.0, 1.0

    while lo < hi:
        mid = (lo + hi) / 2
        # 统计 ≤ mid 的分数个数, 并记录最大的
        count = 0
        p, q = 0, 1
        i = 0
        for j in range(1, n):
            while arr[i] / arr[j] <= mid:
                if arr[i] * q > p * arr[j]:
                    p, q = arr[i], arr[j]
                i += 1
            count += i

        if count == k:
            return [p, q]
        elif count < k:
            lo = mid
        else:
            hi = mid
```

### 8.3 LeetCode 719 - 找出第 K 小的数对距离 (Hard)

```python
def smallestDistancePair(nums, k):
    nums.sort()
    n = len(nums)
    lo, hi = 0, nums[-1] - nums[0]

    def count_pairs(limit):
        cnt = 0
        i = 0
        for j in range(n):
            while nums[j] - nums[i] > limit:
                i += 1
            cnt += j - i
        return cnt

    while lo < hi:
        mid = (lo + hi) // 2
        if count_pairs(mid) >= k:
            hi = mid
        else:
            lo = mid + 1
    return lo
```

## 9. 二维矩阵二分

### 9.1 LeetCode 74 - 搜索二维矩阵 (Medium)

**题目**: 矩阵每行升序, 每行首元素 > 上一行末元素.

```python
def searchMatrix(matrix, target):
    """O(log(m*n))"""
    if not matrix: return False
    m, n = len(matrix), len(matrix[0])
    lo, hi = 0, m * n - 1
    while lo < hi:
        mid = (lo + hi) // 2
        i, j = mid // n, mid % n
        if matrix[i][j] < target:
            lo = mid + 1
        else:
            hi = mid
    return matrix[lo // n][lo % n] == target
```

### 9.2 LeetCode 240 - 搜索二维矩阵 II (Medium)

**题目**: 矩阵每行升序, 每列升序, 但没有"行接行"性质.

```python
def searchMatrix(matrix, target):
    """O(m+n) 从右上角"""
    if not matrix: return False
    m, n = len(matrix), len(matrix[0])
    i, j = 0, n - 1
    while i < m and j >= 0:
        if matrix[i][j] == target:
            return True
        elif matrix[i][j] > target:
            j -= 1
        else:
            i += 1
    return False
```

### 9.3 LeetCode 378 - 有序矩阵中第 K 小的元素 (Medium)

```python
def kthSmallest(matrix, k):
    """O(n log(max-min))"""
    n = len(matrix)
    lo, hi = matrix[0][0], matrix[-1][-1]

    def count_le(mid):
        cnt = 0
        j = n - 1
        for i in range(n):
            while j >= 0 and matrix[i][j] > mid:
                j -= 1
            cnt += j + 1
        return cnt

    while lo < hi:
        mid = (lo + hi) // 2
        if count_le(mid) >= k:
            hi = mid
        else:
            lo = mid + 1
    return lo
```

```python
def searchRange(nums, target):

    def find_bound(find_first):
```

```python
def findMedianSortedArrays(nums1, nums2):
    """O(log(min(m,n)))"""
    if len(nums1) > len(nums2):
        nums1, nums2 = nums2, nums1
    m, n = len(nums1), len(nums2)

    lo, hi = 0, m
    while lo <= hi:
        i = (lo + hi) // 2
        j = (m + n + 1) // 2 - i

        nums1_left = nums1[i-1] if i > 0 else float('-inf')
        nums1_right = nums1[i] if i < m else float('inf')
        nums2_left = nums2[j-1] if j > 0 else float('-inf')
        nums2_right = nums2[j] if j < n else float('inf')

        if nums1_left <= nums2_right and nums2_left <= nums1_right:
            if (m + n) % 2 == 1:
                return max(nums1_left, nums2_left)
            else:
                return (max(nums1_left, nums2_left) + min(nums1_right, nums2_right)) / 2
        elif nums1_left > nums2_right:
            hi = i - 1
        else:
            lo = i + 1
```

## 15. 附录: 二分的扩展思想

### 15.1 三分法 (Ternary Search)

求单峰函数的极值.

```python
def ternary_search(f, lo, hi, eps=1e-7):
    """f 是单峰函数, 求最大值"""
    while hi - lo > eps:
        m1 = lo + (hi - lo) / 3
        m2 = hi - (hi - lo) / 3
        if f(m1) < f(m2):
            lo = m1
        else:
            hi = m2
    return (lo + hi) / 2
```

**复杂度**: $O(\log_{3/2} n)$(每次缩 2/3).

### 15.2 指数搜索 (Exponential Search)

无界数组的二分.

```python
def exponential_search(arr, target):
    n = len(arr)
    if arr[0] == target: return 0

    i = 1
    while i < n and arr[i] <= target:
        i *= 2

    return binary_search_range(arr, i // 2, min(i, n - 1), target)
```

### 15.3 插值搜索 (Interpolation Search)

均匀分布时, 用值估计位置: $\text{pos} = \text{lo} + \frac{(x - a[\text{lo}]) \cdot (\text{hi} - \text{lo})}{a[\text{hi}] - a[\text{lo}]}$.

平均 $O(\log \log n)$, 最坏 $O(n)$.

### 18.2 二分的循环展开

```python
# 大数据二分时, 展开几次循环可减少分支预测失败
def binary_search_unrolled(arr, target):
    n = len(arr)
    lo, hi = 0, n - 1
    while hi - lo >= 4:
        mid = lo + ((hi - lo) >> 1)
        if arr[mid] < target:
            lo = mid + 1
        elif arr[mid] > target:
            hi = mid - 1
        else:
            return mid
    # 处理最后几个
    for i in range(lo, hi + 1):
        if arr[i] == target:
            return i
    return -1
```

### 18.3 硬件友好的二分

```cpp
// C++: __builtin_expect 提示分支预测
int binary_search(int* arr, int n, int target) {
    int lo = 0, hi = n - 1;
    while (lo <= hi) {
        int mid = lo + ((hi - lo) >> 1);
        if (__builtin_expect(arr[mid] == target, 0)) return mid;
        if (arr[mid] < target) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}
```

### 22.2 二分决策树

```python
import matplotlib.pyplot as plt

class TreeNode:
    def __init__(self, lo, hi, mid=None, left=None, right=None):
        self.lo = lo
        self.hi = hi
        self.mid = mid
        self.left = left
        self.right = right

def build_decision_tree(nums, target, lo=0, hi=None):
    """构建二分决策树"""
    if hi is None: hi = len(nums) - 1
    if lo > hi:
        return TreeNode(lo, hi)

    mid = lo + (hi - lo) // 2
    node = TreeNode(lo, hi, mid)

    if nums[mid] == target:
        return node    # 找到

    if nums[mid] < target:
        node.right = build_decision_tree(nums, target, mid + 1, hi)
    else:
        node.left = build_decision_tree(nums, target, lo, mid - 1)

    return node
```

### 23.3 跳表 (Skip List)

```python
import random

class SkipListNode:
    def __init__(self, val, level):
        self.val = val
        self.next = [None] * level

class SkipList:
    """O(log n) 查找/插入/删除"""

    def __init__(self, max_level=16):
        self.max_level = max_level
        self.head = SkipListNode(None, max_level)
        self.level = 0

    def random_level(self):
        lvl = 0
        while random.random() < 0.5 and lvl < self.max_level - 1:
            lvl += 1
        return lvl

    def search(self, target):
        node = self.head
        for i in range(self.level, -1, -1):
            while node.next[i] and node.next[i].val < target:
                node = node.next[i]
        node = node.next[0]
        if node and node.val == target:
            return True
        return False

    def insert(self, val):
        update = [None] * self.max_level
        node = self.head
        for i in range(self.level, -1, -1):
            while node.next[i] and node.next[i].val < val:
                node = node.next[i]
            update[i] = node

        new_level = self.random_level()
        if new_level > self.level:
            for i in range(self.level + 1, new_level + 1):
                update[i] = self.head
            self.level = new_level

        new_node = SkipListNode(val, new_level + 1)
        for i in range(new_level + 1):
            new_node.next[i] = update[i].next[i]
            update[i].next[i] = new_node
```

应用: Redis sorted set, LevelDB.

### 27.1 树状数组 (BIT) + 二分

```python
class BIT:
    """树状数组, O(log n) 单点更新 + 前缀和查询"""

    def __init__(self, n):
        self.n = n
        self.tree = [0] * (n + 1)

    def update(self, i, delta):
        """单点更新"""
        i += 1
        while i <= self.n:
            self.tree[i] += delta
            i += i & -i

    def query(self, i):
        """前 i 个元素之和(0-indexed)"""
        i += 1
        s = 0
        while i > 0:
            s += self.tree[i]
            i -= i & -i
        return s

    def lower_bound(self, s):
        """找最小的 i 使 query(i) >= s"""
        i = 0
        k = 1
        while k <= self.n:
            k <<= 1
        k >>= 1
        while k:
            if i + k <= self.n and self.tree[i + k] < s:
                i += k
                s -= self.tree[i]
            k >>= 1
        return i
```

### 27.2 线段树 + 二分

```python
class SegTree:
    """线段树"""

    def __init__(self, arr):
        self.n = len(arr)
        self.tree = [0] * (4 * self.n)
        self.lazy = [0] * (4 * self.n)
        self.build(arr, 1, 0, self.n - 1)

    def build(self, arr, node, lo, hi):
        if lo == hi:
            self.tree[node] = arr[lo]
            return
        mid = (lo + hi) // 2
        self.build(arr, 2*node, lo, mid)
        self.build(arr, 2*node+1, mid+1, hi)
        self.tree[node] = self.tree[2*node] + self.tree[2*node+1]

    def update(self, node, lo, hi, idx, val):
        if lo == hi:
            self.tree[node] = val
            return
        mid = (lo + hi) // 2
        if idx <= mid:
            self.update(2*node, lo, mid, idx, val)
        else:
            self.update(2*node+1, mid+1, hi, idx, val)
        self.tree[node] = self.tree[2*node] + self.tree[2*node+1]

    def query(self, node, lo, hi, qlo, qhi):
        if qlo > hi or qhi < lo:
            return 0
        if qlo <= lo and hi <= qhi:
            return self.tree[node]
        mid = (lo + hi) // 2
        return self.query(2*node, lo, mid, qlo, qhi) + self.query(2*node+1, mid+1, hi, qlo, qhi)

    def query_first_ge(self, target):
        """二分查找第一个前缀和 >= target 的位置"""
        if self.tree[1] < target:
            return -1
        return self._query_first_ge(1, 0, self.n - 1, target)

    def _query_first_ge(self, node, lo, hi, target):
        if lo == hi:
            return lo
        mid = (lo + hi) // 2
        if self.tree[2*node] >= target:
            return self._query_first_ge(2*node, lo, mid, target)
        else:
            return self._query_first_ge(2*node+1, mid+1, hi, target - self.tree[2*node])
```

```python
def longest_increasing_subsequence(nums):
    """O(n log n) LIS, 维护单调递增栈"""
    import bisect
    tails = []
    for x in nums:
        idx = bisect.bisect_left(tails, x)
        if idx == len(tails):
            tails.append(x)
        else:
            tails[idx] = x
    return len(tails)
```

### 27.4 二分 + 并查集

```python
def kruskal_mst(n, edges):
    """最小生成树, 二分最大边 + 并查集"""
    edges.sort(key=lambda x: x[2])
    parent = list(range(n))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(x, y):
        px, py = find(x), find(y)
        if px == py: return False
        parent[px] = py
        return True

    mst_weight = 0
    edges_used = 0
    for u, v, w in edges:
        if union(u, v):
            mst_weight += w
            edges_used += 1
            if edges_used == n - 1:
                break
    return mst_weight
```

**3. 数学形式化(简洁版)**

虽然我们强调边界条件视角,但数学形式化提供了共同语言。机器学习的核心问题可以表达为:给定输入样本,学习一个映射函数,使得函数输出与真实目标的差距最小化。这个抽象捕捉了分类、回归、生成等大多数任务的本质。

进一步,优化目标通常加入正则化项来控制模型复杂度,平衡经验风险与模型容量。统计学习理论给出了泛化误差的上界,告诉我们模型越复杂并不一定越好——**奥卡姆剃刀**在数学上有严格的形式化。

偏差-方差分解是另一个核心框架:误差可以分解为模型偏差(欠拟合)、方差(过拟合)和不可约噪声三部分。理解这个分解有助于诊断模型表现、选择合适复杂度。

在数值稳定性方面,有几个常见陷阱: 浮点数精度有限、Log-Sum-Exp 计算要减去最大值、Softmax 在大数值下会溢出。这些工程细节常常决定一个模型能否在生产环境稳定运行。

互信息衡量知道一个变量后,另一个变量不确定性减少的量。在机器学习中,它被广泛用于特征选择、表示学习、多模态对齐等场景。

KL 散度衡量两个概率分布的距离,在交叉熵损失、变分推断、策略梯度等场景无处不在。需要注意它是**不对称**的——不同方向有不同的解释。

**7. 实践建议**

结合 "数组二分查找" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "数组二分查找" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
