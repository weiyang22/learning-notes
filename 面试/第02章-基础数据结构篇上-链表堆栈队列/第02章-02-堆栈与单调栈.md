## 1. 栈的定义与实现

### 1.1 定义

**栈 (Stack)**: 后进先出 (LIFO - Last In First Out) 的线性数据结构. 只允许在一端 (栈顶) 进行插入和删除.

```text
[底] 1 2 3 4 5 [顶]
         ↑ 只能从这里进出
```

### 1.2 基本操作

| 操作 | 时间 | 说明 |
|---|---|---|
| push | $O(1)$ | 入栈 |
| pop | $O(1)$ | 出栈 |
| top/peek | $O(1)$ | 看栈顶 |
| empty | $O(1)$ | 判空 |
| size | $O(1)$ | 元素个数 |

### 1.3 Python list 实现栈

```python
class Stack:
    def __init__(self):
        self.items = []

    def push(self, val):
        self.items.append(val)

    def pop(self):
        if not self.items: raise IndexError("Empty stack")
        return self.items.pop()

    def top(self):
        return self.items[-1] if self.items else None

    def empty(self):
        return len(self.items) == 0

    def size(self):
        return len(self.items)
```

### 1.4 collections.deque 实现栈

```python
from collections import deque

stack.append(2)
stack.pop()            # 返回 2

```

### 1.5 链表实现栈

```python
class Node:
    def __init__(self, val, next=None):
        self.val = val
        self.next = next

class StackLinked:
    def __init__(self):
        self.head = None
        self.n = 0

    def push(self, val):
        self.head = Node(val, self.head)
        self.n += 1

    def pop(self):
        if not self.head: raise IndexError("Empty")
        val = self.head.val
        self.head = self.head.next
        self.n -= 1
        return val

    def top(self):
        return self.head.val if self.head else None
```

```python
class MyQueue:

        self._move()
        return self.out_stack.pop()
```

```python
def backspaceCompare(s, t):
    """O(m+n) 时间, O(1) 额外空间"""
    def process(s):
        slow = 0
        s = list(s)
        for fast in range(len(s)):
            if s[fast] != '#':
                s[slow] = s[fast]
                slow += 1
            elif slow > 0:
                slow -= 1
        return ''.join(s[:slow])
```

## 3. 单调栈的本质

### 3.1 定义

**单调栈 (Monotonic Stack)**: 栈内元素保持单调递增或单调递减. 用于解决"下一个更大/更小元素"问题.

### 3.2 思想

遍历数组, 维护一个单调栈. 当新元素能"打破"单调性时, 弹出栈顶并记录答案.

### 3.3 单调递增栈 vs 单调递减栈

| 类型 | 维护 | 应用 |
|---|---|---|
| 递增栈 | 栈底 → 栈顶递增 | 下一个更小元素 |
| 递减栈 | 栈底 → 栈顶递减 | 下一个更大元素 |

### 3.4 单调栈模板

```python
def monotonic_stack(arr):
    """求下一个更大元素"""
    n = len(arr)
    res = [-1] * n
    stack = []    # 存索引

    for i in range(n):
        while stack and arr[stack[-1]] < arr[i]:
            idx = stack.pop()
            res[idx] = arr[i]
        stack.append(i)

    return res
```

**复杂度**: $O(n)$ 时间和空间. 每个元素最多入栈/出栈一次.

## 4. 单调栈的 4 大应用

### 4.1 应用 1: 下一个更大元素 (LeetCode 496)

```python
def nextGreaterElement(nums1, nums2):
    """nums1 是 nums2 的子集, 求 nums1 中每个元素在 nums2 中的下一个更大元素"""
    # 先处理 nums2
    next_greater = {}
    stack = []
    for x in nums2:
        while stack and stack[-1] < x:
            next_greater[stack.pop()] = x
        stack.append(x)
    while stack:
        next_greater[stack.pop()] = -1

    return [next_greater[x] for x in nums1]
```

```python
def dailyTemperatures(T):
```

### 4.3 应用 3: 下一个更大元素 II (循环数组, LeetCode 503)

```python
def nextGreaterElements(nums):
    """O(n), 循环数组"""
    n = len(nums)
    res = [-1] * n
    stack = []
    for i in range(2 * n):
```

### 4.4 应用 4: 柱状图中最大的矩形 (LeetCode 84, Hard)

```python
def largestRectangleArea(heights):
    """O(n)"""
    heights = [0] + heights + [0]
    stack = []
    res = 0
    for i in range(len(heights)):
        while stack and heights[stack[-1]] > heights[i]:
            h_idx = stack.pop()
            h = heights[h_idx]
            w = i - stack[-1] - 1
            res = max(res, h * w)
        stack.append(i)
    return res
```

**关键**: 维护一个递增栈, 每次弹出时计算以弹出节点为最低高度的矩形面积.

```python
    """O(n)"""
    stack = []
    water = 0
    for i, h in enumerate(height):
        while stack and height[stack[-1]] < h:
            bottom = stack.pop()
            if not stack: break

    return water
```

## 5. 表达式求值与转换

### 5.1 中缀转后缀 (Shunting-yard)

```python
def infix_to_postfix(s):
    """中缀转后缀"""
    precedence = {'+': 1, '-': 1, '*': 2, '/': 2, '^': 3}
    output = []
    stack = []

    for c in s:
        if c.isalnum():
            output.append(c)
        elif c == '(':
            stack.append(c)
        elif c == ')':
            while stack and stack[-1] != '(':
                output.append(stack.pop())
            stack.pop()
        else:  # 运算符
            while stack and stack[-1] != '(' and precedence.get(stack[-1], 0) >= precedence[c]:
                output.append(stack.pop())
            stack.append(c)

    while stack:
        output.append(stack.pop())

    return ' '.join(output)
```

### 5.2 后缀表达式求值 (LeetCode 150)

```python
def evalRPN(tokens):
    """O(n)"""
    stack = []
    for t in tokens:
        if t in '+-*/':
            b, a = stack.pop(), stack.pop()
            if t == '+': stack.append(a + b)
            elif t == '-': stack.append(a - b)
            elif t == '*': stack.append(a * b)
            else: stack.append(int(a / b))
        else:
            stack.append(int(t))
    return stack[0]
```

```python
def decodeString(s):
    """栈 + 双指针"""
    stack = []
    num = 0
    res = ""
    for c in s:
        if c.isdigit():
            num = num * 10 + int(c)
        elif c == '[':
            stack.append((res, num))
            res = ""
            num = 0
```

### 5.4 基本计算器 (LeetCode 224, Hard)

```python
def calculate(s):
    """含 + - ( ) 的表达式求值"""
    stack = []
    num = 0
    sign = 1
    res = 0

    for c in s:
        if c.isdigit():
            num = num * 10 + int(c)
        elif c == '+':
            res += sign * num
            num = 0
            sign = 1
        elif c == '-':
            res += sign * num
            num = 0
            sign = -1
        elif c == '(':
            stack.append((res, sign))
            res = 0
            sign = 1
            num = 0
        elif c == ')':
            res += sign * num
            num = 0
            prev_res, prev_sign = stack.pop()
            res = prev_res + prev_sign * res

    res += sign * num
    return res
```

### 5.5 基本计算器 II (LeetCode 227, 含 * /)

```python
def calculate_ii(s):
    """O(n)"""
    stack = []
    num = 0
    op = '+'

    for i, c in enumerate(s):
        if c.isdigit():
            num = num * 10 + int(c)
        if c in '+-*/' or i == len(s) - 1:
            if op == '+':
                stack.append(num)
            elif op == '-':
                stack.append(-num)
            elif op == '*':
                stack.append(stack.pop() * num)
            else:
                stack.append(int(stack.pop() / num))
            op = c
            num = 0

    return sum(stack)
```

## 6. 括号类问题

### 6.1 最长有效括号 (LeetCode 32, Hard)

```python
def longestValidParentheses(s):
    """O(n) 栈"""
    stack = [-1]
    res = 0
    for i, c in enumerate(s):
        if c == '(':
            stack.append(i)
        else:
            stack.pop()
            if not stack:
                stack.append(i)
            else:
                res = max(res, i - stack[-1])
    return res

# DP 版本
def longestValidParentheses_dp(s):
    n = len(s)
    dp = [0] * n
    for i in range(1, n):
        if s[i] == ')':
            if s[i-1] == '(':
                dp[i] = (dp[i-2] if i >= 2 else 0) + 2
            elif i - dp[i-1] - 1 >= 0 and s[i - dp[i-1] - 1] == '(':
                dp[i] = dp[i-1] + 2 + (dp[i - dp[i-1] - 2] if i - dp[i-1] - 2 >= 0 else 0)
    return max(dp) if dp else 0
```

### 6.2 有效的括号字符串 (LeetCode 678, 含 *)

```python
def checkValidString(s):
    """贪心: 维护 (low, high) 范围"""
    low = high = 0
    for c in s:
        if c == '(':
            low += 1
            high += 1
        elif c == ')':
            low = max(0, low - 1)
            high -= 1
        else:  # *
            low = max(0, low - 1)
            high += 1
        if high < 0:
            return False
    return low == 0
```

### 6.3 去除重复字母 (LeetCode 316, Hard)

```python
def removeDuplicateLetters(s):
    """O(n)"""
    last = {c: i for i, c in enumerate(s)}
    stack = []
    in_stack = set()

    for i, c in enumerate(s):
        if c in in_stack:
            continue
        while stack and c < stack[-1] and last[stack[-1]] > i:
            in_stack.remove(stack.pop())
        stack.append(c)
        in_stack.add(c)

    return ''.join(stack)
```

### 6.4 平衡括号字符串的最少插入 (LeetCode 1541)

```python
def minInsertions(s):
    """O(n)"""
    res = 0    # 插入次数
    right = 0  # 需要的右括号

    for c in s:
        if c == '(':
            if right % 2:
                res += 1
                right -= 1
            right += 2
        else:
            right -= 1
            if right < 0:
                res += 1
                right = 1

    return res + right
```

```python
class StockSpanner:
    def __init__(self):
        self.stack = []    # (price, span)

    def next(self, price):
        span = 1
        while self.stack and self.stack[-1][0] <= price:
            span += self.stack[-1][1]
            self.stack.pop()
        self.stack.append((price, span))
        return span
```

```python
def find132pattern(nums):
    """O(n) 单调栈"""
    stack = []
    s3 = float('-inf')
    for x in reversed(nums):
        if x < s3:
            return True
        while stack and stack[-1] < x:
            s3 = stack.pop()
        stack.append(x)
    return False
```

#### LeetCode 726 - 原子的数量

```python
def countOfAtoms(formula):
    """O(n)"""
    stack = [{}]
    i = 0
    while i < len(formula):
        if formula[i] == '(':
            stack.append({})
            i += 1
        elif formula[i] == ')':
            curr = stack.pop()
            i += 1
            num = 0
            while i < len(formula) and formula[i].isdigit():
                num = num * 10 + int(formula[i])
                i += 1
            num = max(num, 1)
            for atom in curr:
                curr[atom] *= num
            if not stack[-1]:
                stack[-1] = {}
            for atom, count in curr.items():
                stack[-1][atom] = stack[-1].get(atom, 0) + count
        else:
            atom = formula[i]
            i += 1
            while i < len(formula) and formula[i].islower():
                atom += formula[i]
                i += 1
            num = 0
            while i < len(formula) and formula[i].isdigit():
                num = num * 10 + int(formula[i])
                i += 1
            num = max(num, 1)
            stack[-1][atom] = stack[-1].get(atom, 0) + num

    return ''.join(f'{atom}{cnt if cnt > 1 else ""}' for atom, cnt in sorted(stack[-1].items()))
```

### 11.4 单调栈 + 二分

```python
def longestMountain(nums):
    """最长山脉, 用单调栈"""
    n = len(nums)
    left = [0] * n
    right = [0] * n

    # 从左到右, 维护递减栈
    stack = []
    for i in range(n):
        while stack and nums[stack[-1]] >= nums[i]:
            stack.pop()
        left[i] = stack[-1] if stack else -1
        stack.append(i)

    # 从右到左, 维护递减栈
    stack = []
    for i in range(n - 1, -1, -1):
        while stack and nums[stack[-1]] >= nums[i]:
            stack.pop()
        right[i] = stack[-1] if stack else n
        stack.append(i)

    # 找最长
    res = 0
    for i in range(n):
        if left[i] != -1 and right[i] != n:
            res = max(res, right[i] - left[i] - 1)
    return res
```

```python
def find132pattern_v2(nums):
    """O(n) 单调栈, 详细注释"""
    stack = []   # 单调递减栈, 存"3"的候选
    s3 = float('-inf')   # 当前找到的"s3" (中间的)

    for x in reversed(nums):

            # 找到了一个"s1 < s3"
            return True
        while stack and stack[-1] < x:
```

### 11.10 LeetCode 1130 - 叶值的最小代价生成树

```python
def mctFromLeafValues(arr):
    """O(n) 单调栈"""
    stack = [float('inf')]
    res = 0
    for x in arr:
        while stack[-1] <= x:
            mid = stack.pop()
            res += mid * min(stack[-1], x)
        stack.append(x)

    while len(stack) > 2:
        res += stack.pop() * stack[-1]

    return res
```

```python
def build_expression_tree(postfix):
    stack = []
    for t in postfix:
        node = TreeNode(t)
        if t in '+-*/':
```

### 16.3 表达式求值 (综合)

```python
def evaluate_expression(s):
    """综合: 数字 + 运算符 + 括号"""
    nums = []
    ops = []
    precedence = {'+': 1, '-': 1, '*': 2, '/': 2}

    def apply_op():
        b, a = nums.pop(), nums.pop()
        op = ops.pop()
        if op == '+': nums.append(a + b)
        elif op == '-': nums.append(a - b)
        elif op == '*': nums.append(a * b)
        else: nums.append(int(a / b))

    i = 0
    while i < len(s):
        if s[i] == ' ':
            i += 1
        elif s[i] == '(':
            ops.append(s[i])
            i += 1
        elif s[i] == ')':
            while ops and ops[-1] != '(':
                apply_op()
            ops.pop()
            i += 1
        elif s[i].isdigit():
            num = 0
            while i < len(s) and s[i].isdigit():
                num = num * 10 + int(s[i])
                i += 1
            nums.append(num)
        else:  # 运算符
            while ops and ops[-1] != '(' and precedence.get(ops[-1], 0) >= precedence[s[i]]:
                apply_op()
            ops.append(s[i])
            i += 1

    while ops:
        apply_op()
    return nums[0]
```

```python
def lengthLongestPath(input):
    stack = [-1]    # 路径长度栈
    res = 0
    i = 0
    n = len(input)

    while i < n:
        depth = 1
        # 计算深度
        while i < n and input[i] == '\t':
            depth += 1
            i += 1

        # 文件名长度
        start = i
        is_file = False
        while i < n and input[i] != '\n':
            if input[i] == '.':
                is_file = True
            i += 1

        length = i - start
        if depth > len(stack) - 1:
            stack.append(stack[-1] + length + 1)
        else:
            stack[depth] = stack[depth - 1] + length + 1

        if is_file:
            res = max(res, stack[depth])

        i += 1  # skip '\n'

    return res
```

```python
class NestedIterator:
    def __init__(self, nestedList):
        self.stack = []
        for nl in reversed(nestedList):
            self.stack.append(nl)

    def next(self):
        return self.stack.pop().getInteger()

    def hasNext(self):
        while self.stack:
            top = self.stack[-1]
            if top.isInteger():
                return True
            self.stack.pop()
            for nl in reversed(top.getList()):
                self.stack.append(nl)
        return False
```

## 18. 附录: 单调栈思维拓展

### 18.1 单调栈的实质

单调栈的实质是"用空间换时间": 把没解决的元素暂存, 等待未来更优的元素.

### 18.2 单调栈的复杂度分析

每个元素最多入栈 1 次, 出栈 1 次. 所以是 $O(n)$.

### 18.3 单调栈 vs 暴力

暴力: 对每个元素, 往后找答案 → $O(n^2)$
单调栈: 用栈暂存, 一次性处理 → $O(n)$

### 18.4 单调栈的局限性

只适合"单调性"问题. 不单调的问题不能用单调栈.

### 18.5 单调栈的扩展

- 单调队列 (deque)
- 双端单调栈
- 区间单调栈

```python
def parseTernary(expression):
    """三目运算, 用栈"""
    stack = []
    for c in expression[::-1]:
        if c.isdigit() or c == 'T' or c == 'F':
            stack.append(c)
        elif c == '?':
            continue
        elif c == ':':
            a = stack.pop()
            b = stack.pop()
            # 检查下一个是 T 还是 F
            next_c = expression[len(expression) - 1 - len(''.join(stack))] if stack else 'T'
            # 简化: 直接解析

        else:
            # 真/假条件

            a = stack.pop()

            stack.append(a if cond == 'T' else b)
```

```python
class BSTIterator:

        self.stack = []
        self._push_left(root)

    def _push_left(self, node):
        while node:
            self.stack.append(node)
            node = node.left

    def next(self):
        node = self.stack.pop()
        self._push_left(node.right)
        return node.val

    def hasNext(self):
```

```python
def factorial_stack(n):
    """O(n) 时间, O(n) 空间 (栈深度)"""
    result = 1
    stack = list(range(1, n + 1))
    while stack:
        result *= stack.pop()
    return result
```

### 31.2 斐波那契的栈实现

```python
def fib_stack(n):
    if n < 2: return n
    stack = [(n, False)]
    result = 0
    while stack:
        k, computed = stack.pop()
        if k < 2:
            result += k
        elif computed:
            result += stack.pop()[0]
        else:
            stack.append((k, True))
            stack.append((k-1, False))
            stack.append((k-2, False))
    return result
```

### 31.3 树的非递归遍历 (栈)

```python
def inorder_iterative(root):
    """中序遍历"""
    stack = []
    res = []
    curr = root
    while curr or stack:
        while curr:
            stack.append(curr)
            curr = curr.left
        curr = stack.pop()
        res.append(curr.val)
        curr = curr.right
    return res

def preorder_iterative(root):
    """前序遍历"""
    if not root: return []
    stack = [root]
    res = []
    while stack:
        node = stack.pop()
        res.append(node.val)
        if node.right:
            stack.append(node.right)
        if node.left:
            stack.append(node.left)
    return res

def postorder_iterative(root):
    """后序遍历"""
    if not root: return []
    stack = [root]
    res = []
    while stack:
        node = stack.pop()
        res.append(node.val)
        if node.left:
            stack.append(node.left)
        if node.right:
            stack.append(node.right)
    return res[::-1]
```

对 "堆栈与单调栈" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
