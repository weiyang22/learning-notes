## 1. 队列的定义

队列 (Queue) 是先进先出 (FIFO) 的线性数据结构. 只允许在队尾插入, 在队首删除.

基本操作:
- enqueue: 入队, O(1)
- dequeue: 出队, O(1)
- front: 看队首, O(1)
- empty: 判空, O(1)
- size: 元素个数, O(1)

Python 实现 (deque):
```python
from collections import deque

q = deque()
q.append(x)        # 入队, O(1)
q.appendleft(x)    # 头插, O(1)
q.popleft()        # 出队, O(1)
q.pop()            # 尾删, O(1)
q[0]               # 队首
q[-1]              # 队尾
```

list 当队列用 (但 popleft O(n)):
```python
q = []
q.append(x)
q.pop(0)    # 慢
```

C++ std::queue:
```cpp
std::queue<int> q;
q.push(1);
q.front();
q.pop();
```

Java:
```java
Queue<Integer> q = new LinkedList<>();
q.offer(1);
q.poll();
q.peek();
```

## 2. 双端队列 (deque)

双端队列允许两端操作. Python 的 collections.deque 是其实现.

```python
from collections import deque
dq = deque([1, 2, 3])
dq.append(4)        # 尾插
dq.appendleft(0)    # 头插
dq.pop()            # 尾删
dq.popleft()        # 头删
dq[0]               # 队首
dq[-1]              # 队尾
dq.rotate(1)        # 循环右移
```

应用:
- 滑动窗口
- 单调队列
- BFS
- 实现栈和队列

## 3. 优先队列 (Priority Queue)

优先队列每次取出**优先级最高**的元素. 通常用**堆**实现.

Python 实现 (heapq, 最小堆):
```python
import heapq

heap = []
heapq.heappush(heap, x)        # 入堆, O(log n)
heapq.heappop(heap)            # 出堆, O(log n)
heap[0]                        # 看最小, O(1)
heapq.heapify(arr)             # 建堆, O(n)
heapq.nlargest(k, arr)        # 前 k 大
heapq.nsmallest(k, arr)       # 前 k 小
```

最大堆实现 (取负):
```python
heap = []
heapq.heappush(heap, -x)
heapq.heappop(heap)    # 返回 -heapq.heappop(heap)
```

C++ priority_queue:
```cpp
std::priority_queue<int> pq;   // 默认最大堆
pq.push(1);
pq.top();
pq.pop();

// 最小堆
std::priority_queue<int, std::vector<int>, std::greater<int>> pq;
```

Java:
```java
PriorityQueue<Integer> pq = new PriorityQueue<>();
pq.offer(1);
pq.poll();
pq.peek();
```

## 4. 堆 (Heap) 详解

堆是**完全二叉树**, 满足堆性质:
- **大根堆**: 父节点 >= 子节点, 根是最大
- **小根堆**: 父节点 <= 子节点, 根是最小

数组实现 (0-indexed):
- 父节点 i 的左右孩子: 2i+1, 2i+2
- 节点 i 的父节点: (i-1)//2
- 第 k 层节点范围: [2^(k-1)-1, 2^k-2]

### 4.1 堆的核心操作

```python
class MaxHeap:
    def __init__(self):
        self.heap = []

    def sift_up(self, i):
        while i > 0 and self.heap[self.parent(i)] < self.heap[i]:
            self.heap[self.parent(i)], self.heap[i] = self.heap[i], self.heap[self.parent(i)]
            i = self.parent(i)

    def sift_down(self, i):
        n = len(self.heap)
        while True:
            l, r = 2*i+1, 2*i+2
            largest = i
            if l < n and self.heap[l] > self.heap[largest]: largest = l
            if r < n and self.heap[r] > self.heap[largest]: largest = r
            if largest == i: break
            self.heap[i], self.heap[largest] = self.heap[largest], self.heap[i]
            i = largest

    def parent(self, i): return (i-1)//2

    def push(self, val):
        self.heap.append(val)
        self.sift_up(len(self.heap) - 1)

    def pop(self):
        if not self.heap: return None
        top = self.heap[0]
        self.heap[0] = self.heap.pop()
        if self.heap: self.sift_down(0)
        return top

    def peek(self): return self.heap[0] if self.heap else None
```

### 4.2 复杂度

| 操作 | 平均 | 最坏 |
|---|---|---|
| push | O(log n) | O(log n) |
| pop | O(log n) | O(log n) |
| peek | O(1) | O(1) |
| heapify | O(n) | O(n) |

### 4.3 堆的应用

1. **优先队列**: 操作系统进程调度
2. **Top K**: LeetCode 215
3. **堆排序**: 时间 O(n log n), 空间 O(1)
4. **Dijkstra**: 最短路 (用堆)
5. **中位数维护**: 两个堆

## 5. 二叉堆 vs 其他堆

| 类型 | 优势 | 劣势 |
|---|---|---|
| 二叉堆 | 简单, O(log n) | 堆顶操作 |
| 二项堆 | 合并 O(log n) | 实现复杂 |
| 斐波那契堆 | 摊还 O(1) decrease-key | 实现极复杂 |

工业中, Java 的 PriorityQueue 默认是小根堆 (用二叉堆实现).

### 6.1 LeetCode 622 - 设计循环队列

```python
class MyCircularQueue:
    def __init__(self, k):
        self.q = [0] * k
        self.front = self.rear = -1
        self.size = 0
        self.cap = k

    def enQueue(self, val):
        if self.isFull(): return False
        if self.isEmpty(): self.front = 0
        self.rear = (self.rear + 1) % self.cap
        self.q[self.rear] = val
        self.size += 1
        return True

    def deQueue(self):
        if self.isEmpty(): return False
        if self.front == self.rear:
            self.front = self.rear = -1
        else:
            self.front = (self.front + 1) % self.cap
        self.size -= 1
        return True

    def Front(self):
        return -1 if self.isEmpty() else self.q[self.front]

    def Rear(self):
        return -1 if self.isEmpty() else self.q[self.rear]

    def isEmpty(self):
        return self.size == 0

    def isFull(self):
        return self.size == self.cap
```

```python
class MedianFinder:
    def __init__(self):
        self.max_heap = []
        self.min_heap = []

    def addNum(self, num):
        if not self.max_heap or num <= -self.max_heap[0]:
            heapq.heappush(self.max_heap, -num)
        else:
            heapq.heappush(self.min_heap, num)
        self._balance()

    def _balance(self):
        if len(self.max_heap) > len(self.min_heap) + 1:
            heapq.heappush(self.min_heap, -heapq.heappop(self.max_heap))
        elif len(self.max_heap) < len(self.min_heap):
            heapq.heappush(self.max_heap, -heapq.heappop(self.min_heap))

    def findMedian(self):
        if len(self.max_heap) > len(self.min_heap):
            return -self.max_heap[0]
        return (-self.max_heap[0] + self.min_heap[0]) / 2
```

### 6.12 LeetCode 1675 - 数组的最小偏移量

```python
def minimumDeviation(nums):
    import heapq
    # 转化为最大堆
    heap = []
    for x in nums:
        heap.append(-(x if x % 2 == 0 else x * 2))
    heapq.heapify(heap)

    min_dev = float('inf')
    max_val = -heap[0]
    while True:
        cur = -heapq.heappop(heap)
        min_dev = min(min_dev, cur - max_val)
        if cur % 2 == 0:
            max_val = max(max_val, cur // 2)
            heapq.heappush(heap, -(cur // 2))
        else:
            break

    return min_dev
```

```python
def getOrder(tasks):
    import heapq
    indexed = sorted([(t[0], t[1], i) for i, t in enumerate(tasks)])
    res = []
    time = 0
    i = 0
    pq = []

    while i < len(tasks) or pq:
        while i < len(tasks) and indexed[i][0] <= time:
            heapq.heappush(pq, (indexed[i][1], indexed[i][2]))
```

## 7. 复杂度分析

### 7.1 队列复杂度

| 操作 | 时间 |
|---|---|
| 入队 | O(1) |
| 出队 | O(1) |
| 队首 | O(1) |
| 判空 | O(1) |

### 7.2 优先队列复杂度 (堆实现)

| 操作 | 时间 |
|---|---|
| push | O(log n) |
| pop | O(log n) |
| peek | O(1) |
| heapify | O(n) |

### 7.3 严格推导

建堆时间 O(n):
- 大多数节点在底层
- sift_down 复杂度 O(h - level)
- 总: sum 2^k (h-k) = O(2^h) = O(n)

插入 / 删除 O(log n):
- 树高 h = log n
- sift_up / sift_down 都是 O(h)

## 8. 易错点

### 8.1 Python list 当队列

```python
# list.pop(0) 是 O(n)
q = []
q.append(x)
q.pop(0)

# 用 deque
from collections import deque
q = deque()
q.append(x)
q.popleft()    # O(1)
```

### 8.2 heapq 是最小堆

```python
# 直接用做最大堆会错
import heapq
heap = []
heapq.heappush(heap, 5)
heapq.heappop(heap)    # 返回 5, 不是最大!

# 取负实现最大堆
heapq.heappush(heap, -5)
heapq.heappop(heap)
val = -heapq.heappop(heap)
```

### 8.3 heapify 后不能直接用 heap[0] 排序

heap 是堆序, 不是完全排序. heap[0] 是最小, 但其他不一定有序.

### 8.4 heapreplace 和 heappushpop 的区别

- heapreplace: 先 pop, 再 push (返回旧堆顶)
- heappushpop: 先 push, 再 pop (返回新堆顶)

### 8.5 队列空判断

```python
# 直接访问空队列会 IndexError
def front(q):
    return q[0] if q else None
```

### 10.4 Dijkstra 算法

```python
import heapq

def dijkstra(graph, start):
    dist = {start: 0}
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist.get(u, float('inf')): continue
        for v, w in graph[u]:
            nd = d + w
            if nd < dist.get(v, float('inf')):
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist
```

### 10.5 Prim 算法 (最小生成树)

```python
def prim(graph, n):
    import heapq
    visited = [False] * n
    mst_weight = 0
    pq = [(0, 0)]
    while pq:
        w, u = heapq.heappop(pq)
        if visited[u]: continue
        visited[u] = True
        mst_weight += w
        for v, weight in graph[u]:
            if not visited[v]:
                heapq.heappush(pq, (weight, v))
    return mst_weight
```

### 10.6 A* 算法

```python
def astar(graph, start, end, heuristic):
    import heapq
    open_set = [(0, start)]
    g_score = {start: 0}
    while open_set:
        _, current = heapq.heappop(open_set)
        if current == end: return reconstruct_path()
        for neighbor, cost in graph[current]:
            tentative_g = g_score[current] + cost
            if tentative_g < g_score.get(neighbor, float('inf')):
                g_score[neighbor] = tentative_g
                f = tentative_g + heuristic(neighbor, end)
                heapq.heappush(open_set, (f, neighbor))
```

```python
def heap_sort(nums):
    n = len(nums)
    for i in range(n // 2 - 1, -1, -1):
        sift_down(nums, i, n)

        if r < n and arr[r] > arr[largest]: largest = r

        arr[i], arr[largest] = arr[largest], arr[i]
```

```python
def findTheWinner(n, k):
```

### 14.4 LeetCode 641 - 设计循环双端队列

```python
class MyCircularDeque:
    def __init__(self, k):
        self.q = [0] * k
        self.front = 0
        self.rear = k - 1
        self.size = 0
        self.cap = k

    def insertFront(self, val):
        if self.isFull(): return False
        self.front = (self.front - 1) % self.cap
        self.q[self.front] = val
        self.size += 1
        return True

    def insertLast(self, val):
        if self.isFull(): return False
        self.rear = (self.rear + 1) % self.cap
        self.q[self.rear] = val
        self.size += 1
        return True

    def deleteFront(self):
        if self.isEmpty(): return False
        self.front = (self.front + 1) % self.cap
        self.size -= 1
        return True

    def deleteLast(self):
        if self.isEmpty(): return False
        self.rear = (self.rear - 1) % self.cap
        self.size -= 1
        return True

    def getFront(self):
        return -1 if self.isEmpty() else self.q[self.front]

    def getRear(self):
        return -1 if self.isEmpty() else self.q[self.rear]

    def isEmpty(self):
        return self.size == 0

    def isFull(self):
```

```python
class FrontMiddleBackQueue:
    def __init__(self):
        from collections import deque
        self.q = deque()

    def pushFront(self, val):
        self.q.appendleft(val)
        self._rebalance()

    def pushMiddle(self, val):
        mid = len(self.q) // 2
        self.q.insert(mid, val)
        self._rebalance()

    def pushBack(self, val):
        self.q.append(val)
        self._rebalance()

    def popFront(self):
        if not self.q: return -1
        val = self.q.popleft()
        return val

    def popMiddle(self):
        if not self.q: return -1
        mid = (len(self.q) - 1) // 2
        val = self.q[mid]
        del self.q[mid]
        return val

    def popBack(self):
        if not self.q: return -1
        return self.q.pop()

    def _rebalance(self):
```

## 29. 附录: 堆的常见误区

### 29.1 堆不是排序的

### 29.2 heapq 是最小堆

### 31.1 用堆实现优先队列 (完整版)

```python
class PriorityQueue:
    def __init__(self, comparator=None):
        import heapq
        self.heap = []
        self.comparator = comparator or (lambda a, b: a < b)

    def push(self, item):
        # 反转以支持最大堆
        import heapq
        heapq.heappush(self.heap, item)

    def pop(self):
        import heapq
        if not self.heap: raise IndexError("Empty")
        return heapq.heappop(self.heap)

    def peek(self):
        return self.heap[0] if self.heap else None

    def __len__(self):
        return len(self.heap)

    def __bool__(self):
        return bool(self.heap)
```

### 31.2 用队列实现 BFS 模板

```python
from collections import deque

def bfs(graph, start):
    visited = {start}
    queue = deque([start])
    order = []

    while queue:
        node = queue.popleft()
        order.append(node)
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

    return order
```

### 31.3 用堆实现 Dijkstra 模板

```python
import heapq

def dijkstra(graph, start, n):
    dist = [float('inf')] * n
    dist[start] = 0
    pq = [(0, start)]

    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]: continue
        for v, w in graph[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))

    return dist
```
