## 1. BFS 的定义

BFS (Breadth First Search) 是按层遍历. 一层一层向外扩展.

```text
        1
       / \
      2   3
     / \ / \
    4   5   6

BFS 顺序: 1 → (2, 3) → (4, 5, 6)
```

---

## 2. BFS 的实现

```python
from collections import deque

def bfs(graph, start):
    visited = {start}
    queue = deque([start])
    res = []

    while queue:
        node = queue.popleft()
        res.append(node)
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

    return res
```

C++:
```cpp
std::queue<int> q;
q.push(start);
std::unordered_set<int> visited;
```

Java:
```java
Queue<Integer> q = new LinkedList<>();
q.offer(start);
Set<Integer> visited = new HashSet<>();
```

## 3. 树的层次遍历 (BFS)

```python
from collections import deque

def levelOrder(root):
    if not root: return []
    res = []
    queue = deque([root])
    while queue:
        level = []
        for _ in range(len(queue)):
            node = queue.popleft()
            level.append(node.val)
            if node.left: queue.append(node.left)
            if node.right: queue.append(node.right)
        res.append(level)
    return res
```

变种:
- 锯齿形层次遍历: 之字形
- 自底向上层次遍历: 反转
- 每层从右到左: 反序入队

## 4. 最短路径 (无权图)

BFS 在无权图中求**最短路**.

```python
def shortest_path(graph, start, end):
    from collections import deque
    visited = {start: 0}
    queue = deque([(start, 0)])

    while queue:
        node, dist = queue.popleft()
        if node == end: return dist
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited[neighbor] = dist + 1
                queue.append((neighbor, dist + 1))
    return -1
```

应用: LeetCode 1091 (二进制矩阵最短路), 752 (打开转盘锁).

## 5. 双向 BFS

双向 BFS 同时从起点和终点扩展, 直到相遇. 比单向快.

```python
def bidirectional_bfs(graph, start, end):
    from collections import deque
    if start == end: return 0

    front_visited = {start: 0}
    back_visited = {end: 0}
    front_queue = deque([start])
    back_queue = deque([end])

    steps = 0
    while front_queue and back_queue:
        steps += 1
        # 扩展 front
        next_front = deque()
        for _ in range(len(front_queue)):
            node = front_queue.popleft()
            for neighbor in graph[node]:
                if neighbor in back_visited:
                    return steps + back_visited[neighbor]
                if neighbor not in front_visited:
                    front_visited[neighbor] = steps
                    next_front.append(neighbor)
        front_queue = next_front

        # 类似地扩展 back

    return -1
```

应用: LeetCode 127 (单词接龙).

## 6. 拓扑排序 (BFS 版)

Kahn 算法: 入度为 0 的入队, 出队后减邻居入度.

```python
from collections import deque

def topological_sort(n, edges):
    in_degree = [0] * n
    graph = [[] for _ in range(n)]

    for u, v in edges:
        graph[u].append(v)
        in_degree[v] += 1

    queue = deque([i for i in range(n) if in_degree[i] == 0])
    order = []

    while queue:
        u = queue.popleft()
        order.append(u)
        for v in graph[u]:
            in_degree[v] -= 1
            if in_degree[v] == 0:
                queue.append(v)

    return order if len(order) == n else []
```

应用: LeetCode 207 (课程表), 210 (课程表 II).

### 7.1 岛屿最短路 (LeetCode 1091)

```python
def shortestPathBinaryMatrix(grid):
    from collections import deque
    n = len(grid)
    if grid[0][0] != 0 or grid[n-1][n-1] != 0: return -1

    queue = deque([(0, 0, 1)])
    grid[0][0] = 1    # 标记

    while queue:
        i, j, d = queue.popleft()
        if i == n-1 and j == n-1: return d
        for di in (-1, 0, 1):
            for dj in (-1, 0, 1):
                ni, nj = i + di, j + dj
                if 0 <= ni < n and 0 <= nj < n and grid[ni][nj] == 0:
                    grid[ni][nj] = 1
                    queue.append((ni, nj, d + 1))

    return -1
```

### 7.2 打开转盘锁 (LeetCode 752)

```python
def openLock(deadends, target):
    from collections import deque
    dead = set(deadends)
    if '0000' in dead: return -1

    def neighbors(s):
        for i in range(4):
            digit = int(s[i])
            for d in (-1, 1):
                new_digit = (digit + d) % 10
                yield s[:i] + str(new_digit) + s[i+1:]

    queue = deque([('0000', 0)])
    visited = {'0000'}

    while queue:
        s, steps = queue.popleft()
        if s == target: return steps
        for ns in neighbors(s):
            if ns not in visited and ns not in dead:
                visited.add(ns)
                queue.append((ns, steps + 1))

    return -1
```

### 7.3 单词接龙 (LeetCode 127, Hard, 双向 BFS)

```python
def ladderLength(beginWord, endWord, wordList):
    from collections import deque
    word_set = set(wordList)
    if endWord not in word_set: return 0

    def neighbors(word):
        for i in range(len(word)):
            for c in 'abcdefghijklmnopqrstuvwxyz':
                if c != word[i]:
                    yield word[:i] + c + word[i+1:]

    begin_set = {beginWord}
    end_set = {endWord}
    visited = {beginWord, endWord}
    steps = 1

    while begin_set and end_set:
        if len(begin_set) > len(end_set):
            begin_set, end_set = end_set, begin_set

        next_set = set()
        for word in begin_set:
            for ns in neighbors(word):
                if ns in end_set:
                    return steps + 1
                if ns in word_set and ns not in visited:
                    visited.add(ns)
                    next_set.add(ns)

        begin_set = next_set
        steps += 1

    return 0
```

### 7.4 课程表 (LeetCode 207)

```python
def canFinish(numCourses, prerequisites):
    from collections import deque
    in_degree = [0] * numCourses
    graph = [[] for _ in range(numCourses)]

    for u, v in prerequisites:
        graph[v].append(u)
        in_degree[u] += 1

    queue = deque([i for i in range(numCourses) if in_degree[i] == 0])
    count = 0

    while queue:
        u = queue.popleft()
        count += 1
        for v in graph[u]:
            in_degree[v] -= 1
            if in_degree[v] == 0:
                queue.append(v)

    return count == numCourses
```

### 7.6 锯齿形层次遍历 (LeetCode 103)

```python
def zigzagLevelOrder(root):
    from collections import deque
    if not root: return []
    res = []
    queue = deque([root])
    reverse = False

    while queue:
        level = []
        for _ in range(len(queue)):
            node = queue.popleft()
            level.append(node.val)
            if node.left: queue.append(node.left)
            if node.right: queue.append(node.right)
        if reverse:
            level.reverse()
        res.append(level)
        reverse = not reverse

    return res
```

### 7.7 二叉树的层平均值 (LeetCode 637)

```python
def averageOfLevels(root):
    from collections import deque
    if not root: return []
    res = []
    queue = deque([root])
    while queue:
        level_sum = 0
        count = len(queue)
        for _ in range(count):
            node = queue.popleft()
            level_sum += node.val
            if node.left: queue.append(node.left)
            if node.right: queue.append(node.right)
        res.append(level_sum / count)
    return res
```

### 7.9 完全平方数 (LeetCode 279, BFS)

```python
def numSquares(n):
    from collections import deque
    squares = [i*i for i in range(1, int(n**0.5) + 1)]
    queue = deque([(n, 0)])
    visited = {n}

    while queue:
        cur, steps = queue.popleft()
        for sq in squares:
            if cur == sq: return steps + 1
            nxt = cur - sq
            if nxt < 0: break
            if nxt not in visited:
                visited.add(nxt)
                queue.append((nxt, steps + 1))

    return -1
```

### 7.10 单词搜索 (BFS 版)

```python
def exist_bfs(board, word):
    from collections import deque
    m, n = len(board), len(board[0])

    def bfs(i, j):
        queue = deque([(i, j, 0)])
        while queue:
            x, y, k = queue.popleft()
            if k == len(word) - 1: return True
            for dx, dy in ((-1, 0), (1, 0), (0, -1), (0, 1)):
                nx, ny = x + dx, y + dy
                if 0 <= nx < m and 0 <= ny < n and board[nx][ny] == word[k+1]:
                    queue.append((nx, ny, k+1))
        return False

    for i in range(m):
        for j in range(n):
            if board[i][j] == word[0]:
                if bfs(i, j): return True
    return False
```

## 8. 复杂度分析

### 8.1 时间复杂度

| 数据结构 | 复杂度 |
|---|---|
| 树 | O(n) |
| 图 (邻接表) | O(V + E) |
| 图 (邻接矩阵) | O(V^2) |
| 网格 | O(m * n) |

### 8.2 空间复杂度

O(V) - 队列 + visited.

### 8.3 BFS vs DFS

| | BFS | DFS |
|---|---|---|
| 数据结构 | 队列 | 栈 / 递归 |
| 适用 | 最短路 | 路径存在 |
| 顺序 | 层次 | 深度 |

### 8.4 双向 BFS

时间从 O(b^d) 降到 O(b^(d/2)), b 是分支因子, d 是深度.

## 9. 易错点

### 9.1 忘记标记

```python
# 没标记, 可能入队多次
def bfs(graph, start):
    queue = deque([start])
    while queue:
        node = queue.popleft()
        for neighbor in graph[node]:
            queue.append(neighbor)    # 邻居可能重复入队
```

### 9.2 边界

```python
# 没检查边界
def shortestPath(grid):
    queue = deque([(0, 0)])
    while queue:
        i, j = queue.popleft()
        # 访问 grid[i][j] 时, i 和 j 可能越界
```

### 9.3 BFS 的入队时机

```python
# 入队时标记 (推荐)
def bfs(graph, start):
    visited = {start}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)    # 立即标记
                queue.append(neighbor)
```

### 9.4 多源 BFS

```python
# 多源 BFS: 把多个起点同时入队
def multi_source_bfs(graph, sources):
    from collections import deque
    visited = set(sources)
    queue = deque(sources)
    while queue:
        node = queue.popleft()
        # 处理
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
```
