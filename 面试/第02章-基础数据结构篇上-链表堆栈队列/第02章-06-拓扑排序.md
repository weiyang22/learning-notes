## 1. 偏序与全序

### 1.1 偏序

偏序关系: 自反、反对称、传递.
例: "a ≤ b" 是偏序, 但不一定 "a ≤ b" 或 "b ≤ a".

### 1.2 全序

全序: 偏序 + 任意两个元素都可比较.
例: 实数 "≤".

### 1.3 拓扑排序

**拓扑排序**: 给 DAG (有向无环图) 一个**线性**的顺序, 使得所有边 (u → v) 满足 u 在 v 之前.

这就是把偏序扩展为全序的过程.

---

## 2. DAG 与拓扑排序

### 2.1 DAG 定义

**有向无环图 (DAG - Directed Acyclic Graph)**: 没有环的有向图.

### 2.2 拓扑排序存在性

**定理**: 一个有向图有拓扑排序 **当且仅当** 它是 DAG.

- DAG ⇒ 有拓扑排序
- 有拓扑排序 ⇒ 无环 ⇒ DAG

### 2.3 应用

- 课程表 (先修关系)
- 编译依赖 (A 依赖 B, B 必须在 A 之前编译)
- 任务调度
- 关键路径
- 偏序扩展为全序

## 3. Kahn 算法 (BFS 版)

### 3.1 思想

1. 计算所有节点的入度
2. 把入度为 0 的节点入队
3. 出队, 加入拓扑序列
4. 邻居入度减 1, 如果变成 0 就入队
5. 直到队列空

### 3.2 实现

```python
from collections import deque

def topological_sort(n, edges):
    """edges: [(u, v), ...] 表示 u -> v"""
    in_degree = [0] * n
    graph = [[] for _ in range(n)]

    for u, v in edges:
        graph[u].append(v)
        in_degree[v] += 1

    queue = deque([i for i in range(n) if in_degree[i] == 0])
    order = []

    while queue:
        u = queue.popleft()
        order.append(u)
        for v in graph[u]:
            in_degree[v] -= 1
            if in_degree[v] == 0:
                queue.append(v)

    if len(order) == n:
        return order
    return []    # 有环
```

### 3.3 复杂度

- 时间: O(V + E)
- 空间: O(V)

### 3.4 唯一性

拓扑排序**不一定唯一**. Kahn 算法产生的顺序取决于入度为 0 的出队顺序.


## 补充章节 1

拓扑排序是 DAG 上的核心操作. 它的两种主要算法是 Kahn (BFS) 和 DFS 后序反转.

拓扑排序在工程中有广泛应用: 课程表、编译依赖、任务调度、Makefile 构建等.

Kahn 算法的本质是: 每次选一个入度为 0 的节点. 这相当于"按偏序的极小元"来扩展.

DFS 后序反转的原理是: 在 DAG 上做 DFS, 后序遍历的逆序就是拓扑序. 这是因为后序意味着所有子节点都已访问过.

拓扑排序的两个算法各有优劣. Kahn 适合检测环, 因为如果最后没访问完所有节点, 就有环. DFS 更简洁, 但难以检测环.

## 4. DFS 后序反转

### 4.1 思想

对 DAG 做 DFS, 节点的后序遍历顺序的**逆序**就是拓扑序.

### 4.2 原因

DFS 访问完所有子节点才返回, 所以后序遍历时, 子节点都在父节点之前. 反转后, 父节点在子节点之前, 满足拓扑序.

### 4.3 实现

```python
def topological_sort_dfs(n, edges):
    graph = [[] for _ in range(n)]
    for u, v in edges:
        graph[u].append(v)

    visited = [False] * n
    on_stack = [False] * n
    order = []
    has_cycle = [False]

    def dfs(u):
        if on_stack[u]:
            has_cycle[0] = True
            return
        if visited[u]:
            return
        visited[u] = True
        on_stack[u] = True
        for v in graph[u]:
            dfs(v)
        on_stack[u] = False
        order.append(u)

    for i in range(n):
        if not visited[i]:
            dfs(i)

    if has_cycle[0]:
        return []
    return order[::-1]
```

### 4.4 检测环

后序反转 vs Kahn 的环检测:
- Kahn: 检查 order 长度是否等于 n
- DFS: 检查是否有节点在 on_stack 中再次访问

## 5. 检测环

### 5.1 Kahn 算法

```python
def has_cycle(n, edges):
    in_degree = [0] * n
    graph = [[] for _ in range(n)]
    for u, v in edges:
        graph[u].append(v)
        in_degree[v] += 1

    queue = deque([i for i in range(n) if in_degree[i] == 0])
    count = 0
    while queue:
        u = queue.popleft()
        count += 1
        for v in graph[u]:
            in_degree[v] -= 1
            if in_degree[v] == 0:
                queue.append(v)
    return count != n
```

```python
def has_cycle_dfs(n, edges):
    graph = [[] for _ in range(n)]
    for u, v in edges:
        graph[u].append(v)

    WHITE, GRAY, BLACK = 0, 1, 2
    color = [WHITE] * n

    def dfs(u):
        if color[u] == GRAY:    # 后向边 → 环
            return True
        if color[u] == BLACK:
            return False
        color[u] = GRAY
        for v in graph[u]:
            if dfs(v): return True
        color[u] = BLACK
        return False

    for i in range(n):
        if color[i] == WHITE:
            if dfs(i): return True
    return False
```

## 7. 拓扑排序变种

### 7.1 最小高度树 (LeetCode 310)

```python
def findMinHeightTrees(n, edges):
    """找根节点, 使树的高度最小"""
    if n == 1: return [0]
    from collections import defaultdict
    graph = defaultdict(set)
    for u, v in edges:
        graph[u].add(v)
        graph[v].add(u)

    leaves = [i for i in range(n) if len(graph[i]) <= 1]

    while n > 2:
        n -= len(leaves)
        new_leaves = []
        for leaf in leaves:
            neighbor = graph[leaf].pop()
            graph[neighbor].remove(leaf)
            if len(graph[neighbor]) == 1:
                new_leaves.append(neighbor)
        leaves = new_leaves

    return leaves
```

### 7.2 序列重建 (LeetCode 444)

```python
def sequenceReconstruction(org, seqs):
    """判断 org 是否是 seqs 的唯一拓扑序"""
    from collections import defaultdict, deque
    n = len(org)
    graph = defaultdict(list)
    in_degree = defaultdict(int)

    for seq in seqs:
        for x in seq:
            in_degree[x] = 0    # 初始化

    for seq in seqs:
        for i in range(len(seq) - 1):
            u, v = seq[i], seq[i+1]
            graph[u].append(v)
            in_degree[v] += 1

    queue = deque([i for i in in_degree if in_degree[i] == 0])
    res = []

    while queue:
        if len(queue) > 1: return False    # 不唯一
        u = queue.popleft()
        res.append(u)
        for v in graph[u]:
            in_degree[v] -= 1
            if in_degree[v] == 0:
                queue.append(v)

    return res == org and len(res) == n
```

            return ""
        for j in range(min_len):
            if w1[j] != w2[j]:
                if w2[j] not in graph[w1[j]]:
                    graph[w1[j]].add(w2[j])
                    in_degree[w2[j]] += 1
                break

    queue = deque([c for c in in_degree if in_degree[c] == 0])
    res = []

    while queue:
        c = queue.popleft()
        res.append(c)
        for nb in graph[c]:
            in_degree[nb] -= 1
            if in_degree[nb] == 0:
                queue.append(nb)

    return ''.join(res) if len(res) == len(in_degree) else ""
```

def scheduleCourse(courses):
    """最多能上多少门课"""
    import heapq
    courses.sort(key=lambda x: x[1])    # 按截止时间排序
    total = 0
    heap = []    # 最大堆, 存已选课程的时长

    for dur, lastDay in courses:
        if total + dur <= lastDay:
            total += dur
            heapq.heappush(heap, -dur)
        elif heap and -heap[0] > dur:
            total += dur - (-heapq.heappop(heap))
            heapq.heappush(heap, -dur)

    return len(heap)

def eventualSafeNodes(graph):
    """出度为 0 的节点是安全的"""
    from collections import defaultdict, deque

    n = len(graph)
    out_degree = [len(graph[i]) for i in range(n)]
    reverse_graph = defaultdict(list)

    for i in range(n):
        for j in graph[i]:
            reverse_graph[j].append(i)

    queue = deque([i for i in range(n) if out_degree[i] == 0])
    safe = [False] * n

    while queue:
        u = queue.popleft()
        safe[u] = True
        for v in reverse_graph[u]:
            out_degree[v] -= 1
            if out_degree[v] == 0:
                queue.append(v)

    return [i for i in range(n) if safe[i]]
```

```python
def leadsToDestination(n, edges, source, destination):
    """从 source 到 destination 是否可达 (路径必须以 destination 结尾)"""
    from collections import defaultdict
    graph = defaultdict(list)
    for u, v in edges:
        graph[u].append(v)

    WHITE, GRAY, BLACK = 0, 1, 2
    color = [WHITE] * n

    def dfs(u):
        if u == destination:
            # 如果是 destination, 必须没有出边
            return len(graph[u]) == 0
        if color[u] == GRAY: return False
        if color[u] == BLACK: return True
        color[u] = GRAY
        for v in graph[u]:
            if not dfs(v): return False
        color[u] = BLACK
        return True

    return dfs(source)
```

```python
def isPrintable(targetGrid):
    """奇怪的打印机"""
    from collections import defaultdict, deque

    m, n = len(targetGrid), len(targetGrid[0])
    colors = set()
    for row in targetGrid:
        colors.update(row)

    # 找每个颜色的边界
    rect = {}
    for c in colors:
        rect[c] = [m, n, 0, 0]    # top, left, bottom, right

    for i in range(m):
        for j in range(n):
            c = targetGrid[i][j]
            rect[c][0] = min(rect[c][0], i)
            rect[c][1] = min(rect[c][1], j)
            rect[c][2] = max(rect[c][2], i)
            rect[c][3] = max(rect[c][3], j)

    # 检查是否每个颜色的矩形都被其他颜色包围
    graph = defaultdict(set)
    in_degree = {c: 0 for c in colors}

    for c1 in colors:
        for c2 in colors:
            if c1 == c2: continue
            r1 = rect[c1]
            r2 = rect[c2]
            # c1 的矩形是否被 c2 包含
            if r1[0] >= r2[0] and r1[1] >= r2[1] and r1[2] <= r2[2] and r1[3] <= r2[3]:
                graph[c1].add(c2)

    for u in graph:
        for v in graph[u]:
            in_degree[v] += 1

    queue = deque([c for c in colors if in_degree[c] == 0])
    visited = set(queue)

    while queue:
        u = queue.popleft()
        for v in graph[u]:
            if v in visited: continue
            in_degree[v] -= 1
            if in_degree[v] == 0:
                queue.append(v)
                visited.add(v)

    return len(visited) == len(colors)
```
