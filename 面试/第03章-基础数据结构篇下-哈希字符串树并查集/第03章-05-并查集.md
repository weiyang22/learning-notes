# 03.05 并查集 (Union-Find)

> **本节定位**: 处理"动态连通性"的利器
> **对应 03 章 Day 13-14**
> **核心**: 几乎 $O(1)$ 的合并/查找
> **复杂度**: $O(\alpha(n))$ 反阿克曼, 实际 ≤ 5
> **应用**: 连通性、环检测、最小生成树 (Kruskal)、离线 LCA、食物链、账户合并
> **多解法对比**: vs BFS/DFS (静态连通)、vs Tarjan (离线 LCA)、vs Floyd (全对最短路)

---

## 1. 并查集是什么

### 1.1 定义

**并查集 (Disjoint Set Union, DSU; Union-Find)** 处理**不相交集合**的合并与查询。

**两种核心操作**:
- `find(x)`: 找 x 所在集合的根 (代表元素)。
- `union(x, y)`: 把 x 和 y 所在的集合合并。

**可选附加信息**:
- `count`: 当前集合的数量 (连通分量数)。
- `rank` / `size`: 树的深度/大小估计, 用于按秩合并。
- `dist[x]`: x 到根的距离 (带权并查集)。

### 1.2 应用场景分类

| 场景 | 推荐使用 UF |
| :--- | :--- |
| 静态连通性 (一次性查询) | 可选, BFS/DFS 也行 |
| **动态连通性** (边逐步加入) | ★ 必须 |
| 连通分量数 | ★ 简洁 |
| 环检测 (加边时) | ★ 经典 |
| 最小生成树 (Kruskal) | ★ 必备 |
| 离线 LCA (Tarjan) | ★ 必备 |
| 二分图判定 | 可选 |
| 带约束的合并 (如食物链) | 带权 UF |

## 2. 通用模板 (★ 必背)

### 2.1 标准实现

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n  # 或 size
        self.count = n      # 集合数量

    def find(self, x):
        """路径压缩"""
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        """按秩合并"""
        px, py = self.find(x), self.find(y)
        if px == py: return False  # 已连通
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        self.count -= 1
        return True

    def connected(self, x, y):
        return self.find(x) == self.find(y)
```

**复杂度**:
- find: $O(\alpha(n))$ (α 是反阿克曼函数, 几乎 ≤ 5)
- union: $O(\alpha(n))$
- 实际可视为 $O(1)$

### 2.2 迭代 find (避免递归深度限制)

```python
def find(self, x):
    """迭代式路径压缩"""
    root = x
    while self.parent[root] != root:
        root = self.parent[root]
    # 二次扫描压缩
    while self.parent[x] != root:
        self.parent[x], x = root, self.parent[x]
    return root
```

### 2.3 按大小合并版 (替代 rank)

```python
class UnionFindSize:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n
        self.count = n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]  # 路径减半
            x = self.parent[x]
        return x

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py: return False
        if self.size[px] < self.size[py]:
            px, py = py, px
        self.parent[py] = px
        self.size[px] += self.size[py]
        self.count -= 1
        return True
```

**注意**: 路径压缩 + 路径减半 (path halving) 在工业实现中更常见, 比完全路径压缩略快。

## 3. 路径压缩 vs 按秩合并

### 3.1 路径压缩

**目的**: 让树变扁, 后续 find 更快。

**递归版**:
```python
def find(self, x):
    if self.parent[x] != x:
        self.parent[x] = self.find(self.parent[x])  # 递归压缩
    return self.parent[x]
```

**迭代版**:
```python
def find(self, x):
    root = x
    while self.parent[root] != root:
        root = self.parent[root]
    while self.parent[x] != root:
        nxt = self.parent[x]
        self.parent[x] = root
        x = nxt
    return root
```

**路径减半 (path halving)**:
```python
def find(self, x):
    while self.parent[x] != x:
        self.parent[x] = self.parent[self.parent[x]]  # 祖父当父
        x = self.parent[x]
    return x
```

**路径分裂 (path splitting)**:
```python
def find(self, x):
    while self.parent[x] != x:
        self.parent[x], x = self.parent[self.parent[x]], self.parent[x]
    return x
```

### 3.2 按秩合并

**目的**: 避免树变高。

**按树高 (rank)**:
```python
def union(self, x, y):
    px, py = self.find(x), self.find(y)
    if px == py: return False
    if self.rank[px] < self.rank[py]:
        px, py = py, px
    self.parent[py] = px
    if self.rank[px] == self.rank[py]:
        self.rank[px] += 1
```

**按大小 (size)**:
```python
def union(self, x, y):
    px, py = self.find(x), self.find(y)
    if px == py: return False
    if self.size[px] < self.size[py]:
        px, py = py, px
    self.parent[py] = px
    self.size[px] += self.size[py]
```

**两者等价**: rank 是树高的上界, size 是节点数。Size 略容易调试, Rank 更"原汁原味"。

### 3.3 复杂度证明 (★ 关键)

**结论**: 单次操作摊还复杂度 $O(\alpha(n))$, 其中 $\alpha$ 是反阿克曼函数, $\alpha(n) \le 5$ (对于 $n$ 在宇宙原子数以内)。

**直觉**:
- 没有路径压缩: 按秩合并 → 树高 $O(\log n)$, 单次 find $O(\log n)$。
- 只有路径压缩: 树高可能 $O(n)$, 但经过多次 find 后摊还 $O(\log n)$。
- 两者结合: 几乎 $O(1)$。

**严格的证明** (Tarjan 1975):
- 节点按"秩"分为 $\log^* n$ 层 (迭代对数)。
- 路径压缩把节点提升到更高层。
- 推导出 $O(\alpha(n))$。

## 4. 并查集的应用

### 4.1 适用场景总结

- **连通性**: 两个节点是否在同一集合。
- **连通分量数**: 集合的数量。
- **环检测**: 加边时是否成环。
- **最小生成树**: Kruskal 算法。
- **最短路径**: Dijkstra + 并查集优化 (Johnson's)。
- **离线 LCA**: Tarjan 算法。
- **带权合并**: 食物链、关系推导。
- **二分图**: 维护奇偶。
- **排列交换**: 情侣牵手。

### 4.2 与 BFS/DFS 的选择

| 场景 | 推荐 | 原因 |
| :--- | :--- | :--- |
| 静态连通性 (一次性查询) | DFS/BFS | 代码简单 |
| **动态连通性** (边逐步加入) | **并查集** | 增量更新 $O(1)$ |
| 需要输出连通分量数 | 都行 | 并查集直接读 count |
| 多次查询两点是否连通 | 并查集 | 增量快 |
| 需要输出连通图具体内容 | DFS/BFS | 遍历自然 |
| 大规模节点 ($n \ge 10^5$) | 并查集 | 内存与常数小 |

### 4.3 与其他算法的关系

| 任务 | 算法 | 选择 |
| :--- | :--- | :--- |
| 最短路径 (单源) | Dijkstra | $O(m \log n)$ |
| 最短路径 (全对) | Floyd | $O(n^3)$ |
| 最小生成树 | Kruskal + UF | $O(m \log n)$ |
| 最小生成树 | Prim + 堆 | $O(m \log n)$ |
| 连通分量 | BFS / DFS / UF | 看场景 |
| LCA (单查询) | 递归 | $O(h)$ |
| LCA (多查询) | Tarjan (离线 UF) / 倍增 | 离线用 Tarjan |

## 5. 实战题解 (LeetCode 14 道)

### 5.1 LeetCode 547 - 省份数量 (Medium)

**题目**: n 个城市, isConnected[i][j]=1 表示相连. 求省份数 (连通分量数)。

```python
def findCircleNum(isConnected):
    n = len(isConnected)
    uf = UnionFind(n)
    for i in range(n):
        for j in range(i + 1, n):
            if isConnected[i][j]:
                uf.union(i, j)
    return uf.count
```

**多解法**:
```python
# BFS 版
def findCircleNum_bfs(isConnected):
    n = len(isConnected)
    visited = [False] * n
    cnt = 0
    for i in range(n):
        if not visited[i]:
            cnt += 1
            queue = [i]
            visited[i] = True
            while queue:
                u = queue.pop()
                for v in range(n):
                    if isConnected[u][v] and not visited[v]:
                        visited[v] = True
                        queue.append(v)
    return cnt
```

### 5.2 LeetCode 200 - 岛屿数量 (Medium, Union-Find 版本)

详见 [06.04 - 高频题 38-50](../第06章-面试篇上-高频题1-50/第06章-04-高频题38-50.md)

**Union-Find 版**:
```python
def numIslands_uf(grid):
    if not grid: return 0
    m, n = len(grid), len(grid[0])
    uf = UnionFind(m * n)
    water = 0

    for i in range(m):
        for j in range(n):
            if grid[i][j] == '0':
                water += 1
                continue
            # 检查 4 邻居, 只看上左避免重复
            for di, dj in [(-1,0),(0,-1)]:
                ni, nj = i + di, j + dj
                if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] == '1':
                    uf.union(i*n + j, ni*n + nj)

    return uf.count - water
```

**多解法对比**:

| 方法 | 时间 | 空间 | 备注 |
| :--- | :--- | :--- | :--- |
| DFS | $O(mn)$ | $O(mn)$ | ★ 简洁, 改原数组 |
| BFS | $O(mn)$ | $O(\min(m,n))$ | 队列 |
| UF | $O(mn \cdot \alpha)$ | $O(mn)$ | 适合动态加岛屿 |

### 5.3 LeetCode 684 - 冗余连接 (Medium)

**题目**: 给一棵树加一条边, 找出哪条边加进去会形成环 (输出这条边)。

**思路**: 用并查集. 如果两个节点已经连通, 这条边就是冗余的。

```python
def findRedundantConnection(edges):
    n = len(edges)
    uf = UnionFind(n + 1)

    for u, v in edges:
        if not uf.union(u, v):
            return [u, v]  # 已连通, 这条边冗余

    return []
```

### 5.4 LeetCode 721 - 账户合并 (Medium)

```python
def accountsMerge(accounts):
    from collections import defaultdict

    uf = UnionFind(len(accounts))
    email_to_idx = {}  # email -> account index

    # 第一遍: 建立映射 + 合并同名账户
    for i, account in enumerate(accounts):
        for email in account[1:]:
            if email in email_to_idx:
                uf.union(i, email_to_idx[email])
            else:
                email_to_idx[email] = i

    # 第二遍: 按 root 分组
    groups = defaultdict(list)
    for email, idx in email_to_idx.items():
        root = uf.find(idx)
        groups[root].append(email)

    # 输出
    res = []
    for root, emails in groups.items():
        name = accounts[root][0]
        res.append([name] + sorted(emails))

    return res
```

### 5.5 LeetCode 765 - 情侣牵手 (Hard)

**题目**: 2N 个人坐在一排, 情侣必须相邻 (0 与 1, 2 与 3, ...)。给出当前排列, 求最少交换次数。

**关键观察**: 把每对情侣看成一个"节点", 座位按顺序相邻两个节点应该属于同一集合。

```python
def minSwapsCouples(row):
    n = len(row) // 2
    uf = UnionFind(n)
    for i in range(n):
        # 座位 2*i 和 2*i+1 应该属于同一对
        a, b = row[2*i] // 2, row[2*i+1] // 2
        uf.union(a, b)
    # 答案 = n - 连通分量数 (因为连通分量内的情侣已经配对好)
    return n - uf.count
```

**例**: `row = [0, 2, 1, 3]` → n = 2, 合并 (0, 1), 答案 = 2 - 1 = 1 次交换。

### 5.6 LeetCode 1319 - 连通网络的操作次数 (Medium)

**题目**: n 台电脑, connections 数组, 问最少几次操作 (重布线) 使所有电脑连通。

```python
def makeConnected(n, connections):
    # 至少需要 n-1 条线, 不够返回 -1
    if len(connections) < n - 1: return -1
    uf = UnionFind(n)
    for u, v in connections:
        uf.union(u, v)
    # 答案 = 连通分量数 - 1
    return uf.count - 1
```

### 5.7 LeetCode 1579 - 保证图可完全遍历 (Hard)

**题目**: Alice 和 Bob 各有一个无向图, 共用一些公共边 (类型 3) 和各自的边 (类型 1, 2)。删最少边使两人都能遍历所有节点。

```python
def maxNumEdgesToRemove(n, edges):
    a = UnionFind(n)
    b = UnionFind(n)
    used = 0

    # 公共边先加
    for t, u, v in edges:
        if t == 3:
            ua = a.union(u-1, v-1)
            ub = b.union(u-1, v-1)
            if ua or ub:  # 至少一条新合并
                used += 1

    # 各加各自的
    for t, u, v in edges:
        if t == 1 and a.union(u-1, v-1):
            used += 1
        elif t == 2 and b.union(u-1, v-1):
            used += 1

    # 两个图都要连通
    if a.count != 1 or b.count != 1:
        return -1
    return len(edges) - used
```

### 5.9 LeetCode 1202 - 交换字符串中的元素 (Medium)

**题目**: 给字符串和索引对数组, 可交换任意对的字符, 求字典序最小的字符串。

**思路**: 用 UF 把可交换的索引连成集合, 每组内字符排序后放回。

```python
def smallestStringWithSwaps(s, pairs):
    uf = UnionFind(len(s))
    for i, j in pairs:
        uf.union(i, j)

    # 按 root 分组
    from collections import defaultdict
    groups = defaultdict(list)
    for i in range(len(s)):
        groups[uf.find(i)].append(i)

    # 每组内字符排序, 放回
    res = list(s)
    for indices in groups.values():
        chars = sorted(res[i] for i in indices)
        for idx, c in zip(sorted(indices), chars):
            res[idx] = c
    return ''.join(res)
```

### 5.10 LeetCode 924 - 尽量减少恶意软件的传播 (Hard)

**题目**: 图中某些节点被感染, 每时刻感染传播到所有邻居。删一个初始未感染节点, 使最终感染节点最少。

```python
def minMalwareSpread(graph, initial):
    n = len(graph)
    uf = UnionFind(n)
    for i in range(n):
        for j in range(i+1, n):
            if graph[i][j]:
                uf.union(i, j)

    # 每个连通分量的节点数
    size = [0] * n
    for i in range(n):
        size[uf.find(i)] += 1

    # 每个连通分量包含多少初始感染节点
    infected = [0] * n
    for x in initial:
        infected[uf.find(x)] += 1

    # 答案: 只含 1 个初始感染的连通分量中, 最大的那个
    best, ans = -1, min(initial)
    for x in sorted(initial):
        r = uf.find(x)
        if infected[r] == 1 and size[r] > best:
            best, ans = size[r], x
    return ans
```

```python
def isBipartite(graph):
    """UF 版: 维护"颜色奇偶"信息"""
    n = len(graph)
    uf = UnionFind(n)

    def is_odd(x):
        # 简化版: 直接用两套并查集
        pass

    # 更简洁: 用 union-find with parity
    parent = list(range(n))
    parity = [0] * n  # 与根的奇偶关系

    def find(x):
        if parent[x] != x:
            root = find(parent[x])
            parity[x] ^= parity[parent[x]]
            parent[x] = root
        return parent[x]

    for u in range(n):
        for v in graph[u]:
            ru, rv = find(u), find(v)
            if ru == rv and parity[u] == parity[v]:
                return False
            if ru != rv:
                parent[rv] = ru
                parity[rv] = parity[u] ^ parity[v] ^ 1

    return True
```

## 6. 带权并查集 (Weighted Union-Find)

### 6.1 思想

在普通并查集的基础上, 维护 `weight[x]` 表示 `x` 到其父节点的某种"距离"或"关系"。通过合并时维护一致性约束, 可以处理更复杂的问题。

### 6.2 食物链问题 (经典)

**题目**: 三类动物 A、B、C, 关系是 A 吃 B, B 吃 C, C 吃 A。给出 K 个描述, 判断假话数。

```python
class WeightedUnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.dist = [0] * n  # 到根的距离 (模 3)

    def find(self, x):
        if self.parent[x] != x:
            root = self.find(self.parent[x])
            self.dist[x] += self.dist[self.parent[x]]
            self.parent[x] = root
        return self.parent[x]

    def union(self, x, y, w):
        """合并 x, y, 约束 x 比 y 大 w (模 3)"""
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return (self.dist[y] - self.dist[x]) % 3 == w
        # 合并: 把 ry 接到 rx
        self.parent[ry] = rx
        # 调整 dist[ry]: dist[x] + w = dist[y] + dist[ry] (mod 3)
        self.dist[ry] = (self.dist[x] + w - self.dist[y]) % 3
        return True

def food_chain_count(n, statements):
    """statements: [(x, y, t), ...], t=1 同类, t=2 x 吃 y"""
    uf = WeightedUnionFind(n + 1)  # 1-indexed
    fake = 0
    for x, y, t in statements:
        if x > n or y > n:
            fake += 1
            continue
        if t == 1:
            if not uf.union(x, y, 0): fake += 1
        else:  # t == 2, x 吃 y
            if not uf.union(x, y, 1): fake += 1
    return fake
```

**应用**: 食物链 (POJ 1182)、关系推导、约束满足。

### 6.3 带权并查集的通用模板

```python
class WeightedUF:
    def __init__(self, n):
        self.parent = list(range(n))
        self.diff = [0] * n  # 与根的"差"

    def find(self, x):
        if self.parent[x] != x:
            root = self.find(self.parent[x])
            self.diff[x] += self.diff[self.parent[x]]
            self.parent[x] = root
        return self.parent[x]

    def weight(self, x):
        """返回 x 到其根的累积 weight"""
        self.find(x)
        return self.diff[x]

    def union(self, x, y, w):
        """约束: weight[y] - weight[x] == w"""
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return self.diff[y] - self.diff[x] == w
        # 接 ry 到 rx
        self.parent[ry] = rx
        self.diff[ry] = self.diff[x] + w - self.diff[y]
        return True
```

## 7. Kruskal 最小生成树 (Kruskal's MST)

### 7.1 思想

按边权从小到大排序, 用并查集检查加边是否成环, 不成环就加入。生成树有 n-1 条边。

### 7.2 实现

```python
def kruskal(n, edges):
    """
    n: 节点数
    edges: [(u, v, w), ...]
    返回 MST 的总权重和边列表
    """
    edges.sort(key=lambda x: x[2])  # 按权重排序
    uf = UnionFind(n)
    total, mst = 0, []
    for u, v, w in edges:
        if uf.union(u, v):  # 加边不成环
            total += w
            mst.append((u, v, w))
            if len(mst) == n - 1:
                break
    return total, mst
```

### 7.3 复杂度

- 排序: $O(m \log m)$。
- union-find: $O(m \cdot \alpha(n))$。
- 总: $O(m \log m)$。

## 9. 并查集的工程实践

### 9.1 Python 标准库没有 UF

需要自己实现。简单场景可以直接用 dict:

```python
class DSU:
    def __init__(self):
        self.parent = {}
        self.rank = {}

    def add(self, x):
        if x not in self.parent:
            self.parent[x] = x
            self.rank[x] = 0

    def find(self, x):
        self.add(x)
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py: return False
        if self.rank[px] < self.rank[py]: px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        return True
```

## 12. 边界情况与坑

### 12.1 常见错误

| 错误 | 后果 | 修正 |
| :--- | :--- | :--- |
| `union` 中忘判 `px == py` | 集合数多减 1 | 早返回 False |
| `find` 递归深度爆栈 | 大数据崩溃 | 改迭代版 |
| 二维网格转一维: `(i, j) → i*n + j` | 列数错乱 | 注意 `n` 是列数 |
| 初始化忘 `self.count = n` | 答案少 1 | 必须在 `__init__` |
| 按秩合并未更新 rank | 树可能退化 | 合并同秩才 +1 |
| find 后忘路径压缩 | 性能慢 | 必须压缩 |
| 用 dict 而非 list 当 parent | 性能差 | 优先用 list |

1. **并查集时间复杂度?**
   - $O(\alpha(n))$, 几乎常数。

2. **路径压缩的目的?**
   - 让树变扁, 后续 find 更快。

   - $O(\alpha(n))$。

```python
def isBipartite(graph):
    parent = list(range(len(graph)))
    parity = [0] * len(graph)
    def find(x):
        if parent[x] != x:
            r = find(parent[x])
            parity[x] ^= parity[parent[x]]
            parent[x] = r
        return parent[x]
    for u in range(len(graph)):
        for v in graph[u]:
            ru, rv = find(u), find(v)
            if ru == rv and parity[u] == parity[v]: return False
            if ru != rv:
                parent[rv] = ru
                parity[rv] = parity[u] ^ parity[v] ^ 1
    return True
```

### 19.1 LeetCode 803 - 打砖块 (Hard)

**题目**: 网格中有砖块, 砖块由相邻 (4 方向) 的 1 组成。打掉一个砖块后, 不与顶部相连的砖块掉落。返回每次打击掉落的砖块数。

**思路**: 逆向思维, 从最后状态往前加砖, 用 UF 维护"和顶部的连通性"。

```python
def hitBricks(grid, hits):
    m, n = len(grid), len(grid[0])
    # 拷贝一份, 把所有 hits 处设为 0
    new_grid = [row[:] for row in grid]
    for i, j in hits:
        new_grid[i][j] = 0

    # 建 UF, 把所有剩余砖块与"虚拟天花板" (n) 连通
    uf = UnionFind(m * n + 1)
    top = m * n

    for i in range(m):
        for j in range(n):
            if new_grid[i][j] == 1:
                if i == 0:  # 与天花板相邻
                    uf.union(i*n + j, top)
                # 与下方/右方连
                if i + 1 < m and new_grid[i+1][j] == 1:
                    uf.union(i*n + j, (i+1)*n + j)
                if j + 1 < n and new_grid[i][j+1] == 1:
                    uf.union(i*n + j, i*n + j + 1)

    # 逆向加砖
    res = []
    for i, j in reversed(hits):
        if grid[i][j] == 0:
            res.append(0)
            continue
        # 加这块砖之前, 与天花板连通的砖数
        before = uf.size[uf.find(top)]  # 假设 size 可读
        # 加砖
        new_grid[i][j] = 1
        if i == 0:
            uf.union(i*n + j, top)
        for di, dj in [(-1,0),(1,0),(0,-1),(0,1)]:
            ni, nj = i+di, j+dj
            if 0 <= ni < m and 0 <= nj < n and new_grid[ni][nj] == 1:
                uf.union(i*n + j, ni*n + nj)
        after = uf.size[uf.find(top)]
        fallen = max(0, after - before - 1)  # -1 是新加的砖自己
        res.append(fallen)

    return res[::-1]
```

### 19.2 LeetCode 827 - 最大人工岛 (Hard)

**题目**: 给 n×n 二维网格, 最多翻转一个 0 为 1, 求最大岛屿面积。

**思路**: 先用 UF 标记所有岛屿, 然后尝试每个 0, 看其相邻岛屿面积之和+1。

```python
def largestIsland(grid):
    n = len(grid)
    uf = UnionFind(n * n)

    def idx(i, j): return i * n + j

    # 合并相邻的 1
    for i in range(n):
        for j in range(n):
            if grid[i][j] == 1:
                for di, dj in [(-1,0),(0,-1)]:
                    ni, nj = i+di, j+dj
                    if 0 <= ni < n and 0 <= nj < n and grid[ni][nj] == 1:
                        uf.union(idx(i, j), idx(ni, nj))

    # 统计每个分量的面积
    area = [0] * (n * n)
    for i in range(n):
        for j in range(n):
            if grid[i][j] == 1:
                area[uf.find(idx(i, j))] += 1

    # 找最大 (翻转后)
    res = max(area) if max(area) > 0 else 0
    for i in range(n):
        for j in range(n):
            if grid[i][j] == 0:
                seen = set()
                cur = 1  # 翻转后这块是 1
                for di, dj in [(-1,0),(1,0),(0,-1),(0,1)]:
                    ni, nj = i+di, j+dj
                    if 0 <= ni < n and 0 <= nj < n and grid[ni][nj] == 1:
                        r = uf.find(idx(ni, nj))
                        if r not in seen:
                            seen.add(r)
                            cur += area[r]
                res = max(res, cur)
    return res
```

### 19.5 LeetCode 1489 - 找到最小生成树里的关键边和伪关键边 (Hard)

**题目**: 给定加权图, 找 MST 中的"关键边" (任何 MST 都包含) 和"伪关键边" (某些 MST 包含)。

**思路**: 对每条边, 跑两次 Kruskal:
- 必不包含该边 → 如果 MST 权值变化, 该边是"关键"的。
- 必包含该边 → 如果 MST 权值不变, 该边是"伪关键"的。

```python
def findCriticalAndPseudoCriticalEdges(n, edges):
    # 给每条边加原始下标
    edges_with_idx = [(w, u, v, i) for i, (u, v, w) in enumerate(edges)]
    edges_with_idx.sort()

    # 基准 MST 权重
    def kruskal(n, edges, exclude=None, include=None):
        uf = UnionFind(n)
        weight = 0
        if include:
            w, u, v, _ = include
            uf.union(u, v)
            weight += w
        for w, u, v, i in edges:
            if i == exclude: continue
            if uf.union(u, v):
                weight += w
        if uf.count != 1: return float('inf')
        return weight

    base = kruskal(n, edges_with_idx)

    critical, pseudo = [], []
    for w, u, v, i in edges_with_idx:
        # 排除 i: 如果权重变了或无法连通, i 是关键边
        if kruskal(n, edges_with_idx, exclude=i) > base:
            critical.append(i)
        # 包含 i: 如果权重不变, i 是伪关键边
        elif kruskal(n, edges_with_idx, include=(w, u, v, i)) == base:
            pseudo.append(i)

    return critical, pseudo
```

### 19.8 LeetCode 1627 - 带阈值的图连通性 (Hard)

**题目**: n 个节点, 当且仅当 gcd(a, b) > threshold 时, a 与 b 相连。回答若干查询 (a, b) 是否连通。

**思路**: 反过来, gcd = 1 的不连, 其他情况按素因子合并。

```python
def areConnected(n, threshold, queries):
    if threshold == 0:
        return [True] * len(queries)

    parent = list(range(n + 1))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(x, y):
        px, py = find(x), find(y)
        if px != py: parent[px] = py

    # 对每个质数 p > threshold, 合并 p, 2p, 3p, ...
    for p in range(threshold + 1, n + 1):
        if is_prime(p):
            for k in range(p, n + 1, p):
                union(p, k)

    return [find(u) == find(v) for u, v in queries]

def is_prime(n):
    if n < 2: return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0: return False
    return True
```

### 25.1 UF 类 (生产级)

```python
class DSU:
    """生产级并查集, 路径压缩 + 按大小合并"""
    __slots__ = ('parent', 'size', 'count')

    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n
        self.count = n

    def find(self, x):
        root = x
        while self.parent[root] != root:
            root = self.parent[root]
        while self.parent[x] != root:
            self.parent[x], x = root, self.parent[x]
        return root

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py: return False
        if self.size[px] < self.size[py]:
            px, py = py, px
        self.parent[py] = px
        self.size[px] += self.size[py]
        self.count -= 1
        return True

    def connected(self, x, y):
        return self.find(x) == self.find(y)

    def component_size(self, x):
        return self.size[self.find(x)]
```

### 25.2 带权 UF (生产级)

```python
class WeightedDSU:
    """带权并查集, 维护 x 到根的累积距离 (mod 3 适用)"""
    __slots__ = ('parent', 'diff')

    def __init__(self, n):
        self.parent = list(range(n))
        self.diff = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            root = self.find(self.parent[x])
            self.diff[x] += self.diff[self.parent[x]]
            self.parent[x] = root
        return self.parent[x]

    def weight(self, x):
        self.find(x)
        return self.diff[x]

    def union(self, x, y, w):
        """约束: weight[y] - weight[x] == w (mod anything)"""
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return self.diff[y] - self.diff[x] == w
        self.parent[ry] = rx
        self.diff[ry] = self.diff[x] + w - self.diff[y]
        return True
```

```python
    """
    返回 (总权重, MST 边列表)
    edges: [(u, v, w), ...]
```

### 27.1 反向并查集 (Reverse DSU)

**思想**: 删边比加边难, 但可以**离线**反向加边。

```python
def reverse_dsu(n, edges, deletions):
    """删边 queries: [(u, v), ...] 返回每步的连通分量数"""
    # 把要删的边先删掉, 然后反向加边
    edge_set = set(edges) - set(deletions)
    uf = UnionFind(n)
    for u, v in edge_set:
        uf.union(u, v)

    res = [uf.count]
    # 反向处理删除 (即反向加边)
    for u, v in reversed(deletions):
        uf.union(u, v)
        res.append(uf.count)
    return res[::-1]
```

### 27.2 带颜色并查集

**应用**: 二分图判定 + 维护奇偶信息。

```python
class ColoredDSU:
    """每个节点有"颜色" (0 或 1), 同色连通, 异色不连"""
    def __init__(self, n):
        self.parent = list(range(n))
        self.color = [0] * n  # 与根的奇偶关系

    def find(self, x):
        if self.parent[x] != x:
            root = self.find(self.parent[x])
            self.color[x] ^= self.color[self.parent[x]]
            self.parent[x] = root
        return self.parent[x]

    def union(self, x, y, same_color=True):
        """same_color=True 表示 x 和 y 同色, False 表示异色"""
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return self.color[x] == self.color[y] if same_color else self.color[x] != self.color[y]
        # 合并
        self.parent[ry] = rx
        self.color[ry] = self.color[x] ^ self.color[y] ^ (0 if same_color else 1)
        return True
```

### 27.3 区间并查集 (用于离线区间合并)

```python
class IntervalDSU:
    """维护 [0, n) 区间的合并, 支持 'next unfilled' 操作"""
    def __init__(self, n):
        self.parent = list(range(n + 1))  # n 作为哨兵

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def occupy(self, x):
        """标记 x 已占用, 返回 x 之后第一个未占用的下标"""
        root = self.find(x)
        if root == len(self.parent) - 1:
            return -1  # 全占满了
        self.parent[root] = self.find(root + 1)
        return root
```

### 28.1 UF + DP

例: "最小生成树上的 DP" (树上 DP)。

```python
def mst_dp(n, edges, weights):
    """在 MST 上做 DP"""
    # 先 Kruskal 找 MST
    _, mst_edges = kruskal_mst(n, edges)
    # 在 MST 上 DP (用邻接表)
    adj = defaultdict(list)
    for u, v, w in mst_edges:
        adj[u].append((v, w))
        adj[v].append((u, w))

    # 在树上 DP
    def dfs(u, parent):
        dp1, dp2 = 0, 0  # dp1: 不取 u, dp2: 取 u
        for v, w in adj[u]:
            if v == parent: continue
            c1, c2 = dfs(v, u)
            dp1 += max(c1, c2)  # u 不取, v 可取可不取
            dp2 += c1  # u 取, v 不能取
        return dp1, dp2 + weights[u]

    return max(dfs(0, -1))
```

```python
class SocialNetwork:
    def __init__(self, n):
        self.uf = UnionFind(n)
        self.friends = defaultdict(set)

        self.uf.union(u, v)
        self.friends[u].add(v)
        self.friends[v].add(u)

    def are_friends(self, u, v):
        return self.uf.connected(u, v)

    def num_communities(self):
        return self.uf.count

    def friend_suggestions(self, u, k=5):
        """二度连接推荐"""
        direct = self.friends[u]
        cnt = Counter()
        for friend in direct:
            for fof in self.friends[friend]:
                if fof != u and fof not in direct:
                    cnt[fof] += 1
        return cnt.most_common(k)

    def community_of(self, u):
        return self.uf.find(u)
```
