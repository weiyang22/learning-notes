# 第05章-01-DP基础与记忆化搜索


## 1. DP 是什么

**动态规划 (Dynamic Programming)** 是求解**多阶段决策过程最优化**的算法思想.

**核心**: 把大问题拆成小问题, 记住小问题的答案 (避免重复计算).

**适用条件**:
1. **最优子结构**: 大问题的最优解可由小问题的最优解推出
2. **重叠子问题**: 不同大问题会用到同一个小问题
3. **无后效性**: 未来的决策不受过去决策的影响

---

## 2. DP 4 步法 (核心方法论)

```text
Step 1: 状态定义
  dp[i] / dp[i][j] 表示什么? (最关键!)

Step 2: 转移方程
  dp[i] 如何由之前状态推出?
  dp[i] = f(dp[i-1], dp[i-2], ...)

Step 3: 初始化
  dp[0] = ? dp[1] = ? (边界)

Step 4: 遍历顺序
  从前往后 / 从后往前? 嵌套顺序?
```

## 3. 入门题: 爬楼梯

### 3.1 LeetCode 70 - 爬楼梯 (Easy)

**题目**: 爬 n 阶楼梯, 每次可爬 1 或 2 阶, 有多少种方法?

**Step 1 - 状态定义**:
$dp[i]$ = 爬到第 i 阶的方法数

**Step 2 - 转移方程**:
$dp[i] = dp[i-1] + dp[i-2]$
- 到第 i 阶: 从第 i-1 阶爬 1 步, 或从第 i-2 阶爬 2 步

**Step 3 - 初始化**:
$dp[0] = 1$ (0 阶 1 种方法: 不动), $dp[1] = 1$

**Step 4 - 遍历顺序**: 从前往后

```python
def climbStairs(n):
    if n <= 2: return n
    dp = [0] * (n + 1)
    dp[1] = 1
    dp[2] = 2
    for i in range(3, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]

# 空间优化: O(1)
def climbStairs(n):
    if n <= 2: return n
    prev, curr = 1, 2
    for i in range(3, n + 1):
        prev, curr = curr, prev + curr
    return curr
```

## 4. 入门题: 打家劫舍

### 4.1 LeetCode 198 - 打家劫舍 (Medium)

**题目**: 一排房子, 每个有金额, 不能偷相邻两家, 求最大金额.

**Step 1 - 状态**:
$dp[i]$ = 偷前 i 个房子的最大金额

**Step 2 - 转移**:
$dp[i] = \max(dp[i-1], dp[i-2] + nums[i])$
- 不偷第 i 家: $dp[i-1]$
- 偷第 i 家: $dp[i-2] + nums[i]$

**Step 3 - 初始化**:
$dp[0] = 0, dp[1] = nums[0]$

**Step 4 - 顺序**: 从前往后

```python
def rob(nums):
    if not nums: return 0
    n = len(nums)
    if n == 1: return nums[0]

    dp = [0] * n
    dp[0] = nums[0]
    dp[1] = max(nums[0], nums[1])
    for i in range(2, n):
        dp[i] = max(dp[i-1], dp[i-2] + nums[i])
    return dp[n-1]

# 空间优化
def rob(nums):
    prev = 0  # dp[i-2]
    curr = 0  # dp[i-1]
    for x in nums:
        prev, curr = curr, max(curr, prev + x)
    return curr
```

### 4.2 LeetCode 213 - 打家劫舍 II (Medium)

**题目**: 房子是环形, 不能偷相邻.

```python
def rob(nums):
    if not nums: return 0
    if len(nums) == 1: return nums[0]

    # 两种情况: 不偷第一家 或 不偷最后一家
    return max(rob_linear(nums[:-1]), rob_linear(nums[1:]))

def rob_linear(nums):
    prev, curr = 0, 0
    for x in nums:
        prev, curr = curr, max(curr, prev + x)
    return curr
```

### 4.3 LeetCode 337 - 打家劫舍 III (Medium, 树形 DP 入门)

**题目**: 二叉树房子, 不能偷直接相连的父子节点.

```python
def rob(root):
    """返回 (抢当前节点, 不抢当前节点) 的最大金额"""
    if not root: return (0, 0)

    left_rob, left_not = rob(root.left)
    right_rob, right_not = rob(root.right)

    # 抢当前: 左右不能抢
    rob_curr = root.val + left_not + right_not
    # 不抢当前: 左右选 max
    not_rob_curr = max(left_rob, left_not) + max(right_rob, right_not)

    return (rob_curr, not_rob_curr)

# 调用
return max(rob(root))
```

## 5. 记忆化搜索 vs 自底向上 DP

### 5.1 记忆化搜索 (自顶向下)

```python
def climbStairs_memo(n, memo={}):
    """记忆化搜索"""
    if n <= 2: return n
    if n in memo: return memo[n]
    memo[n] = climbStairs_memo(n-1, memo) + climbStairs_memo(n-2, memo)
    return memo[n]
```

**优点**: 直观, 容易想到
**缺点**: 递归栈, 大 n 可能爆栈

### 5.2 自底向上 DP

```python
def climbStairs_dp(n):
    """DP 数组"""
    if n <= 2: return n
    dp = [0] * (n + 1)
    dp[1], dp[2] = 1, 2
    for i in range(3, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]
```

**优点**: $O(1)$ 栈空间 (用迭代)
**缺点**: 状态定义要清楚

### 5.3 选择

| 场景 | 推荐 |
|---|---|
| 状态转移复杂 | 记忆化搜索 (更自然) |
| 性能优先 | 自底向上 (无栈开销) |
| 状态依赖"上一个" | 滚动变量 (空间优化) |
| 树形 DP | 记忆化搜索 |

## 6. 状态定义技巧

### 6.1 一维状态

```text
dp[i]: 前 i 个元素的某种性质
  - 最大/最小值
  - 方案数
  - 是否可行
```

### 6.2 二维状态

```text
dp[i][j]:
  - 两个序列的前 i/j 个
  - 矩阵的 (i, j) 位置
  - 两个维度 (剩余次数, 当前状态)
```

### 6.3 状态压缩

```python
# ❌ 空间 O(n)
dp = [0] * (n + 1)
for i in range(n):
    dp[i+1] = f(dp[i])
return dp[n]

# ✅ 空间 O(1)
prev = 0
for i in range(n):
    curr = f(prev)
    prev = curr
return prev
```

## 10. DP 适用条件深入

### 10.1 三大性质详解

**(1) 最优子结构 (Optimal Substructure)**

**定义**: 大问题的最优解可由小问题的最优解组合而成.

**判定**: 假设你知道子问题的最优解, 你能用它们直接构造出大问题的最优解吗? 如果是, 就具备最优子结构.

```python
# 最短路径: 具备最优子结构
# 若 i → j 的最短路径经过 k, 则 i → k 和 k → j 都是最短路径

# 反例: 最长简单路径: 不具备 (子路径的最长 ≠ 全局最长)
```

**(2) 重叠子问题 (Overlapping Subproblems)**

**定义**: 不同大问题会反复求解同一个小问题.

```python
# 斐波那契 fib(5) 的递归树
#                      fib(5)
#                  /            \
#              fib(4)          fib(3)
#             /     \         /     \
#          fib(3) fib(2)  fib(2) fib(1)
#          /   \
#       fib(2) fib(1)
#
# fib(3) 被算了 2 次, fib(2) 被算了 3 次, fib(1) 被算了 2 次
# 重叠! 加记忆化即可
```

**(3) 无后效性 (No Aftereffect)**

**定义**: 未来决策不受过去决策路径的影响, 只与当前状态有关.

```python
# 例: 爬楼梯 dp[i] 只与 dp[i-1] 和 dp[i-2] 有关, 与怎么到 i-1 无关
# 反例: 旅行商问题, 当前城市 + 已访问集合才决定下一步, 状态要包含更多信息
```

### 10.2 反例: 不满足 DP 条件

```python
# ❌ 不满足最优子结构: 最长简单路径
# ❌ 不满足无后效性: 带"已选集合"约束的某些问题
# ✅ 满足: 最短路径, 最长公共子序列, 0-1 背包
```

## 11. DP 与其他算法关系

### 11.1 DP vs 贪心

| 维度 | DP | 贪心 |
|---|---|---|
| 决策 | 全局考虑 | 局部最优 |
| 状态 | 保留所有子问题 | 只保留当前最优 |
| 适用范围 | 满足最优子结构即可 | 需证明局部 = 全局 |
| 时间 | 较高 | 较低 |

**例: 找零问题**
- 硬币 [1, 3, 4], 凑 6: 贪心 (4+1+1=3 枚) 不是最优 (3+3=2 枚), 用 DP.

```python
def coinChange(coins, amount):
    """DP 求最少硬币数"""
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0
    for i in range(1, amount + 1):
        for c in coins:
            if i >= c:
                dp[i] = min(dp[i], dp[i - c] + 1)
    return dp[amount] if dp[amount] != float('inf') else -1
```

### 11.2 DP vs 分治

| 维度 | DP | 分治 |
|---|---|---|
| 子问题 | 重叠 | 独立 |
| 复杂度 | 通常较高 | 通常较低 |
| 关键 | 状态定义 | 拆分 + 合并 |

```python
# 归并排序: 分治 (子问题独立)
# 斐波那契: DP (子问题重叠)
```

### 11.3 DP vs 回溯

| 维度 | DP | 回溯 |
|---|---|---|
| 目标 | 最优解/计数 | 所有解/具体解 |
| 时间 | 多项式 (通常) | 指数 |
| 状态 | dp 数组 | 路径 + 标记 |

**例**: 0-1 背包
- 求最大价值: DP $O(nW)$
- 求所有方案: 回溯 $O(2^n)$

### 11.4 DP vs 记忆化搜索

记忆化搜索 == 自顶向下 DP. 本质相同, 只是实现方式不同.

## 12. DP 状态定义深度指南

### 12.1 状态的本质

**状态 = 当前问题的所有"决策相关信息"**. 一个好的状态定义:
1. **完备**: 包含决策所需的全部信息
2. **最小**: 不包含冗余信息
3. **可转移**: 能从已知状态推出新状态

### 12.2 状态定义的常见模式

**模式 1: 前缀型**

```python
# dp[i] = 前 i 个元素的某种性质
# 例: dp[i] = 前 i 个数能组成的最大和
```

**模式 2: 区间型**

```python
# dp[i][j] = 区间 [i, j] 的某种性质
# 例: dp[i][j] = 区间 [i, j] 是否是回文
```

**模式 3: 选择型**

```python
# dp[i][k] = 前 i 个选了 k 个的某种性质
# 例: dp[i][k] = 前 i 个物品选 k 个的最大价值
```

**模式 4: 状态压缩型**

```python
# dp[mask] = 已选集合为 mask 时的某种性质
# 例: dp[mask] = 已访问 mask 状态的最短路径
```

### 12.3 状态定义的错误与修正

```python
# ❌ 错: 状态信息不足
# 例: 买股票, dp[i] = 前 i 天的最大利润
# 问题: 不知道当前是否持股, 无法决策

# ✅ 对: dp[i][k] = 第 i 天, 已交易 k 次, 是否持股
# 0: 不持股且没卖出过, 1: 持股, 2: 不持股且卖出过
```

### 12.4 状态转移的推导

**步骤**:
1. 列出当前状态的所有"选择"
2. 对每个选择, 求对应的"前一个状态"
3. 取所有选择的最优 (max/min/和/或)

```python
# 例: 打家劫舍
# 状态: dp[i] = 前 i 个房子能偷的最大金额
# 选择: 偷第 i 家 或 不偷第 i 家
#   偷: dp[i-2] + nums[i]  (跳过 i-1)
#   不偷: dp[i-1]          (i-1 是最优)
# 转移: dp[i] = max(dp[i-1], dp[i-2] + nums[i])
```

## 13. DP 初始化与边界

### 13.1 常见初始化模式

```python
# 模式 1: dp[0] 是基本情况
dp = [0] * (n + 1)
dp[0] = 1  # 0 阶 1 种方法

# 模式 2: dp[1] 是基本情况, dp[0] 是辅助
dp = [0] * (n + 1)
dp[0] = 0  # 空数组最大和是 0
dp[1] = nums[0]  # 1 个元素

# 模式 3: 用 "哨兵" 简化边界
# 例: 0-1 背包用 dp[0..n][0..W], dp[0][...] = 0
```

### 13.2 边界条件常见错误

```python
# ❌ 错: 数组越界
def climbStairs(n):
    dp = [0] * (n + 1)
    dp[0] = 1
    dp[1] = 1
    for i in range(2, n):  # 应该是 n+1
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]  # n=2 时返回 0 (错)

# ✅ 对
def climbStairs(n):
    if n <= 2: return n
    dp = [0] * (n + 1)
    dp[1] = 1
    dp[2] = 2
    for i in range(3, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]
```

### 13.3 边界处理的"dp table + 哨兵"法

```python
# 例: 编辑距离
# dp[i][j] = word1[:i] 到 word2[:j] 的编辑距离
# 哨兵: dp[0][j] = j, dp[i][0] = i
# 这样转移公式统一:
#   dp[i][j] = dp[i-1][j-1]  if word1[i-1] == word2[j-1]
#           = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
```

## 14. DP 遍历顺序

### 14.1 单序列: 从前往后

```python
# 状态依赖更前面的状态
dp = [0] * n
dp[0] = base
for i in range(1, n):
    dp[i] = f(dp[i-1], dp[i-2])
```

### 14.2 区间 DP: 区间长度从小到大

```python
# dp[l][r] = 区间 [l, r] 的某种性质
n = len(s)
dp = [[0] * n for _ in range(n)]

# 区间长度
for length in range(2, n + 1):  # 长度从 2 到 n
    for l in range(n - length + 1):
        r = l + length - 1
        dp[l][r] = f(dp[l+1][r], dp[l][r-1], dp[l+1][r-1])
```

### 14.3 背包: 外层物品, 内层容量

```python
# 0-1 背包: 逆序
for i in range(n):
    for j in range(W, weights[i] - 1, -1):
        dp[j] = max(dp[j], dp[j - weights[i]] + values[i])

# 完全背包: 顺序
for i in range(n):
    for j in range(weights[i], W + 1):
        dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
```

### 14.4 二维 DP: 嵌套循环

```python
# 字符串 dp[i][j] 通常两重循环
for i in range(1, m + 1):
    for j in range(1, n + 1):
        dp[i][j] = f(...)
```

## 15. DP 空间优化

### 15.1 滚动变量 (Rolling Variable)

**适用**: 状态只依赖前 1-2 个状态.

```python
# dp[i] = dp[i-1] + dp[i-2]
# 空间 O(n) → O(1)
def fib(n):
    if n <= 1: return n
    a, b = 0, 1
    for _ in range(n - 1):
        a, b = b, a + b
    return b
```

### 15.2 滚动数组 (Rolling Array)

**适用**: dp 是二维, 但只依赖前一行/前一列.

```python
# dp[i][j] = dp[i-1][j] + dp[i][j-1]
# 空间 O(m*n) → O(n)
def uniquePaths(m, n):
    dp = [1] * n
    for i in range(1, m):
        for j in range(1, n):
            dp[j] += dp[j-1]
    return dp[-1]
```

### 15.3 状态压缩 (Bitmask)

**适用**: dp 状态能用 bit 表示.

```python
# TSP 问题: dp[mask][i] = 已访问 mask, 当前在 i
# 空间 O(2^n * n)
```

### 15.4 记忆化搜索天然优化

```python
# 不需要存整个 dp 表, 只存访问过的
from functools import lru_cache

@lru_cache(maxsize=None)
def dfs(i, j):
    if i == 0 or j == 0: return 1
    return dfs(i-1, j) + dfs(i, j-1)
```

```python
# 例: 打家劫舍 nums=[2, 7, 9, 3, 1]
# 预期: 偷 2+9+1=12
def rob_debug(nums):
    n = len(nums)
    dp = [0] * n
    dp[0] = nums[0]
    if n > 1: dp[1] = max(nums[0], nums[1])
```

```python
def longestPalindrome(s):
    def expand(left, right):
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        return s[left+1:right]

        # 奇数中心
        p1 = expand(i, i)
        if len(p1) > len(result): result = p1

        if len(p2) > len(result): result = p2
    return result

def longestPalindrome_dp(s):

    for i in range(n):
        dp[i][i] = True
        result = s[i]

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            if s[i] == s[j]:
                if length == 2 or dp[i+1][j-1]:
                    dp[i][j] = True
                    if length > len(result):
                        result = s[i:j+1]
    return result
```

## 20. 树形 DP 入门

### 20.1 什么是树形 DP

**定义**: 状态定义在树的节点上, 利用树的递归结构求解.

**特征**:
- 后序遍历 (从叶子往根推)
- 状态可能依赖子节点
- 通常用返回值传递状态

### 20.2 LeetCode 337 - 打家劫舍 III 完整分析

**问题**: 二叉树, 不能偷相邻节点 (父子). 求最大金额.

**状态**: $f(\text{node}) = (\text{rob node}, \text{not rob node})$

```python
def rob(root):
    def dfs(node):
        if not node: return (0, 0)

        left_rob, left_not = dfs(node.left)
        right_rob, right_not = dfs(node.right)

        # 偷当前节点
        rob_curr = node.val + left_not + right_not
        # 不偷当前节点
        not_rob_curr = max(left_rob, left_not) + max(right_rob, right_not)

        return (rob_curr, not_rob_curr)

    return max(dfs(root))

# 记忆化版本
def rob_memo(root):
    memo = {}
    def dfs(node):
        if not node: return (0, 0)
        if node in memo: return memo[node]

        left_rob, left_not = dfs(node.left)
        right_rob, right_not = dfs(node.right)

        result = (
            node.val + left_not + right_not,
            max(left_rob, left_not) + max(right_rob, right_not)
        )
        memo[node] = result
        return result

    return max(dfs(root))
```

**复杂度**: $O(n)$ 时间, $O(h)$ 空间 (递归栈) 或 $O(n)$ (记忆化字典).

## 22. DP 思维框架总结

### 22.1 解 DP 题的 5 个问题

```text
1. 状态是什么? (dp[i] 表示什么)
2. 转移方程是什么? (dp[i] 怎么由之前状态推出)
3. 初始状态是什么? (dp[0] = ?)
4. 遍历顺序是什么? (前/后/区间/嵌套)
5. 答案在哪? (dp[n-1] / dp[m-1][n-1] / max(dp) / ...)
```

### 22.2 识别 DP 题的信号

**强信号**:
- "最...的..."
- "有几种方法..."
- "能否..."
- "最大收益..."

**弱信号**:
- 子问题重叠 (画递归树发现)
- 数据范围暗示多项式算法

### 22.3 DP 不会做的应对

1. **画图**: 画状态转移图
2. **小样例**: 手算 n=3, 找规律
3. **回溯法对比**: 暴力递归 → 记忆化
4. **搜索答案**: 看题解, 总结模板
5. **类型归类**: 是 LIS? LCS? 背包? 区间? 状态机?

```python
    return result
```

### 24.1 前缀和优化

**场景**: 区间和 DP, $O(n^2)$ → $O(n)$.

```python
# 普通 DP: O(n^2)
def max_subarray_sum(nums, k):
    n = len(nums)
    dp = [0] * (n + 1)
    for i in range(1, n + 1):
        dp[i] = max(dp[j] + sum(nums[j:i]) for j in range(i))
    return dp[n]

# 前缀和优化: O(n)
def max_subarray_sum_optimized(nums, k):
    n = len(nums)
    prefix = [0] * (n + 1)
    for i in range(1, n + 1):
        prefix[i] = prefix[i-1] + nums[i-1]
    # 用 prefix[i] - prefix[j] 代替 sum(nums[j:i])
```

### 24.2 单调队列优化

**场景**: 滑动窗口 DP, $O(nk)$ → $O(n)$.

```python
# 例: 滑动窗口最大值
from collections import deque

def maxSlidingWindow(nums, k):
    dq = deque()  # 存索引, 单调递减
    result = []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] < x:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            result.append(nums[dq[0]])
    return result
```

### 24.3 矩阵快速幂

**场景**: 线性递推, $O(n)$ → $O(\log n)$.

```python
import numpy as np

def mat_pow(M, n, mod=None):
    """矩阵快速幂"""
    size = M.shape[0]
    result = np.eye(size, dtype=object if mod else float)
    while n > 0:
        if n & 1:
            result = result @ M
        M = M @ M
        n >>= 1
    if mod:
        result = result % mod
    return result

def fib_matrix(n):
    """斐波那契矩阵快速幂 O(log n)"""
    if n <= 1: return n
    M = np.array([[1, 1], [1, 0]], dtype=object)
    return mat_pow(M, n)[0, 1]
```

### 25.2 DP + 状态压缩

```python
# 例: 最短 Hamilton 路径 (TSP)
def shortestHamiltonPath(graph):
    n = len(graph)
    # dp[mask][i] = 已访问 mask, 当前在 i 的最短路径
    dp = [[float('inf')] * n for _ in range(1 << n)]
    dp[1][0] = 0  # 起点

    for mask in range(1 << n):
        for i in range(n):
            if not (mask & (1 << i)) or dp[mask][i] == float('inf'):
                continue
            for j in range(n):
                if mask & (1 << j): continue
                new_mask = mask | (1 << j)
                dp[new_mask][j] = min(dp[new_mask][j],
                                      dp[mask][i] + graph[i][j])

    full = (1 << n) - 1
    return min(dp[full][i] + graph[i][0] for i in range(1, n))
```

```python
from collections import deque

def shortestPath(graph, start, end):
    n = len(graph)
    dist = [float('inf')] * n
    dist[start] = 0
    dq = deque([start])
    while dq:
        u = dq.popleft()
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                if w == 0:
                    dq.appendleft(v)
                else:
                    dq.append(v)
    return dist[end]
```

## 26. DP 实战技巧

### 26.1 自顶向下 vs 自底向上选择

| 场景 | 推荐 | 原因 |
|---|---|---|
| 状态转移复杂 | 自顶向下 | 更自然 |
| 性能优先 | 自底向上 | 无栈开销 |
| 状态依赖"上一个" | 滚动变量 | 空间优化 |
| 树形 DP | 自顶向下 | 递归自然 |
| 状态稀疏 | 自顶向下 | 不访问的不算 |
| 边界清晰 | 自底向上 | 易写 |

### 26.2 多解法对比模板

```python
# 同一问题的不同实现
def fib_v1(n):
    """暴力递归, O(2^n)"""
    if n <= 1: return n
    return fib_v1(n-1) + fib_v1(n-2)

def fib_v2(n, memo={}):
    """记忆化, O(n) 时间 O(n) 空间"""
    if n <= 1: return n
    if n not in memo:
        memo[n] = fib_v2(n-1, memo) + fib_v2(n-2, memo)
    return memo[n]

def fib_v3(n):
    """自底向上, O(n) 时间 O(n) 空间"""
    if n <= 1: return n
    dp = [0] * (n + 1)
    dp[1] = 1
    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]

def fib_v4(n):
    """滚动变量, O(n) 时间 O(1) 空间"""
    if n <= 1: return n
    a, b = 0, 1
    for _ in range(n - 1):
        a, b = b, a + b
    return b

def fib_v5(n):
    """矩阵快速幂, O(log n)"""
    import numpy as np
    if n <= 1: return n
    def mat_mul(A, B):
        return np.dot(A, B)
    def mat_pow(M, p):
        result = np.eye(2, dtype=object)
        while p > 0:
            if p & 1: result = mat_mul(result, M)
            M = mat_mul(M, M)
            p >>= 1
        return result
    M = np.array([[1, 1], [1, 0]], dtype=object)
    return mat_pow(M, n)[0, 1]
```

```python
# LeetCode 188 买卖股票 IV (k 次交易)
def maxProfit(k, prices):
    if not prices: return 0
    n = len(prices)
    k = min(k, n // 2)

    # dp[i][j][s] = 第 i 天, j 次交易, s=0/1 (不持/持股)
    dp = [[[0] * 2 for _ in range(k + 1)] for _ in range(n)]
    for j in range(k + 1):
        dp[0][j][1] = -prices[0]

    for i in range(1, n):
        for j in range(k + 1):
            # 不持: 之前不持 或 之前持的卖出
            dp[i][j][0] = dp[i-1][j][0]
            if j > 0:
                dp[i][j][0] = max(dp[i][j][0], dp[i-1][j-1][1] + prices[i])
            # 持: 之前持 或 之前不持的买入
            dp[i][j][1] = dp[i-1][j][1]
            dp[i][j][1] = max(dp[i][j][1], dp[i-1][j][0] - prices[i])

    return dp[n-1][k][0]
```

```python
def totalNQueens(n):
    def solve(row, cols, diag1, diag2):
        if row == n:
            return 1
        count = 0
        for col in range(n):
            if col in cols or (row - col) in diag1 or (row + col) in diag2:
                continue
            count += solve(row + 1,
                          cols | {col},
                          diag1 | {row - col},
                          diag2 | {row + col})
        return count
    return solve(0, set(), set(), set())

# 位运算优化版
def totalNQueens_bit(n):
    def solve(row, cols, diags1, diags2):
        if row == n:
            return 1
        count = 0
        available = (~(cols | diags1 | diags2)) & ((1 << n) - 1)
        while available:
            pos = available & -available  # 取最低位
            available ^= pos
            count += solve(row + 1,
                          cols | pos,
                          (diags1 | pos) << 1,
                          (diags2 | pos) >> 1)
        return count
    return solve(0, 0, 0, 0)
```

```python
def countDigitOne(n):
    if n <= 0: return 0

        while num > 0:

                count += 1
            num //= 10
```

```python
def matrixChainOrder(p):
    """矩阵链乘最小代价"""
    n = len(p) - 1
    dp = [[0] * n for _ in range(n)]

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            dp[i][j] = float('inf')
            for k in range(i, j):
                cost = dp[i][k] + dp[k+1][j] + p[i] * p[k+1] * p[j+1]
                dp[i][j] = min(dp[i][j], cost)

    return dp[0][n-1]
```

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
