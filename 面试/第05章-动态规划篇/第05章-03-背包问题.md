# 第05章-03-背包问题

> *
> **核心**: 4 种背包的差异在"每个物品能选几次"

---

## 1. 背包四要素

```text
状态: dp[i][j] = 前 i 个物品, 容量 j 下的最优值
转移: 选 vs 不选
```

**4 类背包对比**:

| 类型 | 物品数量 | 关键差异 |
|---|---|---|
| **0-1 背包** | 每个 0 或 1 次 | 倒序遍历 |
| **完全背包** | 每个无限次 | 顺序遍历 |
| **多重背包** | 每个固定 k 次 | 二进制拆分 |
| **分组背包** | 每组选 1 个 | 每组内枚举 |

## 2. 0-1 背包

### 2.1 模板

```python
def knapsack_01(weights, values, W):
    """0-1 背包: 每个物品最多选 1 次"""
    n = len(weights)
    dp = [0] * (W + 1)
    for i in range(n):  # 物品
        for j in range(W, weights[i] - 1, -1):  # 容量: 逆序!
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
    return dp[W]
```

**为什么逆序?** 因为每个物品只能用一次, 逆序保证每个 dp[j] 只被当前物品更新一次.

### 2.2 LeetCode 494 - 目标和 (Medium)

**题目**: 给数组, 在每个数前加 + 或 -, 使最终和等于 target. 求方案数.

**转化为 0-1 背包**:

设 + 的数和为 P, - 的数和为 N. 则 P - N = target, P + N = sum. 所以 $P = (sum + target) / 2$.

问题转化为: 在 nums 中选若干数, 使和为 P. **求方案数**.

```python
def findTargetSumWays(nums, target):
    total = sum(nums)
    if (total + target) % 2 != 0 or abs(target) > total:
        return 0
    P = (total + target) // 2

    dp = [0] * (P + 1)
    dp[0] = 1  # 空集
    for x in nums:
        for j in range(P, x - 1, -1):
            dp[j] += dp[j - x]
    return dp[P]
```

### 2.3 LeetCode 1049 - 最后一块石头的重量 II (Medium)

**题目**: 把石头分成两堆, 重量差最小.

**转化为 0-1 背包**: 选若干石头使和尽可能接近 total/2.

```python
def lastStoneWeightII(stones):
    total = sum(stones)
    target = total // 2
    dp = [0] * (target + 1)
    for x in stones:
        for j in range(target, x - 1, -1):
            dp[j] = max(dp[j], dp[j - x] + x)
    return total - 2 * dp[target]
```

## 3. 完全背包

### 3.1 模板

```python
def knapsack_complete(weights, values, W):
    """完全背包: 每个物品可选无限次"""
    n = len(weights)
    dp = [0] * (W + 1)
    for i in range(n):
        for j in range(weights[i], W + 1):  # 顺序!
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
    return dp[W]
```

**为什么顺序?** 因为完全背包中每个物品可选多次, 顺序遍历允许物品被自己更新.

### 3.2 LeetCode 322 - 零钱兑换 (Medium)

**题目**: 给定硬币面额和总金额, 求凑出金额的最少硬币数. (完全背包求最值)

```python
def coinChange(coins, amount):
    """完全背包: 最少硬币数"""
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0
    for c in coins:
        for j in range(c, amount + 1):  # 顺序
            dp[j] = min(dp[j], dp[j - c] + 1)
    return dp[amount] if dp[amount] != float('inf') else -1
```

### 3.3 LeetCode 518 - 零钱兑换 II (Medium)

**题目**: 求凑出金额的**方案数**.

```python
def change(amount, coins):
    dp = [0] * (amount + 1)
    dp[0] = 1
    for c in coins:
        for j in range(c, amount + 1):
            dp[j] += dp[j - c]
    return dp[amount]
```

### 3.4 LeetCode 279 - 完全平方数 (Medium)

**题目**: 求和为 n 的最少完全平方数 (1, 4, 9, 16, ...).

```python
def numSquares(n):
    """完全背包: 最少完全平方数"""
    dp = [float('inf')] * (n + 1)
    dp[0] = 0
    for i in range(1, int(n**0.5) + 1):
        sq = i * i
        for j in range(sq, n + 1):
            dp[j] = min(dp[j], dp[j - sq] + 1)
    return dp[n]
```

## 4. 进阶: 二维费用背包 + 分组背包

### 4.1 二维费用 (LeetCode 474 - 一和零)

**题目**: 每个字符串有 0 和 1 的数量, 求不超过 m 个 0 和 n 个 1 的最多字符串数.

```python
def findMaxForm(strs, m, n):
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for s in strs:
        zeros = s.count('0')
        ones = s.count('1')
        # 0-1 背包: 二维
        for i in range(m, zeros - 1, -1):
            for j in range(n, ones - 1, -1):
                dp[i][j] = max(dp[i][j], dp[i - zeros][j - ones] + 1)
    return dp[m][n]
```

### 4.2 多重背包 (二进制拆分)

把多重背包的"每个物品 k 次"拆成"多个物品, 每个 0-1 次".

```python
def multi_knapsack(weights, values, counts, W):
    """多重背包: 每个物品 counts[i] 次"""
    new_weights = []
    new_values = []
    for w, v, c in zip(weights, values, counts):
        k = 1
        while c > 0:
            use = min(k, c)
            new_weights.append(w * use)
            new_values.append(v * use)
            c -= use
            k *= 2
    return knapsack_01(new_weights, new_values, W)
```

## 8. 背包问题的统一视角

### 8.1 背包的本质

背包问题的本质是**在容量约束下的最优选择**:
- 容量 = 某种限制 (重量、体积、和、长度、二维资源)
- 物品 = 候选
- 价值 = 优化目标

**判断步骤**:
1. 是否有一组"候选物品"?
2. 是否有"容量约束"?
3. 是否有"优化目标"?
4. 每个物品能否多次选?

### 8.2 4 种背包的统一抽象

```text
设 dp[i][j] 为 "前 i 个物品, 容量 j 下的最优值"

0-1 背包 (每个物品选 0 或 1 次):
- 转移: dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])
- 优化: dp[j] = max(dp[j], dp[j-w] + v)  # 逆序

完全背包 (每个物品选无限次):
- 转移: dp[i][j] = max(dp[i-1][j], dp[i][j-w[i]] + v[i])
- 优化: dp[j] = max(dp[j], dp[j-w] + v)  # 顺序

多重背包 (每个物品选 k 次):
- 二进制拆分: 把 k 拆为 1+2+4+...+剩余, 每个转化为 0-1

分组背包 (每组选 1 个):
- 每组选 1 个或不选
- 转移: dp[i][j] = max(dp[i-1][j], max(dp[i-1][j-w[k]] + v[k]) for k in 组内)
```

### 8.3 顺序 vs 逆序的本质区别

```text
0-1 背包: 容量 j 由 dp[j] (旧) 和 dp[j-w] (新) 决定
- 逆序遍历 j: dp[j-w] 还未被当前物品更新, 等价于"上一行"
- 顺序遍历 j: dp[j-w] 已被当前物品更新, 等价于"同物品多次选"

完全背包: 容量 j 由 dp[j] (旧) 和 dp[j-w] (新) 决定
- 顺序遍历 j: dp[j-w] 已被当前物品更新, 可以多次选同一物品
- 逆序遍历 j: 退化为 0-1 背包
```

## 9. 0-1 背包深度剖析

### 9.1 二维 DP 视角 (教学用)

**状态**: `dp[i][j]` = 前 i 个物品, 容量 j 下的最优值.

**转移**:
$$dp[i][j] = \max(dp[i-1][j], \ dp[i-1][j-w_i] + v_i)$$

**边界**:
- `dp[0][j] = 0` (一个都不选)
- `dp[i][0] = 0` (容量 0)

```python
def knapsack_01_2d(weights, values, W):
    n = len(weights)
    dp = [[0] * (W + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for j in range(1, W + 1):
            dp[i][j] = dp[i-1][j]
            if j >= weights[i-1]:
                dp[i][j] = max(dp[i][j], dp[i-1][j - weights[i-1]] + values[i-1])
    return dp[n][W]
```

### 9.2 一维 DP 优化 (实战用)

```python
def knapsack_01_1d(weights, values, W):
    dp = [0] * (W + 1)
    for i in range(len(weights)):
        for j in range(W, weights[i] - 1, -1):  # 逆序!
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
    return dp[W]
```

**为什么可以压成一维?**
- `dp[i][j]` 只依赖 `dp[i-1][j]` 和 `dp[i-1][j-w]`
- 这两个都在上一行
- 逆序遍历 j, 让 `dp[j-w]` 还是上一行的值

### 9.3 0-1 背包的变种

**变种 1: 恰好装满**

```python
def knapsack_exact(weights, values, W):
    """恰好装满容量 W"""
    n = len(weights)
    dp = [float('-inf')] * (W + 1)
    dp[0] = 0
    for i in range(n):
        for j in range(W, weights[i] - 1, -1):
            if dp[j - weights[i]] != float('-inf'):
                dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
    return dp[W] if dp[W] != float('-inf') else -1
```

**变种 2: 至少装 x**

```python
def knapsack_at_least(weights, values, W, min_v):
    """总价值至少为 min_v 的最小容量"""
    INF = float('inf')
    dp = [INF] * (sum(values) + 1)
    dp[0] = 0
    total_v = 0
    for i in range(len(weights)):
        total_v += values[i]
        for v in range(total_v, values[i] - 1, -1):
            if dp[v - values[i]] != INF:
                dp[v] = min(dp[v], dp[v - values[i]] + weights[i])

    # 找最小 W 使得 v >= min_v
    for v in range(min_v, total_v + 1):
        if dp[v] <= W: return dp[v]
    return -1
```

### 9.4 LeetCode 416 - 分割等和子集 (Medium)

**题目**: 把数组分成两个子集, 使和相等.

**转化为 0-1 背包**: 选若干数使和为 total/2.

```python
def canPartition(nums):
    total = sum(nums)
    if total % 2 != 0: return False
    target = total // 2
    dp = [False] * (target + 1)
    dp[0] = True
    for x in nums:
        for j in range(target, x - 1, -1):
            dp[j] = dp[j] or dp[j - x]
    return dp[target]
```

### 9.8 LeetCode 879 - 盈利计划 (Hard)

```python
def profitableSchemes(self, n, minProfit, group, profit):
    """n 个人, 至少 minProfit 利润, 利润数"""
    MOD = 10**9 + 7
    m = len(group)
    # dp[i][j][k] = 前 i 个计划, 用 j 个人, 利润 k
    dp = [[[0] * (minProfit + 1) for _ in range(n + 1)] for _ in range(m + 1)]
    for j in range(n + 1):
        dp[0][j][0] = 1  # 不选任何计划, 利润 0

    for i in range(1, m + 1):
        for j in range(n + 1):
            for k in range(minProfit + 1):
                # 不选 i
                dp[i][j][k] = dp[i-1][j][k]
                # 选 i (如果人数够)
                if j >= group[i-1]:
                    new_k = max(0, k - profit[i-1])
                    dp[i][j][k] = (dp[i][j][k] + dp[i-1][j - group[i-1]][new_k]) % MOD

    return sum(dp[m][j][k] for j in range(n + 1) for k in range(minProfit + 1)) % MOD
```

**优化**: 滚动数组 (压缩 i 维度).

### 9.10 LeetCode 1658 - 下标对求最小和 (Medium)

```python
def minOperations(nums, x):
    """nums 中移除最少的元素使剩余元素和 = x"""
    total = sum(nums)
    if x > total: return -1
    target = total - x

    # 求最长子数组和 = target
    n = len(nums)
    max_len = -1
    left_sum = 0
    right_sum = 0
    left_count = 0

    for right_count in range(n + 1):
        if right_count > 0:
            right_sum += nums[right_count - 1]

        # 维持 left_sum >= target - right_sum
        while left_count <= right_count and left_sum + right_sum > target:
            left_sum -= nums[left_count]
            left_count += 1

        if left_sum + right_sum == target:
            max_len = max(max_len, n - (right_count - left_count))

    return max_len if max_len != -1 else -1
```

## 10. 完全背包深度剖析

### 10.1 LeetCode 1449 - 数位成本和为目标值的最大数字 (Hard)

**题目**: 给定 cost (每个数字 1-9 的成本) 和 target, 求最大数字 (字符串), 各位数字成本之和 = target.

**思路**: 完全背包求每个数字选几次, 然后拼接最大数字.

```python
def largestNumber(self, cost, target):
    # dp[i] = 数字 i 选几次 (i = 1..9)
    # 转换为完全背包: 重量 = cost[i-1], 价值 = i (数字越大越好)
    # 但要选数字尽量大的多个

    dp = [float('-inf')] * (target + 1)
    dp[0] = 0

    for c in cost:
        for j in range(c, target + 1):
            if dp[j - c] != float('-inf'):
                dp[j] = max(dp[j], dp[j - c] + 1)

    if dp[target] < 0: return "0"

    # 重构: 从最大数字往最小填
    result = []
    remain = target
    for i in range(9, 0, -1):
        c = cost[i-1]
        while remain >= c and dp[remain] == dp[remain - c] + 1:
            result.append(str(i))
            remain -= c

    return ''.join(result)
```

### 10.3 LeetCode 139 - 单词拆分 (Medium)

**题目**: 给定字典 wordDict, 问 s 能否被字典中的单词拆分为子串.

**思路**: 完全背包 (用单词"装满"字符串).

```python
def wordBreak(s, wordDict):
    n = len(s)
    word_set = set(wordDict)
    dp = [False] * (n + 1)
    dp[0] = True

    for i in range(1, n + 1):
        for j in range(i):
            if dp[j] and s[j:i] in word_set:
                dp[i] = True
                break
    return dp[n]
```

### 10.4 LeetCode 140 - 单词拆分 II (Hard)

**题目**: 返回所有拆分方案.

```python
def wordBreak(self, s, wordDict):
    word_set = set(wordDict)
    n = len(s)

    # 先用 DP 判断是否能拆 (剪枝)
    possible = [False] * (n + 1)
    possible[0] = True
    for i in range(1, n + 1):
        for j in range(i):
            if possible[j] and s[j:i] in word_set:
                possible[i] = True
                break
    if not possible[n]: return []

    # 回溯
    result = []
    def dfs(start, path):
        if start == n:
            result.append(' '.join(path))
            return
        for end in range(start + 1, n + 1):
            if possible[end] and s[start:end] in word_set:
                path.append(s[start:end])
                dfs(end, path)
                path.pop()

    dfs(0, [])
    return result
```

```python
def integerBreak(n):
```

## 11. 多重背包深度剖析

### 11.1 二进制拆分详解

**原理**: 把"每个物品能选 k 次"拆为"多个 0-1 物品".

**拆分方法**: `k` 拆为 `1, 2, 4, ..., 2^p, k - (2^(p+1) - 1)` 的和, 每个都转化为 0-1.

例如 k = 13, 拆为 1+2+4+6 (即 1, 2, 4, 13 - 7 = 6).

**理由**: 任何 k 以内的数都可用 1+2+4+...+剩余 的组合表示.

```python
def multi_knapsack_binary(weights, values, counts, W):
    n = len(weights)
    new_weights = []
    new_values = []
    for w, v, c in zip(weights, values, counts):
        k = 1
        while c > 0:
            use = min(k, c)
            new_weights.append(w * use)
            new_values.append(v * use)
            c -= use
            k *= 2

    # 0-1 背包
    dp = [0] * (W + 1)
    for i in range(len(new_weights)):
        for j in range(W, new_weights[i] - 1, -1):
            dp[j] = max(dp[j], dp[j - new_weights[i]] + new_values[i])
    return dp[W]
```

### 11.2 单调队列优化

**问题**: 二进制拆分后, 物品数增加, 时间复杂度 $O(V \sum \log k_i)$. 当 $k$ 很大时, 仍较慢.

**优化**: 单调队列优化, 把复杂度降到 $O(V \sum m_i)$, $m_i$ 是物品种类数.

```python
def multi_knapsack_monoqueue(weights, values, counts, W):
    """多重背包: 单调队列优化"""
    n = len(weights)
    dp = [0] * (W + 1)

    for i in range(n):
        w, v, c = weights[i], values[i], counts[i]
        for r in range(w):  # 按余数分组
            # deque 存 (k, dp[k]) 单位置
            from collections import deque
            q = deque()
            for k in range(r, W + 1, w):
                val = dp[k] - (k // w) * v  # 转化为等差数列
                while q and q[-1][1] <= val:
                    q.pop()
                q.append((k, val))
                # 取最大 (检查是否超过 c)
                if k - q[0][0] > c * w:
                    q.popleft()
                dp[k] = q[0][1] + (k // w) * v
    return dp[W]
```

**复杂度**: $O(W \sum m_i)$ 实际约 $O(W)$.

```python
def group_knapsack(weights, values, groups, W):
    """分组背包: 每组最多选 1 个"""
    n_groups = len(groups)
    dp = [0] * (W + 1)

    for g in range(n_groups):
        for j in range(W, -1, -1):  # 逆序
            best = 0
            for item in groups[g]:
                w, v = weights[item], values[item]
                if j >= w:
                    best = max(best, dp[j - w] + v)
            dp[j] = max(dp[j], best)
    return dp[W]
```

```python
def knapsack_2d(weights_1, weights_2, values, W1, W2):
    n = len(weights_1)
```

```python
def numRollsToTarget(n, k, target):
    """n 个骰子 (1-k), 和为 target 的方案数"""
    MOD = 10**9 + 7
    # dp[i][j] = 前 i 个骰子, 和为 j 的方案数
    dp = [[0] * (target + 1) for _ in range(n + 1)]
    dp[0][0] = 1

    for i in range(1, n + 1):
        for j in range(1, target + 1):
            for face in range(1, k + 1):
                if j >= face:
                    dp[i][j] = (dp[i][j] + dp[i-1][j - face]) % MOD

    return dp[n][target]
```

## 15. 多解法对比

### 15.1 LeetCode 322 - 零钱兑换: 五种解法对比

**解法 1: 完全背包 DP**

```python
def coinChange_v1(coins, amount):
    """完全背包"""
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0
    for c in coins:
        for j in range(c, amount + 1):
            dp[j] = min(dp[j], dp[j - c] + 1)
    return dp[amount] if dp[amount] != float('inf') else -1
```

**解法 2: BFS**

```python
from collections import deque

def coinChange_v2(coins, amount):
    """BFS: 每层是 +1 硬币"""
    if amount == 0: return 0
    visited = {0}
    q = deque([(0, 0)])
    while q:
        cur, count = q.popleft()
        if cur == amount: return count
        for c in coins:
            nxt = cur + c
            if nxt > amount or nxt in visited: continue
            visited.add(nxt)
            q.append((nxt, count + 1))
    return -1
```

**解法 3: 记忆化搜索**

```python
from functools import lru_cache

def coinChange_v3(coins, amount):
    @lru_cache(maxsize=None)
    def dfs(remain):
        if remain == 0: return 0
        if remain < 0: return float('inf')
        return min(dfs(remain - c) + 1 for c in coins if c <= remain)

    ans = dfs(amount)
    return ans if ans != float('inf') else -1
```

**解法 4: DFS + 剪枝 (从小到大试)**

```python
def coinChange_v4(coins, amount):
    """DFS + 剪枝"""
    coins.sort(reverse=True)
    ans = float('inf')

    def dfs(remain, start, count):
        nonlocal ans
        if remain == 0:
            ans = min(ans, count)
            return
        if start >= len(coins): return
        max_use = remain // coins[start]
        for use in range(max_use, -1, -1):
            if count + use >= ans: break
            dfs(remain - use * coins[start], start + 1, count + use)

    dfs(amount, 0, 0)
    return ans if ans != float('inf') else -1
```

**解法 5: Dijkstra**

```python
def coinChange_v5(coins, amount):
    """Dijkstra"""
    import heapq
    if amount == 0: return 0
    dist = [float('inf')] * (amount + 1)
    dist[0] = 0
    pq = [(0, 0)]
    while pq:
        d, cur = heapq.heappop(pq)
        if cur == amount: return d
        if d > dist[cur]: continue
        for c in coins:
            nxt = cur + c
            if nxt > amount: continue
            if d + 1 < dist[nxt]:
                dist[nxt] = d + 1
                heapq.heappush(pq, (d + 1, nxt))
    return -1
```

**对比**:
| 解法 | 时间 | 空间 | 特点 |
|---|---|---|---|
| DP | $O(nk)$ | $O(k)$ | 通用 |
| BFS | $O(nk)$ | $O(k)$ | 求最小步数 |
| 记忆化 | $O(n^k)$ | $O(k)$ | 代码简洁 |
| DFS 剪枝 | $O(?)$ | $O(k)$ | 竞赛优化 |
| Dijkstra | $O(k \log k)$ | $O(k)$ | 加权图 |

```python
def findTargetSumWays_dfs(nums, target):
    n = len(nums)
    self.count = 0

    def dfs(i, cur):
        if i == n:
            if cur == target:
                self.count += 1
            return
        dfs(i + 1, cur + nums[i])
        dfs(i + 1, cur - nums[i])

    dfs(0, 0)
    return self.count
# 时间 O(2^n)
```

```python
def findTargetSumWays_set(nums, target):
    sums = {0}
    for x in nums:
        new_sums = set()
        for s in sums:
            new_sums.add(s + x)
            new_sums.add(s - x)
        sums = new_sums
    return sum(1 for s in sums if s == target)
# 时间 O(n * 2^n)
```

### 15.3 LeetCode 279 - 完全平方数: 三种解法对比

**解法 2: BFS**

```python
from collections import deque

def numSquares_bfs(n):
    """BFS: 每次减一个完全平方数"""
    if n == 0: return 0
    q = deque([(n, 0)])
    visited = {n}
    while q:
        cur, steps = q.popleft()
        if cur == 0: return steps
        for i in range(1, int(cur**0.5) + 1):
            nxt = cur - i*i
            if nxt not in visited:
                visited.add(nxt)
                q.append((nxt, steps + 1))
```

**解法 3: 数学 (拉格朗日四平方定理)**

```python
def numSquares_math(n):
    """四平方和定理: 任何正整数可以表示为 4 个平方数之和"""
    # 步骤 1: 4^a * (8b + 7) -> 4
    while n % 4 == 0:
        n //= 4
    if n % 8 == 7:
        return 4

    # 步骤 2: 判断是否为完全平方数 -> 1
    import math
    if int(math.isqrt(n))**2 == n:
        return 1

    # 步骤 3: 判断是否能拆为 2 个 -> 2
    for i in range(1, int(math.isqrt(n)) + 1):
        remainder = n - i*i
        if int(math.isqrt(remainder))**2 == remainder:
            return 2

    return 3
```

### 16.1 0-1 背包的初始化

```python
# 求最大值:

# dp = [0] * (W + 1)
```

### 16.2 完全背包的初始化

```python
# 与 0-1 背包相同, 但要确认 max/min 操作的初值

# 求最小: dp = [float('inf')] * (W + 1), dp[0] = 0
```

### 16.3 完全背包顺序 vs 逆序

```python
# 0-1 背包: for j in range(W, w-1, -1)  # 逆序
# 完全背包: for j in range(w, W+1)        # 顺序

# 为什么? 顺序 vs 逆序 决定 dp[j-w] 是新还是旧
# 0-1: 旧 (物品只能用 1 次)
# 完全: 新 (物品能用多次)
```

### 16.4 组合 vs 排列的循环顺序

```python
# 组合 (518 零钱兑换 II):
# 外层物品, 内层容量 - 顺序无关
for c in coins:
    for j in range(c, target + 1):  # 完全背包: 顺序
        dp[j] += dp[j - c]

# 排列 (377 组合总和 IV):
# 外层容量, 内层物品 - 顺序相关
for j in range(1, target + 1):
    for x in nums:
        if j >= x:
            dp[j] += dp[j - x]
```

**记忆口诀**:
- 组合: 物品在外 (确保每种顺序各算一次)
- 排列: 容量在外 (确保每个位置都试所有物品)

```text
- 受限选物品, 求最优
- 4 类差异在"每个物品能选几次"

0-1 vs 完全:
- 0-1 背包: 逆序遍历 j (每个用 1 次)
- 完全背包: 顺序遍历 j (每个用多次)

组合 vs 排列:
- 组合 (518): 物品外, 容量内
- 排列 (377): 容量外, 物品内

多重背包:
- 二进制拆分: 把 k 拆为 1+2+4+...
- 单调队列: O(nW) 极致优化

二维 0-1:
- 两个维度都逆序
- 滚动数组压一维度
```

## 25. 总结

### 25.1 核心要点

- **背包问题的本质** 是受限最优化
- **4 种背包** 的差异是物品选择次数
- **顺序 vs 逆序** 是 0-1 vs 完全的关键
- **外层循环** 决定组合 vs 排列
- **二维背包** 是工程常见约束

### 25.2 选择指南

```text
看到 "在 N 个物品中选" 时:
1. 是否有 "次数限制"?
   - 0/1 -> 0-1 背包, 逆序
   - 无限 -> 完全背包, 顺序
   - k -> 多重背包, 二进制拆分
2. 是否有 "二维资源约束"?
   - 是 -> 二维 0-1
3. 是否 "求方案数"?
   - 是 -> 计数 DP
4. 是否 "求最少/最值"?
   - 是 -> min/max DP
```

## 26. 进阶: 与其他算法的关系

### 26.1 背包 vs 贪心

```text
贪心: 局部最优 -> 全局最优 (不总成立)
背包: 严格动态规划

例: 0-1 背包不能用贪心 (局部可能最优但全局不是)
但部分背包可以用贪心 (分数背包, 按性价比排序)

记忆: 背包是"理想", 部分背包是"现实", 取决于物品是否可分
```

```text
DFS 枚举: O(2^n) (0-1 背包的所有选择)
背包 DP: O(nW) (消除重叠子问题)

记忆: 背包 = 优化后的 DFS
```

### 26.3 背包 vs 动态规划

```text
动态规划 (DP): 通用方法
背包: DP 在"物品选择"上的特化

记忆: 背包是 DP 的一个具体应用
```

### 28.1 加题 1: LeetCode 2560 - 打家劫舍 IV (Medium)

**题目**: 相邻至少有 k 个未偷, 求最大可偷金额.

**思路**: 把每 k 个分成一组, 但更简单是二分 + DP.

```python
def minCapability(nums, k):
    """打家劫舍 IV: 用二分求"最少能力" """
    lo, hi = min(nums), max(nums)

    def can_rob(threshold):
        # 选若干个间隔 >= 1 的数, 使都 <= threshold 且至少选 k 个
        dp = [0, 0]  # (count, prev_selected)
        for x in nums:
            if x <= threshold:
                new = max(dp[0], dp[1] + 1)
                dp[1] = dp[0]
                dp[0] = new
            else:
                dp[1] = dp[0]
                dp[0] = dp[0]
        return dp[0] >= k

    while lo < hi:
        mid = (lo + hi) // 2
        if can_rob(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo
```

### 28.2 加题 2: LeetCode 2218 - 从栈中取出 K 个硬币的最大面值和

```python
def maxValueOfCoins(piles, k):
    """Hard 变形: 从栈中取 k 个, 求最大面值和"""
    n = len(piles)
    # dp[i][j] = 前 i 组, 取 j 个的最大和
    dp = [[0] * (k + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        pile = piles[i-1]
        for j in range(k + 1):
            dp[i][j] = dp[i-1][j]  # 不选
            for t in range(1, min(j, len(pile)) + 1):
                # 选 t 个, 总前 j-t
                cur_sum = sum(pile[:t])
                dp[i][j] = max(dp[i][j], dp[i-1][j-t] + cur_sum)

    return dp[n][k]
```

```python
def findKthPositive(arr, k):
    """第 k 个缺失的正整数"""

    # 缺失的按升序, 求第 k 个

    if k <= arr[0] - 1:
        return k

    k -= arr[0] - 1

    for i in range(1, len(arr)):
        gap = arr[i] - arr[i-1] - 1
        if k <= gap:
            return arr[i-1] + k
        k -= gap

    # 最后一段
    return arr[-1] + k
```

### 28.4 加题 4: LeetCode 1674 - 使数组互补的最少操作数 (Medium)

```python
def minMoves(nums, limit):
    """使 nums[i] + nums[n-1-i] 等于 limit 的最少操作"""
    n = len(nums)
    delta = [0] * (2 * limit + 2)

    # delta[v]: 通过操作使一对变成 v, 需要的操作数 (0/1/2)
    for i in range(n // 2):
        a, b = nums[i], nums[n-1-i]
        lo, hi = min(a, b) + 1, max(a, b) + limit  # 所有可能的和
        # delta[lo..hi] -= 1: 1 操作就够 (改变一个)
        # delta[a+b]: 0 操作就够
        # 其他: 2 操作

    for i in range(n // 2):
        a, b = nums[i], nums[n-1-i]
        s = a + b
        lo = min(a, b) + 1
        hi = max(a, b) + limit

        delta[2] += 2
        delta[lo] -= 1
        delta[hi + 1] += 1

        delta[s] -= 1
        delta[s + 1] += 1

    cur = 0
    min_ops = float('inf')
    for i in range(2, 2 * limit + 1):
        cur += delta[i]
        min_ops = min(min_ops, cur)
    return min_ops
```

```python
def peopleAwareOfSecret(n, delay, forget):
    """第 n 天有多少人知道秘密 (delay 天后能分享, forget 天后忘记)"""
    MOD = 10**9 + 7
    # dp[i] = 第 i 天新知道秘密的人数
    dp = [0] * (n + 1)
    dp[1] = 1

    for i in range(2, n + 1):
        # 第 i 天新知道的人 = 前 [i-delay, i-forget] 范围内能分享的人
        for j in range(max(1, i - forget + 1), max(1, i - delay + 1)):
            if j >= 1 and j <= n:
                dp[i] = (dp[i] + dp[j]) % MOD
        # 第 i 天忘记的人
        if i - forget >= 1:
            dp[i] = (dp[i] - dp[i - forget]) % MOD

    return sum(dp[max(1, n - forget + 1):n + 1]) % MOD
```

```python
def tallestBillboard(rods):
    """三状态 DP: dp[d] = 差为 d 的最高广告牌"""
    dp = {0: 0}  # 当前左右差为 d, 最高高度
    for x in rods:
        new_dp = dp.copy()
        for d, h in dp.items():
            # 把钢筋放到较高的一边
            new_dp[d + x] = max(new_dp.get(d + x, 0), h)
            # 把钢筋放到较低的一边 (diff 缩小)
            new_d = abs(d - x)
            new_h = h + min(x, d) if d > 0 else h
            new_dp[new_d] = max(new_dp.get(new_d, 0), new_h)
        dp = new_dp
    return dp.get(0, 0)
```

### 28.8 加题 8: LeetCode 2959 - 关闭分部的可行集合数 (Hard)

```python
def numberOfSets(n, maxDistance, roads):
    """Hard: 关闭若干分部使剩余相互距离 <= maxDistance 的方案数"""
    # 枚举 + 验证
    ans = 0
    for mask in range(1, 1 << n):
        nodes = [i for i in range(n) if mask & (1 << i)]
        # Floyd-Warshall 求剩余节点间最短距离
        dist = {(i, j): 0 for i in nodes for j in nodes}
        for i in nodes:
            for j in nodes:
                dist[(i, j)] = roads[i][j]
        # Floyd
        for k in nodes:
            for i in nodes:
                for j in nodes:
                    dist[(i, j)] = min(dist[(i, j)], dist[(i, k)] + dist[(k, j)])
        # 检查所有距离
        ok = all(dist[(i, j)] <= maxDistance for i in nodes for j in nodes)
        if ok:
            ans += 1
    return ans
```

## 31. 配套练习题答案详解 (续)

### 31.1 LeetCode 416 详细解析

**问题剖析**:
- 把数组分成两个子集, 使和相等
- 等价于: 选若干数, 使和 = total / 2

```python
def canPartition(nums):
    total = sum(nums)
    if total % 2: return False  # 和为奇数, 一定不能分割
    target = total // 2

    dp = [False] * (target + 1)
    dp[0] = True  # 不选任何数, 和为 0

    for x in nums:
        # 0-1 背包: 逆序!
        for j in range(target, x - 1, -1):
            dp[j] = dp[j] or dp[j - x]

    return dp[target]
```

**复杂度**: $O(n \cdot \text{total})$, 空间 $O(\text{total})$.

**进阶**: 返回所有可能的分割方案 (回溯).

### 31.2 LeetCode 494 公式推导详解

**关键推导**:
```text
设: + 的数和为 P, - 的数和为 N
则: P - N = target (目标)
     P + N = sum (总和)

两式相加: 2P = sum + target
所以: P = (sum + target) / 2

问题: 在 nums 中选若干数, 使和 = P
```

**边界条件**:
- `(sum + target) % 2 != 0`: 无解
- `abs(target) > sum`: 无解
- `target > sum`: 无解

```python
def findTargetSumWays(nums, target):
    total = sum(nums)
    if (total + target) % 2 or abs(target) > total:
        return 0
    P = (total + target) // 2

    # 等价于: 选若干数, 使和为 P
    dp = [0] * (P + 1)
    dp[0] = 1
    for x in nums:
        for j in range(P, x - 1, -1):
            dp[j] += dp[j - x]
    return dp[P]
```

### 31.3 LeetCode 322 BFS 思路详解

**为什么 BFS 也行?**
- BFS 树的第 k 层 = 凑出 amount 用了 k 个硬币
- 第一次到达 amount 的层数就是最少硬币数

```python
from collections import deque

def coinChange_bfs(coins, amount):
    if amount == 0: return 0
    visited = set([0])
    q = deque([(0, 0)])  # (current_sum, coins_used)
    while q:
        cur, count = q.popleft()
        if cur == amount: return count
        for c in coins:
            nxt = cur + c
            if nxt > amount or nxt in visited: continue
            visited.add(nxt)
            q.append((nxt, count + 1))
    return -1
```

**对比 DP**: BFS 在 coins 数量小时效率高, DP 在 amount 大时更高效.

### 31.4 LeetCode 377 排列数详解

**关键点**:
- 顺序不同算不同
- 用"容量外, 物品内"的循环顺序

**错误示范**:

```python
    for j in range(x, target + 1):
        dp[j] += dp[j - x]
# 这会算 (1+1+2) 和 (1+2+1) 一样, 因为每一步都基于"已选的所有"
```

**正确写法**:
```python
# 正确: 容量外, 物品内
def combinationSum4(nums, target):
    dp = [0] * (target + 1)
    dp[0] = 1
    for j in range(1, target + 1):
        for x in nums:
            if j >= x:
                dp[j] += dp[j - x]
    return dp[target]
```

**与 518 零钱兑换 II 对比**:
- 518: 求组合 (顺序无关)
- 377: 求排列 (顺序相关)
- 区别在于循环嵌套

### 31.5 LeetCode 474 二维 0-1 背包详解

```python
def findMaxForm(strs, m, n):
    # dp[i][j] = 限制 m 个 0 和 n 个 1 的最多字符串数
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for s in strs:
        zeros = s.count('0')
        ones = s.count('1')
        # 0-1 背包, 二维, 双重逆序!
        for i in range(m, zeros - 1, -1):
            for j in range(n, ones - 1, -1):
                dp[i][j] = max(dp[i][j], dp[i - zeros][j - ones] + 1)

    return dp[m][n]
```

**关键**: 双重逆序 (`for i in range(m, zeros - 1, -1)` 类似).

**进阶**: 多维背包 (e.g., 三维) 时, 用多重循环.

### 31.6 LeetCode 879 详解

```python
def profitableSchemes(n, minProfit, group, profit):
    MOD = 10**9 + 7
    m = len(group)

    # dp[i][j][k] = 前 i 个计划, 用 j 个人, 利润 >= k
    # 优化: 利润维 > minProfit 时都计为 minProfit (避免太多状态)
    dp = [[[0] * (minProfit + 1) for _ in range(n + 1)] for _ in range(m + 1)]
    for j in range(n + 1):
        dp[0][j][0] = 1  # 不选任何计划, 利润 0 -> 算 1 种方案

    for i in range(1, m + 1):
        for j in range(n + 1):
            for k in range(minProfit + 1):
                # 不选 i
                dp[i][j][k] = dp[i-1][j][k]
                # 选 i
                if j >= group[i-1]:
                    prev_profit = max(0, k - profit[i-1])
                    dp[i][j][k] = (dp[i][j][k] + dp[i-1][j - group[i-1]][prev_profit]) % MOD

    return sum(dp[m][j][k] for j in range(n + 1) for k in range(minProfit + 1)) % MOD
```

**优化**: 滚动数组 (压缩 i 维度).

## 33. 背包问题的进阶变种

### 33.1 依赖背包 (Knapsack with Dependencies)

**问题**: 物品 i 只能选了 j 才能选.

**解法**: 把"i 选了 j"转化为"先选 j, 再选 i"的拓扑顺序 DP. 实际上不常用.

### 33.2 三维背包

**问题**: 容量有三个维度 (e.g., 重量, 体积, 时间).

**解法**: 三维 DP, 时间复杂度 $O(n \cdot W_1 \cdot W_2 \cdot W_3)$.

```python
def knapsack_3d(weights_1, weights_2, weights_3, values, W1, W2, W3):
    n = len(weights_1)
    dp = [[[0] * (W3 + 1) for _ in range(W2 + 1)] for _ in range(W1 + 1)]
    for i in range(n):
        for j in range(W1, weights_1[i] - 1, -1):
            for k in range(W2, weights_2[i] - 1, -1):
                for l in range(W3, weights_3[i] - 1, -1):
                    dp[j][k][l] = max(dp[j][k][l], dp[j-weights_1[i]][k-weights_2[i]][l-weights_3[i]] + values[i])
    return dp[W1][W2][W3]
```

### 33.3 带"相关性"的背包

**问题**: 选某些物品时, 会获得额外的奖励.

**解法**: 把"额外奖励"作为另一个维度.

### 33.4 模糊背包 (Fuzzy Knapsack)

**问题**: 物品的价值和体积是模糊数, 而不是确定数.

**解法**: 把 DP 状态扩展为模糊数.

```python
    n = len(weights)
    best = 0
    for mask in range(1 << n):
        total_w = 0
        total_v = 0
        for i in range(n):
            if mask & (1 << i):
                total_w += weights[i]
                total_v += values[i]
        if total_w <= W:
            best = max(best, total_v)
    return best

def knapsack_01(weights, values, W):
    n = len(weights)
    dp = [0] * (W + 1)
    for i in range(n):
        for j in range(W, weights[i] - 1, -1):
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
    return dp[W]

# 对照
for _ in range(50):

    weights = [random.randint(1, 10) for _ in range(n)]
    values = [random.randint(1, 20) for _ in range(n)]
    W = random.randint(1, 30)
    assert knapsack_01(weights, values, W) == knapsack_brute(weights, values, W)
```

## 36. 与 DP 其他类别的对比

### 36.1 背包 vs 线性 DP

```text
线性 DP: dp[i] 是一维, 转移用相邻元素
背包 DP: dp[i][j] (或 dp[j]) 是"容量维度", 转移用物品

逻辑相似, 但维度含义不同
```

### 36.2 背包 vs 区间 DP

```text
区间 DP: dp[i][j] 是"区间"
背包 DP: dp[i][j] 是"前 i 物品 + 容量 j"

都二维, 但前者处理"分割", 后者处理"选择"
```

### 36.3 背包 vs 状态机 DP

```text
状态机 DP: dp[i][state] 是"内部状态"
背包 DP: dp[i][j] 是"容量"

状态机 DP 多用于"股票问题", 背包用于"物品选择"
```

## 37. 最终总结

### 37.1 一句话总结

背包是"受限最优化", 通过"状态 + 转移 + 顺序"三要素求解. 4 种背包的差异是物品选择次数, 决定了循环方向.

### 37.2 速查表

| 类型 | 模板 | 关键 |
|---|---|---|
| 0-1 | `for i in items: for j in range(W, w-1, -1): dp[j] = max(...)` | 逆序 |
| 完全 | `for i in items: for j in range(w, W+1): dp[j] = max(...)` | 顺序 |
| 多重 | 二进制拆分 + 0-1 | 拆 |
| 分组 | `for g in groups: for j: max(item in g)` | 枚举 |

### 37.3 实战口诀

```text
背包本质: 选物品, 限容量, 最大化

识别:
- "在 N 个物品中选" -> 背包
- "总重量不超 X" -> 背包
- "凑出金额" -> 零钱兑换 (完全背包)

判断类型:
- 选 1 次 -> 0-1, 逆序
- 选无限 -> 完全, 顺序
- 选 k -> 多重, 拆分
- 每组选 1 -> 分组, 枚举
```

### 38.1 加题 9: LeetCode 1388 - 披萨 3n 块 (Hard)

**题目**: 3n 块披萨, 交替属于你和他, 你先选. 求你能获得的最大值.

```python
def maxSizeSlices(slices):
    """3n 块披萨选 n 块最大化"""
    n = len(slices)
    k = n // 3

    # dp[i][j] = 前 i 块, 选 j 块的最大值
    # 状态机: 选 / 不选 (但相邻不能都选)

    def solve(arr):
        m = len(arr)
        dp = [[[0] * (k + 1) for _ in range(2)] for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, k + 1):
                # 不选 arr[i-1]
                dp[i][0][j] = max(dp[i-1][0][j], dp[i-1][1][j])
                # 选 arr[i-1] (必须前一块没选)
                dp[i][1][j] = dp[i-1][0][j-1] + arr[i-1] if j >= 1 else 0
        return max(dp[m][0][k], dp[m][1][k])

    return max(solve(slices[:-1]), solve(slices[1:]))
```

**关键**: 因为是环形, 试两种情况 (去头 vs 去尾).

### 38.2 加题 10: LeetCode 1774 - 最接近目标价的甜点 (Medium)

```python
def closestCost(baseCosts, toppingCosts, target):
    """最接近 target 的甜点价格"""
    # 收集所有 toppingCosts 的可能和
    possible = {0}
    for t in toppingCosts:
        new_possible = set()
        for p in possible:
            new_possible.add(p)
            new_possible.add(p + t)
            new_possible.add(p + 2*t)
        possible = new_possible

    # 对每个 base, 找最近的
    ans = float('inf')
    for b in baseCosts:
        # 二分查找
        sorted_p = sorted(possible)
        lo, hi = 0, len(sorted_p) - 1
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if sorted_p[mid] + b <= target:
                lo = mid
            else:
                hi = mid - 1
        # 检查 lo 和 lo-1
        for idx in [lo, lo - 1]:
            if idx < 0 or idx >= len(sorted_p): continue
            cur = sorted_p[idx] + b
            if abs(cur - target) < abs(ans - target):
                ans = cur
            elif abs(cur - target) == abs(ans - target) and cur < ans:
                ans = cur

    return ans
```

```python
def canReach(s, minJump, maxJump):
    """从 0 跳到 s 的末尾, 步长 [minJump, maxJump], 0 不可踩"""
    n = len(s)
    dp = [False] * n
    dp[0] = True

    prefix = [0] * (n + 1)
    for i in range(1, n):
        left = max(0, i - maxJump)
        right = i - minJump
        if right >= 0:
            # dp[left..right] 中任一是 true
            dp[i] = prefix[right + 1] - prefix[left] > 0
        prefix[i + 1] = prefix[i] + (1 if dp[i] else 0)

    return dp[n-1]
```

## 39. 参考实现: Python 通用背包框架

```python
from typing import List
import sys

def knapsack_general(
    items: List[dict],
    capacity: int,
    mode: str = '01',
    *,
    max_or_min: str = 'max',
    count_dp: bool = False,
    multi_dim: List[int] = None,
    counts: List[int] = None,
) -> int:
    """
    通用背包框架

    Args:
        items: 物品列表, 每个包含 weight, value
        capacity: 容量
        mode: '01' / 'complete' / 'multiple' / 'group'
        max_or_min: 'max' / 'min'
        count_dp: 是否计数型
        multi_dim: 多维容量 (如 [W1, W2])
        counts: 每个物品的次数 (multiple 模式)

    Returns:
        最优值
    """
    n = len(items)
    if multi_dim is None:
        # 一维背包
        dp = [0] * (capacity + 1) if max_or_min == 'max' else [float('inf')] * (capacity + 1)
        if max_or_min == 'min': dp[0] = 0

        if mode == '01':
            for item in items:
                for j in range(capacity, item['weight'] - 1, -1):
                    new = dp[j - item['weight']] + item['value']
                    if max_or_min == 'max':
                        dp[j] = max(dp[j], new)
                    elif count_dp:
                        dp[j] += dp[j - item['weight']]
                    else:
                        dp[j] = min(dp[j], new)
        elif mode == 'complete':
            for item in items:
                for j in range(item['weight'], capacity + 1):
                    new = dp[j - item['weight']] + item['value']
                    if max_or_min == 'max':
                        dp[j] = max(dp[j], new)
                    elif count_dp:
                        dp[j] += dp[j - item['weight']]
                    else:
                        dp[j] = min(dp[j], new)
        # ... 其他模式
        return dp[capacity]
```

### 110. 背包问题 - 思维框架 视角

**1. 背景与动机**

任何技术或方法的出现都不是孤立的,而是回应特定历史条件下的具体问题。"背包问题" 的发展也不例外。要理解它,必须回到它出现的那个时间点,看清它要解决的真实问题是什么。当时的主流方案有哪些不足? 它的提出填补了哪些空白? 这些问题的回答,决定了我们今天该如何使用它。

从知识论角度看,**技术演进是问题驱动的**——不是先有方案再找问题,而是先有问题再有方案。这个观察可以帮助我们避免"拿着锤子找钉子"的陷阱,真正把方法用对地方。

历史维度上,我们看到三个规律:

1. **从特殊到一般**: 早期方法往往针对特定场景,后期抽象出通用框架。学习的认知规律也是先掌握具体案例,再抽象出一般模式。这种"自下而上"的学习方式,在机器学习模型的设计里反复出现。

2. **从手工到自动**: 经验规则逐步被数据驱动的方法取代。在早期,很多 AI 系统依赖人工编写的规则。统计学习方法的崛起让"从数据中学习"成为可能。深度学习进一步把特征工程也自动化了。今天的大模型时代,我们看到端到端学习从感知扩展到了推理与生成。

3. **从局部到全局**: 关注单个组件,演进到关注整个系统。早期模型评估只关注单点指标,现在更关注全链路的协同效应。这种"系统视角"的转变,与软件工程从单体架构到微服务架构的演进高度相似。

**2. 思维框架视角的展开**

从思维框架视角出发,我们可以把 "背包问题" 拆解为以下几个层次:

**第一层: 概念层** —— 这是最抽象的层次,定义了我们要研究的对象是什么。例如,"推荐系统"在概念层是一个"为用户从物品集合中筛选合适物品"的问题。这个层次的特点是清晰、稳定、不易变化。一个好的概念定义应该具备几个特征:可操作性、可测量性、可扩展性。

**第二层: 模型层** —— 把概念实例化为数学模型。同一概念可以有不同的模型化方式,例如"推荐系统"可以是协同过滤、矩阵分解、深度学习等。模型的选择决定了后续算法的空间,也决定了能利用的归纳偏置(比如序列模型擅长捕捉时序依赖,图模型擅长建模关系结构)。模型选型是工程实践中最重要的决策之一。

**第三层: 算法层** —— 在选定模型下,具体的求解方法。这一层最活跃,新算法层出不穷。同一模型往往有多种算法,各有优劣。例如同样是优化深度网络,可以选择 SGD、Adam、L-BFGS 等不同算法。算法的选择要考虑收敛速度、数值稳定性、计算成本等多个维度。

**第四层: 工程层** —— 算法落地的实现细节,包括数据流水线、训练框架、推理优化、监控告警等。工程层是研究到生产的桥梁,决定了一个方法能否真正用起来。一个在论文里表现很好的算法,如果不能高效实现、不能稳定运行、不能快速迭代,就没有实际价值。工程能力是把研究转化为生产力的关键。

**第五层: 业务层** —— 在具体业务场景中的表现。同一技术在不同业务里效果差异巨大,因为业务目标、数据分布、用户行为都有差异。从业务视角看技术,我们必须回答几个问题:这个技术解决了什么业务问题?投入产出比如何?长期可持续吗?技术评估必须与业务目标对齐,否则容易陷入"技术自嗨"的陷阱。

**3. 数学形式化(简洁版)**

虽然我们强调思维框架视角,但数学形式化提供了共同语言。机器学习的核心问题可以表达为:给定输入样本,学习一个映射函数,使得函数输出与真实目标的差距最小化。这个抽象捕捉了分类、回归、生成等大多数任务的本质。

进一步,优化目标通常加入正则化项来控制模型复杂度,平衡经验风险与模型容量。统计学习理论给出了泛化误差的上界,告诉我们模型越复杂并不一定越好——**奥卡姆剃刀**在数学上有严格的形式化。

偏差-方差分解是另一个核心框架:误差可以分解为模型偏差(欠拟合)、方差(过拟合)和不可约噪声三部分。理解这个分解有助于诊断模型表现、选择合适复杂度。

在数值稳定性方面,有几个常见陷阱: 浮点数精度有限、Log-Sum-Exp 计算要减去最大值、Softmax 在大数值下会溢出。这些工程细节常常决定一个模型能否在生产环境稳定运行。

**4. 信息论视角**

信息论为"背包问题" 提供了统一的视角:**学习的本质是从数据中提取与目标相关的信息**。

互信息衡量知道一个变量后,另一个变量不确定性减少的量。在机器学习中,它被广泛用于特征选择、表示学习、多模态对齐等场景。

KL 散度衡量两个概率分布的距离,在交叉熵损失、变分推断、策略梯度等场景无处不在。需要注意它是**不对称**的——不同方向有不同的解释。

信息瓶颈原则指出,我们应该寻找既紧凑又预测性强的表示。这一思想影响了大量表示学习方法的设计,包括对比学习、自监督学习、多模态预训练等。

**7. 实践建议**

结合 "背包问题" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "背包问题" 常见的误解包括:

偏差-方差分解是另一个核心框架:误差可以分解为模型偏差(欠拟合)、方差(过拟合)和不可约噪声三部分。理解这个分解有助于诊断模型表现、选择合适复杂度。

在数值稳定性方面,有几个常见陷阱: 浮点数精度有限、Log-Sum-Exp 计算要减去最大值、Softmax 在大数值下会溢出。这些工程细节常常决定一个模型能否在生产环境稳定运行。

**4. 信息论视角**

信息论为"背包问题" 提供了统一的视角:**学习的本质是从数据中提取与目标相关的信息**。

互信息衡量知道一个变量后,另一个变量不确定性减少的量。在机器学习中,它被广泛用于特征选择、表示学习、多模态对齐等场景。

KL 散度衡量两个概率分布的距离,在交叉熵损失、变分推断、策略梯度等场景无处不在。需要注意它是**不对称**的——不同方向有不同的解释。

信息瓶颈原则指出,我们应该寻找既紧凑又预测性强的表示。这一思想影响了大量表示学习方法的设计,包括对比学习、自监督学习、多模态预训练等。

**7. 实践建议**

结合 "背包问题" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "背包问题" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
