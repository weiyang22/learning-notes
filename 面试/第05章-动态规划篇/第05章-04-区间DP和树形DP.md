## 1. 区间 DP

### 1.1 核心思想

**状态**: `dp[i][j]` = 区间 [i, j] 上的最优解.

**转移**: 在 [i, j] 中选一个分割点 k, $dp[i][j] = \min/\max(dp[i][k] + dp[k+1][j] + \text{cost})$.

**遍历顺序**: 按**区间长度**从小到大.

### 1.2 通用模板

```python
def interval_dp(s):
    n = len(s)
    dp = [[0] * n for _ in range(n)]

    # 枚举区间长度
    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            dp[i][j] = float('inf')
            # 枚举分割点
            for k in range(i, j):
                dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + cost(i, k, j))

    return dp[0][n-1]
```

### 1.3 LeetCode 5 - 最长回文子串 (Medium)

详见 [05.02 - 线性DP](第05章-02-线性DP.md) 状态扩展.

```python
def longestPalindrome(s):
    n = len(s)
    dp = [[False] * n for _ in range(n)]

    # 初始化: 单字符是回文
    for i in range(n):
        dp[i][i] = True

    # 枚举区间长度
    longest = 1
    start = 0
    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            if s[i] == s[j]:
                if length == 2 or dp[i+1][j-1]:
                    dp[i][j] = True
                    if length > longest:
                        longest = length
                        start = i

    return s[start:start + longest]
```

### 1.4 LeetCode 516 - 最长回文子序列 (Medium)

**题目**: 求最长回文**子序列** (可以不连续).

```python
def longestPalindromeSubseq(s):
    n = len(s)
    dp = [[0] * n for _ in range(n)]
    for i in range(n):
        dp[i][i] = 1

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            if s[i] == s[j]:
                dp[i][j] = dp[i+1][j-1] + 2
            else:
                dp[i][j] = max(dp[i+1][j], dp[i][j-1])

    return dp[0][n-1]
```

**空间优化**: $O(n)$

```python
def longestPalindromeSubseq(s):
    n = len(s)
    dp = [0] * n
    for i in range(n - 1, -1, -1):
        new_dp = [0] * n
        new_dp[i] = 1
        for j in range(i + 1, n):
            if s[i] == s[j]:
                new_dp[j] = dp[j-1] + 2
            else:
                new_dp[j] = max(dp[j], new_dp[j-1])
        dp = new_dp
    return dp[n-1]
```

### 1.5 LeetCode 312 - 戳气球 (Hard)

**题目**: 有 n 个气球, 戳破第 i 个得 nums[left] * nums[i] * nums[right] 分数, 求最大分数.

**状态**: `dp[i][j]` = 戳破 (i, j) 内所有气球 (不含 i, j) 的最大分数.

```python
def maxCoins(nums):
    """区间 DP"""
    nums = [1] + nums + [1]
    n = len(nums)
    dp = [[0] * n for _ in range(n)]

    # 枚举区间长度
    for length in range(2, n):
        for i in range(n - length):
            j = i + length
            # 最后戳破 k (在 i+1 到 j-1 之间)
            for k in range(i + 1, j):
                dp[i][j] = max(dp[i][j], dp[i][k] + dp[k][j] + nums[i] * nums[k] * nums[j])

    return dp[0][n-1]
```

### 2.4 LeetCode 968 - 监控二叉树 (Hard)

**题目**: 每个节点放摄像头, 监控自己和父节点. 求最少摄像头.

**状态**: 每个节点 3 种状态
- 0: 未被监控
- 1: 已被监控 (但本身没摄像头)
- 2: 本身有摄像头

```python
def minCameraCover(root):
    """后序遍历"""
    self.res = 0

    def dfs(node):
        if not node: return 1  # 空节点视为已监控

        left = dfs(node.left)
        right = dfs(node.right)

        if left == 0 or right == 0:
            # 子节点没被监控, 当前必须放摄像头
            self.res += 1
            return 2

        if left == 2 or right == 2:
            # 子节点有摄像头, 当前被监控
            return 1

        # 子节点都被监控, 当前没被监控
        return 0

    if dfs(root) == 0:
        self.res += 1  # 根节点也要放

    return self.res
```

## 5. 区间 DP 深度剖析

### 5.1 区间 DP 的本质: 分治 + 合并

区间 DP 的本质是把一个**大区间**的问题, 分成**两个小区间**的子问题, 再加上**合并**两个子区间的代价. 这是分治思想在数组上的自然体现.

**为什么用 DP 而不是分治?**
- 分治: 子问题**不重叠**, 一次性递归求解
- 区间 DP: 子问题**大量重叠** (例如 `[0,5]` 包含了 `[0,3]` 和 `[2,5]`)
- 必须用 dp[i][j] 记忆化避免重复计算

### 5.2 四类区间 DP 模式

| 模式 | 代表题 | 状态设计 |
|---|---|---|
| **区间分割** | 戳气球 / 切棍子 | 枚举最后分割点 |
| **回文判定** | 最长回文子串 / 子序列 | dp[i][j] = s[i..j] 是否回文 |
| **回文计数** | 戳回文串 / 回文子串数目 | 计数 + 状态压缩 |
| **区间合并** | 合并石头 / 多边形三角剖分 | 枚举分割点 + 代价合并 |

### 5.3 区间 DP 的遍历顺序

**关键**: 必须**先算小区间, 再算大区间**.

```python
# 错误的遍历: 先 i 后 j
for i in range(n):
    for j in range(i, n):
        # dp[i][j] 依赖 dp[i][j-1], 还未算!

# 正确的遍历: 按长度从小到大
for length in range(2, n + 1):  # 先算 length=2, 再算 3, ...
    for i in range(n - length + 1):
        j = i + length - 1
        # 此时所有 dp[i'][j'] (i'<=i, j'>=j) 都已算
```

### 5.4 状态压缩: $O(n)$ 空间

```python
# 倒序枚举 i, 用一维 dp 替代二维
# 但需要保留 dp[i+1][j-1] (左上角), 用 prev 变量
def longestPalindromeSubseq(s):
    n = len(s)
    dp = [0] * n
    for i in range(n - 1, -1, -1):
        new_dp = [0] * n
        new_dp[i] = 1
        prev = 0  # 上一轮的 dp[i+1][j-1]
        for j in range(i + 1, n):
            temp = dp[j]
            if s[i] == s[j]:
                new_dp[j] = prev + 2
            else:
                new_dp[j] = max(dp[j], new_dp[j-1])
            prev = temp
        dp = new_dp
    return dp[n-1]
```

**总结**: 倒序遍历 i 是关键, 这样 dp[j] 在更新前保存的是 dp[i+1][j] (上一行的值).

## 6. 区间 DP 进阶题库

### 6.1 LeetCode 1547 - 切棍子的最小成本 (Hard)

**题目**: 给定长度为 n 的木棍和 cuts 数组 (切割点), 求最小切割成本 (每次切割成本 = 当前段的长度).

**状态**: `dp[i][j]` = 切割 cuts[i..j] 区间的最小成本.

**关键**: 按 cuts 排序, 加上 0 和 n 作为虚拟切割点.

```python
def minCost(self, n, cuts):
    cuts = sorted([0] + cuts + [n])
    m = len(cuts)
    dp = [[0] * m for _ in range(m)]

    for length in range(2, m):
        for i in range(m - length):
            j = i + length
            dp[i][j] = float('inf')
            for k in range(i + 1, j):
                cost = dp[i][k] + dp[k][j] + cuts[j] - cuts[i]
                dp[i][j] = min(dp[i][j], cost)

    return dp[0][m-1]
```

**复杂度**: $O(m^3)$, $m$ = cuts 长度 + 2

### 6.2 LeetCode 1039 - 多边形三角剖分 (Medium)

**题目**: 给凸多边形顶点 (按顺序), 求最小权值三角剖分 (三元组 (i, k, j) 的权值 = A[i]*A[k]*A[j]).

```python
def minScoreTriangulation(self, values):
    n = len(values)
    dp = [[0] * n for _ in range(n)]

    for length in range(2, n):
        for i in range(n - length):
            j = i + length
            dp[i][j] = float('inf')
            for k in range(i + 1, j):
                dp[i][j] = min(dp[i][j],
                               dp[i][k] + dp[k][j] + values[i] * values[k] * values[j])

    return dp[0][n-1]
```

### 6.3 LeetCode 1000 - 合并石头的最低成本 (Hard)

**题目**: 有 N 堆石头, 每次合并 K 堆连续的石头为一堆, 成本是这 K 堆的总和. 求把所有石头合为一堆的最低成本.

**状态**: `dp[i][j]` = 合并区间 [i, j] 内所有石头为一堆的成本. 但是**合并为 t 堆**需要第 3 维.

```python
def mergeStones(self, stones, K):
    n = len(stones)
    if (n - 1) % (K - 1) != 0:
        return -1

    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i+1] = prefix[i] + stones[i]

    def sum_range(i, j):
        return prefix[j+1] - prefix[i]

    # dp[i][j][t]: 合并 [i,j] 为 t 堆的最小成本
    dp = [[[float('inf')] * (K+1) for _ in range(n)] for _ in range(n)]

    for i in range(n):
        dp[i][i][1] = 0

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            for k in range(i, j, K - 1):
                # 合并 [i,k] 和 [k+1,j]
                for t1 in range(1, K):
                    t2 = K - t1
                    if t2 < 1: continue
                    if dp[i][k][t1] == float('inf') or dp[k+1][j][t2] == float('inf'):
                        continue
                    dp[i][j][1] = min(dp[i][j][1], dp[i][k][t1] + dp[k+1][j][t2] + sum_range(i, j))

    return dp[0][n-1][1] if dp[0][n-1][1] != float('inf') else 0
```

**关键**: 当 `K=2` 时退化为经典矩阵链乘 / Burst Balloons.

### 6.4 LeetCode 132 - 分割回文串 II (Hard)

**题目**: 把字符串分割成回文子串, 求最少分割次数.

**状态**: `dp[i]` = `s[:i+1]` 的最少分割次数.

**预处理**: `is_palindrome[i][j]` = `s[i..j]` 是否回文 (用区间 DP).

```python
def minCut(self, s):
    n = len(s)
    # 预处理回文
    is_palindrome = [[False] * n for _ in range(n)]
    for i in range(n - 1, -1, -1):
        for j in range(i, n):
            if s[i] == s[j] and (j - i < 2 or is_palindrome[i+1][j-1]):
                is_palindrome[i][j] = True

    # dp[i] = s[:i+1] 最少分割
    dp = [float('inf')] * n
    for i in range(n):
        if is_palindrome[0][i]:
            dp[i] = 0
        else:
            for j in range(i):
                if is_palindrome[j+1][i]:
                    dp[i] = min(dp[i], dp[j] + 1)

    return dp[n-1]
```

**复杂度**: $O(n^2)$

**优化思路**: 可以用中心扩展 / Manacher 在 O(n) 内构造 is_palindrome.

### 6.5 LeetCode 87 - 扰乱字符串 (Hard)

**题目**: 给定字符串 s1 和 s2, 判断 s2 是否是 s1 的扰乱字符串 (递归交换子串 + 字符集合相同).

**状态**: `dp[i][j][len]` = s1[i..i+len-1] 能否变成 s2[j..j+len-1].

```python
def isScramble(self, s1, s2):
    if len(s1) != len(s2):
        return False
    if s1 == s2:
        return True
    n = len(s1)

    dp = [[[False] * (n+1) for _ in range(n)] for _ in range(n)]

    for i in range(n):
        for j in range(n):
            if s1[i] == s2[j]:
                dp[i][j][1] = True

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            for j in range(n - length + 1):
                for k in range(1, length):
                    # 不交换
                    if dp[i][j][k] and dp[i+k][j+k][length-k]:
                        dp[i][j][length] = True
                        break
                    # 交换
                    if dp[i][j+length-k][k] and dp[i+k][j][length-k]:
                        dp[i][j][length] = True
                        break

    return dp[0][0][n]
```

**题目**: 最少插入几次字符让字符串变成回文.

```python
def minInsertions(self, s):
```

### 6.7 LeetCode 1771 - 由子序列构造的最长回文串长度 (Hard)

**题目**: 从 word1 和 word2 中各选一个子序列, 组成最长回文串.

```python
def longestPalindrome(self, word1, word2):
    # 拼接 word1 + word2, 求最长回文子序列, 且必须包含至少一个 word1 字符和一个 word2 字符
    s = word1 + word2
    n = len(s)
    m = len(word1)

    dp = [[0] * n for _ in range(n)]
    for i in range(n):
        dp[i][i] = 1

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            if s[i] == s[j]:
                dp[i][j] = dp[i+1][j-1] + 2
            else:
                dp[i][j] = max(dp[i+1][j], dp[i][j-1])

    longest = 0
    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            # 必须包含至少一个 word1 字符和至少一个 word2 字符
            has_w1 = any(c < m for c in range(i, j+1))
            has_w2 = any(c >= m for c in range(i, j+1))
            if has_w1 and has_w2:
                longest = max(longest, dp[i][j])

    return longest
```

### 6.8 LeetCode 1682 - 戳糖果 (Hard)

**题目**: 类似戳气球, 但有 N 段连续相同颜色时一起戳.

```python
# 戳糖果是戳气球的扩展. 戳气球中每次戳一个, 戳糖果中每次戳连续相同颜色的段.
# 状态: dp[i][j] = 戳掉区间 [i,j] 内所有糖果的最大分数
# 先把连续段合并成数组
def candy(self, s):
    # 合并连续相同颜色
    candies = []
    counts = []
    i = 0
    while i < len(s):
        j = i
        while j < len(s) and s[j] == s[i]:
            j += 1
        candies.append(s[i])
        counts.append(j - i)
        i = j

    n = len(candies)
    dp = [[0] * n for _ in range(n)]

    for length in range(1, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            # 方案 1: 单独戳这一段
            gain = (counts[i] + (counts[j] if i == j else 0)) ** 2
            # 方案 2: 找 k 与 i 颜色相同, 一起戳
            for k in range(i+1, j+1):
                if candies[k] == candies[i]:
                    if k == i+1 or k == j:
                        dp[i][j] = max(dp[i][j], dp[i+1 if k > i else i][k-1 if k > i else k] + dp[k+1][j] + gain)
                    # ... 简化
            dp[i][j] = max(dp[i][j], dp[i+1][j] + counts[i] ** 2)

    return dp[0][n-1]
```

### 6.9 LeetCode 664 - 奇怪的打印机 (Hard)

**题目**: 一台奇怪的打印机可以打印相同字符的任意序列, 但每次打印必须覆盖全部. 求最少打印次数.

**状态**: `dp[i][j]` = 打印 s[i..j] 的最少打印次数.

```python
def strangePrinter(self, s):
    if not s: return 0
    n = len(s)
    dp = [[float('inf')] * n for _ in range(n)]

    for i in range(n):
        dp[i][i] = 1

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            dp[i][j] = dp[i+1][j] + 1  # 单独打印 s[i]
            for k in range(i+1, j + 1):
                if s[k] == s[i]:
                    # s[i] 可以和 s[k] 一起打印
                    cost = dp[i+1][k-1] if k > i+1 else 0
                    dp[i][j] = min(dp[i][j], dp[k][j] + cost)

    return dp[0][n-1]
```

## 7. 树形 DP 深度剖析

### 7.1 树形 DP 的三种基本模式

```text
模式 1: 自底向上 (后序遍历, 自下而上传递状态)
- 父依赖子, 子先算完
- 例: 打家劫舍 III, 最大路径和

模式 2: 自顶向下 (前序遍历, 父状态传给子)
- 子依赖父, 需要传"祖先路径"
- 例: 二叉树最长路径 (跨子树)

模式 3: 树的重心 / 树的最远点 (树形 DP + 二次扫描)
- 例: 树的直径
```

### 7.2 树形 DP 的状态设计要点

```text
1. 单值返回: dfs(u) -> int
   例: 树的深度, 节点子树最大和

2. 多值返回: dfs(u) -> tuple
   例: 打家劫舍 III 返回 (rob, not_rob)

3. 全局变量: self.ans 在 dfs 中更新
   例: 最大路径和, 需要"以当前节点为拐点的路径"

4. 父子双向通信: dp[child] = dfs(child) + 一些来自父的信息
   例: 监控二叉树 (父状态影响子决策)
```

### 7.3 树形 DP 的递归 vs 迭代实现

**递归 (后序遍历)**:

```python
def dfs(u):
    if not u: return 0
    left = dfs(u.left)
    right = dfs(u.right)
    return max(left, right) + 1  # 子节点返回后, 当前节点处理
```

**迭代 (后序遍历 / Morris 后序)**:

```python
def postorder_iterative(root):
    stack = [(root, False)]
    result = []
    while stack:
        node, visited = stack.pop()
        if not node: continue
        if visited:
            result.append(node.val)
        else:
            stack.append((node, True))  # 后访问标记
            stack.append((node.right, False))
            stack.append((node.left, False))
    return result
```

**Morris 后序**: $O(1)$ 空间, 工程上一般不用, 面试也几乎不考.

**题目**: 任意两节点间的最长路径 (边数).

```python
def diameterOfBinaryTree(self, root):
```

### 8.2 LeetCode 979 - 在二叉树中分配硬币 (Medium)

```python
def distributeCoins(self, root):
```

### 8.3 LeetCode 834 - 树中距离之和 (Hard)

**题目**: 给定无根树, 求所有节点到其他节点距离之和.

**思路**: 树形 DP + 换根 DP (二次扫描).

**第一遍**: 后序遍历, 计算每个子树的 size 和各节点到子树内距离之和.

**第二遍**: 前序遍历, 通过父节点推算子节点答案.

```python
def sumOfDistancesInTree(self, n, edges):
    from collections import defaultdict
    graph = defaultdict(list)
    for u, v in edges:
        graph[u].append(v)
        graph[v].append(u)

    count = [1] * n
    ans = [0] * n

    # 第一遍: 后序, 计算子树大小和子树内的距离和
    def dfs1(u, parent):
        for v in graph[u]:
            if v == parent: continue
            dfs1(v, u)
            count[u] += count[v]
            ans[u] += ans[v] + count[v]  # v 子树内每个节点离 v 多 1, 离 u 也多 1

    dfs1(0, -1)

    # 第二遍: 前序, 通过 ans[root] 推出 ans[child]
    def dfs2(u, parent):
        for v in graph[u]:
            if v == parent: continue
            # v 的答案 = u 的答案 - count[v] (子树内节点离 v 比离 u 近 1) + (n - count[v]) (子树外节点离 v 比离 u 远 1)
            ans[v] = ans[u] - count[v] + (n - count[v])
            dfs2(v, u)

    dfs2(0, -1)
    return ans
```

### 8.4 LeetCode 1026 - 节点与其祖先之间的最大差值 (Medium)

**题目**: 节点值与祖先值差值的最大值 (绝对值).

```python
def maxAncestorDiff(self, root):
    if not root: return 0

    def dfs(node, min_val, max_val):
        if not node: return max_val - min_val
        min_val = min(min_val, node.val)
        max_val = max(max_val, node.val)
        return max(dfs(node.left, min_val, max_val),
                   dfs(node.right, min_val, max_val))

    return dfs(root, root.val, root.val)
```

### 8.6 LeetCode 1372 - 二叉树中的最长交错路径 (Medium)

**题目**: 路径中方向必须交替 (左-右-左-... 或 右-左-右-...).

```python
def longestZigZag(self, root):
    self.ans = 0

    def dfs(node, direction, length):
        """direction: 0=从左来, 1=从右来"""
        if not node: return
        self.ans = max(self.ans, length)

        # 继续往同方向: 长度不增加 (从左来则去右, 这就是方向交替)
        if direction == 0:  # 从左来 -> 下一节点在右
            dfs(node.right, 1, length + 1)
            dfs(node.left, 0, 1)  # 反向走, 长度重置
        else:
            dfs(node.left, 0, length + 1)
            dfs(node.right, 1, 1)

    dfs(root, 0, 0)
    dfs(root, 1, 0)
    return self.ans
```

### 8.7 LeetCode 437 - 路径总和 III (Medium)

**题目**: 路径 (不一定要从根出发, 不一定要到叶子) 和为目标值的路径数.

```python
def pathSum(self, root, target):
    from collections import defaultdict
    self.count = 0
    prefix_sum = defaultdict(int)
    prefix_sum[0] = 1

    def dfs(node, curr):
        if not node: return
        curr += node.val
        self.count += prefix_sum[curr - target]
        prefix_sum[curr] += 1
        dfs(node.left, curr)
        dfs(node.right, curr)
        prefix_sum[curr] -= 1

    dfs(root, 0)
    return self.count
```

### 8.8 LeetCode 1245 - 树的直径 (Medium, 无向树)

```python
def treeDiameter(self, edges):
    from collections import defaultdict, deque
    if not edges: return 0
    graph = defaultdict(set)
    for u, v in edges:
        graph[u].add(v)
        graph[v].add(u)

    # BFS 找最远节点
    def bfs(start):
        visited = {start}
        q = deque([(start, 0)])
        far_node, far_dist = start, 0
        while q:
            node, dist = q.popleft()
            far_node, far_dist = node, dist
            for nei in graph[node]:
                if nei in visited: continue
                visited.add(nei)
                q.append((nei, dist + 1))
        return far_node, far_dist

    # 两次 BFS
    u, _ = bfs(0)
    _, diameter = bfs(u)
    return diameter
```

### 8.9 LeetCode 2246 - 相邻字符不同的最长路径 (Hard)

**题目**: 树上有字符, 找最长路径, 要求相邻字符不同.

```python
def longestPath(self, parent, s):
    n = len(s)
    graph = [[] for _ in range(n)]
    for i in range(1, n):
        graph[parent[i]].append(i)
        graph[i].append(parent[i])

    self.ans = 1

    def dfs(u, p):
        # 返回以 u 为端点的最长合法路径
        best = 0
        for v in graph[u]:
            if v == p: continue
            child_len = dfs(v, u)
            if s[u] != s[v]:
                self.ans = max(self.ans, best + child_len + 1)
                best = max(best, child_len)
        return best + 1

    dfs(0, -1)
    return self.ans
```

### 8.11 LeetCode 310 - 最小高度树 (Medium)

**题目**: 找树的中心节点 (删掉后剩余每个连通块都是"叶子"的中心节点).

**思路**: 拓扑排序 + BFS. 反复删叶子, 最后剩下的就是中心.

```python
def findMinHeightTrees(self, n, edges):
    from collections import defaultdict, deque
    if n == 1: return [0]

    graph = defaultdict(set)
    degree = [0] * n
    for u, v in edges:
        graph[u].add(v)
        graph[v].add(u)
        degree[u] += 1
        degree[v] += 1

    q = deque([i for i in range(n) if degree[i] == 1])
    remaining = n

    while remaining > 2:
        size = len(q)
        remaining -= size
        for _ in range(size):
            leaf = q.popleft()
            for nei in graph[leaf]:
                degree[nei] -= 1
                if degree[nei] == 1:
                    q.append(nei)

    return list(q)
```

## 9. 多解法对比

### 9.1 LeetCode 312 戳气球: 三种解法对比

**解法 1: 区间 DP (推荐)**

```python
# 时间 O(n^3), 空间 O(n^2)
def maxCoins(nums):
    nums = [1] + nums + [1]
    n = len(nums)
    dp = [[0] * n for _ in range(n)]
    for length in range(2, n):
        for i in range(n - length):
            j = i + length
            for k in range(i + 1, j):
                dp[i][j] = max(dp[i][j], dp[i][k] + dp[k][j] + nums[i]*nums[k]*nums[j])
    return dp[0][n-1]
```

**解法 2: 记忆化搜索 + 区间**

```python
from functools import lru_cache

class Solution:
    def maxCoins(self, nums):
        nums = [1] + nums + [1]
        n = len(nums)

        @lru_cache(maxsize=None)
        def solve(left, right):
            if left + 1 == right: return 0
            ans = 0
            for k in range(left + 1, right):
                ans = max(ans, solve(left, k) + solve(k, right) + nums[left]*nums[k]*nums[right])
            return ans

        return solve(0, n - 1)
```

**解法 3: DP 优化 (最终戳破 vs 不优化)**

```python
# 错误解法: dp[i][j] = 戳破 i..j 内 (含端点) 的最大分数
# 错误的原因: dp 转移时 nums[left]/nums[right] 已经改变

# 正确解法: dp[i][j] = 戳破 (i,j) 内 (不含端点) 的最大分数
# 这样 nums[i]/nums[j] 在转移时仍是"边界", 不会改变
```

**三种解法对比**:

| 解法 | 时间 | 空间 | 易理解度 |
|---|---|---|---|
| 区间 DP | $O(n^3)$ | $O(n^2)$ | 中 |
| 记忆化搜索 | $O(n^3)$ | $O(n^2)$ | 高 |
| 一维优化 | $O(n^2)$ (待验证) | $O(n)$ | 低 |

**为什么不用"先戳破 i"的思路?** 因为戳破 i 后, nums[i] 不存在, 后面的边界条件会变, 状态空间爆炸.

### 9.2 LeetCode 124 最大路径和: 三种解法对比

**解法 1: 树形 DP (推荐)**

```python
def maxPathSum(self, root):
    self.max_sum = float('-inf')

    def dfs(node):
        if not node: return 0
        left = max(0, dfs(node.left))   # 不贡献就丢弃
        right = max(0, dfs(node.right))
        cur = node.val + left + right
        self.max_sum = max(self.max_sum, cur)
        return node.val + max(left, right)  # 单边贡献给父

    dfs(root)
    return self.max_sum
```

**解法 2: 分治 + 全局变量**

```python
class Solution:
    def maxPathSum(self, root):
        self.max_sum = float('-inf')
        self.helper(root)
        return self.max_sum

    def helper(self, node):
        if not node: return 0
        left = max(0, self.helper(node.left))
        right = max(0, self.helper(node.right))
        # 当前节点"为拐点"的最大路径和 (更新全局)
        self.max_sum = max(self.max_sum, node.val + left + right)
        # 向上传的最大单边路径 (只能选一边)
        return node.val + max(left, right)
```

**注意**: 三种解法本质相同, 关键是"区分根节点为端点的路径 vs 拐点路径".

### 9.3 LeetCode 337 打家劫舍 III: 三种解法对比

**解法 1: 暴力递归 (超时)**

```python
def rob(self, root):
    if not root: return 0
    rob_root = root.val + self.rob(root.left.left) + self.rob(root.left.right) + \
               self.rob(root.right.left) + self.rob(root.right.right)
    not_rob = self.rob(root.left) + self.rob(root.right)
    return max(rob_root, not_rob)
# 时间 O(2^n)
```

**解法 2: 记忆化搜索**

```python
from functools import lru_cache

def rob(self, root):
    @lru_cache(maxsize=None)
    def dfs(node):
        if not node: return 0
        rob = node.val + dfs(node.left.left if node.left else None) + \
              dfs(node.left.right if node.left else None) + \
              dfs(node.right.left if node.right else None) + \
              dfs(node.right.right if node.right else None)
        not_rob = dfs(node.left) + dfs(node.right)
        return max(rob, not_rob)
    return dfs(root)
# 时间 O(n), 空间 O(n)
```

**解法 3: 树形 DP (推荐)**

```python
def rob(self, root):
    def dfs(node):
        # 返回 (rob_root, not_rob)
        if not node: return (0, 0)
        l_rob, l_not = dfs(node.left)
        r_rob, r_not = dfs(node.right)
        return (node.val + l_not + r_not, max(l_rob, l_not) + max(r_rob, r_not))

    return max(dfs(root))
```

**三种解法对比**:

| 解法 | 时间 | 空间 | 重点 |
|---|---|---|---|
| 暴力 | $O(2^n)$ | $O(n)$ | 思路错误 |
| 记忆化 | $O(n)$ | $O(n)$ | 关键改进 |
| 状态压缩 DP | $O(n)$ | $O(h)$ | 推荐 (h 为树高) |

### 9.4 LeetCode 968 监控二叉树: 两种解法对比

**解法 1: 自底向上 DP**

```python
def minCameraCover(self, root):

    def dfs(node):
        # 0=未被监控, 1=被监控但无摄像头, 2=有摄像头
        if not node: return 1  # 空节点视为被监控
```

**解法 2: 贪心 + 状态机**

```python
# 类似思路, 但用"尽量不在叶节点父上放摄像头"的贪心
def minCameraCover(self, root):

    def dfs(node):
        if not node: return 2  # 2 = "覆盖"

        if left == 0 or right == 0:  # 子节点有未被覆盖
```

## 10. 边界情况与陷阱

### 10.1 区间 DP 的边界

```python
# 1. 长度为 1 的区间: 单独处理
for i in range(n):
    dp[i][i] = 1  # 或 0, 或 s[i], 视题意

# 2. 空区间: dp[i][i-1] (i > i-1) 表示空区间
# 一般用 dp[i][i] = 0 作为边界

# 3. 哨兵节点 (戳气球): nums = [1] + nums + [1]
# 这样不用处理边界, 也不用单独处理空区间

# 4. 关键循环: for length in range(2, n+1)
# 注意 length=2 也要算, 因为 dp[i][i+1] 可能依赖 dp[i+1][i]
```

### 10.2 树形 DP 的边界

```python
# 1. 空节点: dfs(None) 返回某个状态, 一般是 (0, 0) 或 None (监控二叉树中视为已监控)
# 2. 叶子节点: 没有子节点, 注意特判 (例如监控系统)
# 3. 单子树: 只有一个孩子的节点, 状态转移需注意
# 4. 路径不经过根: 用全局变量而非返回值 (最大路径和)
# 5. 路径必须向下 vs 任意: 区分"单方向路径"和"经过当前节点的拐点路径"
```

### 10.3 常见错误

```text
错误 1: 区间 DP 用 i 循环而非 length 循环
错误 2: 树形 DP 把全局变量当返回值传
错误 3: 用"戳破 i"思路做戳气球 (状态空间爆炸)
错误 4: 忽略"单边贡献" vs "拐点贡献" 的区别 (最大路径和)
错误 5: 监控二叉树中, 空节点状态被设为"未监控"
错误 6: 树的直径和深度混淆 (直径=边数, 深度=节点数)
错误 7: 路径计数时遗漏"不经过当前节点"的分支
```

## 14. 实战经验总结

### 14.1 面试常见问题

```text
Q: 区间 DP 和分治的区别?
A: 区间 DP 的子问题重叠. 例如戳气球中 dp[0][5] 依赖 dp[0][3] 和 dp[2][5],
   而 dp[0][3] 和 dp[2][5] 都依赖 dp[2][3]. 分治不会重叠子问题.

Q: 树形 DP 怎么设计状态?
A: 看子树的"贡献". 例如打家劫舍 III 中, 每个节点返回 (rob, not_rob) 两个值.
   监控二叉树中, 每个节点返回 3 个状态.

Q: 区间 DP 怎么优化?
A: 滚动数组 / 一维数组. 但 2D 状态多时, 难以优化.

Q: 树的直径怎么求?
A: 两种方法: (1) 树形 DP (后序, 维护全局最大) (2) 两次 BFS (找最远点)
```

### 14.2 工程实践要点

```text
1. 区间 DP 的 dp 表初始值: 用 float('inf') 而不是 -1, 避免 max 计算错误

3. 区间 DP 的"哨兵"技巧: 戳气球用 [1] + nums + [1], 让边界统一
4. 树形 DP 的"返回元组" 或 "全局数组": 例 543 用全局数组 depth[i] 避免重复计算
5. 复杂度分析时: 明确这是 n^3 的算法, 提醒面试官 n <= 100 是常见限制
```

## 15. 与其他 DP 类型的关系

### 15.1 区间 DP vs 线性 DP

```text
线性 DP: dp[i] = f(dp[0..i-1])
区间 DP: dp[i][j] = f(dp[i][k], dp[k+1][j])  # 区间 [i,j]
```

**例子**: LIS 是线性 DP (单序列), 最长回文是区间 DP (子序列).

### 15.2 树形 DP vs 图 DP

```text
树形 DP: 树上每个节点只与父亲相关, 无环
图 DP (有环): 需要处理环, 例如树 + 1 条边 = 环, 用树形 DP + 枚举
```

### 15.3 与状压 DP 的关系

状压 DP 是"区间 DP + 状态压缩", 例如旅行商问题.

### 16.3 换根 DP 标准模板

```python
def reroot_dp_template(n, edges):
    """换根 DP 标准模板"""
    from collections import defaultdict
    graph = defaultdict(list)
    for u, v in edges:
        graph[u].append(v)
        graph[v].append(u)

    # 第一遍: 后序, 计算子树信息
    sub_size = [0] * n
    def dfs1(u, parent):
        sub_size[u] = 1
        for v in graph[u]:
            if v == parent: continue
            dfs1(v, u)
            sub_size[u] += sub_size[v]

    dfs1(0, -1)

    # 第二遍: 前序, 通过父推子
    ans = [0] * n
    def dfs2(u, parent):
        for v in graph[u]:
            if v == parent: continue
            # 从 u 换根到 v 的转移
            # ans[v] = f(ans[u], sub_size[v], n)
            dfs2(v, u)

    dfs2(0, -1)
    return ans
```

## 17. 实战应用案例

### 17.1 案例 1: 编辑距离中的"区间 DP"思想

**问题**: 编辑距离本质上是**区间 DP**, 因为 dp[i][j] 是 [0..i] 和 [0..j] 的子问题.
- 状态 dp[i][j] 是二维
- 转移基于 dp[i-1][j-1], dp[i-1][j], dp[i][j-1]
- 这是**带字符约束的线性 DP**

### 17.2 案例 2: 矩阵链乘是经典区间 DP

```python
def matrix_chain_order(p):
    """矩阵链乘: 区间 DP"""
    n = len(p) - 1  # 矩阵数量
    dp = [[0] * n for _ in range(n)]

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            dp[i][j] = float('inf')
            for k in range(i, j):
                cost = dp[i][k] + dp[k+1][j] + p[i] * p[k+1] * p[j+1]
                dp[i][j] = min(dp[i][j], cost)

    return dp[0][n-1]
```

### 17.3 案例 3: Huffman 树的区间 DP

**问题**: 给定字符频率, 构造 Huffman 树, 求最小加权路径和.

```python
def huffman_cost(freqs):
    """Huffman 树: 类似合并石头, 但 K=2"""
    import heapq
    heapq.heapify(freqs)
    total = 0
    while len(freqs) > 1:
        a = heapq.heappop(freqs)
        b = heapq.heappop(freqs)
        total += a + b
        heapq.heappush(freqs, a + b)
    return total
```

**注**: Huffman 树问题用贪心 (堆) 更高效, 区间 DP 是次优解.

## 18. 总结

### 18.1 一句话总结

- **区间 DP**: 在**数组区间**上做分治. 关键是按区间长度遍历, 枚举分割点或边界.
- **树形 DP**: 在**树形结构**上做后序遍历. 关键是状态设计 (返回多个值) 和全局变量.

### 18.2 核心模板

```text
区间 DP:
- 状态: dp[i][j]
- 转移: dp[i][j] = f(dp[i][k], dp[k+1][j]) 或 f(dp[i+1][j-1])
- 遍历: for length in range(2, n+1)

树形 DP:
- 状态: dfs(u) 返回值 (可能多个)
- 转移: 后序遍历, 合并左右子树
- 全局: self.ans 在 dfs 中更新
```

### 18.3 选择建议

```text
做区间 DP 题的判断:
1. 是否在"区间"上求最优?
2. 子问题是否可拆为"小区间最优"?
3. 区间是否固定 (静态) 还是动态 (依赖操作)?

做树形 DP 题的判断:
1. 是否在"树"上求最优?
2. 子树之间是否独立 (打家劫舍) vs 耦合 (路径和)?
3. 是否需要全局变量 (拐点路径) vs 单纯返回值?
```

```python
import sys
sys.setrecursionlimit(10**6)

# 方法 2: 改写为迭代 (后序遍历)
def postorder_iterative(root):
    if not root: return []
    stack = [(root, False)]
    result = []
    while stack:
        node, visited = stack.pop()
        if not node: continue
        if visited:
            result.append(node)
        else:
            stack.append((node, True))
            stack.append((node.right, False))
            stack.append((node.left, False))
    return result

# 方法 3: 用父指针 + 显式栈
def maxPathSum_iterative(root):
    """O(n) 时间, O(h) 空间"""
    if not root: return 0

    stack = [(root, False)]
    max_sum = float('-inf')

    while stack:
        node, processed = stack.pop()
        if not node: continue

        if processed:
            # 后序处理
            left_val = max(0, getattr(node.left, 'max_one', 0))
            right_val = max(0, getattr(node.right, 'max_one', 0))
            node.max_one = max(left_val, right_val) + node.val
            cur = node.val + left_val + right_val
            max_sum = max(max_sum, cur)
        else:
            stack.append((node, True))
            stack.append((node.right, False))
            stack.append((node.left, False))

    return max_sum
```

### 20.1 误区 1: 区间 DP 的"全区间"遍历错误

```python
# 错误: 遍历 i 再 j, dp[i][j] 依赖 dp[i+1][j-1] 时会出错
# 因为 dp[i+1][j-1] 在 i 增大的方向上还没算
for i in range(n):
    for j in range(i, n):
        # dp[i][j] = ...

# 正确: 按区间长度从小到大
for length in range(2, n + 1):
    for i in range(n - length + 1):
        j = i + length - 1
        # 此时所有 dp[i'][j'] (i' < i 或 length' < length) 都已算
```

```python
# 高度: 根到叶的最长路径 (边数或节点数)

def diameter(root):
    ans = [0]
    def depth(node):
        if not node: return 0
        left = depth(node.left)
        right = depth(node.right)
        ans[0] = max(ans[0], left + right)  # 全局变量保存直径
        return max(left, right) + 1
    depth(root)
    return ans[0]
```

## 25. 配套练习题答案详解

### 25.1 LeetCode 5 - 最长回文子串 (中心扩展法对比)

```python
# 解法 1: 区间 DP - 已给出

# 解法 2: 中心扩展 - O(n^2) 时间, O(1) 空间
def longestPalindrome_center(s):
    n = len(s)
    start, longest = 0, 1

    def expand(left, right):
        while left >= 0 and right < n and s[left] == s[right]:
            left -= 1
            right += 1
        return right - left - 1  # 回文长度

    for i in range(n):
        # 奇数长度: 以 i 为中心
        len1 = expand(i, i)
        # 偶数长度: 以 i 和 i+1 为中心
        len2 = expand(i, i + 1)
        cur_max = max(len1, len2)
        if cur_max > longest:
            longest = cur_max
            start = i - (cur_max - 1) // 2

    return s[start:start + longest]
```

```python
    return longestCommonSubsequence(s, s[::-1])

def longestCommonSubsequence(s1, s2):
    m, n = len(s1), len(s2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s1[i-1] == s2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]
```

**复杂度对比**:
- 区间 DP: $O(n^2)$
- LCS 转化: $O(n^2)$, 但常数更大 (因为 LCS 通用, 区间 DP 是针对回文优化过的)

### 25.4 LeetCode 124 - 最大路径和 (三种实现对比)

```python
# 解法 1: 树形 DP (全局变量)
class Solution1:
    def maxPathSum(self, root):
        self.max_sum = float('-inf')
        def dfs(node):
            if not node: return 0
            left = max(0, dfs(node.left))
            right = max(0, dfs(node.right))
            self.max_sum = max(self.max_sum, node.val + left + right)
            return node.val + max(left, right)
        dfs(root)
        return self.max_sum

# 解法 2: 返回 (maxOneEnd, maxAll) 两个值
class Solution2:
    def maxPathSum(self, root):
        def dfs(node):
            if not node: return (0, float('-inf'))
            l_one, l_all = dfs(node.left)
            r_one, r_all = dfs(node.right)
            one_end = node.val + max(0, max(l_one, r_one))
            all_path = max(l_all, r_all, node.val + max(0, l_one) + max(0, r_one))
            return (one_end, all_path)
        return dfs(root)[1]

# 解法 3: 自顶向下 (传祖先最大最小值, 比较当前节点与祖先的差)
# 此法相对少见, 不推荐
```

## 26. 拓展: 与其它算法的关系

### 26.1 区间 DP vs. 中心扩展

```text
区间 DP: 状态 dp[i][j] = 区间内的最优解, 需要 2D 状态
中心扩展: 从中心向外扩展, 常用于回文, 只需 1D 状态

时间复杂度相同 (O(n^2)), 但中心扩展常数更小
```

### 26.2 树形 DP vs. 图 DFS

```text
树是图的一个特例. 树形 DP 的关键是"无环", 所以可以后序遍历
图 DP (有环) 需要处理环, 例如:
- 用 Tarjan 缩点成 DAG
- 用状态压缩 (竞赛思想)
- 用迭代加深 (工程方法)
```

### 26.3 区间 DP vs. 矩阵链乘 / 切棍子

```text
戳气球 (num[i]*num[k]*num[j]) -> 三角形剖分 (A[i]*A[k]*A[j]) -> 切棍子 (cuts[j]-cuts[i])
三者都是"区间分割 + 计算代价", 状态 dp[i][j] 完全相同, 转移类似
```

### 26.4 树形 DP vs. 二叉搜索树 / 红黑树

```text
BST/红黑树的常见操作 (插入/删除) 是 O(h) = O(log n)
但它们的"建树"或"统计"操作, 大量依赖树形 DP:

例: LeetCode 99 恢复 BST 中被错误交换的两个节点
- 用树形 DP 中序遍历找异常
```

### 27.1 应用 1: 文本回文分析

```python
def longest_palindromic_substring(text):
    """NLP: 文本回文分析, 用于情感分析"""
    # 区间 DP 找出最长回文
    n = len(text)
    if n == 0: return ""
    dp = [[False] * n for _ in range(n)]
    start, longest = 0, 1
    for i in range(n):
        dp[i][i] = True
    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            if text[i] == text[j] and (length == 2 or dp[i+1][j-1]):
                dp[i][j] = True
                if length > longest:
                    longest = length
                    start = i
    return text[start:start + longest]
```

```python
# 推荐系统: 用户兴趣迁移路径预测
# 把用户行为建模为树, 用树形 DP 预测下一步行为

class InterestTreeDP:
    """用户兴趣树: 父子兴趣相似度"""
    def __init__(self, root):
        self.root = root
        self.global_ans = 0

    def predict_depth(self, node):
        if not node: return 0
        left = self.predict_depth(node.left)
        right = self.predict_depth(node.right)
        self.global_ans = max(self.global_ans, left + right + 1)
        return max(left, right) + 1
```

### 27.3 应用 3: NLP 中的字符串相似度 (区间 DP 思维)

```python
# 编辑距离本质是区间 DP, 在 NLP 中用于:
# - 拼写检查 (Levenshtein)
# - DNA 序列比对
# - 推荐系统中"相似 query"匹配

def levenshtein_distance(s1, s2):
    """编辑距离 - NLP 拼写检查"""
    m, n = len(s1), len(s2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s1[i-1] == s2[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
    return dp[m][n]
```

**7. 实践建议**

结合 "区间 DP 和树形 DP" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "区间 DP 和树形 DP" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
