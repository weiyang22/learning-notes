## 1. 状压 DP

### 1.1 思想

用**二进制位**表示集合状态. 当 n ≤ 20 时, 状态数 $2^n$ 可接受.

### 1.2 通用模板

```python
def bitmask_dp(n):
    """dp[mask] 表示 mask 状态下的最优解"""
    dp = [float('inf')] * (1 << n)
    dp[0] = 0  # 初始状态

    for mask in range(1 << n):
        # 从 mask 状态转移
        # 找出 mask 中还未访问的位
        not_visited = ((1 << n) - 1) ^ mask
        sub = not_visited
        while sub:
            # 取最低位的 1
            pick = sub & (-sub)
            sub -= pick
            new_mask = mask | pick
            dp[new_mask] = min(dp[new_mask], dp[mask] + cost(mask, pick))

    return dp[(1 << n) - 1]
```

### 1.4 LeetCode 464 - 我能赢吗 (Medium)

**题目**: 两人轮流从 1~maxChoosableInteger 中选数(不重复), 谁先累计到 desiredTotal 赢. 求先手能否必胜.

**状态**: `dp[mask]` = mask 状态下先手是否必胜 (mask 表示已选的数).

```python
def canIWin(maxChoosableInteger, desiredTotal):
    if desiredTotal <= 0: return True
    if maxChoosableInteger * (maxChoosableInteger + 1) // 2 < desiredTotal:
        return False

    from functools import lru_cache
    @lru_cache(None)
    def can_win(mask, cur_total):
        for x in range(1, maxChoosableInteger + 1):
            bit = 1 << (x - 1)
            if mask & bit: continue  # 已选过
            # 选 x 后, 累计到 cur_total + x
            # 如果达到 desiredTotal 必胜
            if cur_total + x >= desiredTotal:
                return True
            # 否则, 让对手进入 mask|bit 状态, 如果对手不能赢, 那我赢
            if not can_win(mask | bit, cur_total + x):
                return True
        return False

    return can_win(0, 0)
```

## 2. 计数 DP

### 2.1 思想

求**方案数**的 DP. 重点在于初始值和转移的乘法.

### 2.2 LeetCode 96 - 不同的二叉搜索树 (Medium)

**题目**: 给 n, 求由 1~n 组成的 BST 的种数.

**答案**: 第 n 个**卡特兰数** $C_n = \frac{C(2n, n)}{n+1}$.

**DP**: $dp[n] = \sum_{i=0}^{n-1} dp[i] \cdot dp[n-1-i]$.

```python
def numTrees(n):
    dp = [0] * (n + 1)
    dp[0] = 1
    for i in range(1, n + 1):
        for j in range(i):
            dp[i] += dp[j] * dp[i - 1 - j]
    return dp[n]
```

**复杂度**: $O(n^2)$

### 2.3 LeetCode 935 - 骑士拨号器 (Medium)

**题目**: 骑士走"日"字, 从 0 开始跳 N-1 次, 求停在每个数字的方案数.

```python
def knightDialer(N):
    MOD = 10**9 + 7
    # 跳跃关系: 从 i 能跳到哪
    moves = {
        0: [4, 6],
        1: [6, 8],
        2: [7, 9],
        3: [4, 8],
        4: [0, 3, 9],
        5: [],
        6: [0, 1, 7],
        7: [2, 6],
        8: [1, 3],
        9: [2, 4],
    }

    dp = [1] * 10
    for _ in range(N - 1):
        new_dp = [0] * 10
        for i in range(10):
            for j in moves[i]:
                new_dp[j] = (new_dp[j] + dp[i]) % MOD
        dp = new_dp

    return sum(dp) % MOD
```

## 3. 数位 DP

### 3.1 思想

按数字的**每一位** DP. 解决"求 1~n 中满足某个性质的数的个数".

### 3.2 通用模板

```python
def digit_dp(n):
    """数位 DP"""
    s = str(n)
    memo = {}

    def dfs(pos, state, tight, leading_zero):
        if pos == len(s):
            return 1 if not leading_zero else 0

        if (pos, state, tight, leading_zero) in memo:
            return memo[(pos, state, tight, leading_zero)]

        limit = int(s[pos]) if tight else 9
        result = 0
        for d in range(limit + 1):
            new_tight = tight and (d == limit)
            new_leading = leading_zero and (d == 0)
            new_state = update_state(state, d, new_leading)
            result += dfs(pos + 1, new_state, new_tight, new_leading)

        memo[(pos, state, tight, leading_zero)] = result
        return result

    return dfs(0, 0, True, True)
```

### 3.3 LeetCode 233 - 数字 1 的个数 (Hard)

**题目**: 求 1~n 中数字 1 出现的次数.

**思路**: 按位统计贡献.

```python
def countDigitOne(n):
    """数学方法"""
    count = 0
    factor = 1
    while factor <= n:
        lower = n % factor
        curr = (n // factor) % 10
        higher = n // (factor * 10)

        if curr == 0:
            count += higher * factor
        elif curr == 1:
            count += higher * factor + lower + 1
        else:
            count += (higher + 1) * factor

        factor *= 10
    return count
```

### 3.4 LeetCode 902 - 最大为 N 的数字组合 (Hard)

**题目**: 给定数字集 D, 求 ≤ N 的正整数个数.

```python
def atMostNGivenDigitSet(D, N):
    s = str(N)
    n = len(s)

    # 比 N 短的数字: 每一位都是 |D| 种选择
    count = 0
    for i in range(1, n):
        count += len(D) ** i

    # 长度等于 N: 从高位开始, 用前缀和
    for i, c in enumerate(s):
        # 当前位能选的 (D 中 < c 的)
        valid = sum(1 for d in D if d < c)
        count += valid * (len(D) ** (n - 1 - i))
        if c not in D:
            break  # 后面的都不可行
    else:
        count += 1  # 恰好 N 本身

    return count
```

## 6. 三类高级 DP 的统一框架

状压 DP、计数 DP 与数位 DP 看似不同，本质都要回答状态、转移、初值和重复计数四个问题。

### 6.1 状压 DP 识别信号

- 元素数通常不超过二十。
- 状态核心是哪些元素已经选择。
- 普通回溯反复遇到相同剩余集合。
- 问题属于排列、配对、覆盖、旅行商、分组或博弈。
- `mask.bit_count()` 经常能推出轮次或当前下标。

### 6.2 计数 DP 识别信号

- 问题询问方案数而不是最值。
- 互斥来源用加法合并。
- 独立选择用乘法组合。
- 顺序是否重要决定循环次序。
- 空方案常用 `dp[0]=1` 表示。

### 6.3 数位 DP 识别信号

- 询问 `[0,n]` 或 `[L,R]` 中合法整数个数。
- 合法性由每一位数字与有限状态决定。
- 数值很大，但位数很少。
- 状态通常含 `position`、`tight`、`started`。
- 区间统计通常写成 `F(R)-F(L-1)`。

### 6.4 位操作模板

```python
def has(mask: int, index: int) -> bool:
    return bool(mask & (1 << index))


def add(mask: int, index: int) -> int:
    return mask | (1 << index)


def remove(mask: int, index: int) -> int:
    return mask & ~(1 << index)


def lowbit(mask: int) -> int:
    return mask & -mask


def iter_submasks(mask: int):
    subset = mask
    while subset:
        yield subset
        subset = (subset - 1) & mask
```

枚举一个掩码的所有子集是 $O(2^k)$，其中 `k` 是掩码中一的数量。

对所有掩码再枚举子集的总复杂度是 $O(3^n)$。

### 7.1 LeetCode 52：N 皇后 II

- 分类：状压DP。
- 推荐方法：位运算 DFS。
- 状态：列、主对角线、副对角线三个掩码。
- 关键观察：空位集合通过 full 与三个禁用掩码计算。
- 复杂度目标：O(n!)。

#### 状态推导

1. 用自然语言定义状态：列、主对角线、副对角线三个掩码。
2. 检查可删除的冗余维度：逐行放置皇后，当前行无需写入状态。
3. 列出当前决策会改变的最少字段。
4. 保证每次转移让处理进度单向推进。
5. 明确终点返回布尔值、最值、数量或概率。

#### 正确性不变量

- 逐行放置皇后，当前行无需写入状态。
- 缓存值只能依赖缓存键，不能依赖隐藏的可变路径状态。
- 每个完整方案应按定义恰好到达终态一次。
- 若多个顺序代表同一组合，要固定顺序或去除对称分支。

#### 多解法对比

| 解法 | 优点 | 缺点 | 使用建议 |
|---|---|---|---|
| 暴力枚举 | 容易验证小样例 | 重复状态多 | 只作基线 |
| 位运算 DFS | 状态明确，复杂度为 O(n!) | 需要证明状态完整 | 当前约束首选 |
| 特殊数学或剪枝 | 特定输入可能更快 | 泛化性较弱 | 有额外结构时补充 |

#### Python 实现提示

- 记忆化搜索优先使用 `functools.cache`。
- 位集合优先使用整数，不要在缓存键里放可变集合。
- 计数题每轮及时取模，避免大整数持续膨胀。
- 数位 DP 要明确前导零是否属于真实数字。
- 一维背包要先确定正序还是倒序更新。

#### 测试边界

- [ ] 最小输入与空状态。
- [ ] 无解、唯一解与大量对称解。
- [ ] 全零、全相同或极限上界。
- [ ] 模数、负区间与递归深度。
- [ ] 状态压缩后的维度是否仍能区分未来。

#### 复盘问题

- 哪个维度能从掩码置位数推出？
- 遍历顺序是否保证来源状态已经求出？
- 同一方案会不会被不同决策顺序重复生成？
- 输入规模增加一倍时，时间还是空间先不可接受？

| 前缀计数或数位 DP | 状态明确，复杂度为 O(log n) | 需要证明状态完整 | 当前约束首选 |
| 特殊数学或剪枝 | 特定输入可能更快 | 泛化性较弱 | 有额外结构时补充 |

#### Python 实现提示

- 记忆化搜索优先使用 `functools.cache`。
- 位集合优先使用整数，不要在缓存键里放可变集合。
- 计数题每轮及时取模，避免大整数持续膨胀。
- 数位 DP 要明确前导零是否属于真实数字。
- 一维背包要先确定正序还是倒序更新。

#### 测试边界

- [ ] 最小输入与空状态。
- [ ] 无解、唯一解与大量对称解。
- [ ] 全零、全相同或极限上界。
- [ ] 模数、负区间与递归深度。
- [ ] 状态压缩后的维度是否仍能区分未来。

#### 复盘问题

- 哪个维度能从掩码置位数推出？
- 遍历顺序是否保证来源状态已经求出？
- 同一方案会不会被不同决策顺序重复生成？
- 输入规模增加一倍时，时间还是空间先不可接受？

## 8. 状压 DP Python 代码

### 8.1 LeetCode 52：N 皇后 II

```python
class Solution52:
    def totalNQueens(self, n: int) -> int:
        full = (1 << n) - 1

        def dfs(columns: int, left: int, right: int) -> int:
            if columns == full:
                return 1
            available = full & ~(columns | left | right)
            ways = 0
            while available:
                position = available & -available
                available -= position
                ways += dfs(
                    columns | position,
                    ((left | position) << 1) & full,
                    (right | position) >> 1,
                )
            return ways

        return dfs(0, 0, 0)
```

每层递归对应一行，不需要额外行号。

三个掩码分别描述下一行被列和对角线攻击的位置。

数组回溯更直观，位运算版本常数更小。

### 8.2 LeetCode 847：访问所有节点的最短路径

```python
from collections import deque


class Solution847:
    def shortestPathLength(self, graph: list[list[int]]) -> int:
        n = len(graph)
        full = (1 << n) - 1
        queue = deque((node, 1 << node, 0) for node in range(n))
        seen = {(node, 1 << node) for node in range(n)}

        while queue:
            node, mask, distance = queue.popleft()
            if mask == full:
                return distance
            for neighbor in graph[node]:
                state = neighbor, mask | (1 << neighbor)
                if state not in seen:
                    seen.add(state)
                    queue.append((state[0], state[1], distance + 1))
        return 0
```

普通最短路状态只有节点，这里必须加上已访问集合。

多源 BFS 同时覆盖所有可能起点，第一次到达完整集合就是答案。

### 8.3 LeetCode 1879：最小异或和

```python
class Solution1879:
    def minimumXORSum(self, first: list[int], second: list[int]) -> int:
        n = len(first)
        dp = [float("inf")] * (1 << n)
        dp[0] = 0

        for mask in range(1 << n):
            index = mask.bit_count()
            if index == n:
                continue
            for other in range(n):
                bit = 1 << other
                if not mask & bit:
                    next_mask = mask | bit
                    dp[next_mask] = min(
                        dp[next_mask],
                        dp[mask] + (first[index] ^ second[other]),
                    )
        return dp[-1]
```

当前位置由 `mask.bit_count()` 推出，因此状态只需一个掩码。

全排列需要 $O(n!)$，状压 DP 将相同已用集合合并为一个状态。

### 8.4 LeetCode 2741：特别的排列

```python
class Solution2741:
    def specialPerm(self, nums: list[int]) -> int:
        mod = 1_000_000_007
        n = len(nums)
        dp = [[0] * n for _ in range(1 << n)]
        for index in range(n):
            dp[1 << index][index] = 1

        for mask in range(1 << n):
            for last in range(n):
                if dp[mask][last] == 0:
                    continue
                for nxt in range(n):
                    bit = 1 << nxt
                    if mask & bit:
                        continue
                    if nums[last] % nums[nxt] and nums[nxt] % nums[last]:
                        continue
                    dp[mask | bit][nxt] += dp[mask][last]
                    dp[mask | bit][nxt] %= mod

        return sum(dp[-1]) % mod
```

末尾元素影响下一步兼容性，所以不能只用 `dp[mask]`。

## 9. 计数 DP Python 代码

### 9.1 LeetCode 115：不同的子序列

```python
class Solution115:
    def numDistinct(self, source: str, target: str) -> int:
        dp = [0] * (len(target) + 1)
        dp[0] = 1

        for char in source:
            for j in range(len(target), 0, -1):
                if char == target[j - 1]:
                    dp[j] += dp[j - 1]
        return dp[-1]
```

倒序更新保证当前源字符最多使用一次。

正序会让本轮刚写入的状态继续传播，造成重复使用。

### 9.2 LeetCode 494：目标和

```python
class Solution494:
    def findTargetSumWays(self, nums: list[int], target: int) -> int:
        total = sum(nums)
        transformed = total + target
        if transformed < 0 or transformed % 2:
            return 0

        positive = transformed // 2
        dp = [0] * (positive + 1)
        dp[0] = 1
        for value in nums:
            for current in range(positive, value - 1, -1):
                dp[current] += dp[current - value]
        return dp[positive]
```

由 `P-N=target` 和 `P+N=total` 得到 `P=(total+target)/2`。

问题转化为选择若干元素达到容量 `P` 的方案数。

### 9.3 LeetCode 2466：统计构造好字符串

```python
class Solution2466:
    def countGoodStrings(self, low: int, high: int, zero: int, one: int) -> int:
        mod = 1_000_000_007
        dp = [0] * (high + 1)
        dp[0] = 1

        for length in range(1, high + 1):
            if length >= zero:
                dp[length] += dp[length - zero]
            if length >= one:
                dp[length] += dp[length - one]
            dp[length] %= mod

        return sum(dp[low:high + 1]) % mod
```

状态只关心长度，因为追加块的内容固定。

## 10. 数位 DP Python 代码

### 10.1 统一模板

```python
from functools import cache


def count_by_rule(n: int) -> int:
    if n < 0:
        return 0
    digits = str(n)

    @cache
    def dfs(position: int, state: int, tight: bool, started: bool) -> int:
        if position == len(digits):
            return int(started)

        upper = int(digits[position]) if tight else 9
        answer = 0
        for digit in range(upper + 1):
            next_tight = tight and digit == upper
            if not started and digit == 0:
                answer += dfs(position + 1, state, next_tight, False)
            elif allowed(state, digit):
                answer += dfs(
                    position + 1,
                    update(state, digit),
                    next_tight,
                    True,
                )
        return answer

    return dfs(0, initial_state, True, False)
```

`state` 只保存未来真正需要的信息，例如已用数字掩码、余数或数位和。

`tight` 表示当前前缀是否仍与上界前缀完全相同。

`started` 区分跳过前导位置与真实数字零。

### 10.2 LeetCode 600：不含连续 1

```python
class Solution600:
    def findIntegers(self, n: int) -> int:
        bits = bin(n)[2:]

        @cache
        def dfs(position: int, previous_one: bool, tight: bool) -> int:
            if position == len(bits):
                return 1

            upper = int(bits[position]) if tight else 1
            ways = 0
            for bit in range(upper + 1):
                if previous_one and bit:
                    continue
                ways += dfs(
                    position + 1,
                    bit == 1,
                    tight and bit == upper,
                )
            return ways

        return dfs(0, False, True)
```

本题中前导零与普通零行为相同，因此无需 `started`。

终点返回一会把整数零计入合法答案。

### 10.3 LeetCode 2376：各位互不相同

```python
class Solution2376:
    def countSpecialNumbers(self, n: int) -> int:
        digits = str(n)

        @cache
        def dfs(position: int, mask: int, tight: bool, started: bool) -> int:
            if position == len(digits):
                return int(started)

            upper = int(digits[position]) if tight else 9
            ways = 0
            for digit in range(upper + 1):
                next_tight = tight and digit == upper
                if not started and digit == 0:
                    ways += dfs(position + 1, mask, next_tight, False)
                elif not mask & (1 << digit):
                    ways += dfs(
                        position + 1,
                        mask | (1 << digit),
                        next_tight,
                        True,
                    )
            return ways

        return dfs(0, 0, True, False)
```

跳过前导位置时不能把数字零标为已使用。

数字开始后，零与其他数字一样需要写入掩码。

### 10.4 数位 DP 与数学贡献法对比

| 方案 | 优点 | 缺点 | 代表题 |
|---|---|---|---|
| 按位数学贡献 | $O(位数)$ 且常数小 | 只适合可独立分解的条件 | LeetCode 233 |
| 数位 DP | 可组合多个有限状态 | 状态设计更复杂 | LeetCode 2376 |
| 组合计数 | 同长度前缀推导简洁 | 对数字集合要求较强 | LeetCode 902 |
| 直接枚举 | 容易验证 | 上界大时不可用 | 仅作小规模对拍 |

## 11. 三类 DP 总对比

| 维度 | 状压 DP | 计数 DP | 数位 DP |
|---|---|---|---|
| 典型规模 | 元素数 15-22 | 多项式状态 | 位数 10-20 |
| 核心状态 | 已选择集合 | 前缀、容量、末尾 | 位置与有限约束 |
| 常见聚合 | 最小、最大、布尔 | 加法、乘法 | 合法数字分支求和 |
| 常见错误 | mask 语义混乱 | 重复或遗漏计数 | tight 与前导零错误 |
| 常用优化 | lowbit、子集预处理 | 滚动数组、前缀和 | 缓存非受限状态 |

### 11.1 记忆化与迭代

- 博弈和数位 DP 通常优先记忆化搜索。
- 背包和路径计数通常优先迭代 DP。
- 记忆化只访问可达状态，但有递归栈。
- 迭代会扫描无效状态，但更新顺序更显式。
- 两者复杂度相同不代表常数相同。

### 11.2 组合与排列

- 组合不区分选择顺序。
- 排列区分选择顺序。
- 组合背包常把物品放外层。
- 排列计数常把目标和放外层。
- 不确定时用小例子列出所有方案检查。

### 11.3 正序与倒序

- 0/1 背包倒序更新容量。
- 完全背包正序更新容量。
- 倒序保证本轮元素只使用一次。
- 正序允许本轮元素继续传播。
- 口诀必须由状态来源验证，不能机械套用。

## 12. 复杂度推导

### 12.1 状压转移

`2^n` 个掩码，每个掩码尝试最多 `n` 个下一元素。

因此常见复杂度为 $O(n2^n)$。

若还要枚举每对元素，则为 $O(n^2 2^n)$。

若对每个掩码枚举子集，则总复杂度为 $O(3^n)$。

### 12.2 数位状态

设位数为 `d`，附加状态数为 `S`，进制为 `B`。

常见时间复杂度是 $O(dSB)$。

`tight` 与 `started` 只带来常数倍。

十进制已用数字掩码有 `2^10` 种。

若再跟踪模 `k` 余数，状态数还要乘 `k`。

### 12.3 Python 空间注意

- 列表中的 Python 整数不是四字节 C 整数。
- 字典只存可达状态，但单个键值对开销较大。
- `n=22` 时必须估算真实内存，而不只写渐进复杂度。
- 二维 `dp[mask][last]` 可用字典压缩稀疏状态。
- 递归深度通常不是状压 DP 的主要瓶颈，状态总数才是。

## 14. 面试追问

### 14.1 为什么 `dp[0]=1`

它表示构成目标零有一种空选择方案。

若初始化为零，后续计数无法从初态产生。

### 14.2 为什么不缓存完整数字前缀

未来只关心有限状态和是否贴住上界。

完整前缀会阻止不同路径合并到同一状态。

### 14.3 什么时候不用状压 DP

元素数量明显超过二十且没有稀疏或特殊结构时，指数状态不可接受。

若能转化为贪心、匹配、网络流或多项式图算法，应优先使用它们。

### 14.4 如何恢复最优方案

更新状态时记录父状态与本次选择。

从终态逆推到初态后反转选择序列。

只求数量时不需要父指针。

### 14.5 如何检查重复计数

给每个方案定义唯一生成顺序。

组合题固定下标递增。

排列题则有意保留不同顺序。
