## 1. LeetCode 1 - 两数之和 (Easy) ⭐TOP5

### 题目描述

给定一个整数数组 `nums` 和一个整数目标值 `target`, 请你在该数组中找出和为目标值 `target` 的那两个整数, 并返回它们的数组下标.

你可以假设每种输入只会对应一个答案, 并且你不能重复使用相同的元素.

你可以按任意顺序返回答案.

**示例 1**:
```text
输入: nums = [2,7,11,15], target = 9
输出: [0,1]
解释: 因为 nums[0] + nums[1] == 9, 返回 [0, 1]
```

**示例 2**:
```text
输入: nums = [3,2,4], target = 6
输出: [1,2]
```

### 思路分析

**暴力法**: 双重循环, 枚举所有两数对 → $O(n^2)$

**优化: 哈希表**: 用哈希表存"已遍历的数和它的索引", 一次遍历:
- 对每个数 `x`, 看 `target - x` 是否在哈希表中
- 在: 返回索引; 不在: 把 `x` 加入哈希表

### 复杂度分析

| | 暴力 | 哈希 |
|---|---|---|
| 时间 | $O(n^2)$ | $O(n)$ |
| 空间 | $O(1)$ | $O(n)$ |

### 代码实现

```python
def twoSum(nums, target):
    """哈希表法 - 一次遍历"""
    seen = {}  # 值 -> 索引
    for i, x in enumerate(nums):
        need = target - x
        if need in seen:
            return [seen[need], i]
        seen[x] = i
    return []
```

### 易错点

```python
# ❌ 错误: 把当前数加入 seen 后再查找
seen[x] = i
if need in seen:  # 这时如果 need == x, 会查到自己的索引!
    return [seen[need], i]

# ✅ 正确: 先查找, 再加入
if need in seen:
    return [seen[need], i]
seen[x] = i
```

- **LeetCode 653 - 两数之和 IV (BST)**: 在 BST 中找两数之和, $O(n)$ 中序 + 哈希

## 2. LeetCode 3 - 无重复字符的最长子串 (Medium) ⭐TOP10

### 题目描述

给定一个字符串 `s`, 请你找出其中不含有重复字符的 **最长子串** 的长度.

**示例**:
```text
输入: s = "abcabcbb"
输出: 3
解释: 因为无重复字符的最长子串是 "abc", 长度为 3
```

### 思路分析

**滑动窗口** (双指针): 维护一个不含重复字符的窗口 `[left, right]`

```text
right 向右扩展:
  - 把 s[right] 加入窗口
  - 如果 s[right] 重复, 移动 left 直到窗口无重复
  - 更新答案
```

**数据结构**: 用哈希表存"字符 -> 上次出现的索引", 这样可以直接把 left 跳到重复字符的下一个位置.

### 复杂度分析

- 时间: $O(n)$ (left 和 right 都只走一次)
- 空间: $O(|\Sigma|)$ (字符集大小, ASCII 128)

### 代码实现

#### 版本 1: 哈希集合 (易理解)

```python
def lengthOfLongestSubstring(s):
    seen = set()
    left = 0
    res = 0
    for right in range(len(s)):
        while s[right] in seen:
            seen.remove(s[left])
            left += 1
        seen.add(s[right])
        res = max(res, right - left + 1)
    return res
```

#### 版本 2: 哈希表 + 跳跃 (最优)

```python
def lengthOfLongestSubstring(s):
    last_seen = {}  # 字符 -> 上次出现的索引
    left = 0
    res = 0
    for right, c in enumerate(s):
        if c in last_seen and last_seen[c] >= left:
            left = last_seen[c] + 1  # 跳到重复字符的下一个位置
        last_seen[c] = right
        res = max(res, right - left + 1)
    return res
```

### 模板化: 滑动窗口通用框架

```python
def sliding_window(s):
    left = 0
    window = {}  # 窗口状态 (Counter / set / int)
    res = 0

    for right in range(len(s)):
        # 1. 扩大窗口: 加入 s[right]
        c = s[right]
        window[c] = window.get(c, 0) + 1

        # 2. 收缩窗口: 当窗口不满足条件
        while window 不满足条件:
            d = s[left]
            window[d] -= 1
            left += 1

        # 3. 更新答案
        res = max(res, right - left + 1)

    return res
```

### 易错点

```python
# ❌ 错误: left 应该跳过重复字符, 不是 1 步
if c in last_seen:
    left = last_seen[c] + 1  # ✅ 但要确保 left 不会回退

# ❌ 错误: 没有判断 last_seen[c] 是否在窗口内
if c in last_seen:
    left = last_seen[c] + 1  # 如果 last_seen[c] < left, 会回退!

# ✅ 正确: 加判断
if c in last_seen and last_seen[c] >= left:
    left = last_seen[c] + 1
```

## 3. LeetCode 15 - 三数之和 (Medium) ⭐TOP10

### 题目描述

给你一个整数数组 `nums`, 判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j, i != k, j != k` 且 `nums[i] + nums[j] + nums[k] == 0`.

请你返回所有和为 0 且不重复的三元组.

注意: 答案中不可以包含重复的三元组.

**示例**:
```text
输入: nums = [-1,0,1,2,-1,-4]
输出: [[-1,-1,2],[-1,0,1]]
```

### 思路分析

**排序 + 双指针**:

```text
1. 排序数组
2. 固定第一个数 nums[i]
3. 用双指针 left=i+1, right=n-1 找两数之和 = -nums[i]
4. 去重 (跳过相同元素)
```

**为什么排序?**
- 方便双指针 (单调)
- 方便去重 (相邻元素比较)

### 复杂度分析

- 时间: $O(n^2)$ (外层 O(n), 内层双指针 O(n))
- 空间: $O(1)$ (不计排序和结果)

### 代码实现

```python
def threeSum(nums):
    nums.sort()
    n = len(nums)
    res = []

    for i in range(n - 2):
        # 剪枝: 最小三个数之和 > 0
        if nums[i] > 0:
            break
        # 去重: 跳过相同的第一位数
        if i > 0 and nums[i] == nums[i-1]:
            continue

        left, right = i + 1, n - 1
        target = -nums[i]

        while left < right:
            s = nums[left] + nums[right]
            if s == target:
                res.append([nums[i], nums[left], nums[right]])
                # 跳过相同的 left 和 right
                while left < right and nums[left] == nums[left+1]:
                    left += 1
                while left < right and nums[right] == nums[right-1]:
                    right -= 1
                left += 1
                right -= 1
            elif s < target:
                left += 1
            else:
                right -= 1

    return res
```

### 关键: 三重去重

```python
# 1. 第一个数去重 (外层循环)
if i > 0 and nums[i] == nums[i-1]:
    continue

# 2. 第二个数去重 (内层找到三元组后)
while left < right and nums[left] == nums[left+1]:
    left += 1

# 3. 第三个数去重
while left < right and nums[right] == nums[right-1]:
    right -= 1
```

### 拓展: N 数之和

```python
def nSum(nums, n, target):
    """通用 N 数之和"""
    nums.sort()
    result = []

    def helper(start, n, target, path):
        if n == 2:
            # 2 数之和: 双指针
            lo, hi = start, len(nums) - 1
            while lo < hi:
                s = nums[lo] + nums[hi]
                if s == target:
                    result.append(path + [nums[lo], nums[hi]])
                    while lo < hi and nums[lo] == nums[lo+1]: lo += 1
                    while lo < hi and nums[hi] == nums[hi-1]: hi -= 1
                    lo += 1
                    hi -= 1
                elif s < target:
                    lo += 1
                else:
                    hi -= 1
            return

        for i in range(start, len(nums) - n + 1):
            if i > start and nums[i] == nums[i-1]: continue
            if nums[i] * n > target or nums[-1] * n < target: break
            helper(i + 1, n - 1, target - nums[i], path + [nums[i]])

    helper(0, n, target, [])
    return result
```

## 4. LeetCode 53 - 最大子数组和 (Easy) ⭐TOP5

### 题目描述

给你一个整数数组 `nums`, 请你找出一个具有最大和的连续子数组 (子数组最少包含一个元素), 返回其最大和.

**示例**:
```text
输入: nums = [-2,1,-3,4,-1,2,1,-5,4]
输出: 6
解释: 连续子数组 [4,-1,2,1] 的和最大, 为 6
```

### 思路分析

**Kadane 算法** (动态规划):

**状态**: `dp[i]` = 以 `nums[i]` 结尾的最大子数组和

**转移**: $dp[i] = \max(nums[i], dp[i-1] + nums[i])$

- 要么 `nums[i]` 单独开头
- 要么 `nums[i]` 接在前面的子数组后面

**答案**: $\max(dp)$

### 复杂度分析

- 时间: $O(n)$
- 空间: $O(1)$ (滚动变量)

### 代码实现

#### 版本 1: 数组 DP

```python
def maxSubArray(nums):
    n = len(nums)
    dp = [0] * n
    dp[0] = nums[0]
    for i in range(1, n):
        dp[i] = max(nums[i], dp[i-1] + nums[i])
    return max(dp)
```

#### 版本 2: 滚动变量 (推荐)

```python
def maxSubArray(nums):
    cur = max_val = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)
        max_val = max(max_val, cur)
    return max_val
```

#### 版本 3: 分治

```python
def maxSubArray(nums):
    """分治: T(n) = 2T(n/2) + O(n) → O(n log n)"""
    def divide(lo, hi):
        if lo == hi:
            return nums[lo]
        mid = (lo + hi) // 2
        left = divide(lo, mid)
        right = divide(mid+1, hi)
        # 跨越中点的最大子数组
        left_max = right_max = 0
        cur = 0
        for i in range(mid, lo-1, -1):
            cur += nums[i]
            left_max = max(left_max, cur)
        cur = 0
        for i in range(mid+1, hi+1):
            cur += nums[i]
            right_max = max(right_max, cur)
        cross = left_max + right_max
        return max(left, right, cross)

    return divide(0, len(nums)-1)
```

### 易错点

```python
# ❌ 错误: dp 初始化不对
dp = [0] * n
for i in range(n):
    dp[i] = nums[i] + max(dp[i-1], 0)  # dp[i-1] 可能为负, 应直接用 nums[i]

# ✅ 正确
dp[i] = max(nums[i], dp[i-1] + nums[i])
```

## 5. LeetCode 121 - 买卖股票的最佳时机 (Easy) ⭐TOP5

### 题目描述

给定一个数组 `prices`, 它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格.

你只能选择 **某一天** 买入这只股票, 并选择在 **未来的某一个不同的日子** 卖出该股票. 设计一个算法来计算你所能获取的最大利润.

返回你可以从这笔交易中获取的最大利润. 如果你不能获取任何利润, 返回 0.

**示例**:
```text
输入: prices = [7,1,5,3,6,4]
输出: 5
解释: 在第 2 天 (价格 = 1) 买入, 第 5 天 (价格 = 6) 卖出, 利润 = 6 - 1 = 5
```

### 思路分析

**暴力**: 双重循环, 找 max(prices[j] - prices[i]) 其中 i < j → $O(n^2)$

**优化**: 一次遍历, 维护历史最低价:

```text
对每天的价格 p:
  - max_profit = max(max_profit, p - min_price)
  - min_price = min(min_price, p)
```

### 复杂度分析

- 时间: $O(n)$
- 空间: $O(1)$

### 代码实现

```python
def maxProfit(prices):
    min_price = float('inf')
    max_profit = 0
    for p in prices:
        min_price = min(min_price, p)
        max_profit = max(max_profit, p - min_price)
    return max_profit
```

### 等价的 DP 解

```python
def maxProfit(prices):
    """dp[i] = 第 i 天为止的最大利润"""
    n = len(prices)
    if n == 0: return 0
    dp = [0] * n
    min_price = prices[0]
    for i in range(1, n):
        min_price = min(min_price, prices[i])
        dp[i] = max(dp[i-1], prices[i] - min_price)
    return dp[n-1]
```

### 13.1 LeetCode 1 - 两数之和 (Easy)

**多语言实现**:

```python
# Python - 哈希表
def twoSum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i
    return []
```

```java
// Java - HashMap
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int need = target - nums[i];
            if (map.containsKey(need)) return new int[]{map.get(need), i};
            map.put(nums[i], i);
        }
        return new int[0];
    }
}
```

```cpp
// C++ - unordered_map
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> m;
        for (int i = 0; i < nums.size(); i++) {
            int need = target - nums[i];
            if (m.count(need)) return {m[need], i};
            m[nums[i]] = i;
        }
        return {};
    }
};
```

**复杂度**: 时间 O(n), 空间 O(n). **下界**: Ω(n) 因为必须遍历全部元素才知道是否有答案.

### 13.2 LeetCode 2 - 两数相加 (Medium)

**题目**: 用链表表示两个非负整数, 数字按逆序存储, 返回两数之和的链表.

**核心思路**: 模拟竖式加法, 维护进位 `carry`:

```python
def addTwoNumbers(l1, l2):
    dummy = cur = ListNode(0)
    carry = 0
    while l1 or l2 or carry:
        s = carry
        if l1: s += l1.val; l1 = l1.next
        if l2: s += l2.val; l2 = l2.next
        cur.next = ListNode(s % 10)
        cur = cur.next
        carry = s // 10
    return dummy.next
```

```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0), cur = dummy;
        int carry = 0;
        while (l1 != null || l2 != null || carry != 0) {
            int s = carry;
            if (l1 != null) { s += l1.val; l1 = l1.next; }
            if (l2 != null) { s += l2.val; l2 = l2.next; }
            cur.next = new ListNode(s % 10);
            cur = cur.next;
            carry = s / 10;
        }
        return dummy.next;
    }
}
```

```cpp
class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        ListNode dummy(0), *cur = &dummy;
        int carry = 0;
        while (l1 || l2 || carry) {
            int s = carry;
            if (l1) { s += l1->val; l1 = l1->next; }
            if (l2) { s += l2->val; l2 = l2->next; }
            cur->next = new ListNode(s % 10);
            cur = cur->next;
            carry = s / 10;
        }
        return dummy.next;
    }
};
```

**复杂度**: 时间 O(max(m, n)), 空间 O(max(m, n)) 用于结果链表.

### 13.3 LeetCode 3 - 无重复字符的最长子串 (Medium)

**多语言实现**:

```python
def lengthOfLongestSubstring(s):
    last, left, res = {}, 0, 0
    for r, c in enumerate(s):
        if c in last and last[c] >= left:
            left = last[c] + 1
        last[c] = r
        res = max(res, r - left + 1)
    return res
```

```java
class Solution {
```

### 13.4 LeetCode 4 - 寻找两个有序数组的中位数 (Hard)

**核心思路**: 二分查找分割线, 满足 `maxLeftX ≤ minRightY` 且 `maxLeftY ≤ minRightX`.

**关键公式**: 分割后左边共 `(m+n+1)/2` 个元素, 保证奇数情况中位数归到左边.

```python
def findMedianSortedArrays(nums1, nums2):
    if len(nums1) > len(nums2): nums1, nums2 = nums2, nums1
    m, n = len(nums1), len(nums2)
    lo, hi = 0, m
    while lo <= hi:
        i = (lo + hi) // 2
        j = (m + n + 1) // 2 - i
        L1 = nums1[i-1] if i > 0 else float('-inf')
        R1 = nums1[i] if i < m else float('inf')
        L2 = nums2[j-1] if j > 0 else float('-inf')
        R2 = nums2[j] if j < n else float('inf')
        if L1 > R2: hi = i - 1
        elif L2 > R1: lo = i + 1
        else:
            if (m + n) % 2: return max(L1, L2)
            return (max(L1, L2) + min(R1, R2)) / 2
```

```java
class Solution {
    public double findMedianSortedArrays(int[] A, int[] B) {
        int m = A.length, n = B.length;
        if (m > n) return findMedianSortedArrays(B, A);
        int lo = 0, hi = m;
        while (lo <= hi) {
            int i = (lo + hi) / 2;
            int j = (m + n + 1) / 2 - i;
            int L1 = (i == 0) ? Integer.MIN_VALUE : A[i-1];
            int R1 = (i == m) ? Integer.MAX_VALUE : A[i];
            int L2 = (j == 0) ? Integer.MIN_VALUE : B[j-1];
            int R2 = (j == n) ? Integer.MAX_VALUE : B[j];
            if (L1 > R2) hi = i - 1;
            else if (L2 > R1) lo = i + 1;
            else {
                if ((m + n) % 2 != 0) return Math.max(L1, L2);
                return (Math.max(L1, L2) + Math.min(R1, R2)) / 2.0;
            }
        }
        return 0;
    }
}
```

**复杂度**: 时间 O(log(min(m, n))), 空间 O(1). **最优**: 因为中位数需要"看到"两边, O(log min) 是信息论下界.

### 13.8 LeetCode 8 - 字符串转换整数 (atoi) (Medium)

```python
def myAtoi(s):

    if i < n and s[i] in '+-':

        num = num * 10 + d
        i += 1
    return sign * num
```

### 13.10 LeetCode 10 - 正则表达式匹配 (Hard)

**核心思路**: DP. `dp[i][j]` = `s[:i]` 是否匹配 `p[:j]`.

**关键转移**:
- `p[j-1] == '*'`: 匹配 0 次 `dp[i][j-2]` 或 匹配 1 次 + `dp[i-1][j]` (当字符匹配)
- 否则: 字符匹配 + `dp[i-1][j-1]`

```python
def isMatch(s, p):
    m, n = len(s), len(p)
    dp = [[False]*(n+1) for _ in range(m+1)]
    dp[0][0] = True
    # 处理 p 前缀的 * (匹配 0 次)
    for j in range(2, n+1):
        if p[j-1] == '*': dp[0][j] = dp[0][j-2]
    for i in range(1, m+1):
        for j in range(1, n+1):
            if p[j-1] == '*':
                dp[i][j] = dp[i][j-2]
                if p[j-2] == '.' or p[j-2] == s[i-1]:
                    dp[i][j] |= dp[i-1][j]
            else:
                dp[i][j] = dp[i-1][j-1] and (p[j-1] == '.' or p[j-1] == s[i-1])
    return dp[m][n]
```

**复杂度**: 时间 O(m·n), 空间 O(m·n) 可优化到 O(n).

**关键陷阱**: `*` 前必须有字符, `a*` 可以匹配空串.

```python
    l, r = 0, len(height) - 1

        h = min(height[l], height[r])
        res = max(res, h * (r - l))
        if height[l] < height[r]: l += 1
        else: r -= 1
    return res
```

## 14. 多解法对比: 暴力 → 优化 → 最优

> **本章目标**: 对 12 道题逐一展开"暴力 → 优化 → 最优"的演进路径, 看清每一步为什么更快, 训练"压榨时间"的工程思维.
> **方法论**: 暴力法先跑通, 再识别瓶颈 (重复计算? 排序? 哈希?), 用对应数据结构优化.

### 14.1 两数之和 (LC 1)

**V1 - 暴力双重循环**: O(n²) 时间 O(1) 空间.

### 14.2 两数相加 (LC 2)

**V2 - 同步遍历, 维护进位** (推荐): O(max(m, n)) 时间 O(max(m, n)) 空间.

### 14.5 最长回文子串 (LC 5)

**V1 - 暴力枚举 + 反转检查**: O(n³).

**V2 - 动态规划**: `dp[i][j] = s[i..j] 是否回文`. O(n²) 时间 O(n²) 空间.

### 14.6 Z 字形变换 (LC 6)

**V1 - 模拟行字符串拼接**: O(n) 时间 O(n) 空间.

**V2 - 模拟行列表**: O(n) 时间 O(n) 空间, 用列表比字符串拼接快 (字符串不可变).

**V3 - 数学公式直接定位**: O(n) 时间 O(1) 额外空间.

```python
# V3 - 数学法
def convert(s, n):
    if n == 1: return s
    res = []
    cycle = 2 * n - 2  # 一个完整周期长度
    for row in range(n):
        for i in range(row, len(s), cycle):
            res.append(s[i])
            # 中间行的"中间位置"
            mid = i + cycle - 2 * row
            if 0 < row < n - 1 and mid < len(s):
                res.append(s[mid])
    return ''.join(res)
```

**对比**: V2 易实现; V3 适合输出流场景 (不能存所有字符).

**V3 - 状态机**: 显式定义 `START, SIGNED, IN_NUMBER, END` 等状态, 处理"数字后再出现非数字"等情况.

```python
# V3 - 状态机

    states = [
        {' ': 0, '+': 1, '-': 1, 'd': 2},  # START
        {'d': 2},                            # SIGNED
        {'d': 2, 'e': 3},                    # IN_NUMBER
        {}                                    # END
    ]
    state, sign, num = 0, 1, 0
    for c in s:
        ctype = 'd' if c.isdigit() else c
        if ctype not in states[state]: break
        state = states[state][ctype]
        if state == 1: sign = 1 if c == '+' else -1
        elif state == 2:
            num = num * 10 + int(c)
            num = min(num, 2**31) if sign == 1 else min(num, 2**31)
    return sign * num
```

**对比**: V2 是面试常用; V3 工业级 (如 LeetCode 65 验证数字字符串).

### 14.9 回文数 (LC 9)

**V1 - 转字符串反转比较**: O(log x) 时间 O(log x) 空间.

**V2 - 数学反转一半**: O(log x) 时间 O(1) 空间.

**V3 - 反转全部 + 溢出检查**: V2 的简化版.

**对比**: V2 是面试最优. 关键洞察: 只需要反转一半, 另一半保留原数比较.

### 14.10 正则表达式匹配 (LC 10)

**V1 - 递归 + 记忆化**: `memo(i, j)`. 时间 O(m·n) 空间 O(m·n).

**V2 - 自顶向下 DP**: 同 V1.

**V3 - 自底向上 DP**: `dp[0][0] = True`, 从小到大填表. 时间 O(m·n) 空间 O(m·n) → O(n).

```python
# V1 递归
def isMatch(s, p):
    memo = {}
    def dp(i, j):
        if (i, j) in memo: return memo[(i, j)]
        if j == len(p): return i == len(s)
        first = i < len(s) and p[j] in {s[i], '.'}
        if j + 1 < len(p) and p[j+1] == '*':
            memo[(i, j)] = dp(i, j+2) or (first and dp(i+1, j))
        else:
            memo[(i, j)] = first and dp(i+1, j+1)
        return memo[(i, j)]
    return dp(0, 0)
```

**对比**: V3 滚动数组版面试常考. V1 易理解但空间较大.

### 14.11 盛最多水的容器 (LC 11)

**V1 - 暴力双重循环**: O(n²).

**V2 - 双指针贪心**: O(n). 每次移动短板, 因为短板限制了面积上限.

**V3 - 预处理最大高度**: 对每个 i 找 `max(h[0..i], h[i+1..n])`, 仍 O(n²) 实际更快.

**对比**: V2 是面试最优. 数学证明: 反证移动长板一定不会得到更大解.

### 14.12 整数转罗马数字 (LC 12)

**V1 - 暴力枚举 (1000, 900, ..., 1)**: 即 V2 贪心. 实际只有这一种实用方法.

**V2 - 千位/百位/十位/个位分别查表**: 思路更清晰.

```python
# V2 - 查表法
def intToRoman(num):
    M = ["", "M", "MM", "MMM"]
    C = ["", "C", "CC", "CCC", "CD", "D", "DC", "DCC", "DCCC", "CM"]
    X = ["", "X", "XX", "XXX", "XL", "L", "LX", "LXX", "LXXX", "XC"]
    I = ["", "I", "II", "III", "IV", "V", "VI", "VII", "VIII", "IX"]
    return M[num//1000] + C[(num%1000)//100] + X[(num%100)//10] + I[num%10]
```

**对比**: V2 更易记; V1 (贪心) 更通用 (可扩展到任意进制).

## 15. 复杂度详解: 时空权衡与最优下界证明

> **本章目标**: 超越"会背 O(n)"的层次, 真正理解每个复杂度背后的"为什么", 并能证明"不能再快了"的下界.
> **核心**: Big-O 是上界, Ω 是下界, Θ 是紧界. 面试问"还能更快吗"时用下界回答.

### 15.1 复杂度层级速览

| 复杂度 | 名称 | n=10⁶ 大致耗时 (假设 10⁸ ops/s) |
|---|---|---|
| O(1) | 常数 | 立即 |
| O(log n) | 对数 | ~20 ns |
| O(√n) | 平方根 | ~30 μs |
| O(n) | 线性 | ~10 ms |
| O(n log n) | 拟线性 | ~200 ms |
| O(n²) | 平方 | ~3 小时 (不可接受) |
| O(2ⁿ) | 指数 | 宇宙寿命 |
| O(n!) | 阶乘 | 不可计算 |

**实战口诀**: 看到 n=10⁶ 还能 1 秒内跑的只有 O(n), O(n log n), O(n) 配合小常数.

---

### 15.2 时间下界证明范式

#### 范式 1: 决策树 (比较类)

**例子**: 排序. 任何基于比较的排序下界是 Ω(n log n) (决策树有 n! 个叶子, 高度 ≥ log(n!) = n log n).

**应用**: 找第 k 小的数 (LC 215) → 下界 Ω(n) 用 Quickselect, 不是 Ω(n log n) 因为不用完全排序.

#### 范式 2: 信息论

**例子**: 找数组中的最大值, 必须遍历所有元素 (否则最后剩下的那个可能更大), 下界 Ω(n).

**例子**: 找数组中是否所有元素相同, 1 次比较不够 (可能前两个相等但第三个不等), 下界 Ω(n).

#### 范式 3: 平凡下界

- 输出大小: 输出 n 个元素至少 O(n).
- 读取输入: 读 n 个元素至少 O(n).
- 哈希查找: 平均 O(1), 最坏 O(n) (退化为链表).

---

### 15.3 12 题下界证明

#### LC 1 - 两数之和

**上界**: O(n) (哈希).
**下界**: Ω(n). 必须看每个元素至少一次 (否则无法判断它是否在解中).
**结论**: 哈希是最优.

#### LC 2 - 两数相加

**上界**: O(max(m, n)).
**下界**: Ω(max(m, n)). 必须遍历较长链表.
**结论**: 同步遍历最优.

#### LC 3 - 无重复字符的最长子串

**上界**: O(n) (滑动窗口).
**下界**: Ω(n). 至少要扫一遍字符串.
**结论**: 滑动窗口最优. 注意: ASCII 字符集大小固定, 空间 O(|Σ|) 是常数.

#### LC 4 - 寻找两个有序数组的中位数

**上界**: O(log min(m, n)) (二分).
**下界**: Ω(log min(m, n)). 中位数位置由两个数组共同决定, 二分只在一个数组上做.
**证明**: 若算法只访问较短数组的 O(1) 个元素, 仍可能漏掉真实中位数 → 至少 log 级别.
**结论**: 二分最优.

#### LC 5 - 最长回文子串

**上界**: O(n²) (中心扩展 / DP).
**下界**: Ω(n). 输出本身可能长度 n (如 "aaaa..." 全相同), 至少要写 n 字符.
**进阶**: Manacher O(n) 信息论最优, 但常数大. 实际 O(n²) 已够用.

#### LC 6 - Z 字形变换

**上界**: O(n) (单遍扫).
**下界**: Ω(n). 输出字符串长度 n, 必须遍历每个输入字符.
**结论**: O(n) 最优.

#### LC 7 - 整数反转

**上界**: O(log x) (10 进制位数).
**下界**: Ω(log x). 必须看每一位数字.
**结论**: 数学反转最优.

#### LC 8 - atoi

**上界**: O(n).
**下界**: Ω(n). 必须扫描整个字符串才能确定结束位置.
**结论**: O(n) 最优.

#### LC 9 - 回文数

**上界**: O(log x).
**下界**: Ω(log x). 必须看最高位数字, 至少读所有位.
**结论**: O(log x) 最优.

#### LC 10 - 正则表达式匹配

**上界**: O(m·n) (DP).
**下界**: Ω(m+n). 输入规模至少 m+n.
**讨论**: O(m·n) 是不是最优? 已知复杂性理论中正则匹配可以做到 O((m+n) log Σ), 但实际工程实现 O(m·n) 即可. 面试无需纠结.

#### LC 11 - 盛最多水的容器

**上界**: O(n) (双指针).
**下界**: Ω(n). 输出是某对索引, 至少 O(1); 但要确定最大对, 至少要看所有边界.
**结论**: O(n) 最优.

#### LC 12 - 整数转罗马数字

**上界**: O(1) (因为输入 ≤ 3999).
**下界**: Ω(1).
**结论**: 常数时间, 已是最优.

### 15.4 空间下界证明

#### 范式: 必须存储的对象数

- 输出本身大小 → 输出下界.
- 哈希表缓存 → 必须 O(n) 空间.
- 递归栈 → 必须 O(depth) 空间.

#### 12 题空间下界

| LC | 必须的空间 | 最优空间 |
|---|---|---|
| 1  | 输出 O(1) + 哈希 O(n) | O(n) ✓ |
| 2  | 输出 O(max(m,n)) | O(max(m,n)) ✓ |
| 3  | 输出 O(1) | O(1) (数组版) / O(Σ) ✓ |
| 4  | 输出 O(1) | O(1) ✓ |
| 5  | 输出 O(n) (回文子串) | O(1) (中心扩展, 输出不计) ✓ |
| 6  | 输出 O(n) | O(n) ✓ |
| 7  | 输出 O(log x) | O(1) (数学反转) ✓ |
| 8  | 输出 O(1) | O(1) ✓ |
| 9  | 输出 O(1) | O(1) ✓ |
| 10 | DP 表 O(m·n) | O(n) (滚动数组) ✓ |
| 11 | 输出 O(1) | O(1) ✓ |
| 12 | 输出 O(1) | O(1) ✓ |

**结论**: 12 题中最难压空间的是 LC 10, 因为 DP 必须存子问题解. 其他均可压到 O(1) 或 O(n).

### 15.5 时空权衡: 经典案例

#### 案例 1: LC 1 两数之和

- 暴力: O(n²) 时间, O(1) 空间.
- 哈希: O(n) 时间, O(n) 空间.
- **权衡**: 用 O(n) 空间换 O(n²) → O(n) 时间, 性价比极高.

#### 案例 2: LC 5 最长回文子串

- DP: O(n²) 时间, O(n²) 空间.
- 中心扩展: O(n²) 时间, O(1) 空间.
- **权衡**: 同一时间复杂度下压空间.

#### 案例 3: LC 10 正则匹配

- 朴素递归: 指数时间, O(m+n) 空间.
- 记忆化递归: O(m·n) 时间, O(m·n) 空间.
- 自底向上 DP: O(m·n) 时间, O(m·n) 空间.
- 滚动数组: O(m·n) 时间, O(n) 空间.
- **权衡**: 用空间换指数时间; 然后压空间到线性.

### 15.6 常数因子: 真实性能的关键

Big-O 之外, **常数因子**决定 100ms vs 10s:

#### 优化技巧

1. **数组代替哈希**: 字符/数字映射用数组 (Python list 或 C 数组), 比 dict 快 5-10x.
2. **避免在热循环里分配对象**: Python 避免 `result.append({...})` 在循环中.
3. **原地操作**: 减少 GC 压力.
4. **预分配**: `arr = [0] * n` 比 `arr.append(...)` 快.
5. **位运算代替乘除**: `x >> 1` 比 `x // 2` 快 (Python 差距小, C/C++ 差距大).

#### 真实案例

```python
# Python - 慢
def count(s):
    return sum(1 for c in s if c == 'a')

# Python - 快
def count(s):
    return s.count('a')
```

```python
# Python - 慢
def reverse_list(lst):
    return [lst[i] for i in range(len(lst)-1, -1, -1)]

# Python - 快
def reverse_list(lst):
    return lst[::-1]
```

```python
def isMatch(s, p):
    m, n = len(s), len(p)
    dp = [[False]*(n+1) for _ in range(m+1)]
    dp[0][0] = True
    for j in range(1, n+1):
        if p[j-1] == '*': dp[0][j] = dp[0][j-1]
    for i in range(1, m+1):
        for j in range(1, n+1):
            if p[j-1] == '*':
                dp[i][j] = dp[i][j-1] or dp[i-1][j]
            elif p[j-1] == '?' or p[j-1] == s[i-1]:
```

### 模板 1: 滑动窗口

```python
def sliding_window(s):
    left = 0
    window = {}
    res = 0

    for right in range(len(s)):
        c = s[right]
        window[c] = window.get(c, 0) + 1

        while window 不满足条件:
            d = s[left]
            window[d] -= 1
            left += 1

        res = max(res, right - left + 1)

    return res
```

```python
def binary_search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

### 模板 4: N 数之和 (NSum)

```python
def nSum(nums, n, target):
    nums.sort()
    res = []
    def helper(start, n, target, path):
        if n == 2:
            lo, hi = start, len(nums) - 1
            while lo < hi:
                s = nums[lo] + nums[hi]
                if s == target:
                    res.append(path + [nums[lo], nums[hi]])
                    while lo < hi and nums[lo] == nums[lo+1]: lo += 1
                    while lo < hi and nums[hi] == nums[hi-1]: hi -= 1
                    lo += 1; hi -= 1
                elif s < target: lo += 1
                else: hi -= 1
            return
        for i in range(start, len(nums) - n + 1):
            if i > start and nums[i] == nums[i-1]: continue
            helper(i + 1, n - 1, target - nums[i], path + [nums[i]])
    helper(0, n, target, [])
    return res
```

### 模板 5: DP (一维滚动)

```python
def dp_1d(nums):
    n = len(nums)
    dp = [0] * n
    dp[0] = nums[0]
    for i in range(1, n):
        dp[i] = max(dp[i-1] + nums[i], nums[i])  # Kadane
    return max(dp)
```

### 110. 高频面试题 1-12 (含 LeetCode 1, 3, 15, 53, 121 详解) - 思维框架 视角

**核心议题**: 本节从思维框架视角切入,系统展开 "高频面试题 1-12 (含 LeetCode 1, 3, 15, 53, 121 详解)" 的相关讨论。

**1. 背景与动机**

任何技术或方法的出现都不是孤立的,而是回应特定历史条件下的具体问题。"高频面试题 1-12 (含 LeetCode 1, 3, 15, 53, 121 详解)" 的发展也不例外。要理解它,必须回到它出现的那个时间点,看清它要解决的真实问题是什么。当时的主流方案有哪些不足? 它的提出填补了哪些空白? 这些问题的回答,决定了我们今天该如何使用它。

从知识论角度看,**技术演进是问题驱动的**——不是先有方案再找问题,而是先有问题再有方案。这个观察可以帮助我们避免"拿着锤子找钉子"的陷阱,真正把方法用对地方。

历史维度上,我们看到三个规律:
