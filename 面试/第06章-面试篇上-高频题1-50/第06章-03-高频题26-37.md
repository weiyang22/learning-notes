## 2. LeetCode 42 - 接雨水 (Hard) ⭐TOP10

### 题目描述

给定 `n` 个非负整数表示每个宽度为 1 的柱子的高度图, 计算按此排列的柱子, 下雨之后能接多少雨水.

**示例**:
```text
输入: height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出: 6
解释: 上面是数组, 由 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图,
      在这种情况下, 可以接 6 个单位的雨水 (蓝色部分).
```

### 思路分析

这是面试 Hard 难度 TOP 5 之一. 共有 4 种主流解法, 从简单到最优:

| 方法 | 时间 | 空间 | 难度 |
|---|---|---|---|
| 1. 按行遍历 | $O(n^2)$ | $O(1)$ | ⭐ |
| 2. 动态规划 | $O(n)$ | $O(n)$ | ⭐⭐ |
| 3. 双指针 | $O(n)$ | $O(1)$ | ⭐⭐⭐ |
| 4. 单调栈 | $O(n)$ | $O(n)$ | ⭐⭐⭐ |

下面给出方法 2/3/4 的实现.

### 方法 1: 动态规划

**核心**: 位置 `i` 的水量 = $\min(\text{left\_max}[i], \text{right\_max}[i]) - \text{height}[i]$

```text
left_max[i]  = max(height[0..i])      (包含 i)
right_max[i] = max(height[i..n-1])    (包含 i)
water[i] = max(0, min(left_max[i], right_max[i]) - height[i])
```

```python
def trap(height):
    if not height: return 0
    n = len(height)
    left_max = [0] * n
    right_max = [0] * n

    left_max[0] = height[0]
    for i in range(1, n):
        left_max[i] = max(left_max[i-1], height[i])

    right_max[n-1] = height[n-1]
    for i in range(n-2, -1, -1):
        right_max[i] = max(right_max[i+1], height[i])

    water = 0
    for i in range(n):
        water += min(left_max[i], right_max[i]) - height[i]
    return water
```

### 方法 2: 双指针 (最优, $O(1)$ 空间)

**核心**: 用双指针, 左右两边向中间推进. 始终在**较矮**的那一侧推进.

```text
left = 0, right = n - 1
left_max = 0, right_max = 0

while left < right:
    if height[left] < height[right]:
        # 左指针较矮, 决定水量靠 left_max
        if height[left] >= left_max:
            left_max = height[left]
        else:
            water += left_max - height[left]
        left += 1
    else:
        # 右指针较矮 (含相等), 决定水量靠 right_max
        if height[right] >= right_max:
            right_max = height[right]
        else:
            water += right_max - height[right]
        right -= 1
```

```python
def trap(height):
    if not height: return 0
    left, right = 0, len(height) - 1
    left_max = right_max = 0
    water = 0

    while left < right:
        if height[left] < height[right]:
            if height[left] >= left_max:
                left_max = height[left]
            else:
                water += left_max - height[left]
            left += 1
        else:
            if height[right] >= right_max:
                right_max = height[right]
            else:
                water += right_max - height[right]
            right -= 1

    return water
```

**核心理解**:
- 为什么先处理较矮的那一侧? 因为**水量由较矮的决定**.
- 例如 height[left] = 2, height[right] = 5, 此时 left 决定水量上限, right 的高度不影响.
- 所以可以放心推进 left, 用 left_max 来算当前位置的水量.

### 方法 3: 单调栈

**核心**: 维护一个**单调递减栈** (存索引), 当遇到更高的柱子时, 可以"装水".

```text
栈内柱子高度严格递减 (从栈底到栈顶)
遇到 height[i] > height[stack.top()]:
    top_idx = stack.pop()
    if stack 非空:
        # 形成了凹槽: 左边界 stack.top() 和右边界 i, 底部是 top_idx
        width = i - stack.top() - 1
        bounded_height = min(height[stack.top()], height[i]) - height[top_idx]
        water += width * bounded_height
stack.append(i)
```

```python
def trap(height):
    stack = []
    water = 0

    for i, h in enumerate(height):
        while stack and h > height[stack[-1]]:
            top = stack.pop()
            if not stack:
                break
            distance = i - stack[-1] - 1
            bounded_height = min(h, height[stack[-1]]) - height[top]
            water += distance * bounded_height
        stack.append(i)

    return water
```

### 图解 (单调栈)

```text
height = [0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]

i=0 (h=0): stack=[0]
i=1 (h=1): 1 > height[0]=0
  弹出 top=0, stack 空, 停止
  stack=[1]
i=2 (h=0): 0 < height[1]=1, 入栈
  stack=[1, 2]
i=3 (h=2): 2 > height[2]=0
  弹出 top=2, stack=[1], distance=3-1-1=1, bounded=min(2, height[1]=1)-0=1
  water += 1*1 = 1
  继续: 2 > height[1]=1
  弹出 top=1, stack 空, 停止
  stack=[3]
... (后续类似)

最终 water = 6
```

### 复杂度对比

| 方法 | 时间 | 空间 |
|---|---|---|
| 动态规划 | $O(n)$ | $O(n)$ |
| 双指针 | $O(n)$ | $O(1)$ ⭐最优 |
| 单调栈 | $O(n)$ | $O(n)$ |

### 推荐方案

**面试首选**: 双指针 (空间最优, 思路清晰)
**次选**: 单调栈 (思想优雅)
**不推荐**: 动态规划 (虽然简单, 但用了额外空间)

### 5.1 LC 35 - 搜索插入位置 (Easy, 二分)

**题意**: 给定排序数组 `nums` 和目标值 `target`, 返回 `target` 在数组中的下标. 若不存在, 返回它按顺序插入的位置下标. 时间复杂度必须为 $O(\log n)$.

**示例**: `nums = [1,3,5,6], target = 5` → 返回 2; `target = 2` → 返回 1; `target = 7` → 返回 4.

**思路**: 标准左边界二分. `left` 指向 `< target` 的最大下标+1, `right` 指向 `>= target` 的最小下标. 循环终止时 `left == right`, 即为插入位置.

**Python**:
```python
class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums)
        while left < right:
            mid = (left + right) // 2
            if nums[mid] < target:
                left = mid + 1
            else:
                right = mid
        return left
```

**Java**:
```java
class Solution {
    public int searchInsert(int[] nums, int target) {
        int left = 0, right = nums.length;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return left;
    }
}
```

**C++**:
```cpp
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int left = 0, right = nums.size();
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < target) left = mid + 1;
            else right = mid;
        }
        return left;
    }
};
```

**关键细节**: `mid = (left+right)//2` 可能溢出, 推荐 `left + (right-left)//2`; 右边界取 `len(nums)` 而非 `len-1` —— 这是"插入位置"的本质, 允许 target 放在末尾.

### 5.2 LC 36 - 有效的数独 (Medium, 哈希 + 位运算)

**题意**: 判断 9×9 数独是否有效 (不要求可解, 只要求已填部分不冲突).

**思路**: 三组状态分别记录: 行、列、3×3 宫. 每个数字 1-9 用 9 个 bit 表示. 每遍历一格, 检查是否已存在对应 bit; 不存在则置位.

**Python**:
```python
class Solution:
    def isValidSudoku(self, board: List[List[str]]) -> bool:
        rows = [0] * 9
        cols = [0] * 9
        boxes = [0] * 9
        for i in range(9):
            for j in range(9):
                c = board[i][j]
                if c == '.': continue
                bit = 1 << int(c)
                b = (i // 3) * 3 + j // 3
                if (rows[i] | cols[j] | boxes[b]) & bit: return False
                rows[i] |= bit; cols[j] |= bit; boxes[b] |= bit
        return True
```

**Java**:
```java
class Solution {
    public boolean isValidSudoku(char[][] board) {
        int[] rows = new int[9], cols = new int[9], boxes = new int[9];
        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                if (board[i][j] == '.') continue;
                int bit = 1 << (board[i][j] - '0');
                int b = (i / 3) * 3 + j / 3;
                if ((rows[i] | cols[j] | boxes[b]) != 0 && (rows[i] & bit) != 0) return false;
                if ((cols[j] & bit) != 0) return false;
                if ((boxes[b] & bit) != 0) return false;
                rows[i] |= bit; cols[j] |= bit; boxes[b] |= bit;
            }
        }
        return true;
    }
}
```

**C++**:
```cpp
class Solution {
public:
    bool isValidSudoku(vector<vector<char>>& board) {
        int rows[9] = {}, cols[9] = {}, boxes[9] = {};
        for (int i = 0; i < 9; i++) {

```

**关键点**: 用位运算替代 `set`, 时间 $O(81)$, 空间 $O(1)$ (固定 27 个 int).

### 5.3 LC 38 - 外观数列 (Medium, 字符串模拟)

**题意**: "外观数列"是按"读自己"生成的序列: 第 1 项是 "1"; 第 n 项描述第 n-1 项. 例如第 5 项是 "111221".

**思路**: 模拟. 从第 1 项开始, 连续 n-1 次生成下一项: 遍历当前项, 统计连续相同字符的个数, 拼出 "个数+字符" 形式.

**Python**:
```python
class Solution:
    def countAndSay(self, n: int) -> str:
        s = "1"
        for _ in range(n - 1):
            nxt, i = [], 0
            while i < len(s):
                j = i
                while j < len(s) and s[j] == s[i]:
                    j += 1
                nxt.append(str(j - i))
                nxt.append(s[i])
                i = j
            s = "".join(nxt)
        return s
```

**Java**:
```java
class Solution {
    public String countAndSay(int n) {
        String s = "1";
        for (int k = 1; k < n; k++) {
            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < s.length(); ) {
                int j = i;
                while (j < s.length() && s.charAt(j) == s.charAt(i)) j++;
                sb.append(j - i).append(s.charAt(i));
                i = j;
            }
            s = sb.toString();
        }
        return s;
    }
}
```

**C++**:
```cpp
class Solution {
public:
    string countAndSay(int n) {
        string s = "1";
        for (int k = 1; k < n; k++) {
            string nxt;
            for (int i = 0; i < (int)s.size(); ) {
```

**复杂度**: 第 n 项长度约为 $O(1.3^n)$, 因此总复杂度近似 $O(1.3^n)$. n ≤ 30 完全无压力.

### 5.4 LC 39 - 组合总和 (Medium, 回溯)

**题意**: 给定无重复元素数组 `candidates` 和目标 `target`, 找出所有使数字和为 target 的组合. `candidates` 中同一数字可被无限次选取.

**思路**: 回溯. 为避免重复组合 (如 [2,2,3] 和 [3,2,2] 被视为同一), 排序后在递归中限制**下轮搜索从当前下标开始**, 不回头.

**Python**:
```python
class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        candidates.sort()
        res, path = [], []
        def dfs(i, remain):
            if remain == 0:
                res.append(path[:])
                return
            for j in range(i, len(candidates)):
                c = candidates[j]
                if c > remain: break
                path.append(c)
                dfs(j, remain - c)
                path.pop()
        dfs(0, target)
        return res
```

**Java**:
```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    int[] cand;
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        cand = candidates; Arrays.sort(cand);
        dfs(0, target); return res;
    }
    void dfs(int i, int remain) {
        if (remain == 0) { res.add(new ArrayList<>(path)); return; }
        for (int j = i; j < cand.length; j++) {
            if (cand[j] > remain) break;
            path.add(cand[j]);
            dfs(j, remain - cand[j]);
            path.remove(path.size() - 1);
        }
    }
}
```

**C++**:
```cpp
class Solution {
public:
    vector<vector<int>> res;
    vector<int> path;
    vector<int> cand;
    vector<vector<int>> combinationSum(vector<int>& candidates, int target) {
        cand = candidates; sort(cand.begin(), cand.end());
        dfs(0, target); return res;
    }
    void dfs(int i, int remain) {
        if (remain == 0) { res.push_back(path); return; }
        for (int j = i; j < (int)cand.size(); j++) {
            if (cand[j] > remain) break;
            path.push_back(cand[j]);
            dfs(j, remain - cand[j]);
            path.pop_back();
        }
    }
};
```

**关键**: 排序 + `c > remain` 剪枝; `dfs(j, ...)` 而非 `dfs(j+1, ...)` 允许重复选取.

### 5.5 LC 40 - 组合总和 II (Medium, 回溯 + 去重)

**题意**: 同 LC39, 但 `candidates` 含重复数字, 每个数字只能使用一次.

**思路**: 排序后, 同一层递归中跳过相同值的"上一个分支": 若 `j > i && candidates[j] == candidates[j-1]`, 跳过 `j`. 不同层递归 (即同一个组合内) 允许相同值.

**Python**:
```python
class Solution:
    def combinationSum2(self, candidates: List[int], target: int) -> List[List[int]]:
        candidates.sort()
        res, path = [], []
        def dfs(i, remain):
            if remain == 0:
                res.append(path[:])
                return
            for j in range(i, len(candidates)):
                if j > i and candidates[j] == candidates[j-1]: continue
                c = candidates[j]
                if c > remain: break
                path.append(c)
                dfs(j + 1, remain - c)
                path.pop()
        dfs(0, target)
        return res
```

**Java**:
```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    public List<List<Integer>> combinationSum2(int[] cand, int target) {
        Arrays.sort(cand); dfs(cand, 0, target); return res;
    }
    void dfs(int[] c, int i, int remain) {
        if (remain == 0) { res.add(new ArrayList<>(path)); return; }
        for (int j = i; j < c.length; j++) {
            if (j > i && c[j] == c[j-1]) continue;
            if (c[j] > remain) break;
            path.add(c[j]); dfs(c, j + 1, remain - c[j]);
            path.remove(path.size() - 1);
        }
    }
}
```

**C++**:
```cpp
class Solution {
public:
    vector<vector<int>> res;
    vector<int> path;
    vector<vector<int>> combinationSum2(vector<int>& cand, int target) {
        sort(cand.begin(), cand.end());
        dfs(cand, 0, target); return res;
    }
    void dfs(vector<int>& c, int i, int remain) {
        if (remain == 0) { res.push_back(path); return; }
        for (int j = i; j < (int)c.size(); j++) {
            if (j > i && c[j] == c[j-1]) continue;
            if (c[j] > remain) break;
            path.push_back(c[j]);
            dfs(c, j + 1, remain - c[j]);
            path.pop_back();
        }
    }
};
```

**去重核心**: 排序后, 同一层 `for` 中 `c[j] == c[j-1]` 跳过 (排除重复组合); 不同层 (递归深度增加) 允许相同值, 因为同一组合内重复值是合法的 (来自原始数组的不同位置).

### 5.6 LC 41 - 缺失的第一个正数 (Hard, 原地哈希)

**题意**: 给定未排序整数数组 `nums`, 找出未出现的最小正整数. 要求 $O(n)$ 时间 + $O(1)$ 额外空间.

**思路**: 把数字 `x` 放到下标 `x-1` 的位置 (桶排序思想). 遍历两次: 第一次放, 第二次找第一个 `nums[i] != i+1`.

**Python**:
```python
class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:
        n = len(nums)
        for i in range(n):
            while 1 <= nums[i] <= n and nums[nums[i]-1] != nums[i]:
                j = nums[i] - 1
                nums[i], nums[j] = nums[j], nums[i]
        for i in range(n):
            if nums[i] != i + 1:
                return i + 1
        return n + 1
```

### 5.7 LC 43 - 字符串相乘 (Medium, 字符串模拟)

**题意**: 给定两个以字符串形式表示的非负整数 `num1` 和 `num2`, 返回 `num1 * num2` 的字符串形式. 不能用 BigInteger 库直接转.

**思路**: 结果最大长度 `m+n`. 用 `int[m+n]` 数组 `res` 累计每位乘积: `num1[i] * num2[j]` 加到 `res[i+j+1]` (低位). 最后统一处理进位并转字符串.

**Python**:
```python
class Solution:
    def multiply(self, num1: str, num2: str) -> str:
        if num1 == "0" or num2 == "0": return "0"
        m, n = len(num1), len(num2)
        res = [0] * (m + n)
        for i in range(m-1, -1, -1):
            for j in range(n-1, -1, -1):
                mul = int(num1[i]) * int(num2[j])
                p1, p2 = i + j, i + j + 1
                s = mul + res[p2]
                res[p2] = s % 10
                res[p1] += s // 10
        i = 0
        while i < len(res) and res[i] == 0: i += 1
        return "".join(map(str, res[i:]))
```

**Java**:
```java
class Solution {

        for (int i = m - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {

                int p1 = i + j, p2 = i + j + 1;
                int s = mul + res[p2];
                res[p2] = s % 10;
                res[p1] += s / 10;
            }
        }
        int i = 0;
        while (i < res.length && res[i] == 0) i++;
        StringBuilder sb = new StringBuilder();
        for (; i < res.length; i++) sb.append(res[i]);
        return sb.toString();
    }
}
```

### 5.8 LC 44 - 通配符匹配 (Hard, DP / 贪心)

**题意**: 给定字符串 `s` 和模式 `p`, `p` 中 `?` 匹配任意单个字符, `*` 匹配任意字符序列 (包括空). 判断 `s` 是否能匹配 `p`.

**思路 (DP)**: `dp[i][j]` = `s[:i]` 是否匹配 `p[:j]`. 转移: 若 `p[j-1] == '*'`, `dp[i][j] = dp[i][j-1] (空) | dp[i-1][j] (匹配一个字符)`. 空间可压成 1D.

**Python (DP 一维)**:
```python
class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        m, n = len(s), len(p)
        dp = [False] * (n + 1)
        dp[0] = True
        for j in range(1, n + 1):
            dp[j] = dp[j-1] and p[j-1] == '*'
        for i in range(1, m + 1):
            new = [False] * (n + 1)
            for j in range(1, n + 1):
                if p[j-1] == '*':
                    new[j] = new[j-1] or dp[j]
                elif p[j-1] == '?' or p[j-1] == s[i-1]:
                    new[j] = dp[j-1]
            dp = new
        return dp[n]
```

**Java**:
```java

            }

        }
        return dp[n];
    }
}
```

### 5.9 LC 45 - 跳跃游戏 II (Medium, 贪心)

**题意**: 给定非负整数数组 `nums`, 初始位置在下标 0, 每个元素表示该位置可跳跃的最大长度. 返回到达 `nums[n-1]` 的最小跳跃次数. 假设总能到达.

**思路**: 贪心. 维护当前能到达的边界 `end` 和下一步能到达的最远位置 `farthest`. 当 `i == end` 时跳跃次数 +1, 更新 `end = farthest`.

**Python**:
```python
class Solution:
    def jump(self, nums: List[int]) -> int:
        n = len(nums)
        if n <= 1: return 0
        end, farthest, jumps = 0, 0, 0
        for i in range(n - 1):
            farthest = max(farthest, i + nums[i])
            if i == end:
                jumps += 1
                end = farthest
        return jumps
```

**Java**:
```java

        for (int i = 0; i < n - 1; i++) {
            farthest = Math.max(farthest, i + nums[i]);
            if (i == end) { jumps++; end = farthest; }
        }

    }
}
```


**关键**: 循环到 `n-2` 即可, 因为到达 `n-1` 时不需要再跳跃; `end` 实时更新保证不会"漏跳".

### 5.10 LC 46 - 全排列 (Medium, 回溯)

**题意**: 给定不含重复数字的数组 `nums`, 返回所有可能的全排列.

**思路**: 回溯, 用 `used` 数组标记已使用元素. 每层递归遍历所有未使用元素.

**Python**:
```python
class Solution:
    def permute(self, nums: List[int]) -> List[List[int]]:
        n = len(nums)
        used = [False] * n
        res, path = [], []
        def dfs():
            if len(path) == n:
                res.append(path[:])
                return
            for i in range(n):
                if used[i]: continue
                used[i] = True
                path.append(nums[i])
                dfs()
                path.pop()
                used[i] = False
        dfs()
        return res
```

**Java**:
```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    boolean[] used;
    int[] nums;
    public List<List<Integer>> permute(int[] nums) {
        this.nums = nums;
        this.used = new boolean[nums.length];
        dfs(); return res;
    }
    void dfs() {
        if (path.size() == nums.length) { res.add(new ArrayList<>(path)); return; }
        for (int i = 0; i < nums.length; i++) {
            if (used[i]) continue;
            used[i] = true; path.add(nums[i]);
            dfs();
            path.remove(path.size() - 1); used[i] = false;
        }
    }
}
```

**C++**:
```cpp
class Solution {
public:
    vector<vector<int>> res;
    vector<int> path;
    vector<int> nums;
    vector<bool> used;
    vector<vector<int>> permute(vector<int>& _nums) {
        nums = _nums;
        used.assign(nums.size(), false);
        dfs(); return res;
    }
    void dfs() {
        if ((int)path.size() == (int)nums.size()) { res.push_back(path); return; }
        for (int i = 0; i < (int)nums.size(); i++) {
            if (used[i]) continue;
            used[i] = true; path.push_back(nums[i]);
            dfs();
            path.pop_back(); used[i] = false;
        }
    }
};
```

**关键**: 与组合 (LC39/40) 不同, 排列的下一层递归从 0 开始 (重新选), 但 `used` 数组防止重复. 复杂度 $O(n!)$.

### 5.11 LC 48 - 旋转图像 (Medium, 原地变换)

**题意**: 给定 n×n 二维矩阵 `matrix`, 表示图像. 将其**原地**顺时针旋转 90°.

**思路**: 两步走 —— 先**转置** (沿主对角线翻转), 再**水平翻转** (每行反转). 或: 先水平翻转, 再沿副对角线翻转.

**Python**:
```python
class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        n = len(matrix)
        for i in range(n):
            for j in range(i + 1, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
        for row in matrix:
            row.reverse()
```

**Java**:
```java
class Solution {
    public void rotate(int[][] matrix) {
        int n = matrix.length;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int t = matrix[i][j]; matrix[i][j] = matrix[j][i]; matrix[j][i] = t;
            }
        }
        for (int[] row : matrix) {
            for (int l = 0, r = n - 1; l < r; l++, r--) {
                int t = row[l]; row[l] = row[r]; row[r] = t;
            }
        }
    }
}
```

**C++**:
```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                swap(matrix[i][j], matrix[j][i]);
            }
        }
        for (auto& row : matrix) reverse(row.begin(), row.end());
    }
};
```

**关键**: 转置时 `j > i` 即可 (避免重复交换). 原地 $O(1)$ 额外空间, $O(n^2)$ 时间.

## 6. 多解法对比 (每题的替代思路)

> 同一道题, 不同解法在时间/空间/可读性上各有取舍. 面试中若能给 2 种解法并比较, 通常是加分项.

### 6.1 LC 35 - 搜索插入位置

| 解法 | 时间 | 空间 | 备注 |
|---|---|---|---|
| **左闭右闭 `[l,r]`** | $O(\log n)$ | $O(1)$ | 经典写法; `l+r>>1` |
| **左闭右开 `[l,r)`** | $O(\log n)$ | $O(1)$ | 推荐; 更清晰, 不易越界 |
| **库函数** | $O(\log n)$ | $O(1)$ | `bisect_left(nums, target)` |
| **线性扫描** | $O(n)$ | $O(1)$ | 题目要求 $O(\log n)$, 不推荐 |

**面试要点**: 强调"为什么右开?" —— 因为 `right` 表示**第一个可能的位置**, 而非"最后一个有效的下标". 左闭右闭写法中 `right = mid - 1` 是因为 `mid` 已经确认不是答案; 而左闭右开 `right = mid` 是因为 `mid` 还可能是答案.

### 6.2 LC 36 - 有效的数独

| 解法 | 时间 | 空间 | 备注 |
|---|---|---|---|
| **3 个 9×9 哈希表** | $O(81)$ | $O(243)$ | 最直观 |
| **3 个 9-bit 整数 (位运算)** | $O(81)$ | $O(27 \cdot 4B)$ | 推荐; 节省空间 |

**面试要点**: 位运算本质是"用 int 的 bit 位模拟 set". 若面试官要求"只用 $O(1)$ 空间", 第三种方案是极致.

### 6.6 LC 41 - 缺失的第一个正数

| 解法 | 时间 | 空间 | 备注 |
|---|---|---|---|
| **原地哈希 (推荐)** | $O(n)$ | $O(1)$ | 把 `x` 放到下标 `x-1` |
| **哈希 set** | $O(n)$ | $O(n)$ | 不满足空间要求 |
| **排序后扫描** | $O(n \log n)$ | $O(1)$ | 违反时间要求 |
| **位图** | $O(n)$ | $O(n)$ | 空间爆炸 |

**面试要点**: "原地哈希"是 41 题的灵魂. 解释: 答案只可能在 `[1, n+1]`. 因此把 `[1, n]` 范围内的数字放到对应下标, 扫一遍找 `nums[i] != i+1`. 复杂度分析的难点是"while 循环总次数" —— 每个数最多被换到正确位置一次, 故摊销 $O(n)$.

### 6.7 LC 43 - 字符串相乘

| 解法 | 时间 | 空间 | 备注 |
|---|---|---|---|
| **数组累计 + 后处理进位** | $O(mn)$ | $O(m+n)$ | 推荐 |
| **逐位相乘 + 立即进位** | $O(mn)$ | $O(m+n)$ | 复杂; 易错 |
| **大数库** | 不允许 | — | 题目禁止 |

**面试要点**: "为什么用 `m+n` 长度数组?" —— 因为 `num1 * num2` 最多 `m+n` 位 (含进位). "为什么从后往前?" —— 因为数组 `res[0]` 是最高位, 数字低位在后, 方便按"自然乘法"顺序累加.

### 6.8 LC 44 - 通配符匹配

**面试要点**: DP 转移是核心: `p[j-1]=='*'` 时, `dp[i][j]` 等于"忽略这个 `*` (空匹配)" 或 "`*` 吃掉 `s[i-1]`". 贪心做法维护两个指针 `i, j` 和"上一个 `*` 的位置", 当不匹配时回溯到 `*` 处.

### 6.9 LC 45 - 跳跃游戏 II

| 解法 | 时间 | 空间 | 备注 |
|---|---|---|---|
| **贪心 (推荐)** | $O(n)$ | $O(1)$ | 维护 `end, farthest` |
| **BFS 层序** | $O(n)$ | $O(n)$ | 不推荐 |
| **DP** | $O(n^2)$ | $O(n)$ | 不推荐 |
| **反向贪心** | $O(n^2)$ | $O(1)$ | 从终点往回找 |

**面试要点**: 贪心为什么是对的? 证明思路: 在 `[i, end]` 这一段内, 任意位置能跳到的最远点都不超过 `farthest`. 故一次跳跃必能到达 `farthest` 内的任意点, 包括 `end` 之后的所有点. 所以步数最优.

### 6.10 LC 46 - 全排列

| 解法 | 时间 | 空间 | 备注 |
|---|---|---|---|
| **回溯 + used 数组** | $O(n!)$ | $O(n)$ | 推荐 |
| **回溯 + 交换法** | $O(n!)$ | $O(n)$ | 不需要 used 数组 |
| **next_permutation (C++)** | $O(n!)$ | $O(1)$ | 适用于"枚举字典序排列" |

**交换法 Python**:
```python
def permute(nums):
    res = []
    def dfs(k):
        if k == len(nums):
            res.append(nums[:])
            return
        for i in range(k, len(nums)):
            nums[k], nums[i] = nums[i], nums[k]
            dfs(k + 1)
            nums[k], nums[i] = nums[i], nums[k]
    dfs(0)
    return res
```

### 6.11 LC 48 - 旋转图像

| 解法 | 时间 | 空间 | 备注 |
|---|---|---|---|
| **转置 + 水平翻转** | $O(n^2)$ | $O(1)$ | 推荐 |
| **水平翻转 + 副对角翻转** | $O(n^2)$ | $O(1)$ | 同样 |
| **新建矩阵** | $O(n^2)$ | $O(n^2)$ | 简单但不满足原地 |
| **逐层旋转 4 元素** | $O(n^2)$ | $O(1)$ | 难写 |

**面试要点**: 用坐标变换证明. 原坐标 `(i, j)` 旋转 90° 后到 `(j, n-1-i)`. 转置 = `(i,j) → (j,i)`, 再水平翻转 = `(j,i) → (j, n-1-i)`, 恰好是旋转结果.

## 7. 复杂度详解 (摊销分析 / 递推 / 下界)

> 大部分同学会背 $O(n)$, 但面试官追问"为什么"时, 需要能解释清楚.

---

### 7.1 时间复杂度分类回顾

| 大O | 名称 | 典型场景 |
|---|---|---|
| $O(1)$ | 常数 | 哈希查表, 数组按下标访问 |
| $O(\log n)$ | 对数 | 二分, 平衡 BST 操作 |
| $O(n)$ | 线性 | 一次扫描, 单调栈 |
| $O(n \log n)$ | 线性对数 | 排序, 分治 |
| $O(n^2)$ | 平方 | 双重循环, 朴素 DP |
| $O(2^n)$ | 指数 | 子集枚举, 朴素递归 fib |
| $O(n!)$ | 阶乘 | 全排列, 旅行商 (NP-hard) |

---

### 7.2 LC 41 的摊销分析 (常考点)

```text
while 1 <= nums[i] <= n and nums[nums[i]-1] != nums[i]:
    swap(nums[i], nums[nums[i]-1])
```

**问题**: 表面上 `while` 看起来是 $O(n)$ 里套循环, 整体 $O(n^2)$. 为什么实际是 $O(n)$?

**答**: 摊销分析. 对每个数字 `x`, 最多被换到正确位置 `x-1` **一次**. 换到位之后, `nums[nums[i]-1] == nums[i]` 恒成立, while 不会再进入. 总交换次数 ≤ n. 故总时间 $O(n)$.

**关键**: 摊销的前提是"循环体让单调变量 +1". 这里每个数字最多被正确放一次, 故单调推进.

---

### 7.3 LC 39/40/46 的回溯时间复杂度

**回溯时间 = 答案数 × 单个答案的构造代价**.

- LC 39: 答案数上界 $O(\binom{n+t}{t})$ (t = target/min). 单答案 $O(t)$. 故上界 $O(t \cdot \binom{n+t}{t})$.
- LC 40: 答案数上界同 LC39, 但去重剪枝.
- LC 46: 答案数固定 $n!$. 单答案 $O(n)$. 总 $O(n \cdot n!)$.

**面试常见反问**: "为什么 LC 46 是 $O(n!)$ 而不是 $O(2^n)$?" —— 因为是**排列** (有序), 元素位置有区别. 组合 (子集) 才是 $O(2^n)$.

---

### 7.4 LC 44 DP 的状态数与转移数

**状态数**: $(m+1)(n+1)$.
**每个状态的转移**: $O(1)$ (只看 `p[j-1]` 一个字符).
**总时间**: $O(mn)$.
**空间**: 二维 $O(mn)$, 一维滚动 $O(n)$.

**为什么能压成 1D?** 转移只依赖 `dp[i-1][j-1]` (上一行左列) 和 `dp[i][j-1]` (当前行左列), 不需要完整二维数组.

---

### 7.5 LC 45 贪心的最优性证明 (反证法)

**命题**: 贪心算法跳跃次数 = 最少跳跃次数.

**证明**: 设贪心算法跳了 $k$ 次. 第 $i$ 次跳跃后到达区间 $[l_i, r_i]$, $r_i$ 是从 $[l_{i-1}+1, r_{i-1}]$ 中任一位置可跳到的最远点. 故 $r_i \geq \max_{p \in [l_{i-1}+1, r_{i-1}]}(p + nums[p])$. 任何算法在第 $i$ 步之后, 最远也只能到达 $r_i$. 故 $k$ 步是最小的. QED.

**面试要点**: 不要死记硬背, 准备一个"区间扩张 + 反证"的模板.

---

### 7.6 LC 43 进位不溢出的证明

`res[p1] += s / 10`, `p1 = i + j`, 数组长度 `m+n`. 最高位 `res[0]` 最多累积多少?

最坏情况: `num1 = "999...9"` (m 个 9), `num2 = "999...9"` (n 个 9). 每个 `res[p1]` 在最坏情况下被加 `min(p1, m) * min(n-1-p1, ...)` 次, 总和上界 `mn`. 故 `res[0] < mn`, 进位累加仍 < `m+n` 数量级, 不溢出 int (m, n ≤ 110, 故 mn ≤ 12100, 完全安全).

---

### 7.7 空间复杂度分类

| 空间类型 | 含义 | 例子 |
|---|---|---|
| $O(1)$ 原地 | 仅用常数变量 | 双指针, 单调栈 (栈大小 ≤ n 但不计输入本身) |
| $O(1)$ 辅助 | 不计输入数组本身 | 哈希表, 数组标记 |
| $O(n)$ 线性 | 与输入规模成线性 | 哈希 set |
| $O(\log n)$ | 递归栈深度 | 二分递归 |

**面试中"原地"严格指**: 除输入本身外, 不申请任何新数据结构.

---

### 7.8 下界 (Lower Bound) 概念

有些题有**信息论下界**:

- LC 35: 至少要比较到能确定位置的元素. 二分是**最优**.
- LC 41: 至少要"访问所有元素"才能判断缺失. $O(n)$ 是下界.
- LC 39/40: 必须枚举所有合法组合. 下界就是答案数.
- LC 36: 必须检查 81 个格子. $O(81)$ 是下界.

**面试要点**: 当被问"还能更快吗?", 思考下界. 若已达下界, 说明最优.

```python
# 标准左边界
def bisect_left(nums, target):
    l, r = 0, len(nums)
    while l < r:
        m = (l + r) // 2
        if nums[m] < target: l = m + 1
        else: r = m
    return l
```

```python
    # Floyd 快慢指针
    slow = fast = 0
    while True:
        slow = nums[slow]
        fast = nums[nums[fast]]
        if slow == fast: break
    slow = 0
    while slow != fast:
        slow = nums[slow]
        fast = nums[fast]
    return slow
```

## 9. 面试追问 (Follow-up Questions)

> 面试官常问的"延伸问题". 提前准备, 能体现深度.

---

### 9.1 通用追问

| 类别 | 追问 | 回答要点 |
|---|---|---|
| **复杂度** | "能不能更快?" | 分析下界, 看是否已达最优 |
| **空间** | "能不能 $O(1)$ 空间?" | 尝试原地算法, 如 LC 41 原地哈希 |
| **正确性** | "为什么这个贪心是对的?" | 区间扩张 + 反证 |
| **边界** | "输入为空呢?" | 加 `if not nums: return ...` |
| **极端** | "全相等 / 全递增 / 全递减?" | 单独说明各分支 |
| **大数据** | "输入是流式 / 单调栈能处理吗?" | 单调栈天然适合流式 |

---

### 9.2 LC 35 专属追问

**Q**: 如果数组是循环有序的 (LC 33)?
**A**: 二分时判断哪半边有序: 若 `nums[l] <= nums[mid]`, 左半有序; 否则右半有序. 进一步判断 target 在哪半边.

**Q**: 找 target 出现的第一个和最后一个位置 (LC 34)?
**A**: 两次二分, 第一次找左边界, 第二次找右边界 (`bisect_right - 1`).

**Q**: 海量数据 (10 亿) 中找某数?
**A**: 内存放不下, 需外排序 + 二分; 或用 Bloom Filter 估概率; 或分布式 (MapReduce).

---

### 9.3 LC 36 专属追问

**Q**: 怎么改成求数独的解?
**A**: LC 37, 回溯 + 位运算优化. 关键: 用 `row[i] | col[j] | box[b]` 求候选数字 (`~(...) & 0x1FF`).

**Q**: 9×9 改成 16×16 (含字母)?
**A**: 哈希/位图扩展到 16 bit, 候选数逻辑相应调整.

---

### 9.4 LC 39/40 专属追问

**Q**: 如果 candidates 含负数?
**A**: 排序后剪枝失效 (因为负数 ≤ remain 始终成立). 需放弃剪枝, 或先 partition 正负数组分别处理.

**Q**: candidates 长度 100, target 1000, 时间能接受吗?
**A**: 答案数可能 $\binom{100+10}{10} \approx 10^{13}$, 太大. 需要剪枝 (例如限制答案长度). 纯回溯不适用, 考虑 meet-in-the-middle.

**Q**: 怎么改成"求方案数"?
**A**: DP 完全背包. `dp[i] = sum(dp[i - c]) for c in candidates if c <= i`. 输出 `dp[target]`.

---

### 9.5 LC 41 专属追问

**Q**: 如果数字范围是 [a, b]?
**A**: 偏移. 把每个数字 `x` 映射到 `x - a + 1`, 然后套用标准做法. 答案再偏移回来.

**Q**: 输入是流式 (不能修改) 怎么办?
**A**: 无法 $O(1)$ 空间. 退化为 $O(n)$ 哈希.

**Q**: 找出所有缺失的数字?
**A**: LC 448. 套用 LC41 思路, 第二次遍历把所有 `nums[i] != i+1` 的位置记下.

---

### 9.6 LC 43 专属追问

**Q**: 改成大整数乘法, 怎么处理溢出?
**A**: Python 无此问题 (int 任意大). Java/C++ 用 long 或 BigInteger (但题目禁止).

**Q**: 怎么优化常数?
**A**: 1) 提前处理零; 2) 减少 string-to-int 转换; 3) 一次性处理整段连续零 (在末尾时跳过).

---

### 9.7 LC 44 专属追问

**Q**: `*` 改成"任意非空字符串", 怎么办?
**A**: DP 状态相同, 但转移条件改为 `p[j-1] == '*'` 时必须 `s[i-1] == p[j-2]` (或反之), 否则 `dp[i][j] = dp[i-1][j-1]`.

**Q**: 模式很大 (10^5 字符), 字符串很小?
**A**: DP 是 $O(mn)$, 大模式慢. 改用自动机 (NFA/DFA) 或 KMP 变种.

---

### 9.8 LC 45 专属追问

**Q**: 如果不能保证能到达 (LC 55)?
**A**: 加判断 `if farthest < i: return -1` (或 False).

**Q**: 改成"最远能到达的下标"?
**A**: 维护 `farthest = max(farthest, i + nums[i])`, 循环结束返回.

**Q**: 改成"列出所有最少的跳跃路径"?
**A**: 反向 DP + 回溯. 先 DP 求最小步数, 再从终点倒推记录所有路径.

---

### 9.9 LC 46 专属追问

**Q**: 改成"输出字典序最小的排列"?
**A**: 先排序原数组, 再用交换法回溯 (交换法天然按字典序).

**Q**: 改成"所有排列中字典序第 k 个"?
**A**: LC 60, 阶乘编码.

**Q**: n=10 时怎么办? (n! = 3628800, 可接受; n=12 时 4.79e8, 慢)
**A**: 回溯已到极限. 用邻位交换 (Steinhaus-Johnson-Trotter) 或阶乘编码枚举第 k 个.

---

### 9.10 LC 48 专属追问

**Q**: 改成逆时针 90°?
**A**: 转置 + **垂直**翻转 (而非水平).

**Q**: 改成 180°?
**A**: 水平翻转 + 垂直翻转 (或转置两次).

**Q**: 矩阵是 m×n (非方阵)?
**A**: 转置后变成 n×m, 水平翻转. 但 m≠n 时不能原地转置 + 反转 (形状变了). 需要新数组.

**Q**: 改成"按对角线翻转"?
**A**: 仅转置, 不水平翻转.

---

### 9.11 LC 42 专属追问 (Hard 重点)

**Q**: 改成 2D 网格 (LC 407)?
**A**: BFS + 最小堆. 思路: 维护边界最小值, 每次从堆中取出最小, 邻居水位 = max(当前边界, 邻居高度). 累积差值即接水量.

**Q**: 改成"输出每个位置的接水量"?
**A**: 双指针 / DP 解法天然可以. 但**单调栈**解法可以扩展: 每次弹出时, 不仅累加 water, 还把 water 累加到 top_idx 位置上的"水位图"数组.

**Q**: 时间 $O(n)$ 空间 $O(1)$ 还能再优化吗?
**A**: 已经最优. 下界 $O(n)$ 时间 (必须遍历所有位置).

**Q**: 如果柱子高度是浮点数?
**A**: 算法不变, 仅数据类型变.

**Q**: 改成 3D 立方体 (三堆方块围水)?
**A**: NP-hard. 没有多项式算法 (类似 3D 凸包问题).

### 11.1 二分模板 (4 种变体)

```python
# 模板 A: 左闭右闭 [l, r]
def binary_search_a(nums, target):
    l, r = 0, len(nums) - 1
    while l <= r:
        m = l + (r - l) // 2
        if nums[m] < target: l = m + 1
        elif nums[m] > target: r = m - 1
        else: return m
    return -1

# 模板 B: 左闭右开 [l, r) - 推荐
def binary_search_b(nums, target):
    l, r = 0, len(nums)
    while l < r:
        m = l + (r - l) // 2
        if nums[m] < target: l = m + 1
        else: r = m
    return l if l < len(nums) and nums[l] == target else -1

# 模板 C: bisect_left - 第一个 >= target
def bisect_left(nums, target):
    l, r = 0, len(nums)
    while l < r:
        m = (l + r) // 2
        if nums[m] < target: l = m + 1
        else: r = m
    return l

# 模板 D: bisect_right - 第一个 > target
def bisect_right(nums, target):
    l, r = 0, len(nums)
    while l < r:
        m = (l + r) // 2
        if nums[m] <= target: l = m + 1
        else: r = m
    return l
```

**记忆口诀**:
- 找具体值 → 模板 A 或 B.
- 找左边界 (插入位置) → bisect_left.
- 找右边界 → bisect_right.
- 循环不变量: `nums[l-1] < target ≤ nums[r]` (左闭右开).

### 11.2 回溯模板 (4 种场景)

```python
# 场景 1: 子集 (每个元素选或不选)
def subsets(nums):
    res, path = [], []
    def dfs(i):
        if i == len(nums):
            res.append(path[:])
            return
        dfs(i + 1)  # 不选
        path.append(nums[i])
        dfs(i + 1)  # 选
        path.pop()
    dfs(0)
    return res

# 场景 2: 组合 (无重复元素, 选 k 个) - LC 77
def combine(n, k):
    res, path = [], []
    def dfs(i):
        if len(path) == k:
            res.append(path[:])
            return
        if n - i + 1 < k - len(path): return  # 剪枝
        for j in range(i, n + 1):
            path.append(j)
            dfs(j + 1)
            path.pop()
    dfs(1)
    return res

# 场景 3: 组合 (有重复, 每个用一次) - LC 40
def combination_sum_2(candidates, target):
    candidates.sort()
    res, path = [], []
    def dfs(i, remain):
        if remain == 0:
            res.append(path[:])
            return
        for j in range(i, len(candidates)):
            if j > i and candidates[j] == candidates[j-1]: continue
            if candidates[j] > remain: break
            path.append(candidates[j])
            dfs(j + 1, remain - candidates[j])
            path.pop()
    dfs(0, target)
    return res

# 场景 4: 排列 (无重复) - LC 46
def permute(nums):
    n = len(nums)
    used = [False] * n
    res, path = [], []
    def dfs():
        if len(path) == n:
            res.append(path[:])
            return
        for i in range(n):
            if used[i]: continue
            used[i] = True
            path.append(nums[i])
            dfs()
            path.pop()
            used[i] = False
    dfs()
    return res
```

**核心要素**: 1) 状态变量; 2) 终止条件; 3) 剪枝; 4) 回溯恢复.

### 11.3 单调栈模板 (3 种)

```python
# 模板 1: 下一个更大元素 - LC 496
def next_greater(nums):
    n = len(nums)
    res = [-1] * n
    stack = []
    for i in range(n):
        while stack and nums[i] > nums[stack[-1]]:
            res[stack.pop()] = nums[i]
        stack.append(i)
    return res

# 模板 2: 柱状图最大矩形 - LC 84
def largest_rectangle(heights):
    stack = []
    res = 0
    heights = [0] + heights + [0]
    for i, h in enumerate(heights):
        while stack and h < heights[stack[-1]]:
            top = stack.pop()
            w = i - stack[-1] - 1
            res = max(res, heights[top] * w)
        stack.append(i)
    return res

# 模板 3: 接雨水 - LC 42
def trap(height):
    stack = []
    water = 0
    for i, h in enumerate(height):
        while stack and h > height[stack[-1]]:
            top = stack.pop()
            if not stack: break
            w = i - stack[-1] - 1
            bh = min(h, height[stack[-1]]) - height[top]
            water += w * bh
        stack.append(i)
    return water
```

**核心**: 维护单调性 + 栈顶是"被破坏"的位置, 出栈时计算贡献.

### 11.4 双指针模板 (5 种)

```python
# 模板 1: 对撞指针 (有序数组两数之和)
def two_sum_sorted(nums, target):
    l, r = 0, len(nums) - 1
    while l < r:
        s = nums[l] + nums[r]
        if s < target: l += 1
        elif s > target: r -= 1
        else: return [l, r]
    return []

# 模板 2: 快慢指针 (原地去重)
def remove_dup(nums):
    slow = 0
    for fast in range(1, len(nums)):
        if nums[fast] != nums[slow]:
            slow += 1
            nums[slow] = nums[fast]
    return slow + 1

# 模板 3: 滑动窗口 (最长无重复子串)
def longest_unique(s):
    seen = {}
    l = res = 0
    for r, c in enumerate(s):
        if c in seen and seen[c] >= l:
            l = seen[c] + 1
        seen[c] = r
        res = max(res, r - l + 1)
    return res

# 模板 4: 接雨水 (左大右小)
def trap(height):
    l, r = 0, len(height) - 1
    lm = rm = 0
    water = 0
    while l < r:
        if height[l] < height[r]:
            lm = max(lm, height[l])
            water += lm - height[l]
            l += 1
        else:
            rm = max(rm, height[r])
            water += rm - height[r]
            r -= 1
    return water

# 模板 5: 盛最多水
def max_area(height):
    l, r = 0, len(height) - 1
    res = 0
    while l < r:
        res = max(res, min(height[l], height[r]) * (r - l))
        if height[l] < height[r]: l += 1
        else: r -= 1
    return res
```

### 11.5 DP 模板 (5 种)

```python
# 模板 1: 一维 DP (爬楼梯)
def climb(n):
    if n <= 2: return n
    a, b = 1, 2
    for _ in range(3, n + 1):
        a, b = b, a + b
    return b

# 模板 2: 二维 DP (最长公共子序列)
def lcs(s1, s2):
    m, n = len(s1), len(s2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s1[i-1] == s2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]

# 模板 3: 背包 DP (0-1 背包)
def knapsack(weights, values, W):
    n = len(weights)
    dp = [0] * (W + 1)
    for i in range(n):
        for w in range(W, weights[i] - 1, -1):
            dp[w] = max(dp[w], dp[w - weights[i]] + values[i])
    return dp[W]

# 模板 4: 区间 DP (最长回文子序列)
def lps(s):
    n = len(s)
    dp = [[0] * n for _ in range(n)]
    for i in range(n - 1, -1, -1):
        dp[i][i] = 1
        for j in range(i + 1, n):
            if s[i] == s[j]:
                dp[i][j] = dp[i+1][j-1] + 2
            else:
                dp[i][j] = max(dp[i+1][j], dp[i][j-1])
    return dp[0][n-1]

# 模板 5: 状态机 DP (股票买卖)
def max_profit(prices):
    hold, cash = -prices[0], 0
    for p in prices[1:]:
        hold = max(hold, -p)
        cash = max(cash, hold + p)
    return cash
```

**核心**: 状态定义 + 转移方程 + 初始化 + 遍历顺序.

```python
def preorder(root):
    if not root: return
    res.append(root.val)
    preorder(root.left)
    preorder(root.right)

def inorder(root):
    if not root: return
    inorder(root.left)
    res.append(root.val)
    inorder(root.right)

def postorder(root):
    if not root: return
    postorder(root.left)
    postorder(root.right)
    res.append(root.val)

# 模板 2: 层序遍历 (BFS)
def level_order(root):
    if not root: return []
    res, q = [], [root]
    while q:
        nxt = []
        for node in q:
            res.append(node.val)
            if node.left: nxt.append(node.left)
            if node.right: nxt.append(node.right)
        q = nxt
    return res

# 模板 3: 最大深度

    if not root: return 0
    return 1 + max(max_depth(root.left), max_depth(root.right))

# 模板 4: 翻转二叉树
def invert(root):

    root.left, root.right = invert(root.right), invert(root.left)

        if not node: return True
        if not (lo < node.val < hi): return False
        return inorder(node.left, lo, node.val) and inorder(node.right, node.val, hi)
```

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "高频面试题 26-37 (含 LeetCode 42 接雨水详解)" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
