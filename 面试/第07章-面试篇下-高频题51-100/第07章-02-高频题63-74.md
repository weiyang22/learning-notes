## 2. LeetCode 75 - 颜色分类 (Medium) ⭐TOP15

### 题目描述

给定一个包含红色、白色和蓝色, 一共 `n` 个元素的数组 `nums`, **原地**对它们进行排序, 使得相同颜色的元素相邻, 并按照红色、白色、蓝色顺序排列.

此题中, 我们使用整数 `0`、`1` 和 `2` 分别表示红色、白色和蓝色.

**约束**: 不能使用 sort 函数.

### 思路分析

这是经典的**荷兰国旗问题** (Dijkstra 提出), 有 3 种解法:

| 方法 | 时间 | 空间 | 难度 |
|---|---|---|---|
| 1. 两次遍历 (计数) | $O(n)$ | $O(1)$ | ⭐ |
| 2. 两次遍历 (双指针分区) | $O(n)$ | $O(1)$ | ⭐⭐ |
| 3. 三向切分 (Dutch Flag) | $O(n)$ | $O(1)$ | ⭐⭐ |

### 方法 1: 计数排序 (简单但要 2 遍)

```python
def sortColors(nums):
    """计数"""
    count = [0, 0, 0]
    for x in nums:
        count[x] += 1

    idx = 0
    for color in range(3):
        for _ in range(count[color]):
            nums[idx] = color
            idx += 1
```

### 方法 2: 双指针分区 (推荐)

**核心**: 一次遍历, 用两个指针把 0/1/2 分别放到正确位置.

```text
0 区间: [0, p0)
1 区间: [p0, i)
未处理: [i, p2]
2 区间: (p2, n-1]

curr = i, 当 curr < p2:
    if nums[curr] == 0: 交换 nums[p0] 和 nums[curr], p0++, curr++
    elif nums[curr] == 1: curr++
    else:  # == 2
        p2--
        交换 nums[curr] 和 nums[p2]
        # 注意: curr 不动, 因为换过来的元素还没处理
```

```python
def sortColors(nums):
    """三向切分 Dutch Flag"""
    p0, p2 = 0, len(nums) - 1
    curr = 0

    while curr <= p2:
        if nums[curr] == 0:
            nums[p0], nums[curr] = nums[curr], nums[p0]
            p0 += 1
            curr += 1
        elif nums[curr] == 2:
            nums[p2], nums[curr] = nums[curr], nums[p2]
            p2 -= 1
            # curr 不动! 因为换过来的元素还没看
        else:  # == 1
            curr += 1
```

**为什么 curr 在 case 0 时 ++, case 2 时不动?**

```text
case 0: 换过来的一定是 1 (因为 p0 左侧一定是 0), 直接处理 1 就 OK, curr++
case 1: 自己就是 1, 直接 curr++
case 2: 换过来的是未知的 (可能是 0/1/2), 必须再看一次, curr 不动
```

### 复杂度

- 时间: $O(n)$
- 空间: $O(1)$ (原地)

### 拓展: 荷兰国旗

- **LeetCode 75** 颜色分类 (3 值)
- **LeetCode 324** 摆动排序 II (类似思想)
- **快速排序的 partition** (2 值的荷兰国旗)

## 4. LeetCode 78 - 子集 (Medium) ⭐TOP10

### 题目描述

给你一个整数数组 `nums`, 数组中的元素 **互不相同**. 返回该数组所有可能的子集 (幂集).

解集 **不能** 包含重复的子集. 你可以按 **任意顺序** 返回解集.

**示例**:
```text
输入: nums = [1,2,3]
输出: [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

### 思路分析

3 种主流解法:

| 方法 | 时间 | 空间 | 思路 |
|---|---|---|---|
| 1. 迭代 | $O(n \cdot 2^n)$ | $O(2^n)$ | 每加一个元素, 复制已有子集并加入新元素 |
| 2. 回溯 | $O(n \cdot 2^n)$ | $O(n)$ | 经典回溯 |
| 3. 位运算 | $O(n \cdot 2^n)$ | $O(1)$ (除结果) | 用 mask 表示子集 |

### 方法 1: 迭代

```python
def subsets(nums):
    res = [[]]
    for x in nums:
        # 对每个已有子集, 创建新子集 = 旧子集 + [x]
        res += [sub + [x] for sub in res]
    return res
```

**图解**:
```text
nums = [1, 2, 3]

初始化: [[]]
加 1: [[], [1]]
加 2: [[], [1], [2], [1,2]]
加 3: [[], [1], [2], [1,2], [3], [1,3], [2,3], [1,2,3]]
```

### 方法 2: 回溯

```python
def subsets(nums):
    res = []

    def backtrack(start, path):
        # 每到一个状态都记录 (因为子集任意长度)
        res.append(path[:])
        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i + 1, path)
            path.pop()

    backtrack(0, [])
    return res
```

### 方法 3: 位运算

```python
def subsets(nums):
    n = len(nums)
    res = []
    for mask in range(1 << n):  # 2^n 个子集
        subset = [nums[i] for i in range(n) if mask & (1 << i)]
        res.append(subset)
    return res
```

**位运算理解**:
```text
nums = [1, 2, 3], n=3, 2^3 = 8 个子集

mask=000 (0): []        mask=100 (4): [3]
mask=001 (1): [1]      mask=101 (5): [1,3]
mask=010 (2): [2]      mask=110 (6): [2,3]
mask=011 (3): [1,2]    mask=111 (7): [1,2,3]
```

### 复杂度

- 时间: $O(n \cdot 2^n)$
- 空间: $O(2^n)$ (结果集)

### 子集 vs 排列 vs 组合

| 类型 | 区别 | 代表题 |
|---|---|---|
| **子集** | 任选 0~n 个 (顺序无关) | 78, 90 |
| **组合** | 选 k 个 (顺序无关) | 77, 39, 40 |
| **排列** | 选 n 个 (顺序敏感) | 46, 47 |

## A.1 LeetCode 94 - 二叉树的中序遍历 (Easy)

### 题目描述

给定一个二叉树的根节点 `root`, 返回它的 **中序** 遍历.

**示例**:
```text
输入: root = [1, null, 2, 3]
输出: [1, 3, 2]

树结构:
    1
     \
      2
     /
    3
```

### 思路分析

中序遍历顺序: 左 → 根 → 右.

| 方法 | 时间 | 空间 | 难度 |
|---|---|---|---|
| 1. 递归 | O(n) | O(h) | ⭐ |
| 2. 迭代 (栈) | O(n) | O(h) | ⭐⭐ |
| 3. Morris 遍历 | O(n) | O(1) | ⭐⭐⭐ |

注: h = 树高, 最坏 O(n).

### 方法 1: 递归 (最直观)

```python
def inorderTraversal(root):
    res = []
    def dfs(node):
        if not node:
            return
        dfs(node.left)
        res.append(node.val)
        dfs(node.right)
    dfs(root)
    return res
```

### 方法 2: 迭代 (栈模拟递归) ⭐推荐

```python
def inorderTraversal(root):
    res, stack = [], []
    cur = root
    while cur or stack:
        # 一路向左压栈
        while cur:
            stack.append(cur)
            cur = cur.left
        # 弹出处理, 再走右子树
        cur = stack.pop()
        res.append(cur.val)
        cur = cur.right
    return res
```

**图解**:
```text
       1
      / \
     2   3
    / \
   4   5

stack 模拟:
push 1 → push 2 → push 4 (4.left 空, 弹 4, 处理右)
       → 弹 2 (处理右 push 5)
       → 弹 5 (5.left 空)
       → 弹 1 (处理右 push 3)
       → 弹 3
```

### 方法 3: Morris 遍历 (O(1) 空间) ⭐进阶

**核心**: 利用叶子节点的右指针临时指向后继, 遍历完再复原.

```python
def inorderTraversal(root):
    res = []
    cur = root
    while cur:
        if not cur.left:
            res.append(cur.val)
            cur = cur.right
        else:
            # 找 cur 左子树的最右节点 (前驱)
            pre = cur.left
            while pre.right and pre.right != cur:
                pre = pre.right
            if not pre.right:
                # 第一次访问, 建立线索
                pre.right = cur
                cur = cur.left
            else:
                # 第二次访问 (左子树已遍历完), 断开线索
                pre.right = None
                res.append(cur.val)
                cur = cur.right
    return res
```

### 复杂度

- 时间: O(n) — 每个节点最多被访问 3 次 (进入/前驱/后继), 但总操作 O(n).
- 空间: 递归 O(h), 迭代 O(h), Morris O(1).

### 失败案例与陷阱

| 场景 | 错误写法 | 后果 |
|---|---|---|
| 忘记判空 | `cur.left.val` | 空指针 |
| 迭代顺序错 | 先 push 再判 cur | 死循环 |
| Morris 不断开 | 不写 `pre.right = None` | 树结构被破坏 (只读场景 OK) |

| 题号 | 题目 | 顺序 |

| 144 | 前序遍历 | 根左右 |
| 145 | 后序遍历 | 左右根 |

## A.2 LeetCode 96 - 不同的二叉搜索树 (Medium)

### 题目描述

给你一个整数 `n`, 求恰由 `n` 个节点组成且节点值从 `1` 到 `n` 互不相同的 **二叉搜索树** 有多少种? 返回满足题意的二叉搜索树的种数.

**示例**:
```text
输入: n = 3
输出: 5

5 棵:
  1         3     3      2      1
   \       /     /      / \      \
    3     2     1      1   3      2
   /     /       \                 /
  2     1         2               3
```

### 思路分析

**关键观察**: BST 的中序遍历是升序. 当根选 `i` 时:
- 左子树: [1..i-1] 共 `i-1` 个节点
- 右子树: [i+1..n] 共 `n-i` 个节点
- 方案数 = `G(i-1) * G(n-i)`

设 `G(n)` 为 n 个节点的 BST 数, 则:
```text
G(n) = Σ G(i-1) * G(n-i),  i=1..n
```

这就是**卡特兰数** (Catalan Number):
```text
C(n) = C(2n, n) / (n+1) = (2n)! / (n!(n+1)!)
```

| 方法 | 时间 | 空间 |
|---|---|---|
| 1. DP | O(n²) | O(n) |
| 2. 卡特兰数公式 | O(n) | O(1) |

### 方法 1: DP

```python
def numTrees(n):
    G = [0] * (n + 1)
    G[0] = G[1] = 1
    for i in range(2, n + 1):
        for j in range(1, i + 1):
            G[i] += G[j - 1] * G[i - j]
    return G[n]
```

**手算示例** (n=3):
```text
G[0] = 1  (空树)
G[1] = 1  (1 个节点)
G[2] = G[0]G[1] + G[1]G[0] = 1 + 1 = 2
G[3] = G[0]G[2] + G[1]G[1] + G[2]G[0] = 2 + 1 + 2 = 5
```

### 方法 2: 卡特兰数公式

```python
def numTrees(n):
    from math import comb
    return comb(2 * n, n) // (n + 1)
```

### 复杂度

- 时间: DP O(n²), 公式 O(n).
- 空间: O(n) 或 O(1).

### 拓展: 卡特兰数应用

| 场景 | 解释 |
|---|---|
| BST 计数 | 本题 |
| 括号匹配 | n 对括号的合法序列数 |
| 路径规划 | 不穿过对角线的路径数 |
| 出栈序列 | 1..n 的合法出栈序列数 |

## A.3 LeetCode 98 - 验证二叉搜索树 (Medium)

### 题目描述

给你一个二叉树的根节点 `root`, 判断其是否是一个有效的二叉搜索树 (BST).

**BST 定义**:
- 左子树所有节点值 **严格小于** 根节点值
- 右子树所有节点值 **严格大于** 根节点值
- 左右子树也必须是 BST

**示例**:
```text
输入: root = [2, 1, 3]
输出: true

输入: root = [5, 1, 4, null, null, 3, 6]
输出: false
解释: 根 5 的左子节点 1 OK, 但右子树根 4 < 5 (违反)
```

### 思路分析

**陷阱**: 不能只比较 `node.val` 与 `node.left.val` / `node.right.val`. 错误示例: 节点 5 的右子树里有 4, 比较时只看父子, 漏掉.

**正确思路**: 中序遍历 BST 应得到严格升序序列.

| 方法 | 时间 | 空间 |
|---|---|---|
| 1. 中序遍历 | O(n) | O(h) |
| 2. 递归 + 边界 | O(n) | O(h) |

### 方法 1: 中序遍历 (检查升序)

```python
def isValidBST(root):
    stack, cur, prev = [], root, float('-inf')
    while cur or stack:
        while cur:
            stack.append(cur)
            cur = cur.left
        cur = stack.pop()
        if cur.val <= prev:
            return False
        prev = cur.val
        cur = cur.right
    return True
```

### 方法 2: 递归 + 上下界

```python
def isValidBST(root):
    def dfs(node, lo, hi):
        if not node:
            return True
        if not (lo < node.val < hi):
            return False
        return dfs(node.left, lo, node.val) and dfs(node.right, node.val, hi)
    return dfs(root, float('-inf'), float('inf'))
```

### 复杂度

- 时间: O(n)
- 空间: O(h)

### 失败案例

```python
# 错误: 只比较父子
def wrong(root):
    if not root: return True
    if root.left and root.left.val >= root.val: return False
    if root.right and root.right.val <= root.val: return False
    return wrong(root.left) and wrong(root.right)
# 漏网之鱼: [5, 1, 6, null, null, 4, 7]  → 4 < 5 但 4 是 6 的左子
```

## A.4 LeetCode 101 - 对称二叉树 (Easy)

### 题目描述

给你一个二叉树的根节点 `root`, 检查它是否轴对称.

**示例**:
```text
输入: root = [1, 2, 2, 3, 4, 4, 3]
输出: true

    1
   / \
  2   2
 / \ / \
3  4 4  3
```

### 思路分析

**对称** = 左子树是右子树的镜像. 镜像比较: `(L.left, R.right)` 与 `(L.right, R.left)` 必须同时相等.

### 方法 1: 递归

```python
def isSymmetric(root):
    def mirror(L, R):
        if not L and not R: return True
        if not L or not R: return False
        return L.val == R.val and mirror(L.left, R.right) and mirror(L.right, R.left)
    return mirror(root, root) if root else True
```

### 方法 2: 迭代 (队列)

```python
def isSymmetric(root):
    q = [root, root]
    while q:
        L, R = q.pop(0), q.pop(0)
        if not L and not R: continue
        if not L or not R or L.val != R.val: return False
        q.extend([L.left, R.right, L.right, R.left])
    return True
```

### 复杂度

- 时间: O(n)
- 空间: O(h) 递归 / O(n) 队列

### 易错点

| 场景 | 错误 |
|---|---|
| 双空 | 当成不等 |
| 单空 | 漏掉 |
| 比较方向 | 应为 `L.left vs R.right`, 不是 `L.left vs R.left` |

## A.5 LeetCode 102 - 二叉树的层序遍历 (Medium)

### 题目描述

给你二叉树的根节点 `root`, 返回其节点值的 **层序遍历** (即逐层地, 从左到右访问所有节点).

**示例**:
```text
输入: root = [3, 9, 20, null, null, 15, 7]
输出: [[3], [9, 20], [15, 7]]

    3
   / \
  9   20
     / \
    15   7
```

### 思路分析

经典 BFS, 用队列记录每层节点.

### 方法 1: BFS (推荐)

```python
def levelOrder(root):
    if not root: return []
    res, q = [], [root]
    while q:
        level = []
        for _ in range(len(q)):
            node = q.pop(0)
            level.append(node.val)
            if node.left: q.append(node.left)
            if node.right: q.append(node.right)
        res.append(level)
    return res
```

### 方法 2: DFS (用 depth 参数)

```python
def levelOrder(root):
    res = []
    def dfs(node, depth):
        if not node: return
        if len(res) == depth:
            res.append([])
        res[depth].append(node.val)
        dfs(node.left, depth + 1)
        dfs(node.right, depth + 1)
    dfs(root, 0)
    return res
```

### 复杂度

- 时间: O(n)
- 空间: O(n) (队列最多一层的节点数)

## A.6 LeetCode 104 - 二叉树的最大深度 (Easy)

### 题目描述

给定一个二叉树, 找出其最大深度.

**最大深度**: 从根节点到最远叶子节点的最长路径上的节点数.

**示例**:
```text
输入: root = [3, 9, 20, null, null, 15, 7]
输出: 3
```

### 思路分析

深度 = 1 + max(左深度, 右深度).

### 方法 1: 递归 (DFS)

```python
def maxDepth(root):
    if not root: return 0
    return 1 + max(maxDepth(root.left), maxDepth(root.right))
```

### 方法 2: BFS (层数)

```python
def maxDepth(root):
    if not root: return 0
    depth, q = 0, [root]
    while q:
        depth += 1
        q = [child for node in q for child in (node.left, node.right) if child]
    return depth
```

### 复杂度

- 时间: O(n)
- 空间: O(h) 递归 / O(w) BFS (w = 最大层宽)

## A.7 LeetCode 105 - 从前序与中序构造二叉树 (Medium)

### 题目描述

给定两个整数数组 `preorder` 和 `inorder`, 其中 `preorder` 是二叉树的**先序遍历**, `inorder` 是同一棵树的**中序遍历**, 请构造二叉树并返回其根节点.

**示例**:
```text
preorder = [3, 9, 20, 15, 7]
inorder  = [9, 3, 15, 20, 7]

输出:
    3
   / \
  9   20
     / \
    15   7
```

### 思路分析

**核心**: 前序第一个 = 根. 在中序中找到根, 左边 = 左子树, 右边 = 右子树. 递归.

**关键优化**: 用哈希表存 `inorder 值 → 索引`, O(1) 查找.

### 实现

```python
def buildTree(preorder, inorder):
    idx = {v: i for i, v in enumerate(inorder)}
    pre_idx = 0

    def build(lo, hi):
        nonlocal pre_idx
        if lo > hi: return None
        root_val = preorder[pre_idx]
        pre_idx += 1
        root = TreeNode(root_val)
        mid = idx[root_val]
        root.left = build(lo, mid - 1)
        root.right = build(mid + 1, hi)
        return root

    return build(0, len(inorder) - 1)
```

### 复杂度

- 时间: O(n) (哈希查找)
- 空间: O(n) (哈希表 + 递归栈)

### 失败案例

| 场景 | 错误 | 后果 |
|---|---|---|
| 无哈希 | 每次 `inorder.index()` O(n) | 总 O(n²) |
| 共享 pre_idx | 用全局变量而不 nonlocal | Python 闭包 bug |
| 边界错 | `lo, hi` 用开闭区间不一致 | 无限递归 |

## A.8 LeetCode 114 - 二叉树展开为链表 (Medium)

### 题目描述

给你二叉树的根节点 `root`, 请将它展开为一个单链表:
- 展开后的单链表应该同样使用 `TreeNode`, 其中 `right` 子指针指向链表中下一个节点, 而左子指针始终为 `null`.
- 展开后的单链表应该与二叉树 **先序遍历** 顺序相同.

**示例**:
```text
输入: root = [1, 2, 5, 3, 4, null, 6]
输出: [1, null, 2, null, 3, null, 4, null, 5, null, 6]
```

### 思路分析

3 种主流解法:

| 方法 | 时间 | 空间 | 难度 |
|---|---|---|---|
| 1. 前序遍历存数组, 再连 | O(n) | O(n) | ⭐ |
| 2. 原地 (寻找左子树最右) | O(n) | O(1) | ⭐⭐⭐ |
| 3. 后序遍历 (左右根) | O(n) | O(h) | ⭐⭐⭐ |

### 方法 1: 前序遍历存数组 (简单)

```python
def flatten(root):
    if not root: return
    arr = []
    def dfs(node):
        if not node: return
        arr.append(node)
        dfs(node.left)
        dfs(node.right)
    dfs(root)
    for i in range(1, len(arr)):
        arr[i - 1].left = None
        arr[i - 1].right = arr[i]
```

### 方法 2: 原地变形 ⭐推荐

**核心**: 把左子树插到根和右子树之间.

```python
def flatten(root):
    cur = root
    while cur:
        if cur.left:
            # 找左子树最右节点
            rightmost = cur.left
            while rightmost.right:
                rightmost = rightmost.right
            # 把原右子树接到最右
            rightmost.right = cur.right
            # 左子树升为右子树
            cur.right = cur.left
            cur.left = None
        cur = cur.right
```

**图解**:
```text
原:
    1
   / \
  2   5
 / \   \
3   4   6

步骤 1 (处理 1):
rightmost=4, 4.right = 5 (原右)
1.right = 2, 1.left = None

    1
     \
      2
     / \
    3   4
         \
          5
           \
            6
```

### 方法 3: 后序遍历 (左右根)

```python
def flatten(root):
    def dfs(node):
        if not node: return None
        left_tail = dfs(node.left)
        right_tail = dfs(node.right)
        if left_tail:
            left_tail.right = node.right
            node.right = node.left
            node.left = None
        return right_tail or left_tail or node
    dfs(root)
```

### 复杂度

- 时间: O(n²) 方法 2 (找最右), O(n) 方法 1 和 3
- 空间: O(1) / O(n) / O(h)

## A.9 LeetCode 121 - 买卖股票的最佳时机 (Easy)

### 题目描述

给定一个数组 `prices`, 它的第 `i` 个元素是一支给定股票第 `i` 天的价格.

你只能选择 **某一天** 买入这只股票, 并选择在 **未来的某一个不同的日子** 卖出. 设计一个算法来计算你所能获取的最大利润. 返回你可以从这笔交易中获取的最大利润. 如果不能获取任何利润, 返回 0.

**示例**:
```text
输入: [7, 1, 5, 3, 6, 4]
输出: 5
解释: 第 2 天买 (1), 第 5 天卖 (6), 利润 5
```

### 思路分析

| 方法 | 时间 | 空间 |
|---|---|---|
| 1. 一次遍历 (维护最小) | O(n) | O(1) |
| 2. DP (状态机) | O(n) | O(1) |
| 3. 暴力 | O(n²) | O(1) |

### 方法 1: 一次遍历 ⭐推荐

```python
def maxProfit(prices):
    min_price = float('inf')
    max_profit = 0
    for p in prices:
        min_price = min(min_price, p)
        max_profit = max(max_profit, p - min_price)
    return max_profit
```

**图解**:
```text
prices: [7, 1, 5, 3, 6, 4]
         ↓  ↓  ↓  ↓  ↓  ↓
min:    [7, 1, 1, 1, 1, 1]
profit: [0, 0, 4, 2, 5, 3]
                         ↑
                       最大 5
```

### 方法 2: DP 状态机

```python
def maxProfit(prices):
    hold, cash = -float('inf'), 0  # 持有 / 现金
    for p in prices:
        cash = max(cash, hold + p)  # 卖
        hold = max(hold, -p)       # 买 (只能买一次, 故 -p 而非 cash-p)
    return cash
```

### 复杂度

- 时间: O(n)
- 空间: O(1)

## A.10 LeetCode 124 - 二叉树中的最大路径和 (Hard)

### 题目描述

**路径** 被定义为一条从树中任意节点出发, 沿父节点-子节点连接, 到达任意节点的序列. 该路径 **至少包含一个节点**, 且不一定经过根节点.

**路径和** 是路径中各节点值的总和.

给你一个二叉树的根节点 `root`, 返回其 **最大路径和**.

**示例**:
```text
输入: root = [1, 2, 3]
输出: 6
路径: 2 → 1 → 3

输入: root = [-10, 9, 20, null, null, 15, 7]
输出: 42
路径: 15 → 20 → 7
```

### 思路分析

**关键**: 对每个节点, 最大路径 = 左贡献 + 节点值 + 右贡献. 但向上返回时只能选一边 (因为不能分叉).

```python
def maxPathSum(root):
    self.max_sum = float('-inf')

    def max_gain(node):
        if not node: return 0
        left = max(0, max_gain(node.left))    # 负贡献不要
        right = max(0, max_gain(node.right))
        # 当前节点为根的路径和
        self.max_sum = max(self.max_sum, node.val + left + right)
        # 返回单边最大 (给父节点用)
        return node.val + max(left, right)

    max_gain(root)
    return self.max_sum
```

**图解**:
```text
       -10
       / \
      9   20
         /  \
        15    7

递归:
- 9: 返回 9, max=9
- 15: 返回 15, max=15
- 7: 返回 7, max=15+20+7=42
- 20: left=15, right=7, val=20 → 路径 42; 返回 20+15=35
- -10: left=9, right=35 → 路径 9-10-35=34; 返回 -10+35=25
max = 42
```

### 复杂度

- 时间: O(n) — 每个节点访问 1 次
- 空间: O(h) — 递归栈

### 失败案例

| 场景 | 错误 |
|---|---|
| 不取 `max(0, ...)` | 负数节点会让 `max_gain` 返回负, 错 |
| 向上返回 `node.val + left + right` | 父节点用不了分叉 |

## E.1 LeetCode 75 高频追问

### Q1: 三向切分中, 为什么交换 0 后 curr++, 交换 2 后 curr 不动?

**答**:
- 交换 0 时, 被换到 `curr` 位置的是 1 (因为 `[0, p0)` 都是 0, 所以 `nums[p0]` 要么是 0 (不可能, 因为已确认), 要么是 1 (来自 `[p0, curr)`). 所以 curr++ 安全.
- 交换 2 时, 被换到 `curr` 位置的是未处理的 `[curr+1, p2]` 之一, 可能是 0/1/2, 必须再看.

### Q2: 如果颜色是 k 种 (不只 3 种), 怎么办?

**答**: 计数排序最直接. 如果要求原地, 用**基数排序**或**双轴快排**.

### Q3: 如何用三向切分实现快速排序?

```python
def quicksort_3way(arr, lo, hi):
    if lo >= hi: return
    lt, gt = lo, hi
    i = lo
    pivot = arr[lo]
    while i <= gt:
        if arr[i] < pivot:
            arr[lt], arr[i] = arr[i], arr[lt]
            lt += 1; i += 1
        elif arr[i] > pivot:
            arr[gt], arr[i] = arr[i], arr[gt]
            gt -= 1
        else:
            i += 1
    quicksort_3way(arr, lo, lt - 1)
    quicksort_3way(arr, gt + 1, hi)
```

**优势**: 当有大量重复元素时, 性能远优于普通快排.

## E.3 LeetCode 78 高频追问

### Q1: 如果 nums 有重复, 怎么去重?

**答**: 排序 + 跳过相同元素.

```python
def subsetsWithDup(nums):
    nums.sort()
    res = []
    def backtrack(start, path):
        res.append(path[:])
        for i in range(start, len(nums)):
            if i > start and nums[i] == nums[i-1]:
                continue  # 跳过
            path.append(nums[i])
            backtrack(i + 1, path)
            path.pop()
    backtrack(0, [])
    return res
```

### Q2: 子集和回溯的复杂度怎么算?

**答**: 共有 2^n 个子集, 每个子集拷贝平均 O(n). 所以 O(n·2^n). 空间是递归栈 O(n) + 结果 O(n·2^n).

### Q3: 能不能用 DP 思路?

**答**: 迭代法本质就是 DP. `dp[i] = 前 i 个的所有子集`. 每加一个元素, 复制所有旧子集并加入新元素.

### 错题 1: 三向切分 curr 移动错误

```python

        p0 += 1
```

```python

def wrong(root):
    if not root: return True
    if root.left and root.left.val >= root.val: return False
    if root.right and root.right.val <= root.val: return False
    return wrong(root.left) and wrong(root.right)
```

### 错题 3: 子集回溯没 append path[:]

```python

            path.pop()
```

```python
def sliding_window(s):
    need, window = {}, {}
    l = 0
    for r in range(len(s)):
        # 1. 扩大窗口
        c = s[r]
        window[c] = window.get(c, 0) + 1
        # 2. 收缩窗口 (满足条件时)
```

```python
from collections import deque
def bfs(start):
    q = deque([start])
    visited = {start}
    while q:
        node = q.popleft()
        for neighbor in node.neighbors:
            if neighbor not in visited:
                visited.add(neighbor)
                q.append(neighbor)
```

```python
def binary_search(arr, target):

    while l <= r:
        mid = (l + r) // 2
        if arr[mid] == target: return mid
        if arr[mid] < target: l = mid + 1
        else: r = mid - 1
    return -1
```

## 附录 J: 性能优化 Tips

## J.1 Python 优化

### 1. 用 list comprehension 替代循环

```python
# 慢
res = []
for x in arr:
    if x > 0:
        res.append(x * 2)

# 快
res = [x * 2 for x in arr if x > 0]
```

### 2. 局部变量快于全局

```python
# 慢
def f():
    for x in range(1000):
        g(x)

# 快
def f():
    local_g = g
    for x in range(1000):
        local_g(x)
```

### 3. 用 `deque` 替代 `list.pop(0)`

```python
# 慢: O(n)
q = [1, 2, 3]
x = q.pop(0)

# 快: O(1)
from collections import deque
q = deque([1, 2, 3])
x = q.popleft()
```

### 4. 用生成器省内存

```python
# 内存 O(n)
def gen():
    return [x for x in range(10**7)]

# 内存 O(1)
def gen():
    return (x for x in range(10**7))
```

## J.2 算法级优化

### 1. 减枝

回溯题里, 如果当前路径已不可能产生解, 提前返回.

```python
def backtrack(剩余, path):
    if 剩余 < 0: return  # 减枝
    if 剩余 == 0: res.append(path); return
    for choice in choices:
        path.append(choice)
        backtrack(剩余 - choice, path)
        path.pop()
```

### 2. 记忆化

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def dfs(n):
    if n <= 1: return n
    return dfs(n-1) + dfs(n-2)
```

### 3. 双指针代替哈希

```python
# 慢: O(n) 空间
seen = set()
for x in arr:
    if x in seen: return True
    seen.add(x)

# 快: O(1) 空间 (前提有序)
l, r = 0, n-1
while l < r:
    s = arr[l] + arr[r]
    if s == target: return True
    if s < target: l += 1
    else: r -= 1
```

## N.1 字节跳动

> **题**: 给定一个数组, 把所有奇数移到偶数前面, 保持相对顺序.

**思路**: 双指针不稳定 → 用额外空间.

```python
def re_order(arr):
```

> **追问**: 不保持顺序呢?

```python
def re_order(arr):
    l, r = 0, len(arr) - 1
    while l < r:
        while l < r and arr[l] % 2: l += 1
        while l < r and not arr[r] % 2: r -= 1
        arr[l], arr[r] = arr[r], arr[l]
    return arr
```

## N.2 阿里巴巴

> **题**: 二叉树的最近公共祖先 (LCA).

```python
def lowestCommonAncestor(root, p, q):
    if not root or root == p or root == q:
        return root
    left = lowestCommonAncestor(root.left, p, q)
    right = lowestCommonAncestor(root.right, p, q)
    if left and right: return root
    return left or right
```

> **追问**: 如果是 BST 呢?

```python
def lowestCommonAncestor_BST(root, p, q):
    while root:
        if p.val < root.val and q.val < root.val:
            root = root.left
        elif p.val > root.val and q.val > root.val:
            root = root.right
        else:
            return root
```

## N.3 腾讯

> **题**: 最长回文子串 (LeetCode 5).

```python
def longestPalindrome(s):
    def expand(l, r):
        while l >= 0 and r < len(s) and s[l] == s[r]:
            l -= 1; r += 1
        return s[l+1:r]
    res = ""
    for i in range(len(s)):
        odd = expand(i, i)
        even = expand(i, i+1)
        res = max(res, odd, even, key=len)
    return res
```

> **追问**: Manacher 算法知道吗?

```python
def manacher(s):
    t = "#" + "#".join(s) + "#"
    n = len(t)
    p = [0] * n
    c = r = 0
    for i in range(n):
        mirror = 2 * c - i
        if i < r: p[i] = min(r - i, p[mirror])
        while (i + p[i] + 1 < n and i - p[i] - 1 >= 0
               and t[i + p[i] + 1] == t[i - p[i] - 1]):
            p[i] += 1
        if i + p[i] > r:
            c, r = i, i + p[i]
    return max(p)
```

## N.4 美团

> **题**: 二分查找的各种变体.

```python
# 1. 找第一个 >= target
def lower_bound(arr, target):
    l, r = 0, len(arr)
    while l < r:
        mid = (l + r) // 2
        if arr[mid] < target: l = mid + 1
        else: r = mid
    return l

# 2. 找最后一个 <= target
def upper_bound(arr, target):
    l, r = 0, len(arr)
    while l < r:
        mid = (l + r) // 2
        if arr[mid] <= target: l = mid + 1
        else: r = mid
    return l - 1
```

## N.5 拼多多

> **题**: 字符串的所有排列.

```python
def permutation(s):
    if not s: return [""]
    if len(s) == 1: return [s]
    res = set()
    for i, c in enumerate(s):
        rest = s[:i] + s[i+1:]
        for p in permutation(rest):
            res.add(c + p)
    return list(res)
```

## 附录 P: 常见误解澄清

## P.1 "BST 一定是平衡的"

**错**. BST 只保证中序升序, 不保证平衡. AVL / 红黑树才是平衡 BST.

## P.2 "哈希查找是 O(1)"

**部分对**. **平均** O(1), **最坏** O(n) (所有键哈希到同一桶). 用好的哈希函数 + 扩容可缓解.

## P.3 "二分查找一定要有序"

**错**. **针对有序数组**的二分要求有序. 但有"局部有序"的变形 (如旋转数组).

## P.4 "递归一定比迭代慢"

**错**. 现代编译器会做尾调用优化. Python 默认不优化, 但可以用 `sys.setrecursionlimit` 调高栈深度.

## P.5 "动态规划 = 记忆化搜索"

**部分对**. 记忆化搜索是 DP 的一种实现方式 (top-down). DP 也可 bottom-up (递推).

## P.6 "回溯 = 暴力"

**错**. 回溯通过剪枝大幅减少搜索. 例如 N 皇后问题, 暴力 N! 但回溯能剪到接近 N².

## P.7 "O(n log n) 一定比 O(n²) 快"

**部分对**. 对大 n 是. 但常数因子重要. 小 n 时 O(n²) 可能更快.

## P.8 "面试题都是 LeetCode 原题"

**部分对**. 大厂面试 60-70% 是原题或变种, 30-40% 是开放设计题.
