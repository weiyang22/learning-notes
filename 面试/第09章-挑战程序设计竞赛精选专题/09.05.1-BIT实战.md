## 1. LeetCode 327 - 区间和的个数 (Hard)

### 题目

给整数数组 nums 和 lower/upper, 求有多少个子数组和 ∈ [lower, upper].

### 思路

**前缀和 + 离散化 + BIT**:
- 区间和 [i, j] = prefix[j+1] - prefix[i]
- 条件: lower ≤ prefix[j+1] - prefix[i] ≤ upper
- 即: prefix[i] ∈ [prefix[j+1] - upper, prefix[j+1] - lower]

用 BIT 统计已遍历的前缀和中, 落在 [L, R] 范围的有多少.

```python
class BIT:
    def __init__(self, n):
        self.tree = [0] * (n + 2)

    def update(self, i, delta):
        while i < len(self.tree):
            self.tree[i] += delta
            i += i & -i

    def query(self, i):
        s = 0
        while i > 0:
            s += self.tree[i]
            i -= i & -i
        return s

    def range_query(self, l, r):
        return self.query(r) - self.query(l - 1)

def countRangeSum(nums, lower, upper):
    # 1. 算所有前缀和 + 边界
    n = len(nums)
    prefix = [0] * (n + 1)
    for i in range(n): prefix[i+1] = prefix[i] + nums[i]

    # 2. 离散化所有可能用到的值
    vals = set()
    for p in prefix:
        vals.add(p)
        vals.add(p - lower)
        vals.add(p - upper)
    sorted_vals = sorted(vals)
    rank = {v: i + 1 for i, v in enumerate(sorted_vals)}

    # 3. 遍历前缀和, 用 BIT 计数
    bit = BIT(len(sorted_vals))
    bit.update(rank[0], 1)  # prefix[0] = 0
    res = 0
    for p in prefix[1:]:
        # 找满足条件的 prefix[i]: rank[p - upper] ≤ rank[prefix[i]] ≤ rank[p - lower]
        lo = rank[p - upper]
        hi = rank[p - lower]
        res += bit.range_query(lo, hi)
        bit.update(rank[p], 1)
    return res
```

**复杂度**: $O(n \log n)$.

### 关键

- 离散化 3 种值: prefix[i] / prefix[i] - lower / prefix[i] - upper
- 顺序遍历 prefix, 累加贡献

## 2. LeetCode 683 - K 个空花盆 (Hard)

### 题目

花盆数组 flowers, 第 i 天种 flowers[i] 朵, 已种位置不能再种. 求至少需要几天能连续种 k 朵.

### 思路

**二分答案 + 滑动窗口**:
- 二分天数, 判断前 mid 天内是否有连续 k 个空位
- 滑动窗口 + 集合存已种位置

```python
def kEmptySlots(bulbs, k):
    n = len(bulbs)
    # day[i] = 第 i 个位置被点燃的日期
    day = [0] * n
    for i, b in enumerate(bulbs): day[b - 1] = i + 1

    res = float('inf')
    # 滑动窗口: 找 window [left, right=k+1+left, right+1, ...]
    left, right = 0, k + 1
    while right < n:
        # 检查 (left, right) 区间内没有种花
        valid = True
        for i in range(left + 1, right):
            if day[i] < max(day[left], day[right]):
                valid = False
                break
        if valid:
            res = min(res, max(day[left], day[right]))
        # 移动 left
        left += 1
        right += 1
    return res if res != float('inf') else -1
```

## 3. LeetCode 493 - 翻转对 (Hard)

### 题目

如果 nums[i] > 2 * nums[j] 且 i < j, 就是翻转对. 求翻转对数.

### 思路

**离散化 + BIT**:
- 离散化 nums (含 nums 和 nums*2+1 用于排除边界)
- 从右向左遍历, 统计比 nums[i]/2 小的数

```python
def reversePairs(nums):
    if not nums: return 0
    # 离散化
    sorted_vals = sorted(set(nums + [x * 2 + 1 for x in nums]))
    rank = {v: i + 1 for i, v in enumerate(sorted_vals)}

    n = len(sorted_vals)
    tree = [0] * (n + 2)

    def update(i):
        while i <= n:
            tree[i] += 1
            i += i & -i

    def query(i):
        s = 0
        while i > 0:
            s += tree[i]
            i -= i & -i
        return s

    res = 0
    for x in reversed(nums):
        # 找满足 nums[j] * 2 < nums[i] 的 j
        # 即 nums[j] <= (x - 1) // 2 (向下取整的一半)
        half = (x - 1) // 2 if x > 0 else x // 2
        # 但要严格 nums[j] < x/2, 用 floor((x-1)/2)
        threshold = (x - 1) // 2
        res += query(rank[threshold]) if threshold in rank else 0
        update(rank[x])
    return res
```

**更简单的归并排序版本**:

```python
def reversePairs(nums):
    """归并排序时统计"""
    def merge_sort(lo, hi):
        if lo >= hi: return 0
        mid = (lo + hi) // 2
        count = merge_sort(lo, mid) + merge_sort(mid + 1, hi)
        # 统计翻转对 (左半 nums[i] > 2 * 右半 nums[j])
        j = mid + 1
        for i in range(lo, mid + 1):
            while j <= hi and nums[i] > 2 * nums[j]: j += 1
            count += j - (mid + 1)
        # 合并
        nums[lo:hi+1] = sorted(nums[lo:hi+1])
        return count

    return merge_sort(0, len(nums) - 1)
```

**复杂度**: $O(n \log n)$.

## 4. BIT 理论基础深入

### 4.1 lowbit 函数详解

**lowbit(x) = x & -x**, 即二进制最低位的 1 对应的值.

```python
def lowbit(x):
    return x & -x

# 等价于: x & (~x + 1)
# 例:
# lowbit(12) = 12 & -12 = 1100 & 0100 = 0100 = 4
# lowbit(10) = 10 & -10 = 1010 & 0110 = 0010 = 2
# lowbit(7)  = 7  & -7  = 0111 & 1001 = 0001 = 1
```

**为什么 -x = ~x + 1 (二进制补码)**:

例如 $x = 12 = 1100_2$:
- ~x = 0011 (按位取反)
- ~x + 1 = 0100 = 4
- x & (~x + 1) = 1100 & 0100 = 0100 = 4

**数学意义**: $x = 2^k \cdot m$ (m 是奇数), lowbit(x) = $2^k$.

### 4.2 BIT 的树形结构

虽然 BIT 叫"树状数组", 但本质是**隐式树**:

```text
位置: 1   2   3   4   5   6   7   8
tree: [_] [a+b] [_] [a+b+c+d] [_] [_] [_] [a+b+c+d+e+f+g+h]

tree[i] 覆盖范围: [i - lowbit(i) + 1, i]
```

例如:
- `tree[1]` 覆盖 `[1, 1]` (1 个元素)
- `tree[2]` 覆盖 `[1, 2]` (2 个元素)
- `tree[4]` 覆盖 `[1, 4]` (4 个元素)
- `tree[8]` 覆盖 `[1, 8]` (8 个元素)
- `tree[6]` 覆盖 `[5, 6]` (2 个元素)

### 4.3 BIT vs 线段树对比

| 维度 | BIT (树状数组) | 线段树 |
| :--- | :--- | :--- |
| 代码量 | 极短 (~10 行) | 长 (~50 行) |
| 常数 | 小 | 大 2-5 倍 |
| 单点更新 + 区间查询 | $O(\log n)$ ✓ | $O(\log n)$ |
| 区间更新 + 单点查询 | $O(\log n)$ (差分) | $O(\log n)$ |
| 区间更新 + 区间查询 | $O(\log n)$ (差分技巧) | $O(\log n)$ |
| 区间最值 | ✗ (需特殊处理) | ✓ |
| 区间第 k 小 | ✗ | ✓ |
| 持久化 | 难 | 易 |
| 适用 | 90% 区间和场景 | 复杂区间操作 |

### 4.4 BIT 适用与不适用

**适用**:
- 单点更新 + 区间求和
- 区间更新 + 单点查询 (用差分)
- 求逆序对 (离散化 + BIT)
- 计数问题 (排名、频次)
- 前缀相关的问题

**不适用**:
- 区间最值 (需额外维护)
- 复杂区间操作 (如区间开方、区间取模)
- 区间第 k 小 (需权值线段树或主席树)
- 二维以上 (用 KD-Tree 或 BIT 套 BIT)

### 4.5 BIT 的边界处理

```python
class BIT:
    def __init__(self, n):
        # n + 2 防止 update 越界
        self.tree = [0] * (n + 2)
        self.n = n + 1

    def update(self, i, delta):
        # i 从 1 开始, 0 是无效索引
        while i <= self.n:
            self.tree[i] += delta
            i += i & -i

    def query(self, i):
        # query(0) = 0
        s = 0
        while i > 0:
            s += self.tree[i]
            i -= i & -i
        return s

    def range_query(self, l, r):
        # query(r) - query(l-1)
        return self.query(r) - self.query(l - 1)
```

**关键约定**:
- 索引从 **1** 开始 (与 lowbit 配合)
- query(0) = 0 (空区间和)
- update(0) = 无操作

## 5. BIT 变种详解

### 5.1 区间更新 + 单点查询

**技巧**: 用差分. 维护差分数组 $d$, 原数组 $a[i] = \sum_{j=1}^{i} d[j]$.

**区间 [l, r] 加 x**:
- $d[l] += x$
- $d[r+1] -= x$

**查询 a[i]**:
- $a[i] = \text{prefix\_sum}(d, i) = \text{BIT.query}(i)$

```python
class BITRange:
    """区间更新 + 单点查询"""
    def __init__(self, n):
        self.bit = BIT(n + 2)

    def range_update(self, l, r, val):
        """区间 [l, r] 加 val"""
        self.bit.update(l, val)
        self.bit.update(r + 1, -val)

    def point_query(self, i):
        """查询 a[i]"""
        return self.bit.query(i)
```

### 5.2 区间更新 + 区间查询

**技巧**: 用两个 BIT, 维护 $(i-1) \cdot d[i]$.

设差分数组 $d$, 区间和:

$$
\sum_{i=l}^{r} a_i = \sum_{i=l}^{r} \sum_{j=1}^{i} d_j = \sum_{j=1}^{r} d_j \cdot (r - j + 1) - \sum_{j=1}^{l-1} d_j \cdot (l - 1 - j + 1)
$$

化简得:
$$
= (r+1) \sum_{j=1}^{r} d_j - \sum_{j=1}^{r} j \cdot d_j - l \sum_{j=1}^{l-1} d_j + \sum_{j=1}^{l-1} j \cdot d_j
$$

**实现**:

```python
class BITRangeFull:
    """区间更新 + 区间查询 (支持任意区间加减 + 区间和查询)"""
    def __init__(self, n):
        self.n = n
        self.bit1 = BIT(n + 2)  # 维护 d[i]
        self.bit2 = BIT(n + 2)  # 维护 i * d[i]

    def range_update(self, l, r, val):
        """区间 [l, r] 加 val"""
        self._add(self.bit1, l, val)
        self._add(self.bit1, r + 1, -val)
        self._add(self.bit2, l, val * (l - 1))
        self._add(self.bit2, r + 1, -val * r)

    def prefix_sum(self, i):
        """求 a[1] + ... + a[i]"""
        return self._sum(self.bit1, i) * i - self._sum(self.bit2, i)

    def range_sum(self, l, r):
        """求 a[l] + ... + a[r]"""
        return self.prefix_sum(r) - self.prefix_sum(l - 1)

    def _add(self, bit, i, val):
        while i <= self.n:
            bit[i] += val
            i += i & -i

    def _sum(self, bit, i):
        s = 0
        while i > 0:
            s += bit[i]
            i -= i & -i
        return s
```

### 5.3 2D BIT (二维树状数组)

**场景**: 二维数组上的前缀和查询 + 单点更新.

```python
class BIT2D:
    """2D 树状数组: 单点更新 + 二维前缀和"""
    def __init__(self, m, n):
        self.m = m
        self.n = n
        self.tree = [[0] * (n + 2) for _ in range(m + 2)]

    def update(self, i, j, delta):
        """更新 (i, j) += delta"""
        x = i
        while x <= self.m:
            y = j
            while y <= self.n:
                self.tree[x][y] += delta
                y += y & -y
            x += x & -x

    def query(self, i, j):
        """求 (1,1) 到 (i,j) 的和"""
        res = 0
        x = i
        while x > 0:
            y = j
            while y > 0:
                res += self.tree[x][y]
                y -= y & -y
            x -= x & -x
        return res

    def rect_sum(self, r1, c1, r2, c2):
        """求 (r1,c1) 到 (r2,c2) 的矩形和"""
        return (self.query(r2, c2)
                - self.query(r1 - 1, c2)
                - self.query(r2, c1 - 1)
                + self.query(r1 - 1, c1 - 1))
```

**时间复杂度**: 单操作 $O(\log m \cdot \log n)$.

### 5.5 排序 BIT (Order Statistic Tree)

**场景**: 求第 k 小的数, 或排名.

```python
class BITOrderStat:
    """排序 BIT: 支持查询排名和第 k 小"""
    def __init__(self, n):
        self.n = n
        self.tree = [0] * (n + 2)

    def update(self, i, delta=1):
        while i <= self.n:
            self.tree[i] += delta
            i += i & -i

    def query(self, i):
        """前 i 个位置的累计计数"""
        s = 0
        while i > 0:
            s += self.tree[i]
            i -= i & -i
        return s

    def kth(self, k):
        """求第 k 小的数 (1-indexed)"""
        if k < 1 or k > self.query(self.n):
            return -1

        idx = 0
        bit_mask = 1 << (self.n.bit_length())
        while bit_mask:
            t_idx = idx + bit_mask
            if t_idx <= self.n and self.tree[t_idx] < k:
                idx = t_idx
                k -= self.tree[t_idx]
            bit_mask >>= 1
        return idx + 1
```

**时间复杂度**: 所有操作 $O(\log n)$.

### 5.6 BIT 的乘法版本 (求乘积)

```python
class BITMultiply:
    """单点更新 (乘) + 区间乘积"""
    def __init__(self, n):
        self.tree = [1] * (n + 2)
        self.n = n

    def update(self, i, val):
        while i <= self.n:
            self.tree[i] *= val
            i += i & -i

    def query(self, i):
        res = 1
        while i > 0:
            res *= self.tree[i]
            i -= i & -i
        return res
```

> 注意: 乘法可能溢出, 实际应用需取模.

### 5.7 取模 BIT

```python
class BITMod:
    """单点更新 + 区间求和 (取模)"""
    MOD = 10**9 + 7

    def __init__(self, n):
        self.tree = [0] * (n + 2)
        self.n = n

    def update(self, i, delta):
        while i <= self.n:
            self.tree[i] = (self.tree[i] + delta) % self.MOD
            i += i & -i

    def query(self, i):
        s = 0
        while i > 0:
            s = (s + self.tree[i]) % self.MOD
            i -= i & -i
        return s
```

## 6. LeetCode 315 - 计算右侧小于当前元素的个数 (Hard)

### 6.1 题目

给定整数数组 nums, 返回新数组 counts, 其中 counts[i] 是 nums[i] 右侧小于 nums[i] 的元素数量.

### 6.2 思路

**从右向左遍历 + BIT**:
- 从右向左, 把每个 nums[i] 插入 BIT
- counts[i] = query(nums[i] - 1) 即比 nums[i] 小的数有几个

**离散化**: nums 范围大, 离散化.

### 6.3 实现

```python
def countSmaller(nums):
    """BIT 解法"""
    if not nums:
        return []

    # 离散化
    sorted_vals = sorted(set(nums))
    rank = {v: i + 1 for i, v in enumerate(sorted_vals)}
    n = len(sorted_vals)

    # BIT
    tree = [0] * (n + 2)

    def update(i):
        while i <= n:
            tree[i] += 1
            i += i & -i

    def query(i):
        s = 0
        while i > 0:
            s += tree[i]
            i -= i & -i
        return s

    # 从右向左
    res = []
    for x in reversed(nums):
        # 找 nums[i] 右侧比 nums[i] 小的数
        idx = rank[x] - 1  # rank[x] - 1 = 比 x 小的最大 rank
        res.append(query(idx))
        update(rank[x])

    return res[::-1]
```

### 6.4 多解法对比

| 解法 | 时间 | 空间 | 优缺点 |
| :--- | :--- | :--- | :--- |
| BIT + 离散化 | $O(n \log n)$ | $O(n)$ | 代码短, 通用 |
| 归并排序 | $O(n \log n)$ | $O(n)$ | 不需离散化, 但要写归并 |
| 暴力 (TLE) | $O(n^2)$ | $O(1)$ | 超时 |
| 树状数组 (BIT) | $O(n \log n)$ | $O(n)$ | 等价上面 |
| 主席树 (Persistent BIT) | $O(n \log n)$ | $O(n \log n)$ | 可查任意前缀历史状态 |

### 6.5 归并排序版本

```python
def countSmaller_merge(nums):
    """归并排序时统计"""
    n = len(nums)
    if n == 0: return []

    # 存 (值, 原索引)
    pairs = [(nums[i], i) for i in range(n)]
    res = [0] * n

    def merge_sort(arr):
        if len(arr) <= 1:
            return arr
        mid = len(arr) // 2
        left = merge_sort(arr[:mid])
        right = merge_sort(arr[mid:])

        # 统计: 左侧中 > 右侧中 (反转对)
        j = 0
        for i in range(len(left)):
            while j < len(right) and left[i][0] > right[j][0]:
                j += 1
            res[left[i][1]] += j

        # 合并
        merged = []
        i = j = 0
        while i < len(left) and j < len(right):
            if left[i][0] <= right[j][0]:
                merged.append(left[i])
                i += 1
            else:
                merged.append(right[j])
                j += 1
        merged.extend(left[i:])
        merged.extend(right[j:])
        return merged

    merge_sort(pairs)
    return res
```

## 7. LeetCode 363 - 矩形区域不超过 K 的最大数值和 (Hard)

### 7.1 题目

给定二维矩阵 matrix 和整数 k, 求矩阵内不超过 k 的最大矩形和.

### 7.2 思路

**枚举上下边界 + 1D 前缀和 + 排序 BIT (或二分)**:

固定上下边界 $r_1, r_2$, 把每列的和压缩成 1D 数组 $col[i]$. 问题化为: 找 $col$ 中最大子数组和, 要求 ≤ k.

子数组和 = prefix[j] - prefix[i], 条件 prefix[j] - prefix[i] ≤ k 即 prefix[i] ≥ prefix[j] - k.

**对每个 prefix[j], 找之前的 prefix[i] 满足 prefix[i] ≥ prefix[j] - k**. 用有序集合 (TreeSet) 或 BIT + 二分.

### 7.3 实现

```python
def maxSumSubmatrix(matrix, k):
    """枚举上下边界 + 1D 子数组和 (TreeSet)"""
    import bisect

    m, n = len(matrix), len(matrix[0])
    res = float('-inf')

    # 枚举上边界
    for top in range(m):
        # col_sums[i] = 第 i 列从 top 到 bottom 的和
        col_sums = [0] * n
        for bottom in range(top, m):
            for i in range(n):
                col_sums[i] += matrix[bottom][i]

            # 1D 问题: 找不超过 k 的最大子数组和
            prefix = [0]
            s = 0
            for x in col_sums:
                s += x
                prefix.append(s)

            # 对每个 prefix[j], 找 prefix[i] >= prefix[j] - k
            # 即 prefix[j] - k <= prefix[i], 找最小满足的 prefix[i]
            sorted_prefix = []
            for pj in prefix:
                # 找 sorted_prefix 中 >= pj - k 的最小元素
                target = pj - k
                idx = bisect.bisect_left(sorted_prefix, target)
                if idx < len(sorted_prefix):
                    res = max(res, pj - sorted_prefix[idx])
                bisect.insort(sorted_prefix, pj)

    return res
```

### 7.4 BIT 版本 (用 kth)

```python
class BITOrder:
    """支持前缀和 + 二分查找"""
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (size + 2)

    def update(self, i, delta):
        while i <= self.n:
            self.tree[i] += delta
            i += i & -i

    def query(self, i):
        s = 0
        while i > 0:
            s += self.tree[i]
            i -= i & -i
        return s

    def lower_bound(self, target):
        """找最小 i 使 query(i) >= target"""
        idx = 0
        bit_mask = 1 << (self.n.bit_length())
        s = 0
        while bit_mask:
            t_idx = idx + bit_mask
            if t_idx <= self.n and s + self.tree[t_idx] < target:
                idx = t_idx
                s += self.tree[t_idx]
            bit_mask >>= 1
        return idx + 1
```

### 7.5 复杂度

- 枚举上下边界: $O(m^2)$
- 1D 子数组: $O(n \log n)$
- 总体: $O(m^2 n \log n)$

当 $m < n$ 时, 枚举上下边界用 $m$; 否则用 $n$ (transpose matrix).

```python
def maxSumSubmatrix_optimized(matrix, k):
    """若 m > n, 转置矩阵"""
    if len(matrix) > len(matrix[0]):
        matrix = list(zip(*matrix))
    return maxSumSubmatrix(matrix, k)
```

## 8. LeetCode 1649 - 通过指令创建有序数组 (Hard)

### 8.1 题目

给定整数数组 instructions, 从空数组开始, 按指令依次插入. 每次插入时, 计算"成本" = 已插入元素中严格小于该元素的数量. 求总成本 (取模).

### 8.2 思路

**BIT 维护已插入元素的频次**:
- 每次插入 x, 成本 = query(x - 1) (已插入中 < x 的数量)
- 然后 update(x, 1)

### 8.3 实现

```python
def createSortedArray(instructions):
    MOD = 10**9 + 7
    sorted_vals = sorted(set(instructions))
    rank = {v: i + 1 for i, v in enumerate(sorted_vals)}
    n = len(sorted_vals)

    tree = [0] * (n + 2)

    def update(i):
        while i <= n:
            tree[i] += 1
            i += i & -i

    def query(i):
        s = 0
        while i > 0:
            s += tree[i]
            i -= i & -i
        return s

    cost = 0
    for x in instructions:
        r = rank[x]
        smaller = query(r - 1)  # 已插入中 < x 的
        larger = query(n) - query(r)  # 已插入中 > x 的
        cost = (cost + min(smaller, larger)) % MOD
        update(r)

    return cost
```

**关键**: 成本取 min(严格小于, 严格大于), 因为实际插入位置取中位.

## 9. LeetCode 2179 - 数组中三元组计数 (Hard)

### 9.1 题目

给定数组 nums, 找 (i, j, k) 满足 i < j < k 且 nums[i] < nums[j] < nums[k].

### 9.2 思路

**固定 j, 找 i 和 k**:
- i < j 且 nums[i] < nums[j] 的数量 = left[j]
- k > j 且 nums[k] > nums[j] 的数量 = right[j]
- 答案 = sum(left[j] * right[j])

**用 BIT 计算 left 和 right**:
- 从左向右遍历, left[j] = BIT.query(nums[j] - 1) (当前 BIT 中 < nums[j] 的元素数)
- 从右向左遍历, right[j] = BIT.query(N) - BIT.query(nums[j]) (BIT 中 > nums[j] 的元素数)

### 9.3 实现

```python
def goodTriplets(nums):
    """数组中三元组计数"""
    n = len(nums)
    # 离散化
    sorted_vals = sorted(set(nums))
    rank = {v: i + 1 for i, v in enumerate(sorted_vals)}
    M = len(sorted_vals)

    left = [0] * n
    right = [0] * n

    # 计算 left: 从左向右
    tree = [0] * (M + 2)

    def update(i):
        while i <= M:
            tree[i] += 1
            i += i & -i

    def query(i):
        s = 0
        while i > 0:
            s += tree[i]
            i -= i & -i
        return s

    for i in range(n):
        r = rank[nums[i]]
        left[i] = query(r - 1)
        update(r)

    # 计算 right: 从右向左
    tree = [0] * (M + 2)
    for i in range(n - 1, -1, -1):
        r = rank[nums[i]]
        right[i] = query(M) - query(r)
        update(r)

    # 求和
    res = 0
    for i in range(n):
        res += left[i] * right[i]
    return res
```

**时间复杂度**: $O(n \log n)$.

### 9.4 多解法对比

| 解法 | 时间 | 空间 |
| :--- | :--- | :--- |
| BIT | $O(n \log n)$ | $O(n)$ |
| 归并排序 | $O(n \log n)$ | $O(n)$ |
| CDQ 分治 | $O(n \log^2 n)$ | $O(n)$ |
| 暴力 | $O(n^3)$ | $O(1)$ |

## 10. LeetCode 1395 - 统计作战单位数 (Medium)

### 10.1 题目

给定 rating 数组, 选 3 个下标 (i < j < k), 满足 rating[i] < rating[j] < rating[k] 或 rating[i] > rating[j] > rating[k]. 计数.

### 10.2 思路

类似 2179, 但需统计两种方向. 用两次 BIT.

### 10.3 实现

```python
def numTeams(rating):
    """统计作战单位数 (上升 + 下降)"""
    n = len(rating)
    sorted_vals = sorted(set(rating))
    rank = {v: i + 1 for i, v in enumerate(sorted_vals)}
    M = len(sorted_vals)

    def make_bit():
        return [0] * (M + 2)

    def update(tree, i):
        while i <= M:
            tree[i] += 1
            i += i & -i

    def query(tree, i):
        s = 0
        while i > 0:
            s += tree[i]
            i -= i & -i
        return s

    # 上升: left[j] = < rating[j] 且 i<j 的数
    # 下降: left[j] = > rating[j] 且 i<j 的数
    left_smaller = [0] * n
    left_larger = [0] * n

    tree = make_bit()
    for i in range(n):
        r = rank[rating[i]]
        left_smaller[i] = query(tree, r - 1)
        left_larger[i] = query(tree, M) - query(tree, r)
        update(tree, r)

    # right_smaller / right_larger: k>j
    right_smaller = [0] * n
    right_larger = [0] * n

    tree = make_bit()
    for i in range(n - 1, -1, -1):
        r = rank[rating[i]]
        right_smaller[i] = query(tree, r - 1)
        right_larger[i] = query(tree, M) - query(tree, r)
        update(tree, r)

    # 求和: 上升 + 下降
    res = 0
    for j in range(n):
        res += left_smaller[j] * right_larger[j]  # i<j<k, rating[i]<rating[j]<rating[k]
        res += left_larger[j] * right_smaller[j]  # i<j<k, rating[i]>rating[j]>rating[k]

    return res
```

## 11. 离线查询与 BIT 优化

### 11.1 离线查询 (Offline Query)

**场景**: 有多个查询, 每个查询是 BIT 操作. 一次性处理所有查询比在线更快.

**例子**: 给定数组 + Q 个查询 (l, r), 求 sum(l, r).

```python
def offline_range_sum(nums, queries):
    """
    queries: list of (l, r, query_id)
    返回 ans[query_id] = sum(nums[l..r])
    """
    Q = len(queries)
    ans = [0] * Q

    # 按 r 排序
    sorted_queries = sorted(enumerate(queries), key=lambda x: x[1][1])

    bit = BIT(len(nums))
    j = 1  # 已处理 nums[1..j-1]
    for qid, (l, r, _) in sorted_queries:
        while j <= r:
            bit.update(j, nums[j-1])
            j += 1
        ans[qid] = bit.range_query(l, r)

    return ans
```

### 13.1 通用 BIT 类 (Python)

```python
class BIT:
    """通用 BIT (单点更新 + 区间求和)"""

    def __init__(self, n):
        self.n = n
        self.tree = [0] * (n + 2)

    def update(self, i, delta):
        """a[i] += delta"""
        while i <= self.n:
            self.tree[i] += delta
            i += i & -i

    def query(self, i):
        """sum(a[1..i])"""
        s = 0
        while i > 0:
            s += self.tree[i]
            i -= i & -i
        return s

    def range_query(self, l, r):
        """sum(a[l..r])"""
        return self.query(r) - self.query(l - 1)

    def __repr__(self):
        return f"BIT(n={self.n})"
```

## 15. BIT vs 其他算法对比

### 15.1 BIT vs 归并排序

| 维度 | BIT | 归并排序 |
| :--- | :--- | :--- |
| 适用 | 动态 (一边遍历一边统计) | 静态 (一次给出所有数据) |
| 时间 | $O(n \log n)$ | $O(n \log n)$ |
| 代码 | 短 | 中 |
| 离散化 | 需要 | 不需要 |
| 空间 | $O(n)$ | $O(n)$ |

**选择**:
- 边遍历边查 → BIT
- 给定完整数组, 问"全部对数" → 归并
- 多次查询 → BIT

### 15.2 BIT vs 线段树

| 维度 | BIT | 线段树 |
| :--- | :--- | :--- |
| 代码量 | 10 行 | 50 行 |
| 常数 | 1× | 2-5× |
| 单点更新 + 区间和 | ✓ | ✓ |
| 区间最值 | ✗ | ✓ |
| 区间更新 + 区间和 | 差分技巧 | ✓ |
| 复杂度 | $O(\log n)$ | $O(\log n)$ |
| 适用 | 简单场景 | 复杂操作 |

**选择**:
- 只需要"和"操作 → BIT
- 需要最值/复杂操作 → 线段树

### 15.3 BIT vs 平衡 BST

| 维度 | BIT | 平衡 BST (如 SortedList) |
| :--- | :--- | :--- |
| 区间和 | $O(\log n)$ ✓ | $O(\log n)$ 但实现复杂 |
| 插入/删除 | $O(\log n)$ | $O(\log n)$ |
| 区间第 k 小 | ✗ (需特殊) | ✓ |
| 区间并集 | ✗ | ✓ |
| 适用 | 计数 + 前缀 | 复杂集合操作 |

### 15.4 BIT vs 哈希

| 维度 | BIT | 哈希 |
| :--- | :--- | :--- |
| 求频次 | $O(\log n)$ | $O(1)$ |
| 前缀和 | $O(\log n)$ | ✗ |
| 适用 | 频次 + 顺序 | 仅频次 |

### 16.1 BIT + 离线处理

**经典场景**: 修改 + 查询问题, 把所有修改和查询按时间排序, 一遍处理.

```python
def solve_modify_query(modifications, queries):
    """
    modifications: list of (time, pos, val)
    queries: list of (time, l, r, qid)
    返回: ans[qid] = 时刻 time 时, sum(l..r)
    """
    events = []
    for time, pos, val in modifications:
        events.append((time, 'mod', {'pos': pos, 'val': val}))

    for time, l, r, qid in queries:
        events.append((time, 'query', {'l': l, 'r': r, 'qid': qid}))

    events.sort(key=lambda e: e[0])

    bit = BIT(N)
    ans = {}

    for time, etype, data in events:
        if etype == 'mod':
            bit.update(data['pos'], data['val'])
        else:
            ans[data['qid']] = bit.range_query(data['l'], data['r'])

    return ans
```

### 16.2 BIT 套 BIT (2D BIT)

**LeetCode 363** 的另一种实现:

```python
class BITofBIT:
    """BIT 套 BIT: 支持二维范围操作"""
    def __init__(self, m, n):
        self.m = m
        self.tree = [[] for _ in range(m + 2)]
        self.bit = [[0] * (n + 2) for _ in range(m + 2)]

    def update(self, x, y, val):
        i = x
        while i <= self.m:
            j = y
            while j <= self.tree[i].size if hasattr(self.tree[i], 'size') else len(self.tree[i]):
                # 实际实现需要先对 y 坐标排序, 再用 BIT
                self.bit[i][j] += val
                j += j & -j
            i += i & -i

    def query(self, x, y):
        res = 0
        i = x
        while i > 0:
            j = y
            while j > 0:
                res += self.bit[i][j]
                j -= j & -j
            i -= i & -x
        return res
```

### 16.3 持久化 BIT (Persistent BIT)

**用途**: 查询任意历史版本的前缀和.

```python
class PersistentBIT:
    """持久化 BIT (用字典或对象数组)"""
    def __init__(self, root=None):
        self.root = root or {}

    def update(self, root, i, delta, n):
        """返回新根节点"""
        new_root = dict(root)
        new_root[i] = root.get(i, 0) + delta
        j = i + (i & -i)
        if j <= n:
            # 递归更新
            sub = self.update(root.get(j, {}), j, delta, n)
            new_root[j] = sub
        return new_root

    def query(self, root, i):
        s = 0
        while i > 0:
            s += root.get(i, 0)
            i -= i & -i
        return s
```

> 实际应用少, 主席树更常用.

### 16.4 BIT 解决最长上升子序列 (LIS)

**思路**: 用 BIT 维护"以 i 结尾的 LIS 长度".

```python
def lengthOfLIS(nums):
    """O(n log n) 求 LIS 长度"""
    # 离散化
    sorted_vals = sorted(set(nums))
    rank = {v: i + 1 for i, v in enumerate(sorted_vals)}
    n = len(sorted_vals)

    # BIT 维护每个 rank 的最长 LIS 长度
    tree = [0] * (n + 2)

    def update(i, val):
        while i <= n:
            tree[i] = max(tree[i], val)
            i += i & -i

    def query(i):
        """返回 rank <= i 的最长 LIS"""
        res = 0
        while i > 0:
            res = max(res, tree[i])
            i -= i & -i
        return res

    for x in nums:
        r = rank[x]
        # 找 < x 的最长 LIS
        lis_len = query(r - 1) + 1
        update(r, lis_len)

    return query(n)
```

**注意**: 这是用 BIT 求 LIS, 不是求和. 用 BIT 的"取 max"操作.

```python
    """2D BIT"""
    def __init__(self, matrix):
        if not matrix:
            return
        self.m, self.n = len(matrix), len(matrix[0])
        self.bit = [[0] * (self.n + 2) for _ in range(self.m + 2)]
        for i in range(self.m):
            for j in range(self.n):
                self._add(i + 1, j + 1, matrix[i][j])

    def update(self, row, col, val):
        self._add(row + 1, col + 1, val - self.matrix[row][col])
        self.matrix[row][col] = val

    def sumRegion(self, r1, c1, r2, c2):
        return self._sum(r2+1, c2+1) - self._sum(r1, c2+1) - self._sum(r2+1, c1) + self._sum(r1, c1)

    def _add(self, i, j, val):

        while x <= self.m:
            y = j
            while y <= self.n:
                self.bit[x][y] += val
                y += y & -y
            x += x & -x

        x = i
        while x > 0:
            y = j
            while y > 0:
                s += self.bit[x][y]
                y -= y & -y
```

### 18.1 内存管理

**问题**: 大 BIT (n = 10^6) 在 Python 中消耗大量内存.

**优化**:
- 用 array.array('l') 代替 list (省内存)
- 用 numpy (向量化)

```python
import array

class BITCompact:
    def __init__(self, n):
        self.n = n
        self.tree = array.array('l', [0] * (n + 2))

    def update(self, i, delta):
        while i <= self.n:
            self.tree[i] += delta
            i += i & -i

    def query(self, i):
        s = 0
        while i > 0:
            s += self.tree[i]
            i -= i & -i
        return s
```

### 18.2 多线程安全

BIT 不是线程安全的 (因为有 in-place 修改). 多线程时需加锁:

```python
import threading

class BITThreadSafe:
    def __init__(self, n):
        self.n = n
        self.tree = [0] * (n + 2)
        self.lock = threading.Lock()

    def update(self, i, delta):
        with self.lock:
            while i <= self.n:
                self.tree[i] += delta
                i += i & -i

    def query(self, i):
        with self.lock:
            s = 0
            while i > 0:
                s += self.tree[i]
                i -= i & -i
            return s
```

> 但加锁会损失性能, 多线程场景考虑用其他数据结构.

## 22. 习题答案与详解

### 22.1 LeetCode 327 - 区间和的个数

**题**: 给定 nums 和 lower/upper, 求子数组和 ∈ [lower, upper] 的个数.

**解**: 前缀和 + 离散化 + BIT.

**详解**:
- 子数组 [i, j] 和 = prefix[j+1] - prefix[i]
- 条件: lower ≤ prefix[j+1] - prefix[i] ≤ upper
- 即: prefix[i] ∈ [prefix[j+1] - upper, prefix[j+1] - lower]
- 离散化 prefix[i], prefix[i] - lower, prefix[i] - upper 这 3 种值
- 遍历 prefix, 用 BIT 统计落在 [L, R] 范围的前缀和数

### 22.2 LeetCode 493 - 翻转对

**题**: 翻转对: i < j 且 nums[i] > 2 * nums[j].

**解**: 离散化 + BIT (或归并排序).

**详解**:
- 离散化 nums 和 nums * 2 + 1 (排除 nums[j] * 2 边界)
- 从右向左遍历 nums
- threshold = (x - 1) // 2 即 floor((x-1)/2)
- query(rank[threshold]) 即 nums 中 < threshold 的数量
- 但要排除 nums[j] = threshold 的情况, 所以用 (x - 1) // 2

### 22.3 LeetCode 315 - 右侧小于

**题**: 数组右侧比当前元素小的元素数.

**解**: 从右向左 + BIT.

**详解**:
- 从右向左遍历, 把元素加入 BIT
- counts[i] = query(rank[nums[i]] - 1) (已加入中 < nums[i] 的数)
- 注意严格小于用 rank - 1

### 22.4 LeetCode 363 - 矩形不超过 K

**题**: 矩阵内不超过 k 的最大矩形和.

**解**: 枚举上下边界 + 1D 前缀和 + TreeSet (或 BIT).

**详解**:
- 固定上下边界, 列压缩为 1D
- 1D 问题: 找最大子数组和, 要求 ≤ k
- prefix[j] - prefix[i] ≤ k → prefix[i] ≥ prefix[j] - k
- 对每个 prefix[j], 找之前的 prefix[i] 中 ≥ prefix[j] - k 的最小值
- 用 TreeSet 维护 sorted prefix

### 22.5 LeetCode 683 - K 个空花盆

**题**: bulbs 数组, bulbs[i] 是第 i 天点燃的花盆位置. 求至少几天能连续种 k 朵.

**解**: 滑动窗口 + day 数组.

**详解**:
- day[i] = 第 i 个花盆被点燃的天数
- 滑动窗口 [left, right=k+1+left]
- 检查 (left, right) 内 day[i] 都 ≥ max(day[left], day[right])
- 即花盆 i 的点燃日期都晚于 left 和 right

## 23. 总结与思考

### 23.1 BIT 的核心思想

1. **隐式树**: 用 lowbit 隐式管理树结构
2. **前缀和**: 通过累加覆盖区间得到前缀和
3. **差分**: 用单点操作实现区间操作
4. **离散化**: 把大数值映射到小范围

### 23.2 实战心法

- **看见"区间和"**: 立刻想 BIT
- **看见"频次"**: 离散化 + BIT
- **看见"前缀相关"**: BIT
- **看见"区间最值"**: 线段树
- **看见"区间复杂操作"**: 线段树

### 23.3 常见误区

- ❌ 以为 BIT 能做所有区间操作 → 区间最值不行
- ❌ 以为 BIT 比线段树慢 → 实际上更短更快
- ❌ 以为离散化可以省略 → 大数值必须离散化
- ❌ 以为 BIT 没有调试信息 → 可以用前缀和验证

### 23.4 BIT 的局限

- 区间最值查询不行
- 二维 BIT 常数大
- 大量修改后查询单次性能可接受, 但批量查询建议离线

```python
def solve_bit(arr, query_range_fn):
    """
    arr: 待处理数组
    query_range_fn(x_rank, bit): 对当前元素 x_rank 的查询 (返回结果, 然后更新)

    返回: 结果列表
    """
    sorted_vals = sorted(set(arr))
    rank = {v: i + 1 for i, v in enumerate(sorted_vals)}
    n = len(sorted_vals)

    bit = BIT(n)
    results = []

    for x in arr:
        r = rank[x]
        result = query_range_fn(r, bit)
        results.append(result)
        bit.update(r, 1)  # 默认更新 +1

    return results
```

### 25.3 求逆序对

```python
def count_inversions(arr):
    """O(n log n) 求逆序对数"""
    sorted_vals = sorted(set(arr))
    rank = {v: i + 1 for i, v in enumerate(sorted_vals)}
    n = len(sorted_vals)

    tree = [0] * (n + 2)

    def update(i):
        while i <= n:
            tree[i] += 1
            i += i & -i

    def query(i):
        s = 0
        while i > 0:
            s += tree[i]
            i -= i & -i
        return s

    inv = 0
    for x in reversed(arr):
        r = rank[x]
        # 逆序对: 前面 > 后面. 当前是后面元素, 前面已加入.
        # inv += 已加入中 > x 的数量 = 已加入总数 - 已加入中 ≤ x 的数量
```

## 26. BIT 进阶专题

### 26.1 树状数组与"区间可加性"

BIT 的核心优势: 区间可加 (sum). 加法满足结合律, 所以前缀和有意义.

**max 不满足**: max(a, b) + max(c, d) ≠ max(a+c, b+d), 所以 BIT 不能直接做区间最值.

### 26.2 树状数组与"差分思想"

差分数组 $d[i] = a[i] - a[i-1]$. 那么:
- $\text{prefix\_sum}(a, k) = \sum_{i=1}^{k} d[i] \cdot (k - i + 1)$

差分让区间更新变单点更新.

### 26.3 树状数组与"莫队算法"

莫队算法: 离线处理区间查询, 通过调整 L/R 边界.

```python
def mo_algorithm(arr, queries):
    """莫队 + BIT"""
    block_size = int(len(arr) ** 0.5) + 1

    sorted_queries = sorted(
        enumerate(queries),
        key=lambda x: (x[1][0] // block_size, x[1][1])
    )

    bit = BIT(len(arr))
    cur_l, cur_r = 0, -1
    results = [0] * len(queries)

    for qid, (l, r, _) in sorted_queries:
        while cur_l > l:
            cur_l -= 1
            bit.update(cur_l + 1, arr[cur_l])
        while cur_r < r:
            cur_r += 1
            bit.update(cur_r + 1, arr[cur_r])
        while cur_l < l:
            bit.update(cur_l + 1, -arr[cur_l])
            cur_l += 1
        while cur_r > r:
            bit.update(cur_r + 1, -arr[cur_r])
            cur_r -= 1

        results[qid] = bit.range_query(l + 1, r + 1)

    return results
```
