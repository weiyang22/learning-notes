## 1. 二分搜索的 4 种典型用法

《挑战程序设计竞赛》把二分搜索的应用分成 4 类, 这是面试 + 竞赛的核心.

### 1.1 类型 1: 从有序数组中查找某个值

**最简单**: LeetCode 704 标准二分.

```python
def binary_search(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

详见 [01.04 - 数组二分查找](../第01章-算法入门与数组篇/第01章-04-数组二分查找.md)

### 1.2 类型 2: 假定一个解并判断是否可行

**典型题**: LeetCode 875 爱吃香蕉的珂珂.

**思路**: 假设速度 K, 判断能否在 H 小时内吃完.

```python
def minEatingSpeed(piles, H):
    """第 3.1.2 节 - 二分答案"""
    lo, hi = 1, max(piles)

    def can_finish(K):
        hours = sum((p + K - 1) // K for p in piles)
        return hours <= H

    while lo < hi:
        mid = (lo + hi) // 2
        if can_finish(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo
```

### 1.3 类型 3: 最大化最小值

**典型题**: LeetCode 410 分割数组的最大值.

**题目**: 给数组 nums 和整数 m, 把数组分成 m 个非空连续子数组, 使各子数组和的最大值**最小**.

```python
def splitArray(nums, m):
    """最大化最小值 (子数组和的最大值最小)"""
    lo, hi = max(nums), sum(nums)

    def can_split(max_sum):
        """判断: 限制 max_sum 时, 至少需要多少段"""
        cur_sum, count = 0, 1
        for x in nums:
            if cur_sum + x <= max_sum:
                cur_sum += x
            else:
                count += 1
                cur_sum = x
                if count > m:
                    return False
        return True

    while lo < hi:
        mid = (lo + hi) // 2
        if can_split(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo
```

**POJ 3273 - Monthly Expense**: 完全相同的题目.

### 1.4 类型 4: 最大化平均值

**典型题**: POJ 3111 - K Best.

**题目**: 给 n 个二元组 (v, w), 选 k 个使 $\sum v / \sum w$ 最大.

**思路**: 二分平均值 x, 判断是否存在选 k 个使 $\sum v_i - x \cdot \sum w_i \geq 0$.

```python
def k_best(V, W, k):
    n = len(V)

    def check(x):
        """判断: 选 k 个, 让 sum(v - x*w) >= 0"""
        diffs = sorted([V[i] - x * W[i] for i in range(n)], reverse=True)
        return sum(diffs[:k]) >= 0

    lo, hi = 0, max(V[i]/W[i] for i in range(n))
    for _ in range(100):  # 浮点二分, 迭代 100 次足够
        mid = (lo + hi) / 2
        if check(mid):
            lo = mid
        else:
            hi = mid
    return lo
```

**LeetCode 875** 类似思想: 最大化最小值 (单位时间内吃的最多数).

## 2. 二分应用的关键判断

### 2.1 何时用二分答案?

```text
✓ 求"满足条件的最大/最小值"
✓ 求"最大值的最小" / "最小值的最大"
✓ 答案具有单调性: 大于 ans 不行, 小于 ans 也不行
✓ 可以 O(n) 验证一个解
```

### 2.2 二分答案模板

```python
def binary_answer(lo, hi):
    """
    通用二分答案模板
    lo..hi 是答案范围 (含两端)
    """
    while lo < hi:
        mid = (lo + hi) // 2
        if check(mid):  # 验证 mid
            hi = mid
        else:
            lo = mid + 1
    return lo

def check(x):
    """验证函数 - 必须满足单调性"""
    return True / False
```

### 2.3 关键陷阱

```python
# ❌ 死循环: lo 和 hi 不动
while lo < hi:
    mid = (lo + hi) // 2
    if check(mid):
        hi = mid  # ✓
    else:
        lo = mid  # ❌ 应该是 lo = mid + 1

# ✅ 正确
while lo < hi:
    mid = (lo + hi) // 2
    if check(mid):
        hi = mid
    else:
        lo = mid + 1
```

```python
def minEatingSpeed(piles, H):
```

## 6. 二分细节: 闭区间 / 左闭右开 / 左开右闭的精确选择

### 6.1 三种区间写法的差异

二分的写法看似简单, 但 "while 循环条件" + "边界更新" + "返回值的语义" 三者的组合有 4 种常见写法. 不同写法适用于不同场景.

#### 写法 A: 闭区间 [lo, hi]

```python
def bsearch_closed(nums, target):
    """标准闭区间写法 - 用于查找值"""
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = lo + (hi - lo) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

- 循环条件: `lo <= hi` (区间非空)
- 更新: `lo = mid + 1` / `hi = mid - 1` (排除了 mid)
- 返回值: `lo` 是第一个 > target 的位置, `hi + 1` 是第一个 ≥ target 的位置

**适用场景**: 查找具体值, 找到就返回.

#### 写法 B: 左闭右开 [lo, hi)

```python
def bsearch_left_open(nums, target):
    """左闭右开 - 用于 lower_bound"""
    lo, hi = 0, len(nums)
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    return lo  # 第一个 >= target 的位置
```

- 循环条件: `lo < hi` (区间非空)
- 更新: `lo = mid + 1` / `hi = mid` (hi 永不包含)
- 返回值: `lo == hi == 第一个 >= target 的位置`

**适用场景**: `bisect_left`, 找插入位置.

#### 写法 C: lower_bound + upper_bound 组合

```python
def lower_bound(nums, target):
    """第一个 >= target"""
    lo, hi = 0, len(nums)
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    return lo

def upper_bound(nums, target):
    """第一个 > target"""
    lo, hi = 0, len(nums)
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] <= target:
            lo = mid + 1
        else:
            hi = mid
    return lo

# 区间 [lower_bound, upper_bound) 内都是 target
```

**适用场景**: LeetCode 34 - 在排序数组中查找元素的第一个和最后一个位置.

### 6.2 整数溢出陷阱

`mid = (lo + hi) // 2` 在 lo + hi 接近 int_max 时会溢出 (C++/Java). Python 不会 (任意精度), 但养成好习惯:

```python
# ✅ 推荐写法 - 永远不溢出
mid = lo + (hi - lo) // 2

# ❌ 不推荐
mid = (lo + hi) // 2  # C++/Java 可能溢出
```

### 6.3 死循环的两个常见原因

**原因 1: 边界更新错误**

```python
# ❌ 当 hi - lo == 1 时死循环
while lo < hi:
    mid = (lo + hi) // 2  # mid == lo
    if check(mid):
        hi = mid  # hi 不变
    else:
        lo = mid  # lo 不变

# ✅ 修复 1: lo = mid + 1
else:
    lo = mid + 1

# ✅ 修复 2: 用 mid = lo + (hi - lo + 1) // 2 (向上取整)
mid = lo + (hi - lo + 1) // 2
```

**原因 2: check 函数不单调**

```python
# ❌ check(x) 不单调 - 二分无意义
def check(x):
    return x % 2 == 0  # 偶数返回 True, 奇数 False - 不单调!

# ✅ check 必须单调: True False False 或 False True True
```

## 7. 类型 1 详解: 查找值 (含变形)

### 7.1 LeetCode 34 - 在排序数组中查找元素的第一个和最后一个位置

**题目**: 给定排序数组 nums 和目标值 target, 找出 target 在数组中的开始位置和结束位置. 不存在返回 [-1, -1]. 要求 O(log n).

**思路**: 两次二分 - lower_bound + upper_bound.

```python
def searchRange(nums, target):
    n = len(nums)

    def lower_bound(nums, target):
        lo, hi = 0, n
        while lo < hi:
            mid = (lo + hi) // 2
            if nums[mid] < target:
                lo = mid + 1
            else:
                hi = mid
        return lo

    left = lower_bound(nums, target)
    right = lower_bound(nums, target + 1) - 1

    if left <= right < n and nums[left] == target:
        return [left, right]
    return [-1, -1]
```

**关键洞察**: `lower_bound(target + 1) - 1 = upper_bound(target) - 1` = 最后一个等于 target 的位置.

### 7.2 LeetCode 33 - 搜索旋转排序数组

**题目**: 升序排列数组在某个未知点旋转 (例如 [0,1,2,4,5,6,7] → [4,5,6,7,0,1,2]). 搜索 target, O(log n).

**思路**: 旋转后, 至少有一半是有序的. 判断哪一半有序, 再决定 target 在哪.

```python
def search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        # 判断哪半有序
        if nums[lo] <= nums[mid]:  # 左半有序
            if nums[lo] <= target < nums[mid]:
                hi = mid - 1
            else:
                lo = mid + 1
        else:  # 右半有序
            if nums[mid] < target <= nums[hi]:
                lo = mid + 1
            else:
                hi = mid - 1
    return -1
```

**关键**: `nums[lo] <= nums[mid]` 还是 `nums[mid] <= nums[hi]` 判断有序区间.

### 7.3 LeetCode 81 - 搜索旋转排序数组 II (含重复)

**题目**: 同上, 但允许重复元素.

**关键差异**: 当 `nums[lo] == nums[mid] == nums[hi]` 时, 无法判断哪半有序, 只能 `lo += 1`.

```python
def search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return True
        if nums[lo] == nums[mid] == nums[hi]:
            lo += 1  # 无法判断, 缩小
        elif nums[lo] <= nums[mid]:
            if nums[lo] <= target < nums[mid]:
                hi = mid - 1
            else:
                lo = mid + 1
        else:
            if nums[mid] < target <= nums[hi]:
                lo = mid + 1
            else:
                hi = mid - 1
    return False
```

**复杂度**: 平均 O(log n), 最坏 O(n) (全相等时).

### 7.4 LeetCode 153 - 寻找旋转排序数组中的最小值

```python
def findMin(nums):
    lo, hi = 0, len(nums) - 1
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] < nums[hi]:  # 右半有序, 最小值在左半
            hi = mid
        else:  # nums[mid] > nums[hi], 最小值在右半
            lo = mid + 1
    return nums[lo]
```

**关键**: 比较 mid 与 hi (而非 lo), 因为 hi 一定是右半的边界.

### 7.5 LeetCode 162 - 寻找峰值

**题目**: nums[i] ≠ nums[i+1], 找到任意一个峰值 (nums[i] > nums[i-1] 且 nums[i] > nums[i+1]).

**思路**: 峰值一定存在 (二分后某侧必单调).

```python
def findPeakElement(nums):
    lo, hi = 0, len(nums) - 1
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] < nums[mid + 1]:  # 上升中, 峰值在右
            lo = mid + 1
        else:  # 下降中, 峰值在左 (含 mid)
            hi = mid
    return lo
```

**关键**: 不需要 nums 严格单调, 只需要 "二段性".

### 7.6 LeetCode 4 - 寻找两个有序数组的中位数 (Hard)

**题目**: nums1, nums2 长度 m, n, 找两个有序数组的中位数, O(log (m+n)).

**思路**: 二分较小数组的分割点.

```python
def findMedianSortedArrays(nums1, nums2):
    if len(nums1) > len(nums2):
        nums1, nums2 = nums2, nums1
    m, n = len(nums1), len(nums2)
    lo, hi = 0, m
    while lo <= hi:
        i = (lo + hi) // 2  # nums1 分割点
        j = (m + n + 1) // 2 - i  # nums2 分割点 (保证左半元素数)
        nums1_left = nums1[i-1] if i > 0 else float('-inf')
        nums1_right = nums1[i] if i < m else float('inf')
        nums2_left = nums2[j-1] if j > 0 else float('-inf')
        nums2_right = nums2[j] if j < n else float('inf')
        if nums1_left <= nums2_right and nums2_left <= nums1_right:
            if (m + n) % 2 == 0:
                return (max(nums1_left, nums2_left) + min(nums1_right, nums2_right)) / 2
            return max(nums1_left, nums2_left)
        elif nums1_left > nums2_right:
            hi = i - 1
        else:
            lo = i + 1
```

## 8. 类型 2 详解: 假定解 (含 check 函数)

### 8.1 LeetCode 875 - 爱吃香蕉的珂珂 (完整分析)

**题目**: 珂珂喜欢吃香蕉. 有 N 堆香蕉, 第 i 堆有 piles[i] 根. 警卫将在 H 小时后回来. 珂珂决定吃香蕉的速度 K (单位: 根/小时). 每小时选一堆吃 K 根 (若该堆少于 K, 则吃完该堆, 然后这小时不再吃). 求最小 K, 使珂珂能在 H 小时内吃完所有香蕉.

**思路**:
- 答案范围: K ∈ [1, max(piles)] (至少 1, 最多一次吃完一堆)
- 验证: 给定 K, 算出吃完所有香蕉需要多少小时. ≤ H 则 K 可行.

**完整 Python 代码**:

```python
def minEatingSpeed(piles, H):
    """K 根/小时, 求最小 K"""

    def hours_needed(K):
        # 每堆需要 ceil(p / K) 小时
        return sum((p + K - 1) // K for p in piles)

    lo, hi = 1, max(piles)
    while lo < hi:
        mid = (lo + hi) // 2
        if hours_needed(mid) <= H:
            hi = mid  # K 可行, 试试更小
        else:
            lo = mid + 1  # K 太小
    return lo
```

**复杂度**: O(n log(max(piles))).

**单调性证明**:
- K 越大, 吃完每堆越快, 总时间越少
- 所以 check(K) = "时间 ≤ H" 是单调的: K 小 → check False, K 大 → check True
- 存在最小可行 K, 这就是二分答案

### 8.2 LeetCode 1011 - 在 D 天内送达包裹的能力 (完整分析)

**题目**: 传送带上的包裹必须按顺序装船, 第 i 个包裹重 weights[i]. 每天装载若干连续包裹, 总重不能超过船的最大载重. 在 D 天内送达, 求最小载重.

```python
def shipWithinDays(weights, D):
    def days_needed(capacity):
        days, cur = 1, 0
        for w in weights:
            if cur + w <= capacity:
                cur += w
            else:
                days += 1
                cur = w
                if days > D:
                    return float('inf')
        return days

    lo, hi = max(weights), sum(weights)
    while lo < hi:
        mid = (lo + hi) // 2
        if days_needed(mid) <= D:
            hi = mid
        else:
            lo = mid + 1
    return lo
```

### 8.3 LeetCode 1482 - 制作 m 束花所需的最少天数

**题目**: 花园有 n 朵花, 第 i 朵在 day[i] 天开花. 制作一束花需要 k 朵连续开的花. 制作 m 束花, 求最少需要多少天.

**思路**: 二分天数, 验证前 mid 天内能否制作 m 束花.

```python
def minDays(bloomDay, m, k):
    if m * k > len(bloomDay):
        return -1

    def can_make(days):
        bouquets = 0
        flowers = 0
        for d in bloomDay:
            if d <= days:
                flowers += 1
                if flowers == k:
                    bouquets += 1
                    if bouquets >= m:
                        return True
                    flowers = 0  # 重置, 制作下一束
            else:
                flowers = 0
        return bouquets >= m

    lo, hi = min(bloomDay), max(bloomDay)
    while lo < hi:
        mid = (lo + hi) // 2
        if can_make(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo
```

### 8.4 LeetCode 1552 - 两球之间的磁力

**题目**: position[i] 表示第 i 个篮子在数轴上的位置. 把 m 个球放进 m 个不同篮子, 任意两球间最小磁力定义为它们距离的最小值. 求最大化这个最小距离.

**思路**: 二分最小距离, 验证能否放下 m 个球 (贪心).

```python
def maxDistance(position, m):
    position.sort()

    def can_place(min_dist):
        """贪心: 第一个篮子必放, 之后每个距离前一个 ≥ min_dist"""
        count = 1
        last = position[0]
        for p in position[1:]:
            if p - last >= min_dist:
                count += 1
                last = p
                if count >= m:
                    return True
        return False

    lo, hi = 1, position[-1] - position[0]
    while lo < hi:
        mid = (lo + hi + 1) // 2  # 向上取整 (最大化最小值)
        if can_place(mid):
            lo = mid
        else:
            hi = mid - 1
    return lo
```

**关键**: 最大化最小值用 `mid = (lo + hi + 1) // 2` (向上取整), 避免死循环.

## 10. 类型 4 详解: 最大化平均值

### 10.1 POJ 3111 - K Best 完整分析

**题目**: n 个钻石, 第 i 个有价值 v[i] 和重量 w[i]. 选 k 个, 使 v[i] 总和 / w[i] 总和最大.

**思路**: 二分平均值 x, 验证是否存在选 k 个使 Σv_i - x·Σw_i ≥ 0.

**为什么这样转化?**
设最优平均值为 ans, 存在选 k 个使 Σv_i / Σw_i = ans, 即 Σv_i - ans·Σw_i = 0.
要验证 ans 是否可达, 等价于判断是否存在选 k 个使 Σ(v_i - x·w_i) ≥ 0.

**完整代码**:

```python
def k_best(V, W, k):
    n = len(V)

    def check(x):
        """验证平均值 x 是否可达"""
        diffs = sorted([V[i] - x * W[i] for i in range(n)], reverse=True)
        return sum(diffs[:k]) >= 0

    lo, hi = 0.0, max(V[i] / W[i] for i in range(n))
    for _ in range(100):  # 浮点二分 100 次
        mid = (lo + hi) / 2
        if check(mid):
            lo = mid
        else:
            hi = mid
    return lo
```

**复杂度**: O(n log n · 100) = O(n log n).

**浮点二分的迭代次数**: 100 次后精度 ~ 2^-100, 远超 double 精度.

**题目**: 整数数组 nums, 找长度 ≥ k 的子数组, 使其平均值最大.

```python
        for j in range(k, n + 1):

            if prefix[j] >= min_prefix:
                return True
        return False

    lo, hi = min(nums), max(nums)
    for _ in range(100):
        mid = (lo + hi) / 2
        if check(mid):
            lo = mid
        else:
            hi = mid
    return lo
```

```python
def sortedListToBST(head):
    def build(head, tail):
        if head == tail:
            return None
        # 快慢指针找中点
        slow, fast = head, head
        while fast != tail and fast.next != tail:
            slow = slow.next
            fast = fast.next.next
        root = TreeNode(slow.val)
        root.left = build(head, slow)
        root.right = build(slow.next, tail)
        return root
    return build(head, None)
```

#### LeetCode 392 - 判断子序列 (用二分加速)

**思路**: 预处理 t 中每个字符的位置列表, 二分查找 s 的每个字符.

```python
def isSubsequence(s, t):
    from collections import defaultdict
    from bisect import bisect_left

    # t 中每个字符的位置列表
    pos = defaultdict(list)
    for i, c in enumerate(t):
        pos[c].append(i)

    # 二分查找 s 的每个字符
    cur = -1
    for c in s:
        if c not in pos:
            return False
        idx_list = pos[c]
        i = bisect_left(idx_list, cur + 1)
        if i == len(idx_list):
            return False
        cur = idx_list[i]
    return True
```

#### LeetCode 209 - 长度最小的子数组 (前缀和 + 二分)

```python
def minSubArrayLen(target, nums):
    n = len(nums)
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i+1] = prefix[i] + nums[i]

    res = n + 1
    for i in range(n + 1):
        # 二分找 j > i 使 prefix[j] - prefix[i] >= target
        lo, hi = i + 1, n + 1
        while lo < hi:
            mid = (lo + hi) // 2
            if prefix[mid] - prefix[i] >= target:
                hi = mid
            else:
                lo = mid + 1
        if lo <= n:
            res = min(res, lo - i)
    return res if res <= n else 0
```

#### LeetCode 862 - 和至少为 K 的最短子数组

```python
def shortestSubarray(nums, k):
    n = len(nums)
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i+1] = prefix[i] + nums[i]

    # 找 j < i 使 prefix[i] - prefix[j] >= k
    # 即 prefix[j] <= prefix[i] - k
    # 用单调队列保持 prefix 递增

    from collections import deque
    res = n + 1
    queue = deque()
    for i in range(n + 1):
        # 移除队首 (前缀和太小, 不可能再被用)
        while queue and prefix[i] - prefix[queue[0]] >= k:
            res = min(res, i - queue.popleft())
        # 维护队列单调递增
        while queue and prefix[i] <= prefix[queue[-1]]:
            queue.pop()
        queue.append(i)
    return res if res <= n else -1
```

```python
        self.level = level

class SkipList:
    def __init__(self):
        self.max_level = 16
        self.head = SkipListNode(-1, self.max_level)
        self.level = 0

    def search(self, target):
        node = self.head
        # 从最高层往下找
        for i in range(self.level - 1, -1, -1):
            while node.next[i] and node.next[i].val < target:
                node = node.next[i]
        # 最后一层精确比较
        node = node.next[0]
        if node and node.val == target:
            return True
        return False
```

## 17. 多解法对比与选择策略

### 17.1 同题多解的典型情况

#### LeetCode 410 - 分割数组的最大值

**解法 1: 二分答案 + 贪心** (推荐, O(n log S))

```python
def splitArray_binary(nums, m):
    lo, hi = max(nums), sum(nums)
    while lo < hi:
        mid = (lo + hi) // 2
        if can_split(nums, m, mid):
            hi = mid
        else:
            lo = mid + 1
    return lo
```

**解法 2: DP** (O(n² m), 复杂但更通用)

```python
def splitArray_dp(nums, m):
    n = len(nums)
    dp = [[float('inf')] * (m + 1) for _ in range(n + 1)]
    dp[0][0] = 0
    # prefix[i] = nums[:i] 的和
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i+1] = prefix[i] + nums[i]

    for i in range(1, n + 1):
        for k in range(1, min(i, m) + 1):
            for j in range(k, i + 1):
                # 在 j-1 和 i-1 之间分割
                dp[i][k] = min(dp[i][k], max(dp[j-1][k-1], prefix[i] - prefix[j-1]))
    return dp[n][m]
```

**对比**: 二分 O(n log S), DP O(n² m). 选二分.

#### LeetCode 875 - 爱吃香蕉的珂珂

**解法 1: 二分** (O(n log max), 推荐)

**解法 2: 累加前缀** (O(max), 不需要二分)

```python
def minEatingSpeed_alt(piles, H):
    # 时间最大的堆
    max_pile = max(piles)

    def hours_needed(K):
        return sum((p + K - 1) // K for p in piles)

    # 尝试 K 从 max_pile 到 1, 找最小可行
    for K in range(1, max_pile + 1):
        if hours_needed(K) <= H:
            return K
    return max_pile  # 永远不会到这里
```

**对比**: 二分 O(n log max), 线性扫描 O(max). 当 max(piles) 很大时选二分.

### 17.2 选择策略

```text
1. 单调性明确 → 二分 (O(n log n))
2. 答案范围小 → 枚举
3. 需要最优解 + 维度低 → DP
4. 答案范围连续 → 浮点二分 (100 次迭代)
5. 矩阵 / 树 → 转化为线性后二分
```

## 18. 调试与踩坑清单

### 18.1 死循环 5 大原因

```text
1. lo = mid 而 hi = mid 不变 (lo+hi 奇偶不变)
   修复: lo = mid + 1 或向上取整 mid

2. check 函数不单调
   修复: 重新审视问题, 确认单调性

3. 边界更新时 mid 一侧被排除, 另一侧没
   修复: 仔细画图

4. 浮点二分用整数 mid
   修复: 用 mid = (lo + hi) / 2.0

5. lo/hi 初值错 (闭区间 vs 半开)
   修复: 选定一种写法, 保持一致
```

### 18.2 越界 5 大陷阱

```text
1. mid = (lo + hi) // 2 溢出 (C++/Java)
   修复: mid = lo + (hi - lo) // 2

2. while 条件与 hi 初值不一致
   例: while lo < hi, 但 hi = len(nums) - 1 应该是 hi = len(nums)
   修复: 闭区间用 lo <= hi + hi = len-1

3. 单调队列 push 时忘了排除无效项
   修复: 每次 push 前检查

4. BIT 索引从 1 开始, 但数组从 0 开始
   修复: rank[i+1] 或单独处理

5. mid * mid 溢出 (LeetCode 69 大数)
   修复: long long / 浮点
```

```python
        return LeafNode(majority(y))

    for feat in range(X.shape[1]):
```

## 24. 总结与延伸

### 24.1 4 种应用的核心差异

| 类型 | check 函数 | 单调性方向 | 典型 update |
|---|---|---|---|
| 查找值 | nums[mid] vs target | 相等 → 返回 | 不等 → 移动 |
| 假定解 | 模拟过程 | "可行" 单调 | hi = mid |
| 最大化最小 | 贪心判定 | "可达" 单调 | lo = mid |
| 最大化平均 | 排序 + 选 k 个 | "≥ 0" 单调 | lo = mid (浮点) |

### 24.2 何时不用二分?

```text
1. 答案不单调 → 用 DFS/BFS/DP
2. 答案范围太大 (e.g. > 10^9) 但不能用浮点 → 用数论/数学
3. 问题规模小 (n ≤ 100) → 直接枚举
4. 需要精确解而非最优 → 用精确算法
```

### 24.3 二分的本质

二分 = 在单调函数上找零点的过程.
二分答案 = 在 "答案-可行性" 单调关系上找边界.
