## 1. 尺取法 (Sliding Window / Two Pointers)

**尺取法** = 在数组上"移动两个指针"的方法. 也叫**双指针法**.

**核心思想**: 通过移动头尾指针, 维护一个满足条件的"窗口".

### 1.1 适用场景

- 求满足某条件的**最长/最短子数组**
- 区间内元素和
- 字符串匹配

### 1.2 LeetCode 209 - 长度最小的子数组 (Medium)

**题目**: 找和 ≥ target 的最短连续子数组.

```python
def minSubArrayLen(target, nums):
    """尺取法"""
    n = len(nums)
    left = 0
    cur_sum = 0
    min_len = float('inf')

    for right in range(n):
        cur_sum += nums[right]
        # 当窗口满足条件, 尝试收缩
        while cur_sum >= target:
            min_len = min(min_len, right - left + 1)
            cur_sum -= nums[left]
            left += 1

    return 0 if min_len == float('inf') else min_len
```

**复杂度**: $O(n)$

### 1.3 LeetCode 76 - 最小覆盖子串 (Hard)

详见 [07.01 - 高频题 51-62](../第07章-面试篇下-高频题51-100/第07章-01-高频题51-62.md)

### 1.4 LeetCode 1004 - 最大连续 1 的个数 III (Medium)

**题目**: 给二进制数组, 最多翻转 K 个 0, 求最长连续 1 的长度.

```python
def longestOnes(nums, k):
    """尺取法: 维护一个窗口, 最多含 k 个 0"""
    left = 0
    zero_count = 0
    max_len = 0

    for right, x in enumerate(nums):
        if x == 0:
            zero_count += 1
        while zero_count > k:
            if nums[left] == 0:
                zero_count -= 1
            left += 1
        max_len = max(max_len, right - left + 1)

    return max_len
```

### 1.5 POJ 3061 - Subsequence (尺取法入门)

**题目**: 给序列, 求和 ≥ S 的最短子序列.

```python
def shortest_subseq(arr, S):
    """尺取法"""
    n = len(arr)
    left = 0
    cur_sum = 0
    min_len = float('inf')

    for right in range(n):
        cur_sum += arr[right]
        while cur_sum >= S:
            min_len = min(min_len, right - left + 1)
            cur_sum -= arr[left]
            left += 1

    return 0 if min_len == float('inf') else min_len
```

## 2. 反转 (开关问题)

**经典题**: 给定一个 01 串, 每次可以反转连续 K 个字符. 求最少操作次数让所有字符相同.

### 2.1 LeetCode 995 - K 连续位的最小翻转次数 (Hard)

```python
def minKBitFlips(nums, k):
    """贪心 + 差分数组"""
    n = len(nums)
    diff = [0] * (n + 1)
    flip = 0
    res = 0

    for i in range(n):
        flip ^= diff[i]
        if nums[i] ^ flip == 0:  # 当前是 0, 需要翻转
            if i + k > n:
                return -1
            res += 1
            flip ^= 1
            diff[i + k] ^= 1

    return res
```

**复杂度**: $O(n)$

## 3. 弹性碰撞 (Anagram / 碰撞问题)

**经典题**: 给定字符串, 两个不同字符会相互抵消. 求最终剩余.

### 3.1 LeetCode 1047 - 删除字符串中的所有相邻重复项 (Easy)

```python
def removeDuplicates(s):
    """栈: 同字符配对消除"""
    stack = []
    for c in s:
        if stack and stack[-1] == c:
            stack.pop()
        else:
            stack.append(c)
    return ''.join(stack)
```

### 3.2 POJ 2217 - 秘书的日记

**题目**: 给字符串 S 和 T, 求 T 在 S 中出现几次.

**解法**: 滚动哈希 (Rabin-Karp).

```python
def secretary_journal(S, T):
    """滚动哈希"""
    n, m = len(S), len(T)
    if m > n: return 0

    base = 256
    mod = 10**9 + 7
    h = pow(base, m-1, mod)  # base^(m-1)

    # 计算 T 的哈希
    hash_t = 0
    for c in T:
        hash_t = (hash_t * base + ord(c)) % mod

    # 滚动 S
    hash_s = 0
    count = 0
    for i in range(n):
        hash_s = (hash_s * base + ord(S[i])) % mod
        if i >= m - 1:
            # 减去最左字符
            hash_s = (hash_s - ord(S[i - m + 1]) * h) % mod
            if hash_s == hash_t:
                count += 1

    return count
```

## 4. 折半枚举 (Meet in the Middle / 双向搜索)

**核心**: 把大问题拆成两半, 分别枚举, 再合并.

**适用**: $n \leq 40$ 时, $2^{40}$ 太大, 但 $2^{20}$ 可行.

### 4.1 LeetCode 1755 - 最接近目标值的子序列和 (Hard)

**题目**: 给数组 nums 和目标值 goal, 找子序列使和最接近 goal.

```python
def minAbsDifference(nums, goal):
    """折半枚举"""
    n = len(nums)
    half = n // 2

    # 前半所有子集和
    left_sums = []
    for mask in range(1 << half):
        s = 0
        for i in range(half):
            if mask & (1 << i):
                s += nums[i]
        left_sums.append(s)

    # 后半所有子集和
    right_sums = []
    for mask in range(1 << (n - half)):
        s = 0
        for i in range(n - half):
            if mask & (1 << i):
                s += nums[half + i]
        right_sums.append(s)

    right_sums.sort()

    # 二分: 对每个 left, 找最接近 goal 的 right
    res = float('inf')
    for x in left_sums:
        target = goal - x
        # 二分找 right_sums 中最接近 target 的
        lo, hi = 0, len(right_sums)
        while lo < hi:
            mid = (lo + hi) // 2
            if right_sums[mid] < target:
                lo = mid + 1
            else:
                hi = mid
        # 检查 lo 和 lo-1
        for idx in [lo, lo - 1]:
            if 0 <= idx < len(right_sums):
                res = min(res, abs(x + right_sums[idx] - goal))

    return res
```

**复杂度**: $O(2^{n/2} \cdot n + 2^{n/2} \log 2^{n/2}) = O(2^{n/2} \cdot n)$

## 5. 坐标离散化 (Coordinate Compression)

**核心**: 把大范围的坐标压缩到小范围, 便于数组索引.

**适用**: 坐标范围很大 ($10^9$) 但点数很少 ($10^5$).

### 5.1 模板

```python
def coordinate_compression(points):
    """坐标离散化"""
    # 收集所有坐标
    coords = sorted(set(x for x, y in points) | set(y for x, y in points))
    # 映射: 原坐标 → 压缩后坐标 (从 1 开始)
    mp = {v: i + 1 for i, v in enumerate(coords)}

    # 应用
    compressed = [(mp[x], mp[y]) for x, y in points]
    return compressed, len(coords)
```

### 5.2 应用场景

- **二维前缀和**: 矩阵中只有少量点, 用坐标离散化建数组
- **线段树/树状数组**: 坐标离散化后用数组索引
- **扫描线算法**: 矩形面积/周长问题

## 8. 进阶: 尺取法的完整理论体系

## 8.1 双指针的分类学 (Taxonomy of Two Pointers)

尺取法在算法竞赛中通常被归入"双指针"(Two Pointers) 家族, 但双指针其实有多个**变种**, 各自适用场景不同. 完整分类如下:

| 变种 | 指针移动方向 | 适用场景 | 时间复杂度 |
|---|---|---|---|
| **同向双指针 (尺取/滑动窗口)** | `left ≤ right`, 同向前进 | 子数组/子串问题 | $O(n)$ |
| **相向双指针 (对撞指针)** | `left →`, `right ←`, 向中间逼近 | 有序数组两数之和, 反转, 回文 | $O(n)$ |
| **快慢双指针 (Floyd)** | `slow < fast`, 不同速度 | 链表环检测, 中点, 去重 | $O(n)$ |
| **分离双指针 (归并)** | 两个数组各一个指针 | 合并, 交集, 差集 | $O(n+m)$ |
| **固定步长双指针** | 间隔固定 k 滑动 | 滑动窗口最大值, 滑动窗口中位数 | $O(n)$ |

### 8.1.1 同向双指针 (Sliding Window)

```text
[---|---|---|---|---|---|---|---]
 ^                   ^
 left               right      (窗口扩张)

        [---|---|---|---]
            ^       ^
           left    right       (窗口收缩)
```

**本质**: 维护一个**满足某条件**的窗口, 通过移动 left 和 right 指针, 让窗口在数组上"滑动". 每个元素最多被 left 和 right 各访问一次, 所以总时间 $O(n)$.

**关键不变量**: 在任意时刻, 窗口都满足(或尝试满足)某个条件. 我们通过扩张 right 直到条件不满足, 然后收缩 left 直到条件再次满足, 循环往复.

### 8.1.2 相向双指针 (Opposite-direction)

```text
[---|---|---|---|---|---|---|---]
 ^                               ^
 left                            right    (初始)

[---|---|---|---|---|---|---|---]
         ^               ^
        left            right           (向中间逼近)
```

**本质**: 利用有序性, 两端夹逼. 通常用于有序数组的"找两个数满足某条件"类问题.

**经典案例**: LeetCode 167 两数之和 II, LeetCode 15 三数之和, LeetCode 11 盛最多水的容器, LeetCode 42 接雨水.

### 8.1.3 快慢双指针 (Fast-Slow)

```text
[---|---|---|---|---|---|---|---]
 ^   ^
slow fast     (快指针每次走 2 步, 慢指针 1 步)
```

**本质**: 快指针负责"探索", 慢指针负责"标记". 经典应用是 Floyd 环检测算法(龟兔赛跑).

**经典案例**: LeetCode 141 环形链表, LeetCode 142 环形链表 II, LeetCode 876 链表的中间节点, LeetCode 26 删除有序数组重复项.

### 8.1.4 分离双指针 (Merge-style)

```text
A: [---|---|---|---|]
            ^            (A 的指针)
B: [---|---|---|]
       ^                 (B 的指针)
```

**本质**: 在两个数组上各自维护一个指针, 同步前进. 用于归并, 交集, 差集, 各种合并问题.

**经典案例**: LeetCode 88 合并两个有序数组, LeetCode 21 合并两个有序链表, LeetCode 349 两个数组的交集.

## 8.2 滑动窗口的 4 种模式 (4 Sliding Window Patterns)

滑窗题看似千变万化, 但本质上只有 **4 种固定模式**. 识别模式后直接套模板即可.

### 模式 1: 固定长度窗口

**特征**: 窗口大小恒定为 k. 每次计算窗口内的某个聚合值.

**模板**:
```python
def fixed_window(arr, k):
    """窗口大小固定为 k"""
    n = len(arr)
    if n < k:
        return None
    # 初始化第一个窗口
    cur = sum(arr[:k])
    best = cur
    # 滑动: 每次去掉左边, 加入右边
    for i in range(k, n):
        cur += arr[i] - arr[i - k]
        best = max(best, cur)  # 或 min, 视题目而定
    return best
```

**复杂度**: $O(n)$ 时间, $O(1)$ 额外空间.

**LeetCode 643 - 子数组最大平均数 I (Easy)**:
```python
def findMaxAverage(nums, k):
    """固定窗口: 平均值 = 总和 / k, 总和最大时平均最大"""
    n = len(nums)
    cur = sum(nums[:k])
    best = cur
    for i in range(k, n):
        cur += nums[i] - nums[i - k]
        best = max(best, cur)
    return best / k
```

**LeetCode 239 - 滑动窗口最大值 (Hard)**:

固定窗口但需要返回**每个窗口的最大值**. 单调队列解法.

```python
from collections import deque

def maxSlidingWindow(nums, k):
    """
    单调递减队列: 队首永远是窗口最大值.
    每次滑动: 弹出过期元素, 加入新元素, 维护单调性.
    """
    dq = deque()  # 存下标, 对应 nums 值单调递减
    res = []
    for i, x in enumerate(nums):
        # 1. 弹出队尾所有小于 x 的(它们不可能是最大值了)
        while dq and nums[dq[-1]] < x:
            dq.pop()
        dq.append(i)
        # 2. 弹出队首过期元素(下标 < i - k + 1)
        if dq[0] < i - k + 1:
            dq.popleft()
        # 3. 当窗口形成后记录答案
        if i >= k - 1:
            res.append(nums[dq[0]])
    return res
```

**复杂度**: $O(n)$ 时间, $O(k)$ 空间.

**多解法对比**:

| 解法 | 时间 | 空间 | 说明 |
|---|---|---|---|
| 暴力 (每窗口遍历) | $O(nk)$ | $O(1)$ | 超时 |
| **单调队列 (推荐)** | $O(n)$ | $O(k)$ | 标准解法 |
| 优先队列 (懒删除) | $O(n \log k)$ | $O(k)$ | 略慢但好写 |
| 线段树 | $O(n \log n)$ | $O(n)$ | 过重 |

**为什么单调队列是 $O(n)$?** 每个元素**最多入队一次出队一次**, 总操作次数 $2n$.

### 模式 2: 最长满足条件子数组 (Longest)

**特征**: 找**最长**子数组满足某条件 (例如"和 ≤ S", "最多 k 个不同字符").

**模板**:
```python
def longest_with_constraint(arr):
    """最长满足条件的子数组"""
    left = 0
    state = init_state()
    best = 0
    for right, x in enumerate(arr):
        add(state, x)  # 加入右端
        while not valid(state):  # 不满足, 收缩左端
            remove(state, arr[left])
            left += 1
        best = max(best, right - left + 1)
    return best
```

**复杂度**: $O(n)$ 时间, 状态空间 $O(|state|)$.

**LeetCode 3 - 无重复字符的最长子串 (Medium)**:
```python
def lengthOfLongestSubstring(s):
    """最长不含重复字符的子串"""
    left = 0
    last = {}  # 字符 -> 最近出现位置
    best = 0
    for right, c in enumerate(s):
        if c in last and last[c] >= left:
            left = last[c] + 1  # 跳到重复字符的下一个
        last[c] = right
        best = max(best, right - left + 1)
    return best
```

**复杂度**: $O(n)$ 时间, $O(|\Sigma|)$ 空间 ($\Sigma$ 为字符集).

**LeetCode 904 - 水果成篮 (Medium)**:
```python
def totalFruit(fruits):
    """最多含 2 种水果的最长子数组"""
    left = 0
    cnt = {}
    best = 0
    for right, f in enumerate(fruits):
        cnt[f] = cnt.get(f, 0) + 1
        while len(cnt) > 2:
            cnt[fruits[left]] -= 1
            if cnt[fruits[left]] == 0:
                del cnt[fruits[left]]
            left += 1
        best = max(best, right - left + 1)
    return best
```

**推广**: LeetCode 159 至多包含两个不同字符的最长子串, LeetCode 340 至多包含 K 个不同字符的最长子串.

**LeetCode 340 的多解法对比**:

| 解法 | 时间 | 空间 | 说明 |
|---|---|---|---|
| 滑动窗口 + 哈希表 | $O(n)$ | $O(k)$ | **最优解**, 推荐 |
| 滑动窗口 + Counter | $O(n)$ | $O(k)$ | Pythonic 但略慢 |
| 前缀和 + 状态压缩 | $O(n \cdot 2^k)$ | $O(n)$ | 仅当 k 极小时 |

### 模式 3: 最短满足条件子数组 (Shortest)

**特征**: 找**最短**子数组满足某条件 (例如"和 ≥ S", "包含目标字符串").

**模板**:
```python
def shortest_with_constraint(arr):
    """最短满足条件的子数组"""
    left = 0
    state = init_state()
    best = float('inf')
    for right, x in enumerate(arr):
        add(state, x)
        while valid(state):  # 已满足, 尝试收缩
            best = min(best, right - left + 1)
            remove(state, arr[left])
            left += 1
    return best if best != float('inf') else 0
```

**复杂度**: $O(n)$ 时间.

**LeetCode 209 - 长度最小的子数组 (Medium)**:
```python
def minSubArrayLen(target, nums):
    """和 ≥ target 的最短子数组"""
    left = 0
    cur = 0
    best = float('inf')
    for right, x in enumerate(nums):
        cur += x
        while cur >= target:
            best = min(best, right - left + 1)
            cur -= nums[left]
            left += 1
    return 0 if best == float('inf') else best
```

**LeetCode 76 - 最小覆盖子串 (Hard)**:
```python
from collections import Counter

def minWindow(s, t):
    """s 中包含 t 所有字符的最短子串"""
    need = Counter(t)
    missing = len(t)
    left = start = end = 0

    for right, c in enumerate(s, 1):  # right 从 1 开始方便取 [left, right)
        if need[c] > 0:
            missing -= 1
        need[c] -= 1
        if missing == 0:  # 当前窗口已覆盖
            while left < right and need[s[left]] < 0:
                need[s[left]] += 1
                left += 1
            if not end or right - left <= end - start:
                start, end = left, right
            need[s[left]] += 1
            missing += 1
            left += 1

    return s[start:end]
```

**复杂度**: $O(n)$ 时间, $O(|\Sigma|)$ 空间.

### 模式 4: 计数型窗口 (Counting Window)

**特征**: 窗口需要满足某种"计数约束" (例如"最多 k 个 0", "恰好 m 个奇数").

**模板**:
```python
def counting_window(arr, k):
    """窗口内某条件出现次数限制为 k"""
    left = 0
    cnt = 0  # 不满足条件元素的计数
    best = 0
    for right, x in enumerate(arr):
        if x == BAD:
            cnt += 1
        while cnt > k:
            if arr[left] == BAD:
                cnt -= 1
            left += 1
        best = max(best, right - left + 1)
    return best
```

**LeetCode 1004 - 最大连续 1 的个数 III (Medium)**:
```python
def longestOnes(nums, k):
    """最多翻转 k 个 0, 求最长 1"""
    left = 0
    zeros = 0
    best = 0
    for right, x in enumerate(nums):
        if x == 0:
            zeros += 1
        while zeros > k:
            if nums[left] == 0:
                zeros -= 1
            left += 1
        best = max(best, right - left + 1)
    return best
```

**LeetCode 424 - 替换后的最长重复字符 (Medium)**:
```python
def characterReplacement(s, k):
    """最多替换 k 个字符, 使所有字符都相同的最长子串"""
    from collections import Counter
    cnt = {}
    left = 0
    best = 0
    max_freq = 0  # 窗口内出现次数最多的字符的频率

    for right, c in enumerate(s):
        cnt[c] = cnt.get(c, 0) + 1
        max_freq = max(max_freq, cnt[c])
        # 窗口长度 - max_freq > k, 说明需要替换的字符太多
        while right - left + 1 - max_freq > k:
            cnt[s[left]] -= 1
            left += 1
        best = max(best, right - left + 1)
    return best
```

**关键技巧**: `max_freq` 不需要更新, 因为即使变小了, 之前记录的 `best` 已经基于更大的 max_freq 算过了.

```python
from collections import Counter

def checkInclusion(s1, s2):
    """s2 是否包含 s1 的排列"""
    need = Counter(s1)
    required = len(need)
    formed = 0
    left = 0
    window_counts = {}

    for right, c in enumerate(s2):
        window_counts[c] = window_counts.get(c, 0) + 1
        if c in need and window_counts[c] == need[c]:
            formed += 1
        if formed == required:
            return True
        # 窗口长度 > len(s1), 收缩
        if right - left + 1 > len(s1):
            lc = s2[left]
            if lc in need and window_counts[lc] == need[lc]:
                formed -= 1
            window_counts[lc] -= 1
            left += 1
    return False
```

## 8.3 滑动窗口的复杂度证明

### 8.3.1 为什么是 $O(n)$?

**核心论据**: 每个元素最多被 left 指针访问 1 次, 最多被 right 指针访问 1 次.

```text
[---|---|---|---|---|---|---|---]
 1   2   3   4   5   6   7   8

left 访问: 元素 1, 2, 3, ..., n (最多 n 次)
right 访问: 元素 1, 2, 3, ..., n (最多 n 次)
总共: 2n 次 → O(n)
```

**反例**: 如果 left 会回退 (例如从 5 退到 3), 那么某些元素会被访问多次, 退化到 $O(n^2)$.

### 8.3.2 单调性约束

为了保证 $O(n)$, 必须满足:

1. **left 单调不减**: `left` 只会向右移动或不变, 不会回退.
2. **right 单调递增**: `right` 每轮循环 +1.
3. **状态转移 $O(1)$**: 每次 `add` / `remove` 操作必须是常数时间.

违反任意一条, 复杂度都会退化.

## 8.4 反转(开关问题)的深度剖析

### 8.4.1 差分数组的核心思想

差分数组 (Difference Array) 是一种**区间修改利器**. 核心思想:

```text
原数组:    a[0], a[1], a[2], a[3], a[4]
差分数组:  d[0], d[1], d[2], d[3], d[4]
关系:     a[i] = d[0] + d[1] + ... + d[i] (前缀和)
```

**区间修改**: 给区间 [l, r] 加上 x:
```python
diff[l] += x
diff[r + 1] -= x
```

**原理**: 差分数组的前缀和就是原数组. 在 l 处 +x, 后面所有元素都 +x. 在 r+1 处 -x, 抵消后续影响.

### 8.4.2 LeetCode 995 的多解法对比

**题目**: 给二进制数组, 每次反转连续 K 个元素. 求最少操作次数让所有元素相同.

#### 解法 1: 暴力 (超时)

每次从头开始找 0, 反转 K 个. $O(nk)$.

#### 解法 2: 滑动窗口 + 实时统计

```python
def minKBitFlips_v2(nums, k):
    """滑动窗口 + 实时统计 0 的个数"""
    n = len(nums)
    zero_count = 0
    flipped = 0  # 当前窗口被翻转的次数
    res = 0

    for right in range(n):
        if right >= k and nums[right - k] == 0:
            # 之前翻转的 0 现在又变回 0 了
            zero_count -= 1
        # ...
    return res
```

复杂但正确性差, 不推荐.

#### 解法 3: **贪心 + 差分数组 (推荐)**

```python
def minKBitFlips(nums, k):
    """贪心: 从左到右, 遇到 0 就翻转它所在的 K 区间."""
    n = len(nums)
    diff = [0] * (n + 1)
    flipped = 0  # 当前累积翻转次数 (奇数次翻转, 0 -> 1; 偶数次, 0 -> 0)
    res = 0

    for i in range(n):
        flipped ^= diff[i]  # 应用累积翻转
        if nums[i] ^ flipped == 0:  # 当前是 0, 需要翻转
            if i + k > n:
                return -1  # 剩余不足 K 个, 无解
            res += 1
            flipped ^= 1  # 从这里开始, 未来 K 个元素都翻转一次
            diff[i + k] ^= 1  # 在 i+k 处取消翻转

    return res
```

**复杂度**: $O(n)$ 时间, $O(n)$ 空间 (可优化到 $O(1)$).

**正确性证明 (贪心)**:

假设我们从左到右考虑每个位置 i:
- 如果 nums[i] 经过前面的翻转后是 0, **必须**在 i 处开始翻转 K 个元素 (因为前面的翻转不影响 nums[i]).
- 这是**唯一**能让 nums[i] 变 1 的机会 (因为只能反转连续 K 个, 而 i 只能被 [i-K+1, i] 区间覆盖).
- 所以贪心是正确的.

**复杂度分析**:
- 外层循环 $O(n)$.
- 每次循环常数次操作.
- 总时间 $O(n)$.

#### 解法 4: 贪心 + 集合 (不推荐, 但更直观)

```python
def minKBitFlips_set(nums, k):
    """用 set 记录所有"开始翻转"的位置"""
    flipped = set()
    res = 0
    for i in range(len(nums)):
        # 移除不在窗口内的翻转
        if i - k in flipped:
            flipped.remove(i - k)
        # 当前累积翻转次数 = len(flipped) % 2
        cur = (nums[i] + len(flipped)) % 2
        if cur == 0:
            if i + k > len(nums):
                return -1
            flipped.add(i)
            res += 1
    return res
```

**复杂度**: $O(n)$ 摊还 (set 操作均摊 $O(1)$).

### 8.4.3 推广: LeetCode 926 - 字符串翻转为单调递增

**题目**: 给 01 字符串, 每次翻转一个字符. 求最少翻转次数使字符串单调递增 (前 0 后 1).

```python
def minFlipsMonoIncr(s):
    """
    动态规划: 前缀 0 的个数 + 后缀 1 的个数.
    等价于: 找一个分割点 k, 让 [0, k) 全为 0, [k, n) 全为 1.
    """
    n = len(s)
    # 前缀和: pref[i] = s[0..i) 中 '1' 的个数
    pref = [0] * (n + 1)
    for i in range(n):
        pref[i + 1] = pref[i] + (1 if s[i] == '1' else 0)

    # 枚举分割点 k: [0, k) 改 1, [k, n) 改 0
    # 改 1 的个数 = pref[k] (其中 1 的个数)
    # 改 0 的个数 = (n - k) - (pref[n] - pref[k]) (其中 0 的个数)
    res = min(pref[k] + (n - k) - (pref[n] - pref[k]) for k in range(n + 1))
    return res
```

**多解法对比**:

| 解法 | 时间 | 空间 | 说明 |
|---|---|---|---|
| **前缀和 + 枚举** | $O(n)$ | $O(n)$ | 最简洁 |
| 前缀和 + 滚动 | $O(n)$ | $O(1)$ | 优化 |
| 动态规划 | $O(n)$ | $O(1)$ | 状态机 |
| 双指针 / 滑动窗口 | $O(n)$ | $O(1)$ | 等价 |

## 8.5 弹性碰撞 (栈) 的深度剖析

### 8.5.1 栈消消乐的核心思想

栈消消乐 (Stack Cancellation) 的本质是**配对消除**:
- 相同字符: 抵消.
- 不同字符: 入栈.

**不变量**: 栈底到栈顶的字符**永远不会相邻相同** (否则会抵消).

```python
        else:
```

```python
def removeDuplicates_count(s):
    """快慢指针 + 计数器"""
    slow = fast = 0
    while fast < len(s):
        # slow 位置要么是栈顶, 要么是 0 (空)
        if slow > 0 and s[slow - 1] == s[fast]:
            slow -= 1
        else:
            s = s[:slow] + s[fast] + s[slow + 1:]
            slow += 1
        fast += 1
    return s[:slow]
```

```python
def removeDuplicates_k(s, k):
    """栈 + 计数"""
    stack = []  # [(char, count), ...]
    for c in s:
        if stack and stack[-1][0] == c:
            stack[-1] = (c, stack[-1][1] + 1)
            if stack[-1][1] == k:
                stack.pop()
        else:
            stack.append((c, 1))
    return ''.join(c * cnt for c, cnt in stack)
```

### 8.5.4 LeetCode 844 - 比较含退格的字符串 (Easy)

**题目**: # 表示退格, 比较两个字符串最终是否相等.

```python
def backspaceCompare(s, t):
    """双指针从后向前扫描"""
    i, j = len(s) - 1, len(t) - 1
    skip_i = skip_j = 0

    while i >= 0 or j >= 0:
        # 找到 s 中下一个有效字符
        while i >= 0:
            if s[i] == '#':
                skip_i += 1
                i -= 1
            elif skip_i > 0:
                skip_i -= 1
                i -= 1
            else:
                break
        # 同样处理 t
        while j >= 0:
            if t[j] == '#':
                skip_j += 1
                j -= 1
            elif skip_j > 0:
                skip_j -= 1
                j -= 1
            else:
                break
        # 比较当前字符
        if i >= 0 and j >= 0:
            if s[i] != t[j]:
                return False
        elif i >= 0 or j >= 0:
            return False
        i -= 1
        j -= 1
    return True
```

**复杂度**: $O(n+m)$ 时间, $O(1)$ 空间.

**多解法对比**:

| 解法 | 时间 | 空间 | 说明 |

| 栈 | $O(n+m)$ | $O(n+m)$ | 直观 |
| **双指针从后向前** | $O(n+m)$ | $O(1)$ | **推荐**, 空间最优 |
| 重建字符串 | $O(n+m)$ | $O(n+m)$ | 同栈 |

## 8.6 折半枚举 (Meet in the Middle) 的深度剖析

### 8.6.1 核心思想

把搜索空间 $2^n$ 拆成两半, 每半 $2^{n/2}$, 分别枚举, 再合并.

**适用条件**:
- $n \leq 40$ (这样 $2^{n/2} \leq 2^{20} \approx 10^6$).
- 问题可以分解为"前半状态 + 后半状态 = 答案".
- 合并步骤能用二分/哈希高效完成.

### 8.6.2 标准流程

```text
1. 拆分: 把数组分成 left (前 n/2 个) 和 right (后 n/2 个).
2. 枚举: 分别求出 left 的所有子集和 (2^(n/2) 个), 存入数组 A, B.
3. 排序: 对 B 排序 (O(m log m)).
4. 合并: 对 A 中每个元素 a, 在 B 中二分找最接近 target - a 的元素 b.
   复杂度: O(m log m) 其中 m = 2^(n/2).
```

### 8.6.3 LeetCode 1755 的多解法对比

#### 解法 1: **折半枚举 (推荐)**

```python
def minAbsDifference(nums, goal):
    """折半枚举 + 二分"""
    n = len(nums)
    half = n // 2

    def gen(arr):
        """生成所有子集和"""
        sums = []
        for mask in range(1 << len(arr)):
            s = 0
            for i in range(len(arr)):
                if mask & (1 << i):
                    s += arr[i]
            sums.append(s)
        return sums

    left = gen(nums[:half])
    right = gen(nums[half:])
    right.sort()

    res = float('inf')
    import bisect
    for x in left:
        target = goal - x
        # 二分找最接近 target 的
        idx = bisect.bisect_left(right, target)
        for i in [idx, idx - 1]:
            if 0 <= i < len(right):
                res = min(res, abs(x + right[i] - goal))
    return res
```

**复杂度**: $O(2^{n/2} \cdot n)$ (生成子集和).

#### 解法 2: DP (次优)

```python
def minAbsDifference_dp(nums, goal):
    """
    DP: 维护所有可能的子集和 (Python 的集合操作).
    但 n 大时集合爆炸, 不推荐.
    """
    sums = {0}
    for x in nums:
        sums = sums | {s + x for s in sums}
    return min(abs(s - goal) for s in sums)
```

**复杂度**: 理论 $O(n \cdot 2^n)$, 实际可能更优, 但空间太大.

#### 解法 3: 剪枝 + 排序

如果数组绝对值之和远小于 goal, 或远大于 goal, 可以先做范围剪枝.

```python
    half = n // 2

    dp = {0: 0}

            new[diff + r] = max(new.get(diff + r, 0), small)
            # r 加到低的柱子:
            if r > diff:
                new[r - diff] = max(new.get(r - diff, 0), small + diff)
            else:
                new[diff - r] = max(new.get(diff - r, 0), small + r)
        dp = new

    # 后半: 同理, 但这次用 set 收集所有可能的 (差, 较小)
    # 然后合并...
    # 复杂度: O(2^(n/2))
    return max(dp.values())
```

## 8.7 坐标离散化的深度剖析

### 8.7.1 适用场景

当坐标范围很大 ($10^9$) 但点数很少 ($10^5$) 时, 直接开数组会 MLE. 离散化把大坐标映射到小下标.

**典型应用**:
- 二维前缀和 (稀疏矩阵)
- 线段树/树状数组 (大坐标)
- 扫描线算法 (矩形面积/周长)

### 8.7.2 完整模板

```python
def coordinate_compression(points):
    """
    坐标离散化.

    Args:
        points: List[Tuple[int, int]]

    Returns:
        compressed: 压缩后的点
        size: 压缩后的坐标范围 [1, size]
    """
    # 1. 收集所有出现过的坐标
    xs = sorted({p[0] for p in points})
    ys = sorted({p[1] for p in points})

    # 2. 建立映射 (从 1 开始, 方便前缀和)
    x_to_i = {x: i + 1 for i, x in enumerate(xs)}
    y_to_i = {y: i + 1 for i, y in enumerate(ys)}

    # 3. 应用映射
    compressed = [(x_to_i[x], y_to_i[y]) for x, y in points]

    return compressed, len(xs), len(ys)
```

### 8.7.3 二维前缀和例题

**题目**: 给 n 个点 (xi, yi) 和 q 个查询 (x1, y1, x2, y2), 每次问矩形内点的个数.

```python
def rectangle_count(points, queries):
    """离散化 + 二维前缀和"""
    # 离散化
    xs = sorted({p[0] for p in points} | {q[0] for q in queries} | {q[2] for q in queries})
    ys = sorted({p[1] for p in points} | {q[1] for q in queries} | {q[3] for q in queries})

    x_to_i = {x: i + 1 for i, x in enumerate(xs)}
    y_to_i = {y: i + 1 for i, y in enumerate(ys)}

    # 建数组
    W, H = len(xs) + 2, len(ys) + 2
    grid = [[0] * W for _ in range(H)]

    for x, y in points:
        grid[y_to_i[y]][x_to_i[x]] += 1

    # 二维前缀和
    for i in range(1, H):
        for j in range(1, W):
            grid[i][j] += grid[i - 1][j] + grid[i][j - 1] - grid[i - 1][j - 1]

    # 查询
    res = []
    for x1, y1, x2, y2 in queries:
        i1, i2 = y_to_i[y1], y_to_i[y2]
        j1, j2 = x_to_i[x1], x_to_i[x2]
        res.append(grid[i2][j2] - grid[i1 - 1][j2] - grid[i2][j1 - 1] + grid[i1 - 1][j1 - 1])

    return res
```

**复杂度**: $O((n + q) \log(n + q))$ 排序 + $O(n + q)$ 处理.

### 8.7.4 线段树应用

**题目**: 单点更新 + 区间查询最大/最小/和, 坐标范围大.

```python
class SegTree:
    """线段树 (基于离散化坐标)"""
    def __init__(self, coords):
        self.N = len(coords)
        self.tree = [0] * (4 * self.N)
        self.coords = coords  # 离散化坐标

    def update(self, idx, val, node=1, lo=0, hi=None):
        if hi is None: hi = self.N - 1
        if lo == hi:
            self.tree[node] += val
            return
        mid = (lo + hi) // 2
        if idx <= mid:
            self.update(idx, val, node * 2, lo, mid)
        else:
            self.update(idx, val, node * 2 + 1, mid + 1, hi)
        self.tree[node] = self.tree[node * 2] + self.tree[node * 2 + 1]

    def query(self, l, r, node=1, lo=0, hi=None):
        if hi is None: hi = self.N - 1
        if r < lo or hi < l:
            return 0
        if l <= lo and hi <= r:
            return self.tree[node]
        mid = (lo + hi) // 2
        return (self.query(l, r, node * 2, lo, mid) +
                self.query(l, r, node * 2 + 1, mid + 1, hi))
```

## 8.8 尺取法的常见陷阱 (Common Pitfalls)

### 陷阱 1: 边界 off-by-one

```python
# 错误: left 从 0 开始但 right 从 1 开始
left = 0
for right in range(1, n):  # ← 这里
    while condition:
        left += 1
# 结果: 访问 nums[right] 时第一个元素被跳过

# 正确: 都从 0 开始, 或都对齐
left = 0
for right in range(n):
    while condition:
        left += 1
```

### 陷阱 2: 死循环

```python
# 错误: while 循环条件不变
while left < right:
    cur = sum(nums[left:right + 1])
    if cur < target:
        right += 1  # ← 如果 right 已经到 n, 这里还会 +1, 导致越界
    else:
        left += 1

# 正确: 加边界检查
while left < right:
    cur = sum(nums[left:right + 1])
    if cur < target and right < n - 1:
        right += 1
    else:
        left += 1
```

### 陷阱 3: 状态没及时更新

```python
# 错误: 加入右端后没有更新状态
for right, x in enumerate(nums):
    # 没把 x 加入状态!
    while condition:
        remove(arr[left])
        left += 1

# 正确: 先 add 再 while
for right, x in enumerate(nums):
    add(x)  # ← 必须
    while condition:
        ...
```

### 陷阱 4: 忘了重置/恢复状态

```python
# 错误: 在子函数里修改了状态但忘了恢复
def helper(...):
    backup = state
    modify(state)
    recurse(...)
    # 忘了 restore state
    # 后续操作基于错误的状态
```

```python
def minOperations(nums, x):
    """转化为找和 = total - x 的最长子数组"""
    target = sum(nums) - x
    n = len(nums)

        return -1
    if target == 0:
        return n

    left = 0
    cur = 0
    max_len = -1
    for right, x in enumerate(nums):
        cur += x
        while cur > target and left <= right:
            cur -= nums[left]
            left += 1
```

```python
def maxFrequency(nums, k):
    nums.sort()

    left = 0
    cur_ops = 0
    best = 1
    for right in range(n):
        # 把 nums[left..right-1] 全部提到 nums[right] 需要的操作数
        cur_ops += (right - left) * (nums[right] - nums[right - 1] if right > 0 else 0)
        while cur_ops > k:

            cur_ops -= nums[right] - nums[left]
            left += 1
        best = max(best, right - left + 1)
```

### LC 480 - 滑动窗口中位数 (Hard, 红黑树)
**题目**: 给数组和 k, 返回每个大小为 k 的滑动窗口中位数.

**解法**: 延迟删除 + 双堆.
```python
from heapq import heappush, heappop

def medianSlidingWindow(nums, k):
    """
    两个堆: max_heap (较小一半) + min_heap (较大一半)
    延迟删除: 用 counter 记录被滑出但仍在堆中的元素个数
    """
    import collections
    max_heap = []  # 存 -x 模拟最大堆
    min_heap = []
    delayed = collections.Counter()

    def prune(heap):
        """清理堆顶已删除元素"""
        while heap:
            num = -heap[0] if heap is max_heap else heap[0]
            if delayed[num]:
                delayed[num] -= 1
                heappop(heap)
            else:
                break

    for i in range(k):
        num = nums[i]
        if not max_heap or num <= -max_heap[0]:
            heappush(max_heap, -num)
        else:
            heappush(min_heap, num)
        # 平衡
        if len(max_heap) > len(min_heap) + 1:
            heappush(min_heap, -heappop(max_heap))
        elif len(min_heap) > len(max_heap):
            heappush(max_heap, -heappop(min_heap))

    res = []
    res.append((-max_heap[0] if k % 2 else (-max_heap[0] + min_heap[0]) / 2))

    for i in range(k, len(nums)):
        out_num, in_num = nums[i - k], nums[i]
        # 判断 out_num 在哪个堆
        if out_num <= -max_heap[0]:
            # 在 max_heap 中
            pass  # 通过 delayed 标记
        delayed[out_num] += 1

        # 加入新元素
        if in_num <= -max_heap[0]:
            heappush(max_heap, -in_num)
        else:
            heappush(min_heap, in_num)

        # 平衡
        if len(max_heap) > len(min_heap) + 1:
            heappush(min_heap, -heappop(max_heap))
        elif len(min_heap) > len(max_heap):
            heappush(max_heap, -heappop(min_heap))

        # 清理过期
        prune(max_heap)
        prune(min_heap)

        # 记录中位数
        res.append((-max_heap[0] if k % 2 else (-max_heap[0] + min_heap[0]) / 2))

    return res
```

**复杂度**: $O(n \log k)$.

**多解法对比**:

| 解法 | 时间 | 空间 | 说明 |
|---|---|---|---|
| **双堆 + 延迟删除** | $O(n \log k)$ | $O(k)$ | 推荐 |
| 双 multiset | $O(n \log k)$ | $O(k)$ | C++ 友好, Python 慢 |
| 排序 | $O(n k \log k)$ | $O(k)$ | 超时 |

### LC 862 - 和至少为 K 的最短子数组 (Hard, 前缀和 + 单调队列)
**题目**: 找最短子数组使其和 ≥ K. 数组可能含负数!

```python
def shortestSubarray(nums, k):
    """前缀和 + 单调递增队列"""
    n = len(nums)
    pref = [0] * (n + 1)
    for i in range(n):
        pref[i + 1] = pref[i] + nums[i]

    from collections import deque
    dq = deque([0])  # 存前缀和的下标, 单调递增
    res = n + 1

    for i in range(1, n + 1):
        # 找 dq 中 pref[dq[0]] <= pref[i] - k 的最早位置
        while dq and pref[i] - pref[dq[0]] >= k:
            res = min(res, i - dq[0])
            dq.popleft()
        # 维护单调性: 弹出比 pref[i] 大的 (它们不可能更优)
        while dq and pref[i] <= pref[dq[-1]]:
            dq.pop()
        dq.append(i)

    return res if res <= n else -1
```

**复杂度**: $O(n)$.

### LC 1438 - 绝对差不超过限制的最长连续子数组
**题目**: 子数组最大最小值差 ≤ limit. 找最长.

```python
def longestSubarray(nums, limit):
    """滑动窗口 + 单调队列"""
    from collections import deque
    max_dq = deque()  # 单调递减, 存 nums 下标
    min_dq = deque()  # 单调递增
    left = 0
    best = 0

    for right, x in enumerate(nums):
        # 维护 max_dq
        while max_dq and nums[max_dq[-1]] < x:
            max_dq.pop()
        max_dq.append(right)
        # 维护 min_dq
        while min_dq and nums[min_dq[-1]] > x:
            min_dq.pop()
        min_dq.append(right)

        # 收缩
        while nums[max_dq[0]] - nums[min_dq[0]] > limit:
            left += 1
            if max_dq[0] < left:
                max_dq.popleft()
            if min_dq[0] < left:
                min_dq.popleft()

        best = max(best, right - left + 1)

    return best
```

**复杂度**: $O(n)$.

## 11. 尺取法与"前缀和"的对比

## 11.1 何时用尺取法 vs 前缀和?

| 场景 | 尺取法 | 前缀和 |
|---|---|---|
| 数组元素均为正数 | ✅ 完美 | ✅ 完美 |
| 含负数 | ❌ 不能用 | ✅ 可以 |
| 元素任意 | ❌ | ✅ 必须 |
| 条件: 和满足某值 | ✅ | ✅ |
| 条件: 计数/种类 | ✅ | ❌ |
| 条件: 极值 | ✅ (用单调队列) | ❌ |

**结论**:
- **无负数 + 计数条件**: 尺取法更快.
- **含负数 + 和条件**: 前缀和 + 单调队列.
- **任意条件**: 看具体问题.

## 11.2 前缀和 + 滑窗结合: LeetCode 862

```python
# 同时使用: 前缀和转换 + 单调队列
def shortestSubarray(nums, k):
    pref = [0]
    for x in nums:
        pref.append(pref[-1] + x)

    from collections import deque
    dq = deque()
    res = float('inf')

    for i, p in enumerate(pref):
        while dq and p - pref[dq[0]] >= k:
            res = min(res, i - dq.popleft())
        while dq and p <= pref[dq[-1]]:
            dq.pop()
        dq.append(i)

    return res if res != float('inf') else -1
```

## 12. 折半枚举的更多应用

## 12.1 经典: $n = 40$ 的子集和

**问题**: 给 $n \leq 40$ 个数, 找是否存在子集和 = S.

**思路**: $2^{40}$ 太大, 拆成两半 $2^{20} \approx 10^6$, 分别枚举, 然后在哈希表中查.

```python
def has_subset_sum(nums, S):
    n = len(nums)
    half = n // 2

    # 前半所有子集和
    left_sums = set()
    for mask in range(1 << half):
        s = 0
        for i in range(half):
            if mask & (1 << i):
                s += nums[i]
        left_sums.add(s)

    # 后半: 找 S - x 是否在 left_sums
    for mask in range(1 << (n - half)):
        s = 0
        for i in range(n - half):
            if mask & (1 << i):
                s += nums[half + i]
        if S - s in left_sums:
            return True

    return False
```

**复杂度**: $O(2^{n/2} \cdot n)$ (生成子集和), 空间 $O(2^{n/2})$.

## 12.2 推广: $n = 50$ 的问题

当 $n \leq 50$, $2^{n/2} \approx 2^{25} \approx 3 \times 10^7$, 仍可行.

但要注意常数优化:
- 用 list 代替 set (因为有重复值).
- 二分查找代替哈希.

## 12.3 不只是子集和: $k$ 子集和

**问题**: 给数组, 找 $k$ 个不相交子集使它们的和最接近 S.

**思路**: 折半 + 优先级合并.

## 13. 实战模拟面试 (Mock Interview)

## 13.1 题目 1: 长度最小的子数组 (LC 209)

**面试官**: 给你一个正整数数组 nums 和一个正整数 target. 找出**和 ≥ target** 的最短连续子数组长度.

**思考路径**:
1. 看到"最短连续子数组" → 滑动窗口.
2. 元素都是正数 → 窗口内和是单调的 → 可以滑窗.
3. 满足条件收缩左端 → 模板直接套.

**代码** (8 分钟):
```python
def minSubArrayLen(target, nums):
    left = 0
    cur = 0
    best = float('inf')
    for right, x in enumerate(nums):
        cur += x
        while cur >= target:
            best = min(best, right - left + 1)
            cur -= nums[left]
            left += 1
    return 0 if best == float('inf') else best
```

**复杂度分析**: 每个元素最多被 right 加 1 次, 被 left 减 1 次, 总 $O(n)$ 时间 $O(1)$ 空间.

**追问 1**: 如果含负数怎么办?
- **回答**: 滑窗失效. 改用前缀和 + 单调队列 (LC 862).

**追问 2**: 如果是二维数组找最小子矩阵呢?
- **回答**: 固定上下边界 + 滑窗. $O(n^3)$ 时间.

## 13.2 题目 2: 滑动窗口最大值 (LC 239)

**面试官**: 给数组和 k, 返回每个大小为 k 的滑动窗口的最大值.

**思考路径**:
1. 固定大小窗口 → 维护窗口极值.
2. 暴力 $O(nk)$ → 超时.
3. 单调队列 $O(n)$ → 标准解法.

**代码** (15 分钟):
```python
from collections import deque

def maxSlidingWindow(nums, k):
    dq = deque()
    res = []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] < x:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            res.append(nums[dq[0]])
    return res
```

**复杂度**: $O(n)$ 时间, $O(k)$ 空间.

**追问**: 为什么单调队列是 $O(n)$?
- **回答**: 每个元素最多入队 1 次出队 1 次, 总操作 $2n$.

## 13.3 题目 3: K 连续位的最小翻转次数 (LC 995)

**面试官**: 给二进制数组和 k, 每次反转连续 k 个元素. 求最少操作数让所有元素相同. 不能则返回 -1.

**思考路径**:
1. "反转" + "区间" → 差分数组 / 标记.
2. 贪心: 从左到右, 遇 0 必翻.
3. 用 set 或异或差分维护当前累积翻转.

**代码** (20 分钟):
```python
def minKBitFlips(nums, k):
    n = len(nums)
    diff = [0] * (n + 1)
    flipped = 0
    res = 0
    for i in range(n):
        flipped ^= diff[i]
        if nums[i] ^ flipped == 0:
            if i + k > n:
                return -1
            res += 1
            flipped ^= 1
            diff[i + k] ^= 1
    return res
```

**追问**: 为什么贪心是正确的?
- **回答**: 假设 nums[i] 经过前面翻转后是 0, 那么 i 必须由 [i, i+k-1] 区间的翻转覆盖 (前面区间已过去), 所以贪心是唯一选择.

## 14. 总结: 尺取法的"信号-槽位"模型

把所有尺取法题抽象成一个统一的**信号-槽位**模型:

```text
input stream ──→ [add signal] ──→ [slot state] ──→ [check valid?] ──→ [shrink]
                       │                                  │                    │
                       ▼                                  ▼                    ▼
                  累计统计                          yes ─→ 记录答案        pop signal
                                                  no ────────────────────────▶
```

**核心循环**:
```python
left = 0
state = init()
for right, x in enumerate(arr):
    add(state, x)               # 1. 加入新信号
    while not valid(state):     # 2. 状态违反约束, 收缩
        remove(state, arr[left])
        left += 1
    record(state, left, right)  # 3. 记录答案
```

**4 个核心问题**:
1. `init(state)`: 初始状态是什么?
2. `add(state, x)`: 加入右端如何更新状态?
3. `remove(state, x)`: 移除左端如何更新状态?
4. `valid(state)`: 状态满足约束吗?

只要回答了这 4 个问题, 尺取法就写完了.

对 "尺取法 (Two Pointers / Sliding Window 进阶)" 常见的误解包括:

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。

**7. 实践建议**

结合 "尺取法 (Two Pointers / Sliding Window 进阶)" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "尺取法 (Two Pointers / Sliding Window 进阶)" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
