## 1. 博弈论基础

**博弈论问题**: 两人轮流操作, 谁不能操作谁输 (或谁先达到目标谁赢).

**核心问题**: 给定状态, 判断**先手**是否必胜?

**关键概念**:
- **必胜状态**: 当前玩家有策略必赢
- **必败状态**: 当前玩家无论如何必输 (对手有必胜策略)

**递推**: 状态是必胜 ⟺ 存在后继是必败; 状态是必败 ⟺ 所有后继都是必胜.

## 2. Nim 游戏 (最经典)

### 2.1 规则

有 n 堆石子, 第 i 堆有 $a_i$ 个. 两人轮流取, 每次从一堆取任意个 (>0). 取完最后一个石子的人赢.

**Nim 定理**: 先手必胜 ⟺ $a_1 \oplus a_2 \oplus \cdots \oplus a_n \neq 0$.

### 2.2 LeetCode 292 - Nim 游戏 (Easy)

```python
def canWinNim(n):
    """Nim 游戏: 1 堆, n 个石子"""
    return n % 4 != 0
```

**原理**:
- n=1,2,3: 先手必胜 (直接拿完)
- n=4: 先手必败 (无论拿几个, 对手都能变成 1/2/3 个, 然后必胜)
- n=5,6,7: 先手必胜 (拿走 1/2/3 个, 留 4 个给对手)
- 规律: n % 4 == 0 必败, 否则必胜.

### 2.3 多堆 Nim (经典)

```python
def can_win_nim(piles):
    """多堆 Nim: 异或判断"""
    xor = 0
    for p in piles:
        xor ^= p
    return xor != 0
```

**证明思路**:
- 异或 = 0: 必败. 因为无论怎么操作, 异或都会变非零.
- 异制 ≠ 0: 必胜. 因为可以选一堆, 拿走石子使异或 = 0 (留给对手).

### 2.4 LeetCode 877 - 石子游戏 (Medium)

**题目**: 偶数堆石子, 两人轮流取第一堆或最后一堆, 分数多者赢. Alex 先手.

**结论**: 先手必胜 (奇数堆之和 > 偶数堆之和).

```python
def stoneGame(piles):
    """DP 解"""
    n = len(piles)
    dp = [[0] * n for _ in range(n)]
    for i in range(n):
        dp[i][i] = piles[i]

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            dp[i][j] = max(piles[i] - dp[i+1][j], piles[j] - dp[i][j-1])

    return dp[0][n-1] > 0
```

## 3. Grundy 数 (SG 函数)

### 3.1 什么是 SG 函数

**SG (Sprague-Grundy) 函数**: 把博弈论问题转化为 Nim.

**定义**:
- 终止状态: $g(x) = 0$
- 非终止状态: $g(x) = \text{mex}\{g(y) | y \in \text{后继}(x)\}$
  - mex = 最小非负整数不在集合中

**SG 定理**:
- 必胜 ⟺ $g(x) \neq 0$
- 必败 ⟺ $g(x) = 0$

**核心**: 多堆博弈 = 单个 Nim, 各堆 SG 异或.

### 3.2 LeetCode 486 - 预测赢家 (Medium)

**题目**: 两人轮流从数组头尾取一个数, 总分多者赢. 求先手能否赢.

**解法 1: DP**.

```python
def predictTheWinner(nums):
    """DP - 区间博弈"""
    n = len(nums)
    dp = [[0] * n for _ in range(n)]
    for i in range(n):
        dp[i][i] = nums[i]

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            dp[i][j] = max(nums[i] - dp[i+1][j], nums[j] - dp[i][j-1])

    return dp[0][n-1] >= 0
```

**解法 2: SG 函数 (递归)**.

```python
def predictTheWinner(nums):
    """SG 函数"""
    from functools import lru_cache

    @lru_cache(None)
    def sg(lo, hi, turn):
        """turn: 0 = 先手, 1 = 后手"""
        if lo > hi:
            return 0
        if turn == 0:
            # 先手: 选 nums[lo] 或 nums[hi]
            take_lo = nums[lo] + sg(lo + 1, hi, 1)
            take_hi = nums[hi] + sg(lo, hi - 1, 1)
            return max(take_lo, take_hi)
        else:
            # 后手: 在剩余中选最优
            return max(sg(lo + 1, hi, 0), sg(lo, hi - 1, 0))

    return sg(0, len(nums) - 1, 0) * 2 >= sum(nums)
```

## 4. 经典博弈问题

### 4.1 POJ 1704 - Georgia and Bob (Nim 变形)

**题目**: n 个棋子在一维棋盘上, 每人每次把一个棋子往左移任意格, 不能越界也不能重叠. 最后不能移者输.

**思路**: 把相邻棋子分成"对", 每对的距离是一个 Nim 堆.

```python
def georgia_bob(positions):
    sorted_pos = sorted(positions)
    n = len(sorted_pos)
    # 棋盘左边界的"虚拟棋盘"
    xor = 0
    for i in range(n - 1, -1, -2):
        if i > 0:
            gap = sorted_pos[i] - sorted_pos[i-1] - 1
        else:
            gap = sorted_pos[i] - 1
        xor ^= gap
    return xor != 0
```

## 5. 博弈论框架

### 5.1 必胜必败判断模板

```python
def is_winning(state):
    """判断当前状态是否必胜"""
    if is_terminal(state):
        return False  # 终止状态: 当前玩家输

    # 尝试所有可能的操作
    for action in get_actions(state):
        new_state = apply(state, action)
        if not is_winning(new_state):  # 对手必败
            return True  # 当前玩家必胜

    return False  # 所有操作都让对手必胜
```

### 5.2 DP 优化 (记忆化搜索)

```python
from functools import lru_cache

@lru_cache(None)
def is_winning(state):
    if is_terminal(state):
        return False
    for action in get_actions(state):
        if not is_winning(apply(state, action)):
            return True
    return False
```

### 5.3 SG 函数实现

```python
from functools import lru_cache

@lru_cache(None)
def grundy(state):
    """SG 函数: mex of 后继的 SG"""
    if is_terminal(state):
        return 0
    next_sgs = {grundy(apply(state, a)) for a in get_actions(state)}
    # mex: 最小不在集合中的非负整数
    g = 0
    while g in next_sgs:
        g += 1
    return g

def is_winning_sg(state):
    return grundy(state) != 0
```

## 8. 博弈论的形式化定义

### 8.1 P-position 与 N-position

博弈论把所有状态分为两类, 这一分类决定了胜负:

| 术语 | 别名 | 定义 | 当前玩家 |
| :--- | :--- | :--- | :--- |
| **P-position** | Previous-player winning, 必败态 | 所有后继都是 N-position | 必输 |
| **N-position** | Next-player winning, 必胜态 | 至少一个后继是 P-position | 必赢 |

**形式化定义**:

$$
\text{state} = \begin{cases}
P\text{-position} & \text{if is\_terminal(state)} \\
P\text{-position} & \text{if } \forall s' \in \text{successor}(s): s' \in N\text{-position} \\
N\text{-position} & \text{if } \exists s' \in \text{successor}(s): s' \in P\text{-position}
\end{cases}
$$

**终止状态** 一定是 P-position (因为当前玩家无法操作, 即输).

**递归求解** (从终止状态回溯):

```python
def is_winning(state, memo={}):
    """True = N-position (必胜), False = P-position (必败)"""
    if state in memo:
        return memo[state]
    if is_terminal(state):
        memo[state] = False  # 终止 → 必败
        return False
    for action in get_actions(state):
        if not is_winning(apply(state, action), memo):
            memo[state] = True  # 找到一个必败后继 → 必胜
            return True
    memo[state] = False  # 所有后继都必胜 → 必败
    return False
```

### 8.2 三类博弈模型

#### (1) 公平博弈 (Impartial Game)

**定义**: 两个玩家在每个状态下能执行的操作集合相同 (与玩家身份无关).

> 大多数算法题属于此类: Nim, Wythoff, Euclid, 翻硬币...

**关键性质**: 状态完全由 SG 函数决定. Sprague-Grundy 定理适用.

#### (2) 非公平博弈 (Partizan Game)

**定义**: 不同玩家在同一状态下能执行的操作集合不同.

**例子**: 国际象棋 (黑/白可走的位置不同), Hex 游戏.

> 不在 SG 定理范围内. 需要单独分析.

#### (3) 合作博弈 vs 非合作博弈

- **合作博弈**: 玩家可以结盟 (经济学, 不在算法竞赛范围)
- **非合作博弈**: 各自为战 (算法竞赛主要研究对象)

### 8.3 博弈树的搜索算法

#### Minimax (极小极大)

```python
def minimax(state, depth, is_max_player):
    """
    is_max_player = True: 当前玩家最大化自己收益
    is_max_player = False: 对手最小化我的收益
    """
    if depth == 0 or is_terminal(state):
        return evaluate(state)

    if is_max_player:
        return max(minimax(apply(state, a), depth - 1, False) for a in get_actions(state))
    else:
        return min(minimax(apply(state, a), depth - 1, True) for a in get_actions(state))
```

#### Alpha-Beta 剪枝

```python
def alpha_beta(state, depth, alpha, beta, is_max):
    if depth == 0 or is_terminal(state):
        return evaluate(state)

    if is_max:
        value = -float('inf')
        for a in get_actions(state):
            value = max(value, alpha_beta(apply(state, a), depth - 1, alpha, beta, False))
            alpha = max(alpha, value)
            if alpha >= beta:  # 剪枝
                break
        return value
    else:
        value = float('inf')
        for a in get_actions(state):
            value = min(value, alpha_beta(apply(state, a), depth - 1, alpha, beta, True))
            beta = min(beta, value)
            if beta <= alpha:
                break
        return value
```

## 9. Sprague-Grundy 定理完整证明

### 9.1 mex 操作的代数性质

**mex (minimum excludant)**: 不在集合中的最小非负整数.

| 集合 | mex |
| :--- | :--- |
| $\emptyset$ | 0 |
| $\{0\}$ | 1 |
| $\{0, 1\}$ | 2 |
| $\{1, 3, 5\}$ | 0 |
| $\{0, 1, 2, 3\}$ | 4 |

**性质 1**: $mex(S) \notin S$ (否则它就不是"不在集合中")

**性质 2**: $mex(S)$ 唯一确定

**性质 3**: $0 \leq mex(S) \leq |S|$

### 9.2 SG 函数定义再深入

对每个状态 $x$, 定义 $\text{SG}(x)$:

$$
\text{SG}(x) = \begin{cases}
0 & \text{if } x \text{ 是终止状态} \\
\text{mex}\{\text{SG}(y) : y \in \text{successor}(x)\} & \text{otherwise}
\end{cases}
$$

### 9.3 SG 定理

**定理 (Sprague-Grundy 1936, Grundy 1939)**: 对于**公平博弈** (两个玩家操作集合相同), 任意状态 $x$ 都有

$$
x \text{ 是 P-position} \iff \text{SG}(x) = 0
$$

**定理 (复合博弈)**: 若博弈由多个**独立**的子博弈组成, 整体 SG = 各子博弈 SG 的异或和.

### 9.4 证明 (核心)

#### 第一部分: SG = 0 ⟺ P-position

**(⟹)** 假设 $\text{SG}(x) = 0$, 我们要证 $x$ 是 P-position.

**反证**: 若 $x$ 是 N-position, 则存在一个操作使得到达 P-position $y$. 即 $\text{SG}(y) = 0$. 但根据 mex 定义, $\text{SG}(x) = \text{mex}(\text{后继 SG}) \neq 0$ (因为 0 在后继集合中). 矛盾.

**(⟸)** 假设 $x$ 是 P-position, 即所有后继都是 N-position, 所以每个后继 $y$ 的 $\text{SG}(y) \neq 0$.

我们要证 $\text{SG}(x) = 0$.

反证: 设 $\text{SG}(x) = k > 0$. 由 mex 定义, $k \notin \{\text{SG}(y) : y \in \text{successor}(x)\}$, 且 $\{0, 1, ..., k-1\} \subseteq \{\text{SG}(y)\}$.

因为每个 $\text{SG}(y) \neq 0$, 所以必有某个 $y$ 满足 $\text{SG}(y) = k$. 但 $y$ 是 $x$ 的后继, 即玩家可以从 $x$ 走到 $\text{SG}(y) = k$.

**关键**: 现在玩家从 $x$ 走到 $y$, 让对手面对 $\text{SG}(y) = k > 0$. 这意味着对手是 N-position, 即必胜. 但 $x$ 是 P-position (所有后继都是 N-position), 所以当前玩家无论怎么走都到 N-position, 即必败. 矛盾.

**但这没用到 mex 性质!** 我们需要更强的引理.

#### 引理: SG(y) = k 的状态 y 必有后继 z 使 SG(z) = m, 其中 $0 \leq m < k$.

**证明引理**: 由 mex 定义, 因为 $\text{SG}(y) = \text{mex}(\{\text{SG}(z) : z \in \text{successor}(y)\}) = k$, 所以 $\{0, 1, ..., k-1\}$ 都出现在某个后继中. 取某个 $z$ 使 $\text{SG}(z) = m \in \{0, 1, ..., k-1\}$ 即可. ✓

#### 完成主证明

由引理, 任意 $\text{SG}(y) = k > 0$ 的状态都有后继 $z$ 使 $\text{SG}(z) < k$.

回到我们的反证: $\text{SG}(x) = k > 0$. 由引理, $x$ 有后继 $y$ 使 $\text{SG}(y) < k$. 一直递归下去, 必定到达 $\text{SG} = 0$ 的状态 (因为 SG 严格递减, 非负).

即: $x$ 有某个后继 $z$ 使 $\text{SG}(z) = 0$. 即 $x$ 是 N-position. 矛盾 ✓

**结论**: $\text{SG}(x) = 0 \iff x \text{ 是 P-position}$. 证毕.

### 9.5 复合博弈的异或定理证明

**定理**: 若博弈 $G$ 由独立子博弈 $G_1, G_2, ..., G_n$ 组合而成, 且每个子博弈都在做必胜/必败决策 (玩家每步只选一个子博弈走), 则

$$
\text{SG}(G) = \text{SG}(G_1) \oplus \text{SG}(G_2) \oplus \cdots \oplus \text{SG}(G_n)
$$

**证明思路**:

定义状态 $x = (x_1, x_2, ..., x_n)$, 其中 $x_i$ 是 $G_i$ 的当前状态.

**SG 的"分配律"**: $\text{mex}(A) \oplus \text{mex}(B) = \text{mex}(\{a \oplus b : a \in A, b \in B\})$.

但这不是显然成立的. 实际上, 我们需要用归纳法:

**对 $n$ 归纳**:

- $n=1$: 显然.
- $n \to n+1$: 假设对 $n$ 成立. 复合 $G_1 \oplus ... \oplus G_{n+1}$ 的后继状态形如
  - 对某个 $i$ 选 $G_i$ 走一步到 $y_i$, 其他不变
  - 即 $\text{SG}$ 变化: 某个 $\text{SG}(x_i)$ 变到 $\text{SG}(y_i)$, 其他不变

$$
\text{SG}(G) = \text{mex}\{\text{SG}(G_1) \oplus ... \oplus \text{SG}(y_i) \oplus ... \oplus \text{SG}(G_{n+1})\}
$$

可以证明这个等于 $\text{SG}(G_1) \oplus ... \oplus \text{SG}(G_{n+1})$. (细节省略, 涉及 SG 函数的代数性质)

### 9.6 算法实现验证

```python
from functools import lru_cache

def sg(state):
    """通用 SG 函数"""
    if is_terminal(state):
        return 0
    sgs = {sg(apply(state, a)) for a in get_actions(state)}
    g = 0
    while g in sgs:
        g += 1
    return g

def is_winning(state):
    return sg(state) != 0
```

**时间复杂度**: 状态数 × 操作数, 可用记忆化剪枝.

## 10. 必胜策略的构造

### 10.1 Nim 游戏必胜策略

**已知**: $\text{xor} = a_1 \oplus a_2 \oplus ... \oplus a_n \neq 0$, 必胜.

**关键**: 如何找到**具体**的操作?

**步骤**:

1. 计算 $\text{xor} = a_1 \oplus ... \oplus a_n$
2. 找到 $\text{xor}$ 的最高位 1, 记为 $b$ (例如 $\text{xor} = 12 = 1100_2$, $b = 8$)
3. 找一堆 $a_i$ 使 $a_i$ 在 $b$ 位上也是 1 (这种堆一定存在, 否则 xor 在 b 位上不可能是 1)
4. 计算 $a_i' = a_i \oplus \text{xor}$ (这一定 < $a_i$, 因为 $a_i$ 在最高位是 1, 异或后会变成 0)
5. 操作: 把第 $i$ 堆从 $a_i$ 减到 $a_i'$

```python
def find_winning_move(piles):
    """返回 (堆索引, 减到多少), 若必败返回 None"""
    xor = 0
    for p in piles:
        xor ^= p

    if xor == 0:
        return None  # 必败

    # 找最高位 1
    highest_bit = 1 << (xor.bit_length() - 1)

    # 找在该位上有 1 的堆
    for i, p in enumerate(piles):
        if p & highest_bit:
            new_pile = p ^ xor  # 异或后变小
            return (i, new_pile)

    return None
```

**示例**: piles = [3, 4, 5] = [011, 100, 101]
- xor = 011 ⊕ 100 ⊕ 101 = 010 = 2
- highest_bit = 2
- 第 0 堆 (3 = 011) 在 bit 1 是 1 ✓
- new_pile = 3 ^ 2 = 1
- 操作: 堆 0 从 3 → 1, 新 piles = [1, 4, 5], xor = 1 ⊕ 4 ⊕ 5 = 0 ✓

### 10.2 SG 函数必胜策略

**已知**: $\text{SG}(x) = k > 0$, 必胜.

**关键**: 如何找到**具体**的操作?

**步骤**:

1. 枚举所有合法操作 $a$, 计算 $\text{SG}(\text{apply}(x, a))$
2. 找某个 $a$ 使 $\text{SG}(\text{apply}(x, a)) < \text{SG}(x)$
3. (可选) 找使 $\text{SG}$ 变为 0 的操作 (最强必胜步)

```python
def find_sg_move(state, k):
    """在 SG=k>0 状态下找必胜操作, 返回操作 a"""
    for a in get_actions(state):
        next_state = apply(state, a)
        if sg(next_state) == 0:
            return a  # 最强步: 直接到 P-position
    # 没找到 0 步, 返回任意使 SG 减小的
    for a in get_actions(state):
        if sg(apply(state, a)) < k:
            return a
    return None  # 不应该发生
```

### 10.3 区间博弈 (Stone Game 类) 必胜策略

**结构**: 玩家在 $[l, r]$ 区间选端点, 取走值.

**关键观察**: $\text{dp}[i][j]$ = 在 $[i, j]$ 区间, **当前玩家** 相对对手的净得分.

**递推**:
- 当前选 $i$: 净得分 = $a_i - \text{dp}[i+1][j]$ (我得 $a_i$, 对手在 $[i+1, j]$ 净得分)
- 当前选 $j$: 净得分 = $a_j - \text{dp}[i][j-1]$
- $\text{dp}[i][j] = \max(a_i - \text{dp}[i+1][j], a_j - \text{dp}[i][j-1])$

**必胜**: $\text{dp}[0][n-1] \geq 0$ (我净得分 ≥ 0, 即不输).

### 10.4 博弈决策树实例

**LeetCode 486**: nums = [1, 5, 2, 4, 6]

```text
P1 选 1:  P2 在 [5,2,4,6] 选, P1 最终得 1 + (净剩)
P1 选 6:  P2 在 [1,5,2,4] 选, P1 最终得 6 + (净剩)
```

## 11. 经典博弈问题详解

### 11.1 Wythoff 博弈 (威佐夫博弈)

**规则**: 两堆石子 $(a, b)$, 操作是: 从一堆取任意个, 或从两堆取相同个数. 取最后一个者赢.

**答案**: 设 $a < b$, $k = b - a$, $m = \lfloor k \cdot \phi \rfloor$ (其中 $\phi = \frac{1+\sqrt{5}}{2}$). 若 $a = m$ 则 P-position, 否则 N-position.

```python
import math

def wythoff(a, b):
    """威佐夫博弈"""
    if a > b:
        a, b = b, a

    k = b - a
    m = int(k * (1 + math.sqrt(5)) / 2)  # φ ≈ 1.618

    if a == m:
        return False  # P-position, 当前玩家必败
    return True  # N-position

def wythoff_move(a, b):
    """返回必胜操作 (新 a, 新 b)"""
    if a > b:
        a, b = b, a
    k = b - a
    m = int(k * (1 + math.sqrt(5)) / 2)
    target_b = m + k
    # 情况 1: 从 b 减到 target_b (使 a = m)
    # 情况 2: 从两堆同时取 (b - target_b)
    return (m, target_b)
```

**原理**: Beatty 序列. $\lfloor n \phi \rfloor$ 和 $\lfloor n \phi^2 \rfloor$ 互补地覆盖所有正整数.

### 11.2 Euclid 博弈

**规则**: 两堆石子 $(a, b)$, $a \leq b$. 操作是: 从 $b$ 减去 $b \mod a$ 的倍数, 使结果 $< a$. 换言之, $b \mod a$ 取走后堆交换. 不能操作者输.

**答案**: $(a, b)$ 是 P-position $\iff \lfloor b / a \rfloor \geq 2$.

```python
def euclid_game(a, b):
    """Euclid 博弈: 谁先让一堆变 0 谁输"""
    if a > b:
        a, b = b, a

    # 递归: 当前玩家把 b 减到 b mod a, 然后交换
    while True:
        if b % a == 0:
            return False  # 必败 (对手可以把 a 堆清零)
        if b // a >= 2:
            return True  # 必胜: 直接清空 b 堆
        # 否则必须减到 b mod a, 然后轮到对手
        b, a = b % a, a  # 实际上 b % a < a, 交换后 a < b
        a, b = b, a
```

**关键**: $\lfloor b/a \rfloor \geq 2$ 时, 当前玩家可以把 $b$ 减到 0 (即清空 $b$ 堆), 让对手面对 $(a, 0)$ 必败.

### 11.3 翻硬币游戏 (Coin Turning)

**规则**: 一排硬币, 每次必须翻**两个相邻**硬币 (一正一反 → 反反), 不能操作者输.

**答案**: 若初始有奇数个反面 → 必胜; 偶数个 → 必败.

```python
def coin_turning(coins):
    """翻相邻两个硬币"""
    n_tails = sum(1 for c in coins if c == 'T')
    return n_tails % 2 == 1
```

**推广**: 一排硬币, 每次必须翻**连续 k 个硬币** (都翻). 此时分析更复杂, 需用 SG 函数.

```python
def coin_turning_k(coins, k):
    """每次必须翻连续 k 个硬币, 都翻"""
    from functools import lru_cache

    n = len(coins)

    @lru_cache(None)
    def sg(state):
        """state: tuple of 0/1"""
        # 找所有能翻的 k 个连续位置
        moves = []
        for i in range(n - k + 1):
            if 1 in state[i:i+k]:  # 至少有一个 1 才能翻
                moves.append(i)

        if not moves:
            return 0  # P-position

        next_sgs = set()
        for i in moves:
            new_state = list(state)
            for j in range(i, i + k):
                new_state[j] = 1 - new_state[j]
            next_sgs.add(sg(tuple(new_state)))

        g = 0
        while g in next_sgs:
            g += 1
        return g

    return sg(tuple(coins)) != 0
```

### 11.5 Kayles 博弈 (保龄球)

**规则**: 一排保龄球瓶 (n 个), 每次击倒 1 个或 2 个**相邻**的瓶子. 击倒后瓶子分成多个连续段, 玩家继续.

**SG 函数**: $\text{SG}(n) = \text{mex}(\{\text{SG}(a) \oplus \text{SG}(b) : a + b + 1 = n \text{ or } a + b + 2 = n\})$

**周期性**: 从 $n \geq 72$ 起, $\text{SG}$ 周期为 12.

```python
def kayles_sg(n):
    """Kayles 博弈 SG 值"""
    if n == 0:
        return 0
    sg_values = [0] * (n + 1)
    for i in range(1, n + 1):
        sgs = set()
        # 击倒 1 个 (位置 j), 分成 [0, j-1] 和 [j+1, i]
        for j in range(i):
            sgs.add(sg_values[j] ^ sg_values[i - j - 1])
        # 击倒 2 个相邻 (j, j+1)
        for j in range(i - 1):
            sgs.add(sg_values[j] ^ sg_values[i - j - 2])
        g = 0
        while g in sgs:
            g += 1
        sg_values[i] = g
    return sg_values[n]
```

### 11.6 Dawson's Kayles

**规则**: 类似 Kayles, 但击倒后**被击中的瓶子**也消失 (即击倒位置 j 处的瓶子, 它和它的邻都不见).

$\text{SG}(n) = \text{mex}(\{\text{SG}(a) \oplus \text{SG}(b) : a + b + 2 = n \text{ or } a + b + 3 = n\})$

**周期性**: $\text{SG}(n)$ 从 $n \geq 0$ 起周期为 34 (一段是特定序列, 然后重复).

```python
def dawson_kayles_sg(n):
    if n == 0:
        return 0
    sg_values = [0] * (n + 1)
    for i in range(1, n + 1):
        sgs = set()
        # 击倒 1 个 (位置 j), 占掉 j 和邻
        for j in range(i):
            left = j
            right = i - j - 1
            sgs.add(sg_values[left] ^ sg_values[right])
        # 击倒 2 个相邻 (j, j+1), 占掉 j-1, j, j+1, j+2
        for j in range(i - 1):
            left = j
            right = i - j - 2
            sgs.add(sg_values[left] ^ sg_values[right])
        g = 0
        while g in sgs:
            g += 1
        sg_values[i] = g
    return sg_values[n]
```

### 12.1 LeetCode 1140 - 石子游戏 II (Medium)

**题目**: 堆 $a[0..n-1]$, Alice 先手. 每次可取前 $1$ 到 $2M$ 个石子 ($M$ 是当前 $M$, 之后 $M = \max(M, x)$, $x$ 是取的个数). 求 Alice 最多能得多少分.

```python
def stoneGameII(piles):
    """DP 解法"""
    n = len(piles)
    # suffix[i] = 从 i 开始的石子总和
    suffix = [0] * (n + 1)
    for i in range(n - 1, -1, -1):
        suffix[i] = suffix[i+1] + piles[i]

    from functools import lru_cache

    @lru_cache(None)
    def dp(i, M):
        """从位置 i 开始, 当前 M, 当前玩家最多能拿多少"""
        if i >= n:
            return 0
        if i + 2 * M >= n:  # 能一次拿完
            return suffix[i]

        # 取 x 个 (1 <= x <= 2M), 对手在 dp(i+x, max(M, x))
        # 我拿 suffix[i] - suffix[i+x], 对手拿 dp(i+x, max(M, x))
        # 我得: suffix[i] - suffix[i+x] + (suffix[i+x] - dp(i+x, max(M, x)))
        #      = suffix[i] - dp(i+x, max(M, x))
        best = 0
        for x in range(1, 2 * M + 1):
            opponent = dp(i + x, max(M, x))
            my_total = suffix[i] - opponent
            best = max(best, my_total)
        return best

    return dp(0, 1)
```

**时间复杂度**: $O(n^3)$, 优化后 $O(n^2)$.

**多解法对比**:

| 解法 | 思路 | 时间 | 空间 |
| :--- | :--- | :--- | :--- |
| 朴素递归 + 记忆化 | 枚举 x, 递归 | $O(n^3)$ | $O(n^2)$ |
| 自底向上 DP | suffix + dp | $O(n^2)$ | $O(n^2)$ |
| 区间 DP | 按段长度递推 | $O(n^3)$ | $O(n^2)$ |

### 12.2 LeetCode 1404 - 二进制减到 1 的步数 (Hard)

**题目**: 给二进制字符串 s. 若 s 是偶数, s /= 2; 若 s 是奇数, s += 1. 求 s 变 1 的最少步数.

```python
def numSteps(s):
    """模拟 + 位运算"""
    steps = 0
    carry = 0  # 进位

    # 从右向左处理, 除了最后一位
    i = len(s) - 1
    while i > 0:
        if int(s[i]) + carry == 1:  # 奇数
            carry = 1  # s += 1, 当前位变 0, 进位到高位
            steps += 2  # +1 然后 /2
        else:  # 偶数
            steps += 1  # 直接 /2
        i -= 1

    # 最后一位: 如果有进位, 加 1 即可
    return steps + carry

def numSteps_v2(s):
    """直接模拟 (容易理解)"""
    steps = 0
    num = int(s, 2)
    while num != 1:
        if num % 2 == 0:
            num //= 2
        else:
            num += 1
        steps += 1
    return steps
```

**关键**: 用进位 carry 避免大数运算.

### 12.3 LeetCode 1510 - 石子游戏 IV (Medium)

**题目**: n 个石子, 每次取走**恰好 $x^2$** 个 ($x > 0$). 取完最后一个者赢.

```python
def winnerSquareGame(n):
    """DP: dp[i] = i 个石子时先手是否必胜"""
    dp = [False] * (n + 1)
    for i in range(1, n + 1):
        # 枚举 x^2 <= i
        x = 1
        while x * x <= i:
            if not dp[i - x * x]:  # 对手必败
                dp[i] = True
                break
            x += 1
    return dp[n]
```

**时间复杂度**: $O(n \sqrt{n})$.

**优化**: 直接用 `int(sqrt(i))` 作为最大 $x$.

### 12.4 LeetCode 1563 - 石子游戏 V (Hard)

**题目**: pile 数组, 每次选一段连续的堆分成两段 (不能全取), 取较小一段的分数加到自己. 求先手最高分.

```python
def stoneGameV(piles):
    """区间 DP"""
    n = len(piles)
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i+1] = prefix[i] + piles[i]

    # dp[i][j] = piles[i..j] 的最高分
    dp = [[0] * n for _ in range(n)]

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            for k in range(i, j):
                left_sum = prefix[k+1] - prefix[i]
                right_sum = prefix[j+1] - prefix[k+1]
                if left_sum < right_sum:
                    dp[i][j] = max(dp[i][j], left_sum + dp[i][k])
                elif left_sum > right_sum:
                    dp[i][j] = max(dp[i][j], right_sum + dp[k+1][j])
                else:
                    dp[i][j] = max(dp[i][j], left_sum + max(dp[i][k], dp[k+1][j]))

    return dp[0][n-1]
```

**时间复杂度**: $O(n^3)$.

### 12.5 LeetCode 1723 - 完成所有工作的最短时间 (Hard)

**题目**: n 个工作, 分给 k 个工人, 每个工人顺序执行被分到的工作. 求最长工人时间的最小值.

**关键**: 这其实不是"博弈", 是分配问题, 但常用状压 DP 或二分解决.

```python
def minimumTimeRequired(jobs, k):
    """二分 + 贪心分配"""
    lo, hi = max(jobs), sum(jobs)

    def can_finish(limit):
        """判断能否用 k 个工人完成, 每个 <= limit"""
        worker_times = [0] * k

        def backtrack(job_idx):
            if job_idx == len(jobs):
                return True
            seen = set()
            for w in range(k):
                if worker_times[w] in seen:  # 剪枝: 相同时间不重复尝试
                    continue
                if worker_times[w] + jobs[job_idx] <= limit:
                    seen.add(worker_times[w])
                    worker_times[w] += jobs[job_idx]
                    if backtrack(job_idx + 1):
                        return True
                    worker_times[w] -= jobs[job_idx]
                if worker_times[w] == 0:  # 第一个空工人放不下, 后面的也不行
                    break
            return False

        return backtrack(0)

    while lo < hi:
        mid = (lo + hi) // 2
        if can_finish(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo
```

**多解法对比**:

| 解法 | 时间 | 空间 |
| :--- | :--- | :--- |
| 二分 + 回溯 | $O(\log S \cdot n!)$ (剪枝后好得多) | $O(k)$ |
| 状压 DP | $O(k \cdot 2^n)$ | $O(2^n)$ |
| 模拟退火 / 遗传 | 启发式 | - |

**状压 DP 版本**:

```python
def minimumTimeRequired_dp(jobs, k):
    """状压 DP"""
    n = len(jobs)
    # sum[mask] = mask 集合中工作的总时间
    sum_mask = [0] * (1 << n)
    for mask in range(1, 1 << n):
        lsb = mask & -mask
        i = lsb.bit_length() - 1
        sum_mask[mask] = sum_mask[mask ^ lsb] + jobs[i]

    # dp[mask] = 把 mask 集合的工作分给若干个工人, 最长工人时间的最小值
    # 但我们最多 k 个, 所以用 dp[i][mask] = 用 i 个工人分 mask 集合
    dp = [[float('inf')] * (1 << n) for _ in range(k + 1)]
    dp[0][0] = 0

    for i in range(1, k + 1):
        for mask in range(1 << n):
            # 枚举 mask 的子集 sub
            sub = mask
            while sub > 0:
                if dp[i-1][mask ^ sub] != float('inf'):
                    dp[i][mask] = min(dp[i][mask], max(dp[i-1][mask ^ sub], sum_mask[sub]))
                sub = (sub - 1) & mask
            dp[i][mask] = min(dp[i][mask], dp[i-1][mask])  # 可以少用工人

    return dp[k][(1 << n) - 1]
```

### 12.6 LeetCode 464 - 我能赢吗 (Medium, 状压)

**题目**: 整数 maxChoosableInteger 和目标 desiredTotal. 两人轮流选 [1, maxChoosableInteger] 中未选过的数, 加到累计和. 先达到或超过 desiredTotal 的人赢.

```python
def canIWin(maxChoosableInteger, desiredTotal):
    """SG 函数 + 状压"""
    if desiredTotal <= 0:
        return True  # 第一个玩家直接赢
    if maxChoosableInteger * (maxChoosableInteger + 1) // 2 < desiredTotal:
        return False  # 总和不够, 没人能赢

    from functools import lru_cache

    @lru_cache(None)
    def sg(used_mask, current_sum):
        """
        used_mask: 已选数字的位掩码
        current_sum: 当前累计和
        返回 True 如果当前玩家必胜
        """
        for i in range(maxChoosableInteger):
            bit = 1 << i
            if not (used_mask & bit):  # 未选过
                number = i + 1
                if current_sum + number >= desiredTotal:
                    return True  # 我赢
                if not sg(used_mask | bit, current_sum + number):
                    return True  # 对手必败

        return False

    return sg(0, 0)
```

**多解法对比**:

| 解法 | 时间 | 空间 | 适用 |
| :--- | :--- | :--- | :--- |
| 状压 DP | $O(2^n \cdot n)$ | $O(2^n)$ | $n \leq 20$ |
| SG 函数 (递归) | 同上 | 同上 | 同上 |
| 数学分析 | $O(1)$ | $O(1)$ | 仅特定模式 |

### 12.7 LeetCode 810 - 黑板异或游戏 (Medium)

**题目**: 黑板上有 n 个数. Alice 先手, 轮流操作: 选一个数擦掉, 然后重新写一个 [0, 10] 的数 (玩家决定). 最后所有数的异或 = 0 的人赢. Alice 是否必胜?

**关键**: Alice 必胜 ⟺ n 是偶数.

```python
def xorGame(nums):
    """Alice 先手必胜 ⟺ nums 长度为偶数 OR 初始 xor = 0"""
    n = len(nums)
    if n % 2 == 0:
        return True  # 偶数个, Alice 总能赢 (策略: 镜像)
    # 奇数个, 看初始异或
    xor = 0
    for x in nums:
        xor ^= x
    return xor == 0  # Alice 擦掉一个数即可让 xor = 0
```

**原理**:
- 若 n 偶数, 无论 Alice 怎么操作, Bob 总能"对称操作" (擦掉一个数 + 填特定值), 最终让 Bob 控制的数为 0. Alice 必胜.
- 若 n 奇数, Alice 必须擦掉一个数. 若此时 xor = 0, Alice 把任意数变 0 即赢. 否则 Alice 必败.

**题目**: 老鼠在节点 1, 猫在节点 2, 老鼠先手. 老鼠到 0 赢, 猫抓到老鼠 (同节点) 鼠输, 平局则 DRAW. 求结果.

```python
def catMouseGame(graph):
    """猫鼠博弈: 0=鼠赢, 1=猫赢, 2=平局"""
    n = len(graph)
    MOUSE, CAT = 1, 2

    # dp[turn][mouse_pos][cat_pos] = result
    # turn: 0=鼠轮, 1=猫轮
    DRAW, MOUSE_WIN, CAT_WIN = 0, 1, 2

    from functools import lru_cache

    @lru_cache(None)
    def get_result(turn, mouse, cat):
        if mouse == 0:
            return MOUSE_WIN
        if cat == mouse:
            return CAT_WIN

        if turn == 0:  # 鼠轮
            for next_mouse in graph[mouse]:
                if next_mouse == 0:
                    return MOUSE_WIN
                res = get_result(1, next_mouse, cat)
                if res == MOUSE_WIN:
                    return MOUSE_WIN
                if res == DRAW:
                    # 暂存 DRAW, 看是否有更好的
                    pass
            # 检查是否所有都是 CAT_WIN
            return CAT_WIN  # 简化: 实际需要更细

        else:  # 猫轮
            for next_cat in graph[cat]:
                if next_cat == 0:
                    continue  # 猫不能进洞
                if next_cat == mouse:
                    return CAT_WIN
                res = get_result(0, mouse, next_cat)
                if res == CAT_WIN:
                    return CAT_WIN
            return MOUSE_WIN  # 简化
```

| :--- | :--- | :--- | :--- |

### 13.2 时间复杂度选择决策树

```text
n <= 20        → 状压 DP / 状压 SG
n <= 100       → O(n^3) DP / O(n^2) DP
n <= 10000     → O(n log n) / O(n)
n > 10000      → O(n) / O(log n) 数学
状态简单       → SG 函数
多步选择       → 区间 DP
```

- **递归深度小** → 记忆化搜索方便
- **递归深度大** → 自底向上 DP
- **状态空间大** → BFS / 拓扑排序

## 14. 实战调试技巧

### 14.1 常见 Bug 与避坑

#### Bug 1: 终止状态搞反

```python
# 错误: 把"赢"当成终止
def is_terminal(state):
    return state == win_state  # 错! 此时当前玩家已经赢了

# 正确: 终止是"无法操作", 不是"赢了"
def is_terminal(state):
    return len(get_actions(state)) == 0
```

**规则**: "无法操作" 意味着当前玩家输. "赢了" 是操作的结果, 不是终止本身.

#### Bug 2: SG 函数忘加记忆化

```python
# 错误: 重复计算
def sg(state):
    if is_terminal(state): return 0
    sgs = {sg(apply(state, a)) for a in get_actions(state)}
    g = 0
    while g in sgs: g += 1
    return g

# 正确: 加 lru_cache
from functools import lru_cache

@lru_cache(None)
def sg(state):
    if is_terminal(state): return 0
    sgs = {sg(apply(state, a)) for a in get_actions(state)}
    g = 0
    while g in sgs: g += 1
    return g
```

#### Bug 3: mex 实现错误

```python
# 错误: 忘记检查非负整数
def mex(s):
    return min(set(range(100)) - s)

# 正确: 检查 0, 1, 2, ... 第一个不在 s 中的
def mex(s):
    g = 0
    while g in s:
        g += 1
    return g
```

#### Bug 4: 区间 DP 越界

```python
# 错误: dp[i+1][j] 当 i+1 > j 时越界
for length in range(2, n+1):
    for i in range(n - length + 1):
        j = i + length - 1
        # 当 length = 2 时, i = j - 1, dp[i+1][j] = dp[j][j], OK
        # 但如果 length = 1, dp[i+1][j] 越界

# 正确: 长度从 1 开始, 单独处理
for i in range(n):
    dp[i][i] = a[i]
for length in range(2, n+1):
    ...
```

#### Bug 5: SG 函数复合计算时异或方向搞反

```python
# 错误: 加而不是异或
total_sg = sum(sg_i for sg_i in sub_sgs)

# 正确: 异或
total_sg = 0
for sg_i in sub_sgs:
    total_sg ^= sg_i
```

## 15. 经典题目完整模板

### 15.1 区间博弈 DP 模板

```python
def interval_game(nums):
    """
    区间博弈通用模板: 每次选端点, 求最优解
    返回 dp[0][n-1] (净得分)
    """
    n = len(nums)
    if n == 0:
        return 0

    # dp[i][j] = 在 [i, j] 区间内, 当前玩家相对对手的净得分
    dp = [[0] * n for _ in range(n)]

    # 初始化: 单元素
    for i in range(n):
        dp[i][i] = nums[i]

    # 长度递增
    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            # 选左端点: 我得 nums[i], 之后是 dp[i+1][j] (对手视角)
            choose_left = nums[i] - dp[i+1][j]
            # 选右端点
            choose_right = nums[j] - dp[i][j-1]
            dp[i][j] = max(choose_left, choose_right)

    return dp[0][n-1]

# 用法:
# LeetCode 486:  predictTheWinner → dp[0][n-1] >= 0
# LeetCode 877:  stoneGame     → dp[0][n-1] > 0
# 变种: 分数差最小 → 取绝对值
```

### 15.2 SG 函数通用模板

```python
from functools import lru_cache

def solve_with_sg(get_actions, apply_action, is_terminal):
    """
    通用 SG 函数求解

    get_actions(state) → list of action
    apply_action(state, action) → new_state
    is_terminal(state) → bool

    返回: (can_win, grundy_value)
    """
    @lru_cache(maxsize=None)
    def grundy(state):
        if is_terminal(state):
            return 0

        next_grundy = set()
        for action in get_actions(state):
            new_state = apply_action(state, action)
            next_grundy.add(grundy(new_state))

        g = 0
        while g in next_grundy:
            g += 1
        return g

    # 调用: 先用初始 state 调用一次
    # g = grundy(initial_state)
    # return g != 0
    return grundy

# 示例: Nim
def nim_solve(piles):
    xor = 0
    for p in piles:
        xor ^= p
    return xor != 0

# 示例: 复合博弈 (多个独立子博弈)
def compound_solve(sub_states):
    """
    sub_states: list of sub_state, 每个子博弈独立
    """
    xor = 0
    for s in sub_states:
        xor ^= grundy(s)
    return xor != 0
```

### 15.3 状压博弈模板

```python
from functools import lru_cache

def bitmask_game(n, win_condition, lose_condition):
    """
    通用状压博弈模板: 状态用位掩码表示

    n: 元素个数 (n <= 20)
    win_condition(state, mask, ...): 当前玩家是否赢
    lose_condition(state, mask, ...): 当前玩家是否输
    """
    @lru_cache(maxsize=None)
    def win(mask, turn):
        """
        mask: 已用元素的位掩码
        turn: 0 = 玩家 0 (先手), 1 = 玩家 1 (后手)
        返回: True 如果当前轮到的玩家必胜
        """
        if win_condition(mask):
            return True
        if lose_condition(mask):
            return False
        if mask == (1 << n) - 1:
            return False  # 全用完

        # 尝试每个未用的位
        for i in range(n):
            if not (mask & (1 << i)):
                if not win(mask | (1 << i), 1 - turn):
                    return True  # 对手必败

        return False

    return win(0, 0)
```

### 15.4 区间博弈 DP 优化版 (空间 O(n))

```python
def interval_game_optimized(nums):
    """O(n) 空间版本"""
    n = len(nums)
    dp = [0] * n
    for i in range(n):
        dp[i] = nums[i]

    for length in range(2, n + 1):
        new_dp = [0] * n
        for i in range(n - length + 1):
            j = i + length - 1
            new_dp[i] = max(nums[i] - dp[i+1], nums[j] - dp[i])
        dp = new_dp[:n - length + 1] + [0] * (length - 1)

    return dp[0]
```

## 16. 状态压缩博弈深入

### 16.1 何时用状压

- **总状态数 ≤ 2^20**: 状压可行
- **状态可以用位掩码表示**: 排列, 集合, 棋盘
- **转移可以枚举**: 每步操作涉及 1-2 个位

### 16.2 状压博弈例子

#### 例 1: 8 数码

```python
def eight_puzzle(initial, goal):
    """8 数码: 0-8 共 9 个位置"""
    from functools import lru_cache

    moves = {0: [1, 3], 1: [0, 2, 4], 2: [1, 5],
             3: [0, 4, 6], 4: [1, 3, 5, 7], 5: [2, 4, 8],
             6: [3, 7], 7: [4, 6, 8], 8: [5, 7]}

    @lru_cache(maxsize=None)
    def solve(state):
        """state: 9 位 4 进制数表示"""
        if state == goal:
            return 0  # P-position
        sgs = set()
        # 找到 0 的位置
        for pos in range(9):
            digit = (state >> (2 * pos)) & 0b11
            if digit == 0:
                for new_pos in moves[pos]:
                    # 交换 pos 和 new_pos
                    new_digit = (state >> (2 * new_pos)) & 0b11
                    new_state = state & ~(0b11 << (2 * pos)) | (new_digit << (2 * pos))
                    new_state = new_state & ~(0b11 << (2 * new_pos))
                    sgs.add(solve(new_state))
        g = 0
        while g in sgs: g += 1
        return g

    return solve(initial) != 0
```

## 21. 总结与思考

### 21.1 博弈论核心思想

1. **状态分类**: P-position (必败) vs N-position (必胜)
2. **递归定义**: SG 函数 (mex of 后继的 SG)
3. **异或合并**: 复合博弈 = 各子博弈 SG 的异或
4. **构造策略**: 必胜态必有必胜操作, 必败态无

### 21.2 实战心法

- **先画博弈树**: 小问题先枚举, 找规律
- **找终止态**: 倒推 P-position / N-position
- **算 SG 函数**: 用记忆化递归
- **找必胜操作**: 枚举候选, 验证

### 21.3 常见误区

- ❌ 以为"先手总占便宜" → 很多博弈先手必败
- ❌ 以为"分越高越赢" → 实为净得分最大化
- ❌ 以为博弈=DP → 还需要 SG, 数学分析
- ❌ 以为必胜=最优 → 还需构造具体操作

### 21.4 进一步学习

- 期望博弈 (CFR, MCCFR, Deep CFR)
- 大型博弈 (CFR+, Discounted CFR)
- 算法博弈论 (Vickrey Auction, Myerson)

## 22. 博弈论面试高频问答

### 22.1 Q&A: 必胜必败的本质

**Q**: 为什么 SG 函数的 mex 定义能正确分类状态?

**A**: mex 给每个状态分配一个"等价 Nim 堆大小". 关键在于:
- SG = 0 等价于空 Nim 堆 (必败)
- SG = k ≠ 0 等价于大小为 k 的 Nim 堆 (必胜)
- 后继 SG 集合的 mex 恰好是"让对手面对 SG = 0 的最小可走步"

**Q**: 为什么异或是合并子博弈的正确操作?

**A**: 因为异或满足"必胜 ⟺ 异或 ≠ 0". 直观上:
- 异或 = 0: 各子博弈"互补", 平衡态, 必败
- 异或 ≠ 0: 至少一个子博弈"溢出", 必胜

### 22.2 Q&A: 区间博弈 DP 的本质

**Q**: 为什么 dp[i][j] 用 `nums[i] - dp[i+1][j]`?

**A**:
- 当前选 `nums[i]`, 我得 `nums[i]`
- 对手在 `[i+1, j]` 决策, 对手净得分 = `dp[i+1][j]`
- 我净得分 = 我得分 - 对手得分 = `nums[i] - dp[i+1][j]`

### 22.3 Q&A: 状压博弈的设计

**Q**: 为什么用位掩码?

**A**: 位掩码紧凑 (64 位可表示 64 个元素), 哈希快 (Python 整数), 可用位运算快速判断/修改.

**Q**: 什么时候不能状压?

**A**:
- 元素数 > 25 (状态空间爆炸)
- 元素有多种状态 (不是 0/1)
- 转移复杂 (单步涉及很多位)

### 22.4 Q&A: 期望博弈的复杂度

**Q**: 为什么期望博弈比确定博弈难?

**A**: 确定博弈只需分析**确定**的最优策略; 期望博弈要考虑**所有可能的随机事件**和**对手的混合策略**. 这导致状态空间指数增长.

**Q**: 如何求解期望博弈?

**A**: 主流算法:
- **CFR (Counterfactual Regret)**: 迭代最小化每局后悔值
- **MCCFR**: CFR 的蒙特卡洛采样版
- **Deep CFR**: 用神经网络近似后悔值
- **NashConv**: 衡量当前策略到 Nash 平衡的距离

### 22.5 Q&A: 大型博弈

**Q**: 什么是大型博弈 (Extensive-Form Game)?

**A**: 决策有顺序, 信息不完美, 每个玩家有"信息集" (看不到对手的牌). 例如德州扑克.

**Q**: 大型博弈怎么求 Nash 平衡?

**A**:
- **线性规划**: 理论上可行, 但实际状态爆炸
- **序列博弈 (Sequence Form)**: 用"序列概率"而非"策略"作为变量, 化为 LP
- **CFR / CFR+**: 迭代式, 实践中可处理 10^12 状态

### 22.6 Q&A: 算法博弈论

**Q**: 什么是 Vickrey 拍卖?

**A**: 第二价格密封拍卖. 赢家付第二高价格. 这是占优策略均衡 (Dominant Strategy Equilibrium).

**Q**: 什么是 Myerson 拍卖?

**A**: 给定投标人估值分布, 设计拍卖最大化期望社会福利. 单物品最优是 Vickrey.

### 22.7 Q&A: 实战选择

**Q**: 看到博弈题, 第一步做什么?

**A**:
1. 识别博弈类型 (Nim / 区间 / 状压 / 期望)
2. 小数据手动画博弈树, 找规律
3. 写 SG 或 DP, 用小数据验证
4. 优化时间和空间

**Q**: 博弈题总是超时, 怎么办?

**A**:
1. 检查状态数: 是否能压缩
2. 检查转移数: 是否能用数学代替枚举
3. 检查终止态: 是否能剪枝
4. 检查对称性: 是否能用规范形式

**Q**: SG 函数和 DP 的关系?

**A**:
- SG 函数: 把博弈化为 Nim, 用异或判断必胜
- DP: 直接算最优得分 (净得分 / 总得分)
- 两者本质等价, 但 DP 更直观, SG 更通用

**Q**: 如何快速判断该用哪种解法?

**A**:
| 题目特征 | 推荐解法 |
| :--- | :--- |
| 单堆取石子 | 数学 (n % k) |
| 多堆 Nim | 异或 |
| 区间博弈 | 区间 DP |
| 状压博弈 | 状压 SG |
| 操作集合简单 | SG + mex |
| 操作复杂 (位置/方向) | DP |

### 23.1 通用 SG 函数库

```python
from functools import lru_cache
from typing import Callable, Generic, TypeVar

State = TypeVar('State')

class SGGame(Generic[State]):
    """
    通用 SG 函数博弈求解器

    用法:
        game = SGGame(
            is_terminal=lambda s: s == 0,
            get_actions=lambda s: range(1, min(4, s + 1)),
            apply_action=lambda s, a: s - a
        )
        print(game.is_winning(10))  # True
    """

    def __init__(
        self,
        is_terminal: Callable[[State], bool],
        get_actions: Callable[[State], list],
        apply_action: Callable[[State, object], State]
    ):
        self.is_terminal = is_terminal
        self.get_actions = get_actions
        self.apply_action = apply_action

    @lru_cache(maxsize=None)
    def grundy(self, state: State) -> int:
        if self.is_terminal(state):
            return 0

        next_grundy = set()
        for action in self.get_actions(state):
            new_state = self.apply_action(state, action)
            next_grundy.add(self.grundy(new_state))

        g = 0
        while g in next_grundy:
            g += 1
        return g

    def is_winning(self, state: State) -> bool:
        return self.grundy(state) != 0

    def find_winning_action(self, state: State):
        """返回必胜操作, 若必败返回 None"""
        g = self.grundy(state)
        if g == 0:
            return None

        for action in self.get_actions(state):
            new_state = self.apply_action(state, action)
            if self.grundy(new_state) == 0:
                return action
        return None
```

### 23.2 通用博弈 DP 库

```python
from functools import lru_cache
from typing import Callable, Generic, TypeVar

State = TypeVar('State')

class GameDP(Generic[State]):
    """
    通用博弈 DP 求解器

    适用于: 玩家最大化自己得分, 双方得分总和固定
    """

    def __init__(
        self,
        is_terminal: Callable[[State], bool],
        get_actions: Callable[[State], list],
        apply_action: Callable[[State, object], State],
        score: Callable[[State, object], float]
    ):
        """
        score(state, action): 玩家执行 action 后获得的得分
        """
        self.is_terminal = is_terminal
        self.get_actions = get_actions
        self.apply_action = apply_action
        self.score = score

    @lru_cache(maxsize=None)
    def optimal_score(self, state: State) -> float:
        """当前玩家在 state 下能获得的最大得分"""
        if self.is_terminal(state):
            return 0

        best = -float('inf')
        for action in self.get_actions(state):
            score_gained = self.score(state, action)
            new_state = self.apply_action(state, action)
            future_score = self.optimal_score(new_state)
            total = score_gained + future_score
            best = max(best, total)
        return best

    def optimal_actions(self, state: State) -> list:
        """返回所有最优操作"""
        if self.is_terminal(state):
            return []

        best_score = self.optimal_score(state)
        return [
            a for a in self.get_actions(state)
            if self.score(state, a) + self.optimal_score(self.apply_action(state, a)) == best_score
        ]
```

### 23.3 区间博弈库

```python
def interval_game_dp(arr, player_a_score=True):
    """
    通用区间博弈 DP

    规则: 每次选左或右端点, 取走值
    player_a_score: True = 返回 A 净得分, False = 返回 (A 得分, B 得分)
    """
    n = len(arr)
    if n == 0:
        return 0

    # dp[i][j] = 在 [i, j] 区间, 当前玩家相对对手的净得分
    dp = [[0] * n for _ in range(n)]

    for i in range(n):
        dp[i][i] = arr[i]

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            # 我选 i, 净得 arr[i] - dp[i+1][j]
            # 我选 j, 净得 arr[j] - dp[i][j-1]
            dp[i][j] = max(arr[i] - dp[i+1][j], arr[j] - dp[i][j-1])

    if player_a_score:
        # A 得分 = (总 + A 净得) / 2
        total = sum(arr)
        a_score = (total + dp[0][n-1]) // 2
        return a_score
    else:
        total = sum(arr)
        a_score = (total + dp[0][n-1]) // 2
        b_score = total - a_score
        return (a_score, b_score)
```

### 23.4 复合博弈库

```python
from functools import lru_cache
from typing import List

def compound_game_is_winning(sub_states: List, sub_grundy_funcs: List[Callable]) -> bool:
    """
    复合博弈: 各子博弈独立, 玩家每步选一个子博弈走
    子博弈必须都是公平博弈 (impartial)

    sub_states: 各子博弈的当前状态
    sub_grundy_funcs: 各子博弈的 SG 函数
    返回: 当前玩家是否必胜
    """
    xor = 0
    for state, sg_func in zip(sub_states, sub_grundy_funcs):
        xor ^= sg_func(state)
    return xor != 0

def compound_game_grundy(sub_states: List, sub_grundy_funcs: List[Callable]) -> int:
    """返回复合博弈的 SG"""
    xor = 0
    for state, sg_func in zip(sub_states, sub_grundy_funcs):
        xor ^= sg_func(state)
    return xor
```

```python
def can_win_pairwise(total):
    return total % 2 == 1
```

### 24.3 阿里面试题: 博弈+图

> 二叉树上, 根有 1 个棋子. 两人轮流把棋子移到子节点. 不能移者输. 必胜?

**答**: 根到所有叶子路径长度都是奇数 → 先手必胜; 否则后手必胜.

```python
def tree_game(root):
    """所有路径长度都是奇数 → 必胜"""
    def dfs(node, depth):
        if not node:
            return depth % 2 == 1
        left = dfs(node.left, depth + 1)
        right = dfs(node.right, depth + 1)
        return left and right  # 全奇数才必胜
    return dfs(root, 0)
```

### 24.4 腾讯面试题: 异或游戏

> n 个数, Alice 先擦一个, Bob 决定新值. 最后 XOR = 0 赢. Alice 必胜条件?

**答**:
- 若 n 偶数: Alice 必胜 (无论怎么擦, Bob 都让 XOR = 0)
- 若 n 奇数: 取决于初始 XOR

```python
def xor_game_alice_wins(nums):

    return 0 not in [x ^ y for x in nums for y in nums]  # 简化判断
```

### 24.6 美团面试题: 动态博弈

> 整数 n, Alice 选 [1, n] 中一个因子 x, 然后 n -= x. 重复直到 n = 0. 取最后一个因子者赢. 必胜?

**答**: 用 SG 函数求解.

```python
def divisor_game_sg(n):
    from functools import lru_cache

    @lru_cache(None)
    def sg(k):
        if k == 0:
            return 0
        sgs = set()
        for x in range(1, k + 1):
            if k % x == 0:
                sgs.add(sg(k - x))
        g = 0
        while g in sgs: g += 1
        return g

    return sg(n) != 0
```

### 24.7 京东面试题: 双方最优化

> n 个任务, 每个有难度 d[i]. Alice 选一个任务, Bob 选下一个难度更高的, 依次. 双方最大化自己的总难度.

**解**: 双方最优策略 = 各自选自己可得的最高难度.

```python
def alternating_pick(tasks):
    """双方各自最优化"""
    tasks.sort()
    n = len(tasks)
    # Alice 先手, 每次选剩余最低难度 (因为对方要更高)
    a, b = 0, 0
    is_alice = True
    lo, hi = 0, n - 1
    while lo <= hi:
        if is_alice:
            a += tasks[lo]
            lo += 1
        else:
            b += tasks[hi]
            hi -= 1
        is_alice = not is_alice
    return a, b
```

## 27. 习题答案与详解

### 27.1 LeetCode 292 - Nim 游戏

**题**: n 个石子, 每次取 1-3 个. 取到最后一个者赢. 先手必胜条件?

**解**: `n % 4 != 0`.

**详解**:
- n = 0: 无法取, 输 (但这是终止态, 不会出现)
- n = 1, 2, 3: 先手直接取完, 必胜
- n = 4: 先手取 1/2/3, 留 3/2/1, 对手都能取完, 先手必败
- n = 5, 6, 7: 先手取到 4, 对手必败, 先手必胜
- n = 8: 先手取到 4/5/6/7 (任意), 但对手都能再变回 4 的倍数, 先手必败
- 规律: n 是 4 的倍数必败, 否则必胜

### 27.2 LeetCode 464 - 我能赢吗

**题**: maxChoosableInteger = 10, desiredTotal = 11. 先手必胜?

**解**: 用状压 SG. 状态: 选过的数字 + 累计和. 枚举每个未选数字.

**详解**: 当 maxChoosableInteger=10 时, 总和 = 55. 足够到达 11.
- 若 desiredTotal=0, 直接赢.
- 若 maxChoosableInteger*(maxChoosableInteger+1)/2 < desiredTotal, 输.

具体递归见 Section 12.6.

### 27.3 LeetCode 877 - 石子游戏

**题**: 偶数堆石子, 每次取第一堆或最后一堆, 总分高者赢.

**解**: 先手必胜 (因为奇数位之和 > 偶数位之和).

**详解**:
- 偶数堆, Alex 先手选 0 或 n-1
- Alex 总能选"奇数位"或"偶数位"中的一个集合
- 假设奇数位之和 > 偶数位之和, Alex 选所有奇数位 (即第一次选 0, 然后无论对手选什么, Alex 都能选到下一个奇数位)
- 若偶数位之和 ≥ 奇数位之和, Alex 选偶数位

### 27.4 LeetCode 486 - 预测赢家

**题**: 数组, 每次取头或尾, 总分高者赢 (或平局也算赢). 先手必胜?

**解**: `interval_game_dp(nums) >= 0`.

**详解**: 详见 Section 15.1. dp[0][n-1] ≥ 0 表示先手净得分非负.

### 27.5 POJ 1704 - Georgia and Bob

**题**: n 个棋子, 每次往左移任意格, 不能越界或重叠. 最后不能移者输.

**解**: 把相邻棋子配对, 每对距离 = Nim 堆. 奇数个棋子时, 第 1 个 vs 边界.

**详解**: 把所有棋子按位置排序. 从右往左每两个配一对. 每对的距离 (减去 1) 是一个 Nim 堆. 异或判断.

### 27.6 POJ 2484 - A Funny Game

**题**: n 个硬币排成环, 每次取连续 2 个或 3 个. 取到最后一个者赢.

**解**: n ≥ 4 时后手必胜.

**详解**:
- n = 1: 先手取完, 必胜
- n = 2: 先手取完, 必胜
- n = 3: 先手取完, 必胜
- n ≥ 4: 先手取后, 留下 2 或 1 个连续段, 对手能继续取, 后手最终能取完 (鸽巢原理)

### 28.1 Nim 模板

```python
def can_win_nim(piles):
    """多堆 Nim"""
    xor = 0
    for p in piles:
        xor ^= p
    return xor != 0

def find_nim_move(piles):
    """找 Nim 必胜操作"""
    xor = 0
    for p in piles:
        xor ^= p
    if xor == 0:
        return None

    highest_bit = 1 << (xor.bit_length() - 1)
    for i, p in enumerate(piles):
        if p & highest_bit:
            new_pile = p ^ xor
            return (i, new_pile)
    return None
```

### 28.2 区间博弈模板

```python
def interval_game(arr):
    n = len(arr)
    if n == 0: return 0

    dp = [[0] * n for _ in range(n)]
    for i in range(n):
        dp[i][i] = arr[i]

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            dp[i][j] = max(arr[i] - dp[i+1][j], arr[j] - dp[i][j-1])

    return dp[0][n-1]
```

```python
def sg_game(state, is_terminal, get_actions, apply_action):

    def grundy(s):
        if is_terminal(s):
            return 0
        next_sgs = {grundy(apply_action(s, a)) for a in get_actions(s)}
```

### 28.4 状压博弈模板

```python
from functools import lru_cache

def bitmask_game(n):
    @lru_cache(None)
    def win(mask, turn):
        if mask == (1 << n) - 1:
            return False
        for i in range(n):
            if not (mask & (1 << i)):
                if not win(mask | (1 << i), 1 - turn):
                    return True
        return False

    return win(0, 0)
```

```python
from collections import defaultdict

def cfr_simplified(game_tree, num_iterations=1000):
```
