## 1. 网络流基础

### 1.1 概念

**网络**: 有向图, 每条边有容量 (capacity).

**流 (flow)**: 边的实际流量, 必须满足:
- 容量限制: $0 \leq f(u, v) \leq c(u, v)$
- 流量守恒: 除了源点 (s) 和汇点 (t), 每个点的入流 = 出流

**源点 (s)**: 水流的起点 (出度 > 入度)

**汇点 (t)**: 水流的终点 (入度 > 出度)

**最大流**: 从 s 到 t 能流的最大流量.

## 2. Ford-Fulkerson 算法 (基础)

### 2.1 思想

**核心**: 反复找增广路 (从 s 到 t 的剩余路径), 增加流量.

```text
while 存在增广路:
    找一条增广路
    增加该路的最小边容量
```

### 2.2 实现 (BFS 找增广路 = Edmonds-Karp)

```python
def max_flow_edmonds_karp(capacity, source, sink, n):
    """Edmonds-Karp: BFS 找增广路"""
    flow = 0
    while True:
        # BFS 找增广路
        parent = [-1] * n
        parent[source] = source
        queue = [source]
        while queue and parent[sink] == -1:
            u = queue.pop(0)
            for v in range(n):
                if parent[v] == -1 and capacity[u][v] > 0:
                    parent[v] = u
                    queue.append(v)

        if parent[sink] == -1:
            break  # 没有增广路

        # 找最小剩余容量
        path_flow = float('inf')
        v = sink
        while v != source:
            u = parent[v]
            path_flow = min(path_flow, capacity[u][v])
            v = u

        # 更新流
        v = sink
        while v != source:
            u = parent[v]
            capacity[u][v] -= path_flow
            capacity[v][u] += path_flow
            v = u

        flow += path_flow

    return flow
```

**复杂度**: $O(VE^2)$, $V$ 顶点数, $E$ 边数.

## 3. Dinic 算法 (★ 推荐)

### 3.1 思想

- **BFS 分层**: 给节点按距离 s 的远近分层 (level graph).
- **DFS 阻塞流**: 在分层图上找多条增广路.
- 重复直到 s 达不到 t.

**复杂度**: $O(V^2 E)$, 实际更快.

### 3.2 实现

```python
from collections import deque

class Dinic:
    def __init__(self, n):
        self.n = n
        self.graph = [[] for _ in range(n)]

    def add_edge(self, u, v, cap):
        """添加有向边 + 反向边"""
        self.graph[u].append([v, cap, len(self.graph[v])])
        self.graph[v].append([u, 0, len(self.graph[u]) - 1])

    def bfs(self, s, t):
        """分层"""
        self.level = [-1] * self.n
        self.level[s] = 0
        queue = deque([s])
        while queue:
            u = queue.popleft()
            for v, cap, _ in self.graph[u]:
                if cap > 0 and self.level[v] == -1:
                    self.level[v] = self.level[u] + 1
                    queue.append(v)
        return self.level[t] != -1

    def dfs(self, u, t, f):
        """找增广路"""
        if u == t: return f
        for i in range(self.it[u], len(self.graph[u])):
            v, cap, rev = self.graph[u][i]
            if cap > 0 and self.level[v] == self.level[u] + 1:
                ret = self.dfs(v, t, min(f, cap))
                if ret > 0:
                    self.graph[u][i][1] -= ret
                    self.graph[v][rev][1] += ret
                    return ret
            self.it[u] += 1
        return 0

    def max_flow(self, s, t):
        flow = 0
        INF = 10**18
        while self.bfs(s, t):
            self.it = [0] * self.n
            while True:
                f = self.dfs(s, t, INF)
                if f == 0: break
                flow += f
        return flow
```

## 5. 二部图匹配

### 5.1 什么是二部图

**二部图**: 节点可分为两部分 (A 和 B), 边只连接 A 和 B.

**匹配**: 选一些边, 任意两条边不共顶点.

**最大匹配**: 选最多的边.

### 5.2 二部图最大匹配 = 最大流

把二部图转化为流网络:
- 源点 → A 节点 (容量 1)
- A 节点 → B 节点 (原图的边, 容量 1)
- B 节点 → 汇点 (容量 1)

**最大流 = 最大匹配数**.

### 5.3 LeetCode 785 - 判断二分图 (Medium)

```python
def isBipartite(graph):
    """二分图判断 - BFS 染色"""
    n = len(graph)
    color = [0] * n  # 0=未染色, 1=A, -1=B

    for i in range(n):
        if color[i] != 0: continue
        queue = deque([i])
        color[i] = 1
        while queue:
            u = queue.popleft()
            for v in graph[u]:
                if color[v] == 0:
                    color[v] = -color[u]
                    queue.append(v)
                elif color[v] == color[u]:
                    return False
    return True
```

### 5.4 LeetCode 886 - 可能的二部划分 (Medium)

**题目**: n 个人, 有些不能在同一组. 能否分成两组?

```python
def possibleBipartition(n, dislikes):
    """二分图判断"""
    graph = [[] for _ in range(n)]
    for u, v in dislikes:
        graph[u - 1].append(v - 1)
        graph[v - 1].append(u - 1)
    return isBipartite(graph)
```

### 5.5 LeetCode 1820 - 最多邀请的个数 (Medium, 二部图匹配)

```python
def maximumInvitations(grid):
    """二部图最大匹配 (匈牙利算法)"""
    m, n = len(grid), len(grid[0])
    # 男 m 找女 n

    match_to = [-1] * n  # match_to[j] = 匹配到 j 的男人

    def try_kun(u, visited):
        for v in range(n):
            if grid[u][v] and not visited[v]:
                visited[v] = True
                if match_to[v] == -1 or try_kun(match_to[v], visited):
                    match_to[v] = u
                    return True
        return False

    res = 0
    for u in range(m):
        visited = [False] * n
        if try_kun(u, visited):
            res += 1

    return res
```

## 10. 网络流的数学基础

### 10.1 形式化定义

**定义 10.1 (网络)**: 一个流网络是一个有向图 $G = (V, E)$, 每条边 $(u, v)$ 有**容量** $c(u, v) \geq 0$, 其中 $V$ 是节点集, $E$ 是边集.

**定义 10.2 (可行流)**: 一个流 (flow) 是一个函数 $f: V \times V \to \mathbb{R}$, 满足:

1. **容量约束**: 对所有 $u, v \in V$, $0 \leq f(u, v) \leq c(u, v)$
2. **流量守恒**: 对所有 $u \in V \setminus \{s, t\}$, $\sum_{v} f(v, u) = \sum_{v} f(u, v)$
3. **斜对称**: $f(u, v) = -f(v, u)$

**定义 10.3 (流的值)**: $|f| = \sum_{v} f(s, v) - \sum_{v} f(v, s)$, 即流出 s 的净流量.

**最大流问题**: 求 $\max_f |f|$.

### 10.2 剩余网络

**定义 10.4 (剩余网络)**: 给定流网络 $G$ 和流 $f$, 剩余网络 $G_f$ 是图 $G$ 加上剩余容量边:

$$c_f(u, v) = c(u, v) - f(u, v)$$

即"还能再流多少".

**关键观察**: 在剩余网络中, 一条边可能"反向" (即从 $u$ 到 $v$ 原本没有边, 但 $f(v, u) > 0$, 那么可以从 $u$ 到 $v$ 退流).

### 10.3 增广路

**定义 10.5 (增广路)**: 在剩余网络中, 从 $s$ 到 $t$ 的一条路径.

**定理 10.1 (Ford-Fulkerson)**: 如果在剩余网络中找不到增广路, 当前流是最大流.

**证明思路**: 设剩余网络中 $s$ 可达的节点集为 $S$, 不可达 (但 $t$ 可达) 的为 $T$, 那么 $(S, T)$ 是一个割, 且容量 = 流值. 因此流值 = 割容量 = 最小割.

### 10.4 最大流最小割定理

**定理 10.2**: 以下三个命题等价:

1. $f$ 是最大流
2. 剩余网络 $G_f$ 中没有增广路
3. 存在最小割, 使 $|f| = c(S, T)$

**推论**: 最大流 = 最小割 = 任何 $(s, t)$ 割的最小容量.

### 10.5 复杂度上界

| 算法 | 时间复杂度 | 适用场景 |
|---|---|---|
| Ford-Fulkerson (整数容量) | $O(E \cdot F)$, $F$ = 最大流值 | 小流量 |
| Edmonds-Karp (BFS) | $O(V E^2)$ | 中等规模 |
| Dinic | $O(V^2 E)$ | 默认推荐 |
| Push-Relabel | $O(V^3)$ | 稠密图 |
| HLPP | $O(V^3)$ (实际更快) | 大规模稀疏图 |

**实战建议**: 99% 场景用 Dinic 即可.

## 11. Dinic 算法深度优化

### 11.1 优化 1: 当前弧优化 (Current Arc)

**问题**: DFS 时反复访问已经满了的边.

**解决**: 用 `it[u]` 记录 $u$ 当前访问到的边索引, 跳过已经尝试过的.

```python
class Dinic:
    def __init__(self, n):
        self.n = n
        self.graph = [[] for _ in range(n)]
        self.it = [0] * n  # 当前弧

    def add_edge(self, u, v, cap):
        """添加有向边 + 反向边"""
        self.graph[u].append([v, cap, len(self.graph[v])])
        self.graph[v].append([u, 0, len(self.graph[u]) - 1])

    def bfs(self, s, t):
        """分层图构建"""
        self.level = [-1] * self.n
        level_s = 0
        self.level[s] = level_s
        queue = deque([s])
        while queue:
            u = queue.popleft()
            for e in self.graph[u]:
                v, cap, _ = e
                if cap > 0 and self.level[v] == -1:
                    self.level[v] = self.level[u] + 1
                    queue.append(v)
        return self.level[t] != -1

    def dfs(self, u, t, f):
        """找阻塞流, 当前弧优化"""
        if u == t:
            return f
        for i in range(self.it[u], len(self.graph[u])):
            e = self.graph[u][i]
            v, cap, rev = e
            if cap > 0 and self.level[v] == self.level[u] + 1:
                ret = self.dfs(v, t, min(f, cap))
                if ret > 0:
                    e[1] -= ret
                    self.graph[v][rev][1] += ret
                    return ret
            self.it[u] += 1
        return 0

    def max_flow(self, s, t):
        flow = 0
        INF = 10**18
        while self.bfs(s, t):
            self.it = [0] * self.n  # 每次 BFS 后重置
            while True:
                f = self.dfs(s, t, INF)
                if f == 0:
                    break
                flow += f
        return flow
```

### 11.2 优化 2: 多路增广

**问题**: 每条 DFS 路径增广后, 这条路径上的某些边可能还能继续流.

**解决**: 用非递归 DFS, 一次压榨完一条路径.

```python
def dfs_multi(self, u, t, f):
    """多路增广版 DFS"""
    if u == t:
        return f

    pushed = 0
    for i in range(self.it[u], len(self.graph[u])):
        e = self.graph[u][i]
        v, cap, rev = e
        if cap == 0 or self.level[v] != self.level[u] + 1:
            self.it[u] += 1
            continue

        pushed = self.dfs_multi(v, t, min(f - pushed, cap))
        if pushed > 0:
            e[1] -= pushed
            self.graph[v][rev][1] += pushed
            if f == pushed:
                return pushed
            self.it[u] += 1

    return pushed
```

### 11.3 优化 3: 初始 BFS 优化

**问题**: BFS 中, 如果 t 已经分层, 可以提前退出 (但要小心处理未访问的节点).

```python
def bfs_early(self, s, t):
    """提前退出的 BFS"""
    self.level = [-1] * self.n
    self.level[s] = 0
    queue = deque([s])
    while queue:
        u = queue.popleft()
        if u == t:  # 提前退出
            return True
        for e in self.graph[u]:
            v, cap, _ = e
            if cap > 0 and self.level[v] == -1:
                self.level[v] = self.level[u] + 1
                queue.append(v)
    return self.level[t] != -1
```

### 11.4 优化 4: 边的存储优化

**问题**: 用 `list` 存边, 反向指针更新麻烦.

**解决 1**: 用对象 / 元组代替 list, 但 Python 中 list 修改更高效.

**解决 2**: 用 `dict` 索引.

```python
class Edge:
    __slots__ = ('to', 'cap', 'rev')
    def __init__(self, to, cap, rev):
        self.to = to
        self.cap = cap
        self.rev = rev

class Dinic:
    def __init__(self, n):
        self.n = n
        self.graph = [[] for _ in range(n)]

    def add_edge(self, u, v, cap):
        self.graph[u].append(Edge(v, cap, len(self.graph[v])))
        self.graph[v].append(Edge(u, 0, len(self.graph[u]) - 1))
```

### 11.5 复杂度对比

| 优化项 | 不优化 | 优化后 |
|---|---|---|
| 当前弧 | $O(E \cdot V)$ dfs | $O(E)$ |
| 多路增广 | 1 路径/dfs | 满 dfs |
| 提前退出 BFS | 必须全扫 | 遇到 t 就停 |

**实战推荐**: 当前弧 + 多路增广, 几乎所有题都能过.

## 12. 最大流算法完整对比

### 12.1 Ford-Fulkerson (1956)

```python
def ford_fulkerson(capacity, source, sink, n):
    flow = 0
    INF = float('inf')

    def has_path():
        """DFS 找增广路"""
        visited = [False] * n
        stack = [source]
        visited[source] = True
        path = {source: None}
        while stack:
            u = stack.pop()
            for v in range(n):
                if not visited[v] and capacity[u][v] > 0:
                    visited[v] = True
                    path[v] = u
                    if v == sink:
                        return path
                    stack.append(v)
        return None

    while True:
        path = has_path()
        if path is None:
            break
        # 计算最小剩余容量
        path_flow = INF
        v = sink
        while v != source:
            u = path[v]
            path_flow = min(path_flow, capacity[u][v])
            v = u
        # 增广
        v = sink
        while v != source:
            u = path[v]
            capacity[u][v] -= path_flow
            capacity[v][u] += path_flow
            v = u
        flow += path_flow

    return flow
```

**问题**: 如果用 DFS, 增广路数量可能达 $O(F)$ 次 (最坏情况), 总复杂度 $O(F \cdot E)$.

**改进**: 用 BFS 找最短增广路 = Edmonds-Karp, $O(V E^2)$.

### 12.2 Edmonds-Karp

(见 2.2 节)

**特点**: 每次找最短增广路, 增广路数量 $O(V E)$.

### 12.3 Dinic (1970)

(见 3.2 节, 11.1 节)

**特点**: BFS 分层 + DFS 多路增广. **最常用**.

**复杂度分析**:

- BFS: $O(E)$
- DFS 阻塞流: $O(V E)$ (一次 DFS 至少推满一条路径)
- 总: $O(V E^2)$, 因为分层图最多 $V$ 次

### 12.4 Push-Relabel (Goldberg 1985)

**思想**: 不维护"s 到 t 的路径", 每个节点维护"超额" (excess), 推流 (push) 到邻居, 重新标签 (relabel).

```python
class PushRelabel:
    def __init__(self, n):
        self.n = n
        self.graph = [[] for _ in range(n)]

    def add_edge(self, u, v, cap):
        self.graph[u].append([v, cap, len(self.graph[v])])
        self.graph[v].append([u, 0, len(self.graph[u]) - 1])

    def max_flow(self, s, t):
        n = self.n
        INF = float('inf')

        # 高度 (label), 超额
        height = [0] * n
        excess = [0] * n

        # 初始化高度: source 高度 = n
        height[s] = n

        # 从 s 推出所有边
        for e in self.graph[s]:
            v, cap, rev = e
            push = cap
            e[1] -= push
            self.graph[v][rev][1] += push
            excess[v] += push
            excess[s] -= push

        # 主循环
        active = [i for i in range(n) if i != s and i != t]

        while active:
            u = active.pop()
            if excess[u] <= 0:
                continue

            # 尝试推送
            pushed = False
            for e in self.graph[u]:
                v, cap, rev = e
                if cap > 0 and height[u] == height[v] + 1:
                    push = min(excess[u], cap)
                    e[1] -= push
                    self.graph[v][rev][1] += push
                    excess[u] -= push
                    excess[v] += push
                    pushed = True
                    if v != s and v != t:
                        active.append(v)

            if not pushed:
                # relabel
                min_h = INF
                for e in self.graph[u]:
                    v, cap, _ = e
                    if cap > 0:
                        min_h = min(min_h, height[v])
                height[u] = min_h + 1

            if excess[u] > 0:
                active.append(u)

        return excess[t]
```

**复杂度**: $O(V^3)$.

**适用**: 稠密图.

## 13. 最小割深入

### 13.1 最小割 = 最大流的实际应用

**经典结论**: 求出一组最大流后, 从 $s$ 出发在剩余网络中能到达的节点集 $S$, $V \setminus S$ 就是 $T$.

```python
def min_cut_partition(dinic, s, t):
    """求最小割的左右两边"""
    dinic.max_flow(s, t)  # 先求最大流

    S = set()
    visited = [False] * dinic.n

    def dfs(u):
        visited[u] = True
        S.add(u)
        for e in dinic.graph[u]:
            v, cap, _ = e
            if cap > 0 and not visited[v]:
                dfs(v)

    dfs(s)
    return S, set(range(dinic.n)) - S
```

### 13.2 LeetCode 1349 用最大独立集 = n - 最小点覆盖 = 最小割

**题目回顾**: 考试座位, 学生不能相邻, 求最大学生数.

**转化为最小割**:

```python
def maxStudents_min_cut(seats):
    """用最小割求最大独立集 = 总数 - 最小割"""
    m, n = len(seats), len(seats[0])

    # 建图: 每个座位是一个节点
    # 冲突关系: 横向 (j, j+1), 纵向 (i, i+1), 对角 (i, j+1) (i+1, j)
    # 二分图: (i + j) 偶数一侧, 奇数一侧

    # 源 → 偶数点 → 奇数点 → 汇

    edges = []
    cells = []
    for i in range(m):
        for j in range(n):
            if seats[i][j] == '.':
                cells.append((i, j))

    idx = {(i, j): k for k, (i, j) in enumerate(cells)}
    total = len(cells)

    dinic = Dinic(total + 2)
    S = total
    T = total + 1

    for i, j in cells:
        u = idx[(i, j)]
        # 源 / 汇连接
        if (i + j) % 2 == 0:
            dinic.add_edge(S, u, 1)
        else:
            dinic.add_edge(u, T, 1)

        # 冲突边 (双向, 这里只单向)
        for di, dj in [(-1,0), (1,0), (0,-1), (0,1)]:
            ni, nj = i + di, j + dj
            if 0 <= ni < m and 0 <= nj < n and (ni, nj) in idx:
                v = idx[(ni, nj)]
                if (i + j) % 2 == 0:
                    dinic.add_edge(u, v, 1)

    max_match = dinic.max_flow(S, T)
    return total - max_match  # 最大独立集
```

**复杂度**: $O(V^2 E)$, 通常 $V \leq 64$, 跑得飞快.

### 13.3 全局最小割 (不指定 s, t)

**Stoer-Wagner 算法** (适用于无向图):

```python
def global_min_cut(n, edges):
    """Stoer-Wagner: 全局最小割 O(n^3)"""
    INF = float('inf')

    # 初始化: 节点集合
    used = [False] * n
    dist = [0] * n

    min_cut = INF

    for _ in range(n - 1):
        # 找最远点 (从 used=0 中找 dist 最大的)
        last = -1
        for v in range(n):
            if used[v]: continue
            if last == -1 or dist[v] > dist[last]:
                last = v

        if last == -1:
            break

        used[last] = True
        # 合并 last 到所有其他点
        for v in range(n):
            if used[v]: continue
            dist[v] += edges[last][v]  # 这里 edges 是邻接矩阵

        min_cut = min(min_cut, dist[last])

    return min_cut
```

**复杂度**: $O(V^3)$, 适用无向图 (要特殊处理边权).

### 13.4 最小割建模: 实际案例

**例 1: 二选一问题**

问题: 选 A 或选 B, 选 A 收益 $a$, 选 B 收益 $b$, 不能同时选 A 和 B.

建模:
- 节点 A, B
- 源 → A, cap = $a$
- 源 → B, cap = $b$
- A → 汇, cap = 0
- B → 汇, cap = 0
- A ↔ B, cap = $\infty$ (不能同时选)
- 最小割 = "不选的收益", 最大流 = "选的收益"

**例 2: 项目选择**

问题: 项目 $p_i$ 收益 $w_i$, 选了 $p_i$ 必须也选 $p_j$ (依赖), 求最大收益.

建模: 闭合图最大权.
- 建图: $p_j$ → $p_i$ (选了 $i$ 必须选 $j$)
- 源 → $p_i$ (cap = $w_i$ if $w_i > 0$)
- $p_i$ → 汇 (cap = $-w_i$ if $w_i < 0$)
- 最大权 = $\sum w_i^+ - \text{min cut}$

## 14. 二部图匹配详解

### 14.1 二部图判定

**算法**: BFS/DFS 染色.

```python
def is_bipartite_dfs(graph):
    """DFS 染色"""
    n = len(graph)
    color = [0] * n  # 0 未染色, 1/-1 已染色

    for i in range(n):
        if color[i] != 0: continue
        # DFS
        color[i] = 1
        stack = [i]
        while stack:
            u = stack.pop()
            for v in graph[u]:
                if color[v] == 0:
                    color[v] = -color[u]
                    stack.append(v)
                elif color[v] == color[u]:
                    return False
    return True
```

### 14.2 最大匹配的算法选择

**问题**: 二部图 $G = (A \cup B, E)$, 找最大匹配.

| 算法 | 时间 | 思想 |
|---|---|---|
| 匈牙利 (DFS) | $O(VE)$ | 增广路 |
| Hopcroft-Karp | $O(\sqrt{V} E)$ | BFS 找多条增广路 |
| Dinic | $O(\sqrt{V} E)$ | 转最大流 |
| Floyd + 二分图等价 | $O(V^3)$ | 太慢 |

**实战推荐**: Hopcroft-Karp (最优) 或 Dinic (够用).

### 14.3 匈牙利算法 (★ 经典)

**思想**: 对每个左节点, 用 DFS 找增广路.

```python
def hungarian(graph, n_left, n_right):
    """graph[u] = [v1, v2, ...] u 在左侧, v 在右侧"""
    match_right = [-1] * n_right  # match_right[v] = u (匹配到 v 的左节点)

    def try_kun(u, visited):
        """DFS 找增广路"""
        for v in graph[u]:
            if visited[v]: continue
            visited[v] = True
            if match_right[v] == -1 or try_kun(match_right[v], visited):
                match_right[v] = u
                return True
        return False

    matching = 0
    for u in range(n_left):
        visited = [False] * n_right
        if try_kun(u, visited):
            matching += 1

    return matching, match_right
```

**复杂度**: $O(V \cdot E)$, 因为最坏情况每个左节点 DFS 走 $E$ 条边.

**递归版本** (DFS) 在 $n = 500$ 时容易栈溢出, 用**非递归版本**:

```python
                    pushed = True
                    # 回溯设置路径
                    cur = u_start
                    cur_v = v
                    while True:
                        # 重新走一遍, 标记所有经过的节点
                        ...
                    break
                else:
                    # 尝试让出
                    stack.pop()
                    stack.append((u, i + 1, False))
                    stack.append((match_right[v], 0, False))
```

### 14.4 Hopcroft-Karp 算法 (★ 最优)

**思想**: BFS 分层, 一次找所有最短增广路.

```python
from collections import deque

def hopcroft_karp(graph, n_left, n_right):
    """graph[u] = [v1, v2, ...]"""
    INF = float('inf')

    # match_right[v] = u (匹配到 v 的左节点)
    # match_left[u] = v (u 匹配到 v)
    match_right = [-1] * n_right
    match_left = [-1] * n_left

    def bfs():
        """BFS 找所有最短增广路, 标记距离"""
        dist = [0] * n_left
        queue = deque()
        for u in range(n_left):
            if match_left[u] == -1:
                dist[u] = 0
                queue.append(u)
            else:
                dist[u] = INF

        found = False
        while queue:
            u = queue.popleft()
            for v in graph[u]:
                nu = match_right[v]
                if nu != -1 and dist[nu] == INF:
                    dist[nu] = dist[u] + 1
                    queue.append(nu)
                elif nu == -1:
                    found = True  # 找到了
        return found, dist

    def dfs(u, dist):
        """DFS 找增广路, 用 BFS 距离"""
        for v in graph[u]:
            nu = match_right[v]
            if nu == -1 or (dist[nu] == dist[u] + 1 and dfs(nu, dist)):
                match_left[u] = v
                match_right[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while True:
        found, dist = bfs()
        if not found:
            break
        for u in range(n_left):
            if match_left[u] == -1 and dfs(u, dist):
                matching += 1

    return matching, match_left, match_right
```

**复杂度**: $O(\sqrt{V} \cdot E)$.

**实战**: 这个算法对 $n \leq 5000$ 跑飞快.

### 14.5 二部图匹配 = 最大流

**转化**:

```text
源 → A 节点 (cap 1)
A → B (cap 1, 原图边)
B → 汇 (cap 1)
```

最大流 = 最大匹配.

```python
def bipartite_matching_dinic(graph_left, n_left, n_right, graph_right_edges=None):
    """用 Dinic 求二部图最大匹配"""
    # 节点编号: 0..n_left-1 是左节点
    #           n_left..n_left+n_right-1 是右节点
    #           n_left+n_right 是源
    #           n_left+n_right+1 是汇

    n = n_left + n_right + 2
    S = n_left + n_right
    T = n_left + n_right + 1
    dinic = Dinic(n)

    # 源 → 左
    for u in range(n_left):
        dinic.add_edge(S, u, 1)

    # 右 → 汇
    for v in range(n_right):
        dinic.add_edge(n_left + v, T, 1)

    # 左 → 右 (根据原图边)
    for u in range(n_left):
        for v in graph_left[u]:
            dinic.add_edge(u, n_left + v, 1)

    return dinic.max_flow(S, T)
```

## 15. 最小费用最大流

### 15.1 问题定义

**最小费用最大流**: 每条边 $e$ 有容量 $c(e)$ 和单位费用 $w(e)$. 求从 $s$ 到 $t$ 的最大流中, 总费用最小的方案.

**算法选择**:

| 算法 | 时间 | 思想 |
|---|---|---|
| SPFA + 增广 | $O(F \cdot VE)$ | 求最短增广路 (按费用) |
| Dinic + SPFA | $O(V^2 E \cdot \log V)$ | 改 BFS 为 SPFA |
| Primal-Dual | $O(F \cdot \log V)$ | 每次找最短路 + 增广 |

**实战推荐**: SPFA + Dinic 即可.

### 15.2 SPFA + EK 实现

```python
from collections import deque

def min_cost_max_flow(n, edges, S, T):
    """edges: list of (u, v, cap, cost)
    返回: (max_flow, min_cost)
    """
    INF = float('inf')
    max_flow = 0
    min_cost = 0

    # 邻接表
    graph = [[] for _ in range(n)]

    def add_edge(u, v, cap, cost):
        graph[u].append([v, cap, cost, len(graph[v])])
        graph[v].append([u, 0, -cost, len(graph[u]) - 1])

    for u, v, cap, cost in edges:
        add_edge(u, v, cap, cost)

    while True:
        # SPFA 找最短费用增广路
        dist = [INF] * n
        in_queue = [False] * n
        prev = [-1] * n
        prev_edge = [-1] * n

        dist[S] = 0
        in_queue[S] = True
        queue = deque([S])

        while queue:
            u = queue.popleft()
            in_queue[u] = False
            for i, e in enumerate(graph[u]):
                v, cap, cost, _ = e
                if cap > 0 and dist[v] > dist[u] + cost:
                    dist[v] = dist[u] + cost
                    prev[v] = u
                    prev_edge[v] = i
                    if not in_queue[v]:
                        queue.append(v)
                        in_queue[v] = True

        if prev[T] == -1:
            break  # 找不到增广路

        # 找最小剩余容量
        path_flow = INF
        v = T
        while v != S:
            u = prev[v]
            e = graph[u][prev_edge[v]]
            path_flow = min(path_flow, e[1])
            v = u

        # 增广
        v = T
        while v != S:
            u = prev[v]
            i = prev_edge[v]
            e = graph[u][i]
            e[1] -= path_flow
            graph[v][e[3]][1] += path_flow
            min_cost += path_flow * e[2]
            v = u

        max_flow += path_flow

    return max_flow, min_cost
```

### 15.3 Dinic + SPFA 实现 (高效版)

```python
class MinCostDinic:
    def __init__(self, n):
        self.n = n
        self.graph = [[] for _ in range(n)]

    def add_edge(self, u, v, cap, cost):
        self.graph[u].append([v, cap, cost, len(self.graph[v])])
        self.graph[v].append([u, 0, -cost, len(self.graph[u]) - 1])

    def spfa(self, s, t):
        """找最短费用路径"""
        INF = float('inf')
        dist = [INF] * self.n
        in_queue = [False] * self.n
        prev = [(-1, -1)] * self.n  # (前节点, 边索引)

        dist[s] = 0
        in_queue[s] = True
        queue = deque([s])

        while queue:
            u = queue.popleft()
            in_queue[u] = False
            for i, e in enumerate(self.graph[u]):
                v, cap, cost, _ = e
                if cap > 0 and dist[v] > dist[u] + cost:
                    dist[v] = dist[u] + cost
                    prev[v] = (u, i)
                    if not in_queue[v]:
                        queue.append(v)
                        in_queue[v] = True

        if dist[t] == INF:
            return None, None
        return dist, prev

    def min_cost_flow(self, s, t, max_f=INF):
        """求最小费用流 (最大 max_f)"""
        total_cost = 0
        total_flow = 0
        INF = float('inf')

        while total_flow < max_f:
            dist, prev = self.spfa(s, t)
            if prev is None:
                break

            # 找最小剩余容量
            path_flow = max_f - total_flow
            v = t
            while v != s:
                u, i = prev[v]
                e = self.graph[u][i]
                path_flow = min(path_flow, e[1])
                v = u

            # 增广
            v = t
            path_cost = 0
            while v != s:
                u, i = prev[v]
                e = self.graph[u][i]
                e[1] -= path_flow
                self.graph[v][e[3]][1] += path_flow
                path_cost += e[2]
                v = u

            total_cost += path_cost * path_flow
            total_flow += path_flow

        return total_flow, total_cost
```

### 16.6 经典建模问题

**例 1: 二分图最小点覆盖**

```python
def min_vertex_cover_bipartite(n_left, n_right, edges):
    """二分图最小点覆盖"""
    # 用最大匹配: König 定理
    # 最大匹配 = 最小点覆盖
    n = n_left + n_right + 2
    S, T = n - 2, n - 1
    dinic = Dinic(n)

    for u in range(n_left):
        dinic.add_edge(S, u, 1)
    for v in range(n_right):
        dinic.add_edge(n_left + v, T, 1)
    for u, v in edges:
        dinic.add_edge(u, n_left + v, 1)

    dinic.max_flow(S, T)

    # 从 s 出发在剩余网络能到达的是 S, 不可达是 T
    # 最小点覆盖: (S 部分右节点) ∪ (T 部分左节点)
    S_set = set()
    visited = [False] * n

    def dfs(u):
        visited[u] = True
        S_set.add(u)
        for e in dinic.graph[u]:
            v, cap, _ = e
            if cap > 0 and not visited[v]:
                dfs(v)

    dfs(S)

    vertex_cover = []
    for u in range(n_left):
        if u not in S_set:
            vertex_cover.append(u)
    for v in range(n_right):
        if (n_left + v) in S_set:
            vertex_cover.append(n_left + v)

    return vertex_cover
```

**例 2: 最大独立集**

**结论**: 二分图最大独立集 = 总节点数 - 最小点覆盖.

```python
def max_independent_set(n_left, n_right, edges):
    """二分图最大独立集"""
    cover = min_vertex_cover_bipartite(n_left, n_right, edges)
    total = n_left + n_right
    return total - len(cover)
```

**例 3: DAG 最小路径覆盖**

**问题**: DAG, 选最少的路径覆盖所有节点 (每节点恰好在一条路径上).

**建模**: 二分图最大匹配.

- 每个节点拆为"左"和"右".
- 左边节点 $u$ 连到 右边节点 $v$, 如果 $G$ 中有边 $u \to v$.
- 最大匹配 = 最小路径数.
- 最小路径覆盖 = $n$ - 最大匹配.

```python
def min_path_cover_dag(n, dag_edges):
    """DAG 最小路径覆盖"""
    n2 = 2 * n + 2
    S, T = n2 - 2, n2 - 1
    dinic = Dinic(n2)

    # 左节点 0..n-1, 右节点 n..2n-1
    for i in range(n):
        dinic.add_edge(S, i, 1)
    for i in range(n):
        dinic.add_edge(n + i, T, 1)

    for u, v in dag_edges:
        dinic.add_edge(u, n + v, 1)

    max_match = dinic.max_flow(S, T)
    return n - max_match
```

### 17.2 POJ 3281 - Dining (经典题)

**题目**: $n$ 头牛, 每头喜欢 $f$ 种食物和 $d$ 种饮料. 每食物/饮料只能用 1 次. 最多几头牛能同时分配.

**建模**: 关键 - 牛节点分裂.

```text
源 → 食物 (cap 1)
食物 → 牛左 (cap 1)
牛左 → 牛右 (cap 1, 强制 1 个食物 + 1 个饮料)
牛右 → 饮料 (cap 1)
饮料 → 汇 (cap 1)
```

```python
def dining(n_foods, n_drinks, cows):
    """n_foods 个食物, n_drinks 个饮料, cows = [(food_ids, drink_ids), ...]"""
    # 节点编号:
    # 食物: 0..n_foods-1
    # 牛左: n_foods..n_foods+n_cows-1
    # 牛右: n_foods+n_cows..n_foods+2*n_cows-1
    # 饮料: n_foods+2*n_cows..n_foods+2*n_cows+n_drinks-1
    # S, T

    n_cows = len(cows)
    total = n_foods + 2 * n_cows + n_drinks + 2
    S, T = total - 2, total - 1
    dinic = Dinic(total)

    # 源 → 食物
    for f in range(n_foods):
        dinic.add_edge(S, f, 1)

    # 饮料 → 汇
    for d in range(n_drinks):
        dinic.add_edge(n_foods + 2 * n_cows + d, T, 1)

    # 牛分裂: 牛 i 的左节点 = n_foods + i, 右节点 = n_foods + n_cows + i
    for i in range(n_cows):
        food_ids, drink_ids = cows[i]
        for f in food_ids:
            dinic.add_edge(f, n_foods + i, 1)
        dinic.add_edge(n_foods + i, n_foods + n_cows + i, 1)
        for d in drink_ids:
            dinic.add_edge(n_foods + n_cows + i, n_foods + 2 * n_cows + d, 1)

    return dinic.max_flow(S, T)
```

### 17.4 POJ 2112 - Optimal Milking (二分图 + 最大流 + Floyd)

**题目**: $K$ 个挤奶机, $C$ 头牛, 每头牛去某个挤奶机 (最多 $M$ 头/挤奶机). 最小化最大距离.

**建模**: 二分答案 + 最大流验证.

```python
def optimal_milking(K, C, M, dist):
    """dist[i][j] = 牛 i 到挤奶机 j 的距离"""
    n = K + C + 2
    S = K + C
    T = K + C + 1

    def can(d):
        """d 是否可行: 牛去挤奶机, 距离 ≤ d"""
        dinic = Dinic(n)
        for i in range(C):
            dinic.add_edge(S, K + i, 1)
            for j in range(K):
                if dist[i][j] <= d:
                    dinic.add_edge(K + i, j, 1)
        for j in range(K):
            dinic.add_edge(j, T, M)
        return dinic.max_flow(S, T) == C

    lo, hi = -1, max(max(d) for d in dist)
    while lo + 1 < hi:
        mid = (lo + hi) // 2
        if can(mid):
            hi = mid
        else:
            lo = mid

    return hi
```

**解法 2: 最小割 / 最大独立集**

```python
def maxStudents_min_cut(seats):
    m, n = len(seats), len(seats[0])

    # 收集所有可坐位置
    cells = [(i, j) for i in range(m) for j in range(n) if seats[i][j] == '.']
    total = len(cells)

    if total == 0:
        return 0

    dinic = Dinic(total + 2)
    S, T = total, total + 1
    idx = {(i, j): k for k, (i, j) in enumerate(cells)}

    # 二分图: (i+j) 偶数与奇数
    for i, j in cells:
        u = idx[(i, j)]
        if (i + j) % 2 == 0:
            dinic.add_edge(S, u, 1)
        else:
            dinic.add_edge(u, T, 1)
        # 冲突 (相邻): 一侧 -> 另一侧
        for di, dj in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
            ni, nj = i + di, j + dj
            if (ni, nj) in idx:
                v = idx[(ni, nj)]
                if (i + j) % 2 == 0:
                    dinic.add_edge(u, v, 1)

    max_match = dinic.max_flow(S, T)
    return total - max_match  # 最大独立集
```

- 边: 转移或分配

**Step 3**: 确定容量.

- 资源容量 (人/物的总数)

### 20.3 实战案例: 信息流问题

**问题**: 谣言在 $n$ 人中传播, 每个人可向几个人传. 求最多几人能在 $k$ 步内收到谣言.

**建模**: 时间展开图 (Time-expanded network).

- 每个时间步一层
- 节点 $(u, t)$ 表示人 $u$ 在时刻 $t$
- 源 = $(0, 0)$, 汇 = 任意 $(i, k)$
- 边: $(u, t) \to (v, t+1)$ (传递)
- 容量: 1 (每时刻一人可传给另一人恰好一次)

时间步 $k$ 后能到达的人数 = 最大流.

## 21. 网络流高级话题

### 21.1 容量缩放算法 (Capacity Scaling)

**思想**: 优先处理高容量边.

```python
def capacity_scaling(capacity, source, sink, n):
    """容量缩放"""
    INF = float('inf')

    max_cap = max(max(row) for row in capacity)

    delta = 1
    while delta <= max_cap:
        delta *= 2
    delta //= 2

    flow = 0
    while delta >= 1:
        # 在剩余容量 ≥ delta 的边上找增广路
        # ... BFS/DFS 略

        delta //= 2

    return flow
```

**复杂度**: $O(E^2 \log U)$, $U$ = 最大边容量.

### 21.2 强连通分量在网络流中的作用

有时先用 SCC 缩点, 减少问题规模:

```python
def scc_reduce(n, edges):
    """Tarjan 求 SCC"""
    from collections import defaultdict

    index_counter = [0]
    stack = []
    lowlink = [0] * n
    index = [0] * n
    on_stack = [False] * n
    result = []

    def strongconnect(v):
        index[v] = index_counter[0]
        lowlink[v] = index_counter[0]
        index_counter[0] += 1
        stack.append(v)
        on_stack[v] = True

        for w in edges[v]:
            if index[w] == 0:
                strongconnect(w)
                lowlink[v] = min(lowlink[v], lowlink[w])
            elif on_stack[w]:
                lowlink[v] = min(lowlink[v], index[w])

        if lowlink[v] == index[v]:
            component = []
            while True:
                w = stack.pop()
                on_stack[w] = False
                component.append(w)
                if w == v: break
            result.append(component)

    for v in range(n):
        if index[v] == 0:
            strongconnect(v)

    return result
```

### 23.1 万能 Dinic 模板

```python
class Dinic:
    __slots__ = ('n', 'graph', 'level', 'it')

    def __init__(self, n):
        self.n = n
        self.graph = [[] for _ in range(n)]

    def add_edge(self, u, v, cap):
        """加有向边 u -> v, 容量 cap"""
        self.graph[u].append([v, cap, len(self.graph[v])])
        self.graph[v].append([u, 0, len(self.graph[u]) - 1])

    def bfs(self, s, t):
        self.level = [-1] * self.n
        self.level[s] = 0
        from collections import deque
        queue = deque([s])
        while queue:
            u = queue.popleft()
            for e in self.graph[u]:
                v, cap, _ = e
                if cap > 0 and self.level[v] == -1:
                    self.level[v] = self.level[u] + 1
                    queue.append(v)
        return self.level[t] >= 0

    def dfs(self, u, t, f):
        if u == t: return f
        for i in range(self.it[u], len(self.graph[u])):
            self.it[u] = i
            e = self.graph[u][i]
            v, cap, rev = e
            if cap > 0 and self.level[v] == self.level[u] + 1:
                ret = self.dfs(v, t, min(f, cap))
                if ret > 0:
                    e[1] -= ret
                    self.graph[v][rev][1] += ret
                    return ret
        return 0

    def max_flow(self, s, t):
        flow = 0
        INF = float('inf')
        while self.bfs(s, t):
            self.it = [0] * self.n
            while True:
                f = self.dfs(s, t, INF)
                if f == 0: break
                flow += f
        return flow

# 使用:
dinic = Dinic(n)
dinic.add_edge(u, v, cap)
ans = dinic.max_flow(s, t)
```

### 23.2 万能 Hopcroft-Karp 模板

```python
from collections import deque

def hopcroft_karp(graph, n_left, n_right):
    """graph[u] 是左 u 邻接的右节点列表"""
    INF = float('inf')

    match_right = [-1] * n_right
    match_left = [-1] * n_left

    matching = 0
    while True:
        # BFS
        dist = [INF] * n_left
        queue = deque()
        for u in range(n_left):
            if match_left[u] == -1:
                dist[u] = 0
                queue.append(u)

        found = False
        while queue:
            u = queue.popleft()
            for v in graph[u]:
                nu = match_right[v]
                if nu != -1 and dist[nu] == INF:
                    dist[nu] = dist[u] + 1
                    queue.append(nu)
                elif nu == -1:
                    found = True

        if not found:
            break

        # DFS
        def dfs(u, dist):
            for v in graph[u]:
                nu = match_right[v]
                if nu == -1 or (dist[nu] == dist[u] + 1 and dfs(nu, dist)):
                    match_left[u] = v
                    match_right[v] = u
                    return True
            dist[u] = INF
            return False

        for u in range(n_left):
            if match_left[u] == -1 and dfs(u, dist):
                matching += 1

    return matching, match_left, match_right
```

### 23.3 万能最小费用最大流模板

```python
from collections import deque

class MinCostMaxFlow:
    def __init__(self, n):
        self.n = n
        self.graph = [[] for _ in range(n)]

    def add_edge(self, u, v, cap, cost):
        self.graph[u].append([v, cap, cost, len(self.graph[v])])
        self.graph[v].append([u, 0, -cost, len(self.graph[u]) - 1])

    def spfa(self, s, t):
        INF = float('inf')
        dist = [INF] * self.n
        in_queue = [False] * self.n
        prev = [(0, 0)] * self.n  # (prev_node, edge_idx)

        dist[s] = 0
        in_queue[s] = True
        queue = deque([s])

        while queue:
            u = queue.popleft()
            in_queue[u] = False
            for i, e in enumerate(self.graph[u]):
                v, cap, cost, _ = e
                if cap > 0 and dist[v] > dist[u] + cost:
                    dist[v] = dist[u] + cost
                    prev[v] = (u, i)
                    if not in_queue[v]:
                        queue.append(v)
                        in_queue[v] = True

        if dist[t] == INF:
            return None, None
        return dist, prev

    def flow(self, s, t):
        total_cost = 0
        total_flow = 0
        INF = float('inf')

        while True:
            dist, prev = self.spfa(s, t)
            if prev is None:
                break

            # 找最小剩余容量
            path_flow = INF
            v = t
            while v != s:
                u, i = prev[v]
                path_flow = min(path_flow, self.graph[u][i][1])
                v = u

            # 增广
            v = t
            path_cost = 0
            while v != s:
                u, i = prev[v]
                e = self.graph[u][i]
                e[1] -= path_flow
                self.graph[v][e[3]][1] += path_flow
                path_cost += e[2]
                v = u

            total_cost += path_cost * path_flow
            total_flow += path_flow

        return total_flow, total_cost

# 使用:
mcmf = MinCostMaxFlow(n)
mcmf.add_edge(u, v, cap, cost)
flow, cost = mcmf.flow(s, t)
```

```python
def logistics_routing(warehouses, customers, transport_options):
    """物流: 仓库 → 客户, 求最小费用方案"""
    n = len(warehouses) + len(customers) + 2
    S = len(warehouses) + len(customers)
    T = len(warehouses) + len(customers) + 1

    # 源 → 仓库
    for w_idx, w in enumerate(warehouses):
        mcmf.add_edge(S, w_idx, w['supply'], 0)

    # 客户 → 汇
    for c_idx, c in enumerate(customers):
        mcmf.add_edge(len(warehouses) + c_idx, T, c['demand'], 0)

    # 仓库 → 客户
    for w_idx, w in enumerate(warehouses):
        for c_idx, c in enumerate(customers):
            for opt in transport_options:
                if opt['from'] == w and opt['to'] == c:
                    mcmf.add_edge(w_idx, len(warehouses) + c_idx,
                                  opt['capacity'], opt['cost'])

    flow, cost = mcmf.flow(S, T)
    return cost
```

```python
def resource_scheduling(resources, tasks, allocation_rules):
    n = len(resources) + len(tasks) + 2
    S = len(resources) + len(tasks)
    T = len(resources) + len(tasks) + 1

    dinic = Dinic(n)
    # 源 → 资源 (cap = 资源数)
    for r_idx, r in enumerate(resources):
        dinic.add_edge(S, r_idx, r['capacity'])

    # 任务 → 汇 (cap = 任务需求)
    for t_idx, t in enumerate(tasks):
        dinic.add_edge(len(resources) + t_idx, T, t['demand'])

    # 资源 → 任务 (cap = 分配规则允许)
    for r_idx in range(len(resources)):
        for t_idx in range(len(tasks)):
            cap = allocation_rules[r_idx][t_idx]
            if cap > 0:
                dinic.add_edge(r_idx, len(resources) + t_idx, cap)

    return dinic.max_flow(S, T)
```

**7. 实践建议**

结合 "网络流基础 (最大流/最小割/匹配)" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "网络流基础 (最大流/最小割/匹配)" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
