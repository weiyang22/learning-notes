### 1.1 LeetCode 1 - 两数之和 (Easy)

```python
def twoSum(nums, target):
    """哈希: 一次遍历"""
    seen = {}
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i
```

### 1.2 LeetCode 15 - 三数之和 (Medium)

```python
def threeSum(nums):
    """排序 + 双指针 + 去重"""
    nums.sort()
    n = len(nums)
    res = []
    for i in range(n - 2):
        if nums[i] > 0: break
        if i > 0 and nums[i] == nums[i-1]: continue
        l, r = i + 1, n - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if s == 0:
                res.append([nums[i], nums[l], nums[r]])
                while l < r and nums[l] == nums[l+1]: l += 1
                while l < r and nums[r] == nums[r-1]: r -= 1
                l += 1; r -= 1
            elif s < 0: l += 1
            else: r -= 1
    return res
```

```python
        if i > 0 and nums[i] == nums[i-1]: continue

                else: r -= 1
    return res
```

### 2.4 LeetCode 567 - 字符串的排列 (Medium)

```python
def checkInclusion(s1, s2):
    """s1 的排列是否是 s2 的子串"""
    from collections import Counter
    need = Counter(s1)
    window = Counter()
    left = right = 0
    valid = 0
    while right < len(s2):
        c = s2[right]
        if c in need:
            window[c] += 1
            if window[c] == need[c]: valid += 1
        right += 1
        while valid == len(need):
            if right - left == len(s1): return True
            d = s2[left]
            if d in need:
                if window[d] == need[d]: valid -= 1
                window[d] -= 1
            left += 1
    return False
```

```python
    left, right = 0, len(matrix[0]) - 1
```

## 6. 模式化解题框架

### 6.1 先判断题型，再选择状态

数组与字符串题看似变化很多，核心通常只有以下几类状态：

1. **下标状态**：`left`、`right`、`slow`、`fast` 表示扫描边界。
2. **区间状态**：窗口 `[left, right]` 内维护计数、和、最大值或合法性。
3. **前缀状态**：`prefix[i]` 表示前 `i` 个元素的信息。
4. **有序状态**：排序后使用双指针，或在单调谓词上二分答案。
5. **位置映射**：哈希表记录元素上次出现位置、前缀和频次或分组签名。
6. **原地标记**：利用数组下标、首行首列或正负号减少额外空间。

拿到题目后按顺序问：

- 结果要求的是元素、下标、区间，还是数量？
- 子数组是否必须连续？子序列是否可以跳过元素？
- 元素是否全为正数？这决定滑动窗口能否安全收缩。
- 输入是否有序？如果无序，排序会不会破坏下标语义？
- 是否频繁查询同一份数据？若是，可预处理前缀和。
- 判定函数是否随答案单调？若是，可二分答案。
- 是否允许修改原数组？原地算法依赖这一前提。
- 字符集是 26 个小写字母、ASCII，还是任意 Unicode？

### 6.2 双指针的三种模型

#### 模型 A：相向双指针

适用条件：

- 数组已经有序，目标与两端元素存在单调关系。
- 区间宽度会随指针移动而缩小。
- 需要寻找两数和、三数和或最大容器面积。

```python
def two_pointer_template(nums, target):
    left, right = 0, len(nums) - 1
    while left < right:
        current = nums[left] + nums[right]
        if current == target:
            return left, right
        if current < target:
            left += 1
        else:
            right -= 1
    return -1, -1
```

正确性要点：

- 当和偏小时，移动右指针只会让和更小，因此只能增大左指针。
- 当和偏大时，移动左指针只会让和更大，因此只能减小右指针。
- 每次至少排除一个不可能成为答案的端点，搜索不会漏解。

#### 模型 B：同向快慢指针

适用条件：

- 原地删除或覆盖元素。
- 快指针负责读，慢指针负责写。
- 需要稳定保留满足条件的元素。

```python
def compact(nums, keep):
    write = 0
    for read, value in enumerate(nums):
        if keep(value):
            nums[write] = value
            write += 1
    return write
```

循环不变量：

- `[0, write)` 始终是已经处理完成且需要保留的元素。
- `[write, read)` 是可被覆盖的旧数据。
- `read` 之后的内容尚未读取。

#### 模型 C：分段扫描

适用条件：

- 连续相同字符压缩。
- 山脉、趋势段或游程编码。
- 每一段都能独立统计答案。

```python
def runs(s):
    result = []
    start = 0
    while start < len(s):
        end = start + 1
        while end < len(s) and s[end] == s[start]:
            end += 1
        result.append((s[start], end - start))
        start = end
    return result
```

### 6.3 滑动窗口的两种边界

固定窗口只需在加入新元素后删除过期元素：

```python
def fixed_window_sum(nums, k):
    if k > len(nums):
        return []
    current = sum(nums[:k])
    answer = [current]
    for right in range(k, len(nums)):
        current += nums[right] - nums[right - k]
        answer.append(current)
    return answer
```

可变窗口依赖“收缩后不会错过更优解”的单调性：

```python
def min_window_with_sum_at_least(nums, target):
    left = 0
    current = 0
    best = float("inf")
    for right, value in enumerate(nums):
        current += value
        while current >= target:
            best = min(best, right - left + 1)
            current -= nums[left]
            left += 1
    return 0 if best == float("inf") else best
```

注意：上面的写法要求 `nums` 全为正数。

若包含负数，删除左端元素可能让和变大，窗口不再单调；应考虑：

- 前缀和 + 哈希表。
- 前缀和 + 单调队列。
- 离线排序或树状数组。

### 6.4 前缀和的统一定义

推荐把 `prefix[0]` 定义为 0：

```python
def build_prefix(nums):
    prefix = [0]
    for value in nums:
        prefix.append(prefix[-1] + value)
    return prefix
```

于是半开区间 `[left, right)` 的和统一为：

```python
def range_sum(prefix, left, right):
    return prefix[right] - prefix[left]
```

这个定义避免处理 `left == 0` 的特殊分支。

二维前缀和使用容斥：

$$
S(r_1,c_1,r_2,c_2)=P(r_2+1,c_2+1)-P(r_1,c_2+1)-P(r_2+1,c_1)+P(r_1,c_1)
$$

### 6.5 二分查找的边界模板

寻找第一个大于等于 `target` 的位置：

```python
def lower_bound(nums, target):
    left, right = 0, len(nums)
    while left < right:
        mid = (left + right) // 2
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid
    return left
```

寻找第一个严格大于 `target` 的位置：

```python
def upper_bound(nums, target):
    left, right = 0, len(nums)
    while left < right:
        mid = (left + right) // 2
        if nums[mid] <= target:
            left = mid + 1
        else:
            right = mid
    return left
```

边界约定：

- 搜索空间始终是半开区间 `[left, right)`。
- 循环结束时 `left == right`，它就是插入点。
- 不需要在循环内部保存答案，减少分支错误。
- 查找首尾位置可组合 `lower_bound` 与 `upper_bound - 1`。

### 6.6 复杂度速查

| 模式 | 时间复杂度 | 额外空间 | 关键前提 |
| :--- | :--- | :--- | :--- |
| 哈希一次扫描 | O(n) | O(n) | 可用空间换时间 |
| 排序 + 双指针 | O(n log n) | 视排序实现 | 排序不破坏题意 |
| 固定滑窗 | O(n) | O(字符集) | 窗口长度固定 |
| 可变滑窗 | O(n) | O(字符集) | 合法性具有单调性 |
| 一维前缀和 | 预处理 O(n) | O(n) | 多次区间查询 |
| 二维前缀和 | 预处理 O(mn) | O(mn) | 多次矩形查询 |
| 二分查找 | O(log n) | O(1) | 有序或单调谓词 |
| 原地标记 | O(n) | O(1) | 允许修改输入 |

## 7. LeetCode 深入：哈希与双指针

### 7.1 LeetCode 1 - 两数之和：两种解法对比

#### 解法一：哈希表一次扫描

思路：扫描 `x` 时，若 `target - x` 已出现，则答案确定。

```python
def two_sum_hash(nums, target):
    seen = {}
    for index, value in enumerate(nums):
        need = target - value
        if need in seen:
            return [seen[need], index]
        seen[value] = index
    return []
```

示例：

```python
assert two_sum_hash([2, 7, 11, 15], 9) == [0, 1]
assert two_sum_hash([3, 2, 4], 6) == [1, 2]
assert two_sum_hash([3, 3], 6) == [0, 1]
```

复杂度：

- 时间 O(n)。
- 空间 O(n)。
- 保留原下标，无需排序。

#### 解法二：排序后双指针

```python
def two_sum_sorted_pairs(nums, target):
    pairs = sorted((value, index) for index, value in enumerate(nums))
    left, right = 0, len(pairs) - 1
    while left < right:
        total = pairs[left][0] + pairs[right][0]
        if total == target:
            return sorted([pairs[left][1], pairs[right][1]])
        if total < target:
            left += 1
        else:
            right -= 1
    return []
```

对比：

| 维度 | 哈希 | 排序 + 双指针 |
| :--- | :--- | :--- |
| 时间 | O(n) 期望 | O(n log n) |
| 空间 | O(n) | 需要保存值与原下标 |
| 输入有序时 | 仍可用 | 可降为 O(n) |
| 面试推荐 | 首选 | 解释空间权衡 |

常见错误：

- 先写入哈希再检查，可能错误地重复使用同一元素。
- 使用 `if seen.get(need)`，下标 0 会被当成假值。
- 返回值而不是题目要求的下标。

### 7.2 LeetCode 15 - 三数之和：去重机制

排序后固定第一个数，再把剩余问题化为两数之和。

```python
def three_sum_deduplicated(nums):
    nums.sort()
    answer = []
    for first in range(len(nums) - 2):
        if nums[first] > 0:
            break
        if first > 0 and nums[first] == nums[first - 1]:
            continue
        left, right = first + 1, len(nums) - 1
        while left < right:
            total = nums[first] + nums[left] + nums[right]
            if total < 0:
                left += 1
            elif total > 0:
                right -= 1
            else:
                answer.append([nums[first], nums[left], nums[right]])
                left += 1
                right -= 1
                while left < right and nums[left] == nums[left - 1]:
                    left += 1
                while left < right and nums[right] == nums[right + 1]:
                    right -= 1
    return answer
```

```python
actual = three_sum_deduplicated([-1, 0, 1, 2, -1, -4])
assert actual == [[-1, -1, 2], [-1, 0, 1]]
assert three_sum_deduplicated([0, 0, 0, 0]) == `0, 0, 0`
```

去重分三层：

1. 固定点 `first` 与前一个固定点相同则跳过。
2. 找到答案后先移动左右指针。
3. 再越过左右两侧的重复值。

为什么不能在进入循环前无条件跳过 `nums[left] == nums[left - 1]`？

- `left - 1` 可能是固定点。
- 某些合法组合需要相同数值但不同下标。
- 去重目标是结果三元组，不是禁止使用重复元素。

复杂度：

- 排序 O(n log n)。
- 双层扫描 O(n²)。
- 结果集之外的额外空间取决于排序实现。

### 7.3 LeetCode 18 - 四数之和：剪枝

```python
def four_sum_pruned(nums, target):
    nums.sort()
    n = len(nums)
    answer = []
    for i in range(n - 3):
        if i > 0 and nums[i] == nums[i - 1]:
            continue
        if nums[i] + nums[i + 1] + nums[i + 2] + nums[i + 3] > target:
            break
        if nums[i] + nums[n - 3] + nums[n - 2] + nums[n - 1] < target:
            continue
        for j in range(i + 1, n - 2):
            if j > i + 1 and nums[j] == nums[j - 1]:
                continue
            if nums[i] + nums[j] + nums[j + 1] + nums[j + 2] > target:
                break
            if nums[i] + nums[j] + nums[n - 2] + nums[n - 1] < target:
                continue
            left, right = j + 1, n - 1
            while left < right:
                total = nums[i] + nums[j] + nums[left] + nums[right]
                if total < target:
                    left += 1
                elif total > target:
                    right -= 1
                else:
                    answer.append([nums[i], nums[j], nums[left], nums[right]])
                    left += 1
                    right -= 1
                    while left < right and nums[left] == nums[left - 1]:
                        left += 1
                    while left < right and nums[right] == nums[right + 1]:
                        right -= 1
    return answer
```

剪枝含义：

- 当前层可组成的最小和已大于目标，后面只会更大，可直接 `break`。
- 当前层可组成的最大和仍小于目标，当前固定点无解，可 `continue`。
- 剪枝不改变最坏 O(n³)，但对分布较散的数据明显有效。

```python

    [-2, -1, 1, 2],
    [-2, 0, 0, 2],
    [-1, 0, 0, 1],
]
```

### 7.4 LeetCode 11 - 盛最多水的容器：贪心证明

面积为：

$$
A=(right-left)\times\min(height[left],height[right])
$$

```python
def max_area_two_pointer(height):
    left, right = 0, len(height) - 1
    best = 0
    while left < right:
        width = right - left
        level = min(height[left], height[right])
        best = max(best, width * level)
        if height[left] <= height[right]:
            left += 1
        else:
            right -= 1
    return best
```

证明移动短板是安全的：

- 假设左板更短。
- 固定左板并向左移动右板，宽度必然减小。
- 新高度上限仍被左板限制，因此面积不可能更大。
- 所以所有“继续保留左板”的候选都可一次排除。
- 对右板更短的情况同理。

```python
assert max_area_two_pointer([1, 1]) == 1
```

错误思路：总是移动较高的一侧。

反例中短板不变、宽度缩小，面积没有突破当前值的机会。

### 7.5 LeetCode 42 - 接雨水：三种解法

#### 解法一：前后缀最大值

```python
def trap_prefix(height):
    n = len(height)
    if n < 3:
        return 0
    left_max = [0] * n
    right_max = [0] * n
    left_max[0] = height[0]
    right_max[-1] = height[-1]
    for i in range(1, n):
        left_max[i] = max(left_max[i - 1], height[i])
    for i in range(n - 2, -1, -1):
        right_max[i] = max(right_max[i + 1], height[i])
    return sum(min(left_max[i], right_max[i]) - height[i] for i in range(n))
```

#### 解法二：双指针

```python
def trap_two_pointer(height):
    left, right = 0, len(height) - 1
    left_max = right_max = 0
    water = 0
    while left < right:
        if height[left] <= height[right]:
            left_max = max(left_max, height[left])
            water += left_max - height[left]
            left += 1
        else:
            right_max = max(right_max, height[right])
            water += right_max - height[right]
            right -= 1
    return water
```

#### 解法三：单调栈

```python
def trap_stack(height):
    stack = []
    water = 0
    for right, current in enumerate(height):
        while stack and current > height[stack[-1]]:
            bottom = stack.pop()
            if not stack:
                break
            left = stack[-1]
            width = right - left - 1
            bounded = min(height[left], current) - height[bottom]
            water += width * bounded
        stack.append(right)
    return water
```

对比：

| 解法 | 时间 | 空间 | 观察角度 |
| :--- | :--- | :--- | :--- |
| 前后缀最大值 | O(n) | O(n) | 按列计算 |
| 双指针 | O(n) | O(1) | 按列计算 |
| 单调栈 | O(n) | O(n) | 按层计算 |

```python

assert trap_two_pointer(sample) == 6
assert trap_stack(sample) == 6
```

### 8.1 LeetCode 3 - 无重复字符的最长子串

#### 解法一：集合 + 左边界逐步收缩

```python
def length_of_longest_substring_set(s):
    window = set()
    left = 0
    best = 0
    for right, char in enumerate(s):
        while char in window:
            window.remove(s[left])
            left += 1
        window.add(char)
        best = max(best, right - left + 1)
    return best
```

循环不变量：窗口 `[left, right]` 内没有重复字符。

```python
assert length_of_longest_substring_set("abcabcbb") == 3
assert length_of_longest_substring_set("bbbbb") == 1
assert length_of_longest_substring_set("") == 0
```

#### 解法二：记录字符最后位置，左边界跳跃

```python
def length_of_longest_substring_jump(s):
    last = {}
    left = 0
    best = 0
    for right, char in enumerate(s):
        if char in last and last[char] >= left:
            left = last[char] + 1
        last[char] = right
        best = max(best, right - left + 1)
    return best
```

关键条件是 `last[char] >= left`。

若省略该条件，旧窗口之外的重复字符会让左边界倒退。

两种解法对比：

| 维度 | 集合收缩 | 最后位置跳跃 |
| :--- | :--- | :--- |
| 每个字符操作次数 | 至多进出一次 | 查询、更新一次 |
| 时间 | O(n) | O(n) |
| 空间 | O(字符集) | O(字符集) |
| 易理解性 | 更直观 | 更精炼 |
| 边界风险 | 较低 | 防止 `left` 倒退 |

### 8.2 LeetCode 209 - 长度最小的子数组

题目中所有元素均为正数，因此窗口和随右边界扩张单调增加，随左边界收缩单调减少。

```python
def min_subarray_len_window(target, nums):
    left = 0
    total = 0
    best = len(nums) + 1
    for right, value in enumerate(nums):
        total += value
        while total >= target:
            best = min(best, right - left + 1)
            total -= nums[left]
            left += 1
    return 0 if best == len(nums) + 1 else best
```

#### 解法二：前缀和 + 二分

```python
from bisect import bisect_left


def min_subarray_len_binary(target, nums):
    prefix = [0]
    for value in nums:
        prefix.append(prefix[-1] + value)
    best = len(nums) + 1
    for left in range(len(nums)):
        wanted = prefix[left] + target
        right = bisect_left(prefix, wanted, left + 1)
        if right < len(prefix):
            best = min(best, right - left)
    return 0 if best == len(nums) + 1 else best
```

对比：

- 滑动窗口时间 O(n)，空间 O(1)，首选。
- 前缀和 + 二分时间 O(n log n)，空间 O(n)。

- 若存在负数，两者的单调性都可能失效。

### 8.3 LeetCode 76 - 最小覆盖子串

窗口需要覆盖 `t` 中每个字符的频次，而不只是字符种类。

```python
from collections import Counter


def min_window(s, t):
    if not t or len(t) > len(s):
        return ""
    need = Counter(t)
    window = Counter()
    required = len(need)
    formed = 0
    left = 0
    best_left = 0
    best_len = float("inf")
    for right, char in enumerate(s):
        if char in need:
            window[char] += 1
            if window[char] == need[char]:
                formed += 1
        while formed == required:
            length = right - left + 1
            if length < best_len:
                best_left = left
                best_len = length
            removed = s[left]
            if removed in need:
                if window[removed] == need[removed]:
                    formed -= 1
                window[removed] -= 1
            left += 1
    if best_len == float("inf"):
        return ""
    return s[best_left:best_left + best_len]
```

```python
assert min_window("ADOBECODEBANC", "ABC") == "BANC"
assert min_window("a", "a") == "a"
assert min_window("a", "aa") == ""
```

状态解释：

- `need[c]`：目标需要字符 `c` 的次数。
- `window[c]`：当前窗口拥有字符 `c` 的次数。
- `formed`：已经完全满足频次要求的字符种类数。
- `required`：目标中不同字符的种类数。
- `formed == required`：当前窗口合法，可以尝试收缩。

常见错误：

- 用 `set(t)`，丢失重复字符信息。
- `window[c] >= need[c]` 时反复增加 `formed`。
- 删除字符后再判断是否失效，导致状态晚更新一步。
- 返回最后一个合法窗口，而不是历史最短窗口。

### 8.4 LeetCode 567 - 字符串的排列

#### 解法一：固定窗口计数

若字符集限定为小写英文字母，可以使用长度 26 的数组。

```python
def check_inclusion_array(s1, s2):
    if len(s1) > len(s2):
        return False
    need = [0] * 26
    window = [0] * 26
    for char in s1:
        need[ord(char) - ord('a')] += 1
    for right, char in enumerate(s2):
        window[ord(char) - ord('a')] += 1
        if right >= len(s1):
            old = s2[right - len(s1)]
            window[ord(old) - ord('a')] -= 1
        if window == need:
            return True
    return False
```

```python
assert check_inclusion_array("ab", "eidbaooo")
assert not check_inclusion_array("ab", "eidboaoo")
```

#### 解法二：维护差异数量

每次比较两个 26 长数组是 O(26)，渐进复杂度仍为 O(n)。

若字符集很大，可维护非零差异项数量，避免完整比较。

```python
def check_inclusion_diff(s1, s2):
    if len(s1) > len(s2):
        return False
    diff = [0] * 26
    for char in s1:
        diff[ord(char) - 97] -= 1
    for char in s2[:len(s1)]:
        diff[ord(char) - 97] += 1
    nonzero = sum(value != 0 for value in diff)
    if nonzero == 0:
        return True
    width = len(s1)
    for right in range(width, len(s2)):
        incoming = ord(s2[right]) - 97
        outgoing = ord(s2[right - width]) - 97
        for index, delta in ((incoming, 1), (outgoing, -1)):
            before = diff[index]
            after = before + delta
            if before == 0 and after != 0:
                nonzero += 1
            elif before != 0 and after == 0:
                nonzero -= 1
            diff[index] = after
        if nonzero == 0:
            return True
    return False
```

### 8.7 LeetCode 424 - 替换后的最长重复字符

```python
def character_replacement(s, k):
    counts = [0] * 26
    left = 0
    max_frequency = 0
    best = 0
    for right, char in enumerate(s):
        index = ord(char) - 65
        counts[index] += 1
        max_frequency = max(max_frequency, counts[index])
        while right - left + 1 - max_frequency > k:
            counts[ord(s[left]) - 65] -= 1
            left += 1
        best = max(best, right - left + 1)
```

### 8.10 LeetCode 992 - K 个不同整数的子数组

“恰好 K 个”不易直接维护，但可以转化为：

$$
exactly(K)=atMost(K)-atMost(K-1)
$$

```python
from collections import defaultdict


def subarrays_with_at_most_k_distinct(nums, k):
    if k < 0:
        return 0
    counts = defaultdict(int)
    left = 0
    total = 0
    for right, value in enumerate(nums):
        counts[value] += 1
        while len(counts) > k:
            old = nums[left]
            counts[old] -= 1
            if counts[old] == 0:
                del counts[old]
            left += 1
        total += right - left + 1
    return total


def subarrays_with_k_distinct(nums, k):
    return (
        subarrays_with_at_most_k_distinct(nums, k)
        - subarrays_with_at_most_k_distinct(nums, k - 1)
    )
```

`right - left + 1` 的含义：

- 固定右端点 `right`。
- 当前最左合法起点为 `left`。
- 从 `left` 到 `right` 之间任意位置作为起点都合法。
- 因而以 `right` 结尾的合法子数组共有 `right-left+1` 个。

### 8.11 滑动窗口选择清单

遇到连续区间题，依次检查：

1. 窗口长度是否固定？
2. 约束是否能用一个计数或一个和维护？
3. 加入右端元素后，非法状态是否只需移动左端即可恢复？
4. 每个元素是否至多进入和离开窗口一次？
5. 题目求最长时，合法后更新答案。
6. 题目求最短时，合法后持续收缩并更新答案。
7. 题目求数量时，考虑累加 `right-left+1`。
8. 题目求恰好 K 时，考虑 `atMost(K)-atMost(K-1)`。
9. 若含负数，重新审查单调性，不要机械套模板。
10. 若字符集固定，数组计数通常比哈希表更简单。

## 9. LeetCode 深入：前缀和与哈希

### 9.1 LeetCode 560 - 和为 K 的子数组

令 `prefix[j]` 为前 `j` 个元素之和。

子数组 `[i, j)` 的和为 `prefix[j] - prefix[i]`。

要让它等于 `k`，需要此前出现过 `prefix[i] = prefix[j] - k`。

```python
from collections import defaultdict


def subarray_sum(nums, k):
    frequency = defaultdict(int)
    frequency[0] = 1
    prefix = 0
    answer = 0
    for value in nums:
        prefix += value
        answer += frequency[prefix - k]
        frequency[prefix] += 1
    return answer
```

为什么初始化 `frequency[0] = 1`？

- 它代表“空前缀”出现一次。
- 当从下标 0 开始的子数组和恰好为 `k` 时，能够被统一统计。
- 若不初始化，需要为起点为 0 的答案写额外分支。

为什么先查询、后更新？

- 子数组必须至少含一个元素。
- 先更新可能把当前前缀与自己配对。
- 当 `k == 0` 时，这会错误增加一个空子数组。

```python
assert subarray_sum([1, 1, 1], 2) == 2
assert subarray_sum([1, 2, 3], 3) == 2
assert subarray_sum([0, 0], 0) == 3
```

#### 对比暴力解法

```python
def subarray_sum_bruteforce(nums, k):
    answer = 0
    for left in range(len(nums)):
        total = 0
        for right in range(left, len(nums)):
            total += nums[right]
            if total == k:
                answer += 1
    return answer
```

- 暴力：O(n²) 时间，O(1) 空间。
- 前缀哈希：O(n) 期望时间，O(n) 空间。
- 暴力适合作为随机测试的正确性基准。

### 9.2 LeetCode 974 - 和可被 K 整除的子数组

- 某些语言中负数取模可能为负。
- 跨语言实现可使用 `(remainder % k + k) % k` 归一化。

### 9.3 LeetCode 525 - 连续数组

把 0 看成 -1，问题转化为“最长和为 0 的子数组”。

求最长长度时，哈希表保存某前缀和**第一次**出现的位置。

```python
def find_max_length(nums):
    first = {0: -1}
    balance = 0
    best = 0
    for index, value in enumerate(nums):
        balance += 1 if value == 1 else -1
        if balance in first:
            best = max(best, index - first[balance])
        else:
            first[balance] = index
    return best
```

```python
assert find_max_length([0, 1]) == 2
assert find_max_length([0, 1, 0]) == 2
```

对比 LeetCode 560：

- 求数量：保存每个前缀状态出现的次数。
- 求最长：保存每个前缀状态最早出现的位置。
- 求最短：通常保存最近位置，或结合单调结构。

### 9.4 LeetCode 523 - 连续的子数组和

需要长度至少为 2，并且子数组和是 `k` 的倍数。

```python
def check_subarray_sum(nums, k):
    first = {0: -1}
    prefix = 0
    for index, value in enumerate(nums):
        prefix += value
        state = prefix if k == 0 else prefix % k
        if state in first:
            if index - first[state] >= 2:
                return True
        else:
            first[state] = index
    return False
```

### 9.6 LeetCode 238 - 除自身以外数组的乘积

#### 解法一：左右乘积数组

```python
def product_except_self_two_arrays(nums):
    n = len(nums)
    left = [1] * n
    right = [1] * n
    for i in range(1, n):
        left[i] = left[i - 1] * nums[i - 1]
    for i in range(n - 2, -1, -1):
        right[i] = right[i + 1] * nums[i + 1]
    return [left[i] * right[i] for i in range(n)]
```

#### 解法二：输出数组复用为前缀积

```python
def product_except_self(nums):
    n = len(nums)
    answer = [1] * n
    prefix = 1
    for i in range(n):
        answer[i] = prefix
        prefix *= nums[i]
    suffix = 1
    for i in range(n - 1, -1, -1):
        answer[i] *= suffix
        suffix *= nums[i]
    return answer
```

```python
assert product_except_self([1, 2, 3, 4]) == [24, 12, 8, 6]
assert product_except_self([-1, 1, 0, -3, 3]) == [0, 0, 9, 0, 0]
```

- 两数组解法额外空间 O(n)，概念直观。
- 复用输出数组后，除返回结果外额外空间 O(1)。
- 使用总乘积再除法会遇到 0，并且题目明确禁止除法。

### 9.7 LeetCode 304 - 二维区域和检索

```python
class NumMatrixPrefix:
    def __init__(self, matrix):
        rows = len(matrix)
        cols = len(matrix[0]) if rows else 0
        self.prefix = [[0] * (cols + 1) for _ in range(rows + 1)]
        for row in range(rows):
            running = 0
            for col in range(cols):
                running += matrix[row][col]
                self.prefix[row + 1][col + 1] = (
                    self.prefix[row][col + 1] + running
                )

    def sumRegion(self, row1, col1, row2, col2):
        p = self.prefix
        return (
            p[row2 + 1][col2 + 1]
            - p[row1][col2 + 1]
            - p[row2 + 1][col1]
            + p[row1][col1]
        )
```

构造时按行维护 `running`，等价于完整容斥递推，但更容易检查。

### 10.7 LeetCode 4 - 寻找两个正序数组的中位数

在较短数组上二分切分位置。

```python
def find_median_sorted_arrays(a, b):
    if len(a) > len(b):
        a, b = b, a
    m, n = len(a), len(b)
    half = (m + n + 1) // 2
    left, right = 0, m
    while left <= right:
        cut_a = (left + right) // 2
        cut_b = half - cut_a
        a_left = float('-inf') if cut_a == 0 else a[cut_a - 1]
        a_right = float('inf') if cut_a == m else a[cut_a]
        b_left = float('-inf') if cut_b == 0 else b[cut_b - 1]
        b_right = float('inf') if cut_b == n else b[cut_b]
        if a_left <= b_right and b_left <= a_right:
            if (m + n) % 2:
                return max(a_left, b_left)
            return (max(a_left, b_left) + min(a_right, b_right)) / 2
        if a_left > b_right:
            right = cut_a - 1
        else:
            left = cut_a + 1
    raise ValueError("inputs must be sorted")
```

```python
assert find_median_sorted_arrays([1, 2], [3, 4]) == 2.5
```

复杂度对比：

- 合并后取中位数：O(m+n) 时间，O(m+n) 空间。
- 双指针走到中点：O(m+n) 时间，O(1) 空间。
- 分割二分：O(log(min(m,n))) 时间，O(1) 空间。

```python
def remove_duplicates(nums):

    write = 1
```

### 11.4 LeetCode 189 - 轮转数组

#### 解法一：三次翻转

```python
def rotate_array(nums, k):
    n = len(nums)
    if n == 0:
        return
    k %= n
    nums.reverse()
    nums[:k] = reversed(nums[:k])
    nums[k:] = reversed(nums[k:])
```

#### 解法二：环状替换

```python
def rotate_array_cycles(nums, k):
    n = len(nums)
    if n == 0:
        return
    k %= n
    moved = 0
    start = 0
    while moved < n:
        current = start
        previous = nums[current]
        while True:
            nxt = (current + k) % n
            nums[nxt], previous = previous, nums[nxt]
            current = nxt
            moved += 1
            if current == start:
                break
        start += 1
```

- 环状替换展示置换环思想，代码边界更多。
- 切片构造 `nums[:] = nums[-k:] + nums[:-k]` 最直观，但额外空间 O(n)。

### 11.5 LeetCode 41 - 缺失的第一个正数

长度为 `n` 的数组，答案一定在 `[1, n+1]`。

把值 `x` 放到下标 `x-1`。

```python
def first_missing_positive(nums):
    n = len(nums)
    for i in range(n):
        while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
            target = nums[i] - 1
            nums[i], nums[target] = nums[target], nums[i]
    for i, value in enumerate(nums):
        if value != i + 1:
            return i + 1
    return n + 1
```

```python
assert first_missing_positive([1, 2, 0]) == 3
assert first_missing_positive([3, 4, -1, 1]) == 2
assert first_missing_positive([7, 8, 9, 11, 12]) == 1
```

为什么是 O(n)？

- 虽然存在嵌套 `while`，每次交换至少把一个合法值放到最终位置。
- 每个位置被正确占据后不会再次搬走。
- 总交换次数不超过 O(n)。

### 11.6 LeetCode 48 - 旋转图像

#### 解法一：转置 + 每行翻转

```python
def rotate_matrix(matrix):

    for row in range(n):
        for col in range(row + 1, n):
            matrix[row][col], matrix[col][row] = (
                matrix[col][row], matrix[row][col]
```

坐标变化：

```python
    for layer in range(n // 2):
        first = layer
        last = n - 1 - layer
        for offset in range(last - first):
            top = matrix[first][first + offset]
            matrix[first][first + offset] = matrix[last - offset][first]
            matrix[last - offset][first] = matrix[last][last - offset]
            matrix[last][last - offset] = matrix[first + offset][last]
            matrix[first + offset][last] = top
```

### 11.7 LeetCode 54 - 螺旋矩阵

```python
def spiral_order(matrix):
    if not matrix or not matrix[0]:
        return []
    top, bottom = 0, len(matrix) - 1
    left, right = 0, len(matrix[0]) - 1
    answer = []
    while top <= bottom and left <= right:
        for col in range(left, right + 1):
            answer.append(matrix[top][col])
        top += 1
        for row in range(top, bottom + 1):
            answer.append(matrix[row][right])
        right -= 1
        if top <= bottom:
            for col in range(right, left - 1, -1):
                answer.append(matrix[bottom][col])
            bottom -= 1
        if left <= right:
            for row in range(bottom, top - 1, -1):
                answer.append(matrix[row][left])
            left += 1
    return answer
```

边界更新顺序很重要：

- 遍历完上边界后立刻 `top += 1`。
- 遍历完右边界后立刻 `right -= 1`。
- 遍历下边界前检查 `top <= bottom`。
- 遍历左边界前检查 `left <= right`。
- 单行或单列矩阵不会被重复访问。

### 11.8 LeetCode 73 - 矩阵置零

#### 解法一：行列集合

```python
def set_zeroes_sets(matrix):
    zero_rows = set()
    zero_cols = set()
    for row in range(len(matrix)):
        for col in range(len(matrix[0])):
            if matrix[row][col] == 0:
                zero_rows.add(row)
                zero_cols.add(col)
    for row in range(len(matrix)):
        for col in range(len(matrix[0])):
            if row in zero_rows or col in zero_cols:

```

#### 解法二：首行首列作为标记

```python
def set_zeroes_constant_space(matrix):
    rows, cols = len(matrix), len(matrix[0])
    first_row_zero = any(matrix[0][col] == 0 for col in range(cols))
    first_col_zero = any(matrix[row][0] == 0 for row in range(rows))
    for row in range(1, rows):
        for col in range(1, cols):
            if matrix[row][col] == 0:
                matrix[row][0] = 0
                matrix[0][col] = 0
    for row in range(1, rows):
        for col in range(1, cols):
            if matrix[row][0] == 0 or matrix[0][col] == 0:
                matrix[row][col] = 0
    if first_row_zero:
        for col in range(cols):
            matrix[0][col] = 0
    if first_col_zero:
        for row in range(rows):
            matrix[row][0] = 0
```

为何最后处理首行首列？

- 它们在中间阶段承担标记数组的角色。
- 提前清零会污染标记，让额外行列被错误清零。
- 两个布尔变量分别保存它们原本是否应清零。

### 11.9 LeetCode 128 - 最长连续序列

```python
def longest_consecutive(nums):

    for value in values:
        if value - 1 in values:

        current = value
```

## 12. 多解法选择与面试表达

### 12.1 先说暴力，再优化

推荐表达顺序：

1. 明确暴力枚举对象，例如所有区间、所有二元组或所有切分点。
2. 给出暴力复杂度，指出重复计算在哪里。
3. 找出可复用状态，例如窗口计数、前缀和或上次位置。
4. 写出优化算法的循环不变量。
5. 说明时间与空间权衡。
6. 主动覆盖空输入、单元素、重复值、负数和极端边界。

### 12.2 题型到方法的映射

| 题目信号 | 首选方法 | 备选方法 |
| :--- | :--- | :--- |
| 有序数组两数关系 | 双指针 | 二分每个元素 |
| 最长合法连续区间 | 滑动窗口 | 前缀状态 |
| 子数组和等于 K 且含负数 | 前缀和 + 哈希 | O(n²) 枚举 |
| 多次区间求和 | 前缀和 | 树状数组处理更新 |
| 第一个满足条件的答案 | 二分答案 | 线性扫描 |
| 原地删除 | 快慢指针 | 新建结果数组 |

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
