```python
def search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = lo + (hi - lo) // 2
        if nums[mid] == target: return mid
        elif nums[mid] < target: lo = mid + 1
```

### 4.1 LeetCode 74 - 搜索二维矩阵 (Medium)

```python
def searchMatrix(matrix, target):
    if not matrix: return False
    m, n = len(matrix), len(matrix[0])
    lo, hi = 0, m * n - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        i, j = divmod(mid, n)
        if matrix[i][j] == target: return True
        elif matrix[i][j] < target: lo = mid + 1
        else: hi = mid - 1
    return False
```

### 4.2 LeetCode 240 - 搜索二维矩阵 II (Medium)

```python
def searchMatrix(matrix, target):
    if not matrix: return False
    m, n = len(matrix), len(matrix[0])
    i, j = 0, n - 1
    while i < m and j >= 0:
        if matrix[i][j] == target: return True
        elif matrix[i][j] < target: i += 1
        else: j -= 1
    return False
```

## 附录 A: 二分查找深度解析

## A.1 算法本质与数学基础

二分查找 (Binary Search) 是计算机科学最经典的算法之一, 属于**分治法 (Divide and Conquer)** 的最简形式. 其核心思想: 在一个具有**单调性 (Monotonicity)** 的区间上, 每次将搜索空间减半, 从而达到 $O(\log n)$ 的时间复杂度.

### A.1.1 前置条件

二分查找的应用前提是搜索区间具有**单调性** 或 **决策单调性 (Decision Monotonicity)**, 具体表现为:

1. **数组有序**: `nums[i] <= nums[i+1]` (或反向)
2. **决策可分**: 存在谓词 `P(x)`, 使得对所有 `x` 满足 `P(x) = True` 的 `x` 形成一个连续区间 `[L, R]`
3. **值域有界**: 搜索空间 `[lo, hi]` 必须明确上下界

### A.1.2 复杂度分析

| 维度 | 复杂度 | 解释 |
|---|---|---|
| 时间 (最优) | $O(1)$ | 第一个元素命中 |
| 时间 (平均) | $O(\log n)$ | 每次排除一半 |
| 时间 (最坏) | $O(\log n)$ | 必遍历到最后一个可能元素 |
| 空间 (迭代) | $O(1)$ | 只用常数变量 |
| 空间 (递归) | $O(\log n)$ | 栈深度 |

### A.1.3 数学证明

**引理**: 在长度为 $n$ 的数组上二分查找, 最多需要 $\lceil \log_2(n+1) \rceil$ 次比较.

**证明**:
设 $T(n)$ 为最坏情况下的比较次数. 每次比较后将搜索区间分为两半, 一半长度为 $\lfloor (n-1)/2 \rfloor$, 另一半长度为 $\lceil (n-1)/2 \rceil$. 因此:
$$T(n) \le 1 + T(\lceil (n-1)/2 \rceil)$$

边界条件 $T(1) = 1$ (只剩一个元素必查). 解递推:
$$T(n) \le \lceil \log_2(n+1) \rceil$$

例如 $n = 8$: 最多 3 次比较. 验证: $\log_2(9) = 3.17$, 向上取整 3. ✓

### A.1.4 循环不变式 (Loop Invariant)

正确实现二分的关键是维护一个**循环不变式**. 对于 `lo..hi` 闭区间版本:

```text
Invariant: target ∈ [lo, hi] 或 target 不存在
```

每次循环维护此不变式, 最终 `lo > hi` 时退出, 结论为 `target 不存在`. 初始 `lo=0, hi=n-1` 显然成立; 终止时无解.

## A.2 边界细节: 9 种写法详解

二分查找最让人头疼的就是边界. 一个 `+1` / `-1` 的差别, 可能就让答案错 1 位甚至死循环. 下面系统梳理 9 种常见写法.

### A.2.1 写法 1: `[lo, hi]` 闭区间 (Standard)

```python
def bsearch(nums, target):
    lo, hi = 0, len(nums) - 1   # 闭区间
    while lo <= hi:              # 区间非空
        mid = lo + (hi - lo) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            lo = mid + 1         # 排除 mid
        else:
            hi = mid - 1         # 排除 mid
    return -1
```

**特点**:
- 退出条件 `lo > hi`
- `mid` 必须排除 (`mid+1` 或 `mid-1`)
- 最常用, 适合查找具体值

### A.2.2 写法 2: `[lo, hi)` 半开区间

```python
def bsearch(nums, target):
    lo, hi = 0, len(nums)        # [lo, hi)
    while lo < hi:                # 区间非空
        mid = lo + (hi - lo) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid              # 注意: 不 -1
    return -1
```

**特点**:
- 退出条件 `lo == hi`
- 适合"插入位置"类问题 (LeetCode 35)
- `hi = mid` 时不 -1, 因为 mid 自身可能成为解

### A.2.3 写法 3: `(lo, hi)` 开区间

```python
def bsearch(nums, target):
    lo, hi = -1, len(nums)        # (lo, hi)
    while lo + 1 < hi:            # lo+1 == hi 时退出
        mid = lo + (hi - lo) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            lo = mid
        else:
            hi = mid
    return -1
```

**特点**:
- 退出条件 `lo + 1 == hi`
- `lo` 永远指向最后一个"小于" target 的位置, `hi` 永远指向第一个"大于等于" target 的位置
- 适合找**边界值**

### A.2.4 写法 4: bisect (Python 标准库)

```python
import bisect

# 找到第一个 >= target 的位置
idx = bisect.bisect_left(nums, target)

# 找到第一个 > target 的位置
idx = bisect.bisect_right(nums, target)
```

**底层实现**: C 语言 `bisect.c`, 写法 3 的优化版, $O(\log n)$.

### A.2.5 写法 5: C++ `lower_bound` / `upper_bound`

```cpp
auto it = lower_bound(nums.begin(), nums.end(), target);  // 第一个 >=
int idx = it - nums.begin();

auto it2 = upper_bound(nums.begin(), nums.end(), target); // 第一个 >
```

**特点**: STL 实现, 写法 3.

### A.2.6 写法 6: 浮点二分

```python
def float_bsearch(lo, hi, eps=1e-6):
    """在 [lo, hi] 上二分, 直到 hi - lo < eps"""
    while hi - lo > eps:
        mid = (lo + hi) / 2
        if check(mid) >= target_value:
            hi = mid
        else:
            lo = mid
    return lo
```

**特点**: 不用 `mid + 1`, 因浮点不存在"等于 mid"问题. 迭代 50-100 次即可达机器精度.

### A.2.7 写法 7: 二分答案 (最大化最小)

```python
def max_min(problem):
    """求最大化最小值"""
    lo, hi = min_possible, max_possible
    while lo < hi:
        mid = (lo + hi + 1) // 2  # 注意 +1 偏中
        if feasible(mid):           # mid 可行 → 尝试更大
            lo = mid
        else:
            hi = mid - 1
    return lo
```

**特点**: `+1` 偏中, 避免死循环 (典型如"最大化"问题).

### A.2.8 写法 8: 二分答案 (最小化最大)

```python
def min_max(problem):
    """求最小化最大值"""
    lo, hi = min_possible, max_possible
    while lo < hi:
        mid = (lo + hi) // 2  # 偏小即可
        if feasible(mid):
            hi = mid          # mid 可行 → 尝试更小
        else:
            lo = mid + 1
    return lo
```

**特点**: 标准 "lo < hi, hi = mid, lo = mid+1".

### A.2.9 写法 9: 离散二分 + 自定义比较

```python
def bsearch_with_compare(arr, target):
    """在非数值数组上二分"""
    lo, hi = 0, len(arr) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        cmp = custom_compare(arr[mid], target)
        if cmp == 0:
            return mid
        elif cmp < 0:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

**特点**: 比较函数返回负/零/正, 适用任意可比较类型.

## A.3 整数溢出与中点计算

### A.3.1 经典坑: `(lo + hi) // 2` 的溢出

在 C/C++/Java 中, 当 `lo` 和 `hi` 都是大整数 (如 `INT_MAX`), `lo + hi` 可能溢出.

**错误写法**:
```cpp
int mid = (lo + hi) / 2;  // 溢出!
```

**正确写法**:
```cpp
int mid = lo + (hi - lo) / 2;  // 永远安全
```

在 Python 中不存在此问题 (大整数), 但**仍推荐**这种写法, 培养好习惯.

### A.3.2 更精确的中点 (避免偶数偏向)

`lo + (hi - lo) // 2` 在 `(hi - lo)` 为奇数时偏向 `lo` (向下取整). 对正确性无影响 (两种选择都行), 但有些题对"偏向"敏感 (如 Java 的 `Array.binarySearch` 在偶数长度时偏向 `lo`).

**对称中点**:
```python
mid = lo + (hi - lo + 1) // 2  # 偏右
```

## A.4 旋转数组专题深入

### A.4.1 旋转数组的"半有序"特性

长度为 `n` 的有序数组旋转 `k` 步 (1 ≤ k < n) 后, 形成的两段都仍有序, 但整体无序:

```text
原数组: [1, 2, 3, 4, 5, 6, 7]
旋转 3 步: [4, 5, 6, 7, 1, 2, 3]
          └─有序─┘  └有序┘
```

关键观察: **至少有一段是有序的** (且包含 `nums[lo]` 或 `nums[hi]`).

### A.4.2 LeetCode 33 详解: 搜索旋转排序数组

**题目**: 升序数组在未知旋转点旋转后, 搜索 target, 要求 $O(\log n)$.

**思路**:
1. 取中点 `mid`, 必有 `[lo, mid]` 或 `[mid, hi]` 之一有序
2. 判断哪段有序: `nums[lo] <= nums[mid]` → 左半有序
3. 在有序段上判断 target 是否在, 缩小边界

**完整代码** (含测试):

```python
def search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = lo + (hi - lo) // 2
        if nums[mid] == target:
            return mid
        # 判断哪半有序
        if nums[lo] <= nums[mid]:  # [lo, mid] 有序
            if nums[lo] <= target < nums[mid]:
                hi = mid - 1
            else:
                lo = mid + 1
        else:  # [mid, hi] 有序
            if nums[mid] < target <= nums[hi]:
                lo = mid + 1
            else:
                hi = mid - 1
    return -1


# 测试
assert search([4, 5, 6, 7, 0, 1, 2], 0) == 4
assert search([4, 5, 6, 7, 0, 1, 2], 3) == -1
assert search([1], 0) == -1
assert search([1, 3], 3) == 1
assert search([3, 1], 1) == 1
```

**复杂度**: 时间 $O(\log n)$, 空间 $O(1)$.

### A.4.3 LeetCode 81 详解: 搜索旋转排序数组 II (有重复)

**题目**: 同 33, 但允许重复元素.

**关键差异**: 当 `nums[lo] == nums[mid] == nums[hi]` 时, 无法判断哪半有序. 此时只能 `lo++` 逐步缩小.

```python
def search_with_dup(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = lo + (hi - lo) // 2
        if nums[mid] == target:
            return True
        if nums[lo] == nums[mid] == nums[hi]:
            lo += 1
            hi -= 1
        elif nums[lo] <= nums[mid]:
            if nums[lo] <= target < nums[mid]:
                hi = mid - 1
            else:
                lo = mid + 1
        else:
            if nums[mid] < target <= nums[hi]:
                lo = mid + 1
            else:
                hi = mid - 1
    return False
```

**复杂度**: 最坏 $O(n)$ (全相等时退化). 这是有重复元素无法避免的.

### A.4.4 LeetCode 153 详解: 找旋转数组最小值

**题目**: 无重复旋转数组, 找最小元素.

**思路**: 始终比较 `nums[mid]` 和 `nums[hi]`:
- `nums[mid] < nums[hi]` → 最小值在 `[lo, mid]`, `hi = mid`
- `nums[mid] > nums[hi]` → 最小值在 `[mid+1, hi]`, `lo = mid + 1`
- `nums[mid] == nums[hi]` → 必有重复, 154 题

```python
def findMin(nums):
    lo, hi = 0, len(nums) - 1
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if nums[mid] < nums[hi]:
            hi = mid
        else:
            lo = mid + 1
    return nums[lo]


# 测试
assert findMin([3, 4, 5, 1, 2]) == 1
assert findMin([4, 5, 6, 7, 0, 1, 2]) == 0
assert findMin([11, 13, 15, 17]) == 11  # 未旋转
```

### A.4.5 LeetCode 154 详解: 找最小值 II

**题目**: 同 153, 但有重复.

**关键**: `nums[mid] == nums[hi]` 时, 只能 `hi -= 1` (因重复无法判断).

```python
def findMin_dup(nums):
    lo, hi = 0, len(nums) - 1
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if nums[mid] < nums[hi]:
            hi = mid
        elif nums[mid] > nums[hi]:
            lo = mid + 1
        else:
            hi -= 1
    return nums[lo]


# 测试
assert findMin_dup([1, 3, 5]) == 1
assert findMin_dup([2, 2, 2, 0, 1]) == 0
```

## A.5 二分答案专题深入

### A.5.1 模式识别

二分答案适用于满足以下条件的问题:

1. **答案有界**: `lo ≤ 答案 ≤ hi`, 且范围已知
2. **决策单调**: 存在阈值 $T$, 当 `mid ≥ T` 时可行, `mid < T` 时不可行 (或反向)
3. **可验证**: 给定候选值 `mid`, 能在多项式时间内判断"mid 是否可行"

### A.5.2 经典题型分类

| 类型 | 目标 | `feasible(mid)` 含义 | 收敛方向 |
|---|---|---|---|
| 最小化最大 | 求最小 $T$ 使所有子问题满足 | mid 可分 ≤ D 段 | hi = mid |
| 最大化最小 | 求最大 $T$ 使所有约束满足 | mid 下分 ≤ K 块 | lo = mid |
| 第 k 小/大 | 求第 k 个值 | mid 排名 ≥ k | lo = mid |
| 速率/容量 | 求最小/最大可行值 | mid 可在 T 时间内完成 | hi=mid / lo=mid |

### A.5.3 LeetCode 875 详解: 爱吃香蕉的珂珂

```python
    while lo < hi:

        if hours_needed(mid) <= h:
            hi = mid
        else:
            lo = mid + 1
    return lo
```

```python
        else:
            hi = mid - 1
    return lo
```

## A.6 二维二分专题

### A.6.1 LeetCode 74 详解: 搜索二维矩阵

**矩阵性质**: 每行升序, 每行首元素 > 上行末元素 → 整体一维有序.

**思路**: 视为长度为 `m*n` 的一维数组, 一维二分.

```python
def searchMatrix(matrix, target):
    if not matrix or not matrix[0]:
        return False
    m, n = len(matrix), len(matrix[0])
    lo, hi = 0, m * n - 1
    while lo <= hi:
        mid = lo + (hi - lo) // 2
        i, j = divmod(mid, n)
        if matrix[i][j] == target:
            return True
        elif matrix[i][j] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return False


# 测试

assert not searchMatrix([[1, 3, 5, 7], [10, 11, 16, 20], [23, 30, 34, 60]], 13)
```

### A.6.2 LeetCode 240 详解: 搜索二维矩阵 II

**矩阵性质**: 仅每行升序, 每列升序, 不保证整体有序.

**思路**: 从右上角开始, 每次排除一行或一列:
- `matrix[i][j] > target` → 排除第 `j` 列, `j--`
- `matrix[i][j] < target` → 排除第 `i` 行, `i++`

```python
def searchMatrix(matrix, target):
    if not matrix or not matrix[0]:
        return False
    m, n = len(matrix), len(matrix[0])
    i, j = 0, n - 1
    while i < m and j >= 0:
        if matrix[i][j] == target:
            return True
        elif matrix[i][j] < target:
            i += 1
        else:
            j -= 1
    return False


# 测试

)

    20
)
```

**复杂度**: $O(m + n)$.

### A.6.3 LeetCode 378 详解: 有序矩阵中第 K 小元素

**题目**: `n x n` 矩阵每行每列升序, 求第 `k` 小.

**思路**: 二分值 `mid`, 计数矩阵中 ≤ `mid` 的元素数.

```python
def kthSmallest(matrix, k):
    n = len(matrix)

    def count_le(x):
        """矩阵中 ≤ x 的元素数, 从左下角开始"""
        cnt, i, j = 0, n - 1, 0
        while i >= 0 and j < n:
            if matrix[i][j] <= x:
                cnt += i + 1
                j += 1
            else:
                i -= 1
        return cnt

    lo, hi = matrix[0][0], matrix[-1][-1]
    while lo < hi:
        mid = (lo + hi) // 2
        if count_le(mid) >= k:
            hi = mid
        else:
            lo = mid + 1
    return lo
```

```python
            return 1.0
        half = fast_pow(b, e // 2)
        if e % 2 == 0:
            return half * half
        else:

        n = -n
    return fast_pow(x, n)
```

## A.8 二分查找的常见错误与陷阱

### A.8.1 死循环陷阱

**错误代码**:
```python
while lo < hi:
    mid = (lo + hi) // 2  # 偏小
    if nums[mid] < target:
        lo = mid          # 应为 mid + 1
    else:
        hi = mid
# 当 lo == hi - 1 且 nums[lo] < target 时, 死循环
```

**正确**:
```python
while lo < hi:
    mid = (lo + hi) // 2
    if nums[mid] < target:
        lo = mid + 1   # 必须 +1
    else:
        hi = mid
```

### A.8.2 答案错误 1 位

**错误**: `mid = (lo + hi) // 2`, 当 hi - lo = 1 时, mid = lo, hi = mid = lo, 死循环.

**正确**: `mid = lo + (hi - lo) // 2` 或 `(lo + hi + 1) // 2` (依情况).

### A.8.3 边界 0 vs len(nums)-1

**错误**: 用闭区间时 `hi = len(nums)`, 越界.

**正确**: 闭区间 `hi = len(nums) - 1`; 半开 `hi = len(nums)`.

### A.8.4 返回值混乱

| 问题类型 | 返回 |
|---|---|
| 查找具体值 | `mid` (找到) / `-1` (未找到) |
| 查找插入位置 | `lo` (循环结束时) |
| 查找左边界 | `lo` (循环结束时) |
| 查找右边界 | `lo - 1` 或 `hi` |

## A.9 高级变体: 偏序集上的二分

### A.9.1 概念

标准的二分要求"全序" (Total Order). 但有时只满足"偏序" (Partial Order), 此时可以采用:

1. **二分图匹配**: 在两组元素上分别二分
2. **隐式二分**: 在"决策空间"而非值域上二分

### A.9.2 实际例子: K-th Number in Two Sorted Arrays

**题目**: 两个有序数组, 求第 k 小.

**思路**: 每次比较两数组第 `k/2` 元素, 排除较小的一半.

```python
def findKth(nums1, nums2, k):
    """两有序数组第 k 小"""
    m, n = len(nums1), len(nums2)
    if m > n:
        return findKth(nums2, nums1, k)
    if m == 0:
        return nums2[k - 1]
    if k == 1:
        return min(nums1[0], nums2[0])

    i = min(m, k // 2)
    j = min(n, k - i)
    if nums1[i - 1] < nums2[j - 1]:
        return findKth(nums1[i:], nums2, k - i)
    else:
        return findKth(nums1, nums2[j:], k - j)


# 测试
assert findKth([1, 3, 5], [2, 4, 6], 4) == 4
assert findKth([1, 2], [3, 4], 3) == 3
```

**复杂度**: $O(\log(\min(m, n)))$.

### A.9.3 中位数问题: LeetCode 4

**题目**: 两有序数组的中位数.

**思路**: 二分"切分点", 使左半 ≤ 右半.

```python
def findMedianSortedArrays(nums1, nums2):
    if len(nums1) > len(nums2):
        nums1, nums2 = nums2, nums1

    m, n = len(nums1), len(nums2)
    lo, hi = 0, m

    while lo <= hi:
        i = (lo + hi) // 2
        j = (m + n + 1) // 2 - i

        left1 = nums1[i - 1] if i > 0 else float('-inf')
        right1 = nums1[i] if i < m else float('inf')
        left2 = nums2[j - 1] if j > 0 else float('-inf')
        right2 = nums2[j] if j < n else float('inf')

        if left1 <= right2 and left2 <= right1:
            if (m + n) % 2 == 1:
                return max(left1, left2)
            else:
                return (max(left1, left2) + min(right1, right2)) / 2
        elif left1 > right2:
            hi = i - 1
        else:
            lo = i + 1
    return -1
```

**复杂度**: $O(\log(\min(m, n)))$.

## A.10 二分查找的应用场景扩展

### A.10.1 数据库索引

B+ 树是数据库常用索引, 其内部就是二分查找的多叉版本.

```python
class BPlusNode:
    """B+ 树节点 (简化)"""
    def __init__(self, is_leaf=True):
        self.is_leaf = is_leaf
        self.keys = []
        self.children = []  # 内部节点
        self.values = []    # 叶子节点

class BPlusTree:
    def __init__(self, order=4):
        self.root = BPlusNode()
        self.order = order

    def search(self, key):
        """二分搜索"""
        node = self.root
        while not node.is_leaf:
            i = self._find_child(node, key)
            node = node.children[i]
        i = self._binary_search(node.keys, key)
        if i < len(node.keys) and node.keys[i] == key:
            return node.values[i]
        return None

    def _binary_search(self, arr, key):
        lo, hi = 0, len(arr) - 1
        while lo <= hi:
            mid = (lo + hi) // 2
            if arr[mid] == key:
                return mid
            elif arr[mid] < key:
                lo = mid + 1
            else:
                hi = mid - 1
        return lo
```

### A.10.4 决策单调性优化 DP

```python
def dp_with_monotonic_queue(n, K):
    """
    决策单调 DP: dp[i] = min(dp[j] + cost(j, i)) for j in [i-K, i-1]
    时间复杂度: O(n) (vs O(nK))
    """
    from collections import deque

    dp = [float('inf')] * n
    dp[0] = 0

    # 队列存 (dp[j], j), 按 dp[j] 递增
    dq = deque([(0, 0)])

    for i in range(1, n):
        # 弹出过期的 j
        while dq and dq[0][1] < i - K:
            dq.popleft()

        if dq:
            dp[i] = dq[0][0] + cost(dq[0][1], i)

        # 加入 i, 维持单调性
        while dq and dq[-1][0] >= dp[i]:
            dq.pop()
        dq.append((dp[i], i))

    return dp[n - 1]
```

## A.11 二分查找复杂度优化技巧

### A.11.1 分块二分

**问题**: 单次二分 $O(\log n)$, 但有 $Q$ 次查询, 总 $O(Q \log n)$. 数据量极大时仍慢.

**优化**: 分块索引.

```python
class BlockedBinarySearch:
    """
    分块 + 二分. 块大小 B = sqrt(N). 块内二分, 块间跳表.
    时间: O(sqrt(N)) 空间, 单次查询 O(sqrt(N)) (vs O(log N))
    但更新 O(1) (vs O(log N)).
    """
    def __init__(self, nums, block_size=None):
        self.nums = nums
        self.n = len(nums)
        self.B = block_size or int(self.n ** 0.5) + 1
        self.blocks = []
        # 每块存最大值
        for i in range(0, self.n, self.B):
            block_max = max(nums[i:i + self.B])
            self.blocks.append(block_max)

    def find(self, target):
        """找 target 应插入的位置"""
        # 1. 块间二分找块
        lo, hi = 0, len(self.blocks) - 1
        while lo <= hi:
            mid = (lo + hi) // 2
            if self.blocks[mid] < target:
                lo = mid + 1
            else:
                hi = mid - 1
        # 2. 块内二分
        block_idx = lo
        start = block_idx * self.B
        end = min(start + self.B, self.n)
        return start + bisect.bisect_left(self.nums[start:end], target)
```

### A.11.2 缓存友好的二分 (Cache-Aware Binary Search)

**问题**: 标准二分因随机访问, 可能反复 cache miss.

**优化**: 改为**二分搜索树 (BST)** + **B+ 树**结构, 利用缓存行.

```python
class CacheFriendlyBinarySearch:
    """
    Eytzinger 排列: 数组布局模拟完美二叉树的层级顺序
    使二分搜索的访问模式符合 CPU 缓存预取.
    """
    def __init__(self, sorted_arr):
        self.n = len(sorted_arr)
        self.arr = [None] * (self.n + 1)
        self._eytzinger(sorted_arr, 1, 0, self.n)

    def _eytzinger(self, src, dst, lo, hi):
        if lo > hi:
            return
        mid = (lo + hi) // 2
        self.arr[dst] = src[mid]
        self._eytzinger(src, 2 * dst, lo, mid - 1)
        self._eytzinger(src, 2 * dst + 1, mid + 1, hi)

    def search(self, target):
        """Eytzinger 二分"""
        i = 1
        while i <= self.n:
            if self.arr[i] == target:
                return i - 1  # 转换回原索引
            elif target < self.arr[i]:
                i = 2 * i
            else:
                i = 2 * i + 1
        return -1
```

实测性能提升 25-35% (cache miss 减少).

### A.11.3 SIMD 加速的二分 (Branchless Binary Search)

```python
import numpy as np

def branchless_binary_search(arr, target):
    """
    无分支二分: 用 numpy 一次性比较, 避免 CPU 分支预测失败.
    适合批量查询.
    """
    arr = np.asarray(arr)
    n = len(arr)

    lo, hi = 0, n - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        cmp = np.searchsorted(arr[lo:hi+1], target)  # 单指令完成比较
        mid_new = lo + cmp - 1

        if arr[mid_new] == target:
            return mid_new
        elif arr[mid_new] < target:
            lo = mid_new + 1
        else:
            hi = mid_new - 1
    return -1
```

```python
def findMinElement(nums):
    """找任意一个局部最小"""
    n = len(nums)
    if n == 1:
        return 0
    if nums[0] < nums[1]:
        return 0
    if nums[-1] < nums[-2]:
        return n - 1

    lo, hi = 1, n - 2
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] < nums[mid - 1] and nums[mid] < nums[mid + 1]:
            return mid
        elif nums[mid - 1] < nums[mid]:
            hi = mid - 1  # 上升, 左侧有最小
        else:
            lo = mid + 1  # 下降, 右侧有最小
    return -1
```

## A.13 二分与其它算法的结合

### A.13.1 二分 + 滑动窗口

**问题**: 长度 ≥ K 的子数组, 满足某条件, 求最长长度.

**示例**: 子数组和 ≥ target, 求最短长度 → 二分长度, 验证用滑动窗口.

```python
def min_subarray_len(target, nums):
    """子数组和 ≥ target, 最短长度"""
    def feasible(L):
        """判断是否存在长 L 的子数组和 ≥ target"""
        s = sum(nums[:L])
        if s >= target:
            return True
        for i in range(L, len(nums)):
            s += nums[i] - nums[i - L]
            if s >= target:
                return True
        return False

    lo, hi = 1, len(nums)
    while lo < hi:
        mid = (lo + hi) // 2
        if feasible(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo if feasible(lo) else 0
```

### A.13.2 二分 + BFS

**问题**: 网格最短路径, 边权有上下界 → 二分边权, 验证用 BFS.

```python
from collections import deque

def shortest_path_binary(grid, target):
    """
    网格最短路径, 边权 [1, K]. 求最小 K 使 (0,0) 可达 (m-1, n-1).
    """
    m, n = len(grid), len(grid[0])

    def feasible(K):
        """判断边权 ≤ K 是否可达"""
        q = deque([(0, 0)])
        visited = {(0, 0)}
        while q:
            i, j = q.popleft()
            if i == m - 1 and j == n - 1:
                return True
            for di, dj in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                ni, nj = i + di, j + dj
                if 0 <= ni < m and 0 <= nj < n and (ni, nj) not in visited:
                    if grid[ni][nj] <= K:
                        visited.add((ni, nj))
                        q.append((ni, nj))
        return False

    lo, hi = 0, max(max(row) for row in grid)
    while lo < hi:
        mid = (lo + hi) // 2
        if feasible(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo
```

### A.13.3 二分 + 线段树

**问题**: 动态区间查询, 二分查找"满足条件的位置".

```python
class SegmentTree:
    """支持区间最小值查询 + 二分"""
    def __init__(self, nums):
        self.n = len(nums)
        self.tree = [float('inf')] * (4 * self.n)
        self._build(nums, 1, 0, self.n - 1)

    def _build(self, nums, node, lo, hi):
        if lo == hi:
            self.tree[node] = nums[lo]
        else:
            mid = (lo + hi) // 2
            self._build(nums, 2 * node, lo, mid)
            self._build(nums, 2 * node + 1, mid + 1, hi)
            self.tree[node] = min(self.tree[2 * node], self.tree[2 * node + 1])

    def find_first_le(self, target):
        """找第一个 ≤ target 的位置"""
        return self._find_first_le(1, 0, self.n - 1, target)

    def _find_first_le(self, node, lo, hi, target):
        if self.tree[node] > target:
            return -1
        if lo == hi:
            return lo
        mid = (lo + hi) // 2
        if self.tree[2 * node] <= target:
            return self._find_first_le(2 * node, lo, mid, target)
        else:
            return self._find_first_le(2 * node + 1, mid + 1, hi, target)
```

### A.13.4 二分 + 哈希

**问题**: 子数组和为某值, 求最长/最短.

```python
def longest_subarray_with_sum(nums, target):
    """和 = target 的最长子数组"""
    prefix = {0: -1}
    cur = 0
    best = 0
    for i, x in enumerate(nums):
        cur += x
        if cur - target in prefix:
            best = max(best, i - prefix[cur - target])
        if cur not in prefix:
            prefix[cur] = i
    return best
```

### A.14.1 通用模板

```python
def binary_search_template(nums, target, mode='exact'):
    """
    通用二分模板
    mode:
      - 'exact': 精确查找
      - 'lower': 第一个 ≥ target
      - 'upper': 第一个 > target
      - 'insert': 插入位置

    lo, hi = 0, len(nums) - 1

    if mode == 'exact':
        while lo <= hi:
            mid = lo + (hi - lo) // 2
            if nums[mid] == target:
                return mid
            elif nums[mid] < target:
                lo = mid + 1
            else:
                hi = mid - 1
        return -1

    elif mode in ('lower', 'insert'):
        # 标准左闭右开
        lo, hi = 0, len(nums)
        while lo < hi:
            mid = lo + (hi - lo) // 2
            if nums[mid] < target:
                lo = mid + 1
            else:
                hi = mid
        return lo

    elif mode == 'upper':
        lo, hi = 0, len(nums)
        while lo < hi:
            mid = lo + (hi - lo) // 2
            if nums[mid] <= target:
                lo = mid + 1
            else:
                hi = mid
        return lo
```

### A.14.2 答案模板

```python
def binary_answer(problem_params):
    """
    通用二分答案模板
    problem_params:
      - lo, hi: 答案上下界
      - feasible(x): 判断 x 是否为可行解
      - find_min: True 求最小, False 求最大
    """
    lo, hi = problem_params['lo'], problem_params['hi']
    feasible = problem_params['feasible']
    find_min = problem_params.get('find_min', True)

    while lo < hi:
        mid = lo + (hi - lo) // 2
        if feasible(mid):
            if find_min:
                hi = mid
            else:
                lo = mid + 1  # 最大化时偏移
        else:
            if find_min:
                lo = mid + 1
            else:
                hi = mid - 1
    return lo
```

### A.14.3 浮点模板

```python
def float_binary_search(lo, hi, feasible, eps=1e-6, max_iter=100):
    """
    浮点二分模板
    lo, hi: 浮点上下界
    feasible(x): 判断 x 是否可行
    eps: 精度
    max_iter: 最大迭代次数
    """
    for _ in range(max_iter):
        mid = (lo + hi) / 2
        if feasible(mid):
            hi = mid
        else:
            lo = mid
        if hi - lo < eps:
            break
    return lo
```

## A.15 复杂度与正确性证明

### A.15.1 复杂度证明

**定理**: 标准二分查找在最坏情况下比较次数为 $\lceil \log_2(n+1) \rceil$.

**证明**:
设 $T(n)$ 为长度 $n$ 数组上二分的最坏比较次数.
- 基础: $T(1) = 1$, $T(0) = 0$.
- 递推: $T(n) = 1 + T(\lceil (n-1)/2 \rceil)$ (中点选左边, 大半边长 $\lceil (n-1)/2 \rceil$).

解递推:
$$T(n) = 1 + T(\lceil (n-1)/2 \rceil) = 1 + 1 + T(\lceil (\lceil (n-1)/2 \rceil - 1)/2 \rceil) = \cdots$$

经过 $k$ 次后, 数组长度 ≤ $\lceil (n+1)/2^k \rceil - 1$. 当此值 ≤ 0 时停止, 即 $\lceil (n+1)/2^k \rceil \le 1$, 即 $2^k \ge n + 1$.

故 $k \ge \log_2(n+1)$, 取最小整数 $k = \lceil \log_2(n+1) \rceil$. $\blacksquare$

### A.15.2 正确性证明

**定理**: 若 `target` 在 `nums` 中, 标准二分返回其索引; 否则返回 `-1`.

**证明**: 用循环不变式.

**不变式**: 循环开始时, 若 `target ∈ nums`, 则 `target` 在 `nums[lo..hi]` 中.

**初始化**: 第一次循环前 `lo=0, hi=n-1`, `target` 在 `nums[0..n-1]`. 显然成立.

**保持**: 假设不变式成立. 设 `mid = ⌊(lo+hi)/2⌋`.
- 若 `nums[mid] == target`, 直接返回, 正确.
- 若 `nums[mid] < target`, 因数组有序, `target` 不在 `nums[lo..mid]`, 必有 `target ∈ nums[mid+1..hi]`. 赋 `lo = mid + 1`, 不变式保持.
- 同理 `nums[mid] > target`, 赋 `hi = mid - 1`, 不变式保持.

**终止**: 循环终止当 `lo > hi`. 此时搜索区间为空, 必有 `target ∉ nums`. 返回 `-1`. $\blacksquare$

### A.15.3 二分答案的正确性

**定理**: 在单调决策上, 二分答案必能找到最优值.

**证明**: 设 `f(x)` 为决策函数 (True/False). 假设 `f` 单调: $x \le T \Rightarrow f(x) = \text{True}$, $x > T \Rightarrow f(x) = \text{False}$ (求最小可行解).

二分时维护 `f(lo) = True` (如果存在) 和 `f(hi) = False` 或边界. 每次取中点 `mid`:
- `f(mid) = True` → `hi = mid`, 最优解仍在 `[lo, mid]`.
- `f(mid) = False` → `lo = mid + 1`, 最优解在 `[mid+1, hi]`.

当 `lo == hi` 时, 即为最优解. 循环必终止, 因每次区间长度减半. $\blacksquare$

### A.17.1 五步心法

1. **识别模式**: 是"标准查找"还是"二分答案"? 看问题是否"最大化最小" / "最小化最大".

## A.19 二分查找 vs. 其它查找

### A.19.1 各种查找对比

| 算法 | 时间 | 空间 | 前置条件 | 适用场景 |
|---|---|---|---|---|
| 顺序查找 | $O(n)$ | $O(1)$ | 无 | 小数据 / 无序 |
| 二分查找 | $O(\log n)$ | $O(1)$ | 有序 | 中等数据 / 静态 |
| 哈希查找 | $O(1)$ avg | $O(n)$ | 哈希函数 | 频繁查找 / 插入 |
| B+ 树 | $O(\log n)$ | $O(n)$ | 有序 | 数据库 / 磁盘 |
| Trie | $O(L)$ | $O(nL)$ | 字符集 | 字符串前缀 |
| 跳表 | $O(\log n)$ | $O(n)$ | 有序 | 并发 / 范围查询 |

### A.19.2 选择指南

```text
1. 数据是否有序?
   - 是 → 二分 / B+ 树 / 跳表
   - 否 → 是否能预排序? (哈希 / 字典树)

2. 数据是否动态 (插入/删除)?
   - 是 → 跳表 / B+ 树 / 红黑树
   - 否 → 二分 (静态排序数组)

3. 是否需要范围查询?
   - 是 → B+ 树 / 跳表
   - 否 → 哈希

4. 是否需要前缀匹配?
   - 是 → Trie / 倒排索引
   - 否 → 哈希 / B+ 树

5. 数据规模?
   - < 10^4: 二分足够
   - 10^4 ~ 10^6: 二分 + 缓存优化
   - > 10^6: B+ 树 / 跳表 / 分布式
```

## A.20 面试真题与答案模板

### A.20.1 常见面试问题

**Q1: 为什么二分查找比顺序查找快?**

A: 二分每次排除一半, 时间复杂度 $O(\log n)$. 顺序查找 $O(n)$. 当 $n$ 大时, $\log n$ 远小于 $n$.

**Q2: 如何处理重复元素?**

A: 三种策略:
- 返回任意一个: 标准二分
- 返回第一个: 用左闭右开区间
- 返回最后一个: 在找到后继续向右

**Q3: 二分查找的循环为什么不能 `lo = mid`?**

A: 当 `lo == hi - 1` 且 `mid = (lo + hi) // 2 = lo` 时, 若 `lo = mid`, 区间不变, 死循环. 必须 `lo = mid + 1`.

**Q4: 浮点二分为什么能终止?**

A: 浮点数有精度限制, 当 `hi - lo < ε` 时停止. 通常 50-100 次迭代足够.

**Q5: 二分答案和二分查找的区别?**

A:
- 二分查找: 数组已排序, 查找具体值
- 二分答案: 答案有界 + 决策单调, 求最优值

**Q6: 给出二分查找的最坏时间复杂度, 并证明.**

A: 最坏 $O(\log n)$. 证明见 A.15.1.

**7. 实践建议**

结合 "第10章-07-二分查找" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "第10章-07-二分查找" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
