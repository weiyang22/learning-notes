```python
        if len(path) == n: res.append(path[:])
        for i in range(n):

            if i > 0 and nums[i] == nums[i-1] and not used[i-1]: continue
```

## 附录 A: 贪心算法深度解析

## A.1 贪心本质: 局部最优 → 全局最优

贪心算法 (Greedy Algorithm) 是一种在每一步选择中都采取**当前状态下最优决策**的算法范式, 希望通过**局部最优**达到**全局最优**.

### A.1.1 贪心的核心要素

1. **贪心选择性质 (Greedy Choice Property)**: 整体最优解可通过一系列局部最优选择达到
2. **最优子结构 (Optimal Substructure)**: 问题的最优解包含子问题的最优解
3. **无后效性**: 某状态一旦确定, 不影响后续决策

### A.1.2 贪心 vs. 其它算法

| 算法 | 决策方式 | 适用范围 | 典型应用 |
|---|---|---|---|
| 贪心 | 每步局部最优 | 满足贪心选择性质 | 区间调度, 最小生成树 |
| 动态规划 | 考虑所有子问题 | 重叠子问题 + 最优子结构 | 背包, LCS |
| 回溯 | 枚举所有可能 | 搜索空间可剪枝 | N 皇后, 数独 |
| 分治 | 分成子问题求解 | 子问题独立 | 归并排序, 快排 |

### A.1.3 证明贪心正确性的两种方法

**方法 1: 交换论证 (Exchange Argument)**

证明存在一个最优解与贪心解"前 k 步"一致:
- 假设贪心选择为 $g_1$, 某最优解首选择为 $o_1$
- 若 $o_1$ 不劣于 $g_1$ (或可交换), 改为 $g_1$ 仍最优
- 递归证明

**方法 2: 反证法**

假设贪心解非最优, 则存在更优解, 推导出矛盾.

## A.2 区间调度详解

### A.2.1 LeetCode 435 详解: 无重叠区间

**题目**: 给定区间集合, 求最少移除几个区间使无重叠.

**贪心策略**: 按**结束时间**升序排序, 每次选最早结束的区间.

**正确性证明**:
- 设最早结束的区间为 $e_1 = (s_1, t_1)$, 最早结束意味着剩余可用时间最长
- 任何最优解的第一个区间 $e^* = (s^*, t^*)$ 必满足 $t^* \ge t_1$ (因 $e_1$ 最早结束)
- 将 $e^*$ 替换为 $e_1$, 解仍可行 → 不劣于原最优解
- 递归得证

```python
def eraseOverlapIntervals(intervals):
    """完整 + 测试"""
    if not intervals:
        return 0

    intervals.sort(key=lambda x: x[1])

    count = 1  # 至少能保留 1 个
    end = intervals[0][1]

    for i in range(1, len(intervals)):
        if intervals[i][0] >= end:
            count += 1
            end = intervals[i][1]

    return len(intervals) - count


# 测试
assert eraseOverlapIntervals([[1, 2], [2, 3], [3, 4], [1, 3]]) == 1
assert eraseOverlapIntervals([[1, 2], [1, 2], [1, 2]]) == 2
assert eraseOverlapIntervals([[1, 2], [2, 3]]) == 0
```

**复杂度**: 时间 $O(n \log n)$ (排序), 空间 $O(1)$.

### A.2.3 LeetCode 56 详解: 合并区间

**题目**: 合并所有重叠区间.

**思路**: 按起点排序, 扫描时合并.

```python
def merge(intervals):
    if not intervals:
        return []

    intervals.sort(key=lambda x: x[0])

    merged = [intervals[0][:]]
    for i in range(1, len(intervals)):
        if intervals[i][0] <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], intervals[i][1])
        else:
            merged.append(intervals[i][:])

    return merged


# 测试
assert merge([[1, 3], [2, 6], [8, 10], [15, 18]]) == [[1, 6], [8, 10], [15, 18]]
assert merge([[1, 4], [4, 5]]) == `1, 5`
```

### A.2.4 LeetCode 253 详解: 会议室 II

**题目**: 最小会议室数.

**思路**: 按开始时间排序, 用最小堆维护当前会议室的结束时间.

```python
import heapq

def minMeetingRooms(intervals):
    if not intervals:
        return 0

    intervals.sort(key=lambda x: x[0])
    heap = []

    for s, e in intervals:
        if heap and heap[0] <= s:
            heapq.heappop(heap)  # 复用会议室
        heapq.heappush(heap, e)

    return len(heap)


# 测试
assert minMeetingRooms([[0, 30], [5, 10], [15, 20]]) == 2
assert minMeetingRooms([[7, 10], [2, 4]]) == 1
```

```python
def removeCoveredIntervals(intervals):
```

```python
def canJump(nums):

    for i, x in enumerate(nums):
```

### A.3.3 LeetCode 134 详解: 加油站

**题目**: 环形路上加油站 gas[i], 耗油 cost[i], 求起点使能绕一圈.

**贪心**: 若总和 `gas < cost`, 不可行; 否则必有解, 起点为最低累计油量的下一站.

```python
def canCompleteCircuit(gas, cost):
    if sum(gas) < sum(cost):
        return -1

    tank = 0
    start = 0

    for i in range(len(gas)):
        tank += gas[i] - cost[i]
        if tank < 0:
            start = i + 1
            tank = 0

    return start


# 测试
assert canCompleteCircuit([1, 2, 3, 4, 5], [3, 4, 5, 1, 2]) == 3
assert canCompleteCircuit([2, 3, 4], [3, 4, 3]) == -1
```

### A.3.4 LeetCode 871 详解: 最低加油次数

**题目**: 起点到终点距离 target, 沿途加油站 stations, 油箱容量, 求最少加油次数.

**贪心**: 用最大堆维护"经过但没加"的油量, 油不够时从堆中加最多的油.

```python
import heapq

def minRefuelStops(target, startFuel, stations):
    if startFuel >= target:
        return 0

    # 最大堆 (取负)
    fuel_heap = []
    prev = 0
    tank = startFuel
    stops = 0

    for s, f in stations + `target, 0`:
        tank -= s - prev
        while tank < 0 and fuel_heap:
            tank += -heapq.heappop(fuel_heap)
            stops += 1
        if tank < 0:
            return -1
        heapq.heappush(fuel_heap, -f)
        prev = s

    return stops


# 测试
assert minRefuelStops(100, 1, `10, 100`) == -1
assert minRefuelStops(100, 10, [[10, 60], [20, 30], [30, 30], [60, 40]]) == 2
```

### A.4.3 LeetCode 135 详解: 分发糖果

**题目**: 评分高的孩子比邻居多, 求最少糖果数.

**贪心**: 左右各扫一遍.

```python
def candy(ratings):
    n = len(ratings)
    candies = [1] * n

    # 左 → 右: 比左邻居高
    for i in range(1, n):
        if ratings[i] > ratings[i - 1]:
            candies[i] = candies[i - 1] + 1

    # 右 → 左: 比右邻居高
    for i in range(n - 2, -1, -1):
        if ratings[i] > ratings[i + 1]:
            candies[i] = max(candies[i], candies[i + 1] + 1)

    return sum(candies)


# 测试
assert candy([1, 0, 2]) == 5
assert candy([1, 2, 2]) == 4
```

### A.4.5 LeetCode 402 详解: 移掉 K 位数字

**题目**: 移除 k 位使剩余数字最小.

**贪心**: 单调栈.

```python
def removeKdigits(num, k):
    stack = []
    for d in num:
        while k > 0 and stack and stack[-1] > d:
            stack.pop()
            k -= 1
        stack.append(d)

    # 移除剩余的 k 个 (从尾部)
    stack = stack[:-k] if k > 0 else stack

    # 去除前导零
    result = ''.join(stack).lstrip('0')
    return result if result else '0'


# 测试

assert removeKdigits("10200", 1) == "200"
assert removeKdigits("10", 2) == "0"
```

### A.4.6 LeetCode 316 详解: 去除重复字母

**题目**: 去除重复字母, 使结果字典序最小, 且不重复.

```python
def removeDuplicateLetters(s):
    last_occurrence = {c: i for i, c in enumerate(s)}
    stack = []
    in_stack = set()

    for i, c in enumerate(s):
        if c in in_stack:
            continue
        # 若栈顶 > 当前, 且栈顶之后还有, 弹出
        while stack and stack[-1] > c and last_occurrence[stack[-1]] > i:
            in_stack.remove(stack.pop())

        stack.append(c)
        in_stack.add(c)

    return ''.join(stack)


# 测试
```

## A.5 贪心反例与陷阱

### A.5.1 经典反例: 0-1 背包

**问题**: 给定物品重量和价值, 容量限制下最大化总价值.

**反例**: 物品 (重 6, 价值 8), (重 5, 价值 5), 容量 10.
- 贪心 (价值密度): 选第一件 (8/6 ≈ 1.33) + 第二件 (5/5 = 1) → 13
- 最优: 第二件 + 第三件 (假设有重 4, 价值 6 的物品) → 11

但实际是 0-1 背包不满足贪心选择性质, 需用 DP.

### A.5.2 经典反例: 最短路径

**问题**: 单源最短路径 (边权非负).

**反例**: Dijkstra 是贪心, 但若边权可为负, 则 Bellman-Ford.

### A.5.3 经典反例: 区间覆盖

**问题**: 给定区间集合, 用最少区间覆盖 `[0, T]`.

**反例**: 贪心 (选起点最小 + 终点最大) 在某些情况下失败.

### A.5.4 何时用贪心 vs. DP

判断标准:
1. 是否能反证贪心? 不能 → 试 DP
2. 是否有"局部最优 → 全局最优" 的交换论证? 是 → 贪心
3. 子问题是否独立? 是 → 贪心; 否 → DP

## A.6 贪心证明方法学

### A.6.1 交换论证模板

**步骤**:
1. 假设某最优解 $OPT$ 与贪心解 $GREEDY$ 不同
2. 设 $OPT$ 第一个不同的位置为 $k$
3. 证明可将 $OPT$ 的第 $k$ 步替换为 $GREEDY$ 的第 $k$ 步, 解仍可行且不劣
4. 递归, 最终 $OPT$ 与 $GREEDY$ 完全一致

### A.6.2 实例: 区间调度证明

设 $OPT$ 是最优解, $g_1$ 是贪心选择的第一个区间 (最早结束).
- $OPT$ 第一个区间 $o_1$ 必满足: 起点 ≥ $g_1$ 起点, 终点 ≥ $g_1$ 终点
- 用 $g_1$ 替换 $o_1$, 不影响后续可行性 (因 $g_1$ 结束更早)
- 递归处理剩余区间

### A.6.3 实例: 单源最短路径 (Dijkstra)

**定理**: Dijkstra 算法给出单源最短路径 (非负边权).

**证明** (反证): 设 $u$ 是第一个被错误标记最短距离的顶点.
- $u$ 被标记时, 路径长度 $d(u) = \delta(s, u) + \epsilon$ (假设)
- $u$ 从优先队列弹出时, $d(u)$ 已确定
- 但存在真实最短路径 $s \to \dots \to v \to u$, 其中 $v$ 在 $u$ 之前处理
- $d(v) = \delta(s, v)$, 松弛时 $d(u)$ 应更新为 $\delta(s, u)$, 矛盾. $\blacksquare$

## 附录 B: 回溯算法深度解析

## B.1 回溯本质: 暴力枚举的优化

回溯 (Backtracking) 是一种**系统化枚举**所有潜在解的算法, 通过**剪枝 (Pruning)** 提前排除不可能的分支, 从而高效搜索解空间.

### B.1.1 回溯 vs. 暴力枚举

| 维度 | 暴力枚举 | 回溯 |
|---|---|---|
| 解空间 | 全部 | 通过剪枝排除 |
| 时间 | $O(k^n)$ | $O(k^n)$ worst, 但剪枝后远小于 |
| 实现 | 嵌套循环 | 递归 + 状态重置 |
| 适用 | 小规模 | 中等规模 |

### B.1.2 回溯的三要素

1. **路径 (Path)**: 已做出的选择
2. **选择列表 (Choices)**: 当前可做的选择
3. **结束条件 (End)**: 到达决策树底部, 无法继续

### B.1.3 回溯的通用框架

```python
def backtrack(路径, 选择列表):
    if 满足结束条件:
        结果.add(路径)
        return

    for 选择 in 选择列表:
        做选择
        backtrack(路径, 选择列表)
        撤销选择
```

## B.2 回溯的剪枝策略

### B.2.1 剪枝分类

1. **排除不合法选择**: 当前选择违反约束, 跳过
2. **排除重复**: 已用过的元素不再选
3. **排除无效分支**: 当前路径不可能达到解, 提前返回
4. **排序剪枝**: 先排序, 提早判断"后续都太小"或"都太大"

### B.2.2 LeetCode 46 详解: 全排列

```python
def permute(nums):
    n = len(nums)
    res = []

    def backtrack(path, used):
        if len(path) == n:
            res.append(path[:])
            return

        for i in range(n):
            if used[i]:
                continue
            used[i] = True
            path.append(nums[i])
            backtrack(path, used)
            path.pop()
            used[i] = False

    backtrack([], [False] * n)
    return res
```

```python
            res.append(''.join(path))
            return

            backtrack(path, l + 1, r)
            path.pop()
```

### B.3.2 LeetCode 51 详解: N 皇后

**题目**: 在 n×n 棋盘放 n 个皇后, 互不攻击.

```python
def solveNQueens(n):
    res = []

    def backtrack(row, cols, diag1, diag2, path):
        if row == n:
            res.append(path[:])
            return
        for col in range(n):
            if col in cols:
                continue
            d1 = row - col
            d2 = row + col
            if d1 in diag1 or d2 in diag2:
                continue

            cols.add(col)
            diag1.add(d1)
            diag2.add(d2)
            path.append('.' * col + 'Q' + '.' * (n - col - 1))

            backtrack(row + 1, cols, diag1, diag2, path)

            cols.remove(col)
            diag1.remove(d1)
            diag2.remove(d2)
            path.pop()

    backtrack(0, set(), set(), set(), [])
    return res
```

```python
def exist(board, word):
    if not board or not board[0]:
        return False

    m, n = len(board), len(board[0])
    visited = [[False] * n for _ in range(m)]

    def backtrack(i, j, k):
        if k == len(word):
            return True
        if i < 0 or i >= m or j < 0 or j >= n:
            return False
        if visited[i][j] or board[i][j] != word[k]:
            return False

            backtrack(i + 1, j, k + 1) or
            backtrack(i - 1, j, k + 1) or
            backtrack(i, j + 1, k + 1) or
            backtrack(i, j - 1, k + 1)
        )
        visited[i][j] = False
        return result

    for i in range(m):
        for j in range(n):
            if backtrack(i, j, 0):
                return True
    return False
```

```python
    n = len(s)

    def is_palindrome(l, r):
        while l < r:
            if s[l] != s[r]:
                return False
            l += 1
            r -= 1
        return True

            res.append(path[:])
            return
        for end in range(start, n):
            if is_palindrome(start, end):
                path.append(s[start:end+1])
                backtrack(end + 1, path)
                path.pop()

    backtrack(0, [])
    return res
```

## B.5 回溯 vs. DP

### B.5.1 决策树视角

```text
回溯: 完整决策树, 剪枝掉无效分支
DP:   重叠子问题, 记忆化, 不重不漏
```

### B.5.2 何时选回溯

1. 需要所有解 (不是最优): 用回溯
2. 解空间无重叠子问题: 用回溯
3. 状态空间小: 回溯直接枚举
4. 约束强, 可大量剪枝: 回溯

### B.5.3 何时选 DP

1. 求最优解 (最少/最大): DP
2. 大量重叠子问题: DP
3. 子问题相互依赖: DP
4. 解空间太大无法枚举: DP

### B.5.4 实例对比: 0-1 背包

- **回溯**: 枚举每个物品取/不取, $O(2^n)$, 适合 n ≤ 20
- **DP**: 状态压缩 $O(2^n)$ 或 $O(nW)$, 适合 n 较大

## B.6 回溯的位运算优化

### B.6.1 N 皇后的位运算优化

```python
def solveNQueens_bits(n):
    res = []

    def backtrack(row, cols, diags1, diags2):
        if row == n:
            res.append(['.' * i + 'Q' + '.' * (n - i - 1)
                        for i in range(n)])
            return

        # 当前行所有可放位置
        available = ((1 << n) - 1) & ~(cols | diags1 | diags2)

        while available:
            pos = available & -available  # 取最低位 1
            available -= pos

            backtrack(
                row + 1,
                cols | pos,
                (diags1 | pos) << 1,
                (diags2 | pos) >> 1
            )

    backtrack(0, 0, 0, 0)
    return res
```

性能提升 5-10 倍.

## B.8 回溯的高级应用

### B.8.1 IDA* 算法 (迭代加深 A*)

```python
def idastar(start, goal, heuristic, neighbors):
    """
    IDA*: 用回溯实现迭代加深的启发式搜索
    """
    threshold = heuristic(start)

    while True:
        result = dfs(start, 0, threshold, goal, heuristic, neighbors)
        if result == "FOUND":
            return True
        if result == float('inf'):
            return False
        threshold = result


def dfs(node, g, threshold, goal, h, neighbors):
    f = g + h(node)
    if f > threshold:
        return f
    if node == goal:
        return "FOUND"

    min_next = float('inf')
    for next_node in neighbors(node):
        result = dfs(next_node, g + 1, threshold, goal, h, neighbors)
        if result == "FOUND":
            return "FOUND"
        if result < min_next:
            min_next = result
    return min_next
```

### B.8.2 蒙特卡洛树搜索 (MCTS)

```python
import math
import random

class MCTSNode:
    def __init__(self, state, parent=None):
        self.state = state
        self.parent = parent
        self.children = {}
        self.visits = 0
        self.wins = 0

    def uct(self, total_visits):
        if self.visits == 0:
            return float('inf')
        return (self.wins / self.visits) +
               math.sqrt(2 * math.log(total_visits) / self.visits)

    def best_child(self):
        return max(self.children.values(),
                   key=lambda c: c.uct(self.visits))

    def expand(self, action, next_state):
        child = MCTSNode(next_state, parent=self)
        self.children[action] = child
        return child
```

## B.10 回溯的正确性证明

### B.10.1 证明回溯返回所有解

**定理**: 回溯框架在无剪枝时, 返回决策树的所有叶节点.

**证明**:
- 决策树每个节点 = 一种部分解
- 每次递归 = 在当前节点的所有子节点递归
- 叶节点 = 完整解
- 无剪枝时, 必遍历所有节点 → 所有解. $\blacksquare$

### B.10.2 证明回溯不重复

**定理**: 标准回溯 (用 `start` 索引) 不产生重复解.

**证明**:
- 每次递归只考虑 `[start, n)` 的元素
- 元素 i 加入后, 下一层从 i+1 开始
- 任何两个解的"加入顺序"按索引严格递增
- 故不同解的"元素序列"不同 → 无重复. $\blacksquare$

```python
def findRightInterval(intervals):
    n = len(intervals)
    starts = sorted([(iv[0], i) for i, iv in enumerate(intervals)])
    res = []

    for iv in intervals:
        # 二分找起点 ≥ iv[1]

            mid = (lo + hi) // 2
            if starts[mid][0] < iv[1]:
                lo = mid + 1
            else:
                hi = mid
```

```python
def reorganizeString(s):
    from collections import Counter
    counts = Counter(s)
    n = len(s)

    max_count = max(counts.values())
    if max_count > (n + 1) // 2:
        return ""

    # 按频次降序

        for _ in range(counts[c]):

            idx += 2
            if idx >= n:
                idx = 1  # 切换到奇数位
```

```python
def minCost(s, cost):
    n = len(s)
    total = sum(cost)

    i = 0
    while i < n:
        j = i
        while j < n and s[j] == s[i]:
            j += 1
        # 段 [i, j)
        if j - i > 1:
            max_cost = max(cost[i:j])
            total -= max_cost
        i = j

    return total
```

```python
def maximumSwap(num):
    digits = list(str(num))
    n = len(digits)

    # 记录每个数字最后出现位置
    last = {int(d): i for i, d in enumerate(digits)}

    for i in range(n):
        cur = int(digits[i])
        # 从 9 到 cur+1 找更大数字
        for d in range(9, cur, -1):
            if d in last and last[d] > i:
                # 交换
                j = last[d]
                digits[i], digits[j] = digits[j], digits[i]
                return int(''.join(digits))

    return num
```

```python
def minimumEffort(tasks):
    """每个任务 [actual, minimum], 能量 ≥ actual 才执行"""
    # 按 actual - minimum 降序
    tasks.sort(key=lambda x: -(x[0] - x[1]))

    energy = 0
    for actual, minimum in tasks:
        # 完成后能量保留 minimum
        energy = max(energy + minimum, actual)
```

```python
    删 "ab" 得 x 分, "ba" 得 y 分. 字符串.

        score = 0
        a, b = pair

            if stack and stack[-1] == a and c == b:

                score += (x if pair == "ab" else y)
```

```python
def findMinMoves(machines):
    n = len(machines)
    total = sum(machines)
    if total % n != 0:
        return -1

    avg = total // n
    max_moves = 0
    left_sum = 0

    for i in range(n):
        right_sum = total - left_sum - machines[i]
        # 当前机需要: 让左边和右边都达到 avg
        # 操作次数 = max(左送右, 右送左)
        left_need = max(0, (i + 1) * avg - left_sum)
        right_need = max(0, (n - i - 1) * avg - right_sum)
        max_moves = max(max_moves, left_need + right_need)
        left_sum += machines[i]

    return max_moves
```

## D.1 状态压缩回溯

### D.1.1 N 皇后的状态压缩

```python
def totalNQueens(n):
    """仅计数, 位运算"""
    def backtrack(row, cols, diags1, diags2):
        if row == n:
            return 1
        count = 0
        available = ((1 << n) - 1) & ~(cols | diags1 | diags2)

        while available:
            pos = available & -available
            available -= pos
            count += backtrack(
                row + 1,
                cols | pos,
                (diags1 | pos) << 1,
                (diags2 | pos) >> 1
            )
        return count

    return backtrack(0, 0, 0, 0)
```

### D.1.2 LeetCode 980 详解: 不同路径 III

**题目**: 网格, 1 起点, 2 终点, 0 空, 4 障碍. 从起点到终点访问所有空格的路径数.

```python
def uniquePathsIII(grid):
    m, n = len(grid), len(grid[0])
    start = end = None
    empty = 0

    for i in range(m):
        for j in range(n):
            if grid[i][j] == 1:
                start = (i, j)
            elif grid[i][j] == 2:
                end = (i, j)
            elif grid[i][j] == 0:
                empty += 1

    # empty + 1 (起点) + 1 (终点) = total steps
    target = empty + 1

    def backtrack(i, j, steps):
        if (i, j) == end:
            return 1 if steps == target else 0

        count = 0
        grid[i][j] = -1  # 标记访问
        for di, dj in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
            ni, nj = i + di, j + dj
            if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] != -1 and grid[ni][nj] != 4:
                count += backtrack(ni, nj, steps + 1)
        grid[i][j] = 0
        return count

    return backtrack(*start, 0)
```

## D.2 双向回溯

### D.2.1 双向 BFS vs. 双向回溯

```python
def two_way_backtrack(start, goal, neighbors):
    """双向回溯 (用于某些图问题)"""
    forward = {start: [start]}
    backward = {goal: [goal]}

    while forward and backward:
        # 扩展小的方向
        if len(forward) > len(backward):
            forward, backward = backward, forward

        new_frontier = {}
        for node, path in forward.items():
            for next_node in neighbors(node):
                if next_node not in new_frontier:
                    new_path = path + [next_node]
                    new_frontier[next_node] = new_path
                    if next_node in backward:
                        return backward[next_node][:-1] + new_path[::-1]

        forward = new_frontier

    return None
```

## D.3 记忆化回溯

### D.3.1 LeetCode 638 详解: 大礼包

```python
def shoppingOffers(price, special, needs):
    from functools import lru_cache

    @lru_cache(maxsize=None)
    def dfs(state):
        # state: tuple of needs
        # 不买大礼包
        res = sum(p * n for p, n in zip(price, state))

        for offer in special:
            new_state = []
            valid = True
            for i in range(len(state)):
                if state[i] < offer[i]:
                    valid = False
                    break
                new_state.append(state[i] - offer[i])

            if valid:
                res = min(res, offer[-1] + dfs(tuple(new_state)))

        return res

    return dfs(tuple(needs))
```

## D.5 回溯的工程优化

### D.5.1 Python 优化技巧

```python
import sys

# 1. 加速递归
sys.setrecursionlimit(10**6)

# 2. 用位图代替列表
def permute_bitmap(nums):
    n = len(nums)
    res = []

    def backtrack(path, used_mask):
        if len(path) == n:
            res.append(path[:])
            return
        for i in range(n):
            if used_mask & (1 << i):
                continue
            path.append(nums[i])
            backtrack(path, used_mask | (1 << i))
            path.pop()

    backtrack([], 0)
    return res

# 3. 用元组代替列表 (哈希友好)
def permute_tuple(nums):
    n = len(nums)
    res = set()

    def backtrack(path_tuple):
        if len(path_tuple) == n:
            res.add(path_tuple)
            return
        for x in nums:
            if x not in path_tuple:
                backtrack(path_tuple + (x,))

    backtrack(())
    return [list(t) for t in res]
```

```cpp
        vector<vector<int>> res;
        vector<int> path;
        vector<bool> used(nums.size(), false);

        function<void()> dfs = [&]() {
            if (path.size() == nums.size()) {
                res.push_back(path);
                return;
            }
            for (int i = 0; i < nums.size(); i++) {
                if (used[i]) continue;
                used[i] = true;
                path.push_back(nums[i]);
                dfs();
                path.pop_back();
                used[i] = false;
            }
        };

        dfs();
        return res;
    }
};
```

C++ 速度通常比 Python 快 50-100 倍.

### D.7.1 LeetCode 1240 详解: 铺瓷砖

**题目**: 用正方形瓷砖铺 n×n 棋盘, 求最少瓷砖数.

```python
def tilingRectangle(n, m):
    """回溯 + 剪枝"""
    if n == m:
        return 1

    # 让 n < m
    if n > m:
        n, m = m, n

    best = [m * n]  # 上界
    grid = [[0] * m for _ in range(n)]

    def can_place(x, y, size):
        for i in range(size):
            for j in range(size):
                if grid[x + i][y + j]:
                    return False
        return True

    def place(x, y, size, val):
        for i in range(size):
            for j in range(size):
                grid[x + i][y + j] = val

    def find_first_empty():
        for i in range(n):
            for j in range(m):
                if grid[i][j] == 0:
                    return i, j
        return None

    def dfs(cnt):
        if cnt >= best[0]:
            return  # 剪枝

        cell = find_first_empty()
        if cell is None:
            best[0] = min(best[0], cnt)
            return

        x, y = cell
        max_size = min(n - x, m - y)

        # 找最大可用
        for size in range(max_size, 0, -1):
            if can_place(x, y, size):
                place(x, y, size, 1)
                dfs(cnt + 1)
                place(x, y, size, 0)

    dfs(0)
    return best[0]
```

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
