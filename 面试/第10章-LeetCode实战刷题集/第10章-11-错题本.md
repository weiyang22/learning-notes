## 1. 错题本的必要性

```text
刷 300 题 1 遍 = 几乎没用 (会忘)
刷 100 题 3 遍 = 真正掌握
关键: 100 题 3 遍的前提是第 1 遍做错, 错题本记下来
```

**每道错题价值 > 5 道新题**. 因为错题暴露了真实的知识漏洞.

## 2. 错因 5 大类

### 2.1 题意没看清 (最常见, ~40%)

**表现**:
- 漏看输入/输出限制 (比如负数、范围)
- 没注意"恰好"、"最多"、"最少"等限定词
- 漏看"返回下标" vs "返回元素"
- 没注意数据是否有序

**对策**:
- 读题 5 分钟, 圈出关键字
- 写代码前, 列出关键约束

### 2.2 边界没考虑 (~25%)

**表现**:
- 空数组 / 空字符串
- 单元素数组
- 全相同 / 全递增 / 全递减
- 极端值 (INT_MAX, INT_MIN)
- 重复元素

**对策**:
- 提交前自测 5 个边界用例
- 见 [附录 C - 常见陷阱与调试](../附录/附录C-常见陷阱与调试.md)

### 2.3 算法选错或写错 (~20%)

**表现**:
- 选错算法 (如 N² 暴力 vs O(N) 双指针)
- 模板没背熟
- 思路对但实现错

**对策**:
- 训练"5 分钟想算法"的能力
- 模板每周复习一次

### 2.4 复杂度算错 (~10%)

**表现**:
- TLE (Time Limit Exceeded)
- 以为是 O(N) 实际是 O(N²)
- 没考虑最坏情况

**对策**:
- 写完代码, 显式算一遍复杂度
- 大数测试 (n = 10⁵, 10⁶)

### 2.5 心理 / 习惯 (~5%)

**表现**:
- 急了没看清数据
- 紧张写错变量名
- 提交前不测试

**对策**:
- 模拟面试训练
- 提交前 checklist

## 5. 10 个真实错题案例

### 案例 1: LeetCode 1 两数之和 (题意错误)

**错因**: 题意没看清 (返回下标, 不是元素)

```python
# 错
def twoSum(nums, target):
    for i in range(len(nums)):
        for j in range(i+1, len(nums)):
            if nums[i] + nums[j] == target:
                return [nums[i], nums[j]]  # ❌ 返回了元素

# 对
def twoSum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]  # ✅ 返回下标
        seen[x] = i
```

### 案例 2: LeetCode 15 三数之和 (去重遗漏)

**错因**: 去重不完整

```python
# 错 (漏掉右指针去重)
def threeSum(nums):
    nums.sort()
    res = []
    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i-1]: continue
        l, r = i + 1, len(nums) - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if s == 0:
                res.append([nums[i], nums[l], nums[r]])
                l += 1  # ❌ 应该跳过重复
                r -= 1
            elif s < 0: l += 1
            else: r -= 1
    return res

# 对
def threeSum(nums):
    nums.sort()
    res = []
    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i-1]: continue
        l, r = i + 1, len(nums) - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if s == 0:
                res.append([nums[i], nums[l], nums[r]])
                while l < r and nums[l] == nums[l+1]: l += 1  # ✅
                while l < r and nums[r] == nums[r-1]: r -= 1  # ✅
                l += 1; r -= 1
            elif s < 0: l += 1
            else: r -= 1
    return res
```

### 案例 4: LeetCode 300 最长递增子序列 (复杂度算错)

**错因**: 用 O(N²) 不知道可以优化到 O(N log N)

```python
# 错: 觉得 N² 也能过
def lengthOfLIS(nums):
    n = len(nums)
    dp = [1] * n
    for i in range(n):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)  # O(N²), n=10^5 时 TLE

# 对: 用二分
def lengthOfLIS(nums):
    tails = []
    for x in nums:
        lo, hi = 0, len(tails)
        while lo < hi:
            mid = (lo + hi) // 2
            if tails[mid] < x: lo = mid + 1
            else: hi = mid
        if lo == len(tails): tails.append(x)
        else: tails[lo] = x
    return len(tails)  # O(N log N)
```

```python
# 错: 移动较矮边反了
```

### 案例 6: LeetCode 46 全排列 (回溯终止条件错)

**错因**: 模板不熟

```python
# 错
def permute(nums):
    res = []
    def backtrack(path):
        res.append(path)  # ❌ 每次都加
        if len(path) == len(nums):
            return
        for x in nums:
            if x not in path:
                path.append(x)
                backtrack(path)
                path.pop()
    backtrack([])
    return res
# 输出: 含中间状态!

# 对
def permute(nums):
    res = []
    n = len(nums)
    used = [False] * n
    def backtrack(path):
        if len(path) == n:  # ✅ 终止才加
            res.append(path[:])
        for i in range(n):
            if used[i]: continue
            used[i] = True
            path.append(nums[i])
            backtrack(path)
            path.pop()
            used[i] = False
    backtrack([])
    return res
```

### 案例 7: LeetCode 200 岛屿数量 (DFS 终止条件错)

**错因**: 边界判断

```python
# 错: 漏掉 m, n 范围
def numIslands(grid):
    def dfs(i, j):
        if grid[i][j] != '1': return  # ❌ 没检查越界
        grid[i][j] = '0'
        dfs(i+1, j); dfs(i-1, j); dfs(i, j+1); dfs(i, j-1)

    for i in range(len(grid)):
        for j in range(len(grid[0])):
            if grid[i][j] == '1':
                dfs(i, j)

# 对
def numIslands(grid):
    m, n = len(grid), len(grid[0])
    def dfs(i, j):
        if i < 0 or i >= m or j < 0 or j >= n: return  # ✅ 边界
        if grid[i][j] != '1': return
        grid[i][j] = '0'
        dfs(i+1, j); dfs(i-1, j); dfs(i, j+1); dfs(i, j-1)
```

### 案例 10: LeetCode 5 最长回文子串 (DP 边界)

**错因**: DP 转移边界

```python
# 错: 单字符初始化漏掉
def longestPalindrome(s):
    n = len(s)
    dp = [[False] * n for _ in range(n)]
    for i in range(n):
        for j in range(i, n):
            if s[i] == s[j]:
                dp[i][j] = (j - i < 3) or dp[i+1][j-1]  # ❌ 单字符时 i+1>j-1
            if dp[i][j] and j - i + 1 > max_len:
                max_len = j - i + 1
                start = i
    return s[start:start+max_len]
# 单字符情况: i+1 > j-1, dp 还没设过, 错!

# 对
def longestPalindrome(s):
    n = len(s)
    dp = [[False] * n for _ in range(n)]
    for i in range(n): dp[i][i] = True  # ✅ 单字符初始化
    max_len, start = 1, 0
    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            if s[i] == s[j]:
                if length == 2 or dp[i+1][j-1]:
                    dp[i][j] = True
                    if length > max_len:
                        max_len = length
                        start = i
    return s[start:start+max_len]
```

## A.1 LeetCode 146 - LRU Cache (Medium)

### 原始错题

```python
class LRUCache:
    def __init__(self, capacity):
        self.cap = capacity
        self.cache = {}
        # 错: 没用 OrderedDict 或双向链表, O(n) get/put
```

### 错因归类

```text
[ ] 题意误解    [ ] 边界遗漏    [√] 算法选择错误    [ ] 复杂度误判    [ ] 代码陷阱
```

### 错误版本 (TLE)

```python
class LRUCache:
    def __init__(self, capacity: int):
        self.cap = capacity
        self.cache = {}
        self.order = []

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1
        # 错: list.remove 是 O(n)
        self.order.remove(key)
        self.order.append(key)
        return self.cache[key]

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            self.cache[key] = value
            self.order.remove(key)
            self.order.append(key)
        else:
            if len(self.cache) >= self.cap:
                # 错: 弹出最近最少使用, 但 order[0] 真的是 LRU 吗?
                oldest = self.order.pop(0)
                del self.cache[oldest]
            self.cache[key] = value
            self.order.append(key)
```

**问题**:
- `list.remove(key)` 是 O(n), 触发 TLE
- `list.pop(0)` 是 O(n), 应该用 deque
- 即使改用 deque, `deque.remove(key)` 仍是 O(n)

### 正确解法: 哈希表 + 双向链表

```python
class DLinkedNode:
    def __init__(self, key=0, value=0):
        self.key = key
        self.value = value
        self.prev = None
        self.next = None

class LRUCache:
    def __init__(self, capacity: int):
        self.cache = {}
        self.cap = capacity
        self.head = DLinkedNode()  # 哨兵
        self.tail = DLinkedNode()
        self.head.next = self.tail
        self.tail.prev = self.head

    def _add_to_head(self, node):
        node.prev = self.head
        node.next = self.head.next
        self.head.next.prev = node
        self.head.next = node

    def _remove_node(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev

    def _move_to_head(self, node):
        self._remove_node(node)
        self._add_to_head(node)

    def _pop_tail(self):
        node = self.tail.prev
        self._remove_node(node)
        return node

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1
        node = self.cache[key]
        self._move_to_head(node)
        return node.value

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            node = self.cache[key]
            node.value = value
            self._move_to_head(node)
        else:
            if len(self.cache) >= self.cap:
                removed = self._pop_tail()
                del self.cache[removed.key]
            node = DLinkedNode(key, value)
            self.cache[key] = node
            self._add_to_head(node)
```

### Pythonic 简化版: OrderedDict

```python
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity: int):
        self.cap = capacity
        self.cache = OrderedDict()

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1
        self.cache.move_to_end(key)
        return self.cache[key]

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.cap:
            self.cache.popitem(last=False)
```

### 复盘要点

| 维度 | 错误版本 | 正确版本 |
|---|---|---|
| get 时间 | O(n) | O(1) |
| put 时间 | O(n) | O(1) |
| 空间 | O(n) | O(n) |
| 难度 | Easy | Hard |

**核心考点**: 双向链表 + 哈希表 联合使用; 哨兵节点消除边界判断; OrderedDict 是 Python 偷懒利器。

## A.2 LeetCode 25 - K 个一组翻转链表 (Hard)

### 原始错题

```python
def reverseKGroup(head, k):
    # 错: 没考虑不足 k 个的尾段保持原样
    # 错: 翻转后指针没接回去
```

### 错因归类

```text
[ ] 题意误解    [ ] 边界遗漏    [√] 算法正确但实现错    [ ] 复杂度误判    [√] 代码陷阱
```

### 错误版本 (死循环)

```python
def reverseKGroup(head, k):
    dummy = ListNode(0)
    dummy.next = head
    pre = dummy
    while pre.next:
        # 错: 没判断剩余节点是否足够 k 个
        cur = pre.next
        for _ in range(k - 1):
            nxt = cur.next
            cur.next = nxt.next
            nxt.next = pre.next
            pre.next = nxt
        pre = cur
    return dummy.next
```

**问题**: 当剩余节点 < k 时仍翻转, 不满足题意。

### 正确解法: 三段式 + 边界判断

```python
def reverseKGroup(head, k):
    dummy = ListNode(0, head)
    pre = dummy

    while True:
        # 1. 检查剩余节点是否足够 k 个
        end = pre
        for _ in range(k):
            if not end.next:
                return dummy.next  # 不够, 直接返回
            end = end.next

        # 2. 翻转 [start, end] 区间
        start = pre.next
        cur = start.next
        for _ in range(k - 1):
            nxt = cur.next
            cur.next = start
            start = cur
            cur = nxt

        # 3. 接回原链表
        # 此时 start 是新头, cur 是下一段起点, pre.next 是旧头
        first = pre.next
        first.next = cur
        pre.next = start
        pre = first
```

### 递归版本 (更优雅)

```python
def reverseKGroup(head, k):
    # 1. 检查剩余是否够 k 个
    cur = head
    for _ in range(k):
        if not cur:
            return head
        cur = cur.next

    # 2. 翻转前 k 个
    new_head, nxt = reverseKGroup_helper(head, cur)
    # 3. 递归处理剩余
    head.next = reverseKGroup(cur, k)
    return new_head

def reverseKGroup_helper(head, stop):
    prev, curr = None, head
    while curr != stop:
        nxt = curr.next
        curr.next = prev
        prev = curr
        curr = nxt
    return prev, head  # (新头, 旧头)
```

### 复盘要点

| 维度 | 错误版本 | 正确版本 |
|---|---|---|
| 边界 | 没判断 | pre-check |
| 翻转逻辑 | 内联复杂 | 单独函数 |
| 难度 | Hard | Hard |

**核心考点**: 链表分段的"三明治"结构 (pre + start + end + cur); 边界 pre-check 是链表题通用范式。

## A.3 LeetCode 4 - 寻找两个正序数组的中位数 (Hard)

### 原始错题

```python
def findMedianSortedArrays(nums1, nums2):
    # 错: 归并排序后取中位数, O(m+n) 空间 + 时间
```

### 错因归类

```text
[ ] 题意误解    [ ] 边界遗漏    [ ] 算法正确    [√] 复杂度误判    [ ] 代码陷阱
```

### 错误版本 (次优)

```python
def findMedianSortedArrays(nums1, nums2):
    merged = []
    i = j = 0
    while i < len(nums1) and j < len(nums2):
        if nums1[i] <= nums2[j]:
            merged.append(nums1[i]); i += 1
        else:
            merged.append(nums2[j]); j += 1
    merged.extend(nums1[i:])
    merged.extend(nums2[j:])
    n = len(merged)
    if n % 2 == 0:
        return (merged[n//2 - 1] + merged[n//2]) / 2
    return merged[n//2]
```

**问题**: 题目要求 O(log(m+n)), 此解是 O(m+n)。

### 正确解法: 二分查找第 k 小

```python
def findMedianSortedArrays(nums1, nums2):
    def get_kth(k):
        # 在 nums1[i:] 和 nums2[j:] 中找第 k 小
        i, j = 0, 0
        while True:
            if i == len(nums1):
                return nums2[j + k - 1]
            if j == len(nums2):
                return nums1[i + k - 1]
            if k == 1:
                return min(nums1[i], nums2[j])

            # 二分: 各取 k//2 个
            ii = min(i + k//2 - 1, len(nums1) - 1)
            jj = min(j + k//2 - 1, len(nums2) - 1)
            if nums1[ii] <= nums2[jj]:
                k -= (ii - i + 1)
                i = ii + 1
            else:
                k -= (jj - j + 1)
                j = jj + 1

    total = len(nums1) + len(nums2)
    if total % 2 == 0:
        return (get_kth(total // 2) + get_kth(total // 2 + 1)) / 2
    return get_kth(total // 2 + 1)
```

### 复盘要点

**核心考点**: 看到"两个有序数组 + 中位数"立即联想 **二分查找第 k 小**; 每次排除 k//2 个元素; 递归改循环避免栈溢出。

## A.4 LeetCode 239 - 滑动窗口最大值 (Hard)

### 原始错题

```python
def maxSlidingWindow(nums, k):
    # 错: 每窗口重新 max(), O(n*k)
    return [max(nums[i:i+k]) for i in range(len(nums) - k + 1)]
```

### 错因归类

```text
[ ] 题意误解    [ ] 边界遗漏    [√] 算法选择错误    [√] 复杂度误判    [ ] 代码陷阱
```

### 正确解法: 单调队列 (deque)

```python
from collections import deque

def maxSlidingWindow(nums, k):
    dq = deque()  # 存下标, 对应值单调递减
    res = []
    for i, x in enumerate(nums):
        # 1. 移除队尾所有小于 x 的下标 (它们永远不会是最大值)
        while dq and nums[dq[-1]] < x:
            dq.pop()
        dq.append(i)
        # 2. 移除队首超出窗口的下标
        if dq[0] <= i - k:
            dq.popleft()
        # 3. 窗口形成后记录答案
        if i >= k - 1:
            res.append(nums[dq[0]])
    return res
```

### 复盘要点

**核心考点**: 单调队列 = 滑动窗口 + 极值; 维护"递减 + 在窗口内"; 队尾 pop 是删除不可能最大值的元素。

## A.5 LeetCode 76 - 最小覆盖子串 (Hard)

### 原始错题

```python
def minWindow(s, t):
    # 错: 每次 check 整个子串, O(n^2 * m)
```

### 正确解法: 滑动窗口 + 欠账表

```python
from collections import Counter, defaultdict

def minWindow(s, t):
    need = Counter(t)
    missing = len(t)  # 还需要多少字符
    left = start = end = 0
    for right, c in enumerate(s, 1):
        if need[c] > 0:
            missing -= 1
        need[c] -= 1
        if missing == 0:  # 当前窗口已覆盖
            while left < right and need[s[left]] < 0:
                need[s[left]] += 1
                left += 1
            if end == 0 or right - left <= end - start:
                start, end = left, right
            need[s[left]] += 1
            missing += 1
            left += 1
    return s[start:end]
```

### 复盘要点

**核心考点**: 滑动窗口 + 欠账 (missing) 跟踪何时满足条件; `need[c] < 0` 表示字符"多余"可被踢出。

## A.6 LeetCode 32 - 最长有效括号 (Hard)

### 原始错题

```python
def longestValidParentheses(s):
    # 错: 栈解法没考虑 '(' 入栈时是 0 还是 -1
```

### 正确解法: 栈底垫 0

```python
def longestValidParentheses(s):
    stack = [-1]  # 栈底垫 -1, 处理起始位置
    res = 0
    for i, c in enumerate(s):
        if c == '(':
            stack.append(i)
        else:
            stack.pop()
            if not stack:
                stack.append(i)  # 当前 ) 无效, 重置基准
            else:
                res = max(res, i - stack[-1])
    return res
```

### DP 版本

```python
def longestValidParentheses(s):
    n = len(s)
    dp = [0] * n
    for i in range(1, n):
        if s[i] == ')':
            if s[i-1] == '(':
                dp[i] = (dp[i-1] if i >= 2 else 0) + 2
            elif i - dp[i-1] - 1 >= 0 and s[i - dp[i-1] - 1] == '(':
                dp[i] = dp[i-1] + 2 + (dp[i - dp[i-1] - 2] if i - dp[i-1] - 2 >= 0 else 0)
    return max(dp)
```

### 复盘要点

**核心考点**: 栈底垫 0 是处理"最近无效位置"的关键技巧; DP 状态 `dp[i]` 表示以 i 结尾的最长有效长度。

## A.7 LeetCode 124 - 二叉树中的最大路径和 (Hard)

### 原始错题

```python
def maxPathSum(root):
    # 错: 递归返回值与全局最大值混用
```

### 正确解法

```python
def maxPathSum(root):
    self.res = float('-inf')

    def gain(node):
        if not node: return 0
        # 左/右贡献, 负数则不取 (用 max(0, ...))
        left = max(0, gain(node.left))
        right = max(0, gain(node.right))
        # 经过当前节点的最大路径 = 左 + 中 + 右
        self.res = max(self.res, left + node.val + right)
        # 返回给父节点的"单边最大贡献"
        return node.val + max(left, right)

    gain(root)
    return self.res
```

### 复盘要点

**核心考点**: **树的路径题** 区分"经过根"和"返回父节点"; `max(0, ...)` 丢弃负贡献; 全局最大值 vs 递归返回值不可混淆。

## A.8 LeetCode 42 - 接雨水 (Hard)

### 原始错题

```python
def trap(height):
    # 错: 双指针解法移动逻辑混乱
```

### 解法对比

#### 解法 1: 前后缀最大值

```python
def trap(height):
    n = len(height)
    left_max = [0] * n
    right_max = [0] * n
    for i in range(1, n):
        left_max[i] = max(left_max[i-1], height[i-1])
    for i in range(n-2, -1, -1):
        right_max[i] = max(right_max[i+1], height[i+1])
    return sum(max(0, min(left_max[i], right_max[i]) - height[i]) for i in range(n))
```

#### 解法 2: 单调栈

```python
def trap(height):
    stack = []
    res = 0
    for i, h in enumerate(height):
        while stack and height[stack[-1]] < h:
            bottom = stack.pop()
            if not stack: break
            left = stack[-1]
            width = i - left - 1
            bounded = min(height[left], h) - height[bottom]
            res += width * bounded
        stack.append(i)
    return res
```

#### 解法 3: 双指针 (最优)

```python
def trap(height):
    left, right = 0, len(height) - 1
    left_max = right_max = 0
    res = 0
    while left < right:
        if height[left] < height[right]:
            if height[left] >= left_max:
                left_max = height[left]
            else:
                res += left_max - height[left]
            left += 1
        else:
            if height[right] >= right_max:
                right_max = height[right]
            else:
                res += right_max - height[right]
            right -= 1
    return res
```

### 复盘要点

**核心考点**: 一题三解 (前缀/单调栈/双指针), 体现"算法选择空间"; 双指针最优, 空间 O(1); 单调栈适合"凹槽"问题。

## A.9 LeetCode 23 - 合并 K 个升序链表 (Hard)

### 原始错题

```python

    # 错: 两两合并, O(k^2 * n)
```

### 正确解法: 优先队列 (堆)

```python
import heapq

def mergeKLists(lists):
    heap = []
    for i, l in enumerate(lists):
        if l:
            heapq.heappush(heap, (l.val, i, l))
    dummy = ListNode(0)
    cur = dummy
    while heap:
        val, i, node = heapq.heappop(heap)
        cur.next = node
        cur = cur.next
        if node.next:
            heapq.heappush(heap, (node.next.val, i, node.next))
    cur.next = None
    return dummy.next
```

## A.10 LeetCode 56 - 合并区间 (Medium)

### 原始错题

```python
def merge(intervals):
    # 错: 没排序直接合并
```

### 正确解法: 排序 + 贪心

```python
def merge(intervals):
    intervals.sort(key=lambda x: x[0])
    res = []
    for interval in intervals:
        if not res or res[-1][1] < interval[0]:
            res.append(interval)
        else:
            res[-1][1] = max(res[-1][1], interval[1])
    return res
```

### 复盘要点

```python
"""
错题本自动统计: 解析 Markdown 错题本, 统计各类错因占比
"""
import re
from collections import Counter
from pathlib import Path

class MistakeAnalyzer:
    def __init__(self, md_path):
        self.path = Path(md_path)
        self.text = self.path.read_text(encoding='utf-8')

    def count_causes(self):
        """统计每类错因出现次数"""
        causes = ['题意误解', '边界遗漏', '算法选择', '复杂度误判', '代码陷阱']
        counts = Counter()
        for cause in causes:
            counts[cause] = self.text.count(cause)
        return counts

    def find_unanswered(self):
        """找出没有'正确解法'的题目"""
        no_solution = []
        for m in re.finditer(r'### LeetCode (\d+)', self.text):
            title_line = m.group(0)
            # 找下一个 ### 之前是否包含'正确解法'
            next_section = self.text.find('###', m.end())
            section = self.text[m.end():next_section if next_section > 0 else None]
            if '正确解法' not in section and '解法' not in section:
                no_solution.append(m.group(1))
        return no_solution

    def report(self):
        counts = self.count_causes()
        unanswered = self.find_unanswered()
        print(f"错题本分析报告: {self.path.name}")
        print("=" * 50)
        print(f"总错因提及: {sum(counts.values())}")
        for c, n in counts.most_common():
            print(f"  {c}: {n}")
        print(f"\n未写解法的题号: {unanswered}")

if __name__ == '__main__':
    analyzer = MistakeAnalyzer('第10章-11-错题本.md')
    analyzer.report()
```

## D.2 错题本回顾提醒脚本

```python
"""
基于艾宾浩斯曲线的错题复习提醒
"""
from datetime import datetime, timedelta
import json

class ReviewScheduler:
    INTERVALS = [1, 2, 4, 7, 15, 30, 60]  # 天

    def __init__(self):
        self.schedule = {}

    def add_mistake(self, problem_id, problem_name):
        now = datetime.now()
        self.schedule[problem_id] = {
            'name': problem_name,
            'added': now.isoformat(),
            'reviews': [now + timedelta(days=d) for d in self.INTERVALS]
        }

    def due_today(self):
        today = datetime.now().date()
        due = []
        for pid, info in self.schedule.items():
            for review_date in info['reviews']:
                if review_date.date() == today:
                    due.append((pid, info['name']))
                    break
        return due

    def save(self, path='review_schedule.json'):
        with open(path, 'w') as f:
            json.dump(self.schedule, f, indent=2)

if __name__ == '__main__':
    sched = ReviewScheduler()
    sched.add_mistake('LC146', 'LRU Cache')
    sched.add_mistake('LC4', '中位数')
    print('今日待复习:', sched.due_today())
```

## 附录 G: 高难度错题专题

## G.1 错题之王: LeetCode 154 - 寻找旋转排序数组中的最小值 II (Hard)

```python
def findMin(nums):
    """二分: 含重复元素的旋转数组最小值"""
    left, right = 0, len(nums) - 1
    while left < right:
        mid = (left + right) // 2
        if nums[mid] < nums[right]:
            right = mid
        elif nums[mid] > nums[right]:
            left = mid + 1
        else:  # nums[mid] == nums[right], 无法判断, 退化为 O(n)
            right -= 1
    return nums[left]
```

**难点**: `nums[mid] == nums[right]` 时无法二分, 退化为线性扫描。

## G.2 错题之王: LeetCode 887 - 鸡蛋掉落 (Hard)

```python
def superEggDrop(k, n):
    """k 个鸡蛋, n 层楼, 求最少扔鸡蛋次数"""
    # dp[k][m] = m 次扔鸡蛋能测的最大楼层数
    # dp[k][m] = dp[k-1][m-1] + dp[k][m-1] + 1
    dp = [[0] * (k + 1) for _ in range(n + 1)]
    m = 0
    while dp[m][k] < n:
        m += 1
        for i in range(1, k + 1):
            dp[m][i] = dp[m-1][i-1] + dp[m-1][i] + 1
    return m
```

**核心思想**: 改变 dp 维度 (扔 m 次能测多少层), 而不是 (k 个鸡蛋测 n 层), 二分思想的关键。

## G.3 错题之王: LeetCode 295 - 数据流的中位数 (Hard)

```python
import heapq

class MedianFinder:
    def __init__(self):
        self.small = []  # 最大堆 (存负数)
        self.large = []  # 最小堆

    def addNum(self, num):
        if len(self.small) == len(self.large):
            heapq.heappush(self.small, -heapq.heappushpop(self.large, num))
        else:
            heapq.heappush(self.large, -heapq.heappushpop(self.small, -num))

    def findMedian(self):
        if len(self.small) > len(self.large):
            return -self.small[0]
        return (-self.small[0] + self.large[0]) / 2
```

**核心思想**: 双堆, 大根堆存小数, 小根堆存大数, 保证平衡。

**7. 实践建议**

结合 "错题本 (含 10 个真实错题 + 错因分析)" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "错题本 (含 10 个真实错题 + 错因分析)" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
