# 11.01 穷竭搜索的优化

> **本节定位**: 让 $O(2^n)$ 暴力"可执行"
> **核心**: 剪枝 + 双向搜索 + 迭代加深 + 启发式

## 1. 剪枝 (Pruning)

暴力搜索的核心是**减少搜索树**的规模. 剪枝是关键.

### 1.1 三大剪枝类型

| 类型 | 描述 | 例子 |
|---|---|---|
| **可行性剪枝** | 当前分支不可能达到合法解 | 数独冲突 / 剪枝后剩余值不够 |
| **最优性剪枝** | 当前分支的最优值已超过当前最优 | 旅行商 (TSP) |
| **对称性剪枝** | 等价的状态只搜索一次 | 排列生成 (避免重复) |

### 1.2 旅行商 (TSP) 的剪枝

**问题**: N 个城市, 起点 0, 找最短回路.

**最优性剪枝**:
- 当前路径长度 + 已访问 + 剩余城市的最小可能距离 > 当前最优 → 剪枝

```python
import sys

def tsp(n, dist):
    """状态压缩 DP + 最优性剪枝"""
    # 状态: (已访问 mask, 当前城市 u)
    INF = float('inf')
    dp = [[INF] * n for _ in range(1 << n)]
    dp[1][0] = 0  # 从 0 出发

    best = INF
    for mask in range(1 << n):
        for u in range(n):
            if dp[mask][u] == INF: continue
            if mask & (1 << u) == 0: continue

            # 当前已用距离
            cur = dp[mask][u]

            # 最优性剪枝: 如果已超过 best, 剪枝
            if cur >= best: continue

            # 扩展
            for v in range(n):
                if mask & (1 << v): continue
                new_mask = mask | (1 << v)
                dp[new_mask][v] = min(dp[new_mask][v], cur + dist[u][v])

            # 检查是否完成
            if mask == (1 << n) - 1:
                # 回到起点
                best = min(best, cur + dist[u][0])

    return best
```

## 2. 双向搜索 (Meet in the Middle)

### 2.1 思想

**当 $n$ 太大 (如 $n=40$, 直接 $2^{40}$ 不可行), 但 $n/2$ 可行**:
- 枚举前 $n/2$ 个的所有子集 → 存哈希表
- 枚举后 $n/2$ 个的所有子集 → 查哈希表

**复杂度**: $O(2^{n/2} \cdot n)$ 而非 $O(2^n)$.

### 2.2 经典题: 4-Sum (LeetCode 18 升级版)

**问题**: 找 4 个数使和为 target, 4 ≤ n ≤ 40.

```python
def four_sum(nums, target):
    """双向搜索"""
    n = len(nums)
    if n < 4: return []

    # 前半: 存所有 (a+b, [i, j])
    half1 = {}
    for i in range(n // 2):
        for j in range(i + 1, n // 2):
            s = nums[i] + nums[j]
            half1.setdefault(s, []).append((i, j))

    # 后半: 找 (a+b) = target - (c+d)
    res = set()
    for k in range(n // 2, n):
        for l in range(k + 1, n):
            s = target - (nums[k] + nums[l])
            if s in half1:
                for i, j in half1[s]:
                    res.add(tuple(sorted([nums[i], nums[j], nums[k], nums[l]])))

    return [list(t) for t in res]
```

### 2.3 经典题: 数组中和为 0 的子集 (POJ 3977)

**问题**: 找子集, 使和最接近 0. n ≤ 35.

```python
def subset_sum_zero(nums):
    n = len(nums)
    half = n // 2

    # 前半所有子集
    first = {}
    for mask in range(1 << half):
        s = sum(nums[i] for i in range(half) if mask & (1 << i))
        cnt = bin(mask).count('1')
        if s not in first or first[s][1] > cnt:
            first[s] = (mask, cnt)

    # 后半所有子集, 找 (a + b = 0)
    best = (float('inf'), 0)
    for mask in range(1 << (n - half)):
        s = sum(nums[half + i] for i in range(n - half) if mask & (1 << i))
        cnt = bin(mask).count('1')
        # 找前半中 -s
        if -s in first:
            total_cnt = first[-s][1] + cnt
            if abs(s) < abs(best[0]) or (abs(s) == abs(best[0]) and total_cnt < best[1]):
                best = (s, total_cnt)

    return best
```

## 3. 迭代加深 DFS (IDDFS)

### 3.1 思想

**当 DFS 树太深 (可能无限), BFS 内存不够**:
- 限制深度 0, 1, 2, ... 逐步加深
- 每次用 DFS 搜该深度限制
- 找到答案就停

**复杂度**: 与 BFS 相当, 但内存是 DFS 的 (递归栈).

### 3.2 经典题: 埃及分数 (EOJ 2578 / UVA 125)

**问题**: 把分子/分母 用最少的"单位分数" (1/a) 之和表示.

```python
def egyptian_fraction(numerator, denominator, max_depth=10):
    """迭代加深 DFS"""

    def dfs(num, den, depth, result):
        if depth == max_depth:
            if num == 0: return result
            return None

        # 试单位分数 1/ceil(den/num)
        start = (den + num - 1) // num  # ceil(den/num)
        for unit in range(start, den * max_depth):
            # 剩余: num/den - 1/unit = (num*unit - den) / (den*unit)
            new_num = num * unit - den
            new_den = den * unit
            if new_num < 0: break
            # 剪枝: 剩余的最小单位分数 1/(unit+1) 数量
            from math import gcd
            g = gcd(new_num, new_den)
            new_num //= g
            new_den //= g
            # 如果 1/(unit+1) > 1/(unit) 无效
            res = dfs(new_num, new_den, depth + 1, result + [unit])
            if res is not None:
                return res
        return None

    return dfs(numerator, denominator, 0, [])
```

## 4. IDA* (A* + 迭代加深)

### 4.1 思想

**A***: 启发式搜索, 用 $f(n) = g(n) + h(n)$ 估计总代价.

**IDA***: 用迭代加深 + A* 启发式:
- 设当前阈值 = $h(\text{start})$
- DFS, 剪枝 $f(n) > \text{threshold}$ 的节点
- 找不到答案, 增大阈值, 重复

**优势**: 内存 $O(d)$ (深度), 完备 + 最优 (启发式 admissible).

### 4.2 经典题: 八数码 (POJ 1077 / LeetCode 773 类似)

**问题**: 3×3 滑块拼图, 最少步数.

```python
import heapq

def eight_puzzle(state):
    """A* 搜索 (用 IDA* 也可)"""
    goal = (1, 2, 3, 4, 5, 6, 7, 8, 0)

    def h(s):
        """曼哈顿距离启发式"""
        return sum(abs(i // 3 - s.index(x) // 3) + abs(i % 3 - s.index(x) % 3) for i, x in enumerate(goal) if x != 0)

    if state == goal: return 0

    # A* 优先队列
    pq = [(h(state), 0, state)]
    visited = {state: 0}
    moves = {0: [1, 3], 1: [0, 2, 4], 2: [1, 5], 3: [0, 4, 6], 4: [1, 3, 5, 7], 5: [2, 4, 8], 6: [3, 7], 7: [4, 6, 8], 8: [5, 7]}

    while pq:
        f, g, s = heapq.heappop(pq)
        if s == goal: return g

        zero = s.index(0)
        for nxt in moves[zero]:
            lst = list(s)
            lst[zero], lst[nxt] = lst[nxt], lst[zero]
            new_s = tuple(lst)
            new_g = g + 1
            if new_s not in visited or new_g < visited[new_s]:
                visited[new_s] = new_g
                heapq.heappush(pq, (new_g + h(new_s), new_g, new_s))

    return -1
```

## 5. 启发式搜索 (Heuristic Search)

### 5.1 核心思想

**关键**: 设计好的"启发函数" $h(n)$, 估计从状态 $n$ 到目标的最少代价.

**admissible**: $h(n) \leq \text{actual cost}$ (保证最优).

**consistent**: $h(n) \leq c(n, n') + h(n')$ (A* 不需要重开列表).

### 5.2 常用启发式

| 问题 | 启发式 |
|---|---|
| 8 数码 | 曼哈顿距离 |
| TSP | 最小生成树 |
| 15 数码 | 曼哈顿 + 线性冲突 |
| 路径规划 | 欧氏距离 |

## A.1 三大剪枝类型的完整对比

| 类型 | 描述 | 触发条件 | 实现难度 | 效果 |
| :--- | :--- | :--- | :--- | :--- |
| 可行性剪枝 | 当前分支不可能达到合法解 | 冲突 / 剩余值不足 / 越界 | 中 | 显著 |
| 最优性剪枝 | 当前分支最优值超当前最优 | 当前代价 + 启发 ≥ 全局最优 | 易 | 显著 |
| 对称性剪枝 | 等价状态只搜一次 | 排列/组合/镜像 | 中 | 中 |

# 剪枝顺序很重要!

# 2. 再检查: 是否已经超最优 (最优性)
# 3. 最后: 对称性剪枝 (减少重复)

def optimized_backtrack(state):

    if not is_feasible(state): return False  # 1. 可行性

        if optimized_backtrack(new_state): return True
    return False

## A.3 经典剪枝题 (LeetCode 51 N 皇后 详解)

```python
def solveNQueens(n):
    """位运算 + 剪枝, 极限优化版本"""
    res = []

    def dfs(row, cols, diag1, diag2, board):
        if row == n:
            res.append(board[:])
            return
        # 当前行可用位置
        available = ((1 << n) - 1) & ~(cols | diag1 | diag2)
        while available:
            # 取最低位 (启发: 选择最低位, 启发搜索效果最好)
            pos = available & -available
            available ^= pos
            col_idx = (pos.bit_length() - 1)
            board.append('.' * col_idx + 'Q' + '.' * (n - col_idx - 1))
            # 下一行: 列 + 两条对角线
            dfs(row + 1,
                cols | pos,
                (diag1 | pos) << 1,
                (diag2 | pos) >> 1,
                board)
            board.pop()

    dfs(0, 0, 0, 0, [])
    return res

# 复杂度: O(n!), n=12 约 1s
# 优化点:
# 1. 位运算代替 set
# 2. 取最低位启发 (启发式搜索)
# 3. 减少对象创建
```

## A.4 可行性剪枝 6 种常见模式

```python
# 模式 1: 数值超界
def feasible_value(state, limit):
    return state.value <= limit

# 模式 2: 重复约束
def feasible_no_repeat(state):
    return len(state.used) == len(set(state.used))

# 模式 3: 范围约束
def feasible_in_range(state, lo, hi):
    return all(lo <= x <= hi for x in state.values)

# 模式 4: 计数约束
def feasible_count(state, required):
    return state.count >= required

# 模式 5: 拓扑约束 (DAG 任务)
def feasible_dag(state, dependencies):
    for task in state.to_do:
        if not all(dep in state.done for dep in dependencies[task]):
            return False
    return True

# 模式 6: 几何约束 (不重叠)
def feasible_no_overlap(state, items):
    for i in range(len(items)):
        for j in range(i + 1, len(items)):
            if overlap(items[i], items[j]): return False
    return True
```

# 技术 1: 排序 (避免重复排列)
def permute_unique(nums):
    nums.sort()  # 排序让相同元素相邻
    n = len(nums)
    res = []
    used = [False] * n

    def backtrack(path):
        if len(path) == n:
            res.append(path[:])
            return
        for i in range(n):
            if used[i]: continue
            # 关键剪枝: 相同元素, 前一个未用则跳过
            if i > 0 and nums[i] == nums[i-1] and not used[i-1]: continue

            backtrack(path)
            path.pop()
            used[i] = False
    backtrack([])
    return res

### 110. 穷竭搜索的优化 (剪枝/双向DFS/迭代加深/IDA*) - 思维框架 视角

**1. 背景与动机**

任何技术或方法的出现都不是孤立的,而是回应特定历史条件下的具体问题。"穷竭搜索的优化 (剪枝/双向DFS/迭代加深/IDA*)" 的发展也不例外。要理解它,必须回到它出现的那个时间点,看清它要解决的真实问题是什么。当时的主流方案有哪些不足? 它的提出填补了哪些空白? 这些问题的回答,决定了我们今天该如何使用它。

从知识论角度看,**技术演进是问题驱动的**——不是先有方案再找问题,而是先有问题再有方案。这个观察可以帮助我们避免"拿着锤子找钉子"的陷阱,真正把方法用对地方。

历史维度上,我们看到三个规律:

1. **从特殊到一般**: 早期方法往往针对特定场景,后期抽象出通用框架。学习的认知规律也是先掌握具体案例,再抽象出一般模式。这种"自下而上"的学习方式,在机器学习模型的设计里反复出现。

2. **从手工到自动**: 经验规则逐步被数据驱动的方法取代。在早期,很多 AI 系统依赖人工编写的规则。统计学习方法的崛起让"从数据中学习"成为可能。深度学习进一步把特征工程也自动化了。今天的大模型时代,我们看到端到端学习从感知扩展到了推理与生成。

3. **从局部到全局**: 关注单个组件,演进到关注整个系统。早期模型评估只关注单点指标,现在更关注全链路的协同效应。这种"系统视角"的转变,与软件工程从单体架构到微服务架构的演进高度相似。

**2. 思维框架视角的展开**

从思维框架视角出发,我们可以把 "穷竭搜索的优化 (剪枝/双向DFS/迭代加深/IDA*)" 拆解为以下几个层次:

**第一层: 概念层** —— 这是最抽象的层次,定义了我们要研究的对象是什么。例如,"推荐系统"在概念层是一个"为用户从物品集合中筛选合适物品"的问题。这个层次的特点是清晰、稳定、不易变化。一个好的概念定义应该具备几个特征:可操作性、可测量性、可扩展性。

**第二层: 模型层** —— 把概念实例化为数学模型。同一概念可以有不同的模型化方式,例如"推荐系统"可以是协同过滤、矩阵分解、深度学习等。模型的选择决定了后续算法的空间,也决定了能利用的归纳偏置(比如序列模型擅长捕捉时序依赖,图模型擅长建模关系结构)。模型选型是工程实践中最重要的决策之一。
