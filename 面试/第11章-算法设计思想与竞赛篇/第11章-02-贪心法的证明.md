# 11.02 贪心法的证明

> **本节定位**: 为什么贪心是对的? 必会的证明方法
> **核心**: 交换论证 / 反证法 / 数学归纳 / 决策单调性

---

## 1. 为什么需要证明?

```text
题目: "贪心能拿到最优解吗?"
错误回答: "看起来对"
正确回答: "证明如下..."
```

**贪心陷阱**: 局部最优 ≠ 全局最优 (除非证明).

**经典反例**:
- 0-1 背包: 贪心按价值/重量比, 不一定最优
- 旅行商: 贪心取最近城市, 不一定最短
- 找零钱 (面额 1, 3, 4): 找零 6 贪心得 4+1+1 (3 枚), 但 3+3 (2 枚) 更优

---

## 2. 证明方法 1: 交换论证 (Exchange Argument)

### 2.1 思想

**假设最优解与贪心解在某处不同, 交换两者的"某一步", 看是否更优或不变. 如果不更优, 说明贪心正确.**

### 2.2 经典证明: 区间调度 (选最多不重叠区间)

**问题**: 给多个区间, 选最多不重叠的.

**贪心**: 按 end 升序, 每次选能选的.

**证明**:
```text
设贪心选 G = [g1, g2, ..., gk] (按 end 排)
设最优解 O = [o1, o2, ..., om] (按 end 排)

我们证明 k = m.

用数学归纳:
- g1 的 end ≤ o1 的 end (因为 g1 是最早结束的)
  → g2 的 end 也 ≤ o2 的 end (g2 是不与 g1 重叠的最早结束的; o2 也不与 o1 重叠, 但 o1 的 end ≥ g1 的 end, 所以 g2 的 end ≤ o2 的 end)
  → ...
  → 推得: g_i 的 end ≤ o_i 的 end (对所有 i ≤ min(k, m))

- 所以 O 可以逐项替换为 G (每个 o_i 可用 g_i 替换, 不影响合法性)
- 因此 m ≤ k
- 但 k ≤ m (G 是合法解, O 是最优)
- 所以 k = m ✓
```

### 2.3 经典证明: Huffman 编码

**问题**: 给字符频率, 构造最优前缀码.

**贪心**: 每次取频率最小的两个合并.

**证明 (sketch)**:
- 设 a, b 是频率最小的两个字符
- 假设最优树中 a, b 的编码长度不相等, 比如 a 比 b 长
- 可以交换 a, b 的位置 (深度), 不会更差
- 所以最优树中 a, b 必在同一层, 且是其父节点的两个叶子
- 递归即可

## 3. 证明方法 2: 反证法 (Proof by Contradiction)

### 3.1 思想

**假设贪心结果不是最优**, 然后推出矛盾.

### 3.2 经典证明: 跳跃游戏 (LeetCode 55)

**问题**: nums[i] 表示可跳的最远距离, 问能否到末尾.

**贪心**: 维护当前能到的最远位置 `max_reach`.

**证明**:
```text
假设贪心说"不能到达", 但实际能到达.

设 max_reach = R, 即位置 0..R 内的点都能跳到.
"不能到达"意味着位置 R+1 跳不到.

但假设存在一个能到达末尾的路径, 设 P[i] 是路径上的第 i 个位置.
P[0] = 0, P[end] = n-1.

必有 P[i] ≤ R (否则与"max_reach = R" 矛盾).
所以 P[i+1] ≤ P[i] + nums[P[i]] ≤ R + nums[P[i]].
若存在 P[i] 使得 P[i] + nums[P[i]] > R, 那么 R+1 也能到, 矛盾.

所以: 路径上每个位置的 next_max 都不超过 R, 矛盾.
```

## 4. 证明方法 3: 数学归纳 (Mathematical Induction)

### 4.1 思想

**证明: 前 k 步贪心都正确, 由 k 推到 k+1.**

### 4.2 经典证明: 单源最短路径 (Dijkstra)

**问题**: 找从源到所有点的最短路.

**贪心**: 每次选未访问中距离最小的点, 更新邻居.

**证明**:
- 基础: 第一次选的点 (距离 0) 显然最短
- 归纳: 假设前 k 次选的点都正确
- 第 k+1 次: 选未访问中距离最小的 u
- 若 u 的距离不是最短, 则存在未访问的 v, 距离比 u 短
- 但 v 必须经过已访问的某个 w
- w 的距离是已知的 (已访问中 w 距离 ≤ u 距离)
- 所以 v 距离 ≥ w 距离 ≥ u 距离
- 矛盾 → u 的距离是最短 ✓

## 5. 证明方法 4: 决策单调性 (Decision Monotonicity)

### 5.1 思想

**贪心的关键是: 决策"取/不取"具有单调性**.

如果"取第 k 个" 蕴含"取第 k-1 个", 则可用单调队列/单调栈.

### 5.2 应用: 任务选择问题

**问题**: 每个任务有 (deadline, profit), 完成每个任务耗时 1 单位, 求最大利润.

**贪心 + 证明**:
- 按 deadline 升序排序
- 用并查集/反证法, 证明"每个任务尽量晚做"最优

## 6. 实战案例分析

### 6.1 案例 1: 区间合并 (LeetCode 56)

**贪心**: 按 start 排序, 合并相邻的.

**证明**:
- 设合并结果 [s1, e1], [s2, e2], ...
- 若 s1 最小, 则 e1 ≥ s2 (否则两个区间)
- 用数学归纳: 任何合并策略产生的区间数 ≥ 贪心结果

### 6.2 案例 2: 加油站 (LeetCode 134)

**贪心**: 一次遍历, 油不够就从下一站开始.

**证明**:
- 设总油量 ≥ 总消耗 (有解)
- 假设从 i 出发, 在 j 处油不够 (j > i)
- 那么 i..j-1 任一站出发, 都会在 j 或之前油不够
- 因为: 从 k (i ≤ k < j) 出发, 到 j 的油量 ≤ 从 i 出发到 j 的油量
- 所以下次从 j+1 开始

### 6.3 案例 3: 分糖果 (LeetCode 135)

**贪心**: 两次贪心, 从左到右 + 从右到左.

**证明**:
- 从左到右: 若右比左大, 右比左多 1
- 从右到左: 若左比右大, 左比右多 1
- 取 max(两次结果), 保证每个高分都比邻居多
- 是最优 (因为若不这样, 必有更高的糖果数)

## 7. 决策单调性优化 (DP 优化基础)

### 7.1 概念

**决策单调性**: DP 中, 状态 $i$ 的最优决策 $opt(i)$ 随 $i$ 单调不减.

**应用**: 单调队列优化, 把 $O(n^2)$ 优化到 $O(n)$.

### 7.2 例: 邮局选址 (经典)

**问题**: 数轴上 n 个村庄, 建 k 个邮局, 最小化总距离.

```python
def post_office(nums, k):
    """DP + 决策单调性"""
    n = len(nums)
    nums.sort()

    # cost[i][j] = nums[i..j] 集中到中位数的距离和
    cost = [[0] * n for _ in range(n)]
    for length in range(1, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            mid = (i + j) // 2
            cost[i][j] = (cost[i][mid-1] + cost[mid+1][j] if mid > i else 0) + \
                         (cost[mid+1][j] + cost[i][mid-1] if mid < j else 0) + \
                         nums[mid] - nums[i] + nums[j] - nums[mid]

    # dp[i][k] = 前 i 个村庄建 k 个邮局的最小距离
    dp = [[float('inf')] * (k + 1) for _ in range(n + 1)]
    for i in range(n):
        dp[i][1] = cost[0][i]
```

## 8. 证明的常见错误

### 8.1 ❌ 错误 1: "显然"

"显然" 不是证明. 必须**显式**说明.

### 8.2 ❌ 错误 2: 循环论证

A → B → A 不算证明.

### 8.3 ❌ 错误 3: 反例没找全

要"完全"地考虑所有情况, 不遗漏.

### 8.4 ❌ 错误 4: 假设不对

"假设贪心错" 是反证法, 但要明确"贪心错"的具体含义.

## 第二部分附录 A: 贪心算法核心洞察

## A.1 贪心的本质

```text
贪心 = 在每一步选择当前最优 (局部最优)
正确性 = 局部最优 ⊆ 全局最优

何时成立?
1. 拟阵 (Matroid): 经典理论 (Kruskal, 任务选择)
2. 拟阵的扩展: 区间调度
3. 单调性 / 决策单调性
4. 不可改进: 局部最优可被"全局化" (交换论证)
```

## A.2 贪心的"危险"区域

```python
# 反例 1: 找零钱
# 面额 [1, 3, 4], 找零 6
# 贪心 (大优先): 4 + 1 + 1 = 3 枚
# 最优: 3 + 3 = 2 枚
# 贪心错!

# 反例 2: 0-1 背包
# 物品 (v, w): (60, 10), (100, 20), (120, 30), 容量 50
# 贪心按 v/w: 选 (60, 10) + (100, 20) + (120, 30) = 280
# 但 (100, 20) + (120, 30) = 220 (不超重), (60, 10) 加不了
# 所以贪心只选 (120, 30) + (60, 10) = 180, 但选 (60, 10) + (100, 20) = 160
# 实际最优: (60, 10) + (100, 20) + (120, 30) = 280, 但 50+10+20+30 = 60 超 50
# 重算: (100, 20) + (120, 30) = 220 (重 50)
#        (60, 10) + (100, 20) = 160 (重 30)
#        (60, 10) + (120, 30) = 180 (重 40)
# 最优: 220, 贪心: 180, 贪心错!

# 反例 3: 旅行商
# 贪心取最近城市, 不一定最短
```

## A.3 何时用贪心

| 条件 | 例子 |
| :--- | :--- |
| 可交换性 (exchangeable) | 排序 + 贪心 |
| 单调性 (monotone) | 二分答案 |
| 拟阵 (matroid) | 任务选择 |
| 决策单调性 | 邮局 |
| 局部最优 = 全局最优 | 区间调度 |
