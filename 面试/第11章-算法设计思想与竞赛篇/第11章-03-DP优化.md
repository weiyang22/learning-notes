# 11.03 DP 优化

> **本节定位**: 把 $O(n^2)$ / $O(n^3)$ DP 优化到 $O(n)$ / $O(n \log n)$
> **核心**: 滚动数组 + 单调队列 + 斜率优化 + 四边形不等式

## 1. 滚动数组 (一维 DP)

### 1.1 思想

**当 DP 状态只依赖前 1-2 个状态**, 用滚动变量代替数组.

**空间**: $O(n)$ → $O(1)$.

### 1.2 例: 爬楼梯 (LeetCode 70)

```python
def climbStairs(n):
    """$O(n)$ 空间 → $O(1)$ 空间"""
    if n <= 2: return n
    prev, curr = 1, 2
    for i in range(3, n + 1):
        prev, curr = curr, prev + curr
    return curr
```

### 1.3 例: 打家劫舍 (LeetCode 198)

```python
def rob(nums):
    prev, curr = 0, 0
    for x in nums:
        prev, curr = curr, max(curr, prev + x)
    return curr
```

## 2. 单调队列优化 (区间 DP)

### 2.1 思想

**DP 中存在 $dp[i] = \min_{j \in [i-k, i-1]} (dp[j] + cost(j, i))$**, 朴素 $O(n^2)$.

**用单调队列维护最优 $j$**: 把 $dp[j]$ 放入单调队列, 每次 $O(1)$ 取队首.

**复杂度**: $O(n)$.

### 2.2 例: 跳跃游戏 VI (LeetCode 1696)

**问题**: 从位置 0 出发, 每次跳到 $[i+1, i+nums[i]]$ 范围内, 问跳到末尾的最小分数和.

```python
def maxResult(nums, k):
    """单调队列优化 DP"""
    from collections import deque
    n = len(nums)
    dp = [float('-inf')] * n
    dp[0] = nums[0]
    dq = deque([0])  # 存下标, dp[dq] 单调递减

    for i in range(1, n):
        # 移除超出窗口的
        while dq and dq[0] < i - k:
            dq.popleft()
        # dp[i] = nums[i] + max(dp[dq[0]])
        dp[i] = nums[i] + dp[dq[0]]
        # 维护单调性
        while dq and dp[dq[-1]] <= dp[i]:
            dq.pop()
        dq.append(i)

    return dp[n-1]
```

**复杂度**: $O(n)$.

### 2.3 例: 跳跃游戏 VII (LeetCode 1654)

**问题**: 同样, 但用 $O(n)$ 时间.

```python
def canReach(s, minJump, maxJump):
    """BFS 优化"""
    from collections import deque
    n = len(s)
    # dp[i] = 能否到达
    dp = [False] * n
    dp[0] = True
    # 维护 [i-maxJump, i-minJump] 范围内可达的位置
    window_sum = 0  # 滑动窗口的 dp 和
    for i in range(minJump, n):
        if s[i] == '0':
            # 添加 i-minJump
            if dp[i - minJump]:
                window_sum += 1
            # 移除 i-maxJump-1
            if i - maxJump - 1 >= 0 and dp[i - maxJump - 1]:
                window_sum -= 1
            if window_sum > 0:
                dp[i] = True
    return dp[n-1]
```

## 3. 斜率优化 (Slope Trick)

### 3.1 思想

**DP 中存在 $dp[i] = \min_{j < i} (dp[j] + (i - j)^2)$** 或类似, 朴素 $O(n^2)$.

**用"凸包"维护最优**: 维护一个下凸包, 每次 $O(1)$ 弹走不可能最优的, $O(\log n)$ 或 $O(1)$ 查询.

**复杂度**: $O(n)$ 或 $O(n \log n)$.

### 3.3 维护下凸包

```python
# 添加点 (x, y) 到下凸包
# 横坐标 x 单调递增
# 需要 (y2 - y1) / (x2 - x1) < (y3 - y2) / (x3 - x2)

from collections import deque
dq = deque()  # 存 (x, y)
def add(x, y):
    while len(dq) >= 2:
        x1, y1 = dq[-2]
        x2, y2 = dq[-1]
        # (y2 - y1) / (x2 - x1) < (y3 - y2) / (x3 - x2) → (y2 - y1) * (x3 - x2) < (y3 - y2) * (x2 - x1)
        if (y2 - y1) * (x - x2) < (y - y2) * (x2 - x1):
            dq.pop()
        else:
            break
    dq.append((x, y))
```

## 4. 四边形不等式 (Quadrangle Inequality)

### 4.1 概念

**对于 DP $dp[i][j] = \min_{k \leq i} (dp[k][j-1] + w(k+1, i))$**:
- 若 $w$ 满足**四边形不等式** (区间单调性), 则 $opt[i][j]$ 单调不减
- 优化: 不用枚举所有 $k$, 只在 $opt[i-1][j] \leq k \leq opt[i+1][j]$ 中找
- 复杂度: $O(n^2)$ → $O(n \log n)$ 或 $O(n^2)$ → $O(n^2)$ (常数优化)

### 4.2 例: 合并石子 (经典)

**问题**: N 堆石子排成一行, 每次合并相邻两堆, 费用是两堆之和, 求合并成一堆的最小总费用.

**朴素 DP**: $O(n^3)$.

**四边形不等式优化**: $O(n^2)$.

```python
def mergeStones(stones):
    """四边形不等式优化"""
    n = len(stones)
    prefix = [0] * (n + 1)
    for i in range(n): prefix[i+1] = prefix[i] + stones[i]

    # dp[i][j] = 合并 [i..j] 的最小费用
    dp = [[0] * n for _ in range(n)]
    # opt[i][j] = dp[i][j] 的最优分割点
    opt = [[0] * n for _ in range(n)]

    for i in range(n - 1): opt[i][i+1] = i

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            dp[i][j] = float('inf')
            # 搜索范围 [opt[i][j-1], opt[i+1][j]]
            lo = opt[i][j-1] if j - 1 > i else i
            hi = opt[i+1][j] if i + 1 < j else j - 1
            for k in range(lo, hi + 1):
                val = dp[i][k] + dp[k+1][j] + prefix[j+1] - prefix[i]
                if val < dp[i][j]:
                    dp[i][j] = val
                    opt[i][j] = k
    return dp[0][n-1]
```

**复杂度**: $O(n^2)$ (常数比朴素 $O(n^3)$ 小 $n$ 倍).

## 5. 决策单调性优化

### 5.1 概念

**DP 中, $opt(i)$ 随 $i$ 单调不减**, 可以用单调队列维护.

**模板**:
```python
def dp_with_monotonic_opt(n):
    dp = [0] * n
    deq = deque()  # 候选分割点
    for i in range(n):
        # 移除不可能最优的
        while deq and condition_to_remove: deq.popleft()
        dp[i] = compute(i, deq[0] if deq else i)
        # 添加新候选
        deq.append(i)
    return dp
```

### 5.2 例: 邮局问题 (决策单调性)

```python
def post_office(nums, k):
    n = len(nums)
    nums.sort()
    # cost[i][j]: i..j 的最小距离 (建在中间)
    cost = [[0] * n for _ in range(n)]
    for i in range(n):
        for j in range(i + 1, n):
            mid = (i + j) // 2
            cost[i][j] = nums[mid] * (mid - i + 1) - (sum(nums[i:mid+1]) if mid > 0 else 0) \
                      + (sum(nums[mid+1:j+1]) if mid < j else 0) - nums[mid] * (j - mid)
    # dp[i][j] = 前 i 个村庄建 j 个邮局的最小距离
    dp = [[float('inf')] * (k + 1) for _ in range(n + 1)]
    for i in range(n): dp[i+1][1] = cost[0][i]

    # 分治优化
    def dc(i_lo, i_hi, k_lo, k_hi, j):
        if i_lo > i_hi: return
        i_mid = (i_lo + i_hi) // 2
        best = (float('inf'), -1)
        for kk in range(k_lo, min(k_hi, i_mid) + 1):
            val = dp[i_mid][j-1] + (cost[kk][i_mid-1] if kk < i_mid else 0)
            if val < best[0]:
                best = (val, kk)
        dp[i_mid][j] = best[0]
        dc(i_lo, i_mid - 1, k_lo, best[1], j)
        dc(i_mid + 1, i_hi, best[1], k_hi, j)

    for j in range(2, k + 1):
        dc(1, n, 1, n, j)

    return dp[n][k]
```

## 6. 凸优化 / 拉格朗日

### 6.1 拉格朗日松弛

**对于约束优化**, 用拉格朗日乘子松弛约束, 用次梯度法更新.

**应用**: 复杂约束 DP 的次优解.

### 6.2 凸包 trick (Li Chao Tree / 离线动态凸包)

**问题**: 维护多条直线, 查询某 $x$ 处 $y$ 最小的直线.

```python
class Line:
    def __init__(self, k, b):
        self.k = k  # 斜率
        self.b = b  # 截距
    def value(self, x):
        return self.k * x + self.b

def intersection_x(l1, l2):
    """两直线交点的 x 坐标"""
    return (l2.b - l1.b) / (l1.k - l2.k)
```

**Li Chao Tree**: 用线段树维护, 每次插入 $O(\log X)$, 查询 $O(\log X)$.

## 第二部分附录 A: DP 优化核心洞察

## A.1 为什么需要 DP 优化?

```text
朴素 DP: O(n^2), O(n^3)
优化后: O(n log n), O(n)

本质: 利用"决策单调性"或"数据结构"减少冗余计算
```

## A.2 6 种 DP 优化技术

| 技术 | 何时用 | 复杂度变化 |
| :--- | :--- | :--- |
| 滚动数组 | dp[i] 只依赖前 1-2 状态 | 空间 $O(n) \to O(1)$ |
| 单调队列 | dp[i] = min over sliding window | 时间 $O(n^2) \to O(n)$ |
| 斜率优化 | dp[i] = min over convex function | 时间 $O(n^2) \to O(n)$ 或 $O(n \log n)$ |
| 四边形不等式 | dp[i][j] = min over区间合并 | 时间 $O(n^3) \to O(n^2)$ |
| 决策单调性 | opt(i) 单调 | 时间 $O(n^2) \to O(n \log n)$ |
| 矩阵快速幂 | 线性递推 | 时间 $O(n) \to O(\log n)$ per query |

## A.3 选择优化技术的判据

```text
1. dp[i] 只依赖前几个状态? → 滚动数组
2. 转移是 min/max over [i-k, i-1]? → 单调队列
3. 转移是 min/max over (j - i)^2 or 类似? → 斜率优化
4. 转移是 min over (cost(l, i) + dp[l]) 且 cost 满足四边形不等式? → 四边形优化
5. opt(i) 单调? → 决策单调性 (分治)
6. dp[i] 是线性递推, n 巨大? → 矩阵快速幂
```

**7. 实践建议**

结合 "DP 优化 (单调队列/斜率优化/四边形不等式)" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "DP 优化 (单调队列/斜率优化/四边形不等式)" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
