# 第12章-01-KMP与Z函数

> **适用场景**: 单/多模式匹配、周期检测、最短回文串、字符串去重
> **对比维度**: 暴力 $O(nm)$ / KMP $O(n+m)$ / Z 函数 $O(n+m)$ / Rabin-Karp $O(n+m)$ 平均 / 后缀数组 $O(n \log n)$

---

## 1. KMP 的核心: 失配时不回退主串

### 1.1 暴力匹配的瓶颈

设主串长 $n$, 模式串长 $m$。暴力算法在每次失配时:
1. 主串指针 `i` 回退到 `i - j + 1`
2. 模式串指针 `j` 回退到 0

最坏情况(如 `text = "aaaaaab"`, `pat = "aaab"`) 会退化为 $O(nm)$。

### 1.2 KMP 的关键观察

**匹配失败时, 主串已匹配的部分是确定的**, 我们不需要回退 `i`。我们只需要决定: **模式串指针 `j` 应该回退到哪个位置, 使得后续比较仍可能成功?**

→ 这个"应该回退到的位置"由**前缀函数 $\pi$** 决定。

### 1.3 前缀函数定义

$\pi[i]$ = 子串 `s[0..i]` 的**最长公共真前后缀**长度。

> "真前后缀": 长度严格小于 $i+1$。即不允许整个串自身匹配。

**例**:
```text
s = "a b a b a b"
i = 0: "a" → 无真前后缀 → π[0] = 0
i = 1: "ab" → 前缀 {a} ∩ 后缀 {b} = ∅ → π[1] = 0
i = 2: "aba" → 前缀 {a,ab} ∩ 后缀 {a,ba} = {a} → π[2] = 1
i = 3: "abab" → 前缀 {a,ab,aba} ∩ 后缀 {b,ab,bab} = {ab} → π[3] = 2
i = 4: "ababa" → {a,ab,aba,abab} ∩ {a,ba,aba,baba} = {a,aba} → π[4] = 3
i = 5: "ababab" → {a,ab,aba,abab,ababa} ∩ {b,ab,bab,abab,babab} = {a,ab,abab} → π[5] = 4
π = [0, 0, 1, 2, 3, 4]
```

### 1.4 为什么 $O(n+m)$

**关键论断**: 主串指针 `i` 单调递增, 永不回退。模式串指针 `j` 的总回退次数摊还为 $O(m)$。

- `i` 走 `n` 步, 每步 $O(1)$。
- `j` 走 $m$ 步前进 + 至多 $m$ 步回退(每次回退都减小 `j`, 且 `j` 最多增加 $m$ 次), 摊还 $O(m)$。

总: $O(n+m)$。

## 2. 手撕前缀函数与匹配

### 2.1 标准实现 (递归版)

```python
def prefix_function(p):
    """next 数组: pi[i] = p[0..i] 最长公共真前后缀长度"""
    n = len(p); pi = [0]*n
    for i in range(1, n):
        j = pi[i-1]
        while j > 0 and p[i] != p[j]:
            j = pi[j-1]                 # 失配: 回退到更短的前后缀
        if p[i] == p[j]:
            j += 1
        pi[i] = j
    return pi

def kmp(text, pat):
    """返回 pat 在 text 中所有出现的起始下标"""
    pi = prefix_function(pat)
    res, j = [], 0
    for i, c in enumerate(text):
        while j > 0 and c != pat[j]:
            j = pi[j-1]                 # 主串 i 不回退, 只回退模式串 j
        if c == pat[j]:
            j += 1
        if j == len(pat):
            res.append(i - j + 1)
            j = pi[j-1]                 # 继续找下一个 (允许重叠)
    return res
```

### 2.2 迭代版 find (避免 Python 递归深度限制)

```python
def find_iter(parent, x):
    """迭代式路径压缩, 不爆栈"""
    root = x
    while parent[root] != root:
        root = parent[root]
    # 压缩路径
    while parent[x] != root:
        parent[x], x = root, parent[x]
    return root

def prefix_function_iter(p):
    """迭代版前缀函数, 与递归版等价"""
    n = len(p); pi = [0]*n
    for i in range(1, n):
        j = pi[i-1]
        while j > 0 and p[i] != p[j]:
            j = pi[j-1]
        if p[i] == p[j]:
            j += 1
        pi[i] = j
    return pi
```

> `prefix_function` 本身已经是 $O(n)$, 不需要 `find` 式的递归, 因为它是 `i` 单调推进 + `j` 跳跃。

### 2.3 边界处理变种

```python
# 变种 1: 返回首个匹配位置 (找不到返回 -1)
def kmp_first(text, pat):
    if not pat: return 0
    pi = prefix_function(pat)
    j = 0
    for i, c in enumerate(text):
        while j > 0 and c != pat[j]:
            j = pi[j-1]
        if c == pat[j]:
            j += 1
        if j == len(pat):
            return i - j + 1
    return -1

# 变种 2: 统计出现次数 (允许重叠)
def kmp_count(text, pat):
    if not pat: return 0
    pi = prefix_function(pat)
    j = cnt = 0
    for c in text:
        while j > 0 and c != pat[j]:
            j = pi[j-1]
        if c == pat[j]:
            j += 1
        if j == len(pat):
            cnt += 1
            j = pi[j-1]   # 关键: 允许重叠匹配 ("aaa" 在 "aaaa" 中出现 2 次)
    return cnt
```

### 2.4 边界情况清单

| 情况 | 行为 |
| :--- | :--- |
| `pat == ""` | 返回空数组 (按惯例) |
| `len(text) < len(pat)` | 返回空数组 |
| `text == pat == ""` | 返回 `[0]` |
| 全文匹配 | 返回 `[0]` |
| 重叠匹配 (`pat="aa"` 在 `"aaaa"` 中) | 返回 `[0, 1, 2]` |
| 不匹配 | 返回 `[]` |

## 3. Z 函数(扩展 KMP)

### 3.1 定义

$z[i]$ = 从 $i$ 开始的后缀与整个串的**最长公共前缀**长度。特殊地 $z[0] = n$ (即整个串)。

**例**:
```text
s = "a b a b a b a"
i = 0: z[0] = 7 (约定)
i = 1: s[1..] = "bababa" vs s = "abababa" → 公共前缀 "" → z[1] = 0
i = 2: s[2..] = "ababa" vs s = "abababa" → "abab" → z[2] = 4
i = 3: s[3..] = "baba" vs s = "abababa" → "" → z[3] = 0
i = 4: s[4..] = "aba" vs s = "abababa" → "ab" → z[4] = 2
i = 5: s[5..] = "ba" vs s = "abababa" → "" → z[5] = 0
i = 6: s[6..] = "a" vs s = "abababa" → "a" → z[6] = 1
z = [7, 0, 4, 0, 2, 0, 1]
```

### 3.2 Z-box 优化思想

类似 KMP, Z 函数维护一个**已知区间** $[l, r]$ (即 Z-box), 满足:
- 在 $[l, r]$ 范围内, $s[i-l]$ 与 $s[i]$ 的关系已知。
- 已有 $z[i-l]$, 那么 $s[i..i+z[i-l]-1]$ 与 $s[l..l+z[i-l]-1]$ 相同, 而后者又等于 $s[..z[i-l]]$。
- 因此 $z[i]$ 至少是 $\min(r-i, z[i-l])$, 避免重复比较。

### 3.3 手撕实现

```python
def z_function(s):
    n = len(s); z = [0]*n; z[0] = n
    l = r = 0
    for i in range(1, n):
        if i < r:
            z[i] = min(r - i, z[i - l])   # 利用已算区间
        while i + z[i] < n and s[z[i]] == s[i + z[i]]:
            z[i] += 1
        if i + z[i] > r:
            l, r = i, i + z[i]
    return z
```

### 3.4 用 Z 函数做匹配

把 `pat + '#' + text` 拼起来求 Z 函数, 凡是 $z[i] == len(pat)$ 的位置就是匹配起点 (减去偏移和分隔符)。

```python
def z_match(text, pat):
    if not pat: return list(range(len(text) + 1))
    s = pat + '#' + text
    z = z_function(s)
    m = len(pat)
    return [i - m - 1 for i in range(m + 1, len(s)) if z[i] == m]
```

**复杂度**: $O(n + m)$。

## 4. KMP vs Z 函数对比

| 维度 | KMP (前缀函数) | Z 函数 |
| :--- | :--- | :--- |
| 预处理对象 | 模式串 | 待搜索的整串 (模式 + 分隔符 + 文本) |
| 输出语义 | $\pi[i]$ = s[0..i] 最长公共真前后缀 | $z[i]$ = s[i..] 与 s 的最长公共前缀 |
| 匹配用法 | 在线扫描 text, 边走边匹配 | 一次性建好 Z 数组后批量判断 |
| 适用场景 | **流式** 匹配 (text 边到边处理) | **离线** 匹配 (text 全可见) |
| 周期检测 | $\pi[n-1] \Rightarrow n - \pi[n-1]$ | $z[i] = n - i$ 的最小 $i$ |
| 复杂度 | $O(n+m)$ | $O(n+m)$ |
| 编码难度 | 中 (回退逻辑易错) | 低 (循环 + while) |

> 实战经验: **Z 函数更容易写对**, KMP 更适合在线/多模式场景(AC 自动机的子结构)。

## 5. 经典应用

### 5.1 最小循环节

字符串 $s$ 长 $n$, 若 $n \% (n - \pi[n-1]) == 0$, 则最小循环节长度为 $n - \pi[n-1]$。

**推导**: 设 $k = n - \pi[n-1]$。则 $s[0..k-1]$ 是 $s$ 的循环节当且仅当 $k | n$。

```python
def min_period(s):
    n = len(s); pi = prefix_function(s)
    k = n - pi[-1]
    return k if n % k == 0 else n     # 否则无整周期, 返回自身
```

**例**:
- `s = "abababab"`, $n = 8$, $\pi[7] = 6$, $k = 2$, $8 \% 2 = 0$ → 循环节 `ab`。
- `s = "abcabcab"`, $n = 8$, $\pi[7] = 5$, $k = 3$, $8 \% 3 \ne 0$ → 无整周期。

### 5.2 周期个数

返回 `s` 是其最小循环节重复多少次。
```python
def period_count(s):
    n = len(s); pi = prefix_function(s)
    k = n - pi[-1]
    return n // k if n % k == 0 else 1
```

### 5.3 字符串的 border

border = 真前后缀长度。把所有 `pi[i]` 串起来求链就是所有 border。
```python
def all_borders(s):
    pi = prefix_function(s)
    borders = []
    k = pi[-1]
    while k > 0:
        borders.append(k)
        k = pi[k - 1]
    return borders
```

### 5.4 字符串的"自匹配"位置

求每个位置 `i` 之后能匹配 `s` 多长 → Z 函数。
```python
def longest_match_at_each(s):
    """返回每个位置 i 开始能匹配 s 多长"""
    return z_function(s)[1:]   # 跳过 z[0]=n
```

### 5.5 拼接最少字符构成回文 (最短回文串)

**LeetCode 214**: 给定字符串 `s`, 在前面添加字符使其成为回文, 求最短结果。

```python
def shortest_palindrome(s):
    if not s: return s
    # 找 s 的最长回文前缀
    rev = s[::-1]
    # 在 s + '#' + rev 上求 Z, 等于 len(s) 的位置意味着 rev 的前缀 = s 的后缀 = s 的前缀
    combined = s + '#' + rev
    z = z_function(combined)
    # 反过来: 在 rev + '#' + s 上求
    combined2 = rev + '#' + s
    z2 = z_function(combined2)
    # s 的最长回文前缀长度:
    n = len(s)
    max_pal = max(z[i] for i in range(n + 1, len(combined)) if z[i] == n) or 0
    # 简化版: 用 KMP 在 s + '#' + rev 上找最长前缀 = 后缀
    cand = s + '#' + rev
    pi = prefix_function(cand)
    # pi[-1] 是 cand 的最长公共前后缀, 但 cand 的后缀中包含 rev 的部分
    # 实际上需要: s 的最长前缀 = s 的后缀, 即 s 的最长回文前缀
    # 用另一种方法: rev + '#' + s 求前缀函数, 末位即为 s 的最长回文前缀长
    cand2 = rev + '#' + s
    pi2 = prefix_function(cand2)
    L = pi2[-1]
    return s[L:][::-1] + s
```

**例**: `s = "aacecaaa"`, `rev = "aaacecaa"`, `rev+'#'+s = "aaacecaa#aacecaaa"`, $\pi$ 末位 = 4 → `"aac"` 是回文前缀 → 答案 = `"aaacecaaa"`。

### 5.6 重复叠加字符串匹配

**LeetCode 686**: 给定 `a` 和 `b`, 问 `a` 重复叠加多少次 (至少一次) 后, `b` 成为其子串。

```python
def repeated_string_match(a, b):
    """返回最小重复次数 k, 使得 b 是 a^k 的子串"""
    from math import ceil
    k = ceil(len(b) / len(a))
    # 至少 k 次, 极端情况 +1
    for cand in (a * k, a * (k + 1)):
        pi = prefix_function(cand)
        j = 0
        for c in b:
            while j > 0 and c != cand[j]:
                j = pi[j-1]
            if c == cand[j]:
                j += 1
            if j == len(cand):
                return k + (1 if cand is a * (k+1) else 0)
    return -1
```

### 5.7 重复子字符串

**LeetCode 459**: 给定 `s`, 判断它是否能由其某个子串重复多次构成。

```python
def repeated_substring_pattern(s):
    n = len(s); pi = prefix_function(s)
    k = n - pi[-1]
    return k < n and n % k == 0
```

**多解法对比**:
- **KMP 版**: $O(n)$, 上面的代码。
- **字符串拼接**: `s in (s + s)[1:-1]`, $O(n)$ (用 KMP/Z 内部实现) — 一行。
- **枚举因子**: $O(n\sqrt{n})$。

```python
# 字符串拼接版
def repeated_substring_pattern(s):
    return s in (s + s)[1:-1]
```

## 6. Rabin-Karp (滚动哈希) 字符串匹配

### 6.1 原理

把字符串视为多项式, 在大模数下做哈希。匹配时滚动更新哈希, 期望 $O(n+m)$。

$$h(s) = \sum_{i=0}^{n-1} s[i] \cdot B^{n-1-i} \mod M$$

### 6.2 实现

```python
def rabin_karp(text, pat, B=256, M=(1<<61) - 1):
    """返回所有匹配位置"""
    n, m = len(text), len(pat)
    if m > n: return []

    # 计算 B^(m-1) mod M
    Bm = pow(B, m - 1, M)

    # 计算初始哈希
    h_text = h_pat = 0
    for i in range(m):
        h_text = (h_text * B + ord(text[i])) % M
        h_pat = (h_pat * B + ord(pat[i])) % M

    res = []
    for i in range(n - m + 1):
        if h_text == h_pat and text[i:i+m] == pat:  # 双保险防冲突
            res.append(i)
        if i < n - m:
            # 滚动: 移除 text[i], 加入 text[i+m]
            h_text = ((h_text - ord(text[i]) * Bm) * B + ord(text[i+m])) % M
    return res
```

### 6.3 适用场景

- **多模式匹配**: 计算多个模式串的哈希, 同时扫描文本。
- **最长公共子串** (二分 + 哈希): $O((n+m) \log \min(n,m))$。
- **不同子串个数** (后缀数组 + LCP 或后缀自动机)。

### 6.4 KMP vs Rabin-Karp

| 维度 | KMP | Rabin-Karp |
| :--- | :--- | :--- |
| 最坏复杂度 | $O(n+m)$ | $O(nm)$ (哈希冲突) |
| 期望复杂度 | $O(n+m)$ | $O(n+m)$ |
| 多模式 | 需 AC 自动机 | 天然支持 |
| 实现难度 | 中 | 低 (但要选好 B, M) |
| 哈希冲突 | 不存在 | 概率 (双检可避免) |

### 7.1 LeetCode 28 - 实现 strStr() (Easy)

**题目**: 返回 `needle` 在 `haystack` 中首次出现的下标, 不存在返回 -1。

```python
def strStr(haystack: str, needle: str) -> int:
    if not needle: return 0
    n, m = len(haystack), len(needle)
    if m > n: return -1
    pi = prefix_function(needle)
    j = 0
    for i in range(n):
        while j > 0 and haystack[i] != needle[j]:
            j = pi[j-1]
        if haystack[i] == needle[j]:
            j += 1
        if j == m:
            return i - m + 1
    return -1
```

| KMP | $O(n+m)$ | 上面代码 |

**题目**: 找 `s` 的最长重复子串 (出现 ≥2 次, 可重叠)。

**解法 1**: 二分 + Rabin-Karp → $O(n \log n)$。
**解法 2**: 后缀数组 + LCP → $O(n \log n)$。
**解法 3**: Z 函数技巧: 在 `s[i..]` 上对完整 `s` 求 Z, 找所有 `z[j] ≥ L` 的 j。

```python
def longest_duplicate_substring(s: str) -> str:
    n = len(s)
    # 二分长度
    lo, hi = 1, n - 1
    ans = ""
    while lo <= hi:
        mid = (lo + hi) // 2
        found = ""
        seen = set()
        for i in range(n - mid + 1):
            sub = s[i:i+mid]
            if sub in seen:
                found = sub
                break
            seen.add(sub)
        if found:
            ans = found
            lo = mid + 1
        else:
            hi = mid - 1
    return ans
```

## 9. KMP 与 AC 自动机的关系

KMP 是**单模式**匹配, AC 自动机 (Aho-Corasick) 是**多模式**匹配 ($O(n + m_1 + m_2 + \ldots + m_k)$)。AC 自动机的失配指针就是 KMP 前缀函数在 trie 上的推广。

- 单模式 → KMP。
- 多模式 → AC 自动机 (在 trie 上做 BFS, 失配指针 + 输出指针)。

## 10. 复杂度详解

### 10.1 时间复杂度严格证明

设 `i` 为主串指针, `j` 为模式串指针。

**观察 1**: `i` 单调递增。每次循环 `i += 1`。
**观察 2**: `j` 总变化量 = (增量和) - (减量和)。增量最多为 `n` (每次至多 +1), 减量最多为 `m` (每次至少 -1, 且 `j ≥ 0`)。
**观察 3**: 在 while 循环中 `j` 严格递减。
**观察 4**: 在 if 分支 `j += 1` 总共最多 $n$ 次。
**结论**: while 循环总次数 ≤ $n + m$。所以总 $O(n+m)$。

### 10.2 空间复杂度

- `pi` 数组: $O(m)$。
- 匹配结果: $O(k)$ (输出)。
- 在线扫描: $O(m)$。

### 12.1 选择题

1. **KMP 为什么 $O(n+m)$?**
   - 主串指针不回退, j 的总回退次数摊还 $O(m)$。

2. **next 数组 (π) 含义?**
   - 最长公共真前后缀长度。

3. **求循环节公式?**
   - $n - \pi[n-1]$ 整除 $n$ 时, 它是最小循环节。

4. **KMP 与 Z 函数的主要区别?**
   - KMP 在线 (text 边到边), Z 函数离线 (一次性建数组)。

5. **Rabin-Karp 与 KMP 的主要区别?**
   - RK 基于哈希, 最坏 $O(nm)$ (冲突), 但实现简单; KMP 基于结构, 保证 $O(n+m)$。

6. **如何检测 `s` 是否为重复子串?**
   - KMP: `n % (n - pi[-1]) == 0 and n - pi[-1] < n`。
   - 字符串拼接: `s in (s+s)[1:-1]`。

7. **Z 函数中 z[0] 为什么约定为 n?**
   - 因为 s[0..] = s, 公共前缀就是 s 本身。

8. **路径压缩的递归 vs 迭代?**
   - 递归直观但有栈深度限制, 大数据用迭代版。

## 13. 实战技巧

### 13.1 模板速记

```python
# === KMP prefix function ===
def pi(p):
    n = len(p); pi = [0]*n
    for i in range(1, n):
        j = pi[i-1]
        while j > 0 and p[i] != p[j]: j = pi[j-1]
        if p[i] == p[j]: j += 1
        pi[i] = j
    return pi

# === Z function ===
def zf(s):
    n = len(s); z = [0]*n; z[0] = n; l = r = 0
    for i in range(1, n):
        if i < r: z[i] = min(r-i, z[i-l])
        while i+z[i] < n and s[z[i]] == s[i+z[i]]: z[i] += 1
        if i+z[i] > r: l, r = i, i+z[i]
    return z

# === 最小循环节 ===
def min_period(s):
    n = len(s); p = pi(s); k = n - p[-1]
    return k if n % k == 0 else n

# === 重复子串 ===
def is_repeated(s):
    return s in (s + s)[1:-1]
```

## 16. 总结

- **KMP** = π[i] + 主串不回退, $O(n+m)$。
- **Z 函数** = z[i] + Z-box 复用, $O(n+m)$, 编码更简单。
- **Rabin-Karp** = 滚动哈希, $O(n+m)$ 平均, $O(nm)$ 最坏, 适合多模式。
- **周期公式** = `n - π[n-1]` 是最小循环节候选。
- **实战推荐**: Python 中优先用内置 `str.find()`, 实在需要重复匹配多个 pattern 再手撕。
- **核心心法**: 失配时**不浪费已知信息**, 用已匹配部分的结构跳到下一个可能匹配点。

## 18. AC 自动机 (Aho-Corasick) — 多模式匹配

### 18.1 解决的问题

给定 $k$ 个模式串 $P_1, P_2, \ldots, P_k$ 和一个文本串 $T$, 找出 $T$ 中**所有** $P_i$ 出现的所有位置。

- $k = 1$ → KMP ($O(n + m)$)。
- $k > 1$ → AC 自动机 ($O(n + m_1 + \ldots + m_k + \text{输出数})$)。

### 18.2 核心思想

把 $k$ 个模式串建一棵 **Trie**, 然后:
1. 在 Trie 上 BFS 算每个节点的**失配指针** (类似 KMP 中"前缀函数在 Trie 上"的推广)。
2. 扫描文本时, 沿 Trie 走; 走不下去时跳失配指针。
3. 每个节点的**输出指针**指向该节点对应的所有模式串 (或通过 fail 链累计)。

### 18.3 手撕实现

```python
from collections import deque, defaultdict

class AhoCorasick:
    def __init__(self, patterns):
        self.trie = {}                        # node_id -> {char: child_id}
        self.output = []                      # node_id -> list of pattern indices
        self.fail = []                        # node_id -> fail node id
        self._build(patterns)

    def _build(self, patterns):
        # 建 trie
        self.trie.append({})                   # root = 0
        self.output.append([])
        self.fail.append(0)

        for idx, p in enumerate(patterns):
            node = 0
            for c in p:
                if c not in self.trie[node]:
                    self.trie[node][c] = len(self.trie)
                    self.trie.append({})
                    self.output.append([])
                    self.fail.append(0)
                node = self.trie[node][c]
            self.output[node].append(idx)

        # BFS 建 fail
        queue = deque()
        # 根的子节点的 fail = 根
        for c, child in self.trie[0].items():
            queue.append(child)

        while queue:
            u = queue.popleft()
            for c, v in self.trie[u].items():
                queue.append(v)
                # fail[v] = trie[fail[u]][c] 或根
                f = self.fail[u]
                while f != 0 and c not in self.trie[f]:
                    f = self.fail[f]
                if c in self.trie[f]:
                    f = self.trie[f][c]
                self.fail[v] = f
                # 输出合并: v 的输出 += fail[v] 的输出
                if self.output[f]:
                    self.output[v] = self.output[v] + self.output[f]

    def search(self, text):
        """返回 [(pattern_idx, end_position), ...]"""
        res = []
        node = 0
        for i, c in enumerate(text):
            while node != 0 and c not in self.trie[node]:
                node = self.fail[node]
            if c in self.trie[node]:
                node = self.trie[node][c]
            else:
                node = 0
            for pidx in self.output[node]:
                res.append((pidx, i))
        return res
```

### 18.4 应用

- **敏感词过滤**: 上百个敏感词 + 实时文本流。
- **生物信息学**: DNA 多模式匹配。
- **日志分析**: 多个错误码同时检测。
- **拼写检查**: 字典 + 文本。

### 18.5 复杂度

- 构建: $O(\sum |P_i|)$。
- 匹配: $O(|T| + \text{匹配数})$。
- 空间: $O(\sum |P_i| \cdot |\Sigma|)$, 用 dict 可降到 $O(\sum |P_i|)$。

## 19. 后缀数组 (Suffix Array)

### 19.1 定义

`SA[i]` = 所有后缀按字典序排序后的第 $i$ 个后缀的起始下标。

`SA` + `rank` (后缀的排名) + `LCP` (相邻后缀的最长公共前缀) 是处理子串问题的瑞士军刀。

### 19.2 倍增算法 (Prefix Doubling) — $O(n \log n)$

```python
def suffix_array(s):
    """返回 SA 数组"""
    n = len(s)
    # 初始: 按单字符排序
    sa = list(range(n))
    rank = [ord(c) for c in s]
    tmp = [0] * n
    k = 1
    while k < n:
        # 按 (rank[i], rank[i+k]) 排序
        sa.sort(key=lambda x: (rank[x], rank[x+k] if x+k < n else -1))
        # 重新编号
        tmp[sa[0]] = 0
        for i in range(1, n):
            prev, cur = sa[i-1], sa[i]
            tmp[cur] = tmp[prev] + (
                (rank[prev], rank[prev+k] if prev+k < n else -1) <
                (rank[cur],  rank[cur+k]  if cur+k  < n else -1)
            )
        rank, tmp = tmp, rank
        if rank[sa[-1]] == n - 1:
            break
        k <<= 1
    return sa
```

### 19.3 Kasai 算法 — $O(n)$ 求 LCP

```python
def lcp_array(s, sa):
    """返回 LCP 数组, lcp[i] = lcp(sa[i-1], sa[i])"""
    n = len(s)
    rank = [0] * n
    for i, x in enumerate(sa):
        rank[x] = i
    lcp = [0] * (n - 1)
    h = 0
    for i in range(n):
        r = rank[i]
        if r > 0:
            j = sa[r - 1]
            while i + h < n and j + h < n and s[i+h] == s[j+h]:
                h += 1
            lcp[r - 1] = h
            if h > 0:
                h -= 1
    return lcp
```

## 20. 后缀自动机 (Suffix Automaton, SAM)

### 20.1 定义

SAM 是一个**有向无环图 (DAG)**, 节点数 ≤ $2n - 1$, 边数 ≤ $3n - 4$。从初始状态出发, 任意路径对应 `s` 的一个子串。

每个节点维护:
- `link`: 后缀链接 (parent / fail)。
- `len`: 该等价类中最长串的长度。
- `next`: 字符转移表 (字典)。

### 20.2 构建

```python
class SAM:
    def __init__(self):
        self.next = []      # list of dict
        self.link = []
        self.len = []
        self._new(0)        # root
        self.last = 0

    def _new(self, l):
        self.next.append({})
        self.link.append(-1)
        self.len.append(l)
        return len(self.next) - 1

    def extend(self, c):
        p = self.last
        cur = self._new(self.len[p] + 1)
        while p != -1 and c not in self.next[p]:
            self.next[p][c] = cur
            p = self.link[p]
        if p == -1:
            self.link[cur] = 0
        else:
            q = self.next[p][c]
            if self.len[p] + 1 == self.len[q]:
                self.link[cur] = q
            else:
                clone = self._new(self.len[p] + 1)
                self.next[clone] = self.next[q].copy()
                self.link[clone] = self.link[q]
                while p != -1 and self.next[p].get(c) == q:
                    self.next[p][c] = clone
                    p = self.link[p]
                self.link[q] = self.link[cur] = clone
        self.last = cur
        return cur
```

### 20.3 应用

| 问题 | SAM 做法 |
| :--- | :--- |
| 不同子串个数 | $\sum (len[v] - len[link[v]])$ |
| 子串出现次数 | 拓扑序从长到短累加 |
| 最长公共子串 (两串) | 在第二串上沿 SAM 走, 维护当前长度 |
| 最小循环移位 | 拼 `s+s`, 在 SAM 上走 $n$ 步 |
| 子串判等 | 沿 SAM 走 |

### 20.4 复杂度

- 构建: $O(n)$。
- 空间: $O(n)$。
- 查询: $O(|pattern|)$ (沿图走)。

## 21. Manacher 算法 — $O(n)$ 最长回文

### 21.1 思想

把奇偶回文统一: 在每两个字符间插入 `#`, 然后维护一个回文"半径"数组 `p[i]` (以 `i` 为中心的最长回文半径)。

类似 Z 函数的 Z-box, 用已知信息跳。

### 21.2 实现

```python
def manacher(s):
    """返回 s 的最长回文子串长度"""
    t = '#' + '#'.join(s) + '#'
    n = len(t)
    p = [0] * n
    c = r = 0
    for i in range(n):
        if i < r:
            p[i] = min(r - i, p[2*c - i])
        while i - p[i] - 1 >= 0 and i + p[i] + 1 < n and t[i-p[i]-1] == t[i+p[i]+1]:
            p[i] += 1
        if i + p[i] > r:
            c, r = i, i + p[i]
    return max(p)
```

### 21.3 与 KMP 的关系

Manacher 和 KMP 都用了"已匹配区间复用"思想, 但:
- KMP: 处理**前缀-后缀**结构 (π 数组)。
- Manacher: 处理**回文半径** (p 数组)。

## 22. 字符串哈希专题

### 22.1 多项式哈希

```python
def poly_hash(s, B=91138233, M=(1<<61) - 1):
    h = 0
    for c in s:
        h = (h * B + ord(c)) % M
    return h

# 预计算前缀哈希 + 幂次
def build_hash(s, B=91138233, M=(1<<61) - 1):
    n = len(s)
    h = [0] * (n + 1)
    p = [1] * (n + 1)
    for i in range(n):
        h[i+1] = (h[i] * B + ord(s[i])) % M
        p[i+1] = (p[i] * B) % M
    return h, p

def get_hash(h, p, l, r):
    """s[l..r-1] 的哈希"""
    return (h[r] - h[l] * p[r-l]) % M
```

### 22.2 双哈希防冲突

```python
def double_hash(s):
    M1, M2 = (1<<61) - 1, (1<<31) - 1
    B1, B2 = 91138233, 97266353
    h1, p1 = build_hash(s, B1, M1)
    h2, p2 = build_hash(s, B2, M2)
    return lambda l, r: (get_hash(h1, p1, l, r), get_hash(h2, p2, l, r))
```

## 23. 字典树 (Trie) 与 KMP 的"逆向"关系

### 23.1 字典树基础

```python
class Trie:
    def __init__(self):
        self.children = {}
        self.is_end = False

    def insert(self, word):
        node = self
        for c in word:
            if c not in node.children:
                node.children[c] = Trie()
            node = node.children[c]
        node.is_end = True

    def search(self, word):
        node = self
        for c in word:
            if c not in node.children:
                return False
            node = node.children[c]
        return node.is_end

    def starts_with(self, prefix):
        node = self
        for c in prefix:
            if c not in node.children:
                return False
            node = node.children[c]
        return True
```

```python
def longest_palindrome_dp(s):

    if n < 2: return s
    dp = [[False]*n for _ in range(n)]

            if s[i] == s[j]:
                if j - i < 3:
                    dp[i][j] = True
                else:
                    dp[i][j] = dp[i+1][j-1]

    return s[start:start+maxlen]

def longest_palindrome_center(s):
    n = len(s)
    def expand(l, r):
        while l >= 0 and r < n and s[l] == s[r]:
            l -= 1; r += 1
        return s[l+1:r]

    for i in range(n):

        even = expand(i, i+1)
        res = max(res, odd, even, key=len)

        while i-p[i]-1 >= 0 and i+p[i]+1 < n and t[i-p[i]-1] == t[i+p[i]+1]:

                if s[i:i+mid] == s[i:i+mid][::-1]:
                    ans = s[i:i+mid]
                    found = True
                    break
        if found:
            lo = mid + 1
        else:
            hi = mid - 1
```

### 24.7 LeetCode 72 - 编辑距离 (Medium, DP)

虽然不是字符串匹配题, 但属于字符串算法。

```python
def minDistance(word1: str, word2: str) -> int:
    n, m = len(word1), len(word2)
    dp = [[0]*(m+1) for _ in range(n+1)]
    for i in range(n+1): dp[i][0] = i
    for j in range(m+1): dp[0][j] = j
    for i in range(1, n+1):
        for j in range(1, m+1):
            if word1[i-1] == word2[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = 1 + min(
                    dp[i-1][j],     # 删除
                    dp[i][j-1],     # 插入
                    dp[i-1][j-1]    # 替换
                )
    return dp[n][m]

# 空间优化: 滚动数组
def minDistance_opt(word1, word2):
    n, m = len(word1), len(word2)
    prev = list(range(m+1))
    for i in range(1, n+1):
        cur = [i] + [0]*m
        for j in range(1, m+1):
            if word1[i-1] == word2[j-1]:
                cur[j] = prev[j-1]
            else:
                cur[j] = 1 + min(prev[j], cur[j-1], prev[j-1])
        prev = cur
    return prev[m]
```

### 24.8 LeetCode 76 - 最小覆盖子串 (Hard, 滑动窗口)

```python
def minWindow(s: str, t: str) -> str:
    from collections import Counter
    need = Counter(t)
    missing = len(t)
    left = start = end = 0
    for right, c in enumerate(s, 1):
        if need[c] > 0:
            missing -= 1
        need[c] -= 1
        if missing == 0:
            while left < right and need[s[left]] < 0:
                need[s[left]] += 1
                left += 1
            if not end or right - left <= end - start:
                start, end = left, right
            need[s[left]] += 1
            missing += 1
            left += 1
    return s[start:end]
```

### 27.1 KMP 找所有出现位置

```python
def kmp_all(text, pat):
    """返回所有匹配起点 (含重叠)"""
    if not pat: return list(range(len(text) + 1))
    pi = [0] * len(pat)
    for i in range(1, len(pat)):
        j = pi[i-1]
        while j and pat[i] != pat[j]:
            j = pi[j-1]
        pi[i] = j + 1 if pat[i] == pat[j] else j
    res, j = [], 0
    for i, c in enumerate(text):
        while j and c != pat[j]:
            j = pi[j-1]
        if c == pat[j]:
            j += 1
        if j == len(pat):
            res.append(i - j + 1)
            j = pi[j-1]
    return res
```

## 30. 终极总结

### 30.1 一句话心法

**KMP 的核心是"不浪费已知信息" — 失配时, 已经匹配的部分的结构 (前缀函数) 告诉我们下一步该怎么跳, 主串指针永远不回退**。

### 30.2 算法族谱

```text
字符串匹配算法
├── 单模式
│   ├── 暴力              O(nm)
│   ├── KMP              O(n+m) ★
│   ├── Z 函数            O(n+m) ★
│   ├── Rabin-Karp       O(n+m) 期望
│   ├── Boyer-Moore      O(n/m) 平均 (跳跃)
│   └── 双调 (Two-Way)    O(n+m) (Python 用)
├── 多模式
│   ├── AC 自动机         O(n + Σm_i) ★
│   ├── Wu-Manber        O(n) 启发式
│   └── 后缀字典树        多种变体
└── 子串结构
    ├── 后缀数组 + LCP    O(n log n) / O(n) (SA-IS)
    ├── 后缀自动机 (SAM)  O(n) ★
    ├── 后缀树 (Ukkonen)  O(n)
    └── Manacher         O(n) (回文)
```

| 任务 | 最佳 |

```python
# ==========================================
# KMP 前缀函数 (核心)
# ==========================================
def pi(p):
    n = len(p); pi = [0]*n
    for i in range(1, n):
        j = pi[i-1]
        while j and p[i] != p[j]: j = pi[j-1]
        if p[i] == p[j]: j += 1
        pi[i] = j
    return pi

# ==========================================
# Z 函数 (核心)
# ==========================================
def zf(s):
    n = len(s); z = [0]*n; z[0] = n; l = r = 0
    for i in range(1, n):
        if i < r: z[i] = min(r-i, z[i-l])
        while i+z[i] < n and s[z[i]] == s[i+z[i]]: z[i] += 1
        if i+z[i] > r: l, r = i, i+z[i]
    return z

# ==========================================
# 关键公式
# ==========================================
# 周期:        k = n - pi[-1], n % k == 0 ?
# 重复子串:    s in (s+s)[1:-1]
# 最短回文:    s[pi(rev + '#' + s)[-1]:][::-1] + s
# border 链:   pi[-1], pi[pi[-1]-1], pi[pi[pi[-1]-1]-1], ...
# 最长公共前缀: zf(a + '#' + b)[len(a)+1]

# ==========================================
# 复杂度
# ==========================================
# KMP / Z 函数:        O(n+m) 时间, O(n+m) 空间
# 暴力:                O(nm) 时间
# Rabin-Karp:          O(n+m) 期望, O(nm) 最坏
# 后缀数组:            O(n log n) 倍增, O(n) SA-IS
# SAM:                 O(n)
# AC 自动机:           O(n + Σm_i) 构建, O(n + 输出数) 匹配
# Manacher:            O(n)
```

在数值稳定性方面,有几个常见陷阱: 浮点数精度有限、Log-Sum-Exp 计算要减去最大值、Softmax 在大数值下会溢出。这些工程细节常常决定一个模型能否在生产环境稳定运行。

**7. 实践建议**

结合 "KMP 与 Z 函数" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "KMP 与 Z 函数" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
