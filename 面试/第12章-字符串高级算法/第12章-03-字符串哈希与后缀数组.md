# 第12章-03-字符串哈希与后缀数组


## 1. 多项式字符串哈希

把子串映射为一个数, $O(1)$ 比较任意两子串是否相等。

$$H(s) = \sum_{i=0}^{n-1} s_i \cdot B^{n-1-i} \bmod M$$

预处理前缀哈希 + $B$ 的幂, 子串哈希 $O(1)$:

```python
class StrHash:
    def __init__(self, s, B=131, M=(1<<61)-1):
        self.B, self.M = B, M
        n = len(s)
        self.h = [0]*(n+1)          # 前缀哈希
        self.p = [1]*(n+1)          # B 的幂
        for i, c in enumerate(s):
            self.h[i+1] = (self.h[i]*B + ord(c)) % M
            self.p[i+1] = self.p[i]*B % M
    def get(self, l, r):            # 子串 s[l..r] 哈希, 闭区间
        return (self.h[r+1] - self.h[l]*self.p[r-l+1]) % self.M
```

**防碰撞**: 用**双哈希**(两组 $(B,M)$ 组成 pair 比较), 碰撞概率降到可忽略。竞赛用大质数模 $2^{61}-1$。

**应用**: 子串比较、最长公共子串(二分长度+哈希)、回文判断、找重复子串。

## 2. 后缀数组 (SA)

$sa[i]$ = 排名第 $i$ 小的后缀的起始下标。倍增法 $O(n\log n)$ 构造: 按前 $2^k$ 个字符排序, 每轮长度翻倍。

```python
def suffix_array(s):
    s = list(map(ord, s)) + [-1]
    n = len(s)
    sa = list(range(n))
    rk = s[:]
    k = 1
    while k < n:
        sa.sort(key=lambda i: (rk[i], rk[i+k] if i+k < n else -1))
        tmp = [0]*n
        for i in range(1, n):
            a, b = sa[i-1], sa[i]
            prev = (rk[a], rk[a+k] if a+k<n else -1)
            cur  = (rk[b], rk[b+k] if b+k<n else -1)
            tmp[b] = tmp[a] + (prev != cur)
        rk = tmp
        if rk[sa[-1]] == n-1: break
        k <<= 1
    return sa[1:]                   # 去掉哨兵
```

> 上面为 $O(n\log^2 n)$ 简洁版; 竞赛可用基数排序做到 $O(n\log n)$。

---

## 3. height 数组(SA 的灵魂)

$height[i]$ = $sa[i]$ 与 $sa[i-1]$ 两后缀的最长公共前缀(LCP)。用 Kasai 算法 $O(n)$ 求。

**应用**:
- 任意两后缀 LCP = height 区间最小值(RMQ)。
- 不同子串个数 = $\frac{n(n+1)}{2} - \sum height[i]$。
- 最长重复子串 = $\max(height)$。

---

## 4. 哈希 vs 后缀数组 选型

| | 字符串哈希 | 后缀数组 |
| :--- | :--- | :--- |
| 写起来 | 简单 | 复杂 |
| 子串比较 | $O(1)$ | 需配 height+RMQ |
| 风险 | 碰撞(双哈希缓解) | 无 |
| 适合 | 判等、二分长度 | 排序、LCP、本质不同子串 |

> 面试首选哈希(好写); 需要"所有后缀有序"或"LCP"时上后缀数组。

---

## 5. 面试高频

1. 哈希如何 $O(1)$ 比较子串? → 前缀哈希 + 幂预处理。
2. 如何防碰撞? → 双哈希 + 大质数模。
3. height 数组能干嘛? → LCP、本质不同子串数、最长重复子串。

## 6. 字符串哈希深入理解

### 6.1 多项式哈希的定义

字符串 $s = s_0 s_1 \ldots s_{n-1}$ 的多项式哈希为:

$$H(s) = s_0 \cdot B^{n-1} + s_1 \cdot B^{n-2} + \ldots + s_{n-1} \cdot B^0 \mod M$$

其中 $B$ 是基数 (base), $M$ 是模数。

### 6.2 为什么用前缀哈希?

直接计算 $H(s[l..r])$ 需要 $O(r-l+1)$ 时间。但用前缀哈希:

$$H(s[0..r]) = H(s[0..l-1]) \cdot B^{r-l+1} + H(s[l..r]) \mod M$$

所以:

$$H(s[l..r]) = H(s[0..r]) - H(s[0..l-1]) \cdot B^{r-l+1} \mod M$$

预处理 $H(s[0..i])$ 和 $B^i$ 后, 任意子串哈希 $O(1)$。

### 6.3 双哈希防碰撞

**生日悖论**: 单哈希碰撞概率 $\approx 1/M$, $M = 2^{61}$ 时 $\approx 10^{-18}$, 看似够小。但:

- 多次比较累计概率变大。
- 攻击者可构造"哈希洪水"。

**双哈希**: 用两组独立 $(B_1, M_1)$, $(B_2, M_2)$, 哈希 = 元组 $(H_1, H_2)$。碰撞概率 $\approx 1/(M_1 \cdot M_2)$, 极小。

```python
class DoubleHash:
    def __init__(self, s):
        self.B1, self.M1 = 131, (1 << 61) - 1
        self.B2, self.M2 = 137, (1 << 31) - 1  # 或 10**9 + 7
        n = len(s)
        self.h1 = [0] * (n + 1)
        self.p1 = [1] * (n + 1)
        self.h2 = [0] * (n + 1)
        self.p2 = [1] * (n + 1)
        for i, c in enumerate(s):
            self.h1[i+1] = (self.h1[i] * self.B1 + ord(c)) % self.M1
            self.p1[i+1] = self.p1[i] * self.B1 % self.M1
            self.h2[i+1] = (self.h2[i] * self.B2 + ord(c)) % self.M2
            self.p2[i+1] = self.p2[i] * self.B2 % self.M2
    def get(self, l, r):
        h1 = (self.h1[r+1] - self.h1[l] * self.p1[r-l+1]) % self.M1
        h2 = (self.h2[r+1] - self.h2[l] * self.p2[r-l+1]) % self.M2
        return (h1, h2)
```

### 6.4 2^61-1 模下的快速乘法 (Mersenne prime)

$2^{61} - 1$ 是梅森素数, 用类似快速乘法的技巧可以避免取模:

```python
def mul_mod(a, b, M=(1 << 61) - 1):
    """2^61-1 下的乘法"""
    return (a * b) & M  # 利用 M 是 2^k - 1 形式
```

但需注意溢出, Python 整数无溢出, 可用 `(a * b) % M`。

#### 6.5.1 最长公共子串 (LeetCode 不直接考, 但常用)

```python
def longest_common_substring(s, t):
    """求 s 和 t 的最长公共子串"""
    # 用 s 的所有子串哈希与 t 的比较, 二分长度
    # O(n log n) 时间
    n, m = len(s), len(t)
    h_s = StrHash(s)
    h_t = StrHash(t)
    def check(le):
        s_hashes = set()
        for i in range(n - le + 1):
            s_hashes.add(h_s.get(i, i + le - 1))
        for j in range(m - le + 1):
            if h_t.get(j, j + le - 1) in s_hashes:
                return True
        return False
    lo, hi = 0, min(n, m)
    while lo < hi:
        mid = (lo + hi + 1) // 2
        if check(mid):
            lo = mid
        else:
            hi = mid - 1
    return lo
```

```python
class Solution:
    def repeatedSubstringPattern(self, s: str) -> bool:
        # s 是某个子串 t 的整数次重复
        # 用 KMP next: 如果 len(s) % (len(s) - next[-1]) == 0 且 next[-1] != 0
        n = len(s)
        pi = [0] * n
        for i in range(1, n):
            j = pi[i-1]
            while j > 0 and s[i] != s[j]:
                j = pi[j-1]
            if s[i] == s[j]:
                j += 1
            pi[i] = j
        if pi[-1] == 0:
            return False
        period = n - pi[-1]
        return n % period == 0
```

#### 6.5.4 二分 + 哈希找最长回文

```python
def longest_palindromic_substring_hash(s):
    """O(n log n)"""
    n = len(s)
    h = StrHash(s)
    # 反向哈希
    h_rev = StrHash(s[::-1])
    best_l, best_len = 0, 0
    for center in range(n):
        # 奇回文
        lo, hi = 0, min(center, n - 1 - center)
        while lo <= hi:
            mid = (lo + hi) // 2
            l, r = center - mid, center + mid
            if h.get(l, r) == h_rev.get(n-1-r, n-1-l):
                lo = mid + 1
            else:
                hi = mid - 1
        if hi * 2 + 1 > best_len:
            best_len = hi * 2 + 1
            best_l = center - hi
    return s[best_l:best_l + best_len]
```

#### LeetCode 1554 - 只有一个不同字符的不同字符串

```python
class Solution:
    def differByOne(self, dict: List[str]) -> bool:
        # 找两个字符串, 只差一个字符
        # 用哈希: 对每个字符串, 替换每个位置为 '*', 哈希
        mod = (1 << 61) - 1
        B = 131
        seen = set()
        for word in dict:
            hv = 0
            for c in word:
                hv = (hv * B + ord(c)) % mod
            for i, c in enumerate(word):
                # 替换 word[i] 为 *
                # hv - c * B^(n-1-i) + '*' * B^(n-1-i)
                # 简化: 不算 '*' 的值, 而是记录每个位置替换后的前缀+后缀哈希
                new_hv = (hv - ord(c) * pow(B, len(word) - 1 - i, mod)) % mod
                if new_hv in seen:
                    return True
                seen.add(new_hv)
        return False
```

## 7. 后缀数组深入理解

### 7.1 后缀数组的定义

字符串 $s$ 长 $n$, 其 $n$ 个后缀 $s[i..n-1]$ ($0 \leq i < n$) 按字典序排序后, 起始下标构成数组 $sa[0..n-1]$。

$sa[i]$ = 排名第 $i$ 小的后缀的起始下标。

**示例**: $s = "banana"$, 后缀:
- $s[0..] = $ `banana`
- $s[1..] = $ `anana`
- $s[2..] = $ `nana`
- $s[3..] = $ `ana`
- $s[4..] = $ `na`
- $s[5..] = $ `a`

字典序排序后: `a`(5) < `ana`(3) < `anana`(1) < `banana`(0) < `na`(4) < `nana`(2)。

所以 $sa = [5, 3, 1, 0, 4, 2]$。

### 7.2 倍增构造 (SA 经典算法)

**核心思想**: 按前 $2^k$ 个字符排序, 每轮长度翻倍, 直到所有后缀都有唯一排名。

```python
def suffix_array(s):
    """倍增法 O(n log^2 n)"""
    s = list(map(ord, s)) + [-1]  # 哨兵 -1 比任何字符小
    n = len(s)
    sa = list(range(n))
    rk = s[:]
    k = 1
    while k < n:
        # 按 (rk[i], rk[i+k]) 排序
        sa.sort(key=lambda i: (rk[i], rk[i+k] if i+k < n else -1))
        # 重新编号
        tmp = [0] * n
        for i in range(1, n):
            a, b = sa[i-1], sa[i]
            prev = (rk[a], rk[a+k] if a+k < n else -1)
            cur = (rk[b], rk[b+k] if b+k < n else -1)
            tmp[b] = tmp[a] + (prev != cur)
        rk = tmp
        if rk[sa[-1]] == n - 1:
            break
        k <<= 1
    return sa[1:]  # 去掉哨兵
```

### 7.3 优化: 基数排序 $O(n \log n)$

```python
def suffix_array_radix(s):
    """SA-IS 风格, 倍增 + 基数排序"""
    s = list(map(ord, s)) + [-1]
    n = len(s)
    sa = list(range(n))
    rk = s[:]
    tmp = [0] * n
    k = 1
    while k < n:
        # 第二关键字排序 (按 rk[i+k])
        # 用计数排序
        # 先按 rk[i+k] 排序, 再按 rk[i] 排序
        # 跳过, 实现复杂, 此处用 sorted 简化
        sa.sort(key=lambda i: (rk[i], rk[i+k] if i+k < n else -1))
        for i in range(1, n):
            a, b = sa[i-1], sa[i]
            prev = (rk[a], rk[a+k] if a+k < n else -1)
            cur = (rk[b], rk[b+k] if b+k < n else -1)
            tmp[b] = tmp[a] + (prev != cur)
        rk = tmp
        if rk[sa[-1]] == n - 1:
            break
        k <<= 1
    return sa[1:]
```

**标准实现 (C++ 风格)**:

```python
def sa_build(s):
    """倍增 + 基数排序"""
    n = len(s)
    s = [ord(c) for c in s] + [0]
    n += 1
    sa = list(range(n))
    rk = s[:]
    tmp = [0] * n
    k = 1
    while k < n:
        # 第二关键字排序
        cnt = [0] * n
        for i in range(n - k, n):
            sa[i] = i  # 暂时放在末尾 (无第二关键字)
        for i in range(n):
            if rk[i] < n - k:
                cnt[rk[i + k]] += 1
        for i in range(1, n):
            cnt[i] += cnt[i-1]
        for i in range(n):
            if rk[i] < n - k:
                cnt[rk[i + k]] -= 1
                sa[cnt[rk[i + k]]] = i + k
        # 实际更复杂, 略
        # 然后按第一关键字排序
        # ...
        # 重新编号
        for i in range(1, n):
            a, b = sa[i-1], sa[i]
            prev = (rk[a], rk[a+k] if a+k < n else -1)
            cur = (rk[b], rk[b+k] if b+k < n else -1)
            tmp[b] = tmp[a] + (prev != cur)
        rk = tmp
        if rk[sa[-1]] == n - 1:
            break
        k <<= 1
    return sa[1:]
```

**复杂度**: $O(n \log n)$。

### 7.5 DC3 算法 $O(n)$

**DC3 (Difference Cover 3)** 也是线性构造 SA, 比 SA-IS 早出现。

### 7.6 height 数组 (Kasai 算法)

```python
def get_height(s, sa):
    """Kasai 算法 O(n)"""
    n = len(s)
    rank = [0] * n
    for i, pos in enumerate(sa):
        rank[pos] = i
    height = [0] * n
    k = 0  # 当前 LCP 长度
    for i in range(n):
        if rank[i] == 0:
            k = 0
            continue
        j = sa[rank[i] - 1]
        while i + k < n and j + k < n and s[i+k] == s[j+k]:
            k += 1
        height[rank[i]] = k
        if k > 0:
            k -= 1
    return height
```

**关键性质**:

- `height[i] >= height[i-1] - 1`
- 总 while 次数 $O(n)$ (类似 Manacher 的 $r$ 单调性)

### 7.7 SA + RMQ = 子串比较 $O(1)$

求任意两后缀 $s[i..]$ 和 $s[j..]$ 的 LCP:

$$\text{LCP}(i, j) = \min(height[\text{rank}[i]+1 .. \text{rank}[j]])$$

用稀疏表 (Sparse Table) 或线段树做 RMQ, 预处理 $O(n \log n)$, 查询 $O(1)$。

```python
class RMQ:
    def __init__(self, arr):
        self.n = len(arr)
        self.log = [0] * (self.n + 1)
        for i in range(2, self.n + 1):
            self.log[i] = self.log[i >> 1] + 1
        self.st = [[0] * (self.log[self.n] + 1) for _ in range(self.n)]
        self.st[0] = arr[:]
        for j in range(1, self.log[self.n] + 1):
            for i in range(self.n - (1 << j) + 1):
                self.st[i][j] = min(self.st[i][j-1], self.st[i + (1 << (j-1))][j-1])
    def query(self, l, r):
        j = self.log[r - l + 1]
        return min(self.st[l][j], self.st[r - (1 << j) + 1][j])
```

### 7.8 SA 的应用

#### 7.8.1 不同子串个数

```python
def count_distinct_substrings(s):
    n = len(s)
    sa = suffix_array(s)
    height = get_height(s, sa)
    return n * (n + 1) // 2 - sum(height)
```

**原因**: 总子串数 = $n(n+1)/2$。每个子串对应 SA 中某个后缀的前缀。`height[i]` 是 $sa[i]$ 与 $sa[i-1]$ 的 LCP, 所以 $sa[i]$ 贡献的"新增子串数" = 长度 - LCP = $n - sa[i] - height[i]$。总和即 $\sum (n - sa[i] - height[i]) = \sum n - \sum sa[i] - \sum height[i] = n^2 - n(n+1)/2 - \sum height[i] = n(n-1)/2 - \sum height[i]$。

等等, 这里有偏差, 让我重推。

实际公式是: $n$ 个后缀的总前缀数 = $\sum_{i=0}^{n-1} (n - sa[i]) = \sum_{i=0}^{n-1} (n - i) = n + (n-1) + ... + 1 = n(n+1)/2$。

但是**重复的子串**需要减去。每个 $sa[i]$ 贡献的"新增前缀数" = $(n - sa[i]) - height[i]$ (因为前 height 个已经和前一个后缀共享)。

总新增 = $\sum_{i=0}^{n-1} ((n - sa[i]) - height[i]) = n(n+1)/2 - \sum height[i]$。

**所以不同子串数 = $n(n+1)/2 - \sum height$** ✓。

#### 7.8.2 最长重复子串


#### 7.8.3 任意两子串的最长公共前缀

```python
def lcp_substring(s, i1, j1, i2, j2):
    """s[i1..j1] 与 s[i2..j2] 的 LCP"""
    sa = suffix_array(s)
    rank = [0] * len(s)
    for i, pos in enumerate(sa):
        rank[pos] = i
    height = get_height(s, sa)
    rmq = RMQ(height)
    # LCP of s[i1..] and s[i2..] = RMQ on height
    if rank[i1] > rank[i2]:
        i1, i2 = i2, i1
    L = rmq.query(rank[i1] + 1, rank[i2])
    return min(L, j1 - i1 + 1, j2 - i2 + 1)
```

## 10. 后缀自动机 (Suffix Automaton, SAM)

### 10.1 SAM 的定义

SAM 是有穷状态机, 接受字符串 $s$ 的所有子串。每个状态代表一组等价后缀。

**关键性质**: SAM 的状态数 $\leq 2n - 1$ (线性), 转移数 $\leq 3n - 4$。

### 10.2 SAM 的节点结构

```python
class SAMNode:
    def __init__(self):
        self.next = {}       # 字符 -> 转移
        self.link = -1       # 后缀链接
        self.len = 0         # 该状态最长字符串长度
        self.cnt = 0         # 该状态对应子串出现次数 (endpos 大小)
```

### 10.3 SAM 的构建

```python
def build_sam(s):
    nodes = [SAMNode()]
    nodes[0].len = 0
    nodes[0].link = -1
    last = 0
    for c in s:
        cur = len(nodes)
        nodes.append(SAMNode())
        nodes[cur].len = nodes[last].len + 1
        p = last
        while p != -1 and c not in nodes[p].next:
            nodes[p].next[c] = cur
            p = nodes[p].link
        if p == -1:
            nodes[cur].link = 0
        else:
            q = nodes[p].next[c]
            if nodes[p].len + 1 == nodes[q].len:
                nodes[cur].link = q
            else:
                clone = len(nodes)
                nodes.append(SAMNode())
                nodes[clone].len = nodes[p].len + 1
                nodes[clone].next = nodes[q].next.copy()
                nodes[clone].link = nodes[q].link
                while p != -1 and nodes[p].next.get(c) == q:
                    nodes[p].next[c] = clone
                    p = nodes[p].link
                nodes[q].link = clone
                nodes[cur].link = clone
        last = cur
    return nodes
```

### 11.1 哈希的常用组合

### 11.2 SA 的常见陷阱

1. **哨兵**: 不加哨兵会出错, 必须加一个比任何字符都小的哨兵 (`-1` 或 `0`)。

2. **下标 0 vs 1**: 注意 SA 数组下标从 0 开始还是 1 开始, 影响 LCP 计算。

3. **字符串结尾**: 哨兵位置 `n` 是"假后缀", 长度 0, 要从 SA 中去掉。

4. **LCP 边界**: `LCP(i, j)` 要求 $i \neq j$, 否则是 $n - i$ (后缀长度)。

### 11.3 哈希碰撞的应急方案

如果怀疑哈希碰撞 (特别是 CF/AtCoder 偶尔有恶意构造):

```python
# 用 64-bit 整数 (Python int) + 2 个 mod
class SafeHash:
    def __init__(self, s):
        self.M1 = (1 << 61) - 1
        self.M2 = (1 << 31) - 1
        self.B = 131
        n = len(s)
        self.h1 = [0] * (n + 1)
        self.p1 = [1] * (n + 1)
        self.h2 = [0] * (n + 1)
        self.p2 = [1] * (n + 1)
        for i, c in enumerate(s):
            self.h1[i+1] = (self.h1[i] * self.B + ord(c)) % self.M1
            self.p1[i+1] = self.p1[i] * self.B % self.M1
            self.h2[i+1] = (self.h2[i] * self.B + ord(c)) % self.M2
            self.p2[i+1] = self.p2[i] * self.B % self.M2
    def get(self, l, r):
        h1 = (self.h1[r+1] - self.h1[l] * self.p1[r-l+1]) % self.M1
        h2 = (self.h2[r+1] - self.h2[l] * self.p2[r-l+1]) % self.M2
        return (h1, h2)
```

### 11.4 滚动哈希的二进制优化

如果字符串是二进制 (0/1), 哈希可以更紧凑:

```python
class BinaryHash:
    def __init__(self, bits):
        n = len(bits)
        self.h = [0] * (n + 1)
        for i, b in enumerate(bits):
            self.h[i+1] = self.h[i] * 2 + b
    def get(self, l, r):
        return self.h[r+1] - self.h[l] * (1 << (r - l + 1))
```

注意: 无模运算, Python int 自动扩展, 但要小心溢出 (虽然 Python 不溢出)。

### 11.5 哈希更新 (滚动)

如果文本动态变化, 滚动哈希可以增量更新:

```python
class RollingHash:
    def __init__(self, s, B=131, M=(1<<61)-1):
        self.B, self.M = B, M
        self.n = len(s)
        self.p = [1] * (self.n + 1)
        for i in range(self.n):
            self.p[i+1] = self.p[i] * B % M
        self.hash = [0] * (self.n + 1)
        for i, c in enumerate(s):
            self.hash[i+1] = (self.hash[i] * B + ord(c)) % M
    def update(self, pos, old_c, new_c):
        """把 s[pos] 从 old_c 改为 new_c"""
        delta = (ord(new_c) - ord(old_c)) * self.p[self.n - 1 - pos] % self.M
        for i in range(pos + 1, self.n + 1):
            self.hash[i] = (self.hash[i] + delta) % self.M
```

简化:

```python
def update_hash(h, p, B, M, pos, old_c, new_c, n):
    delta = (ord(new_c) - ord(old_c)) * p[n - 1 - pos] % M
    return [(x + delta if i > pos else x) % M for i, x in enumerate(h)]
```

## 17. 实战模板 (推荐背诵)

### 17.1 字符串哈希

```python
class StrHash:
    def __init__(self, s, B=131, M=(1<<61)-1):
        self.B, self.M = B, M
        n = len(s)
        self.h = [0]*(n+1)
        self.p = [1]*(n+1)
        for i, c in enumerate(s):
            self.h[i+1] = (self.h[i]*B + ord(c)) % M
            self.p[i+1] = self.p[i]*B % M
    def get(self, l, r):
        return (self.h[r+1] - self.h[l]*self.p[r-l+1]) % self.M
```

### 17.2 后缀数组 (倍增 + 基数排序)

```python
def build_sa(s):
    n = len(s)
    s = [ord(c) for c in s] + [0]
    n += 1
    sa = list(range(n))
    rk = s[:]
    tmp = [0] * n
    k = 1
    while k < n:
        # 简化: 用 sorted, O(n log^2 n)
        sa.sort(key=lambda i: (rk[i], rk[i+k] if i+k < n else -1))
        for i in range(1, n):
            a, b = sa[i-1], sa[i]
            prev = (rk[a], rk[a+k] if a+k < n else -1)
            cur = (rk[b], rk[b+k] if b+k < n else -1)
            tmp[b] = tmp[a] + (prev != cur)
        rk = tmp
        if rk[sa[-1]] == n - 1:
            break
        k <<= 1
    return sa[1:]
```

### 17.3 Kasai height

```python
def get_height(s, sa):
    n = len(s)
    rank = [0] * n
    for i, pos in enumerate(sa):
        rank[pos] = i
    height = [0] * n
    k = 0
    for i in range(n):
        if rank[i] == 0:
            k = 0
            continue
        j = sa[rank[i] - 1]
        while i + k < n and j + k < n and s[i+k] == s[j+k]:
            k += 1
        height[rank[i]] = k
        if k > 0:
            k -= 1
    return height
```

```python
def longest_repeated_hash(s):

    h = StrHash(s)
    def check(le):
        seen = set()
        for i in range(n - le + 1):
            hv = h.get(i, i + le - 1)
            if hv in seen:
                return True
            seen.add(hv)
        return False
    lo, hi = 0, n - 1

        if check(mid):
            lo = mid
        else:
            hi = mid - 1
    return lo
```

```python
class Solution:
    def strStr(self, haystack: str, needle: str) -> int:
        if not needle:
            return 0
        # KMP
        def kmp(s, p):
            pi = [0] * len(p)
            for i in range(1, len(p)):
                j = pi[i-1]
                while j > 0 and p[i] != p[j]:
                    j = pi[j-1]
                if p[i] == p[j]:
                    j += 1
                pi[i] = j
            j = 0
            for i in range(len(s)):
                while j > 0 and s[i] != p[j]:
                    j = pi[j-1]
                if s[i] == p[j]:
                    j += 1
                if j == len(p):
                    return i - j + 1
            return -1
```

```python
class Solution:
    def repeatedStringMatch(self, a: str, b: str) -> int:
        # 找最小 k 使 b 是 a*k 的子串
        # KMP 在 a*a*a... 上匹配 b
        from math import ceil
        k = ceil(len(b) / len(a))
        # 拼接足够多份

        # KMP 找 b

            pi = [0] * len(p)
            for i in range(1, len(p)):
                j = pi[i-1]
                while j > 0 and p[i] != p[j]:
                    j = pi[j-1]
                if p[i] == p[j]:
                    j += 1
                pi[i] = j
            j = 0
            for i in range(len(s)):
                while j > 0 and s[i] != p[j]:
                    j = pi[j-1]
                if s[i] == p[j]:
                    j += 1
                if j == len(p):
                    return i - j + 1
            return -1
        pos = kmp(s, b)
        if pos == -1:
            return -1
        # 算需要几份

        return ceil(end / len(a))
```

```python
    n = len(s)
    h = StrHash(s)
    def check(le):
        seen = {}
        for i in range(n - le + 1):
            hv = h.get(i, i + le - 1)
            if hv in seen:
                # 检查与上次出现是否重叠
                if i >= seen[hv] + le:
                    return True
            seen[hv] = i
        return False
    lo, hi = 0, n // k
    while lo < hi:
        mid = (lo + hi + 1) // 2
        if check(mid):
            lo = mid
        else:
            hi = mid - 1
    return lo
```

### 20.3 字典序第 K 小子串

```python
def kth_substring_naive(s, k):
    """返回字典序第 k 小的子串 (无重复)"""
    n = len(s)
    subs = set()
    for i in range(n):
        for j in range(i + 1, n + 1):
            subs.add(s[i:j])
    sorted_subs = sorted(subs)
    return sorted_subs[k-1] if k <= len(sorted_subs) else ""
```

**SA 解法**:

```python
def kth_substring_sa(s, k):
    """字典序第 k 小子串, O(n)"""
    sa = build_sa(s)
    height = get_height(s, sa)
    for idx in sa:
        # sa[idx] 对应后缀, 长度 = n - sa[idx]
        # 新增前缀数 = (n - sa[idx]) - height[idx]
        new_count = (n - idx) - height[sa.index(idx)]
        if k > new_count:
            k -= new_count
        else:
            # 就在这个后缀的前 k 个字符中
            return s[idx:idx + height[sa.index(idx)] + k]
    return ""
```

## 23. 后缀数组 vs 后缀树 vs 后缀自动机

### 23.1 后缀树 (Suffix Tree)

后缀树是 Trie 化的所有后缀, 边压缩共享前缀。

**性质**:

- 节点数 $O(n)$, 边数 $O(n)$。
- 任意子串对应一条路径, 查询 $O(|sub|)$。
- LCP 查询 $O(1)$ (用 LCA)。
- 不同子串数 = 所有边长度之和。

**构建**: Ukkonen 算法 $O(n)$。

**优缺点**:

- 实现复杂, 工程上多用 SA + LCP 替代。
- 支持最长公共子串、最长回文等。

### 23.2 后缀数组 + LCP

后缀数组是后缀树的"瘦身版": 不存树结构, 只存排序后的下标数组 + height 数组。

**性质**:

- $sa[i]$: 排名第 $i$ 的后缀起始下标。
- $height[i]$: $sa[i]$ 与 $sa[i-1]$ 的 LCP。
- 任意两后缀 LCP = height 区间最小值 (RMQ)。

**优势**: 实现比后缀树简单, 工业界常用。

### 23.3 后缀自动机 (SAM)

后缀自动机是接受字符串所有子串的最小 DFA。

**性质**:

- 状态数 $\leq 2n - 1$, 转移数 $\leq 3n - 4$。
- 每个状态对应一组 endpos 等价的子串。
- 沿字符走, 走到的状态即子串状态。

**优势**: 子串查询 $O(1)$, 出现次数查询 $O(1)$ (DP)。

### 23.4 三者对比

| 维度 | 后缀树 | 后缀数组 | 后缀自动机 |
| :--- | :--- | :--- | :--- |
| 空间 | $O(n)$ | $O(n)$ | $O(n)$ |
| 构建 | $O(n)$ | $O(n \log n)$ ~ $O(n)$ | $O(n)$ |
| 子串查询 | $O(\|sub\|)$ | $O(1)$ (配 RMQ) | $O(\|sub\|)$ |
| 出现次数 | $O(1)$ | 需额外处理 | $O(1)$ |
| 实现难度 | ★★★★★ | ★★★ | ★★★★ |
| 工程常用 | 较少 | 较多 | 中等 |

## 24. 字符串哈希的更多应用

### 24.1 矩阵哈希 (二维)

```python
class MatrixHash:
    """二维矩阵哈希, O(1) 判子矩阵相等"""
    def __init__(self, mat, B=131, M=(1<<61)-1):
        self.B, self.M = B, M
        n, m = len(mat), len(mat[0]) if mat else 0
        self.h = [[0]*(m+1) for _ in range(n+1)]
        self.p_row = [1]*(m+1)
        self.p_col = [1]*(n+1)
        for j in range(1, m+1):
            self.p_row[j] = self.p_row[j-1] * B % M
        for i in range(1, n+1):
            self.p_col[i] = self.p_col[i-1] * B % M
        for i in range(1, n+1):
            for j in range(1, m+1):
                self.h[i][j] = (self.h[i-1][j] * B + self.h[i][j-1] * B
                              - self.h[i-1][j-1] * B * B + mat[i-1][j-1]) % M
    def get(self, r1, c1, r2, c2):
        """子矩阵 mat[r1..r2][c1..c2] 的哈希"""
        # (r1, c1) 到 (r2, c2), 闭区间
        h = (self.h[r2+1][c2+1] - self.h[r1][c2+1] * self.p_col[r2-r1+1]
             - self.h[r2+1][c1] * self.p_row[c2-c1+1]
             + self.h[r1][c1] * self.p_row[c2-c1+1] * self.p_col[r2-r1+1]) % M
        return h
```

### 24.2 树哈希

**问题**: 判两棵树是否同构 (作为无根树)。

**解**: 用哈希, 对每棵子树哈希 = `(size, 子树哈希 multiset)` 的哈希。

```python
def tree_hash(adj, root=0, parent=-1):
    """树哈希, 同构判等"""
    subtree = []
    for child in adj[root]:
        if child != parent:
            subtree.append(tree_hash(adj, child, root))
    subtree.sort()  # 排序, 避免子节点顺序影响
    h = hash(tuple(subtree))
    return (len(subtree) + 1, h)
```

### 25.2 Lyndon 分解

字符串的 Lyndon 分解是其前缀的字典序最小的分解。

```python
def lyndon_decomposition(s):
    """Duval 算法 O(n)"""
    n = len(s)
    result = []
    i = 0
    while i < n:
        j = i
        k = i + 1
        while k < n and s[j] <= s[k]:
            if s[j] < s[k]:
                j = i
            else:
                j += 1
            k += 1
        while i <= j:
            result.append(s[i:i + k - j])
            i += k - j
    return result
```

### 25.3 字符串的 border 树

字符串的所有 border 构成一棵树, 称为 border 树。

```python
def border_tree(s):
    """构造 border 树"""
    n = len(s)
    pi = [0] * n
    for i in range(1, n):
        j = pi[i-1]
        while j > 0 and s[i] != s[j]:
            j = pi[j-1]
        if s[i] == s[j]:
            j += 1
        pi[i] = j
    # pi[i] 是 s[:i+1] 的最长 border
    # border 树: pi[i] 是 i 的父亲 (除 0)
    children = [[] for _ in range(n + 1)]
    for i in range(1, n):
        children[pi[i]].append(i + 1)  # 用 i+1 作节点编号
    return children
```

### 25.4 字符串的 Z 函数

$z[i]$ = $s[i..]$ 与 $s$ 的 LCP。

```python
def z_function(s):
    n = len(s)
    z = [0] * n
    z[0] = n
    l = r = 0
    for i in range(1, n):
        if i < r:
            z[i] = min(r - i, z[i - l])
        while i + z[i] < n and s[z[i]] == s[i + z[i]]:
            z[i] += 1
        if i + z[i] > r:
            l, r = i, i + z[i]
    return z
```

**应用**: 字符串匹配、前缀查询。

### 25.5 Manacher + SA 联合

```python
def longest_palindrome_sa(s):
    """用后缀数组求最长回文子串, O(n log n)"""
    n = len(s)
    # 拼接 s + '$' + rev(s)
    combined = s + '$' + s[::-1]
    sa = build_sa(combined)
    height = get_height(combined, sa)
    rank = [0] * len(combined)
    for i, pos in enumerate(sa):
        rank[pos] = i
    rmq = RMQ(height)
    best_l, best_len = 0, 0
    # 枚举回文中心
    for center in range(n):
        # 奇回文
        l1 = center
        r1 = 2 * n - center  # 在 combined 中的位置
        if rank[l1] > rank[r1]:
            l1, r1 = r1, l1
        L = rmq.query(rank[l1] + 1, rank[r1]) if rank[l1] < rank[r1] else 0
        L = min(L, min(center + 1, n - center))  # 限制
        if L * 2 - 1 > best_len:
            best_len = L * 2 - 1
            best_l = center - L + 1
        # 偶回文 (类似, 略)
    return s[best_l:best_l + best_len]
```

## 28. 边界与陷阱

### 28.1 字符串哈希

- **空串**: `StrHash("")` 应正常初始化。
- **单字符**: `get(0, 0)` 应等于 `ord(s[0]) * B^0 % M`。
- **碰撞**: 即使双哈希也可能碰撞 (虽然概率极小), 关键测试用暴力对照。
- **基数选择**: $B = 131, 137, 127$ 等都常用, 避免 $B = 2^k$。
- **模数选择**: 大质数或 $2^{61} - 1$。

### 28.2 后缀数组

- **哨兵**: 必须加, 否则 SA 不唯一。
- **空串**: SA 应该是空数组, 不要返回哨兵。
- **重复字符**: SA 处理相同字符可能有多解, 任意解都可。
- **height[0]**: 哨兵与第一个后缀的 LCP, 通常为 0。
- **RMQ**: 稀疏表空间 $O(n \log n)$, 大数据用线段树 $O(n)$ 空间。

## 32. SA 构建的详细图解

### 32.1 例子: $s = "aabaaaab"$

**后缀列表**:

```text
0: aabaaaab
1: abaaaab
2: baaaab
3: aaaab
4: aaab
5: aab
6: ab
7: b
```

**字典序排序** (ASCII: 'a' < 'b'):

```text
rank 0: aab       (suffix 5)
rank 1: aabaaaab  (suffix 0)
rank 2: aaaab     (suffix 3)  -- 不对, "aaaa" < "aaba"
```

让我重新排序:

```text
aab      (suffix 5)
aabaaaab (suffix 0)
aaaab    (suffix 3)
aaab     (suffix 4)
ab       (suffix 6)
abaaaab  (suffix 1)
b        (suffix 7)
baaaab   (suffix 2)
```

字典序: `aab` < `aabaaaab` < `aaaab`? 让我再想...

`aab` = `aab`, `aabaaaab` = `aabaaaab`, `aaaab` = `aaaab`。

比较:
- `aab` vs `aabaaaab`: 前 3 个 `aab` 相同, 第 4 个: 空 vs `a`, 空 < `a`, 所以 `aab` < `aabaaaab` ✓
- `aabaaaab` vs `aaaab`: 第 3 个: `b` vs `a`, `a` < `b`, 所以 `aaaab` < `aabaaaab` ✓

OK 排序:

```text
aa[aab]   (suffix 5)    -- "aab"
aa[baaaab](suffix 0)    -- "aabaaaab"
[aaaab]   (suffix 3)    -- "aaaab"
[aaab]    (suffix 4)    -- "aaab"
[ab]      (suffix 6)    -- "ab"
[abaaaab] (suffix 1)    -- "abaaaab"
[b]       (suffix 7)    -- "b"
[baaaab]  (suffix 2)    -- "baaaab"
```

更准确:

| rank | suffix | idx |
| :--- | :--- | :--- |
| 0 | `aab` | 5 |
| 1 | `aabaaaab` | 0 |
| 2 | `aaaab` | 3 |
| 3 | `aaab` | 4 |
| 4 | `ab` | 6 |
| 5 | `abaaaab` | 1 |
| 6 | `b` | 7 |
| 7 | `baaaab` | 2 |

`sa = [5, 0, 3, 4, 6, 1, 7, 2]` (去掉哨兵后 7 个)。

### 32.2 rank 数组

`rank[idx]` = idx 这个后缀的排名。

```text
rank[0] = 1
rank[1] = 5
rank[2] = 7
rank[3] = 2
rank[4] = 3
rank[5] = 0
rank[6] = 4
rank[7] = 6
```

### 32.3 height 数组 (LCP)

`height[i]` = `sa[i]` 与 `sa[i-1]` 的 LCP。

- `height[0]` = 哨兵 = 0
- `height[1]` = LCP(sa[0]=5, sa[1]=0) = LCP("aab", "aabaaaab") = 3
- `height[2]` = LCP(sa[1]=0, sa[2]=3) = LCP("aabaaaab", "aaaab") = 1 (`a`)
- `height[3]` = LCP(sa[2]=3, sa[3]=4) = LCP("aaaab", "aaab") = 3
- `height[4]` = LCP(sa[3]=4, sa[4]=6) = LCP("aaab", "ab") = 0
- `height[5]` = LCP(sa[4]=6, sa[5]=1) = LCP("ab", "abaaaab") = 2
- `height[6]` = LCP(sa[5]=1, sa[6]=7) = LCP("abaaaab", "b") = 0
- `height[7]` = LCP(sa[6]=7, sa[7]=2) = LCP("b", "baaaab") = 1

`height = [0, 3, 1, 3, 0, 2, 0, 1]`。

### 32.4 不同子串数

$n = 8$, $n(n+1)/2 = 36$。
$\sum height = 0 + 3 + 1 + 3 + 0 + 2 + 0 + 1 = 10$。
不同子串数 = $36 - 10 = 26$。

## 33. Kasai 算法的详细图解

### 33.1 Kasai 的核心观察

我们已经知道 `rank[i]`, 想求 `height[rank[i]]`。

设 `k = height[rank[i-1]] - 1` (即上一个后缀在前一比较中的 LCP - 1)。从 $k$ 开始继续匹配 $s[i..]$ 和 $s[sa[rank[i] - 1]..]$, 因为新比较的 $s[i]$ 对应老比较的 $s[i-1]$ (相对偏移 1)。

### 33.2 例子验证

`s = "aabaaaab"`, `sa = [5, 0, 3, 4, 6, 1, 7, 2]`。

`rank = [1, 5, 7, 2, 3, 0, 4, 6]`。

- `i = 0`: `rank[0] = 1`, `height[1] = ?` (我们要求这个)。但需要先求其他, 调整。

实际上, Kasai 是按 $i$ 顺序遍历:

```python
def kasai(s, sa):
    n = len(s)
    rank = [0] * n
    for i, pos in enumerate(sa):
        rank[pos] = i
    height = [0] * n
    k = 0
    for i in range(n):
        if rank[i] == 0:
            k = 0
            continue
        j = sa[rank[i] - 1]
        while i + k < n and j + k < n and s[i+k] == s[j+k]:
            k += 1
        height[rank[i]] = k
        if k > 0:
            k -= 1
    return height
```

```python
class Solution:
    def distinctEchoSubstrings(self, text: str) -> int:

        n = len(text)
        h = StrHash(text)

        for le in range(2, n + 1, 2):  # 偶数长度

            for i in range(n - le + 1):
```

```python
class Solution:
    def sumOfScores(self, s: str) -> int:
        # s[i:] 与 s 的 LCP 之和
        n = len(s)
        # Z 函数
        z = [0] * n
        z[0] = n
        l = r = 0
        for i in range(1, n):
            if i < r:
                z[i] = min(r - i, z[i - l])
            while i + z[i] < n and s[z[i]] == s[i + z[i]]:
                z[i] += 1
            if i + z[i] > r:
                l, r = i, i + z[i]
        return sum(z)
```

## 35. 哈希的优化技巧

### 35.1 显式模运算 vs 隐式

Python 整数无溢出, 可以**省略 mod** (但要小心性能):

```python
class NoModHash:
    def __init__(self, s, B=131):
        n = len(s)
        self.h = [0] * (n + 1)
        self.p = [1] * (n + 1)
        for i, c in enumerate(s):
            self.h[i+1] = self.h[i] * B + ord(c)
            self.p[i+1] = self.p[i] * B
    def get(self, l, r):
        return self.h[r+1] - self.h[l] * self.p[r-l+1]
```

**风险**: 大字符串时整数位数爆炸, 性能下降。

### 35.2 双 mod 优化

```python
class FastHash:
    """双 mod, Python 友好"""
    def __init__(self, s):
        # 用 (10**9 + 7) 和 (10**9 + 9) 双模
        self.M1 = 10**9 + 7
        self.M2 = 10**9 + 9
        self.B = 91138233  # 随机大基数
        n = len(s)
        self.h1 = [0] * (n + 1)
        self.p1 = [1] * (n + 1)
        self.h2 = [0] * (n + 1)
        self.p2 = [1] * (n + 1)
        for i, c in enumerate(s):
            self.h1[i+1] = (self.h1[i] * self.B + ord(c)) % self.M1
            self.p1[i+1] = self.p1[i] * self.B % self.M1
            self.h2[i+1] = (self.h2[i] * self.B + ord(c)) % self.M2
            self.p2[i+1] = self.p2[i] * self.B % self.M2
    def get(self, l, r):
        h1 = (self.h1[r+1] - self.h1[l] * self.p1[r-l+1]) % self.M1
        h2 = (self.h2[r+1] - self.h2[l] * self.p2[r-l+1]) % self.M2
        return (h1, h2)
```

### 35.3 哈希判等的快捷比较

```python
# 慢
for i in range(n):
    if hash_a.get(0, i) == hash_b.get(0, i):
        ...

# 快: 哈希比较时同时比长度

```

### 35.4 哈希的内存优化

如果只关心子串相等, 不需要存所有前缀哈希, 可以**滚动**:

```python
class RollingHash:
    """滚动哈希, 节省内存"""
    def __init__(self, s, k=10, B=131, M=(1<<61)-1):
        self.B, self.M = B, M
        self.k = k  # 窗口大小
        self.p = pow(B, k, M)
        self.h = 0
        for c in s[:k]:
            self.h = (self.h * B + ord(c)) % M
        self.s = s
    def slide(self, old_c, new_c):
        """移除 old_c, 添加 new_c"""
        self.h = ((self.h - ord(old_c) * self.p) * self.B + ord(new_c)) % self.M
```

但滚动哈希失去任意子串查询能力, 实用价值有限。

```python
def match_with_hash(s, p):
    """用哈希做字符串匹配"""
    n, m = len(s), len(p)
    if m > n:
        return -1
    h_s = StrHash(s)
    h_p = StrHash(p)
    p_hash = h_p.get(0, m - 1)
    for i in range(n - m + 1):
        if h_s.get(i, i + m - 1) == p_hash:

    return -1
```

## 37. SA 在算法竞赛中的模板

```python
def build_sa(s):
    """倍增, O(n log^2 n)"""
    n = len(s)
    s = [ord(c) for c in s] + [0]
    n += 1
    sa = list(range(n))
    rk = s[:]
    tmp = [0] * n
    k = 1
    while k < n:
        sa.sort(key=lambda i: (rk[i], rk[i+k] if i+k < n else -1))
        for i in range(1, n):
            a, b = sa[i-1], sa[i]
            prev = (rk[a], rk[a+k] if a+k < n else -1)
            cur = (rk[b], rk[b+k] if b+k < n else -1)
            tmp[b] = tmp[a] + (prev != cur)
        rk = tmp
        if rk[sa[-1]] == n - 1:
            break
        k <<= 1
    return sa[1:]

def get_height(s, sa):
    n = len(s)
    rank = [0] * n
    for i, pos in enumerate(sa):
        rank[pos] = i
    height = [0] * n
    k = 0
    for i in range(n):
        if rank[i] == 0:
            k = 0
            continue
        j = sa[rank[i] - 1]
        while i + k < n and j + k < n and s[i+k] == s[j+k]:
            k += 1
        height[rank[i]] = k
        if k > 0:
            k -= 1
    return height
```

### 37.1 模板使用例: 求所有不同子串数

```python
def count_distinct(s):
    sa = build_sa(s)
    height = get_height(s, sa)
    return len(s) * (len(s) + 1) // 2 - sum(height)
```

### 37.2 模板使用例: 求最大重复子串

```python
def longest_repeat(s):
    sa = build_sa(s)
    height = get_height(s, sa)
    return max(height) if height else 0
```

### 37.3 模板使用例: 两串 LCP

```python
def two_string_lcp(s, t):
    """求 s 和 t 的最长公共子串"""
    combined = s + '$' + t
    sa = build_sa(combined)
    height = get_height(combined, sa)
    # 找跨过分隔符的最大 height
    n = len(s)
    best = 0
    for i in range(1, len(sa)):
        a, b = sa[i-1], sa[i]
        if (a < n) != (b < n):  # 一个在 s, 一个在 t
            best = max(best, height[i])
    return best
```

## 38. SA 的复杂度证明

### 38.1 倍增构建 O(n log^2 n)

外层循环 $O(\log n)$ (k 翻倍), 每次 `sorted` $O(n \log n)$ (Python 的 sort), 总 $O(n \log^2 n)$。

### 38.2 倍增 + 基数排序 O(n log n)

外层 $O(\log n)$, 内层基数排序 $O(n)$, 总 $O(n \log n)$。

### 38.3 Kasai O(n)

`while` 总次数受 `k` 限制, 而 `k` 单调递减 (每次 `k -= 1`), 但每次 `k += 1` 才进 while, 总增量 $O(n)$。

### 38.4 RMQ 查询 O(1)

稀疏表预处理 $O(n \log n)$, 查询 $O(1)$。

### 39.1 Cyclic Hash

循环字符串的哈希, 模拟字符串无限重复。

```python
class CyclicHash:
    """循环哈希, 处理 s = s+s+s+..."""
    def __init__(self, s, k, B=131, M=(1<<61)-1):
        self.B, self.M = B, M
        n = len(s)
        # 把 s 重复 k 次
        extended = s * k
        self.h = [0] * (len(extended) + 1)
        self.p = [1] * (len(extended) + 1)
        for i, c in enumerate(extended):
            self.h[i+1] = (self.h[i] * B + ord(c)) % M
            self.p[i+1] = self.p[i] * B % M
    def get(self, l, r):
        return (self.h[r+1] - self.h[l] * self.p[r-l+1]) % self.M
```
