## 1. 最大公约数 GCD

### 1.1 欧几里得算法(辗转相除法)

**核心等式**: $\gcd(a,b) = \gcd(b, a \bmod b)$, 终止条件 $b=0$ 时 $\gcd(a,0)=a$。

**直觉**: $a$ 和 $b$ 的公因子一定是 $b$ 和 $a-qb$ 的公因子。反复替换, 数对越来越小, 直到一个变 0。

```python
def gcd(a, b):
    """欧几里得算法, O(log min(a,b))"""
    return a if b == 0 else gcd(b, a % b)

# 迭代版(避免 Python 递归深度限制, 推荐)
def gcd_iter(a, b):
    while b:
        a, b = b, a % b
    return a

# Python 3.9+ 自带 math.gcd, 大数可以直接用
import math
math.gcd(12, 18)  # → 6
```

**复杂度**: 每次至少除 2, 所以 $O(\log \min(a,b))$。对 $10^{18}$ 量级都很快。

### 1.2 更相减损术(中国古代算法)

```python
def gcd_sub(a, b):
    """更相减损术, O(max(a,b))"""
    if a < b: a, b = b, a
    while b:
        if a & 1 == 0 and b & 1 == 0:
            return gcd_sub(a >> 1, b >> 1) << 1   # 都是偶数 → gcd *= 2
        if a & 1 == 0: a >>= 1
        elif b & 1 == 0: b >>= 1
        else: a, b = (a - b) >> 1, min(a, b) if a > b else b
    return a
```

适用场景: 大数 + 减法比取模快 (嵌入式/竞赛老题)。

### 1.3 Stein 算法(二进制 GCD)

```python
def stein_gcd(a, b):
    if a < b: a, b = b, a
    if b == 0: return a
    if a & 1 == 0 and b & 1 == 0:
        return stein_gcd(a >> 1, b >> 1) << 1
    if a & 1 == 0:
        return stein_gcd(a >> 1, b)
    if b & 1 == 0:
        return stein_gcd(a, b >> 1)
    return stein_gcd((a - b) >> 1, b)
```

只用移位和减法, 适合硬件实现, 现代 CPU 上慢于欧几里得。

### 1.4 GCD 的性质(面试推导题)

- **交换律**: $\gcd(a,b)=\gcd(b,a)$
- **结合律**: $\gcd(\gcd(a,b),c)=\gcd(a,\gcd(b,c))$
- **分配律**: $\gcd(a,bc)=\gcd(a,b)\cdot\gcd(a,c)$ 当 $\gcd(b,c)=1$
- **Bezout 定理**: $\exists x,y$ 使 $ax+by=\gcd(a,b)$ (扩展欧几里得构造)
- **乘性**: $\gcd(ka,kb)=|k|\gcd(a,b)$

## 2. 最小公倍数 LCM

### 2.1 公式与代码

$$\text{lcm}(a,b) = \frac{a \cdot b}{\gcd(a,b)}$$

```python
def lcm(a, b):
    return a // gcd(a, b) * b    # 先除后乘, 防 a*b 溢出

# Python 3.9+
math.lcm(12, 18)  # → 36
```

**坑**: 一定要 `a // gcd * b` 而不是 `a * b // gcd`, 否则 `a*b` 可能溢出。

### 2.2 多个数的 LCM

```python
from functools import reduce
def lcm_many(nums):
    return reduce(lcm, nums)
```

例: $\text{lcm}(4,6,10) = 60$。

## 3. 快速幂(模运算基石)

### 3.1 核心思想

求 $a^n \bmod M$:

把 $n$ 二进制拆分: $n = \sum_{i=0}^{k} b_i 2^i$, $b_i \in \{0,1\}$。

$$a^n = \prod_{b_i=1} a^{2^i}$$

从低位到高位, 维护当前位对应的 $a^{2^i}$, 每步平方。每处理一位复杂度 $O(1)$, 共 $O(\log n)$ 步。

### 3.2 模板代码

```python
def qpow(a, n, M):
    """a^n % M, 递归版"""
    if n == 0: return 1 % M
    if n & 1:
        return a * qpow(a, n-1, M) % M
    t = qpow(a, n >> 1, M)
    return t * t % M

def qpow_iter(a, n, M):
    """迭代版, 推荐 (无递归深度问题)"""
    res = 1
    a %= M
    while n:
        if n & 1:
            res = res * a % M
        a = a * a % M
        n >>= 1
    return res
```

### 3.3 大数快速幂(指数 $n$ 为 long long)

```python
def qpow_ll(a, n, M):
    """处理 a^n % M, n 可能为 10^18"""
    res = 1
    a %= M
    while n > 0:
        if n & 1:
            res = res * a % M
        a = a * a % M
        n >>= 1
    return res
```

在 Python 中 `int` 任意精度, 所以不用怕溢出; C++/Java 必须用 `long long`/`long`。

### 3.4 快速幂的若干变种

```python
# 1) 计算 a^n 不取模 (Python 可, 其他语言会溢出)
def pow_int(a, n):
    res = 1
    while n:
        if n & 1: res *= a
        a *= a
        n >>= 1
    return res

# 2) 矩阵快速幂 (见 §4)

# 3) 大指数取模, 指数也是大数 (用 pow 内置)
pow(2, 10**18, 10**9+7)   # Python 内置 pow, 三参数版用平方-乘算法, 极快

# 4) 取模后判断 a^n % M == 0
def is_divisible(a, n, M):
    """判断 a^n 是否被 M 整除"""
    return qpow(a, n, M) == 0
```

### 3.5 快速幂复杂度分析

- 时间: $O(\log n)$, 每次循环常数操作。
- 空间: $O(1)$(迭代版)。
- 对 $n = 10^{18}$, 只需约 60 次循环。

## 4. 矩阵快速幂

### 4.1 适用场景

递推关系形如 $f(n) = c_1 f(n-1) + c_2 f(n-2) + \dots + c_k f(n-k)$, 用 $k \times k$ 矩阵加速到 $O(k^3 \log n)$。

经典: 斐波那契数列第 $n$ 项 $\pmod M$, $n$ 可达 $10^{18}$。

### 4.2 实现

```python
def mat_mul(A, B, M):
    """k×k 矩阵乘法 mod M"""
    n = len(A)
    C = [[0]*n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            s = 0
            for k in range(n):
                s += A[i][k] * B[k][j]
            C[i][j] = s % M
    return C

def mat_pow(A, n, M):
    """矩阵 A^n mod M"""
    n_dim = len(A)
    # 单位矩阵
    R = [[1 if i == j else 0 for j in range(n_dim)] for i in range(n_dim)]
    while n:
        if n & 1: R = mat_mul(R, A, M)
        A = mat_mul(A, A, M)
        n >>= 1
    return R

# 斐波那契: F(n) = F(n-1) + F(n-2)
def fib(n, M=10**9+7):
    if n <= 1: return n
    A = [[1, 1], [1, 0]]
    R = mat_pow(A, n-1, M)
    return R[0][0]   # F(n)
```

### 4.3 NumPy 加速版(矩阵大时)

```python
import numpy as np
def mat_pow_np(A, n, M):
    A = np.array(A, dtype=object)
    n_dim = A.shape[0]
    R = np.eye(n_dim, dtype=object)
    while n:
        if n & 1: R = (R @ A) % M
        A = (A @ A) % M
        n >>= 1
    return R
```

NumPy 的 `object` 类型避开溢出警告, 适合 k=50~200 的大型转移矩阵。

## 5. 扩展欧几里得(解 ax+by=gcd)

### 5.1 Bezout 定理与构造

定理: $\gcd(a,b)$ 是 $a,b$ 线性组合能表示的最小正整数, 一定存在整数 $x,y$ 使 $ax+by=\gcd(a,b)$。

扩展欧几里得算法在算 GCD 的同时, 反向回溯得到 $x,y$。

### 5.2 递归实现

```python
def exgcd(a, b):
    """返回 (g, x, y) 使 a*x + b*y = g = gcd(a,b)"""
    if b == 0:
        return a, 1, 0
    g, x1, y1 = exgcd(b, a % b)
    # 原始: b*x1 + (a%b)*y1 = g
    # 代入 a%b = a - (a//b)*b
    # = b*x1 + (a - (a//b)*b)*y1
    # = a*y1 + b*(x1 - (a//b)*y1)
    x = y1
    y = x1 - (a // b) * y1
    return g, x, y
```

### 5.3 迭代实现(避免递归)

```python
def exgcd_iter(a, b):
    """迭代版扩展欧几里得"""
    old_r, r = a, b
    old_s, s = 1, 0
    old_t, t = 0, 1
    while r != 0:
        q = old_r // r
        old_r, r = r, old_r - q * r
        old_s, s = s, old_s - q * s
        old_t, t = t, old_t - q * t
    return old_r, old_s, old_t
```

### 5.4 用途清单

1. **求逆元** (模数不必为质数, 见 §6)。
2. **解线性同余方程**: $ax \equiv c \pmod M \Leftrightarrow ax - c = kM$, 即 $ax + (-k)M = c$, 用扩欧求基础解。
3. **中国剩余定理 CRT** (见 §10)。
4. **判断方程有解**: $ax \equiv c \pmod M$ 有解 $\iff \gcd(a,M) | c$。

### 5.5 例题: POJ 1061 青蛙的约会

两只青蛙在数轴上跳, 周期 $m,n$, 步长 $L_1,L_2$, 起点 $x_1,x_2$。求最少多少次后相遇。

列方程: $x_1 + L_1 t \equiv x_2 + L_2 t \pmod L$, 整理 $(L_1 - L_2) t \equiv x_2 - x_1 \pmod L$。扩欧求 $t$。

```python
def frog_meet(L, x1, x2, L1, L2):
    a = L1 - L2
    c = x2 - x1
    g, t, _ = exgcd(a, L)
    if c % g != 0:
        return -1
    t = t * (c // g) % L
    return t
```

## 6. 乘法逆元(除法变乘法)

### 6.1 概念

模意义下没有除法, 用逆元替代: 若 $a \cdot a^{-1} \equiv 1 \pmod M$, 则 $b/a \equiv b \cdot a^{-1} \pmod M$。

**存在条件**: $\gcd(a,M)=1$。质数模下, 任何非零元素都有逆元。

### 6.2 求法一: 费马小定理(质数模)

$$\gcd(a,M)=1 \Rightarrow a^{M-1} \equiv 1 \Rightarrow a^{M-2} \equiv a^{-1}$$

```python
def inv_fermat(a, M):
    """费马小定理求逆元, M 必须为质数"""
    assert is_prime(M), "M 必须是质数"
    return qpow(a, M - 2, M)
```

### 6.3 求法二: 扩展欧几里得(任意互质模)

```python
def inv_exgcd(a, M):
    """扩展欧几里得求逆元, 只需 gcd(a,M)=1"""
    g, x, _ = exgcd(a, M)
    if g != 1:
        return None    # 逆元不存在
    return x % M       # 最小正整数
```

### 6.4 求法三: 递推(预处理 1~n 全部逆元)

```python
def inv_table(n, M):
    """O(n) 预处理 1..n 的逆元 mod M (M 为质数)"""
    inv = [0] * (n + 1)
    inv[1] = 1
    for i in range(2, n + 1):
        # inv[i] = -(M//i) * inv[M%i] mod M
        inv[i] = (M - M // i) * inv[M % i] % M
    return inv
```

**推导**: 由 $M = k i + r$ (其中 $k=M//i$, $r=M\%i$), 即 $k i \equiv -r \pmod M$, 除以 $i$ 得 $k \equiv -r \cdot i^{-1}$, 即 $i^{-1} \equiv -k \cdot r^{-1}$。把 $r < i$ 视为已经算过。

### 6.5 求法四: 阶乘逆元

```python
def fac_inv(n, M):
    """预处理阶乘 + 阶乘逆元, 用于 C(n,k) = n! / (k! (n-k)!)"""
    fac = [1] * (n + 1)
    for i in range(1, n + 1):
        fac[i] = fac[i-1] * i % M
    inv_fac = [1] * (n + 1)
    inv_fac[n] = qpow(fac[n], M - 2, M)     # Fermat
    for i in range(n - 1, 0, -1):
        inv_fac[i] = inv_fac[i+1] * (i+1) % M
    return fac, inv_fac

def C(n, k, fac, inv_fac, M):
    if k < 0 or k > n: return 0
    return fac[n] * inv_fac[k] % M * inv_fac[n-k] % M
```

### 6.6 逆元的四种方法对比

| 方法 | 时间 | 空间 | 适用 | 限制 |
| :--- | :--- | :--- | :--- | :--- |
| 费马小定理 | $O(\log M)$ | $O(1)$ | 单次查询 | $M$ 必须是质数 |
| 扩展欧几里得 | $O(\log \min(a,M))$ | $O(\log M)$ | 单次查询 | $\gcd(a,M)=1$ |
| 线性递推 | $O(n)$ 预处理, $O(1)$ 查询 | $O(n)$ | $n$ 范围已知, 多次查询 | $M$ 必须是质数 |
| 阶乘逆元 | $O(n)$ 预处理, $O(1)$ 查询 | $O(n)$ | 求组合数 | $M$ 必须是质数 |

**实战推荐**: 单个查询用费马; 多次查询用线性递推; 求组合数用阶乘逆元。

### 6.7 负数取模(常见坑)

```python
def mod_norm(x, M):
    """将 x 归一化到 [0, M)"""
    return ((x % M) + M) % M
```

例如 $-5 \bmod 7 = 2$, Python 直接 `-5 % 7 == 2`, 但其他语言是 -5。

## 7. 费马小定理与欧拉定理

### 7.1 费马小定理

若 $p$ 为质数且 $\gcd(a,p)=1$, 则 $a^{p-1} \equiv 1 \pmod p$。

**直接应用**: $a^{-1} \equiv a^{p-2} \pmod p$。

### 7.2 欧拉定理

若 $\gcd(a,M)=1$, 则 $a^{\varphi(M)} \equiv 1 \pmod M$, 其中 $\varphi$ 是欧拉函数。

$$\varphi(n) = n \prod_{p | n} \left(1 - \frac{1}{p}\right)$$

```python
def euler_phi(n):
    """计算 φ(n)"""
    result = n
    p = 2
    while p * p <= n:
        if n % p == 0:
            while n % p == 0:
                n //= p
            result -= result // p
        p += 1
    if n > 1:
        result -= result // n
    return result
```

### 7.3 欧拉定理求逆元

$$a^{-1} \equiv a^{\varphi(M)-1} \pmod M$$

适用于 $M$ 非质数但 $\gcd(a,M)=1$ 的情形。比扩欧慢但好记。

### 7.4 拓展欧拉定理(指数塔类)

当 $\gcd(a,M) \neq 1$ 时, 指数需要降至 $\varphi(M)$ 以内:

$$a^b \equiv a^{b \bmod \varphi(M) + \varphi(M)} \pmod M \quad (\text{当 } b \geq \varphi(M))$$

应用: 递归降幂, 处理 $a^{a^{a^{\cdots}}}$ 类问题。

## 8. 线性预处理逆元

### 8.1 标准公式

$\text{inv}[i] = -(M/i) \cdot \text{inv}[M \bmod i] \pmod M$

```python
def inv_table(n, M):
    inv = [0] * (n + 1)
    inv[1] = 1
    for i in range(2, n + 1):
        inv[i] = (M - M // i) * inv[M % i] % M
    return inv
```

### 8.2 验证

```python
M = 10**9 + 7
inv = inv_table(10, M)
for i in range(1, 11):
    assert (i * inv[i]) % M == 1, f"Failed at {i}"
print("OK")
```

### 8.3 应用: 求 $\prod_{i=1}^{n} a_i$ 的逆元

$$\left(\prod a_i\right)^{-1} = \prod a_i^{-1}$$

若已知 $a_i$ 各自逆元, 直接相乘。否则:

```python
def prefix_inv_products(arr, M):
    """前缀积 + 前缀积逆元, 用于区间乘积查询"""
    n = len(arr)
    pre = [1] * (n + 1)
    for i in range(n):
        pre[i+1] = pre[i] * arr[i] % M
    inv_pre_n = qpow(pre[n], M - 2, M)
    inv_pre = [1] * (n + 1)
    inv_pre[n] = inv_pre_n
    for i in range(n - 1, 0, -1):
        inv_pre[i] = inv_pre[i+1] * arr[i] % M
    inv_pre[0] = qpow(pre[0], M - 2, M)
    return pre, inv_pre

def range_product(l, r, pre):
    """区间 [l, r) 的乘积 mod M"""
    return pre[r] * pow(pre[l], M-2, M) % M   # 或用 inv_pre
```

## 9. 模运算的坑与防溢出

### 9.1 经典坑汇总

| 坑 | 原因 | 解决 |
| :--- | :--- | :--- |
| `a * b` 溢出 | int64 上限 $9.2 \times 10^{18}$, 超就溢出 | 用 Python / 加 `unsigned long long` / 分解 |
| 减法变负 | `a - b % M` 可能为负 | `((a - b) % M + M) % M` |
| `M` 不是质数 | 费马求逆元得到错解 | 改用扩欧 |
| `qpow(0, 0)` | 约定 $0^0=1$ | 单独处理 |
| GCD 输入 0 | `gcd(0,n) = n` | 显式处理 (math.gcd 已包含) |
| `1 / n` 在模意义下 | 没有除法 | 用 `n^{-1} = qpow(n, M-2, M)` |

### 9.2 防溢出代码模板

```python
def add_mod(a, b, M):
    return (a + b) % M

def sub_mod(a, b, M):
    return (a - b) % M if a >= b else (a - b + M) % M
    # Python: (a - b) % M 自动处理

def mul_mod(a, b, M):
    # Python 没溢出, C++/Java 需写成长乘法
    return (a * b) % M

# C++ 版长乘法 (Python 无所谓)
def mul_mod_long(a, b, M):
    return (a * b) % M   # Python 自动 big int
```

### 9.3 Python 的"侥幸"

Python `int` 任意精度, 所以大部分溢出问题不存在。但**性能会下降**——大数乘法比 64 位乘法慢 10-100 倍。

- 用 PyPy

## 10. 中国剩余定理 CRT

### 10.1 问题

给定 $n$ 个同余方程:
$$x \equiv a_i \pmod{m_i}, \quad i=1,\dots,n$$

若 $m_i$ 两两互质, 求 $x \pmod{M}$ (其中 $M = \prod m_i$)。

### 10.2 解法

设 $M_i = M / m_i$, $M_i^{-1}$ 为 $M_i$ 模 $m_i$ 的逆元, 则:

$$x = \sum_{i=1}^{n} a_i \cdot M_i \cdot M_i^{-1} \pmod M$$

```python
def crt(a_list, m_list):
    """中国剩余定理, m_list 两两互质"""
    M = 1
    for m in m_list:
        M *= m
    x = 0
    for a, m in zip(a_list, m_list):
        Mi = M // m
        inv_Mi = inv_exgcd(Mi, m)
        x = (x + a * Mi * inv_Mi) % M
    return x % M
```

### 10.3 拓展 CRT(模数不互质)

```python
def excrt(a_list, m_list):
    """拓展中国剩余定理, 允许 m_i 不互质"""
    x, m = a_list[0], m_list[0]
    for i in range(1, len(a_list)):
        a, n = a_list[i], m_list[i]
        # 解 x ≡ a (mod n), 即 x + m*k = a + n*k'
        # 即 m*k - n*k' = a - x
        g, p, q = exgcd(m, n)
        if (a - x) % g != 0:
            return None    # 无解
        k = (a - x) // g * p
        x = x + m * k
        m = m * n // g    # 新模数
        x = (x % m + m) % m
    return x % m
```

- 模不同质数的混合运算
- 大数分解后的密码学场景

## 11. 阶乘与组合数预处理

### 11.1 阶乘 + 阶乘逆元(标准模板)

```python
M = 10**9 + 7

def prepare_combinatorics(n, M):
    """预处理 0..n 的阶乘和阶乘逆元"""
    fac = [1] * (n + 1)
    for i in range(1, n + 1):
        fac[i] = fac[i-1] * i % M
    inv_fac = [1] * (n + 1)
    inv_fac[n] = pow(fac[n], M - 2, M)
    for i in range(n - 1, -1, -1):
        inv_fac[i] = inv_fac[i+1] * (i+1) % M
    return fac, inv_fac

def C(n, k, fac, inv_fac, M):
    if k < 0 or k > n: return 0
    return fac[n] * inv_fac[k] % M * inv_fac[n-k] % M

def P(n, k, fac, inv_fac, M):
    """排列 A(n,k) = n! / (n-k)!"""
    if k < 0 or k > n: return 0
    return fac[n] * inv_fac[n-k] % M

# 验证
fac, inv_fac = prepare_combinatorics(10, M)
assert C(10, 3, fac, inv_fac, M) == 120
```

### 11.2 Lucas 定理(大 n 组合数)

当 $M$ 为质数, $n,k$ 很大 ($n,k$ 可达 $10^{18}$), 但 $M$ 较小时:

$$C(n,k) \equiv \prod_{i} C(n_i, k_i) \pmod M$$

其中 $n_i, k_i$ 是 $n, k$ 在 $M$ 进制下的各位数字。

```python
def lucas(n, k, M):
    """Lucas 定理求 C(n,k) mod M (M 必须为质数)"""
    if k == 0: return 1
    ni = n % M
    ki = k % M
    if ki > ni: return 0
    return C(ni, ki, fac, inv_fac, M) * lucas(n // M, k // M, M) % M
```

```python
def myPow(x, n):
    if n < 0:
        x, n = 1/x, -n
    res = 1.0
    while n:
        if n & 1:
            res *= x
        x *= x
        n >>= 1
    return res

# 解法二: 递归
def myPow_rec(x, n):
    if n < 0:
        x, n = 1/x, -n
    if n == 0: return 1
    if n & 1:
        return x * myPow_rec(x, n-1)
    t = myPow_rec(x, n // 2)
    return t * t

def myPow_builtin(x, n):
    return x ** n
```

```python
def countDigitOne(n):
    count = 0
    factor = 1

        lower = n % factor
        cur = (n // factor) % 10
        higher = n // (factor * 10)
        if cur == 0:

        elif cur == 1:
```

**思路**: 哈希表分组, 同组内相邻下标差。

```python
from collections import defaultdict
def min_distance(arr):
    pos = defaultdict(list)
    for i, x in enumerate(arr):
        pos[x].append(i)
    res = [0] * len(arr)
    for x, ps in pos.items():
        ps.sort()
        for i, p in enumerate(ps):
            d = float('inf')
            if i > 0: d = min(d, p - ps[i-1])
            if i < len(ps) - 1: d = min(d, ps[i+1] - p)
            res[p] = d if d != float('inf') else -1
    return res
```

```python
def divide(dividend, divisor):
    INT_MAX = 2**31 - 1
    INT_MIN = -2**31
    if dividend == INT_MIN and divisor == -1:
        return INT_MAX
    sign = -1 if (dividend < 0) ^ (divisor < 0) else 1
    a, b = abs(dividend), abs(divisor)
    res = 0
    for i in range(31, -1, -1):
        if a >= b << i:
            a -= b << i
            res += 1 << i
    return sign * res
```

## 13. 多解法对比与模板选择

### 13.1 GCD 三种实现性能对比

| 算法 | 时间复杂度 | 常数 | 实现难度 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| 欧几里得 (递归) | $O(\log n)$ | 极小 | 简单 | 通用 |
| 欧几里得 (迭代) | $O(\log n)$ | 极小 | 简单 | 推荐(无栈溢出) |
| 更相减损术 | $O(\max)$ | 中 | 复杂 | 历史场景 |
| Stein (二进制) | $O(\log n)$ | 中 | 中 | 硬件实现 |

**结论**: 99% 情况下用迭代版欧几里得。Python 直接 `math.gcd`。

### 13.2 快速幂 vs 矩阵快速幂

| 场景 | 算法 | 时间 |
| :--- | :--- | :--- |
| 单次 $a^n \bmod M$ | 快速幂 | $O(\log n)$ |
| $k$ 阶线性递推第 $n$ 项 | 矩阵快速幂 | $O(k^3 \log n)$ |
| 幂次本身需要模运算 | 快速幂 | $O(\log n)$ |

### 13.3 逆元三种方法选择决策树

```text
单次查询?
├─ M 是质数 → 费马小定理 O(log M)
└─ M 非质数
   ├─ 已知 gcd(a,M)=1 → 扩欧 O(log M)
   └─ 否则 → 无逆元, 返回 None

多次查询 (1..n)?
├─ M 是质数 → 线性递推 O(n)
└─ 组合数 → 阶乘 + 阶乘逆元 O(n)
```

### 13.4 取模 vs 模数选择

- **常见质数模**: $10^9 + 7$, $10^9 + 9$, $998244353$, $10^{18}+3$。
- **选择理由**: 大质数防止冲突 (生日攻击), NTT 友好等。
- **双模**: 当答案可能超过单模时, 用两个质数分别算, CRT 合并。

### 13.5 快速幂在递归/迭代的选择

- **递归**: 代码短, 但 $n=10^{18}$ 时 Python 递归深度可能爆栈。
- **迭代**: 代码略长, 但安全, 推荐。

## 14. 面试高频问答

### Q1: 快速幂原理是什么？

把指数 $n$ 按二进制拆分: $n = b_k 2^k + \dots + b_1 2 + b_0$。则 $a^n = a^{b_k 2^k} \cdot \dots \cdot a^{b_1 2} \cdot a^{b_0}$。每步把当前底数平方 (乘 2), 指数右移 (除 2), 是 $O(\log n)$。

### Q2: 费马小定理和扩展欧几里得都能求逆元, 区别？

- **费马**: $a^{p-2} \bmod p$, 要求 $p$ 是质数。代码简单 (一行 `pow`)。
- **扩欧**: 解 $ax + py = 1$, 得 $x = a^{-1}$。不要求 $p$ 质数, 只要 $\gcd(a,p)=1$。

### Q3: 为什么费马小定理能给出逆元？

$a^{p-1} \equiv 1 \pmod p$ ⟹ $a \cdot a^{p-2} \equiv 1$, 即 $a^{p-2}$ 是 $a$ 的逆元。

### Q4: GCD 时间复杂度？为什么是 log？

每次 `a = b, b = a % b`, 数对单调减小。Fibonacci 数列的相邻项是欧几里得的最坏情况, 此时步数与 $\log_\varphi n$ 成正比 (其中 $\varphi$ 是黄金比例)。

### Q5: 矩阵快速幂的瓶颈？

矩阵乘法 $O(k^3)$。当 $k$ 很大时 (如 $k=200$), 即使 $\log n = 60$, 总复杂度是 $200^3 \cdot 60 = 4.8 \times 10^8$, 会超时。优化: 矩阵分块、稀疏矩阵特化。

### Q6: GCD 在 ML/推荐系统中有应用吗？

- 训练 batch 划分 (让多个进程均分数据, 按 GCD 切分)
- 哈希特征设计 (质数模避免冲突)
- 梯度累积步数设计 (按 loss 缩放因子 GCD)

### Q7: 1e18 的幂次取模会不会溢出？

C++/Java: 用 64 位整数时, $a \times a$ 可能溢出 → 用 `__int128` 或长乘法。
Python: 自动 big int, 无溢出。

### Q8: 为什么求逆元要求 M 是质数(对费马)?

$a^{p-2} \cdot a = a^{p-1}$, 费马要求 $a^{p-1} \equiv 1$, 这只在 $p$ 为质数时对所有 $\gcd(a,p)=1$ 成立。

### Q9: GCD 和 LCM 有什么关系?

$\gcd(a,b) \cdot \text{lcm}(a,b) = a \cdot b$, 但仅当 $a,b > 0$。

### Q10: 写一个 O(log n) 求 GCD 的代码。

```python
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a
```

### 16.2 分布式训练的数据并行切分

```python
def shard_data(N, rank, world_size):
    """按 GCD 切分, 保证各 rank 数据量接近"""
    base = N // world_size
    extra = N % world_size
    start = rank * base + min(rank, extra)
    end = start + base + (1 if rank < extra else 0)
```

### 21.1 LeetCode 1819 序列中不同最大公约数的数目

**题目**: 给定数组 `nums`, 求所有子序列的 GCD 中不同值的数目。

**思路**: 暴力枚举 GCD 值 $g$, 扫描数组统计能整除 $g$ 的元素数。

```python
def countDifferentSubsequenceGCDs(nums):
    max_val = max(nums)
    present = [False] * (max_val + 1)
    for x in nums:
        present[x] = True

    count = 0
    for g in range(1, max_val + 1):
        # 找 nums 中所有 g 的倍数
        found_gcd = 0
        for multiple in range(g, max_val + 1, g):
            if present[multiple]:
                found_gcd = math.gcd(found_gcd, multiple)
        if found_gcd == g:
            count += 1
    return count
```

**复杂度**: $O(n + V \log V)$, $V$ 为 max(nums)。

**思路升级版**: 倒着枚举 $g$, 累加其所有倍数贡献。

### 21.4 LeetCode 166 分数到小数

**题目**: 给定分子分母, 输出小数表示 (含循环节时加括号)。

**思路**: 长除法, 用哈希表记录余数首次出现位置。

```python
def fractionToDecimal(numerator, denominator):
    if numerator == 0: return "0"
    sign = -1 if (numerator < 0) ^ (denominator < 0) else 1
    n, d = abs(numerator), abs(denominator)

    int_part = n // d
    rem = n % d
    if rem == 0:
        return ("-" if sign < 0 else "") + str(int_part)

    frac = []
    rem_pos = {}
    while rem != 0 and rem not in rem_pos:
        rem_pos[rem] = len(frac)
        rem *= 10
        frac.append(str(rem // d))
        rem %= d

    result = str(int_part) + "."
    if rem == 0:
        result += "".join(frac)
    else:
        cycle_start = rem_pos[rem]
        result += "".join(frac[:cycle_start]) + "(" + "".join(frac[cycle_start:]) + ")"

    return ("-" if sign < 0 else "") + result
```

**复杂度**: $O(d)$, 受分子分母绝对值限制。

### 21.5 LeetCode 991 坏了的计算器

**题目**: 起始值 $X$, 目标 $Y$, 每步可以 `X = X - 1` 或 `X = 2X`, 求最少步数。

**思路**: 反向 — 从 $Y$ 出发, 若 $Y$ 是偶数则 $Y = Y/2$, 否则 $Y = Y+1$, 直到 $Y \le X$ 再加 $X - Y$。

```python
def brokenCalc(X, Y):
    steps = 0
    while Y > X:
        steps += 1
        if Y % 2 == 1:
            Y += 1
        else:
            Y //= 2
    return steps + (X - Y)
```

**复杂度**: $O(\log Y)$。

### 21.9 AcWing 204 表达整数的奇怪方式

**题目**: 给定 $a_1, m_1, a_2, m_2, \dots$, 求最小非负整数 $x$ 满足 $x \equiv a_i \pmod{m_i}$。

```python
def excrt_general(a_list, m_list):
    """拓展 CRT 通用版"""
    x, m = 0, 1    # 当前解为 x mod m
    for ai, mi in zip(a_list, m_list):
        # 解 m * k ≡ (ai - x) (mod mi)
        # 即 (m mod mi) * k ≡ (ai - x) (mod mi)
        g, p, q = exgcd(m, mi)
        diff = ai - x
        if diff % g != 0:
            return -1, -1    # 无解
        # m * p + mi * q = g
        k = (diff // g * p) % (mi // g)
        x = x + m * k
        m = m * mi // g
        x = x % m
    return x, m
```

### 21.11 AtCoder Beginner Contest 150 D Semi Common Multiple

**题目**: 给定正整数 $a_1, \dots, a_n$ 和 $M$, 求 $X = a_k \times (p + 0.5)$ (p 非负整数) 形式的数, 使 $X$ 是所有 $a_i$ 的倍数。求 $M$ 以内这样的 $X$ 个数。

**思路**: 所有 $X$ 必须是 $L = \text{lcm}(a_1, \dots, a_n)$ 的倍数, 且每个 $X/L$ 必须是半整数 (奇数一半)。只有当 $L/2$ 整除 $X$ 且 $X/L$ 奇数才满足。

```python
def semi_common_multiple(M, a_list):
    from math import gcd
    L = 1
    for a in a_list:
        L = L * a // gcd(L, a)

    if L % 2 == 1:
        return 0

    half = L // 2
    if half > M:
        return 0

    # X 是 L 的倍数且 X = half * (2k+1), 即 X 在 {half, 3*half, 5*half, ...}
    # 即 X = L * (k + 0.5) (k 整数), X/L = k + 0.5 必为半整数
    # X = L * (2j+1)/2 = half * (2j+1)
    # X <= M => (2j+1) <= M/half => j <= (M/half - 1) / 2
    return (M // half + 1) // 2
```

### 21.13 AtCoder Library Practice 2: Combinatorics

```python
class ModCombinatorics:
    def __init__(self, n, M):
        self.M = M
        self.fac = [1] * (n + 1)
        for i in range(1, n + 1):
            self.fac[i] = self.fac[i-1] * i % M
        self.inv_fac = [1] * (n + 1)
        self.inv_fac[n] = pow(self.fac[n], M - 2, M)
        for i in range(n - 1, -1, -1):
            self.inv_fac[i] = self.inv_fac[i+1] * (i+1) % M

    def C(self, n, k):
        if k < 0 or k > n: return 0
        return self.fac[n] * self.inv_fac[k] % M * self.inv_fac[n-k] % M

    def P(self, n, k):
        if k < 0 or k > n: return 0
        return self.fac[n] * self.inv_fac[n-k] % M

    def H(self, n, k):
        """可重组合 C(n+k-1, k)"""
        return self.C(n + k - 1, k)
```

### 21.15 Codeforces 1295D Same GCDs

**题目**: 给定 $a, m$, 求 $x \in [0, m)$ 使 $\gcd(a, m) = \gcd(a+x, m)$ 的个数。

**思路**: 令 $g = \gcd(a, m)$, 等价于 $\gcd((a+x)/g, m/g) = 1$ 且 $x < m$。设 $M' = m/g$, 求 $[0, M')$ 中与 $M'$ 互质的数个数, 即 $\varphi(M')$。

```python
def same_gcds(a, m):
    from math import gcd
    g = gcd(a, m)
    M = m // g
    # 求 φ(M)
    phi = M
    p = 2
    while p * p <= M:
        if M % p == 0:
            while M % p == 0:
                M //= p
            phi -= phi // p
        p += 1
    if M > 1:
        phi -= phi // M
    return phi
```

### 21.26 LeetCode 952 按公因数计算最大组件大小

**题目**: 给定数组, 若两数有大于 1 的公因数就连边, 求最大连通分量大小。

**思路**: 并查集 + 质因数分解。

```python
def largestComponentSize(nums):
    from collections import defaultdict

    parent = {}
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    def union(x, y):
        rx, ry = find(x), find(y)
        if rx != ry:
            parent[rx] = ry

    for x in nums:
        parent[x] = x

    prime_to_num = defaultdict(int)
    for x in nums:
        y = x
        p = 2
        while p * p <= y:
            if y % p == 0:
                prime_to_num[p] = x if p not in prime_to_num else \
                                  union(prime_to_num[p], x)
                while y % p == 0:
                    y //= p
            p += 1
        if y > 1:
            prime_to_num[y] = x if y not in prime_to_num else \
                              union(prime_to_num[y], x)

    size = defaultdict(int)
    for x in nums:
        size[find(x)] += 1
    return max(size.values())
```

### 21.27 LeetCode 1627 带阈值的图连通性

**题目**: $n$ 个城市, 若两城市编号最大公约数 > threshold 则连边, 问两城市是否连通。

**思路**: 并查集, 枚举公因数。

```python
def areConnected(n, threshold, queries):
    parent = list(range(n + 1))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    def union(x, y):
        rx, ry = find(x), find(y)
        if rx != ry: parent[rx] = ry

    for d in range(threshold + 1, n + 1):
        for k in range(2, n // d + 1):
            union(d, d * k)

    return [find(u) == find(v) for u, v in queries]
```

### Q23.1: 为什么 $\gcd$ 在 Stein 算法中用移位和减法?

Stein 算法 (二进制 GCD) 利用二进制表示和 $\gcd$ 的性质:
- $\gcd(2a, 2b) = 2\gcd(a,b)$
- $\gcd(2a, b) = \gcd(a, b)$ (b 奇)
- $\gcd(a-b, b) = \gcd(a, b)$

移位和减法避免了昂贵的 `%` 操作, 在某些硬件/软件上更快。

### Q23.2: 欧几里得算法为什么是最优的?

这是关于"步数下界"的问题。Fibonacci 数列相邻项给出最坏情况, 此时步数约为 $\log_\varphi n$。任何基于减法的算法在最坏情况下都不比欧几里得更好。

### Q23.3: 矩阵快速幂的空间优化?

可以把单位矩阵和平方结果存为变量, 节省空间。但空间通常不是瓶颈, 时间是。

### Q23.4: 为什么 C++ 要用 long long 而 Python 不用?

C++ `long long` 是 64 位, 上限约 $9.2 \times 10^{18}$。Python `int` 是任意精度, 自动扩展。

### Q23.5: CRT 和 Garner's Algorithm 有什么区别?

CRT 假设模数互质, 解唯一。Garner's Algorithm 用于不互质情形, 或对效率更敏感的场景 (O(n) vs O(n log n))。

### Q23.6: 如何证明 GCD 算法正确性?

数学归纳法:
- 基础: $\gcd(a, 0) = a$ 显然。
- 归纳: 假设对 $(b, a\%b)$ 正确, 由 $a = kb + (a\%b)$, 故 $\gcd(a, b) = \gcd(b, a\%b)$。

### Q23.7: GCD 与质因数分解的关系?

$\gcd$ 可以用质因数分解计算: $\gcd(\prod p_i^{a_i}, \prod p_i^{b_i}) = \prod p_i^{\min(a_i, b_i)}$。但反过来, GCD 不能直接分解质因数。

### Q23.8: 大数的 GCD 用 Python 会不会慢?

Python `math.gcd` 是 C 实现, 对任意大小整数都很快 (基于 Lehmer GCD 或递归减法)。实测 $10^{100}$ 量级也毫秒级。

### Q23.9: 拓展 CRT 的复杂度?

每次合并两个同余方程, 用扩展欧几里得 $O(\log \max(m_i))$, 总共 $O(n \log \max(m_i))$。

```python
def test_inv(method):
```

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。

**7. 实践建议**

结合 "数论基础 (GCD/快速幂/逆元)" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "数论基础 (GCD/快速幂/逆元)" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
