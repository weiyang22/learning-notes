## 1. 概率 DP vs 期望 DP

### 1.1 根本区别

| 类型 | $f[state]$ 含义 | 递推方向 | 边界条件 |
| :--- | :--- | :--- | :--- |
| **概率 DP** | 到达该状态的概率 | **正推** (从起点) | $f[start] = 1$ |
| **期望 DP** | 从该状态到终点的期望代价 | **倒推** (从终点) | $f[goal] = 0$ |

> **记忆口诀**: 概率顺着走 (起点固定), 期望倒着推 (终点固定)。

### 1.2 为什么期望要倒推?

期望定义 $E[X] = \sum x \cdot P(x)$, 在 DP 中, $E[\text{state}]$ 自然包含"未来"信息。从未来推现在, 边界最自然 (终点期望 = 0)。

### 1.3 经典题型分类

- **抛硬币/骰子**: 概率 DP, 累计到达每面/每点数的概率。
- **到达终点步数**: 期望 DP, 倒推 $E[i]$。
- **收集问题**: Coupon Collector, 期望的线性性。
- **随机游走**: 期望 DP + 边界条件。
- **博弈期望**: 双方最优策略下的期望。

## 2. 概率 DP 正推模板

### 2.1 核心公式

$$f[\text{state}] = \sum_{\text{transition}} P(\text{transition}) \cdot f[\text{prev\_state}]$$

即每个状态的概率 = 所有可能转移到的前驱状态的概率之和。

### 2.2 例: 走到第 $n$ 步的概率分布

```python
def prob_dist(n, p_step=0.5):
    """n 步后位置的概率分布, 每次 ±1 等概率"""
    f = [[0.0] * (2*n + 1) for _ in range(n + 1)]
    f[0][n] = 1.0    # 起点 0 (数组中点)
    for i in range(n):
        for j in range(1, 2*n):
            if f[i][j] > 0:
                if j > 0: f[i+1][j-1] += f[i][j] * 0.5
                if j < 2*n: f[i+1][j+1] += f[i][j] * 0.5
    return f[n]
```

### 2.3 例: 抛硬币正面次数的概率分布

```python
def coin_prob(n, p=0.5):
    """n 次抛硬币, k 次正面的概率 (二项分布)"""
    f = [0.0] * (n + 1)
    f[0] = 1.0
    for i in range(n):
        nf = [0.0] * (n + 1)
        for k in range(n):
            if f[k] > 0:
                nf[k] += f[k] * (1 - p)
                nf[k+1] += f[k] * p
        f = nf
    return f
```

### 2.4 例: 骰子点数之和

```python
def dice_sum(n, faces=6):
    """n 个骰子点数之和 s 的概率"""
    f = [0.0] * (n * faces + 1)
    f[0] = 1.0
    for i in range(n):
        nf = [0.0] * (n * faces + 1)
        for s in range(i * 1, i * faces + 1):     # 当前可能的和
            if f[s] > 0:
                for face in range(1, faces + 1):
                    nf[s + face] += f[s] / faces
        f = nf
    return f
```

**复杂度**: $O(n^2 \cdot \text{faces})$。

## 3. 期望 DP 倒推模板

### 3.1 核心公式

$$E[\text{state}] = \sum_{\text{transition}} P(\text{transition}) \cdot (1 + E[\text{next\_state}])$$

或者, 若有吸收态 (立即终止):

$$E[\text{state}] = \sum_{\text{transition}} P(\text{transition}) \cdot (1 + E[\text{next\_state}])$$

(1 表示走一步的代价)

### 3.2 标准模板 (无自环)

```python
def expected_steps(n, p):
    """从 i 每步以 p 概率前进 1, 求到 n 的期望步数, f[n]=0"""
    f = [0.0] * (n + 1)
    for i in range(n - 1, -1, -1):
        f[i] = 1 + p * f[i + 1] + (1 - p) * f[i + 1]    # 注: 此处假设不后退
    return f[0]
```

### 3.3 含自环的方程求解

当 $f[i]$ 出现在等式两边时, 需要代数移项:

```python
def expected_steps_with_back(n, p_forward, p_back):
    """每步以 p_forward 前进, p_back 后退, (1-p_forward-p_back) 留在原地"""
    f = [0.0] * (n + 1)
    for i in range(n - 1, -1, -1):
        # f[i] = 1 + p_f * f[i+1] + p_b * f[i-1] + p_stay * f[i]
        # f[i] - p_stay * f[i] = 1 + p_f * f[i+1] + p_b * f[i-1]
        # f[i] * (1 - p_stay) = 1 + p_f * f[i+1] + p_b * f[i-1]
        # f[i] = (1 + p_f * f[i+1] + p_b * f[i-1]) / (1 - p_stay)
        p_stay = 1 - p_forward - p_back
        if i == 0:
            # 边界: 不后退
            f[0] = (1 + p_forward * f[1]) / (p_forward + p_stay)
        elif i == n:
            f[n] = 0
        else:
            f[i] = (1 + p_forward * f[i+1] + p_back * f[i-1]) / (1 - p_stay)
    return f[0]
```

### 3.4 矩阵形式 (大型转移)

$$E[i] = \mathbf{1} + P \cdot E$$

$$\Rightarrow E = (I - P)^{-1} \mathbf{1}$$

```python
import numpy as np
def expected_via_matrix(transition_matrix):
    """transition_matrix[i][j] = P(i -> j), 不包括留在原地"""
    n = transition_matrix.shape[0]
    P = transition_matrix.copy()
    I = np.eye(n)
    E = np.linalg.inv(I - P) @ np.ones(n)
    return E
```

## 4. 期望的线性性(最强武器)

### 4.1 定理

$$E[X + Y] = E[X] + E[Y]$$

**无论 $X, Y$ 是否独立都成立!**

### 4.2 经典: Coupon Collector (收集邮票)

集齐 $n$ 种邮票的期望抽取次数:

$$E = n \cdot H_n = n \sum_{i=1}^{n} \frac{1}{i} \approx n \ln n + \gamma n$$

**线性性推导**:

```text
E = Σ E[本次抽到新种所需次数 | 已有 i-1 种]
  = Σ n / (n - i + 1)  for i = 1 to n
  = Σ n / j             for j = n, n-1, ..., 1
  = n * Σ 1/j
```

```python
def coupon_collector_expected(n):
    """返回期望抽取次数"""
    return n * sum(1.0 / i for i in range(1, n + 1))

# 验证: n=1 期望 1 次, n=2 期望 3 次, n=3 期望 5.5 次
```

### 4.3 例: 抛硬币直到出现连续 k 个正面

设 $E_i$ = 已连续 $i$ 个正, 期望再抛多少次到达 $k$。

$E_i = 1 + \frac{1}{2} E_{i+1} + \frac{1}{2} E_0$ (其中 $E_k = 0$)

由对称性, $E_0 = E_1 = \dots = E_{k-1}$, 代入得 $E_0 = 2^{k+1} - 2$。

```python
def consecutive_heads_expected(k):
    return 2**(k+1) - 2

# 验证: k=1 → 2 (再抛一次得到正面), k=2 → 6, k=3 → 14
```

### 4.4 例: 排队问题

顾客到达率 $\lambda$, 服务率 $\mu$, 期望队长 $L = \rho / (1 - \rho)$ (M/M/1), 其中 $\rho = \lambda / \mu$。

(连续情形, 离散 DP 类似处理)

### 4.5 例: 等待时间的线性性

```python
def expected_wait_for_first_success(p):
    """伯努利试验, 首次成功期望次数 = 1/p"""
    return 1.0 / p

# 期望线性性: E[总次数] = E[每次成功之间间隔] 之和
```

### 4.6 例: 期望路径长度

```python
def expected_path_in_dag(adj, start, end):
    """DAG 中从 start 到 end 的期望路径长度, 每条出边等概率"""
    n = len(adj)
    E = [0.0] * n
    E[end] = 0

    # 拓扑排序
    from collections import deque
    indeg = [0] * n
    for u in range(n):
        for v in adj[u]:
            indeg[v] += 1
    q = deque([u for u in range(n) if indeg[u] == 0])
    topo = []
    while q:
        u = q.popleft()
        topo.append(u)
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)

    # 倒推 (topo 顺序已经是 DAG 顺序)
    for u in reversed(topo):
        if u == end: continue
        if not adj[u]: continue
        prob = 1.0 / len(adj[u])
        for v in adj[u]:
            E[u] += prob * (1 + E[v])
    return E[start]
```

## 5. 经典概率模型与公式

### 5.1 伯努利试验

$n$ 次独立试验, 每次成功概率 $p$, 总成功次数 $X \sim B(n, p)$:

$$E[X] = np, \quad \text{Var}(X) = np(1-p)$$

### 5.2 几何分布

首次成功时间 $X$, 每次成功概率 $p$:

$$E[X] = 1/p, \quad \text{Var}(X) = (1-p)/p^2$$

### 5.3 泊松分布

$\lambda = $ 单位时间事件率, 事件数 $X \sim \text{Poi}(\lambda)$:

$$E[X] = \lambda$$

### 5.4 指数分布

$T \sim \text{Exp}(\lambda)$:

$$E[T] = 1/\lambda, \quad P(T > s+t | T > s) = P(T > t) \quad (\text{无记忆})$$

### 5.5 均匀分布

$U \sim U(a, b)$:

$$E[U] = (a+b)/2, \quad \text{Var}(U) = (b-a)^2/12$$

### 5.6 正态分布

$X \sim N(\mu, \sigma^2)$:

$$E[X] = \mu, \quad P(|X - \mu| > 2\sigma) \approx 0.05$$

## 6. 经典例题精讲

### 6.1 例 1: 连续 k 个正面的期望次数

**题目**: 抛硬币, 求出现连续 $k$ 个正面的期望次数。

**解法一: 线性性**

每次抛硬币, 设当前已连续 $i$ 个正, 还差 $k-i$ 个就到目标。从状态 $i$ 出发, 每次抛:

- 正面 ($p=1/2$): 进入状态 $i+1$ (若 $i+1 = k$ 则完成)
- 反面 ($p=1/2$): 重置为状态 $0$

由状态对称性, $E_0 = E_1 = \dots = E_{k-1}$, 故:

$$E_0 = 1 + \frac{1}{2} E_0 + \frac{1}{2} E_0 = 1 + E_0$$

但这不对! 等等, 实际上 $E_i$ 满足:

$$E_i = 1 + \frac{1}{2} E_{i+1} + \frac{1}{2} E_0, \quad E_k = 0$$

由于 $i < k$ 时再次抛掷, 失败重置。设 $E = E_0 = E_1 = \dots = E_{k-1}$ (由对称性, 仅当转移到 $k$ 才结束):

$$E = 1 + \frac{1}{2} (k - 1 - i + 1) E_i + \frac{1}{2} E_0$$

不对, 这里要看具体转移。重新推导:

对于 $i < k$, 每次抛掷:
- 正面 (p=1/2): 进入 $i+1$
- 反面 (p=1/2): 重置到 $0$

所以 $E_i = 1 + \frac{1}{2} E_{i+1} + \frac{1}{2} E_0$, 其中 $E_k = 0$。

代入 $i = k-1$: $E_{k-1} = 1 + \frac{1}{2} \cdot 0 + \frac{1}{2} E_0 = 1 + \frac{1}{2} E_0$。

代入 $i = k-2$: $E_{k-2} = 1 + \frac{1}{2} E_{k-1} + \frac{1}{2} E_0$。

一般地, 我们要解出 $E_0$。通过递推消去:

设 $E_i = a_i + b_i E_0$, 则:
- $E_k = 0 \Rightarrow a_k = 0, b_k = 0$
- $E_i = 1 + \frac{1}{2}(a_{i+1} + b_{i+1} E_0) + \frac{1}{2} E_0 = (1 + \frac{1}{2} a_{i+1}) + (\frac{1}{2} b_{i+1} + \frac{1}{2}) E_0$

故 $a_i = 1 + \frac{1}{2} a_{i+1}$, $b_i = \frac{1}{2} b_{i+1} + \frac{1}{2}$。

解: $a_i = 2(1 - (1/2)^{k-i})$ (待定), $b_i = 1 - (1/2)^{k-i}$。

由 $b_0 = 1$ (因为 $E_0 = a_0 + b_0 E_0$, 必须 $b_0 = 1$ 否则无解):

$b_0 = 1 - (1/2)^k = 1$? 不对。

修正: 由对称性 $E_0 = E_1 = \dots = E_{k-1}$ (直觉: 状态 $0$ 和 $1, 2, \dots, k-1$ 都不在末尾, 期望"还要"多少步)。

等等, 这个对称性不对。实际上 $E_i$ 不等于 $E_{i-1}$。重新思考。

假设 $E_0 = E_1 = \dots = E_{k-1}$。若如此, 由 $E_{k-1} = 1 + \frac{1}{2} \cdot 0 + \frac{1}{2} E_0 = 1 + \frac{1}{2} E_0$:

$E_0 = 1 + \frac{1}{2} E_0 \Rightarrow E_0 = 2$? 这仅对 $k=1$ 成立。

**错误结论**。重新严格推导:

$E_0 = 1 + \frac{1}{2} E_1 + \frac{1}{2} E_0$ → $\frac{1}{2} E_0 = 1 + \frac{1}{2} E_1$ → $E_0 = 2 + E_1$

$E_1 = 1 + \frac{1}{2} E_2 + \frac{1}{2} E_0$

...

$E_{k-2} = 1 + \frac{1}{2} E_{k-1} + \frac{1}{2} E_0$

$E_{k-1} = 1 + \frac{1}{2} \cdot 0 + \frac{1}{2} E_0 = 1 + \frac{1}{2} E_0$

由最后一个: $E_0 = 2 + E_1$, $E_1 = 2 + E_2$, ..., $E_{k-2} = 2 + E_{k-1}$。

代入 $E_{k-1} = 1 + \frac{1}{2} E_0$:

$E_{k-2} = 2 + 1 + \frac{1}{2} E_0 = 3 + \frac{1}{2} E_0$

$E_{k-3} = 4 + \frac{1}{2} E_0$

...

$E_0 = (2k - 1) + \frac{1}{2} E_0$

$\frac{1}{2} E_0 = 2k - 1$

$E_0 = 4k - 2 = 2(2k - 1)$

**验证**: $k=1 \Rightarrow E_0 = 2$ ✓ (一次抛硬币得到正面的期望 = 1/p = 2)

$k=2 \Rightarrow E_0 = 6$ ✓

```python
def consecutive_heads(k):
    return 2 * (2*k - 1)
```

### 6.2 例 2: 随机游走从 0 到 n, 无边界

**题目**: 每步 ±1 等概率, 从 0 到 $n$ 的期望步数。

**解法**: 设 $E[i]$ = 从 $i$ 到 $n$ 的期望步数。

$E[n] = 0$

$E[i] = 1 + \frac{1}{2} E[i+1] + \frac{1}{2} E[i-1]$

这是线性递推, 特征方程 $r^2 - 2r + 1 = 0$, 重根 $r=1$, 通解 $E[i] = A + Bi$。

由 $E[n]=0$: $A + Bn = 0$。

由 $E[0] = ?$: 实际上, 随机游走是无界的, 从 $0$ 出发到达 $n$ 期望无穷? 不对, 是有限。

设 $E[0] = X$, $E[i] = X + (X - E[0]) \cdot \frac{i}{n}$? 不对。

实际上, 解二阶常系数递推:

$E[i] - 2 E[i-1] + E[i-2] = -2$ (将原方程整理)

特解: $E[i] = -i^2 + Ci + D$ (因右边常数)

代入: $-i^2 + Ci + D - 2(-(i-1)^2 + C(i-1) + D) + (-(i-2)^2 + C(i-2) + D) = -2$

化简: $-2 = -2$ ✓ (恒等)

边界: $E[n] = 0, E[0] = ?$

**等等**, 随机游走无界 (可能往负方向走), 期望不一定有限。

**修正**: 加入左边界 $0$, 即到达 $-1$ 则反弹回 $0$ (吸收/反射边界)。

**反射边界**: 到达 $0$ 时自动回 $1$, 则:

$E[0] = 1 + E[1]$ (立即反弹)

$E[i] = 1 + \frac{1}{2} E[i+1] + \frac{1}{2} E[i-1]$ for $0 < i < n$

$E[n] = 0$

解: 通解 $E[i] = -i^2 + Ci + D$。

$E[n] = -n^2 + Cn + D = 0$ → $D = n^2 - Cn$

$E[1] = -1 + C + D = -1 + C + n^2 - Cn$

$E[0] = 1 + E[1] = C + n^2 - Cn$

由递推 $E[i] = 1 + \frac{1}{2} E[i+1] + \frac{1}{2} E[i-1]$, 代入 $i=1$:

$E[1] = 1 + \frac{1}{2} E[2] + \frac{1}{2} E[0]$

$E[2] = -4 + 2C + D$

$E[1] + E[0] = -1 + C + D + C + n^2 - Cn = -1 + 2C + n^2 - Cn + D$

代入 D: $-1 + 2C + n^2 - Cn + n^2 - Cn = -1 + 2C + 2n^2 - 2Cn$

$2(E[1] + E[0])/2 = E[1] + E[0]$... 这有点复杂, 直接用代码:

```python
def random_walk_reflect(n):
    """随机游走从 0 到 n, 左边界反射, 求期望步数"""
    E = [0.0] * (n + 1)
    E[n] = 0
    for i in range(n - 1, 0, -1):
        E[i] = 1 + 0.5 * E[i+1] + 0.5 * E[i-1]
    E[0] = 1 + E[1]    # 反射边界
    return E[0]

# 验证: n=1 → 2, n=2 → 6, n=3 → 12
```

### 6.3 例 3: 集合覆盖 / Coupon Collector

**题目**: $n$ 种邮票, 每次随机抽一张 (有放回), 求集齐所有种的期望次数。

**解法**: 期望的线性性。

设 $X$ = 总次数。$X = X_1 + X_2 + \dots + X_n$, 其中 $X_i$ = 从已有 $i-1$ 种到集齐 $i$ 种所需次数。

$X_i$ 服从几何分布, 成功概率 $p_i = (n - i + 1)/n$:

$$E[X_i] = \frac{n}{n - i + 1}$$

$$E[X] = \sum_{i=1}^{n} \frac{n}{n - i + 1} = n \sum_{j=1}^{n} \frac{1}{j} = n H_n$$

```python
def coupon_collector(n):
    return n * sum(1/i for i in range(1, n+1))

# n=10 → 29.29, n=100 → 518.7
```

### 6.5 例 5: 连续两次正面之前期望反面数

设 $X$ = 连续两次正面之前期望反面数。

$E[X] = \frac{1}{2} \cdot 0 + \frac{1}{2}(1 + E[\text{再等到两次正面}])$

由对称性 $E[\text{再等到两次正面}] = 2 + E[X]$ (因为等到的过程中可能反面)。

不对, 重新推导。设状态:
- $S_0$: 还没正面
- $S_1$: 1 个正面
- $S_2$: 2 个正面 (终止)

$E[S_0] = 0$ (还没计数)

$E[X | S_0 \to S_0] = $ 等到 1 个正面期间的反面数 = $\frac{1}{2}(1) + \frac{1}{2}(0) = 0.5$。

等等, 这要更细: $E[\text{反面数} | \text{从 } S_0 \text{ 开始到 } S_2]$.

设 $R_i$ = 从状态 $i$ 到 $S_2$ 期间的期望反面数。

$R_2 = 0$

$R_1$: 抛一次, $\frac{1}{2}$ 进 $R_2$ (0 反面), $\frac{1}{2}$ 回 $R_0$ 加 1 反面。

$R_1 = \frac{1}{2} \cdot 0 + \frac{1}{2}(1 + R_0) = \frac{1}{2} + \frac{1}{2} R_0$

$R_0$: 抛一次, $\frac{1}{2}$ 进 $R_1$ (0 反面), $\frac{1}{2}$ 留 $R_0$ 加 1 反面。

$R_0 = \frac{1}{2} \cdot 0 + \frac{1}{2}(1 + R_0)$

$R_0 - \frac{1}{2} R_0 = \frac{1}{2}$

$R_0 = 1$

$R_1 = \frac{1}{2} + \frac{1}{2} = 1$

答案: 期望 1 个反面。

### 6.7 例 7: 抛硬币期望盈利

**题目**: 抛硬币, 正面赢 $a$, 反面输 $b$, 直到盈利 $T$ 或破产 $0$。

设 $E[i]$ = 当前资金 $i$ 时, 达到 $T$ 或 $0$ 的期望步数。

$E[0] = 0$, $E[T] = 0$

$E[i] = 1 + \frac{1}{2} E[i+a] + \frac{1}{2} E[i-b]$ (需 $i+b \le T$, 否则破产)

```python
def gambler_ruin(T, a=1, b=1, p=0.5):
    """赌徒破产, 每次赢 a 或输 b, p 为赢概率"""
    E = [0.0] * (T + 1)
    # E[T] = 0 (达到目标)
    # E[0] = 0 (破产)
    for i in range(T - 1, 0, -1):
        up = min(i + a, T)
        down = max(i - b, 0)
        if i + a >= T:
            E[i] = 1 + p * 0 + (1-p) * E[down]
        elif i - b <= 0:
            E[i] = 1 + p * E[up] + (1-p) * 0
        else:
            E[i] = 1 + p * E[up] + (1-p) * E[down]
    return E
```

**题目**: 给定无向图, 每条边有成功率, 求从 start 到 end 成功率最大的路径。

```python
import heapq
def maxProbability(n, edges, succProb, start, end):
    adj = [[] for _ in range(n)]
    for (u, v), p in zip(edges, succProb):
        adj[u].append((v, p))
        adj[v].append((u, p))

    prob = [0.0] * n
    prob[start] = 1.0
    heap = [(-1.0, start)]
    while heap:
        neg_p, u = heapq.heappop(heap)
        p = -neg_p
        if p < prob[u]: continue
        if u == end: return p
        for v, edge_p in adj[u]:
            new_p = p * edge_p
            if new_p > prob[v]:
                prob[v] = new_p
                heapq.heappush(heap, (-new_p, v))
    return 0.0
```

**对数化**: $\max \prod p_i = \max \sum \log p_i$, 用 Dijkstra 解。

```python
def expectation_dag(adj, n):
    E = [0.0] * (n + 1)
    E[n] = 0

    # 拓扑排序
    from collections import deque
    indeg = [0] * (n + 1)
    for u in range(1, n + 1):
        for v, _ in adj[u]:
            indeg[v] += 1

    q = deque([u for u in range(1, n+1) if indeg[u] == 0])
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v, _ in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)

    # 倒推
    for u in reversed(order):
        if u == n: continue
        if not adj[u]:
            continue
        prob = 1.0 / len(adj[u])
        for v, w in adj[u]:
            E[u] += prob * (w + E[v])
    return E[1]
```

**题目**: $n$ 种 bug, $s$ 个子系统, 每天随机一个 bug。求集齐所有 $n$ 种、$s$ 个子系统的期望天数。

```python
def collecting_bugs(n, s):
    """期望天数 = n*s * H_{n*s} (类似 coupon collector)"""
    from fractions import Fraction
    # 实际公式较复杂, 用 DP
    dp = [[Fraction(0)] * (s+1) for _ in range(n+1)]
    for i in range(n, -1, -1):
        for j in range(s, -1, -1):
            if i == n and j == s:
                continue
            # dp[i][j] = 1 + (n-i)(s-j)/(ns) * dp[i+1][j+1]
            #          + (n-i)*j/(ns) * dp[i+1][j]
            #          + i*(s-j)/(ns) * dp[i][j+1]
            #          + i*j/(ns) * dp[i][j]  ← 自环, 移项
            remain = n*s - i*j
            if remain == 0:
                continue
            E_next = Fraction(1)
            if i < n and j < s:
                E_next += (n-i)*(s-j) * dp[i+1][j+1] / (n*s)
            if i < n and j >= 1:
                E_next += (n-i)*j * dp[i+1][j] / (n*s)
            if i >= 1 and j < s:
                E_next += i*(s-j) * dp[i][j+1] / (n*s)
            dp[i][j] = E_next * (n*s) / (i*j) if i*j > 0 else E_next
    return dp[0][0]
```

### 10.4 解法三: 不动点迭代

```python
def fixed_point_iteration(transition, n, max_iter=1000, eps=1e-9):
    """E_new = 1 + T @ E_old"""
    E = np.zeros(n)
    for _ in range(max_iter):
        E_new = 1 + transition @ E
        if np.max(np.abs(E_new - E)) < eps:
            return E_new
        E = E_new
    return E
```

- 概率 DP 正推: $O(n \cdot |\text{transition}|)$
- 期望 DP 倒推: 同上
- 含自环: $O(n \cdot |\text{transition}|)$ 一次移项即可
- 高斯消元: $O(n^3)$
- 不动点迭代: $O(n^2 \cdot \text{iter})$

### 12.2 空间优化

滚动数组: $O(n)$ 空间, 而非 $O(n^2)$。

```python
# 完整 DP

    for i in range(n):
        # ...

# 滚动数组 (只需上一行)
dp_prev = [0.0] * n
for step in range(K):
    dp_curr = [0.0] * n
    for i in range(n):
        # ...
    dp_prev = dp_curr
```

### 12.3 NumPy 加速

```python
import numpy as np
def fast_prob_dp(P, K, start, n):
    """P: n×n 转移矩阵, K 步, start 起点"""
    state = np.zeros(n)
    state[start] = 1.0
    for _ in range(K):
        state = P.T @ state    # 转移
    return state
```

```python
    """值迭代求最优价值"""
    V = np.zeros(n)
    for _ in range(1000):
        V_new = np.zeros(n)

            for a in range(P.shape[1]):
```

```python
def ab_test_sample_size(baseline, mde, alpha=0.05, power=0.8):
    """A/B 测试所需样本量"""
    from scipy.stats import norm
    p1, p2 = baseline, baseline + mde
    p_avg = (p1 + p2) / 2
    z_alpha = norm.ppf(1 - alpha / 2)
    z_beta = norm.ppf(power)
    n = (z_alpha * math.sqrt(2 * p_avg * (1 - p_avg)) +
         z_beta * math.sqrt(p1*(1-p1) + p2*(1-p2)))**2 / (mde**2)
    return math.ceil(n)
```

### 13.5 期望最大化 (EM) 算法

```python
def em_gaussian_mixture(X, k, max_iter=100):
    """高斯混合模型的 EM 算法"""
    n, d = X.shape
    # 初始化
    mu = X[np.random.choice(n, k, replace=False)]
    sigma = np.array([np.eye(d)] * k)
    pi = np.ones(k) / k

    for _ in range(max_iter):
        # E-step: 计算责任度
        resp = np.zeros((n, k))
        for j in range(k):
            resp[:, j] = pi[j] * gaussian_pdf(X, mu[j], sigma[j])
        resp /= resp.sum(axis=1, keepdims=True)

        # M-step: 更新参数
        N_k = resp.sum(axis=0)
        pi = N_k / n
        for j in range(k):
            mu[j] = (resp[:, j:j+1] * X).sum(axis=0) / N_k[j]
            diff = X - mu[j]
            sigma[j] = (resp[:, j:j+1] * diff).T @ diff / N_k[j]

    return mu, sigma, pi
```

## 14. 面试高频问答

### Q1: 概率 DP 为什么要正推? 期望 DP 为什么要倒推?

**答**: 概率 $f[state]$ = 到达该状态的概率, 起点固定 ($f[start]=1$), 从前推向后。期望 $f[state]$ = 从该状态到终点的期望, 终点固定 ($f[goal]=0$), 从后推向前。两者边界条件最自然的方向决定了递推方向。

### Q2: 期望的线性性为什么不要独立性?

**答**: $E[X+Y] = E[X] + E[Y]$ 是概率公理的直接推论 (无论是否独立), 由求和的线性性保证。独立性只用于 $E[XY] = E[X]E[Y]$ 这种乘积情形。

### Q3: 转移有自环怎么办?

**答**: 把 $f[i]$ 移到一边解方程。例如 $f[i] = c + p f[i+1] + q f[i-1] + r f[i]$, 移项得 $f[i] = (c + p f[i+1] + q f[i-1]) / (1 - r)$。

### Q4: 怎样快速判断该用概率 DP 还是期望 DP?

**答**:
- 题目问"概率/可能性" → 概率 DP。
- 题目问"期望步数/期望代价/期望次数" → 期望 DP。
- 题目问"最大概率路径" → 改用最短路 (Dijkstra), 把概率取对数。

### Q5: 高斯消元什么时候用?

**答**: 状态数小 (< 300) 且转移复杂, 含自环且不能简单移项时。

### Q6: Coupon Collector 的变种?

**答**:
- 加权 coupon: 不同邮票概率不同, 期望 = $\int_0^\infty (1 - \prod(1 - e^{-p_i t})) dt$。
- 部分收集: 集齐 $k < n$ 种的期望。

### Q7: 期望的样本均值?

**答**: 大数定律, 样本均值依概率收敛到期望。模拟验证时用大 $n$。

### Q8: 概率 DP 的边界条件?

**答**: 起点概率 $= 1$, 其他点 $= 0$。终态概率累加得到答案。

### Q9: 期望 DP 的边界条件?

**答**: 终态期望 $= 0$。起点期望 = 答案。

### Q10: 什么是 Markov 链?

**答**: 下一状态只依赖当前状态, 不依赖历史。$P(s_{t+1} | s_t, s_{t-1}, \dots) = P(s_{t+1} | s_t)$。DP 的概率/期望模型本质上是 Markov 链。

### Q11: 蒙特卡洛和 DP 哪个更快?

**答**:
- 状态数小时 DP 快 (精确)。
- 状态空间巨大 (围棋) 时蒙特卡洛可行。
- DP 提供精确值, 蒙特卡洛只给估计。

### Q12: 概率题中, 题目说"至少一个"怎么办?

**答**: $P(\text{至少一个}) = 1 - P(\text{全否})$。

### Q13: 期望的方差怎么算?

**答**: $\text{Var}(X) = E[X^2] - (E[X])^2$。可以在 DP 中加一个二阶矩 $E[X^2]$, 用同样方法递推。

### Q14: 什么是鞅 (Martingale)?

**答**: $E[X_{t+1} | X_t] = X_t$。例如公平赌博的财富过程。可用于简化期望计算。

### Q15: 在大厂面试中, 概率/期望题目的难度?

**答**:
- 初级: 概率公式 + 简单 DP
- 中级: 倒推 + 自环移项
- 高级: Markov 链 + 蒙特卡洛 + 强化学习关联

```python
def precise_dp(n, p):

    f[n-1] = Fraction(0)
    for i in range(n - 2, -1, -1):
        f[i] = (1 + Fraction(p) * f[i+1]) / Fraction(p)
    return f[0]
```

## 17. 实战模板合集

### 17.1 概率 DP 通用模板

```python
def prob_dp_template(transition_func, n, start, target):
    """通用概率 DP 正推模板"""
    dp = [0.0] * n
    dp[start] = 1.0
    for step in range(n):
        ndp = [0.0] * n
        for i in range(n):
            if dp[i] == 0: continue
            for j, p in transition_func(i):
                ndp[j] += dp[i] * p
        dp = ndp
    return sum(dp[i] for i in target)
```

### 17.2 期望 DP 通用模板

```python
def expectation_dp_template(transition_func, n, terminal):
    """通用期望 DP 倒推模板"""
    dp = [0.0] * n
    for i in terminal:
        dp[i] = 0
    for i in range(n - 1, -1, -1):
        if i in terminal: continue
        # 自环检测: 若 transition(i) 含 i, 移项
        terms = []
        self_prob = 0
        for j, p in transition_func(i):
            if j == i:
                self_prob += p
            else:
                terms.append((dp[j], p))
        # dp[i] = 1 + sum(p * dp[j] for j, p in terms) + self_prob * dp[i]
        # dp[i] (1 - self_prob) = 1 + sum(p * dp[j] for j, p in terms)
        rhs = 1 + sum(p * val for val, p in terms)
        dp[i] = rhs / (1 - self_prob)
    return dp
```

### 17.3 含自环的版本

```python
def expectation_dp_with_self_loop(transition_func, n, terminal):
    """含自环的期望 DP"""
    dp = [None] * n
    for i in terminal:
        dp[i] = 0
    # 高斯消元
    A = [[0.0]*n for _ in range(n)]
    b = [1.0]*n
    for i in range(n):
        if i in terminal:
            A[i][i] = 1.0
            b[i] = 0
        else:
            A[i][i] = 1
            for j, p in transition_func(i):
                A[i][j] = -p
    return np.linalg.solve(np.array(A), np.array(b))
```

## 19. 强化学习中的期望 DP (拓展)

### 19.1 MDP 基础

MDP 五元组 $(S, A, P, R, \gamma)$:
- $S$: 状态空间
- $A$: 动作空间
- $P(s'|s,a)$: 转移概率
- $R(s,a)$: 奖励
- $\gamma$: 折扣因子

### 19.2 Bellman 期望方程

$$V^\pi(s) = \sum_a \pi(a|s) \sum_{s'} P(s'|s,a)[R(s,a) + \gamma V^\pi(s')]$$

### 19.3 值迭代

```python
def value_iteration(env, gamma=0.99, theta=1e-6, max_iter=1000):
    V = np.zeros(env.n_states)
    for _ in range(max_iter):
        delta = 0
        for s in range(env.n_states):
            v = V[s]
            V[s] = max(
                sum(env.P[s][a] * (env.R[s][a] + gamma * V[s_next])
                    for s_next in env.transitions(s, a))
                for a in env.actions(s)
            )
            delta = max(delta, abs(v - V[s]))
        if delta < theta:
            break
    return V
```

### 19.4 策略迭代

```python
def policy_iteration(env, gamma=0.99, theta=1e-6):
    pi = np.zeros(env.n_states, dtype=int)
    for _ in range(100):
        # 策略评估
        V = np.zeros(env.n_states)
        while True:
            delta = 0
            for s in range(env.n_states):
                v = V[s]
                V[s] = sum(env.P[s][pi[s]] * (env.R[s][pi[s]] + gamma * V[s_next])
                           for s_next in env.transitions(s, pi[s]))
                delta = max(delta, abs(v - V[s]))
            if delta < theta:
                break

        # 策略改进
        policy_stable = True
        for s in range(env.n_states):
            old_action = pi[s]
            pi[s] = np.argmax([
                sum(env.P[s][a] * (env.R[s][a] + gamma * V[s_next])
                    for s_next in env.transitions(s, a))
                for a in env.actions(s)
            ])
            if old_action != pi[s]:
                policy_stable = False
        if policy_stable:
            break
    return pi, V
```

### 19.5 Q-learning

```python
def q_learning(env, alpha=0.1, gamma=0.99, epsilon=0.1, episodes=1000):
    Q = np.zeros((env.n_states, env.n_actions))
    for _ in range(episodes):
        s = env.reset()
        done = False
        while not done:
            if random.random() < epsilon:
                a = random.randint(env.n_actions)
            else:
                a = np.argmax(Q[s])

            s_next, r, done = env.step(a)
            Q[s][a] += alpha * (r + gamma * np.max(Q[s_next]) - Q[s][a])
            s = s_next
    return Q
```

### 19.6 期望 SARSA vs SARSA

期望 SARSA 用期望而不是采样:

```python
def expected_sarsa(env, alpha=0.1, gamma=0.99, episodes=1000):
    Q = np.zeros((env.n_states, env.n_actions))
    for _ in range(episodes):
        s = env.reset()
        done = False
        while not done:
            a = np.argmax(Q[s]) if random.random() > 0.1 else random.randint(env.n_actions)
            s_next, r, done = env.step(a)

            # 期望值, 不用采样下一个动作
            expected_q = np.mean(Q[s_next])
            Q[s][a] += alpha * (r + gamma * expected_q - Q[s][a])
            s = s_next
    return Q
```

### 19.7 推荐系统的 Multi-Armed Bandit

```python
class UCB1:
    def __init__(self, n_arms):
        self.n = n_arms
        self.counts = np.zeros(n_arms)
        self.values = np.zeros(n_arms)

    def select_arm(self):
        total = sum(self.counts)
        if 0 in self.counts:
            return np.argmin(self.counts)  # 试每个臂至少一次
        ucb = self.values + np.sqrt(2 * np.log(total) / self.counts)
        return np.argmax(ucb)

    def update(self, arm, reward):
        self.counts[arm] += 1
        n = self.counts[arm]
        self.values[arm] = ((n - 1) * self.values[arm] + reward) / n
```

### 20.2 MCMC (Metropolis-Hastings)

```python
def metropolis_hastings(target_pdf, proposal, x0, n_samples=10000):
    """Metropolis-Hastings 采样"""
    samples = [x0]
    x = x0
    for _ in range(n_samples):
        x_proposed = proposal(x)
        alpha = min(1, target_pdf(x_proposed) / target_pdf(x))
        if random.random() < alpha:
            x = x_proposed
        samples.append(x)
    return np.array(samples)
```

### 20.3 Gibbs 采样

```python
def gibbs_sampling(conditional_pdfs, x0, n_samples=10000):
    """Gibbs 采样"""
    samples = [x0.copy()]
    x = x0.copy()
    for _ in range(n_samples):
        for i in range(len(x)):
            x[i] = conditional_pdfs[i](x)  # 采样第 i 维
        samples.append(x.copy())
    return np.array(samples)
```

```python
def rejection_sampling(target_pdf, proposal_sampler, proposal_max, n=10000):
    """拒绝采样估计期望"""
    samples = []
    while len(samples) < n:
        x = proposal_sampler()
        u = random.random() * proposal_max
        if u < target_pdf(x):
            samples.append(x)
    return np.array(samples)
```

```python
def mc_integrate(func, a, b, n=100000):
    """蒙特卡洛积分 \int_a^b func(x) dx"""
    total = 0
    for _ in range(n):
        x = random.uniform(a, b)
```

```python
def black_scholes_mc(S0, K, T, r, sigma, n=100000):
```

## 21. 概率不等式与极限定理

### 21.1 Markov 不等式

非负随机变量 $X$, $P(X \ge a) \le E[X]/a$。

### 21.2 Chebyshev 不等式

$P(|X - \mu| \ge k\sigma) \le 1/k^2$。

### 21.3 Chernoff 界

$P(X \ge (1+\delta)E[X]) \le \left(\frac{e^\delta}{(1+\delta)^{1+\delta}}\right)^{E[X]}$。

### 21.4 Hoeffding 不等式

独立有界随机变量, $P(|\bar{X} - E[\bar{X}]| \ge \epsilon) \le 2\exp(-2n\epsilon^2/(b-a)^2)$。

### 21.5 大数定律

$\bar{X}_n \to E[X]$ a.s.。

### 21.6 中心极限定理

$\bar{X}_n \approx N(\mu, \sigma^2/n)$。

### 21.7 应用: A/B 测试样本量

```python
def ab_test_size(p1, mde, alpha=0.05, power=0.8):
    """A/B 测试样本量 (双侧检验)"""
    from scipy.stats import norm
    p2 = p1 + mde
    p_avg = (p1 + p2) / 2
    z_alpha = norm.ppf(1 - alpha / 2)
    z_beta = norm.ppf(power)

    n = ((z_alpha * math.sqrt(2 * p_avg * (1 - p_avg)) +
          z_beta * math.sqrt(p1*(1-p1) + p2*(1-p2))) / mde) ** 2
    return math.ceil(n)
```

## 22. 信息论与概率

### 22.1 熵

$H(X) = -\sum_x p(x) \log p(x)$ (比特, 以 2 为底)。

### 22.2 交叉熵

$H(p, q) = -\sum_x p(x) \log q(x)$。

### 22.3 KL 散度

$D_{KL}(p || q) = \sum_x p(x) \log(p(x)/q(x))$。

非负, 不对称, 不满足三角不等式。

### 22.4 互信息

$I(X; Y) = H(X) - H(X|Y) = D_{KL}(p(x,y) || p(x)p(y))$。

### 22.5 应用: 决策树

```python
def information_gain(parent, children):
    """信息增益"""
    def entropy(y):
        p = np.bincount(y) / len(y)
        return -np.sum(p * np.log2(p + 1e-10))

    H_parent = entropy(parent)
    H_children = sum(len(c) / len(parent) * entropy(c) for c in children)
    return H_parent - H_children
```

```python
class NaiveBayes:
    def __init__(self):
        self.class_probs = {}
        self.feature_probs = {}

    def fit(self, X, y):
        n = len(y)
        for c in np.unique(y):
            self.class_probs[c] = np.sum(y == c) / n

        for c in self.class_probs:
            X_c = X[y == c]
            self.feature_probs[c] = {
                f: (np.sum(X_c[:, f] == v) + 1) / (len(X_c) + len(np.unique(X[:, f])))
                for f in range(X.shape[1])
                for v in np.unique(X[:, f])
            }

    def predict(self, x):
        scores = {}
        for c, p_c in self.class_probs.items():
            score = np.log(p_c)
            for f, v in enumerate(x):
                score += np.log(self.feature_probs[c].get((f, v), 1e-10))
            scores[c] = score
        return max(scores, key=scores.get)
```

### 23.3 隐马尔可夫模型 (HMM)

```python
class HMM:
    def __init__(self, n_states, n_obs):
        self.A = np.random.rand(n_states, n_states)
        self.A /= self.A.sum(axis=1, keepdims=True)
        self.B = np.random.rand(n_states, n_obs)
        self.B /= self.B.sum(axis=1, keepdims=True)
        self.pi = np.ones(n_states) / n_states

    def forward(self, obs):
        """前向算法"""
        T = len(obs)
        N = len(self.pi)
        alpha = np.zeros((T, N))
        alpha[0] = self.pi * self.B[:, obs[0]]
        for t in range(1, T):
            for j in range(N):
                alpha[t][j] = np.sum(alpha[t-1] * self.A[:, j]) * self.B[j, obs[t]]
        return alpha

    def viterbi(self, obs):
        """Viterbi 算法求最可能状态序列"""
        T = len(obs)
        N = len(self.pi)
        delta = np.zeros((T, N))
        psi = np.zeros((T, N), dtype=int)

        delta[0] = self.pi * self.B[:, obs[0]]
        for t in range(1, T):
            for j in range(N):
                delta[t][j] = np.max(delta[t-1] * self.A[:, j]) * self.B[j, obs[t]]
                psi[t][j] = np.argmax(delta[t-1] * self.A[:, j])

        path = [np.argmax(delta[T-1])]
        for t in range(T-1, 0, -1):
            path.append(psi[t, path[-1]])
        return path[::-1]
```

### 24.1 案例 1: 推荐系统的探索与利用

```python
class LinUCB:
    """带上下文的 bandit 算法"""
    def __init__(self, n_arms, n_features, alpha=1.0):
        self.n_arms = n_arms
        self.n_features = n_features
        self.alpha = alpha
        self.A = [np.eye(n_features) for _ in range(n_arms)]
        self.b = [np.zeros(n_features) for _ in range(n_arms)]

    def select(self, contexts):
        """对每个臂, 用上下文计算 UCB"""
        scores = []
        for arm in range(self.n_arms):
            A_inv = np.linalg.inv(self.A[arm])
            theta = A_inv @ self.b[arm]
            x = contexts[arm]
            ucb = theta @ x + self.alpha * np.sqrt(x @ A_inv @ x)
            scores.append(ucb)
        return np.argmax(scores)

    def update(self, arm, context, reward):
        self.A[arm] += np.outer(context, context)
        self.b[arm] += reward * context
```

```python
class GaussianAnomalyDetector:
    """基于高斯分布的异常检测"""
    def __init__(self):
        self.mu = None
        self.sigma = None

    def fit(self, X):
        self.mu = X.mean(axis=0)
        self.sigma = X.std(axis=0) + 1e-10

    def score(self, x):
        """返回样本的对数概率"""
        z = (x - self.mu) / self.sigma
        return -0.5 * np.sum(z**2)

    def predict(self, x, threshold=-5):
        return 1 if self.score(x) < threshold else 0
```

```python
def expected_calibration_error(y_true, y_prob, n_bins=10):
    """期望校准误差 (ECE)"""
    bins = np.linspace(0, 1, n_bins + 1)
    ece = 0
    for i in range(n_bins):
        mask = (y_prob >= bins[i]) & (y_prob < bins[i+1])
        if mask.sum() == 0: continue
        avg_pred = y_prob[mask].mean()
        avg_true = y_true[mask].mean()
        ece += abs(avg_pred - avg_true) * mask.sum()
    return ece / len(y_true)
```

### 24.4 案例 4: 期望最大化在聚类中的应用

```python
def em_gmm(X, k, max_iter=100, tol=1e-6):
    """GMM-EM 聚类"""
    n, d = X.shape

    # 初始化
    mu = X[np.random.choice(n, k, replace=False)]
    sigma = np.array([np.cov(X.T) for _ in range(k)])
    pi = np.ones(k) / k

    prev_ll = -np.inf
    for _ in range(max_iter):
        # E-step
        resp = np.zeros((n, k))
        for j in range(k):
            diff = X - mu[j]
            inv_sigma = np.linalg.inv(sigma[j])
            exp_term = np.sum(diff @ inv_sigma * diff, axis=1)
            resp[:, j] = pi[j] * np.exp(-0.5 * exp_term) / np.sqrt(np.linalg.det(sigma[j]))
        resp /= resp.sum(axis=1, keepdims=True)

        # M-step
        N_k = resp.sum(axis=0)
        pi = N_k / n
        for j in range(k):
            mu[j] = (resp[:, j:j+1] * X).sum(axis=0) / N_k[j]
            diff = X - mu[j]
            sigma[j] = (resp[:, j:j+1] * diff).T @ diff / N_k[j]

        # 检查收敛
        ll = np.sum(np.log(resp.sum(axis=1) + 1e-10))
        if abs(ll - prev_ll) < tol:
            break
        prev_ll = ll

    return mu, sigma, pi
```

```python
    for i in range(n):
        p *= (days - 2*k*i) / days
        if p <= 0: return 1.0
    return 1 - p
```
