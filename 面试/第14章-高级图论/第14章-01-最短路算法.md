# 14.01 最短路算法

---

## 1. 四大算法选型

| 算法 | 复杂度 | 负权 | 适用 |
| :--- | :--- | :--- | :--- |
| Dijkstra(堆) | $O(m\log n)$ | ❌ | 单源, 非负权 |
| Bellman-Ford | $O(nm)$ | ✅ | 单源, 有负权/判负环 |
| SPFA(队列优化 BF) | 均摊 $O(km)$ | ✅ | 有负权, 可能被卡 |
| Floyd | $O(n^3)$ | ✅(无负环) | 全源, 小图 |

---

## 2. Dijkstra(堆优化)

贪心: 每次取当前距离最小的未定点, 松弛其邻居。**非负权**保证一旦出堆即最优。

```python
import heapq

def dijkstra(graph, s, n):
    """graph[u] = [(v, w), ...]"""
    dist = [float('inf')]*n; dist[s] = 0
    pq = [(0, s)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]: continue          # 过期项跳过
        for v, w in graph[u]:
            if d + w < dist[v]:
                dist[v] = d + w
                heapq.heappush(pq, (dist[v], v))
    return dist
```

> 为什么不能有负权? 出堆即认为最优, 但负边可能之后带来更短路径, 破坏贪心正确性。

## 3. Bellman-Ford(负权 + 判负环)

松弛所有边 $n-1$ 轮; 第 $n$ 轮还能松弛 → 存在负环。

```python
def bellman_ford(edges, s, n):
    dist = [float('inf')]*n; dist[s] = 0
    for _ in range(n-1):
        for u, v, w in edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
    # 判负环
    for u, v, w in edges:
        if dist[u] + w < dist[v]:
            return None                    # 存在负环
    return dist
```

## 4. SPFA(队列优化的 BF)

只对"距离被更新"的点入队, 均摊更快, 但**可被特殊图卡到 $O(nm)$**。竞赛慎用于卡常题。

```python
from collections import deque
def spfa(graph, s, n):
    dist = [float('inf')]*n; dist[s] = 0
    inq = [False]*n; q = deque([s]); inq[s] = True
    while q:
        u = q.popleft(); inq[u] = False
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                if not inq[v]:
                    q.append(v); inq[v] = True
    return dist
```

## 5. Floyd(全源最短路)

DP: $d[i][j]$ 经过前 $k$ 个点的最短路。三重循环, $k$ 在最外层。

```python
def floyd(dist, n):        # dist 初始为邻接矩阵, 无边为 inf
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
    return dist
```

> 记住: **k 必须在最外层**(枚举中转点)。还可判负环(对角线出现负值)、求传递闭包。

## 6. 面试高频

1. Dijkstra 为何不能负权? → 贪心"出堆即最优"被负边破坏。
2. 如何判负环? → BF 第 n 轮仍能松弛 / Floyd 对角线为负。
3. Floyd 三重循环顺序? → k(中转)在最外层, 否则错。

## 7. 最短路问题的统一视角

给定图 $G=(V,E)$ 与边权函数 $w:E\to\mathbb{R}$，一条路径：

$$
P=(v_0,v_1,\ldots,v_k)
$$

的加法代价是：

$$
w(P)=\sum_{i=0}^{k-1}w(v_i,v_{i+1})
$$

单源最短路要求从源点 $s$ 到每个节点 $v$ 的最小路径代价：

$$
\delta(s,v)=\min_{P:s\leadsto v}w(P)
$$

若不存在路径，则距离记为无穷大。

若从源点可达一个负权环，那么沿该环重复行走可使代价无限下降，相关节点不存在有限最短路。

### 7.1 题目中的“最短”不总是边权和

常见路径目标还包括：

- 最少经过边数：无权 BFS。
- 最小化路径上的最大边权：瓶颈最短路。
- 最大化沿途概率乘积：最大概率路径。
- 最小化转弯数或修改次数：0-1 BFS。
- 最多使用 $k$ 条边：分层 Bellman-Ford。
- 必须满足颜色、奇偶或优惠券状态：状态扩展最短路。
- 访问所有节点：节点与位掩码组成状态图。

选算法前，必须先写清“路径代价如何合并”和“两个候选代价如何比较”。

## 8. 松弛：最短路算法的共同动作

若已知一条从源点到 `u` 的候选路径，再接边 `(u, v, w)`，可得到到 `v` 的候选距离：

```python
candidate = dist[u] + w
if candidate < dist[v]:
    dist[v] = candidate
```

这一步叫松弛。

松弛保持一个重要事实：`dist[v]` 始终是某条实际路径的长度，因此不会凭空小于真实最短距离。

不同算法的主要差异是：

- 按什么顺序选择待松弛的节点或边。
- 一条边可能被松弛多少次。
- 什么时候可以确认某个距离已经最终确定。
- 如何处理负权、状态约束和全源查询。

### 8.1 三角不等式形式

最短距离满足：

$$
\delta(s,v)\le \delta(s,u)+w(u,v)
$$

算法结束时，若所有相关边都无法继续松弛，就达到了与模型相符的稳定状态。

## 9. 算法选型决策树

### 9.1 单源或单次起点查询

1. 所有边代价相同：BFS。
2. 权值只有 0 和 1：0-1 BFS。
3. 权值全部非负：堆优化 Dijkstra。
4. 存在负权但无可达负环：Bellman-Ford。
5. 最多使用 $k$ 条边：分层 Bellman-Ford，复杂度 $O(km)$。
6. 图是 DAG：拓扑序动态规划，可处理负权。

### 9.2 多源

- 多源到最近源点：把所有源点以距离 0 同时入队或入堆。
- 每个源点有不同初始代价：用这些初始距离初始化优先队列。
- 求每点到最近特殊点：若边是无向的，直接多源；若边有向，常需先反图。

### 9.3 全源或大量查询

- $n$ 较小、图较稠密：Floyd-Warshall。
- 边权非负、图稀疏：从每个需要的源点运行 Dijkstra。
- 有负边但无负环、图稀疏：Johnson 重标权 + 多次 Dijkstra。
- 查询源点高度重复：按源点缓存 Dijkstra 结果。

### 9.4 不应默认使用 SPFA

SPFA 在部分数据上很快，但最坏复杂度仍为 $O(nm)$，且容易被构造数据卡住。

面试和竞赛中，除非：

- 数据明确友好。
- 图规模允许最坏情况。
- 或题目专门要求队列优化。

否则应优先选择复杂度上界更可控的算法。

## 10. BFS：单位权最短路

当每条边代价相同，BFS 按距离层扩展节点。

### 10.1 核心不变量

节点第一次入队时，已经找到了从源点到它的最少边数。

原因是队列先处理距离为 $d$ 的所有节点，再处理距离为 $d+1$ 的节点。

```python
from collections import deque


def bfs_shortest_path(graph, source):
    dist = [-1] * len(graph)
    parent = [-1] * len(graph)
    dist[source] = 0
    queue = deque([source])

    while queue:
        u = queue.popleft()
        for v in graph[u]:
            if dist[v] != -1:
                continue
            dist[v] = dist[u] + 1
            parent[v] = u
            queue.append(v)

    return dist, parent
```

### 10.2 多源 BFS

```python
def multi_source_bfs(graph, sources):
    dist = [-1] * len(graph)
    queue = deque()

    for source in sources:
        if dist[source] == -1:
            dist[source] = 0
            queue.append(source)

    while queue:
        u = queue.popleft()
        for v in graph[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                queue.append(v)

    return dist
```

多源 BFS 等价于添加一个超级源点，并用权值 0 的边连接所有真实源点，但无需显式创建超级源点。

## 11. 0-1 BFS：权值仅为 0 或 1

0-1 BFS 使用双端队列：

- 权值为 0 的松弛结果放到队首。
- 权值为 1 的松弛结果放到队尾。

```python
from collections import deque


def zero_one_bfs(graph, source):
    inf = float('inf')
    dist = [inf] * len(graph)
    dist[source] = 0
    deque_ = deque([source])

    while deque_:
        u = deque_.popleft()
        for v, weight in graph[u]:
            candidate = dist[u] + weight
            if candidate >= dist[v]:
                continue
            dist[v] = candidate
            if weight == 0:
                deque_.appendleft(v)
            else:
                deque_.append(v)

    return dist
```

### 11.1 为什么不用普通 BFS

普通 BFS 只保证按“边数”分层，不保证按 0/1 权值和分层。

一条包含很多条 0 权边的路径可能比一条只有一条 1 权边的路径更便宜。

### 11.2 为什么比 Dijkstra 更快

双端队列利用候选距离只可能保持不变或增加 1 的特殊结构，避免了堆操作。

时间复杂度为 $O(n+m)$。

### 11.3 适用题型

- 改变箭头方向的代价是 1，不改变是 0。
- 穿过障碍代价是 1，空地代价是 0。
- 切换模式有代价，保持模式无代价。
- 边权经归一化后只有两种相邻等级。

## 12. Dijkstra：非负权单源最短路

### 12.1 贪心不变量

当节点 `u` 以当前最小距离从最小堆弹出，且该距离等于 `dist[u]` 时，`dist[u]` 已经是最终最短距离。

非负权保证任何尚未经过的后续边都不能把一条更长前缀变成更短路径。

### 12.2 推荐实现

```python
import heapq


def dijkstra(graph, source):
    inf = float('inf')
    dist = [inf] * len(graph)
    parent = [-1] * len(graph)
    dist[source] = 0
    heap = [(0, source)]

    while heap:
        current_distance, u = heapq.heappop(heap)
        if current_distance != dist[u]:
            continue

        for v, weight in graph[u]:
            candidate = current_distance + weight
            if candidate >= dist[v]:
                continue
            dist[v] = candidate
            parent[v] = u
            heapq.heappush(heap, (candidate, v))

    return dist, parent
```

### 12.3 惰性删除

Python `heapq` 不支持高效 decrease-key。

距离改小时直接压入新状态，旧状态留在堆中；弹出时检查：

```python
if current_distance != dist[u]:
    continue
```

过期状态被跳过，这就是惰性删除。

### 12.4 提前结束

若只查询一个目标点，可在目标点以有效状态弹出时返回：

```python
def dijkstra_to_target(graph, source, target):
    dist = [float('inf')] * len(graph)
    dist[source] = 0
    heap = [(0, source)]

    while heap:
        current_distance, u = heapq.heappop(heap)
        if current_distance != dist[u]:
            continue
        if u == target:
            return current_distance
        for v, weight in graph[u]:
            candidate = current_distance + weight
            if candidate < dist[v]:
                dist[v] = candidate
                heapq.heappush(heap, (candidate, v))

    return float('inf')
```

不能在“目标点第一次入堆”时结束，因为之后可能出现更短候选路径。

### 12.5 路径恢复

```python
def restore_path(parent, source, target):
    path = []
    current = target

    while current != -1:
        path.append(current)
        if current == source:
            return path[::-1]
        current = parent[current]

    return []
```

不可达时返回空列表。

### 12.6 最短路径计数

```python
def count_shortest_paths(graph, source, mod=1_000_000_007):
    n = len(graph)
    dist = [float('inf')] * n
    ways = [0] * n
    dist[source] = 0
    ways[source] = 1
    heap = [(0, source)]

    while heap:
        current_distance, u = heapq.heappop(heap)
        if current_distance != dist[u]:
            continue

        for v, weight in graph[u]:
            candidate = current_distance + weight
            if candidate < dist[v]:
                dist[v] = candidate
                ways[v] = ways[u]
                heapq.heappush(heap, (candidate, v))
            elif candidate == dist[v]:
                ways[v] = (ways[v] + ways[u]) % mod

    return dist, ways
```

这里通常要求正权或能保证计数传播顺序正确；存在 0 权环时，“路径条数”的定义本身需要额外澄清。

## 13. Dijkstra 的常见变形

### 13.1 最大概率路径

把“距离越小越好”改为“概率越大越好”：

```python
def maximum_probability(graph, source):
    probability = [0.0] * len(graph)
    probability[source] = 1.0
    heap = [(-1.0, source)]

    while heap:
        negative_probability, u = heapq.heappop(heap)
        current = -negative_probability
        if current < probability[u]:
            continue

        for v, edge_probability in graph[u]:
            candidate = current * edge_probability
            if candidate > probability[v]:
                probability[v] = candidate
                heapq.heappush(heap, (-candidate, v))

    return probability
```

前提是概率位于 $[0,1]$，路径延长不会让概率增大。

### 13.2 最小化最大边权

```python
def minimum_effort(graph, source):
    effort = [float('inf')] * len(graph)
    effort[source] = 0
    heap = [(0, source)]

    while heap:
        current_effort, u = heapq.heappop(heap)
        if current_effort != effort[u]:
            continue
        for v, edge_effort in graph[u]:
            candidate = max(current_effort, edge_effort)
            if candidate < effort[v]:
                effort[v] = candidate
                heapq.heappush(heap, (candidate, v))

    return effort
```

路径合并从加法变成 `max`，但代价沿路径仍单调不减，因此 Dijkstra 的贪心结构继续成立。

### 13.3 使用一次优惠券

把状态从 `u` 扩成 `(u, used)`：

```python
def dijkstra_with_one_discount(graph, source):
    n = len(graph)
    dist = [[float('inf')] * 2 for _ in range(n)]
    dist[source][0] = 0
    heap = [(0, source, 0)]

    while heap:
        current_distance, u, used = heapq.heappop(heap)
        if current_distance != dist[u][used]:
            continue

        for v, weight in graph[u]:
            normal = current_distance + weight
            if normal < dist[v][used]:
                dist[v][used] = normal
                heapq.heappush(heap, (normal, v, used))

            if not used:
                discounted = current_distance + weight // 2
                if discounted < dist[v][1]:
                    dist[v][1] = discounted
                    heapq.heappush(heap, (discounted, v, 1))

    return dist
```

状态扩展的本质是构造一张更大的分层图。

## 14. Bellman-Ford：负权与负环

### 14.1 动态规划解释

第 $i$ 轮松弛结束后，`dist[v]` 不大于所有“至多使用 $i$ 条边”路径的最优值。

任何不含重复节点的简单路径最多有 $n-1$ 条边，因此无可达负环时，$n-1$ 轮足够。

### 14.2 稳健实现

```python
def bellman_ford(n, edges, source):
    inf = float('inf')
    dist = [inf] * n
    parent = [-1] * n
    dist[source] = 0

    for _ in range(n - 1):
        changed = False
        for u, v, weight in edges:
            if dist[u] == inf:
                continue
            candidate = dist[u] + weight
            if candidate < dist[v]:
                dist[v] = candidate
                parent[v] = u
                changed = True
        if not changed:
            break

    has_reachable_negative_cycle = False
    for u, v, weight in edges:
        if dist[u] != inf and dist[u] + weight < dist[v]:
            has_reachable_negative_cycle = True
            break

    return dist, parent, has_reachable_negative_cycle
```

“可达”检查很重要：源点无法到达的负环不应影响该源点的单源最短路结论。

### 14.3 最多使用 K 条边

必须让第 `step` 轮只读取上一轮结果：

```python
def shortest_path_with_at_most_k_edges(n, edges, source, k):
    inf = float('inf')
    dist = [inf] * n
    dist[source] = 0

    for _ in range(k):
        previous = dist[:]
        for u, v, weight in edges:
            if previous[u] == inf:
                continue
            dist[v] = min(dist[v], previous[u] + weight)

    return dist
```

若在同一轮读取刚更新的 `dist`，一轮可能连续走多条边，破坏边数限制。

### 14.4 找出受负环影响的节点

第 $n$ 轮仍可更新的节点位于可达负环上或其后继区域。

做法：

1. 完成 $n-1$ 轮松弛。
2. 收集还能被松弛的节点。
3. 从这些节点沿原图 BFS/DFS。
4. 所有可达节点的最短距离都可下降到负无穷。

## 15. SPFA：理解优化，但不迷信

```python
from collections import deque


def spfa(graph, source):
    n = len(graph)
    dist = [float('inf')] * n
    in_queue = [False] * n
    enqueue_count = [0] * n
    queue = deque([source])
    dist[source] = 0
    in_queue[source] = True
    enqueue_count[source] = 1

    while queue:
        u = queue.popleft()
        in_queue[u] = False

        for v, weight in graph[u]:
            candidate = dist[u] + weight
            if candidate >= dist[v]:
                continue
            dist[v] = candidate
            if in_queue[v]:
                continue
            queue.append(v)
            in_queue[v] = True
            enqueue_count[v] += 1
            if enqueue_count[v] >= n:
                return None

    return dist
```

### 15.1 风险

- 最坏时间复杂度仍是 $O(nm)$。
- 队列顺序可能导致大量重复入队。
- 某些负环计数写法容易出现口径错误。
- 数据范围较大时，Dijkstra 或 Bellman-Ford 的明确上界更可靠。

### 15.2 可接受场景

- 图非常稀疏且实际数据温和。
- 需要快速原型验证。
- 题目明确保证 SPFA 能通过。
- 作为小规模对拍实现，而不是最终高性能方案。

## 16. DAG 最短路

DAG 没有环，即使有负权，也可以按拓扑序一次松弛所有边。

```python
from collections import deque


def dag_shortest_path(graph, source):
    n = len(graph)
    indegree = [0] * n
    for u in range(n):
        for v, _ in graph[u]:
            indegree[v] += 1

    queue = deque(i for i, degree in enumerate(indegree) if degree == 0)
    order = []
    while queue:
        u = queue.popleft()
        order.append(u)
        for v, _ in graph[u]:
            indegree[v] -= 1
            if indegree[v] == 0:
                queue.append(v)

    if len(order) != n:
        raise ValueError('graph is not a DAG')

    dist = [float('inf')] * n
    dist[source] = 0
    for u in order:
        if dist[u] == float('inf'):
            continue
        for v, weight in graph[u]:
            dist[v] = min(dist[v], dist[u] + weight)

    return dist
```

时间复杂度为 $O(n+m)$，优于一般负权图的 Bellman-Ford。

## 17. Floyd-Warshall：全源最短路

### 17.1 状态定义

令 $D^{(k)}[i][j]$ 表示从 `i` 到 `j`，只允许编号小于等于 `k` 的节点作为中间点时的最短距离。

转移为：

$$
D^{(k)}[i][j]
=
\min\left(
D^{(k-1)}[i][j],
D^{(k-1)}[i][k]+D^{(k-1)}[k][j]
\right)
$$

空间压缩后原地更新矩阵，但 `k` 仍必须在最外层。

### 17.2 稳健实现

```python
def floyd_warshall(n, edges, directed=True):
    inf = float('inf')
    dist = [[inf] * n for _ in range(n)]

    for i in range(n):
        dist[i][i] = 0

    for u, v, weight in edges:
        dist[u][v] = min(dist[u][v], weight)
        if not directed:
            dist[v][u] = min(dist[v][u], weight)

    for k in range(n):
        for i in range(n):
            if dist[i][k] == inf:
                continue
            for j in range(n):
                candidate = dist[i][k] + dist[k][j]
                if candidate < dist[i][j]:
                    dist[i][j] = candidate

    return dist
```

### 17.3 负环判定

运行后若存在：

```python
dist[i][i] < 0
```

则图中存在经过 `i` 所在可达区域的负环。

### 17.4 路径恢复

```python
def floyd_with_next(n, edges):
    inf = float('inf')
    dist = [[inf] * n for _ in range(n)]
    next_node = [[-1] * n for _ in range(n)]

    for i in range(n):
        dist[i][i] = 0
        next_node[i][i] = i

    for u, v, weight in edges:
        if weight < dist[u][v]:
            dist[u][v] = weight
            next_node[u][v] = v

    for k in range(n):
        for i in range(n):
            for j in range(n):
                candidate = dist[i][k] + dist[k][j]
                if candidate < dist[i][j]:
                    dist[i][j] = candidate
                    next_node[i][j] = next_node[i][k]

    return dist, next_node


def restore_floyd_path(next_node, source, target):
    if next_node[source][target] == -1:
        return []
    path = [source]
    while source != target:
        source = next_node[source][target]
        path.append(source)
    return path
```

## 18. Johnson：稀疏图全源最短路进阶

Johnson 算法适合：

- 图稀疏。
- 允许负边。
- 不存在负环。
- 需要全源最短路。

基本步骤：

1. 添加超级源点，向所有节点连权值 0 的边。
2. 用 Bellman-Ford 求势函数 $h(v)$。
3. 重标权：

$$
w'(u,v)=w(u,v)+h(u)-h(v)
$$

4. 新权值均非负，从每个源点运行 Dijkstra。
5. 把距离转换回原权值：

$$
d(u,v)=d'(u,v)-h(u)+h(v)
$$

典型复杂度为 $O(nm\log n)$，稀疏图上可优于 Floyd 的 $O(n^3)$。

面试中通常解释思路即可，除非明确要求实现。

## 20. LeetCode 787：K 站中转内最便宜的航班

“最多 `k` 个中转站”等价于“最多使用 `k+1` 条边”。

```python
class Solution:
    def findCheapestPrice(self, n, flights, src, dst, k):
        dist = [float('inf')] * n
        dist[src] = 0

        for _ in range(k + 1):
            previous = dist[:]
            for u, v, price in flights:
                if previous[u] != float('inf'):
                    dist[v] = min(dist[v], previous[u] + price)

        return -1 if dist[dst] == float('inf') else dist[dst]
```

### 为什么普通 Dijkstra 状态不够

到达同一节点时：

- 方案 A 价格更低，但已经用掉更多边。
- 方案 B 价格略高，但剩余边数更多。

两者都可能通向最终最优答案，因此不能只保留一个 `dist[node]`。

可扩展状态为 `(node, edges_used)` 后使用状态 Dijkstra。

## 21. LeetCode 1631：最小体力消耗路径

```python
class Solution:
    def minimumEffortPath(self, heights):
        rows = len(heights)
        cols = len(heights[0])
        effort = [[float('inf')] * cols for _ in range(rows)]
        effort[0][0] = 0
        heap = [(0, 0, 0)]

        while heap:
            current, row, col = heapq.heappop(heap)
            if current != effort[row][col]:
                continue
            if row == rows - 1 and col == cols - 1:
                return current

            for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                next_row = row + dr
                next_col = col + dc
                if not (0 <= next_row < rows and 0 <= next_col < cols):
                    continue
                edge = abs(heights[row][col] - heights[next_row][next_col])
                candidate = max(current, edge)
                if candidate < effort[next_row][next_col]:
                    effort[next_row][next_col] = candidate
                    heapq.heappush(heap, (candidate, next_row, next_col))
```

### 三种解法

- Dijkstra：把路径代价定义为最大边权。
- 二分答案 + BFS：检查只走不超过阈值的边能否到达终点。
- Kruskal：边从小到大加入，起终点首次连通时的边权就是答案。

三者复杂度相近，但展示了“最短路、答案单调性、生成树”三种视角。

## 24. LeetCode 1368 与 2290：0-1 BFS

两题共同结构：

- 网格格子是节点。
- 向四邻格移动是边。
- 符合当前箭头或进入空地的代价为 0。
- 修改箭头或移除障碍的代价为 1。

Dijkstra 也正确，但 0-1 BFS 利用权值结构达到线性复杂度。

```python
def grid_zero_one_bfs(cost_to_enter):
    rows = len(cost_to_enter)
    cols = len(cost_to_enter[0])
    dist = [[float('inf')] * cols for _ in range(rows)]
    dist[0][0] = 0
    deque_ = deque([(0, 0)])

    while deque_:
        row, col = deque_.popleft()
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            next_row = row + dr
            next_col = col + dc
            if not (0 <= next_row < rows and 0 <= next_col < cols):
                continue
            weight = cost_to_enter[next_row][next_col]
            candidate = dist[row][col] + weight
            if candidate >= dist[next_row][next_col]:
                continue
            dist[next_row][next_col] = candidate
            if weight == 0:
                deque_.appendleft((next_row, next_col))
            else:
                deque_.append((next_row, next_col))

    return dist[-1][-1]
```

具体题目要根据边语义决定代价属于“离开当前格”还是“进入下一格”，不能机械套用。

## 25. LeetCode 847：访问所有节点的最短路径

状态必须包含：

- 当前节点 `u`。
- 已访问节点集合 `mask`。

```python
def shortest_path_visiting_all_nodes(graph):
    n = len(graph)
    full_mask = (1 << n) - 1
    queue = deque()
    dist = [[-1] * (1 << n) for _ in range(n)]

    for source in range(n):
        mask = 1 << source
        dist[source][mask] = 0
        queue.append((source, mask))

    while queue:
        u, mask = queue.popleft()
        if mask == full_mask:
            return dist[u][mask]
        for v in graph[u]:
            next_mask = mask | (1 << v)
            if dist[v][next_mask] == -1:
                dist[v][next_mask] = dist[u][mask] + 1
                queue.append((v, next_mask))

    return -1
```

这是在 $n\cdot 2^n$ 个状态上做多源 BFS。

## 26. LeetCode 1129：颜色交替的最短路径

状态 `(node, last_color)` 才能判断下一条边是否合法。

```python
def shortest_alternating_paths(n, red_edges, blue_edges):
    graph = [[[], []] for _ in range(n)]
    for u, v in red_edges:
        graph[u][0].append(v)
    for u, v in blue_edges:
        graph[u][1].append(v)

    dist = [[-1, -1] for _ in range(n)]
    queue = deque()
    for color in (0, 1):
        dist[0][color] = 0
        queue.append((0, color))

    while queue:
        u, last_color = queue.popleft()
        next_color = last_color ^ 1
        for v in graph[u][next_color]:
            if dist[v][next_color] == -1:
                dist[v][next_color] = dist[u][last_color] + 1
                queue.append((v, next_color))

    answer = []
    for red_distance, blue_distance in dist:
        candidates = [d for d in (red_distance, blue_distance) if d != -1]
        answer.append(min(candidates, default=-1))
    return answer
```

## 28. LeetCode 2642：设计可以求最短路径的图类

两种主方案：

### 方案 A：每次查询 Dijkstra

## 30. 正确性证明模板

### 30.1 BFS

按距离层归纳：源点距离为 0；若距离不超过 $d$ 的节点都正确，则它们扩展出的未访问邻居最早只能位于第 $d+1$ 层。

### 30.2 Dijkstra

假设 `u` 是第一个以错误距离确定的节点。真实最短路径上从已确定集合到未确定集合的第一条边会给某个未确定点提供不大于真实最短距离的候选值，与 `u` 是堆中最小候选矛盾。

### 30.3 Bellman-Ford

按允许边数归纳。第 $i$ 轮枚举最后一条边 `(u,v)`，用至多 $i-1$ 条边到 `u` 的最优结果更新 `v`。

### 30.4 Floyd

按允许的中间点集合归纳。最优路径要么不经过 `k`，要么可在 `k` 处分成 `i -> k` 与 `k -> j` 两段。

### 30.5 0-1 BFS

双端队列始终让较小候选距离位于前部。0 权松弛不增加距离放队首，1 权松弛只增加一放队尾，模拟了只有两种增量的优先队列。

## 31. 常见错误与反例

### 错误一：负权图使用 Dijkstra

反例：

```text
0→1 权 2
0→2 权 5
2→1 权 -10
```

节点 1 可能先以距离 2 被确定，但经 2 的路径距离为 -5。

### 错误二：Dijkstra 入堆时标记 visited

节点第一次入堆不代表距离最终确定。应在有效状态出堆时确定，或只用过期状态判断。

### 错误三：有限边数 BF 不复制数组

同一轮连续读取更新值会走多条边，违反“每轮增加一条边”的状态定义。

### 错误四：Floyd 把 `k` 放在内层

这会破坏“允许中间点集合逐步扩大”的 DP 依赖顺序。

### 错误五：重边直接覆盖

邻接矩阵初始化应使用：

```python
dist[u][v] = min(dist[u][v], weight)
```

### 错误六：不可达距离参与普通整数运算

固定大整数作为无穷大时，必须确保上界足够大且避免溢出；Python 可使用 `float('inf')`。

### 错误七：只返回距离，不考虑题目要路径或方案数

恢复路径需要前驱；统计方案数需要在松弛时区分 `<` 与 `==`。

### 错误八：网格建图方向错误

代价可能属于离开当前格、进入下一格或改变当前箭头，必须从题意重新定义边权。
