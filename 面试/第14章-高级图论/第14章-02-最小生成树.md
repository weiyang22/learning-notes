# 14.02 最小生成树 (Kruskal/Prim)

---

## 1. 什么是 MST

连通带权无向图中, 选 $n-1$ 条边连通所有点且边权和最小。基于**切割性质**: 任意切割中最小的横跨边一定在某棵 MST 中。

---

## 2. Kruskal(边视角, 并查集)

按边权升序, 依次加入不成环的边(用并查集判环)。

```python
class DSU:
    def __init__(self, n): self.p = list(range(n))
    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]; x = self.p[x]   # 路径压缩
        return x
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb: return False
        self.p[ra] = rb; return True

def kruskal(n, edges):
    """edges = [(w, u, v)], 返回 MST 权和"""
    edges.sort()
    dsu = DSU(n); total = cnt = 0
    for w, u, v in edges:
        if dsu.union(u, v):
            total += w; cnt += 1
            if cnt == n-1: break
    return total if cnt == n-1 else -1   # -1: 图不连通
```

**复杂度** $O(m\log m)$, 适合**稀疏图**。

## 3. Prim(点视角, 堆)

从一个点出发, 每次把"连接树与非树的最小边"对应的点并入。类似 Dijkstra。

```python
import heapq
def prim(graph, n):
    """graph[u] = [(w, v)]"""
    vis = [False]*n; total = cnt = 0
    pq = [(0, 0)]
    while pq and cnt < n:
        w, u = heapq.heappop(pq)
        if vis[u]: continue
        vis[u] = True; total += w; cnt += 1
        for w2, v in graph[u]:
            if not vis[v]: heapq.heappush(pq, (w2, v))
    return total if cnt == n else -1
```

**复杂度** $O(m\log n)$(堆) 或 $O(n^2)$(邻接矩阵朴素), 稠密图用朴素 Prim。

## 6. MST 切割性质详解

### 6.1 形式定义

> **切割性质 (Cut Property)**: 对任意切割 $(S, V \setminus S)$,连接 $S$ 与 $V \setminus S$ 的所有边中最小的横跨边一定属于某棵 MST。

### 6.2 证明

**反证法**: 假设 $e = (u, v)$ 是切割 $(S, V\setminus S)$ 上最小横跨边,边权 $w(e)$ 最小,但有某 MST $T^*$ 不含 $e$。

把 $e$ 加入 $T^*$ 形成环,环上存在另一跨切边 $e' \in (S, V\setminus S)$(因为 $u \in S, v \notin S$,环上必有另一跨切边)。

由 $e$ 的最小性: $w(e) \leq w(e')$。在 $T^*$ 中去掉 $e'$ 加 $e$,得到新的生成树 $T$,且 $w(T) = w(T^*) - w(e') + w(e) \leq w(T^*)$。

因为 $T^*$ 最小,等号必须取,即 $w(T) = w(T^*)$。

### 6.3 应用

- Kruskal: 把所有边排序,每次取最小边加入就是「取切割最小横跨边」的等效形式
- Prim: 维护一棵生长的树,每个非树顶点到树的最小边就是该顶点的切割最小横跨边

## 7. 环性质

### 7.1 定义

> **环性质 (Cycle Property)**: 给定环 $C$,环上权重最大的边(若有多个取任意一个)不可能在 MST 中。

### 7.2 证明

反证: 设 $e$ 是环 $C$ 上最大边,$e \in T^*$。从 $T^*$ 中去掉 $e$ 形成两棵树,存在环 $C$ 上的跨树边 $e' \in C, e' \neq e$,则 $w(e') \leq w(e)$。把 $e'$ 加回得到新生成树 $T$,$w(T) \leq w(T^*) - w(e) + w(e') \leq w(T^*)$。等号成立时仍是最小。

但若 $w(e) > w(e')$,严格小,矛盾。

### 7.3 应用

次小生成树: 在 MST 加一条非 MST 边 $(u, v)$ 形成环,删环上最长边(不含 $(u, v)$),得到新生成树;取所有方案最优。

## 8. 并查集 (DSU) 详解

### 8.1 两种优化

- **路径压缩 (Path Compression)**: `find(x)` 时把路径上所有节点直接指向根
- **按秩合并 (Union by Rank/Size)**: 合并时小树接大树

```python
class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.rank = [0] * n          # 或 size = [1] * n

    def find(self, x):
        if self.p[x] != x:
            self.p[x] = self.find(self.p[x])    # 路径压缩
        return self.p[x]

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb: return False
        if self.rank[ra] < self.rank[rb]:
            ra, rb = rb, ra
        self.p[rb] = ra
        if self.rank[ra] == self.rank[rb]:
            self.rank[ra] += 1
        return True
```

### 8.2 复杂度分析

$\alpha(n)$ 是阿克曼函数的反函数,实际 $\alpha(n) \leq 5$ 对 $n < 2^{65536}$。

总操作复杂度 $O(\alpha(n))$,实际视为 $O(1)$。

### 8.3 带权并查集 (Weighted Union-Find)

每个节点附带相对根的偏移量。用于处理「同类」「异类」「距离」类问题。

```python
class WeightedDSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.w = [0] * n           # w[x] = x 到根的距离

    def find(self, x):
        if self.p[x] != x:
            r = self.find(self.p[x])
            self.w[x] += self.w[self.p[x]]
            self.p[x] = r
        return self.p[x]

    def union(self, a, b, d):
        """a 比 b 多 d"""
        ra, rb = self.find(a), self.find(b)
        if ra == rb: return False
        # self.w[ra] + d = self.w[rb] + (b - a)
        # 设 ra 的父设为 rb, 则 self.w[ra] = self.w[rb] - d + (a-b)
        self.p[ra] = rb
        self.w[ra] = self.w[b] - self.w[a] + d
        return True

    def diff(self, a, b):
        """返回 a - b"""
        self.find(a); self.find(b)
        return self.w[a] - self.w[b]
```

应用: LC 399「除法求值」、食物链问题。

## 9. Kruskal 详解

### 9.1 完整实现

```python
class DSU:
    def __init__(self, n): self.p = list(range(n))
    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]    # 半路径压缩
            x = self.p[x]
        return x
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb: return False
        self.p[ra] = rb
        return True

def kruskal(n, edges):
    """
    n = 节点数
    edges = [(w, u, v), ...] 或 [(u, v, w), ...]
    返回 MST 权重和, 若图不连通返回 -1 (或 inf)
    """
    edges = sorted(edges, key=lambda e: e[0] if len(e) >= 3 else e[2])
    dsu = DSU(n)
    total = 0
    cnt = 0
    for e in edges:
        w = e[0] if len(e) >= 3 else e[2]
        u, v = (e[1], e[2]) if len(e) >= 3 else (e[0], e[1])
        if dsu.union(u, v):
            total += w
            cnt += 1
            if cnt == n - 1: break
    return total if cnt == n - 1 else -1
```

### 9.2 复杂度推导

- 排序: $O(E \log E)$
- Union-Find: $O(E \alpha(n))$
- 总: $O(E \log E) = O(E \log V)$(因 $V \leq E+1$)

### 9.3 Kruskal 重构树

构造「最大生成树」类变形时,Kruskal 按边降序,在加边时记下「合并两个分量的根是新节点」,可处理 LCA 类问题。

```python
def kruskal_rebuild(n, edges):
    """返回 parent[node] 表示重构树中 node 的父亲(0..2n-1 节点范围)"""
    edges.sort(reverse=True)
    parent = [-1] * (2 * n)
    dsu = DSU(n)
    new_id = n
    for w, u, v in edges:
        ru, rv = dsu.find(u), dsu.find(v)
        if ru == rv: continue
        new_id += 1
        parent[ru] = new_id
        parent[rv] = new_id
        dsu.union(ru, rv)
    return parent
```

应用: 离线「两点路径最大/最小值」类查询。

## 10. Prim 算法详解

### 10.1 堆优化版 (Python)

```python
import heapq

def prim(graph, n):
    """
    graph[u] = [(w, v), ...] (邻接表)
    返回 MST 权重和
    """
    vis = [False] * n
    vis[0] = True
    pq = [(w, v) for v, w in graph[0]]
    heapq.heapify(pq)
    total = 0
    cnt = 1
    while pq and cnt < n:
        w, u = heapq.heappop(pq)
        if vis[u]: continue
        vis[u] = True
        total += w
        cnt += 1
        for v, w in graph[u]:
            if not vis[v]:
                heapq.heappush(pq, (w, v))
    return total if cnt == n else -1
```

### 10.2 朴素版 (邻接矩阵)

```python
def prim_matrix(mat, n):
    """
    mat[i][j] = i, j 边权(无向图对称)
    """
    INF = float('inf')
    dist = [INF] * n
    dist[0] = 0
    in_mst = [False] * n
    total = 0
    for _ in range(n):
        u = -1
        for i in range(n):
            if not in_mst[i] and (u == -1 or dist[i] < dist[u]):
                u = i
        if dist[u] == INF: return -1
        in_mst[u] = True
        total += dist[u]
        for v in range(n):
            if not in_mst[v] and mat[u][v] < dist[v]:
                dist[v] = mat[u][v]
    return total
```

### 10.3 复杂度

- 堆优化: $O((V + E) \log V)$ 实际 $O(E \log V)$
- 朴素: $O(V^2)$

### 10.4 选型

| 图类型 | 选用 |
|:--|:--|
| 稀疏图 ($E \ll V^2$) | Kruskal 或 Prim 堆版 |
| 稠密图 ($E \approx V^2$) | Prim 朴素版 |
| 在线 (边动态) | Prim 更合适 |
| 离线一次完成 | Kruskal 简洁 |

## 11. Borůvka 算法

### 11.1 思想

并行风格: 每轮每个连通分量找最小邻接边,加入 MST。每轮后连通分量数至少减半(最少合并两分量),所以 $O(\log V)$ 轮。

每轮 $O(E)$,总 $O(E \log V)$。

### 11.2 实现

```python
def boruvka(n, edges):
    """edges = [(w, u, v), ...]"""
    parent = list(range(n))
    best = [-1] * n      # best[i] = i 分量的最小邻接边
    mst = []

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    while len(mst) < n - 1:
        for i in range(n):
            best[i] = -1
        for w, u, v in edges:
            ru, rv = find(u), find(v)
            if ru == rv: continue
            if best[ru] == -1 or edges[best[ru]][0] > w:
                best[ru] = (w, u, v)
            if best[rv] == -1 or edges[best[rv]][0] > w:
                best[rv] = (w, u, v)
        for i in range(n):
            if best[i] != -1:
                w, u, v = best[i]
                ru, rv = find(u), find(v)
                if ru != rv:
                    parent[ru] = rv
                    mst.append((w, u, v))
        if len(mst) == 0: break
    total = sum(w for w, _, _ in mst)
    return total, mst
```

### 11.3 应用

并行图算法的基础(每轮独立),并行实现可线性加速。

## 12. 次小生成树 (Second-best MST)

### 12.3 LCA 倍增优化 $O(V \log V + E)$

预处理 MST 上的倍增数组: `up[i][k]` = $i$ 的 $2^k$ 祖先,`max_edge[i][k]` = 路径上最大边权。

```python
def smst_prepare(parent, max_edge, depth, LOG):
    for k in range(1, LOG):
        for v in range(len(parent)):
            if up[v][k-1] != -1:
                up[v][k] = up[up[v][k-1]][k-1]
                max_edge[v][k] = max(max_edge[v][k-1], max_edge[up[v][k-1]][k-1])

def max_on_path(u, v, up, max_edge, depth, LOG):
    """返回 u -> v 路径上的最大边权"""
    if depth[u] < depth[v]: u, v = v, u
    diff = depth[u] - depth[v]
    res = 0
    for k in range(LOG):
        if diff & (1 << k):
            res = max(res, max_edge[u][k])
            u = up[u][k]
    if u == v: return res
    for k in range(LOG - 1, -1, -1):
        if up[u][k] != up[v][k]:
            res = max(res, max_edge[u][k], max_edge[v][k])
            u = up[u][k]; v = up[v][k]
    return max(res, max_edge[u][0], max_edge[v][0])
```

## 13. 最小瓶颈生成树 (MBT)

### 13.1 定义

最大边权最小的生成树。

### 13.2 与 MST 的关系

> **定理**: 每棵 MST 都是 MBT; 但并非每棵 MBT 都是 MST。

证明: MST 上最大边权 ≤ 其他 MBT 的最大边权(否则该 MBT 也最小,可替换)。

```python
def is_mbt(mst_max_weight, any_spanning_max):
    return mst_max_weight <= any_spanning_max
```

### 13.3 应用

- 通信网络设计: 最小化最坏路径
- 近似解某些 NP-hard 问题

## 14. Kruskal 重构树 (Kruskal Reconstruction Tree)

### 14.1 构造

- 初始每个节点是叶子
- Kruskal 加边 $(u, v, w)$ 时: 创建一个新节点 $z$, 左子 = $u$ 所在树根, 右子 = $v$ 所在树根, 边权 $w$ 记在 $z$ 上

### 14.2 性质

- 新树是二叉树, 度数 2 内
- 节点数 $V' = 2V - 1$(最终态)
- 叶子是原节点, 内部节点对应合并时的边

### 14.3 离线查询

- 「两点路径最大/最小权值」可在重构树上 LCA, $O(\log V)$
- 「强制某点 $x$ 出现在某连通分量中」可 LCA $x$ 与超级源

## 15. 度数限制最小生成树

## 17. MST 计数: Matrix-Tree 定理

### 17.1 Kirchhoff 矩阵

$L = D - A$:
- $L_{ii} = \deg(i)$
- $L_{ij} = -$ 边 $(i, j)$ 的条数

### 17.2 定理

> 生成树个数 = 任意主子式 $\det(L^*) = $ 删去一行一列后矩阵的行列式。

### 17.3 实现

```python
import numpy as np

def count_spanning_trees(n, edges):
    """生成树数; edges 为 (u, v)"""
    L = np.zeros((n, n), dtype=np.int64)
    for u, v in edges:
        L[u][u] += 1
        L[v][v] += 1
        L[u][v] -= 1
        L[v][u] -= 1
    if n == 1: return 0
    L_sub = L[1:, 1:]
    # 行列式, 高斯消元
    return round(np.linalg.det(L_sub))

# 推荐手写高斯消元(数值稳定性)
def det_gf2(mat, mod=10**9 + 7):
    """整数矩阵行列式 mod 质数"""
    m = mat.copy().astype(np.int64)
    n = m.shape[0]
    res = 1
    for i in range(n):
        if m[i][i] == 0:
            # 找非零行
            for j in range(i + 1, n):
                if m[j][i] != 0:
                    m`i, j` = m`j, i`
                    res = -res
                    break
        res *= m[i][i]
        for j in range(i + 1, n):
            factor = m[j][i] * pow(m[i][i], mod - 2, mod) % mod
            m[j] = (m[j] - factor * m[i]) % mod
    return res % mod
```

### 17.4 应用

- 电网可靠性
- 概率图模型
- 组合计数

## 19. 平面图 MST

平面图(可无交叉嵌入平面)中, MST 可在 $O(V)$ 时间求:

**方法**: 利用对偶图 + 最短路。平面图 $G$ 的 MST 权 = 对偶图 $\hat G$ 中 s-t 路径的最小边权和(对偶性质)。

具体:
1. 任意生成树 $T$ 的对偶是余树 $\hat T$, MST ↔ $\hat G \setminus \hat T$ 形成 s-t 最短路
2. 单源最短路(S-Node 最短路径树)→ MST

## 20. 拓扑基础

### 20.1 最小生成树 $\neq$ 唯一

当存在等权边时,MST 可有多个。等权边可任意选择。

### 20.2 最小生成树性质总结

- 连通图必有 MST(连通前提)
- MST 边数 = $V - 1$
- MST 可能不唯一, 但权值唯一
- MST 是连通性 + 权最小的平衡
- 切割性质 → Kruskal, Prim; 环性质 → 反证
- Kruskal + Prim 输出的 MST **可能不同**(等权时)

```python
class Solution:
    def minimumCost(self, n, connections):
        # Kruskal
        connections.sort(key=lambda x: x[2])
        dsu = DSU(n)
        total = 0
        cnt = 0
        for u, v, w in connections:
            if dsu.union(u - 1, v - 1):
                total += w
                cnt += 1
                if cnt == n - 1: return total
        return -1
```

```python
class Solution:
```

```python
class Solution:

        vis = [False] * n
        pq = [(0, 0)]
        total = 0
        cnt = 0
        while cnt < n:

            total += d
            cnt += 1
            for v in range(n):

                    heapq.heappush(pq, (w, v))
```

```python
class Solution:
    def minimumHammingDistance(self, source, target, allowedSwaps):
        n = len(source)
        dsu = DSU(n)
        for u, v in allowedSwaps:
            dsu.union(u, v)
        from collections import defaultdict
        groups = defaultdict(list)
        for i in range(n):
            groups[dsu.find(i)].append(i)
        ans = 0
        for grp in groups.values():
            if len(grp) == 1: continue
            # 在 grp 内比较 source 和 target 的差异
            cnt_s = defaultdict(int)
            cnt_t = defaultdict(int)
            for i in grp:
                cnt_s[source[i]] += 1
                cnt_t[target[i]] += 1
            for k in cnt_s:
                match = min(cnt_s[k], cnt_t[k])
                cnt_s[k] -= match
                cnt_t[k] -= match
            # 剩余的就是差异
            for k in cnt_s:
                ans += cnt_s[k]
        return ans
```

## 26. 数学基础:Matroid

### 26.1 拟阵定义

拟阵 $M = (E, \mathcal{I})$:
- $\mathcal{I}$ 非空, $E$ 的有限子集,满足「遗传性」(subsets of independent sets are independent)
- 「交换性」: 若 $A, B \in \mathcal{I}, |A| < |B|$, 则 $\exists e \in B \setminus A$ 使 $A \cup \{e\} \in \mathcal{I}$

### 26.2 图拟阵 (Graphic Matroid)

$E$ = 边集, $\mathcal{I}$ = 无环边集 (acyclic forests)。

MST = 图拟阵上最大权独立集。

### 26.3 线性拟阵

$E$ = 向量集, $\mathcal{I}$ = 线性无关子集。

最大权线性无关集 = 矩阵分析。

## 34. 完整模板库(可直接粘贴)

```python
# mst.py
import heapq
from typing import List, Tuple

class DSU:
    """并查集"""
    __slots__ = ('p', 'rank')
    def __init__(self, n):
        self.p = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]   # 半路径压缩
            x = self.p[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb: return False
        if self.rank[ra] < self.rank[rb]:
            ra, rb = rb, ra
        self.p[rb] = ra
        if self.rank[ra] == self.rank[rb]:
            self.rank[ra] += 1
        return True


def kruskal(n: int, edges: List[Tuple[int, int, int]]) -> Tuple[int, List]:
    """
    edges = [(w, u, v), ...]
    返回 (MST 总权, MST 边列表)
    """
    edges.sort()
    dsu = DSU(n)
    total = 0
    mst_edges = []
    for w, u, v in edges:
        if dsu.union(u, v):
            total += w
            mst_edges.append((u, v, w))
            if len(mst_edges) == n - 1: break
    if len(mst_edges) < n - 1:
        return float('inf'), []   # 不连通
    return total, mst_edges


def prim(n: int, graph: List[List[Tuple[int, int]]]) -> int:
    """
    graph[u] = [(w, v), ...]
    """
    vis = [False] * n
    pq = [(0, 0, -1)]   # (w, u, parent)
    total = 0
    cnt = 0
    while pq and cnt < n:
        w, u, _ = heapq.heappop(pq)
        if vis[u]: continue
        vis[u] = True
        total += w
        cnt += 1
        for w2, v in graph[u]:
            if not vis[v]:
                heapq.heappush(pq, (w2, v, u))
    return total if cnt == n else float('inf')


def boruvka(n: int, edges: List[Tuple[int, int, int]]) -> int:
    """Borůvka MST"""
    parent = list(range(n))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def merge(a, b):
        ra, rb = find(a), find(b)
        if ra == rb: return False
        parent[ra] = rb
        return True

    total = 0
    if n == 1: return 0
    while True:
        best = [-1] * n
        for w, u, v in edges:
            ru, rv = find(u), find(v)
            if ru == rv: continue
            if best[ru] == -1 or edges[best[ru]][0] > w:
                best[ru] = (w, u, v)
            if best[rv] == -1 or edges[best[rv]][0] > w:
                best[rv] = (w, u, v)
        added = False
        for i in range(n):
            if best[i] != -1:
                w, u, v = best[i]
                if merge(u, v):
                    total += w
                    added = True
        if not added: break
    # 校验
    roots = {find(i) for i in range(n)}
    if len(roots) != 1: return float('inf')
    return total
```

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Edge { int u, v, w; };
bool operator<(const Edge& a, const Edge& b) { return a.w < b.w; }

vector<int> p;
int find(int x) {
    if (p[x] != x) p[x] = find(p[x]);
    return p[x];
}

int kruskal(int n, vector<Edge>& edges) {
    sort(edges.begin(), edges.end());
    p.resize(n);
    iota(p.begin(), p.end(), 0);
    int total = 0, cnt = 0;
    for (auto& e : edges) {
        int ru = find(e.u), rv = find(e.v);
        if (ru != rv) {
            p[ru] = rv;
            total += e.w;
            cnt++;
            if (cnt == n - 1) return total;
        }
    }
    return -1;
}
```

```java
class DSU {
    int[] p;
    DSU(int n) { p = IntStream.range(0, n).toArray(); }
    int find(int x) {
        if (p[x] != x) p[x] = find(p[x]);
        return p[x];
    }
    boolean union(int a, int b) {
        int ra = find(a), rb = find(b);
        if (ra == rb) return false;
        p[ra] = rb;
        return true;
    }
}

int kruskal(int n, int[][] edges) {
    Arrays.sort(edges, (a, b) -> a[2] - b[2]);
    DSU dsu = new DSU(n);
    int total = 0, cnt = 0;
    for (int[] e : edges) {
        if (dsu.union(e[0], e[1])) {
            total += e[2];
            if (++cnt == n - 1) return total;
        }
    }
    return -1;
}
```

## 41. 关键边 / 伪关键边的严格证明

### 41.1 关键边定义回顾

**关键边** $e$: $G \setminus e$ 的 MST 严格大于 $G$ 的 MST。

### 41.2 伪关键边定义

**伪关键边** $e$: 存在某 MST $T$ 使 $e \in T$, 但 $G \setminus e$ 的 MST 不严格大于原 MST。

### 41.3 计算流程

```text
1. 计算 G 的 MST 总权 W
2. 对每条边 e:
   - 不含 e: MST 权重 > W? → e 关键
   - 含 e: 能造 MST = W 且非关键? → e 伪关键
3. 关键边不属于伪关键
```

### 41.4 实现步骤

```python
def find_critical_pseudo(n, edges):
    edges_idx = [(w, u, v, i) for i, (u, v, w) in enumerate(edges)]
    edges_idx.sort()
    W = kruskal(n, edges_idx)[0]
    critical = []; pseudo = []
    for w, u, v, i in edges_idx:
        excl_edges = [e for e in edges_idx if e[3] != i]
        if kruskal(n, excl_edges)[0] > W:
            critical.append(i)
        else:
            # 强制包含测试
            dsu = DSU(n)
            dsu.union(u, v)
            forced_total = w
            cnt = 1
            for w2, u2, v2, j in edges_idx:
                if j == i: continue
                if dsu.union(u2, v2):
                    forced_total += w2
                    cnt += 1
            if cnt == n - 1 and forced_total == W:
                pseudo.append(i)
    return critical, pseudo
```

### 41.5 复杂度

$O(m \cdot (m \log m + n \alpha(n))) = O(m^2 \log m)$。

可优化到 $O(m \log m + n)$ 但实现复杂。

## 42. 工程实现模板(可直接使用)

```python
# complete_mst.py
from typing import List, Tuple, Optional

class DSU:
    __slots__ = ('p', 'rank')
    def __init__(self, n: int):
        self.p = list(range(n))
        self.rank = [0] * n
    def find(self, x: int) -> int:
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x
    def union(self, a: int, b: int) -> bool:
        ra, rb = self.find(a), self.find(b)
        if ra == rb: return False
        if self.rank[ra] < self.rank[rb]:
            ra, rb = rb, ra
        self.p[rb] = ra
        if self.rank[ra] == self.rank[rb]:
            self.rank[ra] += 1
        return True


def mst_kruskal(n: int, edges: List[Tuple[int, int, int]]) -> Tuple[int, List]:
    """edges = [(w, u, v), ...] or [(u, v, w), ...]"""
    edges.sort(key=lambda e: (e[2], e[0], e[1]) if len(e) == 3 else (e[0], e[1], e[2]))
    dsu = DSU(n)
    total = 0; mst = []; cnt = 0
    for e in edges:
        if len(e) == 3:
            w, u, v = e
        else:
            u, v, w = e
        if dsu.union(u, v):
            total += w; mst.append((u, v, w)); cnt += 1
            if cnt == n - 1: return total, mst
    return float('inf'), []


def mst_prim(n: int, graph: List[List[Tuple[int, int]]]) -> int:
    """graph[u] = [(v, w), ...]"""
    import heapq
    vis = [False] * n
    pq = [(0, 0)]  # (weight, vertex)
    total = 0; cnt = 0
    while pq and cnt < n:
        w, u = heapq.heappop(pq)
        if vis[u]: continue
        vis[u] = True; total += w; cnt += 1
        for v, w2 in graph[u]:
            if not vis[v]:
                heapq.heappush(pq, (w2, v))
    return total if cnt == n else float('inf')


def second_mst(n: int, edges: List[Tuple[int, int, int]]) -> Optional[int]:
    """次小生成树"""
    total, mst = mst_kruskal(n, edges)
    if not mst: return None
    second = float('inf')
    for i, (w_excl, u_excl, v_excl) in enumerate(edges):
        excl_edges = edges[:i] + edges[i+1:]
        t, _ = mst_kruskal(n, excl_edges)
        if t < second: second = t
    return second if second < float('inf') else total
```

### 48.1 Problem A: 最少修缮费

**描述**: $n$ 个城市, $m$ 条道路可修缮, 每条修缮费用 $c_i$。要找最少的费用使所有城市连通(不强求修缮哪些边)。

**输入**:
- 第一行 $n, m$
- 接下来 $m$ 行: $u, v, w$

**输出**: 最少总费用,若不可能则 $-1$。

**解法**: Kruskal。$O(m \log m)$。

```python
import sys
input = sys.stdin.readline

def main():
    n, m = map(int, input().split())
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        edges.append((w, u - 1, v - 1))

main()
```

**解法**: 加「超级源 0」, 把 $a_i$ 当作 $0 \to i$ 的边权。

**描述**: 给定无向图(不连通), 求最少加几条边使全连通。

**描述**: 给定 $n$ 节点图, 求生成树个数 mod 质数。

**描述**: 给定无向图边权, MST 是否唯一。

**解法**: 等权边时可能不唯一,枚举边删一条后两 MST 权重仍相等 → 不唯一。

**描述**: 求严格次小(权重严格大)。

### 48.7 Problem G: MST + LCA 查询

**解法**: 倍增 LCA + 维护每层最大边。

**描述**: 求 MST 但要求某节点 v 度数 ≤ K。

## 52. 关键边/伪关键边再次深入

### 52.1 严谨定义

- 关键边: 该边存在于所有 MST 中(必然包含)
- 伪关键边: 该边存在于至少一个 MST 中(可能包含)

不对,我之前写的反了。修正:

**正确版本**:
- **关键边 (Critical)**: 若不在 MST 中, MST 增大 → 必加边。**任何 MST 都包含**。
- **伪关键边 (Pseudo-Critical)**: 可选加入, 加入某些 MST 不会让原 MST 变差 → 部分包含。

**判定**:
- $W$ = 原 MST
- 不含 e 的 MST = $W'$
- 含 e 的 MST = $W''$ (强制 +1 边)
- 关键: $W' > W$
- 伪关键: $W'' = W$ 且非关键

实现见 §41.4。

## 54. 算法心智模型

### 54.1 DSU 的本质

DSU 是「最小化连通操作」的合并结构, 把每个节点视为独立的, 合并后查询 $O(1)$(摊)。

### 54.2 切割 = 合并的对偶

- 加边合并(从最小边开始, 是「最小合并」)
- 切边解构(从最大边开始, 是「最大切除」)

两种视角给出同一 MST。

### 54.3 度量树 vs 路径树

- 度量树(MST): 边权之和最小
- 路径树(BFS/DFS): 树高最小
- 中心树(Steiner): 加辅助点 → 最小总路径

三者不同。
