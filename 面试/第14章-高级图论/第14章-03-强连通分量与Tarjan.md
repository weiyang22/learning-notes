# 14.03 强连通分量与 Tarjan

---

## 1. 强连通分量 (SCC)

有向图中, 若两点互相可达则属于同一 SCC。把每个 SCC **缩成一个点** → 得到 DAG, 便于在其上做拓扑 DP。

---

## 2. Tarjan 核心: dfn 与 low

- `dfn[u]`: DFS 访问 u 的时间戳(次序)。
- `low[u]`: u 及其子树能通过**至多一条返祖边**回到的最小 dfn。
- 当 `dfn[u] == low[u]`, u 是某个 SCC 的"根", 栈中从 u 到栈顶的点构成一个 SCC。

```python
import sys
def tarjan_scc(graph, n):
    sys.setrecursionlimit(1 << 20)
    dfn = [0]*n; low = [0]*n
    idx = 0; stack = []; in_stk = [False]*n
    scc_id = [-1]*n; scc_cnt = 0

    def dfs(u):
        nonlocal idx, scc_cnt
        idx += 1; dfn[u] = low[u] = idx
        stack.append(u); in_stk[u] = True
        for v in graph[u]:
            if dfn[v] == 0:
                dfs(v)
                low[u] = min(low[u], low[v])      # 树边: 用子节点 low
            elif in_stk[v]:
                low[u] = min(low[u], dfn[v])      # 返祖/横叉且在栈: 用 dfn
        if dfn[u] == low[u]:                       # u 是 SCC 根
            while True:
                w = stack.pop(); in_stk[w] = False
                scc_id[w] = scc_cnt
                if w == u: break
            scc_cnt += 1

    for u in range(n):
        if dfn[u] == 0: dfs(u)
    return scc_id, scc_cnt
```

**复杂度** $O(n+m)$, 每点每边只访问一次。

## 3. 缩点建 DAG

```python
def condense(graph, n):
    scc_id, cnt = tarjan_scc(graph, n)
    dag = [set() for _ in range(cnt)]
    for u in range(n):
        for v in graph[u]:
            if scc_id[u] != scc_id[v]:
                dag[scc_id[u]].add(scc_id[v])       # SCC 间的边
    return dag, scc_id, cnt
```

缩点后可在 DAG 上跑拓扑排序 + DP(如求最长路、可达点数)。

---

## 4. 相关: 割点与桥(无向图)

无向图 Tarjan 变体:
- **割点**: 删去后连通分量增加的点。根节点有 ≥2 棵子树, 或非根 `low[v] >= dfn[u]`。
- **桥**: 删去后不连通的边, 条件 `low[v] > dfn[u]`。

---

## 5. 应用场景

- 2-SAT(强连通判可满足性)。
- 有向图缩点后拓扑 DP。
- 找必经点/必经边(割点/桥)。
- 搜索/推荐中的社群/环检测。

---

## 6. 面试高频

2. 何时弹出一个 SCC? → `dfn[u]==low[u]`。
3. 缩点后图是什么? → DAG, 可拓扑 DP。

## 7. 学习目标与术语边界

本节把三个容易混淆的主题分开：

1. 有向图的强连通分量（SCC）。
2. 无向图的桥与割点。
3. 基于 SCC 的缩点、DAG 动态规划与 2-SAT。

它们都维护 `dfn` 与 `low`，但 `low` 的更新规则和根条件并不完全相同，不能把代码机械混用。

### 7.1 可达与强连通

在有向图 $G=(V,E)$ 中：

- 若存在从 $u$ 到 $v$ 的有向路径，则记作 $u\leadsto v$。
- 若 $u\leadsto v$ 且 $v\leadsto u$，则称 $u$ 与 $v$ 强连通。
- 强连通关系满足自反、对称和传递，因此会把所有点划分成互不相交的等价类。
- 每个等价类就是一个强连通分量。

单个点即使没有自环，也独自构成一个 SCC，因为长度为零的路径使它可达自身。

### 7.2 缩点图为什么是 DAG

把每个 SCC 缩成一个点，保留不同 SCC 之间的有向边。

假设缩点图仍有环：

$$
C_1 \to C_2 \to \cdots \to C_k \to C_1
$$

环上任意两个分量都能沿环互相到达，它们本应属于同一个更大的 SCC，与“已经是极大强连通分量”矛盾。

因此 SCC 缩点图一定是有向无环图。

### 7.3 三组数组的准确语义

- `dfn[u]`：节点 `u` 第一次被 DFS 发现的时间戳。
- `low[u]`：在当前 DFS 与栈约束下，`u` 的 DFS 子树能到达的最小 `dfn`。
- `on_stack[u]`：`u` 已发现、尚未归入一个已经弹出的 SCC。
- `component_id[u]`：节点最终所属的 SCC 编号。

对 SCC Tarjan 来说，`on_stack` 是正确性的关键，而不仅是优化。

---

## 8. Tarjan SCC 的逐行不变量

进入 `dfs(u)` 时：

1. 为 `u` 分配新的时间戳。
2. 令 `dfn[u] = low[u]`。
3. 把 `u` 压栈并标记为在栈中。

扫描边 `u -> v` 时分三类：

### 8.1 `v` 尚未访问

这是一条 DFS 树边：

```python
dfs(v)
low[u] = min(low[u], low[v])
```

递归返回后，`low[v]` 已概括 `v` 子树能回到的最早栈中节点。

### 8.2 `v` 已访问且仍在栈中

这条边连接到一个尚未封闭的搜索区域：

```python
low[u] = min(low[u], dfn[v])
```

这里使用 `dfn[v]`，不是无条件使用 `low[v]`。

### 8.3 `v` 已访问但已经出栈

`v` 属于一个已经封闭的 SCC，不能帮助 `u` 与旧分量合并，因此不更新 `low[u]`。

### 8.4 根条件

当所有出边扫描完毕且：

```python
dfn[u] == low[u]
```

说明从 `u` 的当前 DFS 子树无法到达栈中比 `u` 更早的节点。

从栈顶持续弹出直到 `u`，弹出的节点恰好组成一个 SCC。

## 9. 完整、可复用的 Tarjan SCC 实现

```python
import sys


def tarjan_scc(graph):
    """返回 (component_id, components)。

    graph[u] 是 u 的所有出邻居。
    components[cid] 保存第 cid 个强连通分量中的节点。
    """
    n = len(graph)
    sys.setrecursionlimit(max(1000, n * 2 + 10))

    dfn = [-1] * n
    low = [0] * n
    stack = []
    on_stack = [False] * n
    component_id = [-1] * n
    components = []
    timestamp = 0

    def dfs(u):
        nonlocal timestamp
        dfn[u] = low[u] = timestamp
        timestamp += 1
        stack.append(u)
        on_stack[u] = True

        for v in graph[u]:
            if dfn[v] == -1:
                dfs(v)
                low[u] = min(low[u], low[v])
            elif on_stack[v]:
                low[u] = min(low[u], dfn[v])

        if low[u] != dfn[u]:
            return

        component = []
        while True:
            v = stack.pop()
            on_stack[v] = False
            component_id[v] = len(components)
            component.append(v)
            if v == u:
                break
        components.append(component)

    for u in range(n):
        if dfn[u] == -1:
            dfs(u)

    return component_id, components
```

### 9.1 复杂度

- 每个节点进入和离开栈各一次。
- 每条有向边被扫描一次。
- 时间复杂度为 $O(n+m)$。
- 邻接表、DFS 栈、Tarjan 栈与辅助数组共占 $O(n+m)$ 空间。

### 9.2 SCC 编号顺序

上面实现按照“弹栈顺序”编号。

对于跨 SCC 边 `u -> v`，常见情况下会有：

```text
component_id[u] > component_id[v]
```

即编号天然接近拓扑序的逆序，但工程代码不应依赖未明确证明的编号约定；需要拓扑序时，显式构造缩点图并拓扑排序更稳妥。

## 10. 缩点：从一般有向图到 DAG

```python
def build_condensation(graph, component_id, component_count):
    dag = [set() for _ in range(component_count)]
    indegree = [0] * component_count

    for u in range(len(graph)):
        source = component_id[u]
        for v in graph[u]:
            target = component_id[v]
            if source == target or target in dag[source]:
                continue
            dag[source].add(target)
            indegree[target] += 1

    return [list(neighbors) for neighbors in dag], indegree
```

### 10.1 为什么要去重

原图中两个 SCC 之间可能有很多平行边。

如果缩点时不去重：

- 拓扑排序仍可通过“重复增加与减少入度”得到正确结果。
- 但边数可能远大于必要值。
- 按边计数的 DP 可能重复累计。
- 后续算法的常数显著增加。

因此缩点图通常使用 `set` 去重，再转换回列表。

### 10.2 SCC 权值汇总

```python
def aggregate_component_weights(component_id, component_count, node_weights):
    component_weight = [0] * component_count
    for node, weight in enumerate(node_weights):
        component_weight[component_id[node]] += weight
    return component_weight
```

### 10.3 缩点 DAG 上的最大权路径

```python
from collections import deque


def max_weight_path(dag, indegree, weight):
    indegree = indegree[:]
    queue = deque(i for i, degree in enumerate(indegree) if degree == 0)
    best = weight[:]

    while queue:
        u = queue.popleft()
        for v in dag[u]:
            best[v] = max(best[v], best[u] + weight[v])
            indegree[v] -= 1
            if indegree[v] == 0:
                queue.append(v)

    return max(best, default=0)
```

使用前提：同一个 SCC 内的节点可以通过路径互相访问，题目允许把分量内权值按规则汇总。

## 11. Tarjan、Kosaraju 与 Gabow 对比

| 算法 | DFS 次数 | 反图 | 核心结构 | 时间复杂度 | 特点 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Tarjan | 1 | 不需要 | `dfn/low` + 栈 | $O(n+m)$ | 一趟完成，细节较多 |
| Kosaraju | 2 | 需要 | 完成序 + 反图 | $O(n+m)$ | 思路直观，代码易验证 |
| Gabow | 1 | 不需要 | 两个栈 | $O(n+m)$ | 避免显式 `low`，较少见 |

### 11.1 Kosaraju 完整实现

```python
def kosaraju_scc(graph):
    n = len(graph)
    reverse_graph = [[] for _ in range(n)]
    for u in range(n):
        for v in graph[u]:
            reverse_graph[v].append(u)

    visited = [False] * n
    order = []

    def first_dfs(u):
        visited[u] = True
        for v in graph[u]:
            if not visited[v]:
                first_dfs(v)
        order.append(u)

    for u in range(n):
        if not visited[u]:
            first_dfs(u)

    component_id = [-1] * n
    components = []

    def second_dfs(u, component):
        component_id[u] = len(components)
        component.append(u)
        for v in reverse_graph[u]:
            if component_id[v] == -1:
                second_dfs(v, component)

    for u in reversed(order):
        if component_id[u] == -1:
            component = []
            second_dfs(u, component)
            components.append(component)

    return component_id, components
```

### 11.2 如何选

- 面试现场：若不熟悉 `low` 细节，Kosaraju 更容易一次写对。
- 内存敏感：Tarjan 不需要额外反图。
- 需要同时解决桥或割点：理解 Tarjan low-link 更有迁移价值。
- Python 深链：两者的递归实现都可能栈溢出，应评估迭代写法或调整递归上限。

### 11.3 结果如何比较

不同算法的 SCC 编号通常不同，不能直接比较 `component_id` 数组。

正确比较方式是：

```python
def normalize_components(components):
    return sorted(tuple(sorted(component)) for component in components)
```

把每个分量内部排序，再对分量集合排序。

## 12. 无向图中的桥

无向边 `(u, v)` 是桥，当且仅当删除它后连通分量数量增加。

对 DFS 树边 `u -> v`：

```text
low[v] > dfn[u]
```

说明 `v` 的子树无法通过任何非父边回到 `u` 或 `u` 的祖先，因此这条边是唯一通道。

### 12.1 为什么必须使用边编号

若 `u` 与 `v` 之间存在两条平行边：

- DFS 使用其中一条作为树边。
- 另一条是返回父节点的合法返边。
- 若代码用 `if v == parent: continue`，会把两条边都跳过，错误地把树边判为桥。

正确做法是只跳过进入当前节点的那一个 `parent_edge_id`。

### 12.2 完整实现

```python
def find_bridges(n, edges):
    graph = [[] for _ in range(n)]
    for edge_id, (u, v) in enumerate(edges):
        graph[u].append((v, edge_id))
        graph[v].append((u, edge_id))

    dfn = [-1] * n
    low = [0] * n
    timestamp = 0
    bridges = []

    def dfs(u, parent_edge_id):
        nonlocal timestamp
        dfn[u] = low[u] = timestamp
        timestamp += 1

        for v, edge_id in graph[u]:
            if edge_id == parent_edge_id:
                continue
            if dfn[v] == -1:
                dfs(v, edge_id)
                low[u] = min(low[u], low[v])
                if low[v] > dfn[u]:
                    bridges.append(edge_id)
            else:
                low[u] = min(low[u], dfn[v])

    for u in range(n):
        if dfn[u] == -1:
            dfs(u, -1)

    return bridges
```

## 13. 无向图中的割点

节点 `u` 是割点，当删除 `u` 及其相邻边后，原连通块被拆成更多连通块。

### 13.1 非根节点

若存在 DFS 子节点 `v` 满足：

```text
low[v] >= dfn[u]
```

则 `v` 的子树无法绕过 `u` 到达 `u` 的祖先，删除 `u` 会隔断该子树。

### 13.2 根节点

DFS 根没有祖先，必须单独判断：

- 根在 DFS 树中有至少两个子树时，根是割点。
- 只有一个 DFS 子树时，删除根后剩余部分仍连通，根不是割点。

### 13.3 完整实现

```python
def find_articulation_points(graph):
    n = len(graph)
    dfn = [-1] * n
    low = [0] * n
    is_cut = [False] * n
    timestamp = 0

    def dfs(u, parent):
        nonlocal timestamp
        dfn[u] = low[u] = timestamp
        timestamp += 1
        child_count = 0

        for v in graph[u]:
            if dfn[v] == -1:
                child_count += 1
                dfs(v, u)
                low[u] = min(low[u], low[v])
                if parent != -1 and low[v] >= dfn[u]:
                    is_cut[u] = True
            elif v != parent:
                low[u] = min(low[u], dfn[v])

        if parent == -1 and child_count >= 2:
            is_cut[u] = True

    for u in range(n):
        if dfn[u] == -1:
            dfs(u, -1)

    return [u for u, cut in enumerate(is_cut) if cut]
```

> 有平行边的无向图同样应改用边编号；上面版本适合简单图。

## 14. SCC 与 2-SAT

每个布尔变量 $x_i$ 建两个节点：

- `2*i` 表示 $x_i=False$。
- `2*i+1` 表示 $x_i=True$。
- 一个文字的否定可用节点编号异或 `1` 得到。

子句 $(a\lor b)$ 等价于两条蕴含：

$$
\neg a \Rightarrow b
$$

$$
\neg b \Rightarrow a
$$

若某变量的真节点与假节点属于同一个 SCC，则二者可以互相推出，公式不可满足。

```python
class TwoSAT:
    def __init__(self, variable_count):
        self.variable_count = variable_count
        self.graph = [[] for _ in range(variable_count * 2)]

    @staticmethod
    def node(variable, value):
        return variable * 2 + int(value)

    def add_implication(self, a, b):
        self.graph[a].append(b)

    def add_or(self, variable_a, value_a, variable_b, value_b):
        a = self.node(variable_a, value_a)
        b = self.node(variable_b, value_b)
        self.add_implication(a ^ 1, b)
        self.add_implication(b ^ 1, a)

    def satisfiable(self):
        component_id, _ = tarjan_scc(self.graph)
        for variable in range(self.variable_count):
            false_node = variable * 2
            true_node = false_node + 1
            if component_id[false_node] == component_id[true_node]:
                return False
        return True
```

只判断可满足性不依赖 SCC 编号顺序；若要构造赋值，需要明确实现所返回编号与拓扑顺序的关系。

## 15. LeetCode 1192：查找集群内的关键连接

### 15.1 题目模型

- 服务器是无向图节点。
- 连接是无向边。
- 删除后使图不再连通的连接就是桥。

### 15.2 直接解法

对每条边：

1. 临时删除该边。
2. 从一个端点 BFS/DFS。
3. 检查能否到达另一个端点。

复杂度约为 $O(m(n+m))$，只能用于很小的数据。

### 15.3 Tarjan 解法

```python
class Solution:
    def criticalConnections(self, n, connections):
        graph = [[] for _ in range(n)]
        for edge_id, (u, v) in enumerate(connections):
            graph[u].append((v, edge_id))
            graph[v].append((u, edge_id))

        dfn = [-1] * n
        low = [0] * n
        answer = []
        timestamp = 0

        def dfs(u, parent_edge_id):
            nonlocal timestamp
            dfn[u] = low[u] = timestamp
            timestamp += 1

            for v, edge_id in graph[u]:
                if edge_id == parent_edge_id:
                    continue
                if dfn[v] == -1:
                    dfs(v, edge_id)
                    low[u] = min(low[u], low[v])
                    if low[v] > dfn[u]:
                        answer.append([u, v])
                else:
                    low[u] = min(low[u], dfn[v])

        for u in range(n):
            if dfn[u] == -1:
                dfs(u, -1)
        return answer
```

### 15.4 复杂度对比

| 解法 | 时间 | 空间 | 适用场景 |
| :--- | :--- | :--- | :--- |
| 逐边删除 + 搜索 | $O(m(n+m))$ | $O(n+m)$ | 小图验证 |
| Tarjan 桥 | $O(n+m)$ | $O(n+m)$ | 正式解法 |

### 16.1 何时不要使用 Tarjan

- 无向静态连通块：普通 DFS 或并查集更简单。
- 只判断 DAG 是否有环：拓扑排序或三色 DFS 更直接。
- 函数图求最长环：时间戳 DFS 利用每点出度至多一，更简洁。
- 点数很小：Floyd 传递闭包也能判断互相可达。
- 动态加边/删边：一次性 Tarjan 不能直接维护动态答案。

## 17. 常见错误与最小反例

### 错误一：对所有已访问邻居都更新 `low`

错误代码：

```python
else:
    low[u] = min(low[u], dfn[v])
```

在 SCC Tarjan 中必须附加 `on_stack[v]`，否则已经归属旧 SCC 的点会污染当前 `low`。

### 错误二：树边返回后使用 `dfn[v]`

错误代码：

```python
dfs(v)
low[u] = min(low[u], dfn[v])
```

这会丢失 `v` 子树通过返边到达更早祖先的信息，应使用 `low[v]`。

### 错误三：把 SCC 根条件写成 `low[u] <= dfn[u]`

由于 `low[u]` 本就不会大于 `dfn[u]`，该条件几乎总成立。

正确条件是严格相等：

```python
low[u] == dfn[u]
```

### 错误四：只从节点 0 启动 DFS

图可能不连通。必须遍历所有节点，对未访问点启动新 DFS。

### 错误五：无向图用父节点代替父边

存在平行边时会漏掉合法返边。桥算法必须优先使用边编号。

### 错误六：割点根节点套用非根条件

根节点的 `low[child] >= dfn[root]` 常常成立，但只有至少两个 DFS 子树时根才是割点。

### 错误七：递归层数过深

链式图可能让 Python 递归深度达到 $n$。应根据数据规模：

- 提高递归上限。
- 改写为显式栈。
- 在允许时使用其他语言。

## 18. 面试高频问答扩展

### 问：`low[u]` 是不是从 `u` 出发任意可达点的最小 `dfn`？

不是。它受 DFS 子树、返边与当前栈状态约束。若理解成任意可达，会错误合并已经封闭的 SCC。

### 问：为什么使用栈而不是队列？

SCC 根被发现时，需要弹出当前 DFS 路径上最近进入且尚未归属分量的连续区域；后进先出的栈正好对应 DFS 嵌套结构。

### 问：为什么 SCC 缩点后一定无环？

若缩点后有环，环上的分量互相可达，应合并成同一个 SCC，与极大性矛盾。

### 问：桥条件为何是严格大于？

若 `low[v] == dfn[u]`，`v` 子树至少能通过另一条边回到 `u`，删除树边后仍可能连通，因此不是桥。

### 问：割点条件为何是大于等于？

删除点 `u` 后，即使子树只能回到 `u` 本身也无济于事，所以 `low[v] == dfn[u]` 已足以让 `u` 成为割点候选。

### 问：Tarjan SCC 和桥算法能共用同一段代码吗？

不能直接共用。SCC 处理有向图并依赖在栈状态；桥处理无向图并必须跳过父边。

## 20. 复习路线

### 第一遍：概念

- 只学习可达、强连通、SCC 与缩点 DAG。
- 手动画三个有向图，直接按互相可达关系分组。
- 不写代码，先建立分量的集合直觉。

### 第二遍：状态

- 学习 `dfn`、`low`、栈与 `on_stack`。
- 对六个点以内的图逐步手算。
- 重点区分树边、栈内边与指向已出栈分量的边。

### 第三遍：实现

- 闭卷实现 Tarjan SCC。
- 用 Kosaraju 作为独立对照。
- 对随机小图用 Floyd 可达矩阵对拍分量结果。

### 第四遍：迁移

- 学习缩点 DAG 与拓扑 DP。
- 学习无向图桥和割点，明确代码不能直接复用。
- 学习 2-SAT 的蕴含图建模。

### 第五遍：题目

- LeetCode 1192：桥。
- LeetCode 1568：割点思想与小规模枚举。
- LeetCode 207/210：SCC 与拓扑的选型对比。
- LeetCode 2360/2127：函数图特化。
