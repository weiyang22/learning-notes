## 1. 最大流与最小割

- **最大流**: 源 s 到汇 t 能通过的最大流量。
- **最小割**: 删去权和最小的边使 s、t 不连通。
- **最大流最小割定理**: 最大流 = 最小割。这是网络流建模的理论基石。

---

## 2. Dinic 算法($O(V^2 E)$)

BFS 分层 + DFS 多路增广。是竞赛主流最大流算法, 二分图上可达 $O(E\sqrt V)$。

```python
from collections import deque

class Dinic:
    def __init__(self, n):
        self.n = n
        self.g = [[] for _ in range(n)]   # g[u] = `v, cap, rev_index`
    def add(self, u, v, c):
        self.g[u].append([v, c, len(self.g[v])])
        self.g[v].append([u, 0, len(self.g[u])-1])   # 反向边初始 0

    def bfs(self, s, t):
        self.level = [-1]*self.n; self.level[s] = 0
        q = deque([s])
        while q:
            u = q.popleft()
            for v, c, _ in self.g[u]:
                if c > 0 and self.level[v] < 0:
                    self.level[v] = self.level[u]+1; q.append(v)
        return self.level[t] >= 0

    def dfs(self, u, t, f):
        if u == t: return f
        while self.it[u] < len(self.g[u]):
            e = self.g[u][self.it[u]]
            v, c, rev = e
            if c > 0 and self.level[v] == self.level[u]+1:
                d = self.dfs(v, t, min(f, c))
                if d > 0:
                    e[1] -= d; self.g[v][rev][1] += d   # 更新正/反向边
                    return d
            self.it[u] += 1
        return 0

    def max_flow(self, s, t):
        flow = 0
        while self.bfs(s, t):
            self.it = [0]*self.n
            while True:
                f = self.dfs(s, t, float('inf'))
                if f == 0: break
                flow += f
        return flow
```

## 3. 二分图最大匹配: 匈牙利算法

左部每个点找增广路。$O(VE)$, 适合中小图。

```python
def hungarian(adj, nl, nr):
    """adj[u] = 左点 u 可匹配的右点列表"""
    match = [-1]*nr           # 右点匹配的左点
    def dfs(u, vis):
        for v in adj[u]:
            if not vis[v]:
                vis[v] = True
                if match[v] == -1 or dfs(match[v], vis):
                    match[v] = u; return True
        return False
    res = 0
    for u in range(nl):
        if dfs(u, [False]*nr): res += 1
    return res
```

## 4. König 定理与建模

- **König 定理**: 二分图**最小点覆盖 = 最大匹配**。
- **最大独立集 = 总点数 − 最大匹配**(二分图)。
- 最小路径覆盖(DAG) = 点数 − 拆点后二分图最大匹配。

**网络流建模套路**: 把约束转成"容量", 源汇分别接选择两端。二分图匹配可建成单位容量网络流用 Dinic 求。

## 6. 流网络严格定义

### 6.1 形式定义

**流网络** $G = (V, E)$:
- $V$: 顶点集
- $E \subseteq V \times V$: 有向边集
- $c: E \to \mathbb{Z}_{\geq 0}$: 容量函数(capacity)
- $s, t \in V$: 源点(s)、汇点(t),且 $s \neq t$

**流** $f: E \to \mathbb{Z}$:
- **容量约束** (capacity constraint): $0 \leq f(u, v) \leq c(u, v)$
- **反对称性** (skew symmetry): $f(u, v) = -f(v, u)$
- **流量守恒** (flow conservation): $\forall u \neq s, t: \sum_{v} f(u, v) = 0$

**流值** $|f| = \sum_{v} f(s, v)$(从源流出的净流量)。

### 6.2 残量网络 (Residual Network)

**定义**: 给定流网络 $G$ 和流 $f$,残量网络 $G_f$:
- 节点同 $G$
- 边: 对每条原边 $(u, v)$,
  - **正向边** 容量 $c_f(u, v) = c(u, v) - f(u, v)$(剩余可推)
  - **反向边** 容量 $c_f(v, u) = f(u, v)$(可回退)

**物理解释**: 反向边表示撤销一部分已推流,允许算法在错误路径上修正。

```python
def build_residual(G, f):
    """根据流 f 构造残量网络"""
    Gf = defaultdict(dict)
    for u in G:
        for v, cap, flow in G[u]:
            rc = cap - flow
            if rc > 0: Gf[u][v] += rc
            if flow > 0: Gf[v][u] += flow
    return Gf
```

### 6.3 增广路 (Augmenting Path)

**定义**: 残量网络中从 $s$ 到 $t$ 的一条简单路径。

**瓶颈容量** (bottleneck): 路径上最小残量,$b = \min_{(u,v) \in P} c_f(u, v)$。

**增广**: 把这条路径上每条边的流加 $b$,反向边减 $b$(对应原来的流减 $b$)。流值增加 $b$。

## 7. 最大流最小割定理

### 7.1 s-t 切割定义

**s-t 切** $(S, T)$: $S \subseteq V$,$T = V \setminus S$,$s \in S$,$t \in T$。

**切割容量** $c(S, T) = \sum_{u \in S, v \in T} c(u, v)$。

### 7.2 定理陈述

> **最大流最小割定理**: 最大流值 = 最小切割容量。

**等价表述** (三命题等价):
1. $f$ 是最大流。
2. 残量网络 $G_f$ 无 $s \to t$ 路径。
3. 存在某切割 $(S, T)$ 使 $|f| = c(S, T)$。

### 7.3 证明思路

**正向**: 流 $f$ → 切割 $(S, T)$。取 $S = \{$ 在 $G_f$ 中从 $s$ 可达的顶点 $\}$,$T = V \setminus S$。$t \notin S$(否则有 $s \to t$ 路径,矛盾)。由 $f$ 的流量守恒,$|f| = c(S, T)$。

**反向**: 切割 → 流上界。$|f| = \sum_{(s, v)} f(s, v) - \sum_{(v, s)} f(v, s)$
$\leq \sum_{(s, v)} c(s, v) \leq \sum_{(u, v) \in (S, T)} c(u, v) = c(S, T)$。
(因为 $T$ 中节点净流入 = 净流出 = 0,流量只在跨切边上非零)

### 7.4 直观理解

最大流是网络「瓶颈」的精确度量。无论哪条路径组合,流量都被最弱的切割限制。

## 8. Ford-Fulkerson 方法

### 8.1 算法框架

```python
def ford_fulkerson(G, s, t):
    """基础版本: DFS 找任意增广路"""
    flow = 0
    while True:
        path = dfs_path(G, s, t)         # 在残量网络找 s→t 路径
        if not path: break
        b = min(G[u][v] - flow[(u,v)] for (u,v) in path)
        for (u, v) in path:
            flow[(u,v)] = flow.get((u,v), 0) + b
            flow[(v,u)] = flow.get((v,u), 0) - b
        flow += b
    return flow
```

### 8.2 复杂度分析

$O(E \cdot |f^*|)$,其中 $|f^*|$ 是最大流值。

整数容量必终止(每次增广至少 +1)。

**整数假设**: 容量为正整数。

### 8.3 问题

- 容量非整数(如 √2)可能不终止
- 实际中用 Edmonds-Karp 或 Dinic 改进

## 9. Edmonds-Karp 算法

### 9.1 关键改进: BFS 找最短增广路

```python
from collections import deque
from typing import Dict, List, Tuple

def edmonds_karp(graph, s, t):
    """graph[u][v] = 容量, 无向边视为两条单向边"""
    n = len(graph)
    flow = [[0] * n for _ in range(n)]
    f = 0
    while True:
        parent = [-1] * n
        q = deque([s]); parent[s] = s
        while q and parent[t] == -1:
            u = q.popleft()
            for v in range(n):
                if parent[v] == -1 and graph[u][v] - flow[u][v] > 0:
                    parent[v] = u
                    q.append(v)
        if parent[t] == -1: break
        # 计算增广量
        path_flow = float('inf')
        v = t
        while v != s:
            u = parent[v]
            path_flow = min(path_flow, graph[u][v] - flow[u][v])
            v = u
        # 更新流
        v = t
        while v != s:
            u = parent[v]
            flow[u][v] += path_flow
            flow[v][u] -= path_flow
            v = u
        f += path_flow
    return f
```

### 9.2 复杂度

$O(V E^2)$。BFS 找 O(V) 层,每次至少一个边饱和,共 O(E) 次增广。

### 9.3 与 FF 对比

- FF: DFS 任意路径,可能绕远
- EK: BFS 最短路径,保证更少增广次数

## 10. Dinic 算法(主流)

### 10.1 三件套: BFS 分层 + DFS 多路增广 + 当前弧优化

```python
from collections import deque

class Dinic:
    """O(V²E) 一般, O(√V·E) 单位容量(二分图匹配)"""
    def __init__(self, n):
        self.n = n
        self.g = [[] for _ in range(n)]

    def add(self, u, v, c):
        """加边, 自动加反向边"""
        self.g[u].append([v, c, len(self.g[v])])
        self.g[v].append([u, 0, len(self.g[u]) - 1])

    def bfs(self, s, t):
        """分层, 距离"""
        self.level = [-1] * self.n
        self.level[s] = 0
        q = deque([s])
        while q:
            u = q.popleft()
            for v, c, _ in self.g[u]:
                if c > 0 and self.level[v] == -1:
                    self.level[v] = self.level[u] + 1
                    q.append(v)
        return self.level[t] != -1

    def dfs(self, u, t, f):
        """多路增广 + 当前弧优化"""
        if u == t: return f
        while self.it[u] < len(self.g[u]):
            e = self.g[u][self.it[u]]
            v, c, rev = e
            if c > 0 and self.level[v] == self.level[u] + 1:
                d = self.dfs(v, t, min(f, c))
                if d > 0:
                    e[1] -= d
                    self.g[v][rev][1] += d
                    return d
            self.it[u] += 1
        return 0

    def max_flow(self, s, t):
        flow = 0
        while self.bfs(s, t):
            self.it = [0] * self.n
            while True:
                f = self.dfs(s, t, float('inf'))
                if f == 0: break
                flow += f
        return flow
```

### 10.2 原理详解

**BFS 分层**: 只允许从 level $i$ 流向 level $i+1$,避免绕路。

**DFS 多路增广**: 一次 DFS 后,所有子路径上的流都被增广。

**当前弧优化**: `self.it[u]` 记录 DFS 已经处理到第几条邻接边,避免重复访问。

### 10.3 复杂度证明

- BFS 每轮 $O(V + E)$
- DFS 总增广数 $O(E)$,因为每次至少一条边容量耗尽
- BFS 轮数: 普通 $O(V)$, 单位图 $O(\sqrt V)$
- 总: 普通 $O(V^2 E)$, 单位图 $O(\sqrt V E)$

### 10.4 Dinic 的迭代版(避免递归深度限制)


**Improvement of SAP**: 类似于 Dinic 但用「距离标签」+ 「GAP 启发式」。

```python
        self.cur = [0] * n
        self.gap = [0] * (n + 1)

    def add(self, u, v, c):
        self.g[u].append([v, c, len(self.g[v])])
        self.g[v].append([u, 0, len(self.g[u]) - 1])

    def bfs(self, s, t):
        # 从 t 倒 bfs
        self.dep = [-1] * self.n
        self.dep[t] = 0
        q = deque([t])
        while q:
            u = q.popleft()
            for e in self.g[u]:
                v, c = e[0], e[1]
                if c > 0 and self.dep[v] == -1:

            i += 1
            if self.gap[self.dep[u]] == 1 and self.dep[u] > 0:

                ...
        return 0

    def max_flow(self, s, t):
```

## 12. Push-Relabel 算法

### 12.1 思想

## 13. 二分图详解

### 13.1 定义

顶点分两部分 $L, R$, 边只跨 $L-R$。

### 13.2 二分图判定

BFS/DFS 染色:

```python
def is_bipartite(n, edges):
    """返回是否是二分图; n 节点, edges 为 [(u,v),...]"""
    color = [-1] * n
    for start in range(n):
        if color[start] != -1: continue
        color[start] = 0
        q = deque([start])
        while q:
            u = q.popleft()
            for v in edges[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    return False
    return True
```

### 13.3 匹配与覆盖

- **匹配** (matching): 边集,任意两条边无公共顶点
- **完美匹配**: $|M| = |V|/2$
- **最大匹配**: 边数最多的匹配
- **点覆盖** (vertex cover): $C \subseteq V$,每条边至少一个端点在 $C$
- **独立集** (independent set): $I \subseteq V$, $I$ 中任意两点无边

## 14. 匈牙利算法(DFS 找增广路)

### 14.1 算法

```python
def hungarian(adj, nl, nr):
    """
    adj[u] = [v1, v2, ...], u ∈ [0, nl), v ∈ [0, nr)
    match[v] = u or -1
    """
    match = [-1] * nr
    res = 0
    def dfs(u, visited):
        for v in adj[u]:
            if not visited[v]:
                visited[v] = True
                if match[v] == -1 or dfs(match[v], visited):
                    match[v] = u
                    return True
        return False

    for u in range(nl):
        if dfs(u, [False] * nr):
            res += 1
    return res, match
```

### 14.2 复杂度

$O(VE)$。

### 14.3 时间分析

外层循环 $|L|$,每次 DFS 试所有邻边,DFS 内部沿增广路走最多 $|R|$ 步。

## 15. Hopcroft-Karp 算法

### 15.1 BFS 分层 + DFS 多路增广

```python
from collections import deque

def hopcroft_karp(adj, nl, nr):
    """
    adj[u] = [v1, v2, ...]
    返回最大匹配数 + match_left[u], match_right[v]
    """
    INF = 10**9
    dist = [0] * nl
    match_l = [-1] * nl
    match_r = [-1] * nr

    def bfs():
        q = deque()
        for u in range(nl):
            if match_l[u] == -1:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        found = False
        while q:
            u = q.popleft()
            for v in adj[u]:
                mu = match_r[v]
                if mu != -1:
                    if dist[mu] == INF:
                        dist[mu] = dist[u] + 1
                        q.append(mu)
                else:
                    found = True
        return found

    def dfs(u):
        for v in adj[u]:
            mu = match_r[v]
            if mu == -1 or (dist[mu] == dist[u] + 1 and dfs(mu)):
                match_l[u] = v; match_r[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(nl):
            if match_l[u] == -1:
                if dfs(u): matching += 1
    return matching, match_l, match_r
```

### 15.2 复杂度

$O(\sqrt V \cdot E)$。

### 15.3 与匈牙利对比

| 指标 | 匈牙利 | Hopcroft-Karp |
|:--|:--|:--|
| 时间 | O(VE) | O(√V·E) |
| 实现 | 简单 | 中等 |
| 适用 | V ≤ 1000 | V ≥ 1000 |

## 16. König 定理与最小点覆盖

### 16.1 定理陈述

> 二分图**最小点覆盖 = 最大匹配**。

### 16.2 构造算法

从最大匹配 $M$ 出发:
1. 找未被匹配的左点 $u_0$,作为起点
2. BFS/DFS 经过「未匹配的左→右」、「匹配的右→左」交替边,标记可达左点 $Z_L$ 和可达右点 $Z_R$
3. 最小点覆盖 $C = (L \setminus Z_L) \cup (R \cap Z_R)$

```python
def min_vertex_cover(adj, nl, nr, match_l, match_r):
    """从最大匹配构造最小点覆盖"""
    from collections import deque
    Z_L = [False] * nl
    Z_R = [False] * nr
    q = deque([u for u in range(nl) if match_l[u] == -1])
    Z_L_set = set()
    while q:
        u = q.popleft()
        if u in Z_L_set: continue
        Z_L_set.add(u)
        for v in adj[u]:
            if v < nr and match_r[v] != -1 and match_r[v] != u:
                # 经未匹配边
                Z_R[v] = True
                u2 = match_r[v]
                if u2 not in Z_L_set:
                    q.append(u2)
    # C = (L \ Z_L) ∪ (R ∩ Z_R)
    cover = [(u, 0) for u in range(nl) if u not in Z_L_set]
    cover += [(v + nl, 1) for v in range(nr) if Z_R[v]]
    return cover
```

### 16.3 最大独立集

由 König 定理(补集):

> 最大独立集 $|I^*| = |V| - |M^*|$($M^*$ 最大匹配)。

```python
def max_independent_set(nl, nr, cover):
    """cover 是最小点覆盖元组列表 [(node_id, side)]"""
    covered = {node for node, _ in cover}
    all_nodes = set(range(nl)) | {v + nl for v in range(nr)}
    return all_nodes - covered
```

## 17. 最小路径覆盖 (DAG)

### 17.1 定义

DAG 中,用最少的路径覆盖所有顶点(每点恰好出现在一条路径上)。

### 17.2 拆点建图

对原 DAG $G = (V, E)$:
- 每个 $v \in V$ 拆成 $v_{in}$ 和 $v_{out}$
- 源集 $L = \{v_{in}\}$, 汇集 $R = \{v_{out}\}$
- 对每条原边 $(u, v) \in E$, 加二分部边 $(u_{out}, v_{in})$
- 求最大匹配 $M$

**最小路径数 = $|V| - |M|$**(每匹配一对相当于一条边把两路径合并)。

### 17.3 完整代码

```python
def min_path_cover_dag(n, edges):
    """DAG n 节点,edges 为 [(u, v), ...], 返回最小路径覆盖数和路径列表"""
    adj = [[] for _ in range(n)]
    # 拆点 0..n-1 = L, n..2n-1 = R
    for u, v in edges:
        adj[u].append(v)
    matching, match_l, match_r = hopcroft_karp(adj, n, n)
    # 路径数 = n - matching
    paths = []
    used = [False] * n
    # 找路径起点: L 中未被匹配的节点
    for u in range(n):
        if match_l[u] == -1:
            path = [u]
            cur = u
            while True:
                v = match_l[cur] if cur < n else None
                if v == -1 or v is None: break
                path.append(v)
                cur = v
            paths.append(path)
            used[path[0]] = True
            for x in path: used[x] = True
    return n - matching, paths
```

## 18. 网络流建模套路

### 18.1 三大要素

1. **源点**: 表示「所有东西的起点」
2. **汇点**: 表示「所有东西的终点」

### 18.3 经典模型: 二分图最大匹配

```python
def bipartite_matching_max_flow(adj, nl, nr):

        for v in adj[u]:
            d.add(u, nl + v, 1)
    for v in range(nr):
        d.add(nl + v, T, 1)

```

### 18.4 最大权闭合子图

**问题**: 选子集 $S \subseteq V$ 使 $\sum_{v \in S} w^+(v) - \sum_{(u,v) \in E, u \in S, v \notin S} c(u, v)$ 最大。

**解法**:
- 正权点连源(容量 $w^+(v)$)
- 负权点连汇(容量 $|w^-(v)|$)
- 边按容量连
- 最大权 = 正权和 - 最小割

```python
import heapq
class Solution:
    def reachableNodes(self, edges, maxMoves, n):
        graph = [[] for _ in range(n)]
        for u, v, cnt in edges:
            graph[u].append((v, cnt + 1))
            graph[v].append((u, cnt + 1))
        dist = [10**9] * n
        dist[0] = 0
        pq = [(0, 0)]
        while pq:

            if d > dist[u]: continue

                if dist[u] + w < dist[v]:
                    dist[v] = dist[u] + w
                    heapq.heappush(pq, (dist[v], v))
        ans = sum(1 for d in dist if d <= maxMoves)
        # 边内节点
        for u, v, cnt in edges:
            a = max(0, maxMoves - dist[u])
            b = max(0, maxMoves - dist[v])
            ans += min(a + b, cnt)
        return ans
```

## 20. 网络流高级建模

### 20.1 项目选择问题

**问题**: 给定一组项目,每个 $i$ 有收益 $p_i$ 和成本 $c_i$,以及依赖关系 ($i$ 依赖 $j$ 必须先选 $j$)。最大化收益。

**模型**: 最大权闭合子图
- 节点 $i$: 收益为正连源(容量 $p_i$),为负连汇(容量 $|c_i|$)
- 依赖边 $(i, j)$: 容量 $\infty$, 强制 $i$ 选则 $j$ 必选

### 20.2 节点容量问题

**问题**: 在原有边上流量限额外,还限制通过某节点 $v$ 的总流量。

**解法**: 拆点 $v \to v_{in}, v_{out}$,中间加容量为限额的边。

### 20.3 多源多汇最大流

**解法**: 加「超级源」连所有源(容量 $\infty$),「超级汇」从所有汇连(容量 $\infty$)。等价单源单汇。

### 20.4 下界最小流

**问题**: 每条边 $(u, v)$ 有容量下界 $l_{uv}$ 和上界 $c_{uv}$。求最小可行流。

**解法**: 上下界转可行流问题。先按无下界求可行流,调整。

### 20.5 最小费用最大流

**问题**: 每条边有容量和单位费用,求最大流下总费用最小。

**算法**: SSP(Successive Shortest Path)用 Bellman-Ford/SPFA 找最短路(费用),每次沿其增广。

```python
from collections import deque

class MCMF:
    """最小费用最大流"""
    def __init__(self, n):
        self.n = n
        self.g = [[] for _ in range(n)]

    def add(self, u, v, c, w):
        self.g[u].append([v, c, w, len(self.g[v])])
        self.g[v].append([u, 0, -w, len(self.g[u]) - 1])

    def spfa(self, s, t):
        """Bellman-Ford 找最短费用路径"""
        INF = 10**18
        dist = [INF] * self.n
        inq = [False] * self.n
        prev = [None] * self.n
        dist[s] = 0
        q = deque([s]); inq[s] = True
        while q:
            u = q.popleft(); inq[u] = False
            for e in self.g[u]:
                v, c, w = e[0], e[1], e[2]
                if c > 0 and dist[v] > dist[u] + w:
                    dist[v] = dist[u] + w
                    prev[v] = (u, e[3])
                    if not inq[v]:
                        q.append(v); inq[v] = True
        return dist[t] < INF, prev

    def min_cost_flow(self, s, t, maxf=float('inf')):
        flow = cost = 0
        while flow < maxf:
            ok, prev = self.spfa(s, t)
            if not ok: break
            # 找瓶颈
            f = maxf - flow
            v = t
            while v != s:
                u, ei = prev[v]
                e = self.g[u][ei]
                f = min(f, e[1])
                v = u
            # 增广
            v = t
            while v != s:
                u, ei = prev[v]
                self.g[u][ei][1] -= f
                self.g[v][self.g[u][ei][3]][1] += f
                cost += f * self.g[u][ei][2]
                v = u
            flow += f
        return flow, cost
```

应用: 运输问题、二分图最大权匹配(转费用流,设置左→右 边权 = 匹配权值)。

## 24. 常见错误与陷阱

1. **反向边缺失**: 残量网络中反向边是关键,漏了算法不能修正错误流。
2. **INF 选择**: 用太大可能溢出,Python 默认无限大整数但慢;用 $10^{18}$ 通常够。
3. **零边处理**: 容量 0 的边不进残量网络。
4. **递归深度**: Python 默认 1000,DFS 在网络流中可能有爆栈,用 `sys.setrecursionlimit`。
5. **节点编号**: 0-indexed 还是 1-indexed 容易混。
6. **无向边**: 转两条容量相同的有向边(u→v 和 v→u)。
7. **多重边**: 用 add 多次,容量累加或保留为多条边。
8. **邻接表 vs 邻接矩阵**: Dinic 用邻接表(含反向边索引)。

```python
import numpy as np

def count_spanning_trees(n, edges):
    L = np.zeros((n, n), dtype=int)
    for u, v in edges:
        L[u][u] += 1
        L[v][v] += 1
        L[u][v] -= 1
        L[v][u] -= 1
    # 求任意 (n-1) × (n-1) 子矩阵行列式
    L_sub = L[1:, 1:]  # 删首行首列
```

```python
        self.dist = [0] * nl

    def add_edge(self, u, v):
        """u ∈ [0, nl), v ∈ [0, nr)"""
        self.adj[u].append(v)

    def bfs(self):
        from collections import deque
        INF = 10**9
        q = deque()
        for u in range(self.nl):
            if self.match_l[u] == -1:
                self.dist[u] = 0
                q.append(u)
            else:
                self.dist[u] = INF
        found = False
        while q:
            u = q.popleft()
            for v in self.adj[u]:
                mu = self.match_r[v]
                if mu != -1 and self.dist[mu] == INF:
                    self.dist[mu] = self.dist[u] + 1
                    q.append(mu)
                elif mu == -1:
                    found = True
        return found

    def dfs(self, u):
        for v in self.adj[u]:
            mu = self.match_r[v]
            if mu == -1 or (self.dist[mu] == self.dist[u] + 1 and self.dfs(mu)):
                self.match_l[u] = v
                self.match_r[v] = u
                return True
        self.dist[u] = 10**9
        return False

    def max_matching(self):
        matching = 0
        while self.bfs():
            for u in range(self.nl):
                if self.match_l[u] == -1 and self.dfs(u):
                    matching += 1
        return matching, self.match_l, self.match_r
```

```python
class Solution:
    def maxStudents(self, seats: List[str]) -> int:
        m, n = len(seats), len(seats[0])
        valid = [[seats[i][j] == '.' for j in range(n)] for i in range(m)]
        # 0..N-1 为「在交叉线左的格」
        # N..2N-1 为「在交叉线右的格」
        N = m * n
        d = MaxFlow(2 * N + 2)
        S, T = 2 * N, 2 * N + 1
        for i in range(m):
            for j in range(n):
                if not valid[i][j]: continue
                idx = i * n + j
                # 学生作为「选择」, 用网络流选/不选
                d.add(S, idx, 1)
                d.add(idx + N, T, 1)
                # 冲突: 相邻 (奇偶) 不同时选
                for di, dj in [(-1, -1), (-1, 1), (1, -1), (1, 1)]:
                    ni, nj = i + di, j + dj
                    if 0 <= ni < m and 0 <= nj < n and valid[ni][nj]:
                        nidx = ni * n + nj
                        # i 不能和 ni 同时选
                        d.add(idx, nidx + N, 1)
        # 最大流 = 最小点覆盖(冲突图) → 最大独立集 = 满座位数 - 最小点覆盖 = 满座位数 - 最大流
        total = sum(1 for i in range(m) for j in range(n) if valid[i][j])
        return total - d.max_flow(S, T)
```

```python
import heapq

class Solution:
    def maxProbability(self, n, edges, succProb, start, end):
        g = [[] for _ in range(n)]
        for i, (u, v) in enumerate(edges):
            g[u].append((v, succProb[i]))
            g[v].append((u, succProb[i]))
        dist = [0] * n
        dist[start] = 1
        pq = [(-1, start)]
        while pq:
            d, u = heapq.heappop(pq)
            if -d <= dist[u]: continue
            dist[u] = -d
            for v, p in g[u]:
                if dist[u] * p > dist[v]:
                    dist[v] = dist[u] * p
                    heapq.heappush(pq, (-dist[v], v))
        return dist[end]
```

```python
import heapq
from typing import List

class Solution:
    def minCostConnectPoints(self, points: List[List[int]]) -> int:
        n = len(points)
        visited = [False] * n
        pq = [(0, 0)]
        total = 0
        while pq:
            d, u = heapq.heappop(pq)
            if visited[u]: continue
            visited[u] = True
            total += d
            for v in range(n):
                if not visited[v]:
                    w = abs(points[u][0] - points[v][0]) + abs(points[u][1] - points[v][1])

        return total
```

```python
import numpy as np

def count_spanning_trees(n, edges):
    """
    n 节点无向图, edges = [(u, v, w)]
    无权时 (w=1) 求生成树数
    """
    L = np.zeros((n, n))
    for u, v, w in edges:
        L[u][u] += 1
        L[v][v] += 1
        L[u][v] -= 1
        L[v][u] -= 1
    if n == 1: return 0
    L_sub = L[1:, 1:]
    det = np.linalg.det(L_sub)
    return round(det)
```

```python
    """带油量限制的最短路"""

    pq = [(0, start_state)]
    dist = {}
    while pq:
```

## 45. 组合数学视角

### 45.1 最大流 ↔ 最小割 ↔ 矩阵树定理

平面图 $G$ 中:
- 最大流 = 最小 s-t 切
- 对偶图 $\hat G$ 中,s-t 最短路 = 最小切
- 生成树个数 = $\det(L^*)$

三者在不同数学层面互相等价。

### 45.2 网络流与拟阵

最大权基问题: 在 matroid 上找权重最大的独立集。最小生成树是图拟阵(graphic matroid)上的最大权基;最大权独立集是子集和的拟阵上的最大权基。

### 45.3 二部图与拟阵交

最大匹配可视为两个拟阵的交。Birkhoff 定理: 完美匹配存在等价于 Hall 定理。

## 46. 实战: 写一个完整 Graph 包

```python
# graph.py
class Graph:
    def __init__(self, n):
        self.n = n
        self.adj = [[] for _ in range(n)]
    def add(self, u, v, w=1):
        self.adj[u].append((v, w))
    def add_undirected(self, u, v, w=1):
        self.add(u, v, w); self.add(v, u, w)
    def dijkstra(self, s):
        import heapq
        dist = [float('inf')] * self.n
        dist[s] = 0
        pq = [(0, s)]
        while pq:
            d, u = heapq.heappop(pq)
            if d > dist[u]: continue
            for v, w in self.adj[u]:
                nd = d + w
                if nd < dist[v]:
                    dist[v] = nd
                    heapq.heappush(pq, (nd, v))
        return dist
    def bfs(self, s):
        from collections import deque
        visited = [False] * self.n
        dist = [0] * self.n
        visited[s] = True
        q = deque([s])
        while q:
            u = q.popleft()
            for v, _ in self.adj[u]:
                if not visited[v]:
                    visited[v] = True
                    dist[v] = dist[u] + 1
                    q.append(v)
        return dist
```
