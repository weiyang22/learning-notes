# 15.01 凸包与旋转卡壳

---

## 1. Andrew 单调链凸包

先按坐标排序, 分别构造下凸壳和上凸壳。用**叉积**保证只保留左转(凸)顶点。$O(n\log n)$。

```python
def cross(o, a, b):
    return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])

def convex_hull(pts):
    pts = sorted(set(pts))
    if len(pts) <= 2: return pts
    def build(points):
        h = []
        for p in points:
            while len(h) >= 2 and cross(h[-2], h[-1], p) <= 0:
                h.pop()                   # 非左转则弹出, 保持凸性
            h.append(p)
        return h
    lower = build(pts)
    upper = build(pts[::-1])
    return lower[:-1] + upper[:-1]        # 去重首尾, 逆时针
```

> `cross <= 0` 弹出保留严格凸; 若需保留共线点用 `< 0`。

## 2. 旋转卡壳求直径(最远点对)

凸包上最远点对一定是**对踵点对**。用两条平行卡尺绕凸包旋转, 单调推进对踵点, $O(n)$。

```python
def rotating_calipers(hull):
    n = len(hull)
    if n == 2:
        return dist2(hull[0], hull[1])
    m = 0; j = 1; best = 0
    for i in range(n):
        ni = (i+1) % n
        # 推进 j 使三角形面积(叉积)最大 = 离边 i 最远的点
        while abs(cross(hull[i], hull[ni], hull[(j+1)%n])) > \
              abs(cross(hull[i], hull[ni], hull[j])):
            j = (j+1) % n
        best = max(best, dist2(hull[i], hull[j]), dist2(hull[ni], hull[j]))
    return best

def dist2(a, b):
    return (a[0]-b[0])**2 + (a[1]-b[1])**2
```

**应用**: 最远点对、最小宽度、最小外接矩形。

---

## 3. 为什么对踵点单调

随着枚举边 $i$ 逆时针转, 离该边最远的点也逆时针单调移动, 不会回退 → 整个过程 $j$ 只走一圈, 均摊 $O(n)$。

**竞赛中的地位**: 计算几何是 ACM/ICPC, NOI, LeetCode Hard 题的常见考点. 但**精度**问题经常坑人.

## 5.2 浮点数精度问题 (Critical Pitfall)

### 5.2.1 浮点数比较: 绝不能用 `==`

```python
# 错误!
if cross(o, a, b) == 0:
    # ...

# 正确: 用 eps 容差
EPS = 1e-9
if abs(cross(o, a, b)) < EPS:
    # ...
```

### 5.2.2 比较两个数的技巧

```python
def cmp(a, b):
    """返回 -1, 0, 1 表示 a < b, a == b, a > b"""
    if abs(a - b) < EPS:
        return 0
    return -1 if a < b else 1
```

### 5.2.3 整数几何: 一切用整数

**强烈推荐**: 如果输入是整数, 一切计算都用整数 (64-bit), 最后用 `sqrt()` 一次.

```python
# 错误: 全程浮点
def dist(a, b):
    return math.sqrt((a[0]-b[0])**2 + (a[1]-b[1])**2)

# 正确: 距离平方用整数, 距离用 sqrt
def dist2(a, b):
    return (a[0]-b[0])**2 + (a[1]-b[1])**2  # 整数

def dist(a, b):
    return math.sqrt(dist2(a, b))  # 最后才 sqrt
```

**为什么?** 浮点运算会累积误差. 多次叉积、点积后, 误差可能让原本应该 `> 0` 的结果变成 `< 0`.

### 5.2.4 Python 整数无溢出

Python 的整数是任意精度, 没有 64-bit 溢出问题. 这是 Python 比 C++ 安全的地方.

但 C++ 用户需要小心: 用 `long long`, 必要时用 `__int128`.

## 6. 叉积 (Cross Product) 深度剖析

叉积是计算几何的**第一公民**. 一切凸性、面积、共线判断都基于它.

## 6.1 叉积定义

二维向量 $\vec{OA} = (a_1, a_2)$, $\vec{OB} = (b_1, b_2)$ 的叉积:

$$\vec{OA} \times \vec{OB} = a_1 b_2 - a_2 b_1$$

**几何意义**: $\vec{OA} \times \vec{OB}$ = 由 O, A, B 构成的**有向平行四边形面积** (即三角形面积的 2 倍).

## 6.2 叉积符号的几何意义

设 $C = \vec{OA} \times \vec{OB}$.

| $C$ 的符号 | 含义 | 几何关系 |
|---|---|---|
| $C > 0$ | OA 在 OB 的**逆时针方向** | **左转** |
| $C < 0$ | OA 在 OB 的**顺时针方向** | **右转** |
| $C = 0$ | O, A, B **三点共线** | 共线 |

```text
        B
       /
      /  ← C > 0 (逆时针/左转)
     A
    /
   O

        B
        \
         \  ← C < 0 (顺时针/右转)
          A
         /
        O
```

## 6.3 叉积的性质

| 性质 | 公式 |
|---|---|
| 反交换律 | $\vec{OA} \times \vec{OB} = -\vec{OB} \times \vec{OA}$ |
| 结合律 (标量) | $(k \vec{OA}) \times \vec{OB} = k (\vec{OA} \times \vec{OB})$ |
| 分配律 | $\vec{OA} \times (\vec{OB} + \vec{OC}) = \vec{OA} \times \vec{OB} + \vec{OA} \times \vec{OC}$ |
| 自反 | $\vec{OA} \times \vec{OA} = 0$ |
| 模长 | $\|\vec{OA} \times \vec{OB}\| = \|\vec{OA}\|\|\vec{OB}\|\sin\theta$ |

**注意**: 三维叉积是向量 (有方向), 二维叉积是**标量** (只有 z 分量).

## 6.4 叉积的代码实现

```python
def cross(o, a, b):
    """
    o, a, b 是点 (x, y).
    返回值:
      > 0: o → a → b 是逆时针 (左转)
      < 0: 顺时针 (右转)
      = 0: 共线
    """
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])
```

**等价写法**:
```python
# 用向量
def cross_v(va, vb):
    return va[0] * vb[1] - va[1] * vb[0]
```

## 6.5 叉积的应用: 凸包判定

```python
def is_convex(polygon):
    """判断多边形是否是凸多边形"""
    n = len(polygon)
    if n < 3:
        return False
    sign = 0
    for i in range(n):
        a = polygon[i]
        b = polygon[(i + 1) % n]
        c = polygon[(i + 2) % n]
        c = cross(a, b, c)
        if c != 0:
            if sign == 0:
                sign = c
            elif c * sign < 0:  # 符号不一致, 不凸
                return False
    return True
```

**复杂度**: $O(n)$.

## 6.6 叉积的应用: 线段相交

```python
def segment_intersect(p1, p2, p3, p4):
    """
    判断线段 p1p2 与 p3p4 是否相交 (含端点).
    使用跨立实验 (straddle test).
    """
    d1 = cross(p3, p4, p1)
    d2 = cross(p3, p4, p2)
    d3 = cross(p1, p2, p3)
    d4 = cross(p1, p2, p4)

    if ((d1 > 0 and d2 < 0) or (d1 < 0 and d2 > 0)) and \
       ((d3 > 0 and d4 < 0) or (d3 < 0 and d4 > 0)):
        return True

    # 共线情况: 检查端点
    if d1 == 0 and on_segment(p3, p4, p1): return True
    if d2 == 0 and on_segment(p3, p4, p2): return True
    if d3 == 0 and on_segment(p1, p2, p3): return True
    if d4 == 0 and on_segment(p1, p2, p4): return True

    return False

def on_segment(p, q, r):
    """点 r 是否在线段 pq 上 (假设 p, q, r 共线)"""
    return min(p[0], q[0]) <= r[0] <= max(p[0], q[0]) and \
           min(p[1], q[1]) <= r[1] <= max(p[1], q[1])
```

**复杂度**: $O(1)$.

## 6.7 叉积的应用: 多边形面积

```python
def polygon_area(polygon):
    """Shoelace 公式 (鞋带公式) 计算多边形面积"""
    n = len(polygon)
    area = 0
    for i in range(n):
        j = (i + 1) % n
        area += polygon[i][0] * polygon[j][1]
        area -= polygon[j][0] * polygon[i][1]
    return abs(area) / 2
```

**复杂度**: $O(n)$.

**原理**: 叉积的有向面积累加. 逆时针为正, 顺时针为负, 取绝对值得到面积.

## 8. 凸包 (Convex Hull) 详解

## 8.1 什么是凸包?

**定义**: 给定点集 $P$, 其凸包是包含 $P$ 的**最小凸多边形**. 等价定义: $P$ 的凸包是 $P$ 中所有点的**凸组合**的集合.

**形式化**: $\text{Conv}(P) = \{\sum_i \lambda_i p_i \mid \lambda_i \geq 0, \sum_i \lambda_i = 1, p_i \in P\}$

## 8.2 凸包的直观理解

想象把一个橡皮筋套在所有点上, 松手后橡皮筋收缩到的形状就是凸包.

```text
   . .
  .   .
 .     .  ← 凸包
.       .
 .     .
  .   .   ← 凹包 (非凸)
   . .
```

## 8.3 凸包的应用场景

1. **最远点对**: 凸包上的对踵点对.
2. **凸多边形直径**: 旋转卡壳.
3. **最小外接矩形**: 凸包 + 旋转卡壳.
4. **凸多边形交**: 用半平面交.
5. **凸包分离 (SVM)**: 机器学习.
6. **Graham 扫描的预处理**: 找极点.

## 8.4 凸包算法 1: Andrew 单调链 (Monotone Chain)

**思路**: 排序后, 分别构造下凸壳和上凸壳.

**步骤**:
1. 按 (x, y) 字典序排序.
2. 构造下凸壳: 从左到右, 用叉积保证只左转.
3. 构造上凸壳: 从右到左, 同样只左转.
4. 拼接下凸壳和上凸壳 (去掉重复的端点).

```python
def convex_hull(pts):
    """Andrew 单调链凸包, 严格凸 (不含共线点)"""
    pts = sorted(set(pts))  # 排序 + 去重
    n = len(pts)
    if n <= 1:
        return pts

    def build(points):
        """构造一半凸壳"""
        h = []
        for p in points:
            while len(h) >= 2 and cross(h[-2], h[-1], p) <= 0:
                h.pop()
            h.append(p)
        return h

    lower = build(pts)
    upper = build(pts[::-1])
    return lower[:-1] + upper[:-1]
```

**复杂度**:
- 排序: $O(n \log n)$.
- 构造: 每个点最多入栈 1 次, 出栈 1 次, $O(n)$.
- 总: $O(n \log n)$.

**正确性证明**:
- 下凸壳按 x 升序遍历, 每加一个新点, 弹出所有"非左转"的栈顶点.
- 左转保证: 栈顶前两个点 + 新点形成逆时针三角形, 新点在"凸"的左侧.
- 弹出维护凸性.
- 最终栈是从左到右的"下"边界.
- 类似得到上边界.

**严格凸 vs 保留共线**:
- `cross <= 0` 弹出: 严格凸 (不含共线中间点).
- `cross < 0` 弹出: 保留所有共线点 (但中间点也在凸包上).

## 8.5 凸包算法 2: Graham 扫描

**思路**: 选最下最左的点为极点, 按极角排序, 然后单调栈.

```python
def graham_scan(pts):
    """Graham 扫描构造凸包"""
    pts = sorted(set(pts))
    if len(pts) <= 1:
        return pts

    # 找最下最左的点
    start = min(pts, key=lambda p: (p[1], p[0]))

    # 按极角排序
    import math
    def angle_key(p):
        if p == start:
            return (-1, 0, 0)
        dx, dy = p[0] - start[0], p[1] - start[1]
        return (math.atan2(dy, dx), dy * dy + dx * dx)

    pts.sort(key=angle_key)

    # Graham 扫描
    stack = []
    for p in pts:
        while len(stack) >= 2 and cross(stack[-2], stack[-1], p) <= 0:
            stack.pop()
        stack.append(p)

    return stack
```

**复杂度**: $O(n \log n)$ (排序主导).

**适用**: 凸包点可能不严格按 x 排序时.

## 8.6 凸包算法 3: Jarvis 步进 (Gift Wrapping)

**思路**: 从最左点开始, 每次找"最左转"的点, 像包礼物一样绕一圈.

```python
def jarvis_march(pts):
    """Jarvis 步进 (Gift Wrapping) 构造凸包"""
    pts = list(set(pts))
    n = len(pts)
    if n <= 2:
        return pts

    # 找最左点
    leftmost = min(range(n), key=lambda i: (pts[i][0], pts[i][1]))

    hull = []
    p = leftmost
    while True:
        hull.append(pts[p])
        # 找"最左转"的点 q (即所有其他点都在 pq 的右边)
        q = (p + 1) % n
        for i in range(n):
            if i == p:
                continue
            # cross(pts[p], pts[q], pts[i]) < 0 表示 q 应该换
            if cross(pts[p], pts[q], pts[i]) < 0:
                q = i
        p = q
        if p == leftmost:
            break

    return hull
```

**复杂度**:
- 最坏情况: $O(nh)$, 其中 $h$ 是凸包大小 (可能是 $n$).
- 适合**凸包很小**的情况.

## 8.7 凸包算法 4: 分治法

**思路**: 把点集拆成两半, 分别求凸包, 再合并.

**合并**: 用上下公切线把两个凸包连起来.

**复杂度**: $O(n \log n)$.

**实现**: 工业级库常用, 竞赛较少用.

## 8.8 凸包算法对比

| 算法 | 时间 | 空间 | 适用场景 |
|---|---|---|---|
| **Andrew** | $O(n \log n)$ | $O(n)$ | **通用首选** |
| Graham | $O(n \log n)$ | $O(n)$ | 不严格按 x 排序时 |
| Jarvis | $O(nh)$ | $O(h)$ | $h \ll n$ 时 (凸包小) |
| 分治 | $O(n \log n)$ | $O(n)$ | 工业级 |
| 暴力 | $O(n^3)$ | $O(n)$ | 仅验证用 |
| Quickhull | 期望 $O(n)$ | $O(n)$ | 平均更快, 最坏 $O(n^2)$ |

**Andrew 是默认选择**: 简单、稳定、最优复杂度.

## 9. 旋转卡壳 (Rotating Calipers) 详解

## 9.1 什么是旋转卡壳?

**定义**: 用两条平行的"卡尺" (直线) 夹住凸包, 然后绕凸包旋转, 解决各种"凸包对踵点"问题.

**对踵点对 (Antipodal Pair)**: 凸包上能同时被两条平行线夹住的两个点.

```text
       ____________
      /            \
     /  p_i         \
    /          p_j   \
   |                |
    \              /
     \            /
      \__________/
```

## 9.2 旋转卡壳的核心原理

**关键观察**: 当一条边 $i \to i+1$ 旋转到下一条边时, 对应的对踵点 $j$ 也单调移动 (逆时针或顺时针), 不会回退.

**因此**: 整个过程 $j$ 最多绕凸包一圈, 总操作 $O(n)$.

## 9.3 旋转卡壳模板

```python
def rotating_calipers_template(hull):
    """
    旋转卡壳通用模板.
    对每个对踵关系 (i, j), 处理一次.
    """
    n = len(hull)
    if n == 1:
        return 0
    if n == 2:
        return dist2(hull[0], hull[1])

    res = 0  # 累积答案
    j = 1
    for i in range(n):
        ni = (i + 1) % n
        # 推进 j 直到下一个 j+1 让叉积更大
        while abs(cross(hull[i], hull[ni], hull[(j + 1) % n])) > \
              abs(cross(hull[i], hull[ni], hull[j])):
            j = (j + 1) % n
        # 此时 (i, j) 是对踵点对, 处理 (i, j) 和 (ni, j) (因为边 ni 的对踵点也是 j 或 j 的下一个)

    return res
```

## 10.5 经典: 半平面交 (Half-plane Intersection)

**问题**: 给若干条直线 (每条定义一个半平面), 求所有半平面的交.

**应用**: 线性规划可视化, 凸多边形核, 凸包交.

```python
def half_plane_intersection(half_planes):
    """
    半平面交 (双端队列算法).
    half_planes: 列表, 每个元素是 (point1, point2) 表示有向直线 (左侧是半平面).
    """
    from collections import deque
    import math

    EPS = 1e-9

    def line_intersection(l1, l2):
        """求两条直线的交点"""
        p1, p2 = l1
        p3, p4 = l2
        d1 = cross(p3, p4, p1)
        d2 = cross(p3, p4, p2)
        # 注意: 假设 l1 和 l2 不平行
        t = d1 / (d1 - d2)
        return (p1[0] + t * (p2[0] - p1[0]), p1[1] + t * (p2[1] - p1[1]))

    def on_left(l, p):
        """点 p 是否在半平面 l 的左侧"""
        return cross(l[0], l[1], p) >= 0

    # 按角度排序
    half_planes.sort(key=lambda l: math.atan2(l[1][1] - l[0][1], l[1][0] - l[0][0]))

    dq = deque()
    for hp in half_planes:
        # 弹出队尾不再满足的
        while len(dq) >= 2 and not on_left(hp, line_intersection(dq[-1], dq[-2])):
            dq.pop()
        # 弹出队首
        while len(dq) >= 2 and not on_left(hp, line_intersection(dq[0], dq[1])):
            dq.popleft()
        dq.append(hp)

    return list(dq)
```

**复杂度**: $O(n \log n)$.

## 11.3 凸包闵可夫斯基和 (Minkowski Sum)

**问题**: 两个凸包的闵可夫斯基和: $A + B = \{a + b \mid a \in A, b \in B\}$.

**应用**: 凸多边形平移后求交.

```python
def minkowski_sum(A, B):
    """两个凸多边形的闵可夫斯基和"""
    # 把 A 和 B 的边按极角排序
    # 合并边, 起点对齐
    A = list(A)
    B = list(B)
    n, m = len(A), len(B)

    # 找 A, B 的最低点 (字典序最小)
    def lowest(pts):
        return min(range(len(pts)), key=lambda i: (pts[i][1], pts[i][0]))

    i, j = lowest(A), lowest(B)
    i0, j0 = i, j
    res = [A[i][0] + B[j][0]]

    while i != i0 or j != j0:
        # 下一条边
        ni = (i + 1) % n
        nj = (j + 1) % m
        # 比较两条边的方向
        cross_val = cross(A[i], A[ni], B[j])
        if cross_val >= 0:
            j = nj
        if cross_val <= 0:
            i = ni
        res.append(A[i][0] + B[j][0])

    return res[:-1]  # 去重最后一点
```

**复杂度**: $O(n + m)$.

## 12. 凸包与旋转卡壳的复杂度理论

## 12.1 下界

凸包问题的**输出敏感下界**: $\Omega(n \log n + h)$, 其中 $h$ 是凸包大小.

- $\Omega(n \log n)$: 因为排序可以归约到凸包 (排序的下界是 $\Omega(n \log n)$).
- $\Omega(h)$: 因为输出大小至少 $h$.

## 12.2 各种算法的复杂度

| 算法 | 时间 | 输出敏感 |
|---|---|---|
| Andrew | $O(n \log n)$ | 否 |
| Graham | $O(n \log n)$ | 否 |
| Jarvis | $O(nh)$ | **是** |
| Quickhull | 期望 $O(n)$ | 是 (期望) |
| Kirkpatrick-Seidel | $O(n \log h)$ | **是** |

**Kirkpatrick-Seidel 算法**: $O(n \log h)$ 是最优的输出敏感算法, 但实现复杂.

## 12.3 旋转卡壳的复杂度

旋转卡壳在**凸包已经建好**的前提下是 $O(n)$, 加上建凸包的 $O(n \log n)$ 总 $O(n \log n)$.

如果凸包退化 (例如三角形), 旋转卡壳退化为 $O(3) = O(1)$.

```python
def sat_collision(A, B):
    """两个凸多边形是否碰撞 (SAT)"""
    # 枚举所有边作为分离轴
    for poly in [A, B]:
        for i in range(len(poly)):
            p1 = poly[i]
            p2 = poly[(i + 1) % len(poly)]
            # 分离轴是边的法线
            axis = (p2[1] - p1[1], -(p2[0] - p1[0]))
            # 在这条轴上投影两个多边形
            proj_A = [dot(axis, p) for p in A]
            proj_B = [dot(axis, p) for p in B]
            if max(proj_A) < min(proj_B) or max(proj_B) < min(proj_A):
                return False  # 分离轴存在, 不碰撞
    return True  # 没有分离轴, 碰撞
```

## 18. 凸包与旋转卡壳的面试高频问题

## 18.1 必会问题

### Q1: 凸包如何保证凸性?
**A**: 用叉积判左转. 构造过程中, 如果新点加入时, 栈顶前两点和新点不构成左转 (即叉积 $\leq 0$), 就弹出栈顶点.

### Q2: 为什么 Andrew 算法是 $O(n \log n)$?
**A**: 排序占主导 ($O(n \log n)$), 单调链构造每个点最多入栈出栈各一次 ($O(n)$).

### Q3: 最远点对为什么一定在凸包上?
**A**: 反证. 如果最远点对中某点 P 不在凸包上, 那么 P 严格在凸包某条边 AB 的同一侧. 在 AB 上延长线找 P', 那么 P' 距离对端点至少和 P 一样远 (画图可证). 因此最远点对必在凸包顶点上.

### Q4: 旋转卡壳为什么是 $O(n)$?
**A**: 凸包上一条边旋转时, 对应的对踵点也单调地旋转, 不会回退. 所以对踵点 j 最多绕凸包一圈, 总 $O(n)$.

### Q5: 凸包什么时候用 < 0 vs <= 0?
**A**:
- 严格凸 (不含共线中间点): `cross <= 0` 时弹出.
- 保留共线中间点: `cross < 0` 时弹出.

## 18.2 加分问题

### Q6: 凸包能用哪些排序方式?
**A**: Andrew 按 (x, y) 字典序, Graham 按极角, Jarvis 不需要排序.

### Q7: 半平面交和凸包什么关系?
**A**: 半平面交是多边形核问题的基础. 给定凸多边形的每条边 (作为半平面), 求交就是核.

### Q8: 凸包闵可夫斯基和有什么用?
**A**: 凸多边形 A 和 B 的和也是凸多边形. 用于凸多边形平移后求交: $A \cap (B + \vec{v}) \neq \emptyset \Leftrightarrow \vec{v} \in A \ominus B$ (差).

### Q9: 凸包碰撞检测的时间复杂度?
**A**: SAT 算法 $O(n + m)$, 其中 n, m 是两个凸多边形的边数.

### Q10: 凸包重建从周长可以吗?
**A**: 可以, 但凸包重建需要至少 3 个不共线的点. 给定周长能确定凸多边形的边长序列 (Niven 定理).

## 19. 凸包与旋转卡壳的算法总结

## 19.1 核心洞察

凸包 + 旋转卡壳的核心是:

1. **凸包**: 把无序点集压缩成"边界".
2. **旋转卡壳**: 在边界上高效找"对踵点对".
3. **对踵点对的单调性**: 让旋转卡壳从 $O(n^2)$ 优化到 $O(n)$.

## 19.2 关键公式

- 叉积: $\vec{OA} \times \vec{OB} = (a_1 b_2 - a_2 b_1)$.
- 点积: $\vec{OA} \cdot \vec{OB} = a_1 b_1 + a_2 b_2$.
- 面积: $|cross|/2$.
- 距离平方: $(a_1 - b_1)^2 + (a_2 - b_2)^2$.

## 19.3 应用场景速查

| 场景 | 算法 |
|---|---|
| 围栏 (凸包) | Andrew |
| 最远点对 | 凸包 + 旋转卡壳 |
| 凸多边形判断 | 叉积 |
| 多边形面积 | Shoelace 公式 |
| 凸多边形交 | 半平面交 |
| 凸包碰撞 | SAT |
| 凸包平移求交 | 闵可夫斯基和 |

```python
import math

def cross(o, a, b):
    """叉积 (o->a) × (o->b)"""
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def dot(a, b):
    """点积"""
    return a[0] * b[0] + a[1] * b[1]

def dist2(a, b):
    """距离平方"""
    return (a[0] - b[0]) ** 2 + (a[1] - b[1]) ** 2

def dist(a, b):
    """距离"""
    return math.sqrt(dist2(a, b))

def vec(a, b):
    """a->b 向量"""
    return (b[0] - a[0], b[1] - a[1])

def add_vec(p, v):
    """p + v"""
    return (p[0] + v[0], p[1] + v[1])

def sub_vec(p, v):
    """p - v"""
    return (p[0] - v[0], p[1] - v[1])

def scale_vec(v, k):
    """k * v"""
    return (v[0] * k, v[1] * k)
```

## A.2 点与线

```python
def point_on_segment(p, a, b):
    """p 在线段 ab 上 (a, b, p 共线 + p 在 ab 范围内)"""
    if cross(a, b, p) != 0:
        return False
    return min(a[0], b[0]) <= p[0] <= max(a[0], b[0]) and \
           min(a[1], b[1]) <= p[1] <= max(a[1], b[1])

def point_in_segment_strictly(p, a, b):
    """p 在线段 ab 上 (不含端点)"""
    if cross(a, b, p) != 0:
        return False
    return min(a[0], b[0]) < p[0] < max(a[0], b[0]) and \
           min(a[1], b[1]) < p[1] < max(a[1], b[1])

def segment_intersect(p1, p2, p3, p4):
    """线段 p1p2 与 p3p4 相交 (含端点)"""
    d1 = cross(p3, p4, p1)
    d2 = cross(p3, p4, p2)
    d3 = cross(p1, p2, p3)
    d4 = cross(p1, p2, p4)

    if ((d1 > 0 and d2 < 0) or (d1 < 0 and d2 > 0)) and \
       ((d3 > 0 and d4 < 0) or (d3 < 0 and d4 > 0)):
        return True

    if d1 == 0 and point_on_segment(p1, p3, p4): return True
    if d2 == 0 and point_on_segment(p2, p3, p4): return True
    if d3 == 0 and point_on_segment(p3, p1, p2): return True
    if d4 == 0 and point_on_segment(p4, p1, p2): return True

    return False

def line_intersection(p1, p2, p3, p4):
    """直线 p1p2 与直线 p3p4 的交点 (假设不平行)"""
    d = cross(p1, p2, p3, p4) if False else (p2[0] - p1[0]) * (p4[1] - p3[1]) - (p2[1] - p1[1]) * (p4[0] - p3[0])
    if d == 0:
        return None  # 平行
    t = ((p3[0] - p1[0]) * (p4[1] - p3[1]) - (p3[1] - p1[1]) * (p4[0] - p3[0])) / d
    return (p1[0] + t * (p2[0] - p1[0]), p1[1] + t * (p2[1] - p1[1]))
```

```python
def polygon_area(polygon):
    """Shoelace 公式"""
    n = len(polygon)
    s = 0
    for i in range(n):
        j = (i + 1) % n
        s += polygon[i][0] * polygon[j][1] - polygon[j][0] * polygon[i][1]
    return abs(s) / 2

def is_convex(polygon):
    """判断凸多边形"""
    n = len(polygon)
    sign = 0
    for i in range(n):
        a = polygon[i]
        b = polygon[(i + 1) % n]
        c = polygon[(i + 2) % n]
        c_val = cross(a, b, c)
        if c_val != 0:
            if sign == 0:
                sign = c_val
            elif c_val * sign < 0:
                return False
    return True

def point_in_polygon(p, polygon):
    """点是否在多边形内 (射线法)"""
    n = len(polygon)
    inside = False
    j = n - 1
    for i in range(n):
        if ((polygon[i][1] > p[1]) != (polygon[j][1] > p[1])) and \
           (p[0] < (polygon[j][0] - polygon[i][0]) * (p[1] - polygon[i][1]) / (polygon[j][1] - polygon[i][1]) + polygon[i][0]):
            inside = not inside
        j = i
    return inside
```

```python
def convex_hull(pts):
    """Andrew 单调链凸包"""
    pts = sorted(set(pts))
    n = len(pts)
    if n <= 1:
        return pts

    def build(points):
        h = []
        for p in points:
            while len(h) >= 2 and cross(h[-2], h[-1], p) <= 0:
                h.pop()
            h.append(p)
        return h

    lower = build(pts)
    upper = build(pts[::-1])
    return lower[:-1] + upper[:-1]
```

**命题**: Andrew 算法返回的点集是输入点集的凸包.

**证明**:
1. **下凸壳正确性**: 按 x 升序遍历, 每加一个新点 $p$, 弹出栈顶所有让"栈顶前两点 + $p$"非左转的点.
   - 弹出后, 栈中任意连续 3 点构成左转 (逆时针).
   - 由数学归纳, 栈中的下边界是凸的.
2. **上凸壳正确性**: 类似, 上边界也是凸的.
3. **合并**: 下凸壳 + 上凸壳 = 凸包 (去掉重复端点).
4. **覆盖性**: 每个输入点要么在下凸壳, 要么在上凸壳, 要么在凸包内部 (因为凸包包含所有点).

**复杂度**:
- 排序: $O(n \log n)$.
- 构造: 每个点最多入栈出栈各 1 次, $O(n)$.
- 总: $O(n \log n)$.

## F.2 旋转卡壳的正确性证明

**命题**: 旋转卡壳遍历所有对踵点对, 复杂度 $O(n)$.

**证明**:
1. **对踵点对的定义**: 凸包上能同时被两条平行线夹住的两个点. 等价地, 存在一条边 $e_i$, 使点 $p_j$ 离 $e_i$ 最远.
2. **单调性**: 边 $e_i$ 旋转到 $e_{i+1}$ 时, 离新边最远的点也单调移动 (逆时针或顺时针), 不会回退.
   - 反证: 假设离 $e_i$ 最远的点是 $p_j$, 离 $e_{i+1}$ 最远的点是 $p_{j-1}$ (回退).
   - 那么 $p_j$ 离 $e_{i+1}$ 不如 $p_{j-1}$ 远.
   - 但 $p_{j-1}$ 在 $e_i$ 上也不如 $p_j$ 远.
   - 这与"对踵点对"的定义矛盾.
3. **复杂度**: $j$ 最多绕凸包一圈, 总 $O(h)$. 加上建凸包 $O(n \log n)$, 总 $O(n \log n)$.

## F.3 最远点对在凸包上的证明

**命题**: 任意点集 $P$ 的最远点对必在凸包 $\text{Conv}(P)$ 的顶点上.

**证明**:
- 反证: 设最远点对 $(A, B)$ 中 $A$ 不在凸包顶点上, 即 $A$ 在凸包某条边 $CD$ 的"内部" (严格在 $CD$ 上方).
- 那么存在 $A'$ 在 $CD$ 上 (或边上) 使 $|A'B| \geq |AB|$ (因为 $A'$ 在 $CD$ 上, 距 $B$ 最远的就是 $C$ 或 $D$).
- 但 $(A, B)$ 是最远点对, 矛盾.

因此 $A, B$ 都在凸包顶点上.

## 附录 J: 凸包与旋转卡壳的 10 大易错点

1. **排序时只按 x**: 必须按 (x, y) 字典序.
2. **叉积符号搞反**: `cross > 0` 是左转 (逆时针), 不是右转.
3. **共线点处理**: `<= 0` 弹出会丢共线点, `< 0` 弹出会保留.
4. **合并时重复**: 必须 `lower[:-1] + upper[:-1]`.
5. **空集 / 单点**: 必须先检查 `len(pts) <= 1`.
6. **浮点比较**: 用 eps 容差, 不要用 `==`.
7. **j 初始化**: 必须 `j = 1`, 不能 `j = 0`.
8. **旋转卡壳退化**: `n == 2` 时直接返回距离, 不进入循环.
9. **距离平方 vs 距离**: 凸包直径用距离平方, 避免 sqrt.
10. **画图调试**: 写完代码立即画图验证.

## 附录 M: 凸包与旋转卡壳的"为什么"

## M.1 为什么凸包用 Andrew 单调链?

因为:
1. **简单**: 排序 + 单调栈, 没有复杂数据结构.
2. **稳定**: 复杂度严格 $O(n \log n)$, 没有最坏情况退化.
3. **实用**: 实现 30 行, 调试方便.
4. **通用**: 适用于大多数场景.

## M.2 为什么旋转卡壳用单调推进?

因为对踵点具有**单调性**:
- 边从 $e_i$ 转到 $e_{i+1}$ 时, 对应的对踵点也单调推进.
- 这种单调性把 $O(n^2)$ 的枚举优化到 $O(n)$.
- 类似尺取法 (滑窗) 的单调推进.

## M.3 为什么用距离平方而不是距离?

因为:
1. **避免 sqrt**: sqrt 是慢运算, 而且引入浮点误差.
2. **整数安全**: 如果输入是整数, 距离平方仍是整数.
3. **比较正确**: $a^2 \leq b^2 \Leftrightarrow |a| \leq |b|$, 单调性保持.

虽然我们强调边界条件视角,但数学形式化提供了共同语言。机器学习的核心问题可以表达为:给定输入样本,学习一个映射函数,使得函数输出与真实目标的差距最小化。这个抽象捕捉了分类、回归、生成等大多数任务的本质。

进一步,优化目标通常加入正则化项来控制模型复杂度,平衡经验风险与模型容量。统计学习理论给出了泛化误差的上界,告诉我们模型越复杂并不一定越好——**奥卡姆剃刀**在数学上有严格的形式化。

偏差-方差分解是另一个核心框架:误差可以分解为模型偏差(欠拟合)、方差(过拟合)和不可约噪声三部分。理解这个分解有助于诊断模型表现、选择合适复杂度。

在数值稳定性方面,有几个常见陷阱: 浮点数精度有限、Log-Sum-Exp 计算要减去最大值、Softmax 在大数值下会溢出。这些工程细节常常决定一个模型能否在生产环境稳定运行。

**4. 信息论视角**

互信息衡量知道一个变量后,另一个变量不确定性减少的量。在机器学习中,它被广泛用于特征选择、表示学习、多模态对齐等场景。

KL 散度衡量两个概率分布的距离,在交叉熵损失、变分推断、策略梯度等场景无处不在。需要注意它是**不对称**的——不同方向有不同的解释。

**7. 实践建议**

结合 "凸包与旋转卡壳" 的特点,实践中有以下建议:

1. **数据优先**: 数据质量决定上限,模型只是逼近这个上限。把 50% 的时间投入到数据理解和清洗上,这条经验被无数实践证明。数据问题往往比模型问题更关键,但也更容易被忽视。

2. **基线先行**: 先用最简单的方法(如逻辑回归、规则)做基线,确认增益是来自方法还是数据。没有强基线的"创新"往往不靠谱。很多看似 fancy 的方法,在强基线面前提升有限。

3. **迭代式改进**: 不要追求一步到位,而是 baseline → 简单改进 → 高级方法 → 调优。每一步都用验证集确认有提升。每一步的提升幅度通常递减,要预期边际收益下降。

4. **失败案例分析**: 重点看模型做错的样本,往往能发现系统性问题。错误样本里藏着模型没学会的知识。把这些样本按错误类型分类,可以发现模型的薄弱点。

5. **A/B 测试**: 在生产环境做对照实验,用业务指标而非离线指标评估。离线指标只是手段,业务指标才是目的。指标可以被优化,但业务目标很难直接优化。

6. **监控与回滚**: 上线后持续监控关键指标,异常时快速回滚。任何线上系统都必须考虑"最坏情况",并预先设计好应对方案。

**8. 常见误解**

对 "凸包与旋转卡壳" 常见的误解包括:

1. **"模型越复杂越好"**: 实际上,简单模型 + 好数据往往优于复杂模型 + 烂数据。这条法则在实践中反复被验证。

2. **"训练 loss 越低越好"**: 训练 loss 低不代表泛化好,可能过拟合。要看验证集表现,做误差分析。

3. **"指标好就等于业务好"**: 离线指标与在线业务有 gap,必须做 A/B 测试。指标可以被优化,但业务目标很难直接优化。

4. **"新方法一定比旧方法好"**: 新方法通常针对特定场景,在你的场景未必更好。要谨慎评估,先复现,再改进。

5. **"开源即用"**: 开源代码与你的数据/工程栈往往有 gap,需要适配。盲目复用经常踩坑,要理解代码再做改动。
