# 15.03 扫描线算法

---

## 1. 核心思想

一条竖直线从左到右扫过平面, 在**关键事件点**(矩形左右边界)更新维护的数据结构。把二维问题降为"沿 x 轴的一维事件序列"。

### 1.1 几何视角

想象你拿着一把透明的尺子(扫描线)从左向右匀速划过整个平面。尺子虽然只占一个 x 位置, 但它"扫到"的整个 y 区间都是当前可见的。这种几何直觉有三大推论:

1. **状态只在边界变化**: 两个相邻事件之间, "哪些几何对象被穿过" 这个状态完全不变。因此贡献(面积/周长)可按段乘累加, 不必逐点扫描。
2. **离散坐标降维**: 矩形的 y 坐标是有限的几个值(2n 个), 连续 y 轴被压缩成 2n 个区间。复杂度由 $O(W)$(W = 坐标范围) 降到 $O(n)$。
3. **可平行推广**: x 轴换成 t, y 轴换成价格/状态 → 时间维度上的"扫描线"; x 轴换成空间, y 轴换成优先级 → 资源调度扫描线。

### 1.2 事件驱动范式

扫描线是**事件驱动 (event-driven)** 算法的典范。每个事件描述"在 x = x0 这个瞬间, 状态如何变化":

| 事件类型 | 含义 | 典型取值 |
| :--- | :--- | :--- |
| 入边 +1 | 矩形左边界, 区间开始被覆盖 | typ = +1 |
| 出边 -1 | 矩形右边界, 区间结束被覆盖 | typ = -1 |
| 询问 (only for 前缀和) | 在 x = q 给出当时覆盖值 | typ = 0 |

排序时必须先按 x 主键、再按 typ 次键(右边界先于左边界以避开零长度区间的双重计数), 或者更常见 — 用半开区间 `[x1, x2)` 严格区分。

### 1.3 时间复杂度推导

设矩形数 = n, y 离散化后得 m ≤ 2n 个区间。

- 排序事件: $O(n \log n)$
- 每次扫描线走到下一个事件, 用数据结构更新"被覆盖 y 长度":
  - 朴素数组扫: 每次 $O(m)$, 总 $O(n \cdot m) = O(n^2)$
  - **线段树懒标记**: 每次 $O(\log m) = O(\log n)$, 总 $O(n \log n)$
- 总复杂度: $O(n \log n)$ (线段树版)

## 2. 矩形面积并

$n$ 个矩形, 求覆盖总面积(重叠只算一次)。

- **事件**: 每个矩形贡献两个事件——左边界(+1 覆盖)、右边界(−1 覆盖)。
- 按 x 排序, 相邻事件间: `面积 += 当前被覆盖的 y 长度 × Δx`。
- 用**线段树**(离散化 y 坐标)维护"当前被覆盖的 y 总长度"。

### 2.1 朴素 O(n²) 版(可读性最高, 教学用)

```python
def rectangle_area_union(rects):
    """rects = [(x1,y1,x2,y2)]"""
    events = []                       # (x, y1, y2, type)
    ys = set()
    for x1,y1,x2,y2 in rects:
        events.append((x1, y1, y2, 1))    # 入边 +1
        events.append((x2, y1, y2, -1))   # 出边 -1
        ys.add(y1); ys.add(y2)
    ys = sorted(ys)
    yid = {y:i for i,y in enumerate(ys)}
    m = len(ys)
    cnt = [0]*(2*m)                    # 每个 y 区间被覆盖次数
    covered = [0.0]*(2*m)             # 被覆盖长度(此处用朴素统计示意)

    events.sort()
    area = 0.0; prev_x = events[0][0]
    def covered_len():
        return sum(ys[i+1]-ys[i] for i in range(m-1) if cnt[i] > 0)
    for x, y1, y2, typ in events:
        area += covered_len() * (x - prev_x)   # 累加上一段面积
        lo, hi = yid[y1], yid[y2]
        for i in range(lo, hi):                # 朴素区间更新(可换线段树)
            cnt[i] += typ
        prev_x = x
    return area
```

> 生产/竞赛用**线段树 lazy 维护覆盖长度**把区间更新降到 $O(\log n)$, 总 $O(n\log n)$; 上为可读的朴素版。

### 2.2 线段树版 O(n log n)(竞赛/工程必备)

```python
class SegTree:
    """
    线段树维护区间被覆盖总长度。
    - cover[i] > 0: 该节点代表的整个 y 区间被覆盖, length = 该区间总长
    - cover[i] == 0: 长度由左右子节点累加
    - 不需要 lazy 下推, 因为 cover 计数本身就在传递"是否被覆盖"。
    """
    def __init__(self, ys):
        self.ys = ys                  # 离散化坐标数组
        self.n = len(ys) - 1          # 区间数 (m-1)
        self.cnt = [0] * (4 * self.n) # 覆盖计数
        self.len = [0.0] * (4 * self.n)

    def update(self, node, l, r, ql, qr, val):
        """区间 [ql, qr) 计数 +val"""
        if ql >= r or qr <= l:
            return
        if ql <= l and r <= qr:
            self.cnt[node] += val
            self._pushup(node, l, r)
            return
        mid = (l + r) // 2
        self.update(node*2, l, mid, ql, qr, val)
        self.update(node*2+1, mid, r, ql, qr, val)
        self._pushup(node, l, r)

    def _pushup(self, node, l, r):
        if self.cnt[node] > 0:
            self.len[node] = self.ys[r] - self.ys[l]
        elif l + 1 == r:
            self.len[node] = 0.0
        else:
            self.len[node] = self.len[node*2] + self.len[node*2+1]

    def modify(self, y1, y2, val):
        """外层入口: 离散化区间索引"""
        lo = self._index(y1); hi = self._index(y2)
        self.update(1, 0, self.n, lo, hi, val)

    def _index(self, y):
        # 二分找 y 在 ys 中的位置; 实际可换成 dict 加速
        import bisect
        return bisect.bisect_left(self.ys, y)

    @property
    def length(self):
        return self.len[1]


def rectangle_area_union_v2(rects):
    """
    O(n log n) 版矩形面积并
    rects: List[Tuple[int, int, int, int]] = [(x1, y1, x2, y2)]
    """
    if not rects:
        return 0.0
    events = []
    ys = set()
    for x1, y1, x2, y2 in rects:
        events.append((x1, y1, y2, 1))
        events.append((x2, y1, y2, -1))
        ys.add(y1); ys.add(y2)
    ys = sorted(ys)
    seg = SegTree(ys)
    events.sort(key=lambda e: (e[0], e[3]))   # 出边在前: -1 < +1

    area = 0.0
    px = events[0][0]
    for i, (x, y1, y2, typ) in enumerate(events):
        if i > 0:
            area += seg.length * (x - px)
        seg.modify(y1, y2, typ)
        px = x
    return area
```

### 2.3 LeetCode 850 - 矩形面积 II

> 给定 N 个矩形, 求它们覆盖的精确面积(重叠只算一次)。答案误差在 $10^{-6}$ 内均可接受。

```python
class Solution:
    def rectangleArea(self, rectangles):
        events = []
        ys = set()
        for x1, y1, x2, y2 in rectangles:
            events.append((x1, y1, y2, 1))
            events.append((x2, y1, y2, -1))
            ys.add(y1); ys.add(y2)
        ys = sorted(ys)
        seg = SegTree(ys)
        events.sort()
        MOD = 10**9 + 7
        area = 0
        px = events[0][0]
        for i, (x, y1, y2, typ) in enumerate(events):
            if i > 0:
                area += seg.length * (x - px)
            seg.modify(y1, y2, typ)
            px = x
        return area % MOD
```

**复杂度**: $O(n \log n)$, $n$ = 矩形数。线段树的常数约为 8(树高 3)。

## 3. 天际线问题 (The Skyline Problem)

> LeetCode 218 - 给出 N 栋楼 (left, right, height), 求天际线轮廓的关键点。

### 3.1 思路

每栋楼拆成两个事件:

- `(left, -height)` 入边 — 出堆加 −height
- `(right, height)` 出边 — 待弹出 height

按 x 排序扫描, 用**最大堆**维护当前所有"还在飞"的楼的高度:

- 入边: push -h, 若 h > 当前最高则触发新关键点 (−h, h)
- 出边: 标记 lazy 删除, 等堆顶等于该 h 时再 pop

### 3.2 代码

```python
import heapq
from sortedcontainers import SortedList

class Solution:
    def getSkyline(self, buildings):
        events = []
        for l, r, h in buildings:
            events.append((l, -h, r))   # 入边用负高, 巧妙之处
            events.append((r, 0, 0))    # 出边高度 = 0
        events.sort()
        result = []
        heap = [(0, float('inf'))]      # (高度, 右边界)
        for x, neg_h, r in events:
            if neg_h:                    # 入边
                heapq.heappush(heap, (neg_h, r))
            while heap[0][1] <= x:       # 弹出失效的楼
                heapq.heappop(heap)
            h = -heap[0][0]
            if not result or h != result[-1][1]:
                result.append(([x, h]))
        return result
```

### 3.3 输出例

输入 `[[2,9,10],[3,7,15],[5,12,12],[15,20,10],[19,24,8]]` 输出:

```text
[[2,10],[3,15],[7,12],[12,0],[15,10],[20,8],[24,0]]
```

### 3.4 多解法对比

| 解法 | 时间 | 空间 | 备注 |
| :--- | :--- | :--- | :--- |
| 事件 + 最大堆 | $O(n \log n)$ | $O(n)$ | 标准, 工业首选 |
| 事件 + TreeMap (高度 → 计数) | $O(n \log n)$ | $O(n)$ | Java 写法, Python 用 `SortedList` |

| 朴素逐段 | $O(n \cdot W)$ | $O(W)$ | W = 坐标范围, 不可行 |

## 4. 矩形周长并

LeetCode 587 - 给定 N 个矩形, 求它们覆盖区域的精确周长。

### 4.1 思路

把"水平边"和"垂直边"分开算:

- **水平边**: 同一高度上覆盖长度发生变化的次数 × 2
- **垂直边**: 扫描线扫过 x 时, 覆盖长度从 L₁ 变到 L₂, 竖直贡献 = $|L_1 - L_2|$ 再按事件点累加

### 4.2 关键观察

- 矩形下边也算水平边 (高度 = y1, +2 长度)
- 矩形上边也算水平边 (高度 = y2, +2 长度)
- 两条水平边的"消失"和"出现"次数取决于是否相邻

### 4.3 代码

```python
class Solution:
    def rectanglePerimeter(self, rectangles):
        events = []
        ys = set()
        for x1, y1, x2, y2 in rectangles:
            # 下边进入, 上边退出
            events.append((x1, y1, y2, 1))
            events.append((x2, y1, y2, -1))
            ys.add(y1); ys.add(y2)
        ys = sorted(ys)
        seg = SegTree(ys)
        events.sort()

        perim = 0
        prev_len = 0
        prev_x = events[0][0]

        # 1. 累积事件间的水平横线 (top/bottom edge per segment)
        for i, (x, y1, y2, typ) in enumerate(events):
            if i > 0:
                dx = x - prev_x
                perim += 2 * seg.length    # 上下两条边界
            seg.modify(y1, y2, typ)
            prev_x = x

        # 2. 垂直边 = 每次事件时长度变化量的绝对值
        events2 = sorted(
            [(x1, y1, y2, 1) for x1,y1,x2,y2 in rectangles] +
            [(x2, y1, y2, -1) for x1,y1,x2,y2 in rectangles]
        )
        prev = 0
        seg2 = SegTree(ys)
        perim_v = 0
        for x, y1, y2, typ in events2:
            cur = seg2.length  # 在更新前的长度
            perim_v += abs(cur - seg2.length_after_modify(y1, y2, typ))
            prev = seg2.length
        return perim + perim_v
```

## 5. 线段相交对数

> 给定 $n$ 条垂直线段 $(x, y_1, y_2)$ 和 $m$ 条水平线段 $(y, x_1, x_2)$, 求所有垂直-水平交点对数。

### 5.1 思路

- 按 x 排序垂直线段: 进入事件 → 把 y 区间加入平衡树; 离开事件 → 移除
- 进入事件时, 询问水平线段的 y 落在哪些垂直段的 y 区间中: 用 interval tree 或 Fenwick

### 5.2 适用场景

- 计算机图形学: 多边形裁剪 / 区域边界检测
- VLSI 布图: 路由冲突检查

```python
from sortedcontainers import SortedList

def count_intersections(vertical, horizontal):
    """
    vertical: [(x1, y1, y2), ...]
    horizontal: [(y, x1, x2), ...]
    """
    events = []
    for x, y1, y2 in vertical:
        events.append((x, y1, y2, 'in'))
        events.append((x + 0.5, y1, y2, 'out'))   # 出边靠后
        # 简化: 假设 x 不重复, 用 (x, y, +1) 入和 (x, -y, -1) 出
    events.sort()

    active_ys = SortedList()
    hor = sorted(horizontal)

    res = 0
    j = 0
    for x, y1, y2, typ in events:
        while j < len(hor) and hor[j][0] < y2:   # 简化版
            j += 1
        if typ == 'in':
            active_ys.add((y1, y2))
        else:
            active_ys.discard((y1, y2))
    return res
```

### 5.3 多解法对比

| 解法 | 时间 | 备注 |
| :--- | :--- | :--- |
| 扫描线 + 区间树 | $O((n+m) \log n)$ | 通用 |
| 平面扫描 + BIT | $O((n+m) \log N)$ | y 离散化 + BIT |
| 暴力 | $O(nm)$ | n,m ≤ 100 |

## 6. 最近点对 (Closest Pair)

> 给定平面 n 个点, 求欧几里得距离最近的一对。

### 6.1 思路

- 按 x 排序所有点
- 扫描线逐个加入, 维护**宽度 ≤ d 的 y-ordered 候选带**
- 每个点只需和后续 O(1) 个候选比较 → 总 $O(n \log n)$

### 6.2 代码

```python
import math

def closest_pair(points):
    points.sort()                       # 按 x 排序
    best = math.inf

    # active: 按 y 排序的列表, x 在 [px - best, px]
    active = []

    def remove_outside(px, best):
        while active and active[0][0] < px - best:
            active.pop(0)

    left = 0
    for x, y in points:
        # 二分搜索 y 范围 [y - best, y + best]
        # 简化用 bisect
        import bisect
        ys = [p[1] for p in active]
        lo = bisect.bisect_left(ys, y - best)
        hi = bisect.bisect_right(ys, y + best)
        for _, ay in active[lo:hi]:
            d = math.hypot(x - _, y - ay)
            if d < best:
                best = d
        # 插入新点
        bisect.insort(ys, y)
        # 重新同步 active 不优雅, 改用 SortedList
        active.append((x, y))
        # 清理离开窗的
        while active and active[0][0] < x - best:
            active.pop(0)
    return best
```

| 解法 | 时间 | 备注 |
| :--- | :--- | :--- |
| 分治 (经典) | $O(n \log n)$ | 课堂首选 |
| 扫描线 (Sweep) | $O(n \log n)$ | 与分治等价, 易实现 |
| KD-Tree | $O(n^{1+\epsilon})$ | 高维推广 |
| 暴力 | $O(n^2)$ | n ≤ 10³ |

## 7. 通用套路

1. **离散化**坐标(y 值可能很大)。
2. 把几何对象拆成**事件**(进入/离开)。
3. 按扫描方向**排序事件**。
4. 用合适数据结构(线段树/堆/平衡树)维护当前状态。
5. 相邻事件间累加贡献。

### 7.1 选型表

| 场景 | 主数据结构 | 备注 |
| :--- | :--- | :--- |
| 矩形面积并 / 周长并 | 线段树 + 计数懒标记 | 经典 |
| 天际线 | 最大堆 + 懒删除 | event 加负高度巧妙 |
| 线段相交 | 平衡树 / BIT | y 离散化 |
| 最近点对 | y-ordered SortedList | 宽度 = 当前最优 |
| 区间染色 | 线段树 (区间赋值) | 与"覆盖长度"不同, 需 pushdown |

### 7.2 调试技巧

- **画图**: 5 个矩形以内用手画验证
- **debug print**: 每个事件打印当前 seg.length
- **小数据对比**: 朴素版与线段树版答案必须 ≤ 1e-6
- **边界**: 单矩形 / 全重叠 / 全不重叠 / y 坐标相等

## 8. 线段树模板(覆盖长度版)

```python
class SegTree:
    """
    维护区间被覆盖的总长度。
    - cnt > 0: 整个区间被覆盖, len = 区间长度
    - cnt == 0 且非叶: len = 左 + 右
    - cnt == 0 且叶: len = 0
    """
    def __init__(self, ys):
        self.ys = ys
        self.n = len(ys) - 1
        self.cnt = [0] * (4 * max(self.n, 1))
        self.len = [0.0] * (4 * max(self.n, 1))

    def _pushup(self, node, l, r):
        if self.cnt[node] > 0:
            self.len[node] = self.ys[r] - self.ys[l]
        elif l + 1 == r:
            self.len[node] = 0.0
        else:
            self.len[node] = self.len[node*2] + self.len[node*2+1]

    def update(self, node, l, r, ql, qr, val):
        if ql >= r or qr <= l:
            return
        if ql <= l and r <= qr:
            self.cnt[node] += val
            self._pushup(node, l, r)
            return
        mid = (l + r) // 2
        self.update(node*2, l, mid, ql, qr, val)
        self.update(node*2+1, mid, r, ql, qr, val)
        self._pushup(node, l, r)

    def modify(self, y1, y2, val):
        lo = bisect_left(self.ys, y1)
        hi = bisect_left(self.ys, y2)
        self.update(1, 0, self.n, lo, hi, val)

    @property
    def length(self):
        return self.len[1]
```

### 8.1 适用扩展

- 矩形覆盖最值(被覆盖 y 的最大/最小值): 维护 max/min

## 11. 面试高频

1. 矩形面积并如何避免重复? → 扫描线 + 覆盖计数, 只统计被覆盖 y 长度。
2. 为什么要离散化? → y 坐标范围大, 映射到下标建线段树。
3. 扫描线本质? → 降维: 二维几何 → 一维事件序列。
4. 为什么 cnt=0 时长度由子节点累加? → 该区间未被任何矩形覆盖, 但子区间可能部分覆盖。
5. 怎么从面积并扩展到周长并? → 水平边看覆盖长度变化次数, 垂直边看相邻事件长度差。
6. 事件排序时出入边如何区分? → 出边先于入边排序, 或用半开区间 `[x1, x2)`。
7. 线段树懒标记 vs pushdown? → 覆盖计数 cnt 本身"可传递覆盖信息", 不需要 pushdown。
8. 天际线为啥堆顶是负高度? → Python 默认最小堆, 取负号模拟最大堆。
9. 最近点对为何只需要 O(1) 后继比较? → 最小 d 确定的"候选带"宽度有限, 后继点数有上界。
10. 离散化时为什么同时收 y1 和 y2? → 矩形覆盖的是 [y1, y2) 半开区间, 端点必须都出现。

## 12. 进阶: 区间染色与并查集优化

并查集能把"离散化区间"做合并, 区间染色从 $O(n \log n)$ 降到 $O(n \alpha)$。

### 12.1 用法: 无重叠着色

```python
class UnionFind:
    def __init__(self, n):
        self.p = list(range(n + 1))
    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x
    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx != ry:
            self.p[rx] = ry

def paint_intervals(intervals, m):
    """
    intervals: [(l, r)] 半开区间
    m: 离散坐标数组长度
    返回每个区间被涂的颜色 (1-based)
    """
    parent = list(range(m + 1))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    color = [-1] * m
    def paint(l, r, c):
        i = find(l)
        while i < r:
            color[i] = c
            parent[i] = i + 1
            i = find(i)

    for l, r in intervals:
        paint(l, r, 1)
```

### 12.2 何时用

- 仅插入, 不删除
- 需要"下一个未涂位置"
- 必须 $O(n \alpha)$, 近乎常数

## 16. 常见错误清单

| 错误 | 症状 | 修正 |
| :--- | :--- | :--- |

## 17. 工程实现: 工业级扫描线包装

```python
class SweepLineEngine:
    """
    通用扫描线引擎。给定事件 + 维护器, 自动累加贡献。
    """
    def __init__(self, coord_extractor, area_per_segment=None):
        self.events = []
        self.coord_extractor = coord_extractor
        self.area_per_segment = area_per_segment or (lambda prev, cur, state: 0)

    def add_event(self, x, **kwargs):
        self.events.append((x, kwargs))

    def run(self, initial_state):
        events = sorted(self.events, key=lambda e: e[0])
        prev_x = events[0][0]
        state = initial_state
        result = 0
        for i, (x, kw) in enumerate(events):
            if i > 0:
                result += self.area_per_segment(prev_x, x, state)
            state.update(**kw)
            prev_x = x
        return result
```

## 18. 总结

扫描线 = **事件 + 数据结构 + 段累加**。掌握以下三类问题即可应对 80% 面试:

1. **矩形面积并 / 周长并 / 完美矩形**: 线段树计数
2. **天际线**: 最大堆 + 懒删除
3. **线段相交 / 最近点对**: 平衡树 / SortedList 维护活跃集

**核心口诀**:
- 离散坐标压下标, 线段树懒标记维护计数
- 事件按 x 排, 出边先于入边
- 相邻事件间贡献 = 当前状态 × Δx (或 Δy)
- 不变式: cnt > 0 → 整段覆盖; cnt = 0 → 由子节点决定

### 19.1 LC 218 - The Skyline Problem

**题目**: 一座城市的天际线是从远处观看该城市时所有建筑物形成的轮廓的外部轮廓。给定所有建筑物的位置和高度, 返回由这些建筑物形成的天际线。

```python
from heapq import heappush, heappop

class Solution:
    def getSkyline(self, buildings):
        # 关键: 入边用负高度, 出边用正高度 (使排序时入边在前)
        events = []
        for l, r, h in buildings:
            events.append((l, -h, r))   # 入边
            events.append((r, 0, 0))    # 出边 (高度=0 不会影响)

        events.sort()  # 按 (l, h, r) 排序: 出边 0 排在入边 -h 前

        result = []
        heap = [(0, float('inf'))]  # (高度, 右边界), 默认 (0, ∞) 表示地面

        for x, neg_h, r in events:
            if neg_h:
                heappush(heap, (neg_h, r))
            # 移除已结束的楼
            while heap[0][1] <= x:
                heappop(heap)
            cur_h = -heap[0][0]
            if not result or result[-1][1] != cur_h:
                result.append([x, cur_h])
        return result
```

**复杂度**: $O(n \log n)$

**思路详解**:
- 每栋楼的轮廓由矩形构成, 矩形的高 = 楼高、底 = 楼左右边界
- 在 x 轴方向扫描, 维护"活跃"楼的集合, 每次取最高
- 关键技巧: 把入边高度取负, 出边高度取 0, 这样排序时同一 x 的出边先于入边处理(0 > −h) - 避免 x = 右边界时输出点的逻辑混乱

**易错点**:
- 忘记去除已结束的楼 → 堆中残留旧楼导致答案错误
- 没有用懒删除 (lazy removal) → TLE
- 输出末尾需要包含"落回地面"的点, 通常 ``最后x, 0`` 由最后一个出边自动产生

### 19.2 LC 850 - Rectangle Area II

**题目**: 给出一个二维平面上的矩形列表, 计算由这些矩形覆盖的精确面积。每个矩形由左下角的 `(x1, y1)` 和右上角的 `(x2, y2)` 定义。答案需要保证在 $10^{-6}$ 的误差范围内。

```python
from bisect import bisect_left

class SegTree:
    def __init__(self, ys):
        self.ys = ys
        self.n = max(len(ys) - 1, 1)
        self.cnt = [0] * (4 * self.n)
        self.length = [0.0] * (4 * self.n)

    def _pushup(self, node, l, r):
        if self.cnt[node] > 0:
            self.length[node] = self.ys[r] - self.ys[l]
        elif l + 1 >= r:
            self.length[node] = 0.0
        else:
            self.length[node] = self.length[node*2] + self.length[node*2+1]

    def update(self, node, l, r, ql, qr, val):
        if ql >= r or qr <= l:
            return
        if ql <= l and r <= qr:
            self.cnt[node] += val
            self._pushup(node, l, r)
            return
        mid = (l + r) // 2
        self.update(node*2, l, mid, ql, qr, val)
        self.update(node*2+1, mid, r, ql, qr, val)
        self._pushup(node, l, r)

    def modify(self, y1, y2, val):
        lo = bisect_left(self.ys, y1)
        hi = bisect_left(self.ys, y2)
        self.update(1, 0, self.n, lo, hi, val)

class Solution:
    def rectangleArea(self, rects):
        MOD = 10**9 + 7
        events = []
        ys = []
        for x1, y1, x2, y2 in rects:
            events.append((x1, y1, y2, 1))
            events.append((x2, y1, y2, -1))
            ys.extend([y1, y2])
        ys = sorted(set(ys))
        seg = SegTree(ys)
        events.sort()

        area = 0.0
        px = events[0][0]
        for i, (x, y1, y2, typ) in enumerate(events):
            if i > 0:
                area += seg.length[1] * (x - px)
            seg.modify(y1, y2, typ)
            px = x
        return int(area) % MOD
```

**复杂度**: $O(n \log n)$, $n$ = 矩形数

**思路详解**:
1. 离散化 y 坐标
2. 排序事件(按 x, 出边先于入边)
3. 相邻事件间贡献 = 当前覆盖 y 总长 × Δx
4. 用线段树维护"被覆盖 y 总长度", cnt > 0 时长度 = 整个区间长, 否则 = 子节点之和

### 19.3 LC 391 - Perfect Rectangle

**题目**: 给定二维平面上的若干矩形, 判断它们是否能拼成一个"完美矩形"——即所有矩形无重叠、无间隙地组成一个完整矩形。

```python
class Solution:
    def isRectangleCover(self, rectangles):
        # 思路 1: 顶点面积匹配
        # 总面积应 = 大矩形面积
        # 检查顶点的"奇偶性": 完美矩形中, 大矩形的 4 个角出现奇数次, 其他点偶数次
        # 思路 2 (更简洁): 离散化扫描线

        area = 0
        min_x, min_y = float('inf'), float('inf')
        max_x, max_y = -float('inf'), -float('inf')
        corner = set()

        for x1, y1, x2, y2 in rectangles:
            area += (x2 - x1) * (y2 - y1)
            min_x, min_y = min(min_x, x1), min(min_y, y1)
            max_x, max_y = max(max_x, x2), max(max_y, y2)
            for px, py in [(x1, y1), (x1, y2), (x2, y1), (x2, y2)]:
                if (px, py) in corner:
                    corner.remove((px, py))
                else:
                    corner.add((px, py))

        big_area = (max_x - min_x) * (max_y - min_y)
        if area != big_area:
            return False
        # 大矩形 4 角必须出现在 corner 中, 且无其他
        return corner == {(min_x, min_y), (min_x, max_y),
                          (max_x, min_y), (max_x, max_y)}
```

**复杂度**: $O(n)$

**思路亮点**:
- 矩形并的总面积 = 大矩形的面积 (否则一定有重叠或空隙)
- 大矩形的 4 个角在合并图中出现奇数次; 其他顶点出现偶数次(可被配对)
- 这是 O(1) 空间的"扫描线"检测版

### 19.4 LC 587 - Erect the Fence (凸包, 非扫描线但相关)

**题目**: 给定树的位置数组, 用最少的绳子围出包含所有树的凸多边形。

```python
class Solution:
    def outerTrees(self, points):
        # Andrew's monotone chain 算法
        points.sort()

        def cross(o, a, b):
            return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

        lower = []
        for p in points:
            while len(lower) >= 2 and cross(lower[-2], lower[-1], p) < 0:
                lower.pop()
            lower.append(p)

        upper = []
        for p in reversed(points):
            while len(upper) >= 2 and cross(upper[-2], upper[-1], p) < 0:
                upper.pop()
            upper.append(p)

        return list(set(lower + upper))[:-1]  # 去重首尾
```

**复杂度**: $O(n \log n)$

```python
class Solution:

        # 找矩形中离圆心最近的点
        nx = max(x1, min(x_center, x2))
```

### 19.7 LC 1229 - Meeting Scheduler

**题目**: 给定两人的可用时段和会议时长, 返回一个可行的会议时间。

```python
class Solution:
    def minAvailableDuration(self, slots1, slots2, duration):
        # 经典: 双指针扫描
        slots1.sort()
        slots2.sort()
        i = j = 0
        while i < len(slots1) and j < len(slots2):
            start = max(slots1[i][0], slots2[j][0])
            end = min(slots1[i][1], slots2[j][1])
            if end - start >= duration:
                return [start, start + duration]
            if slots1[i][1] < slots2[j][1]:
                i += 1
            else:
                j += 1
        return []
```

**思路**: 区间合并 + 双指针 (扫描线的简化版)。

### 20.1 区间合并 (LC 56, 57, 1288)

```python
        self.t = [0] * (n + 1)
    def update(self, i, v=1):
```

```python
        prefix = [0]

            all_vals.update([p, p - lower, p - upper])

        res = 0
        for p in prefix:
            r_lo = rank[p - upper]
            r_hi = rank[p - lower]
            res += fw.query(r_hi) - fw.query(r_lo - 1)
            fw.update(rank[p])
```

```python
def graham_scan(points):
    points = sorted(points)
    if len(points) <= 1:
        return points
    def cross(o, a, b):
        return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])
    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)
    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)
    return lower[:-1] + upper[:-1]
```

## 24. 扫描线 + KD-Tree

KD-Tree 把"几何最近点"问题优化到 $O(n^{1+\epsilon})$。

### 24.1 简要实现

```python
class KDNode:
    __slots__ = ('point', 'axis', 'left', 'right')
    def __init__(self, point, axis):
        self.point = point
        self.axis = axis
        self.left = None
        self.right = None

def build_kdtree(points, depth=0):
    if not points:
        return None
    axis = depth % 2  # 假设 2D
    points.sort(key=lambda p: p[axis])
    mid = len(points) // 2
    node = KDNode(points[mid], axis)
    node.left = build_kdtree(points[:mid], depth + 1)
    node.right = build_kdtree(points[mid+1:], depth + 1)
    return node
```

### 24.2 在扫描线中的作用

- "最近点对" 改为 KD-Tree 后不需排序扫描, 但常数大
- "矩形最近点" (LC 973) 是 KD-Tree 经典应用

### 31.1 区间扫描线 (合并 / 加和 / 染色)

```python
from bisect import bisect_left, insort

class IntervalScanner:
    """
    半开区间扫描器: [l, r)
    """
    def __init__(self):
        self.points = []   # 所有区间端点 (有序)
        self.delta = {}

    def add(self, l, r, val):
        self.delta[l] = self.delta.get(l, 0) + val
        self.delta[r] = self.delta.get(r, 0) - val
        # 维护端点
        if l not in self.points:
            insort(self.points, l)
        if r not in self.points:
            insort(self.points, r)

    def scan(self, x_query):
        cur = 0
        for x in self.points:
            if x > x_query:
                break
            cur += self.delta.get(x, 0)
        return cur

    def max_value(self):
        cur = best = 0
        for x in sorted(self.delta):
            cur += self.delta[x]
            best = max(best, cur)
        return best
```

### 31.2 几何扫描线 (覆盖长度)

```python
class GeometricSweep:
    """
    几何扫描线维护覆盖长度
    """
    def __init__(self, ys):
        from bisect import bisect_left
        self.ys = sorted(set(ys))
        self.n = max(len(self.ys) - 1, 1)
        self.cnt = [0] * (4 * self.n)
        self.length = [0.0] * (4 * self.n)

    def update(self, node, l, r, ql, qr, val):
        if ql >= r or qr <= l:
            return
        if ql <= l and r <= qr:
            self.cnt[node] += val
            self._pushup(node, l, r)
            return
        mid = (l + r) // 2
        self.update(node*2, l, mid, ql, qr, val)
        self.update(node*2+1, mid, r, ql, qr, val)
        self._pushup(node, l, r)

    def _pushup(self, node, l, r):
        if self.cnt[node] > 0:
            self.length[node] = self.ys[r] - self.ys[l]
        elif l + 1 >= r:
            self.length[node] = 0
        else:
            self.length[node] = self.length[node*2] + self.length[node*2+1]

    def modify(self, y1, y2, val):
        lo = bisect_left(self.ys, y1)
        hi = bisect_left(self.ys, y2)
        self.update(1, 0, self.n, lo, hi, val)

    @property
    def total_length(self):
        return self.length[1]
```

```python
import heapq

class SkylineBuilder:
    def __init__(self):
        self.events = []

    def add(self, l, r, h):
        self.events.append((l, -h, r))
        self.events.append((r, 0, 0))

    def build(self):
        self.events.sort()
        heap = [(0, float('inf'))]
        result = []
        for x, neg_h, r in self.events:
            if neg_h:
                heapq.heappush(heap, (neg_h, r))
            while heap and heap[0][1] <= x:
                heapq.heappop(heap)
            h = -heap[0][0]
            if not result or result[-1][1] != h:
                result.append([x, h])
        return result
```

## 36. 完整实战手册

### 36.1 如何设计扫描线

设计扫描线的标准流程:

1. **问题归类**: 把问题归到"求面积 / 周长 / 交集 / 重叠层数"之一
2. **维度决策**: 选 x 还是 y 轴扫描, 一般选变化更剧烈的轴
3. **事件定义**: 在哪个点状态变化? 拆解为最少事件
4. **DS 选型**: 线段树(覆盖计数) / 堆(最值) / 平衡树(动态集合)
5. **贡献累加**: 相邻事件间 Δ × state
6. **边界**: 半开 vs 闭; 出边先 vs 入边先
7. **测试**: 小数据对比朴素解; 输出验证 (x, y)

### 36.2 编写扫描线的 7 个习惯

1. 离散化前先验证 y 坐标数 ≤ 200 (否则用坐标压缩)
2. 事件排序 key: `(x, type)` 默认可, 出边在前 = `type=-1` 自然排前
3. 累加区间的初始值: `prev_x = events[0][0]`
4. 第一个事件不贡献面积: 状态从"空"到"初始"
5. 输出时记得 mod (若题目要求)
6. 浮点用 round 或固定精度
7. 注意多边形坐标逆时针 / 顺时针 → 面积符号

```python
from bisect import bisect_left

class SegTree:
    def __init__(self, ys):
        self.ys = ys
        self.n = max(len(ys) - 1, 1)
        self.cnt = [0] * (4 * self.n)
        self.length = [0.0] * (4 * self.n)

    def _pushup(self, node, l, r):
        if self.cnt[node] > 0:
            self.length[node] = self.ys[r] - self.ys[l]
        elif l + 1 >= r:
            self.length[node] = 0.0
        else:
            self.length[node] = self.length[node*2] + self.length[node*2+1]

    def update(self, node, l, r, ql, qr, val):
        if ql >= r or qr <= l:
            return
        if ql <= l and r <= qr:
            self.cnt[node] += val
            self._pushup(node, l, r)
            return
        mid = (l + r) // 2
        self.update(node*2, l, mid, ql, qr, val)
        self.update(node*2+1, mid, r, ql, qr, val)
        self._pushup(node, l, r)

    def modify(self, y1, y2, val):
        lo = bisect_left(self.ys, y1)
        hi = bisect_left(self.ys, y2)
        self.update(1, 0, self.n, lo, hi, val)

class Solution:
    def rectangleArea(self, rectangles):
        MOD = 10**9 + 7
        events = []
        ys = []
        for x1, y1, x2, y2 in rectangles:
            events.append((x1, y1, y2, 1))
            events.append((x2, y1, y2, -1))
            ys.extend([y1, y2])
        ys = sorted(set(ys))
        seg = SegTree(ys)
        events.sort()

        area = 0.0
        px = events[0][0]
        for i, (x, y1, y2, typ) in enumerate(events):
            if i > 0:
                area += seg.length[1] * (x - px)
            seg.modify(y1, y2, typ)
            px = x
        return int(area) % MOD
```

```python
from typing import List

class PerfectRect:
    def isRectangleCover(self, rectangles: List[List[int]]) -> bool:
        area = 0
        min_x, min_y = float('inf'), float('inf')
        max_x, max_y = -float('inf'), -float('inf')
        corner = set()

        for x1, y1, x2, y2 in rectangles:
            area += (x2 - x1) * (y2 - y1)
            min_x, min_y = min(min_x, x1), min(min_y, y1)
            max_x, max_y = max(max_x, x2), max(max_y, y2)
            for p in [(x1,y1),(x1,y2),(x2,y1),(x2,y2)]:
                if p in corner:
                    corner.remove(p)
                else:
                    corner.add(p)

        big_area = (max_x - min_x) * (max_y - min_y)
        if area != big_area:
            return False
        return corner == {(min_x, min_y), (min_x, max_y),
                          (max_x, min_y), (max_x, max_y)}
```

```python
class RangeModule:
    def __init__(self):
        self.intervals = []   # list of [l, r) sorted, disjoint

    def addRange(self, left: int, right: int) -> None:
        new = []
        i = 0
        # 找 first interval with end > left
        while i < len(self.intervals) and self.intervals[i][1] < left:
            new.append(self.intervals[i])
            i += 1
        # merge overlapping
        l, r = left, right
        while i < len(self.intervals) and self.intervals[i][0] <= right:
            l = min(l, self.intervals[i][0])
            r = max(r, self.intervals[i][1])
            i += 1
        new.append([l, r])
        # add remaining
        while i < len(self.intervals):
            new.append(self.intervals[i])
            i += 1
        self.intervals = new

    def queryRange(self, left: int, right: int) -> bool:
        # 二分找最大 r in intervals with r >= right
        import bisect
        i = bisect.bisect_right(self.intervals, [right, float('inf')]) - 1
        if i >= 0 and self.intervals[i][0] <= left and self.intervals[i][1] >= right:
            return True
        return False

    def removeRange(self, left: int, right: int) -> None:
        new = []
        for l, r in self.intervals:
            if r <= left or l >= right:
                new.append([l, r])
            else:
                if l < left:
                    new.append([l, left])
                if r > right:
                    new.append([right, r])
        self.intervals = new
```

```python
        self.t = [0] * (n + 1)
```
