### 1.2 模板代码

#### 二分查找（左边界）

```python
def lower_bound(nums, target):
    lo, hi = 0, len(nums)
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    return lo
```

#### 滑动窗口

```python
from collections import Counter

def min_window(s, t):
    need = Counter(t)
    missing, left, best = len(t), 0, (0, float("inf"))
    for right, ch in enumerate(s, 1):
        if need[ch] > 0:
            missing -= 1
        need[ch] -= 1
        while missing == 0:
            if right - left < best[1] - best[0]:
                best = (left, right)
            need[s[left]] += 1
            if need[s[left]] > 0:
                missing += 1
            left += 1
    return "" if best[1] == float("inf") else s[best[0]:best[1]]
```

#### BFS 层序

```python
from collections import deque

def level_order(root):
    if not root:
        return []
    q, ans = deque([root]), []
    while q:
        level = []
        for _ in range(len(q)):
            node = q.popleft()
            level.append(node.val)
            if node.left: q.append(node.left)
            if node.right: q.append(node.right)
        ans.append(level)
    return ans
```

#### DFS 回溯

```python
def subsets(nums):
    ans, path = [], []
    def dfs(start):
        ans.append(path.copy())
        for i in range(start, len(nums)):
            path.append(nums[i])
            dfs(i + 1)
            path.pop()
    dfs(0)
    return ans
```

#### 并查集

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n
    def find(self, x):
        while x != self.parent[x]:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb: return False
        if self.size[ra] < self.size[rb]: ra, rb = rb, ra
        self.parent[rb] = ra
        self.size[ra] += self.size[rb]
        return True
```

#### 单调栈

```python
def next_greater(nums):
    ans, stack = [-1] * len(nums), []
    for i, x in enumerate(nums):
        while stack and nums[stack[-1]] < x:
            ans[stack.pop()] = x
        stack.append(i)
    return ans
```

#### TopK 小根堆

```python
import heapq

def top_k(nums, k):
    heap = []
    for x in nums:
        if len(heap) < k:
            heapq.heappush(heap, x)
        elif x > heap[0]:
            heapq.heapreplace(heap, x)
    return heap
```

#### Dijkstra

```python
import heapq

def dijkstra(graph, start):
    dist, pq = {start: 0}, [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d != dist[u]: continue
        for v, w in graph[u]:
            nd = d + w
            if nd < dist.get(v, float("inf")):
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist
```

### 1.3 题目难度分级

- Level 0：能解释复杂度、写出遍历与哈希。
- Level 1：Easy 10 分钟内一次通过；Medium 25 分钟内。
- Level 2：能识别滑窗、二分、树 DFS、基础 DP 等模式。

### 1.5 Coding Interview 最佳实践

- 复述题意并确认输入、输出、规模、是否允许修改输入。
- 先给基线解，指出瓶颈，再给优化解；不要静默写代码。
- 编码前说清不变量，例如“窗口始终满足至多 K 个不同字符”。
- 每写完一个分支就想边界，不在最后一次性补洞。
- 用最小样例手跑：正常、空、单元素、重复、极值、无解。
- 主动报时间与空间复杂度，区分平均、最坏与摊销。
- 卡住时暴露思路：列出已知模式、状态和可利用单调性。

## 2. 机器学习基础

### 2.1 监督学习

#### Logistic Regression

- 线性 logit + sigmoid；交叉熵；可解释、易校准；非线性靠特征交叉。
- 回答结构：目标函数 → 训练过程 → 超参数 → 复杂度 → 适用边界。

#### SVM

- 最大间隔；hinge loss；核技巧；大样本核矩阵成本高。
- 回答结构：目标函数 → 训练过程 → 超参数 → 复杂度 → 适用边界。

#### 决策树

- 按信息增益/Gini 分裂；可解释；高方差，需剪枝。
- 回答结构：目标函数 → 训练过程 → 超参数 → 复杂度 → 适用边界。

#### Random Forest

- Bagging + 特征随机；降方差；并行友好。
- 回答结构：目标函数 → 训练过程 → 超参数 → 复杂度 → 适用边界。

#### GBDT

- 逐轮拟合负梯度/残差；强表达；串行且易过拟合。
- 回答结构：目标函数 → 训练过程 → 超参数 → 复杂度 → 适用边界。

#### XGBoost

- 二阶近似、显式正则、缺失值方向、列采样。
- 回答结构：目标函数 → 训练过程 → 超参数 → 复杂度 → 适用边界。

#### LightGBM

- 直方图、leaf-wise、GOSS、EFB；大规模高效但小数据易过拟合。
- 回答结构：目标函数 → 训练过程 → 超参数 → 复杂度 → 适用边界。

#### 损失函数

- 分类：BCE、Softmax CE、Focal Loss、Hinge Loss。
- 回归：MSE 对大误差敏感；MAE 鲁棒但零点不可导；Huber 折中；Quantile 估计分位数。
- 排序：pairwise BPR/RankNet，listwise ListNet/LambdaRank。
- 不平衡：类别权重、focal、重采样；不要只换损失而忽略校准与业务代价。

#### 优化方法

- 闭式解只适合小规模且条件良好的问题。
- GD 稳但每步贵；SGD 噪声大；mini-batch 是工程默认。
- Momentum 加速一致方向；Adam 自适应但 weight decay 应使用 AdamW 式解耦。
- 树模型用贪心分裂；SVM 可用 SMO；EM 用于隐变量模型。

- 密度可达；能识别噪声和非球形簇；高维与密度不均困难。

- 最大方差投影，等价于中心化数据的 SVD；线性、可解释。
- 面试必须说明：目标、步骤、复杂度、超参数、失败场景。

#### t-SNE

- 保持局部邻域的可视化方法；全局距离与簇大小不可直接解释。
- 面试必须说明：目标、步骤、复杂度、超参数、失败场景。

### 2.4 特征工程

- 数值：缺失指示、标准化、稳健缩放、log1p、分桶、截尾。
- 类别：one-hot、频次、目标编码（必须折外计算）、embedding、hash。
- 时间：周期、间隔、窗口统计；所有特征必须 point-in-time correct。
- 交叉：业务驱动优先；树模型常自动交叉，线性模型需显式构造。
- 文本/图像：预训练表征 + 任务微调；监控分布漂移与 OOV。

### 2.5 模型选择

- 先定义指标、延迟、内存、解释性、更新频率和标注成本。
- 从简单基线开始；验证增益来自数据、特征还是模型。
- 严格按时间/用户/实体切分，避免泄漏。
- 交叉验证适用于 i.i.d.；时间序列用滚动验证。
- 超参搜索报告预算和随机种子，不只报最好点。

### 2.6 正则化

- L1 产生稀疏；L2 平滑权重；Elastic Net 折中。
- 早停限制有效训练步数；数据增强注入不变性；Dropout 类似随机子网络集成。
- 树模型用深度、叶子样本数、学习率、子采样正则。
- 正则强度必须在验证集选择；归一化影响 L1/L2 的公平性。

### 2.7 Bias-Variance Tradeoff

- 高偏差：训练与验证都差；加特征、模型容量或训练时间。
- 高方差：训练好验证差；加数据、正则、降容量、Bagging。
- 不可约噪声不能靠模型复杂度消除。
- 学习曲线比单点指标更能区分偏差与方差。

## 3. 深度学习基础

### 3.1 神经网络基础

#### 激活函数（ReLU / Sigmoid / GeLU / SwiGLU）

- Sigmoid 有界但饱和；适合概率门。
- ReLU 便宜、稀疏，但可能 dying ReLU。
- GeLU 平滑门控，Transformer 常用。
- SwiGLU 用门控乘法增强 FFN，参数量与宽度需一起比较。

#### 优化器（SGD / Adam / AdamW）

- SGD+Momentum 泛化常稳；Adam 收敛快。
- AdamW 解耦 weight decay，避免与自适应缩放混合。
- 都需学习率、warmup、梯度裁剪和数值监控。

#### BatchNorm / LayerNorm / RMSNorm

- BN 跨 batch 统计，CNN 常用，训练/推理统计不同。
- LN 对单样本特征归一化，序列长度与 batch 更灵活。
- RMSNorm 不减均值，计算更省，现代 LLM 常用。

#### Dropout

- 训练按概率置零并缩放，推理关闭。
- 与 BN、残差、超大数据共同使用时需实验验证。

### 3.2 CNN

- 卷积利用局部连接与权重共享；输出尺寸由 kernel/stride/padding/dilation 决定。
- 池化提供局部不变性但损失位置；现代网络常用步幅卷积或全局平均池化。
- ResNet 的恒等捷径改善深层优化；不是简单“防止梯度消失”一句话。
- 感受野、计算量 FLOPs、参数量要能现场计算。

### 3.3 RNN / LSTM / GRU

- RNN 共享时间权重，BPTT 易梯度消失/爆炸。
- LSTM：输入、遗忘、输出门和 cell state；加法通路改善长依赖。
- GRU 合并部分门，参数少、速度快；效果依任务。
- 并行性差是 Transformer 替代 RNN 的关键工程原因。

### 3.4 Transformer

- Attention(Q,K,V)=softmax(QKᵀ/√d_k)V；缩放避免 logits 方差随维度增大。
- Multi-Head 在多个投影子空间建模关系；输出拼接再投影。
- 位置：正弦、可学习、RoPE、ALiBi；2024-2026 高频追问 RoPE 外推。
- 训练常用 Pre-Norm、RMSNorm、SwiGLU；推理追问 KV Cache、MQA/GQA、FlashAttention。
- 标准注意力时间和注意力矩阵空间为 O(n²)；FlashAttention 改 IO，不改变算术阶。

### 3.5 损失函数

- 分类 CE；多标签 BCE；难例 Focal；度量学习 Contrastive/Triplet/InfoNCE。
- 序列语言模型是 next-token CE，注意 padding 与 causal mask。
- 蒸馏通常混合 hard label 与温度缩放 soft target。
- 数值稳定：log-sum-exp、直接用 logits 版本损失、避免先 softmax 再 log。

## 4. 概率与统计

### 4.1 概率基础

- 条件概率、全概率、独立与互斥必须区分。
- 期望线性不要求独立；方差相加通常需要不相关。
- 协方差为 0 不等于独立，联合高斯是常见例外。

### 4.2 贝叶斯

- 后验 ∝ 似然 × 先验；证据是归一化常数。
- MLE 只看似然；MAP 加先验；完整贝叶斯对参数积分。
- 共轭先验方便解析更新，但不是必须。

### 4.3 常见分布

- Bernoulli/Binomial：二元试验；Poisson：计数；Exponential：等待时间。
- Gaussian：连续噪声；Beta：概率先验；Dirichlet：多项概率先验。
- 要会期望、方差、支持集和典型业务场景。

### 4.4 假设检验

- 先定义 H0/H1、统计量、显著性水平和检验方向。
- p 值不是 H0 为真的概率；置信区间不是参数随机落入区间。
- 多重检验用 Bonferroni/FDR；A/B 反复偷看需序贯方法。

### 4.5 大数定律 / 中心极限定理

- LLN 说明样本均值收敛到期望；CLT 说明标准化和趋于正态。
- CLT 条件与收敛速度要说明，重尾/相关数据可能失效。

### 4.6 信息论

- 熵表示平均不确定性；交叉熵用于编码真实分布的代价。
- KL 非对称且不满足三角不等式；互信息衡量一般依赖。
- CE(P,Q)=H(P)+KL(P||Q)，训练时 H(P) 常为常数。

## 5. 线性代数与微积分

### 5.1 矩阵

- 形状先行：AB 要求 A 的列数等于 B 的行数。
- 秩表示独立方向数；条件数衡量扰动放大。
- 正交变换保持二范数；正定矩阵二次型恒正。

### 5.2 特征值

- Av=λv；表示线性变换的不变方向与缩放。
- 对称矩阵有实特征值和正交特征向量。
- 谱半径影响迭代稳定性与 RNN 梯度。

### 5.3 SVD

- A=UΣVᵀ，适用于任意矩阵。
- 截断 SVD 给 Frobenius 范数下最佳低秩近似。
- 应用：PCA、压缩、去噪、伪逆、协同过滤。

### 5.4 梯度

- 梯度给最陡上升方向；方向导数为梯度与方向的内积。
- Jacobian 处理向量对向量；Hessian 描述二阶曲率。
- 矩阵求导先写形状并用微分/迹技巧。

### 5.5 链式法则

- 复合函数局部导数相乘；反向传播是向量-Jacobian 积。
- 计算图反向复用中间结果，成本通常与前向同阶。
- 梯度检查用中心差分，但注意浮点误差与非光滑点。

## 6. 优化理论

### 6.1 凸优化

- 凸集任意两点连线仍在集合内；凸函数满足弦上界。
- 可微凸函数的一阶条件；强凸给唯一最优与更快收敛界。
- 约束优化要会拉格朗日、对偶、Slater 与 KKT。

### 6.2 梯度下降变种

- Batch GD 精确但贵；SGD 噪声可帮助探索；mini-batch 平衡硬件。
- Momentum 累积速度；Nesterov 前瞻；AdaGrad 适合稀疏但学习率单调衰减。
- Adam 用一二阶矩估计；AdamW 解耦权重衰减。

### 6.3 学习率调度

- Warmup 缓解训练初期不稳定；cosine 是现代模型常用默认。
- Step/Exponential 简单；Reduce-on-plateau 依赖验证指标。
- One-cycle 先升后降；调度必须与总步数、batch 和优化器配套。

### 10.2 STAR 法则

- Situation：3 句内交代业务、规模和痛点。
- Task：明确你的责任、目标与约束。
- Action：讲你的判断、方案、取舍、实验和协作；避免全用“我们”。
- Result：业务、模型、工程三类指标；说明统计显著性与持续时间。
- Reflection：失败、边界、如果重做会改变什么。

### 10.3 项目展示

- 准备 90 秒、5 分钟、15 分钟三个版本。
- 一张架构图、一张数据流、一张实验表即可；不堆截图。
- 必须能回答数据来源、标签、切分、基线、消融、上线、监控、回滚。
- 数字要自洽：样本、参数、GPU、训练时长、QPS、P99。
- 保密信息用比例和量级，不编造。

### 10.4 LinkedIn 优化

- Headline 用“目标岗位 + 方向 + 结果”，避免只写公司名。
- About 前三行说明专长、影响与目标。
- Experience 与简历一致，加入英文关键词便于检索。
- Featured 放项目、论文、技术文章；自定义 URL。
- 每周有质量地连接同方向工程师和招聘者，不群发模板。

### 12.1 高频题专项话术

#### 自我介绍

- 现在的定位 → 两段与岗位最相关经历 → 一个量化成果 → 为什么匹配本岗，控制 90 秒。
- 禁忌：背诵口号、贬低他人、无法量化、故事与简历冲突。

#### 最大成就

- 选能体现难度、个人贡献和可验证影响的案例，不一定是最大业务数字。
- 禁忌：背诵口号、贬低他人、无法量化、故事与简历冲突。

#### 最大失败

- 选真实但可控的失败；承担责任，讲诊断、补救、机制改进和后续证据。
- 禁忌：背诵口号、贬低他人、无法量化、故事与简历冲突。

#### 团队冲突

- 区分目标冲突、信息冲突和关系冲突；先对齐共同目标，再用数据/实验决策。
- 禁忌：背诵口号、贬低他人、无法量化、故事与简历冲突。

#### 加班态度

- 认可关键节点担当，也强调靠规划、自动化和复盘减少长期无效加班。
- 禁忌：背诵口号、贬低他人、无法量化、故事与简历冲突。

#### 离职原因

- 说未来拉力，不攻击前公司；聚焦方向、成长、职责和长期匹配。
- 禁忌：背诵口号、贬低他人、无法量化、故事与简历冲突。

#### 5 年规划

- 方向稳定、路径可调整：先成为独立 owner，再扩大系统与业务影响。
- 禁忌：背诵口号、贬低他人、无法量化、故事与简历冲突。

## 附录 A. 2024-2026 趋势与来源

### A.1 趋势观察

- 编码仍是门槛：高频以 Medium 模式题为主，要求沟通、测试和复杂度。
- 传统 ML 不退场：LR、树模型、评估、泄漏、偏差方差仍是通用底座。
- 大模型方向追问从 Transformer 八股扩展到 SFT/RL、RAG/Agent、显存与推理效率。
- 推荐系统更强调多阶段链路、偏差校正、生成式推荐、长序列、多任务和在线实验。
- 系统设计更重容量估算、故障模式、成本、隐私、监控与降级，而非组件清单。
- 项目真实性通过数据、公式、消融、线上约束、失败实验和个人贡献交叉验证。
