# Datawhale 补充阅读路线图

> 用法：每个节点 = 一个"-Datawhale补充"文件（全名见《[速查索引](Datawhale补充速查索引.md)》）。箭头 A→B 表示 A 是 B 的前置（硬依赖）；无箭头相连的节点可按需穿插。每个文件正文里的"本地相关文件"指向原章节——**补充文件永远与原章节成对读**（先原章节后补充，或交替）。

## 一、主干六阶段（通用骨架）

### 阶段 0 · 地基（约 2 周）

```text
手撕基础模块(01~04) → 手撕Transformer(05章) → LLM·第02章架构演进 → LLM·第03章位置编码
```

- 手撕基础的自检清单没过不要往下走（路线图失效的头号原因）；
- 第02章的"组件 diff 清单"是后续所有 LLM 文件的词汇表。

### 阶段 1 · LLM 主线（约 6 周）

```text
LLM·第01章总览 → 附录D(从零构建) → LLM·第07章训练实务 → 附录B(开源实战)
  → LLM·第09章SFT后训练 → LLM·第05章对齐 → LLM·第06章推理
  → LLM·第11章Scaling → LLM·第10章Model-Infra → 附录C(Prompt与RAG)
```

- 附录D 与第07章是"动手锚"：理论文件（对齐/推理/Scaling）读完都要回到产线验证；
- 第05→06 章是强依赖（RLVR/GRPO 同源）；第11→10 章是强依赖（账本→算子）；
- 支撑数学在此阶段插入：**第05章-08 信息论**（读第06章评估前必读）。

### 阶段 2 · Agent 线（约 4 周）

```text
Agent·第01章脉络 → 附录E(从零构建) → Agent·第04章范式 → Agent·第05章工作流
  → Agent·第02章RAG → Agent·第03章协议 → Agent·第07章记忆
  → Agent·第06章多智能体 → Agent·第08章评估
```

- 附录E 在范式之前：先有内核再谈范式；第03章协议可提前到第05章后任一时点；
- 第08章评估收口：把前八个文件的产物串成一次"三层评估 + 事故复盘"。

### 阶段 3 · 搜推广线（约 5 周）

```text
[数学·第06章-03 二阶方法] → 经典推荐·第04章多任务 → 第24章特征交叉
  → 第25章召回 → 第26章重排 → 第19章蒸馏
  → SID·Tokenizer 全景 → GR·HSTU与生成式架构 → 第16章小型LLM设计模式
  → RL·教程对照 → 工业架构·fun-rec工业谱系 → PTH·权重工程
```

- 二阶方法是第24章的数学前置；第25/26 章依赖第24章的谱系词汇；
- 第16章依赖 LLM 阶段 1 完成（三阶段产线映射）；RL 教程对照在第05章对齐之后读更顺（PPO 已熟）；
- 支撑数学：**第03章-08 假设检验**（做 AB 实验前必读）。

### 阶段 4 · 工程与职业线（约 3 周）

```text
工具·Linux与容器 → 工程·14-Git规范 → 工程·4-数据工程与特征平台
  → 工程·0-K8s部署 → 工程·2-生产服务化 → 工程·1-推荐端到端设计
```

- Linux 是一切远程训练的前置（可与其他阶段并行推进）；
- 0-K8s → 2-服务化 → 1-端到端是递进关系（部署→服务→总装）。

### 阶段 5 · 具身线（约 4 周，可选方向）

```text
具身·第01章概论 → 第05章模仿学习数据 → 第07章仿真器基准
  → 第04章VLA清单 → 第08章世界模型 → 第06章RL与Sim2Real
```

- 第07章在第05章之后（先有数据与算法，再进考场）；
- 第04章 VLA 清单是"消费方"，依赖前三个文件建立的环境与数据概念。

## 三、面试线（贯穿，每周固定投入）

```text
面试·第10章LeetCode专题刷题法（起步）→ 第09章算法题库扩展（阶段②③题源）
  → 第14章高级图论（竞赛向）→ 面试笔记·LLM面试（求职期前 6 周）
```

- 四阶段刷题法从阶段 0 就启动（每天 2~3 题），与所有主线并行；
- LLM 面试笔记在读完 LLM 主线 + Agent 线后收益最大（对练表能对出深度）。

## 六、进度自检（每周一问）

2. 它的前置（第五节速查表）都勾掉了吗？

> 三连"否"即降速：回退到前置节点，宁可慢不可虚。
